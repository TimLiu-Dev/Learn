2. Browser Security: CORS & Cookie Hardening

Cross-Origin Resource Sharing (CORS)

Origin = Scheme + Host + Port. If different, browser triggers CORS.

  • Simple Request: GET/HEAD/POST with standard headers (text/plain, multipart/form-data, application/x-www-form-urlencoded). Directly dispatched; browser checks Access-Control-Allow-Origin on response.
  • Preflighted Request: Triggered by PUT/DELETE/PATCH, custom headers (e.g. Authorization), or Content-Type: application/json. Browser sends OPTIONS probe before actual request.
  • Credentials Rule: If Access-Control-Allow-Credentials: true, the origin header MUST NOT be wildcard *; it must explicitly match client origin.

3. Modern TLS 1.3 Architecture & Handshake

StepSender $\rightarrow$ ReceiverPayload Content & Cryptographic Operation
1. ClientHelloClient $\rightarrow$ ServerSupported TLS versions (1.3), cipher suites (e.g. TLS_AES_256_GCM_SHA384), SNI extension (hostname), and Key Share (client ephemeral ECDHE public key e.g. X25519).
2. ServerHelloServer $\rightarrow$ ClientChosen cipher suite, server Key Share (server ephemeral ECDHE public key). Both sides compute symmetric session key here!
3. Encrypted ExtensionsServer $\rightarrow$ ClientEverything encrypted: Server X.509 Certificate, CertificateVerify (digital signature), and Server Finished HMAC.
4. Client FinishedClient $\rightarrow$ ServerClient Finished HMAC. Handshake complete in 1 RTT! First application data payload attached immediately.

Perfect Forward Secrecy (PFS): Static RSA key exchange is completely removed. Compromise of server private key in the future cannot decrypt past recorded sessions because session keys depend strictly on discarded ephemeral keys.

4. gRPC & Protocol Buffers

Protocol Buffers (Protobuf) Efficiency

  • No Field Names on Wire: Replaces string field keys with 1-byte integer tags (field numbers).
  • Base-128 Varints: Small numbers encode into 1 byte (7 data bits + 1 continuation bit) rather than 4 or 8 bytes.
  • Zero-Copy Deserialization: Binary parser validates offsets directly without parsing JSON strings or escaping.
