MAC addresses Link

Session 4 · RFC 9542 §2.1 · RFC 9724 §2.1

Size
48 bits, six hex bytes: xx:xx:xx:xx:xx:xx. Belongs to an interface, not a computer.
OUI
First 3 bytes: prefix the IEEE sells to a manufacturer (why Wireshark can print a vendor). Last 3: chosen by the manufacturer.
Broadcast
ff:ff:ff:ff:ff:ff: every interface on the link accepts it. Used by ARP and DHCP.
Private Wi-Fi
macOS 15+: per-network address, Off / Fixed / Rotating. Randomised → locally administered.
Docs range
00:00:5e:00:53:00–…:ff (RFC 9542 §2.1.4)
Scope
One hop only: every router builds a new frame with new MACs; IP addresses stay.

Read the first byte's second hex digit

2nd hex digitI/G bit (value 1)U/L bit (value 2)Meaning
0 4 8 c0 unicast0 universala factory address under an OUI
2 6 a e0 unicast1 localsoftware-chosen, e.g. private Wi-Fi
1 5 9 d1 group0 universalmulticast
3 7 b f1 group1 localgroup; incl. broadcast ff:…

Example f6:…: 6 = 0110 → I/G 0, U/L 1: locally administered unicast. Wireshark calls the U/L bit the LG bit and decodes both under each address.

Header = 6 + 6 + 2 = 14 bytes. Max payload 1,500 = Ethernet's MTU.

Switches

  • Learn source MAC → arrival port; entries expire.
  • Known destination → that one port. Unknown or broadcast → flood to every other port.
  • Never modify the frame; invisible to hosts. Home "router" = router + switch + Wi-Fi access point.

Wi-Fi

  • Real 802.11 frames carry four address fields; without monitor mode the driver hands Wireshark a "fake" Ethernet II header.

IPv4 address and header Network

Session 5 · RFC 791 §3.1 · IANA protocol numbers

32 bits, dotted decimal (four bytes 0–255, e.g. 192.0.2.10), 2³² ≈ 4.3 billion addresses; IANA's free pool ran out 3 Feb 2011. Service: best effort, connectionless: no acks, retransmission, ordering or flow control (RFC 791 §1.4).

bit 081624 … 31
VersionIHLDSCP · ECNTotal length IdentificationFlagsFragment offset TTLProtocolHeader checksum Source address Destination address Options (rare; only if IHL > 5)

Five rows × 4 bytes = 20-byte fixed header.

FieldBitsWhat it's for
Version44 (IPv6 has its own header)
IHL4header length in 4-byte words; 5 = 20 bytes, no options
DSCP · ECN8priority marking + congestion signal; usually 0
Total length16header + data in bytes; max 65,535
Identification · Flags · Fragment offset16 · 3 · 13fragmentation: same ID per fragment; flags = reserved, DF, MF (set on all but the last); offset in 8-byte units
TTL8hop limit: each router −1; at 0 → discard + ICMP Time Exceeded (type 11)
Protocol8what's inside: 1 ICMP · 6 TCP · 17 UDP
Header checksum16header only; recomputed every hop (TTL changes)
Source · Destination32 · 32original sender, final destination (unchanged end to end, except NAT)

Too big for the next link? Router fragments it (reassembled only at the destination; lose one fragment, lose the packet: RFC 8900). With DF set it drops it and returns ICMP 3/4 instead → path MTU discovery (RFC 1191).

Subnet math (CIDR) Network

Session 6 · RFC 4632 §3.1 · RFC 1122 §3.2.1.3 · Systems Approach §3.3.5

QuantityRule
a.b.c.d/nfirst n bits = prefix (network); last 32 − n = host part
Addresses232−n
Network addressaddress AND mask (host bits all 0)
Broadcasthost bits all 1
Usable hostsnetwork + 1 … broadcast − 1; count 232−n − 2 (except /31, /32)
Mask spellings/20 = 255.255.240.0 = 0xfffff000 (macOS ifconfig)

Head shortcut: find the octet where the prefix ends; if b of its bits are network bits, subnets step by 28−b in that octet. Round down to a multiple for the network; add step − 1 for the broadcast. Earlier octets copy; later ones become 0 (network) or 255 (broadcast).

Same subnet? AND the destination with your mask: equal to your network → deliver directly (ARP for it); different → send to the default gateway (RFC 1122 §3.3.1.1).

IPv6 addresses Network

Session 11 · RFC 4291 · RFC 5952 §4 · Systems Approach §4.2

128 bits (2¹²⁸ ≈ 3.4 × 10³⁸), written as eight groups of 16 bits in hex, separated by colons. On an ordinary LAN the split is always /64:

global routing prefix (from the ISP)subnet IDinterface ID: 64 bits, chosen by the host network prefix: 64 bits, advertised by a router (Router Advertisement)e.g. 2001:db8:85a3:42:1c2d:3e4f:5a6b:7c8d/64

Canonical form (RFC 5952 §4)

RuleExample
Drop leading zeros in each group0db8 → db8, 0000 → 0
Longest run of zero groups → ::, once2001:db8:0:0:0:0:2:1 → 2001:db8::2:1
Longest run wins2001:db8:0:0:7:0:0:0 → 2001:db8:0:0:7::
Tie → compress the first—
Never :: for a single zero group2001:db8:7:0:6:5:4:3 stays as is
Lowercase hex2001:DB8::AB → 2001:db8::ab

In URLs, bracket the address: http://[::1]:8080/ (RFC 3986 §3.2.2). Link-local needs a zone: fe80::1%en0 (RFC 4007 §11).

Kinds of address (first bits tell you)

PrefixTypeNotes
::1/128loopbacklike 127.0.0.1
fe80::/10link-localnever routed; every interface has one
fc00::/7unique local (ULA)site-private, like RFC 1918; in practice fd…
2000::/3global unicastpublic; starts with 2 or 3
ff00::/8multicastff02::1 = all nodes on the link
ff02::1:ffxx:xxxxsolicited-nodelast 24 bits of a target; NDP sends here
2001:db8::/32documentationexamples only (RFC 3849)

No broadcast in IPv6: multicast does its jobs. An interface normally has several addresses at once.

Where the interface ID comes from

  • SLAAC (RFC 4862): prefix from a Router Advertisement + the host's own 64-bit ID. No server, no lease. ifconfig flag: autoconf.
  • Old way, modified EUI-64: MAC with ff:fe inserted in the middle and the U/L bit flipped. Trackable, so now discouraged (RFC 8064 §3); stable random-looking IDs instead.
  • Temporary addresses (RFC 8981 §3.8): rotate, by default preferred 1 day, valid 2 days; used for outgoing connections. Flag: temporary.
