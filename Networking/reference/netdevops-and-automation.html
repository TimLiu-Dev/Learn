3. Campus Security & IP Multicast · S80, S81

AAA & L2 Access Hardening

  • RADIUS (UDP 1812/1813): Encrypts password only (or RadSec TCP 2083 TLS); best for 802.1X/Wi-Fi.
  • TACACS+ (TCP 49): Encrypts entire payload; splits Auth/Authz/Acct for per-CLI command control.
  • L2 Trio: DHCP Snooping → Dynamic ARP Inspection (DAI) → IP Source Guard (whitelist static IPs!).

IPv4 Multicast Rules (224.0.0.0/4)

  • L2 MAC Overlap: Maps only low 23 bits onto 01:00:5e:XX:YY:ZZ (32 IPs share 1 MAC!).
  • IGMP Snooping: Prevents VLAN multicast flooding; isolated L2 VLANs need an IGMP Querier.
  • PIM-SM RPF: Drops multicast packets arriving off the unicast best-path toward Source S.
