ARP: IPv4 address → MAC address Link

Session 7 · RFC 826 · Systems Approach §3.3.6

RequestReply
Opcode12
Sent bywhoever needs a MAConly the owner of the target IP
Frame tobroadcast ff:ff:ff:ff:ff:ffunicast to the asker
Says"Who has X? Tell Y" (sender IP + MAC, target IP)"X is at mac"

Rides directly in a frame, EtherType 0x0806, not inside IP. Wireshark also shows ARP Probe/Announcement: address-conflict checks (RFC 5227).

  • Local link only: broadcasts never cross a router. Off-subnet destination → ARP for the gateway's IP; the IP header keeps the far destination.
  • Cache: entries expire, typically 15–20 min (macOS: about 20 min after validation, man 4 arp). The target also caches the asker's mapping.
  • No answer: entry shows (incomplete); after several tries the host counts as down for ~20 s and sends fail: sendto: Host is down.
  • No authentication: any new reply overwrites the old mapping → ARP spoofing (session 34).
  • IPv6: no ARP; NDP does the job.

DHCP: getting a configuration Application

Session 8 · RFC 2131 §3.1–3.2, §4.4.5 · options: RFC 2132

A host needs four facts before it can talk: IP address, subnet mask, default gateway, DNS server. With no address yet it shouts: UDP 68 → 67, IP 0.0.0.0 → 255.255.255.255, frame to ff:ff:ff:ff:ff:ff. Routers don't forward broadcasts, so bigger networks put a relay agent on each subnet.

Routing and forwarding Network

Session 9 · RFC 4632 §5.1 · Systems Approach §3.3.4–3.3.5

Forwarding
Local, per packet: look up the destination, send out an interface. Every router and your Mac.
Routing
Network-wide process that builds the tables: OSPF inside an organisation, BGP between networks (named only).
Entry
destination prefix → next hop + interface.
Direct
Destination on this link: ARP for the destination.
Via gateway
ARP for the router; destination IP unchanged, only the frame's destination MAC changes.
Default route
0.0.0.0/0 (macOS: default): zero prefix bits, matches everything; "anything else → gateway".
Hop by hop
Each router repeats the lookup on its own table. Nobody knows the whole path; the way back can differ.

Traceroute mechanics Network

Session 9 · man traceroute · RFC 792 · rate limiting: RFC 1812 §4.3.2.8

  1. Send probes with TTL 1, then 2, 3, …
  2. The probe with TTL n dies at router n, which returns ICMP Time Exceeded (type 11) from its own address → hop n revealed.
  3. macOS probes are UDP to port 33434 and up; nothing listens there, so the destination answers Port Unreachable (type 3, code 3) → stop.
  4. With -I: ICMP Echo probes instead; some networks treat the two differently.
Default / optionMeaning
3 probes per TTL-q 1 for one
5 s wait per probe-w to change
64 hops max-m 5 to stop early
-nnumbers only, no reverse-DNS per hop
*no reply in time. Not loss: many routers don't send or rate-limit Time Exceeded. Later hops answering = the silent hop forwards fine. Stars at the end → firewall near the target; try -I.

NAT (NAPT) Network Transport

Session 10 · RFC 3022 §2, §4 · RFC 4787 · RFC 4864 · RFC 6598

Many private hosts (RFC 1918 ranges) share one public address. Home routers do NAPT: translate address and port. Ports (16-bit) are what tell replies apart.

DirectionRouter does
Outboundrewrite source IP → public IP and source port → a port it picks; record the pair in the translation table. Destination untouched.
Inboundlook up the destination port; rewrite destination back to the private IP and port; forward onto the LAN.
Unsolicited inboundno matching entry → dropped

Entry, e.g. 192.168.1.20:51000 ⇄ 203.0.113.7:40001. Rewriting ports means fixing TCP/UDP checksums: a layer violation and the source of NAT's side effects.

  • Mappings are created only by outbound traffic and expire when idle (UDP ≥ 2 min, 5+ recommended: RFC 4787 REQ-5).
  • Port forwarding = a static mapping you configure: public port → inside host:port.
  • NAT ≠ firewall: drops happen for lack of a mapping; the protection is the stateful filtering run alongside (session 36).
  • Peer-to-peer: STUN learns your public IP:port (RFC 8489), hole punching tries a direct path, TURN relays when that fails (RFC 8656).
  • CGNAT: ISP-run NAT; your router's WAN address is in 100.64.0.0/10. Port forwarding on your router can't help.
  • Double NAT: e.g. ISP modem-router + your own router. Spot NATs by comparing LAN IP, public IP and router WAN IP, and classifying the first traceroute hops: private / shared / public.

A Neighbor Solicitation goes to the solicited-node multicast ff02::1:ffxx:xxxx (last 24 bits of the target), not to everyone. ndp -an is IPv6's arp -a.

SLAAC: an address without a server

  1. Make a link-local address (fe80:: + interface ID); duplicate address detection checks no neighbour has it.
  2. Ask for routers (RS); a Router Advertisement lists one or more /64 prefixes.
  3. Prefix + own 64-bit interface ID = address. No lease, no server state. Temporary addresses rotate on top (RFC 8981).

DHCPv6 (RFC 8415) exists and some networks use it.
