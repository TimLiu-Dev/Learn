Two minutes, from memory, before you read on:

Why can an IGP like OSPF not be used to route the entire global Internet?

OSPF requires every router to maintain an identical Link-State Database of all links and routers. The global Internet contains ~1,000,000 routes; calculating Dijkstra's SPF across the entire planet would consume terabytes of RAM and crash router CPUs on every link flap.

The Internet is a network of networks

The Internet is not a single giant network managed by one entity; it is an interconnected federation of over 100,000 independently owned and operated networks called Autonomous Systems (ASNs).RFC 4271: A Border Gateway Protocol 4 (BGP-4). Y. Rekhter, T. Li, S. Hares (2006).

Inside an Autonomous System (like Google, Comcast, or a university), an Interior Gateway Protocol (OSPF or IS-IS) handles internal routing. But to exchange prefixes between independent organizations, networks speak the only protocol capable of global scale and policy enforcement: the Border Gateway Protocol (BGP).

Autonomous Systems & ASNs

An Autonomous System (AS) is a collection of IP networks and routers under the administrative control of a single organization presenting a unified routing policy to the outside world:

  • Assigned by IANA and Regional Internet Registries (ARIN for North America, RIPE NCC for Europe, APNIC for Asia-Pacific).
  • 2-Byte ASNs: 1 to 65535 (Private ASNs: 64512 to 65534, similar to RFC 1918 private IPs).
  • 4-Byte ASNs (RFC 4893): Up to 4,294,967,295. Examples: Google is AS15169, Cloudflare is AS13335, Lumen/Level3 is AS3356.

How BGP Differs: The Path-Vector Model

BGP is fundamentally different from OSPF and RIP:

  • Runs over TCP Port 179: BGP does not implement its own retransmission or packet acknowledgment mechanisms; it establishes a standard point-to-point TCP session on port 179 between neighbor IPs.
  • Path-Vector Protocol: Instead of advertising link costs or hop counts, BGP advertises reachable IP prefixes accompanied by an ordered list of every Autonomous System the advertisement has traversed: the AS-PATH.
  • Loop Prevention via AS-PATH: When a router receives an eBGP advertisement, it inspects the AS-PATH attribute. If it sees its own ASN anywhere in the list, it immediately drops the advertisement! This prevents inter-domain loops effortlessly.

eBGP vs iBGP Mechanics

BGP operates in two distinct modes depending on neighbor ASN:

1. External BGP (eBGP)

  • Peers reside in different Autonomous Systems (e.g. AS 100 peering with AS 200).
  • By default, eBGP packets are transmitted with an IP TTL of 1, enforcing that peers must be directly connected across the same physical link (unless explicitly configured with ebgp-multihop).
  • When re-advertising a prefix to an eBGP peer, the router prepends its own ASN to the beginning of the AS-PATH.

2. Internal BGP (iBGP) & Route Reflectors

  • Peers reside within the same Autonomous System. Used to distribute externally learned Internet routes to all edge routers inside the AS.
  • The iBGP Split-Horizon Rule: To prevent routing loops inside an AS (where AS-PATH does not change), an iBGP router will never re-advertise a route learned from one iBGP peer to another iBGP peer!
  • This rule historically required a full mesh of iBGP sessions between every router (N(N − 1) / 2). In modern large networks, this scaling bottleneck is solved using BGP Route Reflectors (RRs), which are authorized to reflect routes to client peers.

    $ telnet route-views.routeviews.org
    (Username: rviews with no password).

    route-views> show ip bgp 8.8.8.8
    Look for: Network: 8.8.8.0/24, Path: 3356 15169 i (traversed Lumen AS3356 to reach Google AS15169).
  3. Check the total size of the global IPv4 routing table: 
    route-views> show ip bgp summary
    Notice that the table contains over 950,000 distinct routing prefixes!

Free Recall Practice

From memory: explain why BGP uses the AS-PATH attribute for loop prevention. What is the iBGP split-horizon rule?

Key points to compare against:

  • AS-PATH loop prevention: Every router prepends its own ASN to the AS-PATH when advertising to an eBGP peer. When an eBGP router receives an advertisement, it scans the AS-PATH list; if its own ASN appears in the path, it drops the update to prevent a circular inter-AS loop.
  • iBGP split-horizon: Because routers within the same AS do not prepend their ASN to AS-PATH, an iBGP router is forbidden from re-advertising a route learned from one iBGP peer to any other iBGP peer, requiring either a full mesh of peerings or Route Reflectors.
