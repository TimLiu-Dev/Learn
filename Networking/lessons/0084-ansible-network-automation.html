Warm-up · from earlier sessions

Two minutes, from memory, before you read on:

On Linux servers, Ansible copies Python modules over SSH and executes them on the managed node. Why would that immediately fail against a Cisco Catalyst switch or Juniper router—and how do Ansible network collections solve it?

Proprietary switch operating systems restrict shell access and don't allow running arbitrary uploaded Ansible Python modules on the switch CPU. Instead, network collections execute modules locally on the Ansible control node (connection: ansible.netcommon.network_cli, netconf, or httpapi) and send only pure CLI, XML, or JSON RPCs over the wire!

1 · Inventory Hierarchy & Variable Precedence

Good Ansible separates what (data in YAML inventories) from how (templates + playbooks):

  • group_vars/all.yml — Global defaults (NTP servers, syslog targets, SNMPv3 auth).
  • group_vars/leaves.yml — Role-level settings (e.g., Leaf BGP ASN base, Anycast GW MAC).
  • host_vars/leaf1.yml — Per-box uniqueness (loopback0_ip, router_id, bgp_asn). Host vars override group vars!

2 · Jinja2 Templates & Safe Rollout Flags

Instead of writing brittle regex edits line-by-line, render complete vendor stanzas deterministically with Jinja2 (.j2) and gate every production run with:

  • ansible-playbook site.yml --check --diff — Simulates execution and prints unified diffs before changing a single packet.
  • serial: 1 (or canary batches serial: [1, 5, "25%"]) — Halts rollout on the very first device failure so a bad BGP route-map never bricks an entire region simultaneously!

  hosts: leaves

Why do Ansible playbooks targeting Cisco IOS-XE, Arista EOS, or Juniper switches run module Python code on the control node instead of copying Python scripts to the switch?

      
    
        
  1. Because Ansible cannot parse YAML files larger than 4 KB over SSH connections.
    2. 
        
  2. Network OS shells block uploading arbitrary Python modules, so Ansible speaks CLI/NETCONF/API.
    3. 
        
  3. Switches disable IP routing automatically whenever a Python interpreter starts.
    4. 
        
  4. Because BGP routers only accept commands sent via UDP SNMP port 162.
    5. 
      

      
Network automation modules execute on the Ansible controller over network_cli / netconf / httpapi transports.

  1. 1500, because group_vars/all always overrides host-specific variables for safety.
