Why a comprehensive review session?

In isolation, each network protocol makes intuitive sense: 802.1Q segments broadcast domains, STP prevents loops, OSPF routes internally, BGP peers across the planet, IPsec encrypts tunnels, and VXLAN scales data centers.See Master Curriculum: Track B Capstone.

In production, however, these protocols do not operate in silos; they interact across the exact same physical silicon and fiber. A single MTU oversight in a VXLAN tunnel drops TCP sessions; a missing route-map filter in BGP leaks private traffic to transit providers; an unshielded patch cord creates CRC errors that flap OSPF adjacencies. Why does Ethernet frame forwarding require Spanning Tree Protocol while IP packet forwarding does not? How did modern hyper-scale data centers eliminate STP?

Key points to compare against:

  • Why Ethernet needs STP: IP packets contain a Time-to-Live (TTL) field that routers decrement, dropping packets safely when TTL reaches 0. Ethernet frames lack any TTL mechanism; a Layer 2 loop causes broadcast frames (like ARP) to circulate and duplicate indefinitely, generating a catastrophic broadcast storm and CAM table thrashing. STP prevents loops by placing redundant ports into a blocking state.
  • How modern data centers eliminated STP: Data centers replaced Layer 2 switching fabrics with pure Layer 3 Leaf-Spine (Clos) routed underlays running BGP/OSPF with Equal-Cost Multi-Path (ECMP). Layer 2 virtualization is handled via VXLAN encapsulation over UDP port 4789, keeping 100% of physical fiber links active with zero blocked ports.

Explain the difference between Transit and Settlement-Free Peering in BGP economics. How does Local Preference enforce business policy?

Key points to compare against:

  • Transit vs Peering: IP Transit is a commercial contract where a customer network pays an upstream Tier-1 provider for access to the entire global Internet routing table. Settlement-free peering is a bilateral agreement at an Internet Exchange Point (IXP) where two networks exchange traffic destined solely for each other's customers at zero financial charge.
  • Local Preference enforcement: Local Preference is evaluated at Step 2 of the BGP decision algorithm (before AS-PATH length). Engineers set higher Local Preference on routes learned from paying customers (e.g. 200) and free peers (150) than on expensive upstream transit providers (100), ensuring outbound traffic always exits via the most economical link.

What causes an MTU black hole in an IPsec tunnel or VXLAN overlay, and how is it resolved in production?

Key points to compare against:

  • Root cause: Tunnel encapsulation adds outer IP, UDP, ESP, or VXLAN headers (adding 50 to 70 bytes of overhead). When internal servers send standard 1500-byte packets with the Don't Fragment (DF) bit set, the encapsulated packet exceeds the 1500-byte physical MTU. If intermediate routers drop the oversized packet and firewalls block the return ICMP "Fragmentation Needed" error, Path MTU Discovery (PMTUD) fails and the TCP connection hangs indefinitely.
  • Production resolution: In data center underlays, engineers configure Jumbo Frames (MTU 9000 or 9216 bytes). On enterprise VPN edge gateways, engineers configure TCP MSS Clamping (e.g. ip tcp adjust-mss 1360) to force TCP endpoints to negotiate segment sizes that fit within the tunnel.

3 · The Principal Network Engineer Architecture Gauntlet

  
Diagnose these three complex production incidents like a Principal Network Engineer:


  

    
Scenario A: The 3 AM Root Bridge Hijack

    
Incident: A corporate campus with 30 switches suddenly experiences a total network brownout. Latency between internal servers spikes to 2,000 ms, video calls drop, and switch management consoles become unresponsive. Running show mac address-table reveals that MAC addresses are flapping between ports every few seconds. Further investigation shows that an intern plugged a cheap, unmanaged test switch with priority 0 into an open cubicle wall jack.

    
Root Cause Analysis: The rogue switch announced Bridge ID priority 0, winning the Root Bridge election and pulling the entire campus spanning tree topology toward an underpowered 100 Mbps desktop switch. Links flapped and looped.

    
Architectural Remediation: (1) Manually set core switch priorities to 0 and 4096 so edge devices can never win. (2) Enable spanning-tree portfast bpduguard default globally on all access ports to automatically err-disable any port receiving BPDUs.

  


  

    
Scenario B: The \$80,000 Accidental Transit Leak

    
Incident: A regional tech company connects to an Internet Exchange Point (IXP) for free peering with Netflix and Google, while maintaining an expensive metered transit link with Cogent. At the end of the month, the CFO receives an \$80,000 bandwidth overage bill from Cogent. Traffic graphs show that outbound traffic through Cogent spiked by 800% overnight.

    
Root Cause Analysis: An engineer added a new BGP peering session at the IXP but forgot to apply an outbound route-map filter. The company accidentally re-advertised prefixes learned from Cogent (Transit) out to other IXP peers (violating the Gao-Rexford valley-free rule). External networks began routing their global transit traffic through the company's network to reach Cogent!

    
Architectural Remediation: Implement strict BGP filtering using BGP Communities and prefix-lists: tag all transit-learned routes with community NO-EXPORT-PEERS and enforce that only locally originated prefixes (owned by the company's ASN) are ever advertised to peering partners.

  


  

    
Scenario C: The "Web Page Hangs at 99%" Tunnel Freeze

    
Incident: Remote branch office users can ping 8.8.8.8 and establish SSH connections to cloud servers across a new IPsec site-to-site tunnel. However, whenever they attempt to load an internal web application or fetch a 20 KB image, the browser spinner spins forever and eventually times out with ERR_CONNECTION_TIMED_OUT.

    
Root Cause Analysis: Small packets (ping echo requests, SSH keystrokes, TCP handshakes) are under 100 bytes and easily fit inside the tunnel. However, web server HTTP responses emit full-sized 1,500-byte TCP segments. IPsec tunnel encapsulation adds 60 bytes of overhead, producing a 1,560-byte packet. The public broadband router drops the packet because it exceeds 1,500 bytes and has DF=1. A corporate firewall dropped the return ICMP Type 3 Code 4 notification, breaking Path MTU Discovery.

    
Architectural Remediation: (1) Allow ICMP Type 3 Code 4 (Fragmentation Needed) through perimeter firewalls. (2) Configure TCP MSS Clamping on the IPsec router: ip tcp adjust-mss 1360, forcing client and server TCP stacks to restrict segment size during the initial 3-way handshake.
