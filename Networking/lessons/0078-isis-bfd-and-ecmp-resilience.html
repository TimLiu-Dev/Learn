IS-IS, BFD, ECMP &amp; Segment Routing Overview

Why hyperscalers and telecom backbones love IS-IS over OSPF, how BFD triggers sub-50 ms link failure detection, how 5-tuple ECMP prevents packet reordering, and how Segment Routing removes LDP state.

Warm-up · from earlier sessions

Two minutes, from memory, before you read on:

Two optical routers are linked via a passive DWDM media converter. One physical fiber snaps mid-span, so Router A's Ethernet PHY port stays UP/UP against the local converter even though traffic is dead. With OSPF's default 40-second Dead Timer, traffic black-holes for up to 40 seconds! How do service providers cut failover down to ~150 ms without flooding OSPF hellos every 50 ms?

They offload fast liveness probing to BFD (Bidirectional Forwarding Detection, RFC 5880). BFD sends ultra-lightweight UDP packets every e.g. 50 ms (multiplier 3 = 150 ms timeout) directly in forwarding hardware/dedicated thread. When BFD fails, it immediately notifies OSPF, IS-IS, and BGP simultaneously to withdraw the link.

1 · IS-IS (Intermediate System to Intermediate System) vs OSPF

Both IS-IS and OSPF are link-state IGPs running Dijkstra's SPF algorithm, yet IS-IS dominates telecom backbones and massive AI/cloud underlays for clean architectural reasons:

DimensionOSPFv2 / OSPFv3IS-IS (ISO 10589 / RFC 1195)
Transport LayerRuns directly over IP (protocol 89); needs separate OSPFv3 for IPv6Runs directly over L2 Ethernet frames (CLNS) — naturally dual-stack (IPv4 + IPv6) inside one session!
ExtensibilityFixed LSA types (Type 1–11), Opaque LSAs bolted on laterClean TLV (Type-Length-Value) encoding — adding Segment Routing or Traffic Engineering is just a new TLV
Area BoundariesSplit sits inside ABR routers (router interfaces in different areas)Split sits between routers (L1, L2, or L1/L2 routers; whole router belongs to an area)

2 · BFD (Bidirectional Forwarding Detection)

Running 50 ms OSPF/BGP timers scales poorly because protocol hellos require parsing routing tables in main control-plane CPU. BFD (UDP dst port 3784 single-hop / 4784 multihop) solves this universally:

  • Protocol-agnostic: One BFD session can trigger instant teardown across IS-IS, OSPF, eBGP/iBGP, and static routes at once.
  • Timer math: Detection time = max(localDesiredMinTx, peerRequiredMinRx) * detectMult. With 50 ms × 3, link loss triggers reroute in 150 ms.

3 · ECMP (Equal-Cost Multi-Path) & Polarization Traps

When Dijkstra finds multiple equal-metric paths to a destination prefix, the FIB installs an ECMP group. Why shouldn't switches simply send Packet 1 to Link A and Packet 2 to Link B (per-packet round-robin)?

Why Flow-Based Hashing (5-Tuple) Beats Per-Packet Load Balancing: Per-packet spraying across uneven links causes out-of-order TCP segments, triggering spurious 3-DupACK fast retransmits and collapsing throughput! Instead, ASICs hash the invariant flow 5-tuple (srcIP, dstIP, proto, srcPort, dstPort) modulo N links so every packet of a TCP flow takes the exact same path.
Trap — Hash Polarization: If Spine switches and Leaf switches compute the exact same hash function on the exact same fields, Leaf hashes (even -> uplink 0, odd -> uplink 1), meaning Spine 0 only ever sees even-hashed flows and leaves half its own downlinks idle! Real ASICs apply different hash seeds/rotations per tier.

4 · MPLS & Segment Routing (SR-MPLS / SRv6)

Traditional MPLS Traffic Engineering required RSVP-TE or LDP signaling state on every hop router across a backbone. Segment Routing removes intermediate signaling state: the ingress router encodes an ordered list of network segments (SIDs — MPLS labels in SR-MPLS, or IPv6 extension headers/addresses in SRv6) right inside the packet header. Transit routers only need IGP (IS-IS/OSPF) plus stateless label/SID forwarding—unlocking sub-50 ms TI-LFA (Topology-Independent Loop-Free Alternate) backup paths.

// Choosing an ECMP link via flow 5-tuple + switch-tier seed (prevents polarization!)
fun selectEcmpLink(
    srcIp: Int, dstIp: Int, proto: Int, srcPort: Int, dstPort: Int,
    tierSeed: Int, numLinks: Int
): Int {
    var h = tierSeed xor srcIp
    h = (h * 0x45d9f3b) xor dstIp
    h = (h * 0x45d9f3b) xor ((proto shl 16) or (srcPort xor dstPort))
    return ((h ushr 16) xor h).and(0x7fffffff) % numLinks
}
