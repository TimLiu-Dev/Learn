How does an operating system or router choose between two matching routes in its routing table?

It uses Longest Prefix Match (LPM): the route with the most specific subnet mask (highest prefix length, e.g. /28 beats /24) always wins, regardless of administrative distance or metric.

Why static routing fails at enterprise scale

When a network has four routers, typing ip route commands by hand is manageable. When a network has 400 routers across thirty corporate campuses, static routing is suicide: a single cut fiber requires engineers to manually retype thousands of route statements at 3 AM.RFC 2328: OSPF Version 2. John Moy (1998).

Dynamic routing protocols allow routers to discover each other automatically, monitor link health, and instantly recalculate paths around failures. Within an enterprise or autonomous organization, network engineers deploy an Interior Gateway Protocol (IGP)—and the industry standard link-state protocol is OSPF (Open Shortest Path First).

Distance-Vector vs Link-State Routing

Dynamic routing protocols split into two core philosophies:

  • Distance-Vector (e.g. RIP): "Routing by rumor." Routers only know what their immediate neighbors tell them: "I can reach Network X in 3 hops." They have no map of the full network topology, suffer from slow convergence, and are vulnerable to routing loops (count-to-infinity).
  • Link-State (OSPF, IS-IS): Every router advertises the state of its directly connected links (up/down, bandwidth, neighbors) to all other routers via Link-State Advertisements (LSAs). Every router builds an identical complete map of the entire network (Link-State Database / LSDB) and independently runs Dijkstra's algorithm to compute the shortest path tree!

The 7 Stages of OSPF Adjacency

OSPF routers discover neighbors by sending periodic Hello packets to multicast address 224.0.0.5 (AllSPFRouters) every 10 seconds. To become fully synchronized, neighbors step through a 7-stage state machine:

  1. Down: No Hello packets heard from the neighbor.
  2. Init: Received a Hello from the neighbor, but my own Router ID is not listed in its neighbor list yet.
  3. 2-Way: Bidirectional communication verified (both routers see each other in Hello packets). On broadcast multi-access segments, the DR (Designated Router) and BDR (Backup DR) are elected here.
  4. ExStart: Negotiating Master/Slave status and initial Database Description (DBD) sequence numbers.
  5. Exchange: Exchanging DBD summaries describing the contents of their Link-State Databases.
  6. Loading: Routers send Link-State Requests (LSR) for missing or outdated routes; neighbor replies with Link-State Updates (LSU).
  7. Full: The Link-State Databases are 100% identical and fully synchronized. Both routers run Dijkstra SPF to populate their IP routing tables!

The DR/BDR Election on Multi-Access Networks

If 10 routers connect to the same Ethernet switch, forming full mesh adjacencies between every pair would require N(N − 1) / 2 = 45 neighbor relationships and trigger massive flooding of redundant LSAs.See John Moy, OSPF: Anatomy of an Internet Routing Protocol (Addison-Wesley).

To eliminate this overhead, OSPF elects a Designated Router (DR) and a Backup Designated Router (BDR):

  • Non-DR routers (DROthers) only form full adjacencies with the DR and BDR (using multicast 224.0.0.6 AllDRouters).
  • The DR acts as the central hub: it collects LSAs from all DROthers and floods them out to the rest of the network, dropping adjacency complexity from O(N2) to O(N).
  • Election rule: Highest OSPF Interface Priority (0-255; priority 0 = ineligible). Tie-breaker: Highest Router ID (highest loopback IP).

Calculating OSPF Cost (Dijkstra Metric)

OSPF calculates path cost based on link bandwidth:

Cost = Reference Bandwidth / Interface Bandwidth

By default, OSPF's historical reference bandwidth is 108 bps (100 Mbps). This creates a dangerous modern bug: a 100 Mbps FastEthernet link has a cost of 100 / 100 = 1, but a 1 Gbps link (100 / 1,000 = 0.1) also rounds to cost 1, and a 10 Gbps link also equals cost 1! In modern data centers, engineers must change the reference bandwidth to 100 Gbps (auto-cost reference-bandwidth 100000) so that 10G and 100G fiber paths are preferred over 1G copper.

Hands-on: Inspecting OSPF neighbors and LSDB

  1. View active OSPF neighbor adjacencies: 
    router# show ip ospf neighbor
    Look for: Neighbor ID: 10.255.255.2, State: FULL/DR or FULL/BDR, and Address: 192.168.1.2.
  2. Inspect the router's complete Link-State Database (LSDB): 
    router# show ip ospf database
    Identify the LSA types: Router Link States (Area 0) [Type 1] and Summary Net Link States (Area 0) [Type 3].
  3. Verify OSPF routes installed into the main routing table: 
    router# show ip route ospf
    Notice routes marked O (intra-area) vs O IA (inter-area) and their composite metric costs.

Free Recall Practice

From memory: explain the difference between Distance-Vector and Link-State routing. Why does OSPF elect a DR on broadcast networks?

Key points to compare against:

  • Distance-Vector vs Link-State: Distance-vector protocols (RIP) pass periodic routing table copies only to immediate neighbors ("routing by rumor"), lacking a complete topological map. Link-state protocols (OSPF) synchronize full link status advertisements across all routers into an LSDB, running Dijkstra SPF to calculate optimal loop-free paths independently.
  • Why DR is elected: On a shared multi-access broadcast segment (like an Ethernet switch), electing a Designated Router (DR) prevents a full mesh of N(N − 1) / 2 adjacencies. DROthers form adjacencies only with the DR/BDR, dramatically reducing control message flooding.
