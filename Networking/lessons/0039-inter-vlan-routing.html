Warm-up · from earlier sessions

Two minutes, from memory, before you read on:

When a laptop sends a packet to an IP address outside its local subnet, what destination MAC address does it put in the Ethernet frame?

The laptop puts the MAC address of its Default Gateway (the local router interface), which it resolves using ARP. The destination IP address remains the final remote target host.

The Inter-VLAN Dilemma

By design, a Layer 2 switch will never forward a frame between two different VLANs. If Host A in VLAN 10 (192.168.10.50) needs to query a database in VLAN 20 (192.168.20.100), Layer 2 switching cannot help.See Peterson & Davie §3.3: Basic Internetworking (IP).

To cross between broadcast domains, packets must be decapsulated, routed at Layer 3 (IP), and re-encapsulated into a new Ethernet frame. How networks achieve this has evolved from slow software routers to wire-speed silicon.

Architecture 1: Router-on-a-Stick (ROAS)

In smaller branch offices or budget topologies, a single physical router provides routing across all VLANs using a single physical cable called a Router-on-a-Stick (ROAS):

How ROAS Subinterfaces Work

The router's physical interface (e.g. GigabitEthernet 0/0) is carved into virtual subinterfaces, each bound to an 802.1Q VLAN tag:

router(config)# interface GigabitEthernet 0/0.10
router(config-subif)# encapsulation dot1Q 10
router(config-subif)# ip address 192.168.10.1 255.255.255.0

router(config)# interface GigabitEthernet 0/0.20
router(config-subif)# encapsulation dot1Q 20
router(config-subif)# ip address 192.168.20.1 255.255.255.0

The ROAS Hairpin Bottleneck

While inexpensive, ROAS introduces the notorious hairpin effect (or "one-armed router"):

  • Every packet from VLAN 10 must travel up the physical link to the router, be processed by software, and travel down the exact same link tagged for VLAN 20!
  • This cuts the effective trunk bandwidth in half (a 1 Gbps link saturates at ~500 Mbps of inter-VLAN throughput) and introduces high serialization latency.

Architecture 2: Layer 3 Switches & SVIs

To eliminate the router bottleneck, modern enterprise networks deploy Layer 3 (Multilayer) Switches. A Layer 3 switch merges switching and routing into a single chassis using specialized hardware:

Switched Virtual Interfaces (SVIs)

Instead of sending packets out to an external router, the Layer 3 switch creates internal virtual router interfaces called SVIs directly on the switch backplane:

switch(config)# ip routing
switch(config)# interface Vlan 10
switch(config-if)# ip address 192.168.10.1 255.255.255.0
switch(config)# interface Vlan 20
switch(config-if)# ip address 192.168.20.1 255.255.255.0

TCAM & Wire-Speed Hardware Forwarding

Traditional routers forward packets in software via CPU interrupts. Layer 3 switches forward packets in hardware at full wire speed using TCAM (Ternary Content Addressable Memory) and CEF (Cisco Express Forwarding):

  • Standard RAM evaluates bits as 0 or 1.
  • TCAM evaluates bits as 0, 1, or X ("don't care"). This allows the switch ASIC to match IP routing table prefixes (e.g. 192.168.0.0/16) in a single clock cycle!
  • When Host A sends a packet to Host B, the switch ASIC rewrites the MAC headers, decrements the IP TTL, recalculates the IP checksum, and switches the frame between VLANs in nanoseconds without ever interrupting the switch CPU.

Hands-on: Checking SVI routing status

  1. Verify that Layer 3 IP routing is enabled globally on the switch: 
    switch# show ip route
    Look for connected routes: C 192.168.10.0/24 is directly connected, Vlan10 and C 192.168.20.0/24 is directly connected, Vlan20.
  2. Check the operational state of the Switched Virtual Interfaces: 
    switch# show ip interface brief | include Vlan
    Confirm both Vlan10 and Vlan20 are Status: up / Protocol: up (an SVI only comes up if at least one active physical port belongs to that VLAN!).
  3. Convert a switchport from a Layer 2 access port into a routed Layer 3 port: 
    switch(config-if)# no switchport
switch(config-if)# ip address 10.1.1.1 255.255.255.252
    This strips the port of all VLAN functions and turns it into a point-to-point routed link directly into the core backbone.

Free Recall Practice

From memory: explain why Router-on-a-Stick causes a bandwidth bottleneck, and how a Layer 3 switch achieves wire-speed inter-VLAN routing.

Key points to compare against:

  • ROAS bottleneck: Traffic between VLANs must traverse the single physical trunk link twice (up to the router and back down the same wire), cutting effective throughput in half, while software CPU interrupts on the router cap packet-per-second rates.
  • Layer 3 Switch wire speed: A Layer 3 switch implements Switched Virtual Interfaces (SVIs) on its internal backplane and routes packets in silicon using TCAM (Ternary CAM), performing IP route lookups, TTL decrements, and MAC re-encapsulation in hardware at line rate.
