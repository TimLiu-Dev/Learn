2 · Mandatory Design Constraints (Senior NetEng Sign-Off Rubric)

  1. Non-Overlapping IP Plan: DC Loopbacks 10.255.0.0/24, DC Underlay P2P 10.0.0.0/22 (/31 links RFC 3021), DC Workloads 10.10.0.0/16, Cloud Spoke 10.200.0.0/16.
  2. Routing & Redundancy: Spine-Leaf eBGP underlay with BFD (50 ms × 3 = 150 ms detection) + EVPN Type-2/Type-5 overlay; Dual-Tunnel WAN IPsec + eBGP where both inbound (AS-Path prepending) and outbound (Local Preference) prefer Tunnel A to eliminate asymmetric firewall drops!
  3. MTU Discipline: Underlay links set to jumbo 9000 bytes (so 1500B inner frame + VXLAN/UDP/Outer-IP 50B = 1550B never fragments!); Cloud IPsec WAN sets tunnel interface MTU 1400 + TCP MSS clamp 1360.
  4. Chaos Test Verification: Cutting Spine-1 or shutting Tunnel A must recover end-to-end flow within <1 second (BFD + ECMP) with zero packet drops across remaining paths.

Check yourself

  

    

      
Why does Capstone 2 require raising physical leaf-spine underlay link MTUs to >= 1550 (typically 9000 bytes) while clamping TCP MSS down to 1360 across the WAN IPsec tunnel?

      
    
        
  1. VXLAN headers shrink packets by 50 bytes, requiring 9000B links to pad zeros.
    2. 
        
  2. DC underlay uses jumbo MTU so 1500B tenant frames + 50B VXLAN never fragment; WAN IPsec shrinks MSS so packets avoid Internet PMTU black holes.
    3. 
        
  3. BGP EVPN drops all TCP packets if MSS exceeds the spine switch VLAN ID.
    4. 
        
  4. Terraform automatically sets physical fiber SFPs to 1360-byte frames unless overridden.
    5. 
      

      
Control what you own (raise DC underlay MTU to 9000); adapt to what you don't (clamp WAN IPsec MSS to ~1360).

    

    

      
On dual redundant BGP-over-IPsec WAN tunnels to a cloud VPC, Tunnel A has Local Preference 200 + 3x AS-Path prepend outbound, while Tunnel B has Local Preference 100 + 0x prepend. Why do stateful firewalls drop connections?

      
    
        
  1. OSPF areas 0 and 1 collide inside VXLAN VNI 50000.
    2. 
        
  2. DNSSEC fails when two IPsec tunnels advertise the same /16 cloud CIDR.
    3. 
        
  3. Outbound SYNs exit Tunnel A while return SYN-ACKs enter Tunnel B—tripping stateful firewall checks.
    4. 
        
  4. BFD disconnects any tunnel carrying non-zero BGP Local Preference.
    5. 
      

      
Match outbound Local-Pref preference with inbound shortest AS-Path on the exact same primary tunnel.

    

    

      
When cutting the primary link to Spine-1 during Capstone 2 chaos testing, why does BFD + ECMP keep packet loss under a few hundred milliseconds instead of 40–180 seconds?

      
    
        
  1. BFD detects loss in ~150 ms and withdraws the dead Spine-1 ECMP nexthop, draining flows to Spine-2.
    2. 
        
  2. Spanning Tree runs Listening->Learning->Forwarding in 30 seconds across every server port.
    3. 
        
  3. VRRP waits 3 seconds for missing hellos before sending Gratuitous ARPs across the WAN.
    4. 
        
  4. ARP cache timers expire every 100 ms globally on every host NIC.
    5. 
      

      
BFD + multi-path ECMP achieves sub-second fault isolation across Clos fabrics.
