How This Curriculum Is Built

You don't need to choose between being a software developer, a network engineer, or a cloud architect before you start. All networking flows through the exact same physics and packet structures. We build the indestructible shared trunk first, then branch into the deep operational realities of each domain:

Trunk Shared Foundations

Sessions 1–12. Packets, delay physics, OSI/TCP-IP models, MAC/Ethernet, IPv4/IPv6, CIDR subnetting, ARP, DHCP, routing tables, and NAT.

Track A Professional Devs

Sessions 13–35. TCP/UDP, sockets in Kotlin/Java, HTTP/1.1, HTTP/2, HTTP/3 (QUIC), TLS 1.3, WebSockets, gRPC, and building an HTTP server from raw sockets.

Track B Network Engineers

Sessions 36–50. Enterprise switching, 802.1Q VLANs, Spanning Tree (STP), OSPF, BGP peering & AS path routing, hardware firewalls, IPsec, and QoS.

Track C Cloud & Modern Infra

Sessions 51–65. Software-Defined Networking (SDN), AWS/GCP VPCs, subnets, route tables, IGW/NAT, Transit Gateways, ALBs, and Kubernetes CNI/eBPF.
