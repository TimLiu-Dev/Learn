TDD & good tests

Beforewrite the list of test cases
Redone new test; watch it fail (compile error counts)
Greensimplest code that passes, even if ugly
Refactorimprove structure (code and tests); stay green
Good testsfast · independent · repeatable · one reason to fail · cover edges
Equality ★assertEquals calls equals: plain classes compare identity, data classes/records compare contents
Neverrely on test order, the clock, or HashMap order
source: Fowler: TDD · Fowler: Test Pyramid · Beck, TDD: By Example
