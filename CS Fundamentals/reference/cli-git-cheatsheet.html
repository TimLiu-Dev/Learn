Command Line & Git

Every command from the workbench, on one printable page.

Navigate

pwdPrint the working directory
ls · ls -laList entries · include hidden files and details
cd dir · cd .. · cd ~Into dir · up one level · home
/a/b vs a/bAbsolute (from the root) vs relative (from here)
. · .. · ~This folder · parent folder · home folder
Tab · ↑Complete a name · previous command
man cmd · cmd --helpManual (q quits) · quick help

Files & plumbing

mkdir -p a/bMake folders, including missing parents
cat fPrint a file
echo textPrint text
cmd > fOutput to a file, overwriting it
cmd >> fOutput to a file, appending
a | bPipe a's output into b's input
grep wordKeep only the lines containing word
a && bRun b only if a succeeded
nano fEdit in the terminal: Ctrl-O saves, Ctrl-X exits

Compile & run: JAVA

javac Hello.javaCompile → Hello.class
java HelloRun a class (no extension)
java Hello.javaSingle-file shortcut: compile in memory and run (JDK 11+)
source: JEP 330

Compile & run: KOTLIN

brew install kotlinInstall kotlinc
kotlinc A.kt -include-runtime -d a.jarCompile to a self-contained jar
java -jar a.jarRun the jar
kotlinc A.kt -d outCompile to a folder → out/AKt.class
source: Kotlin command-line compiler

Git: the core loop

working dir ──git add──▶ staging ──git commit──▶ history
git initMake this folder a repository
git statusUntracked / modified / staged? Run it often.
git add f · git add .Stage a file, as it is right now · stage everything here
git commit -m "msg"Record the staged snapshot
git diffChanges not yet staged
git log --onelineHistory, one line per commit
source: Pro Git §2.2
