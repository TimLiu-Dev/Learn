Gates & adders

Nand0 only when both inputs are 1; every gate can be built from it
From nandnot a = nand(a, a) · or = nand(not a, not b)
Half addersum = xor, carry = and
Full adder2 half adders + or on the carries (15 nands)
Ripple carryn full adders; slow: carry crosses every column
Subtracta + not(b) + 1: carry-in = 1
Overflow ★carry out of the top bit is dropped: 255 + 1 = 0
Signed?same adder, same bits; only the reading differs
Muxthe hardware if: sel ? b : a

The language pipeline
