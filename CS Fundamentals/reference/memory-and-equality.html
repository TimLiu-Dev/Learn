The one rule

Primitive variableholds the value
Object variableholds a reference (an arrow)
b = acopies the value or the arrow, never the object
b.x = 1mutates the object, so every alias sees it
b = Thing()re-points only b
nulla reference with no arrow; calling through it throws an NPE

Passing arguments

Alwayspass-by-value: the parameter is a copy
Primitive argumentthe callee can't affect the caller

Java traps

"hi" == "hi"true: literals are interned
s + "lo" == "hello"false: built at runtime
Integer 127 == 127true: values −128 to 127 are cached
Integer 128 == 128false
Integer == intunboxes; throws an NPE if the Integer is null
Ruleobjects: .equals(), never ==
source: Integer.valueOf · JLS §3.10.5

A view sees later changes to the original. A copy doesn't.

Defensive copies

// Kotlin
class Team(players: List<String>) {
    val players: List<String> = players.toList()
}
// Java
Team(List<String> players) {
    this.players = List.copyOf(players);
}
Copy on the way in, and never hand out mutable internals. Effective Java Item 50.
