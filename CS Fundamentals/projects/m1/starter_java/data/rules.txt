# Rules: pattern -> Category. The first matching rule wins.
# A pattern in /slashes/ is a regular expression; anything else is a substring.
# Both ignore case. Careful: the substring "tfl" is also inside "Netflix",
# which is why the TfL rule is a regex anchored to the start.

interest          -> Pay
moorside lettings -> Rent
yorkshire water   -> Bills

café              -> Eating Out
pret a manger     -> Eating Out
bakery            -> Eating Out
/ramen|ラーメン|pierogi/ -> Eating Out
/^tfl\b/          -> Transport
trains            -> Transport
netflix           -> Subscriptions
spotify           -> Subscriptions
puregym           -> Subscriptions
amazon            -> Shopping
