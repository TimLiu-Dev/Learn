# Mission: CS & Programming Fundamentals (Kotlin + Java)

## Why
Today I mostly code with AI. I want to be able to write, read and reason about code by hand, understanding what's happening underneath. The longer-term goal is to build Android and Spring Boot projects with real fundamentals behind them, instead of depending on whatever the AI produces.

## Success looks like
- Write small but non-trivial Kotlin and Java programs from a blank file, with AI completion turned off
- Read an AI-generated diff and spot bugs, race conditions, inefficient algorithms and poor design
- Explain what the JVM does with my code: where objects live, when they're collected, and what Kotlin generates compared with what Java makes you write
- Implement the core data structures by hand and reason about their Big O
- Build a small REST API backed by a SQL database using only the JDK, so I know exactly what Spring Boot automates
- Use Git and the command line comfortably, with no GUI crutch
- Sketch a reasonable design for a small multi-service system and explain where caching, queues and replicas fit

## Constraints
- About 4–7 hours a week, roughly one short lesson most days
- Personal mastery: no job deadline and no interview pressure
- Has JDK 26, Gradle, IntelliJ IDEA and Android Studio installed. The Kotlin CLI isn't installed yet.

## Out of scope
- Frameworks: Android SDK, Spring Boot, Ktor, Hibernate and the like. They're the destination, not this course.
- Interview grinding (LeetCode volume) beyond what's needed to understand the algorithms
