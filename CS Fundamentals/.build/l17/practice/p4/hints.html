You need only one index, next: the slot the next add writes to. After writing, move it on with (next + 1) % capacity. size grows until it reaches the capacity, then stays there. Check the capacity first, with require.

---

Until the buffer fills, the oldest item is in slot 0. Once it's full, the oldest is the one the next add will overwrite: slot next. toList() reads size items from the oldest slot, wrapping with %.

---

One formula covers both cases: oldest = (next - size + capacity) % capacity. The + capacity matters, because % of a negative number is negative in both Kotlin and Java. In Java the array is (T[]) new Object[capacity], as in MyQueue.java (L13's erasure again).
