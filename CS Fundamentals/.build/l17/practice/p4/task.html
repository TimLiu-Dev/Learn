Keep only the last N

A log viewer or a "recent searches" box keeps only the newest N items. Write LastN<T>(capacity) on a circular buffer that never grows:

  • add(item) is O(1). When the buffer is full, the new item overwrites the oldest one.
  • toList() returns the items oldest first, and size counts them.
  • A capacity below 1 throws IllegalArgumentException (L10).
