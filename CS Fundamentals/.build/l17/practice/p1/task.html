Find the loop

The buggy insertAfter made a node point back into its own list, and then a plain while (cur != null) walk never ends. Write hasCycle(head): true if following next from head ever reaches a node it has already visited, false if it reaches null.

  • Don't change any links, and make sure your own walk always stops.
  • Stretch: use O(1) extra memory, so no set of visited nodes.
