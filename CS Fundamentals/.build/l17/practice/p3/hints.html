Start from Part 3's isBalanced. The change: the stack has to remember where each opener was, so push its index instead of the character. You can still look the character up with text[top].

---

On a closer, pop. If the stack was empty, or text[top] isn't the matching opener, return the closer's own index i. After the loop, an empty stack means -1.

---

For leftovers, think about which end of the stack is which. The top is the most recent unclosed opener; the leftmost one is at the bottom. Kotlin's addLast stack has its bottom at first(). Java's push adds at the front, so there the bottom is peekLast().
