Why it works. It's the same stack algorithm as isBalanced, but the stack holds positions, so every failure can name one. A closer fails at the moment it arrives, so the first bad closer is returned straight from the loop. Leftover openers can only be judged at the end, and the stack keeps them in left-to-right order from bottom to top.

Common mistake. Returning the top of the stack for leftovers. In "((" the top is index 1, the innermost opener; the outer one at index 0, at the bottom of the stack, is the leftmost that never closed.
