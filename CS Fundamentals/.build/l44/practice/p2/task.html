Flush the click queue into daily counts

The batch writer from 2.5 and 2.6, in SQL. click_queue holds one row per redirect; clicks_daily already has counts from earlier flushes. Write the flush:

  • Add each queued click to its (code, day) row. Create the row if it's new, and never overwrite a count that's already there.
  • Then empty the queue.

The check lists every daily count plus how many clicks are left in the queue. Note the two clicks either side of midnight UTC.
