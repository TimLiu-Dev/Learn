Keep every unit in sight. Writes per second is new rows per month divided by seconds per month. Storage needs the number of months in years, and the cache is a share of one month's rows, not of all of them.

---

For minCodeLength: codes distinct codes are the numbers 0 to codes - 1. The length you need is how many base62 digits codes - 1 has, which is how often you can divide it by 62, plus one. Multiplying a Long up to 62^k overflows past 62^10 (L2), and the loop may never end.

---

var rest = (codes - 1) / 62; var length = 1; while (rest > 0) { rest /= 62; length++ }. Watch out for the lesson's own ceil(ln(n) / ln(62)): it's right for 6 billion but gives 0 for a single code. Java is the same code with long and int, inside the record-based Practice class.
