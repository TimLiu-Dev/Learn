Start with isIdempotent. There are exactly six methods to accept, so keep them in a setOf(…) and ask whether the method is in it.

---

Listing what's allowed (an allow-list) handles the unknown-method test for free: anything not in the set is "not idempotent". Listing what's forbidden (method != "POST") misses PATCH and anything new.
