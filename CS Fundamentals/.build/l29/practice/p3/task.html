Only the pages you need

A search API returns results one page at a time: page(1), page(2), …, until a page comes back empty. Each call suspends, like a network request.

  • allItems(api): a Flow of every item on every page, in order. Fetch a page only when the collector needs it.
  • firstMatches(api, word, n): the first n items that contain word (ignoring case), uppercased.

The checks count which pages were fetched. This is L15's lazy sequence, with a body that can suspend. Java has no Flow operators, so its version uses the nearest pull-based equivalent: a lazy Stream over blocking calls.
