Inside flow { }, write an ordinary loop: keep a page number, call api.page(number), stop with break when the list is empty, and emit each item. Calling a suspending function there is fine: that's what makes it a Flow and not a Sequence.

---

Don't collect the pages into a list first. Emit each item as soon as its page arrives: emit suspends until the collector has handled it, so the loop only reaches the next page if the collector still wants more.

---

firstMatches is allItems(api).filter { it.contains(word, ignoreCase = true) }.map { it.uppercase() }.take(n).toList(). take(n) cancels the flow above it after the n-th item. In Java: Stream.iterate(1, p -> p + 1).map(api::page).takeWhile(p -> !p.isEmpty()).flatMap(List::stream), then filter, map, limit(n).
