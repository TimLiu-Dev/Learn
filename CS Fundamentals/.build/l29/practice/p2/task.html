Make it main-safe

Db.countRows is a blocking call you can't change, like an old JDBC driver. loadCounts is called from the UI thread. Make it main-safe:

  • no blocking call may run on the caller's thread, and the caller carries on on its own thread afterwards;
  • all tables load at the same time, and the result maps each table to its count.

The hidden fake answers only once every table has been asked for, and the checks use one more table than Dispatchers.Default has threads. Choose the dispatcher with that in mind. Java has no dispatchers or suspend: its version takes the IO executor as a parameter and returns a CompletableFuture.
