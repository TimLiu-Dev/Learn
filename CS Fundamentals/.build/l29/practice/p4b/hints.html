A one-shot callback becomes suspendCancellableCoroutine { cont -> … }: start the lookup inside the block, and let the callbacks call cont.resume(…) or cont.resumeWithException(…). A callback that fires many times becomes callbackFlow { … }, where the listener calls trySend(…).

---

Both bridges need a cleanup step, and both tests that check it pass silently without it. Keep the Lookup that lookup returns and cancel it in cont.invokeOnCancellation { … }. End the callbackFlow block with awaitClose { removeListener(listener) }: without awaitClose the block returns at once and the flow throws IllegalStateException.

---

val lookup = lookup(address, onResult = { lat, lon -> cont.resume(lat to lon) }, onError = { cont.resumeWithException(it) }); cont.invokeOnCancellation { lookup.cancel() }. For the flow: val listener = PlaceListener { trySend(it) }; addListener(listener); awaitClose { removeListener(listener) }. Java has no coroutines: its version completes a CompletableFuture from the callbacks, and cancels the lookup in whenComplete.
