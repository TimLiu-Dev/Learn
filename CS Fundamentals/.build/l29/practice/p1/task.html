Three calls at once, one page

A profile page needs three slow calls: name, friendCount and posts. Write:

  • loadPage(api, id): start all three at the same time. If any call fails, the whole load fails with that exception, and the calls still running are cancelled.
  • loadPages(api, ids): load every page at the same time, in the order of ids. A page that fails becomes null, and the other pages still load.

The hidden fake API records start, end and cancel events, so the checks can see what really ran. The Java version is the nearest honest equivalent: futures on virtual threads (L28), cancelled by hand.
