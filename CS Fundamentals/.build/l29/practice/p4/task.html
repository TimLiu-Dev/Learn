Meet Java halfway

A Java team's client returns a CompletableFuture for every price (L28). Use it from coroutine code:

  • total(client, items): ask for every price first, then suspend until all have arrived, and return the sum.
  • totalOrNull(client, items, timeoutMs): the same, but give up after timeoutMs: return null and cancel the futures still pending.

The Playground runs Java 17, which has no virtual threads, so this practice works on the other seam between the two worlds: futures. In Java there's no coroutine to cancel, so its version cancels the futures itself.
