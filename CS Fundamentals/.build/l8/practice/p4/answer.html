Why it works. CountingSet has a set, so the inner set's own addAll → add calls stay inside it, and our add is never called twice. by inner writes all the other forwarding methods (remove, contains, iterator…), which is why the "still a full set" check passes. Java has no by, so its wrapper forwards only what it needs. To make it a full Set, you'd write a forwarding method for every one of Set's methods, as Bloch's ForwardingSet does.

Common mistake. elements.forEach { add(it) } plus addCount += elements.size: that counts 6 for three elements.
