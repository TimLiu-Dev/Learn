===== Clocks.kt
== One run, two kinds of logical clock
event        Lamport  vector
P1 a               1  [1,0,0]
P1 send m1         2  [2,0,0]
P2 b               1  [0,1,0]
P2 recv m1         3  [2,2,0]
P2 send m2         4  [2,3,0]
P3 c               1  [0,0,1]
P3 recv m2         5  [2,3,2]
P1 d               3  [3,0,0]

== What each clock can tell you about a pair of events
P1 send m1 vs P2 recv m1  Lamport 2 < 3   vector BEFORE
P1 a       vs P3 recv m2  Lamport 1 < 5   vector BEFORE
P2 b       vs P1 d        Lamport 1 < 3   vector CONCURRENT
P1 d       vs P3 recv m2  Lamport 3 < 5   vector CONCURRENT
P1 a       vs P3 c        Lamport 1 = 1   vector CONCURRENT

== A total order: sort by (Lamport time, process number)
P1 a@1  P2 b@1  P3 c@1  P1 send m1@2  P1 d@3  P2 recv m1@3  P2 send m2@4  P3 recv m2@5

== Version vectors on two cart replicas (entry 0 counts A's writes, entry 1 B's)
[book,lamp] [2,0] vs [book,pen] [1,1]: CONCURRENT -> keep both, merge
[book,lamp,pen] [2,2] vs [book,lamp] [2,0]: AFTER -> safe to overwrite
[book] [1,0] vs [book,lamp,pen] [2,2]: BEFORE -> a stale write, ignore it
