Storage that fences stale lock holders

Write the storage side of fencing. Every write carries the token its writer got from the lock service, and the store remembers the highest token it has accepted for each key.

  • write accepts the write and returns true if its token is at least the highest one seen for that key; otherwise it changes nothing and returns false.
  • The current holder may write many times with the same token. A key nobody has written yet accepts any token.
  • read returns the key's value, or null.
