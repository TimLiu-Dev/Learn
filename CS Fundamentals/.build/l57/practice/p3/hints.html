Handle the term first, then the vote. Three cases for the term: older (refuse at once), equal (keep the voter), newer (copy it with the new term and votedFor = null, L7).

---

Then grant only if both hold: votedFor is null or already this candidate, and candidateIsUpToDate. Granting means returning a copy with votedFor = req.candidateId. Refusing returns the voter from step one, not the original.

---

candidateIsUpToDate is one expression: req.lastLogTerm > v.lastLogTerm || (req.lastLogTerm == v.lastLogTerm && req.lastLogIndex >= v.lastLogIndex). In Java, records have no copy, so build a new Voter(…) instead.
