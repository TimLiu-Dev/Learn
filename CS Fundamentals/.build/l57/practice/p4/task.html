A coordinator that decides once

Write phase 1 of a two-phase-commit coordinator as a pure state machine: no network, no clock. It hears votes, and a timeout if the votes take too long. Its decision starts as WAITING.

  • COMMIT once every participant has voted yes. ABORT as soon as any participant votes no, or on a timeout while still waiting.
  • A decision is final: it's in the coordinator's log, so later votes and timeouts don't change it.
  • The network may deliver a message twice (L42), so a repeated yes from one participant counts once.
