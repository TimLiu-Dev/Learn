Stamp the script, then compare vectors

Two halves of Part 2, written from memory:

  • lamportStamps gives the Lamport time of every step in a script of local events, sends and receives across processes 0, 1 and 2. Each message is sent before it is received.
  • compare says whether the event with vector clock a came BEFORE, AFTER, was EQUAL to, or was CONCURRENT with the event with vector clock b.

One check replays the lesson's own script, so you can compare with Clocks.kt's table.
