Why it works. Each clock does the one job it's good at. The monotonic clock measures how long the lease has run, so an NTP step can't touch that. The wall clock answers "what time is it?" for the log line, which is why expiresAtWall() reads it now, after any step, instead of adding 10 s to the start time. Passing the clocks in as functions is the same trick as L43's injected clock: the checks control time, so nothing sleeps.

Common mistake. Switching to monoNanos() but forgetting the unit: durationMs - (monoNanos() - start) subtracts nanoseconds from milliseconds, so the lease runs out a million times too early. Kotlin's TimeSource.Monotonic returns a typed Duration and avoids this.
