Try writing lo <= hi in the init block first. The compiler refuses, because a plain T could be any type at all, and not every type can be compared. Which bound from Part 1 promises "T can be compared with other Ts"?

Change the header to class Span<T : Comparable<T>>, and give spanOf the same bound: fun <T : Comparable<T>> spanOf. Now <, <= and > work on T. Use require(lo <= hi) { … } in init.

contains is lo <= x && x <= hi. clamp is a when with x < lo -> lo, x > hi -> hi, else -> x. For spanOf, return null when the list is empty, then track the smallest and largest in one loop. In Java the bound is T extends Comparable<T>, and every comparison is spelled a.compareTo(b) <= 0.
