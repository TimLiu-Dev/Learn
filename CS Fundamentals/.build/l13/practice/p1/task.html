A span of anything comparable

Finish Span, a closed range from lo to hi that works for Int, String or any other comparable type:

  • Creating a span with lo greater than hi throws IllegalArgumentException (L10's require). A single-point span like Span(3, 3) is fine.
  • x in span is true when lo ≤ x ≤ hi, and clamp(x) moves x to the nearest end if it's outside.
  • spanOf(items) returns the span from the smallest to the largest item, or null for an empty list.

The starter compiles only because nothing compares yet. You'll need to make a promise about T first.
