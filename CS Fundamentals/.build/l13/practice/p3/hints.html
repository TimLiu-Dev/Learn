The map is keyed by KClass. Inside a function with a reified T, you can write T::class to get the class object for the type argument the caller used.

---

put is one line: slots[T::class] = value. For get, look up slots[T::class]. You get an Any? back, and you need a T?.

---

Use as? T: because T is reified, it's a real runtime check, not an unchecked cast, so there's no warning. In Java, the token does the same jobs: slots.put(type, type.cast(value)) and return type.cast(slots.get(type)). Class.cast(null) returns null.
