Why it works. out T makes Kennel<Cat> a subtype of Kennel<Animal>: anything it releases is a cat, so it's an animal. in T flips the direction, so a Vet<Animal> counts as a Vet<Cat>: a vet who treats any animal can treat a cat. You marked each interface once, and every use benefits. Java has to repeat ? extends / ? super at each use.

Common mistake. Writing Vet<out T> because treat "gives something back". What it returns is a String, not a T. T is a parameter, which is an in position, so the compiler refuses: "type parameter 'T' is declared as 'out' but occurs in 'in' position".
