Read the three errors. Each says "argument type mismatch": a Kennel<Cat> where a Kennel<Animal> was expected, and so on. Generic types are invariant unless you say otherwise. Look at where T appears in each interface: only as a return type, or only as a parameter?

---

Kennel only returns T, so it's a producer: interface Kennel<out T>. Vet only takes T, so it's a consumer: interface Vet<in T>. Kotlin arrays are invariant and you can't change Array's declaration, so project the one use instead.

---

The third fix is fun rollCall(animals: Array<out Animal>), a read-only view, like describeAll in Part 2. In Java you can't mark a declaration, so the wildcards go on the two methods that use it: Kennel<? extends Animal> and Vet<? super Cat>. Java's rollCall needs nothing, because Java arrays are covariant (with the ArrayStoreException risk you saw).
