Pick the queue: alphabetical scheduling

needs maps each task to the tasks that must run before it, as in Topo.kt. Write schedule(needs), Kahn's algorithm with one new rule: whenever several tasks are ready, run the alphabetically first one.

  • Return null if the tasks contain a cycle, and an empty list for no tasks.
  • A task unlocked late may still jump ahead of one that's been waiting. Choose the collection for the ready tasks from the Part 4 table.
