ways follows the recipe in Stairs.kt, with one change: instead of adding exactly dp[i-1] and dp[i-2], add dp[i - s] for every step size s that fits. dp[0] = 1.

---

For minCoins, write the naive recursion first: best(0) = 0, and otherwise best(a) is 1 + the smallest best(a - coin) that isn't -1. Then wrap the body in memo.getOrPut(a) { … }. A local fun inside minCoins can see coins and memo.

---

If no coin leads anywhere, return -1, and cache that too. In Java, don't memoise with computeIfAbsent: the recursive calls modify the map mid-call, and you get the ConcurrentModificationException from this part. Write get, compute, put.
