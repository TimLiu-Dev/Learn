Why it works. The FIFO queue hands out cells in order of distance: every 1-move cell before any 2-move cell. So the first time a cell is discovered, it's by a shortest route, and its distance never needs updating. Storing the distance when a cell is enqueued also stops it from being queued twice. Each cell is handled once: O(rows × cols).

Common mistake. Taking cells from the back (removeLast). That's DFS: it still reaches every cell, but the first route it finds can be a long detour, so some distances come out too big.
