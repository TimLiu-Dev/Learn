How far is every cell?

In the grid, # is a wall and . is open. You move up, down, left or right. Fill in the TODOs:

  • distances(grid, start) returns the fewest moves from start to every open cell it can reach. Unreachable cells and walls are left out.
  • stepsTo(grid, start, target) returns the fewest moves to target, or -1 if it can't be reached.

The final asks for the path itself. Here you only need the distance, so a distance map replaces the parent map.
