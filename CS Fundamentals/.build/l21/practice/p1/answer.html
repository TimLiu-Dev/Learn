Why it works. An undirected edge has no "from" end, so it's stored twice: once in each endpoint's list, or in both m[a][b] and m[b][a]. Creating every vertex's list up front means an isolated vertex has an empty list rather than none, and the list's index is the vertex number.

Common mistake. Adding only adj[a].add(b). That stores a directed graph, so vertex 2 never learns about vertex 1 and the matrix isn't symmetric.
