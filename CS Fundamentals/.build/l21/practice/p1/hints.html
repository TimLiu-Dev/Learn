Start with List(n) { mutableListOf<Int>() }: n separate, empty lists. Vertices with no edges keep theirs, so the result always has n entries, even when n is 0.

---

For each pair (a, b), add b to a's list and a to b's. The matrix is the same idea with Array(n) { BooleanArray(n) }: set both m[a][b] and m[b][a].

---

isolated is adj.indices.filter { adj[it].isEmpty() }. In Java, don't build the lists with Collections.nCopies(n, new ArrayList<>()): that's n references to one list. Use a loop that calls new ArrayList<>() each time.
