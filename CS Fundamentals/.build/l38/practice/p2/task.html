Hand it the time

HoldShelf already takes a Clock and an id generator, but it ignores both: it asks System.currentTimeMillis() and UUID.randomUUID() instead. So no test can say "three days later".

  • Use the injected clock and newId everywhere, so the hidden tests' fake clock and ids take effect.
  • A hold lasts 3 days: at exactly 3 days it has expired. pickUp succeeds only for a hold that is still waiting, and removes it.
