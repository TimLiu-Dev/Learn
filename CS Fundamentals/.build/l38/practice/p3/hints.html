One mutableListOf<Reservation>() holding every reservation is enough. A list keeps insertion order, so "oldest first" comes for free.

---

For ids, keep a separate counter (private var nextId = 1L) and use nextId++. Don't derive the id from the list's size: after a cancel, the size goes down and an old id comes back. For queue, filter already returns a brand-new list, which is exactly a snapshot.

---

add is Reservation(nextId++, bookId, member).also { all += it }, queue is all.filter { it.bookId == bookId }, and cancel is all.removeIf { it.id == id }, which already returns whether anything was removed. In Java, use a long counter, stream().filter(…).toList() and the same removeIf.
