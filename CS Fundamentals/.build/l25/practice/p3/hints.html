"1.10.0" < "1.9.0" as strings, because '1' < '9'. Split each version on ".", turn the parts into Ints, and let the first part that differs decide.

---

For resolve, the module is everything before the last colon: groupBy({ it.substringBeforeLast(":") }, { it.substringAfterLast(":") }) gives module → versions. Then take maxWith(::compareVersions) of each list.

---

SemVer item 4: "Major version zero (0.y.z) is for initial development. Anything MAY change at any time." So any change from a 0. version counts as breaking; otherwise only a different MAJOR does. In Java, a TreeMap with merge(module, version, …) keeps the higher of the old and new version in one pass.
