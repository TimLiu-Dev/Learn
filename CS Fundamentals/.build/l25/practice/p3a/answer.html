Why it works. Post-order DFS gives a topological order: every task appears after everything it depends on (L21). done makes each task run once, which is the reason a build that asks for both test and jar compiles once. path is the recursion stack. If a task is reached again while it's still on the stack, the graph has a cycle. Gradle refuses such a graph before running anything, and so does this function.

Common mistakes. Using a single visited set for both jobs: then you can't tell "finished earlier" (fine) from "still being visited" (a cycle). Leaving out done entirely runs classes twice. Leaving out path turns a cycle into a StackOverflowError instead of a clear message.
