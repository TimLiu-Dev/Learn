Run the task graph yourself

Gradle builds a graph of tasks and runs each one after the tasks it depends on. Write executionOrder(tasks, requested) that does the same for a map from task name to its dependsOn list:

  • A task runs after everything it depends on, and every task runs once, even when several tasks need it.
  • Only requested tasks and the tasks they need run. Dependencies go in the order they're declared, depth first (L21's DFS, emitting a task after its dependencies).
  • An unknown task throws IllegalArgumentException naming it. A cycle throws IllegalStateException showing the path, like a -> b -> a.
