Three number traps

Each function needs only one line, and each hides a trap from this part:

  • weekday(offset): day 0 is a Monday. Return the weekday offset days later. A negative offset goes back in time.
  • average(a, b): the exact average of any two Ints, as a Double.
  • closeEnough(x, y): true when two doubles differ by less than 1e-9.
