Both functions are one regex each. For command, trim first, then look for a / at the very start followed by word characters. For seconds, the whole token must be digits and then exactly one of s, m, h.

---

command: Regex("""^/(\w+)""").find(input.trim()) gives a match or null; the word is groupValues[1]. seconds: find would accept 10min, because 10m appears inside it. Use matchEntire, then turn groupValues[1] into an Int and multiply by 1, 60 or 3600.

---

End command with m.groupValues[1].lowercase(); Kotlin's lowercase() already ignores the default locale. For seconds: if (unit == "s") n else if (unit == "m") n * 60 else n * 3600. In Java, toLowerCase() with no argument fails the Turkish check (QUIT becomes quıt), so write toLowerCase(Locale.ROOT), and use matcher.matches(), not find().
