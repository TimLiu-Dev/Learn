Why it works. The ^ anchor and matchEntire both pin the pattern to the text, so only well-formed input gets through: ^ to the start, matchEntire to the whole token. Lower-casing with the invariant rules (Kotlin's lowercase(), Java's toLowerCase(Locale.ROOT)) gives the same command name on every machine.

Common mistake. Using find for seconds. It searches for the pattern anywhere, so 10min matches as 10m and comes back as 600 instead of null. In Java, the classic mistake is plain toLowerCase(), which returns quıt on a Turkish laptop.
