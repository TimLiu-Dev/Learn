Do the examples by hand first. How many times can you chop the last digit off 1234 with n / 10 before nothing is left? Now try 0: does a while (n > 0) loop even run once?

---

Every number has at least one digit, so start the count at 1. Then keep chopping while n / 10 != 0, counting each chop. That gives 0 the right answer with no special case.

Skip abs(): Part 1 showed that abs(Int.MIN_VALUE) is still negative. You don't need it, because -907 / 10 is -90, which also heads towards 0. Java is the same code with int.
