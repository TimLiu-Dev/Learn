Preview a name without breaking it

A chat app compares names and shows short previews. Fill in the TODOs:

  • sameText(a, b): true when the two strings are the same text, even if one spells é as e plus a combining accent.
  • preview(s, max): the first max user-perceived characters, followed by "…" if anything was cut. A string that fits comes back unchanged.

The checks use emoji and combining accents, so s.take(max) won't pass.
