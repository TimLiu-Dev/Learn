Why it works. NFC turns both spellings of é into the same single code point, so plain == works afterwards. BreakIterator knows the grapheme cluster rules of UAX #29, so its boundaries never fall inside a surrogate pair or between a letter and its accent. Cutting only at a boundary can't break a character.

Common mistake. Counting code points with offsetByCodePoints. It keeps each emoji's surrogate pair together, so the emoji check passes, but it still treats the combining accent as a separate character and returns "cafe…".
