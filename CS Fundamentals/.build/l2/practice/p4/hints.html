Each call to next() moves forward one user-perceived character and returns the index where it ends. next(max) jumps max characters at once, and returns BreakIterator.DONE if the text runs out first. That index is where you cut with substring.

---

Return s unchanged when next(max) gives DONE or lands exactly on s.length. Otherwise return s.substring(0, end) + "…". The Java code is the same. On JDK 20+ this also keeps a family emoji like 👨‍👩‍👧 together, but the checks avoid one because the in-page runner uses Java 17.
