Ask the tree for a rank and a range

An in-order walk hands you a BST's keys sorted. Use that:

  • inOrder(root): a lazy Sequence of the keys, built with sequence { } and yieldAll (L15).
  • kthSmallest(root, k): the k-th smallest key, counting from 1, or null if there's no such key.
  • between(root, lo, hi): the keys with lo ≤ key ≤ hi, sorted. Skip any subtree that can't hold one.
