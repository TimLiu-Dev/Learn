Why it works. Balance is a property of every subtree, so the check recurses into both sides after testing the current node. floor is a search that remembers the last time it turned right: every right turn passes a key smaller than the target, and the deepest one is the closest. Both run on one path or one tree walk, just like the lesson's contains.

Common mistake. Checking only the root's two heights. The tree 50, 30, 20, 10, 70, 80, 90 has height 3 on both sides of the root, but each side is a stick. (Calling height at every node makes this O(n²) on a stick; returning the height and the verdict together makes it O(n).)
