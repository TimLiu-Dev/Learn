isBalanced is recursive, with the same base case as height: an empty tree is balanced. For a real node, compare height(node.left) with height(node.right).

---

The root passing isn't enough: one test builds a tree whose root is fine but whose node 30 leans. Return diff in -1..1 && isBalanced(node.left) && isBalanced(node.right). For floor, keep a best: Int? that starts as null.

---

In floor's loop: if key < n.key, go left (this node is too big). If key > n.key, this node is a candidate, so set best = n.key and go right to look for a closer one. If they're equal, return it. In Java, floor returns Integer so it can be null, and Math.abs(diff) <= 1 does the height check.
