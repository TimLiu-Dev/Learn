Heapify: build a heap in place

Adding n items one at a time costs O(n log n). PriorityQueue(collection) does better: it sifts down every parent, from the last one back to the root. Write it for an IntArray, 0-based like the lesson:

  • isMinHeap(a): true if every parent is ≤ its children.
  • siftDown(a, i, n): sink a[i] within the first n slots, swapping it with its smaller child while it's bigger.
  • heapify(a): call siftDown on each parent, starting at the last one and going back to index 0.
