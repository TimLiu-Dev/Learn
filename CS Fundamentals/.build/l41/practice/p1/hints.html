Nearest rank counts from 1: in 10 sorted values, p50 is rank ceil(0.5 × 10) = 5, the 5th smallest. ceil rounds a fractional rank up, so p81 of 5 values is rank ceil(4.05) = 5.

Use ms.sortedArray(), which returns a new sorted array; ms.sort() would reorder the caller's data. Then convert rank to index with rank - 1. Computing p * n / 100 (rather than p / 100 * n) keeps the multiplication exact for whole-number inputs. For fan-out, the page is fast only if all its calls are fast: (1 - perCall) to the power calls.

---

val rank = ceil(p * sorted.size / 100).toInt(), then sorted[maxOf(rank, 1) - 1] (the maxOf guards p = 0). Fan-out is 1 - (1 - perCall).pow(calls). In Java: ms.clone() then Arrays.sort, (int) Math.ceil(...) and Math.pow.
