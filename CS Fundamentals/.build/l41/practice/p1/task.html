Percentiles by nearest rank

Write the two numbers Part 1 used to read a latency distribution:

  • percentile(ms, p): the nearest-rank percentile, like Tail's pct. Sort a copy, then take the value at rank ceil(p / 100 × n), where rank 1 is the smallest. Don't change the caller's array.
  • fanOutSlow(perCall, calls): the chance that a page making calls parallel calls hits at least one slow one, if each is slow with probability perCall.

The checks use small samples with ties, where off-by-one mistakes show.
