One load per key

CoalescingCache works, but it stampedes: eight threads that miss on the same key all call the slow loader. Make concurrent misses for one key share a single load, as Part 2's Stampede did:

  • Keep loads in progress in inFlight. The first miss starts a load; the others wait for that same future.
  • If a load fails, every waiter gets the failure, and the next get tries again.
  • A slow load for one key must not hold up other keys.

The checks block the loader with a latch, so they're deterministic: no sleeps, no timing.
