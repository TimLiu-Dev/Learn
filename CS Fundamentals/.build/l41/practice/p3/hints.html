get is Part 3's get without the TTL: look up the node, unlink it, addFront it. For put, handle three cases in order: too heavy to ever fit, an existing key, a new key. Then evict.

---

Keep totalWeight exact in every case: an update changes it by value.length - old.value.length. Eviction takes tail.prev, the least recently used node, and must repeat: one 5-character value may need two 3-character values to leave. That calls for while, not if.

---

The eviction loop: while (totalWeight > maxWeight) { val lru = tail.prev!!; unlink(lru); map.remove(lru.key!!); totalWeight -= lru.value.length; evicted += lru.key }. It can never reach the entry you just wrote, because that entry fits on its own. In Java the node's key is a plain String and the loop is the same.
