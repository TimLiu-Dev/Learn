Bounded by size, not by count

Real caches often limit total size, not the number of entries: Caffeine calls this a maximum weight. Here an entry's weight is its value's length. The map, the list with sentinels, unlink and addFront are done; write get and put:

  • A hit moves the entry to the front. After a put, evict from the back (adding each key to evicted) until totalWeight <= maxWeight.
  • put on an existing key replaces its value and weight, and makes it most recently used.
  • A value heavier than maxWeight is never stored, and it removes any old value for that key (the old one is stale now). That removal isn't an eviction.
