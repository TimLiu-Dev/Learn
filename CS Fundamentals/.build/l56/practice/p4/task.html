One question, two data models

For each author, how many of their books came out before 1980? Most books first, then by name. The relational answer is a join through book_authors:

SELECT a.name, count(*) AS books
FROM authors a JOIN book_authors ba ON ba.author_id = a.id JOIN books b ON b.id = ba.book_id
WHERE b.year < 1980
GROUP BY a.name ORDER BY books DESC, a.name;

It returns Ursula K. Le Guin | 2 and Octavia E. Butler | 1. Write the same query against book_docs only, with ->> and json_each, and get the same two rows. Read the documents closely first: the starter shows them.
