Start from Part 4's "who wrote what" query: FROM book_docs d, json_each(d.doc, '$.authors') AS a gives one row per (book, author), and a.value is the author's name. Add GROUP BY a.value, count(*) and the ORDER BY. Then filter on d.doc ->> '$.year'.

---

If Le Guin comes out with 1 book, look at The Left Hand of Darkness: its year is "1969", a JSON string. ->> hands it back as SQL TEXT, and with no column affinity to convert it, SQLite ranks any TEXT value above any number, so '1969' < 1980 is false. (With -> every year comes back as JSON text, and you get no rows at all.)

---

Make the reader do the check the schema didn't: WHERE CAST(d.doc ->> '$.year' AS INTEGER) < 1980. The relational table could never hold that string, because year INTEGER NOT NULL on an ordinary table converts '1969' to the integer 1969 on insert (type affinity, L34).
