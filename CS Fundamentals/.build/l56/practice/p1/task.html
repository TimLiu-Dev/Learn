A log in a list, with a hash index

MiniCask is Part 1's store with the file swapped for a MutableList<String>. Each record is one string, "put key value" or "del key" (a tombstone), and a key's offset is its position in the list. Opening a store replays the log; that part is written.

  • Write put, get and delete. Writes only ever append, and the index points at each key's newest record.
  • Write compact(): rewrite the same list so it holds one put per live key, and fix the index to match.

Some checks reopen the store with MiniCask(db.log), the way a restart replays the file.
