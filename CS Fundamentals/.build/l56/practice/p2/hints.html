CRC32().apply { update(payload.toByteArray()) }.value is a Long between 0 and 232 − 1. Format it with "%08x": plain toString(16) drops leading zeros, and crcHex("dune") starts with one.

---

Don't split the log into lines: split and lines() hand you a last line without its \n as if it were whole. Walk it instead. Keep pos, the end of the last good record, and find the next record's end with log.indexOf('\n', pos). No newline means a torn record: stop.

---

For each line, the first 8 characters are the stored CRC, character 8 is a space, and the rest is the payload. If the line is too short, has no =, or crcHex(payload) differs, stop. Otherwise store substringBefore('=') → substringAfter('=') and set pos = end + 1. validLength is pos when you stop. Java's String.format("%08x", crc.getValue()) pads the same way.
