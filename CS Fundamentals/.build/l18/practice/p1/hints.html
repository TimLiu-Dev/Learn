Both base cases are the empty list, node == null. For maxValue the answer there is null, not 0: a list of negative numbers has a max below 0.

---

Trust the recursion: maxValue(node.next) is the max of the rest, or null if the rest is empty. In that case node.value is the answer; otherwise take the bigger of the two. For without, first get without(node.next, x), then either drop node or put a new Node(node.value, rest) in front.

---

val rest = maxValue(node.next) ?: return node.value handles the one-element case in one line. In Java, the return type is Integer so it can be null; compare with rest == null before unboxing.
