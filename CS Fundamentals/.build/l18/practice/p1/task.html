Base cases on a linked list

Here is L17's singly linked list, where null is the empty list. Write both functions recursively, with no loops:

  • maxValue(node): the largest value in the list, or null if the list is empty.
  • without(node, x): a new list with every x removed, the other values in their original order. Don't change the old nodes.

Before you write the recursive case, decide what each function returns for an empty list.
