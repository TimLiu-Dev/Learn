Count inversions with merge sort

An inversion is a pair i < j with a[i] > a[j]. It's what insertion sort pays one shift for. Counting them with two loops is O(n²); merge sort can count them in O(n log n) while it sorts.

  • Write sortAndCount(a): merge-sort a in place, as in MergeSort.kt above, and return how many inversions it had.
  • countInversions is done: it sorts a copy, so the caller's array is unchanged.

Equal values are not an inversion.
