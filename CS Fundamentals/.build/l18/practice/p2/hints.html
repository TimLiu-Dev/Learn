Both are the Part 2 exercise's lower bound and upper bound with a half-open range [lo, hi) and hi = xs.size. Never return from inside the loop; let lo and hi meet.

---

For firstIndexOf, loop while lo < hi: if xs[mid] < target then lo = mid + 1, else hi = mid. After the loop, lo is the first index with xs[lo] >= target, but it might be xs.size or a bigger value, so check before you return it.

---

insertSorted is the same loop with <= instead of <, so lo lands after the last equal value; then xs.add(lo, x). In Java, the list is a List<Integer>: compare with xs.get(mid), which unboxes, and insert with xs.add(lo, x).
