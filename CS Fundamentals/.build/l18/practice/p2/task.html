First occurrence and a sorted insert

Both functions work on a sorted list that may contain duplicates, and both must be O(log n): a binary search with no linear scan.

  • firstIndexOf(xs, target): the index of the first copy of target, or -1 if it's missing.
  • insertSorted(xs, x): insert x so the list stays sorted, after any equal values, and return the index where it went.

One check counts how many times your code reads the list, on a million equal values.
