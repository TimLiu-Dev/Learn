fun range(start: Int, count: Int) = if (count == 1) "$start" else "$start,$count", and the header is "@@ -${range(oldStart, oldCount)} +${range(newStart, newCount)} @@". A count of 0 still prints ,0. In Java, count with body.stream().filter(…).count().
