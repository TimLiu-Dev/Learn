Write the hunk header

Given a hunk's body lines and where it starts in each file, return the header Git prints above it: @@ -oldStart,oldCount +newStart,newCount @@.

  • A line starting with a space counts for both files, - only for the old file, + only for the new one.
  • A \ No newline at end of file line counts for neither.
  • Like Git, leave out ,1: a one-line range is just its start, as in @@ -1 +1 @@.
