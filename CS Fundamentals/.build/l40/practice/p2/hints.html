Start from the easy case: every commit becomes "pick ${c.hash} # ${c.subject}", in order. That already passes the first test. Then ask, for each commit, "does its subject start with fixup! or squash! , and have I already seen the commit it names?"

---

Think of the todo list as groups: each picked commit starts a group, and its fixups join the end of that group. Keep a MutableList of groups and a map from subject to group. At the end, groups.flatten() is the todo list.

---

For each commit: find the action with listOf("fixup", "squash").firstOrNull { c.subject.startsWith("$it! ") }, then look up bySubject[c.subject.removePrefix("$action! ")]. If both exist, add the line to that group; otherwise start a new group and record it in the map. In Java, a Map<String, List<String>> and a List<List<String>> do the same job.
