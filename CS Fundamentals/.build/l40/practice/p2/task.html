Build the autosquash todo list

Given your branch's commits, oldest first, return the todo list that git rebase -i --autosquash opens with, one line per commit in Git's format: pick 86bed1d # Add discount.

  • A commit whose subject is fixup! <subject> moves to just after the earlier commit with that subject, with the action fixup. squash! <subject> works the same way, with squash.
  • Several fixups for one commit keep their order. A fixup whose target isn't on the branch stays where it is, as a pick.
