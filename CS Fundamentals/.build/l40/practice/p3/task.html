Run a CI job

Write runJob, which runs a job's steps in order the way a GitHub Actions job does, and returns whether the job passed plus one log line per step.

  • Exit code 0 logs ok <name>. Any other code logs FAILED <name> (exit N) and fails the job.
  • A step that throws fails too: FAILED <name> (threw IllegalStateException), using the exception's simple class name.
  • After a failure, later steps log skipped <name> and never run, unless they're marked always, like if: always().
