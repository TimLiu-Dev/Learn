You need one piece of state that survives from step to step: has anything failed yet? Start with var passed = true and a mutableListOf<String>() for the log.

---

For each step, first decide whether it runs at all: skip it when !passed && !step.always. If it runs, wrap step.run() in try/catch (e: Exception), so a throw becomes a failure like a non-zero exit. e::class.simpleName gives IllegalStateException.

---

Only ever set passed = false, never back to true: a green step after a red one doesn't make the job green. Turn each outcome into its log line with a small if. If a test fails, println(log) inside your function shows up under the failure. In Java, e.getClass().getSimpleName() does the same job.
