Why it works. The only reliable anchors in the line are the first two numbers, the :: in the method name and the (N bytes) size; everything else is optional. Ignoring OSR lines matters: a % compile only gives the running loop a way in, at the @ offset. The method's normal entry point gets C2 code only when the full-method compile lands.

Common mistake. Taking the first tier-4 line. In Hot's log that's the OSR compile at 10 ms, nine milliseconds before C2's whole-method version. (This format is a HotSpot implementation detail, so a parser like this is for your own logs, not production.)
