Split on whitespace, as the starter does. tokens[0] is the time and tokens[1] the ID. The method is the token containing ::, and the size is the token starting with (.

---

Everything between the ID and the method is the "middle": flag characters such as %, then the tier if there is one. middle.any { '%' in it } gives osr; middle.lastOrNull()?.toIntOrNull() gives the tier, or null when the last token isn't a number (L3's safe call).

---

c2Landed is lines.map(::parse).firstOrNull { it.method == method && it.tier == 4 && !it.osr && !it.retired }?.ms. In Java, make Compile a record, use Integer for the nullable tier, and loop instead of firstOrNull.
