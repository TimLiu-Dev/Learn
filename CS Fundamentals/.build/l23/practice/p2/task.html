Simulate class initialisation

MiniJvm.use(name) stands for a new, getstatic or invokestatic that refers to a class. Make it follow JVMS §5.5, recording "init NAME" in events when a class's initialiser runs:

  • A class initialises once. Its superclass initialises first.
  • Its initialiser then touches each class in initUses, in order, which may initialise those too.
  • A class whose initialisation has already started counts as done. That's how the JVM survives A using B while B uses A.

One check runs real Kotlin classes and compares their log with your simulation.
