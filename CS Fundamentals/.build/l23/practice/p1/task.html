Be the interpreter

execute runs a tiny bytecode program, the way HotSpot's interpreter does before the JIT steps in. Locals start as the arguments (slot 0, 1, …); the operand stack starts empty. Fill in the TODOs:

  • iconst N pushes N. iload K pushes local K. istore K pops into local K.
  • iadd, isub, imul pop two ints and push the result. ireturn pops the result and returns it.

Our toy writes iload 0 where javap prints iload_0; otherwise the programs in the checks are real javac output.
