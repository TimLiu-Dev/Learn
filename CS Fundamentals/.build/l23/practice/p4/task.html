Undo R8's renaming

A release build's crash says at a.b.a.a(SourceFile:17). R8's mapping file says what the short names were. Make retrace rewrite one stack frame:

  • A class line, original -> obfuscated:, starts at column 0. Under it, indented lines are fields (no parentheses) or methods: [first:last:]returnType name(args) -> obfuscated.
  • Several methods can share one short name. The optional first:last: line range says which one owns the frame's line number.
  • A class that isn't in the mapping (the JDK's own, say) was never renamed: return the frame unchanged.
