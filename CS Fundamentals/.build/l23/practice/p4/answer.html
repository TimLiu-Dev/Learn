Why it works. The mapping file is a two-level map, class then members, and only line numbers can tell apart two methods that R8 renamed to the same a. That's why release builds should keep line-number information. This is a toy: Android's real retrace tool also maps the line numbers back to the source, and handles methods R8 inlined into others (R8 retrace, mapping format).

Common mistake. Taking the first method whose short name matches. a.b.a.a then always says lend, and you'd debug the wrong method. ProGuard's ReTrace, given no line numbers, lists every candidate instead of guessing.
