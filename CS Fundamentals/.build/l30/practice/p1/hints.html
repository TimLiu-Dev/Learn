Build the number one octet at a time: start from 0, and for each part shift what you have left by 8 and or the new number in. Check parts.size and the 0–255 range with require; "a".toInt() already throws a NumberFormatException, which is an IllegalArgumentException.

---

A mask is -1 (all 32 bits set) shifted left by 32 - prefix, so the right-hand zeros appear. An address is in the block when (ip and mask) == (network and mask). Don't compare with < or >: 192.168.… is a negative Int.

---

If only the /0 checks fail, remember L48: an Int shift uses only the low 5 bits of the distance, so -1 shl 32 is -1, not 0. Give prefix 0 its own case. In Java, split with text.split("\\."): the argument is a regex, and a bare "." matches every character.
