A cache that counts down

Build the cache a resolver keeps, on a fake clock: clock() returns the time in seconds, so the checks can move time without sleeping.

  • store(name, addresses, ttl) caches an answer for ttl seconds.
  • lookup(name) returns the addresses and the seconds left, counting down like dig's 169 → 162. Once no seconds are left, or if the name was never stored, it returns null.
  • With fixedTtl = 30, the cache behaves like the JVM's: it ignores the record's TTL and keeps every answer for 30 seconds.
