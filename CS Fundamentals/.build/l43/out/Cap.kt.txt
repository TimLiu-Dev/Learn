===== Cap.kt
== CP mode: a bank balance
A write balance=100 -> OK (replicated to B)
-- partition: the link between A and B is cut
A write balance=70  -> REJECTED: can't reach B, so the write can't be replicated
B write balance=40  -> REJECTED: can't reach A, so the write can't be replicated
reads: A=100 B=100   (consistent, but no one can write)

== AP mode: a shopping cart
A write cart=[book] -> OK (sent to B)
-- partition
A write cart=[book,lamp] -> OK locally (B will hear later)
B write cart=[book,pen]  -> OK locally (A will hear later)
reads: A=[book,lamp] B=[book,pen]   (available, but they disagree)
-- heal: exchange the writes each side missed (last write wins)
    B drops [book,lamp] (t=5 from A): older than [book,pen] (t=6)
reads: A=[book,pen] B=[book,pen]   (agree again, and the lamp is gone)
