The lesson's rule was "replace mine only if the incoming ts is strictly greater". With a tie, A keeps its lamp and B keeps its pen, and they never agree. You need a rule that has an answer for every pair, and gives the same answer both ways round.

---

Compare by ts first; only when the timestamps are equal, compare the node names. Kotlin builds that comparator for you: compareBy({ it.ts }, { it.node }), and maxOf(a, b, comparator) picks the larger.

---

receive is data[key] = if (mine == null) incoming else lww(mine, incoming). Because lww returns the same winner whatever the order, receiving a version twice, or an old one late, can't change the result. In Java, data.merge(key, incoming, Practice::lww) does both cases in one call.
