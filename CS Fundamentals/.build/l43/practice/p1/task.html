Last write wins, without the split

In the lesson's demo one global clock stamped every write. Real replicas each keep their own counter, so two concurrent writes can carry the same timestamp. Fill in the TODOs:

  • lww(a, b) returns the winner: the newer ts, and on a tie the larger node name. It must pick the same winner whichever order the two arrive in.
  • receive keeps the winner of what the replica holds and what arrived. A version can arrive late, or twice.

One check partitions two replicas, writes on both, swaps the writes and expects them to agree.
