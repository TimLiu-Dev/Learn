Start with the children: spans.groupBy { it.parent } gives every parent id its list of child spans in one pass, whatever order the spans arrived in. A leaf just has no entry.

---

Don't subtract the sum of the children's durations: two parallel 50 ms calls inside a 100 ms span would leave 0. You need the length of the union of their intervals. Sort the children by start, then walk them, remembering the furthest end reached so far, and add only the part beyond it.

---

Write a helper covered(intervals) with var total and var reach = Long.MIN_VALUE; for each sorted (start, end), add end - maxOf(start, reach) when that's positive, then move reach. culprit is spans.maxBy { self.getValue(it.id) }.service. In Java, group with computeIfAbsent and sort with Comparator.comparingLong(Span::start).
