Write allowRequest as a when (state) with three branches. CLOSED is the easy one: always true. Then do recordFailure, so the first test can open the circuit.

---

OPEN: compare now() - openedAt with openMs. Too early, return false. Otherwise switch to HALF_OPEN and return true: this caller is the trial. HALF_OPEN itself returns false, because the one trial is already out.

---

recordSuccess: failures = 0; state = CLOSED. recordFailure: failures++, then open if you were HALF_OPEN or reached the threshold, and set openedAt = now() every time you open. In Java the clock is a LongSupplier, read with now.getAsLong().
