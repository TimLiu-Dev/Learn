Drive a circuit breaker by hand

This breaker has the shape many libraries use: callers ask allowRequest() before a call, then report recordSuccess() or recordFailure(). Fill in the three TODOs:

  • CLOSED: allow everything; threshold failures in a row open the circuit. A success resets the count.
  • OPEN: refuse until openMs have passed, then go HALF_OPEN and allow exactly one trial.
  • HALF_OPEN: refuse everyone else. A successful trial closes the circuit; a failed one reopens it with a fresh timer.

The tests pass a fake clock, { t }, and move t by hand (L38).
