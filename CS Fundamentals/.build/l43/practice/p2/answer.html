Why it works. Every state answers one question differently: CLOSED trusts the dependency, OPEN protects it, HALF_OPEN asks it a single question. The clock is a parameter, so the tests jump 1,000 ms in a line instead of sleeping. This is the same machine as the lesson's CircuitBreaker, split the way libraries such as Resilience4j split it (ask permission, then report the outcome), so the caller decides what counts as a failure. @Synchronized keeps two request threads from both taking the trial.

Common mistake. Returning true from HALF_OPEN. The moment the timer expires, every waiting caller rushes a dependency that may have barely recovered, and one more overload knocks it straight back down. One trial at a time is the whole point of half-open.
