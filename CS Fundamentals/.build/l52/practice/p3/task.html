Take the branch out

Part 3's mask loop picks a value with bits instead of an if. Use the same trick for min:

  • signMask(x) returns -1 (all ones) when x is negative, and 0 otherwise. One shift does it.
  • minBranchless(a, b) returns the smaller Int with no if, when, comparison or minOf: build a mask that is all ones when a < b, and use it to pick.

It must be right for every Int, including Int.MIN_VALUE and Int.MAX_VALUE.
