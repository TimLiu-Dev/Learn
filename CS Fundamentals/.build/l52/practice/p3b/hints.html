When step() reaches the when, pc has already moved past the CALL. So pc is the return address: the instruction the caller should continue with.

---

CALL: after the overflow check, move sp down one ((sp - 1) and 0xFF, so 00 becomes FF), store pc at mem[sp], then set pc = b1. RET undoes it in reverse: after the underflow check, read mem[sp] into pc, then move sp up one.

---

check(sp != STACK_LIMIT) { "stack overflow at ${hex(at)}: SP=${hex(sp)}" } and check(sp != 0x00) { "stack underflow at ${hex(at)}" }. In Java, write the if and throw new IllegalStateException(…) yourself.
