Be the assembler, in code

You encoded instructions by hand. Now let a function do it. assemble("SUB R2, R3") must return the two bytes [0x5B, 0x00].

  • tokens(line) is given: "LD R1, [80]" becomes [LD, R1, 80]. Numbers and addresses are hex.
  • Byte 0 packs oooo dd ss (opcode, rd, rs) as in the table above. Byte 1 is the number or address, or 0 when there isn't one. Unused fields are 0.
  • An unknown mnemonic throws IllegalArgumentException.
