One object per currency

A factory doesn't have to make a new object every time (Effective Java Item 1). Make Currency.of the only way to get a Currency:

  • The constructor is private. of trims and upper-cases the code, and rejects anything that isn't exactly three letters with IllegalArgumentException.
  • Asking twice for the same code returns the same object: Currency.of("eur") === Currency.of(" EUR ").
  • Currency.known is how many distinct currencies exist so far.
