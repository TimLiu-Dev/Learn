Private is not enough

Outside code can overfill this Playlist by reaching for items. Lock it down:

  • items must not be visible outside the class. add stays the only way in: it trims the title and refuses to go past maxSize.
  • songs must be a snapshot. Changing what it returns, or adding songs later, must never change a list someone already got.

One check casts songs to MutableList and tries to add, the way a Java caller could.
