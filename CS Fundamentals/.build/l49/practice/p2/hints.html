You need three things besides out: dist (an arrayOfNulls<Int>(n), with the source at 0), a settled flag per vertex, and a PriorityQueue<Pair<Int, Int>> ordered by the distance, compareBy { it.first }.

---

Loop while the queue isn't empty: poll (d, v). If v is already settled, this entry is stale, so skip it. Otherwise settle it, and for each edge out of v, relax: if d + weight beats dist[to] (or dist[to] is null), store it and add a new entry.

---

Never treat a distance as final when you first write it. Only polling makes it final. That's what lets 0 → 2 → 1 (3) beat the direct edge (10). In Java, use Integer[] so it can hold null, and a queue of int[]{dist, vertex} with Comparator.comparingInt(a -> a[0]).
