Union-find, checked against a naive one

Finish DisjointSets, the weighted quick-union with path compression from Part 3:

  • find(p) walks to the root, then points every node on that path straight at the root.
  • union(p, q) hangs the smaller tree's root under the larger one's, and returns false if p and q were already connected.
  • sizeOf(p) is the number of sites in p's component.

The last check runs 500 random operations against a slow quick-find written in the test file, and compares every answer.
