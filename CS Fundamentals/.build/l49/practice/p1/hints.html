Sort a copy with sessions.sortedBy { it.end }. Then walk it once, keeping the names you took and one number: the end time of the last session you took.

---

A session fits if it starts at or after that last end. Because you go in order of end time, it can't clash with anything taken earlier, so there's no need to check the whole list the way Schedule's greedy does.

---

Start with var lastEnd = Int.MIN_VALUE, and use s.start >= lastEnd: >=, not >, because touching sessions don't overlap. In Java, sort a copy with Comparator.comparingInt(Session::end).
