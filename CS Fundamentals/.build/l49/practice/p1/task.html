Earliest finish, in one pass

Write schedule(sessions): the names of the largest set of sessions that don't overlap, in time order. Times are half-open, [start, end), as in Schedule, so a session may start the minute another ends.

  • Use the rule Part 1 proved: earliest finish first.
  • After the sort, make one pass that compares each session only with the last one you took, Erickson's "simple linear-time loop".

One check is trap1, where "earliest start" fails. Another compares your answer with brute force on 300 random schedules.
