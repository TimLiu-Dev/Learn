For each right: add 1 to c's count. The number of distinct characters in the window is simply counts.size, as long as no zero counts stay in the map.

---

While counts.size > k, take s[left] out: decrease its count, remove the key when it reaches 0, and move left forward. Only after that loop is the window valid, so that's where you compare its length with the best.

---

Use >, not >=, when comparing with bestLen, so a later window of the same length doesn't replace an earlier one. In Java, counts.merge(c, 1, Integer::sum) grows a count, and s.charAt(left++) reads the leaving character.
