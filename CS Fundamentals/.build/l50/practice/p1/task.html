Longest stretch with at most k distinct letters

Write longestAtMostK(s, k): the longest substring of s that contains at most k different characters. If two are equally long, return the one that starts first.

  • "eceba" with k = 2 gives "ece". k = 0 or an empty string gives "".
  • Make it O(n) with a sliding window. Unlike longestUnique, the left edge can't jump: it has to shrink one character at a time, keeping a count per character.
