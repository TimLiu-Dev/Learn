Why it works. right visits each index once and left only moves forward, so the loops do at most 2n steps between them: O(n), like longestUnique. Removing a key when its count hits 0 keeps counts.size equal to the number of distinct characters in the window. The best is recorded only after the while, when the window is valid again.

Common mistake. Updating the best before the shrinking loop. For "eceba" that records "eceb", a window with 3 distinct letters, for the one step before it gets fixed.
