Shrink a counterexample

A stress tester's first counterexample is often longer than it needs to be. Write shrink(input, fails), which makes a failing input as small as it can by deleting elements:

  • Try deleting one element at a time. Whenever the smaller list still fails, keep it and start again from the front.
  • Stop when deleting any single element makes the failure go away, and return that list. Reject an input that doesn't fail with IllegalArgumentException.

One check shrinks an 8-number input that breaks Part 4's if-instead-of-while window.
