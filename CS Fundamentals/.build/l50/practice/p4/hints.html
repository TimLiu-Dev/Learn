Start with require(fails(input)). Then keep a current list and an index i, and build "current without element i" with filterIndexed.

---

If the smaller list still fails, it becomes current. Otherwise element i is needed, so move on to i + 1. The loop ends when i reaches the end without a successful deletion.

---

After a successful deletion, don't also do i++: the next element has just slid into slot i. Resetting i = 0 is simplest, because a deletion can make an earlier element unnecessary too. In Java, the parameter is a Predicate<List<T>>, and the smaller list is a copy with remove(i), by index.
