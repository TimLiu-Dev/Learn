insert is the lesson's: walk the characters with getOrPut, then set isWord on the last node. For the query, start at the root and step one character at a time.

---

Keep bestLen, the length of the longest word end passed so far (−1 for none). After each step, if the node is a word end, set bestLen = i + 1.

---

When the next child is missing, don't return null the way find does: break and answer from bestLen with query.substring(0, bestLen). In Java, a missing child is children.get(c) == null, and the walk is an index loop over query.charAt(i).
