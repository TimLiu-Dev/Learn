The run from index s + 1 to i sums to k exactly when the prefix sum up to i minus the prefix sum up to s is k. So at each i, look up sum - k in the map: if it's there, the run is i - s long.

---

Seed the map with 0 → -1, so a run that starts at index 0 has somewhere to start from. After the lookup, record where sum occurred, but only if it isn't in the map yet.

---

firstAt.putIfAbsent(sum, i) keeps the first index, which gives the longest run; firstAt[sum] = i would keep the latest. Java: Integer start = firstAt.get(sum - k); if (start != null) best = Math.max(best, i - start);
