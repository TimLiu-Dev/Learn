Longest run that sums to k

Write longestWithSum(a, k): the length of the longest contiguous run of a whose sum is exactly k, or 0 if there is none. The numbers may be negative.

  • [1, -1, 5, -2, 3] with k = 3 gives 4 (the run 1, -1, 5, -2).
  • Make it O(n) with prefix sums and a HashMap (L19). countSubarrays stored how often each prefix sum occurred; this one needs to know where.
