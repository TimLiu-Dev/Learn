Every subset that hits the target

Write subsetSums(nums, target): every subset of nums whose sum is exactly target. The numbers are positive, distinct and sorted ascending, and each one may be used at most once.

  • Return each subset in ascending order, and the subsets in the order a search finds them when it always tries the next number from left to right: [1, 2, 3, 4, 5] with target 5 gives [[1, 4], [2, 3], [5]].
  • Prune: once the running sum would pass the target, stop trying larger numbers. One check runs on 1 to 40, which has 240 subsets.
