Each call decides the next number to add, choosing from position start onwards. If sum == target, record a copy of current and return: with positive numbers, adding anything more would overshoot.

---

For i from start: add nums[i] to current, call go(i + 1, sum + nums[i]), then remove it again. Passing i + 1 is what stops a number from being used twice.

---

Before choosing, check sum + nums[i] > target. Because the list is sorted, every later number overshoots too, so break, not continue. In Java, the copy is List.copyOf(current) and the un-choose is current.remove(current.size() - 1), by index.
