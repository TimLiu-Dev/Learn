Amdahl is one line once the inputs are checked: speed-up = 1 / ((1 − p) + p / n). Kotlin's require(condition) { "message" } throws IllegalArgumentException for you. For Little, convert milliseconds to seconds: 50 ms is 0.05 s, so 200 × 0.05 = 10.

Stay in whole numbers for poolSizeFor: busy milliseconds per second = requestsPerSecond * latencyMs, and threads = that ÷ 1000, rounded up. Integer division rounds down, so use the ceiling trick from L48: (x + 999) / 1000. Then try the overflow test: 50,000 × 60,000 is 3 billion, more than an Int holds (L4).

---

val busyMs = requestsPerSecond.toLong() * latencyMs, then return ((busyMs + 999) / 1000).toInt(). In Java, the same: long busyMs = (long) requestsPerSecond * latencyMs;, and if (p < 0 || p > 1) throw new IllegalArgumentException(…) in place of require.
