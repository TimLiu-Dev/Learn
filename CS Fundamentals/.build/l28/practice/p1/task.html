Amdahl and Little in code

Write the two laws from "How big should a pool be?" as functions you could use in a design review:

  • amdahlSpeedup(p, n): the best possible speed-up on n cores when a fraction p of the work is parallel. Reject a p outside 0..1 or an n below 1 with IllegalArgumentException.
  • poolSizeFor(requestsPerSecond, latencyMs): how many threads are busy on average (L = λW), rounded up to whole threads.
