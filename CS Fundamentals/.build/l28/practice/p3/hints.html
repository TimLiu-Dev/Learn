Three steps: semaphore.acquire(), run block(), semaphore.release(). The first two tests pass with just that. Which one still fails, and why?

---

When block() throws, any line after it is skipped, so the permit never comes back. After three failed queries, a Gate(3) would let nobody in, ever. The tool for "run this no matter what" is finally (L10).

---

semaphore.acquire(), then try { return block() } finally { semaphore.release() }. Acquire before the try: if acquire() itself is interrupted, you hold no permit and must not release one. In Java, enter takes a Callable<T> and declares throws Exception; the body is the same.
