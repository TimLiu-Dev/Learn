Start the discount first (val off = discount()), so it runs while the user is looked up. Then start from findUser(userId). The orders call needs the user, and ordersFor returns a future: which method flattens a future-returning function, thenApply or thenCompose?

---

Inside thenCompose { user -> … }, combine the orders with the discount: ordersFor(user).thenCombine(off) { amounts, d -> … }. That keeps user.name in scope. Finish the chain with exceptionally { e -> … }. If a test says failed: java.lang.IllegalStateException: orders down, add println(e): what type is e?

---

e is a CompletionException whose cause is the real exception, as in CfErrors. Use val cause = if (e is CompletionException) e.cause ?: e else e, then "failed: ${cause.message}". In Java, the same chain uses findUser.apply(userId).thenCompose(user -> ordersFor.apply(user).thenCombine(off, (amounts, d) -> …)).
