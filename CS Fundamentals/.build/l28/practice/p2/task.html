Bill a user without blocking

Write bill(userId, findUser, ordersFor, discount). It looks up the user, then that user's order amounts, and meanwhile the discount, and completes with "Ada pays 950" (the sum of the orders minus the discount).

  • Return the pipeline straight away: no join() or get() inside bill.
  • If any stage fails, complete with "failed: " plus the original exception's message, not an exception.
