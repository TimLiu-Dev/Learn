Run SELECT customer_id FROM orders; on its own. Which value in that list is different from the others, and where does it come from?

---

The guest orders put a NULL in the list. For Eli (id 5), 5 NOT IN (1, 1, 1, 2, 3, 4, 4, NULL, NULL) is unknown, because a NULL might be 5. Unknown isn't true, so WHERE drops him, and everyone else.

---

Ask "is there an order for this customer?" instead: WHERE NOT EXISTS (SELECT 1 FROM orders o WHERE o.customer_id = c.id), with c as the alias for customers. That test is always plainly true or false.
