Build it one clause at a time and run after each. First the WHERE alone, with no ORDER BY or LIMIT: you should see 7 books, two of them undated.

---

"Undated" is year IS NULL; year = NULL is never true. Because AND binds tighter than OR, the OR needs parentheses: price_cents < 1300 AND (year IS NULL OR year < 1980). Without them, One Thousand and One Nights ($15.99) sneaks in.

---

Sort with ORDER BY year NULLS FIRST, title. SQLite already puts NULLs first in ascending order, but saying so keeps the query right on PostgreSQL too. Page 2 at 3 per page skips 3 rows: LIMIT 3 OFFSET 3.
