expectEqual is one line: if (expected != actual) throw AssertionError("…"). Use a string template for the message, with expected first.

---

In runAll, loop with for ((name, body) in tests). Call body() inside a try. If it returns, the test passed. If it throws, it failed.

---

Catch AssertionError, not Exception. L10's family tree puts it under Error, so catch (e: Exception) lets it escape and crash the whole run. Add "PASS $name" after body() and "FAIL $name: ${e.message}" in the catch. In Java, the test bodies are Runnables, so you call run().
