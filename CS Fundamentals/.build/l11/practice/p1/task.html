Build a tiny JUnit

A test framework is less magic than it looks. Write its two halves:

  • expectEqual(expected, actual) returns quietly when the two are equal (by ==). Otherwise it throws an AssertionError whose message is exactly expected: <X> but was: <Y>.
  • runAll(tests) runs every test body in order and returns one line per test: "PASS name", or "FAIL name: MESSAGE". One failing test must not stop the rest.

The hidden checks are JUnit 4, so they import org.junit.Test. Your Gradle projects use JUnit 5+, where it's org.junit.jupiter.api.Test (or kotlin.test.Test). The idea is the same.
