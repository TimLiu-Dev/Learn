Why it works. A test is just a function that either returns (pass) or throws (fail). An assertion is an if plus a throw, and a runner is a loop with a try/catch around each test. JUnit adds discovery, reports and much more, but its core is this. That's also why the order of expected and actual matters: the message is built from it.

Common mistake. catch (e: Exception). AssertionError is an Error, not an Exception, so the first failing test escapes the runner and the rest never run. (Real JUnit also catches other exceptions and reports them as failures.)
