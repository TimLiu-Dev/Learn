TDD in miniature: a string calculator

The six checks are the spec for add(numbers), numbered in the order a TDD session would write them. Work through them strictly, one at a time:

  • Make step 1 green with the simplest code that could work, and run. Then step 2, and run again. Never write code that no red check asks for.
  • When a step is green, tidy the code if it needs it, and run once more to prove you broke nothing.

The checks use JUnit 4 (org.junit.Test). In your Gradle projects it's org.junit.jupiter.api.Test, and assertFailsWith or assertThrows instead of the try/fail pattern you'll see in step 6.
