Middle-of-the-band scores like 95 or 50 get the same grade from every buggy copy. Bugs hide where the answer changes: at the edges between bands.

An off-by-one can push an edge either way, so test both sides of it. For the A/B edge, that's 89 and 90. The same goes for the edges of the valid range, 0 and 100, and just outside them.

Eight rows are enough: -1, 0, 70, 80, 89, 90, 100 and 101, each with the grade the spec gives. Work out each expected value from the spec, not from code. In Java, each row is a new Case(score, "grade").
