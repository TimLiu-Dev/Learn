Why it works. Each pattern describes the shape of the data narrowly, so it masks what it should and nothing more. The email stops at the last letter of its domain, so the comma survives, and \b keeps the card pattern from firing inside a longer digit run. Over-masking matters too: a log that hides order ids and trace ids is useless for debugging.

Common mistake. Leaving out the \bs. The pattern then grabs the first 19 digits of the trace id and calls it a card. And remember that redaction is the safety net: the real fix is not to log personal data at all. A production masker would also run the Luhn checksum before calling a number a card.
