Card: one digit, then 12 to 18 more, each optionally preceded by a space or hyphen: \d(?:[ -]?\d){12,18}. Keep the last four with m.value.filter { it.isDigit() }.takeLast(4).

---

The trace-id test needs word boundaries: wrap the card pattern in \b…\b so it can't start or stop in the middle of a digit run. Kotlin raw strings ("""…""") save you doubling every backslash. In Java you do double them, and Matcher.replaceAll(m -> …) takes a function for the card part.
