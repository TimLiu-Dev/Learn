Split stored on "$". You want exactly four parts, and the first must be pbkdf2-sha256; anything else is false.

---

Parse the iterations with toIntOrNull() and return false on null. Decode salt and hash with Base64.getDecoder(), call pbkdf2(pw, salt, iterations), and compare with MessageDigest.isEqual.

---

Bad Base64, an empty salt and zero iterations all throw IllegalArgumentException, so wrap the decode-and-hash in try { … } catch (e: IllegalArgumentException) { false }. In Java, remember split("\\$"): a bare "$" is a regex anchor and gives one piece.
