Verify a stored hash at any cost

Stored hashes look like Part 2's: pbkdf2-sha256$<iterations>$<base64 salt>$<base64 hash>. pbkdf2 and store are written for you.

  • Write verify(pw, stored): re-hash pw with the stored salt and iteration count, and compare in constant time.
  • An unknown algorithm or a malformed string returns false. It never throws.

The tests use 1,000–3,000 iterations to stay fast. Real code uses at least 600,000.
