Sign and verify a token with HMAC

A token is message + "." + tag, where the tag is the hex HMAC-SHA256 of the message. hmacHex is written for you.

  • sign(key, message) builds the token.
  • verify(key, token) returns the message if the tag is genuine, and null for anything else: an edited message, another key, or a token that isn't even shaped right. It must never throw.
  • Messages may contain dots themselves, like v1.2.3.
