Verify a webhook signature

A payment provider POSTs events to your server with a header like t=1767225600,v1=<tag>. The tag is the hex HMAC-SHA256, under your shared secret, of the timestamp, a dot and the raw body: "$t.$body". This is the scheme Stripe documents. hmacHex is written for you.

  • sign(secret, t, body) builds the header, as the sender would.
  • verify(secret, header, body, now) returns true only if the tag is genuine and t is within 300 seconds of now, so an old delivery can't be replayed. Compare tags with MessageDigest.isEqual.
  • Anything malformed gives false. It must never throw.
