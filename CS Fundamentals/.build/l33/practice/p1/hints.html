sign is one line: message + "." + hmacHex(key, message). For verify, find the dot that separates message from tag, recompute the tag from the message, and compare.

---

The tag is hex, so it never contains a dot, but the message might. That means the separator is the last dot: token.lastIndexOf('.'). If there's no dot at all (-1), return null straight away.

---

Compare MessageDigest.isEqual(expected.toByteArray(), tag.toByteArray()) and return the message only when it's true. Comparing hex strings this way avoids decoding the tag, so a non-hex tag simply doesn't match instead of throwing. Java is the same, with getBytes(StandardCharsets.UTF_8).
