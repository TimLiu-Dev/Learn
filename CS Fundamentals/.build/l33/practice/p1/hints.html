sign is one line: the tag is hmacHex(secret, "$t.$body"), and the header is "t=$t,v1=$tag". For verify, split the header at , and each entry at its first =, then recompute the tag from the received timestamp and body.

---

Parse defensively: parts["t"]?.toLongOrNull() ?: return false, and the same for v1, so a broken header falls out as false. Compare with MessageDigest.isEqual(expected.toByteArray(), tag.toByteArray()). Comparing the hex strings this way means a non-hex tag simply doesn't match.

---

Only after the tag matches, check the age: Math.abs(now - t) <= TOLERANCE_SECONDS. The timestamp is trustworthy at that point, because it was inside the signed text. In Java, loop over header.split(",") with indexOf('='), catch NumberFormatException from Long.parseLong, and use getBytes(StandardCharsets.UTF_8).
