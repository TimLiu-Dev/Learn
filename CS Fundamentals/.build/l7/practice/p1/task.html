Equal means the same hash

Two Emails are the same address when they match ignoring letter case: Ana@X.io and ana@x.io are one person. A data class can't express that, so write the three methods by hand:

  • equals: same address, ignoring case. Anything that isn't an Email is never equal.
  • hashCode: must agree with equals, so equal emails land in the same HashSet bucket.
  • toString: Email(Ana@X.io), showing the address as it was typed.
