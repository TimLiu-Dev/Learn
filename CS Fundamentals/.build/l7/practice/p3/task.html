The case someone added later

A form field asks for an age. Someone recently added OutOfRange to the sealed family, but describe was written before that, with an else.

  • parseAge: trim the text. Blank text is Blank; text that isn't a whole number is NotANumber (with the trimmed text); a number outside 0..150 is OutOfRange; anything else is Valid.
  • describe: delete the else first and run once. Read the compiler error, then give every case its own branch. OutOfRange(200) reads out of range: 200.
  • validAges: the ages from every valid input, in order.
