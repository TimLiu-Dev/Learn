Compile to a stack machine, then run it

Write compile(e), which turns a tree into stack-machine instructions, and execute(code), which runs them with an ArrayDeque<Int> as the operand stack (L17).

  • Instructions are strings: "push 3", "neg", "add", "sub", "mul", "div".
  • 1 + 2 * 3 compiles to [push 1, push 2, push 3, mul, add].
  • execute returns the one value left on the stack.
