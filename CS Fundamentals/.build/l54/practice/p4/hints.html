compile has the same shape as eval: one when branch per node type, children first. The difference is what each branch returns: instructions to compute the value later, not the value itself.

---

A Bin compiles to compile(e.left) + compile(e.right) + "add" (or sub, mul, div). In execute, push does stack.addLast(…); every other instruction pops its operands with removeLast() and pushes one result.

---

Mind the pop order: the right operand was pushed last, so it comes off first. Write val b = stack.removeLast(), then val a = stack.removeLast(), then compute a - b. In Java, ArrayDeque<Integer> has the same addLast and removeLast.
