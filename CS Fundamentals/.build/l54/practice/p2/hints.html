Each rule's function calls the function of the rule below it: expr asks term for its operands, and term asks atom. The ( … )* in the grammar becomes a while loop.

---

In expr: var left = term(), then while (peek() == "+" || peek() == "-"). Inside, take the operator with next()!![0], read the right operand with term(), and make left a new Bin. term has the same shape with *, / and atom().

---

The loop is what makes 8-3-2 lean left: the tree built so far becomes the left child of the next Bin. Don't call expr() for the right operand; that recursion builds (- 8 (- 3 2)). Java is the same with a while and Objects.equals(peek(), "+"), since peek() can be null.
