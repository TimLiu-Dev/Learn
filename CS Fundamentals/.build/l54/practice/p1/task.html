Tokenize arithmetic, with a two-character operator

Write tokenize(src) for arithmetic: whole numbers, the operators + - * / ( ) and ** (power). It returns each token's text, skips spaces, and ends with no EOF marker.

  • A number is a run of digits: "12+3" gives [12, +, 3].
  • Maximal munch: ** is one token, so "2***3" gives [2, **, *, 3].
  • Anything else throws CalcError("unexpected 'c' at column N"), counting columns from 1.
