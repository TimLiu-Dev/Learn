Why it works. Each branch consumes exactly one token's characters and leaves i on the first character that can't continue it. That's maximal munch: a number keeps going while digits come, and ** is tried before *, so the longest match wins. "2***3" becomes ** then *, just as Java turns a---b into a, --, -, b.

Common mistake. Adding one token per digit, so "12" becomes [1, 2]. The parser would then see two numbers in a row and report a confusing error far from the cause.
