Replace the TODO with a when that has one branch per kind of character: a space, a digit, a * followed by another *, any other operator, and else. Every branch must move i forward, or the loop never ends.

---

For a digit, remember start = i, then advance while src[i] is still a digit (check i < src.length first) and add src.substring(start, i). For **, peek at src[i + 1] before you settle for a single *.

---

Order matters: test the ** branch before the one-character operators, or * always wins. The column is i + 1, because i counts from 0. In Java the same shape is an if/else if chain, with the digit test written as c >= '0' && c <= '9'.
