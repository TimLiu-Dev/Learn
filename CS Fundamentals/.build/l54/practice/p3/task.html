Walk the tree: an interpreter with variables

Write eval(e, env), which evaluates a tree post-order (children first, then the node), and run(program), which runs the lets in order and then evaluates the result.

  • An undefined variable throws CalcError("undefined variable 'b'").
  • / and % by zero throw CalcError("division by zero"), not a JVM ArithmeticException.
  • let x = x * x reads the old x. Everything else follows Int's rules.
