Write eval as one when (e) with a branch for each of the four node types. Because Expr is sealed, the compiler tells you if you forget one (L7).

---

A Var is a map lookup: env[e.name] ?: throw CalcError(…). A Bin evaluates e.left and e.right recursively into a and b, then a second when (e.op) combines them. Check b == 0 before / and %.

---

For run: make a HashMap<String, Int>(), and for each let write env[let.name] = eval(let.value, env). The right side runs first, so let x = x * x sees the old x. In Java, env.get(name) returns a nullable Integer: check it for null before unboxing.
