Give each task an index and its own slot in an Array(tasks.size) { "" }. A thread that writes only its own slot shares nothing with the others, just like the parallel-sum exercise. thread(name = …) { … } creates and starts a thread.

---

Use two separate loops. The first starts every thread and keeps the Thread objects (tasks.mapIndexed { i, task -> thread(…) { … } }). The second calls join() on each one. If you join inside the first loop, the next thread can't start until the previous one has finished.

---

The thread body is results[i] = task(). After the joins, return results.toList(). In Java, the lambda can't use the loop variable i because it changes, so copy it first: int idx = i;. Also call start() yourself, never run().
