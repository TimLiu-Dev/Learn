Play the scheduler in code

Two threads, A and B, each run count++ once, as three steps: read count into the thread's own register, add 1 to the register, write the register back to count. A schedule such as "ABAABB" says which thread takes its next step.

  • finalCount(start, schedule) follows a schedule and returns the final count.
  • allSchedules(a, b) lists every order of a A-steps and b B-steps. Then the checks count how many of the orders lose an update.
