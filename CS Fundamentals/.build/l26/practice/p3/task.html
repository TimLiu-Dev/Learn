Load each key exactly once

Memo caches what loader returns, and loads counts the calls to loader. With one thread it's correct. With several threads, get is a check-then-act race, and loads++ is a read-modify-write race.

  • Make Memo thread-safe with a lock, so loader runs at most once per key however many threads ask.
  • One check starts a second thread while the first is still inside loader, so the race shows up on every run, not just sometimes.
