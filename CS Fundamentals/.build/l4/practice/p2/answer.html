Why it works. map builds a new list, and its block creates a new Counter for every element, copying only the Int inside. Copying an Int copies the number, so nothing in the copy shares an object with the originals.

Common mistake. counters.toList() (Java: new ArrayList<>(counters)). It passes the "adding to the original list" check, because the list itself is new, but fails when an original counter changes: both lists hold arrows to the same objects. L5 calls a copy of just the list a snapshot, and shows when that's enough.
