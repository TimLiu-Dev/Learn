A loop needs only one frame

sumTo(n) adds 1 + 2 + … + n. It's correct for small n, but every call pushes another frame, so a big n overflows the stack. A negative n never reaches the base case at all.

  • Rewrite sumTo with a loop, so it runs in a single frame. A negative or zero n gives 0.
  • Watch the size of the answer: sumTo(100_000) is about 5 billion.
