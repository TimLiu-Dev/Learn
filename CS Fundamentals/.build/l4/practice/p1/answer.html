Why it works. The recursive version keeps every unfinished call on the stack until the base case returns, so its depth grows with n. The loop never calls anything, so it uses one frame with two locals, whatever n is. The negative case is fixed for free: 1..n is empty, so the loop body never runs.

Common mistake. var total = 0. It infers Int, which overflows silently past about 2.1 billion, and converting to Long at the end is too late: the wrong number is already there.
