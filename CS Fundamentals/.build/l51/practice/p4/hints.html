verify is three checks joined with &&: every index is in sizes.indices, no index appears twice, and the sizes add up to target. Put the range check first, so && stops before sizes[it] can throw.

---

"No repeats" is pick.toSet().size == pick.size. For search, loop mask over 0 until (1 shl sizes.size): bit i set means item i is in the subset. Build the list of indices, and hand it to verify.

---

The indices for one mask are sizes.indices.filter { mask and (1 shl it) != 0 }. Mask 0 is the empty subset, which is why target 0 returns an empty list. In Java the test is (mask & (1 << i)) != 0, with the parentheses (Part 1's precedence trap), and new HashSet<>(pick).size() finds repeats.
