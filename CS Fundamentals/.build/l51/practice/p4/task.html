Check fast, search slow

Subset sum: given item sizes and a target, is there a set of items whose sizes add up to exactly the target? It's NP-complete, and like SAT it has a quick check and, as far as anyone knows, only a slow search.

  • verify checks a proposed answer, a list of item indices, in one pass. Reject anything that isn't a real subset with the right sum: no index out of range, no item used twice.
  • search tries every subset as a bit mask (L48), from mask 0 upwards, and returns the first one verify accepts, or null.
