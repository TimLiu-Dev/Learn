Decide halting, where you can

Halting can't be decided for every program. But a machine that can only ever be in finitely many configurations (state, head position, tape: everything that determines what it does next) must either halt or repeat one, by the pigeonhole principle (L48). Once a configuration repeats, the run cycles forever.

  • analyse(start, next) runs the machine. next returns the next configuration, or null when the machine halts.
  • Return Halts(steps), or Loops(entry, length): the step at which the repeated configuration was first seen, and how many steps one trip round the cycle takes.
  • No step budget: a long run isn't a loop.
