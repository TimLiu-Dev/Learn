Start the trace as a list holding just start. Each character adds one state, looked up in the map for the last state in the list. table[q][c] is null when there's no move.

---

The elvis operator can bail out of the whole function in the middle of the loop: table[q][c] ?: return null. Then accepts is "no trace → false, otherwise is the last state accepting?"

divisibleBy(m) is Dfa(List(m) { r -> mapOf('0' to 2 * r % m, '1' to (2 * r + 1) % m) }, setOf(0)). In Java, table.get(q).get(c) returns null for a missing move, so compare with null before unboxing it into an int.
