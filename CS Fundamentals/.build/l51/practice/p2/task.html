Run an NFA as a set of states

Part 2's engine follows every choice at once. Write its three pieces for an NFA with ε-moves:

  • closure: the given states plus every state reachable from them by ε-moves alone, however many in a row. ε-moves can form a cycle.
  • step: read one character from every state in the set, then take the closure.
  • matches: start from the closure of {start}, step through the input, and accept if accept is in the final set.

coxNfa(n) builds Part 2's a?{n}a{n}. One check runs it with n = 40, which a backtracker could never finish.
