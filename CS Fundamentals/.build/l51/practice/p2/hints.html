closure is graph reachability (L21): the ε-moves are the edges. Keep a seen set that starts as a copy of states, and a to-do list of states whose ε-moves you haven't followed yet. The seen set is what stops an ε-cycle from looping forever.

---

step collects the to of every move whose from is in the set and whose character is c, then calls closure on that. matches is a fold over the input, starting from closure(nfa, setOf(nfa.start)), not from setOf(nfa.start).

---

In the closure loop: pop a state s, and for each ε-move (s, to), if (seen.add(to)) todo.addLast(to). add returns false for a state already seen. Java's version is the same with an ArrayDeque<Integer> and a HashSet<Integer>.
