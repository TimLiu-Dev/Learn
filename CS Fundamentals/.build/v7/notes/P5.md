## Design (decided 2026-11-26)
- Single Gradle project (like M1/M3), toolchain 25, kotlin 2.4.0, junit 6.0.1; app name `chat` -> build/install/chat/bin/chat.
- JSON: Kotlin kotlinx-serialization-json 1.12.0 (JsonElement API, no plugin); Java Jackson 3.2.4 (tools.jackson).
- CLI: chat --tcp-port P --http-port Q --users FILE [--token-ttl S=3600] [--idle-timeout S=300] [--max-queue N=1024]; port 0 = any.
  prints `ready tcp=<p> http=<q>` once both bound. usage/file errors -> stderr `error: ...`, exit 2.
- users.txt: `name:iterations:saltB64:hashB64` (# comments). name [a-z0-9_]{1,16}. tools/HashPasswords.java (name:password stdin).
- Frames: 4-byte big-endian unsigned length + UTF-8 payload, max 4096. >4096 -> ERR 413 frame_too_large + close. bad utf8 -> ERR 400 bad_utf8 (stay).
- Commands AUTH/JOIN/LEAVE/MSG/WHO/QUIT; each gets exactly one reply OK.../ERR code reason, reply before events it causes.
  AUTH -> OK <user>; WHO -> OK sorted names; QUIT -> OK + close. Events: MSG room user text, JOINED room user (incl joiner), LEFT room user (remaining).
  errors: 400 unknown_command/bad_args/bad_room/bad_text/text_too_long(>4000B)/bad_utf8; 401 not_authenticated/bad_token/token_expired;
  403 not_member; 409 already_authenticated/already_connected/already_member; 408 idle_timeout; 413 frame_too_large; 503 slow_consumer/shutting_down.
  room [A-Za-z0-9_-]{1,32}. text no control chars.
- Token: JWT HS256 {"sub","exp"} (L55), random secret per start.
- HTTP: POST /login {"user","password"} -> 200 {"token","expires_in"}; 401 invalid_credentials; 400 bad_request; 405.
  GET /rooms/{room}/events Bearer -> text/event-stream, first `: ok`, then `id: <room seq>` `data: <event line>`; shutdown `event: shutdown`.
- Outbox per subscriber: bounded deque, offer under room lock; overflow -> abort(clear + ERR 503 slow_consumer), 10 s watchdog, leaveAll async.
- Bugs: global_lock_broadcast, one_read_one_frame, expiry_not_checked, unbounded_queue, out_of_order_fanout, (java) signature_not_checked.
