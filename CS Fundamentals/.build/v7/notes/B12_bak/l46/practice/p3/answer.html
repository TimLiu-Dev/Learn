Why it works. Each layer overwrites the one before it, so the strongest source is applied last, and a key that only one layer knows survives the merge. Collecting every missing key before throwing means one failed start tells the operator everything to fix, rather than one key per restart. The secret is still in values for the code that needs it. Only its printed form is masked: Shelf's L33 rule, applied to the startup log.

Common mistake. env + file + defaults, which reads naturally in priority order. But in a + b the right side wins, so the defaults overwrite everything, and PORT stays 8080 whatever the environment says.
