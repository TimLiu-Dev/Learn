Merge first, check second. Kotlin's + on two maps returns a new map with the keys of both. Which side wins when both have the same key?

---

In a + b, b's value wins. So put the weakest layer first: defaults + file + env. The missing keys are a set difference, required - merged.keys, and you need to sort them for the message.

---

For toString, use values.toSortedMap(), then joinToString(", ") { (k, v) -> … } and print *** when k in secrets. In Java, copy defaults into a HashMap and call putAll(file) and then putAll(env). A TreeMap gives you sorted keys.
