A reviewer's check: can a client retry this?

One review question, automated: "a client times out and retries; what happens?" (L32). Write it for an API table like the one in the design doc:

  • isIdempotent(method): true for the methods RFC 9110 §9.2.2 calls idempotent (PUT, DELETE and the safe methods GET, HEAD, OPTIONS, TRACE). Any other method, including one you've never heard of, is not.
  • retryProblems(api): one comment, "POST /api/links needs an Idempotency-Key", for each endpoint that isn't idempotent and has no key, in the API's order.
