Run the starter first: UNIQUE constraint failed is the primary key refusing a second ('docs', '2026-11-14') row. That's the key doing its job. You want "insert, or if the key exists, add to it": an upsert, exactly like plans.sql in 2.4.

---

Append ON CONFLICT (code, day) DO UPDATE SET clicks = … to the insert. Inside DO UPDATE, clicks is the existing row's value and excluded.clicks is the value the insert tried to write.

---

… GROUP BY 1, 2 ON CONFLICT (code, day) DO UPDATE SET clicks = clicks + excluded.clicks; then DELETE FROM click_queue;. Don't reach for INSERT OR REPLACE: it deletes the old row and writes the new count in its place.
