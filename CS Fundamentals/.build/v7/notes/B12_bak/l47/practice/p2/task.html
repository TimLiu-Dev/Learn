Bind configuration the way Spring does

Shelf's Config.fromEnv (L46) read each variable by hand. Write the two halves of Spring's @ConfigurationProperties for three settings: shelf.db (default shelf.db), shelf.port (default 8080, allowed 0..65535) and shelf.pool-size (default 4, allowed 1..64).

  • envName applies relaxed binding: dots become underscores, dashes are removed, then uppercase.
  • bind looks in env first (under the relaxed name), then in props, then uses the default.
  • Report every problem in one IllegalArgumentException, joined with "; ": shelf.port: 'abc' is not a number or shelf.pool-size: 0 is out of range 1..64.
