Decide the next version

Given the current release (like "1.4.2") and the Conventional Commits messages since it, return the next SemVer version, or null when nothing needs releasing.

  • A breaking change bumps MAJOR: a ! before the colon (feat(api)!:), or a body line starting BREAKING CHANGE:. Otherwise a feat bumps MINOR, otherwise a fix bumps PATCH. Other types alone (docs, chore…) release nothing.
  • Bumping a number resets the ones to its right to 0. While MAJOR is 0, a breaking change bumps MINOR instead.
  • current must be exactly three numbers: throw IllegalArgumentException for anything else, including a tag name like "v1.2.3".
