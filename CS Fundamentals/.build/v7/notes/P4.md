## Design (decided)
- CLI: runner <jobs-file> --workers N [--retries R=0] [--timeout-ms T=0 none] [--queue Q=16] [--grace-ms G=3000]; launcher app/build/install/runner/bin/runner (applicationName="runner").
- Jobs file: `id=a duration=200 fail=2 deps=b,c`; # comments, blank lines. Errors -> stderr `error: ...`, exit 2, no stdout events.
- Events stdout `t=NNNN <ev> ...` (ms since start, >=4 digits, timestamp taken under the print lock -> nondecreasing):
  queued id | start id attempt=k | done id attempt=k | fail id attempt=k | timeout id attempt=k | retry id attempt=k+1 delay=ms |
  giveup id attempts=k | skip id dep=d | cancel id attempt=k | drop id | shutdown | summary total= done= giveup= skip= cancel= drop=
- backoff after failed attempt k = 50*2^(k-1). Exit 0 all done, 1 otherwise, 2 input error, 143 SIGTERM.
- Queue in topo order (Kahn FIFO, file order). Slot (Semaphore N) acquired BEFORE take; job waits deps holding slot (safe by topo order).
- Deps: all deps terminal; all DONE->run; any GIVEUP/SKIP -> skip dep=<first such>; else drop.
- Shutdown: hook -> beginShutdown under print lock (no start after shutdown line); stop producer/dispatcher; undispatched -> drop;
  running attempts get G ms then cancel; job wanting a new attempt after shutdown -> drop; summary; exit 143 (JVM default). Hook no-op if run finished.
- Checker invariants: maxconc sweep <=N; queued-left<=Q+N+1; done-start>=dur-2; retry gap>=delay-2; timeout at T..T+500; summary==event counts.
- Bugs: unbounded_concurrency, lost_update_counter (read-emit-write), retry_without_backoff, timeout_not_cancelled, hook_exits_without_drain, deadlock_file_order (Java); unbounded_queue (Kotlin).
