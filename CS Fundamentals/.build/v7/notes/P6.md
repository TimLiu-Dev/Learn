## Design decisions (2026-11-26)
- Model after M4 layout (check/Check.java, bugs/<name>/{BUG.txt,patch.diff,app/...}, tools/verify.sh).
- Java: Jackson 3.2.4 (tools.jackson); Kotlin: kotlinx.serialization 1.12.0 (same as L32). sqlite-jdbc 3.53.4.0.
- Design: connection per request, URL ?transaction_mode=IMMEDIATE (as L36), busy_timeout 10000, WAL, synchronous=FULL, foreign_keys.
  Transfer in one IMMEDIATE txn: idem lookup -> accounts -> conditional UPDATE balance-? WHERE balance>=? -> credit -> insert transfer -> insert idem row -> commit.
- Money: JSON integers minor units; 0..10^15 opening, 1..10^15 amount; reject 12.5, 1e3, "100".
- Errors {"error":code,"message":..,"field"?}: 400 bad_json, 400 missing_idempotency_key, 422 validation_failed(field), 404 not_found,
  422 unknown_account(field), 422 currency_mismatch, 409 insufficient_funds, 422 idempotency_key_reused. Only 201s stored for idem.
- GET /transfers newest first; after=opaque cursor (next), limit 1..100 default 50; next null when page not full.
- GET /audit {"totals":{"EUR":n},"transfers":n} one read txn. GET /health {"status":"ok","schemaVersion":2,"migrations":[...]}.
- Bugs: lost_update_no_tx, float_money, idempotency_key_after_commit, offset_pagination, migrations_reapplied, deferred_tx_upgrade(SQLITE_BUSY "deadlock").
