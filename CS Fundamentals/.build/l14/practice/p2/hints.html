Write memoize with a block body. Create the map before the return, then return a lambda that uses it. The map lives as long as the lambda does, just like count in makeCounter.

---

Inside the lambda, cache.getOrPut(n) { f(n) } returns the stored answer, or computes, stores and returns a new one. For multipliers: all three lambdas share one var k, and they read it when they run, after the loop has pushed it to 4.

---

Replace the while loop with for (k in 1..3), which gives each iteration a fresh, read-only k. Java won't let you capture a C-style j at all, so you copy it first: int k = j;. Java's memoize is n -> cache.computeIfAbsent(n, f).
