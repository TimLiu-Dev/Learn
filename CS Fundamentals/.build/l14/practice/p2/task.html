A cache inside a closure
  • memoize(f) returns a function with the same answers as f, but it calls f at most once per distinct input. Keep the cache inside the closure: no top-level variables.
  • multipliers() should return three functions, x * 1, x * 2 and x * 3. It compiles, but all three multiply by 4. Fix it.

The checks count calls to f with a captured var of their own.
