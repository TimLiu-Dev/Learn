A function whose declared return type is Rule can return a lambda written as Rule { … }. Inside it, it is the password, and n is captured from minLength's parameter.

String.any { … } asks "does any character match?" It wants a (Char) -> Boolean, and Char::isDigit is exactly that: an unbound reference whose receiver becomes the parameter.
