Password rules as values

A Rule is a fun interface, so a lambda can become one. Fill in the TODOs:

  • minLength(n) returns a rule that passes when the password has at least n characters.
  • hasDigit passes when any character is a digit. Use a function reference, not a lambda, inside it.
  • failures returns the names of the rules a password breaks, in the map's order. One check passes in a rule you've never seen.
