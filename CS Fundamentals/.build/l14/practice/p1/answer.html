Why it works. Rule has one abstract method, so a lambda converts to it: in Kotlin because of fun interface, in Java because of the one-method rule. minLength returns a new rule on every call, and each captures its own n. failures never knows which rules exist, so the "no spaces" rule from the checks just works.

Common mistake. Saving the limit in a top-level var limit that every rule reads. Then minLength(10) silently changes the limit of the rule minLength(3) made earlier. Capture the parameter itself, so each rule keeps its own value.
