Your own find and takeWhile

Write both as inline generic extension functions, without calling the stdlib versions (no find, firstOrNull, takeWhile or filter):

  • myFind returns the first element that matches, or null. It must stop looking as soon as it finds one.
  • myTakeWhile returns the leading elements while the predicate holds, and stops at the first that doesn't.

Keep inline: one check uses a bare return inside the lambda it passes to myFind.
