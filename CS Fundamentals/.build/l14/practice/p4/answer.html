Why it works. A return inside the loop leaves myFind at once, so the predicate never sees the rest of the list. Because the function is inline, the caller's lambda is pasted in too, so a bare return written in the caller's lambda leaves the caller, which is how describe stops at the blank word.

Common mistake. Using forEach { if (predicate(it)) { found = it; return@forEach } } to "stop" the search. return@forEach only ends the current call of the lambda, like continue, so the loop runs on and found ends up as the last match.
