Give both functions a block body and a plain for (item in this) loop. You're writing the library, so a loop inside it is fine.

---

In myFind, return item as soon as predicate(item) is true, and return null after the loop. In myTakeWhile, add items to an ArrayList and break at the first item that fails. Don't reach for forEach with return@forEach: that skips one element, it doesn't stop.

---

The check with the bare return compiles only because myFind is inline: the lambda is pasted into describe, so return leaves describe. Java can't do that. Its version returns Optional, and the wildcards Predicate<? super T> let a Predicate<Object> test strings.
