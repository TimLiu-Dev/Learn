unitsPerItem is two steps: groupBy { it.item } gives a map from item to its sales, then mapValues turns each list of sales into a sum with sumOf { it.qty }.

---

topItem works on the totals, not on the sales: take the map from unitsPerItem and use maxByOrNull { it.value }, which gives null for an empty map. partition splits a list in two, and zipWithNext { a, b -> … } (or windowed(2)) pairs each element with the next.

---

unitsPerItem(sales).maxByOrNull { it.value }?.key, sales.partition { it.qty >= min } and totals.zipWithNext { a, b -> b - a }. Java has no partition or zipWithNext: use Collectors.partitioningBy, and IntStream.range(1, size) over the indexes.
