Wrap the whole body in conn.use { … }. Whatever the lambda's last expression is becomes the value of use, and the connection is closed on the way out, whether the block returned or threw.

---

Inside use, read the line, then put only the parsing in a try. Catch NumberFormatException, not Exception: the dropped-connection check wants its IllegalStateException to pass through untouched.

---

In the catch, write throw ConfigException("bad port in ${conn.name}: '$text'", e). Passing e as the second argument is what puts the Caused by: section in the trace. In Java, the same shape is try (conn) { … } and throw new ConfigException(…, e), and readPort must declare throws ConfigException because it extends Exception.
