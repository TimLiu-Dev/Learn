Why it works. use closes the connection on every path out of the block, just like try-with-resources. The narrow catch translates only the failure this level understands, a bad number, into ConfigException. It passes the original along as the cause, so nothing is lost (Effective Java Item 73). The dropped connection isn't a config problem, so it isn't caught at all.

Common mistake. Calling conn.close() at the end of the function. It runs only when parsing succeeds, so every bad line leaks a connection. Cleanup belongs in use or finally.
