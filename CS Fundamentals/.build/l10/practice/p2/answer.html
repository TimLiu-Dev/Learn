Why it works. The exception type is part of the message. IllegalArgumentException says "you called me wrong", IllegalStateException says "not now", and SeatTakenException says "this can happen, here's who has it", carrying the data a caller needs to offer another seat (Effective Java Items 72 and 75). Checking the argument first means a bad seat is always reported as a bug, whatever state the cinema is in.

Common mistake. require(open) { … }. It reads naturally, but it throws IllegalArgumentException, blaming the caller's arguments for the cinema's state. Use check for state.
