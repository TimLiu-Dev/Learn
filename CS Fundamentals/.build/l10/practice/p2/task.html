Fail with the right exception

Finish Cinema.book(seat, name) so each failure throws the exception that tells the caller what went wrong:

  • a seat outside 1..seats is the caller's bug: IllegalArgumentException;
  • booking while the cinema is closed is the wrong state: IllegalStateException;
  • a seat someone already holds is expected and recoverable: throw SeatTakenException with the seat and the holder's name.

Check the argument first. Then write seatOrDefault with try as an expression.
