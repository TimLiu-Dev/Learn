Start with one tier. object Basic : Tier { override val loanLimit = 3; override fun lateFeeCents(daysLate: Int) = … }, then make Tier.parse a when (code) that returns it. Run the checks after each tier: small steps.

---

Each object gets the rule from its own branch of the old if chain. Don't forget the daysLate <= 0 guard: maxOf(0, …) does it in one expression. Premium is the basic fee minus 100, never below zero.

---

Now the wrappers. loanLimit(code) is Tier.parse(code)?.loanLimit ?: 0. For fees, look at the characterisation check: an unknown code like "gold" can't borrow, but the old else branch still charged it the basic rate. So it's (Tier.parse(code) ?: Basic).lateFeeCents(daysLate). In Java, use singleton classes (or an enum whose constants have bodies) and a switch expression in parse.
