Why it works. Each tier now carries both of its rules, so adding a tier means writing one object and one line in parse, instead of finding every switch on the code. Callers that have a Tier just call tier.lateFeeCents(days), and dispatch picks the rule (L8). The type check only happens once, at the edge, where text comes in.

Common mistake. Writing Tier.parse(code)?.lateFeeCents(daysLate) ?: 0. It looks consistent with loanLimit, but the old code charged unknown codes the basic rate, and the characterisation check goes red. The two switches disagreed about unknown codes. The refactoring made that visible; fixing it is a separate, deliberate change.
