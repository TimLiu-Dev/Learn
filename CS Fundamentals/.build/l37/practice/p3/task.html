Hide the hold queue

Today every caller pokes at HoldQueue.holds directly and has to remember the ritual. Build a deep Holds class instead, with four public methods and its storage private:

  • place(title, member) returns the member's 1-based place in line. Placing twice keeps your first place.
  • next(title) removes and returns the first member, or null. cancel(title, member) never throws.
  • waiting(title) returns who's waiting, in order, as a list that callers can't use to change the queue.
