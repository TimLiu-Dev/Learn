One function per mode

bookLines(books, x) works, but x switches between two different jobs: author lines sorted by author, and catalogue lines sorted by year. A named argument wouldn't help, because the modes share almost nothing. Apply Remove Flag Argument:

  • Fill in authorLines and yearLines, one per mode.
  • Turn bookLines into a one-line wrapper over them, so old callers keep working. One check pins its output in both modes; it passes now and must stay green.
