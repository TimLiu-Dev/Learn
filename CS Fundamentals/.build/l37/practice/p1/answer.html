Why it works. The flag chose between two jobs that shared nothing but a loop, so each job gets a function named for what it does. A call like yearLines(shelf) needs no explaining, unlike bookLines(shelf, false). The old function stays as a wrapper, so you can move callers over one at a time with every check green. That's Fowler's mechanics for Remove Flag Argument.

Common mistake. "Improving" the order while you're in there, for example sorting by year then title. It looks harmless, but books from the same year now come out in a different order. That's a behaviour change hiding inside a refactoring, and the stable-sort check catches it.
