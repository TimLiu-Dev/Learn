Why it works. A vararg parameter arrives as an array, so an ordinary loop handles zero, two or ten names. Because suffix comes after the vararg, a call can only set it by name. initials("alan", "turing", "") would treat "" as a third name. Defaults let clamp(150) and clamp(50, max = 40) share one function, where Java needs two overloads. (Kotlin also has a built-in value.coerceIn(min, max).)

Common mistake. names.joinToString(suffix) { … }. joinToString puts the suffix only between initials, so you get "A.L" with no final dot.
