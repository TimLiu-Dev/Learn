Initials and a clamp

The signatures are written for you. Fill in the bodies:

  • initials(vararg names, suffix = "."): the first letter of each name, uppercased, each followed by suffix. initials("Ada", "Lovelace") is "A.L.", and no names give "".
  • clamp(value, min = 0, max = 100): value, pulled back inside min..max. clamp(150) is 100.

Read the checks: they call these with defaults, named arguments and a spread array.
