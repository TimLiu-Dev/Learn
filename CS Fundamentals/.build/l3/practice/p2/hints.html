Inside the function, names is an array, so for (name in names) works. name[0] is the first character, and .uppercase() turns it into an uppercase String.

---

Start with var result = "" and add the initial plus suffix for every name. clamp is one if expression: below min, above max, or neither.

---

result += name[0].uppercase() + suffix, then return result. For clamp: if (value < min) min else if (value > max) max else value. Java has no defaults or named arguments, so the Java version needs overloads that delegate. A Java varargs parameter must come last, so the suffix version takes the suffix first.
