Why it works. Each when branch is checked top to bottom, and the first match wins. That's why the ranges can simply follow each other, and why "FizzBuzz" must come first. Both functions return their text instead of printing it, so fizzBuzzLine can reuse fizzBuzz, and the checks can test each one.

Common mistake. Testing i % 3 == 0 first. Then 15 matches the Fizz branch and never reaches FizzBuzz, so fizzBuzz(15) returns "Fizz".
