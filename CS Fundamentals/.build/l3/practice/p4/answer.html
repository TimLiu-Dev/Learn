Why it works. Checking the set and then adding means a word can only be found if an earlier copy put it there, so the first hit is the first repeat. A Set makes "have I seen this?" one quick question instead of a scan back through the list. lowStock never tries to change the read-only Map: it builds its own MutableList and returns it as a List. Sorting makes the order predictable, whatever order the map uses.

Common mistake. Adding the word before checking. Then every word is "already seen", and firstRepeat returns the first word of any non-empty list.
