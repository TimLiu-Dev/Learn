The order inside the loop matters: if (word in seen) return word comes before seen.add(word). "Fewer than" means count < threshold, not <=. In Java, seen.add(word) returns false when the word was already there, so if (!seen.add(word)) return word; does both steps at once. Sort with Collections.sort(low).
