Minutes of the day are arithmetic mod 1440, like Part 3's days of the week. Which operator gives −20 for (10 - 30) % 1440, and which function gives 1420?

---

(start + delta).mod(1440) passes everything except the huge-delta check: 1439 + Int.MAX_VALUE overflows before mod runs. Reduce delta first, then add, then reduce again. For halvings, start with require(n >= 1), then divide by 2 in a loop while the value is above 1, counting passes.
