A tautology is a formula equivalent to "always true": alwaysTrue(f) = equivalent(f) { _, _ -> true }. In Java, the lambdas need a functional interface. Formula takes two primitive booleans. BiPredicate<Boolean, Boolean> would also work, but it boxes every value.
