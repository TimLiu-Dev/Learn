A Bloom filter in one Long

TinyBloom keeps 64 bits in one Long. Each item maps to three bit positions (0 to 63), and positions is written for you.

  • add(item) sets the item's three bits.
  • mightContain(item) is true only if all three bits are set. False means "definitely absent".

One check compares bits exactly, for items whose positions go above 31.
