Part 4's flag idioms work on a Long too: set a bit with or, test it with and and compare with 0L. The bit for position i is a 1 shifted left by i.

---

In add, loop over positions(item) and do bits = bits or (1L shl i). In mightContain, every position must pass: positions(item).all { … }.

---

If the exact-bits check fails for sequence or kotlin, look at the shift: it must start from 1L. 1 shl 36 is an Int shift, so it uses only the low 5 bits of 36 and sets bit 4. In Java, bits |= 1 << i even compiles silently, because the int is widened to long after the shift.
