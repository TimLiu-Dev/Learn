How far can you trust an alert, and a timing?
  • pOutageGivenAlert(prior, hitRate, falseAlarmRate) returns P(outage | alert) by Bayes' rule. The inputs are P(outage), P(alert | outage) and P(alert | normal).
  • stdDev(timings) returns the standard deviation, dividing by n as MCS's definition does.

The checks include a rare outage, an alert that ignores the system completely, and timings that all agree.
