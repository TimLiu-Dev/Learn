Double-checked locking, by hand

Once should run init at most once, however many threads call get() at the same moment. Right now it's racy check-then-act. Turn it into double-checked locking:

  • a fast path that reads value without the lock, so callers never wait once the value exists;
  • a second check inside synchronized(lock), before running init.

Keep the field named value: one check reads its modifiers.
