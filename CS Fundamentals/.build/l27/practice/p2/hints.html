In transfer, decide which account to lock first before taking any lock. The body inside stays exactly the same: it still moves money from from to to.

---

val (first, second) = if (from.id < to.id) from to to else to to from, then first.locked { second.locked { … } }. For audit, sort with sortedBy { it.id }. You can't write a fixed number of nested locked calls for any number of accounts, so nest them with recursion.

---

A local function lockFrom(i): if i is past the end, return sorted.sumOf { it.balance }; otherwise sorted[i].locked { lockFrom(i + 1) }. In Java, the same recursion uses locked(() -> lockFrom(sorted, i + 1)).
