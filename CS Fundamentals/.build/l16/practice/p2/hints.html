The sizes are start, start * 2, start * 4, … Build a list of rows counts first, then turn neighbouring pairs into ratios.

---

List(rows) { i -> count(start shl i).toDouble() } gives the counts (shl i multiplies by 2i). zipWithNext { a, b -> b / a } gives the ratios. Convert to Double before dividing, or 7 / 2 becomes 3.

---

For the exponent, use log2(ratio).roundToInt(). toInt() truncates, so a noisy 3.9 (log₂ ≈ 1.96) would come out as 1. In Java, there's no log2: use Math.log(ratio) / Math.log(2) and Math.round.
