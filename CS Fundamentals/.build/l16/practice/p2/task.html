A doubling experiment without a stopwatch

Times are noisy, and this code runs on a shared server. Steps aren't: count them, and double n exactly as Bench did. Fill in the two TODOs:

  • doublingRatios(count, start, rows) calls count at n = start, 2·start, 4·start, … (rows sizes) and returns each count divided by the one before: rows - 1 ratios.
  • exponent(ratio) returns the whole number b with 2b closest to ratio.

The checks then use your tools on step counts of their own, including the hidden loop in uniqueSlow.
