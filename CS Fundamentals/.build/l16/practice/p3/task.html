Shrink without thrashing

ResizingStack already grows: push doubles the array when it's full, and resize counts every element it copies. Write pop:

  • Return the top element and null out its slot. On an empty stack, throw NoSuchElementException.
  • When the stack drops to a quarter of its capacity (and isn't empty), halve the array, so a stack that once held a million elements doesn't keep a million slots forever.

One check pushes and pops 1,000 times right at a resize boundary, and counts the copies.
