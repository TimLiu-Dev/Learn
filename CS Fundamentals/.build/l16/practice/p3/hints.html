Popping is the reverse of push: decrement size, then read data[size]. It's stored as Any?, so cast it with as T, as GrowList.get did.

---

After reading the element, write null into its slot. Then: if size > 0 && size == data.size / 4, call resize(data.size / 2). Throw NoSuchElementException first if size == 0.

---

Why a quarter, not a half? Right after the halving, the array is half full, so it can take many pushes before it grows again. Shrink at half full and one push/pop pair at the boundary copies everything twice. In Java, the array is an Object[] and the cast is (T) data[size] with @SuppressWarnings("unchecked").
