Walk the list once. When you reach x, the partner it needs is target - x. Has that partner already gone by?

---

Keep a HashSet<Int> of the elements you've passed. For each x: if target - x is in the set, return true; otherwise add x and move on. A set lookup is O(1) on average, so the loop is O(n).

---

Order matters: check before you add. If you put every element in the set first, [5] with target 10 finds its own 5 and wrongly returns true. In Java, use Set<Integer> seen = new HashSet<>() and seen.contains(target - x).
