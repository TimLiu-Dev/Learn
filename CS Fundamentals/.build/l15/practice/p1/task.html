firstFound looks up ids with a slow lookup and keeps the first n that return a name. It's correct, but it's eager: it looks up every id. Make it stop calling lookup as soon as it has n names.

Then write collatz(start): a lazy sequence that halves even numbers, sends odd n to 3n + 1, and ends with 1. For example, collatz(6) gives 6, 3, 10, 5, 16, 8, 4, 2, 1.
