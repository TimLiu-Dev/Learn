Your own apply-style builder

Finish a tiny DSL so this reads naturally: request { method = "POST"; url = "/books"; header("Accept", "json") }.

  • header stores a header. Setting the same name again replaces its value; headers keep the order they were first added.
  • build() rejects a blank url with IllegalArgumentException (L10), and the built Request must not change if the builder is used again (L5).
  • request runs the block with a fresh builder as its receiver, then builds.
