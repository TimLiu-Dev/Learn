Why it works. block has the type RequestBuilder.() -> Unit, so inside the braces the builder is the implicit this, and url = … and header(…) need no prefix. apply returns the builder rather than the block's Unit, so build() chains straight on. That's the same pattern as buildString and Gradle's dependencies { }.

Common mistake. Request(method, url, headers) without a copy. Every check about one request passes, but the request shares the builder's map, so a later header("B", …) silently changes a request that was already built.
