fun request(block: RequestBuilder.() -> Unit) = RequestBuilder().apply(block).build(). In Java, the block is a Consumer<RequestBuilder>, so every call inside needs the prefix: b -> { b.url = "/a"; b.header("A", "1"); }. Map.copyOf doesn't keep order, so copy into a new LinkedHashMap and wrap it with Collections.unmodifiableMap.
