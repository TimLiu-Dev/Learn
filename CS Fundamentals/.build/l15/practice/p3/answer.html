Why it works. For each by Tracked(…), the compiler stores a hidden title$delegate field and turns every d.title = x into setValue(d, ::title, x). So the delegate gets the owner (thisRef) to mark, and the property's name to record. The logic is written once and works for String and Int alike.

Common mistake. Storing first and comparing second: this.value = value, then if (value != this.value). The two are now always equal, so nothing is ever marked dirty.
