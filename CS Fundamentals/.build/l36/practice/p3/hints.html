Two different kinds of user input arrive here. The values can be bound with ?. The keys are identifiers, which can't, so the only safe way for a key to reach the SQL is if it equals one of your strings.

---

Start with require(changes.isNotEmpty()) and a require(column in setOf("name", "email")) for each key, which throws IllegalArgumentException (L10). Then build "$it = ?" for each key, joined with ", ".

---

Query("UPDATE members SET $sets WHERE id = ?", changes.values + id): a Kotlin map keeps insertion order, so keys and values line up. In Java, collect the values into a new ArrayList and add(id) last; use LinkedHashMap wherever the order matters.
