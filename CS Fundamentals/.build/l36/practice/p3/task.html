A safe PATCH, built by hand

A PATCH /members/7 request sends only the fields to change, as a map from column name to new value. updateMember turns it into SQL text plus a parameter list for a PreparedStatement. Right now it glues everything into the text, so a name like x' OR '1'='1 becomes SQL code instead of a name.

  • Every value becomes a ? in the text and an entry in params, in the same order, with the id last. null is a value too.
  • The keys are column names, which can't be bound (Part 3's ORDER BY ?). Allow only name and email. Reject anything else, and an empty map, with IllegalArgumentException.
