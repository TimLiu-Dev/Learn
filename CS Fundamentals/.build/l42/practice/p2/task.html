A hash ring with CRC32

Build Part 2's consistent-hashing ring yourself. position(s) is given: CRC32, so every run gives the same numbers.

  • add(node) puts the node at vnodes positions: position("n1#0"), position("n1#1"), …; remove takes them all off again.
  • nodeFor(key) returns the node at the first position at or after the key's position, wrapping round to the start of the ring.

The tests count how many of 10,000 keys move when a node joins or leaves, and compare with mod N.
