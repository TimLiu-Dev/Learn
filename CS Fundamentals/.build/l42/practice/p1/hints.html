Start with val up = backends.filter { it.healthy } and return null if it's empty. Every strategy then chooses from up.

---

Round-robin is up[next++ % up.size]; Math.floorMod keeps it safe if the counter ever overflows. Least-connections is up.minBy { it.active }, which returns the first of several equal minimums.

---

Choose into a val b = when (strategy) { … }, then b.active++, b.served++, return b. In Java, the least-connections line is up.stream().min(Comparator.comparingInt(b -> b.active)).orElseThrow(); Kotlin's minBy documents that it returns the first smallest; OpenJDK's Stream.min does the same on a sequential stream.
