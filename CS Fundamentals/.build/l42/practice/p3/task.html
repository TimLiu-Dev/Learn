Exactly-once effect from at-least-once delivery

The queue may deliver the same message more than once. Finish EmailWorker.handle so each job's email goes out once:

  • A message whose id has already been sent is skipped, and counted in skipped.
  • If sendEmail throws, let the exception escape: the queue then doesn't ack, and delivers the message again. That retry must send it.
  • Two different ids with the same text are two different jobs.
