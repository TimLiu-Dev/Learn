Predict the JVM's default heap

Write defaultMaxHeap(limit, xmx, maxRamPercentage), which returns the maximum heap in bytes that JDK 26 picks for a given memory limit. The rules, from HotSpot's source and checked against real runs on this Mac:

  • If xmx is given, it wins.
  • Otherwise compute small = 50% of the limit and big = maxRamPercentage% of it. If small is below SMALL_HEAP (about 125 MB), the heap is small. If not, it's the larger of big and SMALL_HEAP.
  • Either way, round the result up to a multiple of ALIGN (8 MB), as this JVM did.

Every expected value in the checks is a number the real JVM printed.
