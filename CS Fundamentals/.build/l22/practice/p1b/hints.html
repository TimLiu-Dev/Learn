Start with roundUp: integer division already rounds down, so add step - 1 first. Then do the rules in order: xmx, then the two percentages.

---

Compute both small = (limit * 50.0 / 100).toLong() and big the same way with maxRamPercentage. Use 50.0, not 50, so a fractional percentage like 37.5 still works.

val heap = if (small < SMALL_HEAP) small else maxOf(big, SMALL_HEAP), then return roundUp(heap, ALIGN). Don't forget to round xmx too: -Xmx300m became 304 MB. In Java, Long xmx can be null, and Math.max replaces maxOf.
