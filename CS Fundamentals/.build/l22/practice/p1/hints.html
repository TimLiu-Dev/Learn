16384 is 214, so the low 14 bits of an address are the offset and everything above them is the page number. Dividing by PAGE_SIZE and taking % would work too, but the hardware just splits the bits.

---

va ushr PAGE_BITS drops the 14 offset bits. va and (PAGE_SIZE - 1) keeps only them, because PAGE_SIZE - 1 is fourteen 1-bits.

---

In translate, look up pageTable[pageNumber(va)], return null with ?: return null, then build frame * PAGE_SIZE + offset(va). In Java the operators are >>> and &, and Map.get returns null for a missing key.
