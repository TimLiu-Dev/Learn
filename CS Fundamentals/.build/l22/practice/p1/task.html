Translate a virtual address

Be the hardware for a moment. A page here is 16 KB (214 bytes), as on this Mac. A virtual address splits into a page number and an offset inside that page:

  • pageNumber(va) and offset(va): use a shift and a mask, since the page size is a power of two (L48).
  • translate(va, pageTable): look up the page's physical frame and keep the offset. Return null if the page isn't mapped (a page fault).

One check gives two processes the same virtual address and expects two different physical ones.
