Build the buffer yourself

The Playground has no files, so CountingStream plays the kernel: it serves bytes from memory and counts every call made to it, as if each one were a system call. Write MyBufferedStream.read(), a tiny BufferedInputStream:

  • When the buffer is used up, refill it with one src.read(buf, 0, buf.size) call, then hand out bytes from the array.
  • Return each byte as 0..255, and -1 only at the end of the data.

One check uses a source that returns at most 5 bytes per call, as real files and sockets may.
