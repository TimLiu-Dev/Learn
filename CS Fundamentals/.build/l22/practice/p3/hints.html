pos == count means every byte in the buffer has been handed out (that's also true at the very start, when both are 0). Only then do you call src, once.

---

src.read(buf, 0, buf.size) returns how many bytes it actually put in buf, or -1 at the end. Store that number in count and reset pos to 0. Don't assume it filled the buffer.

---

Return buf[pos++].toInt() and 0xFF. Without and 0xFF, the byte 0xFF becomes -1 and looks like the end of the stream. In Java it's buf[pos++] & 0xFF, which already works on an int.
