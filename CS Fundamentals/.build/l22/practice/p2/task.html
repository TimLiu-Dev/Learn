Count the misses

Rebuild the toy cache from the stepper above, then let it count. A grid of n × n ints is stored flat, so cell (r, c) is at index r * n + c.

  • columnMajor(n): the indices in column-major order. rowMajor is done for you.
  • misses(indices, intsPerLine, lines): replay the accesses through an LRU cache that holds lines cache lines, and return how many were misses.

The checks expect the stepper's numbers: 16 misses row-major, 64 column-major.
