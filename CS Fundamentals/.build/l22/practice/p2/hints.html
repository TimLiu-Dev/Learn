columnMajor is rowMajor with the two loops swapped: the outer loop picks the column, the inner one walks down the rows. The index is still r * n + c.

Index i lives on line i / intsPerLine. Keep the cached lines in a LinkedHashMap created with accessOrder = true (L19's LRU): then the first key is always the least recently used one.

---

For each access: if cache[line] is null, count a miss, evict cache.keys.first() when the cache is full, and insert the line. A hit needs no code, because get already moved the line to the end. In Java, use new LinkedHashMap<>(16, 0.75f, true), and containsKey doesn't refresh the order, so call get.
