A booking that can't be invalid

A meeting-room Booking uses named arguments and defaults instead of a Builder. Fill in the TODOs so that no invalid booking can exist, however it's made:

  • Rules: the room isn't blank, 8 <= start < end <= 18, and at least one person attends. Break one and you get an IllegalArgumentException.
  • Two named factories: allDay(room) books 8 to 18, and parse("Ada 9-11 x4") reads a room, hours and an optional head count (x4).

The checks also build bookings with the constructor and with copy.
