Stack your own log decorators

A Log stores lines. Write three decorators, each with by inner so it overrides only write:

  • Numbered puts "1: ", "2: "… in front of each line that reaches it.
  • Shortened(inner, max) cuts each line to at most max characters.
  • SkipBlank drops lines that are empty or only spaces.

The checks stack them in different orders, and add a decorator of their own.
