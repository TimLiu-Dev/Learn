Why it works. Every decorator is a Log and holds a Log, so any of them can wrap any other, including the checks' Shouting. A line travels from the outermost wrapper inwards, and each layer changes it before passing it on. That's why order matters: a filter inside the numbering never sees a blank line, and a cut outside the numbering keeps the text while a cut inside it keeps only "1: ".

Common mistake. Writing write("$count: $line") instead of inner.write(…). Inside the class, a plain write is this decorator's own method, so it calls itself until a StackOverflowError. by inner forwards only the methods you don't override.
