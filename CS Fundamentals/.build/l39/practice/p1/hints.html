onChange is one comparison. In update, build the Change from the old and new price before you overwrite price, and remember the price even when the rule says "stay quiet".

---

listeners -= listener removes the first element that equals listener. Two equal Recorders, or one listener added twice, defeat it. You need something that belongs to exactly one subscription.

---

Wrap each listener in a fresh object, e.g. a private class Subscription(val listener: (Change) -> Unit), and store those. A plain class compares by identity, so the handle's subs -= sub removes only its own wrapper, and a second close removes nothing. Java's List.remove(Object) uses equals too, so the same wrapper works there.
