Each subscribe creates its own Subscription object, and the handle remembers that object. Because a plain class uses identity for equals, closing a handle can only remove its own entry, however equal the listeners inside are.

Common mistake. Removing the listener itself, as Events.kt does. remove uses equals, so it takes the first equal listener, which may be someone else's. Switching to removeIf { it === listener } fixes that but removes every subscription of the same listener at once.
