cut is one map: check delim in line first, then split(delim). Field 2 is index 1, and getOrElse covers a field that isn't there.

---

uniqC keeps a list of runs. For each line, look at the last run: if its line is the same, replace it with count + 1; otherwise append 1 to line. Never look further back than the last run.

---

topN is uniqC(lines.sorted()).sortedByDescending { it.first }.take(n). Sorting first is what makes equal lines adjacent. In Java, a record Count(int n, String line) stands in for Pair, List.sort is stable too, and split(regex, -1) keeps trailing empty fields, which Java drops by default.
