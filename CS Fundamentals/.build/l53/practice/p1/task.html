The top-N pipeline as functions

Rebuild cut -d, -f2, uniq -c and the whole sort | uniq -c | sort -rn | head -n N as three Kotlin functions over lines:

  • cut keeps field field (counting from 1). Like the real cut, a line with no delimiter passes through whole, and a missing field gives an empty string.
  • uniqC merges only adjacent equal lines into count to line pairs, exactly like uniq -c.
  • topN composes them: sort, uniqC, highest count first, keep n. Equal counts stay alphabetical, which is sort -k1,1nr -k2 (plain sort -rn puts ties in reverse order).

Then run the real thing in your terminal: printf '/b\n/a\n/b\n' | sort | uniq -c | sort -rn | head -2.
