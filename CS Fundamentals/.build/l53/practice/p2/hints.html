For each line, decide first whether to skip it: isBlank(), startsWith("#"), or no '=' in it. Put the rest in a map; assigning a key twice keeps the later value for free.

---

Split at the first = only: substringBefore('=') is the key and substringAfter('=') the value. A plain split("=") chops -Dmode=fast in half.

---

which: env["PATH"] ?: return null, then split(':'), build "$dir/$cmd", and firstOrNull { it in files }. In Java, line.split("=", 2) does the first-= split, and a loop that returns early replaces firstOrNull.
