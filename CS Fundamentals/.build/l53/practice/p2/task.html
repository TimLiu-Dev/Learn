Read an env file, then search PATH

Two jobs the shell does for you before a program even starts:

  • parseEnv reads KEY=value lines, the format of env's output and of .env files. Skip blank lines, # comments and lines without =. Split at the first = only, and let a later line win.
  • which does what which java does: try each directory of the env's PATH (split on :) in order, and return the first dir/cmd that exists, or null. The set files stands in for the file system.

Compare with the real thing in your terminal: env | grep '^PATH=' and which -a java.
