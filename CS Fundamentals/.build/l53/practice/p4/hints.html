Split the line on " ", then turn each token into a list of words, because one token can become zero, one or several words. flatMap joins those lists. Test the forms most specific first: "$@" before "$NAME".

---

Write two small helpers: valueOf(name), which looks the name up and throws IllegalStateException("$name: unbound variable") if it's missing, and splitWords(s), which splits on Regex("\\s+") and drops empty pieces. Only the unquoted forms call splitWords.

---

A quoted token is token.startsWith("\"\$") && token.endsWith("\""); its name is token.drop(2).dropLast(1), and its result is listOf(valueOf(name)), never split. In Java, collect into an ArrayList with addAll, and remember "".split("\\s+") returns one empty string, so filter it out.
