Expand a command line the way bash does

expand returns the arguments a program receives after bash expands one line. Tokens are separated by single spaces, and each token is one of:

  • "$@": every script argument as its own word. $@ or $* without quotes: the arguments joined with spaces, then split again.
  • "$NAME": exactly one word, even when the value is empty. $NAME: the value split on whitespace, and an empty value gives no word at all.
  • Anything else is a literal word. Like set -u, an unset NAME throws IllegalStateException("NAME: unbound variable").

Then try it for real: bash -c 'f="my notes.txt"; printf "[%s]\n" $f "$f"'.
