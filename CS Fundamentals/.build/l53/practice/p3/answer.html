Why it works. grep searches for the pattern anywhere in each line, and its exit status answers one yes-or-no question: was any line selected? So grep -q … && echo found works, and a grep -c that finds nothing fails a set -e script. The 128 + N rule is how bash, and the JVM's own signal handler, report a death by signal.

Common mistake. pattern.matches(line). It needs the whole line to match, so " 500 " finds nothing, and the count drops to 0 with status 1.
