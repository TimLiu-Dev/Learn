Exit statuses, the shell's way

Model the number $? shows:

  • grepC is grep -c: count the lines in which the pattern matches anywhere, and exit 0 if there was at least one, else 1. (It still prints 0 when nothing matched.)
  • status turns how a process ended into $?: its own exit code, or 128 + the signal's number. Use the SIGNALS table.

Then check both in your terminal: printf 'a\nb\n' | grep -c zzz; echo $?, and Part 3's kill runs.
