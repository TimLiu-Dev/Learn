Why it works. Binding the path against every route first is what separates the three answers: no template fits (404), templates fit but not for this method (405 with Allow), or one fits both. distinct() matters because two templates can fit the same path for the same method, and Allow should name each method once.

Common mistake. Filtering routes by method before binding. It's shorter and the happy paths pass, but PATCH /books/7 then finds nothing and becomes a 404, so the client never learns which methods would work.
