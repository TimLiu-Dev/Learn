Three ways a route can answer

Write Shelf's matching logic for a list of routes. Each Route has a method, a template such as /books/{id} and a name.

  • bind(template, path) returns the path parameters, such as {id=7}, or null when the shapes differ. Empty segments don't count, so /books/ is /books.
  • match returns Found (the first route that fits both path and method), WrongMethod (the path fits, but only for other methods: list them sorted, without repeats) or NoRoute.
