Instant.epochSecond gives the Unix seconds. require(condition) { message } throws IllegalArgumentException for you; isBefore compares two instants.

---

For the date, build one DateTimeFormatter with ofPattern, Locale.ENGLISH (so a German laptop doesn't print Sa.), and withZone(ZoneOffset.UTC), so it can format an Instant directly.

---

The pattern is "EEE, dd MMM yyyy HH:mm:ss 'GMT'". Don't reach for DateTimeFormatter.RFC_1123_DATE_TIME: it prints the 5th as 5, and RFC 9110 says day = 2DIGIT. In Java, the same formatter works, and if (...) throw new IllegalArgumentException(...) replaces require.
