From result to response

Write the POST /loans handler's logic: validate the body, call lend, and turn every result into a response.

  • problem(status, detail, errors) builds RFC 9457 Problem Details: type about:blank, the status phrase as title (400 Bad Request, 404 Not Found, 409 Conflict), media type application/problem+json.
  • A missing id is a 400 listing every problem ("bookId is required", "memberId is required") with detail "N problem(s) with the request", and lend is never called.
  • Lent is a 201 with Location: /loans/ID. The details for the others: "No book with id 1", "No member with id 2", "Book 1 is already on loan", "Member 2 already has 3 open loans".
  • Null fields must be left out of every body, so configure json too.
