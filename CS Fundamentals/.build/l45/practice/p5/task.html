Write the property

Write checkPaging, a hand-made property-based test for any page function shaped like BookStore.list. The hidden tests give it one correct pager and several buggy ones; it must accept the first and reject every other.

  • Make runs random cases from Random(seed): a list of 0–30 numbers and a limit of 1–10.
  • The property: reading page after page from offset 0, stepping by limit, until a page comes back empty, gives back exactly the list, in order, and no page is longer than limit.
  • Return null if every case passes, or a short description of the first failing case. A pager that throws has failed too.
