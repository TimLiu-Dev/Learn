Why it works. The property says what every correct pager must do for any list and limit, without naming expected outputs, so 300 generated cases reach the inputs that example tests forget: the empty list, a last page that's only partly full, a list exactly one page long. A seeded Random makes each run repeatable, and the message names the failing input, so you can turn it into an ordinary example test. This is what jqwik and kotest-property automate, plus shrinking: cutting the failing list down to the smallest one that still fails.

Common mistake. Checking only the first page. It accepts the correct pager, and also every bug that only shows up on a later page: the lost last page and the crash past the end of the list.
