A TreeMap<Long, Loan> keeps loans sorted by id, so loans.values is already "oldest first". Every query is a filter, firstOrNull or any over those values.

---

close must not touch a loan that's already returned: look it up, keep it only if isOpen, and store loan.copy(returned = returned). A data class is immutable, so you replace it in the map.

---

The constraint goes first in add: check(openForBook(bookId) == null) { "book $bookId already has an open loan" }. Kotlin's check throws IllegalStateException. In Java, if (openForBook(bookId).isPresent()) throw new IllegalStateException(…), and the queries return Optional.
