A fake that keeps the database's promises

Write MemoryLoanStore, the in-memory fake behind the unit tests. The hidden tests are its contract: the same checks the SQLite store passes.

  • Ids start at 1. forMember lists a member's loans oldest first; anyForBook counts returned loans too.
  • close returns false for a missing loan or one that's already closed.
  • SQLite's partial unique index refuses a second open loan for a book (L36). The fake must refuse it too: throw IllegalStateException.
