One decision, four answers

A notes API sends every request through decide, which returns the HTTP status: 200 to go ahead, 401, 403 or 404. Apply the rules in this order:

  • No such note: 404. Reading a public note (isPublic): 200 for anyone, logged in or not.
  • Anything else without a user: 401.
  • The owner may READ, EDIT and DELETE. An admin may READ and DELETE any note (moderation), but not EDIT.
  • Everything else is 403, including SHARE, which has no rule yet.
