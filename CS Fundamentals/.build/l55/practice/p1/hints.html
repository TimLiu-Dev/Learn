Start with tokensMatch: return false for null, then hand both strings' bytes (toByteArray()) to MessageDigest.isEqual. In csrfAllowed, a safe method returns true straight away.

---

Write the safe methods as a set and test req.method in SAFE_METHODS. Don't list the unsafe ones instead: PATCH, or a method nobody has invented yet, would slip past a list of POST, PUT and DELETE. For Origin, use ==, never startsWith or contains.

---

The last line is return req.origin == OUR_ORIGIN && tokensMatch(sessionToken, req.csrfHeader). A missing Origin is null and the string "null" is just text, so == rejects both. In Java, write OUR_ORIGIN.equals(req.origin()) (constant first, so a null origin can't throw) and getBytes(StandardCharsets.UTF_8).
