Build the CSRF gate

Every request passes this gate before its handler runs. Write two functions:

  • tokensMatch(expected, presented): true only when the presented token equals the session's, compared in constant time (L33). null never matches.
  • csrfAllowed(req, sessionToken): treat only GET, HEAD and OPTIONS as safe, and let them through. Any other method, including ones you've never heard of, needs Origin exactly equal to OUR_ORIGIN and a matching X-CSRF-Token.

The checks only test which requests get through. Nobody times anything.
