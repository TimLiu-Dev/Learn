challengeOf is two calls: MessageDigest.getInstance("SHA-256").digest(...) on verifier.toByteArray(Charsets.US_ASCII), then Base64.getUrlEncoder().withoutPadding().encodeToString(...). The plain getEncoder() would give +, / and =, and the RFC check would fail.

---

Start redeem with val g = grants.remove(code) ?: return false. remove returns the grant and deletes it, so an unknown code, a used code and the second of two attempts all end up at return false.

---

Then one expression joined by &&: now() - g.issued <= 60, g.clientId == clientId, g.redirectUri == redirectUri and challengeOf(verifier) == g.challenge. In Java, MessageDigest.getInstance throws a checked NoSuchAlgorithmException; every JVM must support SHA-256, so wrap it in an AssertionError.
