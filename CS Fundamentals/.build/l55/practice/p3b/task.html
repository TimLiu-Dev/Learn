Verify a passkey login

You're the server. A login sends you an Assertion: the browser's clientDataJSON bytes, the authenticator's 37 authenticatorData bytes, and an Ed25519 signature over authenticatorData ‖ SHA-256(clientDataJSON). Write problem: null to accept, else the first failing check's reason, in this order:

  • type must be "webauthn.get" ("wrong type"), challenge the one you issued ("wrong challenge"), and origin exactly ORIGIN ("wrong origin"). Read them with the given field.
  • The first 32 bytes of authenticatorData must be SHA-256(RP_ID) ("wrong RP ID"), and byte 32's lowest bit, user present, must be set ("user not present").
  • Last, the signature must verify with the stored public key ("bad signature").
