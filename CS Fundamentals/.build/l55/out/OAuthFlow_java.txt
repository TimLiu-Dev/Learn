== the checks ==
1 the same code again              -> 400 {"error":"invalid_grant","error_description":"code already used"}
2 a copied code, no verifier       -> 400 {"error":"invalid_grant","error_description":"PKCE verifier does not match"}
3 an unregistered redirect_uri     -> 400 unregistered client or redirect_uri
4 a callback the app didn't start  -> 400 unknown state: I never started this login
5 an ID token sent to the API      -> 401 WWW-Authenticate: Bearer error="invalid_token", error_description="wrong audience"
