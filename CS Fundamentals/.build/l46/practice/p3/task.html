Config in layers, with no secrets in the log

Shelf's Config knows two layers: the environment and the defaults. Real services often add a file in between, and they print their settings at startup. Write loadSettings and Settings.toString:

  • For each key, the environment beats the file, and the file beats the defaults.
  • If required keys are missing, fail at startup with one message that names all of them.
  • toString masks every secret as ***, so the startup log never leaks a password (L33).
