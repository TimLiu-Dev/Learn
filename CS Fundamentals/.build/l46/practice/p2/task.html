Build the filter chain yourself

HttpServer runs Shelf's filters for you. Here you write that machinery, in miniature:

  • chain(filters, handler) returns one Handler in which filters[0] runs first and the handler runs last.
  • RateLimit answers 429 with Retry-After: 1 itself, and never calls next, when allow(client) is false.

The last two checks build the same chain in both orders, so you can see which order the access log needs.
