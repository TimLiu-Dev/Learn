404 or 405? A tiny router

The final's server picks a handler from the method and the path. Build that part on its own. Routes are patterns like /books/{id}, where {id} matches exactly one non-empty path segment.

  • Write match(pattern, path): the captured parameters ({"id": "42"}), or null if the path doesn't fit. Segments must line up one to one.
  • Finish handle: no route fits the path → 404. Some route fits the path but none has this method → 405, with allow listing that path's methods in the order they were added, like "GET, POST".
