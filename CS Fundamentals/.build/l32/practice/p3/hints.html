Start with match. "/books/42".split("/") is ["", "books", "42"]. Split the pattern the same way, and the two lists must have the same size before you compare them segment by segment.

---

For each pair (w, g) from want.zip(got): if w looks like {name}, store params[name] = g (but an empty g is no match); otherwise w must equal g, or return null. removeSurrounding("{", "}") strips the braces.

---

In handle, first collect every route whose pattern fits the path, whatever its method. None → 404. Then look among them for the method: found → call its handler; not found → 405 with allow = fits.map { it.method }.distinct().joinToString(", "). In Java, fits.stream().map(Route::method).distinct().collect(Collectors.joining(", ")) builds the same list.
