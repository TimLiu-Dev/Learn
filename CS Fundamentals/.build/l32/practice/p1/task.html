Write the JSON yourself

Libraries do this for you, but writing it once shows you exactly what a JSON string has to escape. Finish two functions:

  • quote(s) returns s as a JSON string literal, quotes included. Escape " and \, use \n, \r, \t, \b, \f for those control characters, and \u00XX (lower-case hex) for any other character below U+0020.
  • encode(v) turns null, booleans, numbers, strings, lists and string-keyed maps into compact JSON, the way Json.encodeToString prints it.

One check compares your quote with kotlinx.serialization on a nasty string.
