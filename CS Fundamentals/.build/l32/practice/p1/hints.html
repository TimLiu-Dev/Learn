Build the result one character at a time: buildString { }, a for (c in s) loop and a when (c). Most characters are appended unchanged; only ", \ and the characters below U+0020 need an escape.

---

The branches: '"' -> append("\\\""), '\\' -> append("\\\\"), then \n, \r, \t, \b and '\u000C' (form feed: Kotlin has no '\f'). For the rest of the control range, in '\u0000'..'\u001F' -> append("\\u%04x".format(c.code)).

---

encode is recursive (L18): a list is v.joinToString(",", "[", "]") { encode(it) }, and a map is the same over v.entries, each entry as quote(key) + ":" + encode(value). Keys are strings, so they need quote too. In Java, switch on the char and use Collectors.joining(",", "[", "]").
