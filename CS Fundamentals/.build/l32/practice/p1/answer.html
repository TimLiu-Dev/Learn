Why it works. One pass over the characters decides each one exactly once, so an escape you've just written can never be escaped again. Only ", \ and U+0000–U+001F must be escaped (RFC 8259 §7). Everything else, including é and ✓, may go through as is, which is what kotlinx.serialization does. encode recurses into lists and maps, so any nesting depth works, and keys go through quote like any other string.

Common mistake. A chain of replace calls with the quote first: .replace("\"", "\\\"").replace("\\", "\\\\"). The second call doubles the backslash the first one added, so "hi" comes out as \\"hi\\", which ends the string early. Replacing \ first works, but the single pass can't get the order wrong.
