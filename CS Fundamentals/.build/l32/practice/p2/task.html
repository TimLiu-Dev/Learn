Make the retry harmless

Orders is a tiny server. A plain post creates a new order every time, so a retried POST charges twice. Make post honour an Idempotency-Key:

  • No key (null): create, as now.
  • A new key: create, and remember the key with the item and the response.
  • The same key with the same item: create nothing, and return the original response.
  • The same key with a different item is a client bug: create nothing, and answer 422.
