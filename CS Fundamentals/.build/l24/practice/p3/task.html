Allocation-free totals

An allocation profile of a shop's checkout says most of its garbage is Money objects, all made in total, which runs for every basket. Rewrite total so that one call allocates exactly one Money: the result.

  • Don't change Money. Its factory counts every object made, so the checks can count exactly instead of sampling.
  • The answer must stay the same, as the profiling checklist says: one check compares against the original loop.
