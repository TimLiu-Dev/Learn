"Shortest" means BFS, as in L21. Put every root in the queue at the start, at distance 0, then search outwards from all of them at once.

---

Keep a parent map: when you first reach an object, record which object you came from (null for a root). The map doubles as your visited set, which is what stops the cycles. After the search, if target isn't in the map, return null.

---

Walk back from target through parent until you hit null, then reverse: generateSequence(target) { parent[it] }.toList().reversed(). Check membership with in (Java: containsKey), not parent[x] != null, because roots map to null.
