Who is holding it? A leak trace

A heap dump tool answers one question about a leaked object: which chain of references, starting at a GC root, keeps it alive? Fill in leakPath(target, roots, heap). The heap is a map, as in Part 1's practice.

  • Return a shortest chain, from a root's object to target, both ends included. Short chains are the easiest to read.
  • Return null if nothing reaches target: then it isn't leaked, it's garbage.
