Be the collector: mark, then sweep

The heap is a map from each object's name to the names it refers to. Every object is a key, even one that refers to nothing. roots lists the objects the GC roots point at directly. Fill in the TODOs:

  • mark(roots, heap) returns every object reachable from the roots.
  • sweep(roots, heap) returns everything else: the garbage.

One check builds a chain of 100,000 objects, so don't recurse: keep your own stack, as real collectors do.
