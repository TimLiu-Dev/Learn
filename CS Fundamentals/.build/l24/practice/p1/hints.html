This is graph search from L21, started from several places at once. Keep a marked set and a stack of objects you've reached but not yet looked inside. Put every root on the stack to begin.

---

Loop while the stack isn't empty: take one object off. If it's already marked, skip it; otherwise mark it and push everything it refers to. Use an ArrayDeque rather than a recursive function: 100,000 nested calls overflow the thread's stack.

---

if (marked.add(obj)) stack.addAll(heap.getValue(obj)) is the whole loop body, because add returns false when the object was already there. sweep is then one line: heap.keys - mark(roots, heap). In Java, copy the key set into a HashSet and call removeAll.
