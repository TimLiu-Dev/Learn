Why it works. An object is marked only when it's popped from a stack that started with the roots, so marked means reachable. Every reference out of a marked object is pushed, so nothing reachable is missed. The marked set is what ends a cycle: Node A and Node B are never pushed, because no root leads to them, and they're swept even though each one refers to the other.

Common mistake. A recursive visit. It gives the right answer on small heaps, but the 100,000-object chain needs 100,000 nested calls and throws StackOverflowError. Forgetting the marked check is worse: the first cycle loops forever.
