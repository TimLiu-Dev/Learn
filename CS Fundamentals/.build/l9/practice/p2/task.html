Guard the Java boundary

java.util.Properties and java.io.File are plain JDK classes with no nullability annotations, so their results reach Kotlin as platform types. Finish three functions:

  • port(config): the "port" setting as an Int, or 8080 if it's missing or not a number. The starter crashes on a missing port, so read its message first.
  • folderOf(path): the file's parent folder, or "." if the path has none.
  • describe(path): "NAME (absolute)" or "NAME (relative)".

Use property syntax for File's getters getName(), getParent() and isAbsolute().
