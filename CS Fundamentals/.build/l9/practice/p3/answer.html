Why it works. Each annotation changes only what the compiled class shows Java: a field instead of a getter, an extra add(String) overload, a throws clause, and a static method on Library. The two Kotlin checks passed before and after, because Kotlin callers never needed any of it.

Common mistake. Writing @Throws(Exception::class) "to be safe". Every Java caller must then catch or declare Exception, the broadest checked type. Declare exactly what the function can throw.
