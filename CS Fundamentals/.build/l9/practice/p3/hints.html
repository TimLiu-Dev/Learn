Each failing check names one thing Java can't write yet. Match each one to a row of Part 3's table: a public field, a shorter overload, a throws clause, and a static method on an object.

---

You need four annotations: @JvmField on the name property, @JvmOverloads on add, @Throws(…) on load, and @JvmStatic on Library.register.

---

class Playlist(@JvmField val name: String), @JvmOverloads fun add(…), @Throws(IOException::class) fun load(…) and @JvmStatic fun register(…). In Java, you write by hand what those annotations generate: a public final field, an add(String) that calls add(title, 1), a throws IOException clause, and static methods instead of an INSTANCE.
