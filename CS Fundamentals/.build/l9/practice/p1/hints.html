Inside labels, it has the static type Item. Extensions are chosen at compile time from that static type, so Item.label() runs for every element, books included.

---

Only members get dynamic dispatch. Move label into Item as an open member, give Book an override, and delete both extensions. For bookCount, count the elements that pass an is Book check.

---

open fun label() = "item: $name" in Item, override fun label() = "book: $name by $author" in Book, and get() = count { it is Book }. Java's static label(Item) / label(Book) overloads fail the same way. Turn them into instance methods with @Override, and labels maps Item::label.
