Why it works. An extension is a static method chosen from the declared type, so it can never be overridden. A member with override is dispatched on the object's runtime class (L8), so a Book in a List<Item> runs Book.label(). bookCount stays an extension: you can't add members to List, and counting needs no dispatch. One extension with when (this) { is Book -> … } also passes, but every new subclass would mean editing it.

Common mistake. Making Item.label() a member but leaving Book's version as an extension. The member wins ("this extension is shadowed by a member"), so even a plain Book variable prints item: Dune.
