== The naive way: rename the column in one step while v1 still serves
v1 after the rename: 20 of 20 requests failed
v1 sees: [SQLITE_ERROR] SQL error or missing database (no such column: name)

== Expand, migrate, contract: never more than two releases live
step                          live     failed wrong
0 v1 only                     v1         0     0
1 migrate V4 (expand)         v1         0     0
2 roll out v2                 v1+v2      0     0
  v2 everywhere               v2         0     0
3 backfill: 50 rows in 3 batches [20, 20, 10]
4 roll out v3                 v2+v3      0     0
  v3 everywhere               v3         0     0
5 migrate V5 (contract)       v3         0     0
v3 reads 140 of 140 members correctly

== Three mistakes the steps protect you from
v1 and v3 live together: 300 wrong reads in 20 requests
v3 before the backfill reads member 1 as: null
contract before the backfill: V5 failed and was rolled back: [SQLITE_CONSTRAINT_NOTNULL] A NOT NULL constraint failed (NOT NULL constraint failed: new_members.full_name)
