Two loops. The first only reads: for each migration that already has an entry in db.history, compare the recorded checksum with m.checksum. check(condition) { "message" } throws the IllegalStateException for you.

---

The second loop applies migrations.filter { it.version !in db.history }.sortedBy { it.version }. Sorting matters: the list you're given may be out of order.

---

Put both db.run(m.script) and db.history[m.version] = m.checksum inside one db.transaction { … }. If the script throws, the transaction restores the tables and the history, and the exception carries on up to the caller. In Java, the same block is a lambda: db.transaction(() -> { db.run(m.script()); db.history.put(m.version(), m.checksum()); return null; }).
