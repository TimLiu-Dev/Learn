A canary router and its verdict

Two functions a canary release needs:

  • inCanary(userId, percent): is this user in the canary slice? Put each user in a bucket from 0 to 99 using hashCode(), and send buckets below percent to the canary. The same user must always get the same answer, so a person doesn't flip between versions on every click.
  • verdict(control, canary): WAIT until the canary has served at least minRequests; then ROLLBACK if its error rate is more than tolerance above the control's, otherwise PROMOTE.
