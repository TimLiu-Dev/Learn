A bucket is hashCode() reduced to 0..99. A string's hash code is the same on every call and every JVM (its formula is in the String.hashCode docs), so the same user always lands in the same bucket.

---

Watch the sign. Most of these users' hash codes are negative, and % keeps the sign of the left side (L48), so h % 100 can be −37. Math.floorMod(h, 100) always gives 0..99.

verdict is a when with three branches, in this order: too few canary requests → WAIT; canary.errorRate > control.errorRate + tolerance → ROLLBACK; else PROMOTE. In Java, an if chain returning Verdict.WAIT and so on.
