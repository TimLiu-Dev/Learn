Step 1 is one UPDATE … SET full_name = name WHERE full_name IS NULL. The WHERE is what makes a backfill safe to run again: it never touches a row that already has a value.

---

Step 2 follows the recipe: create new_members in the final shape (add NOT NULL to full_name), INSERT INTO new_members (…) SELECT … FROM members, DROP TABLE members, then ALTER TABLE new_members RENAME TO members.

---

Dropping a table drops its indexes too, so finish with CREATE INDEX members_by_joined ON members(joined);. The UNIQUE on email comes back by itself, because it's part of the new CREATE TABLE. If you skip step 1, the INSERT fails with "NOT NULL constraint failed": the constraint is your safety net.
