Why it works. The UPDATE fills only the gaps, so it can run as many times as you like. The rebuild copies every row into a table that has the final shape; NOT NULL on full_name then guarantees the backfill really finished, because a missing value makes the copy fail and the whole migration roll back.

Common mistake. Forgetting step 8 of the recipe: DROP TABLE silently takes the table's indexes with it, and nothing recreates them. Every query that used members_by_joined turns into a full scan (L35), and you only notice when production gets slow.
