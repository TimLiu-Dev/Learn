LSM-trees, Bloom filters, B-trees

Write pathmemtable (sorted, in memory) → flush as SSTable
Read pathmemtable, then SSTables newest first; first hit wins
SSTablesorted, immutable; sparse index + Bloom filter in memory
Compactionk-way merge with a heap; keep newest; full merge drops tombstones
Bloom "no"always right · "maybe" can be wrong
False positivesf = (1 − e−kn/m)k; best k = ln 2 · m/n
Sizingbits/key = −ln p / (ln 2)²: 1% ≈ 9.6, k = 7
B-tree write ★whole page (4 KB) per commit: batch your writes
Trade-offread vs write vs space amplification: pick two
