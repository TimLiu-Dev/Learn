Greedy & Dijkstra (L49)

Greedybest-looking choice now, never undo; usually sort + one pass, O(n log n)
Interval schedulingearliest finish first ★ (earliest start / shortest first fail)
Exchange argumentfirst difference → swap in greedy's choice → no worse → induct
Relax v→wif (d[v] + wt < d[w]) update d[w], parent[w]
Dijkstra (lazy)poll min; if (!settled.add(v)) continue; relax; re-add, don't decrease
CostO(E log V) time, O(V) + queue; polled = final
Early exitstop when the target is polled, not when relaxed
Negative edgesDijkstra wrong → Bellman–Ford: relax all edges V−1 times, O(EV)
Ties in the queueJDK: "broken arbitrarily"; add a 2nd key for repeatable runs
A*Dijkstra + estimate to goal; exact if it never overestimates

Quick-unionparent links; can degrade to a chain, height n−1
Weightedsmaller tree under larger: height ≤ lg n
+ path compressionpoint the path at the root: ~O(1) amortised (inverse Ackermann)

Kruskalsort edges; take if find(a) != find(b); stop at V−1; O(E log E)
