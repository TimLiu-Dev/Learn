Find, then walk right

Lay an index's leaf pages end to end and you get one sorted list of (key, rowid) entries. Binary search stands in for the descent from the root, and stepping to the next entry stands in for walking along the linked leaves.

  • lowerBound(key): the first position whose key is >= key (or size), by binary search.
  • lookup(key) and range(lo, hi): find the start once, then walk right while the keys still match.

Read entries only through at(i): it counts reads, and one check asks a lookup on 200,000 entries to stay under 40.
