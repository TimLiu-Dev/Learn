Copying the old array into a bigger one keeps every element at its old index. But contains looks for x starting at x.mod(newSize), and that's usually a different slot.

---

Keep a reference to the old array, point slots at a fresh array of twice the size, then loop over the old one. For each non-null element, ask find(slots, x) where it goes now.

---

for (x in old) if (x != null) slots[find(slots, x)] = x. Don't call add here: it would count every element again and might call resize in the middle of a resize. In Java the new array is new Integer[old.length * 2].
