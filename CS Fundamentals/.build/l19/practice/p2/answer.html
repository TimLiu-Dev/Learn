Why it works. An element's home slot is x.mod(capacity), so it changes when the capacity does. Re-inserting with find on the new array puts each element on its new probe path. Keeping the table at most half full means find always meets an empty slot quickly.

Common mistake. slots = slots.copyOf(slots.size * 2). Everything stays at its old index, so 11, which sat in slot 4 of 8, is never found: contains starts at slot 11 of 16, finds it empty and stops.
