Changing var name to val name stops the key from drifting. It also stops rename from compiling, which is the point: a key can't be edited in place, so you must swap it for a new one.

---

Three steps: take the old entry out with remove (it returns the points, or null if there were none), build the new key with the data class's copy (L7), and put it back with the same points.

---

val pts = points.remove(member) ?: return null, then val renamed = member.copy(name = newName) and points[renamed] = pts. In Java, make Member a record and write new Member(newName, member.city()).
