Rename without losing the points

Registry.rename changes a key while it sits in the HashMap, so the member's points become unreachable. Fix the design:

  • Make Member safe to use as a key: its name must not change.
  • rename(member, newName) moves the points to a new key with the new name and the same city, and returns that new Member. The old name must be gone.
  • Renaming someone who isn't registered returns null and changes nothing.
