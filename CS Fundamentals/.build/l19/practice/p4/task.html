Pairs that add up, in one pass

Both functions read the list once, left to right, and use a map to remember what they've seen. No nested loops.

  • twoSum(nums, target): the indices i < j of two numbers that add up to target, as a pair. Return the pair that completes first, meaning the smallest j (any matching i will do). If no pair exists, return null.
  • countPairs(nums, target): how many index pairs i < j add up to target. [3, 3, 3] with target 6 has 3 pairs.
