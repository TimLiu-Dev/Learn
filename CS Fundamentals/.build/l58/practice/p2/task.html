Make the aggregate guard its rules

Borrower is the aggregate root for one member's loans, but right now anyone can push onto its list and lend checks nothing. Make every change go through the root:

  • lend returns "Lent C-1", or "Blocked: …" for these rules, checked in this order: has an overdue loan (an open loan older than 14 days), already has C-1 (same copy, still open), already has 3 loans.
  • giveBack closes the open loan of that copy and returns true, or returns false if there isn't one.
  • openLoans hands out a copy, never the aggregate's own list.
