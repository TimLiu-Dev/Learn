violations: go through every (from, tos) entry of deps, keep the tos whose ring is bigger than from's, and turn each into a string. flatMap then sorted().

findCycle: keep the current DFS path as a list. Visit a module: if it is already on the path, you've walked in a circle, so return the path from its first appearance to here, plus the module again. Otherwise add it, visit each dependency, and remove it again when you're done.

Add a done set for modules you've fully explored, so a big graph doesn't get re-walked (that's L21's "black" colour). Start a visit from every module, because the cycle might not be reachable from the first one. In Java, a recursive helper with a List<String> path and a Set<String> done works the same way.
