Check the dependency rule

Each module sits in a ring: 0 is the domain at the centre, bigger numbers are further out. Write violations: every dependency a -> b where b is in an outer ring, as "a -> b" strings, sorted.

Then write findCycle: a path like [a, b, a] that follows dependencies back to where it started, or null if there is none. A depth-first search (L21) does it.
