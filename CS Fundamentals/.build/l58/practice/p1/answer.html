Why it works. The dependency rule is a comparison per arrow: an arrow may stay in its ring or point inward, never outward. A cycle is a DFS that meets a module still on its own path (L21's "grey" node). Real tools do the same over class files or Gradle's project graph; Gradle itself refuses a cycle between projects.

Common mistake. Treating "already visited" as "cycle". In the hexagonal graph, main reaches domain through several routes. That's a diamond, not a cycle, so only a module on the current path counts.
