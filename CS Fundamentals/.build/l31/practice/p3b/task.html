Parse a Server-Sent Events stream

Turn the raw text of an event stream into a list of Event(type, data, id), following the WHATWG rules from this part:

  • A blank line dispatches the event. data: lines append to the data, joined with \n. A line starting with : is a comment.
  • Split each line at its first colon; if the value starts with a space, remove that one space. event: sets the type (default message, reset after each event); id: sets the last event id, which stays until a new id:.
  • Don't dispatch an event with no data, and drop an unfinished event at the end of the input. Lines may end in \n or \r\n.
