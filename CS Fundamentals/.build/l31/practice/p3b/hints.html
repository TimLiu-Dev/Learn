Keep three pieces of state outside the loop: the event type, a StringBuilder for the data, and the last id. Loop over stream.lines(), which already handles \n and \r\n. An empty line is the moment to emit an event, then reset the type and the data, but not the id.

---

For a field line, line.substringBefore(':') is the field name and line.substringAfter(':', "") the value (empty if there's no colon). Then removePrefix(" ") drops exactly one space. Don't use trim(): a second space is part of the data.

---

On data, append the value and a '\n'. On a blank line, emit only if (data.isNotEmpty()), using data.removeSuffix("\n").toString() and type.ifEmpty { "message" }. Whatever is still buffered when the loop ends is simply never emitted. In Java, stream.split("\\r?\\n", -1) gives the lines (the -1 keeps the trailing empty ones), and indexOf(':') does the splitting.
