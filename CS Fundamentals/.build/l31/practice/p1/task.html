Pick the right status code

A tiny notes API answers with a Response(status, headers, body). Fill in handle:

  • /notes: GET lists the titles, one per line. POST adds the body as a title: a blank title is 422, a title that already exists is 409, otherwise 201 with Location: /notes/N.
  • /notes/N: GET returns note N (numbered from 1), or 404 if there's no such note.
  • A path that exists but not for this method is 405, with an Allow header listing the methods that do work: "GET, POST" or "GET". Any other path is 404.
