Lower-case both strings first. Without a wildcard, covers is plain equality. With one, remove the host's first label and compare what's left with the name minus its *..

---

host.substringAfter('.', "") drops the first label and returns "" if there's no dot. Don't use endsWith(".example.com"): it also accepts a.b.example.com, two labels deep.

---

In verify: names.none { covers(it, host) }, then chain.firstOrNull { it.notAfter < now }, then chain.zipWithNext().forEachIndexed { i, (cert, parent) -> … }, and finally chain.last().issuer in trusted. In Java, Instant.isBefore replaces <, and a plain index loop replaces zipWithNext.
