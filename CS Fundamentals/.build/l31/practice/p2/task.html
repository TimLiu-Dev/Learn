Check a certificate chain (a model)

Your machine checks a chain before any HTTP is sent. Model that check with the real example.com chain from this part. Fill in:

  • covers(name, host): does one name from a certificate cover the host? Compare without case. A wildcard is only allowed as the whole left-most label, and *.example.com covers exactly one extra label (RFC 9525 §6.3).
  • verify(chain, host, now, trusted): "OK", or the first problem in the order the comment lists. chain[0] is the leaf, and each certificate is signed by the next one.

A real verifier also checks each signature with the issuer's public key. This model checks names, dates and links only.
