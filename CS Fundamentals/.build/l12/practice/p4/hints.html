Start with isAncestor. Either a == b, or a is an ancestor of one of b's parents. That's a two-line recursive function. The first commit has no parents, so the recursion stops there.

---

In merge, check the cases in this order. If theirs is an ancestor of ours, you already have it. If ours is an ancestor of theirs, your branch hasn't moved since they split, so set branches[head] = theirs. Otherwise the history has diverged.

---

For the diverged case, branches[head] = newCommit(ours, theirs). If the "merging back" check fails, look at isAncestor: following only parents[b].first() never sees the second parent of a merge commit. In Java, any { … } becomes a loop over parents.get(b).
