The badge printer crashes

initials works on every name you try by hand, yet badges crashes on the full roster. The stack trace names the line, but not the input that broke it. Find that input, then fix initials so that:

  • each word gives one upper-case letter ("grace hopper" → "GH");
  • stray spaces anywhere in a name are ignored, and a blank name gives "".

In IntelliJ, you'd add an exception breakpoint and read name and parts in the paused frame. Here, use println, and print only when something looks wrong: that's the page's version of a conditional breakpoint.
