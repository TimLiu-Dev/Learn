The badge printer crashes

initials works on every name you try by hand, yet badges crashes on the full roster with String index out of range: 0. That says what went wrong, but not which name caused it. Find that name, then fix initials so that:

  • each word gives one upper-case letter ("grace hopper" → "GH");
  • stray spaces anywhere in a name are ignored, and a blank name gives "".

In IntelliJ, an exception breakpoint would stop at the throw, with name and parts visible in the frame. Here, put a println inside an if: it prints only when something looks wrong, and a failing check shows what was printed after its message. That's the page's version of a conditional breakpoint.
