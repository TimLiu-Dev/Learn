Why it works. split(" ") cuts at every space, so two spaces in a row, or a space at either end, produce empty strings. Filtering them out leaves only real words, and a blank name leaves no words at all, so the result is "". The conditional println found the input in one run, the way a conditional or exception breakpoint does in IntelliJ, without printing all twelve names, or all ten thousand in a real roster.

Common mistake. Fixing only the input you found, such as replace(" ", " ") for the double space. The next run crashes on " Linus Torvalds". A fix should remove the cause, empty words, not the one example you happened to catch.
