Branches are just pointers

Git can't run in this page, so here's the next best thing: a tiny model of a repository in Kotlin. Commits are ids that remember their parent. A branch is nothing but a name that points at one commit, and head names the branch you're on. Fill in the TODOs:

  • commit() moves only the branch HEAD points to. createBranch and switch make no commits at all.
  • createBranch refuses a name that exists, and switch refuses one that doesn't, both with IllegalArgumentException (L10's require).
  • log() lists commit ids from HEAD's commit back to the first one, like git log --oneline.

The real practice is still in your terminal: do Part 3's exercise in ~/katas with real Git.
