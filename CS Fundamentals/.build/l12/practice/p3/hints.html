Think of every method as changing one or two map entries, nothing more. commit() already recorded the parent; what's left is moving one pointer: branches[head] = id. switch changes only head.

---

createBranch copies the current commit id under the new name: branches[name] = branches.getValue(head). Put require(name !in branches) { … } first, and require(name in branches) at the top of switch.

---

For log(), start at branches.getValue(head) and keep following parent[id] until it's null: a while loop into a list, or generateSequence(start) { parent[it] }.toList(). In Java, require becomes if (…) throw new IllegalArgumentException(…), and the method is switchTo because switch is a Java keyword.
