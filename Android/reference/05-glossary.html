2027 Android & KMP Engineering Reference Glossary

Comprehensive desk dictionary of canonical curriculum terminology across Phases I–X. (Your personal mastered-terms tracker lives in GLOSSARY.md.)

Phase I: Kotlin 2.x, Coroutines & Reactive Streams

K2 Compiler (FIR)
Kotlin's Frontend Intermediate Representation compiler delivering ~2x faster builds and Smart Cast 2.0 across local boolean aliases and inline lambdas.
Avoid: Legacy K1 frontend
Sealed Interface (sealed interface)
A closed sum-type hierarchy known at compile time within a module/package, enabling exhaustive when expressions without catch-all else branches.
Avoid: Boolean flag soup, nullable state bags
Inline Value Class (@JvmInline value class)
A single-property compile-time wrapper (such as UserId or UsdMicros(val micros: Long)) that unboxes to its underlying primitive/reference in JVM bytecode when non-nullable and non-generic.
Avoid: Primitive obsession, IEEE-754 Double for currency
Context Parameters (context(...))
Kotlin 2.2+ mechanism for declaring named, lexically scoped ambient capabilities (transactions, DSL scopes) lowered to standard JVM method parameters.
Avoid: Experimental unnamed context receivers, ThreadLocal globals
Structured Concurrency & Cooperative Cancellation
The invariant that every coroutine runs inside a parent-child Job tree where cancellation cascades downward via CancellationException (which must never be swallowed by generic catch (e: Exception) blocks).
Avoid: GlobalScope.launch, fire-and-forget threads
SharingStarted.WhileSubscribed(5_000)
The standard stateIn lifecycle policy keeping upstream flows alive across 5-second configuration changes (rotation/unfolding) while stopping collection 5 seconds after backgrounding.
Avoid: SharingStarted.Eagerly on UI-driven database/socket streams

Phase II: Jetpack Compose, Text/i18n & UI Testing

Three Compose Frame Phases (Composition → Layout → Draw)
The sequential per-frame pipeline updating the Slot Table (*what*), measuring/placing nodes in one pass (*where*), and recording GPU RenderNodes (*how*). Deferring state reads via lambda modifiers skips earlier phases.
Avoid: Reading high-frequency scroll/animation state directly in Composition
TextFieldState (rememberTextFieldState)
Buffer-backed synchronous text state holder for Compose inputs that preserves IME composition regions and cursor selection without async StateFlow round-trip glitches.
Avoid: Asynchronous ViewModel onValueChange loops that corrupt Asian IME input
Strong Skipping Mode
Default Compose compiler mode comparing stable parameters via equals(), unstable parameters via referential ===, and automatically memoizing lambdas.
Avoid: Manual remember {{ }} wrappers around standard event lambdas
Modifier.Node
Lifecycle-aware, allocation-free custom modifier architecture replacing deprecated stateful Modifier.composed.
Avoid: Modifier.composed

Phases III–V: Navigation 3, Offline-First Data & Multi-Module Build

Jetpack Navigation 3 (androidx.navigation3)
Compose-native navigation library where the developer owns a reactive SnapshotStateList<NavKey> (rememberNavBackStack) rendered into single- or multi-pane adaptive layouts via NavDisplay and SceneStrategy.
Avoid: Imperative string-template route URLs
Single Source of Truth (SSOT)
Offline-first rule where UI ViewModels observe only local persistence (Room Flow / DataStore), while network calls write exclusively into local storage via @Upsert.
Avoid: Returning raw Retrofit/Ktor DTOs directly to ViewModels
ABI Compilation Avoidance (implementation vs api)
Declaring internal dependencies with implementation so changes inside :core:network or :core:database do not alter downstream compile classpaths or invalidate cached :feature:* builds.
Avoid: Blanket api(...) dependencies or feature-to-feature imports
Session-Consistent Feature Flags
Freezing non-killswitch remote config flags at cold start from local disk cache (with lazy exposure logging at feature entry) so active user journeys never morph mid-flow.
Avoid: Blocking cold start on fetchAndActivate() or logging A/B exposure in Application.onCreate()

Phases VI–X: 2027 Mandates, KMP/CMP, On-Device AI & Specializations

16 KB ELF Page Alignment
Google Play requirement that all native .so shared libraries align PT_LOAD segments on 16384-byte (0x4000) boundaries (NDK r28+ / AGP 8.5.1+) for 16 KB Linux kernel compatibility.
Avoid: Hardcoded 4096 PAGE_SIZE macros or unaligned prebuilt AARs
CredentialManager & Play Integrity requestHash
Pairing phishing-resistant FIDO2 Passkeys with server-verified Play Integrity tokens cryptographically bound to a SHA-256 digest of the request payload and server nonce.
Avoid: EncryptedSharedPreferences, client-side root booleans, static nonces
ApplicationExitInfo
Kernel-persisted process death forensics (getHistoricalProcessExitReasons + 128-byte setProcessStateSummary breadcrumbs) capturing silent foreground LMK OOMs and ANR thread dumps.
Avoid: Relying solely on user-space UncaughtExceptionHandler crash reporters
Kotlin Multiplatform (KMP) & SKIE
Sharing pure commonMain domain/data logic compiled to Android DEX and iOS LLVM ARM64 frameworks, using Touchlab SKIE to bridge Flow to Swift AsyncSequence and sealed interface to exhaustive Swift enums.
Avoid: Unchecked Kotlin exceptions crossing into Swift without @Throws or typed results
Android AICore (Gemini Nano)
System-managed on-device foundation model service delivering zero-egress NPU inference when foregrounded, gated behind runtime checkFeatureStatus() and token-budget routing.
Avoid: Bundling GB-scale LLM weights inside base AABs or invoking AICore from background workers
Idempotent Purchase Verification (Play Billing 7+)
Validating Google Play purchaseToken entitlements on your backend via the Play Developer API + RTDN Pub/Sub webhooks before granting access and acknowledging within 3 days.
Avoid: Trusting client-only Purchase.PurchaseState.PURCHASED booleans without server verification
