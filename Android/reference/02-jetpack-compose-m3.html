1. Side-Effects Selection Guide

APITriggers WhenDisposal / Cancellation

2. Modifier Order: The Golden Rule

Modifiers apply from the outside in. The order determines measurement, clip bounds, and touch propagation.

Modifier
    .padding(16.dp)         // Outer margin: shrinks available space
    .clip(RoundedCornerShape(12.dp))
    .background(Color.Blue) // Painted inside clipped bounds
    .clickable { ... }      // Ripple & touch match clipped bounds
    .padding(12.dp)         // Inner padding: pushes child inward
