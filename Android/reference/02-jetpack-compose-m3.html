Composition lifecycle, side-effects, stability rules, and modifier ordering.

1. Side-Effects Selection Guide

APITriggers WhenDisposal / Cancellation

2. Modifier Order: The Golden Rule

Modifiers apply from the outside in. The order determines measurement and event propagation.

Modifier
    .padding(16.dp)         // Outer margin: affects outer layout
    .background(Color.Blue) // Painted within outer margin
    .clickable { ... }      // Touch target matches current bounds
    .padding(8.dp)          // Inner padding: pushes child inward
