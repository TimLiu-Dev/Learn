Aether: Core Infrastructure & Design System Modules

Build the shared design tokens, custom buttons, cards, and theme infrastructure in :core:designsystem.

Every professional engineering team maintains a Design System Module (:core:designsystem). This module contains the branded theme tokens, typography, custom icon sets, and atomic components (buttons, badges, cards) used across all feature screens, guaranteeing visual consistency.

🌱 Junior Android Dev Mental Model: Design System Independence

:core:designsystem contains ONLY UI primitives. It knows nothing about financial portfolios, networking, or databases! It can be showcased in isolation using Compose previews or a standalone Catalog app.

🎯 Reference Production Solution 
import androidx.compose.material3.*
import androidx.compose.runtime.Composable

@Composable
fun AetherPrimaryButton(text: String, onClick: () -> Unit) {
    Button(onClick = onClick) {
        Text(text)
    }
}

Why this works: Atomic design system components ensure that buttons and controls across all feature modules adhere to consistent spacing, touch targets, and themes.
