Static Code Analysis & Code Health: Detekt & Lint

Enforce strict Kotlin code health, detect architectural leaks, and enforce Compose rules with Detekt and Android Lint.

Recommended Primary Source
Detekt: Static code analysis for Kotlin
Official Documentation →

Preventing bugs during code review is far cheaper than fixing production crashes. Static Analysis tools (Android Lint, Detekt, and Compose Lint rules) analyze your Kotlin Abstract Syntax Tree (AST) to flag anti-patterns, memory leaks, and naming defects automatically before code is merged.

🌱 Junior Android Dev Mental Model: Common Detekt Rules in Android
  • ViewModelForwardingParameter: Flags passing entire ViewModels into child composables.
  • ComposeNaming: Enforces that @Composable functions returning Unit must start with an uppercase letter.
  • UnusedPrivateMember: Prevents dead code accumulation.

🎯 Reference Production Solution 
fun formatRuleCheck(violations: Int): String =
    if (violations == 0) "BUILD PASSED" else "BUILD FAILED: $violations defects"

Why this works: Automated quality gates ensure that pull requests with style violations or architectural leaks fail in CI before reaching production codebases.
