Android Hardware Security & Biometrics

Protect sensitive cryptographic keys using Android Keystore (StrongBox/TEE) and BiometricPrompt authentication.

Recommended Primary Source
Google Android: Show a biometric authentication dialog
Official Documentation →

Storing user API tokens or encryption keys in plain text in SharedPreferences or a database is a critical security vulnerability. The Android Keystore system stores cryptographic keys inside hardware-isolated secure hardware: the Trusted Execution Environment (TEE) or StrongBox Keymaster.

🌱 Junior Android Dev Mental Model: BiometricPrompt + CryptoObject

Don't just check onAuthenticationSucceeded and assume the user is authenticated! A rooted device can spoof the callback. In production (like our Aether Vault), you generate a key in Keystore that requires biometric authentication to decrypt. You pass a BiometricPrompt.CryptoObject(cipher): the key is hardware-unlocked ONLY when the user passes biometric verification!
