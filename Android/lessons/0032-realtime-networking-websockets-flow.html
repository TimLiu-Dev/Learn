Real-Time Streaming: WebSockets, <code>callbackFlow</code> & Backpressure Conflation

Polling a REST endpoint every second for live market quotes or chat messages wastes battery, saturates radio wake-locks, and adds HTTP header overhead. In our Aether capstone, sub-second BTC/ETH order-book ticks stream over a full-duplex WebSocket (via OkHttp's <code>WebSocketListener</code> or Ktor's <code>webSocketSession</code>) wrapped inside a cold Kotlin callbackFlow { ... }.

Bridging a callback-based WebSocket API into structured concurrency requires three strict rules inside <code>callbackFlow</code>:

  1. Non-blocking Emission (<code>trySend</code>): Inside <code>onMessage(webSocket, text)</code>, push parsed domain frames into the channel using trySend(tick).
  2. Mandatory Cleanup (<code>awaitClose</code>): The final statement of every <code>callbackFlow</code> block must be awaitClose { webSocket.close(1000, "Collector unsubscribed") }! <code>awaitClose</code> suspends keeping the flow alive while collectors are active, and executes its cleanup lambda deterministically the instant the downstream collector cancels (e.g., 5 seconds after the user backgrounds the app via <code>WhileSubscribed(5_000)</code>). Forgetting <code>awaitClose</code> causes <code>callbackFlow</code> to terminate immediately after opening the socket—or worse, leaks an open WebSocket connection in the background!
  3. Backpressure Strategy (<code>.buffer(Channel.CONFLATED)</code> or <code>.conflate()</code>): High-frequency crypto exchanges can push 200+ order-book frames per second (~5ms apart), while the UI renders at 60–120Hz (8.3–16.6ms) and only cares about the latest price snapshot. Applying .conflate() ensures slow UI collectors always receive the freshest tick without buffering stale backlog frames in RAM.
🌱 Junior Android Dev Mental Model: Sharing One Socket Across Multiple Collectors

Because callbackFlow is cold, every independent collector that calls .collect() on it will open a brand-new WebSocket connection! In your Repository, share a single underlying socket connection across multiple consumers using .shareIn(scope, started = SharingStarted.WhileSubscribed(5_000), replay = 1).

Senior Interview Trap: Reconnection Loops When Device is Offline (<code>ConnectivityManager</code>)

If a WebSocket drops because the user entered an elevator or airplane mode, blindly retrying with a tight loop spins the CPU and fails immediately. Senior engineers combine exponential backoff (<code>retryWhen { cause, attempt -> ... }</code>) with an upstream <code>NetworkMonitor.isOnline</code> <code>callbackFlow</code> (backed by <code>ConnectivityManager.NetworkCallback</code>) so reconnection attempts wait until the OS reports a validated <code>NET_CAPABILITY_INTERNET</code> connection.

❌ Junior Anti-Pattern: Missing awaitClose & Unbounded Buffer Backlog

fun streamTicksBad(client: OkHttpClient, req: Request): Flow<Tick> = callbackFlow {
    val listener = object : WebSocketListener() {

✅ 2027 Senior Production Standard: callbackFlow + awaitClose + Conflation

fun observeLiveTicks(
    client: OkHttpClient,
    request: Request
): Flow<MarketTick> = callbackFlow {
    val listener = object : WebSocketListener() {
        override fun onMessage(webSocket: WebSocket, text: String) {
            val tick = json.decodeFromString<MarketTickDto>(text).toDomain()
            trySend(tick)
        }
        override fun onFailure(webSocket: WebSocket, t: Throwable, response: Response?) {
            close(t) // Propagates exception downstream to trigger retryWhen!
        }
    }
    val socket = client.newWebSocket(request, listener)

    // Suspends until downstream collector cancels, then cleanly closes RFC-6455 socket!
    awaitClose {
        socket.close(1000, "Lifecycle stopped")
    }
}.conflate()

data class OrderBookTick(val sequence: Long, val symbol: String, val bid: Double, val ask: Double)

class SimulatedConflatedWebSocketStream {
    private var latestBufferedTick: OrderBookTick? = null
    var isSocketOpen: Boolean = false
        private set

    fun openSocket() {
        isSocketOpen = true
        println("[WS-OPEN] Connected to wss://stream.aether.finance/v1/orderbook")
    }

    fun onWebSocketFrame(tick: OrderBookTick) {
        val dropped = latestBufferedTick?.sequence
        latestBufferedTick = tick
        if (dropped != null) {
            println("[WS-CONFLATE] Fast producer emitted seq=${tick.sequence} (conflated unconsumed seq=$dropped)")
        } else {
            println("[WS-EMIT] Producer emitted seq=${tick.sequence} (${tick.symbol} ${tick.bid}/${tick.ask})")
        }
    }

    fun collectNextUiFrame(): OrderBookTick? {
        val item = latestBufferedTick
        latestBufferedTick = null
        if (item != null) println("[UI-COLLECT 120Hz] Rendered latest tick seq=${item.sequence} -> bid=$${item.bid}")
        return item
    }

    fun awaitCloseCleanup() {
        isSocketOpen = false
        println("[WS-AWAIT-CLOSE] Downstream cancelled -> Sent RFC-6455 Close(1000, 'Lifecycle stopped')")
    }
}

fun main() {
    val stream = SimulatedConflatedWebSocketStream()
    stream.openSocket()
    stream.onWebSocketFrame(OrderBookTick(101, "BTC", 94200.0, 94201.0))
    stream.onWebSocketFrame(OrderBookTick(102, "BTC", 94215.0, 94216.0))
    stream.onWebSocketFrame(OrderBookTick(103, "BTC", 94240.0, 94241.0))
    stream.collectNextUiFrame()
    stream.awaitCloseCleanup()
}

import kotlinx.coroutines.channels.awaitClose
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.callbackFlow
import kotlinx.coroutines.flow.conflate

interface RealtimeSocket {
    fun close()
}

fun observeTickerStream(
    connect: (onPrice: (Double) -> Unit) -> RealtimeSocket
): Flow<Double> = callbackFlow {
    val socket = connect { price ->
        trySend(price)
    }
    awaitClose {
        socket.close()
    }
}.conflate()

Why this works: callbackFlow bridges the asynchronous callback into a cold Flow, trySend safely dispatches values into the underlying Channel from the socket callback thread, awaitClose guarantees socket.close() runs when collection cancels, and .conflate() drops stale intermediate ticks under backpressure.

Quiz 1: Code Analysis & Bug Hunt

A developer wrote this <code>callbackFlow</code> to observe network connectivity using <code>ConnectivityManager</code>. Why does the app immediately crash at runtime with <code>IllegalStateException: 'awaitClose { yourCallbackOrListener.cancel() }' should be used in the end of callbackFlow block</code>?

fun observeNetworkStatus(cm: ConnectivityManager): Flow<Boolean> = callbackFlow {
    val callback = object : ConnectivityManager.NetworkCallback() {
        override fun onAvailable(network: Network) { trySend(true) }
        override fun onLost(network: Network) { trySend(false) }
    }
    cm.registerDefaultNetworkCallback(callback)
}
ProducerScope trySend cannot be invoked from the background ConnectivityManager IPC Binder thread without switching dispatchers.
Kotlin callbackFlow channels only support emitting heap reference objects and reject boxed primitive Boolean values.
ConnectivityManager registerDefaultNetworkCallback must always be invoked synchronously on Dispatchers.Main before registering any coroutine flow collector.
callbackFlow requires calling awaitClose to suspend and unregister callbacks on cancellation, throwing IllegalStateException if omitted.
