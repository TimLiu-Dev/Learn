🌱 Junior Android Dev Mental Model: Candlestick Rendering & Vault Security
  1. Candlestick Chart: Built using Canvas and DrawScope. Green candles (close > open) and red candles (close < open) are drawn alongside high-low wicks in sub-millisecond draw passes.
  2. Biometric Vault: The user's portfolio secret is encrypted with AES-256 GCM in Android Keystore with setUserAuthenticationRequired(true), requiring a verified fingerprint or face biometric to decrypt!

🎯 Reference Production Solution 
data class Candle(
    val open: Double,
    val high: Double,
    val low: Double,
    val close: Double
) {
    val isBullish: Boolean get() = close >= open
}

Why this works: Encapsulating OHLC calculations in immutable domain models ensures charts and summaries calculate bullish/bearish candle styling consistently.
