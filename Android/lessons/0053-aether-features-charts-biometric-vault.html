In Lesson 0053, we build Aether's two flagship vertical feature slices: <code>:feature:market</code> (featuring a 120fps custom <code>Canvas</code> / <code>DrawScope</code> OHLC Candlestick Chart with interactive touch scrubbing and haptic feedback) and <code>:feature:vault</code> (featuring a hardware-backed <code>BiometricPrompt.CryptoObject</code> AES-256-GCM cold-storage vault).

1. <code>:feature:market</code>: 120fps <code>DrawScope</code> Candlestick Chart & Phase Skipping

Rendering 200 OHLC (Open, High, Low, Close) candlesticks with a live crosshair scrubber requires strict adherence to Jetpack Compose's 3-phase pipeline (<strong>Composition → Layout → Draw</strong>). If we allocate <code>Path</code> or <code>Paint</code> objects inside the <code>Canvas { ... }</code> lambda, or read <code>scrubberX</code> directly inside the outer <code>@Composable</code> body, every 8.33ms finger movement triggers a full recomposition and garbage-collection churn! Instead:

  • We cache reusable <code>Path</code> objects via <code>remember { Path() }</code> and pre-compute Y-axis min/max bounds via <code>remember(candles) { ... }</code>.
  • We track finger gestures using <code>Modifier.pointerInput(candles) { detectHorizontalDragGestures(...) }</code> updating a <code>scrubberIndexState</code>, and read <code>scrubberIndexState.value</code> exclusively inside <code>Modifier.drawWithCache</code> / <code>DrawScope</code>—skipping Composition and Layout entirely on every drag frame!
🌱 Junior Android Dev Mental Model: Coordinate Normalization in <code>DrawScope</code>

In an Android <code>Canvas</code> / <code>DrawScope</code>, <code>y = 0f</code> is the TOP edge of the chart and <code>y = size.height</code> is the BOTTOM edge! Therefore, to map a financial price <code>p</code> between <code>[minPrice, maxPrice]</code> onto pixel Y coordinates, you invert the normalized ratio: val y = size.height * (1f - ((p - minPrice) / (maxPrice - minPrice))).

2. <code>:feature:vault</code>: <code>BiometricPrompt.CryptoObject</code> Hardware Unsealing

When the user opens <code>:feature:vault</code> to view or sign with their encrypted recovery seed, <code>VaultViewModel</code> requests an initialized <code>Cipher</code> (<code>AES/GCM/NoPadding</code> with the stored 12-byte IV) from <code>AetherKeystoreCipherProvider</code> and emits a UI action to launch <code>BiometricPrompt.authenticate(promptInfo, BiometricPrompt.CryptoObject(cipher))</code>. Once <code>onAuthenticationSucceeded</code> returns the hardware-unlocked <code>result.cryptoObject?.cipher</code>, the ViewModel decrypts the ciphertext into a temporary char buffer and clears it when the user locks the vault.

✅ 2027 Senior Production Standard: <code>drawWithCache</code> + Inverted Y Mapping

Spacer(
    modifier = Modifier
        .fillMaxWidth()
        .height(260.dp)
        .pointerInput(candles) {
            detectDragGesturesAfterLongPress(
                onDrag = { change, _ ->
                    val idx = ((change.position.x / size.width) * candles.size)
                        .toInt().coerceIn(0, candles.lastIndex)
                    onScrubIndexChanged(idx)
                }
            )
        }
        .drawWithCache {
            val priceRange = (maxPrice - minPrice).coerceAtLeast(0.01f)
            onDrawBehind {
                candles.forEachIndexed { i, candle ->
                    val x = (i + 0.5f) * (size.width / candles.size)
                    val highY = size.height * (1f - ((candle.high - minPrice) / priceRange))
                    val lowY = size.height * (1f - ((candle.low - minPrice) / priceRange))
                    drawLine(color = candle.color, start = Offset(x, highY), end = Offset(x, lowY))
                }
            }
        }
)

⚠️ Senior Interview Trap: Accessibility (<code>Modifier.semantics</code>) on Custom <code>Canvas</code> Charts

A custom <code>Canvas</code> or <code>drawWithCache</code> node emits raw GPU pixels—by default, Android <strong>TalkBack</strong> screen readers see an unlabeled empty box! In production financial apps, always attach <code>Modifier.semantics { contentDescription = ...; stateDescription = ... }</code> (or expose custom accessibility actions / virtual nodes) so visually impaired users hear the asset's trend, high/low range, and active scrubbed candle price.

data class OhlcCandle(val timestamp: String, val open: Float, val high: Float, val low: Float, val close: Float) {
    val isBullish: Boolean get() = close >= open
}

class CandlestickGeometryMapper(
    private val canvasWidthPx: Float,
    private val canvasHeightPx: Float,
    private val minPrice: Float,
    private val maxPrice: Float
) {
    private val priceSpan = (maxPrice - minPrice).coerceAtLeast(0.0001f)

    fun priceToCanvasY(price: Float): Float =
        canvasHeightPx * (1f - ((price - minPrice) / priceSpan))

    fun touchXToCandleIndex(touchX: Float, candleCount: Int): Int =
        ((touchX / canvasWidthPx) * candleCount).toInt().coerceIn(0, candleCount - 1)
}

fun main() {
    val candles = listOf(
        OhlcCandle("10:00", open = 92000f, high = 92800f, low = 91800f, close = 92600f),
        OhlcCandle("11:00", open = 92600f, high = 93100f, low = 92100f, close = 92200f),
        OhlcCandle("12:00", open = 92200f, high = 94500f, low = 92200f, close = 94200f)
    )
    val minP = candles.minOf { it.low }
    val maxP = candles.maxOf { it.high }
    val mapper = CandlestickGeometryMapper(canvasWidthPx = 1080f, canvasHeightPx = 600f, minPrice = minP, maxPrice = maxP)

    candles.forEachIndexed { idx, c ->
        val wickTopY = mapper.priceToCanvasY(c.high)
        val wickBottomY = mapper.priceToCanvasY(c.low)
        println("[CANDLE #$idx ${c.timestamp}] bullish=${c.isBullish} | high=$${c.high} (y=${"%.1f".format(wickTopY)}px) -> low=$${c.low} (y=${"%.1f".format(wickBottomY)}px)")
    }
    val scrubbedIdx = mapper.touchXToCandleIndex(touchX = 820f, candleCount = candles.size)
    println("[SCRUBBER] Touch at x=820px -> Selected Candle #$scrubbedIdx (${candles[scrubbedIdx].timestamp}, close=$${candles[scrubbedIdx].close})")
}

class ChartCoordinateProjector {
    fun priceToY(
        price: Float,
        minPrice: Float,
        maxPrice: Float,
        heightPx: Float
    ): Float {
        val ratio = (price - minPrice) / (maxPrice - minPrice)
        return heightPx * (1f - ratio)
    }

    fun xToCandleIndex(
        touchX: Float,
        widthPx: Float,
        totalCandles: Int
    ): Int {
        val rawIndex = ((touchX / widthPx) * totalCandles).toInt()
        return rawIndex.coerceIn(0, totalCandles - 1)
    }
}

Why this works: Inverting the normalized price ratio places maxPrice at y=0f (top of the Canvas) and minPrice at y=heightPx (bottom), while coerceIn(0, totalCandles - 1) prevents IndexOutOfBoundsException when the user drags slightly outside the chart bounds.

@Composable
fun MarketScreen(candles: ImmutableList<OhlcCandle>) {

    Column {

        )
    }

The mutableIntStateOf snapshot state delegate boxes primitive integers onto the heap on every pointer movement frame.
Reading scrubbedIndex in MarketScreen recomposes the whole screen; deferring reads via lambdas to drawWithCache skips recomposition.
Compose Column layouts always force all sibling child composables to recompose whenever any child redraws Canvas.
Accessing ImmutableList elements through the bracket indexing operator triggers a defensive allocation and invalidates parent composables.
