Predictive Back, Modern Permissions & Foreground Service Types

Replace broken legacy back overrides, drop broad storage permissions with Photo Picker, and declare compliant typed Foreground Services.

Recommended Primary Source
Android Developers: Add Support for the Predictive Back Gesture
Official Documentation →

On Android 16+ (targetSdk 36+), system predictive back animations are enabled by default and legacy Activity.onBackPressed() overrides are bypassed. At the same time, Play Console review strictly audits storage permissions (expecting the System Photo Picker) and requires explicit android:foregroundServiceType attributes plus runtime permissions for any Foreground Service.

🌱 Junior Pitfall vs. Senior System Boundary

Juniors intercept back gestures eagerly with BackHandler(enabled = true) even when a form has no unsaved edits—which breaks the OS back-to-home preview animation! Seniors set enabled = hasUnsavedChanges (or use PredictiveBackHandler to drive custom progress animations) so the OS knows ahead of time whether it owns the gesture. Compare with Lesson 0009 and Lesson 0038.

❌ Junior Pitfall: Always-On Interception & Broad Storage

Overriding onBackPressed(), requesting READ_MEDIA_IMAGES just to pick an avatar, or launching an untyped Service.

✅ 2027 Senior Standard: Ahead-of-Time Signals

Use PredictiveBackHandler(enabled = isDirty), PickVisualMedia (zero storage permission), and typed FGS (e.g. dataSync) only when user-visible.

@Composable
fun UnsavedFormGuard(hasUnsavedEdits: Boolean, onConfirmDiscard: () -> Unit) {
    PredictiveBackHandler(enabled = hasUnsavedEdits) { progress ->
        try {
            progress.collect { backEvent ->
                // Drive progress state = backEvent.progress
            }
            onConfirmDiscard()
        } catch (e: CancellationException) {
            // Reset preview state when user cancels back gesture
        }
    }
}

Why this works: Because enabled is declarative, the WindowManager knows before the gesture starts whether to play the system preview or route BackEventCompat frames into your composable.
