ProGuard & R8 Full Mode Optimization

Shrink APK size by 40%+, eliminate unused code, and write safe keep rules with R8 Full Mode.

Recommended Primary Source
Google Android: Shrink, obfuscate, and optimize your app
Official Documentation →

When compiling release binaries for Google Play, R8 performs code shrinking, resource shrinking, obfuscation (renaming classes to a.b.c to thwart reverse engineering), and dead-code elimination. In 2026/2027, production projects run with R8 Full Mode enabled by default.

🌱 Junior Android Dev Mental Model: Writing Keep Rules

If your code uses reflection or native JNI bindings, R8 might think a class is unused and delete it! You protect classes using -keep rules in proguard-rules.pro (e.g. -keep class app.aether.models.** { *; }). With kotlinx.serialization, keep rules are generated automatically!

🎯 Reference Production Solution 
fun getKeepRule(packageName: String): String =
    "-keep class $packageName.** { *; }"

Why this works: Keep rules instruct R8's tree-shaker to retain specified classes and member variables even if no direct static references appear in bytecode.
