Clean Architecture Domain Layer (When & How to Use Cases)

Encapsulate complex business rules with single-responsibility Use Cases and avoid 1:1 pass-through over-engineering.

Recommended Primary Source
Google Android: Guide to App Architecture - Domain Layer
Official Documentation →

The Domain Layer sits between the UI Layer (ViewModels) and Data Layer (Repositories). It is responsible for encapsulating complex business rules, validating domain data, and coordinating multiple repositories.

🌱 Junior Android Dev Mental Model: When NOT to write a Use Case

Avoid the 1:1 Pass-Through Anti-Pattern! If a UseCase merely calls repository.getItems() without adding validation, combining streams, or applying business logic, it is unnecessary boilerplate. Call the repository directly from the ViewModel! Write a UseCase only when logic is reused across ViewModels or combines multiple repositories.

The Idiomatic Kotlin operator fun invoke

Naming UseCases with operator fun invoke() allows you to call the instance directly like a regular function: val result = validateTransferUseCase(amount).

2027 Production Standard (Runnable Example)

Click ▶ Run Example to execute this snippet and inspect the simulated runtime output and state transformations:

KOTLIN 2.X DomainUseCases.kt 
class ValidateAndSubmitTransferUseCase {
    operator fun invoke(amountUsd: Double, balanceUsd: Double): Result<Double> {
        if (amountUsd <= 0.0) return Result.failure(IllegalArgumentException("Amount must be positive"))
        if (amountUsd > balanceUsd) return Result.failure(IllegalStateException("Insufficient funds"))
        return Result.success(balanceUsd - amountUsd)
    }
}

fun main() {
    val transferUseCase = ValidateAndSubmitTransferUseCase()
    
    val attempt1 = transferUseCase(amountUsd = -50.0, balanceUsd = 1000.0)
    println("[USECASE] Attempt 1 (Negative Amount): $attempt1")

    val attempt2 = transferUseCase(amountUsd = 1200.0, balanceUsd = 1000.0)
    println("[USECASE] Attempt 2 (Overdraft): $attempt2")

    val attempt3 = transferUseCase(amountUsd = 250.0, balanceUsd = 1000.0)
    println("[USECASE] Attempt 3 (Valid Transfer): $attempt3")
    println("[SUCCESS] Domain business logic cleanly isolated from UI and Android SDK!")
}

🎯 Reference Production Solution 
class ValidateUsernameUseCase {
    operator fun invoke(username: String): Boolean =
        username.trim().length >= 3
}

Why this works: operator fun invoke allows clean call-site syntax, treating the UseCase object like an executable function while preserving dependency injection capabilities.
