Visual Regression & Screenshot Testing (Roborazzi / Paparazzi)

Catch clipped text, dark-mode contrast bugs, and tablet layout regressions in seconds on the JVM without emulators.

Recommended Primary Source
Android Developers: Compose Preview Screenshot Testing
Official Documentation →

Functional Compose tests (Lesson 0021) assert that a node exists—not that it is readable, unclipped, and aligned at 2.0x font scale or in dark theme on a 840.dp tablet. Senior teams run deterministic JVM screenshot tests (Roborazzi + Robolectric, Paparazzi, or Android Studio Compose Preview Screenshot Testing) in CI on every PR.

🌱 Senior Tip: Why CI Must Run on One Deterministic Host OS

Font hinting and Skia anti-aliasing differ subtly between macOS and Linux! Golden PNGs recorded on a developer's MacBook can fail on a Linux GitHub Actions runner unless you either record goldens via CI/Docker Linux or configure a small perceptual diff threshold (or use Compose Preview Screenshot Testing's headless renderer).

❌ Junior Pitfall: Manual QA Matrix

Manually checking light/dark/RTL/200% font scale on an emulator before release, or skipping visual checks in CI.

✅ 2027 Senior Standard: Parameterized JVM Snapshots

Run verifyRoborazziDebug across a matrix of uiMode, fontScale, and WindowSizeClass in under 10 seconds on JVM.

data class SnapshotConfig(val theme: String, val fontScale: Float, val widthDp: Int)

fun main() {
    val matrix = listOf(
        SnapshotConfig("Light ", 1.0f, 411),
        SnapshotConfig("Dark  ", 1.0f, 411),
        SnapshotConfig("Light ", 2.0f, 411),
        SnapshotConfig("Dark  ", 1.0f, 840)
    )
    matrix.forEach { cfg ->
        println("[SNAPSHOT] PortfolioCard | ${cfg.theme} | fontScale=${cfg.fontScale}x | ${cfg.widthDp}dp  -> 0.00% diff (PASSED)")
    }
    println("[SUCCESS] 4 visual configurations verified on JVM in 420ms!")
}

Interactive Code Practice

Write a Roborazzi Compose test annotated with @RunWith(RobolectricTestRunner::class) and @GraphicsMode(GraphicsMode.Mode.NATIVE) that sets content inside composeRule.setContent and captures the root via composeRule.onRoot().captureRoboImage().

@RunWith(RobolectricTestRunner::class)
@GraphicsMode(GraphicsMode.Mode.NATIVE)
class PortfolioSnapshotTest {
    @get:Rule val composeRule = createComposeRule()

    @Test
    fun portfolioCard_matchesGolden() {
        composeRule.setContent { PortfolioCard() }
        composeRule.onRoot().captureRoboImage()
    }
}

Why this works: Robolectric's native Skia graphics mode renders Compose frames directly on the JVM so Roborazzi can diff pixels fast in CI.
