Production ViewModels & Lifecycle-Aware State Collection

Stop background battery drain by collecting StateFlow with collectAsStateWithLifecycle.

Recommended Primary Source
Google Android: Collecting flows in a lifecycle-aware manner
Official Documentation →

In Compose, developers often write val state by viewModel.uiState.collectAsState(). In production, this is a dangerous battery leak! collectAsState() continues collecting emissions from the ViewModel even when the app is in the background and the screen is turned off.

🌱 Junior Android Dev Mental Model: collectAsStateWithLifecycle()

Always use collectAsStateWithLifecycle() from androidx.lifecycle.compose! It internally uses Lifecycle.repeatOnLifecycle(Lifecycle.State.STARTED) to automatically pause flow collection when the app enters the background, and resume collection when the app returns to the foreground.

import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.lifecycle.compose.collectAsStateWithLifecycle

@Composable
fun MarketScreen(viewModel: MockMarketViewModel) {
    val uiState by viewModel.uiState.collectAsStateWithLifecycle()
}

Why this works: collectAsStateWithLifecycle is the gold-standard recommendation from the Android team to stop background resource leakage when UI is invisible.
