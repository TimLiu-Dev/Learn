ProGuard & R8 Full Mode Optimization

Shrink APK size by 40%+, eliminate unused code, and write safe keep rules with R8 Full Mode.

Recommended Primary Source
Google Android: Shrink, obfuscate, and optimize your app
Official Documentation →

Before shipping a production Android release build, the R8 compiler transforms your compiled JVM bytecode and all third-party library dependencies into optimized DEX bytecode in a single whole-program pass. With AGP 8+ and 9+, R8 Full Mode is enabled by default (isMinifyEnabled = true, isShrinkResources = true), routinely cutting APK download size by 40–65% and boosting runtime execution speed by up to 20%.

Under the Hood: R8's 4 Optimization Phases

  1. Tree Shaking (Dead Code Elimination): Starting from entry points declared in AndroidManifest.xml (Activities, Services, Receivers) and -keep rules, R8 builds a whole-program reachability graph and deletes every unreferenced class, method, and field—followed by resource shrinking (isShrinkResources = true) which strips unreferenced res/drawable and res/layout files.
  2. Whole-Program Optimization & Devirtualization: If an interface (PortfolioRepository) has only a single runtime implementation (OfflineFirstPortfolioRepository), R8 devirtualizes the interface call and inlines small methods directly into call sites, eliminating virtual dispatch overhead and shrinking Compose lambda wrapper classes!
  3. Identifier Minification (Obfuscation): Renames com.aether.feature.vault.BiometricVaultManager to a.b.c, drastically shrinking the DEX string constant pool and raising the bar against reverse engineering.
  4. Debug Line Number & Mapping File Generation (mapping.txt): Emits the exact translation map from a.b.c -> BiometricVaultManager so Play Console and Crashlytics can deobfuscate production stack traces.
🌱 Junior Android Dev Mental Model: Why Reflection Crashes R8

R8 traces static bytecode references. If a library (like legacy Gson or Java reflection Class.forName("...")) instantiates a DTO or reads its fields by string name at runtime, R8 thinks those fields are unused or renames val priceUsd to val a—causing JSON parsing to silently return null or 0.0 in release builds! Using Kotlinx Serialization (@Serializable) or KSP codegen generates static bytecode adapters that survive R8 without brittle reflection keep rules.

❌ Junior Anti-Pattern: Blanket -keep class com.aether.**

# proguard-rules.pro
# Developer hit a release crash and kept the entire app package!
# Destroys R8 tree-shaking, inlining, and obfuscation across the whole app!
-keep class com.aether.** { *; }

✅ 2027 Senior Production Standard: Consumer Rules + @Keep / @Serializable

// :core:network/build.gradle.kts
android {
    defaultConfig {
        // Travels inside the module's AAR automatically!
        consumerProguardFiles("consumer-rules.pro")
    }
}

// Inside :core:network DTO (Kotlinx Serialization needs zero reflection!)
@Serializable
data class NetworkAssetQuote(
    @SerialName("symbol") val symbol: String,
    @SerialName("price_usd") val priceUsd: Double
)

⚠️ Senior Interview Trap: R8 Full Mode vs. Compat Mode & -keepclassmembers

In R8 Full Mode (unlike legacy ProGuard compatibility mode), R8 aggressively removes default no-arg constructors if they aren't explicitly invoked in bytecode, and strips generic Signature attributes unless explicitly kept by the consumer rule (-keepattributes Signature). Furthermore, when writing a targeted ProGuard rule, always prefer -keepclassmembers or -keepnames over a blanket -keep: -keep forces the class and its members to remain in the APK even if the class is never instantiated anywhere in the app (Dead Code), whereas -keepclassmembers only preserves the fields/methods *if* the enclosing class is actually reachable!

data class ClassNode(
    val fqcn: String,
    val obfuscatedName: String,
    val isEntryPointOrKept: Boolean,
    val referencedBy: List<String>,
    val usesReflectionWithoutKeep: Boolean = false
)

class R8FullModeSimulator {
    fun runShrinkingAndMinification(programClasses: List<ClassNode>): List<String> {
        val log = mutableListOf<String>()
        val reachable = programClasses.filter { it.isEntryPointOrKept || it.referencedBy.isNotEmpty() }
        val stripped = programClasses - reachable.toSet()

        log += "[R8 TREE-SHAKING] Kept ${reachable.size} reachable classes, stripped ${stripped.size} dead classes: ${stripped.map { it.fqcn }}"
        for (cls in reachable) {
            val finalName = if (cls.isEntryPointOrKept) cls.fqcn else cls.obfuscatedName
            log += "[R8 MAPPING] ${cls.fqcn} -> $finalName"
            if (cls.usesReflectionWithoutKeep && !cls.isEntryPointOrKept) {
                log += "  ⚠️ [RUNTIME-HAZARD] ${cls.fqcn} uses reflection but was renamed to '$finalName'!"
            }
        }
        return log
    }
}

fun main() {
    val classes = listOf(
        ClassNode("com.aether.MainActivity", "a.a", isEntryPointOrKept = true, referencedBy = emptyList()),
        ClassNode("com.aether.feature.PortfolioViewModel", "b.a", isEntryPointOrKept = false, referencedBy = listOf("com.aether.MainActivity")),
        ClassNode("com.aether.network.LegacyGsonReflectiveDto", "c.a", isEntryPointOrKept = false, referencedBy = listOf("com.aether.feature.PortfolioViewModel"), usesReflectionWithoutKeep = true),
        ClassNode("com.aether.debug.UnusedMockHelper", "d.a", isEntryPointOrKept = false, referencedBy = emptyList())
    )

    R8FullModeSimulator().runShrinkingAndMinification(classes).forEach(::println)
}

class StackTraceDeobfuscator {
    fun retraceFrames(
        obfuscatedFrames: List<String>,
        mappingTable: Map<String, String>
    ): List<String> {
        return obfuscatedFrames.map { frame ->
            var restored = frame
            for ((obfuscated, original) in mappingTable) {
                restored = restored.replace(obfuscated, original)
            }
            restored
        }
    }
}

Why this works: R8 emits a deterministic mapping.txt file during every release build; replacing obfuscated identifiers (like 'b.a') with their original symbols restores human-readable stack traces in Crashlytics and Play Console.
