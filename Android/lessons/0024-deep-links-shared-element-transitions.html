Deep Links, Backstack & Shared Element Transitions

Integrate type-safe deep links and build cinematic shared element transitions with SharedTransitionLayout.

Recommended Primary Source
Google Android: Shared element transitions in Compose
Official Documentation →

Shared element transitions create continuity: an item card on a list screen smoothly expands into the header image of a detail screen. Compose provides SharedTransitionLayout and Modifier.sharedElement to animate bounds across screen transitions.

🌱 Junior Android Dev Mental Model: Shared Elements in Compose

To share an element between screens:

  1. Wrap your NavHost inside a SharedTransitionLayout { ... }.
  2. Pass AnimatedVisibilityScope to both screen composables.
  3. Add Modifier.sharedElement(rememberSharedContentState(key = "item_${id}"), animatedVisibilityScope) to the image on both screens. Compose handles the interpolation automatically!

fun buildSharedKey(assetId: String): String =

Why this works: Unique shared content keys tell Compose which element in the departing composable corresponds to the arriving element in the destination composable.
