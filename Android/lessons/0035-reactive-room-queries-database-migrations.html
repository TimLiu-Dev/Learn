Reactive Room Queries & Database Migrations

Stream database updates automatically with Flow<List<T>> and execute non-destructive database migrations.

Recommended Primary Source
Google Android: Understanding migrations with Room
Official Documentation →

Room queries that return Flow<List<T>> are reactive: whenever any table modified by the query is updated, Room automatically re-queries SQLite and emits the fresh list to all active collectors.

🌱 Junior Android Dev Mental Model: Never Use fallbackToDestructiveMigration() in Production!

During local prototyping, calling fallbackToDestructiveMigration() is common. But in production, this wipes all user data when upgrading your app version! Learn to write AutoMigrations or manual SQL Migration(from, to) objects to preserve user data.

import androidx.room.Dao
import androidx.room.Query
import kotlinx.coroutines.flow.Flow

class AssetEntity

@Dao
interface ReactiveAssetDao {
    @Query("SELECT * FROM assets ORDER BY symbol ASC")
    fun observeAllAssets(): Flow<List<AssetEntity>>
}

Why this works: Returning a Flow from a Room DAO creates an observable data stream that notifies collectors whenever rows in the queried table change.
