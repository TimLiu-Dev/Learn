fun isValidReleaseTag(tag: String): Boolean =
    Regex("^v[0-9]+\\.[0-9]+\\.[0-9]+$").matches(tag)

Why this works: Enforcing semantic version tag patterns (e.g. v1.0.0) in release automation workflows prevents accidental deployment triggers from dirty git tags.
