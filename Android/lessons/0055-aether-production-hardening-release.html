Aether: Production Hardening, Baseline Profiles & CI/CD

Bundle generated Baseline Profiles, tune ProGuard R8 keep rules, and automate release publishing via GitHub Actions.

Recommended Primary Source

Official Documentation →

Shipping the Aether capstone to production requires moving beyond debug builds into deterministic binary optimization and automated release pipelines. Three pillars separate hobbyist repositories from enterprise Android releases: Baseline Profiles (ahead-of-time ART compilation rules for critical user journeys), R8 Full Mode (whole-program shrinking, dead-code elimination, and class obfuscation), and immutable CI/CD release pipelines driven by semantic git tags in GitHub Actions.

Under the hood, Jetpack Compose ships as an unbundled library rather than part of the Android OS framework. Without a Baseline Profile, the Android Runtime (ART) must JIT-compile thousands of Compose slot-table and modifier functions on the device's first cold start, causing frame drops during initial rendering and scrolling. By executing a BaselineProfileRule on a Gradle Managed Device in CI, AGP extracts human-readable profile rules (baseline-prof.txt) and compiles them into binary assets/dexopt/baseline.prof inside your Android App Bundle (.aab). Play Store Cloud Profiles merge with your Baseline Profile so ART pre-compiles critical code paths into native machine instructions during app installation.

🌱 Junior Android Dev Mental Model: Why Release Builds Crash When Debug Works

R8 Full Mode (android.enableR8.fullMode=true, default in AGP 8+) aggressively strips classes, fields, and constructors that are not reachable via static call graphs—and renames remaining symbols to a.b.c. Any code relying on reflection or runtime metadata (such as unannotated Retrofit Gson DTOs or dynamic JNI lookups) will work in Debug but throw NullPointerException or SerializationException in Release! Prefer compile-time codegen (@Serializable with Kotlinx Serialization, KSP Room, and Hilt) so R8 can optimize without fragile reflection keep rules.

Senior Interview Trap & Production Edge Case

Trap: A candidate adds -keep class com.aether.** { *; } to fix a release crash. In a senior interview, this is an immediate red flag: wildcard keep rules disable shrinking and obfuscation across the entire app, bloating the AAB by megabytes and exposing proprietary business logic to reverse engineering.
Edge Case: When uploading a release AAB to Google Play from GitHub Actions, R8 renames stack trace symbols. If your CI pipeline does not archive and upload the generated mapping.txt (or bundle debug symbols for native .so libraries) to Play Console / Crashlytics, production stack traces become unreadable obfuscated gibberish.

data class ReleaseArtifactConfig(
    val versionTag: String,
    val baselineProfileIncluded: Boolean,
    val r8FullModeEnabled: Boolean,
    val mappingFileGenerated: Boolean,
    val wildcardKeepRulesCount: Int
)

sealed interface ReleaseGateVerdict {
    data class Approved(val tag: String, val estimatedStartupGainPct: Int) : ReleaseGateVerdict
    data class Rejected(val reasons: List<String>) : ReleaseGateVerdict
}

object AetherReleaseVerifier {
    private val semverRegex = Regex("^v\\d+\\.\\d+\\.\\d+$")

    fun evaluate(config: ReleaseArtifactConfig): ReleaseGateVerdict {
        val failures = buildList {
            if (!semverRegex.matches(config.versionTag)) add("Invalid semantic tag: ${config.versionTag}")
            if (!config.baselineProfileIncluded) add("Missing assets/dexopt/baseline.prof in AAB")
            if (!config.r8FullModeEnabled) add("R8 Full Mode must be enabled for production")
            if (!config.mappingFileGenerated) add("Missing R8 mapping.txt for Crashlytics/Play deobfuscation")
            if (config.wildcardKeepRulesCount > 0) add("Found ${config.wildcardKeepRulesCount} blanket -keep wildcard rules")
        }
        return if (failures.isEmpty()) {
            ReleaseGateVerdict.Approved(config.versionTag, estimatedStartupGainPct = 32)
        } else {
            ReleaseGateVerdict.Rejected(failures)
        }
    }
}

fun main() {
    val badBuild = ReleaseArtifactConfig("1.0-beta", false, true, false, wildcardKeepRulesCount = 2)
    println("[CI-GATE] Auditing dirty candidate: ${AetherReleaseVerifier.evaluate(badBuild)}")

    val prodBuild = ReleaseArtifactConfig("v1.2.0", true, true, true, wildcardKeepRulesCount = 0)
    when (val verdict = AetherReleaseVerifier.evaluate(prodBuild)) {
        is ReleaseGateVerdict.Approved -> {
            println("[CI-GATE] Release ${verdict.tag} APPROVED for Play Console Internal Track")
            println("[BASELINE-PROF] AOT profile bundled -> ~${verdict.estimatedStartupGainPct}% faster cold startup & frame time")
            println("[R8-FULL] Mapping file archived -> uploading release-aether-${verdict.tag}.aab")
        }
        is ReleaseGateVerdict.Rejected -> println("[CI-GATE] Blocked: ${verdict.reasons}")
    }
}

fun buildReleaseGateReport(
    tag: String,
    hasBaselineProf: Boolean,
    r8MappingBytes: Long,
    keepRules: List<String>
): Result<String> {
    val tagRegex = Regex("^v[0-9]+\\.[0-9]+\\.[0-9]+$")
    if (!tagRegex.matches(tag)) {
        return Result.failure(IllegalStateException("Invalid release tag: $tag"))
    }
    if (!hasBaselineProf || r8MappingBytes <= 0L) {
        return Result.failure(IllegalStateException("Missing Baseline Profile or R8 mapping file"))
    }
    if (keepRules.any { it.contains("com.aether.**") }) {
        return Result.failure(IllegalStateException("Blanket package keep rule detected"))
    }
    return Result.success("READY:$tag")
}

Why this works: Enforcing semantic tags, bundled Baseline Profiles, non-empty R8 mapping files, and zero blanket ProGuard wildcards in CI prevents unoptimized or un-deobfuscatable binaries from reaching the Play Store.

Baseline Profiles expire cryptographically after twenty-four hours and must only be generated on Google Play servers.
Enabling automaticGenerationDuringBuild in Gradle automatically disables R8 code shrinking and obfuscation inside the :app consumer module.
