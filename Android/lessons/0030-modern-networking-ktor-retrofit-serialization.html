Modern Networking with Ktor / Retrofit + kotlinx.serialization

Build reflection-free, lightning-fast REST clients using Ktor/Retrofit and Kotlinx Serialization.

Recommended Primary Source
Kotlin Official Documentation: kotlinx.serialization
Official Documentation →

In legacy Android, developers used Gson or Moshi for JSON parsing. Both relied on heavy runtime Java reflection, which slows down app startup, causes memory churn, and produces crashes when non-nullable fields are missing from the JSON payload. kotlinx.serialization generates serialization logic at compile time with zero reflection!

🌱 Junior Android Dev Mental Model: Reflection-Free Parsing

Annotate models with @Serializable. The Kotlin compiler creates a serializer directly in bytecode. If a JSON response is missing a required non-null field, kotlinx.serialization catches it immediately instead of silently populating a non-nullable Kotlin variable with a dangerous hidden null!

🎯 Reference Production Solution 
import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable

@Serializable
data class AssetDto(
    val id: String,
    val symbol: String,
    val priceUsd: Double,
    @SerialName("change_24h") val change24h: Float = 0f
)

Why this works: @SerialName decouples Kotlin naming conventions (camelCase) from backend JSON schema conventions (snake_case) without runtime reflection.
