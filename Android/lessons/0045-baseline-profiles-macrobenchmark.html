Baseline Profiles & Jetpack Macrobenchmark

Slash cold app startup times by 40%+ using ahead-of-time (AOT) Baseline Profiles and Macrobenchmark tests.

Recommended Primary Source
Google Android: Baseline Profiles Overview
Official Documentation →

When an Android app is installed, code is compiled Just-In-Time (JIT) by the Android Runtime (ART) as the user interacts with the app. On first launch ("cold start"), interpreting uncompiled DEX bytecode causes slow startup and stutter. Baseline Profiles bundle pre-compiled Ahead-Of-Time (AOT) machine code instructions with your APK, delivering 30% to 50% faster startup speeds on day one!

🌱 Junior Android Dev Mental Model: Macrobenchmark Generator

You generate baseline profiles by writing a Macrobenchmark test that automates common user journeys: launching the app, scrolling the feed, and opening details. Android Studio records which classes and methods executed and compiles them into a baseline-prof.txt bundle.
