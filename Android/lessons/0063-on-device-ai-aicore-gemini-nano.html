On-Device Generative AI: Android AICore, Gemini Nano & Hybrid Routing

Deliver zero-egress, offline-capable LLM summarization and rewriting with Android AICore, ML Kit GenAI APIs, and capability fallbacks.

Recommended Primary Source
Android Developers: Gemini Nano & ML Kit GenAI on Android AICore
Official Documentation →

Flagship Android 15, 16, and 17 devices ship with Android AICore—a privileged, isolated OS system service that manages hardware-accelerated on-device foundation models like Gemini Nano across mobile NPUs/TPUs without bundling multi-gigabyte model weights inside your APK! Accessed through the high-level ML Kit GenAI APIs (Summarization, Proofreading, Rewrite, Image Description) or the Google AI Edge SDK (GenerativeModel), on-device inference runs with zero cloud API cost, works 100% offline (e.g., on an airplane), and enforces strict local privacy so sensitive financial notes, medical records, or private messages never leave the user's device.

Because NPU hardware and AICore model cache states vary across the Android device ecosystem, a Senior Android Engineer never assumes Gemini Nano is warm and ready. Instead, you architect a 3-State Capability Router inspecting checkFeatureStatus() before inference: (1) AVAILABLE—stream tokens immediately via runInferenceStreaming() / generateContentStream(): Flow<String> so the user sees the first token in ~150ms; (2) DOWNLOADABLE—trigger AICore's background weight download with progress callbacks while serving an immediate cloud or extractive fallback (unless strict local-only privacy mode is active); and (3) UNAVAILABLE—gracefully route to your server-side Gemini Flash endpoint or deterministic fallback without crashing.

🌱 Junior Android Dev Mental Model: Why You Never Bundle LLM Weights Inside Your Base AAB

Even a quantized 4-bit 2B–3B parameter LLM weighs ~1.5 GB. Bundling it inside your base AAB blows past Google Play download limits, tanks install conversion, and duplicates gigabytes across apps! Android AICore solves this at the OS level: one system-managed Gemini Nano model + LoRA fine-tuning adapters are shared across all apps on the phone and updated silently via Google Play System Updates.

⚠️ Senior Interview Trap: Background Worker Calls & Mobile NPU Token Quotas

Trap: Invoking AICore / Gemini Nano from a background WorkManager job at 3:00 AM, or waiting 4 seconds for non-streaming generateContent() before updating UI! To protect battery and thermal headroom, Android AICore strictly blocks background processes from running NPU inference—only foreground user-visible flows (IMPORTANCE_FOREGROUND) are permitted.
Edge Case: Mobile NPUs enforce a tight per-request context token quota (typically 1,024–4,096 tokens). Passing a raw 50,000-character transaction log throws a quota exception! Always chunk or bound inputs (map-reduce summarization for long documents) and verify safety filter finish reasons (FinishReason.SAFETY) gracefully in UI state.

❌ Junior Anti-Pattern: Blind Blocking Inference & Unbounded Prompt

// 1. Crashes on devices where AICore is UNAVAILABLE or DOWNLOADABLE!
// 2. Passes 50,000-character raw log exceeding NPU context window!
suspend fun summarizeCrashLog(hugeLog: String): String {
    val response = geminiNanoModel.generateContent("Summarize: $hugeLog")
    return response.text.orEmpty()

✅ 2027 Senior Standard: Capability Probe + Token Budget + Streaming Flow

fun summarizeWithHybridRouter(rawText: String): Flow<String> = flow {
    val boundedPrompt = rawText.trim().take(4_000) // Respect NPU context window!
    when (aiCoreSummarizer.checkFeatureStatus()) {
        FeatureStatus.AVAILABLE ->
            aiCoreSummarizer.runInferenceStreaming(boundedPrompt).collect { emit(it) }
        FeatureStatus.DOWNLOADABLE -> {
            aiCoreSummarizer.downloadModelInBackground()
            emit(cloudFallbackGateway.summarize(boundedPrompt))
        }
        else -> emit(cloudFallbackGateway.summarize(boundedPrompt))
    }
}

enum class AiCoreStatus { AVAILABLE, DOWNLOADABLE, UNAVAILABLE }

data class InferenceAudit(
    val engineUsed: String,
    val promptCharsBounded: Int,
    val privacyTier: String,
    val outputPreview: String
)

class HybridSummarizationUseCase(private val maxLocalChars: Int = 4_000) {
    fun execute(
        status: AiCoreStatus,
        rawDocument: String,
        allowCloudFallback: Boolean
    ): InferenceAudit {
        val bounded = rawDocument.trim().take(maxLocalChars)
        return when (status) {
            AiCoreStatus.AVAILABLE -> InferenceAudit(
                engineUsed = "AICore:GeminiNano-OnDevice-NPU",
                promptCharsBounded = bounded.length,
                privacyTier = "ZERO_DATA_EGRESS (100% Local)",
                outputPreview = "[Local Stream] Key insight: ${bounded.take(36)}..."
            )
            AiCoreStatus.DOWNLOADABLE -> InferenceAudit(
                engineUsed = if (allowCloudFallback) "CloudFallback (AICore Download Queued)" else "DeferredUntilDownload",
                promptCharsBounded = bounded.length,
                privacyTier = if (allowCloudFallback) "CLOUD_TLS" else "LOCAL_PENDING",
                outputPreview = "[Queued AICore weight download] Summary ready."
            )
            AiCoreStatus.UNAVAILABLE -> InferenceAudit(
                engineUsed = if (allowCloudFallback) "CloudGeminiFlash" else "DeterministicExtractiveFallback",
                promptCharsBounded = bounded.length,
                privacyTier = if (allowCloudFallback) "CLOUD_TLS" else "LOCAL_DETERMINISTIC",
                outputPreview = "[Fallback] ${bounded.take(36)}..."
            )
        }
    }
}

fun main() {
    val router = HybridSummarizationUseCase(maxLocalChars = 4000)
    val doc = "Q4 Portfolio Rebalance: BTC allocation rose to 62%, exceeding our 50% target cap."

    println("[PIXEL-10-PRO]  ${router.execute(AiCoreStatus.AVAILABLE, doc, allowCloudFallback = true)}")
    println("[FRESH-DEVICE]  ${router.execute(AiCoreStatus.DOWNLOADABLE, doc, allowCloudFallback = true)}")
    println("[BUDGET-STRICT] ${router.execute(AiCoreStatus.UNAVAILABLE, doc, allowCloudFallback = false)}")
}

fun routeGenAiRequest(
    featureStatus: String,
    prompt: String,
    maxChars: Int,
    strictLocalPrivacyOnly: Boolean
): Result<String> {
    val safePrompt = prompt.trim().take(maxChars)
    if (safePrompt.isEmpty()) {
        return Result.failure(IllegalArgumentException("EMPTY_PROMPT"))
    }
    if (featureStatus == "AVAILABLE") {
        return Result.success("LOCAL_NANO:${safePrompt.length}")
    }
    if (strictLocalPrivacyOnly) {
        return Result.failure(IllegalStateException("LOCAL_AI_UNAVAILABLE"))
    }
    return Result.success("CLOUD_FALLBACK:${safePrompt.length}")
}

Why this works: Bounding prompt length protects the on-device NPU token quota, probing featureStatus == "AVAILABLE" prevents crashes on unsupported hardware, and honoring strictLocalPrivacyOnly prevents accidental cloud egress of private user data.
