Custom Canvas Drawing (DrawScope) & Gesture Handling

Draw high-performance financial charts and custom shapes with Canvas, DrawScope, and pointerInput gestures.

When off-the-shelf components aren't enough (like the interactive candlestick charts in our Aether capstone app), you drop into Canvas and DrawScope. DrawScope provides hardware-accelerated 2D drawing primitives (lines, paths, rects, arcs) executed directly by Skia on the GPU.

🌱 Junior Android Dev Mental Model: DrawScope & Pointer Input

DrawScope executes in Phase 3 (Draw Phase) without re-running Composition or Layout! For touch interaction (like dragging a scrubber along a chart), combine Canvas with Modifier.pointerInput(Unit) { detectDragGestures { ... } }.

🎯 Reference Production Solution 
import androidx.compose.foundation.Canvas
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun ColorIndicator(color: Color) {
    Canvas(modifier = Modifier.size(24.dp)) {
        drawCircle(color = color)
    }
}

Why this works: DrawScope provides direct drawing operations without allocating Android View nodes, minimizing memory footprint and delivering 120fps render performance.
