Pagination & Asynchronous Media: Paging 3 + Coil 3

Stream infinite datasets without OutOfMemory crashes using Paging 3, RemoteMediator, and Coil 3 image loading.

Recommended Primary Source
Google Android: Page and present data with Paging 3
Official Documentation →

Fetching 5,000 items from a REST API all at once destroys performance: it exhausts device memory, drains battery, and slows down UI rendering. Jetpack Paging 3 streams paginated data in small chunks with automatic pre-fetching, local database caching via RemoteMediator, and direct Compose integration via collectAsLazyPagingItems().

🌱 Junior Android Dev Mental Model: Coil 3 for Images

Coil 3 (Coroutine Image Loader) is the modern standard for image loading on Android. It integrates with Kotlin Coroutines and OkHttp, providing memory caching, disk caching, placeholder crossfades, and automatic cancellation when images scroll offscreen: AsyncImage(model = item.imageUrl, contentDescription = null).

🎯 Reference Production Solution 
fun <T> buildPageResult(items: List<T>, nextPage: Int): Any =
    LoadResult.Page(
        data = items,
        prevKey = null,
        nextKey = if (items.isEmpty()) null else nextPage
    )

Why this works: LoadResult.Page models a single chunk of data and tells the Paging runtime whether more items exist or if the pagination stream has terminated.
