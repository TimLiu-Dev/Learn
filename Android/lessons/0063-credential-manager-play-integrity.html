Unified Auth & Trust: Credential Manager & Play Integrity

Implement Passkeys with Credential Manager, retire deprecated EncryptedSharedPreferences, and enforce server-verified Play Integrity.

Recommended Primary Source
Android Developers: Credential Manager & Play Integrity API
Official Documentation →

Modern Android authentication and anti-abuse engineering rests on two unified pillars: Credential Manager (combining Passkeys, passwords, and federated sign-in into a single bottom sheet) and the Play Integrity API (giving your backend cryptographic proof that requests originate from an unmodified binary on a genuine device). Meanwhile, EncryptedSharedPreferences is deprecated in favor of DataStore + Tink AEAD / Android Keystore (covered in Lesson 0047 and Lesson 0036).

🌱 Senior Rule: Never Verify Integrity on the Client Alone

Checking if (!isDeviceRooted) inside Kotlin is trivial to bypass by patching the APK or hooking methods. With Play Integrity, the client requests an encrypted integrity token bound to a server-issued requestHash, sends it to your backend, and your backend decrypts/verifies the verdict with Google's servers before issuing a session token.

❌ Junior Pitfall: Fragmented & Client-Only Trust

Maintaining separate Google Sign-In + password SDKs, storing secrets in EncryptedSharedPreferences, and trusting client booleans.

✅ 2027 Senior Standard: Passkeys + Server Attestation

Single GetCredentialRequest supporting Passkeys + passwords, DataStore + Tink AEAD locally, and backend-verified Play Integrity verdicts.

data class IntegrityVerdict(val deviceIntegrity: Boolean, val appRecognized: Boolean)

fun canIssueSession(verdict: IntegrityVerdict): Boolean =
    verdict.deviceIntegrity && verdict.appRecognized

fun main() {
    println("[PASSKEY] Building GetCredentialRequest (GetPublicKeyCredentialOption + GetPasswordOption)...")
    println("[PASSKEY] User confirmed biometric prompt -> Signed WebAuthn assertion returned.")
    println("[INTEGRITY] Hashing action payload -> requestHash = sha256(login:nonce_991)")
    println("[INTEGRITY] Sending encrypted integrityToken + WebAuthn assertion to backend...")
    val verdict = IntegrityVerdict(deviceIntegrity = true, appRecognized = true)
    if (canIssueSession(verdict)) {
        println("[BACKEND] Play Integrity Verdict: MEETS_DEVICE_INTEGRITY + PLAY_RECOGNIZED")
        println("[SUCCESS] Short-lived OAuth2 session issued!")
    }
}

🎯 Reference Production Solution 
suspend fun signInWithPasskey(
    credentialManager: CredentialManager,
    context: Context,
    requestJson: String
): Credential {
    val option = GetPublicKeyCredentialOption(requestJson)
    val request = GetCredentialRequest.Builder()
        .addCredentialOption(option)
        .build()
    return credentialManager.getCredential(context, request).credential
}

Why this works: CredentialManager unifies system Passkeys, third-party password managers, and federated providers behind one coroutine-friendly API.
