Android Performance Profiling: CPU & Systrace

Eliminate 16ms frame drops using Android Studio Profiler, Perfetto traces, and CPU thread contention analysis.

On a 60Hz display, a frame must render within 16.6 milliseconds; on a modern 120Hz display, you have only 8.3ms! If the main thread is blocked for 50ms (e.g. parsing JSON or accessing Room disk), the UI freezes ("jank").

🌱 Junior Android Dev Mental Model: Trace Sections in Compose

Use androidx.tracing.trace("sectionName") { ... } to label critical code blocks. When you record a system trace in Perfetto or Android Studio Profiler, your custom trace sections appear right alongside Choreographer VSYNC slices, showing you down to the microsecond which function caused a frame drop!

Write a tracing helper function fun <T> traceSection(name: String, block: () -> T): T that calls MockTrace.beginSection(name), executes block() within a try block, and calls MockTrace.endSection() in a finally block.

🎯 Reference Production Solution 
object MockTrace {
    fun beginSection(name: String) {}
    fun endSection() {}
}

fun <T> traceSection(name: String, block: () -> T): T {
    MockTrace.beginSection(name)
    try {
        return block()
    } finally {
        MockTrace.endSection()
    }
}

Why this works: Guaranteed endSection cleanup in a finally block prevents unclosed trace slices from corrupting system trace visualization files.
