Aether: Real-Time Telemetry & Offline Cache Engine

Bridge live WebSocket market updates into Room database cache and schedule periodic WorkManager sync.

The core engine of Aether is its offline-first data synchronization engine in :core:data. It merges high-throughput WebSocket price telemetry, REST historical queries, and the local Room SQLite cache into a unified reactive stream.

🌱 Junior Android Dev Mental Model: Conflated Database Writes

If a WebSocket emits 100 prices per second, executing 100 database transactions per second will lock the SQLite database. In Aether, we buffer and conflate price updates using chunked() or sample(), writing batched updates to Room at controlled 500ms intervals!

🎯 Reference Production Solution 
interface MockDao {
    suspend fun upsertQuotes(items: List<String>)
}

suspend fun syncQuotes(remote: List<String>, dao: MockDao) {
    dao.upsertQuotes(remote)
}

Why this works: Writing network quotes directly into the local database cache ensures that the UI's reactive Room query emits the new state without coupling the UI directly to network listeners.
