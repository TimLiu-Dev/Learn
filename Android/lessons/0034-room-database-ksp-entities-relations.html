Room Database with KSP: Entities, DAOs & Relations

Model SQLite schemas with Room 2.7+ using KSP, 1:N relations, indices, and foreign keys.

Room is an abstraction layer over SQLite. It provides compile-time verification of SQL queries, eliminates raw SQL boilerplate, and integrates natively with Kotlin Coroutines and Flow.

🌱 Junior Android Dev Mental Model: @Transaction for Relations

When modeling 1-to-many or many-to-many relationships using @Relation (e.g. A Portfolio containing many AssetHolding items), Room executes two separate SQL queries under the hood. You must annotate the DAO method with @Transaction to ensure both queries run inside an atomic database transaction!

import androidx.room.Dao
import androidx.room.Upsert

class AssetEntity

@Dao
interface AssetDao {
    @Upsert
    suspend fun upsertAssets(items: List<AssetEntity>)
}

Why this works: @Upsert automatically determines whether to INSERT a new row or UPDATE an existing row based on primary key matching, eliminating manual conflict resolution code.
