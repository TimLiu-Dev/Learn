Compose Multiplatform (CMP) & On-Device AI (Gemini Nano)

Evaluate shared Compose UI via Compose Multiplatform and integrate privacy-first on-device GenAI with graceful capability fallbacks.

At the frontier of 2027 mobile architecture sit two transformative technologies: JetBrains Compose Multiplatform (CMP) and On-Device Generative AI via Android AICore (Gemini Nano / ML Kit GenAI APIs). While KMP shares business logic under native UIs, Compose Multiplatform extends your Jetpack Compose skillset (<code>@Composable</code>, <code>StateFlow</code>, <code>Modifier</code>, Material 3, multiplatform <code>composeResources</code>, and multiplatform Navigation) to render shared UI across Android, iOS (<code>ComposeUIViewController</code> backed by Skia/Metal), Desktop, and Web/Wasm. When a screen requires platform-native views on iOS—such as Apple <code>MKMapView</code>, <code>AVPlayer</code>, or <code>WKWebView</code>—CMP provides <code>UIKitView</code> / <code>UIKitViewController</code> inside <code>iosMain</code>, mirroring how <code>AndroidView</code> works on <code>androidMain</code>.

Meanwhile, flagship Android 15/16/17 devices ship with Android AICore—an isolated system service managing hardware-accelerated on-device foundation models like Gemini Nano without bundling multi-gigabyte model weights inside your APK! Accessible via the Google AI Edge SDK (<code>GenerativeModel</code>) or high-level ML Kit GenAI APIs (Summarization, Proofreading, Rewrite, Image Description), on-device inference runs with zero cloud token cost, works 100% offline, and guarantees sensitive user data (financial notes, health journals, private messages) never leaves the phone. However, because on-device NPU capabilities vary across hardware tiers, a Senior Android Engineer always architects an AI Capability Router (<code>checkFeatureStatus()</code>): handling <code>AVAILABLE</code> (instant local inference), <code>DOWNLOADABLE</code> (streaming model weight download progress via AICore), and <code>UNAVAILABLE</code> (gracefully falling back to a cloud Gemini API or deterministic summary).

🌱 Junior Android Dev Mental Model: Why You Never Bundle LLM Weights Inside Your Base AAB

Even a quantized 4-bit 2B-parameter LLM weighs ~1.2 GB to 2 GB. Bundling it in your base AAB exceeds Play Store size limits, destroys install conversion rates, and wastes 2 GB of storage per app! Android AICore solves this at the OS level: one system-managed Gemini Nano model is shared across all apps on the device and updated automatically via Google Play System Updates.

Senior Interview Trap & Production Edge Case

Trap: Calling <code>generativeModel.generateContent(prompt)</code> directly without checking <code>checkFeatureStatus()</code> or without streaming tokens via <code>generateContentStream(prompt): Flow<GenerateContentResponse></code>. Waiting 3.5 seconds for a full paragraph to finish generating before showing a single word makes the UI feel frozen; streaming tokens via <code>Flow</code> delivers the first token in ~150ms.
Edge Case: Android AICore enforces a strict per-prompt context token quota (typically 1,024 to 4,096 tokens on mobile NPUs) and rejects prompts when the app moves to the background (to prevent background thermal/battery abuse). Always chunk or truncate long documents before passing them to Gemini Nano, and restrict on-device GenAI calls to foreground user-initiated flows.

✅ 2027 Senior Standard: Capability Probe + Token Budget + Fallback

suspend fun summarizeWithHybridRouter(rawText: String): Flow<String> = flow {
    val boundedPrompt = rawText.take(4_000) // Respect mobile NPU context window!
    when (aiCoreSummarizer.checkFeatureStatus()) {
        FeatureStatus.AVAILABLE ->
            aiCoreSummarizer.runInferenceStreaming(boundedPrompt).collect { emit(it) }
        FeatureStatus.DOWNLOADABLE -> {
            aiCoreSummarizer.downloadModel()
            emit(cloudFallbackGateway.summarize(boundedPrompt))
        }
        else -> emit(cloudFallbackGateway.summarize(boundedPrompt))
    }
}

enum class AiCoreStatus { AVAILABLE, DOWNLOADABLE, UNAVAILABLE }

data class InferenceAudit(
    val engineUsed: String,
    val promptCharsBounded: Int,
    val privacyTier: String,
    val outputPreview: String
)

class HybridSummarizationUseCase(private val maxLocalChars: Int = 4_000) {
    fun execute(
        status: AiCoreStatus,
        rawDocument: String,
        allowCloudFallback: Boolean
    ): InferenceAudit {
        val bounded = rawDocument.trim().take(maxLocalChars)
        return when (status) {
            AiCoreStatus.AVAILABLE -> InferenceAudit(
                engineUsed = "AICore:GeminiNano-OnDevice-NPU",
                promptCharsBounded = bounded.length,
                privacyTier = "ZERO_DATA_EGRESS (100% Local)",
                outputPreview = "[Local Stream] Key insight: ${bounded.take(36)}..."
            )
            AiCoreStatus.DOWNLOADABLE -> InferenceAudit(
                engineUsed = if (allowCloudFallback) "CloudFallback (AICore Download Queued)" else "DeferredUntilDownload",
                promptCharsBounded = bounded.length,
                privacyTier = if (allowCloudFallback) "CLOUD_TLS" else "LOCAL_PENDING",
                outputPreview = "[Queued AICore weight download] Summary ready."
            )
            AiCoreStatus.UNAVAILABLE -> InferenceAudit(
                engineUsed = if (allowCloudFallback) "CloudGeminiFlash" else "DeterministicExtractiveFallback",
                promptCharsBounded = bounded.length,
                privacyTier = if (allowCloudFallback) "CLOUD_TLS" else "LOCAL_DETERMINISTIC",
                outputPreview = "[Fallback] ${bounded.take(36)}..."
            )
        }
    }
}

fun main() {
    val router = HybridSummarizationUseCase(maxLocalChars = 4000)
    val doc = "Q4 Portfolio Rebalance: BTC allocation rose to 62%, exceeding our 50% target cap."

    println("[PIXEL-10-PRO]  ${router.execute(AiCoreStatus.AVAILABLE, doc, allowCloudFallback = true)}")
    println("[FRESH-DEVICE]  ${router.execute(AiCoreStatus.DOWNLOADABLE, doc, allowCloudFallback = true)}")
    println("[BUDGET-STRICT] ${router.execute(AiCoreStatus.UNAVAILABLE, doc, allowCloudFallback = false)}")
}

fun routeGenAiRequest(
    featureStatus: String,
    prompt: String,
    maxChars: Int,
    strictLocalPrivacyOnly: Boolean
): Result<String> {
    val safePrompt = prompt.trim().take(maxChars)
    if (safePrompt.isEmpty()) {
        return Result.failure(IllegalArgumentException("EMPTY_PROMPT"))
    }
    if (featureStatus == "AVAILABLE") {
        return Result.success("LOCAL_NANO:${safePrompt.length}")
    }
    if (strictLocalPrivacyOnly) {
        return Result.failure(IllegalStateException("LOCAL_AI_UNAVAILABLE"))
    }
    return Result.success("CLOUD_FALLBACK:${safePrompt.length}")
}

Why this works: Bounding prompt length protects the on-device NPU token quota, probing <code>featureStatus == "AVAILABLE"</code> prevents crashes on unsupported hardware, and honoring <code>strictLocalPrivacyOnly</code> prevents accidental cloud egress of sensitive user notes.

On-device Gemini Nano models only execute during daytime hours because hardware NPU accelerators enforce timezones.
WorkManager CoroutineWorker classes cannot invoke any Kotlin coroutine suspend functions inside overridden doWork execution methods.
Android AICore services automatically delete the application SQLite database file whenever WorkManager returns Result.success status.
To protect battery and thermal limits, Android AICore restricts on-device NPU inference to IMPORTANCE_FOREGROUND processes.
