High-Performance Lists: LazyColumn & Item Animations

Render 10,000+ items smoothly with LazyColumn, stable keys, contentType optimization, and animateItem.

Recommended Primary Source
Google Android: Lazy lists and grids in Compose
Official Documentation →

Unlike Column which renders all children at once (crashing with OutOfMemory on large datasets), LazyColumn only composes and lays out items currently visible in the viewport.

🌱 Junior Android Dev Mental Model: Keys and ContentType
  • key = { item.id }: Essential! Without keys, when an item is inserted or deleted, Compose recomposes the entire list. With stable keys, Compose only moves nodes and preserves item scroll state.
  • contentType = { item.type }: Enables layout reuse across similar list item types (e.g. Header vs. Card vs. Ad).
  • Modifier.animateItem(): Modern Compose API for automatic spring animations when items are added, removed, or reordered!

fun main() {
    val items = listOf(
        CryptoItem("1", "BTC", 92450.0),
        CryptoItem("2", "ETH", 3420.0),
        CryptoItem("3", "SOL", 195.0)
    )
    println("[LAZY-LAYOUT] Viewport height: 800dp. Total items: 10,000")
    println("[RECYCLE] Composing visible window: index 0..2 (3 nodes allocated)")

    items.forEachIndexed { idx, item ->
        println("[NODE $idx] Bound Stable Key '${item.id}': ${item.symbol} -> $${item.price}")
    }

    println("[SUCCESS] LazyColumn recycled nodes offscreen. Frame render time: 2.1ms (Target < 16ms)")
}

Write a composable StockFeed(items: List<StockItem>) using LazyColumn. Inside items(items = items, key = { it.id }), render a Text showing item.symbol and item.price.

🎯 Reference Production Solution 
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable

data class StockItem(val id: String, val symbol: String, val price: Double)

@Composable
fun StockFeed(items: List<StockItem>) {
    LazyColumn {
        items(
            items = items,
            key = { it.id }
        ) { stock ->
            Text("${stock.symbol}: $${stock.price}")
        }
    }
}

Why this works: Providing stable unique keys allows LazyColumn to track items across insertions, deletions, and sort changes without resetting state or dropping frames.
