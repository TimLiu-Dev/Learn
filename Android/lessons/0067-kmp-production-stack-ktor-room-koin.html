KMP Production Stack: Ktor, Room KMP, DataStore & Koin

Assemble an offline-first multiplatform data layer using Ktor engines, Jetpack Room KMP with BundledSQLiteDriver, DataStore, and Koin DI.

Google officially ships Room KMP, DataStore KMP, ViewModel KMP, and Paging KMP. To share an offline-first data layer across Android and iOS, you swap Android-only libraries (Retrofit → Ktor Client; Dagger Hilt inside :shared → Koin or manual/Hilt-bridged factories) while keeping the exact same Single Source of Truth pattern from Lesson 0037.

🌱 Senior Stack Insight: BundledSQLiteDriver & Hilt Coexistence

1. Room KMP: Configure setDriver(BundledSQLiteDriver()) and setQueryCoroutineContext(Dispatchers.IO) so both Android and iOS run the exact same SQLite version.
2. DI Boundary: Hilt requires JVM/Dagger annotation processing, so it cannot live inside commonMain. Either use Koin across :shared, or expose a factory from :shared and bind its repositories in your Android app's Hilt @Module! See Reference Sheet 04.

❌ Junior Pitfall: Using Retrofit & Hilt in commonMain

Retrofit relies on JVM dynamic proxies (`Proxy.newProxyInstance`) and Hilt relies on Android/JVM Dagger—neither compiles for iOS.

✅ 2027 Senior Standard: Ktor + Room KMP + Koin

Ktor swaps OkHttp (Android) / Darwin (iOS) engines automatically; Room KMP shares @Dao + Flow queries across both platforms.

fun buildSharedDatabase(
    builder: RoomDatabase.Builder<AetherDatabase>
): AetherDatabase = builder
    .setDriver(BundledSQLiteDriver())
    .setQueryCoroutineContext(Dispatchers.IO)
    .build()

Why this works: BundledSQLiteDriver guarantees consistent SQLite behavior and FTS/JSON support across Android API levels and iOS without OS driver drift.
