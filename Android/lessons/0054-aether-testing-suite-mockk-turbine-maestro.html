Top-tier tech employers want to see robust automated tests. For the Aether portfolio project, we construct a 4-layer testing pyramid achieving 85%+ code coverage:

🌱 Junior Android Dev Mental Model: The Modern Testing Pyramid
  1. Unit Tests (MockK + Turbine): Tests ViewModels, UseCases, and Repositories on the JVM in milliseconds.
  2. Database Tests (Room in-memory): Verifies SQL queries and migrations without touching real disk files.
  3. Headless UI Tests (Robolectric + ComposeTestRule): Tests composable interactions without an emulator.
  4. End-to-End (Maestro): Declarative YAML scripts simulating user journeys (login, buy asset, view vault) across physical devices!

🎯 Reference Production Solution 
interface MockRepo { suspend fun fetchQuotes() }
fun coVerify(exactly: Int, block: suspend () -> Unit) {}

fun verifyFetchCalled(mockRepository: MockRepo) {
    coVerify(exactly = 1) {
        mockRepository.fetchQuotes()
    }
}

Why this works: coVerify is MockK's coroutine-aware verification method, asserting that suspending functions are invoked with expected parameters and call counts.
