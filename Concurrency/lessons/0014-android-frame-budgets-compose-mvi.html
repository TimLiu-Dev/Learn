Part 01 · First Principles

The 8.3ms Vsync Ceiling, MVI CAS Loops & Lifecycle Bounds

On modern 120Hz Android displays, Choreographer fires a vsync pulse every 8.33ms. Within that slice, the Main OS thread (Dispatchers.Main Looper) must process input events, run animations, recompose/measure/layout/draw, and submit a frame to RenderThread (Android App Performance: Slow Rendering). Senior Android engineers pair strict main-safety with atomic MVI state transitions and lifecycle-bounded collectors (Android Developers: Lifecycle-aware Coroutines).

120Hz Frame Budget & Binder IPC Jank

A 120Hz panel gives you half the time of 60Hz: 8.33ms vs. 16.67ms.

Work that "felt fine" at 10ms on a 60Hz test phone drops frames on 120Hz flagships. Even worse, synchronous Binder IPC calls (PackageManager, ConnectivityManager, cold SharedPreferences, ClipboardManager) cross process boundaries into system_server, blocking the Main thread for milliseconds—or triggering a 5-second Input Dispatch ANR under lock contention (Coroutines Best Practices).

MVI CAS Loops & Lifecycle Collection

_state.value = _state.value.copy(...) is a read-modify-write race condition.

When two coroutines on Dispatchers.Default or Dispatchers.IO finish concurrently, both can read the same snapshot, copy one field, and overwrite the sibling's update. MutableStateFlow.update { it.copy(...) } executes a lock-free Compare-And-Swap (CAS) retry loop so no field update is lost. On the UI side, repeatOnLifecycle(STARTED) cancels upstream collectors when backgrounded, avoiding launchWhenStarted's paused-producer resource leak.

Part 03 · Production Kotlin & Android

Junior Traps vs. Senior Patterns in Android & Compose

Production patterns from Android Coroutines Best Practices and Jetpack Compose Side-effects.

Pattern 1: Stale copy() Race vs. StateFlow.update { it.copy(...) }

✗ JUNIOR TRAP: Non-Atomic Read-Copy-Write
fun loadDashboard() {
    viewModelScope.launch(Dispatchers.IO) {
        val profile = repo.fetchProfile()
        _state.value = _state.value.copy(profile = profile)
    }
    viewModelScope.launch(Dispatchers.IO) {
        val feed = repo.fetchFeed()
        _state.value = _state.value.copy(feed = feed)
    }
}
// Both threads read stale _state.value -> one update lost!
✓ SENIOR PATTERN: Lock-Free CAS Loop
fun loadDashboard() {
    viewModelScope.launch {
        val profile = withContext(Dispatchers.IO) { repo.fetchProfile() }
        _state.update { current -> current.copy(profile = profile) }
    }
    viewModelScope.launch {
        val feed = withContext(Dispatchers.IO) { repo.fetchFeed() }
        _state.update { current -> current.copy(feed = feed) }
    }
}
// .update {} retries via CAS if current changed mid-lambda!

Pattern 2: launchWhenStarted Leak vs. repeatOnLifecycle / collectAsStateWithLifecycle

✗ JUNIOR TRAP: Paused Producer Leak
// Deprecated! Pauses collector on ON_STOP but leaves
// upstream GPS / Room / WebSocket Flow running in background:
lifecycleScope.launchWhenStarted {
    viewModel.locationFlow.collect { renderMap(it) }
}
// Or in Compose: collectAsState() stays active when stopped!
✓ SENIOR PATTERN: Lifecycle-Bounded Cancellation
// Views / Fragments: cancels upstream on ON_STOP, restarts on ON_START
viewLifecycleOwner.lifecycleScope.launch {
    viewLifecycleOwner.repeatOnLifecycle(Lifecycle.State.STARTED) {
        viewModel.uiState.collect { render(it) }
    }
}
// Jetpack Compose:
val state by viewModel.uiState.collectAsStateWithLifecycle()

Pattern 3: LaunchedEffect(key) vs. rememberCoroutineScope vs. snapshotFlow

✗ JUNIOR TRAP: Effect Restarts on Every Scroll Pixel
@Composable
fun FeedList(listState: LazyListState, vm: FeedViewModel) {
    // Re-launches coroutine on EVERY scroll frame!
    LaunchedEffect(listState.firstVisibleItemIndex) {
        vm.trackImpression(listState.firstVisibleItemIndex)
    }
    Button(onClick = { /* Cannot call LaunchedEffect here! */ }) { }
}
✓ SENIOR PATTERN: snapshotFlow + rememberCoroutineScope
@Composable
fun FeedList(listState: LazyListState, vm: FeedViewModel) {
    val scope = rememberCoroutineScope() // For UI event callbacks
    LaunchedEffect(listState) {
        snapshotFlow { listState.firstVisibleItemIndex }
            .distinctUntilChanged()
            .debounce(150)
            .collect { idx -> vm.trackImpression(idx) }
    }
    Button(onClick = { scope.launch { listState.animateScrollToItem(0) } }) { }
}

Pattern 4: Eliminating Binder IPC Jank on the Main Thread

✗ JUNIOR TRAP: Synchronous Binder in Composition
@Composable
fun VersionBadge(context: Context) {
    // Synchronous Binder IPC to system_server during composition!
    val info = context.packageManager.getPackageInfo(context.packageName, 0)
    Text("v${info.versionName}") // Can stall 5-20ms on cold cache!
}
✓ SENIOR PATTERN: Offload to IO & Cache in StateFlow
// Inject version/network metadata loaded once on Dispatchers.IO:
val versionName by produceState(initialValue = "") {
    value = withContext(Dispatchers.IO) {
        context.packageManager
            .getPackageInfo(context.packageName, 0).versionName.orEmpty()
    }
}
Text("v$versionName") // Main thread only reads in-memory State<String>
