Part 01 · End-to-End Architecture & Concurrency Invariants

System Architecture, Invariants & Failure Modes

LedgerFlow isolates fast, bounded database transactions from slow downstream webhook I/O so 10,000+ Virtual Threads can stay in flight without exhausting a 16-connection HikariCP pool or dropping events during pod rollouts.

HTTP Client (Idempotency-Key + TraceId) │ ▼ Spring MVC + Virtual Threads (JEP 491 · ScopedValue Trace) │ Resilience4j Bulkhead + RateLimiter ▼ @Transactional LedgerService (HikariCP Pool · Short TX · NO HTTP inside TX!) ├──► Account Table (@Version Optimistic CAS Debit/Credit) └──► Outbox Table (FOR UPDATE SKIP LOCKED Worker Claim) │ ▼ Kafka Outbox Relay + Webhook Dispatcher (Resilience4j CircuitBreaker + Graceful Drain)

Core Concurrency Invariants

  • Double-Entry Conservation: Every committed transfer decrements from_account and increments to_account inside one ACID transaction; total ledger balance is strictly invariant.
  • Exact Idempotency: Unique constraint on idempotency_key plus in-TX lookup guarantees duplicate client/network retries return the original receipt with zero second debit.
  • Zero HTTP Inside @Transactional: DB connections are acquired only for sub-5ms SQL work and released before any Kafka or webhook HTTP call runs.
  • Disjoint Worker Claims: Outbox pollers use PostgreSQL FOR UPDATE SKIP LOCKED across pods so no two workers process the same outbox row concurrently.
  • Clean Pod Drain: On SIGTERM, readiness fails (503), active TXs and webhooks finish within grace period, and HikariCP closes with 0 leaked connections.

Failure Modes Prevented

  • HikariCP Pool Exhaustion: Putting a 1.5s webhook inside @Transactional pins all 16 pool connections at 11 RPS and throws SQLTransientConnectionException.
  • Lost Updates on Hot Accounts: Unversioned read-modify-write overwrites concurrent payouts; @Version CAS + bounded jittered retry (or PESSIMISTIC_WRITE above conflict threshold) preserves balances.
  • Ghost Events / Missing Webhooks: Publishing to Kafka before DB commit leaks rolled-back events; publishing after commit without an Outbox loses events on pod crash.
  • Retry Storms & DLQ Poisoning: Retrying into a dead merchant endpoint burns outbox attempts; Resilience4j CircuitBreaker short-circuits before claiming rows.
  • Carrier Pinning & Context Leaks: JEP 491 eliminates synchronized pinning, while ScopedValue propagates traceId without mutable ThreadLocal pooling leaks.

TransferService.java ScopedValue Trace + Optimistic @Version Retry + Atomic Outbox (Zero HTTP inside TX) 
package com.ledgerflow.ledger;

import io.github.resilience4j.bulkhead.annotation.Bulkhead;
import io.github.resilience4j.ratelimiter.annotation.RateLimiter;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.dao.OptimisticLockingFailureException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.support.TransactionTemplate;

import java.time.Instant;
import java.util.UUID;
import java.util.concurrent.ThreadLocalRandom;

@Service
public class TransferService {

    public static final ScopedValue<String> TRACE_ID = ScopedValue.newInstance();
    private static final int MAX_VERSION_RETRIES = 4;

    private final TransactionTemplate txTemplate;
    private final AccountRepository accountRepo;
    private final IdempotencyRepository idempotencyRepo;
    private final OutboxRepository outboxRepo;

    public TransferService(
            TransactionTemplate txTemplate,
            AccountRepository accountRepo,
            IdempotencyRepository idempotencyRepo,
            OutboxRepository outboxRepo) {
        this.txTemplate = txTemplate;
        this.accountRepo = accountRepo;
        this.idempotencyRepo = idempotencyRepo;
        this.outboxRepo = outboxRepo;
    }

    @RateLimiter(name = "transferApi")
    @Bulkhead(name = "ledgerDb", type = Bulkhead.Type.SEMAPHORE)
    public TransferReceipt executeTransfer(TransferCommand cmd) {
        if (cmd.amountCents() <= 0) {
            throw new IllegalArgumentException("amountCents must be > 0");
        }
        String traceId = TRACE_ID.isBound() ? TRACE_ID.get() : UUID.randomUUID().toString();

        for (int attempt = 1; attempt <= MAX_VERSION_RETRIES; attempt++) {
            try {
                // Keep TransactionTemplate strictly around fast SQL (no RestClient/Kafka I/O inside!)
                return txTemplate.execute(status -> commitLedgerAndOutbox(cmd, traceId));
            } catch (OptimisticLockingFailureException ex) {
                if (attempt == MAX_VERSION_RETRIES) throw ex;
                jitteredBackoff(attempt);
            } catch (DataIntegrityViolationException ex) {
                // Concurrent duplicate idempotency_key lost the race to insert: fetch committed receipt
                return idempotencyRepo.findByKey(cmd.idempotencyKey())
                        .map(rec -> rec.toReceipt(true))
                        .orElseThrow(() -> ex);
            }
        }
        throw new IllegalStateException("Unreachable");
    }

    private TransferReceipt commitLedgerAndOutbox(TransferCommand cmd, String traceId) {
        var existing = idempotencyRepo.findByKey(cmd.idempotencyKey());
        if (existing.isPresent()) {
            return existing.get().toReceipt(true);
        }

        Account from = accountRepo.findById(cmd.fromAccountId()).orElseThrow();
        Account to = accountRepo.findById(cmd.toAccountId()).orElseThrow();

        if (from.getBalanceCents() < cmd.amountCents()) {
            throw new InsufficientFundsException(cmd.fromAccountId(), from.getBalanceCents());
        }

        from.debit(cmd.amountCents());   // Mutates @Version-managed JPA entity
        to.credit(cmd.amountCents());
        accountRepo.saveAndFlush(from);  // Forces immediate @Version CAS check before Outbox append
        accountRepo.saveAndFlush(to);

        UUID transferId = UUID.randomUUID();
        var receipt = new TransferReceipt(
                transferId, cmd.idempotencyKey(), from.getBalanceCents(), to.getBalanceCents(), false);

        idempotencyRepo.save(IdempotencyRecord.of(cmd.idempotencyKey(), receipt));
        outboxRepo.save(OutboxEvent.pending(
                transferId, cmd.idempotencyKey(), cmd.webhookUrl(), cmd.amountCents(), traceId, Instant.now()));

        return receipt;
    }

    private static void jitteredBackoff(int attempt) {
        long capMs = 8L * (1L << (attempt - 1));
        long sleepMs = ThreadLocalRandom.current().nextLong(1, capMs + 1);
        try {
            Thread.sleep(sleepMs); // Unmounts Virtual Thread cleanly (JEP 491)
        } catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
            throw new IllegalStateException("Interrupted during @Version retry", ie);
        }
    }
}
OutboxPoller.java PostgreSQL SKIP LOCKED Claim + Virtual Thread Fan-Out + Kafka Idempotent Relay 
package com.ledgerflow.outbox;

import io.github.resilience4j.circuitbreaker.CallNotPermittedException;
import org.springframework.kafka.core.KafkaTemplate;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;
import org.springframework.transaction.support.TransactionTemplate;

import java.time.Instant;
import java.util.List;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicBoolean;

@Component
public class OutboxPoller {

    private static final int MAX_ATTEMPTS = 5;
    private static final int BATCH_SIZE = 32;

    private final TransactionTemplate txTemplate;
    private final OutboxRepository outboxRepo;
    private final KafkaTemplate<String, String> kafkaTemplate;
    private final WebhookClient webhookClient;
    private final AtomicBoolean draining = new AtomicBoolean(false);

    public OutboxPoller(
            TransactionTemplate txTemplate,
            OutboxRepository outboxRepo,
            KafkaTemplate<String, String> kafkaTemplate,
            WebhookClient webhookClient) {
        this.txTemplate = txTemplate;
        this.outboxRepo = outboxRepo;
        this.kafkaTemplate = kafkaTemplate;
        this.webhookClient = webhookClient;
    }

    public void startDrain() {
        draining.set(true);
    }

    @Scheduled(fixedDelayString = "150")
    public void pollAndRelay() {
        if (draining.get() || !webhookClient.isCircuitPermitted()) {
            return; // Avoid burning attempts while shutting down or CB is OPEN
        }

        // Short TX #1: Claim disjoint batch across pods with PostgreSQL FOR UPDATE SKIP LOCKED
        List<OutboxEvent> claimed = txTemplate.execute(status ->
                outboxRepo.claimPendingBatchSkipLocked(BATCH_SIZE, Instant.now()));
        if (claimed == null || claimed.isEmpty()) return;

        // Fan out across Virtual Threads OUTSIDE any DB transaction
        try (var scope = Executors.newVirtualThreadPerTaskExecutor()) {
            for (OutboxEvent event : claimed) {
                scope.submit(() -> dispatchSingle(event));
            }
        }
    }

    private void dispatchSingle(OutboxEvent event) {
        try {
            // 1) Publish to Kafka with idempotent producer (enable.idempotence=true, acks=all)
            kafkaTemplate.send("ledger.transfers.v1", event.getIdempotencyKey(), event.toJson()).get();

            // 2) Deliver merchant webhook protected by Resilience4j CircuitBreaker + Bulkhead
            webhookClient.deliver(event);

            // Short TX #2: Mark DELIVERED
            txTemplate.executeWithoutResult(s -> outboxRepo.markDelivered(event.getId(), Instant.now()));
        } catch (CallNotPermittedException openEx) {
            // Circuit opened mid-batch: release lock WITHOUT incrementing attempts
            txTemplate.executeWithoutResult(s -> outboxRepo.releaseWithoutPenalty(event.getId()));
        } catch (Exception ex) {
            txTemplate.executeWithoutResult(s -> {
                if (event.getAttempts() >= MAX_ATTEMPTS) {
                    outboxRepo.markDeadLetter(event.getId(), ex.getMessage());
                } else {
                    outboxRepo.scheduleRetry(event.getId(), Instant.now().plusMillis(500L * event.getAttempts()));
                }
            });
        }
    }
}
WebhookClient.java Resilience4j Bulkhead + CircuitBreaker + RestClient Timeouts + SmartLifecycle Drain 
package com.ledgerflow.outbox;

import io.github.resilience4j.bulkhead.Bulkhead;
import io.github.resilience4j.bulkhead.BulkheadRegistry;
import io.github.resilience4j.circuitbreaker.CircuitBreaker;
import io.github.resilience4j.circuitbreaker.CircuitBreakerRegistry;
import org.springframework.context.SmartLifecycle;
import org.springframework.http.MediaType;
import org.springframework.http.client.JdkClientHttpRequestFactory;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestClient;

import java.net.http.HttpClient;
import java.time.Duration;
import java.util.concurrent.Phaser;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.TimeoutException;
import java.util.concurrent.atomic.AtomicBoolean;

@Component
public class WebhookClient implements SmartLifecycle {

    private final RestClient restClient;
    private final CircuitBreaker circuitBreaker;
    private final Bulkhead bulkhead;
    private final Phaser inFlight = new Phaser(1);
    private final AtomicBoolean running = new AtomicBoolean(false);

    public WebhookClient(CircuitBreakerRegistry cbRegistry, BulkheadRegistry bhRegistry) {
        HttpClient jdkClient = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(2))
                .build();
        var reqFactory = new JdkClientHttpRequestFactory(jdkClient);
        reqFactory.setReadTimeout(Duration.ofSeconds(3));

        this.restClient = RestClient.builder().requestFactory(reqFactory).build();
        this.circuitBreaker = cbRegistry.circuitBreaker("merchantWebhook");
        this.bulkhead = bhRegistry.bulkhead("merchantWebhook");
    }

    public boolean isCircuitPermitted() {
        return circuitBreaker.tryAcquirePermission();
    }

    public void deliver(OutboxEvent event) {
        if (!running.get()) {
            throw new IllegalStateException("WebhookClient is draining");
        }
        inFlight.register();
        try {
            // CircuitBreaker wraps Semaphore Bulkhead so OPEN circuit never consumes bulkhead slots
            circuitBreaker.executeRunnable(() ->
                bulkhead.executeRunnable(() ->
                    restClient.post()
                        .uri(event.getWebhookUrl())
                        .contentType(MediaType.APPLICATION_JSON)
                        .header("Idempotency-Key", event.getIdempotencyKey())
                        .header("X-Trace-Id", event.getTraceId())
                        .body(event.toJson())
                        .retrieve()
                        .toBodilessEntity()
                )
            );
        } finally {
            inFlight.arriveAndDeregister();
        }
    }

    @Override public void start() { running.set(true); }
    @Override public boolean isRunning() { return running.get(); }

    @Override
    public void stop(Runnable callback) {
        running.set(false);
        int phase = inFlight.arriveAndDeregister();
        Thread.ofVirtual().name("webhook-drain").start(() -> {
            try {
                if (phase >= 0) inFlight.awaitAdvanceInterruptibly(phase, 15, TimeUnit.SECONDS);
            } catch (InterruptedException | TimeoutException ignored) {
                Thread.currentThread().interrupt();
            } finally {
                callback.run();
            }
        });
    }
}
LedgerIntegrationTest.java Testcontainers (PostgreSQL + Kafka) + Virtual Thread Contention + Awaitility Verification 
package com.ledgerflow;

import com.ledgerflow.ledger.*;
import com.zaxxer.hikari.HikariDataSource;
import org.awaitility.Awaitility;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.test.context.DynamicPropertyRegistry;
import org.springframework.test.context.DynamicPropertySource;
import org.testcontainers.containers.PostgreSQLContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;
import org.testcontainers.kafka.KafkaContainer;

import java.time.Duration;
import java.util.concurrent.Executors;
import java.util.stream.IntStream;

import static org.assertj.core.api.Assertions.assertThat;

@SpringBootTest
@Testcontainers
class LedgerIntegrationTest {

    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16-alpine");

    @Container
    static KafkaContainer kafka = new KafkaContainer("apache/kafka:3.8.0");

    @DynamicPropertySource
    static void props(DynamicPropertyRegistry r) {
        r.add("spring.datasource.url", postgres::getJdbcUrl);
        r.add("spring.datasource.username", postgres::getUsername);
        r.add("spring.datasource.password", postgres::getPassword);
        r.add("spring.datasource.hikari.maximum-pool-size", () -> 10);
        r.add("spring.kafka.bootstrap-servers", kafka::getBootstrapServers);
        r.add("spring.threads.virtual.enabled", () -> true);
    }

    @Autowired TransferService transferService;
    @Autowired AccountRepository accountRepo;
    @Autowired OutboxRepository outboxRepo;
    @Autowired HikariDataSource hikariDataSource;

    @Test
    void concurrentTransfersPreserveBalanceAndRelayOutboxWithoutPoolLeak() {
        accountRepo.save(new Account("acct-a", 100_000L));
        accountRepo.save(new Account("merchant-1", 0L));

        // 50 Virtual Threads hammering hot merchant-1 + duplicate idempotency retries
        try (var exec = Executors.newVirtualThreadPerTaskExecutor()) {
            IntStream.range(0, 50).forEach(i -> exec.submit(() -> {
                String idemKey = "pay-" + (i % 25); // 25 unique transfers, each sent twice
                ScopedValue.where(TransferService.TRACE_ID, "trace-" + i)
                        .run(() -> transferService.executeTransfer(
                                new TransferCommand(idemKey, "acct-a", "merchant-1", 100L, "http://localhost:9999/hook")));
            }));
        }

        // Exact conservation: 25 unique * 100 = 2,500 cents moved
        assertThat(accountRepo.findById("acct-a").orElseThrow().getBalanceCents()).isEqualTo(97_500L);
        assertThat(accountRepo.findById("merchant-1").orElseThrow().getBalanceCents()).isEqualTo(2_500L);

        // Outbox eventually relays all 25 events cleanly via Awaitility
        Awaitility.await().atMost(Duration.ofSeconds(10)).untilAsserted(() -> {
            assertThat(outboxRepo.countByStatus("DELIVERED")).isEqualTo(25L);
            assertThat(hikariDataSource.getHikariPoolMXBean().getActiveConnections()).isZero();
        });
    }
}
