Part 01 · End-to-End Architecture & Concurrency Invariants

System Topology, Safety Invariants & Senior Benchmark Targets

Concurrency across a network boundary fails whenever backpressure, retries, leases, and shutdown are treated as isolated concerns. PulseQueue aligns client retry policy, gateway admission, worker scheduling, and storage CAS around five provable invariants. 

Android Client (SharedFlow Stream + Offline Command Queue)
   │  Idempotency-Key + Exponential Backoff + Full Jitter
   ▼
JVM API Gateway (Token-Bucket Rate Limiter -> HTTP 429 + Circuit Breaker)
   │
   ▼
PulseQueue Scheduler (Bounded Priority Queue + Worker Pool + Leases)
   └──► Durable Job Store (Fencing Token CAS + Dead-Letter Queue)

Exact Concurrency Invariants

Invariant Mechanism Formal Guarantee
I1 · Bounded Admission & Backpressure Token-Bucket (capacity, refillPerSec) + Bounded Priority Queue (maxQueueSize) + Circuit Breaker Memory stays strictly O(maxQueueSize); bursts above capacity fail fast with HTTP 429 + Retry-After instead of OOM or latency collapse.
I2 · Idempotent Enqueue Client-generated Idempotency-Key checked atomically before token/queue consumption Network drops or retry storms for an already-admitted key return HTTP 200 with the existing jobId and zero duplicate executions.
I3 · Monotonic Fencing Token CAS Strictly increasing fencingToken per granted lease + Storage CAS (token > lastSeenToken) A worker paused by stop-the-world GC or OS swap cannot overwrite or duplicate a terminal commit once a newer lease token has been issued or committed.
I4 · Lease Expiry & Bounded DLQ TTL-bounded leases (expiresAt = now + ttlMs) + maxAttempts cap Crashed workers trigger automatic re-queuing after TTL expiry; poison jobs exceeding maxAttempts move to the Dead-Letter Queue instead of starving healthy work.
I5 · Graceful Drain & Client Reconciliation SIGTERM → 503 ingress stop → bounded drain deadline → durable checkpoint → Android SharedFlow / Outbox sync Zero silent job loss on rolling deploys; Android UI reconciles completed vs. checkpointed commands off Dispatchers.Main while preserving 120fps.

GatewayRateLimiter.kt Token-Bucket Admission + Circuit Breaker + Idempotency Deduplication 
package com.pulsequeue.gateway

import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import java.util.concurrent.ConcurrentHashMap
import kotlin.math.ceil
import kotlin.math.min

sealed interface AdmissionResult {
    data class Accepted(val jobId: String, val deduplicated: Boolean) : AdmissionResult
    data class Rejected(val httpStatus: Int, val reason: String, val retryAfterMs: Long) : AdmissionResult
}

enum class BreakerState { CLOSED, OPEN, HALF_OPEN }

class CircuitBreaker(
    private val failureThreshold: Int = 5,
    private val openCooldownNanos: Long = 5_000_000_000L,
    private val nanoClock: () -> Long = System::nanoTime
) {
    private val mutex = Mutex()
    private var state = BreakerState.CLOSED
    private var consecutiveFailures = 0
    private var openedAtNanos = 0L

    suspend fun allowRequest(): Boolean = mutex.withLock {
        when (state) {
            BreakerState.CLOSED -> true
            BreakerState.OPEN -> {
                if (nanoClock() - openedAtNanos >= openCooldownNanos) {
                    state = BreakerState.HALF_OPEN
                    true
                } else false
            }
            BreakerState.HALF_OPEN -> true
        }
    }

    suspend fun recordSuccess() = mutex.withLock {
        consecutiveFailures = 0
        state = BreakerState.CLOSED
    }

    suspend fun recordFailure() = mutex.withLock {
        consecutiveFailures++
        if (state == BreakerState.HALF_OPEN || consecutiveFailures >= failureThreshold) {
            state = BreakerState.OPEN
            openedAtNanos = nanoClock()
        }
    }
}

class GatewayRateLimiter(
    private val capacity: Double,
    private val refillPerSecond: Double,
    private val maxQueueDepth: Int,
    private val breaker: CircuitBreaker,
    private val nanoClock: () -> Long = System::nanoTime
) {
    private val mutex = Mutex()
    private var tokens: Double = capacity
    private var lastRefillNanos: Long = nanoClock()
    private val idempotencyIndex = ConcurrentHashMap<String, String>()

    suspend fun admit(
        idempotencyKey: String,
        currentQueueDepth: Int,
        enqueue: suspend () -> String
    ): AdmissionResult {
        idempotencyIndex[idempotencyKey]?.let { existing ->
            return AdmissionResult.Accepted(existing, deduplicated = true)
        }
        if (!breaker.allowRequest()) {
            return AdmissionResult.Rejected(503, "CIRCUIT_OPEN", retryAfterMs = 1_000L)
        }
        val permitted = mutex.withLock {
            idempotencyIndex[idempotencyKey]?.let { return@admit AdmissionResult.Accepted(it, true) }
            val now = nanoClock()
            val elapsedSec = ((now - lastRefillNanos).coerceAtLeast(0L)) / 1_000_000_000.0
            tokens = min(capacity, tokens + elapsedSec * refillPerSecond)
            lastRefillNanos = now

            if (tokens < 1.0) {
                val waitMs = ceil(((1.0 - tokens) / refillPerSecond) * 1000.0).toLong().coerceAtLeast(10L)
                return@withLock AdmissionResult.Rejected(429, "RATE_LIMITED", waitMs)
            }
            if (currentQueueDepth >= maxQueueDepth) {
                return@withLock AdmissionResult.Rejected(429, "QUEUE_FULL", retryAfterMs = 100L)
            }
            tokens -= 1.0
            null
        }
        if (permitted != null) return permitted

        return try {
            val jobId = enqueue()
            val raced = idempotencyIndex.putIfAbsent(idempotencyKey, jobId)
            breaker.recordSuccess()
            AdmissionResult.Accepted(raced ?: jobId, deduplicated = raced != null)
        } catch (t: Throwable) {
            breaker.recordFailure()
            throw t
        }
    }
}
LeaseScheduler.kt Priority Scheduler + Monotonic Fencing Tokens + Storage CAS + DLQ 
package com.pulsequeue.scheduler

import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import java.util.PriorityQueue
import java.util.concurrent.atomic.AtomicLong

enum class JobStatus { QUEUED, LEASED, COMPLETED, DLQ }

data class LeaseGrant(
    val jobId: String,
    val workerId: String,
    val fencingToken: Long,
    val expiresAtMs: Long,
    val attempt: Int
)

private data class JobRecord(
    val jobId: String,
    val priority: Int,
    val seq: Long,
    var status: JobStatus = JobStatus.QUEUED,
    var attempts: Int = 0,
    var activeWorkerId: String? = null,
    var leaseExpiresAtMs: Long = 0L,
    var highestIssuedToken: Long = 0L,
    var lastCommittedToken: Long = 0L,
    var resultPayload: String? = null
)

sealed interface CommitResult {
    data class Committed(val jobId: String, val token: Long) : CommitResult
    data class Rejected(val reason: String, val lastToken: Long) : CommitResult
}

class LeaseScheduler(
    private val leaseTtlMs: Long = 5_000L,
    private val maxAttempts: Int = 3,
    private val clockMs: () -> Long = System::currentTimeMillis
) {
    private val mutex = Mutex()
    private val tokenGen = AtomicLong(0L)
    private val seqGen = AtomicLong(0L)
    private val jobs = LinkedHashMap<String, JobRecord>()
    private val readyQueue = PriorityQueue<JobRecord>(
        compareByDescending<JobRecord> { it.priority }.thenBy { it.seq }
    )

    suspend fun enqueue(jobId: String, priority: Int = 0): Boolean = mutex.withLock {
        if (jobs.containsKey(jobId)) return@withLock false
        val rec = JobRecord(jobId = jobId, priority = priority, seq = seqGen.incrementAndGet())
        jobs[jobId] = rec
        readyQueue.add(rec)
        true
    }

    suspend fun reclaimExpired(): List<String> = mutex.withLock {
        reclaimExpiredLocked(clockMs())
    }

    private fun reclaimExpiredLocked(now: Long): List<String> {
        val reclaimed = mutableListOf<String>()
        for (rec in jobs.values) {
            if (rec.status == JobStatus.LEASED && now >= rec.leaseExpiresAtMs) {
                rec.activeWorkerId = null
                if (rec.attempts >= maxAttempts) {
                    rec.status = JobStatus.DLQ
                } else {
                    rec.status = JobStatus.QUEUED
                    readyQueue.add(rec)
                }
                reclaimed += rec.jobId
            }
        }
        return reclaimed
    }

    suspend fun pollLease(workerId: String): LeaseGrant? = mutex.withLock {
        val now = clockMs()
        reclaimExpiredLocked(now)
        val next = readyQueue.poll() ?: return@withLock null
        val token = tokenGen.incrementAndGet()
        next.attempts += 1
        next.status = JobStatus.LEASED
        next.activeWorkerId = workerId
        next.leaseExpiresAtMs = now + leaseTtlMs
        next.highestIssuedToken = token
        LeaseGrant(next.jobId, workerId, token, next.leaseExpiresAtMs, next.attempts)
    }

    /** Storage-layer CAS: rejects any stale fencing token <= lastCommittedToken or superseded by a newer lease. */
    suspend fun commitWithFence(jobId: String, token: Long, result: String): CommitResult = mutex.withLock {
        val rec = jobs[jobId] ?: return@withLock CommitResult.Rejected("NOT_FOUND", 0L)
        if (rec.status == JobStatus.COMPLETED) {
            return@withLock CommitResult.Rejected("ALREADY_COMPLETED", rec.lastCommittedToken)
        }
        if (token <= rec.lastCommittedToken || token < rec.highestIssuedToken) {
            return@withLock CommitResult.Rejected("STALE_FENCING_TOKEN", rec.highestIssuedToken)
        }
        rec.lastCommittedToken = token
        rec.status = JobStatus.COMPLETED
        rec.activeWorkerId = null
        rec.resultPayload = result
        CommitResult.Committed(jobId, token)
    }
}
WorkerPool.kt Virtual-Thread / Coroutine Workers + Cooperative Cancellation + Graceful Drain 
package com.pulsequeue.worker

import com.pulsequeue.scheduler.LeaseGrant
import com.pulsequeue.scheduler.LeaseScheduler
import kotlinx.coroutines.*
import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.Executors
import java.util.concurrent.atomic.AtomicBoolean

class WorkerPool(
    private val scheduler: LeaseScheduler,
    private val concurrency: Int = 32,
    private val drainDeadlineMs: Long = 5_000L,
    private val executeJob: suspend (LeaseGrant) -> String
) {
    // JEP 444 Virtual Threads keep blocking JDBC/HTTP calls non-pinning when ReentrantLock/Mutex is used.
    private val virtualDispatcher = Executors.newVirtualThreadPerTaskExecutor().asCoroutineDispatcher()
    private val accepting = AtomicBoolean(true)
    private val inFlight = ConcurrentHashMap.newKeySet<Job>()
    private val poolScope = CoroutineScope(SupervisorJob() + virtualDispatcher)

    fun startWorkers() {
        repeat(concurrency) { idx ->
            val workerId = "worker-$idx"
            poolScope.launch {
                while (isActive && accepting.get()) {
                    val lease = scheduler.pollLease(workerId)
                    if (lease == null) {
                        delay(25L)
                        continue
                    }
                    val taskJob = launch {
                        val output = executeJob(lease)
                        scheduler.commitWithFence(lease.jobId, lease.fencingToken, output)
                    }
                    inFlight.add(taskJob)
                    try {
                        taskJob.join()
                    } finally {
                        inFlight.remove(taskJob)
                    }
                }
            }
        }
    }

    suspend fun shutdownGracefully(): Int {
        accepting.set(false)
        val drainedCleanly = withTimeoutOrNull(drainDeadlineMs) {
            inFlight.toList().joinAll()
            true
        } ?: false

        if (!drainedCleanly) {
            inFlight.forEach { it.cancel(CancellationException("Drain deadline exceeded")) }
        }
        poolScope.cancel()
        virtualDispatcher.close()
        // Unfinished jobs automatically expire via LeaseScheduler TTL or explicit checkpoint on restart.
        return scheduler.reclaimExpired().size
    }
}
PulseClientRepository.kt Android Offline Outbox + Full-Jitter Backoff + SharedFlow Live Stream 
package com.pulsequeue.android.data

import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.withContext
import java.util.UUID
import kotlin.math.min
import kotlin.random.Random

data class OutboxCommand(
    val idempotencyKey: String = UUID.randomUUID().toString(),
    val payload: String,
    val priority: Int = 1,
    val localState: String = "PENDING",
    val serverJobId: String? = null
)

sealed interface JobEvent {
    data class Admitted(val key: String, val jobId: String) : JobEvent
    data class Completed(val jobId: String, val result: String) : JobEvent
    data class RequeuedAfterDrain(val jobId: String) : JobEvent
}

interface OutboxDao {
    suspend fun insertPending(cmd: OutboxCommand)
    suspend fun markAdmitted(key: String, jobId: String)
    suspend fun markSynced(jobId: String)
    suspend fun pendingCommands(): List<OutboxCommand>
    fun observeOutbox(): Flow<List<OutboxCommand>>
}

class PulseClientRepository(
    private val dao: OutboxDao,
    private val api: PulseApi,
    private val ioDispatcher: CoroutineDispatcher,
    private val random: Random = Random.Default
) {
    private val _events = MutableSharedFlow<JobEvent>(
        replay = 1,
        extraBufferCapacity = 64,
        onBufferOverflow = kotlinx.coroutines.channels.BufferOverflow.DROP_OLDEST
    )
    val events: SharedFlow<JobEvent> = _events.asSharedFlow()

    fun observeQueue(): Flow<List<OutboxCommand>> = dao.observeOutbox()

    suspend fun submitOfflineFirst(payload: String, priority: Int = 1): String = withContext(ioDispatcher) {
        val cmd = OutboxCommand(payload = payload, priority = priority)
        dao.insertPending(cmd) // Persist locally first so process death never drops user intent
        cmd.idempotencyKey
    }

    suspend fun flushOutboxWithJitter(
        maxRetries: Int = 5,
        baseDelayMs: Long = 100L,
        capDelayMs: Long = 4_000L
    ) = withContext(ioDispatcher) {
        for (cmd in dao.pendingCommands()) {
            var attempt = 0
            while (attempt <= maxRetries) {
                when (val resp = api.submitJob(cmd.idempotencyKey, cmd.priority, cmd.payload)) {
                    is ApiResult.Success -> {
                        dao.markAdmitted(cmd.idempotencyKey, resp.jobId)
                        _events.tryEmit(JobEvent.Admitted(cmd.idempotencyKey, resp.jobId))
                        break
                    }
                    is ApiResult.Retryable -> {
                        attempt++
                        if (attempt > maxRetries) break
                        val expCap = min(capDelayMs, baseDelayMs * (1L shl attempt.coerceAtMost(10)))
                        val fullJitterMs = random.nextLong(0L, expCap + 1L)
                        val backoffMs = maxOf(resp.retryAfterMs, fullJitterMs)
                        delay(backoffMs)
                    }
                }
            }
        }
    }

    suspend fun reconcileFromServer(snapshot: Map<String, String>) = withContext(ioDispatcher) {
        for ((jobId, status) in snapshot) {
            if (status == "COMPLETED") {
                dao.markSynced(jobId)
                _events.tryEmit(JobEvent.Completed(jobId, status))
            } else if (status == "CHECKPOINTED") {
                _events.tryEmit(JobEvent.RequeuedAfterDrain(jobId))
            }
        }
    }
}
ChaosLoadTest.kt Deterministic Virtual-Time Chaos & Fencing Verification Suite 
package com.pulsequeue.test

import com.pulsequeue.gateway.*
import com.pulsequeue.scheduler.*
import kotlinx.coroutines.test.runTest
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertIs
import kotlin.test.assertTrue

class ChaosLoadTest {

    @Test
    fun `burst traffic sheds with 429 and idempotent retry returns original jobId`() = runTest {
        var fakeNanos = 0L
        val breaker = CircuitBreaker(nanoClock = { fakeNanos })
        val limiter = GatewayRateLimiter(
            capacity = 2.0,
            refillPerSecond = 1.0,
            maxQueueDepth = 5,
            breaker = breaker,
            nanoClock = { fakeNanos }
        )
        var seq = 0
        val r1 = limiter.admit("k-1", 0) { "job-${++seq}" }
        val r2 = limiter.admit("k-2", 1) { "job-${++seq}" }
        val r3 = limiter.admit("k-3", 2) { "job-${++seq}" }

        assertIs<AdmissionResult.Accepted>(r1)
        assertIs<AdmissionResult.Accepted>(r2)
        val rejected = assertIs<AdmissionResult.Rejected>(r3)
        assertEquals(429, rejected.httpStatus)

        // Retrying k-1 while bucket is empty MUST deduplicate and return job-1
        val retryK1 = limiter.admit("k-1", 2) { error("Should not enqueue duplicate") }
        val deduped = assertIs<AdmissionResult.Accepted>(retryK1)
        assertTrue(deduped.deduplicated)
        assertEquals("job-1", deduped.jobId)
    }

    @Test
    fun `gc paused worker with stale fencing token is rejected after lease reassignment`() = runTest {
        var nowMs = 1_000L
        val scheduler = LeaseScheduler(leaseTtlMs = 5_000L, maxAttempts = 3, clockMs = { nowMs })
        scheduler.enqueue("job-critical", priority = 10)

        val leaseA = scheduler.pollLease("worker-A")!!
        assertEquals(1L, leaseA.fencingToken)

        // Worker A freezes in stop-the-world GC past lease TTL
        nowMs += 6_000L
        val leaseB = scheduler.pollLease("worker-B")!!
        assertEquals(2L, leaseB.fencingToken)
        assertTrue(leaseB.fencingToken > leaseA.fencingToken)

        // Worker A wakes up and tries to commit before OR after Worker B
        val staleAttempt = scheduler.commitWithFence("job-critical", leaseA.fencingToken, "stale-A")
        assertIs<CommitResult.Rejected>(staleAttempt)

        val validCommit = scheduler.commitWithFence("job-critical", leaseB.fencingToken, "fresh-B")
        assertIs<CommitResult.Committed>(validCommit)
    }
}

CAPSTONE LAB 2.1 · GATEWAY BACKPRESSURE

PulseGateway: Token Bucket + Bounded Queue + Idempotency

Implement PulseGateway admission control returning 429 on empty bucket or full queue while deduplicating retries by idempotencyKey.

Not Run
• submit({ idempotencyKey, priority, payload }):
  1) If idempotencyKey was already admitted, return { status: 200, deduplicated: true, jobId, queueDepth } without consuming a token or adding to the queue (even if bucket is empty or queue is full!).
  2) Refill tokens from elapsed time: Math.min(capacity, tokens + (elapsedMs / 1000) * refillPerSec).
  3) If tokens < 1, return { status: 429, reason: 'RATE_LIMITED', retryAfterMs: Math.ceil(((1 - tokens) / refillPerSec) * 1000), queueDepth }.
  4) If queue.length >= maxQueueSize, return { status: 429, reason: 'QUEUE_FULL', retryAfterMs: 100, queueDepth } without deducting a token.
  5) Otherwise deduct 1 token, enqueue job, record key, and return { status: 202, deduplicated: false, jobId, queueDepth }.
• drainOne() removes and returns the highest-priority queued job (FIFO tie-break), or null if empty.

CAPSTONE LAB 2.2 · FENCED WORKER SCHEDULER

FencedWorkerScheduler: Priority Leases, Fencing Tokens & DLQ

Issue strictly monotonic fencing tokens per lease, reclaim expired leases on worker crashes, enforce storage CAS on commit, and route exhausted jobs to DLQ.

Not Run
• enqueue(jobId, priority = 0) adds job in 'QUEUED' status.
• reclaimExpired() checks all 'LEASED' jobs where now >= expiresAt: if attempts >= maxAttempts move to 'DLQ', else return to 'QUEUED'.
• pollLease(workerId) first reclaims expired leases, then leases the highest-priority 'QUEUED' job (FIFO tie-break) with a strictly increasing token, incrementing attempts and setting expiresAt = now + leaseTtlMs.
• commit(jobId, token, result) rejects with { ok: false, reason: 'ALREADY_COMPLETED' } if already completed, or { ok: false, reason: 'STALE_TOKEN' } if token <= lastCommittedToken or token < highestIssuedToken. Otherwise commits result and marks 'COMPLETED'.

CAPSTONE LAB 2.3 · GRACEFUL DRAIN & RECONCILIATION

GracefulDrainManager: Stop Ingress → Bounded Drain → Checkpoint & Reconcile

Coordinate server shutdown within drainDeadlineMs, checkpoint unfinished or queued jobs, and reconcile the Android client outbox cleanly.

Not Run
