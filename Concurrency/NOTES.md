# Teaching Notes & User Preferences

- **Career Target**: Senior Engineer level in concurrency by 2027 across **both**:
  - **Part 1**: Core OS/JMM + Kotlin Coroutines/Flow + Android Production + Distributed Systems (Lessons 01–18 + Capstones 01–02)
  - **Part 2**: Java 21–25+ & Spring Boot Senior Backend Concurrency (Lessons 21–26 + Capstone 03 `LedgerFlow`)
- **Preferred Lesson Format**:
  - Clean offline HTML pages in `./lessons/` sharing `./assets/concurrency-theme.css` and `./assets/lesson-engine.js`, linked from `master_plan.html`.
  - Every lesson includes:
    1. First-principles mental model + primary source citations
    2. Interactive in-browser visual simulator
    3. Side-by-side Junior Trap vs. Senior Production Kotlin/Java/Spring Boot examples
    4. 3 runnable JS/simulation code practice labs with live test assertions, 3 progressive hints, and final reference answer + Kotlin/Java equivalent
    5. 5 multiple-choice code quizzes with **balanced option lengths** (within ±2 words!) and explicit explanations for why the right choice works AND why every wrong choice fails
    6. Primary source recommendation + reminder to ask follow-up questions
