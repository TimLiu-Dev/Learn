Spring Boot Concurrency & Database Contention Cheat Sheet

Senior 2027 checklist for Virtual Threads, JEP 491, HikariCP sizing, @Async / @Transactional traps, WebFlux backpressure, Kafka consumers, and Resilience4j.

Virtual Threads & @Async Rules

  • spring.threads.virtual.enabled=true wires SimpleAsyncTaskExecutor with virtual threads.
  • JEP 491 (Java 24+): synchronized unmounts cleanly; JNI/native & class-init still pin carrier threads.
  • Never pool virtual threads—spawn 1 virtual thread per task; bound downstream concurrency with Semaphore / Bulkhead!
  • @Async & @Transactional use Spring AOP proxies: same-class self-invocation bypasses them!
  • Prefer immutable ScopedValue over mutable ThreadLocal for millions of virtual threads.

HikariCP & Transaction Hygiene

  • 10,000 virtual threads + maximum-pool-size=10 causes SQLTransientConnectionException if queries stall.
  • Never execute external HTTP calls inside @Transactional—it holds a scarce HikariCP connection open!
  • Use @Version optimistic locking for low-contention edits; PESSIMISTIC_WRITE / FOR UPDATE SKIP LOCKED for hot queues/ledgers.
  • Emit events via @TransactionalEventListener(AFTER_COMMIT) or a DB Outbox table, never raw @EventListener pre-commit.
