1. Self-Service IDP & Supply Chain Blueprint (Mobile + Microservices)

Platform Spec

Capstone 2B turns the infrastructure from Capstone 2A into a developer-friendly product. When an Android engineer opens a PR on the mobile app or a backend engineer updates a Spring Boot API, one reusable Golden Path pipeline handles security attestation, isolated PR previews, and zero-trust cluster admission automatically. 

[PR Opened / Push] --> [Golden Path workflow_call (OIDC Keyless)]
                              |--> Spring Boot: Build + Syft SBOM + Trivy Gate + Cosign Sign
                              |--> Android CI:  Test + Signed AAB + Firebase Preview Track
                              v
[Ephemeral Env: ns pr-<num>] <-- [Gateway API HTTPRoute: pr-<num>.preview.internal]
         |                                    |
  [External Secrets <- Vault]      [Kyverno Admission: verifyImages + non-root]
         |
[PR Merged / Closed] --> [Auto-Delete Namespace pr-<num> + Record DORA Metrics]
IDP Capability Implementation Mobile + Microservice Benefit
Golden Path CI Reusable workflow_call + GitHub OIDC Teams onboard a new service in 10 lines of YAML with zero static cloud secrets.
Ephemeral PR Previews pr-<num> namespace + shared Gateway API Android feature branches point directly at matching backend PR preview URLs before merging.
Supply Chain Gate Syft SBOM + Trivy + Sigstore Cosign + Kyverno Every production pod is proven non-root, CVE-checked, and cryptographically signed by CI.
Secrets & DORA External Secrets Operator + DORA telemetry Zero secrets in Git; tracks Deployment Frequency, Lead Time, CFR, and MTTR across teams.

  4. Document your DORA metrics baseline and Android + Spring Boot preview integration flow in your root README.md.
