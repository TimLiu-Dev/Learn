1. Mental Model Bridge: Offline Sync & Staged Rollouts to HA, DR & GPU Infra

Start Here

As an Android engineer, you never break old app versions when updating a backend JSON schema—you support both fields during a rollout. The exact same backward-compatibility discipline governs Expand-Contract Flyway database migrations, Multi-AZ PodDisruptionBudgets, documented RPO (max acceptable data loss) & RTO (max acceptable recovery time), and 2027 GPU inference pools.

Resilience / AI Concept Engineering Mechanism Concrete Production Target
Multi-AZ High Availability topologySpreadConstraints + PodDisruptionBudget + Multi-AZ RDS Survives an entire datacenter Availability Zone outage or node upgrade with zero dropped requests.
Disaster Recovery (RPO / RTO) Cross-region WAL/snapshot replication + automated restore drills RPO ≤ 15 min data loss, RTO ≤ 30 min full traffic restoration.
Zero-Downtime DB Migration Expand-Contract (add nullable column → dual-write → backfill → drop old) Old and new Spring Boot pods run side by side during canary rollouts without 500 SQL errors.
2027 AI-Infra Readiness Dedicated GPU NodePool taints + nvidia.com/gpu limits + slow startupProbe Prevents CPU pods from stealing expensive GPU nodes and prevents kubelet from killing 2-minute model weight loads.
RPO vs RTO in One Line
RPO (Recovery Point Objective) looks backward in time: "How many minutes of committed transactions can we afford to lose?" RTO (Recovery Time Objective) looks forward: "How many minutes until production traffic is healthy again?"

5 Mistakes That Break HA, DR & AI Workloads

  1. Untested backups: Discovering a corrupt pg_dump or missing KMS cross-region key during a real outage turns a 20-minute RTO into a 2-day crisis.
  2. Destructive Flyway migrations in one deploy: Running ALTER TABLE ... DROP COLUMN while old pods are still serving traffic causes immediate 500s.
  3. Zero PodDisruptionBudget: Cluster autoscaler or EKS node upgrades drain all replicas simultaneously.
  4. Un-tainted GPU nodes: Random CPU logging agents schedule onto $3/hour GPU nodes unless tainted with nvidia.com/gpu=true:NoSchedule.
  5. Missing startupProbe on LLM inference pods: Downloading or loading 14GB model weights takes minutes; without a generous startupProbe, kubelet's livenessProbe kills the pod in an infinite boot loop.
