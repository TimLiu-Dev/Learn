1. Mental Model Bridge: Android OkHttp Exceptions to Linux Tools

Start Here

Every HTTPS request from your Android app or Spring Boot RestClient travels through four layers in strict order: DNS lookup → TCP 3-way handshake → TLS 1.3 handshake → HTTP/2 request & response. Debug from the bottom up so you never waste hours restarting Spring Boot when the real culprit is an expired TLS certificate or a missing DNS record.

Android / Spring Symptom Network Layer Failing Linux Diagnostic Tool
UnknownHostException DNS resolution (A, AAAA, CNAME) dig api.example.com A +short
ConnectException: Connection refused or timeout TCP socket not listening or firewall blocking port ss -tlnp + cloud security group / ufw
SSLHandshakeException / cert mismatch TLS certificate SAN, chain, or expiry (notAfter) openssl s_client -connect host:443
HTTP 502 Bad Gateway or silent CI failure Reverse proxy upstream / HTTP status handling curl -s -i / curl -s -f (exit 22 on 4xx/5xx)
Loopback (127.0.0.1) vs All Interfaces (0.0.0.0)
If Spring Boot binds to 127.0.0.1:8080, a reverse proxy like Caddy on the same host can reach it, but remote Docker containers or external clients cannot. Binding to 0.0.0.0:8080 listens on every network interface—always pair it with firewall rules so only your proxy reaches port 8080.

5. Primary Sources, Pitfalls & Next Steps

Knowledge & Retention
Recommended Primary Source to Read
Read the Caddy Server Documentation (Automatic HTTPS & Reverse Proxy) alongside the GNU Bash Reference Manual for scripting health checks. Understanding how a reverse proxy terminates TLS and forwards headers (X-Forwarded-For, X-Forwarded-Proto) prevents most production gateway bugs.

5 Networking Mistakes That Cause Production Outages

  1. Calling curl without -f in CI: An HTTP 500 still exits 0 unless you pass -f (--fail), marking broken deploys as green.
  2. Exposing PostgreSQL (5432) or Redis (6379) on 0.0.0.0 without firewall rules: Automated scanners probe public IPs within minutes.
  3. Binding a container app to 127.0.0.1: Inside Docker, 127.0.0.1 refers only to that container—other containers cannot connect.
  4. Forgetting SAN entries on TLS certs: Modern OkHttp and browsers ignore CN alone and require Subject Alternative Name (DNS:) matches.
  5. Ignoring DNS TTL during migrations: High TTL values (e.g. 86400s) keep clients hitting the old server IP for up to 24 hours.
