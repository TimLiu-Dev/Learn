1. Full Architecture Flow: Commit to Production & Rollback

Capstone Blueprint

Unlike toy tutorials that stop at docker run, this delivery platform connects mobile release engineering, reproducible container builds, TLS edge routing, database migrations, and telemetry into one cohesive loop. 

[Developer Push / Tag v1.4.0]
        │
        ├──► [GitHub Actions: Spring Boot CI]
        │       ├─ ./gradlew test (Testcontainers PostgreSQL + Flyway)
        │       ├─ Multi-stage non-root Docker build (eclipse-temurin:21-jre-alpine)
        │       └─ Push immutable image ghcr.io/org/api:sha-<commit> via OIDC
        │
        ├──► [GitHub Actions: Android Release CI]
        │       ├─ ./gradlew lint testReleaseUnitTest
        │       ├─ Decode keystore (chmod 600 + trap cleanup) → bundleRelease (.aab)
        │       └─ Upload to Play Internal Track (Fastlane) / Firebase App Distribution
        │
        ▼
[Production Host / Cloud VM]
  Android App (OkHttp + W3C traceparent)
        │  HTTPS / TLS 1.3
        ▼
  Caddy Reverse Proxy (:80 / :443, HSTS, ACME certs)
        │  HTTP + readiness probe (/actuator/health/readiness)
        ├──► Blue Slot (:8081) ◄── Active or Rollback Target
        └──► Green Slot (:8082) ──► PostgreSQL 16 (:5432 private network) + Flyway
        │
        ▼  Scrape /actuator/prometheus + ECS JSON logs
  Prometheus + Grafana Dashboard (5xx ratio, p95 latency, HikariCP, JVM heap)
Platform Layer Chosen Tooling Failure Mode Prevented
Spring Boot CI Testcontainers + GHCR SHA tags + OIDC Eliminates H2 dialect drift, mutable :latest ambiguity, and long-lived registry keys.
Android Release CI Play App Signing + chmod 600 + Fastlane Protects signing keystores on shared runners and automates reproducible staged rollouts.
Edge & Runtime Caddy TLS + Graceful SIGTERM + Compose healthchecks Prevents HTTP 502s during deployments, expired certs, and DB connection race loops.
Observability W3C traceparent + Prometheus + jq Connects mobile client errors straight to failing Spring endpoints and DB bottlenecks.

Resume Bullet Templates (Copy & Customize With Your Metrics)

  • Full-Stack Delivery Platform: Architected an end-to-end delivery pipeline for a Spring Boot API and Android client using GitHub Actions, Testcontainers (PostgreSQL + Flyway), and immutable SHA-tagged containers pushed to GHCR via keyless OIDC.
  • Zero-Downtime Edge & TLS: Deployed containerized Spring Boot services behind Caddy automatic HTTPS (TLS 1.3, HSTS) with readiness-gated Blue/Green cutovers and graceful SIGTERM request draining, eliminating deployment 502 errors.
  • Mobile-to-Backend Observability: Instrumented Micrometer/Prometheus RED dashboards and propagated W3C traceparent headers from Android OkHttp interceptors into ECS JSON logs, cutting API incident triage time significantly.
  • Android Release Automation: Automated signed AAB builds and Play Console internal track publishing with Fastlane, Gradle build caching, and hardened chmod 600 ephemeral keystore cleanup traps.
