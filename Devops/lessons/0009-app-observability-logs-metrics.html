1. Mental Model Bridge: Logcat & Profiler to Production Telemetry

Start Here

Observability turns production into a queryable system. Instead of SSHing into servers to read unstructured text, your Android app and Spring Boot backend emit correlated signals that answer what broke, how widespread it is, and which call failed.

Android Studio / Client World Production Observability Pillar Operational Value
Android Logcat + Timber Structured ECS/JSON logs queried with jq Every log line is valid JSON with trace_id, level, endpoint, and status—never split multi-line stack traces.
Android Studio CPU / Memory Profiler Spring Boot Actuator + Micrometer → Prometheus & Grafana Tracks RED metrics (Rate, Errors, Duration), JVM heap pressure, and HikariCP DB pool exhaustion over time.
OkHttp Interceptor adding request IDs W3C traceparent header (00-<traceId>-<spanId>-01) Ties an Android Timber error directly to the exact Spring Boot controller and PostgreSQL query span.
Crashlytics ANR dashboard PromQL histogram_quantile(0.95, ...) & 5xx ratio alerts Quantifies p95/p99 tail latency and alerts on real user pain rather than noisy CPU spikes.
The Cardinality Rule for Metrics
Logs can hold unbounded IDs like user_id or order_id. Prometheus metric labels must stay low-cardinality (e.g., uri="/api/v1/orders/{id}", status="500")—never raw IDs or unmasked URLs—otherwise Prometheus memory explodes.

5 Observability Mistakes That Blind On-Call Engineers

  1. Exposing management.endpoints.web.exposure.include=*: Leaks /actuator/env secrets and lets attackers trigger /actuator/heapdump.
  2. Putting user_id or order_id in Prometheus labels: Causes cardinality explosions and OOM-kills Prometheus.
  3. Alerting on average latency instead of p95/p99: Averages hide 10-second tail timeouts suffered by 5% of mobile users.
  4. Writing plain-text multi-line stack traces: Breaks log shippers into dozens of unindexed fragments.
  5. Dropping traceparent at the mobile client or proxy: Severs the link between Android crash reports and backend SQL slowdowns.
