1. Mental Model Bridge: Gradle Variants to Kustomize, Helm & Argo CD

Start Here

In Android Gradle, you maintain one shared src/main codebase and layer staging or release buildTypes on top. In Spring Boot, you layer application-prod.yml over defaults. Kustomize and Helm bring that exact parameterization to Kubernetes YAML—and Argo CD continuously pulls those Git manifests into the cluster.

Android / Spring World Kubernetes GitOps Equivalent Why It Matters in Production
Gradle buildTypes / application-prod.yml Kustomize base/ + overlays/prod/ Templating-free YAML patching for your own microservices across dev, staging, and prod.
Adding a third-party SDK library via Maven/Gradle Helm Chart (Chart.yaml + values.yaml) Standard way to install and upgrade packaged dependencies like Prometheus, Ingress/Gateway controllers, and Cert-Manager.
CI script pushing kubectl apply from outside Argo CD Pull Reconciliation Cluster pulls desired state from Git; no external CI runner holds cluster-admin write access, and manual drift auto-heals.
Running Flyway DB migration before app boot Argo CD PreSync Hook + sync-wave: "-1" Ensures schema migrations succeed cleanly before the new Spring Boot Pods roll out.
Multi-flavor matrix build across environments Argo CD ApplicationSet Generates and manages dozens of environment Application objects from one declarative template.
CI vs CD Separation in GitOps
CI (GitHub Actions) builds, tests, scans, pushes the immutable container tag, and opens/merges a PR updating the tag in the GitOps config repo; CD (Argo CD) detects the Git commit and reconciles the cluster automatically.

5. Primary Sources, Pitfalls & Next Steps

Knowledge & Retention
Recommended Primary Source to Read

5 GitOps & Packaging Mistakes That Cause Outages

  1. Committing plaintext Secrets into Git: Encrypt secrets via External Secrets Operator, SealedSecrets, or KMS—never commit raw database passwords to your GitOps repo.
  2. Using mutable :latest image tags in GitOps manifests: Argo CD sees no Git diff when :latest changes in ECR/GHCR; always update immutable version/SHA tags.
  3. Enabling prune: true blindly on stateful namespaces without testing: Deleting a file in Git immediately deletes the corresponding Kubernetes resource (including PVCs if unprotected).
  4. Hot-editing live prod deployments with kubectl edit: With selfHeal: true, Argo CD overwrites manual edits within minutes—all changes belong in Git.
  5. Skipping PreSync hooks for breaking DB migrations: Rolling new Pods before schema columns exist triggers immediate startup crashes.

Authoring Helm Charts & Previewing Diffs Safely
When authoring reusable internal Helm charts (not just overriding values), keep templates DRY with _helpers.tpl, validate schemas with values.schema.json, and render locally before merge via helm template ... | kubeconform -strict or helm diff upgrade.
