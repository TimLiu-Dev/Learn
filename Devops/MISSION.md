# Mission: Junior Android Developer to Senior DevOps Engineer (2027)

## Why
Transition from a junior Android developer into a job-ready Senior DevOps Engineer by 2027, using a structured progression: first owning end-to-end build, release, and production operations for Android and Spring Boot applications, then mastering cloud infrastructure, automation SDKs, Kubernetes, GitOps, security, SRE, and real local cluster labs.

## Success looks like
- **Tier 1 (Senior App DevOps)**: Ship and operate a production Spring Boot API + Android CI/CD release pipeline end to end (Capstone Project 1 — Lesson 0011).
- **Tier 2 (Mid-Level DevOps & SRE)**: Provision and run a multi-environment Kubernetes cloud platform with Terraform, Python/Ansible/Packer automation, Argo CD, canary rollouts, OpenTelemetry/SLO alerting, and load/chaos testing (Capstone Project 2A — Lesson 0024).
- **Tier 3 (Senior DevOps / Platform Engineer)**: Build a self-service IDP with Golden Path CI, ephemeral PR environments, SLSA/SBOM/Cosign/Kyverno supply chain security, HA/DR/AI-Infra, and defend Senior System Design + local `kind` labs (Capstone Project 2B — Lesson 0025 + Lesson 0029).

## Constraints
- Lessons live in `./lessons/0001-<dash-case-name>.html` and include runnable in-browser code examples, interactive code practice (with automated checks, hints, and final answers), and multiple-choice quizzes explaining why every choice is right or wrong.
- `index.html` serves as the Master Plan & Curriculum Legend across Tier 1, Tier 2, and Tier 3.
- Every browser lab pairs with real terminal verification tools (`kind`, `docker`, `terraform`, `tflint`, `actionlint`, `kubeconform`, `k6`) documented in Lesson 0029 and the reference sheets.
- Starting baseline: junior Android / JVM familiarity; no prior production infrastructure assumption.

## Out of scope
- Proprietary single-vendor UI click-ops tutorials that cannot be reproduced as code (IaC/YAML/scripts).
- Low-level kernel C programming or building container runtimes from scratch.
