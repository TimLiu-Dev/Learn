SRE Burn Rates, Supply Chain Security & Platform IDP

Compressed operational formulas and command reference for SRE (0020), DevSecOps (0021), Platform IDP/FinOps (0022), and HA/DR & AI Infra (0023).

1. SLI / SLO & Multi-Window Burn Rates

SLI = (Good Events / Valid Events) * 100%
Error Budget = 1 - SLO   (e.g., 99.9% => 0.001)
Burn Rate = Observed Error Ratio / Error Budget

# PromQL Fast-Burn Page (2% budget in 1h => 14.4x)
slo:http_errors:ratio_rate1h > (14.4 * 0.001)

2. Incident Response & Postmortem Flow

# 1. Mitigate first: verify & roll back bad deploy
kubectl get pods -n prod
kubectl logs -n prod <pod> --tail=100
kubectl rollout undo deployment/checkout-api -n prod

# 2. Check active SLO error budget before re-deploying
jq -r '.remaining_pct' /etc/slo/budget.json
  • Roles: Incident Commander (IC), Operations Lead, Comms Lead.
  • Rule: Restore service before hunting root cause; freeze non-critical releases if budget = 0%.
  • Blameless Postmortem: Timeline, User Impact, Root Cause, Contributing Factors, Tracked Action Items (owner + due date).

3. Supply Chain: Syft, Trivy, Cosign & Kyverno

# Generate CycloneDX SBOM & gate HIGH/CRITICAL CVEs
syft ghcr.io/acme/api@sha256:... -o cyclonedx-json > sbom.json
trivy image --severity CRITICAL,HIGH --exit-code 1 ghcr.io/acme/api@sha256:...

# Keyless OIDC Sign & Verify (Sigstore Cosign)
cosign sign --yes ghcr.io/acme/api@sha256:...
cosign verify ghcr.io/acme/api@sha256:... \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp "^https://github.com/acme/"
  • Always sign and deploy by immutable @sha256:... digest, never mutable tags.
  • Kyverno ClusterPolicy enforces verifyImages + runAsNonRoot: true at admission time.
  • External Secrets Operator syncs Vault secrets into K8s Secret without plaintext secrets in Git.
