Linux Permissions, Signals & Safe Bash

Compressed operational essence of Lesson 0001. Keep this open during CI debugging and server triage.

1. Strict Bash Header

#!/usr/bin/env bash
set -euo pipefail
trap 'rm -f "$TMP_FILE"' EXIT
  • -e: abort on non-zero command exit code
  • -u: abort on unset variable expansion
  • -o pipefail: fail pipeline if any stage fails
  • Always double-quote variables: "$APK_PATH"

2. POSIX Permissions (chmod)

ModeSymbolicRule
600-rw-------Keystores, SSH keys, .env
644-rw-r--r--Configs, JARs, static files
755-rwxr-xr-xExecutable scripts & dirs
777-rwxrwxrwxNever use in production

3. Process Signals & Ports

ss -tlnp          # Find PID on port (Linux)
lsof -i :8080     # Find PID on port (macOS)
ps aux | grep jar # Inspect running JVM process
kill -15 <PID>    # SIGTERM: graceful shutdown
kill -9 <PID>     # SIGKILL: last resort only

Spring Boot drains active HTTP requests on SIGTERM when server.shutdown=graceful.

4. Streams, Exit Codes & Log Triage

./app.sh > app.log 2>&1   # Capture stdout + stderr
cmd_a && cmd_b            # Run cmd_b only on exit 0
cmd_a || echo "failed"    # Run fallback on non-zero

jq -r 'select(.level=="ERROR") | .path' app.jsonl \
  | sort | uniq -c | sort -rn
