GitHub Actions OIDC, Mobile Signing, Spring Boot & Edge TLS

Operational reference for 0006 (Actions/OIDC), 0007 (Android Signing), 0008 (Spring Boot CI), 0010 (Caddy/Nginx), and Capstone 1 (0011).

1. Hardened GitHub Actions OIDC Header

permissions:
  contents: read
  id-token: write      # Keyless OIDC token minting
  packages: write      # Scoped GHCR push

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true
  • Pin third-party actions to full 40-char commit SHAs.
  • Never interpolate untrusted github.event.pull_request.title directly inside run: (use env:).
  • Lint locally before pushing: actionlint

2. Android Keystore & Gradle CI Hygiene

trap 'rm -f "$KEYSTORE_PATH"' EXIT
echo "$KEYSTORE_B64" | base64 -d > "$KEYSTORE_PATH"
chmod 600 "$KEYSTORE_PATH"
./gradlew bundleRelease --no-daemon
# Archive app/build/outputs/mapping/release/mapping.txt
  • Set org.gradle.daemon=false and cap -Xmx4g in CI.
  • Always upload R8 mapping.txt alongside signed AABs for Play crash deobfuscation.

3. Spring Boot 12-Factor & Graceful Drain

server.shutdown=graceful
spring.lifecycle.timeout-per-shutdown-phase=30s
management.endpoints.web.exposure.include=health,prometheus
management.endpoint.health.probes.enabled=true
  • Use Testcontainers + @ServiceConnection instead of H2 fakes.
  • Build multi-arch images when on Apple Silicon: docker buildx build --platform linux/amd64,linux/arm64.

4. Caddy TLS Edge & Readiness Probe

api.example.com {
  header Strict-Transport-Security "max-age=31536000; includeSubDomains"
  reverse_proxy 127.0.0.1:8080 {
    health_uri /actuator/health/readiness
    health_interval 10s
  }
}
  • Never expose /actuator/prometheus or Postgres 5432 on public interfaces.
  • Validate before reload: caddy validate --config Caddyfile or nginx -t.
