Git Branching, SemVer & Network Debugging

Compressed operational reference for Lesson 0002 (Git & Releases) and Lesson 0003 (DNS, HTTP, Ports & TLS).

1. Trunk-Based Git Workflow

git switch -c feat/login-pkce   # Short-lived branch
git add -p                      # Stage hunks cleanly
git commit -m "feat(auth): add PKCE flow"
git fetch origin
git rebase origin/main          # Linear history before PR
git tag -a v1.4.0 -m "Release v1.4.0"
  • Never rewrite history (rebase) on shared main.
  • Configure shared hooks: git config core.hooksPath .githooks
  • Hooks must be executable: chmod 755 .githooks/commit-msg

2. Conventional Commits & SemVer

Commit PrefixSemVer BumpExample
fix:PATCH (0.0.+1)fix(api): guard null token
feat:MINOR (0.+1.0)feat(cart): add promo codes
feat!: / BREAKING CHANGE:MAJOR (+1.0.0)feat(auth)!: drop v1 keys
chore: / ci: / docs:None (0.0.0)ci(gradle): cache wrapper

Android versionCode formula: MAJOR * 10000 + MINOR * 100 + PATCH (e.g. 2.4.1 → 20401).

3. DNS & Socket Triage (dig, ss)

dig api.example.com A +short        # IPv4 address only
dig api.example.com CNAME +short    # Alias chain
dig @1.1.1.1 api.example.com        # Bypass local resolver
ss -tlnp                            # Listening TCP sockets + PID
  • 127.0.0.1 listener = reachable locally only; 0.0.0.0 = all interfaces.
  • NXDOMAIN = DNS record missing; check zone & CNAME target.

4. HTTP & TLS Inspection (curl, openssl)

curl -I https://api.example.com/health        # Headers only
curl -s -i https://api.example.com/health     # Status + body
curl -s -f https://api.example.com/health     # Exit 22 on 4xx/5xx
openssl s_client -connect api.example.com:443 # Inspect CN/SAN/notAfter

Use curl -s -f in CI smoke tests so HTTP 500 or 404 fails the pipeline instead of exiting 0.
