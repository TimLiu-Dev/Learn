Dockerfiles, Compose Stacks & GitHub Actions

Compressed reference for Lesson 0004 (Docker), Lesson 0005 (Compose), and Lesson 0006 (GitHub Actions & OIDC).

1. Multi-Stage Spring Boot Dockerfile

FROM gradle:8.10-jdk21-alpine AS build
WORKDIR /src
COPY build.gradle.kts settings.gradle.kts ./
RUN gradle dependencies --no-daemon
COPY src ./src
RUN gradle bootJar --no-daemon

FROM eclipse-temurin:21-jre-alpine
RUN addgroup -S app && adduser -S app -G app
WORKDIR /app
COPY --from=build /src/build/libs/*.jar app.jar
USER app
ENTRYPOINT ["java","-XX:MaxRAMPercentage=75.0","-jar","/app/app.jar"]
  • Pin explicit tags (never :latest).
  • Always use exec-form ENTRYPOINT ["..."] so SIGTERM reaches PID 1.

2. Production-Parity Compose Patterns

services:
  db:
    image: postgres:16-alpine
    volumes: [pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app"]
      interval: 5s
      retries: 5
  api:
    build: .
    depends_on:
      db:
        condition: service_healthy
    networks: [backend]
  • depends_on + condition: service_healthy prevents startup race failures.
  • Use named volumes for DB state; never bake secrets into Dockerfile.

3. GitHub Actions Hardening & OIDC

permissions:
  contents: read
  id-token: write   # Required for OIDC cloud auth

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true
  • Pin third-party actions to full 40-char commit SHAs.
  • Use id-token: write + OIDC instead of static AWS/GCP keys.
  • Cache Gradle with gradle/actions/setup-gradle.

4. Essential Container & CI Commands

docker build -t orders-api:1.4.0 .
docker compose up -d --build
docker compose logs -f api
docker compose exec db psql -U app
docker system df   # Check image/cache disk usage

Always include a .dockerignore excluding .git, build/, target/, and .env.
