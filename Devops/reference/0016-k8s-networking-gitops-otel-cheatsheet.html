Gateway API, NetworkPolicies, Argo CD, Canaries & PromQL

Operational syntax for 0016 (Networking/HPA), 0017 (Helm/Argo CD), 0018 (Canaries/Mesh), and 0019 (OTel/PromQL).

1. Gateway API Weighted Split & NetworkPolicy

backendRefs:
  - name: orders-stable
    port: 8080
    weight: 90
  - name: orders-canary
    port: 8080
    weight: 10
  • Gateway API splits infrastructure (Gateway) from app routing (HTTPRoute).
  • Once a NetworkPolicy selects a Pod, all unlisted ingress/egress traffic is denied.
  • Use Cilium/Hubble for L7 HTTP policies & live eBPF flow debugging.

2. Helm, Kustomize & Argo CD Sync

helm template my-app ./chart -f values-prod.yaml | kubeconform -strict
kustomize build overlays/prod | kubectl apply --dry-run=server -f -
  • syncPolicy.automated.prune: true removes deleted Git resources; selfHeal: true reverts manual kubectl edit drift.
  • Use argocd.argoproj.io/hook: PreSync for Flyway/Liquibase migrations before rollout.

3. PromQL Golden Signals & Recording Rules

# 5xx Error Ratio
sum(rate(http_server_requests_seconds_count{status=~"5.."}[5m]))
  / sum(rate(http_server_requests_seconds_count[5m]))

# p95 Latency (MUST keep 'le' label!)
histogram_quantile(0.95,
  sum by (le, service) (rate(http_server_requests_seconds_bucket[5m])))
  • Never put unbounded IDs (user_id, trace_id) into metric labels—keep them in logs/spans.
  • Always set memory_limiter first in OTel Collector processors:.

4. Autoscaling & Retry Safety

# Safe Retry + Timeout Discipline
timeout > (attempt_timeout * max_retries)
# Avoid multi-hop retry storms: retry only idempotent calls at edge.
  • HPA scales on CPU/memory/custom metrics; KEDA scales to/from zero on queue depth (SQS/Kafka).
  • Avoid rigid CPU limits on latency-sensitive JVM APIs if cgroups throttling spikes p99; size memory requests == limits.
