Terraform HCL, Remote State & Kubernetes Primitives

Operational reference companion for Lesson 0013 and Part 2 Kubernetes modules. Keep this open during IaC PR reviews, state triage, and cluster debugging.

1. Terraform Remote State & Provider Pinning

terraform {
  required_version = ">= 1.10.0"
  required_providers {
    aws = { source = "hashicorp/aws", version = "~> 5.80" }
  }
  backend "s3" {
    bucket       = "acme-prod-tfstate"
    key          = "platform/eks/terraform.tfstate"
    region       = "us-east-1"
    encrypt      = true
    use_lockfile = true
  }
}
  • Commit .terraform.lock.hcl (pins provider SHA256 hashes).
  • Never commit *.tfstate, .terraform/, or secret *.tfvars.
  • Use moved { from = ... to = ... } to rename without destroy/recreate.

2. Terraform CI & Drift CLI Workflow

terraform fmt -check -recursive  # Enforce canonical formatting
terraform init -backend=true     # Download providers & init backend
terraform validate               # Syntax + type check
terraform plan -out=tfplan       # Preview exact + / ~ / - diff
terraform apply tfplan           # Execute reviewed plan only
terraform plan -refresh-only     # Detect manual ClickOps drift
terraform state list             # Inspect tracked resource addresses

PRs run plan with OIDC (id-token: write); apply runs only after merge + environment approval.

3. Reusable HCL Modules & Outputs

module "vpc" {
  source      = "./modules/vpc"
  environment = var.environment
  cidr_block  = "10.20.0.0/16"
}

module "eks" {
  source     = "./modules/eks"
  vpc_id     = module.vpc.vpc_id
  subnet_ids = module.vpc.private_subnet_ids
}

output "cluster_endpoint" {
  value = module.eks.endpoint
}

Split state by blast radius (network/, cluster/, apps/) instead of one giant root module.

4. Kubernetes Workload Primitives

ObjectRole in Production
PodSmallest schedulable unit (1+ containers sharing network/IPC)
DeploymentManages stateless ReplicaSets & zero-downtime rolling updates
ServiceStable virtual IP (ClusterIP) & DNS across ephemeral Pod IPs
Gateway / HTTPRouteModern 2027 L7 ingress routing & TLS termination standard
ConfigMap / Secret12-factor non-sensitive config & externalized credentials
HPA / PDBHorizontal autoscaling & min-available eviction guardrails

5. Essential kubectl Triage Commands

kubectl get pods -A -o wide
kubectl describe pod <pod> -n prod       # Check Events & OOMKilled
kubectl logs <pod> -n prod --previous    # Inspect crashed container logs
kubectl get deploy,svc,httproute -n prod
kubectl rollout status deploy/orders-api -n prod
kubectl rollout undo deploy/orders-api -n prod

6. Production Guardrails Checklist

  • Always define readinessProbe (/actuator/health/readiness) and livenessProbe.
  • Set resources.requests and memory limits (keep JVM -XX:MaxRAMPercentage=75.0 to avoid exit 137).
  • Run containers with runAsNonRoot: true and immutable SHA image digests.
  • Configure terminationGracePeriodSeconds: 30 to match Spring Boot graceful shutdown.
