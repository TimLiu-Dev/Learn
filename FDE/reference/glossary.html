FDE & 2027 AI Systems Glossary

Shared terminology used across every lesson in this curriculum. Terms here represent concrete engineering mechanisms, delivery artifacts, and operational failure modes—not buzzwords.

Scope: Phases 1–7 & Capstone Print-ready: Optimized for quick desk review

Operating Model, Scoping & Delivery Craft

Term Definition & FDE Field Reality
FDE vs. Core SWE vs. SE Core SWEs build one generalized product for all tenants; Solutions/Sales Engineers run pre-sales demos and scoping; Forward Deployed Engineers embed post-sale to ship production integration, data, infra, and AI code inside messy customer stacks and upstream reusable primitives.
Dev vs. Delta Palantir's distinction between core Product Developers (building one general platform capability for many customers) and Forward Deployed Engineers / Deltas (shipping many custom capabilities for a single embedded customer). See Palantir Blog.
Discovery-First Scoping Investigating the real business workflow, data ownership, compliance boundaries, and user incentives before writing code or choosing a stack. Prevents building an immaculate solution to the wrong problem.
The Consulting Trap Failure mode where FDEs fork core software or write brittle one-off customer scripts that cannot be maintained or reused. Senior FDEs isolate customer variance into declarative configs/adapters and push recurring patterns upstream.
Phase-1 Thin Slice Smallest end-to-end production workflow (data source → transform → UI/action → verification metric) deliverable within days to validate real customer value and expose hidden constraints early.
SOW, UAT & Runbooks Commercial delivery contracts and handoff artifacts: a Statement of Work (SOW) locks bounded outcomes; User Acceptance Testing (UAT) proves customer sign-off against real data; Runbooks enable smooth transfer to client or core ops.

Enterprise Data & Reliability

Term Definition & FDE Field Reality
Dead-Letter Queue (DLQ) Quarantine store for malformed or unprocessable records so one dirty row (missing ID, invalid negative balance, broken encoding) never halts an entire customer batch sync. Must support safe inspection and replay after fixes.
Idempotency Property allowing an ingestion job, webhook handler, or agent tool call to be retried multiple times with the same key while producing the exact same final state—essential when customer networks flake mid-sync.
Webhook HMAC & Replay Guard Verifying cryptographic signatures (HMAC-SHA256) and timestamp tolerance windows on inbound SaaS events (Salesforce, ServiceNow, Stripe) so spoofed or replayed payloads cannot trigger unauthorized pipelines.
Entity Resolution Linking conflicting records across fragmented customer systems (e.g., Salesforce acct_91, SAP CUST-0091, and legacy CSVs) into one canonical identity inside an operational ontology.
Operational Ontology Typed semantic layer mapping raw tables and APIs into business objects (Order, Shipment, Facility), relationships, and permitted write actions—used by both human dashboards and AI agents.
Postgres Indexing & Keyset Paging Using tenant-first composite B-tree indexes, GIN indexes for JSONB/tsvector, HNSW indexes for pgvector, CREATE INDEX CONCURRENTLY (non-blocking), and deterministic (created_at, id) keyset cursors instead of collapsing OFFSET queries.
Practical FDE DSA Applied algorithms tested in FDE coding screens: cycle-safe BFS/DFS (nested Okta/ReBAC group expansion and entity graphs), Kahn's topological sort (DAG pipeline ordering and cycle detection), sliding-window rate limits, and interval merging.

Identity, Security, Infra & Observability

Term Definition & FDE Field Reality
OIDC / SAML SSO & SCIM Enterprise identity standards linking Okta/Entra ID login sessions (OIDC/SAML) and automated directory group provisioning/deprovisioning (SCIM) directly to tenant access policies.
PII Redaction Deterministic scrubbing or tokenization of personally identifiable information (emails, SSNs, phone numbers, keys) before logs, DLQ messages, telemetry, or external LLM prompts leave trusted security boundaries.
Permission-Aware Retrieval (ACL / ReBAC) Enforcing customer Access Control Lists (RBAC or graph ReBAC like OpenFGA/SpiceDB) before retrieved documents enter an LLM prompt or search result—preventing unauthorized employees from leaking confidential data.
Terraform & K8s Field Ops Using declarative Infrastructure-as-Code (Terraform) to replicate VPC/IAM setups across clients and debugging Kubernetes pods (CrashLoopBackOff, readiness probes, NetworkPolicy egress blocks) inside customer clusters.
VPC Subnets, PrivateLink & mTLS Isolating databases and AI inference inside non-routable private VPC subnets, routing model/warehouse calls over private cloud backbones (PrivateLink) instead of public internet, mounting corporate internal CA bundles, and binding workload IAM roles instead of static keys.
Air-Gapped / VPC & vLLM Running workloads inside customer networks with zero/restricted internet egress—requiring private container registries, PrivateLink endpoints, and self-hosted inference servers like vLLM.
OpenTelemetry GenAI Traces Propagating correlation IDs and GenAI semantic conventions (token usage, TTFT, model name, retrieval latency, tool spans) from gateway to model execution so on-site FDEs isolate failures in seconds.

2027 Applied AI, Agents & Evals

Term Definition & FDE Field Reality
Contextual Hybrid Search & RRF Prepending chunk-level document context (Contextual Retrieval) before indexing both exact lexical matching (BM25 for SKUs, error codes) and dense vectors, fused via Reciprocal Rank Fusion (RRF) and reranked.
Multimodal PDF / OCR Parsing Triaging native-text pages through fast layout parsers (preserving column reading order and tables) while routing scanned PDFs and complex financial grids to OCR/Vision-Language Models (VLMs) with page + bounding-box citation provenance.
Safe Text2SQL Translating natural-language questions into schema-grounded, read-only SQL queries bounded by tenant row filters, AST/query-cost validation, and explicit timeouts—critical for enterprise BI and data lakehouse FDEs.
Model Context Protocol (MCP) Open vertical standard separating Host, Client, and Server so AI models connect cleanly to enterprise data and tools via uniform Resources, Tools, and Prompts.
Agent2Agent (A2A) Protocol Open horizontal standard (Linux Foundation) enabling agents across distinct frameworks/vendors to discover capabilities via Agent Cards and delegate long-running tasks safely without exposing internal prompts or state.
MicroVM / gVisor Agent Sandboxing Isolating untrusted LLM-generated code or shell tool execution inside user-space kernels (gVisor) or hardware MicroVMs (Firecracker / E2B) instead of shared-kernel Docker containers (runc) to prevent host breakouts.
Evals & Error Analysis Application-specific automated test suites built from real failure logs (axial coding) combining deterministic checks, retrieval metrics (Recall@K, MRR), and calibrated LLM-as-judge gates in CI/CD.
Human-in-the-Loop (HITL) Explicit approval boundary pausing high-impact agent actions (refunds, database writes, external emails) until an authorized human operator confirms the structured payload.
