# Prior Knowledge: Junior Android Developer Baseline

The learner is currently a **Junior Android Developer** targeting a Senior FDE role in 2027.

- **Established baseline:** Familiar with typed OOP (Kotlin/Java), mobile client-side REST/JSON integration, basic asynchronous execution (coroutines/callbacks), client UI state, and Git workflows.
- **Implications for ZPD:** Do not re-teach introductory programming syntax (`if`, loops, classes, JSON concepts, HTTP basics). Instead, immediately target the *assumptions* that break when moving from first-party mobile clients to forward-deployed enterprise backend/data/AI engineering: strict DTO parsing crashing on dirty data, missing multi-tenant ACL isolation, rate-limited flaky customer APIs, probabilistic LLM outputs, and ambiguous customer discovery.
