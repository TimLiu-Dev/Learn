# Mission: Senior Forward Deployed Engineer (2027)

## Why
Transition from a Junior Android Developer to a job-ready **Senior Forward Deployed Engineer (FDE)** in 2027 — capable of embedding with enterprise customers, diagnosing ambiguous workflows, shipping production-grade full-stack and AI systems under strict security constraints, and landing a Senior FDE offer backed by an end-to-end portfolio project.

## Success looks like
- Conduct live customer discovery and problem decomposition (Palantir "Decomp" / Anthropic customer simulation) without jumping prematurely to tech stacks.
- Build resilient enterprise data pipelines (dirty schemas, rate limits, backoff, idempotent upserts, DLQs, SQL debugging) in Python and TypeScript.
- Architect and ship secure, permission-aware AI systems (hybrid RAG, deterministic guardrails, tool-call dispatchers, MCP servers, SSE streaming UIs).
- Design and run quantitative AI evaluation suites (error analysis, retrieval metrics, calibrated LLM-as-judge, red-team CI gates).
- Ship **AegisOps**, a deployed, end-to-end, resume-ready enterprise operations copilot and ingestion platform with ADRs, telemetry, and eval scorecards.
- Pass Senior FDE coding, system design, and behavioral/executive-communication interviews in 2027.

## Constraints
- Starting baseline: Junior Android Developer (comfortable with Kotlin/Java, OOP, REST/JSON, Git, basic async; new to enterprise backend, Postgres internals, cloud VPC networking, data pipelines, security/ACLs, AI systems, evals, and customer discovery).
- Learning format: Short, working-memory-friendly HTML lessons (`0000`–`0039`, 40 units split into **Track 1: Job-Ready Mid-Level FDE (`0000`–`0021` + Capstone I `AegisOps Core`)** and **Track 2: Senior FDE Mastery (`0022`–`0039` + Capstone II `AegisOps Enterprise`)**) anchored by `master-plan.html`, `./reference/`, and `./aegisops/`.
- Two-stage career strategy: Reach Mid-Level FDE readiness and start applying after Unit `0021` (`AegisOps Core`), then complete Track 2 (`0022`–`0039`, `AegisOps Enterprise`) for Senior FDE / Frontier AI Lab offers in 2027.
- Every lesson must include runnable in-browser code practice (with automated checks, progressive hints, and final answers) plus code quizzes explaining both correct and incorrect choices.

## Out of scope
- Deep ML model pre-training, CUDA kernel optimization, or academic ML research math.
- Pure mobile UI framework deep-dives (Jetpack Compose / Android SDK internals) except when bridging mental models.
- Generic LeetCode puzzle grinding unrelated to practical production integration coding.
