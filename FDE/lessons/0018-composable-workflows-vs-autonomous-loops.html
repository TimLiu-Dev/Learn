Composable Workflows vs. Autonomous Loops

Applying Anthropic's core production rule: start with deterministic routing, parallelization, and evaluator-optimizer workflows—reserving autonomous agent loops only for open-ended multi-step uncertainty.

Estimated Time: 25 min Prerequisites: 0016 Tangible Win: Build a Deterministic Classifier-Router & Evaluator-Optimizer Loop

1. Why Most "Agents" Should Actually Be State Machines

In Anthropic's "Building Effective Agents", the central lesson from production enterprise deployments is unmistakable: simplicity wins. Unbounded autonomous loops compound small errors exponentially (0.95^10 = 0.60), inflate token cost, and become nightmares to audit.

Before reaching for an open-ended agent loop, match the customer workflow to one of three deterministic patterns:

  1. Routing Workflow: A lightweight classifier sends billing disputes, shipment status checks, and general FAQ queries down separate, predictable code paths with tailored prompts/tools.
  2. Parallel Sectioning / Voting: Run compliance screening and customer draft generation concurrently so total wall-clock latency stays flat.
  3. Evaluator-Optimizer Loop: One prompt drafts a reply/SQL query; a separate evaluator scores it against explicit rubric checks and feeds targeted critique up to maxRounds, always keeping the best-scoring draft!
Rule for 2027 FDEs:
Use deterministic workflows whenever the execution graph is known upfront; use autonomous loops only when you cannot predict the number of steps ahead of time.
