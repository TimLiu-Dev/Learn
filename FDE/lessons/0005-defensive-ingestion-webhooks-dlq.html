Defensive Ingestion, Webhook HMACs & DLQ Replay

Securing inbound customer webhooks with cryptographic HMAC-SHA256 verification and replay windows—then building Dead-Letter Queues that safely quarantine and replay failed events without poison-pill loops.

Estimated Time: 25 min Prerequisites: 0001, 0003 Tangible Win: Build Webhook HMAC Guard & Bounded DLQ Replay Engine

1. Real-Time Customer Webhooks Are Untrusted Public Endpoints

Unlike polling a trusted first-party mobile endpoint, enterprise webhook receivers (receiving Salesforce, Stripe, GitHub, or ERP events) sit on the public internet or a customer DMZ. Any attacker who guesses your URL can POST forged order-paid events unless you enforce HMAC signature & replay validation (GitHub Webhook Security; Stripe Signatures).

Four production rules govern every FDE webhook & DLQ boundary:

  1. Hash Raw Bytes, Never Re-Serialized JSON: Parsing and calling JSON.stringify() alters whitespace and key order, breaking valid HMAC digests.
  2. Constant-Time Comparison: Standard === exits on the first mismatched byte, leaking timing side-channels. Always compare fixed-length digests in constant time (hmac.compare_digest / crypto.timingSafeEqual).
  3. Enforce Replay Windows: Include the signed timestamp inside the MAC payload (t + "." + rawBody) and reject events older than ~5 minutes (300s).
  4. Bounded DLQ Replay: Quarantined messages in a DLQ need a strict maxAttempts cap so one permanently corrupt poison-pill message never loops forever.
Common Field Gotcha:
FastAPI/Express middleware that parses JSON before signature middleware runs is the #1 reason customer webhook integrations mysteriously fail HMAC checks on Day 1.

2. Annotated Code: Python FastAPI Webhook Verifier

Python / FastAPI Raw-Body HMAC-SHA256 + Timestamp Replay Guard 
import hmac, hashlib, time
from fastapi import Request, HTTPException

async def verify_customer_webhook(request: Request, secret: bytes, max_skew_sec: int = 300):
    raw_body = await request.body()  # Exact bytes BEFORE json.loads()!
    ts_str = request.headers.get("X-Webhook-Timestamp", "")
    sig = request.headers.get("X-Webhook-Signature", "")
    if not ts_str.isdigit() or abs(int(time.time()) - int(ts_str)) > max_skew_sec:
        raise HTTPException(status_code=401, detail="Stale or missing timestamp")

    signed_payload = f"{ts_str}.".encode() + raw_body
    expected = "v1=" + hmac.new(secret, signed_payload, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, sig):  # Constant-time equality
        raise HTTPException(status_code=401, detail="Invalid HMAC signature")
    return raw_body
