1. What Is a Forward Deployed Engineer (In Plain English)?

Normally, a software company builds one standardized product and tells customers: "Read our docs and integrate yourself." That works for simple SaaS apps, but breaks completely when an airline, bank, hospital, or defense agency wants AI or data platforms running on 20-year-old legacy databases behind strict security walls.

A Forward Deployed Engineer (FDE)—a role pioneered at Palantir ("Deltas") and now heavily hired by OpenAI, Anthropic, Databricks, Anduril, and Scale AI—is a full-stack/AI software engineer embedded directly with the customer to ship working production software inside their messy reality (The Pragmatic Engineer; roadmap.sh FDE).

A typical week splits across four concrete activities—not PowerPoint decks:

  1. Discovery (15–20%): Shadowing real operators and security teams to find where data actually lives and what decision matters.
  2. Integration & Data Plumbing (40%): Writing Python/TypeScript connectors, SQL pipelines, SSO/ACL rules, and Docker/K8s configs against ugly customer systems.
  3. Applied AI & Operator UI (25%): Shipping RAG/agent workflows, React/TS dashboards, and eval suites proving accuracy before rollout.
  4. Product Feedback Loop (15%): Turning recurring customer hacks into reusable config adapters or core product RFCs (a16z Services-Led Growth).

2. Junior Android → FDE Prerequisites Bridge

You do not start from zero. Kotlin/Java OOP, Retrofit REST calls, JSON parsing, Git branches, and coroutines already put you ahead of non-coding consultants. Before Lesson 0001, you only need reading/writing comfort across four backend tools—all exercised in the labs below:

Rosetta Stone Kotlin (Android) → TypeScript & Python FDE Equivalents 
// Kotlin (What you already know):
data class Order(val id: String, val amount: Double)
val paid = orders.filter { it.amount > 0 }.map { it.id }

// TypeScript / JavaScript (Used in our instant browser workbench & React UIs):
type Order = { id: string; amount: number };
const paid = orders.filter((o) => o.amount > 0).map((o) => o.id);

# Python (Used in FastAPI, ingestion workers, & AI evals):
paid = [o["id"] for o in orders if o["amount"] > 0]

-- SQL (Used in Postgres/DuckDB debugging & Text2SQL):
SELECT id FROM orders WHERE amount > 0;
