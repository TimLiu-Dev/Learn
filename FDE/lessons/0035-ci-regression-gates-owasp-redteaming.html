1. Indirect Prompt Injection: The Hidden Enterprise Attack

According to OWASP LLM01 (Prompt Injection), the sneakiest production attack doesn't come from your logged-in employee—it arrives inside untrusted external tickets, emails, or web pages your RAG pipeline indexes! For example, an attacker emails support:

Defend at three layers simultaneously:

  1. Structural Data Isolation + Sanitization: Strip/quarantine suspicious override phrases and active Markdown external-image beacons (![...](https://...)) that exfiltrate context via browser GET requests when rendered!
  2. Deterministic Tool & CSP Boundaries: Enforce server-side tool allowlists (Unit 0031) and browser Content-Security-Policy blocking arbitrary third-party markdown image loads.
  3. CI Release Blocking: Every PR touching prompts, models, or retrievers runs your golden + red-team eval suite; if recallAt5, faithfulness, redTeamPassRate, or p95LatencyMs regresses past limits, CI blocks merge!
