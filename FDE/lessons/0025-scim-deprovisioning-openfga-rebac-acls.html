1. Why Flat RBAC Fails Fortune-500 Document & AI Platforms

Saying a banker has role "analyst" doesn't tell you which of 50,000 deal rooms they are cleared to read! Senior FDEs implement two enterprise mechanisms (OpenFGA Docs; ReBAC ACLs):

  1. SCIM Authoritative Active & Group Checks: Even if a terminated employee holds a valid 1-hour JWT, SCIM webhooks mark active = false and update authoritative group memberships immediately in Redis/Postgres.
  2. Relationship-Based Access Control (ReBAC): Express permissions as graph tuples (user:alice#member@group:deal_team → viewer@folder:q4 → parent@doc:nda_99) and traverse them with cycle guards!

2. Annotated Code: OpenFGA Authorization Model Pattern

OpenFGA DSL Modeling Transitive Group & Folder Inheritance 
type user
type group
  relations
    define member: [user, group#member]
type folder
  relations
    define viewer: [user, group#member]
type document
  relations
    define parent: [folder]
    define viewer: [user, group#member] or viewer from parent
