Track 2 · Phase 6 · Unit 0022 · Product Flywheel & Rapid PoCs

48h AI-Assisted PoCs → Reusable Primitives

How Senior FDEs leverage AI coding speed to ship 48-hour customer proofs-of-concept, then "absorb pain and excrete product" instead of drowning in forked consulting scripts.

Estimated Time: 25 min Prerequisites: 0001, 0003 Tangible Win: Build an Adapter Registry & Upstream Candidate Detector

1. "Absorb Pain, Excrete Product" — Not Client Forks

Andreessen Horowitz characterizes successful FDE organizations as "trading margin for moat" (a16z: Services-Led Growth). In 2027, AI coding assistants let a single FDE scaffold a custom customer PoC in 48 hours. That speed is a superpower—and a trap.

If five FDEs each vibe-code separate bespoke connectors for five enterprise logos, your company wakes up with five forked repos, zero shared tests, and consulting-agency economics (Pragmatic Engineer). Senior FDEs enforce a strict Two-Phase Hardening Rule:

  1. Isolate customer variance declaratively: Put column aliases, formatting quirks, and routing flags in a validated config registry—never in if (customer === "Acme") branches inside core modules.
  2. Notice repeating field pain across 2+ clients: When two deployments both hack around the same limitation (e.g., SFTP zip extraction or SAP date formats), extract it into a tested core primitive and file an upstream RFC.
Rule of Three (Modified for FDEs):
Client 1: ship fast in config/adapter.
Client 2: spot the shared shape.
Client 3: it belongs in the core platform, never copied again.

2. Annotated Code: Branch-Per-Client Trap vs. Adapter Registry

TypeScript Replacing Client If-Else Spaghetti with Validated Declarative Adapters 
// ANTI-PATTERN: Consulting trap inside shared pipeline
function transform(row, tenant) {
  if (tenant === "acme") return { id: row.erp_ref, amt: Number(row.usd) };
  if (tenant === "globex") return { id: row.inv_no, amt: row.cents / 100 }; // Unscalable!
}

// SENIOR FDE PATTERN: Core stays immutable; tenant descriptors declare transforms
const registry = new AdapterRegistry();
registry.register("acme", { fieldMap: { id: "erp_ref", rawAmt: "usd" }, amountScale: 1 });
registry.register("globex", { fieldMap: { id: "inv_no", rawAmt: "cents" }, amountScale: 0.01 });
