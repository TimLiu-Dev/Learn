Rate Limiters, Backoff & Legacy SaaS Connectors

Syncing 50,000+ records from brittle Salesforce, ServiceNow, and legacy ERP APIs without triggering HTTP 429 bans, thundering-herd retries, or concurrent OAuth token refresh races.

Estimated Time: 25 min Prerequisites: 0003 Tangible Win: Build a Token-Bucket Rate Limiter & Circuit-Breaker Syncer

1. Why Naive Coroutine/Async Loops Get Banned On-Site

On Android, one user triggers one Retrofit call at a time. In an FDE data pipeline, your worker might fire 200 concurrent requests against a customer's 15-year-old SAP or ServiceNow gateway. Without client-side throttling, you either crash their ERP or hit daily API quota bans before lunch.

This is also one of the most common live-coding tests in FDE interviews. Master these four primitives:

  1. Token Bucket Limiter: Enforces average sustained QPS while allowing bounded short bursts—refilling tokens continuously by elapsed time.
  2. Full-Jitter Exponential Backoff: Computes random(0, min(maxMs, baseMs * 2^attempt)) so 50 workers hitting a 429 don't wake up at the exact same millisecond (thundering herd). Always honor Retry-After headers first!
  3. Circuit Breaker: Trips OPEN after consecutive 5xx/network failures so you stop hammering a downed customer system until cooldown passes.
  4. Singleflight OAuth Refresh Lock: When an access token expires across 20 concurrent workers, share one in-flight refresh promise instead of firing 20 refresh calls (which invalidates rotating refresh tokens!).
Interview Favorite:
"Implement an API client that respects 10 req/sec, retries 429s with jittered backoff, and opens a circuit breaker after 3 consecutive 503s."

2. Annotated Code: Python Async Token Refresh Singleflight

Python / Asyncio Preventing Concurrent OAuth Refresh Token Races 
class SaaSAuthClient:
    def __init__(self):
        self._lock = asyncio.Lock()
        self._token: str | None = None

    async def get_valid_token(self, force_refresh: bool = False) -> str:
        async with self._lock:  # Singleflight: 20 workers wait on 1 refresh call
            if self._token is None or force_refresh:
                self._token = await self._refresh_oauth_token()
            return self._token
