Track 1 · Phase 3 · Unit 0010 · Enterprise Cloud Networking & Security

Cloud Networking, VPCs, PrivateLink, TLS/mTLS & IAM

Closing the biggest blind spot for mobile engineers: understanding public vs. private subnets, CIDR blocks, PrivateLink vs. public internet, TLS/mTLS handshakes, and least-privilege IAM roles before touching Kubernetes.

Estimated Time: 25 min Prerequisites: 0003, 0009 Tangible Win: Build a VPC Subnet/Traffic Auditor & IAM Least-Privilege Validator

1. Why Enterprise APIs Live Inside Locked-Down VPCs

On Android, hitting https://api.example.com goes over the public internet using system-trusted CA certificates. Inside a bank, hospital, or defense contractor, your application pods sit inside a Virtual Private Cloud (VPC) with zero public inbound IPs and zero direct internet egress (AWS VPC User Guide).

  1. Public vs. Private Subnets: Only load balancers / NAT gateways belong in public subnets (routes to an Internet Gateway). Databases (pgvector), workers, and vLLM GPUs belong in private subnets.
  2. PrivateLink Over NAT / Public Internet: Regulated customers forbid traffic to LLM endpoints or SaaS warehouses from crossing the public internet. AWS PrivateLink / GCP Private Service Connect routes traffic over private cloud backbones.
  3. Internal CAs & Mutual TLS (mTLS): Enterprise proxies and internal services often present private internal CA certificates (causing CERTIFICATE_VERIFY_FAILED in Python until you mount the customer CA bundle) or require client certificates (mTLS).
  4. IAM Roles Over Static Access Keys: Never paste long-lived AWS_SECRET_ACCESS_KEY strings into container env vars. Bind short-lived workload IAM roles (IRSA / Workload Identity) scoped to specific buckets and KMS keys.
Android Bridge:
Mounting a customer's internal root CA bundle in Kubernetes is the server-side sibling of Android network_security_config.xml pinning—except skipping verification (verify=False) is an instant security audit failure!
Mobile Network World

Public HTTPS + Device Store

  • App connects directly to public DNS endpoints over LTE/Wi-Fi.
  • Android OS bundles public root CAs automatically.
  • Single OAuth token stored in encrypted Android Keystore.
Enterprise VPC World

Private Subnets + IAM + mTLS

  • Databases & workers live in non-routable private CIDRs (10.0.0.0/16).
  • Split-horizon DNS resolves service URLs onto private PrivateLink IPs.
  • Pods assume ephemeral IAM roles and fetch secrets via KMS/Secrets Manager.

2. Annotated Code: Least-Privilege IAM Policy Pattern

JSON / IAM Scoped Bucket + KMS Access (Never Use "Action": "*" or "Resource": "*") 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject"],
      "Resource": "arn:aws:s3:::aegisops-acme-ingest/*"
    },
    {
      "Effect": "Allow",
      "Action": ["kms:Decrypt", "kms:GenerateDataKey"],
      "Resource": "arn:aws:kms:us-east-1:123456789012:key/acme-cmk-id"
    }
  ]
}
