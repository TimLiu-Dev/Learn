1. The Five Technical Gates (2026–2027 Reality)

  • Online Assessments (OAs) & Take-Homes: Expect CodeSignal/HackerRank timed screens before human rounds, and 3–4 hour Android Compose or Spring Boot REST take-homes at Mid-Tech scale-ups (timebox cleanly, prioritize tests + README tradeoffs).
  • DSA (Mandatory FAANG Gate): Follow Yangshun Tay's Grind 75 pattern-by-pattern (Two Pointers, Sliding Window, Trees/Graphs, Heaps, DP). Explain invariants and Big-O aloud.
  • AI-Assisted Coding & Portfolio Defense: Expect live code-review rounds debugging LLM-written diffs plus deep architectural questioning on SignalApply to verify you own every design choice without an AI prompt.
  • Android Craft Round: Structured concurrency (CoroutineScope, SupervisorJob, StateFlow vs SharedFlow), Jetpack Compose recomposition stability, process death (SavedStateHandle), and LeakCanary debugging.
  • Spring Boot Backend Round: Hibernate N+1 queries (JOIN FETCH, @EntityGraph, batching), @Transactional proxy self-invocation & rollback rules, Spring Security (JWT/OAuth2 resource server), SQL indexing & EXPLAIN ANALYZE, ProblemDetail REST contracts, and Java 21/25 Virtual Threads + HikariCP sizing.

2. Classic Spring Boot Interview Bug Trap

@Service
class OrderService {
    fun processOrder() {
        saveAuditLog() // Self-invocation bypasses Spring CGLIB proxy!
    }
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    open fun saveAuditLog() { /* NO new transaction opened! */ }
}
