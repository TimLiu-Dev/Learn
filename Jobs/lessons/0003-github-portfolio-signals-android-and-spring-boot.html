1. Quality Over Quantity: The 3-Pinned-Repo Rule

Private Work Problem: Your best JHT code is behind corporate Git. Two to three clean public repos prove how you architect code when nobody is looking. Hiring leads do not browse 18 half-finished tutorial clones. Pin 2–3 production-grade repositories that directly back your 2027 Mid-Tech transition:

  1. Flagship Android Client (signalapply-android): Kotlin, Jetpack Compose (Material 3), Unidirectional Data Flow (StateFlow), Hilt DI, Room offline-first cache + Retrofit/Ktor, Unit & Compose UI tests.
  2. Flagship Spring Boot 4 Backend (signalapply-backend): Java 21/25 LTS or Kotlin + Spring Boot 4 (Spring Framework 7, Jackson 3, OpenTelemetry), PostgreSQL (not H2-only demos), Flyway migrations, integration tests via Testcontainers, Docker Compose, and clean transaction boundaries.
  3. AI Crawler & Router (job-radar-crawler): Python Crawl4AI / Stagehand ingestion + local 128GB OpenAI-compatible LLM scoring pipeline feeding the Spring Boot API.
