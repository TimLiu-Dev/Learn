2. Serving One OpenAI-Compatible Endpoint (Port 8080) + Structured JSON

# On M5 Max (MLX native — verify current model IDs in mlx-community):
mlx_lm.server --model mlx-community/Qwen3-Coder-Next-4bit --port 8080

# On Ryzen AI Max+ 395 (Linux ROCm tuned — 30B–120B GGUF weights):
export ROCBLAS_USE_HIPBLASLT=1
./llama-server -m qwen3-coder-80b-q4_k_m.gguf --port 8080 -ngl 99 --flash-attn -c 65536

Because both expose an OpenAI-compatible /v1/chat/completions server, your Python crawler and browser-use / Stagehand agents switch between Frontier APIs and Local 128GB by changing a single base_url environment variable! Always pass response_format={"type": "json_schema", ...} (or llama.cpp GBNF grammars) so local weights never emit malformed JSON that breaks Pydantic ingestion.
