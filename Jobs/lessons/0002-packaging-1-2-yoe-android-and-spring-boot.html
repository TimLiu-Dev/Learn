Packaging 1–2 YoE Experience: Android + Spring Boot

How to translate day-job connected-fitness Android work at Johnson Health Tech into Google XYZ impact bullets — and maintain targeted Android and Spring Boot resume variants without diluting either signal.

Primary Source & Citations

Grounded in Tech Interview Handbook — Resume Guide (Google XYZ formula) and Gergely Orosz's The Tech Resume Inside Out ("So What?" rule & single-page calibration under 5 YoE).

1. The Dual-Stack Trap at 1–2 YoE

Rule of Thumb: A single canonical JSON/YAML experience graph feeds two clean 1-page PDF builds — never one cluttered "Android / Spring Boot / Full-Stack" hybrid PDF. Moving from 1 YoE Android at Johnson Health Tech toward 2 YoE Mid-Tech Android and Spring Boot backend roles creates a common resume mistake: dumping both specializations into one unfocused header. Recruiter Boolean filters and hiring managers want fast classification:

  • Android Variant (Android Software Engineer): Leads with Kotlin, Jetpack Compose, Coroutines/Flow, BLE/hardware integration, crash-free sessions, and UI latency — keeping Spring Boot as a supporting backend collaboration signal.
  • Backend Variant (Software Engineer — Java / Spring Boot): Leads with REST API integration (RestClient), Spring Boot 4 (Java 21/25 LTS) services, PostgreSQL schema/query tuning, Docker, and end-to-end ownership — framing your JHT production mobile work as distributed client-server engineering.
