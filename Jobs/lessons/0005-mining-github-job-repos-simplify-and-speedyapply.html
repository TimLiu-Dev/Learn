1. Under the Hood of GitHub Job Aggregators

2027 2-YoE Reality: College New-Grad repos rarely require 2+ YoE, so use them for L3/early-career targets and company discovery — while pairing them with Phase 4 ATS crawlers for Mid-Tech Android & Spring Boot roles. Do not scrape rendered GitHub HTML pages. Both major community repos expose clean raw files:

  • SimplifyJobs JSON Feed: https://raw.githubusercontent.com/SimplifyJobs/New-Grad-Positions/dev/.github/scripts/listings.json returns structured objects with company, title, category, locations, url, date_posted, active, and sponsorship.
  • speedyapply Markdown Table: https://raw.githubusercontent.com/speedyapply/2027-SWE-College-Jobs/main/NEW_GRAD_USA.md uses pipe-delimited Markdown rows (with companion NEW_GRAD_INTL.md and 2027-AI-College-Jobs).
import requests, time

URL = "https://raw.githubusercontent.com/SimplifyJobs/New-Grad-Positions/dev/.github/scripts/listings.json"
jobs = requests.get(URL, timeout=15).json()
cutoff = time.time() - (72 * 3600)  # Fresh within 72 hours

matches = [
    j for j in jobs
    if j.get("active") and j.get("date_posted", 0) >= cutoff
    and any(k in j.get("title", "").lower() for k in ("android", "mobile", "backend", "software"))
]

2. Schema Edge Cases & Student-Only vs. 1–2 YoE Filtering

With 1–2 YoE at Johnson Health Tech, check two details in your ingestion script:

  • Eligibility & Graduation Windows: Many Big Tech New-Grad requisitions require graduation within the last 12 months, whereas standard Early Career / Software Engineer I / Android Engineer postings accept 1–2 YoE.
  • Feed Schema Quirks: Check both active and is_visible flags in listings.json, use date_updated alongside date_posted for reopened roles, normalize multi-location arrays (plus sub-rows using ↳ continuation markers in Markdown tables), and maintain your own companies.yaml ATS watchlist for 2-YoE Mid-Tech roles.
