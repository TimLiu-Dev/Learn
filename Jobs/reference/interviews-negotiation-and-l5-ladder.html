2. Interview Deep-Dive Checklist

  • OAs & AI-Era Rounds: Timebox CodeSignal/HackerRank screens & 3–4h Mid-Tech take-homes; practice live PR review of LLM diffs and defending SignalApply design tradeoffs without AI.
  • DSA: Grind 75 patterns (Two Pointers, Sliding Window, Trees/Graphs, Heaps, DP) — clean code + edge cases + complexity.
  • Android: Structured concurrency, StateFlow vs SharedFlow, Compose recomposition stability, Room offline-first + WorkManager, LeakCanary.
  • Spring Boot: Hibernate N+1 (JOIN FETCH, @EntityGraph), @Transactional proxy self-invocation & rollback rules, Spring Security (JWT/OAuth2), SQL indexing / EXPLAIN ANALYZE, ProblemDetail, Transactional Outbox + idempotency keys, HikariCP + Virtual Threads.
  • Progression & Hygiene: Prepare for Google/Meta Team Matching, guard against down-leveling, and build SignalApply strictly on personal hardware/hours (never JHT equipment).
