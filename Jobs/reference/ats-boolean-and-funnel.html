ATS Parsers, Boolean Precedence & Hiring Funnel

Compressed cheat sheet from Lesson 0001. Keep open when formatting resumes or auditing PDF text layers.

1. The 4-Stage Tech Hiring Funnel

Stage Gatekeeper Primary Mechanism How Candidates Fail
1. Ingestion & Parsing ATS Parser (Workday, Greenhouse, Lever) Top-to-bottom, left-to-right text extraction into structured DB fields Multi-column layouts, tables, Canva image-PDFs, missing text layer
2. Search & Indexing Recruiter Boolean / Filter Query Exact phrase match, Boolean precedence, title/date facet filters Split phrases across columns, creative headers, buried tech stack
3. 6-Second Human Scan Technical Recruiter / Sourcer Visual scan of latest role, stack match, and quantified outcomes Walls of text, duty-only bullets, no measurable impact (XYZ)
4. HM Screen & Loop Engineering Manager / Senior SWE GitHub code quality check, technical screen, system design, behavioral Tutorial-clone repos, unverified/fabricated resume skills

2. Major ATS Parser Quirks

ATS Platform Where You See It Parsing Behavior & Known Traps
Workday Fortune 500, Enterprise Tech Rigid rule-based top-to-bottom, left-to-right parser; two-column layouts scramble fields; requires standard headers (Experience, Education, Skills) and consistent MMM YYYY dates.
Greenhouse Startups, Mid-Tech, High-Growth NLP + field mapping with full-text Boolean search; sidebars/header tables drop contact info; preserves clean hyperlinks (GitHub, LinkedIn).
Lever Mid-Market Tech, Consumer Brands Balanced parser, but flattened/image-only PDFs yield zero extracted text; non-standard font encodings corrupt characters.

3. Boolean Precedence (Greenhouse & LinkedIn Recruiter)

Evaluation order from highest to lowest priority: "Exact Phrases" → (Parentheses) → NOT → AND (including implicit space-separated terms) → OR. 

# Safe Junior Android Recruiter Query (operators MUST be UPPERCASE)
("Android Developer" OR "Android Engineer" OR "Mobile Engineer")
AND Kotlin
AND ("Jetpack Compose" OR Compose)
NOT (Senior OR Staff OR Principal OR Lead)
  • Smart Quotes Trap: Curly quotes (“...”) pasted from Word/Docs break Greenhouse queries; always use straight quotes ("...").
  • Trailing Wildcard: Kotlin* or Java* matches suffix variations (note: Java* also matches JavaScript).

4. 10-Second Local PDF Audit Command

# Verify your PDF extracts linearly in a single clean stream (macOS / Linux)
pdftotext -layout First-Last-Resume.pdf - | head -n 40

# Python check with pdfplumber (catches empty image PDFs or column interleaving)
python3 -c 'import pdfplumber, sys; print("\n".join(p.extract_text() or "" for p in pdfplumber.open(sys.argv[1]).pages))' First-Last-Resume.pdf
