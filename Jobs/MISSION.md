# Mission: End-to-End Job Search & Automation Mastery (1 YoE Android → 2027 Mid-Tech Android/Spring Boot → FAANG)

## Why
Currently working as a Junior Android Developer at Johnson Health Tech (1 YoE). By 2 YoE in 2027, transition into high-paying Mid-Tech Android or Backend (Spring Boot) roles — and ultimately reach **Senior Software Engineer at Big Tech / FAANG (Google L5 / Meta E5 / Amazon L6)** — by mastering every hiring channel (GitHub job feeds, LinkedIn, Wellfound, Built In, Indeed), recruiter strategy, and building a frontier-to-local AI job crawler & application pipeline on 128GB hardware (M5 Max + Ryzen AI Max+ 395).

## Success looks like
- Package 1–2 YoE Johnson Health Tech Android production work plus Spring Boot backend projects into ATS-proof resumes and high-signal GitHub repositories.
- Systematically mine GitHub job aggregators (`speedyapply`, `SimplifyJobs`), LinkedIn, Wellfound, Built In, Indeed, and direct ATS boards for both 0–2 YoE SWE and Mid-Tech Android / Spring Boot openings.
- Locate, message, and convert internal/agency recruiters and employee referrals into interview loops.
- Prototype an automated job crawler, JD scorer, resume tailor, and Playwright application runner using frontier AI APIs (Claude, Gemini, Codex/GPT), then migrate high-volume execution to local 128GB inference (M5 Max via MLX + Ryzen AI Max+ 395 via ROCm/`llama.cpp`).
- Pass Android, Spring Boot, DSA, and Mobile/Backend System Design loops and negotiate Mid-Tech and FAANG offers.

## Constraints
- Current baseline: 1 YoE Junior Android Developer (Johnson Health Tech); 2027 target = 2 YoE Mid-Tech Android & Spring Boot backend.
- Hardware available for local AI pipeline: Apple M5 Max (128GB unified memory) and AMD Ryzen AI Max+ 395 (128GB unified memory).
- Learning format: Short, benchmark-quality Tufte-style HTML lessons with code-based multiple-choice quizzes where every option explains why it is right or wrong.
- Guardrails: Never build CAPTCHA/anti-bot bypasses or fabricate unverifiable experience; pause automation cleanly for human handoff on verification gates.

## Out of scope
- Introductory programming or "learn Kotlin from zero" tutorials (already shipping production Android code at 1 YoE).
- Defeating CAPTCHAs, Turnstile/anti-bot gates, or platform access controls.
