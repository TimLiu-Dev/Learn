# Baseline Profile: Junior Android Developer Targeting 2027

Status: superseded by LR-0002

Targeting an entry-level / junior Android engineering role in 2027 with the goal of mastering end-to-end job search systems—spanning platforms, recruiter outreach, ethical AI search automation, and long-term progression to Mid-Tech and FAANG. No prior job-search mastery has been verified yet, so Lesson 1 starts from first principles of the hiring funnel and ATS parsing.

- **Evidence**: User-stated starting point and goal in initial `/teach` prompt.
- **Implications**: Frame technical examples and code quizzes around Android (Kotlin, Jetpack Compose, Room, Hilt) alongside job-search automation code (Python/TypeScript/JSON/Boolean logic), and benchmark all lessons to build progressively toward an end-to-end resume-grade capstone project.
