0000-1. The Go Toolchain & Android → Go Mental Model

Coming from Kotlin and Android, your first hurdle in Go is unlearning JVM ceremony: Gradle daemons, inheritance hierarchies, nullable reference wrappers, and exception control flow. Go compiles a repository directly into one static native binary built for Linux containers.

📱 Android / Kotlin Bridge: What Changes on Day 1

In Android you model state with data class, inheritance, nullable types (Int?), and Gradle modules. In Go, files live in flat directory-scoped packages inside a go.mod module, structs have deterministic zero values (0, "", false, nil), and Go 1.26 adds new(expr) to allocate initialized pointers inline without helper boilerplate.

2. Packages, Exported Symbols & Go 1.26 new(expr)

Every directory of .go files forms one package, and circular package imports are a hard compile error—forcing clean dependency graphs from day one. Any identifier starting with an uppercase letter is exported across packages; lowercase identifiers stay visible only within that package directory.

Before Go 1.26, initializing optional configuration pointer fields like MaxRetries *int required a temporary local variable or an intPtr(3) helper because you cannot write &3 directly. Since Go 1.26, built-in new(3) allocates storage initialized to 3 and yields its *int directly.

config_example.go (Go 1.26+ struct + zero values + comma-ok) 
type ServiceConfig struct {
    Host       string // zero value: ""
    Port       int    // zero value: 0
    MaxRetries *int   // nil means unset; Go 1.26: new(3) sets *int to 3
    TLSEnabled bool   // zero value: false
}

func DefaultConfig() ServiceConfig {
    return ServiceConfig{
        Host:       "0.0.0.0",
        Port:       8080,
        MaxRetries: new(3), // Go 1.26+: expression form of new()
        TLSEnabled: true,
    }
}

func ParseModuleName(importPath string) (string, bool) {
	if importPath == "" || strings.HasSuffix(importPath, "/") {
		return "", false
	}
	idx := strings.LastIndex(importPath, "/")
	if idx == -1 {
		return importPath, true
	}
	return importPath[idx+1:], true
}

4. Knowledge Verification Quizzes

Quiz 1 of 2 • Structs & Pointer Initialization
In Go 1.26+, you want to populate MaxRetries *int on a struct literal to point to the integer 3 without writing a helper function. What is idiomatic?
A Take the address directly with MaxRetries: &3 in the struct field initializer.
B Pass an expression to built-in MaxRetries: new(3) to obtain an initialized *int.
C Declare var MaxRetries int? = 3 using Go's nullable primitive suffix syntax.
D Assign MaxRetries: *int(3) because Go converts typed integer literals into heap pointers.
Option A (Incorrect): Taking the address of an untyped numeric constant (&3) is invalid syntax in Go.
Option B (Correct): Go 1.26 extends new(expr) to allocate and initialize storage from an expression, returning *int directly.
Option C (Incorrect): Go has no Kotlin-style ? nullable suffix on primitive types.
Option D (Incorrect): *int(3) attempts pointer dereference of a cast rather than pointer allocation.
Quiz 2 of 2 • Package Architecture
How does Go's compiler enforce package boundaries and symbol visibility compared to Kotlin Gradle modules?
A Go requires public keywords and lets sibling packages import each other freely at runtime.
B Go scopes visibility per source file, so sibling files in one folder cannot read lowercase types.
C Go bundles multiple Kotlin-style namespaces per file while Gradle resolves package cycles via reflection.
D Go scopes unexported lowercase symbols to the package directory and forbids cyclic imports at compile time.
Option A (Incorrect): Go has no public keyword and strictly rejects import cycles at compile time.
Option B (Incorrect): All files in the same directory belong to one package and share lowercase (package-private) declarations.
Option C (Incorrect): Each Go file begins with a single package clause matching its directory, and imports form a DAG.
Option D (Correct): Directory-scoped packages plus uppercase exports and disallowed import cycles enforce modular cloud codebases cleanly.
