roadmap.sh/golang Calibration: What We Added & Trimmed

➕ Added for Junior Android → 2027 Senior Cloud

  • Module 00 Android → Go Bridge: Maps JVM/Gradle, nullable types, Kotlin Result, and coroutines onto Go modules, value/pointer semantics, explicit (T, error) handling, and goroutines.
  • Modern Go Stdlib & Testing: Table-driven tests, -race, Go 1.25+ deterministic virtual clocks (testing/synctest), Go 1.22+ net/http method routing, and iter.Seq / weak.Pointer.
  • Container & Backend Foundations: Linux cgroups & Go 1.25+ native container-aware GOMAXPROCS (plus legacy automaxprocs context), sqlc + PostgreSQL transactions, Redis basics, PGO, ConnectRPC/SSE, and OpenTelemetry.

✂️ Trimmed or Deferred from Generic Roadmaps

  • Redundant Basics: Skips generic "what is a variable, loop, or class" filler since you already write production Kotlin/Java syntax on Android.
  • Pre-1.22 Boilerplate & Heavy ORMs: Drops legacy gorilla/mux glue and reflection-heavy ORM magic (e.g., GORM in hot paths) in favor of stdlib net/http, pgx, and compile-time sqlc.
  • Non-Cloud Detours: Defers desktop GUI libraries, niche CGO tricks, and premature microservices frameworks until runtime, concurrency, and transactional persistence are solid.
