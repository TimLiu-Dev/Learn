01 // MENTAL MODEL & INTERACTIVE SIMULATOR

4-Level Radix Page Tables, 4KB vs 16KB Pages & TLB/ASID Caching

Why Multi-Level Page Tables Exist

A flat page table for a 48-bit virtual address space with 4KB pages needs 2^36 entries × 8 bytes = 512 GB per process!

Instead, ARM64/x86-64 organize translations as a sparse 4-level radix tree: PGD → PUD → PMD → PTE. Unmapped regions allocate zero intermediate tables, so a process using a few MBs needs only a few KBs of page tables.

4KB vs 16KB Pages: With 4KB (12-bit offset), 48-bit VA splits as 9+9+9+9+12 (512 entries/table). With 16KB (14-bit offset), each page is 4× larger and each PTE table holds 2,048 entries (11-bit indices), multiplying TLB reach by 4×.

TTBR0_EL1 vs TTBR1_EL1, ASIDs & Shootdowns

ARM64 Split Address Space: Hardware checks bit 55/63 of the VA. Low addresses (0x0000...) walk TTBR0_EL1 (per-process user space); high addresses (0xFFFF...) walk TTBR1_EL1 (shared kernel space, never swapped on syscall traps!).

ASID (Address Space ID): Tagging TLB entries with an 8/16-bit ASID lets CPU cores retain App A's TLB entries across context switches to App B without flushing.

TLB Shootdown: When modifying or unmapping a PTE (e.g., munmap or CoW), all SMP cores must invalidate stale TLB lines matching (ASID, VPN) via ARM64 TLBI VAE1IS or x86 IPIs.

ARM64 PTE Flags, Kernel CoW Fault Handler & SMP TLB Shootdown

1. ARM64 Stage-1 Page Table Entry Bits (arch/arm64/include/asm/pgtable-hwdef.h) 
#define PTE_VALID       (1UL << 0)  /* Entry is valid; 0 triggers Translation Fault */
#define PTE_TYPE_PAGE   (1UL << 1)  /* Level-3 page descriptor */
#define PTE_USER        (1UL << 6)  /* AP[1]=1: EL0 user space allowed */
#define PTE_RDONLY      (1UL << 7)  /* AP[2]=1: Read-only (triggers Permission Fault on write -> CoW) */
#define PTE_AF          (1UL << 10) /* Access Flag (hardware/OS page aging) */
#define PTE_NG          (1UL << 11) /* Not Global: tagged with ASID in TLB (user space) */
#define PTE_PXN         (1UL << 53) /* Privileged Execute-Never (EL1 cannot execute user pages) */
#define PTE_UXN         (1UL << 54) /* Unprivileged Execute-Never (W^X / NX heap protection) */

/* Context switch only swaps TTBR0_EL1 (user) with ASID; TTBR1_EL1 (kernel) stays intact */
static inline void switch_user_mm(uint64_t pgd_phys, uint16_t asid) {
    uint64_t ttbr0 = ((uint64_t)asid << 48) | pgd_phys;
    asm volatile("msr ttbr0_el1, %0\nisb" :: "r"(ttbr0) : "memory");
}
2. Copy-on-Write Page Fault Logic (mm/memory.c: do_wp_page) 
vm_fault_t handle_write_fault(struct vm_area_struct *vma, unsigned long addr, pte_t *ptep) {
    if (!(vma->vm_flags & VM_WRITE))
        return VM_FAULT_SIGSEGV; /* True illegal write to read-only segment */

    if (pte_none(*ptep))
        return do_anonymous_zero_page(vma, addr, ptep); /* Demand-zero allocation */

    struct page *old_page = pte_page(*ptep);
    if (page_count(old_page) == 1) {
        /* Sole remaining owner after sibling exited/copied: upgrade PTE to RW in place! */
        pte_t entry = pte_mkwrite(*ptep);
        set_pte_at(vma->vm_mm, addr, ptep, entry);
        flush_tlb_page(vma, addr);
        return 0;
    }

    struct page *new_page = alloc_page(GFP_HIGHUSER_MOVABLE);
    copy_user_highpage(new_page, old_page, addr, vma);
    set_pte_at(vma->vm_mm, addr, ptep, mk_pte(new_page, vma->vm_page_prot));
    put_page(old_page); /* Drop reference to shared CoW frame */
    flush_tlb_page(vma, addr);
    return 0;
}
3. ARM64 Inner-Shareable SMP TLB Shootdown (arch/arm64/include/asm/tlbflush.h) 
static inline void flush_tlb_page_asid(uint16_t asid, unsigned long vaddr) {
    unsigned long arg = ((unsigned long)asid << 48) | ((vaddr >> 12) & 0xFFFFFFFFFFFUL);
    dsb(ishst);                  /* Ensure updated PTE store is visible to page-table walkers */
    asm volatile("tlbi vae1is, %0" :: "r"(arg)); /* Hardware broadcast across all SMP cores */
    dsb(ish);                    /* Wait for all cores to acknowledge TLB invalidation */
    isb();                       /* Synchronize local instruction pipeline */
}
Security Trap (Missing TLB Shootdown): If Core 0 frees a physical frame via munmap() and updates the PTE, but skips the SMP TLB shootdown, Core 1's stale TLB entry still translates that VA to the freed physical frame—allowing a thread on Core 1 to read or corrupt another process's newly allocated memory!
03 // ANDROID INTERNALS BRIDGE

Android 15/16 16KB Page Transition, .apk/.so mmap & VSS/RSS/PSS

Android 15/16: 4KB → 16KB Page Size Migration

Modern ARM64 SoCs support both 4KB and 16KB OS pages. Moving Android to 16KB pages gives 4× TLB coverage, ~5–10% faster app launches, and faster camera starts (fewer page faults & page-table walks), at the cost of ~9% higher RAM overhead from internal fragmentation.

Why Native NDK Apps Broke: ELF PT_LOAD segments compiled with 4KB alignment (p_align = 0x1000) fail to mmap() cleanly with distinct R/X/RW permissions on a 16KB kernel! Android 15+ requires -Wl,-z,max-page-size=16384 in NDK builds and zero hardcoded 4096 assumptions.

mmap of .so/.apk & VSS vs RSS vs PSS

Zero-Duplication Code Mapping: When 20 apps load libc.so or framework.jar via mmap(MAP_PRIVATE), they map the exact same physical Page Cache frames read-only. Copy-on-Write only duplicates dirty .data/.bss pages.

VSS (Virtual Set Size): Total virtual address reservations (inflated by ART heap reservations & mmap).

RSS (Resident Set Size): Physical RAM mapped into the process (over-counts shared .so pages across apps).

PSS (Proportional Set Size): Private pages + (Shared pages / # of sharing processes). This is what dumpsys meminfo and lmkd track!

LAB 1 OF 3 // HARDWARE MMU & TLB

Implement Multi-Level Page Table Walker (walkPageTable)

Check TLB first, walk 2-level tables on miss, enforce user/write/exec bits, and populate TLB.

Not Run
Specification: walkPageTable(tlb, pageTables, vaddr, asid, accessType) (PAGE_SIZE = 4096):
• Compute vpn = Math.floor(vaddr / 4096), offset = vaddr % 4096, l1 = Math.floor(vpn / 1024), l2 = vpn % 1024.
• tlb is a Map keyed by `${asid}:${vpn}` storing { pfn, user, write, exec }.
• accessType is "read" | "write" | "exec".
• Check TLB first: if present, verify permissions (entry.user must be true; "write" requires entry.write; "exec" requires entry.exec). If denied, return { ok: false, errno: -13, tlbHit: true } (-EACCES). Otherwise return { ok: true, paddr: entry.pfn * 4096 + offset, tlbHit: true }.
• On TLB miss, look up pte = pageTables[asid]?.[l1]?.[l2]. If missing or !pte.valid, return { ok: false, errno: -14, tlbHit: false } (-EFAULT).
• Check permissions on pte: if denied, return { ok: false, errno: -13, tlbHit: false } (do not insert into TLB).
• Otherwise populate tlb.set(`${asid}:${vpn}`, { pfn: pte.pfn, user: pte.user, write: pte.write, exec: pte.exec }) and return { ok: true, paddr: pte.pfn * 4096 + offset, tlbHit: false }.
LAB 2 OF 3 // DEMAND PAGING & COPY-ON-WRITE

Implement Write Page Fault & CoW Handler (handleCowFault)

Distinguish SIGSEGV, demand-zero allocation, CoW frame copy (refcount > 1), and in-place reuse (refcount === 1).

Not Run
Specification: handleCowFault(vm, vaddr) (PAGE_SIZE = 4096, vpn = Math.floor(vaddr / 4096)):
• Find VMA in vm.vmas where vma.startVpn <= vpn && vpn < vma.endVpn. If none, return { ok: false, action: "segfault", errno: -14 }.
• If !vma.writable, return { ok: false, action: "segfault", errno: -13 }.
• Look up pte = vm.ptes[vpn]:
  1. Demand-zero: If !pte || !pte.present, call newPfn = vm.allocFrame(), set vm.frameRefcounts[newPfn] = 1, vm.ptes[vpn] = { present: true, writable: true, pfn: newPfn }, return { ok: true, action: "demand_zero", pfn: newPfn }.
  2. CoW copy (refcount > 1): If !pte.writable and vm.frameRefcounts[pte.pfn] > 1, call newPfn = vm.allocFrame(), copy vm.frames[newPfn] = vm.frames[pte.pfn].slice(), decrement vm.frameRefcounts[pte.pfn], set vm.frameRefcounts[newPfn] = 1, update vm.ptes[vpn] = { present: true, writable: true, pfn: newPfn }, return { ok: true, action: "cow_copy", oldPfn, pfn: newPfn }.
  3. CoW reuse (refcount === 1): Set pte.writable = true in place without allocating/copying, return { ok: true, action: "cow_reuse", pfn: pte.pfn }.
  4. Already writable: return { ok: true, action: "noop", pfn: pte.pfn }.
LAB 3 OF 3 // SMP TLB SHOOTDOWN

Implement Targeted ASID TLB Shootdown (tlbShootdown)

Invalidate stale (ASID, VPN) translations across all SMP cores without flushing unrelated processes.

Not Run
Specification: tlbShootdown(cores, targetAsid, vaddr):
• cores: array of { coreId: number, tlb: Array<{ asid: number, vpn: number, global?: boolean }> }.
• Compute vpn = Math.floor(vaddr / 4096).
• For each core, remove matching entries from core.tlb:
  - If targetAsid !== null: remove entries where !entry.global && entry.asid === targetAsid && entry.vpn === vpn.
  - If targetAsid === null (kernel/global shootdown): remove any entry where entry.vpn === vpn.
• Return { invalidatedCount, coresTouched } where coresTouched is how many cores had ≥1 entry removed.
