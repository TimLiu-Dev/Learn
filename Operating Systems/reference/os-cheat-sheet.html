2. Processes, Scheduling, Concurrency & IPC

clone() & Scheduling

Thread: CLONE_VM | CLONE_FILES | CLONE_THREAD | CLONE_SIGHAND (shared mm_struct, same TGID).

EEVDF: Eligible when vruntime <= avg_vruntime (positive lag); picks smallest vdeadline.

Android EAS: Places tasks on energy-optimal LITTLE/Mid/Big cluster satisfying uclamp_min.

Atomics, Futex & Binder

Futex 3-State: 0 unlocked, 1 locked uncontended (no syscall!), 2 contended (FUTEX_WAIT/WAKE).

Binder: 1 copy (user → kernel mmap ring shared read-only with receiver); 1MB shared pool; async oneway capped at 50%.

Zero-Copy Buffers: memfd_create / DMA-BUF passes FD handles, not bytes.

3. Memory, I/O, Security & Forensics Commands

Memory & Storage

Allocators: Buddy (page frames, buddy = addr ^ (1 << order)) → SLUB (kernel objects) / Scudo + MTE (Android user heap).

Reclaim: MGLRU generations + ZRAM compressed swap + PSI (/proc/pressure/memory) driving Android lmkd.

I/O: epoll (Android Looper + eventfd) vs io_uring (shared SQ/CQ rings); F2FS log-structured flash + fsync WAL durability.

Production Forensics CLI

strace -f -c ./bin            # Syscall breakdown
cat /proc/<pid>/smaps_rollup  # RSS / PSS / Swap
cat /proc/pressure/memory     # PSI some/full stalls
perf record -F 99 -g -- ./bin # CPU Flamegraph data
grep Seccomp /proc/<pid>/status

4. Interrupts, Signals, Power & Kernel Rust (Lessons 17–20)

IRQs, Signals & ELF Linking

GICv3 & Deferral: Ack ICC_IAR1_EL1 → top half (atomic, NO sleep!) → ICC_EOIR1_EL1 → softirq / threaded IRQ / workqueue; NO_HZ + hrtimer.

Signals & ELF: rt_sigframe + rt_sigreturn; SA_RESTART vs -EINTR; sigaltstack; pidfd_send_signal; 16KB PT_LOAD + BIND_NOW Full RELRO.

Power, Thermal & Rust-for-Linux

Power & Thermal: $P = C V^2 f$ + schedutil; cpuidle break-even residency; wakeup_source / EPOLLWAKEUP blocking s2idle; Thermal IPA.

Rust Kernel: Fallible GFP_KERNEL (Result, no OOM panic), Pin<KBox<T>> intrusive lists, Mutex<T> data-owning guards, UserSlice, Rust Binder.
