01 // MENTAL MODEL & INTERACTIVE SIMULATOR

Popek-Goldberg, 2-Stage Paging & Trap-and-Emulate

1. Popek-Goldberg Criteria & Hardware Extensions

A CPU architecture is classically virtualizable if all sensitive instructions (those that read/alter hardware configuration or privilege state) are a subset of privileged instructions (those that trap when executed outside hypervisor privilege).

Trap-and-Emulate: A guest OS thinks it owns the machine in kernel mode (de-privileged to guest EL1 or non-root Ring 0). Normal instructions run natively on silicon; sensitive operations (MMIO device access, hypercalls, system-register traps) raise a VMExit into the hypervisor (EL2 / VMX root).

ARM64 EL2 vs Intel VT-x: Classic x86 had non-trapping sensitive instructions (like POPF/SGDT), requiring binary translation until Intel VT-x (VMX root/non-root) and AMD-V. ARM64 built EL2 specifically for hypervisors, later adding VHE (Virtualization Host Extensions) so Linux KVM can run directly at EL2.

2. Two-Dimensional MMU: GVA → GPA → HPA

A guest kernel manages its own page tables (TTBR0_EL1/TTBR1_EL1) assuming it owns physical RAM starting at 0x80000000. The hardware MMU enforces a second invisible translation layer controlled only by the hypervisor (VTTBR_EL2 on ARM64, EPTP on Intel):

Stage 1 (Guest OS controlled): Translates GVA (Guest Virtual) → GPA (Guest Physical). Missing mappings raise a normal Guest EL1 page fault.

Stage 2 (Hypervisor controlled): Translates GPA → HPA (Host Physical). Unmapped Stage-2 GPAs (like emulated VirtIO MMIO registers) or permission violations trap straight to EL2 as a Stage-2 Fault / VMExit!

02 // LINUX KVM, VIRTIO & pKVM ARCHITECTURE

Inside KVM ioctl(KVM_RUN), Split Virtqueues & pKVM Stage-2

vmm_kvm_loop.c — Userspace VMM (QEMU / crosvm) Drive Loop 
// Simplified VMM vCPU thread (runs in host EL0)
void *vcpu_thread(struct vcpu_ctx *ctx) {
  struct kvm_run *run = ctx->kvm_run; // mmap'd shared page with KVM

  for (;;) {
    // Traps EL0 -> EL1 (KVM) -> EL2 -> enters Guest EL1!
    if (ioctl(ctx->vcpu_fd, KVM_RUN, 0) < 0) {
      if (errno == EINTR) continue; // Host signal preempted guest
      break;
    }

    switch (run->exit_reason) {
    case KVM_EXIT_MMIO:
      // Guest touched unmapped Stage-2 GPA (e.g. VirtIO doorbell)
      emulate_mmio(run->mmio.phys_addr, run->mmio.data,
                   run->mmio.len, run->mmio.is_write);
      break;
    case KVM_EXIT_HYPERCALL:
      run->hypercall.ret = handle_vmm_hvc(&run->hypercall);
      break;
    case KVM_EXIT_SHUTDOWN:
    case KVM_EXIT_SYSTEM_EVENT:
      return NULL;
    }
  }
  return NULL;
}

pkvm_hyp_ownership.c — Android Protected KVM (pKVM) De-Privileged Host 
// Classic KVM (VHE): Host Linux kernel runs in EL2 and maps ALL guest RAM.
// A compromised host kernel (CVE in a vendor driver) can read any VM's secrets!
//
// Protected KVM (pKVM / nVHE):
//   - Bootloader drops host Linux to EL1; a tiny audited hypervisor stays in EL2.
//   - Host Linux gets its OWN Stage-2 page table (host_s2) enforced by EL2!

enum pkvm_page_state {
  PKVM_PAGE_OWNED = 0,           // Exclusively owned by a single VM (or host)
  PKVM_PAGE_SHARED_OWNED = 1,    // Owner still has R/W; explicitly shared via hypercall
  PKVM_PAGE_SHARED_BORROWED = 2, // Recipient mapped shared GPA (e.g. VirtIO bounce buffer)
  PKVM_NOPAGE = 3,               // Unmapped in this VM's Stage-2 (access traps to EL2!)
};

// When Protected VM (VMID > 0) starts, EL2 transitions guest pages from
// Host PKVM_PAGE_OWNED -> Host PKVM_NOPAGE and Guest PKVM_PAGE_OWNED.
// Even root/EL1 in the host Linux kernel triggers a Stage-2 fault if it reads guest RAM!
Why 2-Stage Paging Multiplies TLB Miss Cost (and How Hardware Mitigates It):
In a 4-level Stage-1 + 4-level Stage-2 walk, every Stage-1 PTE lookup is itself a GPA that requires a 4-level Stage-2 walk! A single cold TLB miss can trigger up to 4 × 4 + 4 = 20 memory reads (or 5 × 5 + 5 = 30 with 5-level paging). Modern ARM64 and x86 CPUs cache intermediate walk entries in paging-structure caches, tag TLB entries by ASID + VMID so VM switches don't flush the TLB, and use 2MB/1GB hugepages in Stage-2 to collapse walk depth.
03 // ANDROID INTERNALS BRIDGE

Android Virtualization Framework (AVF), crosvm & Microdroid

Why Android Needed pKVM (Android 13–16+)

The Problem with TrustZone TEE: Historically, sensitive code (DRM, Keymaster, biometrics) ran in proprietary EL3/Secure-EL1 TrustZone OSes written by SoC vendors—fragmented, hard to update, and running with broad physical memory access.

The AVF Solution: Android ships an upstreamable tiny EL2 hypervisor (pKVM) plus Google's Rust-based VMM (crosvm) running Microdroid (a stripped-down Linux/Bionic VM inside an updatable APEX). Even if an attacker gets root and arbitrary kernel R/W in the Android host kernel (EL1), pKVM prevents the host from inspecting or tampering with Microdroid's memory or signed DICE attestation chain.

Real Workloads & DMA / IOMMU Isolation

1. KeyMint / Widevine DRM / Biometrics: Executed inside isolated Microdroid VMs with cryptographic secret verification backed by hardware DICE.

2. Isolated Compilation & On-Device AI: Heavy or privacy-sensitive inference and ART AOT compilation payloads run inside protected VMs with bounded VirtIO-vsock RPC channels.

3. SMMU / IOMMU Enforcement: Stage-2 only guards CPU accesses. Without an IOMMU (ARM SMMU) configured by EL2, a compromised host kernel could program a GPU or PCIe DMA engine to read protected guest HPA frames directly from DRAM. pKVM programs SMMU Stage-2 tables too!

LAB 1 OF 3 // 2-STAGE MMU WALK

Implement translate2Stage(s1Table, s2Table, gva)

Translate Guest Virtual Address → Guest Physical Address → Host Physical Address with 4KB pages.

Not Run
Specification: Assume PAGE_SIZE = 4096 (0x1000).
• Validate Number.isInteger(gva) && gva >= 0. If invalid, return { ok: false, fault: "INVALID_GVA" }.
• Compute gvaPage = Math.floor(gva / 4096) and offset = gva % 4096 (note: do not use 32-bit bitwise shifts like << 12, which overflow on >4GB addresses!).
• Look up s1 = s1Table[gvaPage]. If !s1 || !s1.present, return { ok: false, fault: "STAGE1_FAULT", gvaPage }.
• Compute gpa = s1.gpaPage * 4096 + offset. Look up s2 = s2Table[s1.gpaPage]. If !s2 || !s2.present, return { ok: false, fault: "STAGE2_FAULT", gpa, gpaPage: s1.gpaPage }.
• Compute hpa = s2.hpaPage * 4096 + offset and return { ok: true, gpa, hpa, offset }.
LAB 2 OF 3 // KVM TRAP-AND-EMULATE

Implement handleVmExit(vcpu, exitEvent, mmioDevices)

Emulate MMIO reads/writes and hypercalls on VMExit while advancing vcpu.pc accurately.

Not Run
Specification: Given vcpu ({ pc, regs, halted }), exitEvent, and mmioDevices (map of addr → { read(), write(val) }):
• exitEvent.type === "MMIO_READ": Look up dev = mmioDevices[exitEvent.addr]. If missing, return { ok: false, reason: "UNMAPPED_MMIO" } (do not advance pc). Otherwise set vcpu.regs[exitEvent.reg] = dev.read(), vcpu.pc += 4, and return { ok: true, action: "MMIO_READ", value: vcpu.regs[exitEvent.reg] }.
• exitEvent.type === "MMIO_WRITE": If dev missing, return { ok: false, reason: "UNMAPPED_MMIO" }. Otherwise call dev.write(exitEvent.value), vcpu.pc += 4, and return { ok: true, action: "MMIO_WRITE" }.
• exitEvent.type === "HYPERCALL": Support callId === 1 (returns 1) and callId === 2 (returns 0); any other callId returns -38 (-ENOSYS). Store result in vcpu.regs.x0, vcpu.pc += 4, return { ok: true, action: "HYPERCALL", ret: vcpu.regs.x0 }.
• exitEvent.type === "HLT": Set vcpu.halted = true, vcpu.pc += 4, return { ok: true, action: "HLT" }.
• Any other exitEvent.type: return { ok: false, reason: "UNKNOWN_EXIT" } without changing vcpu.pc.
LAB 3 OF 3 // pKVM PAGE OWNERSHIP GUARD

Implement pkvmCheckAccess(s2Ownership, actorVmId, hpaPage, isWrite)

Enforce EL2 pKVM ownership so even a compromised host kernel (actorVmId === 0) cannot read private guest pages.

Not Run
Specification: s2Ownership[hpaPage] holds { ownerVmId, state, sharedWith, writableByShared } where state is "OWNED" or "SHARED", and sharedWith is an Array or Set of VM IDs (0 = Host Linux, > 0 = Guest VMs).
• If no ownership entry exists for hpaPage, return { allowed: false, fault: "STAGE2_UNMAPPED" }.
• If actorVmId === entry.ownerVmId, allow both reads and writes: { allowed: true, fault: null }.
• Otherwise (non-owner, including Host 0 accessing Guest > 0):
  - If entry.state !== "SHARED", return { allowed: false, fault: "PKVM_OWNERSHIP_VIOLATION" }.
  - Check whether actorVmId is in entry.sharedWith (support both Set and Array). If not, return { allowed: false, fault: "PKVM_NOT_SHARED_WITH_ACTOR" }.
  - If isWrite && !entry.writableByShared, return { allowed: false, fault: "STAGE2_WRITE_PERM_FAULT" }.
  - Otherwise return { allowed: true, fault: null }.
