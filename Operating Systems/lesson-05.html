Coffman Conditions, Lock-Free Progress & Epoch Reclamation

The 4 Coffman Conditions for Deadlock

A deadlock occurs if and only if all four hold simultaneously:

1. Mutual Exclusion: Only one thread can hold a resource (e.g., mutex) at a time.

2. Hold & Wait: A thread holds lock A while blocking to acquire lock B.

3. No Preemption: Locks cannot be forcibly stolen; only the owner releases them.

4. Circular Wait: A cycle exists in the Wait-For Graph: T1 → T2 → ... → T1.

Production Fix: Enforce a strict global lock hierarchy (rank(L1) < rank(L2)) to make Circular Wait mathematically impossible.

Wait-Free SPSC Rings & RCU Grace Periods

SPSC Ring Buffer: With 1 Producer writing head and 1 Consumer writing tail, no CAS loop or mutex is ever needed—just store-release on index advance and load-acquire on the peer's index.

ABA & Memory Reclamation: Freeing a lock-free node while a preempted reader still holds a raw pointer causes Use-After-Free (UAF).

RCU (Read-Copy-Update): Readers enter rcu_read_lock() with zero atomic writes on the read path. Writers publish a new copy, then wait for a grace period (all pre-existing readers pass a quiescent state) before calling kfree().

Canonical Lock Ordering, C11 SPSC Rings & Linux Kernel RCU

1. Canonical Lock Hierarchy (Breaking Coffman #4 in C / Linux Kernel) 
/* Acquire two locks of the same class safely by canonical address ordering */
void lock_pair(struct spinlock *a, struct spinlock *b) {
    if (a == b) {
        spin_lock(a);
        return;
    }
    if ((uintptr_t)a < (uintptr_t)b) {
        spin_lock(a);
        spin_lock_nested(b, SINGLE_DEPTH_NESTING); /* Linux lockdep annotation */
    } else {
        spin_lock(b);
        spin_lock_nested(a, SINGLE_DEPTH_NESTING);
    }
}
2. C11 Wait-Free SPSC Ring Buffer (Cache-Line Padded + Acquire/Release) 
#include <stdatomic.h>
#include <stdbool.h>
#include <stdalign.h>

#define RING_CAP 1024u /* must be power of 2 */

struct spsc_ring {
    alignas(64) _Atomic uint32_t head; /* written only by Producer */
    alignas(64) _Atomic uint32_t tail; /* written only by Consumer */
    alignas(64) uint64_t buf[RING_CAP];
};

bool spsc_push(struct spsc_ring *r, uint64_t item) {
    uint32_t h = atomic_load_explicit(&r->head, memory_order_relaxed);
    uint32_t t = atomic_load_explicit(&r->tail, memory_order_acquire); /* pair w/ consumer release */
    if ((h - t) == RING_CAP) return false; /* full (unsigned wraparound safe!) */
    r->buf[h & (RING_CAP - 1)] = item;
    atomic_store_explicit(&r->head, h + 1, memory_order_release); /* publish item before head++ */
    return true;
}

bool spsc_pop(struct spsc_ring *r, uint64_t *out) {
    uint32_t t = atomic_load_explicit(&r->tail, memory_order_relaxed);
    uint32_t h = atomic_load_explicit(&r->head, memory_order_acquire); /* pair w/ producer release */
    if (h == t) return false; /* empty */
    *out = r->buf[t & (RING_CAP - 1)];
    atomic_store_explicit(&r->tail, t + 1, memory_order_release); /* free slot after reading */
    return true;
}
3. Linux Kernel RCU Read-Copy-Update Pattern (include/linux/rcupdate.h) 
/* Reader path: 0 atomics, 0 cache-line bouncing on multi-core ARM64 */
int lookup_route(int key) {
    int val = -ENOENT;
    rcu_read_lock();
    struct route_entry *e = rcu_dereference(global_route); /* READ_ONCE + address dependency */
    if (e && e->key == key)
        val = e->ifindex;
    rcu_read_unlock();
    return val; /* CANNOT sleep inside rcu_read_lock() */
}

/* Writer path: allocate new copy, swap pointer, wait for grace period, free old */
void update_route(int key, int new_ifindex) {
    struct route_entry *old_e, *new_e = kmalloc(sizeof(*new_e), GFP_KERNEL);
    new_e->key = key;
    new_e->ifindex = new_ifindex;

    mutex_lock(&route_write_lock);
    old_e = rcu_dereference_protected(global_route, lockdep_is_held(&route_write_lock));
    rcu_assign_pointer(global_route, new_e); /* smp_store_release barrier */
    mutex_unlock(&route_write_lock);

    synchronize_rcu(); /* Blocks until all pre-existing readers exit rcu_read_unlock() */
    kfree(old_e);
}
Senior Engineer Detail: Notice alignas(64) in struct spsc_ring! Without separating head and tail onto distinct 64-byte cache lines, Producer and Consumer cores ping-pong the same MESI cache line ("false sharing"), cutting throughput by 5–10x even though there are zero locks.
03 // ANDROID INTERNALS BRIDGE

ANR Deadlock Traces, Perfetto Ring Buffers & Kotlin Coroutines

1. Reading ANR Deadlock Traces (/data/anr/traces.txt)

When an app hits a 5-second input dispatch timeout, ART dumps all Java/native thread stacks and monitor ownership:

"main" prio=5 tid=1 Blocked
- waiting to lock <0x09c3a110> (a CacheLock) held by thread 14

"Binder:4821_2" prio=5 tid=14 Blocked
- waiting to lock <0x0412be08> (a DbLock) held by thread 1

On the kernel side, Android debug kernels enable CONFIG_PROVE_LOCKING (lockdep) to catch potential AB-BA inversions on the very first run, even before two threads actually collide.

2. Perfetto Lock-Free Buffers & Kotlin Coroutines

Perfetto (TraceBuffer / SharedMemoryArbiter): App processes emit trace packets into shared-memory SPSC/page-ring buffers using atomics so logging never stalls the 120Hz render thread on a kernel lock.

Kotlin Coroutines (M:N) vs 1:1 Threads: Coroutines are heap-allocated state machines multiplexed over a small thread pool (e.g., Dispatchers.Default = # of CPU cores). Calling blocking synchronized or Thread.sleep() inside a coroutine pins the underlying kernel thread; calling Mutex.withLock suspends cleanly—but still deadlocks if two coroutines acquire two Mutexes in opposite orders!

LAB 1 OF 3 // DEADLOCK DETECTION

Implement Wait-For Graph Cycle Detection (detectDeadlockCycle)

Distinguish true circular-wait deadlocks from diamond DAGs and disconnected subgraphs.

Not Run
Specification: Given edges (array of [waiter, holder] string pairs meaning waiter is waiting on a lock held by holder):
• Build a directed adjacency list from waiter → holder.
• Run 3-color DFS (0 = unvisited, 1 = visiting / on current recursion stack, 2 = done) across all nodes.
• A diamond DAG (A→B, A→C, B→D, C→D) is not a cycle—only a back-edge to a node currently on the recursion stack (state === 1) is a cycle.
• If no cycle exists, return null.
• If a cycle exists (including self-loops like ["T1", "T1"]), return the cycle path starting and ending at the repeated node, e.g. ["T1", "T2", "T1"].
LAB 2 OF 3 // LOCK-FREE RING BUFFER

Implement Modular SPSC Ring Buffer (createSpscRing)

Handle wraparound, full/empty disambiguation without wasting slots, and falsy payloads.

Not Run
Specification: createSpscRing(capacity):
• Validate capacity is a positive integer (Number.isInteger(capacity) && capacity >= 1); otherwise throw an Error.
• Maintain producer head and consumer tail indices without locks, storing elements in a fixed-size array of length capacity.
• push(item): If ring is full (size() === capacity), return false without overwriting. Otherwise write at head % capacity, advance head, and return true.
• pop(): If ring is empty (size() === 0), return undefined. Otherwise read from tail % capacity, clear slot to undefined, advance tail, and return the item (must correctly return falsy items like 0, false, "", null!).
• size(): Return current element count 0..capacity. Keep indices bounded or wraparound-safe across arbitrary numbers of operations.
LAB 3 OF 3 // RCU GRACE PERIOD RECLAMATION

Implement Epoch-Based RCU Reclaimer (rcuReclaim)

Determine which retired objects have passed all active reader grace periods and can be safely freed.

Not Run
Specification: rcuReclaim(activeReaderEpochs, retiredObjects, currentEpoch):
• activeReaderEpochs: array of integer epochs at which active rcu_read_lock() readers entered.
• retiredObjects: array of { id: string, retiredEpoch: number } waiting to be freed.
• currentEpoch: current writer epoch.
• If activeReaderEpochs.length > 0, compute minReader = Math.min(...activeReaderEpochs). An object is safe to reclaim iff obj.retiredEpoch < minReader.
• If activeReaderEpochs.length === 0, no readers pin any prior epoch, so every retired object with obj.retiredEpoch <= currentEpoch (or < currentEpoch + 1) is reclaimed.
• Do not mutate inputs. Return { reclaimed: string[], retained: Array<{ id, retiredEpoch }> } preserving original order.
