# Mission: Operating Systems Engineering Mastery (2027)

## Why
Transition from a Junior Android Developer to a Senior Operating Systems / Systems / Android Platform Engineer by 2027—capable of debugging kernel-userspace boundaries, performance bottlenecks, memory/IPC subsystems, and shipping a resume-grade OS kernel project (`AegisOS-64`).

## Success looks like
- Explain and trace ARM64/x86-64 privilege transitions, `clone()`/`fork()`, EEVDF scheduling, `futex`, Binder IPC, 4-level/16KB paging, Buddy/SLUB/Scudo, MGLRU/ZRAM/`lmkd`, `io_uring`, F2FS/Ext4 crash consistency, Linux networking, `seccomp`/SELinux, pKVM, eBPF, GICv3 IRQs/`hrtimer`/`NO_HZ`, signals/ELF Full RELRO, `cpuidle`/thermal/`wakeup_source`, and Rust-for-Linux / Rust Binder from first principles.
- Pass all 60 runnable browser OS-VM coding labs and 120 diagnostic quizzes across Lessons 01–20.
- Build, benchmark, and defend the 5-milestone **AegisOS-64** ARM64 QEMU kernel & zero-copy IPC capstone on GitHub and in Senior Systems interviews.

## Constraints
- Ground every OS concept in Linux 6.x + ARM64 + Android AOSP internals where relevant.
- Self-contained interactive HTML lessons with runnable checks, progressive hints, final answers, and multi-option explanations.
- Target readiness for 2027 Senior Systems / Platform engineering interviews.

## Out of scope
- Purely theoretical OS history detached from modern Linux/ARM64/Android hardware.
- Legacy 16-bit x86 real-mode BIOS minutiae beyond boot-chain context.
