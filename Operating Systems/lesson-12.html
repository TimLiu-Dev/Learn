01 // MENTAL MODEL & INTERACTIVE SIMULATOR

From NIC DMA Ring to Socket Queue Without Wasting Copies

1. NIC DMA Ring & NAPI Interrupt Mitigation

Receive Livelock Problem: If a NIC triggers a hardware IRQ for every incoming 64-byte packet at line rate, the CPU spends 100% of its time saving/restoring trap frames and never runs user apps to drain sockets.

NAPI (New API) Hybrid IRQ + Poll:
1. NIC writes incoming packets into pre-allocated DMA descriptors in the RX Ring.
2. NIC raises one hardware IRQ.
3. Driver masks further RX IRQs for that queue and calls napi_schedule().
4. Kernel's NET_RX_SOFTIRQ loop invokes driver's poll(budget=64), draining up to budget frames. If the ring empties, IRQs are re-enabled (napi_complete_done); if packets remain, it reschedules fairly.

2. sk_buff Headroom, Socket Buffers & Zero-Copy

struct sk_buff (skb): As a packet climbs/descends TCP → IP → Ethernet, the kernel never reallocates or memcpys the payload to add/strip headers! An skb allocates extra headroom between head and data:

• skb_push(len): decrements data toward head to prepend a TCP/IP/ETH header in O(1).
• skb_pull(len): increments data toward tail to strip a lower-layer header in O(1).

Socket Queues & TIME_WAIT: Validated packets land in the socket's receive queue bounded by sk_rmem_alloc ≤ sk_rcvbuf (full buffer = packet drop + TCP zero-window). Closing active TCP connections enters TIME_WAIT (2×MSL = 60s) so delayed old packets can't corrupt a new connection on the same 4-tuple.

Zero-Copy Paths — sendfile(), splice(), MSG_ZEROCOPY & XDP:
• Standard read() + write(): 4 data copies (Disk DMA → Page Cache → User buf → Socket buf → NIC DMA) + 4 mode switches.
• sendfile(out_sock, in_file, &off, n): Directs kernel to attach Page Cache page descriptors straight into the socket's skb scatter-gather fragments → NIC DMA (0 CPU copies! Note: user-space TLS breaks this unless using kernel TLS / kTLS).
• splice(): Moves pages between any two FDs via a kernel pipe buffer.
• XDP (eXpress Data Path): Runs an eBPF program inside the NIC driver before sk_buff allocation—capable of XDP_DROP (DDoS mitigation at 20M+ pps/core), XDP_PASS, or XDP_TX.

02 // C & KERNEL REALITY

sk_buff Operations, NAPI Poll Loop, sendfile() & XDP

skbuff_napi.c — Linux NAPI Poll & Zero-Copy Header Push/Pull 
// Simplified NAPI poll & sk_buff pointer arithmetic (net/core/skbuff.c)
static inline unsigned char *skb_push_sim(struct sk_buff *skb, unsigned int len) {
  skb->data -= len;     // Grow toward skb->head (prepend TCP/IP/ETH header)
  skb->len  += len;
  BUG_ON(skb->data < skb->head); // skb_under_panic!
  return skb->data;
}

static inline unsigned char *skb_pull_sim(struct sk_buff *skb, unsigned int len) {
  if (len > skb->len) return NULL;
  skb->len  -= len;
  return skb->data += len; // Strip outer header without memcpy!
}

int my_nic_napi_poll(struct napi_struct *napi, int budget) {
  int work_done = 0;
  while (work_done < budget && rx_ring_has_packet(napi)) {
    struct sk_buff *skb = rx_ring_pop_skb(napi);
    skb->protocol = eth_type_trans(skb, napi->dev); // calls skb_pull(ETH_HLEN)
    napi_gro_receive(napi, skb);
    work_done++;
  }
  if (work_done < budget) {
    napi_complete_done(napi, work_done); // Ring drained: re-arm NIC RX IRQ!
    enable_nic_rx_irq(napi);
  }
  return work_done; // If work_done == budget, softirq keeps polling next round
}

TCP Congestion Control & Socket Memory Backpressure:
TCP maintains a congestion window (cwnd) and slow-start threshold (ssthresh). In Slow Start (cwnd < ssthresh), every ACK increments cwnd += 1 (exponential doubling per RTT). In Congestion Avoidance (cwnd ≥ ssthresh), each ACK adds 1 / cwnd (linear +1 MSS per RTT). On 3 duplicate ACKs (packet loss without full stall), TCP triggers Fast Recovery: ssthresh = max(2, floor(cwnd / 2)) and sets cwnd = ssthresh. Meanwhile, if the receiving app fails to call recv(), sk_rmem_alloc fills up and the kernel advertises TCP window = 0 (or drops UDP frames).
03 // ANDROID INTERNALS BRIDGE

Mobile Radio Tail Energy, Cronet/OkHttp & Android eBPF Netd

1. Mobile Radio Tail Energy & OkHttp / Cronet Reactor

The RRC Tail Tax: Transmitting a single 60-byte TCP keepalive wakes the cellular modem from RRC_IDLE to high-power RRC_CONNECTED, where it stays powered for a 5–15 second inactivity tail timer burning ~500mW! Bursting/batching telemetry via WorkManager and multiplexing streams over HTTP/2 or QUIC (HTTP/3) dramatically cuts battery drain.

OkHttp vs Cronet: OkHttp uses blocking sockets + thread pools (or HTTP/2 frame multiplexing per socket). Google's Cronet wraps Chromium's C++ network stack driven by an asynchronous epoll event loop with QUIC/0-RTT support and BBR-friendly pacing—essential on high-jitter cellular networks.

2. Android eBPF Traffic Accounting (netd / xt_bpf)

From xt_qtaguid to eBPF: Legacy Android used custom kernel netfilter modules to count per-UID bytes. Modern Android (9+) attaches BPF_PROG_TYPE_CGROUP_SKB programs directly to the cgroup v2 hierarchy via bpfloader and netd.

Zero-Lock Per-CPU Maps: On every ingress/egress sk_buff, the eBPF filter reads bpf_get_socket_uid(skb), checks per-UID Data Saver / background-restriction maps, and updates lock-free eBPF hash maps read by NetworkStatsService (TrafficStats) and dumpsys netstats.

LAB 2 OF 3 // SK_BUFF HEADROOM

Implement skbOps(skb, actions)

Simulate zero-copy header prepending (push) and stripping (pull) with strict pointer bounds checks.

Not Run
Specification: skb is { head, data, tail, end } (with head ≤ data ≤ tail ≤ end). actions is an array of { op: "push" | "pull", len: number }.
• Apply actions in order. Validate Number.isInteger(len) && len ≥ 0 (else return { ok: false, error: "EINVAL", data: skb.data, tail: skb.tail, len: skb.tail - skb.data }).
• On "push": if skb.data - len < skb.head, fail immediately with { ok: false, error: "HEADROOM_UNDERFLOW", data: skb.data, tail: skb.tail, len: skb.tail - skb.data }. Else skb.data -= len.
• On "pull": if skb.data + len > skb.tail, fail immediately with { ok: false, error: "LINEAR_OVERRUN", data: skb.data, tail: skb.tail, len: skb.tail - skb.data }. Else skb.data += len.
• If all actions succeed, return { ok: true, data: skb.data, tail: skb.tail, len: skb.tail - skb.data, headroom: skb.data - skb.head }.
LAB 3 OF 3 // TCP CONGESTION CONTROL

Implement tcpCwndUpdate(state, event)

Implement Slow Start, Congestion Avoidance, 3-dup-ACK Fast Recovery, and Timeout resets.

Not Run
Specification: Given state = { cwnd, ssthresh, dupAcks? } and event ("ACK" | "DUP_ACK" | "TIMEOUT"), return a new state object { cwnd, ssthresh, dupAcks, phase } without mutating state:
• "ACK": reset dupAcks = 0. If cwnd < ssthresh, cwnd = cwnd + 1 (Slow Start); else cwnd = cwnd + 1 / cwnd (Congestion Avoidance).
• "DUP_ACK": dupAcks = (state.dupAcks || 0) + 1. If dupAcks === 3, set ssthresh = Math.max(2, Math.floor(cwnd / 2)) and cwnd = ssthresh. If dupAcks > 3, inflate cwnd = cwnd + 1. (For 1 or 2 dup ACKs, keep cwnd and ssthresh unchanged.)
• "TIMEOUT": ssthresh = Math.max(2, Math.floor(cwnd / 2)), cwnd = 1, dupAcks = 0.
• Set phase to "FAST_RECOVERY" if dupAcks >= 3, else cwnd < ssthresh ? "SLOW_START" : "CONGESTION_AVOIDANCE".
