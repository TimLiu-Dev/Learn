Autonomous Coding Agent Glossary (Senior AI Engineer Standard)

Essential vocabulary, technical concepts, and architectural definitions required for Senior AI Engineers designing production-grade coding agents.

Pedagogical Purpose

This glossary acts as the single source of truth across all curriculum lessons and senior technical interview rounds. Every term defined here is strictly adhered to in lesson implementations.

Agentic Loop Core
The cyclical state machine where an LLM alternates between reasoning (thought), executing an action (tool invocation), receiving an environmental observation (stdout/file diff/error), and updating its working context until a terminal state is reached.
ReAct Pattern
Reasoning + Acting (Yao et al., 2022). A paradigm that prompts models to generate verbal reasoning traces alongside specific actions, significantly reducing hallucination and enabling dynamic plan adaptation based on tool feedback.
MCP (Model Context Protocol) Protocol
An open standard (originated by Anthropic) allowing models to securely discover, negotiate, and query client tools, database resources, and dev prompts across STDIO and SSE process boundaries.
Agent Skills Extensibility
Modular bundles of instructions, scripts, schemas, and assets dynamically discovered by agents through metadata indexing and loaded into context on demand (progressive disclosure) to prevent context window bloat.
Code Graph RAG Retrieval
Retrieval-Augmented Generation specifically engineered for codebases. Combines AST symbol call-graphs, import dependency trees, lexical BM25, and dense embeddings with cross-encoder re-ranking for multi-file comprehension.
Repo Map Context
A token-budgeted, graph-based structural summary of a codebase. Uses Tree-sitter AST symbol tags (definitions, calls, imports) and algorithms like PageRank to surface the most relevant file skeletons without overloading LLM context windows.
Tree-sitter Tooling
An incremental, language-agnostic parsing system that compiles source code into a concrete syntax tree (CST/AST). Enables ultra-fast symbol extraction, code chunking, and syntax-valid diff validation.
Prefix Caching / KV Cache Optimization
Structuring multi-turn prompts and system instructions so that common initial token sequences are reused in the inference engine's Key-Value memory, delivering up to 90% latency reduction and dramatic cost savings.
Subagent Swarms Orchestration
A hierarchical pattern where an Orchestrator agent delegates bounded tasks to specialized subagents (Planner, Coder, Critic) communicating through structured message protocols or shared artifacts.
Git Worktree Isolation Workspaces
A mechanism giving parallel subagents independent directory checkouts linked to the same underlying Git repository, preventing concurrent subagents from overwriting each other's work during multi-step tasks.
Surgical Editing Execution
Applying localized code changes (via Search/Replace blocks or unified diffs with fuzzy context matching) rather than rewriting full files, preventing regression, preserving formatting, and saving tokens.
Self-Healing Loop Feedback
An automated feedback mechanism where the agent runs test suites (e.g. pytest, jest), linter checks (ruff, eslint), or type-checkers (mypy), parses tracebacks, and iteratively generates patches until all tests pass.
Reflexion Learning
Verbal reinforcement learning (Shinn et al., 2023) where an agent analyzes execution tracebacks and self-generates linguistic post-mortems stored in episodic memory to adjust subsequent attempts without weight fine-tuning.
SWE-bench Evaluation
The premier benchmark (Jimenez et al., 2024) evaluating agents on real-world GitHub issues across popular open-source repositories. Measures pass@1, pass@k, and cost-per-resolved-issue in isolated Docker containers.
Sandbox Isolation Security
Executing untrusted shell commands and compiled code generated by LLMs within isolated micro-VMs (Firecracker), lightweight containers (Docker/gVisor), or constrained subprocesses to prevent host compromise.
Stop Sequence Inference
A specific token sequence (e.g. Observation:) that signals the LLM inference engine to halt generation immediately so the environment can execute a requested tool and inject real output.
Test-Time Compute (TTC) Reasoning
Scaling inference-time search compute (rollouts, branch exploration, verifiers) to evaluate multiple trajectory candidates instead of relying on greedy single-turn token sampling.
Process Reward Model (PRM) Verification
A scoring engine (learned or execution-based) that evaluates intermediate reasoning and tool-action steps rather than scoring only the final terminal outcome. Enables early dead-end pruning.
Event Sourcing (Agent Store) Durability
An architectural pattern where every state transition, LLM response, and tool observation is recorded in an immutable, append-only log. Enables deterministic crash recovery, time-travel debugging, and zero-token replays.
BPE & Nucleus Sampling (top_p) Foundations
Byte-Pair Encoding splits rare identifiers and syntax into variable-length subword tokens. Nucleus (top_p) sampling truncates next-token candidates dynamically once cumulative softmax probability reaches threshold p.
HNSW & Cross-Encoder Reranking RAG
Hierarchical Navigable Small World (HNSW) multi-layer graphs enable O(log N) approximate nearest-neighbor retrieval. Second-stage Cross-Encoders inspect [query, chunk] pairs jointly to reorder top candidates with high precision.
Indirect Prompt Injection Security
OWASP LLM01 attack where adversarial instructions hidden inside untrusted external text (GitHub issues, docs, MCP outputs) hijack agent reasoning. Requires trust-boundary delimiters, PII/secret redaction, and least-privilege tool gates.
PagedAttention & LLM-as-a-Judge Serving & Evals
vLLM's PagedAttention stores KV caches in non-contiguous memory pages for high-throughput continuous batching. Dual-pass swapped LLM-as-a-Judge harnesses mitigate slot-order position bias during non-deterministic evals.
LoRA / QLoRA & DPO Adaptation
LoRA freezes base weights and trains low-rank matrices (<1% params) to adapt style or latency. Direct Preference Optimization (DPO) aligns models from chosen/rejected pairs without training a separate RLHF reward model.
Android AICore & LiteRT Mobile Edge
OS-managed system service exposing on-device Gemini Nano on Android without APK bloat (AICore), paired with LiteRT / LiteRT-LM for deploying custom INT4/INT8 quantized edge models with NPU/GPU/CPU delegation.
