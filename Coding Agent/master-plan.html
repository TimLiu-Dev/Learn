The 2-Part Capstone Project Strategy

To establish hireability for a 2027 Senior AI Engineer role, you will build and document two distinct projects across this curriculum:

Part 1: Foundational MVP

Micro-Coder (Minimal ReAct Agent)

A zero-dependency autonomous coding agent implemented from scratch in pure Python (~400 lines). Demonstrates mastery of the core state machine without framework bloat.

  • Pure ReAct loop (Thought → Action → Observation) with custom stop sequences.
  • File inspection, surgical search/replace, and sandboxed bash execution tools.
  • Automated self-healing loop: executes pytest, parses tracebacks, and iterates patches until green.
  • Verified on 10 canonical bug-fix scenarios.

Part 2: Production End-to-End

AegisCoder (Senior Portfolio System)

A production-grade, resume-defining open-source coding agent designed for real-world codebases. Built to pass senior technical interviews with flying colors.

  • Tree-sitter Repo Map & Code Graph: PageRank-scored AST symbol graphs for multi-thousand file repositories (Python, Kotlin, Java).
  • Model Context Protocol (MCP): Native MCP client & server supporting custom IDE, DB, and devtool integrations.
  • Surgical Patching Engine: Unified diff parser with fuzzy context fallback and AST-aware validation.
  • Hierarchical Multi-Agent Team: Orchestrator, Planner, Coder, and Test Verifier subagents with Git worktree isolation.
  • SWE-bench Evaluation Pipeline: Automated Dockerized test harness evaluating pass@1 and cost-per-issue.
  • Production CI/CD, OpenTelemetry tracing, documentation whitepaper, and GitHub showcase.

Senior AI Engineer (2027) Competency Matrix

How senior AI engineers differentiate from standard AI application developers:

Frontier Competency Junior / Mid-Level AI Builder Senior AI Engineer (2027 Standard)
Async LLM Gateways Writes blocking synchronous API scripts with brittle retries. Bridges Kotlin Coroutines intuition into Python asyncio, SSE streaming FastAPI wrappers, bounded 429 backoff, and complexity model routing.
Agent Skills & MCP Hardcodes bespoke prompt wrappers or ad-hoc functions. Architects standardized Model Context Protocol (MCP) servers & clients; designs modular Agent Skills with dynamic progressive disclosure to conserve context.
Code & Production RAG Dumps raw files or naive chunk embeddings into context. Builds Tree-sitter AST symbol graphs, PageRank repo maps, HNSW vector indexing, Cross-Encoder reranking, and Ragas faithfulness evals.
Context & Cache Engineering Suffers from context window overflow and astronomical token bills. Implements dynamic context compaction, micro-summarization, and KV cache / prefix caching optimization, achieving 90% cost reduction and sub-second TTFT.
AI Security (OWASP LLM01) Feeds untrusted GitHub issues or MCP outputs raw into prompts. Enforces trust-boundary delimiters, HTML comment stripping, secret/PII egress redaction, and least-privilege container/HITL gates against indirect injection.
Multi-Agent Swarms Monolithic agent trying to plan, write, and verify simultaneously. Orchestrates hierarchical subagent swarms (Planner, Coder, Critic) with isolated Git worktrees so subagents work in parallel without file collisions.
Evals, vLLM & LoRA Tradeoffs Guesses prompt quality visually and fine-tunes prematurely. Builds position-debiased LLM-as-a-Judge suites, sizes vLLM PagedAttention + INT4 VRAM budgets, and knows when RAG beats LoRA/DPO.
Polyglot & Mobile Edge AI Limited to toy Python scripts and cloud-only HTTP calls. Drives Kotlin/Java ASTs, Gradle loops, Compose multimodal vision verifiers, and hybrid on-device Android AICore (Gemini Nano) / LiteRT routers.
Verification & Self-Healing Blindly accepts code outputs without automated validation. Integrates automated self-healing loops (pytest/gradle), localized frame traceback parsing, and Reflexion verbal reinforcement learning.
Benchmarking & Telemetry Manually tests 2 or 3 examples and hopes for the best. Constructs reproducible Dockerized SWE-bench harnesses measuring Pass@1, Pass@5, and cost-per-issue curves with distributed OpenTelemetry tracing.
Test-Time Compute (TTC) Relies solely on greedy single-turn ReAct loops that compound early errors. Implements trajectory tree search (MCTS / Best-of-N) guided by execution-based Process Reward Models (PRMs) to explore divergent hypotheses and prune dead ends before disk commits.
Durability & Resumability Holds fragile in-memory arrays in a script; crashes lose all context on network drops or rate limits. Architects event-sourced state machines (Temporal / SQLite WAL) with monotonic sequence logs and snapshots for instant zero-loss recovery and non-deterministic tool replay caching.
