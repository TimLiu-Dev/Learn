# Mission: Senior AI Coding Agent Engineer (2027 Frontier)

## Why
Transition to a Senior AI Engineer specializing in autonomous coding agents, developer infrastructure, and tool-use systems by 2027. Build the architectural judgment and implementation mastery required to design production-grade coding agents (Agent Skills, Model Context Protocol, Hierarchical Subagent Swarms, Tree-sitter Repo Maps, Code Graph RAG, Prefix Caching Optimization, Sandboxed Execution, Self-Healing Loops, Test-Time Compute Trajectory Search, and Durable Event Sourcing) and ship a resume-defining, hireable end-to-end portfolio project.

## Success looks like
- Build and ship a working Part 1 MVP autonomous coding agent from first principles in Python (Micro-Coder: ReAct loop, file tools, and test repair).
- Architect and ship a Part 2 production-grade coding agent system (AegisCoder) featuring AST code indexing via Tree-sitter, Code Graph RAG, Model Context Protocol (MCP) client/server, Agent Skills with progressive disclosure, hierarchical subagents with Git worktree isolation, secure Docker/gVisor sandboxing, SWE-bench evaluation harness, and durable event-sourced session resumability.
- Master agentic loop mechanics, KV cache/prefix caching optimization, context compaction, diff parsing, AST symbol graphs, test-time compute search (MCTS/PRMs), and evaluation benchmarks (SWE-bench / HumanEval).
- Pass rigorous technical interviews for Senior AI Engineer / Agent Platform roles with deep architectural rationale and hands-on code fluency.

## Constraints
- Hands-on, interactive format: each lesson must feature runnable code practice with hints/solutions and interactive quizzes with balanced choices and full rationales.
- Browser-native execution without external dependencies (Pyodide in-browser WebAssembly execution with resilient fallbacks).
- No fluff or hand-waving: every abstraction is unpacked to runnable code and concrete architectural diagrams.

## Out of scope
- Pre-training LLMs from scratch or GPU cluster CUDA kernel tuning.
- Generic consumer chatbots or prompt-only wrapper apps without tool use and execution sandboxes.
