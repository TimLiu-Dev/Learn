1. Hybrid Perception: Semantics Tree + Screenshot Tiles

Sending a 1440×3120 raw Pixel screenshot on every agent step burns thousands of visual tokens (~ceil(W / 28) * ceil(H / 28) tile formula or downscaled resolution buckets) and still leaves exact pixel coordinates blurry to guess. Senior mobile agents fuse two signals:

  • Deterministic Layout Tree Check: Extract bounding rectangles [left, top, right, bottom] from Jetpack Compose semantics / UIAutomator dumps to catch exact overlaps and off-screen clipping mathematically in <1ms.
  • Downscaled Multimodal Vision Call: Resize screenshots cleanly (e.g., max edge 1092px) and place image blocks before text prompts ONLY when structural geometry passes or visual contrast/aesthetics need human-like inspection.
