1. Kotlin Coroutines vs. Python asyncio Rosetta Stone

Why does synchronous Python kill agent throughput? An LLM call blocks waiting on network I/O for 2–20 seconds per turn. Running multi-file retrieval or subagent workers sequentially wastes wall-clock time unless you yield control back to an event loop:

  • suspend fun ↔ async def (coroutine returning an awaitable instead of blocking the thread).
  • kotlinx.coroutines.async { }.awaitAll() ↔ asyncio.gather(*tasks) (concurrent fan-out across I/O-bound tool or LLM calls).
  • Flow<TokenChunk> ↔ AsyncGenerator[str, None] fed directly into FastAPI StreamingResponse(..., media_type="text/event-stream").
  • OkHttp / Retrofit Interceptor ↔ httpx.AsyncClient with explicit 429 Retry-After exponential backoff + jitter.

2. Handling SSE Frames & Model Tier Routing

In Server-Sent Events (SSE), every payload arrives framed as data: <json>\n\n. A robust client buffer ignores blank keepalive lines and comments (starting with :), terminates cleanly on data: [DONE], and stitches fragmented text deltas and partial JSON arguments before tool validation. Combining a cheap fast model for routine routing/classification with a frontier model for multi-file debugging keeps unit economics sustainable.
