Building "Micro-Coder": The 400-Line Autonomous Agent Architecture

In this milestone capstone, you will construct Micro-Coder: a fully functional, self-contained 400-line autonomous coding agent in pure Python. Micro-Coder synthesizes the foundational pillars of the curriculum—ReAct state loops, surgical file editing tools, sandboxed subprocess command execution, and automated pytest repair cycles—into an elegant, transparent architecture designed for interview live demonstrations and production prototyping.

Enterprise coding agents often obscure their internal control loops beneath layers of third-party abstractions. To truly master autonomous coding agents, you must be capable of drafting the end-to-end engine from scratch on a whiteboard or in a live coding interview.

2. The Agent-Computer Interface (ACI) for Code Manipulation

A common junior mistake is granting the LLM an unconstrained bash prompt and letting it use cat, sed, or echo "..." > file.py. This approach consistently fails on non-trivial codebases for three reasons:

  1. Context Flooding: Running cat on a 2,000-line file immediately pollutes the context window, triggers KV-cache degradation, and escalates API costs.
  2. Escaping & Quoting Failures: Shell commands like sed -i 's/.../.../g' break when code snippets contain double quotes, backslashes, single quotes, or newlines.
  3. Silent File Destruction: An unconstrained echo "new code" > file.py completely overwrites existing source files if the model hallucinates or truncates lines.

Micro-Coder solves this by implementing three surgical tools: 

# 1. Surgical File Viewer (Paginated line ranges with line numbers)
view_file_lines(path: str, start: int, end: int) -> str

# 2. Block Replacer (Exact unique text matching)
replace_file_content(path: str, target_block: str, replacement_block: str) -> bool

# 3. Guarded Subprocess Runner (With strict timeouts and truncated stdout)
run_bash_command(cmd: str, timeout_seconds: int = 30) -> tuple[int, str]

3. The Complete 400-Line Micro-Coder Architecture

Below is the complete reference implementation of Micro-Coder. Notice how cleanly separation of concerns is preserved: 

import subprocess
import os
import re
from dataclasses import dataclass, field
from typing import List, Dict, Tuple, Optional

@dataclass
class ToolResult:
    success: bool
    output: str
    error: Optional[str] = None

class WorkspaceEnvironment:
    """Manages isolated disk operations and test execution."""
    def __init__(self, root_dir: str):
        self.root = os.path.abspath(root_dir)

    def _resolve(self, relative_path: str) -> str:
        full_path = os.path.abspath(os.path.join(self.root, relative_path))
        if not full_path.startswith(self.root):
            raise PermissionError("Path traversal attack detected outside workspace sandbox.")
        return full_path

    def read_lines(self, rel_path: str, start: int = 1, end: int = 100) -> str:
        path = self._resolve(rel_path)
        if not os.path.exists(path):
            return f"Error: File '{rel_path}' does not exist."
        with open(path, "r", encoding="utf-8") as f:
            lines = f.readlines()
        selected = lines[max(0, start - 1):end]
        numbered = [f"{i + start:4d} | {line}" for i, line in enumerate(selected)]
        return "".join(numbered)

    def replace_block(self, rel_path: str, target: str, replacement: str) -> str:
        path = self._resolve(rel_path)
        with open(path, "r", encoding="utf-8") as f:
            content = f.read()
        if target not in content:
            return "Error: target_block not found in file. Ensure exact whitespace match."
        if content.count(target) > 1:
            return "Error: target_block matches multiple locations. Provide more surrounding context lines."
        new_content = content.replace(target, replacement, 1)
        with open(path, "w", encoding="utf-8") as f:
            f.write(new_content)
        return f"Successfully updated '{rel_path}'."

    def run_tests(self, test_cmd: str = "pytest -q") -> Tuple[bool, str]:
        try:
            proc = subprocess.run(
                test_cmd, shell=True, cwd=self.root,
                capture_output=True, text=True, timeout=30
            )
            passed = (proc.returncode == 0)
            output = proc.stdout if passed else proc.stdout + "\n" + proc.stderr
            return passed, output.strip()
        except subprocess.TimeoutExpired:
            return False, "Error: Test execution timed out (30s limit exceeded)."
