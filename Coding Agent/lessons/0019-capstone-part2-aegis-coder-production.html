Building "AegisCoder": Production Multi-Agent Coding System

While Micro-Coder demonstrated the core autonomous loop in 400 lines, enterprise environments require distributed resilience, semantic code intelligence, and rigorous sandboxing. In this capstone, you will architect AegisCoder: a production-grade multi-agent coding platform featuring the Model Context Protocol (MCP), Tree-sitter Code Graph RAG, isolated Git worktrees, and Dockerized SWE-bench evaluation harnesses.

Primary Source & Architecture Reference

"Model Context Protocol Specification" & "SWE-bench Evaluation Standard" — Anthropic (2024) & Carlos E. Jimenez et al. (Princeton & Chicago, ICLR 2024).

Model Context Protocol Docs → • Core Insight: Decoupling tool servers from agent orchestrators via JSON-RPC 2.0 (MCP) and indexing codebases via Tree-sitter symbol graphs solves the context window bottleneck and enables horizontal scaling of specialized subagents.

1. The Architectural Shift: Single-Agent vs. Distributed Mesh

In Lesson 0018, a single agent handled everything: reading files, reasoning about test failures, editing lines, and running bash scripts. When applied to 500,000-line repositories, this monolithic pattern breaks down:

  • Context Pollution: File listings, tool schemas, tracebacks, and code snippets quickly crowd out the model's instruction-following attention.
  • Cognitive Overload: Expecting one prompt to simultaneously act as a senior software architect, surgical editor, and QA test engineer causes frequent regressions.
  • Security Exposure: Running tests in the host subprocess risks catastrophic file corruption or remote code execution.

2. Tree-sitter Symbol Indexing & Code Graph RAG

AegisCoder does not dump raw file contents into prompts. Instead, it maintains a lightweight in-memory Symbol Index constructed via Tree-sitter AST queries: 

// Example Symbol Index Entry
{
  "authenticate_jwt": {
    "file": "src/security/auth.py",
    "line": 42,
    "kind": "function_definition",
    "signature": "def authenticate_jwt(token: str, secret: str) -> User",
    "callers": ["src/api/routes.py:105", "src/middleware/guard.py:28"],
    "dependencies": ["jwt.decode", "User.find_by_id"]
  }
}

When an issue mentions "JWT token expiration failure", the Orchestrator does not greedily read all files. It queries the Symbol Index, identifies authenticate_jwt, and passes only its immediate 2-hop neighborhood in the dependency graph to the Researcher subagent.

3. The Model Context Protocol (MCP) Backbone

Rather than writing ad-hoc tool dispatchers, AegisCoder connects to tool servers using the Model Context Protocol (MCP):

  • mcp/list_tools: Dynamic discovery of server capabilities (e.g., Docker execution, git operations, database queries).
  • mcp/call_tool: Strictly validated JSON-RPC 2.0 payloads with return envelopes containing content blocks and error codes.
  • Worktree Isolation: Every Coder subagent operates inside an isolated Git worktree (git worktree add ../worktree-agent-1 fix-branch), preventing dirty file states from leaking into production branches.
