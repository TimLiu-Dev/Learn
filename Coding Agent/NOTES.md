# Notes & Learner Preferences

## Learner Profile & Target
- **Target Role**: Senior AI Engineer (2027 frontier) specializing in AI Coding Agents, developer tooling, and autonomous software engineering systems.
- **Language Architecture Preference**:
  - **Core Curriculum**: Kept **purely Python** (Python 3.12) for core agent runtimes, algorithms, and interactive in-browser Pyodide labs to ensure maximum clarity, speed, and standard AI engineering alignment.
  - **JVM & Mobile Extension**: Dedicated **Kotlin & Java Extension Section** added to teach polyglot codebase support (Tree-sitter AST parsing of `.kt`/`.java`, Gradle/Maven test harness execution, and JVM enterprise agent design).
- **Pedagogical Format**:
  - Interactive HTML lessons with clear theory, diagrams, and citations.
  - In-browser runnable code practice with hints, automated test verification, and complete final answer.
  - Interactive multiple-choice quizzes with strict equal-length options (per pedagogy guidelines) and comprehensive explanations for both correct and incorrect options.
- **Master Plan**:
  - Comprehensive end-to-end curriculum roadmap in HTML acting as an interactive legend for all 25 lessons across 9 modules.
  - Active challenge scaffolding: every lesson features structured `# TODO` and `raise NotImplementedError(...)` starter code requiring real implementation effort, backed by 100% verified reference solutions and tests.
  - Module 9 (2027 Frontier): Dedicated lessons on Test-Time Compute (TTC) Trajectory Search (MCTS / PRM Verifiers) and Durable Event-Sourced Agent Execution (Session Checkpointing & Replay).
- **Capstone Project (2-Part)**:
  - Part 1: Fundamental MVP (Micro-Coder: ReAct loop, file tools, terminal sandbox, automated test repair).
  - Part 2: Production-grade End-to-End System (AegisCoder: MCP client/server, Tree-sitter AST repo map, fuzzy diff engine, Docker sandbox isolation, SWE-bench evaluation pipeline, resume-grade open-source package).
- **Benchmark Lesson**:
  - Lesson 0001 sets the standard for quality, styling, code runner functionality, and quiz design.
