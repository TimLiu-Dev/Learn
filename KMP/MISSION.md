# Mission: Master Kotlin Multiplatform (KMP) & Compose Multiplatform

## Why
Transition into a high-impact Multiplatform Mobile Engineer capable of architecting, implementing, testing, and shipping production-grade dual-platform (Android & iOS) applications from a single codebase, qualifying for competitive KMP roles in the modern job market.

## Success looks like
- Architect clean, reactive multiplatform codebases using Kotlin 2.x, Coroutines, and Flow with unidirectional data flow (MVI/MVVM).
- Confidently build and share UI across Android and iOS using Compose Multiplatform, while understanding how to integrate with native SwiftUI where required.
- Build resilient data layers using Ktor 3.x, Kotlinx.Serialization, and multiplatform persistence (Room KMP / SQLDelight) with offline-first synchronization.
- Master native platform bridges: `expect`/`actual`, platform APIs (camera, biometrics, secure keychain/keystore), and Swift/Kotlin interop using SKIE and SPM.
- Implement comprehensive automated testing (unit testing flows with Turbine, mock engines with Ktor, and Compose Multiplatform UI tests).
- Design and ship an end-to-end production capstone application with CI/CD automation ready for a professional portfolio and technical interviews.

## Constraints
- Focus primarily on mobile platforms (Android & iOS) where production industry demand and hiring are concentrated.
- Hands-on, practical code examples and exercises in every lesson to maximize retention.
- Stick to established, industry-standard, actively maintained libraries (Kotlin 2.x+, Ktor 3+, Compose Multiplatform, Room/SQLDelight, Koin/Kotlin-Inject, SKIE, Coil 3).

## Out of scope
- Desktop/Web (JVM desktop / Wasm) deep-dives, except where trivial or illuminating, to keep 95% of bandwidth focused on Mobile (Android & iOS).
- Legacy Kotlin Multiplatform patterns (e.g. old memory model, pre-K2 compiler architectures, obsolete Cocoapods-only setups).
