# Learner Profile & Working Notes

## Preferences & Constraints
- **Goal**: Full mastery of Kotlin Multiplatform (KMP) from scratch to production-ready, aiming for a senior mobile multiplatform engineer role.
- **Tech Stack Horizon**: Modern best practices (Kotlin 2.x+, K2 compiler, Compose Multiplatform, Ktor 3.x, Room KMP / SQLDelight, Koin / Kotlin-Inject, SKIE, Coil 3, Jetpack Navigation Multiplatform).
- **Delivery Requirements**:
  - Every lesson must include concrete, production-grade code examples.
  - **In-Browser Interactive Code Practice**: Every lesson HTML must contain an interactive code editor/practice widget where the learner can write/modify code, click "Run / Check Solution" to run automated tests with immediate diagnostic feedback, access progressive hints, and reveal the annotated final answer/solution.
  - **Comprehensive Multiple-Choice Quizzes**: Code quizzes with options of uniform length. Upon selection, must clearly explain **why** the correct option is right AND **why** each distractor option is incorrect.
  - Clean HTML lessons in `./lessons/` sharing reusable components in `./assets/`.
  - Compressed reference guides in `./reference/` for long-term quick lookup.
  - Culmination in an end-to-end, portfolio-grade capstone project suitable for resumes and technical interviews.
