Clean Architecture Layer Boundaries in KMP

Adopt Clean Architecture, define strict layer boundaries, and understand what to share vs. what to keep platform-native.

Clean Architecture Boundary Rules

  • commonMain (Domain): Entities, Use Cases, Repository Interfaces. Zero Android/Apple SDK dependencies.
  • commonMain (Data): Repository Implementations, Ktor Client, SQLDelight/Room Database.
  • Presentation: ViewModels, StateFlow, Compose Multiplatform or SwiftUI.
