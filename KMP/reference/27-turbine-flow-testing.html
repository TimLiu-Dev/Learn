Turbine Flow Testing Reference & Patterns

Test reactive StateFlow emissions, debounce delays, and error states deterministically with Cash App's Turbine.

Turbine Assertion Methods

  • awaitItem(): T: Awaits the next emission.
  • awaitComplete(): Awaits successful completion.
  • awaitError(): Throwable: Awaits an exception emission.
  • cancelAndIgnoreRemainingEvents(): Clean exit for StateFlow.
