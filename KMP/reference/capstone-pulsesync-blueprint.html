PulseSync: Architecture Blueprint & Technical Specification

Decentralized Incident & Operations Hub: A production-grade multiplatform reference application proving end-to-end KMP architectural mastery.

1. Monorepo Module Layout

In accordance with enterprise best practices, PulseSync uses Gradle convention plugins (build-logic) and a layered modular architecture:

PulseSync/ ├── build-logic/ ← Gradle Convention Plugins │ └── convention/src/main/kotlin/ ← Shared KMP, Compose, and Android plugins ├── gradle/ │ └── libs.versions.toml ← Centralized Version Catalog ├── core/ │ ├── model/ (commonMain) ← Pure Kotlin Domain Entities (Zero dependencies) │ ├── network/ (commonMain, androidMain, iosMain) ← Ktor 3.x Client & WebSockets │ ├── database/ (commonMain, androidMain, iosMain) ← Jetpack Room KMP + SQLite │ ├── data/ (commonMain) ← Offline-First Repositories (SSOT) │ ├── di/ (commonMain, androidMain, iosMain) ← Koin / Kotlin-Inject Module Graph │ └── ui/ (commonMain) ← Shared Design System (Material 3 Adaptive) ├── feature/ │ ├── incidents/ (commonMain) ← Incident List & Detail MVI Screens │ └── analytics/ (commonMain) ← Real-Time Telemetry Graphs ├── composeApp/ (androidMain, iosMain) ← Unified Compose Multiplatform Application └── iosApp/ (SwiftUI) ← Native iOS Companion Widget & App Host

3. Step-by-Step Implementation Milestones

Milestone 1: Monorepo Scaffolding & Core Models Phases 0 & 1

Configure gradle/libs.versions.toml and modular project layout. Define immutable domain models (Incident, TelemetryEvent, IncidentSeverity) and pure repository interfaces in core:model.

Milestone 2: Offline-First Engine (Room KMP + Ktor 3) Phases 3 & 4

Implement Ktor 3 HTTP client with token refresh interceptor. Configure Room KMP database with BundledSQLiteDriver. Construct the OfflineFirstIncidentRepository streaming Room cached data while syncing delta updates via Ktor.

Milestone 3: Reactive State Machines & SKIE Swift Bridge Phases 2 & 7

Build IncidentViewModel utilizing androidx.lifecycle.ViewModel and StateFlow. Configure SKIE to expose state as Swift AsyncSequence and Kotlin sealed interfaces as Swift native enums.

Milestone 4: Dual-UI Implementation (Compose + SwiftUI) Phases 6 & 7

Build the main cross-platform UI using Compose Multiplatform with Adaptive Material 3. Build a native iOS SwiftUI WidgetKit extension bound directly to the shared KMP core via SKIE.

Milestone 5: Verification, Testing & Matrix CI/CD Phases 8 & 9

Achieve 85%+ automated test coverage using Turbine, Ktor MockEngine, and Compose semantic testing. Set up GitHub Actions workflow building Android AAB and iOS test XCFramework.
