Compose Multiplatform UI Testing & Semantics

Author cross-platform UI tests using Compose UI test matchers, semantics assertions, and simulated user touch gestures.

Essential Compose Test Matchers

  • onNodeWithTag("tag"): Locale-independent matching.
  • onNodeWithText("title"): Visible text matching.
  • performClick() / performTextInput("text"): Gestures.
  • assertIsDisplayed() / assertDoesNotExist(): Assertions.
