macOS Environment Pre-Flight Checklist

Configure Java 21, Xcode Developer Paths, and kdoctor before compiling Kotlin Multiplatform targets.

1. Diagnostic System Summary

Tool / SDK Standard Path Purpose
Android Studio /Applications/Android Studio.app Android SDK, Emulator, Bundled JetBrains JDK 21
Xcode /Applications/Xcode.app iOS SDK, Simulators, Apple LLVM Clang toolchain
Java (JDK 21) $JAVA_HOME/bin/java Gradle daemon, K2 compiler backend, Android build tools
kdoctor Homebrew (brew install kdoctor) Official automated verification diagnostic tool

2. Key Terminal Commands

Set JAVA_HOME in ~/.zshrc:

# Use Android Studio's bundled OpenJDK 21
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export PATH="$JAVA_HOME/bin:$PATH"

Switch xcode-select to Full Xcode Toolchain:

# Point to full Xcode instead of basic CommandLineTools
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer

Verify Setup with kdoctor:

brew install kdoctor
kdoctor
Why xcode-select matters in KMP
Kotlin/Native links directly against the iOS SDK frameworks (like UIKit, Foundation, Security). If xcode-select points to /Library/Developer/CommandLineTools, the Kotlin/Native compiler will fail with SDK "iphoneos" not found. Switching it to /Applications/Xcode.app/Contents/Developer resolves this immediately.
