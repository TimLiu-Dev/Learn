StateFlow vs. SharedFlow vs. Channels Cheatsheet

Architect unidirectional MVI state machines using StateFlow for state and Channels for one-off side effects.

StateFlow vs Channel Decision Table

  • StateFlow: UI State (loading, error, content). Conflated, retains last value, replay = 1.
  • Channel: Side effects (Navigation, Toast, Dialog trigger). Delivered once, no replay.
