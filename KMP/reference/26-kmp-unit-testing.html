Multiplatform Unit Testing with kotlin.test Reference

Write deterministic unit tests for ViewModels, Use Cases, and Repositories running across JVM and Kotlin/Native runners.

CLI Testing Commands

  • ./gradlew allTests: Runs tests across all targets.
  • ./gradlew jvmTest / ./gradlew testDebugUnitTest: Android/JVM tests.
  • ./gradlew iosSimulatorArm64Test: iOS Simulator native tests.
