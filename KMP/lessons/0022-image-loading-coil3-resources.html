Image Loading & Multiplatform Resources

Load remote images with Coil 3 and access localized strings, custom fonts, and vector drawables using Compose Resources.

1. The Why & Architectural Mental Model

In Kotlin Multiplatform, resource management and image loading have evolved rapidly:

  1. Coil 3 (Multiplatform Coil): The premier image loading library for KMP. Supports asynchronous disk and memory caching, SVG decoding, and animated GIFs on Android, iOS, and Desktop.
  2. Compose Multiplatform Resources: JetBrains' official gradle plugin generating strongly typed accessors (Res.drawable.logo, Res.string.app_name) for assets stored in commonMain/composeResources/.

2. Production Code Examples

1. Loading Network Images with Coil 3 in commonMain

package com.pulsesync.ui.components

import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import coil3.compose.AsyncImage

@Composable
fun UserAvatar(imageUrl: String, contentDescription: String?) {
    AsyncImage(
        model = imageUrl,
        contentDescription = contentDescription,
        modifier = Modifier.size(48.dp)
    )
}

2. Accessing Multiplatform Strings & Drawables

import org.jetbrains.compose.resources.painterResource
import org.jetbrains.compose.resources.stringResource
import pulsesync.shared.generated.resources.Res
import pulsesync.shared.generated.resources.*

@Composable
fun AppHeader() {
    Icon(
        painter = painterResource(Res.drawable.ic_incident_alert),
        contentDescription = stringResource(Res.string.alert_icon_description)
    )
}

3. Production Pitfalls & Anti-Patterns

Pitfall: Using Coil 2 on KMP
Coil 2 was Android-only (dependent on Android Context and OkHttp). Do not import io.coil-kt:coil-compose. Always use Coil 3 (io.coil-kt.coil3:coil-compose) which is built from the ground up for Kotlin Multiplatform.
