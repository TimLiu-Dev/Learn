Reactive State with Flow, StateFlow & Channels

Architect unidirectional MVI state machines using StateFlow for state and Channels for one-off side effects.

1. The Why & Architectural Mental Model

In modern multiplatform UI architecture, unidirectional data flow (UDF / MVI) is standard. We distinguish between two kinds of data:

  1. Persistent UI State (e.g. Loading, Content, Error): Modeled via StateFlow<UiState>. It always retains the latest value and replays it to new subscribers (conflated).
  2. Transient Side Effects (e.g. Navigate to screen, Show Toast/Snackbar): Modeled via Channel<UiEffect> consumed as a Flow. Effects must be delivered exactly once and never re-triggered on screen rotation.

2. Production Code Examples

Official Jetpack Multiplatform ViewModel
Starting with AndroidX Lifecycle 2.8+, Google's official androidx.lifecycle.ViewModel and viewModelScope are fully multiplatform in commonMain. You no longer need third-party MVVM wrapper libraries!

Multiplatform MVI ViewModel using Official AndroidX Lifecycle

package com.pulsesync.presentation

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.channels.Channel
import kotlinx.coroutines.launch

data class IncidentListState(
    val isLoading: Boolean = false,
    val incidents: List = emptyList(),
    val errorMessage: String? = null
)

sealed interface IncidentEffect {
    data class ShowToast(val message: String) : IncidentEffect
    data class NavigateToDetail(val id: String) : IncidentEffect
}

class IncidentViewModel : ViewModel() {
    private val _uiState = MutableStateFlow(IncidentListState())
    val uiState: StateFlow = _uiState.asStateFlow()

    private val _effects = Channel(Channel.BUFFERED)
    val effects: Flow = _effects.receiveAsFlow()

    fun onRefreshClicked() {
        viewModelScope.launch {
            _uiState.update { it.copy(isLoading = true) }
        }
    }
}

3. Production Pitfalls & Anti-Patterns

Pitfall: Using StateFlow for One-Off Navigation Events
If you put navigateToDetail: String? inside your UI state StateFlow, any configuration change (such as rotating an Android phone or resizing an iPad split window) will re-emit the state and trigger navigation again. Use Channel for events!
