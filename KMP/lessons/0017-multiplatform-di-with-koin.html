Multiplatform Dependency Injection with Koin

Wire shared repositories, Ktor clients, Room databases, and multiplatform ViewModels using Koin 4.x.

1. The Why & Architectural Mental Model

In multiplatform projects, we need a Dependency Injection (DI) system that compiles on both JVM and Native. Koin is the most widely adopted pragmatic DI framework in the KMP industry:

  • Pure Kotlin, zero reflection on Kotlin/Native.
  • Declarative DSL (single, factory, viewModel).
  • Provides koinViewModel() directly for Compose Multiplatform.
  • Allows injecting platform-specific modules (e.g. platformModule() in androidMain vs iosMain).

2. Production Code Examples

Koin Multiplatform Module Definition

package com.pulsesync.di

import org.koin.core.module.Module
import org.koin.dsl.module
import org.koin.core.context.startKoin

val appModule = module {
    // 1. Singleton Network Client
    single { createHttpClient(get()) }

    // 2. Singleton Repository
    single {
        OfflineFirstIncidentRepository(localDao = get(), remoteApi = get())
    }

    // 3. Multiplatform ViewModel
    factory { IncidentViewModel(repository = get()) }
}

// Platform Module (expect/actual or passed from host app)
expect val platformModule: Module

fun initKoin() {
    startKoin {
        modules(appModule, platformModule)
    }
}

3. Production Pitfalls & Anti-Patterns

Pitfall: Calling startKoin Twice on iOS
On Android, startKoin is called once in Application.onCreate(). On iOS, calling startKoin multiple times (e.g. inside a SwiftUI View's init) throws KoinAppAlreadyStartedException. Ensure your Swift App struct calls KoinKt.initKoin() exactly once during app launch.
