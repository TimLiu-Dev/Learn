Production Network Resilience & Authentication

Implement automated OAuth2 token refresh mutexes, exponential backoff retries, and typed Result error modeling.

1. The Why & Architectural Mental Model

In production mobile apps, network requests fail due to flaky cellular towers, expired JWT tokens, and rate limits. A robust KMP networking layer requires:

  1. Ktor Auth Plugin: Automatically intercepts 401 Unauthorized responses, calls a refresh endpoint, stores the new token in SecureStorage, and retries the original request seamlessly.
  2. Refresh Mutex: If 5 concurrent requests fail with 401 simultaneously, they must wait for a single refresh call rather than firing 5 duplicate refresh requests.
  3. Domain Result Modeling: Never let raw HTTP exceptions bubble into ViewModels. Map responses into a typed Result<T, NetworkError>.

2. Production Code Examples

Ktor 3.x Bearer Auth with Token Refresh

package com.pulsesync.network

import io.ktor.client.*
import io.ktor.client.plugins.auth.*
import io.ktor.client.plugins.auth.providers.*

fun configureAuth(client: HttpClient, tokenProvider: TokenStorage) {
    client.plugin(Auth).bearer {
        loadTokens {
            val access = tokenProvider.getAccessToken()
            val refresh = tokenProvider.getRefreshToken()
            if (access != null && refresh != null) {
                BearerTokens(access, refresh)
            } else null
        }
        refreshTokens {
            // Executed automatically on 401 Unauthorized (Thread-safe mutex built into Ktor!)
            val newTokens = callRefreshApi(oldTokens?.refreshToken)
            tokenProvider.saveTokens(newTokens.accessToken, newTokens.refreshToken)
            BearerTokens(newTokens.accessToken, newTokens.refreshToken)
        }
    }
}

3. Production Pitfalls & Anti-Patterns

Pitfall: Refresh Endpoint Returning 401 Triggers Infinite Loop
Ensure your token refresh API call does NOT use the authenticated HttpClient instance! If the refresh token itself is expired, the refresh call will return 401, triggering an infinite recursive refresh loop. Use an unauthenticated client for the refresh call.
