💻 Interactive Code Practice: Build a Resilient Mock Interceptor

The technical implementation: Create an OkHttp interceptor that intercepts target URLs and returns mock JSON with realistic status codes.

OkHttp & Networking
Scenario: You need to test UI loading and success states for /api/v1/rewards without an active backend.

Your Task: Complete MockInterceptor:
  • Intercept requests when request.url.encodedPath.contains("rewards").
  • Construct a simulated 200 OK Response with JSON body.
  • Otherwise, forward the request via chain.proceed(request).
MockRewardsInterceptor.kt Kotlin / OkHttp3
💡 Hint: Check request.url.encodedPath. If it matches, construct:
Response.Builder().code(200).message("OK").request(request).protocol(Protocol.HTTP_1_1).body(mockJson.toResponseBody("application/json".toMediaType())).build().

🏆 Production Implementation:

class MockRewardsInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        val request = chain.request()

        if (request.url.encodedPath.contains("rewards")) {
            val mockJson = """{"points": 1450, "tier": "Gold", "status": "ACTIVE"}"""
            return Response.Builder()
                .code(200)
                .message("OK")
                .request(request)
                .protocol(Protocol.HTTP_1_1)
                .body(mockJson.toResponseBody("application/json".toMediaType()))
                .addHeader("content-type", "application/json")
                .build()
        }

        return chain.proceed(request)
    }
}
