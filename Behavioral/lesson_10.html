💻 Interactive Code Practice: Offline Conflict Resolution (LWW)

The core engine: Merge local offline edits with incoming remote server records using Last-Write-Wins with version clocks.

Offline Sync Conflict Engine
The Problem: When a field technician edits a record offline while another user edits it concurrently, naive sync overwrites local data and causes data loss!

Your Task: Complete resolveConflict(local: Record, remote: Record): Record:
  • If local.updatedAt > remote.updatedAt and local.isDirty: preserve local record and mark for upstream sync.
  • Else: accept remote record and set isDirty = false.
SyncConflictResolver.kt Kotlin / Offline-First
💡 Hint: Compare timestamps: if (local.isDirty && local.updatedAt > remote.updatedAt) local else remote.copy(isDirty = false).

🏆 Production Conflict Resolver:

class SyncConflictResolver {
    fun resolve(local: Record, remote: Record): Record {
        return if (local.isDirty && local.updatedAt > remote.updatedAt) {
            // Local offline modification is newer; preserve local and schedule upstream sync
            local
        } else {
            // Remote is newer or equal; accept remote authority and reset dirty flag
            remote.copy(isDirty = false)
        }
    }
}
