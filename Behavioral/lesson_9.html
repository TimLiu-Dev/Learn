💻 Interactive Code Practice: Build a Leak-Free Interop Bridge

The technical fix: Convert a legacy RxJava Observable/Flowable into a modern Kotlin StateFlow with automatic cancellation.

RxJava ↔ Kotlin Flow Interop
The Problem: The legacy code bridges RxJava to Flow using a raw callbackFlow, but forgets to handle coroutine cancellation via awaitClose, causing leaked RxJava subscriptions and memory leaks!

Your Task: Fix asSafeFlow():
  • Store the Disposable subscription.
  • Invoke awaitClose { disposable.dispose() } when the collector cancels.
RxFlowBridge.kt Kotlin / Coroutines & RxJava
💡 Hint: Call awaitClose { disposable.dispose() } at the bottom of the callbackFlow block.

🏆 Production Interop Bridge:

fun <T : Any> Observable<T>.asSafeFlow(): Flow<T> = callbackFlow {
    val disposable = subscribe(
        { value -> trySend(value) },
        { error -> close(error) },
        { close() }
    )

    // Critical: automatically disposes the RxJava subscription when Coroutine is cancelled
    awaitClose {
        disposable.dispose()
    }
}
