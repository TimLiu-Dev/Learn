💻 Interactive Code Practice: Eliminate Compose Recomposition Jank

The technical fix: Mark data models as `@Immutable` and provide explicit stable keys to prevent unnecessary LazyColumn redraws.

Jetpack Compose Stability
The Problem: The feed list below uses an unstable model and missing item keys. Whenever one post changes, the entire list recomposes, dropping frames and causing Jank in production!

Your Task:
  • Annotate PostItem with @Immutable.
  • Add key = { it.id } inside items(posts).
FeedScreen.kt Kotlin / Jetpack Compose
💡 Hint: Add @Immutable above data class PostItem(...) and change items(posts) to items(items = posts, key = { it.id }).

🏆 Production Stable Compose Implementation:

@Immutable
data class PostItem(
    val id: String,
    val title: String,
    val isLiked: Boolean
)

@Composable
fun FeedList(posts: List<PostItem>) {
    LazyColumn {
        items(
            items = posts,
            key = { post -> post.id } // Enables Compose to skip recomposition for unchanged items
        ) { post ->
            PostRow(post)
        }
    }
}
