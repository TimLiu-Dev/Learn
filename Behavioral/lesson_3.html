💻 Interactive Code Practice: Battery-Safe Background Worker

The technical solution: Configure WorkManager with strict battery and unmetered network constraints.

Jetpack WorkManager
The Problem: The PM asked for a recurring background synchronization every 15 minutes. The junior code uses a raw `PeriodicWorkRequestBuilder` without any constraints. On low-battery devices, this will wake up the cellular radio and CPU constantly, violating Google Play Vitals battery guidelines!

Your Task: Add Constraints.Builder() requiring:
  • setRequiresBatteryNotLow(true)
  • setRequiredNetworkType(NetworkType.UNMETERED) or NetworkType.CONNECTED
  • Set a safe backoff exponential retry policy.
SyncWorkerFactory.kt Kotlin / Android WorkManager
💡 Hint: Build constraints via: val constraints = Constraints.Builder().setRequiresBatteryNotLow(true).setRequiredNetworkType(NetworkType.CONNECTED).build() and attach them using .setConstraints(constraints).

🏆 Production Senior Implementation:

fun createSyncRequest(): PeriodicWorkRequest {
    val constraints = Constraints.Builder()
        .setRequiresBatteryNotLow(true)
        .setRequiredNetworkType(NetworkType.CONNECTED)
        .setRequiresStorageNotLow(true)
        .build()

    return PeriodicWorkRequestBuilder<SyncWorker>(15, TimeUnit.MINUTES)
        .setConstraints(constraints)
        .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS)
        .build()
}
