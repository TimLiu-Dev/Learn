💻 Interactive Code Practice: Low-Memory Trim Listener

The technical fix: Listen for Android OS low-memory callbacks and evict bitmap caches dynamically.

ComponentCallbacks2 / Memory
The Problem: On low-RAM Android devices, the app gets killed by the OS low-memory killer (LMK) during background switching because the bitmap cache fails to release memory.

Your Task: Implement onTrimMemory(level: Int):
  • When level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_CRITICAL: evict 100% of memory cache.
  • When level >= ComponentCallbacks2.TRIM_MEMORY_BACKGROUND: evict 50% of memory cache.
MemoryAwareCache.kt Kotlin / Android OS
💡 Hint: Use if (level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_CRITICAL) lruCache.evictAll() and else if (level >= ComponentCallbacks2.TRIM_MEMORY_BACKGROUND) lruCache.trimToSize(lruCache.size() / 2).

🏆 Production Memory Management:

class MemoryAwareCache(private val lruCache: LruCache<String, Bitmap>) : ComponentCallbacks2 {
    override fun onTrimMemory(level: Int) {
        when {
            level >= ComponentCallbacks2.TRIM_MEMORY_RUNNING_CRITICAL -> {
                // Free all memory when OS is critically starved
                lruCache.evictAll()
            }
            level >= ComponentCallbacks2.TRIM_MEMORY_BACKGROUND -> {
                // Trim 50% when app moves into background
                lruCache.trimToSize(lruCache.size() / 2)
            }
        }
    }

    override fun onConfigurationChanged(newConfig: Configuration) {}
    override fun onLowMemory() {
        lruCache.evictAll()
    }
}
