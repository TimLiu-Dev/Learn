# Teaching Notes & Student Profile

## Target Goal
- **Target Role**: Senior / Staff / Principal Software Engineer (L5 / L6 / E5 / E6 / IC5 / IC6)
- **Target Companies**:
  - Mid-Tech: Stripe, Datadog, Shopify, Airbnb, DoorDash, Figma
  - Big-Tech: Meta, Google, Uber, Netflix, Apple, Amazon
- **Target Interview Year**: 2027

## Language Strategy for Interviews
1. **Primary**: **Kotlin** (Top choice for 2027 OOD interviews: immutable `data class`, `sealed interface` FSMs, compile-time null safety, zero-boilerplate JVM concurrency).
2. **Secondary**: **Python** (High typing speed fallback; strictly use `@dataclass(frozen=True)`, type hints, `Enum`, and explicit locks).
3. **Tertiary**: **Java** (Universal enterprise fallback; utilize Java 17+ `record`, `sealed interface`, and `java.util.concurrent`).

## Learning Preferences & Conventions
- Preferred learning pace: Step-by-step master plan with immediate in-browser interactive practice.
- Working memory: Keep lessons tightly scoped with tangible wins per module.
- In-browser Sandboxes: Evaluated client-side in modern JS/TS for instant test feedback.
- Polyglot Reference: Every core architectural pattern is mapped directly to Kotlin, Python, and Java.
- Verification: Loop test suites until 100% green before proceeding to subsequent modules.
