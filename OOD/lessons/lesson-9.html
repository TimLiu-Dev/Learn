Big-Tech Flagship Case Studies: Ride Matchers & Distributed Sagas

Tackling top-tier FAANG architectural interview challenges: geospatial driver bucketing (Uber/Lyft), and the Distributed Saga Compensation Pattern for resilient multi-service workflows without two-phase commit.

1. The 2027 Big-Tech Reality: Handling Partial Distributed Failures

In microservice architectures, a single user checkout or ride booking spans multiple independent services:

  1. Inventory Service: Reserve item
  2. Payment Service: Charge credit card
  3. Fulfillment Service: Dispatch warehouse shipment

What happens if Step 1 and 2 succeed, but Step 3 fails due to a warehouse stockout? In monolithic apps, you could wrap everything in a database transaction (`BEGIN TRANSACTION ... ROLLBACK`). But across microservices with separate databases, local rollbacks are impossible.

2. The Saga Pattern: Orchestrated Compensations

A Saga is a sequence of local transactions. Every forward transaction $T_i$ has a corresponding compensating transaction $C_i$ that semantically undoes its effects:

  • Forward step $T_1$: Reserve Inventory $\rightarrow$ Compensation $C_1$: Release Inventory
  • Forward step $T_2$: Charge Card $\rightarrow$ Compensation $C_2$: Refund Card
  • Forward step $T_3$: Dispatch Order $\rightarrow$ FAILS!

Upon failure of $T_3$, the Saga Orchestrator executes compensations in strict reverse order: $C_2$ (Refund Card) followed by $C_1$ (Release Inventory).

3. Geospatial Ride Matching (Uber / Lyft Tier)

In ride-matching interviews, you cannot do an $O(N)$ distance scan across 500,000 active drivers. Senior candidates partition drivers into Geohashes or QuadTree spatial cells:

GeospatialPartitioning.ts
// Drivers indexed by Spatial Cell (e.g. Geohash 6-character precision ~1.2km)
class SpatialDriverIndex {
  private cells = new Map<string, Set<Driver>>();

  findAvailableNearby(riderGeohash: string): Driver[] {
    const neighborCells = this.getAdjacentCells(riderGeohash);
    // O(1) cell lookup + small local filter
    return neighborCells.flatMap(cell => Array.from(this.cells.get(cell) || []))
                        .filter(d => d.isAvailable());
  }
}

Senior Phrasing to Use

"Because this transaction crosses service boundaries, traditional two-phase commit is unacceptable due to locking and latency. I will model an orchestrated Saga with forward operations and explicit backward compensations. If payment succeeds but fulfillment fails, the orchestrator triggers an idempotent refund compensation."

Instant Disqualification Trap

Assuming network calls never fail, or leaving customer credit cards charged without a compensation mechanism when an inventory reservation or delivery step throws an unhandled error.
