Alternatively, you can serve locally via Python:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

## 🛠️ Feature Highlights in Every Lesson
1. **Senior Theory & 2027 Evolution**: High-signal explanations contrasting junior anti-patterns with senior designs.
2. **Interactive Practice Studio**: In-browser code editor with real-time test execution.
3. **Automated Assertion Suite**: Verifies domain invariants, edge cases, immutability, and defensive copying.
4. **Progressive Hints**: Hint 1 (Architectural idea) → Hint 2 (Algorithmic guard) → Reveal Official Solution.
5. **Interactive Multiple-Choice Quizzes**: Diagnostic senior questions with deep explanations of why the right answer is correct and why each distractor is flawed.
6. **45-Minute Interview Playbook**: Step-by-step interview time management, verbal scripts, and disqualification traps.
