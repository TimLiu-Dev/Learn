# Mission: Object-Oriented Design & Low-Level Design (2027 Mid-Tech & Big-Tech Bar)

## Why
Master Senior Staff and Principal-level Object-Oriented Design (OOD) and Low-Level Design (LLD) to clear technical interviews at Mid-Tech (e.g., Stripe, Datadog, Shopify, Airbnb) and Big-Tech (e.g., Meta, Google, Uber, Netflix, Apple) in 2027, landing a Senior, Staff, or Principal Software Engineer offer.

## Success looks like
- Pass a 45-minute live OOD/LLD interview in front of a Senior Staff/Principal interviewer without getting bogged down in toy inheritance or anemic models.
- Fluently design and implement Rich Domain Models, immutable Value Objects, and strict business invariants with zero primitive obsession.
- Architect deterministic Finite State Machines (FSMs) with guarded transitions and immutable audit logs.
- Write concurrency-safe in-memory domain logic defending against check-then-act race conditions using granular locks (RWLock), atomics, and deadlock-prevention hierarchies.
- Implement high-throughput algorithms (Token Bucket, Leaky Bucket, LRU Cache with eviction) cleanly under time pressure.
- Seamlessly bridge OOD into distributed system primitives: Aggregate Root boundaries, Transactional Outbox, idempotent event handling, and Saga compensation patterns.
- Confidently present and discuss the resume-grade NexusFlow workflow engine capstone project.

## Constraints
- Hands-on interactive browser practice with real client-side test suites and zero build tooling friction.
- Language strategy: Interactive browser execution in JS/TS for immediate automated feedback, paired with Kotlin (Primary), Python (Secondary), and Java (Tertiary) architectural translation for live interview delivery.
- Focus on production patterns and senior trade-offs over memorizing textbook trivia or toy UML diagrams.
- Must prepare for both Mid-Tech (craftsmanship, clean code, SOLID) and Big-Tech (throughput, concurrency, aggregate boundaries, distributed edge cases).

## Out of scope
- High-level distributed system design (DNS, CDN, sharding algorithms, global database replication topologies) except where it directly dictates in-memory object boundaries (Aggregates, Outbox, Sagas).
- LeetCode data structure algorithm speed drills (dynamic programming, graph traversal) except standard in-memory structures used in OOD (LRU doubly linked list, Geohashing, ring buffers).
- Front-end UI framework styling/CSS details.
