# 0001: Baseline Curriculum Assessment & 2027 Interview Scope

The student is initiating preparation for Senior and Staff-level Object-Oriented Design (OOD) / Low-Level Design (LLD) interviews targeting 2027 rounds at Mid-Tech (Stripe, Datadog, Shopify, Airbnb) and Big-Tech (Meta, Google, Uber, Netflix, Apple).

The curriculum was audited across 9 core modules, 1 resume capstone project, interactive code test runners, diagnostic quizzes, and interview playbooks. Key adjustments were made to ensure full alignment with the 2027 bar: establishing clean teaching workspace artifacts (MISSION, RESOURCES, GLOSSARY, NOTES), fixing HTML card layout nesting in index.html, preparing polyglot reference sheets (Java, Python, C++, Go, TypeScript), and standardizing lesson navigation and primary source grounding.
