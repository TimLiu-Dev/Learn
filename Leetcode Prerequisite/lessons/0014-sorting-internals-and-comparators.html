1. Under the Hood of .sort(): Merge Sort, Quicksort & TimSort

Calling nums.sort() is easy, yet senior interviewers routinely ask: "Which sorting algorithm runs under the hood, what is its worst-case time, and how much auxiliary memory does it allocate?"

Why Comparison Sorting Cannot Beat Ω(n log n) (Decision Tree Proof)
Any algorithm that only learns order via a < b comparisons forms a binary decision tree of Yes/No branches. To distinguish all n! possible input permutations, the tree needs at least n! leaves—so its height (worst-case comparisons) must be at least log2(n!) ≈ n log2 n − 1.44n = Ω(n log n)! Only non-comparison algorithms (Counting Sort, Radix Sort) can beat n log n by exploiting bounded key ranges.

2. Sort Stability & Overflow-Safe Custom Comparators

What is Sort Stability? A sort is stable if elements with equal sort keys preserve their original relative order. For example, sorting [("Ana", 90), ("Bob", 85), ("Cal", 90)] by score descending stably keeps "Ana" before "Cal"!

🧸 ELI5: Alphabetizing Mail Without Scrambling Timestamps

Suppose emails arrive sorted by timestamp, and you re-sort your inbox by sender name. A stable sort keeps Alice's 9:00 AM email ahead of Alice's 2:00 PM email; an unstable sort may scramble Alice's two emails randomly!

Fatal Comparator Bug: Never Return a - b!
In Kotlin or Java, writing arr.sortWith { a, b -> a - b } causes silent 32-bit integer overflow when comparing a = -2_000_000_000 and b = +2_000_000_000 (wrapping positive, sorting backward!). Always use compareBy<IntArray>({ it[0] }, { it[1] }) or a.compareTo(b) / Integer.compare(a, b)!

3. Polyglot Code Study: Merge Two Sorted Arrays & Custom Comparators

class SortingToolbox {
    // 1. MERGE TWO SORTED ARRAYS: O(n + m) Time | O(n + m) Space
    fun mergeSorted(a: IntArray, b: IntArray): IntArray {
        val out = IntArray(a.size + b.size)
        var i = 0; var j = 0; var k = 0
        while (i < a.size && j < b.size) {
            // <= preserves stability by taking from left array 'a' on ties!
            out[k++] = if (a[i] <= b[j]) a[i++] else b[j++]
        }
        while (i < a.size) out[k++] = a[i++]
        while (j < b.size) out[k++] = b[j++]
        return out
    }

    // 2. OVERFLOW-SAFE MULTI-KEY INTERVAL SORT
    fun sortIntervals(intervals: Array<IntArray>) {
        intervals.sortWith(compareBy<IntArray> { it[0] }.thenBy { it[1] })
    }
}
class SortingToolbox:
    def merge_sorted(self, a: list[int], b: list[int]) -> list[int]:
        out = []
        i = j = 0
        while i < len(a) and j < len(b):
            if a[i] <= b[j]:
                out.append(a[i]); i += 1
            else:
                out.append(b[j]); j += 1
        out.extend(a[i:])
        out.extend(b[j:])
        return out

    def sort_intervals(self, intervals: list[list[int]]) -> None:
        intervals.sort(key=lambda x: (x[0], x[1]))
import java.util.Arrays;

public class SortingToolbox {
    public int[] mergeSorted(int[] a, int[] b) {
        int[] out = new int[a.length + b.length];
        int i = 0, j = 0, k = 0;
        while (i < a.length && j < b.length) {
            out[k++] = (a[i] <= b[j]) ? a[i++] : b[j++];
        }
        while (i < a.length) out[k++] = a[i++];
        while (j < b.length) out[k++] = b[j++];
        return out;
    }

    public void sortIntervals(int[][] intervals) {
        Arrays.sort(intervals, (a, b) ->
            a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1])
        );
    }
}
