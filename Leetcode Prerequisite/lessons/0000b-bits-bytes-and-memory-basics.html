Bits, Bytes, ASCII, Hexadecimal & How Memory is Built

What a bit and byte are, why an Int takes 4 bytes, how characters like 'a' are secretly numbers in RAM, why addresses look like 0x1000, and how modulo % wraps numbers safely.

1. The Smallest Unit of Reality: Bits, Bytes & Primitive Sizes

At the silicon level, computers do not store letters, emojis, or decimal digits. A CPU chip contains billions of microscopic transistor switches, and each switch only has two physical voltage states: OFF (0) or ON (1).

  • 1 Bit: A single 0 or 1 (short for Binary Digit).
  • 1 Byte: Exactly 8 bits wired together as the smallest addressable unit of RAM.
🧸 ELI5: The Box of 8 Lightbulbs

Imagine a cardboard box holding 8 tiny switches in a row: [0 0 0 0 0 0 0 0].

Because each switch has 2 choices, 8 switches give 28 = 256 distinct combinations—storing unsigned values from 0 (00000000) up to 255 (11111111). To hold larger numbers, the CPU simply glues 2, 4, or 8 byte-boxes side by side!

2. Characters Are Secretly Integers: ASCII Offset Math (ch - 'a')

Nearly half of beginner LeetCode problems involve strings (Valid Anagram, Longest Substring, Valid Palindrome). Here is the hardware secret that unlocks them: every Char in memory is stored as an integer code under the ASCII / Unicode standard:

  • Digits '0' through '9' sit consecutively at codes 48 through 57.
  • Uppercase 'A' through 'Z' sit consecutively at codes 65 through 90.
  • Lowercase 'a' through 'z' sit consecutively at codes 97 through 122.

You never need to memorize 97 or 48! Because the letters are contiguous, subtracting 'a' from any lowercase character maps 'a'..'z' directly onto array indices 0..25:

'a' - 'a' = 97 - 97 = 0  •  'c' - 'a' = 99 - 97 = 2  •  'z' - 'a' = 122 - 97 = 25

Similarly, '7' - '0' equals the integer 7! (Warning: calling '7'.code in Kotlin returns 55, its ASCII code—subtract '0' or call digitToInt() when you want the numeric value 7!).

🧸 ELI5: Classroom Cubbies Labeled A to Z

Suppose a kindergarten wall has 26 cubbies numbered 0 through 25. If Alice ('a') wants her cubby, she subtracts 'a' - 'a' = 0. Charlie ('c') is 2 letters after Alice, so 'c' - 'a' = 2. That single subtraction lets an IntArray(26) count letter frequencies in O(1) memory without even needing a HashMap!

3. Demystifying Hexadecimal (Base 16): Why 0x1000?

Memory addresses in debuggers and textbooks look like 0x1000 and 0x1004. Why Base 16 instead of Base 10?

Because 24 = 16, 4 binary bits compress into exactly 1 hexadecimal digit (using 0–9 plus A=10, B=11, C=12, D=13, E=14, F=15), and 1 full byte (8 bits) is always 2 hex digits (0x00 to 0xFF). The prefix 0x simply tells the compiler and human reader: "this number is written in hexadecimal."

5. Modulo (%) Clock Math & The Negative Number Trap

The modulo operator a % b returns the remainder after dividing a by b. For positive numbers, x % 8 wraps any giant number onto a valid index between 0 and 7 (just like a 12-hour wall clock wraps 15 % 12 = 3).

🧸 ELI5: The 12-Hour Wall Clock

If it is 10:00 AM and 5 hours pass, you don't say "15 o'clock"—you wrap around the circle to 3:00 PM because 15 ÷ 12 = 1 with a remainder of 3 (15 % 12 = 3). Modulo turns an infinite number line into a fixed ring of buckets!

Critical Kotlin / Java Gotcha: Negative Modulo!
In Python, -3 % 8 evaluates to +5 (true mathematical floor modulo).
In Kotlin and Java, % is the truncated remainder operator: -3 % 8 evaluates to -3! Indexing buckets[-3] immediately crashes with ArrayIndexOutOfBoundsException.
The Clean Fix in Kotlin: Use Kotlin's built-in key.mod(capacity) (which always returns 0 until capacity), or bitmask the sign bit (hash and 0x7fffffff) % capacity.

6. Polyglot Code Study: ASCII Indexing & Safe Modulo

class MemoryAndAsciiDemo {
    // 1. ASCII OFFSET INDEXING: Maps 'a'..'z' -> 0..25 in O(1) space
    fun countLetters(s: String): IntArray {
        val counts = IntArray(26)
        for (ch in s) {
            val idx = ch - 'a'   // 'a'->0, 'b'->1, ..., 'z'->25
            counts[idx]++
        }
        return counts
    }

    // 2. SAFE MODULO WRAPPING (Handles negative keys safely!)
    fun getBucketIndex(key: Int, capacity: Int): Int {
        return key.mod(capacity) // Always in 0 until capacity (unlike key % capacity)
    }
}

public class MemoryAndAsciiDemo {
    // 1. ASCII OFFSET INDEXING
    public int[] countLetters(String s) {
        int[] counts = new int[26];
        for (int i = 0; i < s.length(); i++) {
            int idx = s.charAt(i) - 'a';
            counts[idx]++;
        }
        return counts;
    }

    // 2. SAFE MODULO WRAPPING in Java via Math.floorMod
    public int getBucketIndex(int key, int capacity) {
        return Math.floorMod(key, capacity);
    }
}
