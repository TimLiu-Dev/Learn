Search & Traversal Skeletons: Boundary Binary Search, DFS Orders & Level-Order BFS

Bridging data structures into real interview algorithms: finding the firstTrue monotonic boundary in O(log n), Pre/In/Post-Order Tree DFS mechanics, and level-by-level BFS with 2D grid bounds.

1. Beyond Exact Match: Monotonic Boundary Binary Search (firstTrue)

In Lessons 04 and 07, you used while (left <= right) to check whether an exact number exists in a sorted array. In modern 2027 interviews, 80% of Binary Search questions ask something far more general: find the first index (or minimum answer x) where a monotonic condition flips from false to true!

  • First Bad Version (#278): Versions 1..3 pass (F, F, F), version 4..n fail (T, T, T) → find the first T!
  • Lower Bound / Search Insert (#35): Condition nums[i] ≥ target flips from F to T → find the first index ≥ target!
  • Binary Search on Answer (#875 Koko Eating Bananas): Eating speed k is monotonic: if speed k finishes on time (T), every speed > k also finishes (T)!
Why Boundary Search Uses while (left < right) with right = mid & left = mid + 1
  1. If feasible(mid) is true, mid might BE the first true—so we CANNOT discard mid! Set right = mid.
  2. If feasible(mid) is false, mid and everything left of it are definitely false—discard mid via left = mid + 1.
  3. Because integer division mid = left + (right - left) / 2 rounds down, when left < right we always have mid < right—so right = mid and left = mid + 1 both strictly shrink the window on every step until left == right!

🧸 ELI5: Finding the Exact Streetlight Where the Power Outage Starts

Imagine 1,000 streetlights in a row where the first 641 are glowing (False = not broken) and #642 through #1,000 are dark (True = broken). Checking #500 (glowing!) proves #1..#500 are fine (left = 501). Checking #750 (dark!) means #750 could be the first broken light, so you keep #750 in range (right = 750) until only #642 remains!

2. The Three Tree DFS Orders: Pre-Order, In-Order & Post-Order

Every recursive tree traversal walks the exact same Call Stack path—the only difference between Pre-order, In-order, and Post-order is which moment you process the current node!

[4] / \ • PRE-ORDER (Node → Left → Right): [4, 2, 1, 3, 6] (Clone / serialize top-down) [2] [6] • IN-ORDER (Left → Node → Right): [1, 2, 3, 4, 6] (SORTED ascending on any BST!) / \ • POST-ORDER (Left → Right → Node): [1, 3, 2, 6, 4] (Bottom-up heights / diameters) [1] [3]
🧸 ELI5: Boss Checking In Before, Between, or After Two Sub-Teams

Pre-order gives instructions before sending Left and Right teams to work. In-order finishes the Left team (all smaller BST values), logs the Boss, then runs the Right team (all larger BST values)—producing perfectly sorted order! Post-order waits until both sub-teams report back before computing the Boss's total (just like maxDepth in Lesson 13!).

3. Level-Order BFS (val levelSize = q.size) & Clean 2D Grid Bounds

When a Tree or Graph problem asks for shortest unweighted distance, minimum minutes/steps, or nodes grouped by depth level, use an ArrayDeque FIFO queue and snapshot val levelSize = q.size at the start of each wave:

  • Why Snapshot val levelSize = q.size? Inside the inner loop, pushing children grows q.size! Freezing val levelSize = q.size before the inner repeat(levelSize) processes strictly the current distance wave before incrementing depth++.
  • Idiomatic Kotlin 2D Grid Bounds Check: Instead of error-prone 4-part inequalities, write nr in grid.indices && nc in grid[0].indices to verify (nr, nc) stays inside an R × C matrix!

4. Polyglot Code Study: firstTrue Binary Search & Level-Order BFS

class SearchAndTraversalTemplates {
    // 1. MONOTONIC BOUNDARY BINARY SEARCH (Lower Bound / First True): O(log n)
    fun firstIndexAtLeast(nums: IntArray, target: Int): Int {
        var left = 0
        var right = nums.size // nums.size handles case where ALL elements < target!
        while (left < right) {
            val mid = left + (right - left) / 2
            if (nums[mid] >= target) {
                right = mid       // mid is True; keep mid as candidate!
            } else {
                left = mid + 1    // mid is False; discard mid!
            }
        }
        return left
    }

    // 2. LEVEL-ORDER TREE BFS WITH WAVE SNAPSHOT: O(n) Time | O(n) Queue Space
    fun levelOrder(root: TreeNode?): List<List<Int>> {
        if (root == null) return emptyList()
        val res = mutableListOf<List<Int>>()
        val q = ArrayDeque<TreeNode>().apply { addLast(root) }

        while (q.isNotEmpty()) {
            val levelSize = q.size // Snapshot current wave count!
            val level = ArrayList<Int>(levelSize)
            repeat(levelSize) {
                val node = q.removeFirst()
                level.add(node.`val`)
                node.left?.let { q.addLast(it) }
                node.right?.let { q.addLast(it) }
            }
            res.add(level)
        }
        return res
    }
}
from collections import deque

class SearchAndTraversalTemplates:
    def first_index_at_least(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums)
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] >= target:
                right = mid
            else:
                left = mid + 1
        return left

    def level_order(self, root) -> list[list[int]]:
        if not root:
            return []
        res, q = [], deque([root])
        while q:
            level_size = len(q)
            level = []
            for _ in range(level_size):
                node = q.popleft()
                level.append(node.val)
                if node.left: q.append(node.left)
                if node.right: q.append(node.right)
            res.append(level)
        return res
import java.util.*;

public class SearchAndTraversalTemplates {
    public int firstIndexAtLeast(int[] nums, int target) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) right = mid;
            else left = mid + 1;
        }
        return left;
    }

    public List<List<Integer>> levelOrder(TreeNode root) {
        if (root == null) return Collections.emptyList();
        List<List<Integer>> res = new ArrayList<>();
        Deque<TreeNode> q = new ArrayDeque<>();
        q.addLast(root);
        while (!q.isEmpty()) {
            int levelSize = q.size();
            List<Integer> level = new ArrayList<>(levelSize);
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = q.removeFirst();
                level.add(node.val);
                if (node.left != null) q.addLast(node.left);
                if (node.right != null) q.addLast(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
