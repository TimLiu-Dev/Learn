1. The #1 Prompt Terminology Trap: Subarray vs. Subsequence vs. Subset

Mixing up these three words immediately ruins your algorithm design because each creates a completely different search space! For nums = [10, 20, 30]:

Term Must Be Contiguous? Order Matters? Valid Examples from [10, 20, 30] Total Count
Subarray / Substring YES (no gaps!) Yes (left → right) [10], [10, 20], [20, 30], [10, 20, 30] (NOT [10, 30]!) n(n + 1) / 2 (O(n²))
Subsequence No (may skip elements) YES (relative order kept) [], [10, 30], [20, 30] (NOT [30, 10]!) 2n (exponential!)
Subset No No ({10, 30} == {30, 10}) {}, {10, 30}, {10, 20, 30} 2n
🧸 ELI5: Train Cars vs. Deleted Chapters vs. Grocery Bag

A Subarray is a coupled block of train cars sitting side-by-side on the track—you cannot skip Car #2 to grab Cars #1 and #3. A Subsequence is reading a book while tearing out random pages: you never read Chapter 5 before Chapter 2, though you can skip Chapter 3. A Subset is tossing items into a grocery bag where order doesn't matter at all.

Experienced engineers spot hidden clues in the prompt wording and constraints before writing a single line:

3. Strings Under the Hood: UTF-16 Layout, CharArray & Character-Set Discipline

In Lesson 04 we saw why res += ch inside a loop degrades to O(n²). Here is the exact JVM memory layout behind Kotlin strings so you always pick the right mutable tool:

  • 2-Byte UTF-16 & Mutable Alternatives: Every Char occupies 2 bytes with O(1) index access (s[i]), wrapped inside an immutable String object. Use StringBuilder(s.length) (amortized O(1) doubling appends) when building variable-length output, or val chars = s.toCharArray() when swapping characters in-place before calling String(chars).
  • Character-Set Discipline: Only allocate IntArray(26) with ch - 'a' when constraints strictly guarantee lowercase English letters! If constraints permit uppercase, digits, or symbols, use IntArray(128) for standard ASCII or HashMap<Char, Int>() for full Unicode.

4. Prefix Sums: Precomputing O(1) Range Queries

Suppose a problem asks 100,000 queries of the form "What is the sum of elements from index l to r?" Re-looping from l to r per query costs O(n) per query → O(n · q) (TLE!).

Instead, build a Prefix Sum Array of size n + 1 where prefix[0] = 0 and prefix[i + 1] = prefix[i] + nums[i] (representing the sum of the first i + 1 elements):

sum(l .. r) = prefix[r + 1] − prefix[l]   (Computed in O(1) time!)

🧸 ELI5: Highway Mile-Markers

To find the distance between Exit 12 and Exit 47 on a highway, you don't drive a measuring wheel between them! You subtract the total mile-marker signs from Mile 0: 47 − 12 = 35 miles in one instant subtraction. A prefix array stores cumulative "mile-markers from index 0."

5. Polyglot Code Study: Prefix Sums & O(n) String Building

class PromptToolkit {
    // 1. PREFIX SUM ARRAY: O(n) build | O(1) per rangeSum(l, r) query
    fun buildPrefix(nums: IntArray): LongArray {
        val prefix = LongArray(nums.size + 1) // Long avoids 32-bit overflow!
        for (i in nums.indices) {
            prefix[i + 1] = prefix[i] + nums[i]
        }
        return prefix
    }

    fun rangeSum(prefix: LongArray, left: Int, right: Int): Long =
        prefix[right + 1] - prefix[left]

    // 2. O(n) STRING FILTERING VIA StringBuilder
    fun keepAlphanumericLower(s: String): String {
        val sb = StringBuilder(s.length)
        for (ch in s) {
            if (ch.isLetterOrDigit()) sb.append(ch.lowercaseChar())
        }
        return sb.toString()
    }
}
class PromptToolkit:
    def build_prefix(self, nums: list[int]) -> list[int]:
        prefix = [0] * (len(nums) + 1)
        for i, x in enumerate(nums):
            prefix[i + 1] = prefix[i] + x
        return prefix

    def range_sum(self, prefix: list[int], left: int, right: int) -> int:
        return prefix[right + 1] - prefix[left]

    def keep_alphanumeric_lower(self, s: str) -> str:
        return "".join(ch.lower() for ch in s if ch.isalnum())
public class PromptToolkit {
    public long[] buildPrefix(int[] nums) {
        long[] prefix = new long[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        return prefix;
    }

    public long rangeSum(long[] prefix, int left, int right) {
        return prefix[right + 1] - prefix[left];
    }

    public String keepAlphanumericLower(String s) {
        StringBuilder sb = new StringBuilder(s.length());
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (Character.isLetterOrDigit(ch)) {
                sb.append(Character.toLowerCase(ch));
            }
        }
        return sb.toString();
    }
}
