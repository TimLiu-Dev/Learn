Lesson 05 Deep CS Edition State Tracing & Testing

Tabular Dry-Running, Variable State Tracing & The Edge-Case Gauntlet

Being your own compiler: building column-by-column execution trace tables, proving loop invariants, catching off-by-one boundary bugs, and running the 6-point edge-case gauntlet.

1. Being Your Own Compiler: Code as a Deterministic State Machine

Many interview platforms (Google Docs, whiteboard, execution-disabled CoderPad) give you zero Run button—and even on LeetCode, submitting buggy code without tracing builds sloppy habits. Every loop is a deterministic state machine: given current variable values, the next line produces one exact state transition.

🧸 ELI5: The Airline Pilot's Tarmac Checklist

Pilots never take off to 30,000 feet "just to see if the flaps work." They verify every switch state on the ground first. A 2-minute trace table catches 90% of pointer, boundary, and initialization bugs before your code ever runs.

3. Loop Invariants & Choosing < vs. ≤ Without Guessing

Never guess between while (left < right) and while (left ≤ right)! Ask one concrete question: "Is a single remaining state where left == right a valid candidate to inspect, or an invalid empty/self-pair?"

  • Two Sum II (Two Distinct Elements): When left == right, both pointers point to the same element—self-pairing is forbidden! Use strict while (left < right).
  • Standard Binary Search (Single Element Target): When left == right (e.g. nums = [5], target = 5), that final single element could be the target! Use inclusive while (left ≤ right).
🧸 ELI5: The 10-Meter Fence Needs 11 Fence Posts

A 10-meter straight fence with a post every 1 meter has 10 spans but 11 posts (0..10 inclusive). In Kotlin, 0 until n visits 0..n-1 (exclusive top), while 0..n-1 is inclusive—knowing which boundary includes the final post eliminates off-by-one crashes!

5. Polyglot Code: Sorted Two Pointers with Invariant Comments

class TwoPointersShowcase {
    // Time: O(n) | Auxiliary Space: O(1)
    fun twoSumSorted(numbers: IntArray, target: Int): IntArray {
        var left = 0
        var right = numbers.size - 1

        // INVARIANT: Any valid pair must reside inside numbers[left..right], and left != right
        while (left < right) {
            val sum = numbers[left] + numbers[right]
            when {
                sum == target -> return intArrayOf(left + 1, right + 1)
                sum < target -> left++   // Need larger value
                else -> right--          // Need smaller value
            }
        }
        return intArrayOf()
    }
}

public class TwoPointersShowcase {
    public int[] twoSumSorted(int[] numbers, int target) {
        int left = 0, right = numbers.length - 1;
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) return new int[] { left + 1, right + 1 };
            else if (sum < target) left++;
            else right--;
        }
        return new int[0];
    }
}
