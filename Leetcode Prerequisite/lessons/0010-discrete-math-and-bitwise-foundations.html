Discrete Math & Bitwise Foundations

1. Bitwise Operations: Speaking Directly to the CPU's Logic Gates

Inside the CPU's Arithmetic Logic Unit (ALU), bitwise operators do not loop over digits—they apply physical AND, OR, and XOR transistor gates to all 32 (or 64) bits of two integers simultaneously in 1 clock cycle.

🧸 ELI5: The XOR Light Switch Trick

Think of XOR as a hallway toggle switch. Flipping a switch twice with the same number (5 xor 5 = 0) puts every lightbulb right back where it started! If a list contains [4, 1, 2, 1, 2], XOR-ing all elements cancels 1 ^ 1 = 0 and 2 ^ 2 = 0, leaving only the lone survivor 4 in O(n) time and O(1) space!

2. Four Bitwise Idioms You Will Reuse Constantly

  • Safe Odd/Even Check (Even for Negative Numbers!): Writing n % 2 == 1 in Kotlin/Java fails on negative odd numbers because -3 % 2 == -1! Checking the lowest bit with (n and 1) == 1 (or n % 2 != 0) works identically for positive and negative integers.
  • Power-of-Two Check in O(1): A positive power of two has exactly one 1 bit (e.g., 8 = 1000₂, 8 - 1 = 0111₂). Therefore, n > 0 && (n and (n - 1)) == 0 is true if and only if n is a power of 2!
  • Test / Set the i-th Bit of a Bitmask: Check bit i with (mask shr i) and 1; turn bit i on with mask or (1 shl i).
  • Unsigned Midpoint Trick: In Java/Kotlin, (left + right) ushr 1 shifts the unsigned 32-bit sum right by 1, immune to sign-bit overflow—though left + (right - left) / 2 remains clearest in interviews.

🧸 ELI5: Why Factors Stop at the Square Root (√n)

Suppose you want all pairs of dimensions that multiply to area 36: 1×36, 2×18, 3×12, 4×9, 6×6. After 6 = √36, the pairs just flip around (9×4, 12×3)! Checking past √n never discovers a brand-new factor pair—it only repeats factors you already saw.

4. Polyglot Code Study: Bitwise XOR, Ceiling Division & Euclidean GCD

class MathAndBitsToolkit {
    // 1. CEILING DIVISION WITHOUT FLOATS: O(1)
    fun ceilDiv(totalItems: Int, batchSize: Int): Int = (totalItems + batchSize - 1) / batchSize

    // 2. POWER OF TWO CHECK: O(1)
    fun isPowerOfTwo(n: Int): Boolean = n > 0 && (n and (n - 1)) == 0

    // 3. EUCLIDEAN GCD: O(log min(a, b))
    fun gcd(a: Int, b: Int): Int {
        var x = kotlin.math.abs(a)
        var y = kotlin.math.abs(b)
        while (y != 0) {
            val rem = x % y
            x = y
            y = rem
        }
        return x
    }

    // 4. PRIMALITY CHECK IN O(sqrt(n)) WITHOUT i*i OVERFLOW
    fun isPrime(n: Int): Boolean {
        if (n < 2) return false
        var d = 2
        while (d <= n / d) { // Equivalent to d * d <= n, zero Int overflow risk!
            if (n % d == 0) return false
            d++
        }
        return true
    }
}
