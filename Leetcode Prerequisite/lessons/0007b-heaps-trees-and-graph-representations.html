Lesson 07b Deep CS Edition Heaps, Trees & Graphs

Priority Queues (Heaps), Binary Trees & Graph Representations

Completing your non-linear CS foundation: how a Binary Heap packs a tree into a contiguous array, why Top-K uses a Min-Heap, Tree/BST anatomy, and representing Graphs & 2D grids without MLE.

1. Binary Heaps & PriorityQueue: Tree Logic Inside a Flat Array

Sorting an entire array just to repeatedly grab the smallest or largest item wastes O(n log n) work every time a new item arrives. A Binary Min-Heap guarantees that the smallest element always sits at index 0 (peek() in O(1)), while supporting insertion (add) and minimum extraction (poll) in O(log n)!

Zero-Pointer RAM Secret: Instead of allocating scattered TreeNode objects on the heap, PriorityQueue stores a complete binary tree inside one contiguous array using pure index arithmetic:

parent(i) = (i - 1) / 2  •  leftChild(i) = 2i + 1  •  rightChild(i) = 2i + 2
Interactive Binary Min-Heap Array Simulator heap[0] = Guaranteed Minimum
Insert or poll to watch O(log n) sift-up and sift-down!
Two Famous PriorityQueue Gotchas
  • Iterating a PriorityQueue is NOT sorted! A heap only guarantees parent ≤ children (level-order array), NOT global sorted order. To retrieve elements in sorted order, repeatedly call pq.poll()!
  • Why "Top K Largest" Uses a Min-Heap of Size K: Keep only the K largest candidates seen so far. The gatekeeper at pq.peek() is the weakest of your top K—if a new item is bigger than pq.peek(), evict the weakest with pq.poll() in O(log K)!
🧸 ELI5: The Hospital ER Triage Desk

A regular queue (ArrayDeque) serves patients strictly in arrival order (FIFO). An ER triage desk (PriorityQueue) always puts the highest-urgency case at the front (O(1) peek) and slides each arriving patient up or down the priority board in at most log2 n comparisons!

2. Binary Trees & Binary Search Tree (BST) Vocabulary

[8] ← Root (Depth 0, Tree Height = 3 nodes / 2 edges) / \ [3] [10] ← Internal Nodes (Depth 1) / \ \ [1] [6] [14] ← Leaves (left == null && right == null)
  • Depth vs. Height: Depth counts downward from the Root; Height counts upward from the deepest Leaf (remember LeetCode #104 counts nodes along the longest root-to-leaf path!).
  • Binary Tree vs. Binary Search Tree (BST): A general Binary Tree allows any values in any child. A BST enforces the strict invariant: every value in the entire left subtree < node < every value in the entire right subtree—enabling O(log n) search on balanced trees (degrading to O(n) on a skewed chain!).

3. Graphs & 2D Grids: Adjacency Lists vs. Matrices

Trees are simply connected, acyclic graphs with one root. General Graphs consist of Vertices (V) connected by Edges (E)—which may be directed (one-way streets) or undirected (two-way friendships) and may contain cycles!

Representation Kotlin Structure Space Cost When to Use on LeetCode
Adjacency List Array(n) { mutableListOf<Int>() } O(V + E) Default for 95% of graphs! Sparse edges (V ≤ 105).
Adjacency Matrix Array(n) { IntArray(n) } O(V2) Tiny dense graphs (V ≤ 400) needing O(1) edge-exists checks.
2D Grid (Implicit Graph) grid: Array<IntArray> + 4-dir offsets O(R · C) Islands, mazes, shortest paths using dirs (dr, dc).
🧸 ELI5: Your Phone Contacts vs. A Wall-Sized All-Humans Spreadsheet

If 100,000 people live in a city and each has 5 friends, an Adjacency Matrix draws a 100,000 × 100,000 grid (10 billion mostly empty cells → 40 GB MLE!). An Adjacency List simply gives each person a tiny contact list holding only their 5 actual friends (O(V + E))!

import java.util.PriorityQueue

class NonLinearToolkit {
    // 1. TOP K LARGEST ELEMENTS USING MIN-HEAP: O(n log k) Time | O(k) Space
    fun kthLargest(nums: IntArray, k: Int): Int {
        val minHeap = PriorityQueue<Int>()
        for (x in nums) {
            minHeap.add(x)
            if (minHeap.size > k) minHeap.poll() // Evict smallest!
        }
        return minHeap.peek()!!
    }

    // 2. BUILD UNDIRECTED ADJACENCY LIST: O(V + E)
    fun buildGraph(n: Int, edges: Array<IntArray>): Array<MutableList<Int>> {
        val adj = Array(n) { mutableListOf<Int>() }
        for ((u, v) in edges) {
            adj[u].add(v)
            adj[v].add(u)
        }
        return adj
    }

    def kth_largest(self, nums: list[int], k: int) -> int:
        min_heap: list[int] = []
        for x in nums:
            heapq.heappush(min_heap, x)
            if len(min_heap) > k:
                heapq.heappop(min_heap)
        return min_heap[0]

            adj[u].append(v)

import java.util.*;

public class NonLinearToolkit {
    public int kthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        for (int x : nums) {
            minHeap.add(x);
            if (minHeap.size() > k) minHeap.poll();
        }
        return minHeap.peek();
    }

    public List<List<Integer>> buildGraph(int n, int[][] edges) {
        List<List<Integer>> adj = new ArrayList<>(n);
        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
        for (int[] e : edges) {
            adj.get(e[0]).add(e[1]);
            adj.get(e[1]).add(e[0]);
        }
        return adj;
    }

    static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
}
