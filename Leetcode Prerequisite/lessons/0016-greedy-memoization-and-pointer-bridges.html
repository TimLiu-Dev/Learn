Optimization Bridges: In-Place Read/Write Pointers, Greedy Proofs & Top-Down Memoization

Removing the final three blind spots before Blind 75 / NeetCode 150: compacting arrays in-place in O(1) space, testing Greedy hypotheses with 30-second counterexamples, and turning O(2n) recursion into O(n) Dynamic Programming with a 3-line cache.

1. Same-Direction Read/Write Pointers: Mutating Arrays Without removeAt

Many beginner problems (#26 Remove Duplicates, #27 Remove Element, #283 Move Zeroes) forbid allocating a new array (O(1) auxiliary space). Beginners try calling list.removeAt(i) inside a for loop—causing two bugs at once:

  • Skipped Neighbors Bug: Deleting index i shifts index i + 1 left into slot i, and then i++ jumps right over it without checking it!
  • O(n²) Shifting TLE: Every removeAt(i) copies all trailing elements left in RAM.

The Clean Fix — Read/Write Two Pointers: Sweep read across 0..<nums.size; whenever nums[read] should be kept, write it at nums[write++] in O(n) time and O(1) space!

🧸 ELI5: Snowplow Compaction vs. Moving Every Parked Car One-by-One

Instead of towing 10,000 cars forward by 1 parking space every time an empty spot appears (removeAt), keep a write chalk line at the front: each valid car you pass simply pulls into the next open write spot once!

2. Greedy Algorithms vs. The 30-Second Counterexample Test

A Greedy algorithm commits to the locally best choice at each step and never looks back. Sometimes Greedy is provably optimal—and sometimes it fails catastrophically!

When Greedy Wins (#121 Buy & Sell Stock)

To maximize prices[sell] − prices[buy] for any sell > buy, the best buy day before today is unconditionally the lowest price seen so far (minPrice). Tracking minPrice and bestProfit in one O(n) pass is 100% exact!

When Greedy Fails (#322 Coin Change)

Given coins [1, 3, 4] and target 6: greedily grabbing the largest coin 4 forces 4 + 1 + 1 (3 coins), missing optimal 3 + 3 (2 coins)! Whenever today's choice restricts better future combinations, you need Dynamic Programming.

3. Demystifying Dynamic Programming: Memoization = Recursion + Cache

Self-taught engineers often dread the words "Dynamic Programming". Mechanically, Top-Down DP (Memoization) is literally Lesson 13 recursion plus a lookup array so you never solve the same subproblem twice!

In LeetCode #70 Climbing Stairs (ways(n) = ways(n - 1) + ways(n - 2)), naive recursion recomputes ways(2), ways(3), … millions of times (O(2n)). Storing each answer in val memo = IntArray(n + 1) { -1 } means each state 0..n computes at most once:

(n + 1 unique states) × O(1) work per state = O(n) Time & O(n) Space!

class OptimizationBridges {
    // 1. IN-PLACE READ/WRITE COMPACTION (#283 Move Zeroes): O(n) Time | O(1) Space
    fun moveZeroes(nums: IntArray) {
        var write = 0
        for (read in nums.indices) {
            if (nums[read] != 0) {
                val tmp = nums[write]; nums[write] = nums[read]; nums[read] = tmp
                write++
            }
        }
    }

    // 2. GREEDY RUNNING MINIMUM (#121 Best Time to Buy & Sell Stock): O(n) Time | O(1) Space
    fun maxProfit(prices: IntArray): Int {
        var minPrice = Int.MAX_VALUE
        var best = 0
        for (p in prices) {
            minPrice = minOf(minPrice, p)
            best = maxOf(best, p - minPrice)
        }
        return best
    }

    // 3. TOP-DOWN MEMOIZATION (#70 Climbing Stairs): O(n) Time | O(n) Space
    fun climbStairs(n: Int): Int {
        val memo = IntArray(n + 1) { -1 }
        fun dfs(k: Int): Int {
            if (k <= 1) return 1
            if (memo[k] != -1) return memo[k] // O(1) cache hit!
            memo[k] = dfs(k - 1) + dfs(k - 2)
            return memo[k]
        }
        return dfs(n)
    }
}

import java.util.Arrays;

public class OptimizationBridges {
    public void moveZeroes(int[] nums) {
        int write = 0;
        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) {
                int tmp = nums[write]; nums[write] = nums[read]; nums[read] = tmp;
                write++;
            }
        }
    }

    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE, best = 0;
        for (int p : prices) {
            minPrice = Math.min(minPrice, p);
            best = Math.max(best, p - minPrice);
        }
        return best;
    }

    public int climbStairs(int n) {
        int[] memo = new int[n + 1];
        Arrays.fill(memo, -1);
        return dfs(n, memo);
    }

    private int dfs(int k, int[] memo) {
        if (k <= 1) return 1;
        if (memo[k] != -1) return memo[k];
        return memo[k] = dfs(k - 1, memo) + dfs(k - 2, memo);
    }
}
