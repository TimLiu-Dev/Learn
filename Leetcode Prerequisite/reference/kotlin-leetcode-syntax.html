5. Stack, Queue (ArrayDeque) & Heap (PriorityQueue)

6. Sorting, Node Pointers & Overflow-Safe Arithmetic

Sorting & Custom Comparators (O(n log n))

  • In-place primitive sort: nums.sort() / nums.sortDescending()
  • Sort 2D intervals by start, tie-break end:
    intervals.sortWith(compareBy<IntArray> { it[0] }.thenBy { it[1] })
  • Non-mutating copy: val copy = nums.sorted() (returns List<Int>, costs O(n) space).

LeetCode ListNode? & TreeNode?

  • Backtick `val` Gotcha: val is a reserved Kotlin keyword, so LeetCode node values MUST be accessed with backticks: curr.`val` and root.`val`.
  • Null-safe pointer walk:
    var curr = head; while (curr != null) { ...; curr = curr.next }

Overflow-Safe Math & Constants

  • 32-bit Bounds: Int.MAX_VALUE (2,147,483,647 ≈ 2.14 × 109) • Int.MIN_VALUE (-2,147,483,648).
  • Overflow-safe midpoint: val mid = left + (right - left) / 2
  • Pre-cast before multiply/add: val prod: Long = a.toLong() * b (casting (a * b).toLong() overflows before widening!).
  • Non-negative modulo wrap: key.mod(m) (returns 0 .. m-1 even for negative keys; key % m can stay negative in Kotlin/Java).
  • Clean branchless bounds: maxOf(a, b), minOf(a, b), kotlin.math.abs(x).
