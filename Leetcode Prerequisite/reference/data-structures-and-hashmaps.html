2. Hash Map Mechanics: From Key to Memory Bucket

How map.get(key) works without linear searching:

  1. Hash Generation: The key's 32-bit integer hash code is computed: h = key.hashCode().
  2. Modulo Compression: Map the large integer to a bucket index: bucket = (h & 0x7FFFFFFF) % bucket_count (or h.mod(bucket_count)).
  3. Direct Address Jump: CPU computes contiguous bucket memory address: bucket_addr = base + (bucket * pointer_size).
  4. Separate Chaining Collision Check: The CPU inspects the linked list or red-black tree at that bucket, comparing key.equals(stored_key). Average chain length with a 0.75 load factor is ≤ 2, producing O(1) average time.

4. The Two Sum Archetype (One-Pass Hash Map)

// Kotlin: O(n) Time, O(n) Auxiliary Space
class Solution {
    fun twoSum(nums: IntArray, target: Int): IntArray {
        val seen = HashMap<Int, Int>() // Maps value -> index

        for (i in nums.indices) {
            val complement = target - nums[i]
            if (seen.containsKey(complement)) {
                return intArrayOf(seen[complement]!!, i)
            }
            seen[nums[i]] = i // Insert AFTER checking to prevent self-pairing
        }
        return intArrayOf()
    }
}
