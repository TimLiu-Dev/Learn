Canonical CS & Technical Interview Glossary

Precise mechanical definitions used across the curriculum and expected in Tier-1 technical interviews, along with vague phrasing to avoid.

1. Hardware & Memory

Contiguous Memory

A continuous, unbroken sequence of byte addresses allocated in physical RAM without gaps.

Avoid: Sequential storage, connected memory
Pointer

A variable whose numerical value is the physical or virtual memory address of another location in RAM.

Avoid: Memory reference, link variable
Stack Frame

A fixed, contiguous block of memory allocated on the call stack to store a single function invocation's local variables, arguments, and return address.

Avoid: Call record, activation block
Heap

A dynamic, unstructured region of system RAM used for objects and arrays whose lifespan exceeds the stack frame that created them.

Avoid: Free pool, dynamic area
Cache Line

The fixed-size chunk of physical memory (typically 64 bytes) transferred between main RAM and the CPU L1/L2/L3 caches in a single bus transaction.

Avoid: Memory packet, cache block

2. Asymptotic Complexity

Asymptotic Analysis

The mathematical evaluation of how an algorithm's resource consumption (time or memory) scales as the input size n approaches infinity.

Avoid: Performance testing, benchmark calculation
Big O (O(...))

The formal mathematical upper bound that guarantees an algorithm's worst-case rate of growth as n → ∞.

Avoid: Average speed, maximum runtime
Auxiliary Space

The extra temporary memory allocated by an algorithm during execution, strictly excluding the memory occupied by input arguments and returned output.

Avoid: Working space, scratchpad memory
Logarithmic Growth (O(log n))

A growth rate proportional to the number of times the input size n can be divided by a constant factor (typically 2) before reaching 1.

Avoid: Sub-linear curve, exponential decay
Amortized Complexity

The average resource cost per operation evaluated over a worst-case sequence of operations, where infrequent expensive steps are distributed across frequent inexpensive steps.

Avoid: Average-case runtime, smoothed complexity
In-Place Algorithm

An algorithm that transforms its input directly within the existing structure using O(1) bounded auxiliary memory (note: recursive stack frames still count toward auxiliary space).

Avoid: Zero-memory algorithm, destructive algorithm

3. Data Structures & Algorithmic Mechanics

Algorithmic Bottleneck

The single most computationally expensive operation in an execution pipeline that dominates total Big O runtime.

Avoid: Slow part, chokepoint
Dynamic Array

A resizable wrapper around a contiguous backing array (ArrayList, Python list) that allocates a 2× larger array and copies elements upon overflow, achieving O(1) amortized tail append.

Avoid: Elastic array, auto-growing list
Hash Set

A hash-table-backed collection storing unique keys without values, supporting O(1) average membership checks, insertion, and deletion.

Avoid: Unique list, deduplicated array
Separate Chaining

A collision resolution technique where each hash table bucket stores a linked list or balanced tree of entries hashing to the same bucket index.

Avoid: Bucket chaining, collision list
Modulo Compression

The operation (hash & 0x7FFFFFFF) % bucket_count (or hash.mod(bucket_count)) mapping an arbitrary 32-bit hash integer into a valid array index 0 .. bucket_count - 1.

Avoid: Array wrapping, index clamping
ASCII Offset Indexing

Direct-address array indexing subtracting a base character code (ch - 'a' or ch - '0') to map bounded characters into a tiny contiguous frequency array in O(1) worst-case time.

Avoid: Letter numbering, alphabet hashing
Ring Buffer (Deque)

A contiguous array paired with modulo-wrapped head and tail indices (ArrayDeque), supporting O(1) amortized push and pop at both ends.

Avoid: Double list, two-way array
Base Case

The explicit non-recursive termination condition in a recursive function that returns immediately without pushing further stack frames.

Avoid: Stop rule, exit line
Call Stack Unwinding

The LIFO return phase of recursion after reaching a base case, popping completed stack frames one by one and returning values to suspended callers.

Avoid: Back-stepping, reverse looping
Loop Invariant

A formal logical condition guaranteed to hold before a loop begins, at the end of every iteration, and immediately upon termination.

Avoid: Loop rule, consistency check
Complement

In pair-matching problems, the exact mathematical difference between the target value and the current element (complement = target - current).

Avoid: Target difference, matching partner

4. Interview Dynamics

State Trace Table

A systematic columnar walkthrough recording deterministic values of all active variables and pointers across sequential loop iterations on a sample input.

Avoid: Trace matrix, variable chart
Edge Case

An extreme, degenerate, or boundary input (empty collection, singleton, all duplicates, negative values, Int.MAX_VALUE) that exposes latent logical flaws.

Avoid: Corner case, weird input
Consensus Check

A deliberate, explicit verbal confirmation requested by the candidate to align with the interviewer on an algorithmic strategy before writing code.

Avoid: Green light, permission request
