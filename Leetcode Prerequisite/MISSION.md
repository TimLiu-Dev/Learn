# Mission: Computer Science Foundations, Kotlin 2.x Toolkit & 2027 Interview Readiness

## Why
Master physical computer science mechanics, asymptotic complexity analysis, core linear and non-linear data structures, recursion, sorting internals, and modern 2027 technical interview protocols to confidently solve algorithmic problems and defend engineering tradeoffs as a self-taught engineer.

## Success looks like
- Trace how source code compiles and executes across CPU registers, cache lines, the Call Stack, and Heap RAM with zero black-box hand-waving.
- Calculate Big O time and auxiliary space complexity (worst-case, average-case, and amortized) across iterative, two-pointer, and recursive code without guessing.
- Reverse-engineer target Big O bounds directly from LeetCode constraint blocks (`n`) using the `10^7`–`10^8` ops/sec ceiling, memory budgets, and 64-bit `Long` overflow rules.
- Execute both 2027 interview modes fluently: (1) zero-IDE 45-minute problem solving with multi-part constraint pivots and invariant defense, and (2) code-critique / AI-assisted debugging of subtle complexity and boundary bugs.
- Manually dry-run pointers, hash tables, prefix sums, and recursive call stacks using state trace tables and the 6-point edge-case gauntlet before running code.
- Select and implement idiomatic Kotlin 2.x data structures (`IntArray`, `ArrayList`, `HashMap`, `HashSet`, `TreeMap`, `ArrayDeque`, `PriorityQueue`, `ListNode`, `TreeNode`, Adjacency Lists), custom comparators, `firstTrue` boundary binary search, Pre/In/Post/Level-Order traversals, Read/Write pointers, and Top-Down Memoization from memory.
- Independently solve and submit live LeetCode bridge milestones in Kotlin—starting with **#1 Two Sum** (Lesson 09) and progressing through **#136**, **#231**, **#217**, **#242**, **#215**, **#104**, **#88**, **#56**, **#278**, **#102**, **#283**, **#121**, and **#70 Climbing Stairs**—before entering Phase 2 (Blind 75 / NeetCode 150).

## Constraints
- Primary implementation language: **Kotlin 2.x** (matching LeetCode's OpenJDK 25 runtime).
- Secondary read-along languages: **Python** and **Java**.
- Ground every abstraction in concrete hardware mechanics, ELI5 analogies, execution traces, and active in-browser verification (simulators, bug hunts, fill-in-the-code labs, and word-balanced retrieval quizzes).
- Current learner progress starts at **0 / 16 lessons completed** (beginning at Lesson 01).

## Out of scope
- Niche competitive-programming structures rarely seen in industry interviews (e.g., Heavy-Light Decomposition, Suffix Automata).
- Distributed system architecture or behavioral-only interview prep (covered in dedicated tracks after algorithmic foundations).
