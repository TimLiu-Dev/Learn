# Mission: Algorithmic Thinking & Technical Interview Foundations

## Why
Master foundational computer science vocabulary, complexity analysis, and communication mechanics to confidently solve algorithmic problems and articulate solutions in modern technical coding interviews as a self-taught engineer.

## Success looks like
- Clearly differentiate brute-force from optimal solutions and identify algorithmic bottlenecks.
- Calculate Big O time and auxiliary space complexity without guessing, intuitively understanding logarithmic scales ($\log n$).
- Translate LeetCode input constraints ($n$) directly into target Big O bounds using the $10^7$ operations/second ceiling.
- Execute the standard 45-minute technical interview script (Clarify → Verbalize Brute Force → Propose Optimal → Implement → Trace & Verify).
- Manually dry-run and state-trace code line-by-line on sample inputs using trace tables without relying on an IDE, compiler, or online judge.
- Independently solve and submit LeetCode #1 Two Sum in Kotlin (passing all test cases with optimal $O(n)$ time and $O(n)$ space) to anchor real-world execution.

## Constraints
- Primary implementation language: Kotlin.
- Secondary reference languages: Python and Java.
- Ground explanations in concrete execution traces and state changes rather than abstract mathematical proofs.
- One tightly-scoped concept per lesson with an interactive check or quiz.

## Out of scope
- Advanced competitive programming niche algorithms (e.g., Fenwick trees, heavy-light decomposition).
- Language-specific bytecode optimizations or JVM internal memory layout details.
- System design or behavioral interview prep.
