1. Curriculum Legend — How Every Lesson Works

Every lesson in this series follows the exact benchmark structure established in Lesson 01. Here is how to read the tags, sections, and difficulty markers.

Standard 6-Part Lesson Anatomy

  • 1. Android → Web Bridge: Maps what you already know (Compose, OkHttp, Coroutines, Looper) to Web equivalents so you don't re-learn fundamentals from zero.
  • 2. Interactive Architecture Visualizer: Step-by-step interactive diagrams showing data, rendering, or memory flow.
  • 3. Runnable Code Examples: Live editable HTML/CSS/JS examples executing inside isolated sandboxes.
  • 4. Code Practice Labs: Real coding tasks with an automated test checker, 3 progressive hints, and a full explained final answer.
  • 5. Diagnostic Quizzes: Multiple-choice scenarios explaining why the right option works AND why every wrong option fails.
  • 6. Senior Verification & DevTools Lab: Real browser DevTools workflows and resume/interview takeaways.

Badge & Difficulty Legend

Core Foundation — Non-negotiable web platform mechanics every engineer must know cold.
Production Craft — Patterns used daily in modern TypeScript, React, and Next.js codebases.
Senior Depth — Architecture, perf budgets, tradeoffs, security, and failure modes expected at Senior level.
Android Bridge — High-leverage analogies (and subtle traps!) for Android developers moving to Web.
Interview Hotspot — Topics heavily tested in 2027 Senior Frontend technical & system design loops.
UX Engineering — Product-minded UI craft: 5-state completeness, cognitive load, Figma-to-tokens, and A/B telemetry.
Built & Ready vs Planned in Series — Tracks which HTML lessons exist on disk right now.

What Separates "Junior" from "Senior" Frontend in 2027

  • Not just framework syntax: Understanding browser scheduling, rendering pipelines, GC/memory leak profiling, native platform APIs (Intl, AsyncIterator), and network waterfalls.
  • Type-level rigor: Designing unrepresentable invalid states in TypeScript instead of defensive runtime hacks.
  • Product-minded UX engineering: Handling all 5 UI states (loading, empty, error, optimistic, offline), reducing cognitive load via progressive disclosure, and translating Figma tokens accurately.
  • Measurable quality: Enforcing Core Web Vitals (LCP, INP, CLS), WCAG 2.2 accessibility, CSP/XSS defense, feature-flagged experiments, and reliable CI tests.
  • System ownership: Writing crisp Architecture Decision Records (ADRs), mentoring, and verifying AI-generated code critically rather than trusting it blindly.

2. Junior Android → Senior Frontend Translation Map

Your Android experience is an unfair advantage: you already understand asynchronous UI threads, reactive state, dependency injection, and lifecycles. Watch out for the traps where Web behaves differently.

Domain Android Mental Model (You Know) Modern Web Equivalent (2027) Critical Trap to Avoid
UI Rendering View Measure/Layout/Draw or Jetpack Compose Composition → Layout → Drawing DOM + CSSOM → Render Tree → Layout (Reflow) → Paint → GPU Composite Reading layout geometry (offsetHeight) after mutating styles forces synchronous reflow (jank).
Main Thread Android Main Looper + Choreographer (16.6ms frame budget) Browser Event Loop (Macrotasks, Microtasks) + requestAnimationFrame Web is single-threaded per tab (unless using Web Workers); heavy sync JS stalls clicks and hurts INP.
Networking OkHttp + Retrofit + Interceptors + TLS Cert Pinning fetch() + AbortController + HTTP Cache-Control + CORS + CDN Browsers enforce Same-Origin Policy & CORS automatically; tokens in localStorage are vulnerable to XSS.
Language & Types Kotlin (Null-safety, Sealed Classes, Coroutines, Flow) JavaScript (Closures, Prototypes) + TypeScript (Structural Types, Unions) TypeScript types are erased at runtime! Never trust API JSON without runtime validation (e.g. Zod).
State & UI Jetpack Compose + ViewModel + StateFlow React Hooks + TanStack Query (server cache) + Zustand + URL State Treating fetched API data like local UI state instead of a stale-while-revalidate server cache.
Build & Tooling Gradle + Kotlin Compiler + R8 / ProGuard pnpm + Vite / Rollup / Turbopack + Tree-shaking + Code Splitting Shipping huge client bundles destroys mobile LCP; Web loads code lazily over the network on every first visit.
Testing JUnit + MockK + Espresso / Compose Test Vitest + React Testing Library + MSW + Playwright E2E Testing internal component state/hooks instead of user-observable behavior & accessible roles.
