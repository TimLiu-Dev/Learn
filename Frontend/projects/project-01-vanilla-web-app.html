Section 4 · Architecture Decisions, Interviews & Resume

ADR Templates, Senior Talking Points & Resume Bullet Builder

Senior engineers don't just ship working features—they document tradeoffs in Architecture Decision Records (ADRs) and articulate failure modes clearly under interview pressure.

Senior Interview Talking Points

1. Why isn't debouncing alone enough for live search?

Debouncing only delays firing requests; it never cancels an already-in-flight request. If query "re" takes 900ms and query "react" resolves in 120ms, the stale response overwrites newer UI state. Pairing debounce with AbortController.abort() guarantees single-winner ordering at the network and state layer.

2. Why does fetch() resolve on HTTP 500/503?

fetch() only rejects on network failures or aborts, not HTTP error statuses. A production wrapper checks response.ok, distinguishes retryable transient statuses (429, 502, 503, 504) from client errors (400, 404), honors Retry-After, and adds full jitter to avoid thundering herds.

3. How do native <dialog> & popover eliminate z-index bugs?

dialog.showModal() and popover="auto" promote elements into the browser's Top Layer above every stacking context (transform, opacity, isolation), automatically providing ::backdrop, focus trapping, Esc dismissal, and light-dismiss without fragile z-index: 9999 wars.

4. How do you prove zero memory leaks in a Vanilla JS app?

Attach one delegated listener on stable landmarks instead of per-card closures, pass an AbortSignal to global keydown/resize listeners for one-line cleanup, call observer.disconnect() on teardown, and verify flat retained heap size across 50 open/close/search cycles in Chrome DevTools Heap Snapshots.
