Required 3 Architecture Decision Records (ADRs)

Senior Interview Talking Points

1. "Why store session cookies in a BFF instead of JWTs in localStorage, and how do you handle refresh token theft?"

Answer: Any JS-readable token in localStorage is exfiltrated by a single XSS payload. OpsDeck terminates OAuth2 PKCE in the Next.js BFF and issues HttpOnly; Secure; SameSite=Lax cookies. Refresh tokens belong to a server-tracked familyId in Postgres/Redis: each rotation marks the prior token used. If an already-rotated token is presented again (reuse detected), the API immediately revokes the entire token family and forces re-authentication.

2. "Why SSE + Redis Pub/Sub over WebSockets, and how do you survive multi-instance scaling and offline drops?"

Answer: Incident timelines are 95% server-to-client push; SSE works natively over HTTP/2 multiplexing, plays nicely with corporate proxies, and supports automatic reconnection with Last-Event-ID. Mutations go over standard HTTP POST with a client-generated Idempotency-Key. When offline, mutations queue in IndexedDB and replay safely on reconnect—deduplicated server-side in a Postgres transaction. Horizontal API pods subscribe to tenant-scoped Redis Pub/Sub channels so any pod can broadcast updates to connected SSE clients.

3. "How does strict nonce-based CSP work with Next.js App Router Streaming SSR?"

Answer: Static unsafe-inline disables XSS protection. Middleware generates a per-request cryptographic nonce, attaches Content-Security-Policy: script-src 'nonce-...' 'strict-dynamic', and passes it via request headers so Next.js injects the nonce onto hydration and streamed RSC script chunks. Any dynamically rendered route opts out of static caching so nonces are never reused across users.

4. "How do you prove your Lighthouse budgets and backend reliability aren't just local-machine luck?"

Answer: Every PR runs GitHub Actions against production Docker builds: Vitest + Supertest hit an ephemeral Postgres container via Testcontainers (verifying real SQL constraints, migrations, and transactions), Playwright exercises critical multi-tenant flows + offline outbox replay, and Lighthouse CI gates merge on LCP < 1.8s, INP < 100ms, and CLS < 0.05. Distributed OpenTelemetry traces connect browser fetch spans to Fastify handlers and Drizzle SQL queries.
