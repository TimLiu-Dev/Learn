01 · Mental Model Bridge (Android Bridge)

Android ConstraintLayout / Compose Row-Column-Box → Modern CSS Layout

In Android Jetpack Compose, every composable takes explicit modifiers (Modifier.padding(), Modifier.zIndex(), Row, Column, BoxWithConstraints) that apply locally in the order you chain them. On the Web, CSS rules are global pattern-matched sheets where multiple selectors compete via the Cascade, Specificity, and @layer, elements paint inside isolated Stacking Contexts, and Grid, Flexbox, :has(), and @container solve responsive layout natively inside the browser's C++ layout engine.

Layout & Styling Concept Android XML / Compose Equivalent Modern CSS First-Principles Mechanism Common Web Pitfall
Box Sizing & Dimensions View bounds include padding; Compose Modifier.size() vs padding() chain order box-sizing: border-box includes padding + border inside declared width/height (default is content-box). Forgetting *, *::before, *::after { box-sizing: border-box; } makes width: 100% + padding: 16px overflow by 32px.
Precedence & Cascade ThemeOverlay + local Compose modifier overrides (last modifier wins locally) Origin → !important → @layer order → Specificity (ID, Class/Attr/Pseudo, Element) → Source order. Unlayered rules beat all @layer rules regardless of specificity; selector escalation leads to !important wars.
Z-Ordering & Overlays Modifier.zIndex() within parent Box / View elevation Stacking Contexts: z-index only compares siblings inside the same stacking context; transform, opacity < 1, filter, and isolation: isolate create new contexts. Setting z-index: 9999 on a modal/tooltip inside a transformed card fails to lift it above an adjacent section.
1D & 2D Layout + RTL Row / Column, ConstraintLayout, paddingHorizontal / start Flexbox (1D content-driven flow) + CSS Grid (fr, minmax(), auto-fit 2D tracks) + Logical Props (margin-inline, padding-block). Hardcoding margin-left breaks Arabic/Hebrew RTL layouts; using fixed Grid column counts breaks mobile instead of auto-fit.
Component Responsiveness & Tokens BoxWithConstraints + MaterialTheme.colorScheme / dp spacing tokens @container queries adapt to parent width; :has() styles parents by child state; clamp() scales fluidly; Figma Auto Layout maps to flex + gap + CSS custom properties. Using viewport @media queries for reusable cards fails when the same card lives in both a 300px sidebar and a 900px main pane.

06 · DevTools Verification & Next Steps

Chrome DevTools Layout & Stacking Checklist + Teacher Follow-Up

  • Stacking Context & Layers Audit: In Chrome DevTools → Elements → Computed (or the 3D Layers panel), inspect any element whose z-index seems ignored and check its ancestor chain for transform, opacity < 1, filter, or isolation: isolate.
  • Grid, Flex & Container Badges: Click the grid, flex, and container pills directly in DevTools' DOM tree to overlay track lines, gap, fr sizing, and container query breakpoints visually.
  • Cascade & @layer Tracing: Open the Styles pane to see rules grouped by @layer order (unlayered rules sit at the top) and verify logical properties (padding-inline, margin-block) flip cleanly when toggling dir="rtl" on <html>.
  • Anchor & Entry Transitions: For modern tooltips/popovers, inspect position-anchor / position-area in DevTools and verify @starting-style entry animations run cleanly on <dialog> and [popover] without blocking interaction or violating prefers-reduced-motion.
