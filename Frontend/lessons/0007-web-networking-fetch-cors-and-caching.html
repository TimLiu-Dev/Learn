01 · Mental Model Bridge (Android Bridge)

Retrofit + OkHttp Interceptors & Timeout → Browser fetch() Stack

On Android and Spring Boot, you configure an explicit HTTP client (OkHttpClient) with socket timeouts, an interceptor chain, and Retrofit's HttpException converter—and native apps never enforce browser Same-Origin Policy. In a web browser, the browser engine owns the network stack, cookie jar, HTTP cache, and CORS security sandbox. fetch() is a low-level Promise primitive, not an opinionated client: understanding its exact boundaries is what separates fragile UI fetches from senior production infrastructure.

06 · Production Verification & Next Steps

Chrome DevTools Network Checklist + Teacher Follow-Up

  • CORS Preflight Audit: Open DevTools → Network, filter by Fetch/XHR, and watch for paired OPTIONS requests before POST/PATCH calls. Verify Access-Control-Max-Age is set on your API gateway so preflights are cached instead of adding an extra RTT per call.
  • Credentials & Origin Headers: When sending cookies or auth credentials cross-origin (credentials: "include"), confirm the response returns an explicit origin (e.g., Access-Control-Allow-Origin: https://app.example.com) plus Access-Control-Allow-Credentials: true—never *.
  • Conditional ETag & 304 Check: Inspect repeated GET requests in DevTools and verify ETag on the initial 200, If-None-Match on the reload, and 304 Not Modified (minimal transfer size) when unchanged.
  • SSE / Stream Inspection: For AI/streaming endpoints, open the request's EventStream (or Timing) tab in DevTools to verify chunks arrive incrementally rather than buffered until completion, and confirm cancelling navigation triggers (canceled) via AbortController.
