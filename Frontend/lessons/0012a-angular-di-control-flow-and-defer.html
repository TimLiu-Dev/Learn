01 · Mental Model Transfer & First Principles

From Hilt Scopes & RecyclerView DiffUtil to Angular DI, @for & @defer

First principles: In a large frontend app, components need three core capabilities without tangled imports or bloated initial bundles: (1) Dependency Injection (DI) so a component asks what service it needs rather than instantiating it directly; (2) Structural Control Flow so the template engine creates, destroys, and moves DOM nodes deterministically; and (3) Lazy Boundaries & Content Projection so heavy subtrees load only when needed and wrapper components stay reusable.

If you come from Android (Hilt / Dagger, DiffUtil, Compose slots, and ViewStub), Angular's architecture maps almost 1-to-1—with one huge web superpower: Angular's DI tree mirrors the live DOM/route hierarchy at runtime, and @defer automatically splits Vite/esbuild JS chunks without manual dynamic imports.

Concept Android / Hilt / Compose Equivalent Angular Mechanism Senior Pitfall & UX Impact
App & Route Singletons @SingletonComponent / @ActivityRetainedComponent in Hilt EnvironmentInjector (providedIn: 'root', route providers) providedIn: 'root' is tree-shakeable (unused services are stripped from the bundle); route providers scope state to a lazy route.
Component-Scoped State @ViewModelScoped or View-local helper object ElementInjector (@Component({ providers: [...] })) Putting a service in providers creates a new instance per component instance—great for form/wizard state, fatal if meant to be shared.
Lookup & Qualifiers @Inject constructor + @Named qualifiers inject(Token, { optional, self, skipSelf, host }) + InjectionToken<T> TypeScript interfaces vanish at runtime; always use InjectionToken for configs/interfaces. Use skipSelf when overriding a parent token cleanly.
Conditional & List Diffing if + RecyclerView.ListAdapter (DiffUtil.ItemCallback) / Compose key() @if / @else, @for (item of items; track item.id), @empty track is mandatory in Angular 17+. Tracking by $index on mutable lists preserves the wrong DOM node and corrupts input focus/state.
Lazy Subtree & UX ViewStub + dynamic feature module + Skeleton shimmer @defer (on viewport | interaction | idle) + @placeholder / @loading / @error Showing a spinner for 40ms causes visual flicker (cognitive load). Pair @placeholder (minimum 300ms) with @loading (after 100ms; minimum 250ms).
Slot Composition Compose slot lambdas (header: @Composable () -> Unit) <ng-content>, multi-slot select="...", and ngProjectAs Projected DOM is created in the parent template context; wrap lazy projected internals in <ng-template> if instantiation should wait.
Mental Model Summary — Two Parallel Injector Trees: When a component calls inject(FooService), Angular walks up the ElementInjector tree first (self → parent component → ancestor components). If no component provides FooService, Angular jumps to the EnvironmentInjector tree (child route injector → root injector → platform/null injector). Only if both trees miss does it throw NG0201: No provider found (unless { optional: true } is passed, which returns null).

06 · Real-World Verification & Next Steps

Angular DevTools & Production Verification Checklist

  • Injector Tree Audit (Angular DevTools): Open the Angular DevTools Chrome extension → Injector Tree tab. Verify global services resolve from EnvironmentInjector (root) and never accidentally duplicate inside a feature component's ElementInjector.
  • @for DOM Identity Check (Elements Panel): Inspect a list item's <li> in Chrome DevTools Elements, type into an inner <input>, then prepend a new item. Confirm the existing <li> node flashes/moves without losing input focus or text—proving track item.id is working.
  • @defer Bundle Split Check (Network Panel): Record a page load in DevTools → Network (JS filter). Verify heavy below-the-fold widgets (charts, rich text editors) only request their chunk-*.js file when the on viewport or on interaction trigger fires—or prefetch cleanly on idle.
  • UX Flicker Check (CPU/Network Throttling): Test @defer under both Fast 3G and No throttling. Confirm @placeholder (minimum 300ms) and @loading (after 100ms; minimum 250ms) prevent jarring 1-frame layout flashes.
