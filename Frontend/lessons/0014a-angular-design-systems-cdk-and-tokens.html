01 · Mental Model Transfer

Material 3 & Compose Modifiers → Angular Design Systems & CDK

On Android, Views and Jetpack Compose live inside an isolated app window with built-in MaterialTheme tokens, chained Modifier behavior composition, and OS-managed popups (PopupWindow / ModalBottomSheet). On the Web, every stylesheet shares one global cascade by default, elements can be clipped by ancestor overflow: hidden or CSS transform stacking contexts, and custom widgets have zero keyboard or screen-reader semantics unless you wire ARIA and focus management explicitly.

Angular solves these foundational Web challenges with three cooperating layers: ViewEncapsulation (scoped CSS boundaries), Host Directives (composable, non-inheritance behavior like Compose Modifiers), and the Angular Component Dev Kit (CDK) (headless, unstyled behavioral primitives for overlays, focus trapping, keyboard navigation, and screen-reader announcements)—all themed via a three-tier CSS Custom Property token pipeline translated directly from Figma.

Design System Layer Android / Jetpack Compose Equivalent Angular + CDK Web Mechanism Key Web Pitfall
Style Isolation ComponentActivity theme + scoped Compose layout nodes ViewEncapsulation.Emulated (_ngcontent-* attrs), ShadowDom, or None Using deprecated ::ng-deep without :host leaks styles globally across unrelated routes.
Behavior Composition Chained Compose Modifier.clickable().semantics() hostDirectives on @Component / @Directive with explicit inputs/outputs Class inheritance (extends BaseButton) creates rigid mixins and hides host bindings from templates.
Floating Layers PopupWindow / Dialog attached to WindowManager CDK Overlay + Portal teleported into .cdk-overlay-container at <body> Rendering a dropdown inline with z-index: 9999 still clips inside an ancestor with overflow: hidden or transform.
Focus & Keyboard FocusRequester + focusGroup() + TalkBack announcements FocusTrap, FocusKeyManager / ActiveDescendantKeyManager, LiveAnnouncer Forgetting to restore focus to the trigger button on modal close strands keyboard users at the top of <body>.
Design Tokens & Variants MaterialTheme.colorScheme + sealed variant enums 3-tier CSS Variables (--ref → --sys → --comp) + typed signal input() unions Hardcoding raw hex colors or boolean prop explosions (isPrimary + isDanger) breaks dark mode and Figma parity.

06 · Real-World Verification & Next Steps

Chrome DevTools Audit Checklist + Teacher Follow-Up

  • ViewEncapsulation & CSS Cascade Inspection: In DevTools Elements, verify component hosts carry _nghost-* and templates carry _ngcontent-* (or a #shadow-root for ShadowDom). Confirm theme overrides happen via CSS Custom Properties on :root or host classes—never unguarded ::ng-deep.
  • Overlay & Focus Restoration Test: Open any modal/menu/combobox using only Tab, Enter, ArrowDown, and Escape. Confirm the overlay sits inside .cdk-overlay-container, focus stays trapped inside modals, and closing returns focus to the exact trigger element.
  • Accessibility Tree & WCAG Contrast Audit: Open DevTools Accessibility pane to verify roles (listbox, option, dialog), aria-activedescendant, and live regions. Click any color swatch in Styles to verify ≥ 4.5:1 contrast for normal text and ≥ 3:1 for large text and focus rings.
