Compressed production rules for landmarks, Top Layer native controls, responsive media, cascade layers, stacking contexts, and intrinsic layouts.

1. Semantic HTML, ARIA & Top Layer Controls

PatternCorrect Native PrimitiveCritical Trap to Avoid
Landmarks<header>, <nav>, <main>, <aside>, <footer>Using <div onClick> instead of <button>/<a href> (loses keyboard & screen-reader semantics).
Modals & Popovers<dialog>.showModal() (Top Layer + Escape + backdrop) and [popover]Hand-rolling z-index: 9999 modals trapped inside parent transform/overflow: hidden.
Live Regionsaria-live="polite" (toasts/status) or role="alert" (urgent)Mounting the live region dynamically at error time instead of keeping it mounted and updating text.
