1. Strict TypeScript & Type-Level Patterns

PatternSyntax / FlagWhy It Matters
Production tsconfig"strict": true, "noUncheckedIndexedAccess": true, "exactOptionalPropertyTypes": true, "isolatedModules": trueCatches arr[i] undefined crashes and distinguishes omitted keys from explicit undefined.
satisfies vs as constconst routes = { ... } as const satisfies Record<string, Route>;Validates structure against a contract without widening literal keys/values.
Exhaustive UnionsDiscriminated union + default: return assertNever(state);Compiler fails loudly whenever a new union variant isn't handled.
Boundary ValidationParse unknown API JSON with Zod / x is T guardsTS types erase at runtime; res.json() as User is an unchecked lie.
Variance & NoInferProperty arrow callbacks onChange: (v: T) => void; NoInfer<T> on fallback argsEnforces contravariance under strictFunctionTypes and stops invalid defaults from widening T.
infer & Mapped TypesT extends Promise<infer U> ? U : T; { -readonly [K in keyof T]-?: T[K] }Powers Awaited, ReturnType, Parameters, and recursive Paths<T>.
.d.ts AugmentationInclude export {} at top + declare global { interface Window { ... } }Without export {}, a .d.ts file becomes a global script and overwrites rather than merges.
