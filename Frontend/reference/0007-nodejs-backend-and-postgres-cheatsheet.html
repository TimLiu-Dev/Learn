Compressed backend engineering reference bridging Java/Kotlin Spring Boot mental models to production TypeScript + Node.js.

1. Node Runtime, REST/DI & Persistence

PillarCore MechanismSpring Boot Mental Anchor
libuv & WorkersSingle-threaded non-blocking I/O phases (timers → poll → check) + microtasks (nextTick before Promise); stream.pipeline backpressure; worker_threads for CPU.Netty EventLoop vs Tomcat Thread-per-Request; offload heavy CPU off the EventLoop.
REST, RFC 9457 & DIStrict verbs/status codes (201, 204, 409, 422), RFC 9457 Problem Details, Idempotency-Key for POST; constructor IoC container (Fastify/Hono or NestJS).@RestController + ProblemDetail + Spring IoC bean lifetimes (singleton vs request).
PostgreSQL & RedisDrizzle/Prisma migrations, connection pooling, ACID transactions (BEGIN/COMMIT/ROLLBACK), JOIN/batching to kill N+1 queries, Redis TTL caching.Spring Data JPA / Flyway + @Transactional + HikariCP pool.

2. Auth Security, Queues, Testing & Docker Ops

PillarProduction StandardCritical Trap to Avoid
Auth & ValidationFail-fast Zod env/DTO validation; argon2id password hashing; rotating refresh tokens with reuse detection; RBAC + tenant-scoped queries; token-bucket/sliding rate limitsPlain SHA-256 passwords; IDOR bugs (checking auth without checking WHERE tenant_id = req.user.tenantId); SSRF on user URLs.
Real-Time & QueuesRedis Pub/Sub fan-out across API replicas for SSE/WS; BullMQ persistent retries + Dead-Letter Queue (DLQ) + idempotent webhook handlersStoring WebSocket subscribers only in process RAM (breaks horizontally across >1 Node container).
Testing & Prod OpsVitest + Supertest + Testcontainers (real Postgres); Pino JSON logs (redacted PII); OpenTelemetry traces; graceful SIGTERM drain in multi-stage DockerMocking SQL with fake JS objects instead of Testcontainers; killing active DB transactions on deploy without draining.
