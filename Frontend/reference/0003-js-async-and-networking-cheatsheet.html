Compressed mental models for closures, memory reachability, microtask priority, observers, i18n, and resilient HTTP networking.

1. JS Engine, Memory & Event Loop Order

ConceptExact BehaviorProduction Rule
Browser Tick Order1. Sync Call Stack → 2. Drain all Microtasks (Promise, queueMicrotask) → 3. requestAnimationFrame + Render → 4. Next Macrotask (setTimeout, I/O).Never chain recursive microtasks; they starve Layout & input.
Promise Combinatorsall (fail-fast), allSettled (all outcomes), race (first settle—win or error), any (first fulfill).Use allSettled for independent dashboard panels; race + AbortController for timeouts.
this Binding Ordernew > explicit (call/apply/bind) > implicit (obj.fn()) > default (undefined in strict). Arrow functions capture lexical this.Bind or use arrow wrappers when passing methods as DOM/timer callbacks.
Memory & GCReachability from GC roots; WeakMap/WeakSet hold weak object keys so metadata auto-collects.Clean up AbortController, timers, and observers on teardown to avoid Detached DOM leaks.

2. DOM, Storage, i18n & Networking

APICore MechanicsSenior Pitfall
Event DelegationOne listener on parent; resolve target via e.target.closest(selector).e.target.matches() fails when user clicks an inner <svg> or <span>.
ObserversIntersectionObserver (visibility/lazy load), ResizeObserver (box size), MutationObserver (DOM edits).Mutating observed element size inside ResizeObserver causes loop warnings.
Storage & ClonelocalStorage (~5MB sync string); IndexedDB (async transactional objects/Blobs); structuredClone().Never store JWTs in localStorage (XSS-readable); cache new Intl.* formatters outside loops.
fetch() & Streamsfetch only rejects on network/abort errors (NOT HTTP 404/500!). Check res.ok; stream via res.body.getReader() + TextDecoder(..., { stream: true }).Always wire AbortController on route/input changes; never skip res.ok checks.
CORS PreflightNon-simple headers/methods trigger OPTIONS; credentials: "include" requires explicit Access-Control-Allow-Origin (not *).Set Access-Control-Max-Age on APIs so preflights are cached across calls.
