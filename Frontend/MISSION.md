# Mission: Senior Web Frontend & Fullstack Node.js Engineering (2027)

## Why
Transition from a Junior Android + Java/Kotlin Spring Boot developer to a job-ready Senior Frontend / Fullstack-capable Engineer by 2027, mastering modern web frontend end to end alongside a complete Node.js + TypeScript backend stack and flagship resume-grade Fullstack Capstone.

## Success looks like
- Completing Part 1 (Frontend: browser internals, HTML/CSS, deep JS, strict TS, React + Next.js primary track & Modern Angular enterprise track, testing, security, CWV) and Part 2 (Node.js + TS backend: `libuv`, REST/DI, Fastify/Hono & NestJS, PostgreSQL + Drizzle/Prisma, Redis, auth security, Docker/OTel).
- Shipping milestone projects cleanly (Milestone 1: Vanilla HTML/CSS/JS → Milestone 2: React or Angular SPA → Final Fullstack Capstone: Next.js App Router + Node.js/PostgreSQL `OpsDeck` monorepo with Playwright/Supertest CI, ADRs, Docker, and Lighthouse CI budgets).

## Constraints
- Starting background: Junior Android Developer + Junior Java/Kotlin Spring Boot Developer.
- Do NOT skip foundational backend/architecture concepts (e.g., REST semantics, Dependency Injection, SQL transactions)—teach them comprehensively end to end while using Android/Spring Boot analogies to accelerate transfer.
- Every lesson must be an interactive HTML document with runnable code examples, automated code practice checks + hints + final answers, and diagnostic MCQs explaining why right is right and why every distractor fails.

## Out of scope
- Non-JS backend stacks (e.g., Python/Go) or heavy DevOps/Kubernetes administration beyond Dockerized Node/Next.js CI/CD.
