# Prior Knowledge: Junior Android Developer Baseline

Status: active
Evidence: User stated goal "become a senior frontend engineer from a junior android developer in 2027" (initial session).

The learner already understands mobile app fundamentals—typed OOP/FP basics (Kotlin/Java), HTTP client calls, async UI-thread constraints (16.6ms frame budgets, avoiding main-thread blocking), declarative/view-tree UI lifecycles, and basic automated testing. Future lessons should skip "what is a variable/HTTP request/UI thread" basics and instead anchor directly onto Android-to-Web translations while drilling web-specific failure modes (DOM/CSSOM render blocking, layout thrashing, Event Loop microtasks, CORS/XSS, JS bundle budgets, and TypeScript type erasure).
