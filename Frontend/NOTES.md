# Teaching Notes & User Preferences

- **Background:** Junior Android + Junior Java/Kotlin Spring Boot Developer targeting **Senior Frontend / Fullstack Engineer in 2027**. Use Android & Spring Boot analogies as bridges, **without skipping foundational general backend/web concepts** (such as REST semantics, Dependency Injection from first principles, ACID transactions, auth fundamentals).
- **Curriculum Structure & Project Cadence:** `master-plan.html` covers Part 1 Frontend (24 lessons in React or Angular track; 30 total modules) + Part 2 Node.js Backend (6 comprehensive lessons B01–B06), aligned with all 10 `roadmap.sh` roadmaps (`frontend`, `html`, `css`, `javascript`, `typescript`, `react`, `angular`, `nextjs`, `ux-design`, `nodejs`).
  - Milestone 1 (after Phase 2): Vanilla HTML/CSS/JS app
  - Milestone 2 (after Phase 4): Pure React SPA (or Angular SPA)
  - Milestone 3 (Final Fullstack Capstone): Next.js App Router (or Angular SSR) + Node.js (Fastify/NestJS) + PostgreSQL (Drizzle) + Redis `OpsDeck` monorepo.
- **Required Lesson Features (Benchmark established in Lesson 01):**
  1. **Runnable Code Examples** embedded directly inside the HTML.
  2. **Interactive Code Practice Labs** inside the HTML that execute in-browser, run automated assertion checks, and offer progressive hints plus a revealed final answer with explanation.
  3. **Diagnostic Multiple-Choice Quizzes** with balanced option lengths (no formatting giveaways) and explicit explanations of *why the right choice is correct* AND *why each wrong choice is wrong*.
  4. **Reusable Assets (`./assets/`)** so all lessons share one cohesive stylesheet, sandboxed lab runner, and quiz engine.
  5. **Reference Sheets (`./reference/`)** for compressed, printable quick review.
