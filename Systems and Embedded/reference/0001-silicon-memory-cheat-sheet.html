Silicon Memory, Bitwise Logic & Compilation Quick Reference

A compressed reference sheet of essential memory layouts, bitwise manipulation operators, compiler commands, and pointer scale factors. Designed for rapid retrieval during firmware and driver development.

1. The 4 Stages of C Compilationgcc / clang

Command breakdown for low-level inspection:

  • gcc -E file.c -o file.i
    Preprocessor: Expands `#include`, `#define`, and comments.
  • gcc -S file.i -o file.s
    Compiler: Translates C to assembly text.
  • gcc -c file.s -o file.o
    Assembler: Emits binary object machine code.
  • gcc file.o -T link.ld -o app.elf
    Linker: Resolves symbols and lays out physical memory addresses.
2. Memory Segments of an ELF Binaryreadelf -S
  • .text • Flash / ROM
    Executable machine instructions and Vector Table.
  • .rodata • Flash / ROM
    Read-only constants (string literals, lookup tables).
  • .data • Flash $\rightarrow$ SRAM
    Initialized global & static variables (copied to RAM at boot).
  • .bss • SRAM
    Uninitialized globals (cleared to 0 at boot by startup code).
  • .stack / .heap • SRAM
    Runtime call frames (stack descends; heap ascends).
3. Bitwise Register ManipulationMISRA-C Standard
/* Set Bit n to 1 (OR) */
REG |= (1U << n);

/* Clear Bit n to 0 (AND NOT) */
REG &= ~(1U << n);

/* Toggle Bit n (XOR) */
REG ^= (1U << n);

/* Test if Bit n is set */
bool is_set = (REG & (1U << n)) != 0;

/* Multi-bit field replace (mask & shift) */
REG = (REG & ~MASK) | ((val << shift) & MASK);
4. Pointer Scaling Mechanicssizeof(*ptr)

ptr + n increments by n * sizeof(*ptr) bytes, NOT n bytes:

  • uint8_t* p8; p8 + 1 $\rightarrow$ base + 1 byte
  • uint16_t* p16; p16 + 1 $\rightarrow$ base + 2 bytes
  • uint32_t* p32; p32 + 1 $\rightarrow$ base + 4 bytes
  • uint64_t* p64; p64 + 1 $\rightarrow$ base + 8 bytes
5. Volatile DeclarationsCompiler Safety
/* Read/Write Peripheral Control Register */
volatile uint32_t* reg = (volatile uint32_t*)0x40001000;

/* Read-Only Hardware Status Register */
const volatile uint32_t* sr = (const volatile uint32_t*)0x40001004;

/* Fixed Address CMSIS Peripheral Mapping */
#define UART1 ((UART_TypeDef* const)0x40011000UL)
6. Binary Inspection CommandsGNU Binutils
  • arm-none-eabi-size app.elf
    Reports Flash (.text + .data) and RAM (.data + .bss) footprint.
  • arm-none-eabi-objdump -d app.elf
    Disassembles machine code back to assembly instructions.
  • arm-none-eabi-readelf -a app.elf
    Dumps complete ELF headers, symbol tables, and sections.
