# Curriculum Audit & 4-Tier Portfolio Alignment (C, C++, Rust, Capstone)

The learner reviewed the curriculum ahead of commencing study, clarifying that as a junior Android developer with 2 years of experience starting from scratch in low-level engineering, the curriculum must strictly follow a 4-tier language-and-project progression to build a senior-caliber resume for 2027:
1. C and C project
2. C++ and C++ project
3. Rust and Rust project
4. Grand Capstone project

## Implications
- The 4 core resume projects are now explicitly demarcated across C, C++, Rust, and Heterogeneous AAOS Capstone.
