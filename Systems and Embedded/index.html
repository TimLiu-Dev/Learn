Curriculum Architecture: Prerequisites, Pacing Adjustments & Hardware Anchors

1. Prerequisites & Prep Runway

Start with Lessons 0000a–0000b to refresh forgotten BSEE bench rules (voltage levels, I2C pull-ups, 60Ω CAN termination, 10x probing) and fitness-console IPC (AF_UNIX framing, SystemService, AOSP IME), then use Prep Track 00 (0001–0004d) for C11 pointers/Make/GDB before Phase 1.

2. Pacing Guardrails Applied

Phase 1 (Wks 1–5): Core drivers (SSD1306, LSM6DSV16X, EC11) in Wks 1–4; BME280 + FatFs MicroSD buffered in Wk 5.
Phase 5A (Wks 21–25): Buildroot-first for fast Pi 4 iteration; Yocto (meta-raspberrypi) as Wk 25 stretch.
Phase 5B: Side-by-side C++ & Rust vendor.dev.hardware.fitnesstelemetry AIDL HAL on Cuttlefish.

3. Every Phase Engineering Bar

Host unit tests (Unity/Ceedling, GoogleTest, cargo test + embedded-hal-mock, Zephyr native_sim/Twister), GitHub Actions CI, GDB/logic-analyzer/DSO2512G captures, and README wiring + pinned SDK versions. Verify local algorithms first in ./labs/ (make test)!
