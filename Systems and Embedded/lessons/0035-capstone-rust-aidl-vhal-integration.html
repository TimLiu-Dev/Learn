Grand Capstone Part 3:
Rust AIDL VHAL Service & Jetpack Compose Cockpit UI

In this third milestone of the Grand Capstone, you will complete the upper tiers of our automotive system: writing the native Rust Vehicle HAL daemon that reads packets from /dev/cockpit_bridge, verifies CRC integrity, dispatches property events over Binder IPC, and feeds a 60 FPS Jetpack Compose digital instrument cluster.

Mental Model Shift: Raw Byte Stream to Reactive Framework State

In device driver programming, data exists as untyped byte buffers in kernel memory. If a user space app interprets byte offsets incorrectly, data corrupts without compiler warnings.

In AOSP Systems Architecture, the Rust AIDL VHAL acts as the authoritative type-safe bridge: it reads the binary stream from /dev/cockpit_bridge, validates CRC-16 checksums, maps raw numbers to standardized enum properties (VehicleProperty::PERF_VEHICLE_SPEED), and fires AIDL callbacks. In Kotlin, Jetpack Compose binds directly to this reactive stream to animate speedometer needles smoothly at 60 FPS!

1. The Rust AIDL VHAL Service Implementation

The native daemon runs with vendor SELinux privileges, reading telemetry packets and pushing updates into Android's CarService:

vhal/src/main.rsRust AIDL Service
use android_hardware_automotive_vehicle::aidl::android::hardware::automotive::vehicle::{
    IVehicle::{BnVehicle, IVehicle},
    IVehicleCallback::IVehicleCallback,
    VehiclePropValue::VehiclePropValue,
    VehicleProperty::VehicleProperty,
};
use binder::{BinderFeatures, Interface, ProcessState, Result as BinderResult, Strong};
use std::fs::File;
use std::io::Read;
use std::sync::{Arc, Mutex};
use std::thread;

const COCKPIT_BRIDGE_DEV: &str = "/dev/cockpit_bridge";
const PACKET_SIZE: usize = 16;
const SYNC_BYTE_0: u8 = 0xAA;
const SYNC_BYTE_1: u8 = 0x55;

struct VehicleService {
    callbacks: Arc<Mutex<Vec<Strong<dyn IVehicleCallback>>>>,
}

impl Interface for VehicleService {}
impl IVehicle for VehicleService {
    fn subscribe(&self, callback: &Strong<dyn IVehicleCallback>, _options: &[...]) -> BinderResult<()> {
        let mut list = self.callbacks.lock().unwrap();
        list.push(callback.clone());
        Ok(())
    }
}

// Background hardware worker thread reading from Linux SPI character driver
fn start_telemetry_reader(callbacks: Arc<Mutex<Vec<Strong<dyn IVehicleCallback>>>>) {
    thread::spawn(move || {
        let mut file = File::open(COCKPIT_BRIDGE_DEV)
            .expect("Failed to open /dev/cockpit_bridge");
        let mut buffer = [0u8; PACKET_SIZE];

        loop {
            // Blocks efficiently in kernel poll() until MCU DRDY interrupt fires
            if let Ok(()) = file.read_exact(&mut buffer) {
                // 1. Verify Frame Synchronization
                if buffer[0] != SYNC_BYTE_0 || buffer[1] != SYNC_BYTE_1 {
                    continue;
                }

                // 2. Verify CRC-16 Integrity
                let expected_crc = ((buffer[14] as u16) << 8) | (buffer[15] as u16);
                let calculated_crc = compute_crc16(&buffer[0..14]);
                if expected_crc != calculated_crc {
                    log::warn!("CRC mismatch! Corrupted telemetry dropped.");
                    continue;
                }

                // 3. Unpack scaled speed (Big-Endian u16 / 100.0)
                let raw_speed = ((buffer[4] as u16) << 8) | (buffer[5] as u16);
                let speed_kmh = (raw_speed as f32) / 100.0;

                // 4. Dispatch VehiclePropValue event to CarService subscribers
                let prop = VehiclePropValue {
                    prop: VehicleProperty::PERF_VEHICLE_SPEED as i32,
                    areaId: 0,
                    value: speed_kmh,
                };

                let active_listeners = callbacks.lock().unwrap();
                for cb in active_listeners.iter() {
                    let _ = cb.onPropertyEvent(&[prop.clone()]);
                }
            }
        }
    });
}

2. Jetpack Compose Automotive Instrument Cluster

In Android Automotive OS, our Kotlin ViewModel collects speed telemetry from CarPropertyManager and surfaces it via Compose StateFlow:

ClusterSpeedometer.ktJetpack Compose (AAOS)
@Composable
fun ClusterSpeedometer(viewModel: ClusterViewModel = viewModel()) {
    val speedKmh by viewModel.speedKmh.collectAsStateWithLifecycle()
    val animatedSpeed by animateFloatAsState(
        targetValue = speedKmh,
        animationSpec = spring(stiffness = Spring.StiffnessLow),
        label = "speedNeedle"
    )

    Box(modifier = Modifier.fillMaxSize().background(Color(0xFF0F172A)), contentAlignment = Alignment.Center) {
        Canvas(modifier = Modifier.size(300.dp)) {
            // Draw dial background arc (from 135 deg to 405 deg)
            drawArc(
                color = Color.DarkGray,
                startAngle = 135f,
                sweepAngle = 270f,
                useCenter = false,
                style = Stroke(width = 24.dp.toPx(), cap = StrokeCap.Round)
            )

            // Draw active speed arc (0 to 240 km/h mapped to 0 to 270 degrees)
            val sweep = (animatedSpeed.coerceIn(0f, 240f) / 240f) * 270f
            drawArc(
                brush = Brush.sweepGradient(listOf(Color(0xFF06B6D4), Color(0xFF10B981))),
                startAngle = 135f,
                sweepAngle = sweep,
                useCenter = false,
                style = Stroke(width = 24.dp.toPx(), cap = StrokeCap.Round)
            )
        }

        Column(horizontalAlignment = Alignment.CenterHorizontally) {
            Text(
                text = "${speedKmh.toInt()}",
                fontSize = 64.sp,
                fontWeight = FontWeight.Black,
                color = Color.White
            )
            Text(text = "KM / H", fontSize = 14.sp, color = Color(0xFF94A3B8), fontWeight = FontWeight.Bold)
        }
    }
}

Implement the Rust packet verification routine: verify that the packet starts with sync bytes [0xAA, 0x55], unpack the big-endian speed_scaled u16, divide by 100.0, and return the speed as f32. If framing is invalid, return -1.0.

Reference Solution: 
float parse_vhal_speed_packet(const uint8_t *packet) {
    if (packet[0] != 0xAA || packet[1] != 0x55) return -1.0f;
    uint16_t speed_scaled = ((uint16_t)packet[4] << 8) | (uint16_t)packet[5];
    return (float)speed_scaled / 100.0f;
}
