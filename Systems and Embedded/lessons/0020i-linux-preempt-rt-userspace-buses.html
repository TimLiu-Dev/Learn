Real-Time Linux (PREEMPT_RT) &
Userspace Hardware Buses (libgpiod, spidev, i2c-dev)

You do not always need a custom kernel module to drive SPI, I2C, or GPIO—and when robotics or industrial control loops require sub-millisecond jitter on Linux, mainline PREEMPT_RT transforms Linux into a deterministic real-time OS.

Mental Model Shift: Best-Effort CFS vs Deterministic PREEMPT_RT

Standard Linux optimizes for average throughput (CFS/EEVDF) and swaps/pages lazily, meaning a background log flush can stall a thread for 15ms.

With PREEMPT_RT (now upstream in Linux 6.12+), kernel spinlocks convert to priority-inheriting sleeping locks, IRQs run as schedulable kernel threads, and SCHED_FIFO + mlockall() guarantee bounded wakeup latency under 50 µs!

1. The 3 Rules of Real-Time Linux Threads

  1. Lock All Memory Pages: Call mlockall(MCL_CURRENT | MCL_FUTURE) and pre-fault your stack before entering the control loop so page faults never stall real-time execution.
  2. Elevate Scheduler Priority & Pin CPU: Use pthread_setschedparam(..., SCHED_FIFO, ...) paired with kernel boot parameter isolcpus=3 so non-RT tasks never preempt core 3.
  3. Zero Syscall / Allocator Surprises: Pre-allocate buffers upfront and avoid malloc(), file logging, or blocking mutexes inside the RT loop.

2. Userspace Bus Access Without Custom Kernel Drivers

Use standard Linux subsystems before writing custom out-of-tree kernel code: libgpiod v2 (character device /dev/gpiochip0—replacing deprecated /sys/class/gpio), /dev/spidev0.0 via SPI_IOC_MESSAGE, and /dev/i2c-1 via I2C_SLAVE.

rt_loop.c (Deterministic Linux Control Thread Setup) 
int enter_realtime_mode(int priority) {
    if (mlockall(MCL_CURRENT | MCL_FUTURE) < 0) return -1;
    struct sched_param sp = { .sched_priority = priority };
    return pthread_setschedparam(pthread_self(), SCHED_FIFO, &sp);
}

Question 1 • Real-Time Jitter Prevention
Why must a SCHED_FIFO control thread call mlockall(MCL_CURRENT | MCL_FUTURE) before entering its 1 kHz loop?
Prevents minor or major page faults from stalling deterministic thread execution
Forces the Linux kernel to disable hardware interrupts across all CPUs
Automatically grants root network socket permissions without systemd capability settings
Converts SPI character devices into zero copy shared memory ring buffers
✓ Correct! (Option A: Prevent page faults during RT loops)
Locking memory pages into physical RAM guarantees the MMU never pauses your real-time thread to fault in memory pages on demand.
Analysis of Distractors:
• Options B, C, D: mlockall() deals exclusively with virtual memory page residency, not IRQs, capabilities, or SPI DMA.
