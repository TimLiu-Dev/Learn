Bare-Metal Peripheral Drivers:
SSD1306, LSM6DSV16X, EC11, BME280 & MicroSD

Bring your Milestone 1 Telemetry Flight Recorder to life on the WeAct STM32F411CEU6 without STM32 HAL: page-addressed OLED DMA, interrupt-driven IMU FIFO reads, hardware timer quadrature decoding, datasheet sensor compensation, and shared-SPI MicroSD logging.

Pacing Strategy: Core (Weeks 1–4) vs Week 5 Stretch Buffer

Build Milestone 1 in clean increments: Weeks 1–4 lock down SSD1306 SPI+DMA, LSM6DSV16X I2C+EXTI into an SPSC ring buffer, and EC11 timer quadrature.

Week 5 adds BME280 compensation math and FatFs MicroSD logging—after verifying whether your MicroSD module has a 74LVC125 buffer that hogs MISO when deselected!

1. Core Drivers (Weeks 1–4)

  • 0.96" SSD1306 OLED (4-Wire SPI + DMA): Ships configured for SPI with a separate DC pin (0 = command, 1 = pixel data). Maintain a 1024-byte framebuffer (128 × 64 / 8 pages) in SRAM and blast it over SPI DMA at 60 FPS with zero CPU copy.
  • LSM6DSV16X 6-DoF IMU (I2C + EXTI): Verify WHO_AM_I (0x0F == 0x70). Configure INT1 data-ready to fire an EXTI ISR that triggers an I2C/DMA read and pushes samples into a lock-free SPSC ring buffer.
  • EC11 Quadrature Encoder (Hardware Timer): Map channels A/B to TIM2/TIM3 Encoder Mode (SMS = 0b011). Silicon counts every edge and flips direction automatically with zero missed interrupts; debounce the push switch in a 10 ms tick.

Interactive Practice: SSD1306 Page-Addressed Pixel Setter

An SSD1306 stores 8 vertical pixels per byte across 8 horizontal pages (128 × 8 = 1024 bytes). Implement oled_set_pixel(uint8_t fb[1024], uint8_t x, uint8_t y, bool on): ignore out-of-bounds x >= 128 or y >= 64, compute byte index (y / 8U) * 128U + x and bitmask (uint8_t)(1U << (y & 7U)), and set or clear that bit.

ssd1306_fb.c
💡 Progressive Guidance Hints:
Hint 1: Page number is y >> 3 (same as y / 8U), and bit inside that byte is y & 7U.
Hint 2: Clear a pixel cleanly with fb[idx] &= (uint8_t)~mask;.
✅ Reference Production Solution:
void oled_set_pixel(uint8_t fb[1024], uint8_t x, uint8_t y, bool on) {
    if (x >= 128U || y >= 64U) return;
    uint16_t idx = (uint16_t)((y / 8U) * 128U + x);
    uint8_t mask = (uint8_t)(1U << (y & 7U));
    if (on) {
        fb[idx] |= mask;
    } else {
        fb[idx] &= (uint8_t)~mask;
    }
}

Knowledge Check

Question 1 • Shared SPI Contention
When you connect both your BME280 and a cheap MicroSD module to SPI1 with separate CS pins, BME280 reads return 0xFF or garbage. What hardware defect on many MicroSD breakouts causes this?
MicroSD cards permanently lock SPI clock to mode three
Onboard level shifter keeps MISO driven when CS rises
FAT32 cluster tables overwrite external Bosch temperature trim bytes
BME280 sensors require external pull-down resistors on chip select
✓ Correct! (Option B: Level-shifter buffer fails to tri-state MISO)
Many low-cost MicroSD boards wire the 74LVC125 buffer's output enable permanently LOW, fighting other SPI slaves on MISO. Moving MicroSD to SPI2 or inspecting the PCB traces eliminates the collision.
Analysis of Distractors:
• Options A, C, D: SD cards run in SPI Mode 0, FAT32 never touches sensor EEPROM trims, and chip select is push-pull active-LOW.
Question 2 • Hardware Quadrature Decoding
Why should the EC11 rotary encoder's A/B channels be wired to an STM32 hardware timer in Encoder Mode rather than polled inside while(1)?
Hardware timers supply five-volt power directly to rotary switches
Hardware timers replace external pull-up resistors with analog ADCs
Hardware timers track direction and edges without CPU latency
Hardware timers compress mechanical contact bounce into UART packets
✓ Correct! (Option C: Deterministic edge & direction tracking in silicon)
The timer peripheral samples A/B quadrature transitions in hardware and updates TIMx->CNT up or down automatically, even while the CPU handles DMA or OLED frames.
Analysis of Distractors:
• Options A, B, D: Timers don't source 5V power, aren't ADCs, and don't emit UART packets.
