Custom 4-Layer Carrier PCB:
KiCad Layout, Differential Routing & First-Power Bring-Up

Move off solderless breadboards onto your own assembled 4-layer carrier PCB in KiCad (routing an STM32F411 or pre-certified ESP32-C3 module to SN65HVD230 CAN, SP3485 RS485, INA226, and SWD/UART headers), then execute a disciplined Hardware Bring-Up Report.

Mental Model Shift: Jumper-Wire Debugging vs Design for Bring-Up

When a custom PCB arrives from assembly, never apply 5V/USB power immediately! A single solder bridge under an IC can pop a regulator before your firmware even flashes.

Design test points (`GND` loops, `3V3` rail, `NRST`, `SWDIO/SWCLK`, `CAN_H/L`), include `0Ω` isolation jumpers or removable `120Ω` CAN termination jumpers, and follow a strict unpowered → current-limited power → clock → SWD → bus bring-up sequence.

1. 4-Layer Stackup, Decoupling & Differential Pairs

  • Standard 4-Layer Stackup: L1: Signal + Components • L2: Solid Unbroken GND Plane • L3: 3V3 Power Pour • L4: Secondary Signal. Keeping L2 unbroken gives every fast signal on L1 a tight, low-inductance return path!
  • Decoupling Placement: Place 100 nF ceramics directly beside every VDD/VSS pin pair (trace to pad first, then via to L2/L3—never put the via between the cap and the MCU pin).
  • Differential Pairs & DFM: Route USB D+/D- (90Ω differential), CAN_H/CAN_L (120Ω), and RS485 A/B tightly coupled with matched lengths, and export Gerber/Drill + BOM + Pick-and-Place CPL verified in KiCad DRC.

2. First-Article Hardware Bring-Up Report Sequence

Disciplined 5-Stage Custom Board Bring-Up 
1. Visual + Continuity (Delixi DT9205APRO): Verify NO short between 3V3-GND and 5V-GND!
2. Power Rail Bring-Up: Apply 5V/USB (current-limited if possible), measure 3.30V ± 3%,
   check rail ripple on DSO2512G (AC-coupled, short ground spring!).
3. Clock & Reset Check: Probe NRST (3.3V high) and crystal oscillator startup on DSO2512G (10x).
4. SWD / JTAG Attach: Flash blinky via CMSIS-DAP + probe-rs/OpenOCD.
5. Peripheral & Bus Sign-Off: Verify INA226 I2C ACK, CAN_H/L diff waveform, and RS485 DE/RE!

✅ Reference Production Solution:
int evaluate_pcb_bringup(bool gnd_short, uint32_t rail_mv,
                         uint32_t ripple_mv, uint32_t swd_idcode) {
    if (gnd_short) return -1;
    if (rail_mv < 3200U || rail_mv > 3400U || ripple_mv > 50U) return -2;
    if (swd_idcode == 0U) return -3;
    return 0;
}

Knowledge Check

Question 1 • 4-Layer PCB Stackup
Why should Layer 2 in your 4-layer carrier PCB (Signal / GND / 3V3 / Signal) remain a solid, unbroken ground plane?
Unbroken planes convert three-volt signals into differential pairs
Unbroken planes provide tight low-inductance return current paths
Unbroken planes eliminate external decoupling capacitors on pins
Unbroken planes bypass Design Rule Checks during export
✓ Correct! (Option B: Low-inductance return path & controlled impedance)
High-frequency return currents flow directly underneath signal traces on the adjacent reference plane. Splitting Layer 2 forces return currents to detour, creating EMI loops and ringing!
Analysis of Distractors:
• Options A, C, D: Ground planes don't create differential signals, never replace local decoupling caps, and still require full DRC verification.
Question 2 • Board Bring-Up Discipline
What is the very first test you run on a newly assembled PCB with your Delixi DT9205APRO before plugging in any USB cable?
Flash full Zephyr Bluetooth firmware via OpenOCD scripts
Measure crystal oscillator startup amplitude using ten-times probes
Check continuity across power rails and ground shorts
Transmit one megabit CAN frames across both nodes
✓ Correct! (Option C: Unpowered rail-to-GND continuity check)
Checking 3V3-to-GND and 5V-to-GND resistance before applying power catches assembly solder bridges before they burn traces or LDO regulators.
Analysis of Distractors:
• Options A, B, D: Flashing, probing live crystal clocks, and running CAN all require powering the board first.
