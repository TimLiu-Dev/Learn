Hardware Bus Protocols & Direct Memory Access (DMA)

When an automotive sensor streams data at 25 Megabits per second, servicing each byte with an interrupt consumes 100% of the CPU's processing power. In this lesson, we master hardware serial buses (UART, SPI, I2C) and offload data transfers to the on-chip Direct Memory Access (DMA) controller.

Mental Model Shift: OkHttp Streaming vs Hardware DMA

In Android, streaming network data uses OkHttp and background threads; the Linux kernel driver and network card manage packet buffers transparently.

In embedded silicon, you configure the DMA Controller directly. You hand it a physical peripheral data register address (e.g. SPI1->DR) and an SRAM buffer address. The DMA hardware streams megabytes of data directly into RAM over the AHB bus while the CPU core enters low-power sleep!

1. The Big Three Serial Bus Protocols

  • UART (Universal Asynchronous Receiver-Transmitter): Asynchronous (no clock wire). Uses start/stop framing bits and agreed-upon baud rates (115200, 921600). Ideal for debug logs and GPS modems.
  • SPI (Serial Peripheral Interface): Synchronous, full-duplex, high-speed (up to 50+ MHz). 4 physical wires: MOSI (Master Out), MISO (Master In), SCK (Clock), and CS (Chip Select). Standard for flash memories, displays, and IMU sensors.
  • I2C (Inter-Integrated Circuit): Synchronous, 2-wire open-drain bus with pull-up resistors: SDA (Data) and SCL (Clock). Supports multiple addressed devices on a shared bus at 100 kHz (Standard), 400 kHz (Fast), or 1 MHz.

2. DMA Circular Ping-Pong Buffer Architecture

To ingest streaming high-speed data without packet loss, engineers configure the DMA in Circular Mode with two halves:

Circular Ping-Pong DMA Buffer Flow 
             ┌──────────────────────┬──────────────────────┐
DMA Buffer:  │   BUFFER HALF 1      │    BUFFER HALF 2     │
             │   (Bytes 0 to 511)   │   (Bytes 512 to 1023)│
             └──────────────────────┴──────────────────────┘
                         ▲                      ▲
                         │                      │
             Half-Transfer Interrupt (HT)   Transfer-Complete Interrupt (TC)
             CPU processes Half 1 while     CPU processes Half 2 while
             DMA fills Half 2!              DMA wraps back to fill Half 1!

This completely eliminates race conditions and ensures zero CPU cycle waste during transmission!

Interactive Practice: DMA Buffer Switcher Handler

Implement dma_get_active_buffer_offset() for a circular DMA controller. Given the buffer total size and whether the interrupt is Half-Transfer (HT) or Transfer-Complete (TC), return the start byte offset that the CPU is safe to process.

dma_circular_buffer.c
💡 Progressive Guidance Hints:
Hint 1: On Half Transfer, the first half (bytes 0 to total_size/2 - 1) is full and ready for CPU consumption.
Hint 2: On Transfer Complete, the second half (bytes total_size/2 to total_size - 1) is full.
✅ Reference Production Solution:
uint32_t dma_get_active_buffer_offset(uint32_t total_size, int event_type) {
    if (event_type == DMA_HALF_TRANSFER) {
        return 0;
    } else if (event_type == DMA_TRANSFER_COMPLETE) {
        return total_size / 2;
    }
    return 0;
}

3. Check Your Understanding

Question 1 • DMA Bus Offloading
What is the primary advantage of Direct Memory Access (DMA) over interrupt-driven I/O?
Transfers data without consuming processor clock cycles
Enables automatic encryption on serial communication lines
Eliminates requirement for physical pullup bus resistors
Doubles the maximum physical voltage of signals
✓ Correct! (Option A: Transfers data without consuming processor cycles)
DMA controllers operate independently on the high-speed AHB bus, moving memory words between SRAM and peripherals directly while the CPU core executes application code or sleeps.
Analysis of Distractors:
• Option B, C, D: DMA does not encrypt, replace pullups, or change voltages.
Question 2 • Serial Bus Comparisons
Which physical serial communication bus protocol requires an explicit chip-select (CS) signal line?
Universal asynchronous receiver transmitter bus interface
Serial peripheral interface synchronous communication bus
Inter integrated circuit two wire interface
Controller area network differential bus protocol
✓ Correct! (Option B: Serial peripheral interface - SPI)
SPI uses a dedicated Chip Select (CS / SS) wire per slave device to activate communication, whereas I2C addresses devices over software address bytes and UART is point-to-point.
Analysis of Distractors:
• Option A: UART has no CS pin.
• Option C: I2C uses 7-bit addresses sent over the SDA wire.
• Option D: CAN bus uses 11-bit or 29-bit message IDs.
