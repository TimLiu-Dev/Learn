Track 02: Real-Time Operating Systems • Lesson 0011

FreeRTOS Memory Strategies & Tickless Low-Power Idle

In battery-powered connected devices and automotive telematics units, running dynamic heap allocations and waking the CPU 1,000 times per second drains battery reserves. In this lesson, we master FreeRTOS memory schemes (heap_1 to heap_5), static allocation, and Tickless Idle power saving.

Mental Model Shift: Android Doze Mode vs RTOS Tickless Idle

In Android, power management is handled by system servers and the Linux kernel via Doze mode and CPU frequency governors.

In an RTOS, the periodic 1 ms SysTick interrupt wakes the CPU core 1,000 times a second even when no tasks are running! Tickless Idle stops the periodic SysTick and reprograms an on-chip low-power timer to sleep continuously until the exact microsecond the next task is scheduled.

1. FreeRTOS Heap Allocation Schemes (heap_1 to heap_5)

  • heap_1.c: The simplest allocator. Allocates memory from a static array. Memory can never be freed! Ideal for safety-critical systems where tasks, queues, and semaphores are created once at boot and never deleted.
  • heap_2.c: Best-fit algorithm. Allows freeing memory, but does not coalesce adjacent free blocks. (Deprecated in modern FreeRTOS).
  • heap_3.c: Wraps standard C library malloc() and free() with thread-safety locks. Non-deterministic execution time.
  • heap_4.c: First-fit algorithm with automatic block coalescing (merges adjacent free blocks into one large block). Standard choice for general systems.
  • heap_5.c: Like heap_4, but can span multiple non-contiguous physical SRAM banks (e.g. internal SRAM + external SDRAM).

2. Static Allocation: The Zero-Fragmentation Standard

For ISO 26262 automotive compliance, dynamic allocation is eliminated by using xTaskCreateStatic():

static_task.c (Deterministic Memory Footprint) 
#define STACK_SIZE 256
StaticTask_t xTaskBuffer;
StackType_t  xStack[STACK_SIZE];

void app_main(void) {
    // Zero heap allocation! Uses pre-allocated stack and TCB arrays in .bss
    xTaskCreateStatic(vTaskCode, "Telemetry", STACK_SIZE, NULL, 1, xStack, &xTaskBuffer);
}

Which FreeRTOS heap implementation guarantees zero memory fragmentation by prohibiting frees?
The heap one allocation scheme implementation
The heap two allocation scheme implementation
The heap three allocation scheme implementation
The heap four allocation scheme implementation
✓ Correct! (Option A: The heap one scheme)
heap_1.c allocates memory linearly and never frees it, making memory fragmentation physically impossible!
Analysis of Distractors:
• heap_2, 3, 4: All allow freeing, introducing potential fragmentation.
Question 2 • Tickless Idle Power Savings
How does FreeRTOS Tickless Idle mode reduce microcontroller power consumption?
Erases application firmware from internal flash storage
Suppresses periodic systick interrupts during idle intervals
Increases system clock frequency during sleep periods
Disables memory protection unit access permission checks
✓ Correct! (Option B: Suppresses periodic systick interrupts)
Tickless idle stops the 1 ms periodic timer, allowing the CPU to remain in deep low-power sleep modes until the next task deadline or external interrupt.
Analysis of Distractors:
• Option A: Firmware is never erased.
• Option C: Clock frequencies are reduced, not increased.
• Option D: MPU checks remain active.
