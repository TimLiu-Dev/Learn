Mental Model Shift: Open-Loop Duty Cycle vs Safety-Bounded Closed-Loop Control

Spinning a motor at a fixed 50% PWM duty cycle collapses under load or stalls silently into burned windings.

A production controller executes a fixed-period PID loop (e.g., 1 kHz hardware timer ISR), inserts hardware dead-time on complementary outputs, latches an immediate INA226 overcurrent cutoff, feeds IWDG/WWDG only on healthy loop completion, and recovers cleanly when CAN_H/CAN_L shorts.

1. TIM1 Complementary PWM, 12GA-N20 Wiring & Break Input

  • 12GA-N20 + TB6612FNG Power Isolation: Trace the 6-pin rear harness (M+, M-, Encoder VCC, GND, Phase A, Phase B). Wire Encoder VCC to 3.3 V (not 5 V!) so A/B quadrature outputs stay 3.3 V-safe into STM32F411 timer encoder pins, feed TB6612FNG VM from your second MB-102 5 V rail with a shared GND so stall spikes don't brown out the MCU, and pull STBY HIGH.
  • Dead-Time Insertion (TIM1_BDTR.DTG): When driving high-side and low-side MOSFETs on complementary channels (CH1 / CH1N), silicon transistors take tens of nanoseconds to turn off. Hardware dead-time guarantees both FETs are never on simultaneously (no battery-to-ground shoot-through!).
  • Hardware Break (BKIN) + Overcurrent: Wire INA226's programmable ALERT pin directly to an EXTI (or TIM1_BKIN) so motor drive cuts off in microseconds—not seconds after an I2C polling loop notices smoke.

2. Watchdogs & CAN Bus-Off Recovery

Deliberate Fault Injection Checklist (Verify on DSO2512G!) 
1. Short CAN_H to CAN_L on Blue Pill bus:
   -> TEC (Transmit Error Counter) hits 255 -> Node enters BUS-OFF (CAN_ESR.BOFF = 1).
   -> Enable ABOM (Automatic Bus-Off Management) or timed recovery after 128 x 11 recessive bits!
2. Inject an infinite while(1) stall in control task:
   -> Window Watchdog (WWDG) / Independent Watchdog (IWDG) resets MCU cleanly.
   -> On reboot, RCC->CSR reports IWDGRSTF -> motor defaults to safe 0% coast state!

Interactive Practice: Anti-Windup Clamped PID Step

Implement pid_step() in fixed-point/float C with overcurrent kill-switch and integrator anti-windup clamping: if overcurrent == true, reset pid->integral = 0.0f and return 0.0f immediately; otherwise compute err = setpoint - measured, accumulate & clamp integral to [-out_max, out_max], and clamp final output p + i + d to [-out_max, out_max].

motor_pid.c
💡 Progressive Guidance Hints:
Hint 1: Clamp helper: if (v > pid->out_max) v = pid->out_max; if (v < -pid->out_max) v = -pid->out_max;.
Hint 2: Resetting integral = 0.0f during overcurrent avoids a violent surge when power resumes!
✅ Reference Production Solution:
float pid_step(PidState *pid, float setpoint, float measured, float dt, bool overcurrent) {
    if (overcurrent) {
        pid->integral = 0.0f;
        return 0.0f;
    }
    float err = setpoint - measured;
    pid->integral += pid->ki * err * dt;
    if (pid->integral > pid->out_max) pid->integral = pid->out_max;
    if (pid->integral < -pid->out_max) pid->integral = -pid->out_max;

    float d = pid->kd * (err - pid->prev_err) / dt;
    pid->prev_err = err;

    float out = pid->kp * err + pid->integral + d;
    if (out > pid->out_max) out = pid->out_max;
    if (out < -pid->out_max) out = -pid->out_max;
    return out;
}

Knowledge Check

Question 1 • H-Bridge Power Safety
Why does TIM1 inject hardware dead-time between complementary high-side and low-side PWM gate signals?
Dead-time raises DC supply voltage doubling motor torque
Dead-time prevents overlapping transistor conduction causing short circuits
Dead-time lets I2C sensors share motor power pins
Dead-time filters mechanical bounce from rotary switch pins
✓ Correct! (Option B: Prevent shoot-through short circuits)
Because MOSFETs turn off slower than they turn on, switching complementary pairs instantaneously creates a momentary dead short from V+ to GND (shoot-through). Hardware dead-time guarantees safe break-before-make switching.
Analysis of Distractors:
• Options A, C, D: Dead-time slightly reduces effective max duty cycle rather than boosting voltage, doesn't multiplex I2C, and doesn't debounce switches.
Question 2 • PID Integrator Anti-Windup
What happens to a motor PID loop without anti-windup clamping if the shaft is mechanically stalled for three seconds?
Hardware timer counters automatically convert PWM into CAN packets
Proportional gain drops permanently to zero until hard reset
Integral error accumulates excessively causing huge overshoot upon release
Derivative terms erase the setpoint stored in flash memory
✓ Correct! (Option C: Integral windup drives massive overshoot)
While stalled, error stays large and the integral sum grows unboundedly. Once the jam clears, the saturated integrator slams the motor past the setpoint!
Analysis of Distractors:
• Options A, B, D: Timers never emit CAN frames, proportional gain is constant, and derivatives never erase flash.
