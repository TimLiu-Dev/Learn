Phase 2 Cheat Sheet: Identity, Permissions, Processes & systemd

Production checklists for users/sudo, chmod/ACLs/links, signals, hardened systemd units, timers, and packages.

Users, Groups & sudo

Command / ConceptProduction Usage / Rule
useradd -r -s /usr/sbin/nologin svcCreate non-login system service account
usermod -aG docker aliceAppend group (forgetting -a strips existing groups!)
id alice / groups aliceEffective UID, primary GID, supplementary groups
visudo -f /etc/sudoers.d/opsSyntax-checked least-privilege sudo drop-in
/etc/passwd vs /etc/shadowWorld-readable metadata vs 0640 hashed passwords

Permissions, Special Bits & Links

Command / ConceptProduction Usage / Rule
chmod 0750 dir / 0640 fileOwner rwx/rw, group rx/r, world none
4000 / 2000 / 1000SUID / SGID (inherit group on dirs) / Sticky (/tmp)
umask 027Default new files 640, dirs 750
ln a b vs ln -s a bHard link (same inode) vs symlink (points to path)
setfacl -m u:bob:rx /srv/appFine-grained POSIX ACL entry; inspect with getfacl

Processes, Signals & Scheduling

Command / ConceptProduction Usage / Rule
ps aux --sort=-%mem | headTop memory consumers snapshot
kill -15 PID vs kill -9 PIDSIGTERM (clean shutdown) vs uncatchable SIGKILL
kill -HUP PIDSIGHUP: reload config without dropping sockets
State Z (Zombie)Already dead; waiting on parent wait() — signal parent, not Z
nice -n 10 cmd / reniceAdjust CPU scheduling priority (-20 highest to +19 lowest)
