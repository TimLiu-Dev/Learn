Phase 3 Cheat Sheet: Storage, LVM, Hardware & Boot Rescue

Commands for disk exhaustion, deleted-open-file recovery, LVM online resize, kernel drivers, and GRUB/chroot rescue.

Disk Space, Inodes & fstab

Command / ConceptProduction Usage / Rule
df -hT vs df -iBlock usage + FS type vs inode count exhaustion
du -xhd1 /var | sort -hOne-filesystem top space directories under /var
lsblk -f / blkidBlock tree, FS types, and persistent UUIDs
mount -o remount,ro /mntSwitch mount read-only cleanly
findmnt --verify / mount -aValidate /etc/fstab BEFORE rebooting (use nofail on secondary disks)
cryptsetup luksDump /dev/nvme0n1p3Inspect LUKS2 cipher, keyslots, and UUID before editing /etc/crypttab
btrfs subvolume snapshot -r @data @snapCreate instantaneous read-only COW filesystem snapshot

Open Files, LVM, logrotate & Disk Latency

Command / ConceptProduction Usage / Rule

pvs / vgs / lvsInspect Physical Volumes, Volume Groups, Logical Volumes

logrotate -d /etc/logrotate.d/aegisDry-run rotation, copytruncate / postrotate signal rules
iostat -xz 1Inspect await latency and %util saturation
