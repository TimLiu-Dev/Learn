Linux Systems Engineering Glossary

Canonical systems definitions spanning all 6 phases — engineered for fast interview review, incident command clarity, and clean printing.

Term Definition Curriculum Link / Android Bridge
Linux KernelPrivileged Ring-0 OS core managing CPU scheduling, virtual memory, hardware drivers, filesystems, and network stacks.Same core as Android's GKI kernel; inspected via uname -a and /proc.
System Call (Syscall)Controlled entry point from user space into the kernel (e.g., openat, read, fork, execve, chdir).Documented in man 2 <name>; traced in Lesson 0025 via strace.
Shell & BuiltinsUser-space interpreter (/bin/bash) plus compiled-in state mutators like cd, export, and type.Android uses Toybox/mksh in adb shell; verify with type.
FHS 3.0Filesystem Hierarchy Standard defining /etc, /var, /usr, /opt, /tmp, and /srv.Replaces Android's /system, /vendor, and /data layout.
procfs & sysfsIn-memory kernel filesystems exposing live processes (/proc) and hardware/driver tunables (/sys) with 0 disk bytes.Lesson 0001 & 0022; backing source for top, ps, and custom monitors.
Globbing vs RegexShell filename expansion (*, ?, [a-z]) vs pattern matching engines inside grep -E, sed, and awk.Lesson 0001 vs Lesson 0005.
PTY / Multiplexer (tmux)Pseudo-terminal pairs managed by a background server so interactive shells and split panes survive SSH disconnects.Lesson 0002; prevents dropped deploy or upgrade sessions.
File Descriptor (FD 0/1/2)Per-process kernel handle table index: 0=stdin, 1=stdout, 2=stderr. Shell redirection mutates FDs left-to-right before execve.Lesson 0004; Android Logcat pipes work on standard FDs.
POSIX ACLAccess Control Lists extending traditional rwx owner/group/other bits to specific additional users or groups (getfacl/setfacl).Lesson 0008; inspect + suffix in ls -l.
InodeFilesystem metadata structure storing permissions, owner, timestamps, link count, and block pointers (everything except the filename).Lesson 0008 & 0013; exhausting inodes causes No space left even with free GiB.
LUKS2 / dm-cryptLinux Unified Key Setup on-disk block encryption format managed by cryptsetup with Argon2id keyslots and /etc/crypttab boot unlock.Lesson 0013; equivalent concept to Android file-based/metadata encryption.
logrotateScheduled log rotation daemon/timer compressing aged logs and signaling services (or using copytruncate) to prevent runaway disk fill.Lesson 0014; paired with lsof +L1 incident triage.
systemd Unit & SandboxingDeclarative INI config defining a service, socket, or timer plus kernel restrictions like ProtectSystem=strict and NoNewPrivileges=yes.Lesson 0010; replaces imperative SysV init scripts.
LVM (PV / VG / LV)Logical Volume Manager layer abstracting physical disks into Volume Groups and online-resizable Logical Volumes with snapshots.Lesson 0014; essential for zero-downtime disk expansion.
initramfsCompressed cpio root archive loaded into RAM by GRUB before the real root filesystem mounts; holds storage/encryption drivers.Lesson 0016; Android boot images use an analogous ramdisk.
systemd-resolved & Split DNSLocal stub resolver (127.0.0.53) routing internal corporate/VPN zones cleanly to tunnel DNS servers via resolvectl.Lesson 0017; separates corporate domains from public DNS.
Netfilter / nftablesLinux kernel packet-filtering hook framework configured atomically via nft tables, chains, and verdict rules.Lesson 0019; modern replacement for legacy iptables.
WireGuardModern in-kernel Layer-3 VPN tunnel using Curve25519/ChaCha20-Poly1305 with stateless UDP roaming.Lesson 0020; configured via wg and /etc/wireguard/.
Page Cache & OOM KillerKernel cache of disk pages in unused RAM (reclaimable instantaneously); OOM killer terminates highest-score process if memory truly exhausts.Lesson 0023; compare Android Low Memory Killer Daemon (lmkd).
Linux CapabilitiesFine-grained privilege slices (e.g., CAP_NET_BIND_SERVICE) splitting root power without granting full UID 0.Lesson 0024; heavily used by systemd services and containers.
SELinux / AppArmorMandatory Access Control (MAC) kernel modules enforcing least-privilege policy even on UID 0 processes.Lesson 0024; Android enforces SELinux strictly across every domain.
strace & eBPFstrace intercepts syscalls via ptrace (higher overhead); eBPF runs sandboxed bytecode inside the kernel for safe nanosecond observability.Lessons 0025 & 0026; USE Method tooling.
Namespaces & cgroups v2Kernel isolation of PIDs/net/mounts/users paired with unified hierarchical CPU/memory/I/O resource accounting.Lesson 0027; containers are ordinary processes wrapped in both.
Podman QuadletsDeclarative .container INI units translated by systemd generators so rootless OCI containers enjoy native dependency ordering and logging.Lesson 0027; production alternative to ad-hoc shell container scripts.
VRRP (Keepalived)Virtual Router Redundancy Protocol electing an active node to hold a floating Virtual IP and failing over automatically on health-check loss.Lesson 0029; eliminates single load-balancer points of failure.
