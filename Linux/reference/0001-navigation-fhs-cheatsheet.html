Host Reconnaissance Commands

CommandPurpose
uname -aKernel name, hostname, release, CPU arch
cat /etc/os-releaseLinux distribution & version
ps -p $$Actual currently running shell process
echo $SHELLConfigured default login shell
type <cmd>Builtin vs alias vs $PATH binary
man <sec> <name>Manual (1=cmd, 2=syscall, 5=config, 8=admin)
whatis / apropos1-line summary / search man descriptions

Navigation, CRUD & Glob Rules

Pattern / CommandBehavior
pwd / cd -Print $PWD / jump back to $OLDPWD
ls -lahSLong, dotfiles, human sizes, largest first
mkdir -p a/{b,c}Idempotent nested directory creation
cp -r / mvRecursive copy / atomic rename or move
rm *.tmpDeletes .tmp files; skips leading dotfiles
rm -rf "${DIR:?}/"*Safe guarded delete (fails if $DIR unset)

FHS 3.0 Directory Placement Map

PathRoleDo Not Confuse With
/etcEditable host/service text configsNot for binaries or growing logs
/var/log & /var/libGrowing logs & persistent app/DB stateNot /tmp (auto-purged!)
/proc & /sysVirtual kernel & hardware views (0 disk bytes)Not normal files on block storage
/bin → /usr/binStandard user executables (merged symlink)/sbin holds admin/boot tools
/tmp vs /var/tmpShort scratch (often tmpfs) vs reboot-safe scratchNeither is durable storage
/opt vs /srvSelf-contained 3rd-party bundles vs served site dataPackage-managed files live in /usr
