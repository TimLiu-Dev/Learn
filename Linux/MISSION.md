# Mission: Senior Linux Engineer (2027)

## Why
Transition from a Junior Android Developer in 2026 to a job-ready **Senior Linux Engineer** in 2027 capable of designing, hardening, automating, and debugging production Linux infrastructure—and proving it with a resume-grade, end-to-end platform project.

## Success looks like
- Navigate, inspect, and troubleshoot any unfamiliar Linux server over SSH using only the CLI (`ip`, `ss`, `journalctl`, `systemctl`, `lsblk`, `lsof`, `strace`, `tcpdump`).
- Build and operate hardened `systemd` services, `nftables` firewalls, LVM storage with verified backup/restore drills, and SELinux/AppArmor security policies.
- Diagnose kernel, virtual memory (OOM), filesystem, and network bottlenecks using `procfs`/`sysfs`, `perf`, and eBPF (`bpftrace`).
- Complete and publish the **AegisOps** end-to-end capstone (automated multi-node Linux infrastructure with Ansible, observability, chaos drills, and incident runbooks) ready for technical interviews.

## Constraints
- Starting background: Junior Android Developer (familiar with `adb shell`, `logcat`, basic Git/Gradle, and Android's Linux-based runtime, but new to server-side GNU/Linux operations).
- Target timeline: Structured mastery from November 2026 through mid-2027 (~28–30 weeks).
- Learning format: Self-contained interactive HTML lessons with runnable in-browser labs, automated checks/hints/answers, diagnostic quizzes, and printable reference sheets.

## Out of scope
- Desktop Linux customization ("ricing" window managers, gaming on Linux, audio/GUI tweaks).
- Managed Kubernetes-only abstractions before mastering the underlying Linux kernel primitives (`namespaces`, `cgroups v2`, `overlayfs`).
- Legacy SysVinit scripting or memorizing deprecated tools (`ifconfig`, `netstat`) except to recognize old output.
