# Teaching Notes & User Preferences

- **User background:** Junior Android Developer transitioning to Senior Linux Engineer in 2027.
- **Pedagogical style requested:**
  - Interactive HTML lessons that work offline (`file://`) with zero external runtime dependencies.
  - Runnable code examples directly in the HTML.
  - Runnable code practice labs with automated checks, progressive hints, and revealable/runnable final answers.
  - Diagnostic multiple-choice quizzes where **every choice** explains why it is correct or why it is wrong — and options must stay balanced in word count/character length so length never leaks the answer.
  - End-to-end, resume-grade Capstone project (`AegisOps`) suitable for job applications and Senior Linux interviews.
- **Curriculum pacing & cognitive load:**
  - Keep each lesson tightly scoped (20–30 min, 1–2 core skills) so working memory is respected.
  - Include spaced retrieval warmups from prior lessons starting in Lesson 02+.
  - Pair lessons with printable `./reference/*.html` cheat sheets and maintain `./reference/glossary.html` consistently across all lessons.
  - Every lesson includes external authoritative citations, a primary recommended reading/source, and a prompt to ask follow-up questions.
