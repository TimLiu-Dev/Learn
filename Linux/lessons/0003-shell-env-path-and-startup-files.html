2. Local Shell Variables vs Exported Environment

Process Inheritance

Assigning FOO=bar creates a variable local to the current shell only. Running export FOO=bar promotes it into the process environment block inherited by every child process forked from that shell.

example-01: Inspecting Env, Exporting Variables & PATH 
env                          # Print all exported environment variables
export APP_ENV=production    # Export variable to child processes
echo $APP_ENV
echo $PATH                   # Colon-separated executable search dirs

3. .profile vs .bashrc, source & Aliases

Shell Initialization

Interactive login shells (SSH) read /etc/profile then ~/.profile (which on Ubuntu sources ~/.bashrc). Interactive non-login shells read ~/.bashrc. Non-interactive scripts read neither—which is why cron scripts fail if they assume ~/.bashrc ran! Use source ~/.bashrc to reload edits in the current shell without spawning a subshell.

example-02: Viewing & Reloading .bashrc + Aliases 
cat ~/.bashrc
alias                 # List active shell aliases
alias gs='uname -r'
source ~/.bashrc      # Reload config into current shell
Security Rule: Never Put . (Current Dir) in $PATH
Putting . at the front of $PATH allows an attacker who drops a malicious ls binary inside /tmp to hijack your shell the moment you run ls there. Always invoke local binaries explicitly with ./mytool.

Real Outage Pattern: Shadowed Binary in /usr/local/bin Broke TLS Cert Renewals

A host had an outdated manual build of certbot in /usr/local/bin/certbot ahead of /usr/bin/certbot in $PATH. Interactive debugging ran fine when someone typed /usr/bin/certbot, while the automated job ran certbot and failed silently. Checking which -a certbot or type -a certbot catches $PATH shadowing immediately.

Interview Q1

What is the difference between a login shell, an interactive non-login shell, and a non-interactive shell?

Model Answer: Login shells (initial SSH) read /etc/profile and ~/.profile; interactive non-login shells (opening a sub-shell or tmux pane) read ~/.bashrc; non-interactive shells (scripts, cron) read neither unless $BASH_ENV is set.

Interview Q2

How do you diagnose which exact executable runs when you type `python3`?

Model Answer: Run type -a python3 or which -a python3 to view aliases, functions, and every matching executable in $PATH order.
