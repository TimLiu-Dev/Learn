1. Android Developer → Linux Mental Bridge

Transferring Prior Knowledge

Android apps rely on per-UID permissions inside /data/data plus SELinux. On Linux servers, standard DAC (Discretionary Access Control) mode bits govern 95% of daily file access errors.

2. Reading rwx on Files vs Directories & umask

DAC Permissions

Permissions apply in 3 triads: user (owner), group, and other (r=4, w=2, x=1). Deleting a file inside a directory requires write + execute permission on the parent directory, not write permission on the file itself! umask (default 0022) subtracts bits from newly created files (666 - 022 = 644) and dirs (777 - 022 = 755).

example-01: Fixing Executable Scripts, Locking Keys & Checking umask 
ls -l ~/perm_lab
chmod 750 ~/perm_lab/deploy.sh    # rwxr-x---
chmod 600 ~/perm_lab/secret.key   # rw------- (SSH requires this!)
umask
ls -l ~/perm_lab

3. Hard Links vs Symlinks, setuid/Sticky & ACLs

Inodes & Fine-Grained Access

A hard link (ln src dst) binds a second directory name to the exact same inode—deleting src leaves data alive via dst (cannot span filesystems or link directories). A symlink (ln -s target link) stores a path string and breaks if the target moves. Need one extra user to read a file without changing primary group? Use setfacl -m u:aegis:r file.

example-02: Symlinks, Hard Links & ACLs 
ln -s v1.txt ~/perm_lab/current      # Relative symlink (zero-downtime deploy pattern)
ln ~/perm_lab/v1.txt ~/perm_lab/v1_hard
setfacl -m u:aegis:r ~/perm_lab/v1.txt
getfacl ~/perm_lab/v1.txt

Real Outage Pattern: chmod -R 777 Broke SSH and Sudo Across a Staging Server

After hitting a permission error on an upload folder, someone ran chmod -R 777 / instead of ./uploads. Immediately sshd refused all key logins (strict mode forbids group/world-writable ~/.ssh) and sudo broke because its setuid root bit (4755) was wiped to 0777.

Interview Q1

What does the execute bit (`x`) do on a directory vs a regular file?

Model Answer: On a file, x lets the kernel execute it via execve(). On a directory, x grants search/traversal access (cd into it or stat files inside); r alone only lists filenames.

Interview Q2

Why can't hard links cross filesystems or target directories?

Model Answer: Inode numbers are unique only within a single filesystem; directory hard links are banned to keep the directory tree acyclic (preventing infinite loops in tools like find).
