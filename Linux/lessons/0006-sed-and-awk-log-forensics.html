2. Surgical Edits & Line Extraction with sed

Stream Editor

sed reads line-by-line: s/old/new/g substitutes all occurrences on every line (omit g to change only the first per line). Use sed -n '2,4p' to print only lines 2–4, /pattern/d to delete matching lines, and sed -i only after testing without -i first!

example-01: Previewing sed Substitutions & Printing Line Ranges 
sed 's/staging/production/g' ~/service.ini   # Preview edit on stdout
sed -n '2,4p' /var/log/api_latencies.log    # Print lines 2..4 only

3. Column Extraction, Thresholds & Counters in awk

Pattern-Action Language

Unlike cut, awk treats runs of spaces/tabs as a single field separator by default ($1, $2, ..., $NF for last field, $0 for full line). Wrap rules in pattern { action } and summarize totals in END { ... }.

example-02: Filtering Slow Requests & Summing Latencies with awk 
awk '$4 > 100 {print $1, $2, $4}' /var/log/api_latencies.log
awk '{sum += $4} END {print "total_ms:", sum}' /var/log/api_latencies.log
awk -F: '{print $1}' /etc/passwd    # Custom delimiter :

Real Outage Pattern: Forgetting Quotes Around $1 in Double-Quoted awk

An engineer wrote ssh prod "awk '{print $2}' /var/log/app.log" using double quotes on the outer command. The local shell expanded $2 to empty before SSH even ran, turning the remote command into awk '{print }'—dumping the entire 12 GB log over the wire! Single-quote awk programs or escape \$2.

Interview Q1

Why does `sed -n '50,60p;61q' huge.log` run dramatically faster than `sed -n '50,60p' huge.log` on a 50 GB file?

Model Answer: Adding 61q tells sed to quit immediately at line 61 instead of reading the remaining 49.9 GB to EOF.

Interview Q2

How would you sum column 4 per unique status code in column 3 using a single `awk` one-liner?

Model Answer: awk '{tot[$3] += $4} END {for (k in tot) print k, tot[k]}' file.log.
