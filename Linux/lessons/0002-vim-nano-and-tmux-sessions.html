1. Android Developer → Linux Mental Bridge

Transferring Prior Knowledge

In Android Studio you rely on GUI tabs and auto-save. On a remote Linux VM over SSH, there is no GUI—and if your laptop sleeps mid-upgrade, the SSH PTY dies and sends SIGHUP to running jobs unless multiplexed.

2. Vim Modal Editing vs Nano Quick Edits

Zero-GUI Editing

vim separates Normal mode (navigation & commands, press Esc), Insert mode (typing text, press i), and Command-line mode (save/quit/replace via :). Use nano for quick 2-line edits when present, and vim everywhere else (especially visudo or minimal containers).

example-01: Non-Interactive File Inspection & Safe In-Place Config Prep 
cat ~/nginx.conf
# Equivalent of Vim :%s/staging.local/prod.aegis.internal/g
sed -i 's/staging.local/prod.aegis.internal/g' ~/nginx.conf
cat ~/nginx.conf
Vim Muscle Memory Checklist
Always remember: Esc returns to Normal mode; :wq saves and exits; :q! quits discarding changes; dd deletes a line; u undoes; /text searches forward.

3. Surviving Dropped SSH Connections with tmux

Session Multiplexing

tmux runs a persistent server process holding virtual terminals. Attach from one laptop, detach with Ctrl+b then d, close your SSH connection, and reattach later with tmux attach -t <name>.

example-02: Managing Persistent tmux Sessions 
tmux ls                  # List active background sessions
tmux new -s deploy-api   # Create named session
tmux ls                  # Verify session persists

Real Outage Pattern: Half-Finished Package Upgrade Killed by Laptop Sleep

An engineer ran apt upgrade over raw hotel Wi-Fi without tmux. Midway through unpacking libc6, Wi-Fi dropped, SSH killed the shell with SIGHUP, and dpkg locked in an interrupted state. Running remote upgrades inside tmux completely prevents orphaned half-upgrades.

Interview Q1

What happens to a foreground process when your SSH connection drops abruptly, and how does tmux prevent it?

Model Answer: The SSH daemon closes the pseudo-terminal (PTY), sending SIGHUP to the foreground process group. tmux owns its own detached PTYs under a persistent daemonized server, so the process never receives SIGHUP when your SSH client disconnects.

Interview Q2

Why do Linux admins still standardize on Vim motions even when Nano exists?

Model Answer: Tools like visudo, kubectl edit, git, and minimal Alpine/rescue containers routinely invoke vi by default, and Vim's modal motions + regex substitution scale effortlessly to huge config files.
