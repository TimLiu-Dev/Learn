Linux Architecture, Kernel vs Shell, FHS & Precision Navigation

Every Senior Linux Engineer builds on an accurate mental model of what happens between pressing Enter and bytes moving on disk. This benchmark lesson connects your Android background to GNU/Linux internals, teaches how to interrogate any unfamiliar server safely, and drills filesystem precision through 5 runnable labs and 6 diagnostic quizzes.

1. Android Developer → Linux Engineer Mental Bridge

Transferring Prior Knowledge

Android is built directly on top of the Linux kernel. When you used adb shell to inspect a crash or read /proc, you were already interacting with Linux kernel interfaces. What changes on cloud and production servers is user space: instead of Bionic libc, Zygote, and Binder, you work with GNU/glibc (or musl), systemd, and POSIX/GNU shells.

Android Ecosystem GNU/Linux Server Equivalent Why Senior Linux Engineers Care
Android Linux Kernel (GKI) Upstream / Distro Linux Kernel (6.8.0) Same syscalls (open, read, fork, execve) and same /proc & /sys interfaces.
adb shell (Toybox / mksh) SSH → PTY → /bin/bash (GNU Coreutils) Server Bash supports brace expansion, job control, and full GNU flags (--help, -h).
init + Zygote systemd (PID 1) PID 1 boots user space, starts daemons, manages cgroups v2, and reaps orphaned processes.
/system, /vendor, /data FHS 3.0: /usr, /etc, /var, /opt Knowing where configs, logs, and persistent state live lets you triage any distribution immediately.
logcat /var/log/* & journalctl Kernel OOM kills, SSH logins, and daemon failures are recorded in syslog and journald.

2. Hardware → Kernel → Terminal → Shell

Architecture Layering

Beginners often confuse the terminal, the shell, and Linux. Keep the boundary exact (see Glossary):

  • Linux Kernel: The privileged Ring-0 OS core managing CPU scheduling, virtual memory, device drivers, filesystems, and network sockets. User programs request services via system calls (syscalls(2)).
  • Terminal Emulator (TTY/PTY): The I/O layer (or SSH pseudo-terminal /dev/pts/0) that renders characters and forwards keystrokes.
  • Shell (Bash / Zsh): A regular user-space program (/bin/bash) running inside the terminal. It parses your input, expands globs and variables, forks child processes, and wires pipes.
example-01: Inspecting Kernel vs Current Shell Process 
uname -a              # Kernel name, hostname, release, architecture
cat /proc/version     # Live kernel version + compiler info from /proc
echo $SHELL           # User's configured default login shell
ps -p $$              # Inspect the running shell process itself ($$ = current PID)
Note on $$ vs $SHELL
Per the GNU Bash Manual, $SHELL holds your configured default login shell from /etc/passwd, not necessarily the shell currently executing. If you start zsh inside bash, $SHELL can remain /bin/bash while ps -p $$ shows zsh.

3. Getting Unstuck Like a Senior Engineer (man, --help, type)

Self-Sufficiency

On air-gapped production hosts you will not have a browser. Linux ships built-in documentation and introspection tools. Check man(1), --help, and type before guessing flags.

example-02: Builtins vs Aliases vs Binaries & Manual Discovery 
type cd ls ll         # Shows builtin vs external binary vs alias
which ls              # Finds executable path in $PATH (misses builtins)
whatis grep find      # One-line summary from man page index
apropos directory     # Search man page descriptions by keyword
Why MUST cd be a shell builtin?
In POSIX/Linux, a child process inherits a copy of its parent's working directory and cannot mutate its parent's working directory. If cd were an external binary /usr/bin/cd, the child would call chdir(2) on itself, exit, and leave your shell in the old directory. Therefore cd executes inside the shell process itself.

Interactive Directory Map

Unlike drive letters, Linux mounts every storage device and kernel view under one inverted tree rooted at /. Click any directory below to inspect its role, production pitfalls, and Android counterpart:

ls -la /                 # Notice bin -> usr/bin (the modern /usr merge!)
cat /etc/os-release      # Standard distro identification file
head -n 4 /proc/meminfo  # Kernel-synthesized RAM stats (0 bytes on disk)

5. Precision Navigation, File Lifecycle & Globbing

Core Mechanics

Absolute vs Relative Paths

  • Absolute path: Starts with / (e.g., /var/log/syslog). Independent of working directory.
  • Relative path: Resolved against $PWD (e.g., ../shared/config).
  • . = current dir, .. = parent dir, ~ = $HOME, cd - = toggle $OLDPWD.

Shell Globbing Rules (Critical!)

  • * matches 0+ characters, except a leading dot (.env is skipped by rm *).
  • ? matches any single character (e.g., log-?.txt).
  • [0-9] matches one character in the set/range.
  • {a,b} brace expansion generates strings before globbing (mkdir -p app/{src,logs}).
example-04: Listing Hidden Files, Sorting by Size & Viewing Directory Trees 
pwd                   # Print exact current directory
ls -la ~/staging      # Reveal dotfiles (.env.bak, .keep)
ls -lhS ~/staging     # Long format, human sizes, sorted largest first
tree ~                # Visual tree of home directory
Production Hazard: Unquoted Variables with rm -rf
Never run rm -rf $BUILD_DIR/* in a script without guarding it! If $BUILD_DIR is unset/empty, Bash expands it to rm -rf /*. Always guard with rm -rf "${BUILD_DIR:?}/"*, covered in depth in Lesson 18.

Real Outage Pattern: /tmp vs /var/tmp Silent Data Loss

A team migrating an Android artifact caching service to Ubuntu wrote downloaded SDK archives into /tmp/sdk-cache. Everything passed in staging. Two weeks later, nightly builds failed with FileNotFoundError: systemd-tmpfiles-clean.timer automatically purges /tmp files untouched for 10 days (and /tmp is often a RAM-backed tmpfs wiped on reboot). Persistent application state belongs in /var/lib/<app>, caches in /var/cache/<app>, and longer-lived temp files in /var/tmp.

Interview Q1

“Why does which cd return nothing or fail, yet cd /tmp works?”

Model Answer: which searches directories in $PATH for external executables. cd is a shell builtin (verified with type cd) because changing directories calls chdir(2), which only affects the calling process. An external child process cannot alter its parent shell's working directory.

Interview Q2

“You SSH into an unfamiliar production box. What 4 read-only commands do you run first?”

Model Answer: uname -a (kernel & arch), cat /etc/os-release (distro & version), id (current user & privilege groups), and cat /proc/uptime or ls -la /var/log (uptime & log layout) before mutating anything.
