1. Android Developer → Linux Mental Bridge

Transferring Prior Knowledge

On Android, vendor HALs and prebuilt kernel modules (.ko) wire hardware like cameras and modems. On Linux servers, you inspect PCI/virtio hardware directly, manage loadable .ko kernel modules with modprobe, and catch driver/disk/OOM errors in dmesg.

2. Reading Hardware Errors in dmesg -T & lspci

Hardware Triage

Whenever storage hangs, a NIC flaps, or a container runtime hits limits, check dmesg -T (-T converts raw boot-seconds into wall-clock timestamps). Use lspci to verify whether the kernel even sees a PCI/NVMe/virtio device and which driver bound to it.

example-01: Inspecting PCI Devices, Kernel Ring Buffer & udev Metadata 
lspci                             # List PCI devices (NICs, NVMe, GPU)
dmesg -T                          # Kernel ring buffer with readable timestamps
udevadm info /sys/class/net/eth0  # Device driver & udev attributes

3. Loading & Blacklisting Kernel Modules with modprobe

Dynamic Kernel Drivers

Linux kernels stay modular: filesystems (xfs, overlay), firewalls (nf_tables), and VPNs (wireguard) load dynamically as .ko modules. Inspect loaded modules via lsmod, load with sudo modprobe <mod>, unload with sudo modprobe -r <mod>, and persist boot loads under /etc/modules-load.d/.

example-02: Listing & Loading Kernel Modules 
lsmod                  # List loaded kernel modules
sudo modprobe dummy    # Load module (+ dependencies)
lsmod | grep dummy

Real Outage Pattern: Kubernetes Nodes Failed Because br_netfilter Wasn't Persisted

Someone ran sudo modprobe br_netfilter during cluster bring-up and everything passed. Three months later after a security kernel reboot, pods lost cross-node networking because the module wasn't listed in /etc/modules-load.d/k8s.conf. Always persist runtime kernel changes on disk!

Interview Q1

How do you prevent a buggy kernel module (e.g. `nouveau` or legacy `usb-storage`) from loading at boot?

Model Answer: Add blacklist <module> (and install <module> /bin/false to block dependency pulls) in /etc/modprobe.d/blacklist.conf, then rebuild initramfs.

Interview Q2

How do you check which kernel driver is currently bound to a network card?

Model Answer: Run lspci -k (shows Kernel driver in use:) or ethtool -i eth0.
