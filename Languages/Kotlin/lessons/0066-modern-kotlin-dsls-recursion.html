Warm-up: Rapid Recall

  1. Inside a function marked inline, why is a bare return inside a lambda allowed—and how do you return only from the lambda?
    CheckInlined lambda bytecode is pasted directly into the caller, enabling a non-local return from the enclosing function. Use a qualified label like return@forEach for a local lambda exit.
  2. Why does matching a sealed interface with when (state) eliminate defensive else branches?
    CheckThe compiler knows every permitted subtype within the module at compile time, guaranteeing exhaustiveness—so adding a new state produces a compile error wherever it isn't handled.

The Concept: Modern Kotlin Syntax & DSL Safety

1. when Guard Conditions & Non-Local break/continue (Kotlin 2.2+)

Both when guards and non-local break/continue graduated to stable in Kotlin 2.2.0 and compile with zero flags here.Instead of nesting an extra if inside a when branch (forcing an ugly fallback branch), attach an inline boolean if guard right on the branch pattern:

sealed interface SyncResult { data class Failed(val code: Int, val retryable: Boolean) : SyncResult data class Success(val count: Int) : SyncResult } fun formatSync(result: SyncResult): String = when (result) { is SyncResult.Failed if result.retryable -> "Retry scheduled (HTTP ${result.code})" is SyncResult.Failed -> "Fatal failure (HTTP ${result.code})" is SyncResult.Success if result.count == 0 -> "Up to date" is SyncResult.Success -> "Synced ${result.count} items" } fun firstValidBatch(batches: List<List<Int>>): Int? { for (batch in batches) { batch.run { if (isEmpty()) continue // Non-local continue inside inline lambda! if (first() == -1) break // Non-local break exits the for-loop! return sum() } } return null } fun main() { println(formatSync(SyncResult.Failed(503, retryable = true))) println(formatSync(SyncResult.Success(0))) println("First valid sum: ${firstValidBatch(listOf(emptyList(), listOf(10, 20), listOf(-1)))}") }

2. Context Parameters & Explicit Backing Fields (Kotlin 2.2–2.4)

Two major ergonomics upgrades reshape modern Android/KMP reading and authoring in Kotlin 2.4. Note that Kotlin 2.2 replaced experimental context receivers (`context(Logger)`) with named Context Parameters (`context(logger: Logger)`), which stabilized in Kotlin 2.4 alongside Explicit Backing Fields (`field = ...`):

Traditional Pattern (Works Everywhere)

// 1. Manual scope/parameter passing for logging fun saveUser(id: String, logger: Logger) { logger.log("Saving $id") } // 2. Two-property ViewModel encapsulation private val _state = MutableStateFlow(UiState()) val state: StateFlow<UiState> = _state.asStateFlow()

Kotlin 2.4 Syntax (No Boilerplate)

// 1. Context parameter (named, or access via contextOf<Logger>()) context(logger: Logger) fun saveUser(id: String) { logger.log("Saving $id") } // 2. Explicit backing field on one property! val state: StateFlow<UiState> field = MutableStateFlow(UiState())

3. @DslMarker, fun interface SAM & Stack-Safe Recursion

  • @DslMarker: Apply a meta-annotated marker annotation to DSL builder classes so inner lambdas cannot accidentally invoke outer receiver methods implicitly (essential when reading Compose/HTML/Gradle builders).
  • fun interface (SAM) & crossinline/noinline: Declare a single-abstract-method interface so callers pass a clean lambda while keeping a named contract; use crossinline if an inlined lambda runs inside another object/coroutine and must forbid non-local return, or noinline if you need to store the function reference.
  • tailrec vs DeepRecursiveFunction: Prefix a self-recursive function whose very last step is calling itself with tailrec so the compiler compiles it into an allocation-free loop; use stdlib DeepRecursiveFunction<T, R> when tree/graph recursion isn't in tail position and would otherwise overflow the JVM stack.
tailrec fun gcd(a: Int, b: Int): Int = if (b == 0) a else gcd(b, a % b) // Heap-backed non-tail recursion (handles depth 50,000+ without StackOverflowError) val deepDepth = DeepRecursiveFunction<Int, Int> { n -> if (n == 0) 0 else 1 + callRecursive(n - 1) } fun main() { check(gcd(48, 18) == 6) check(deepDepth(40_000) == 40_000) println("GCD(48, 18)=${gcd(48, 18)}, DeepDepth=${deepDepth(40_000)}") }

Quick Check

1. When using a Kotlin 2.2+ when guard condition like is UiState.Error if state.retryable -> ... on a sealed hierarchy, what must still be true for compilation?

Since the compiler cannot statically prove a boolean guard expression is always true, you must still handle the case where the pattern matches but the guard evaluates to false.

2. How do modern Kotlin Context Parameters (context(logger: Logger)) differ from deprecated context receivers?

Giving context dependencies explicit names prevents accidental receiver shadowing across nested lambdas while keeping call sites clean.

3. Which recursive function actually benefits from the tailrec modifier cleanly in Kotlin bytecode?

tailrec only eliminates stack frames when the recursive call is the literal last operation executed before returning—no pending multiplications, additions, or try/catch wrappers afterward.

Type-Safe Route Guard DSL & Backoff Spec

Build a small routing policy DSL using modern Kotlin constructs (compiles cleanly out-of-the-box):

  1. @DslMarker annotation class RouteDsl
  2. fun interface RoleGuard { fun canAccess(role: String): Boolean }
  3. sealed interface Screen with data object Feed : Screen, data class Profile(val verified: Boolean) : Screen, and data class Checkout(val cents: Int, val hasCard: Boolean) : Screen.
  4. @RouteDsl class PolicyBuilder with fun checkRole(guard: RoleGuard) (storing/updating the guard, defaulting to always true) and fun build(): (String, Screen) -> String. Inside evaluate, return "Denied" if the guard rejects role, then classify screen with when (screen) using guard conditions:
    • is Screen.Checkout if !screen.hasCard -> "Add Card"
    • is Screen.Checkout -> "Pay ${screen.cents}c"
    • is Screen.Profile if !screen.verified -> "Verify Email"
    • is Screen.Profile -> "Open Profile"
    • Screen.Feed -> "Open Feed"
  5. Top-level fun routePolicy(setup: PolicyBuilder.() -> Unit): (String, Screen) -> String and tailrec fun backoffMs(attempt: Int, accMs: Long = 100L): Long (doubling accMs each step down to attempt <= 0).
// Write RouteDsl, RoleGuard, Screen, PolicyBuilder, routePolicy, and backoffMs above main: fun main() { val evaluate = routePolicy { checkRole { role -> role != "guest" } } check(evaluate("guest", Screen.Feed) == "Denied") check(evaluate("member", Screen.Checkout(2500, hasCard = false)) == "Add Card") check(evaluate("member", Screen.Checkout(2500, hasCard = true)) == "Pay 2500c") check(evaluate("member", Screen.Profile(verified = false)) == "Verify Email") check(backoffMs(3) == 800L) println("All Modern Kotlin DSL & guard checks passed!") }
Hint 1: DSL builder and SAM guardStore private var guard: RoleGuard = RoleGuard { true } inside @RouteDsl class PolicyBuilder and expose fun checkRole(guard: RoleGuard) { this.guard = guard }.
Hint 2: Guarded when & tailrecHandle guarded branches before their unguarded fallback (e.g. is Screen.Checkout if !screen.hasCard -> ... before is Screen.Checkout -> ...). In backoffMs, return accMs when attempt <= 0 else recurse with backoffMs(attempt - 1, accMs * 2).
Exercise 2 · Refactor

Flatten Nested if Chains & Naive Stack Recursion

Refactor this verbose code into idiomatic Kotlin using fun interface SAM, Kotlin 2.2+ when guard conditions, and tailrec recursion.

sealed interface JobState { data class Running(val progress: Int) : JobState data class Error(val reason: String, val fatal: Boolean) : JobState data object Idle : JobState } // REFACTOR: Replace anonymous interface clutter, nested ifs, and non-tailrec recursion interface RetryRule { fun shouldRetry(reason: String): Boolean } fun describeJob(state: JobState, rule: RetryRule): String { if (state is JobState.Idle) { return "Waiting" } else if (state is JobState.Running) { if (state.progress >= 90) { return "Finishing" } else { return "Working (${state.progress}%)" } } else if (state is JobState.Error) { if (!state.fatal && rule.shouldRetry(state.reason)) { return "Retrying: ${state.reason}" } else { return "Aborted: ${state.reason}" } } return "Unknown" } fun sumUpTo(n: Int): Long { if (n <= 0) return 0L return n + sumUpTo(n - 1) // Overflows stack on large n! } fun main() { val rule = object : RetryRule { override fun shouldRetry(reason: String) = "timeout" in reason } check(describeJob(JobState.Idle, rule) == "Waiting") check(describeJob(JobState.Running(95), rule) == "Finishing") check(describeJob(JobState.Running(40), rule) == "Working (40%)") check(describeJob(JobState.Error("network timeout", fatal = false), rule) == "Retrying: network timeout") check(describeJob(JobState.Error("network timeout", fatal = true), rule) == "Aborted: network timeout") check(sumUpTo(100_000) == 5_000_050_000L) println("Refactored DSL, when guards, and tailrec verified!") }
Hint 1: fun interface + guarded whenMark fun interface RetryRule and use val rule = RetryRule { "timeout" in it } in main. Make describeJob a single-expression when (state) using is JobState.Running if state.progress >= 90 -> ... and is JobState.Error if !state.fatal && rule.shouldRetry(state.reason) -> ....
Hint 2: Tail-recursive accumulatorAdd a default accumulator parameter: tailrec fun sumUpTo(n: Int, acc: Long = 0L): Long = if (n <= 0) acc else sumUpTo(n - 1, acc + n).
