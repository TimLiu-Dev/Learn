The Concept: Suspending vs Blocking

A coroutine is an instance of a computation that can be suspended and resumed without blocking the underlying OS thread. While suspended, the thread is free to execute other coroutines!

1. suspend fun

Functions marked with suspend can only be called from inside a coroutine or from another suspending function:

suspend fun fetchUserData(userId: String): User { delay(500) // Non-blocking delay! Thread is released during these 500ms return User(userId, "Alice") }

2. launch vs async

  • launch: "Fire and forget". Starts a new coroutine concurrently without blocking the current thread. Returns a Job (used to cancel or wait for completion with job.join()).
  • async: Computes a result concurrently. Returns a Deferred<T> (a lightweight, non-blocking Future). Call .await() to retrieve the result.
coroutineScope { // Concurrent execution: both start immediately! val deferredOrders = async { fetchOrders() } val deferredProfile = async { fetchProfile() } // Await both results concurrently: val orders = deferredOrders.await() val profile = deferredProfile.await() }

3. runBlocking

Bridges the non-coroutine world with coroutines by blocking the current thread until all children complete. Only use in main() and unit tests! Never inside production Android or backend services.

Quick Check

What happens to the current thread when a coroutine calls delay(2000)?

delay is a suspending function. It unbinds from the thread, scheduling a wakeup after 2 seconds, while the thread continues handling other tasks.

Exercise 1 · Write from blank

Parallel User Profile Aggregator

Implement loadUserProfile(userId: String): UserSummary:

  1. Simulate suspending network calls: fetchDetails(userId) returning "Details for $userId" after 50ms, and fetchPreferences(userId) returning "Theme=Dark" after 50ms.
  2. Use coroutineScope with async to run both calls in parallel.
  3. Await both and return data class UserSummary(val details: String, val preferences: String).
import kotlinx.coroutines.* data class UserSummary(val details: String, val preferences: String) suspend fun fetchDetails(userId: String): String { delay(50) return "Details for $userId" } suspend fun fetchPreferences(userId: String): String { delay(50) return "Theme=Dark" } suspend fun loadUserProfile(userId: String): UserSummary = coroutineScope { // Run fetchDetails and fetchPreferences concurrently using async UserSummary("", "") } fun main() = runBlocking { val summary = loadUserProfile("user_42") println(summary) }
Hint 1: Structured concurrencyWrap asynchronous child tasks in coroutineScope { ... } so any failure automatically cancels siblings.
Hint 2: Concurrent async/awaitLaunch both calls concurrently: val p = async { fetchProfile(id) }; val m = async { fetchMetrics(id) }, then return UserSummary(p.await(), m.await()).
