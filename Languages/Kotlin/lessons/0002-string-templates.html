String templates and raw strings

Put values where they appear in the text, and write multi-line text exactly as it looks.

The problem templates solve

Look at the last line of the refactor exercise from lesson 1.1:

println(userName + ": " + label + ", " + zones.size + " zones, " + totalMinutes + " min")

To see what this prints, you have to mentally glue eight pieces together and check every space. It's easy to drop one, and the actual sentence is buried under quotes and pluses.

Docs: Strings → String templates: “string templates are usually easier to read and more idiomatic.”A string template flips this round. You write the sentence, and mark where the values go with $:

fun main() { //sampleStart val userName = "Sam" val totalMinutes = 35 println("$userName trained for $totalMinutes min") //sampleEnd }

$name vs ${expression}

There are two forms, and the rule for choosing is simple:

  • $name works for a plain variable name, and nothing else.
  • ${…} is for anything more: a property, a function call, arithmetic, or a variable that sits right next to other letters.

This is the classic trap. $ grabs only the name, so the .length after it is treated as ordinary text:

fun main() { //sampleStart val zone = "Cardio" println("$zone.length") // ❌ prints: Cardio.length println("${zone.length}") // ✅ prints: 6 println("${zone}Plus") // braces needed: zonePlus isn't a variable println("Calories: ${35 * 10}") //sampleEnd }

From Coding conventions → String templates.The conventions also say to skip the braces when you don't need them: write "$name", not "${name}". And there's no need for .toString() inside a template, because templates already turn the value into text.

A literal dollar sign

A $ that isn't followed by a name, like the one in "$5", prints as itself. When it is followed by a name, escape it with \$ to print a real dollar sign:

fun main() { //sampleStart val price = 9.99 println("Premium: \$$price/month") // Premium: $9.99/month //sampleEnd }

Escape sequences are listed in Characters → Escape sequences.

Raw strings: text exactly as it looks

Multi-line text built from "\n" and + is hard to read and harder to edit. A raw string in triple quotes keeps line breaks as written. It also treats backslashes as plain text, so \n inside one stays as two characters. Templates still work inside raw strings.

The catch is that your code's indentation ends up in the string too. trimIndent() removes the indentation all the lines share. It also drops a blank first or last line, so you can put the triple quotes on their own lines:

fun main() { //sampleStart val athlete = "Priya" val minutes = 42 val summary = """ Workout summary Athlete: $athlete Minutes: $minutes """.trimIndent() println(summary) //sampleEnd }

Docs: Strings → Multiline strings. The conventions say to use trimIndent when no inner indentation is needed and trimMargin when it is (Coding conventions → Strings).When some lines need extra indentation that has to survive, use trimMargin(). Start each line with |, and everything up to and including the | is removed:

fun main() { //sampleStart val plan = """ |Monday | Run 5 km | Stretch """.trimMargin() println(plan) //sampleEnd }

Raw strings don't process \$. If you need a literal $ right before a name inside one, write ${'$'}. Newer Kotlin versions also support multi-dollar interpolation ($$"""…""") for text with lots of dollar signs, like JSON schemas. You'll rarely need it.

AI/Java-flavoured smells to spot
  • Chains of + to glue text and values together
  • Braces around a simple name, "${count}", or .toString() inside a template
  • "line1\n" + "line2\n" instead of a raw string
  • String.format("%s ran %d min", name, mins) where a template says it more plainly

Quick check

1. val name = "Row". What does println("$name.length") print?

$ takes only the name name. The .length after it is plain text. For the length you need "${name.length}".

2. val sets = 4. Which is the most idiomatic way to build "Sets: 4"?

They all produce the same text. But a simple name needs neither braces nor toString(), and a template reads better than +.

3. What does println("""Pace:\n5:30""") print?

Raw strings don't process escapes, so \n is just a backslash and an n. To get a line break, put a real one inside the triple quotes.

4. Your raw string has no | markers. Which call strips the indentation all its lines share?

trimIndent() removes the shared leading indentation. trimMargin() needs a margin prefix (| by default). trim() and trimStart() only touch the start and end of the whole string.
