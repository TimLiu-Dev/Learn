References, inline, and lambda returns

Member references (::), zero-allocation inlining, and non-local vs qualified returns.

Warm-up

  1. In Kotlin, what is the trailing lambda convention?
    CheckIf the last parameter of a function is a lambda, it can be written outside the parentheses.
  2. When can you use the implicit it identifier inside a lambda?
    CheckWhen the lambda has exactly one parameter and you don't explicitly name it.

Member & Constructor References (::)

Docs: Function references. Direct reference to a named function or property.When a lambda simply forwards its argument to a property or method, replace the lambda with a member reference using :::

Verbose Lambda

athletes.map { it.name } names.map { it.uppercase() } ids.map { UserId(it) }

Idiomatic Reference (::)

athletes.map(Athlete::name) names.map(String::uppercase) ids.map(::UserId)

The hidden cost of lambdas and inline

Docs: Inline functions. Eliminates function object allocation.In JVM bytecode, every non-inlined lambda compiles to an anonymous object (an instance of Function1<T, R>). In tight loops, game loops, or LeetCode algorithms, creating thousands of function objects causes severe garbage collection pauses.

By marking a higher-order function with inline, the compiler copies both the function bytecode and the lambda bytecode directly into the call site:

inline fun measureTime(block: () -> Unit) { val start = System.currentTimeMillis() block() println("Elapsed: ${System.currentTimeMillis() - start}ms") } // At call site: measureTime { doHeavyWork() } // Bytecode generates NO function object; code is pasted directly inline!

Returns in lambdas: Non-local vs Qualified

Because inlined functions are pasted directly into the call site, a bare return exits the enclosing function (non-local return):

fun findFirstPositive(numbers: List<Int>) { numbers.forEach { if (it > 0) return // Returns from findFirstPositive! Not just the loop! } }

To return early from just the lambda (like continue in a regular loop), use a qualified return with an @label:

fun printPositives(numbers: List<Int>) { numbers.forEach { if (it <= 0) return@forEach // Skips to next iteration (like continue) println(it) } }

Quick check

When should you mark a function as inline in Kotlin?

inline should only be used on functions that take lambda parameters. Inlining large normal functions increases bytecode size without performance benefit.

Replace Lambdas with Member References
