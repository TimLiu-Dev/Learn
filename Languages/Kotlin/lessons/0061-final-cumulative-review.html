Warm-up: Rapid Recall

  1. When does a @JvmInline value class still allocate a wrapper object on the JVM heap?
    CheckWhen used as a nullable type (wrapping a primitive), as a generic type argument (List<UserId>, Result<UserId>), or upcast to an interface / Any.
  2. Why must suspending code never blindly swallow runCatching { ... } failures?
    CheckBecause runCatching catches Throwable including CancellationException, preventing cooperative coroutine cancellation unless CancellationException is rethrown.

Mixed Quick Check

1. Which Kotlin construct gives compile-time domain type safety around a single value while erasing the wrapper in direct non-null bytecode signatures?

typealias has zero runtime overhead but fails to stop parameter swapping (UserId and String remain interchangeable). @JvmInline value class enforces distinct compile-time types with unboxed direct signatures.

2. You chain items.asSequence().map { ... }.filter { ... }.first() on a list of 1,000,000 elements where the 2nd item matches. How many times does map run?

Sequence pipelines are vertical (element-by-element) and short-circuit immediately as soon as terminal first() finds a match.

3. Inside a CPU-bound withContext(Dispatchers.Default) loop with no suspending calls, how do you ensure prompt cooperative cancellation?

Coroutine cancellation is cooperative: non-suspending CPU loops must periodically check ensureActive() (or yield()) to throw CancellationException when cancelled.

The Grand Anti-Pattern Refactor

Refactor calculateHighValueTotal—written in verbose imperative Java/AI style—into a concise idiomatic extension function fun List<LegacyOrder>?.highValueTotal(): Double summing non-null totals >= 100.0 only for orders with a non-null id.

class LegacyOrder(val id: String?, val items: List<String>?, val total: Double?) // REFACTOR THIS IMPERATIVE LOOP INTO extension fun List<LegacyOrder>?.highValueTotal(): Double fun calculateHighValueTotal(orders: List<LegacyOrder>?): Double { if (orders == null) return 0.0 var sum = 0.0 for (o in orders) { if (o.id != null) { val t = o.total if (t != null && t >= 100.0) { sum += t } } } return sum } // Write fun List<LegacyOrder>?.highValueTotal(): Double here: fun main() { val orders = listOf( LegacyOrder("o1", listOf("Laptop"), 1200.0), LegacyOrder("o2", listOf("Pen"), 5.0), LegacyOrder(null, listOf("Ghost"), 500.0), LegacyOrder("o3", listOf("Monitor"), 300.0) ) val nullOrders: List<LegacyOrder>? = null check(orders.highValueTotal() == 1500.0) check(nullOrders.highValueTotal() == 0.0) println("Grand refactor verified: ${orders.highValueTotal()}") }
