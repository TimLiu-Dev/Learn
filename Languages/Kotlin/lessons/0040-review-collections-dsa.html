Quick Check

You need to find the Top 5 most frequent words in a list of 100,000 strings. Which approach is most idiomatic and optimal in Kotlin?

groupingBy { it }.eachCount() aggregates counts in O(N) without intermediate list allocations, and a Min-Heap of size 5 retrieves Top-K in O(N log K) time and O(K) space.

Exercise 1 · Write from blank

Top-K Frequent Elements

Implement topKFrequent(nums: IntArray, k: Int): IntArray:

  1. Given an integer array nums and an integer k, return the k most frequent elements in any order.
  2. Count frequencies using nums.asSequence().groupingBy { it }.eachCount() or a HashMap.
  3. Use PriorityQueue of size k (or bucket sort) to extract the top k elements.
  4. Return the result as an unboxed IntArray.

The Algorithmic Anti-Pattern Special

Refactor this Java-style, boxed, multi-loop mess into clean, idiomatic Kotlin.

// REFACTOR THIS: fun analyzeSensorData(readings: List<Double>): Map<String, Double> { var sum = 0.0 var count = 0 var maxVal = Double.NEGATIVE_INFINITY var minVal = Double.POSITIVE_INFINITY for (r in readings) { if (r >= 0.0) { sum += r count++ if (r > maxVal) maxVal = r if (r < minVal) minVal = r } } val avg = if (count > 0) sum / count else 0.0 val result = java.util.HashMap<String, Double>() result.put("average", avg) result.put("max", if (count > 0) maxVal else 0.0) result.put("min", if (count > 0) minVal else 0.0) return result } fun main() { val data = listOf(12.5, -1.0, 24.0, 18.2, -99.0) println(analyzeSensorData(data)) }
Hint 1: FilteringExtract non-negative readings: val valid = readings.filter { it >= 0.0 }, returning zeros if valid.isEmpty().
Hint 2: Standard summary metricsReturn mapOf("average" to valid.average(), "max" to (valid.maxOrNull() ?: 0.0), "min" to (valid.minOrNull() ?: 0.0)).
