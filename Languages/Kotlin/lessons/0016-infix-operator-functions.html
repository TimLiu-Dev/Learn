Infix and operator functions

Read them everywhere in the standard library, define them judiciously in domain modeling.

Warm-up

  2. Can an extension property have a backing field (field)?
    CheckNo, extension properties cannot hold state; they must define a custom getter (and optional setter).

Infix functions: omittable dots and parentheses

Docs: Infix notation. Must have exactly one parameter without default values.You already use infix notation every day when creating maps:

val pair = "Mon" to 30 // "to" is an infix extension function returning Pair("Mon", 30)

You can define your own infix functions by adding the infix keyword to a member or extension function:

infix fun String.coachedBy(coach: String): String = "$this (Coach: $coach)" val session = "Morning 10k" coachedBy "Elena"

Operator overloading: predefined symbolic methods

Docs: Operator overloading. Fixed set of identifiers: plus, minus, times, get, contains, inc, etc.Kotlin does not allow arbitrary operator creation (like C++ or Scala). Instead, you can overload a fixed set of predefined operators using the operator modifier:

class Distance(val meters: Int) { operator fun plus(other: Distance): Distance = Distance(meters + other.meters) operator fun contains(part: Int): Boolean = meters >= part } val total = Distance(5000) + Distance(3000) // calls plus() println(total.meters) // 8000 println(2000 in total) // calls contains(), prints true
Idiom Advice

Read them everywhere, define them rarely. Use infix notation for expressive DSLs and assertions (e.g. athlete shouldBe "Alex"). Use operators only when the mathematical or collection metaphor is unmistakable.

Infix Sets & Point Addition

Implement two things:

  1. An infix fun Int.setsOf(reps: Int): String that returns "<Int> sets of <reps> reps" (e.g. 4 setsOf 12 → "4 sets of 12 reps")
  2. An operator fun plus on Point(val x: Int, val y: Int) that adds corresponding coordinates and returns a new Point
// 1. Write infix fun setsOf here // 2. Define Point and operator fun plus here fun main() { println(3 setsOf 10) val p1 = Point(2, 4) val p2 = Point(3, 5) val sum = p1 + p2 println("Point: (${sum.x}, ${sum.y})") }
Hint 1: Infix declarationDefine infix fun Int.setsOf(reps: Int): String = "$this sets of $reps reps".
Hint 2: Operator overloadingIn data class Point(val x: Int, val y: Int), add operator fun plus(other: Point) = Point(x + other.x, y + other.y).

Clean Up Domain Calculations

Refactor the custom methods in Money to use operators, and taggedWith to use infix notation.

class Money(val amount: Double) { fun add(other: Money): Money = Money(amount + other.amount) fun multiply(times: Int): Money = Money(amount * times) } fun tagWorkout(workout: String, tag: String): String = "[$tag] $workout" fun main() { val m1 = Money(25.0) val m2 = Money(15.0) val total = m1.add(m2).multiply(2) println("Total: $${total.amount}") val tagged = tagWorkout("Morning Run", "Cardio") println(tagged) }
Hint 1: Operator fun on MoneyRename methods to operator fun plus(other: Money) = Money(amount + other.amount) and operator fun times(factor: Int) = Money(amount * factor).
Hint 2: Infix tag extensionWrite infix fun String.taggedWith(tag: String): String = "[$tag] $this" and call it as "Morning Run" taggedWith "Cardio".
