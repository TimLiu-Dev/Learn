Section 1 · Foundations · Review R1

Foundations review

Nothing new today. Mixed practice across lessons 1.1–1.6, so you have to work out which tool fits before you use it.

Why mixed? In a single lesson you always know which tool to use, because it's the one you just learned. Real code doesn't tell you. Mixing the topics makes you choose, and that harder retrieval is what makes it stick. Expect this to feel harder than the lessons did. That's the point.

Warm-up

One question per lesson. Answer each out loud or on paper before you open the check.

  1. val sets = mutableListOf(3) then sets.add(4). Does it compile? Why? (1.1)
    CheckYes. val fixes which list sets points to, not what's inside it.
  2. When does a string template need braces? (1.2)
    CheckFor anything beyond a plain variable name: "${w.minutes}", "${a + b}", "${name.length}".
  3. Which numbers does for (i in 9 downTo 1 step 3) visit? (1.3)
    Check9, 6, 3.
  4. What value does try { "x".toInt() } catch (e: NumberFormatException) { 0 } produce? (1.4)
    Check0, the last expression of the catch block that ran.
  5. When can a when expression leave out else? (1.5)
    CheckWhen it has a subject with a fixed set of values (Boolean, enum, sealed) and every value is covered. A when with no subject always needs else.
  6. Which operator asks “same contents?” and which asks “same object?” (1.6)
    Check== is contents (it calls equals, and is null-safe). === is the same object.

Mixed quick check

The topics are shuffled, and each question needs a different lesson.

1. What does for (i in 10 downTo 1 step 4) print("$i ") print?

Start at 10 and count down by 4: 10, 6, 2. The next value, −2, is past the end (1), so it stops.

2. val w = "Run". What does println("$w.length") print?

$w takes only the name w. The .length after it is plain text. You need "${w.length}".

3. Which declaration compiles?

A whole-number literal can become any integer type it fits, including Long. Nothing else converts implicitly: 5 isn't a Double, and 9.5 is a Double, not a Float (that needs 9.5f).

4. val last: String? = null. What happens with last == "Run"?

== checks for null before calling equals, so comparing a null value just gives false.

5. val minutes = 45. What is the value of when (minutes) { in 0..<20 -> "short"; in 20..45 -> "medium"; else -> "long" }?

20..45 includes 45, because .. includes its end value. With 20..<45, the answer would be "long".

6. val n = try { "12a".toInt() } catch (e: NumberFormatException) { -1 } finally { println("done") }. What happens?

Parsing fails, so the value comes from catch: −1. finally always runs, so it prints done, but it never supplies the value.

7. bpm is an Int. Which line fails to compile?

An if used for its value must have an else. Line (c) is fine because it's a statement: nothing uses its value.
