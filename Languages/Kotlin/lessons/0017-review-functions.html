Warm-up: Rapid Recall

  1. When should you use an extension function over a member function?
    CheckWhen extending third-party classes, keeping domain models decoupled from utility logic, or improving discoverability.
  2. What are the 3 constraints on an infix function?
    CheckMust be a member or extension; must have exactly one parameter; that parameter cannot have a default value or be a vararg.
  3. What symbol does Kotlin use for single-expression function bodies?
    Check= (equals sign).

Quick check

Which of the following is considered an anti-pattern in idiomatic Kotlin?

In Kotlin, static utility classes are an antipattern; top-level extension functions replace them entirely.

Review Practice

Exercise 1 · Write from blank

Session Logger & Rate Calculator

Write three functions from scratch:

  1. An extension property Int.secondsToTime: String formatted as "M:SS" (e.g. 125.secondsToTime → "2:05")
  2. An infix function infix fun String.assignedTo(coach: String?): String that returns "<session> → <coach ?: 'Unassigned'>"
  3. A single-expression function calcSpeed(distanceMeters: Double, seconds: Int = 3600): Double = ... returning meters per second (defaults to 1 hour)
// 1. Extension property Int.secondsToTime // 2. Infix function String.assignedTo // 3. Single-expression function calcSpeed fun main() { println(125.secondsToTime) println(300.secondsToTime) println("Hill Repeats" assignedTo "Elena") println("Solo Run" assignedTo null) println("Speed: ${calcSpeed(5000.0, 1000)} m/s") println("Speed default: ${calcSpeed(5000.0)} m/s") }
Hint 1: Extension property with formattingDefine val Int.secondsToTime: String get() = "${this / 60}:${(this % 60).toString().padStart(2, '0')}".
Hint 2: Infix and default argumentsUse infix fun String.assignedTo(coach: String?): String = "$this -> ${coach ?: "Unassigned"}" and compute meters per second in fun calcSpeed(distanceMeters: Double, seconds: Int = 3600): Double = distanceMeters / seconds.
Exercise 2 · Refactor

The Java/AI Functions Special

Refactor this bloated Java-flavoured snippet into clean, idiomatic Kotlin using default arguments, extension functions, and single-expression bodies.

class Distance(val km: Double) object DistanceHelper { fun add(d1: Distance, d2: Distance): Distance { return Distance(d1.km + d2.km) } fun format(d: Distance): String { return "${d.km} kilometers" } fun formatWithUnit(d: Distance, unit: String): String { return "${d.km} $unit" } } fun calculatePace(km: Double, minutes: Double): Double { return minutes / km } fun main() { val d1 = Distance(10.0) val d2 = Distance(5.0) val sum = DistanceHelper.add(d1, d2) println(DistanceHelper.format(sum)) println(DistanceHelper.formatWithUnit(sum, "km")) println("Pace: " + calculatePace(sum.km, 75.0) + " min/km") }
Hint 1: Operator overloadingIn class Distance(val km: Double), declare operator fun plus(other: Distance) = Distance(km + other.km).
Hint 2: Default argument consolidationAdd an extension fun Distance.format(unit: String = "kilometers") = "$km $unit" to replace both formatting overloads.
