Warm-up: Quick diagnostic check

Answer these from memory before touching code:

  1. In Kotlin, what does val x: String? = null mean compared to val x: String = ""?
    CheckString? is nullable (can hold null or a string); String is non-null (the compiler guarantees it can never be null).
  2. Why does Kotlin have no ternary operator (condition ? a : b)?
    CheckBecause if is an expression in Kotlin: val x = if (condition) a else b directly returns a value.
  3. What does val (a, b) = pair do under the hood?
    CheckIt calls pair.component1() and pair.component2() (destructuring declaration).

Audit & Clean Java-Flavoured Code

Refactor this snippet into clean, idiomatic Kotlin. Output must remain identical.

fun main() { var rawInput: String? = "45" var minutes: Int = 0 if (rawInput != null) { minutes = rawInput.toInt() } else { minutes = 30 } var title: String = "" if (minutes > 40) { title = "Long Run" } else { title = "Recovery" } println("Session: " + title + " (" + minutes + " min)") }
Hint 1: Null coalescing with ElvisReplace the if (rawInput != null) ... else 30 with the Elvis operator: val minutes = rawInput?.toIntOrNull() ?: 30.
