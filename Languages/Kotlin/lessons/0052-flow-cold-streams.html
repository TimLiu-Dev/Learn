Cold asynchronous streams: Flow

Reactive stream pipelines: builders, intermediate operators, terminal collectors, and context preservation.

Warm-up: Rapid Recall

  1. What is the difference between a suspending function returning List<T> and a function returning Flow<T>?
    CheckA suspending function returns all elements at once when done; a Flow<T> emits elements asynchronously over time as they become available.
  2. Why are Flows called "cold"?
    CheckThe code inside a flow { ... } builder does not run until a terminal operator (like collect) starts listening.

The Concept: Kotlin Flow Architecture

1. Flow Builder & Emission

fun countdownTimer(seconds: Int): Flow<Int> = flow { for (i in seconds downTo 1) { emit(i) // Emit value to subscriber delay(1000) } }

2. Intermediate and Terminal Operators

  • Intermediate: map, filter, take, transform. Returns a new Flow; lazy.
  • Terminal: collect, toList(), first(), reduce(). Starts stream collection.

3. Flow Context Preservation & flowOn

Rule of Flow: Never change the coroutine context inside a flow { ... } builder using withContext! It violates the Flow invariant. Instead, use .flowOn(Dispatchers.IO) upstream:

fun readLogFile(): Flow<String> = flow { // Reads file lines emit("line 1") emit("line 2") }.flowOn(Dispatchers.IO) // Changes dispatcher for upstream emissions ONLY!

4. Exception Handling with catch

Catches upstream exceptions without breaking downstream collectors:

userFlow .catch { e -> emit(FallbackUser) } .collect { println(it) }

Quick Check

What happens if you call withContext(Dispatchers.IO) { emit(x) } inside a flow { ... } block?

Flow preserves caller context. To offload emission to another dispatcher, you must use .flowOn(Dispatchers.IO).

Stock Ticker Flow Pipeline

Implement trackStockPrices(symbol: String, initialPrice: Double): Flow<Double>:

  1. Emit initialPrice, followed by 3 simulated updates (each incrementing by 1.5 with delay(20)).
  2. Apply flowOn(Dispatchers.Default).
  3. In main(), collect only prices > 100.0, formatting them as "TICKER: $price".
import kotlinx.coroutines.* import kotlinx.coroutines.flow.* fun trackStockPrices(symbol: String, initialPrice: Double): Flow<Double> { // Build cold flow emitting initialPrice and 3 updates return emptyFlow() } fun main() = runBlocking { trackStockPrices("KT", 98.0) .filter { it > 100.0 } .map { "TICKER: $it" } .collect { println(it) } }

Hint 2: Flow dispatcher switchingAppend .flowOn(Dispatchers.Default) to shift emission to the default worker pool.
