Section 7 · Collections & DSA · Lesson 7.1

Read-only vs mutable & primitive arrays

Idiomatic collection design, defensive copying, and avoiding boxing overhead in DSA coding interviews.

Warm-up: Rapid Recall

  1. What is the difference between val and immutability?
    Checkval means the reference cannot be reassigned; the underlying object itself may still be mutable (e.g. val list = mutableListOf<Int>()).
  2. Why does Kotlin have separate List<T> and MutableList<T> interfaces?
    CheckList<T> exposes only read-only methods and is covariant (out T); MutableList<T> adds mutation methods (add, remove) and is invariant.
  3. What is boxing in the JVM?
    CheckWrapping a primitive type (like int) into an object wrapper (like java.lang.Integer), incurring 16–24 bytes of heap overhead per element.

The Concept: Kotlin Collections Architecture

1. Read-Only is Not Immutable

In Kotlin, List<T> is a read-only interface, not necessarily an immutable data structure. Under the hood on the JVM, listOf(1, 2) returns an instance of java.util.Arrays$ArrayList or similar.

val readOnly: List<String> = mutableListOf("A", "B") // readOnly.add("C") // Compilation error! No .add() method on List // Idiomatic builder: construct mutably, expose as read-only val numbers: List<Int> = buildList { add(10) add(20) if (includeBonus) add(99) } // Returns a read-only List<Int> with zero defensive copies

2. DSA Critical: Primitive Arrays vs Boxed Arrays

In DSA interviews (LeetCode, Codeforces), choosing the wrong array type can cause Time Limit Exceeded (TLE) or Memory Limit Exceeded (MLE) due to GC pressure:

TypeUnderlying JVM TypeMemory per elementInterview Recommendation
IntArray int[] (primitive) 4 bytes Always use for DSA integers/counts/tables
Array<Int> Integer[] (boxed) 16–24 bytes Avoid in performance-critical code
List<Int> List<Integer> (boxed) 24+ bytes Great for clean APIs, avoid in tight loops

Creation idioms:

val freq = IntArray(26) // filled with 0s val dp = IntArray(n + 1) { -1 } // initialized to -1 val matrix = Array(m) { IntArray(n) } // 2D primitive grid m × n

Quick Check

In an algorithmic coding interview where you need to track character frequencies of lowercase English letters ('a'..'z'), which declaration is most idiomatic and cache-friendly?

IntArray(26) allocates an unboxed primitive int[26] directly with contiguous memory, O(1) index access, zero boxing, and automatic zero-initialization.
