object, companion object, and data object

Replacing Java static members with singletons, factory companions, and clean toString() objects.

Warm-up

  1. What is the main difference between an enum class and a sealed interface?
    CheckAn enum entry has only one shared instance and cannot hold distinct per-instance state. A sealed hierarchy allows each subclass (e.g. data class Success(val items)) to hold unique instance data.
  2. Why does when (state) { is Ready -> state.title } require no explicit casting?
    CheckBecause Kotlin automatically smart-casts state to Ready inside that branch.

Singletons with object

Docs: Object declarations. Thread-safe and initialized on first access.In Java, thread-safe singletons required 15 lines of double-checked locking boilerplate. In Kotlin, the singleton pattern is a first-class language feature:

object AppDatabase { val name = "TrainingDB" fun connect() = println("Connected to $name") } // Access anywhere as a single instance: AppDatabase.connect()

companion object: Replacing Java's static

Kotlin has no static keyword. When you need a function or constant tied to a class rather than a specific instance (such as a factory method), define a companion object inside the class:

class Athlete private constructor(val name: String, val age: Int) { companion object { const val DEFAULT_MAX_HR = 190 // Factory function replacing secondary constructor fun fromBirthYear(name: String, birthYear: Int): Athlete = Athlete(name, age = 2026 - birthYear) } } // Call site looks just like a static method in Java: val athlete = Athlete.fromBirthYear("Elena", 1998) println(Athlete.DEFAULT_MAX_HR)

Extending companion objects

Because companion objects are real objects, you can extend them with new factory functions without modifying the original class:

fun Athlete.Companion.anonymous(): Athlete = Athlete("Guest", 25)

data object: Clean logging & serialization

When an object is used as a state (e.g. in a sealed interface or MVI event bus), printing a plain object Loading outputs ugly JVM identity strings like ScreenState$Loading@3b07988b. Marking it as data object generates clean, readable toString() output:

object PlainState data object CleanState println(PlainState) // prints: PlainState@7f31245a println(CleanState) // prints: CleanState

Quick check

Can a class have more than one companion object?

Each Kotlin class can have at most one companion object (though it can have any number of named nested objects).

Factory Companion & Data Object State

Define two things:

  1. A sealed interface DownloadState with two subtypes:
    • data object Idle : DownloadState
    • data class InProgress(val percent: Int) : DownloadState
  2. A class SessionToken private constructor(val raw: String) with a companion object:
    • A constant const val PREFIX = "RUN_"
    • A factory function create(userId: String): SessionToken returning SessionToken("$PREFIX$userId")
// 1. Define sealed interface DownloadState with data object Idle // 2. Define SessionToken with private constructor and companion factory fun main() { val state: DownloadState = DownloadState.Idle println("State: $state") // Should print: State: Idle val token = SessionToken.create("u123") println("Token: ${token.raw}") // Should print: Token: RUN_u123 }
Hint 1: Companion factoryDefine class SessionToken private constructor(val raw: String) { companion object { fun create(raw: String): SessionToken? = raw.takeIf { it.isNotBlank() }?.let { SessionToken(it) } } }.
Hint 2: Data object stateDeclare data object Idle : AppState for clean singleton state modeling.
Exercise 2 · Refactor

Kill the Java Static Pattern

Refactor this Java-style singleton and factory into idiomatic Kotlin using object and a companion object.

// Refactor this Java-style singleton: class AppConfig private constructor() { val environment = "Production" val timeoutMs = 4000 companion object { private var instance: AppConfig? = null fun getInstance(): AppConfig { if (instance == null) { instance = AppConfig() } return instance!! } } } // Refactor this Java-style static factory: class User(val id: String, val role: String) { companion object { fun makeAdmin(id: String): User { return User(id, "ADMIN") } } } fun main() { val config = AppConfig.getInstance() println("${config.environment}: ${config.timeoutMs}ms") val admin = User.makeAdmin("a01") println("User ${admin.id}: ${admin.role}") }
Hint 1: Top-level singletonReplace the verbose Java singleton with object AppConfig { val apiEndpoint: String = "https://api.workout.com"; val timeoutMs: Int = 5000 }.
Hint 2: Companion factory methodIn User, place makeAdmin inside companion object { fun makeAdmin(name: String) = User(name, isAdmin = true) }.
