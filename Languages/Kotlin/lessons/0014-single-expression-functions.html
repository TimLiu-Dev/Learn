Section 3 · Functions · Lesson 3.2

Single-expression functions

Replacing boilerplate return blocks with clean expression bodies, and knowing when to keep return types.

Warm-up

  1. In fun save(timeout: Int = 1000), what does = 1000 provide?
    CheckA default argument value used when the caller omits that parameter.
  2. Why does Kotlin encourage named arguments when calling functions with multiple boolean or numeric parameters?
    CheckIt prevents mystery literal bugs (e.g. connect(true, false, 5) vs connect(retry = true, useCache = false)).

The problem single-expression bodies solve

Docs: Single-expression functions.When a function body consists of a single expression, wrapping it in curly braces and writing return adds visual noise without clarifying anything. Kotlin lets you assign the expression directly with =:

Verbose (Statement Body)

fun maxHr(age: Int): Int { return 220 - age }

Idiomatic (Expression Body)

fun maxHr(age: Int): Int = 220 - age

When can you omit the return type?

Because the compiler can infer the return type from the right-hand side, you can write fun maxHr(age: Int) = 220 - age. However, the official Kotlin style guide states a clear convention:

Kotlin Coding Convention

Public APIs: Always specify return types explicitly on public and protected functions to prevent accidental API breaks when implementation changes.

Private / Local helpers: Type inference on expression bodies is encouraged for concise private code.

Quick check

Which of the following is NOT valid Kotlin?

= { pace < 4.5 } assigns a lambda function () -> Boolean, not a Boolean return value!

Exercise 1 · Write from blank

Metrics & Conversions

Write three single-expression functions from scratch:

  1. milesToKm(miles: Double): Double → multiplies miles by 1.60934
  2. paceDescription(minPerKm: Double): String → returns "Elite" if < 3.5, "Fast" if 3.5..5.0, otherwise "Steady" (use a single when expression)
  3. calorieEstimate(weightKg: Double, km: Double): Double → calculates weightKg * km * 1.036
// Write the 3 single-expression functions here fun main() { println(milesToKm(10.0)) println(paceDescription(4.2)) println(calorieEstimate(70.0, 10.0)) }
Hint 1: Direct expression returnWrite fun milesToKm(miles: Double): Double = miles * 1.60934 and fun calorieEstimate(weightKg: Double, km: Double): Double = weightKg * km * 1.036.
Hint 2: Argumentless when expressionIn paceDescription, use : String = when { minPerKm < 3.5 -> "Elite"; minPerKm <= 5.0 -> "Fast"; else -> "Steady" }.
Exercise 2 · Refactor

Simplify Java-Flavoured Calculators

Refactor all functions in this snippet into idiomatic single-expression functions. The output of main must not change.

fun calculateBmi(weightKg: Double, heightM: Double): Double { return weightKg / (heightM * heightM) } fun isHealthyWeight(bmi: Double): Boolean { if (bmi in 18.5..24.9) { return true } else { return false } } fun formatAthleteBadge(name: String, rank: Int): String { return "#$rank: $name" } fun main() { val bmi = calculateBmi(72.0, 1.78) println("BMI: $bmi (Healthy: ${isHealthyWeight(bmi)})") println(formatAthleteBadge("Alex", 1)) }
Hint 1: Direct boolean range checkReplace if (bmi in 18.5..24.9) return true else return false with simply fun isHealthyWeight(bmi: Double): Boolean = bmi in 18.5..24.9.
Hint 2: Expression bodiesRefactor the others to fun calculateBmi(weightKg: Double, heightM: Double): Double = weightKg / (heightM * heightM) and fun formatAthleteBadge(name: String, rank: Int): String = "#$rank: $name".
