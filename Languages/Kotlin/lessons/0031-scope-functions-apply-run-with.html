The Concept: Object Configuration & Receiver Execution

Inside apply, run, and with, the context object is available as this. You don't write it.title = "..."; you write title = "..." directly.

1. apply: Configure and Return the Object

apply returns the context object itself. It is the gold standard for object initialization (Android Views, Intents, Spring DTOs, HTTP clients):

val dialog = CustomDialog().apply { title = "Confirm Deletion" isCancelable = false setPositiveButton("OK") { dismiss() } } // Returns dialog

2. run: Configure/Scope and Return Lambda Result

run returns the result of the lambda. It is an extension function: receiver.run { ... }.

val bannerText = bannerConfig.run { // 'this' is bannerConfig "[$priority] $header: $body" }

run can also be called as a non-extension function (bare run { ... }) to execute an expression block with local scope.

3. with: Non-Extension Function for Grouping Operations

with is NOT an extension function. It takes the context object as its first argument: with(receiver) { ... } and returns the lambda result:

val summary = with(stringBuilder) { append("Line 1 ") append("Line 2 ") toString() // Returns this String }

Idiom rule: Prefer run over with if the receiver might be null (receiver?.run { ... } works; with(receiver) does not safe-call easily).
