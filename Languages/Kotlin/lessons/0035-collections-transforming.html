The Concept: Core Transformation Operators

1. mapNotNull vs filterNotNull().map()

Instead of filtering out nulls in one pass and then mapping in a second pass (allocating two intermediate lists), use mapNotNull to transform and discard null results in a single step:

val rawStrings = listOf("10", "apple", "42", "invalid") // Idiomatic: single pass, single list allocation val numbers: List<Int> = rawStrings.mapNotNull { it.toIntOrNull() } // [10, 42]

2. flatMap vs flatten

  • flatten(): flattens a nested collection: List<List<T>> -> List<T>.
  • flatMap { ... }: transforms each item into a collection and flattens the result in one go:
data class Order(val id: String, val items: List<String>) val orders = listOf(Order("o1", listOf("Book", "Pen")), Order("o2", listOf("Coffee"))) val allItems: List<String> = orders.flatMap { it.items } // ["Book", "Pen", "Coffee"]

3. associateBy, associateWith, and associate

Quick lookup indexing from collections to maps:

  • associateBy { it.id }: keys are extracted; values are the original elements (Map<K, T>).
  • associateWith { computeValue(it) }: keys are the elements; values are computed (Map<T, V>).
  • associate { it.key to it.value }: produces custom key-value pairs (more allocation due to Pair).
data class User(val id: String, val name: String) val users = listOf(User("u1", "Alice"), User("u2", "Bob")) // Indexed map for O(1) lookup by ID: val userMap: Map<String, User> = users.associateBy { it.id } println(userMap["u1"]?.name) // "Alice"

4. Type-Filtering with filterIsInstance<T>()

Filtering heterogeneous collections with automatic smart-casting:

val mixed: List<Any> = listOf(1, "hello", 2.5, "world") val stringsOnly: List<String> = mixed.filterIsInstance<String>() // ["hello", "world"] with type List<String>
