Section 8 · Delegation · Lesson 8.3

Class delegation

First-class composition: implementing interfaces by delegating to underlying instances with zero boilerplate.

Warm-up: Rapid Recall

  1. What design pattern wraps an object to add new functionality while maintaining the same interface?
    CheckThe Decorator pattern.
  2. Why is deep class inheritance often discouraged compared to composition?
    CheckInheritance couples subclasses tightly to parent internal implementations (the fragile base class problem); composition allows swapping and testing decoupled implementations.

The Concept: First-Class Interface Delegation

In Java, decorating an interface with 15 methods requires writing 15 forwarding methods: public void methodA() { delegate.methodA(); }. In Kotlin, the compiler generates all forwarding boilerplate in a single keyword: by.

interface Repository { fun getById(id: String): String? fun save(id: String, data: String) fun delete(id: String) } // Implement Repository by delegating to 'inner': class LoggingRepository( private val inner: Repository ) : Repository by inner { // Selectively override only the methods you want to intercept! override fun save(id: String, data: String) { println("[LOG] Saving record $id") inner.save(id, data) // Delegate to underlying implementation } // getById and delete are automatically forwarded! }

Important Caveat: No Virtual Dispatch Inside Delegate

Delegated methods on inner execute in the context of inner itself. If inner calls another of its own interface methods internally, it will call its own version, NOT your decorator's override!

Quick Check

Given class CountingList<T>(val inner: List<T>) : List<T> by inner. If you override size to return inner.size + 1, what does isEmpty() return on an empty list?

Delegation is forwarding, not inheritance. inner executes its own methods directly and does not dispatch virtually to the outer wrapper.

Practice: Hands-On Exercises

Exercise 1 · Write from blank

Auditing Analytics Client Decorator

Implement the following:

  1. Interface AnalyticsService with methods trackEvent(name: String), identifyUser(userId: String), and flush().
  2. Class ConsoleAnalytics : AnalyticsService that prints each operation.
  3. Class AuditingAnalytics(private val inner: AnalyticsService) : AnalyticsService by inner that:
    • Maintains a counter var eventCount = 0.
    • Overrides trackEvent(name: String) to increment eventCount, log "Audit: Event #$eventCount -> $name", and forward to inner.trackEvent(name).
interface AnalyticsService { fun trackEvent(name: String) fun identifyUser(userId: String) fun flush() } class ConsoleAnalytics : AnalyticsService { override fun trackEvent(name: String) = println("Console: event $name") override fun identifyUser(userId: String) = println("Console: identify $userId") override fun flush() = println("Console: flushed") } // 1. Implement AuditingAnalytics using 'by inner' class delegation: fun main() { val service: AnalyticsService = AuditingAnalytics(ConsoleAnalytics()) service.identifyUser("u-99") service.trackEvent("login") service.trackEvent("purchase") service.flush() }
Hint 1: Interface delegationDeclare class AuditingAnalytics(private val inner: AnalyticsService) : AnalyticsService by inner.
Hint 2: Selective overrideTrack var eventCount = 0 and override only trackEvent(name: String) to increment eventCount, log the audit line, and forward to inner.trackEvent(name).
Exercise 2 · Refactor

Java-Style Manual Forwarding Decorator

Refactor this verbose manual forwarding class into a concise 1-line class delegation.

interface TaskQueue { fun push(task: String) fun pop(): String? fun peek(): String? val size: Int } class SimpleQueue : TaskQueue { private val items = ArrayDeque<String>() override fun push(task: String) { items.addLast(task) } override fun pop(): String? = items.removeFirstOrNull() override fun peek(): String? = items.firstOrNull() override val size: Int get() = items.size } // REFACTOR THIS MANUAL BOILERPLATE: class MonitoredTaskQueue(private val inner: TaskQueue) : TaskQueue { override fun push(task: String) { println("Task queued: $task") inner.push(task) } override fun pop(): String? = inner.pop() override fun peek(): String? = inner.peek() override val size: Int get() = inner.size } fun main() { val q = MonitoredTaskQueue(SimpleQueue()) q.push("Send Email") println("Queue size: ${q.size}") }
Hint 1: Eliminate boilerplate forwardersDeclare class MonitoredTaskQueue(private val inner: TaskQueue) : TaskQueue by inner and override only push(task: String).
Hint 2: Delete manual methodsRemove manual implementations of pop(), peek(), and size; the compiler auto-generates forwarding bytecode for all non-overridden methods.
