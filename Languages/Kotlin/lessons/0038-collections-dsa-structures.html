The Concept: Core Algorithmic Data Structures

1. ArrayDeque: Queue and Stack

Kotlin's standard library provides kotlin.collections.ArrayDeque (resizable array with head and tail pointers). It provides amortized O(1) operations at both ends:

Use CasePush / EnqueuePop / DequeuePeek
FIFO Queue (BFS traversal) addLast(x) removeFirst() or removeFirstOrNull() first()
LIFO Stack (DFS, paren matching) addLast(x) removeLast() or removeLastOrNull() last()
val deque = ArrayDeque<Int>() // As a queue: deque.addLast(1) deque.addLast(2) val next = deque.removeFirst() // 1 // As a stack: deque.addLast(10) deque.addLast(20) val top = deque.removeLast() // 20

2. PriorityQueue: Min-Heap & Max-Heap for Top-K

For Top-K elements or Dijkstra's shortest path, use java.util.PriorityQueue:

  • Min-Heap (default): smallest element at top.
  • Max-Heap: pass reverse comparator: PriorityQueue<Int>(compareByDescending { it }).
// Top K frequent elements pattern: val minHeap = java.util.PriorityQueue<Int>() for (x in stream) { minHeap.add(x) if (minHeap.size > k) { minHeap.poll() // Discard smallest, keeping K largest in heap } }

3. LRU Cache with LinkedHashMap

LinkedHashMap maintains insertion order or access order. Overriding removeEldestEntry creates an automatic LRU cache:

class LruCache<K, V>(private val capacity: Int) : LinkedHashMap<K, V>(capacity, 0.75f, true) { override fun removeEldestEntry(eldest: MutableMap.MutableEntry<K, V>?): Boolean { return size > capacity } }

Quick Check

Which collection should you instantiate in Kotlin when implementing a BFS (Breadth-First Search) level-order traversal queue?

ArrayDeque provides O(1) amortized insertion at the back and removal at the front. ArrayList.removeAt(0) takes O(N) because it shifts every element in memory.
