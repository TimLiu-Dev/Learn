The Concept: Writing Pointer & Graph Algorithms Cleanly

1. Nullable Binary Trees (TreeNode?): Elvis DFS & Level-Order BFS

Coding platforms like LeetCode model binary trees with nullable child pointers: class TreeNode(var `val`: Int, var left: TreeNode? = null, var right: TreeNode? = null). Never litter tree code with !!:

  • Recursive DFS: Open with val node = root ?: return baseValue so node.left and node.right are accessed cleanly without ?. chains.
  • Level-order BFS: Seed an ArrayDeque<TreeNode>() (only enqueueing non-null nodes!) and freeze each level's width via repeat(queue.size) { ... }.

2. Graph Adjacency Lists & Topological / Cycle Detection

When vertices are labeled 0 until n, avoid boxed Map<Int, MutableList<Int>> overhead by allocating an indexed adjacency array:

val adj = Array(n) { mutableListOf<Int>() } val inDegree = IntArray(n) for ((u, v) in edges) { adj[u].add(v) inDegree[v]++ }

For directed cycle detection via DFS instead of Kahn's BFS, use val state = IntArray(n) with 0 = unvisited, 1 = visiting (on active stack), 2 = completed.Use BooleanArray(n) for O(1) visited checks on undirected graphs, or Kahn's in-degree queue (ArrayDeque<Int>) for dependency ordering and cycle detection.

3. Backtracking: Choose → Explore → Unchoose (Snapshot Trap!)

Backtracking explores subsets, permutations, or paths using a single shared mutable buffer (val path = ArrayDeque<Int>() or mutableListOf<Int>()). The #1 interview bug in Kotlin is writing results.add(path) at the base case—which stores a reference to the same list that later gets emptied! Always snapshot an immutable copy via results.add(path.toList()) before popping with path.removeLast().

Run level-order tree BFS and subset backtracking side by side:

Quick Check

1. In a backtracking algorithm using val path = mutableListOf<Int>(), what happens if your base case executes results.add(path) instead of results.add(path.toList())?

Because MutableList<T> is a subtype of read-only List<T>, results.add(path) compiles silently while aliasing the mutated buffer. Always call path.toList() at the leaf.

2. Inside a binary tree level-order BFS loop, why does repeat(queue.size) { ... } work safely even though children are enqueued inside the block?

Passing queue.size into repeat(...) captures the exact integer count of the current depth level before any child nodes are appended.

3. When detecting cycles in a directed dependency graph (like Course Schedule) using Kahn's BFS algorithm, how do you know a cycle exists after the queue empties?

Every node in a cycle waits on another node in that cycle, so none of them ever reaches inDegree == 0—leaving processed < n.

Exercise 2 · Refactor

Fix the Backtracking Aliasing Bug & O(V²) Graph BFS

This candidate's code has two classic bugs/anti-patterns: (1) combinationSum adds the mutable path directly into results without copying, so every returned combination is empty []; and (2) shortestSteps uses mutableListOf for both queue (removeAt(0) = O(V)) and visited (in visited = O(V) linear scan). Fix both!

// BUG 1: results.add(path) aliases the mutated list instead of snapshotting path.toList()! fun combinationSum(candidates: IntArray, target: Int): List<List<Int>> { val results = mutableListOf<List<Int>>() val path = mutableListOf<Int>() fun dfs(startIdx: Int, remaining: Int) { if (remaining == 0) { results.add(path) // <-- BUG: aliases mutable path! return } if (remaining < 0) return for (i in startIdx until candidates.size) { path.add(candidates[i]) dfs(i, remaining - candidates[i]) path.removeLast() } } dfs(0, target) return results } // BUG 2: O(V) removeAt(0) and O(V) list.contains() inside BFS! fun shortestSteps(n: Int, edges: Array<IntArray>, target: Int): Int { val adj = Array(n) { mutableListOf<Int>() } for (e in edges) { adj[e[0]].add(e[1]) adj[e[1]].add(e[0]) } val visited = mutableListOf<Int>() val queue = mutableListOf(0 to 0) visited.add(0) while (queue.isNotEmpty()) { val (node, dist) = queue.removeAt(0) if (node == target) return dist for (next in adj[node]) { if (next !in visited) { visited.add(next) queue.add(next to dist + 1) } } } return -1 } fun main() { val combos = combinationSum(intArrayOf(2, 3, 6, 7), 7) check(combos == listOf(listOf(2, 2, 3), listOf(7))) { "Bug 1: expected [[2, 2, 3], [7]] but got $combos" } val edges = arrayOf(intArrayOf(0, 1), intArrayOf(1, 2), intArrayOf(0, 3), intArrayOf(3, 4), intArrayOf(4, 2)) check(shortestSteps(5, edges, 2) == 2) println("Fixed backtracking snapshot & O(V + E) graph BFS: combos=$combos") }
Hint 1: Snapshot copyChange results.add(path) to results.add(path.toList()) so subsequent path.removeLast() calls don't mutate saved solutions.
Hint 2: O(V + E) BFS structuresUse val visited = BooleanArray(n).also { it[0] = true } and val queue = ArrayDeque<Pair<Int, Int>>().apply { addLast(0 to 0) }, popping with queue.removeFirst() and checking !visited[next].
