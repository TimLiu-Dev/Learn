Warm-up: Rapid Recall

  1. In a lambda with receiver StringBuilder.() -> Unit, what does this refer to?
    CheckThe StringBuilder instance being configured.
  2. What is the difference between a bare return and return@forEach inside a lambda?
    CheckA bare return exits the enclosing outer function (non-local return), whereas return@forEach exits only the current lambda iteration (like a continue statement).
  3. Why does listOf("a", "b").map(String::uppercase) not allocate an extra wrapper lambda?
    CheckBecause member references (::) refer directly to the existing method handle.

Quick check

Which function signature represents a lambda that configures an Athlete and returns Unit?

Athlete.() -> Unit denotes a function literal with receiver Athlete, taking no parameters and returning Unit.

Type-Safe Report Builder

Implement a type-safe report builder:

  1. A class ReportScope with:
    • val lines = mutableListOf<String>()
    • fun header(title: String) { lines.add("=== $title ===") }
    • fun item(text: String) { lines.add("* $text") }
  2. An inline fun buildReport(block: ReportScope.() -> Unit): String that initializes a ReportScope, executes block on it, and returns all lines joined with newlines (joinToString("\n"))
// 1. Define ReportScope // 2. Define inline fun buildReport fun main() { val report = buildReport { header("Weekly Running Log") item("Mon: 10k Tempo") item("Wed: 8k Recovery") item("Sat: 21k Long Run") } println(report) }
Hint 1: Receiver lambda DSLDeclare inline fun buildReport(block: ReportScope.() -> Unit): String so callers can call header(...) and item(...) directly on the implicit receiver.
Hint 2: Scope executionInside buildReport, instantiate val scope = ReportScope(), invoke scope.block(), and return scope.lines.joinToString("\n").
Exercise 2 · Refactor

The Functional Anti-Pattern Special

Refactor this snippet: eliminate the manual loop and temporary variables by using standard functional operations (map, filter) with member references (::) and buildList.

data class User(val name: String, val active: Boolean) fun isUserActive(u: User): Boolean = u.active fun getActiveNames(users: List<User>): List<String> { val result = ArrayList<String>() for (u in users) { if (isUserActive(u)) { result.add(u.name.uppercase()) } } return result } fun main() { val users = listOf( User("Sam", true), User("Alex", false), User("Elena", true) ) println(getActiveNames(users)) }
Hint 1: Collection pipelineReplace the imperative for-loop with users.filter(::isUserActive).map(User::name).
Hint 2: Callable referencesUse ::isUserActive for the top-level predicate and User::name for member property extraction.
