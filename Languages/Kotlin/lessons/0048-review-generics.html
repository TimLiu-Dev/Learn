Practice: Hands-On Exercises

Exercise 1 · Write from blank

Type-Safe In-Memory Message Bus

Implement MessageBus:

  1. Open class Message, subclasses TextMessage(val text: String) : Message() and AlertMessage(val level: Int) : Message().
  2. Method publish(msg: Message) that stores messages in an internal list.
  3. inline fun <reified T : Message> filterMessages(): List<T> that returns only messages of type T (using filterIsInstance<T>()).
open class Message class TextMessage(val text: String) : Message() class AlertMessage(val level: Int) : Message() class MessageBus { val messages = mutableListOf<Message>() fun publish(msg: Message) { messages.add(msg) } // Implement inline fun <reified T : Message> filterMessages(): List<T> } fun main() { val bus = MessageBus() bus.publish(TextMessage("Hello")) bus.publish(AlertMessage(5)) bus.publish(TextMessage("World")) val texts = bus.filterMessages<TextMessage>() println("Texts: ${texts.map { it.text }}") }
Hint 1: Reified type filteringInside MessageBus, define inline fun <reified T : Message> filterMessages(): List<T> using messages.filterIsInstance<T>().
Hint 2: Upper bound constraintThe upper bound : Message ensures only message subtypes can be filtered.
Exercise 2 · Refactor

Declaration-Site Covariance Refactor

Right now DataSupplier<T> is invariant, forcing every caller like printAllSuppliers to write awkward call-site out projections (or failing to compile without them). Make DataSupplier declaration-site covariant so printAllSuppliers can cleanly accept List<DataSupplier<CharSequence>>.

// REFACTOR THIS: Make DataSupplier declaration-site covariant so main() compiles cleanly! interface DataSupplier<T> { fun get(): T } fun printAllSuppliers(suppliers: List<DataSupplier<CharSequence>>) { for (s in suppliers) { println("Item: ${s.get()}") } } class StringSupplier(val v: String) : DataSupplier<String> { override fun get(): String = v } fun main() { val list: List<DataSupplier<String>> = listOf(StringSupplier("Alpha"), StringSupplier("Beta")) printAllSuppliers(list) }
Hint 1: Declaration-site covarianceAdd out to the interface definition: interface DataSupplier<out T> { fun get(): T }.
Hint 2: Clean call sitesSince DataSupplier only returns T and never accepts T as an input parameter, out eliminates all call-site wildcards.
