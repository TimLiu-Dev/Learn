Anti-Pattern: The Dreaded "Arrow of Scope"

A frequent anti-pattern produced by LLMs and beginners is chaining or nesting multiple ?.let calls:

// BAD: Nested pyramid of scopes user?.let { u -> u.profile?.let { p -> p.address?.let { a -> println(a.city) } } } // GOOD: Simple safe navigation user?.profile?.address?.city?.let { println(it) } // OR even simpler: val city = user?.profile?.address?.city if (city != null) println(city)

takeIf and takeUnless: Inline Filtering

takeIf tests an object against a predicate lambda:

  • If the predicate returns true, it returns the receiver.
  • If the predicate returns false, it returns null.
val input = "kotlin" val validName = input.takeIf { it.isNotBlank() && it.length >= 3 } // Returns "kotlin" val emptyInput = " " val invalid = emptyInput.takeIf { it.isNotBlank() } // Returns null!

takeIf is extremely powerful when combined with Elvis (?:) or safe calls (?.):

val port = rawPort.takeIf { it in 1024..65535 } ?: 8080

Quick Check

What does val result = "admin".takeUnless { it == "guest" }?.uppercase() evaluate to?

takeUnless returns the object if the predicate is FALSE. Since "admin" == "guest" is false, it returns "admin", which is then mapped to "ADMIN".

Exercise 1 · Write from blank

Sanitized Port Validator Pipeline

Implement resolvePort(configuredPort: Int?, defaultPort: Int = 8080): Int:

  1. If configuredPort is not null and is inside standard range 1..65535, return it (use takeIf).
  2. Otherwise fallback to defaultPort.
  3. Use also to log "Resolved active port: $port" before returning.
fun resolvePort(configuredPort: Int?, defaultPort: Int = 8080): Int { // Implement with takeIf and also return defaultPort } fun main() { println(resolvePort(443)) println(resolvePort(-1)) println(resolvePort(null)) println(resolvePort(70000)) }
Hint 1: Validation with takeIfUse configuredPort?.takeIf { it in 1..65535 } ?: defaultPort to fall back on null or out-of-range ports.
Hint 2: Side-effect chainingWrap the Elvis expression in parentheses and attach .also { port -> println("Resolved active port: $port") }.

Flatten the "Arrow of Scope" Anti-Pattern

Refactor this deeply nested pyramid into a clean, idiomatic single-expression or guard check.

data class Company(val name: String, val ceo: Person?) data class Person(val name: String, val email: String?) // REFACTOR THIS ANTI-PATTERN: fun sendCeoEmail(company: Company?, message: String) { company?.let { c -> c.ceo?.let { ceo -> ceo.email?.let { email -> if (email.contains("@")) { println("Sending to $email: $message") } } } } } fun main() { val comp = Company("Acme Corp", Person("Alice Smith", "alice@acme.com")) sendCeoEmail(comp, "Welcome aboard!") sendCeoEmail(null, "Hello") }
