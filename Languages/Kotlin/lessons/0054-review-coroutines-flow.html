Exercise 1 · Write from blank

Real-Time Live Search Debouncer

Implement searchPipeline(queryFlow: Flow<String>): Flow<List<String>>:

  1. Simulate search query debouncing: filter out blank queries.
  2. Simulate query lookup offloaded to Dispatchers.IO via flowOn.
  3. Map each valid query to listOf("Result 1 for $it", "Result 2 for $it").
import kotlinx.coroutines.* import kotlinx.coroutines.flow.* fun searchPipeline(queryFlow: Flow<String>): Flow<List<String>> { // Filter blank, map to mock results, and offload via flowOn return emptyFlow() } fun main() = runBlocking { val queries = flowOf("kot", "", "kotlin", "coroutines") searchPipeline(queries).collect { results -> println("Search results: $results") } }
Hint 1: Query transformationFilter and map queries: queries.filter { it.isNotBlank() }.map { searchDb(it) }.
Hint 2: Offload I/OAppend .flowOn(Dispatchers.IO) to keep database queries off the collector's dispatcher.
Exercise 2 · Refactor

The Coroutine Anti-Pattern Special

Refactor this buggy coroutine pipeline which uses GlobalScope, hardcoded blocking calls, and swallows cancellations.

import kotlinx.coroutines.* // REFACTOR THIS: suspend fun fetchSensorDataBad(): String = withContext(Dispatchers.Default) { try { Thread.sleep(50) // BAD: blocking thread on Default pool "Temperature: 24C" } catch (e: Exception) { "Error" // BAD: Swallowed CancellationException } } // Write the clean idiomatic version: suspend fun fetchSensorData(): String = withContext(Dispatchers.IO) { delay(50) "Temperature: 24C" } fun main() = runBlocking { println(fetchSensorData()) }
Hint 1: Never swallow cancellationIf catching Exception, always rethrow CancellationException: if (e is CancellationException) throw e.
Hint 2: Non-blocking delayReplace Thread.sleep with delay to participate in cooperative structured cancellation.
