Quick Check

1. Which dispatcher should you switch to before executing file.readText() on disk?

File reading is blocking I/O, which belongs on Dispatchers.IO.

2. You want two independent network calls fetchProfile() and fetchFeed() to run concurrently, and if *either* fails, both should cancel immediately and throw the error. Which scope function should wrap them?

Use coroutineScope when children form an all-or-nothing unit of work, and supervisorScope when children should fail independently.

3. Why do we pair debounce(300) with distinctUntilChanged() before flatMapLatest in a search-as-you-type Flow pipeline?

debounce(300) + distinctUntilChanged() + flatMapLatest { ... } is the classic Kotlin Flow triad for responsive, race-free search UI.

Exercise 1 · Write from blank

Real-Time Live Search Debouncer

Implement searchPipeline(queryFlow: Flow<String>): Flow<List<String>>:

  1. Simulate search query debouncing: filter out blank queries.
  2. Simulate query lookup offloaded to Dispatchers.IO via flowOn.
  3. Map each valid query to listOf("Result 1 for $it", "Result 2 for $it").
import kotlinx.coroutines.* import kotlinx.coroutines.flow.* fun searchPipeline(queryFlow: Flow<String>): Flow<List<String>> { // Filter blank, map to mock results, and offload via flowOn return emptyFlow() } fun main() = runBlocking { val queries = flowOf("kot", "", "kotlin", "coroutines") searchPipeline(queries).collect { results -> println("Search results: $results") } }
Hint 1: Query transformationFilter blank inputs and transform queryFlow: queryFlow.filter { it.isNotBlank() }.map { query -> listOf("Result 1 for $query", "Result 2 for $query") }.
Hint 2: Offload I/OAppend .flowOn(Dispatchers.IO) to keep database queries off the collector's dispatcher.

The Coroutine Anti-Pattern Special

Refactor this buggy coroutine pipeline which uses GlobalScope, hardcoded blocking calls, and swallows cancellations.

import kotlinx.coroutines.* // REFACTOR THIS: suspend fun fetchSensorData(): String = withContext(Dispatchers.Default) { try { Thread.sleep(50) // BAD: blocking thread on Default pool "Temperature: 24C" } catch (e: Exception) { "Error" // BAD: Swallowed CancellationException } } fun main() = runBlocking { println(fetchSensorData()) }
Hint 1: Never swallow cancellationIf catching Exception, always rethrow CancellationException: if (e is CancellationException) throw e.
Hint 2: Non-blocking delayReplace Thread.sleep with delay to participate in cooperative structured cancellation.
