Exercise 1 · Write from blank

Thread-Safe Metric Cache with Class Delegation

Implement the following:

  1. Interface MetricStore with fun record(key: String, value: Double) and fun read(key: String): Double?.
  2. Class InMemoryMetricStore : MetricStore using an internal HashMap<String, Double>.
  3. Class CachedMetricStore(private val store: MetricStore) : MetricStore by store:
    • Has a lazy status summary: val statusSummary: String by lazy { "MetricStore active with cache" }.
    • Overrides record to print "LOG: Recorded $key = $value" before calling store.record(key, value).
interface MetricStore { fun record(key: String, value: Double) fun read(key: String): Double? } // 1. InMemoryMetricStore // 2. CachedMetricStore with 'by store' and lazy statusSummary fun main() { val store = CachedMetricStore(InMemoryMetricStore()) println(store.statusSummary) store.record("cpu_usage", 42.5) println("CPU: ${store.read("cpu_usage")}") }
Hint 1: Interface delegationDeclare class CachedMetricStore(private val store: MetricStore) : MetricStore by store and override record(key, value) to log before calling store.record(key, value).
Hint 2: Lazy status cacheDefine val statusSummary: String by lazy { "MetricStore active with cache" }.
Exercise 2 · Refactor

Over-Inherited Base Class Anti-Pattern

Refactor this fragile base class inheritance pattern into clean interface delegation and observable.

interface Notifier { fun sendNotification(msg: String) } class StandardNotifier : Notifier { override fun sendNotification(msg: String) = println("Notification: $msg") } // REFACTOR THIS: Replace fragile inheritance with interface delegation abstract class BaseService { val notifier = StandardNotifier() fun notifyUser(m: String) = notifier.sendNotification(m) } class OrderService : BaseService() { fun completeOrder(id: String) { println("Order $id finished.") notifyUser("Your order $id is ready!") } } fun main() { val s = OrderService() s.completeOrder("ord-777") }
Hint 1: Replace inheritance with delegationDelete abstract class BaseService. Define class OrderService(private val notifier: Notifier) : Notifier by notifier.
Hint 2: Clean compositionComposition via interface delegation cleanly separates concerns without rigid superclass hierarchies.
