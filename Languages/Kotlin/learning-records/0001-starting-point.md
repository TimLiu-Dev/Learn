# Starting point: reads basic Kotlin, can't write it without AI

Learner has used Kotlin at work (mostly Android) for under 6 months. They can read and write basic code, but in practice AI writes most of it and they can't produce it themselves. Little or no Java. So the gap is **production and judgement**, not exposure: lessons should stress recall (writing from blank) and explaining *why* a construct exists, not re-explaining syntax they've already seen.

**Implications**: run a short diagnostic first to find where recall actually breaks down. Don't assume anything they "know" from reading holds up when they have to write it.
