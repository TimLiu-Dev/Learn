# Mission: Idiomatic Kotlin

## Why
At work I write Android (mostly), I'm learning Spring Boot, and I want KMP later. Right now AI writes most of my Kotlin and I can't write it myself. I want to write idiomatic Kotlin from a blank file, and to judge and fix the Kotlin that AI gives me.

## Success looks like
- Write a small feature (data model + logic) in idiomatic Kotlin with AI assistance turned off
- Read AI-generated Kotlin, point out what isn't idiomatic, and explain why
- Read teammates' code that uses scope functions, delegates and sealed types without stopping to decode it
- Pick the right construct (sealed vs enum, data class vs class, extension vs member, `let` vs `apply`) and justify the choice

## Constraints
- Under 6 months of Kotlin; little or no Java, so Java comparisons only when they really help
- Exercises run in Kotlin Playground (play.kotlinlang.org); answers get pasted back to the teacher for review
- One concept per session, with a mixed review at the end of each section
- No solutions unless I ask for them

## Out of scope (for now)
- Coroutines and Flow, Jetpack Compose, Spring Boot specifics, KMP (`expect`/`actual`): candidates for later tracks
