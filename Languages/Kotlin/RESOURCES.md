# Kotlin Resources

## Knowledge

- [Kotlin docs: Idioms](https://kotlinlang.org/docs/idioms.html)
  JetBrains' official list of idiomatic one-liners. Use for: the "is this idiomatic?" baseline in every lesson.
- [Kotlin docs: Coding conventions](https://kotlinlang.org/docs/coding-conventions.html)
  Official style and idiom guidance (expression bodies, scope functions, immutability). Use for: justifying refactor targets.
- [Kotlin docs: language reference](https://kotlinlang.org/docs/basic-syntax.html)
  Primary source per topic: [null safety](https://kotlinlang.org/docs/null-safety.html), [functions](https://kotlinlang.org/docs/functions.html), [extensions](https://kotlinlang.org/docs/extensions.html), [control flow](https://kotlinlang.org/docs/control-flow.html), [classes](https://kotlinlang.org/docs/classes.html), [data classes](https://kotlinlang.org/docs/data-classes.html), [sealed](https://kotlinlang.org/docs/sealed-classes.html), [objects](https://kotlinlang.org/docs/object-declarations.html), [enums](https://kotlinlang.org/docs/enum-classes.html), [lambdas](https://kotlinlang.org/docs/lambdas.html), [scope functions](https://kotlinlang.org/docs/scope-functions.html), [collections](https://kotlinlang.org/docs/collections-overview.html), [delegation](https://kotlinlang.org/docs/delegation.html), [delegated properties](https://kotlinlang.org/docs/delegated-properties.html). Use for: citations in every lesson.
- [Android Kotlin style guide](https://developer.android.com/kotlin/style-guide)
  Google's Kotlin style rules for Android code. Use for: Android-specific conventions.
- [Book: _Kotlin in Action_, 2nd ed. (Aigner, Elizarov, Isakova, Jemerov), Manning](https://www.manning.com/books/kotlin-in-action-second-edition)
  Written by Kotlin team members; strong on *why* features exist. Use for: deeper reading per section.
- [Book: _Effective Kotlin_ (Marcin Moskała), Kt. Academy](https://kt.academy/book/effectivekotlin)
  Best-practice items ("prefer read-only", "use sealed hierarchies"). Use for: idiom judgement and the capstone.
- [Kotlin Koans](https://kotlinlang.org/docs/koans.html)
  Official in-browser exercises. Use for: extra practice between sessions.
- [Kotlin Playground](https://play.kotlinlang.org)
  Runs Kotlin in the browser. Use for: all exercises.

## Wisdom (Communities)

- [Kotlin Slack](https://kotlinlang.org/community/) (linked from the official community page)
  Official community with #getting-started and #android channels. Use for: "is this idiomatic?" questions with real practitioners.
- [Kotlin Discussions forum](https://discuss.kotlinlang.org)
  Official, searchable forum. Use for: longer design questions.
- [r/Kotlin](https://www.reddit.com/r/Kotlin/) and [r/androiddev](https://www.reddit.com/r/androiddev/)
  Active subreddits. Use for: code review of small snippets, Android idioms.
- Workplace code review
  The most useful community available: ask reviewers to flag non-idiomatic Kotlin on PRs.
