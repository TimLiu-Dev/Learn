Idiomatic Kotlin

From reading AI-written Kotlin to writing it yourself, the idiomatic way.

One lesson per session, about 15–20 minutes each. Every lesson starts with recall from earlier lessons, explains why the syntax exists, checks you with a quiz, then has you write and refactor code. Paste your exercise answers to Claude for review.

Running the code

The code blocks are live Kotlin editors. For the Run buttons to work, start the local server from this folder:

./serve.sh → open http://localhost:8000
