Scope Functions

Quick-reference decision matrix, syntax cheat sheet, and anti-pattern guide.

1. The 2×2 Decision Matrix

Function Context Reference Return Value Is Extension? Primary Idiomatic Use Case
apply this Context object (T) Yes Object configuration (Android Views, Intents, Spring Entities)
also it Context object (T) Yes Transparent side-effects (logging, analytics, assert checks)
let it Lambda result (R) Yes Null checks (?.let) and localized transformations
run this Lambda result (R) Yes (or bare) Object configuration + computing a result
with this Lambda result (R) No: with(obj) Grouping multiple method calls on an existing object
takeIf it T? Yes Returns receiver if predicate is true, else null
takeUnless it T? Yes Returns receiver if predicate is false, else null

2. Golden Rules for Scope Functions

  1. Do NOT nest let calls. Use safe navigation (a?.b?.c?.let { ... }) or standard if (x != null) checks.
  2. Do NOT use apply when you need the computed result. Use run instead.
  3. Keep blocks short (< 5 lines). If a scope function spans an entire screen, extract it to a private helper function.
