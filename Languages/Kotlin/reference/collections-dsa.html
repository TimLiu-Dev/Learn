Collections & DSA Data Structures

Standard library operations by intent, algorithmic complexity, and unboxed primitives.

1. Collections by Intent

IntentStandard Library FunctionNotes / Big-O
Transform 1-to-1 map { ... } Allocates new list of same size
Transform & Filter nulls mapNotNull { ... } Single-pass transformation + filter
Transform 1-to-Many flatMap { ... } Maps and flattens into single list
Filter into Two Lists partition { predicate } Returns Pair<List<T>, List<T>> in 1 pass
Group into Map groupBy { keySelector } Returns Map<K, List<V>>
Index to Map (1-to-1) associateBy { it.id } Overwrites duplicates
Count Occurrences groupingBy { it }.eachCount() No intermediate list allocation
Sum / Average sumOf { it.amount } / average() Inline primitive accumulation
Sliding Window windowed(size, step) Essential for sliding window DSA problems
Fixed Batching chunked(batchSize) Divides into fixed sub-lists
