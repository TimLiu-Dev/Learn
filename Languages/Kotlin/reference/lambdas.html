Lambdas & Functional Kotlin

Compressed syntax reference: function types, member references, inlining, and lambdas with receiver.

1. Function Types & Lambda Literals

Type SignatureExample LambdaDescription
() -> Unit { println("done") } No arguments, returns nothing useful.
(Int) -> Boolean { it > 0 } Single argument, implicit it available.
(A, B) -> C { a, b -> a + b } Multiple arguments, explicit parameter names required.
T.() -> Unit { append("!") } Lambda with receiver: this points to T.

2. Member & Constructor References (::)

Reference TypeSyntaxEquivalent Lambda
Top-level function ::isPositive { isPositive(it) }
Class member function String::uppercase { it.uppercase() }
Class property Athlete::name { it.name }
Constructor ::UserId { UserId(it) }

3. inline and Return Semantics

ModifierBytecode EffectReturn Rule
inline Pastes function and lambda directly into call site. Zero heap allocation. Allows bare return to exit the enclosing outer function (non-local return).
noinline Keeps a specific lambda parameter as a normal object while inlining others. Bare return forbidden; must use qualified return@label.
crossinline Inlines the lambda, but forbids non-local returns (e.g. executed in another thread). Bare return forbidden; guarantees execution stays within local scope.
