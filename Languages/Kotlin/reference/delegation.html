2. Standard Library Property Delegates

  • val x by lazy { ... }: deferred evaluation on first read.
  • var x by Delegates.observable(initial) { prop, old, new -> ... }: notification on assignment.
  • var x by Delegates.vetoable(initial) { prop, old, new -> Boolean }: conditional assignment interception.

3. Class Delegation: class C(b: B) : B by b

Implements all methods of interface B by forwarding them to b. Selectively override only methods you wish to intercept.

Android/Compose bridge: var text by remember { mutableStateOf("") } uses MutableState's getValue/setValue operator delegates so reads and writes look like ordinary local properties.
