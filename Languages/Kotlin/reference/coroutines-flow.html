Coroutines & Flow Reference

Builders, dispatchers, structured concurrency, cold flows, and StateFlow.

1. Coroutine Builders

  • launch { ... }: Fire-and-forget; returns Job.
  • async { ... }: Computes deferred result; returns Deferred<T>; call .await().
  • runBlocking { ... }: Blocks caller thread; only for main() and tests!
