2. Fakes vs Mocks: Senior Decision Matrix

DimensionIn-Memory Fakes (Recommended Default)Mocking Libraries (MockK / Mockito)

Refactoring ResilienceHigh: tests observable state and return values. Internal private refactorings do not break tests.Low: tests are tightly coupled to exact method calls and argument matchers (verify { ... }).

3. Coroutine Testing with kotlinx-coroutines-test

// 1. Standard Coroutine Test with Virtual Time:
@Test
fun `loads user with retry delay`() = runTest {
    val fakeApi = FakeUserApi()
    val viewModel = UserViewModel(fakeApi, testScheduler)

    viewModel.loadUser()
    assertEquals(UserUiState.Loading, viewModel.uiState.value)

    advanceTimeBy(3_000) // Skips 3 seconds of delay instantly in virtual time!
    runCurrent()         // Drains tasks ready at the current virtual timestamp

    val success = assertIs<UserUiState.Success>(viewModel.uiState.value)
    assertEquals("Alice", success.user.name)
}
Test FunctionBehaviorPrimary Use Case
runTest { ... }Creates a test coroutine scope with a virtual TestCoroutineScheduler.Root wrapper for any test calling suspending functions or coroutines.
advanceTimeBy(ms)Advances the virtual clock by ms and executes all tasks scheduled in that window.Testing delays, debounce timers, animations, and timeouts without sleeping CPU threads.
runCurrent()Executes all tasks currently scheduled at the present virtual timestamp.Draining newly launched coroutines before asserting state without moving the clock.
advanceUntilIdle()Advances virtual time until no pending tasks remain in the queue.Fast-forwarding background workloads to completion.
backgroundScopeA scope whose child coroutines are automatically cancelled when the test ends.Collecting infinite hot flows (StateFlow) without hanging the test runner.

4. Testing Hot & Cold Flows with Turbine

// 2. Testing Flow with Turbine:
@Test
fun `emits loading then success`() = runTest {
    val repository = FakeOrderRepository()
    val viewModel = OrderViewModel(repository)

    // Turbine attaches a test observer:
    viewModel.uiState.test {
        assertEquals(OrderUiState.Idle, awaitItem())

        viewModel.fetchOrders()
        assertEquals(OrderUiState.Loading, awaitItem())

        val success = awaitItem() as OrderUiState.Success
        assertEquals(2, success.orders.size)

        cancelAndIgnoreRemainingEvents() // Cleanly detach
    }
}
Turbine OperatorVerification Action
awaitItem(): TSuspends until the flow emits its next item, then pops and returns it for assertion.
awaitError(): ThrowableAsserts that the flow completes with an exception and returns the error.
awaitComplete()Asserts that a cold flow terminates normally with no further emissions.
expectNoEvents()Verifies that zero emissions occurred in the observed window.
cancelAndIgnoreRemainingEvents()Unsubscribes from the flow and suppresses errors for unconsumed future events.

5. Senior Concurrency Checklist

  • Never hardcode Dispatchers.IO or Dispatchers.Default: Always inject a CoroutineDispatcher via constructor default (dispatcher: CoroutineDispatcher = Dispatchers.IO) so unit tests can supply a StandardTestDispatcher(testScheduler).
  • Never call Thread.sleep() in async tests: Use advanceTimeBy() or virtual clocks.
  • Mutate StateFlow atomically: Always use _state.update { current -> current.copy(...) } to eliminate race conditions under concurrent coroutines.
  • Never swallow CancellationException: Rethrow cancellation in suspending try/catch blocks to maintain cooperative cancellation.
