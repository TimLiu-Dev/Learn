val, var and type inference · 1.1

RuleExample
Start with val. Use var only when the value really is reassigned.val name = "Sam"
val fixes the reference, not the object. Its contents can still change.val l = mutableListOf(1); l.add(2) ✓
A val can be assigned later, once on every path. The type is then required.val zone: String
Whole numbers are Int if they fit, otherwise Long. L forces Long.3_000_000_000 → Long, 12L
Decimals are Double. f makes a Float.5.2, 72.5f
No implicit number conversions.val d: Double = 5 ✗ → 5.0
Write the type only when there's no initializer, you want another type, or it's public API.val total: Long = 0

String templates · 1.2

RuleExample
$name for a plain name; ${…} for anything else."$zone", "${w.minutes}", "${a + b}"
Trap: $ only takes the name."$zone.length" → Cardio.length
No braces around simple names, no .toString() inside templates, no + concatenation."Hi $name", not "Hi " + name
Literal $: \$ in normal strings, ${'$'} in raw strings."\$price"
Raw strings keep line breaks and run templates, but don't process escapes."""…""".trimIndent()
trimIndent() removes shared indentation. trimMargin() cuts up to | on each line.

if and try as expressions · 1.4

val zone = if (hr > 160) "Peak" else "Cardio" // no ternary: if IS the ternary return if (done) total else 0 // one return, not one per branch val minutes = try { input.toInt() } catch (e: NumberFormatException) { 0 }
  • When an if's value is used, else is required. A block's value is its last expression.
  • if (c) true else false is just c.
  • try gives the value of try or catch. finally runs but never changes the value.
  • Kotlin has no checked exceptions. throw is an expression (type Nothing), so it fits in a branch.

when · 1.5

val label = when (bpm) { // with subject in 0..<100 -> "Easy" in 100..<150 -> "Moderate" else -> "Hard" } val kind = when (type) { "run", "jog" -> "Cardio"; "lift" -> "Strength"; else -> "Other" } when { // no subject: replaces if / else-if ladders hr > max -> warn() hr < rest -> checkSensor() else -> Unit } when (val w = current()) { is Run -> w.km; else -> 0.0 } // w exists only inside
  • Only the first matching branch runs. No fall-through, no break.
  • A branch can be a value, a comma list, any expression, in / !in a range, or is Type.
  • Used as a value, it must be exhaustive. else can be dropped only for Boolean, enum or sealed subjects with every case listed.
  • Use if for two options, when for three or more.
  • Kotlin 2.2+: guard conditions, is Run if (w.km > 10) -> … (only in a when with a subject).

Equality and destructuring · 1.6

WriteMeans
a == bSame contents (calls equals). Safe with null. Never write a.equals(b).
a === bSame object in memory
Plain class vs data classPlain class == compares identity; data class compares fields.
a.contentEquals(b)Arrays: == on arrays compares identity
val (name, km) = pairCalls component1(), component2(). Position matters, not names.
"run" to 5.0Makes a Pair
val (_, km) = pairSkip a part
for ((day, km) in map)Name key and value
{ (a, b) -> } vs { a, b -> }Split one parameter vs take two parameters

Once a pair of values travels beyond one function, give it a name: a data class beats Pair.
