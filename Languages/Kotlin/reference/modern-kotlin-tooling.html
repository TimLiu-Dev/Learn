2. Production Android Flow & Concurrency Patterns

API / PatternCore IdiomCritical Trap Prevented
callbackFlow + awaitClosecallbackFlow { host.on { trySend(it) }; awaitClose { host.off() } }Always register cleanup inside awaitClose { ... } so cancellation unregisters Android SDK listeners.
stateIn(..., WhileSubscribed(5_000), init)Turns cold repository Flow into ViewModel StateFlow5s stop timeout survives screen rotation without wasting battery in background; stays at init until collected.
flatMapLatest / collectLatestqueries.debounce(300).flatMapLatest { repo.search(it) }Cancels stale in-flight network requests whenever a newer query arrives, preventing out-of-order UI races.
Mutex.withLockmutex.withLock { cached ?: fetch().also { cached = it } }Non-blocking mutual exclusion safe for suspend blocks (unlike OS synchronized). Non-reentrant: never re-lock inside the same lock.

4. kotlinx.serialization & JVM Interop Annotations

Annotation / ConfigPurposeGotcha / Rule
@Serializable + @SerialName("user_id")Compile-time JSON adapter respecting nullability & defaults (KMP-safe)Requires the kotlin-serialization compiler plugin; never silently nulls non-null fields like Gson reflection does.
Json { ignoreUnknownKeys = true; coerceInputValues = true }Resilient production JSON parser configWithout ignoreUnknownKeys = true, any new backend JSON field throws SerializationException.
@JvmOverloadsGenerates Java overloaded constructors/methods from Kotlin default argumentsAvoid blind use on custom Android View constructors with default defStyleAttr unless you verify theme attributes.
@JvmName("sumInts")Disambiguates identical JVM erased bytecode signatures (e.g. List<Int> vs List<String>)Keep extension helpers clean in Kotlin while giving Java callers distinct static method names.
@JvmStatic / @Throws(IOException::class)Exposes companion methods directly as static Java methods & declares checked exceptionsJava callers cannot catch checked IOException from Kotlin unless @Throws emits bytecode throws metadata.

5. Staff Internals: Kotlin Contracts, @PublishedApi & R8

ConstructSignature / RuleWhy It Matters in Production
callsInPlace(block, EXACTLY_ONCE)Declared inside contract { ... } on an inline higher-order functionAllows callers to initialize a local val inside your lambda (just like run or Mutex.withLock).
returns(true) implies (x != null)Declared inside contract { ... } on a boolean validatorSmart-casts x to non-null (or a checked subtype) automatically in the caller's if branch.
@PublishedApi internalApplied to internal backing properties/functions called by public inline reified APIsAllows inlined bytecode at external call sites to access internal state without polluting public IDE autocomplete.
R8 / ProGuard & @KeepUse @Serializable / KSP over reflection; add @Keep or consumer-rules.pro for JNI/reflectionR8 renames fields (userName → a) and strips unused constructors in release builds, breaking unannotated reflection.

6. Compose Compiler Runtime & Multi-Module Architecture (Lessons 13.5–13.6)

ConceptIdiom / RuleSenior Engineering Trade-Off
Strong Skipping ModeStable types compare via old == new; unstable types compare via old === newDefault in Kotlin 2.0.20+. Avoids recomposition when unstable List<T> reference is unchanged; never mutate lists in place.
rememberUpdatedStateval currentCb by rememberUpdatedState(cb) inside long-lived LaunchedEffect(Unit)Fixes the stale Kotlin closure bug where a non-restarting coroutine invokes the first composition's lambda.
snapshotFlow { ... }Bridges Compose Snapshot reads into cold Flow<T> with automatic distinctUntilChanged()Use when you need Flow operators (debounce, filter, flatMapLatest) or suspending side effects on UI state.
kotlin { explicitApi() }Requires explicit visibility (public/internal) and explicit return types on public symbolsPrevents accidental public leaks of internal classes and accidental ABI changes from inferred single-expression return types.
internal + implementation(...)Expose public interface Repo; hide internal class RepoImpl; use api(...) only for public signature typesEnforces compile-time module encapsulation and keeps incremental Gradle builds fast.
