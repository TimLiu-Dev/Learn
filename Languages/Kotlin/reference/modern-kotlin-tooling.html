2. Production Android Flow & Concurrency Patterns

API / PatternCore IdiomCritical Trap Prevented
callbackFlow + awaitClosecallbackFlow { host.on { trySend(it) }; awaitClose { host.off() } }Always register cleanup inside awaitClose { ... } so cancellation unregisters Android SDK listeners.
stateIn(..., WhileSubscribed(5_000), init)Turns cold repository Flow into ViewModel StateFlow5s stop timeout survives screen rotation without wasting battery in background; stays at init until collected.
flatMapLatest / collectLatestqueries.debounce(300).flatMapLatest { repo.search(it) }Cancels stale in-flight network requests whenever a newer query arrives, preventing out-of-order UI races.
Mutex.withLockmutex.withLock { cached ?: fetch().also { cached = it } }Non-blocking mutual exclusion safe for suspend blocks (unlike OS synchronized). Non-reentrant: never re-lock inside the same lock.

3. Gradle Kotlin DSL (build.gradle.kts) & libs.versions.toml

# gradle/libs.versions.toml
[versions]
kotlin = "2.4.0"
coroutines = "1.10.2"
serialization = "1.8.0"

[libraries]
kotlinx-coroutines-android = { group = "org.jetbrains.kotlinx", name = "kotlinx-coroutines-android", version.ref = "coroutines" }
kotlinx-serialization-json = { group = "org.jetbrains.kotlinx", name = "kotlinx-serialization-json", version.ref = "serialization" }

[bundles]
networking = ["ktor-client-core", "kotlinx-serialization-json"]

[plugins]
kotlin-serialization = { id = "org.jetbrains.kotlin.plugin.serialization", version.ref = "kotlin" }
// app/build.gradle.kts — built cleanly with receiver lambdas (T.() -> Unit)
plugins {
    alias(libs.plugins.kotlin.serialization)
}
kotlin {
    jvmToolchain(17)
}
dependencies {
    implementation(libs.kotlinx.coroutines.android)
    implementation(libs.bundles.networking)
}

4. kotlinx.serialization & JVM Interop Annotations

Annotation / ConfigPurposeGotcha / Rule
@Serializable + @SerialName("user_id")Compile-time JSON adapter respecting nullability & defaults (KMP-safe)Requires the kotlin-serialization compiler plugin; never silently nulls non-null fields like Gson reflection does.
Json { ignoreUnknownKeys = true; coerceInputValues = true }Resilient production JSON parser configWithout ignoreUnknownKeys = true, any new backend JSON field throws SerializationException.
@JvmOverloadsGenerates Java overloaded constructors/methods from Kotlin default argumentsAvoid blind use on custom Android View constructors with default defStyleAttr unless you verify theme attributes.
@JvmName("sumInts")Disambiguates identical JVM erased bytecode signatures (e.g. List<Int> vs List<String>)Keep extension helpers clean in Kotlin while giving Java callers distinct static method names.
@JvmStatic / @Throws(IOException::class)Exposes companion methods directly as static Java methods & declares checked exceptionsJava callers cannot catch checked IOException from Kotlin unless @Throws emits bytecode throws metadata.
