Generics & Variance Reference

Declaration-site variance, type constraints, reified types, and star projections.

1. Variance: out vs in

ConceptKotlin SyntaxJava EquivalentAllowed PositionsSubtyping
Covariant <out T> <? extends T> Producer (return values only) Preserved: Source<Dog> is Source<Animal>
Contravariant <in T> <? super T> Consumer (parameters only) Inverted: Sink<Animal> is Sink<Dog>
Invariant <T> <T> Both Producer and Consumer None: only exact type matches

2. Reified Generics Cheat Sheet

Allows runtime type inspection (is T, T::class) by copying bytecode to call sites:

inline fun <reified T> isType(value: Any?): Boolean = value is T
inline fun <reified T : Activity> Context.start() = startActivity(Intent(this, T::class.java))
