Functions & Extensions

Compressed syntax reference: defaults, expression bodies, extensions, and operator overloading.

1. Defaults & Named Arguments

PatternSyntaxNotes
Default parameter fun query(timeout: Int = 1000) Replaces method overloads completely.
Named argument query(timeout = 5000) Eliminates mystery boolean & integer literals at call site.
Trailing lambda fetch("users") { data -> ... } If the last parameter is a lambda, it moves outside parentheses.

2. Expression Bodies vs Statement Bodies

TypeSyntaxConvention
Single-expression fun maxHr(age: Int): Int = 220 - age Preferred for any function whose body is one expression.
Public API return type fun fetch(): UserDto = ... Always write explicit return types on public/protected APIs.
Private helper private fun isFast(p: Double) = p < 4.0 Return type can be inferred for concise private helpers.

3. Extension Functions & Properties

ConstructSyntaxUsage
Extension Function fun String.slugify(): String = ... Adds methods to third-party or library classes.
Nullable Receiver fun String?.orEmpty(): String = this ?: "" Handles nulls internally; callers don't need safe call ?..
Extension Property val Int.hours: Int get() = this * 60 Cannot have backing field (field); requires custom getter.
