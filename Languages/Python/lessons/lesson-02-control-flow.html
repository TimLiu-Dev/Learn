1. Branching, Truthiness & Guard Clauses

Beginners often nest if inside if inside if (the "arrow anti-pattern"). Senior Python engineers invert invalid checks at the top of a function using guard clauses: check the bad case, return or raise early, and keep the happy path flat at 1 level of indentation.

Complete select_model_tier(prompt, budget_cents) using clean guard clauses:

- If not isinstance(prompt, str) or prompt.strip() == "": return "invalid".
- If budget_cents < 1: return "rejected".
- If budget_cents >= 50 and len(prompt.strip()) > 100: return "reasoning".
- If budget_cents >= 10: return "standard".
- Otherwise: return "mini".

Hint 1: For Step 2, write if budget_cents < 1: return "rejected" right after the prompt check.
Hint 2: Store cleaned_len = len(prompt.strip()), check if budget_cents >= 50 and cleaned_len > 100: return "reasoning", then if budget_cents >= 10: return "standard", and finally return "mini".
Final Answer & Rationale: 
def select_model_tier(prompt, budget_cents):
    if not isinstance(prompt, str) or not prompt.strip():
        return "invalid"
    if budget_cents < 1:
        return "rejected"
    if budget_cents >= 50 and len(prompt.strip()) > 100:
        return "reasoning"
    if budget_cents >= 10:
        return "standard"
    return "mini"

Notice how every branch returns directly—no else nesting needed, and ordering >= 50 before >= 10 prevents the broader condition from shadowing the specific one.

2. Structural Pattern Matching (match / case)

Introduced in Python 3.10 (PEP 636), match / case looks like a C/Kotlin switch, but it is far more powerful: it inspects the shape, keys, and types of data and binds variables in one step. In AI backends, this shines when routing JSON events or LLM tool-call responses.

[WATCH OUT] Capture Variables vs. Constants

Writing case target: (a bare lowercase name) does not compare against a variable named target—it captures anything into a new local variable called target! Use literals ("ok", 200) or dotted names (Status.OK) to match fixed values.

[PRACTICE 2] Agent Event Dispatcher (match/case)
Solved ✓

Implement dispatch_agent_event(event) using match / case:

- {"type": "reply", "text": str(msg)} → return f"REPLY:{msg}".
- {"type": "tool", "name": str(n), "retries": int(r)} where r > 0 → return f"TOOL:{n}#{r}".
- {"type": "stop", "code": 0 | 200} → return "STOP:clean".
- Anything else (wildcard _) → return "UNKNOWN".

Hint 1: Remember bool is a subclass of int in Python—wait: in case ... "retries": int(r) if not isinstance(r, bool) and r > 0: (or r > 0 when ints are passed). Adding if not isinstance(r, bool) and r > 0 is extra safe!
Hint 2: For stop, match literal OR values: case {"type": "stop", "code": 0 | 200}: return "STOP:clean".
Final Answer & Rationale: 
def dispatch_agent_event(event):
    match event:
        case {"type": "reply", "text": str(msg)}:
            return f"REPLY:{msg}"
        case {"type": "tool", "name": str(n), "retries": int(r)} if not isinstance(r, bool) and r > 0:
            return f"TOOL:{n}#{r}"
        case {"type": "stop", "code": 0 | 200}:
            return "STOP:clean"
        case _:
            return "UNKNOWN"

Notice how match/case simultaneously validates key presence, value types (str(n), int(r)), and numeric bounds (r > 0) in 2 clean lines.

3. Pythonic Loops (enumerate, zip(..., strict=True) & for/else)

  • Iterate items directly: Prefer for item in items: instead of for i in range(len(items)):.
  • Need the index too? Use for idx, item in enumerate(items):.
  • Walking two lists together? Use zip(expected, actual, strict=True) (Python 3.10+!). Without strict=True, zip silently stops at the shorter list—hiding data bugs!
  • for ... else: The else block executes only if the loop finished normally without hitting break (think of it as nobreak:).

Solved ✓

Write score_eval_batch(expected_list, actual_list) to grade an AI model's test batch:

- Pair items using zip(expected_list, actual_list, strict=True) (so mismatched lengths raise ValueError automatically!).
- Compare exp.strip().lower() == act.strip().lower().
- Return a tuple (passed_count, failed_indices) where failed_indices is a list of 0-based indices that did not match.

Hint 1: Inside the loop, check if exp.strip().lower() == act.strip().lower():.
Hint 2: When they match, do passed += 1; otherwise do failed_indices.append(idx).
Final Answer & Rationale: 
def score_eval_batch(expected_list, actual_list):
    passed = 0
    failed_indices = []
    for idx, (exp, act) in enumerate(zip(expected_list, actual_list, strict=True)):
        if exp.strip().lower() == act.strip().lower():
            passed += 1
        else:
            failed_indices.append(idx)
    return (passed, failed_indices)

Using zip(..., strict=True) turns silent truncation bugs into an immediate ValueError.

4. Exception Engineering (try/except/else/finally & Chaining)

Python favors EAFP ("Easier to Ask for Forgiveness than Permission"): attempt the operation and catch the specific failure, rather than pre-checking every condition (LBYL) which can race or duplicate work.

  • Put only the risky line in try: and put follow-up code in else: so you don't accidentally swallow unrelated bugs!
  • Never write bare except: — it catches KeyboardInterrupt and SystemExit. Catch specific classes or Exception at top-level boundaries.
  • Chain domain errors: raise InvalidOutputError("bad JSON") from exc preserves the original root-cause traceback (`__cause__`).
  • Python 3.11+ ExceptionGroup: Lets concurrent tasks raise multiple errors together, handled selectively via except* ValueError:.

[PRACTICE 4] Resilient LLM JSON Score Extractor
Solved ✓

An LLM sometimes returns malformed JSON or out-of-range scores. Implement parse_llm_score(raw_json):

- Define class InvalidModelOutputError(ValueError): pass.
- Parse raw_json with json.loads(raw_json) inside try/except json.JSONDecodeError as exc, raising InvalidModelOutputError("Malformed JSON") from exc.
- Ensure the parsed object is a dict containing "score", and that score is an int (not bool!) between 0 and 100 inclusive; otherwise raise InvalidModelOutputError.
- Return the integer score.

Hint 1: Guard with if not isinstance(payload, dict) or "score" not in payload: raise InvalidModelOutputError("Missing score").
Hint 2: Extract score = payload["score"] and check if isinstance(score, bool) or not isinstance(score, int) or not (0 <= score <= 100): raise InvalidModelOutputError("Score out of range").
Final Answer & Rationale: 
import json

class InvalidModelOutputError(ValueError):
    pass

def parse_llm_score(raw_json):
    try:
        payload = json.loads(raw_json)
    except json.JSONDecodeError as exc:
        raise InvalidModelOutputError("Malformed JSON") from exc

    if not isinstance(payload, dict) or "score" not in payload:
        raise InvalidModelOutputError("Missing 'score' field")

    score = payload["score"]
    if isinstance(score, bool) or not isinstance(score, int) or not (0 <= score <= 100):
        raise InvalidModelOutputError(f"Invalid score value: {score!r}")

    return score

Chaining from exc preserves the exact JSON syntax error position in logs while giving callers a single clean exception type to catch or retry.
