1. Structured JSON Logging, contextvars & OpenTelemetry

Under 500 concurrent async requests, plain print("failed") lines scramble together with no idea which tenant or request failed. Production Python uses structured JSON logs (e.g., structlog) paired with contextvars.ContextVar (which propagates trace/request IDs safely across await!) and OpenTelemetry spans/metrics for LLM token cost & latency histograms.

[PRACTICE 1] Structured JSON Log Formatter with ContextVar & Secret Scrubbing
Solved ✓

Implement format_json_log(event: str, **fields) -> str reading a module-level request_id_var: ContextVar[str | None]:

- Build a dictionary containing "event": event and "request_id": request_id_var.get().
- For every key/value in fields, if key.lower() is in {"api_key", "authorization", "password", "secret"}, replace its value with "***REDACTED***"!
- Return json.dumps(record, sort_keys=True).

Hint 1: Start with record = {"event": event, "request_id": request_id_var.get()}.
Hint 2: Loop over fields.items(): record[k] = "***REDACTED***" if k.lower() in SENSITIVE_KEYS else v.
Final Answer & Rationale: 
import json
from contextvars import ContextVar

request_id_var: ContextVar[str | None] = ContextVar("request_id", default=None)
SENSITIVE_KEYS = {"api_key", "authorization", "password", "secret"}

def format_json_log(event: str, **fields) -> str:
    record: dict[str, object] = {
        "event": event,
        "request_id": request_id_var.get(),
    }
    for k, v in fields.items():
        record[k] = "***REDACTED***" if k.lower() in SENSITIVE_KEYS else v
    return json.dumps(record, sort_keys=True)

2. API Security: Constant-Time HMAC & SSRF Protection

  • Never compare secrets with ==: Standard string == exits on the first mismatched byte, leaking signature bytes via timing side-channels. Always use hmac.compare_digest(expected, provided)!
  • SSRF Defense (Crucial for AI URL-ingestion endpoints!): If users submit a URL for your backend to fetch and index into RAG, an attacker could pass http://169.254.169.254/latest/meta-data/ or http://127.0.0.1:5432/ to steal cloud credentials or probe internal services! Always validate scheme + IP ranges with urllib.parse & ipaddress.
[PRACTICE 2] Timing-Safe HMAC-SHA256 Webhook Signer & Verifier
Solved ✓

Implement two helpers:

1. sign_payload(secret: str, body: bytes) -> str: compute HMAC-SHA256 hex digest using secret.encode("utf-8") and return f"sha256={digest}".
2. verify_signature(secret: str, body: bytes, header_sig: str) -> bool: recompute expected signature and compare using hmac.compare_digest.

Hint 1: Compute digest = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest().
Hint 2: In verify_signature, check isinstance(header_sig, str) and return hmac.compare_digest(sign_payload(secret, body), header_sig).
Final Answer & Rationale: 
import hashlib, hmac

def sign_payload(secret: str, body: bytes) -> str:
    digest = hmac.new(secret.encode("utf-8"), body, hashlib.sha256).hexdigest()
    return f"sha256={digest}"

def verify_signature(secret: str, body: bytes, header_sig: str) -> bool:
    if not isinstance(header_sig, str):
        return False
    expected = sign_payload(secret, body)
    return hmac.compare_digest(expected, header_sig)
[PRACTICE 3] SSRF Guard for Document Ingestion URLs
Solved ✓

Implement is_safe_public_url(url: str) -> bool for an AI web-scraper/RAG ingestion endpoint:

- Parse with urllib.parse.urlsplit(url.strip()).
- Allow ONLY schemes "http" or "https", and require a non-empty hostname.
- Reject "localhost" or any hostname ending in ".local" / ".internal".
- If hostname parses as an IP via ipaddress.ip_address(hostname), return False unless ip.is_global is True (blocks loopback 127.0.0.1, private 10.0.0.1/192.168.1.1, link-local metadata 169.254.169.254, etc.).

Hint 1: Check if host == "localhost" or host.endswith((".local", ".internal")): return False.
Hint 2: Try ip = ipaddress.ip_address(host); if it succeeds, return ip.is_global; if ValueError (normal domain name), return True.
Final Answer & Rationale: 
import ipaddress
from urllib.parse import urlsplit

def is_safe_public_url(url: str) -> bool:
    parts = urlsplit(url.strip())
    if parts.scheme.lower() not in ("http", "https") or not parts.hostname:
        return False
    host = parts.hostname.lower()
    if host == "localhost" or host.endswith((".local", ".internal")):
        return False
    try:
        ip = ipaddress.ip_address(host)
    except ValueError:
        return True
    return ip.is_global

In production, combine this with DNS resolution checks right before opening the socket to prevent DNS rebinding!

3. Multi-Stage uv Dockerfiles & GitHub Actions CI

[PRODUCTION TEMPLATE] Slim Multi-Stage uv Dockerfile
# Stage 1: build reproducible venv from uv.lock
FROM ghcr.io/astral-sh/uv:python3.13-bookworm-slim AS builder
WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen --no-dev --no-install-project
COPY src ./src
RUN uv sync --frozen --no-dev

# Stage 2: minimal non-root runtime image
FROM python:3.13-slim-bookworm
RUN useradd --create-home appuser
USER appuser
WORKDIR /app
COPY --from=builder /app/.venv /app/.venv
COPY --from=builder /app/src /app/src
ENV PATH="/app/.venv/bin:$PATH"
CMD ["uvicorn", "docupulse.main:app", "--host", "0.0.0.0", "--port", "8000"]
