1. Type Hints, TypedDict, Literal & PEP 695 Generics

Python 3.12+ introduced clean built-in generic syntax (PEP 695): write def first[T](items: list[T]) -> T | None: instead of declaring boilerplate TypeVar("T") objects. Remember: CPython does not enforce type annotations at runtime—tools like pyright and mypy read them statically!

[PRACTICE 1] Generic Helper & TypeGuard Narrowing
Solved ✓

Write two typed helpers:

1. def pick_first[T](items: list[T]) -> T | None: returns items[0] if non-empty, else None.
2. def is_str_list(val: object) -> TypeGuard[list[str]]: returns True only if isinstance(val, list) AND every element is a str.

Hint 1: For pick_first, write return items[0] if items else None.
Hint 2: For is_str_list, write return isinstance(val, list) and all(isinstance(x, str) for x in val).
Final Answer & Rationale: 
from typing import TypeGuard

def pick_first[T](items: list[T]) -> T | None:
    return items[0] if items else None

def is_str_list(val: object) -> TypeGuard[list[str]]:
    return isinstance(val, list) and all(isinstance(x, str) for x in val)

TypeGuard[list[str]] lets static checkers like pyright narrow object to list[str] inside an if is_str_list(x): branch!

2. Any vs object, Narrowing & Exhaustiveness

Concept Static Behavior Senior Rule
Any Disables type checking; allows x.anything_at_all() without error. Avoid in public APIs; use object for unknown payloads until narrowed.
object Base of all Python types; forbids calling .strip() until checked with isinstance. Safest default for untrusted JSON dicts before validation.
assert_never(x) Static error if a Literal or Enum branch was forgotten; raises AssertionError at runtime. Put in the final else: / case _: of finite state machines.
[PRACTICE 2] Exhaustive Action Handler with assert_never
Solved ✓

Implement action_cost(kind: Literal["embed", "chat", "rerank"]) -> int:

- Return 1 for "embed", 10 for "chat", 3 for "rerank".
- In the fallback branch, call assert_never(kind) (imported from typing) so invalid runtime values raise AssertionError AND static checkers verify exhaustiveness!

Hint 1: Add case "chat": return 10 and case "rerank": return 3 above case _:.
Hint 2: Keep case _: assert_never(kind) at the bottom—if someone adds a 4th literal later, pyright flags the missing case immediately!
Final Answer & Rationale: 
from typing import Literal, assert_never

def action_cost(kind: Literal["embed", "chat", "rerank"]) -> int:
    match kind:
        case "embed":
            return 1
        case "chat":
            return 10
        case "rerank":
            return 3
        case _:
            assert_never(kind)

3. Runtime Boundary Validation & Pydantic v2

Static types vanish at runtime. When an LLM returns {"confidence": "0.95", "tags": "billing"} instead of a float and a list, Python needs a runtime validator. In 2027, Pydantic v2 is the industry standard:

[PRODUCTION PATTERN] Pydantic v2 Model for Structured LLM Output
from pydantic import BaseModel, ConfigDict, Field, field_validator

class ExtractedInvoice(BaseModel):
    model_config = ConfigDict(extra="forbid")
    vendor: str = Field(min_length=1)
    confidence: float = Field(ge=0.0, le=1.0)

    @field_validator("vendor")
    @classmethod
    def strip_vendor(cls, v: str) -> str:
        return v.strip()

# Validated directly from raw JSON bytes/str in Rust-backed pydantic-core:
invoice = ExtractedInvoice.model_validate_json('{"vendor": " Acme ", "confidence": 0.94}')
[PRACTICE 3] Build a Mini Boundary Schema Validator (Pure Python)
Solved ✓

To understand what Pydantic v2 does under the hood, implement validate_rag_query(raw_json: str) -> dict in pure Python:

- Parse raw_json with json.loads (raise ValueError on bad JSON or non-dict).
- Reject any unexpected keys outside {"query", "top_k", "min_score"} by raising ValueError (like extra="forbid").
- query (required): must be a str whose .strip() is non-empty; store the stripped string.
- top_k (optional, default 5): must be a non-bool int between 1 and 50 inclusive.
- min_score (optional, default 0.5): must be an int or float (not bool) between 0.0 and 1.0 inclusive; convert to float.
- Return the normalized dict {"query": ..., "top_k": ..., "min_score": ...}.

Hint 1: Check unknown keys cleanly with unknown = set(data.keys()) - allowed; if non-empty, raise ValueError.
Hint 2: Remember isinstance(True, int) is True, so always guard isinstance(val, bool) first when validating top_k and min_score!
Final Answer & Rationale: 
import json

def validate_rag_query(raw_json: str) -> dict:
    try:
        data = json.loads(raw_json)
    except json.JSONDecodeError as exc:
        raise ValueError("Invalid JSON") from exc
    if not isinstance(data, dict):
        raise ValueError("Payload must be a JSON object")

    allowed = {"query", "top_k", "min_score"}
    unknown = set(data.keys()) - allowed
    if unknown:
        raise ValueError(f"Unexpected fields: {sorted(unknown)}")

    query = data.get("query")
    if not isinstance(query, str) or not query.strip():
        raise ValueError("query must be a non-empty string")

    top_k = data.get("top_k", 5)
    if isinstance(top_k, bool) or not isinstance(top_k, int) or not (1 <= top_k <= 50):
        raise ValueError("top_k must be an int in [1, 50]")

    min_score = data.get("min_score", 0.5)
    if isinstance(min_score, bool) or not isinstance(min_score, (int, float)) or not (0.0 <= min_score <= 1.0):
        raise ValueError("min_score must be a float in [0.0, 1.0]")

    return {"query": query.strip(), "top_k": top_k, "min_score": float(min_score)}
