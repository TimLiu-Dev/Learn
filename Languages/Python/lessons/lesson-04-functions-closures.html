1. Parameter APIs (/, *, *args, **kwargs) & Mutable Defaults

Default argument values in Python are evaluated once when def executes—not every time you call the function! If you write def add_msg(msg, history=[]):, every call without history mutates the exact same shared list across requests (a classic user-data leak in web backends!).

[COMMON PITFALL] Always Use None as the Mutable Default Sentinel

Write def add_msg(msg: str, history: list[str] | None = None) -> list[str]: and create a fresh list inside: if history is None: history = [].

Python 3.8+ also lets library authors lock down how callers pass arguments:

Syntax Meaning Example
Before / Positional-only (cannot be passed as name=val) def embed(text, /, model="mini"):
Between / and * Standard (positional or keyword) def call(url, timeout=5.0, *, retry=True):
After * Keyword-only (prevents ambiguous boolean/numeric flags!) call("/chat", retry=False)
*args / **kwargs Captures extra positional args (tuple) / extra keyword args (dict) def log(event, *tags, **meta):

def add_prompt_tags(prompt, *, tags=None):
    result_tags = [] if tags is None else list(tags)
    if "safe" not in result_tags:
        result_tags.append("safe")
    return (prompt.strip(), result_tags)

Using None as the sentinel and copying with list(tags) guarantees total isolation across calls and callers.

def build_api_request(endpoint, /, *parts, timeout=5.0, **headers):

2. LEGB Scope Resolution & Late-Binding Closures

When Python reads a name, it searches four scopes in strict LEGB order: Local (current function) → Enclosing (outer function scopes) → Global (module level) → Built-in (len, int, etc.).

If a function assigns to a variable anywhere in its body (like count += 1), Python marks that name as local at compile time. Trying to read it before assigning raises UnboundLocalError unless you declare nonlocal count (for an enclosing function variable) or global count (for a module variable—rarely good style!).

[COMMON PITFALL] The Late-Binding Closure Loop Trap

Closures look up enclosing variables when the inner function is called, not when it is defined! In funcs = [lambda x: x + i for i in range(3)], all three lambdas share the same cell for i, which ends the loop at 2—so all three return x + 2! Fix it by capturing the current value at definition time via a default argument (lambda x, i=i: x + i) or functools.partial.

[PRACTICE 3] Closure Quota Tracker (nonlocal)
Solved ✓

Build a stateful closure factory make_quota_guard(max_tokens) that returns a function consume(tokens):

- Maintain remaining = max_tokens in the enclosing scope.
- Inside consume(tokens), use nonlocal remaining.
- If tokens <= 0: raise ValueError("tokens must be positive").
- If tokens > remaining: return (False, remaining) without changing remaining.
- Otherwise subtract tokens from remaining and return (True, remaining).

Hint 1: First check if tokens <= 0: raise ValueError("tokens must be positive").
Hint 2: Next check if tokens > remaining: return (False, remaining), then do remaining -= tokens and return (True, remaining).
Final Answer & Rationale: 
def make_quota_guard(max_tokens):
    remaining = max_tokens

    def consume(tokens):
        nonlocal remaining
        if tokens <= 0:
            raise ValueError("tokens must be positive")
        if tokens > remaining:
            return (False, remaining)
        remaining -= tokens
        return (True, remaining)

    return consume

Each call to make_quota_guard creates an independent closure cell for remaining, keeping per-user quotas cleanly encapsulated.

3. Lambdas, functools.partial & Recursion Limits

  • lambda expressions: Single-expression anonymous functions (lambda r: r["score"]). Ideal for inline sort keys like sorted(rows, key=lambda r: r["score"], reverse=True). Never assign a lambda to a variable when a def is clearer!
  • functools.partial(fn, *fixed_args, **fixed_kwargs): Pre-fills arguments on an existing function and returns a clean callable—much more readable and pickleable than nested lambdas, and avoids late-binding bugs in loops!
  • Recursion & stack limits: Python does not perform tail-call optimization and caps call depth around sys.getrecursionlimit() (default 1000) to prevent C stack crashes. Use recursion for naturally bounded trees/JSON payloads, and switch to an explicit list stack/loop if depth could exceed a few hundred levels.

2. Create extract_long_texts = partial(extract_texts, min_len=5) using functools.partial.

Hint 1: Inside both loops, call results.extend(extract_texts(item, min_len=min_len)) (passing min_len=min_len down!).
Hint 2: Define extract_long_texts = partial(extract_texts, min_len=5) right after the function.
Final Answer & Rationale: 
from functools import partial

def extract_texts(node, *, min_len=1):
    if isinstance(node, str):
        return [node] if len(node.strip()) >= min_len else []
    results = []
    if isinstance(node, (list, tuple)):
        for item in node:
            results.extend(extract_texts(item, min_len=min_len))
    elif isinstance(node, dict):
        for val in node.values():
            results.extend(extract_texts(val, min_len=min_len))
    return results

extract_long_texts = partial(extract_texts, min_len=5)

Passing keyword-only min_len=min_len through recursive calls ensures configured filters hold at every tree depth, and partial binds reusable presets cleanly.
