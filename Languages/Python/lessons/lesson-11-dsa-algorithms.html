1. Big-O in CPython, Linked Lists, Stacks & Queues

Python's list is not a linked list—it is a contiguous dynamic array of pointers. That single fact explains almost every performance surprise in Python: appending at the right end is amortized O(1), while inserting or popping at index 0 shifts every remaining pointer in memory (O(n)).

Operation list (Dynamic Array) collections.deque (Doubly Linked Blocks) set / dict (Hash Table)
Append / Pop right O(1) amortized O(1) O(1) avg (add / [k]=v)
Insert / Pop left (0) O(n) (shifts all items!) O(1) (appendleft / popleft) N/A
Index lookup a[i] O(1) O(n) (walks blocks) O(1) avg by key
Membership x in c O(n) (linear scan) O(n) O(1) avg
  • Stack (LIFO): Use a plain list with .append(x) and .pop()—both O(1).
  • Queue (FIFO): Use collections.deque with .append(x) and .popleft()—never list.pop(0)!
  • Linked Lists: Useful in interviews and LRU caches (each Node holds val and next pointer); O(1) splice if you already hold the node reference, O(n) random index access.

[PRACTICE 1] Stack Lab: Validate LLM JSON Bracket Structure
Solved ✓

Before parsing an LLM response, you want a fast O(n) bracket validator. Complete is_balanced_brackets(text) using a list as a stack:

- Only inspect bracket characters: ( ) [ ] { } (ignore letters, quotes, spaces, numbers).
- When you see an opener ((, [, {), push it onto stack.
- When you see a closer (), ], }), return False if stack is empty or the top doesn't match.
- Return True at the end only if stack is completely empty.

Hint 1: Inside if ch in openers:, write stack.append(ch). Inside elif ch in pairs:, write if not stack or stack.pop() != pairs[ch]: return False.
Hint 2: At the end of the function, return len(stack) == 0 (or not stack).
Final Answer & Rationale: 
def is_balanced_brackets(text: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    openers = set(pairs.values())
    stack = []

    for ch in text:
        if ch in openers:
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False

    return len(stack) == 0

Each character is pushed or popped at most once, giving strict O(n) time and O(n) worst-case space.

2. Heaps (heapq), Binary Search (bisect) & BSTs

When you repeatedly need the smallest/highest-priority item or the top-K results from a stream of RAG chunks, sorting the entire list every time wastes work (O(n log n)). A binary heap gives O(log n) push/pop and O(1) peek at heap[0].

  • heapq is always a min-heap: heapq.heappop(h) pops the smallest item. For a max-heap on numeric scores, push (-score, item)—or maintain a min-heap of size k to keep the top-k largest items in O(n log k) time and O(k) memory!
  • Tuple tie-breaker trap: If two pushed tuples have the same priority (1, objA) and (1, objB), Python compares objA < objB. If objects aren't comparable (like dicts), insert a monotonic counter: (priority, seq, payload).
  • bisect binary search: On a sorted list, bisect_left(arr, x) finds the leftmost insertion index in O(log n)—great for rate-limit windows or score percentile lookup.
  • Binary Search Tree (BST): Every node satisfies left.val < node.val < right.val. Balanced BSTs search in O(log n); inserting already-sorted keys creates a skewed chain (O(n)).

Solved ✓

Complete top_k_chunks(scored_chunks, k):

- Input: scored_chunks is a list of (chunk_id, score) tuples; k is a non-negative int.
- If k <= 0 or scored_chunks is empty, return [].
- Return a list of the top k chunk_id strings ordered from highest score to lowest score.
- On equal scores, break ties by alphabetically smaller chunk_id first (e.g. "a" before "b").
- Use heapq (hint: push (-score, chunk_id) into a heap, or use heapq.nsmallest(k, ...)!).

Hint 1: Create heap = [(-score, cid) for cid, score in scored_chunks] and call heapq.heapify(heap) (which runs in O(n) time!).
Hint 2: Loop for _ in range(min(k, len(heap))): _, cid = heapq.heappop(heap); result.append(cid).
Final Answer & Rationale: 
import heapq

def top_k_chunks(scored_chunks: list[tuple[str, float]], k: int) -> list[str]:
    if k <= 0 or not scored_chunks:
        return []

    heap = [(-score, cid) for cid, score in scored_chunks]
    heapq.heapify(heap)

    result = []
    for _ in range(min(k, len(heap))):
        _, cid = heapq.heappop(heap)
        result.append(cid)
    return result

heapify takes O(n) and popping k items takes O(k log n), beating full O(n log n) sorting when k << n. Negating score turns Python's min-heap into a max-heap while keeping lexicographical tie-breaking on cid.

3. Graphs (BFS, DFS, Topological Sort) & Sliding Windows

Graphs are everywhere in modern AI systems: agent execution DAGs, dependency installers (uv), and knowledge-graph retrieval. Represent graphs in Python using an adjacency dictionary: graph: dict[str, list[str]].

  • BFS (Breadth-First Search): Uses a deque + visited set. Explores level-by-level—guarantees the shortest unweighted path.
  • DFS (Depth-First Search): Uses recursion or an explicit stack list + visited set. Ideal for reachability and connected components.
  • Topological Sort (Kahn's Algorithm): Orders a Directed Acyclic Graph (DAG) so every prerequisite runs before its dependents. Track in_degree counts, enqueue all 0-indegree nodes in a deque, pop, decrement neighbors' in-degrees. If len(order) < len(nodes), a cycle exists!
  • Two-Pointers & Sliding Window: Instead of re-scanning subarrays in O(n · k), maintain two indices left and right that only move forward, giving O(n) single-pass speed.

[PRACTICE 3] AI Pipeline DAG Order (Kahn's Topological Sort)
Solved ✓

An AI workflow has named steps nodes: list[str] and directed edges edges: list[tuple[str, str]] where (u, v) means u must run before v. Implement topological_order(nodes, edges) using Kahn's algorithm:

- Build adj (mapping each node to its outgoing neighbors) and in_degree (starting at 0 for every node).
- Seed a deque with all nodes whose in_degree == 0 (in the order they appear in nodes).
- Pop from the left, append to order, and decrement each neighbor's in_degree (enqueuing when it hits 0).
- If len(order) != len(nodes), raise ValueError("Cycle detected"); otherwise return order.

Hint 1: In Step 1, write adj[u].append(v) and in_degree[v] += 1.
Hint 2: Inside while queue:, pop curr = queue.popleft(), order.append(curr), then loop for nxt in adj[curr]: in_degree[nxt] -= 1 and if in_degree[nxt] == 0: queue.append(nxt).
Final Answer & Rationale: 
from collections import deque

def topological_order(nodes: list[str], edges: list[tuple[str, str]]) -> list[str]:
    adj = {n: [] for n in nodes}
    in_degree = {n: 0 for n in nodes}

    for u, v in edges:
        adj[u].append(v)
        in_degree[v] += 1

    queue = deque([n for n in nodes if in_degree[n] == 0])
    order = []

    while queue:
        curr = queue.popleft()
        order.append(curr)
        for nxt in adj[curr]:
            in_degree[nxt] -= 1
            if in_degree[nxt] == 0:
                queue.append(nxt)

    if len(order) != len(nodes):
        raise ValueError("Cycle detected")
    return order

Kahn's algorithm runs in O(V + E) time and detects dependency cycles automatically without recursion depth limits.

[PRACTICE 4] Sliding Window: Peak Token Burst in O(n)
Solved ✓

You log token counts per minute: counts: list[int]. To spot peak rate-limit pressure, implement max_window_sum(counts, k) returning the maximum sum of any k consecutive elements:

- If k <= 0 or k > len(counts), raise ValueError.
- Compute the first window sum sum(counts[:k]), then slide the window in O(n): add the incoming right value counts[i] and subtract the outgoing left value counts[i - k].

Hint 1: Inside the loop, write window_sum += counts[i] - counts[i - k].
Hint 2: Right after updating window_sum, do if window_sum > best: best = window_sum (or best = max(best, window_sum)).
Final Answer & Rationale: 
def max_window_sum(counts: list[int], k: int) -> int:
    if k <= 0 or k > len(counts):
        raise ValueError("Invalid window size")

    window_sum = sum(counts[:k])
    best = window_sum

    for i in range(k, len(counts)):
        window_sum += counts[i] - counts[i - k]
        if window_sum > best:
            best = window_sum

    return best

Sliding the window avoids calling sum() repeatedly, reducing runtime from O(n · k) down to O(n) with O(1) extra space.

4. Sorting (Timsort / MergeSort) & @lru_cache Memory Trap

Python's built-in sorted() and list.sort() use Timsort (a hybrid of MergeSort and Insertion Sort invented by Tim Peters). It is stable (equal keys preserve their original relative order), runs in O(n log n) worst-case, and drops to O(n) on already-sorted or nearly-sorted data.

For expensive pure functions or overlapping subproblems (dynamic programming), @functools.lru_cache(maxsize=128) (or unbounded @functools.cache in Python 3.9+) memoizes return values in a hash table keyed by arguments.

[WATCH OUT] The @lru_cache Bound-Method Memory Leak

Never decorate an instance method directly with @lru_cache! Because self is the first argument to the method, the class-level cache stores a strong reference to every instance self forever—so instances are never garbage collected even after going out of scope! Fix: Put @lru_cache on a standalone helper function or @staticmethod, or use functools.cached_property for zero-arg properties.
