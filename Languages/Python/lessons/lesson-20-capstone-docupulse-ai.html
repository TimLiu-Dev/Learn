2. Build Core Engine Module 1: Overlapping Document Chunker

Before a document enters pgvector, you must split it into overlapping chunks so sentences split across boundaries retain context. A classic production bug with naive slicing loops is either an infinite loop when overlap >= max_words or repeating a short final tail chunk unnecessarily.

[EXAMPLE] Trace Sliding-Window Word Slices Before Coding
[PRACTICE P1] Implement docupulse.domain.chunking.chunk_document
Solved ✓

Complete chunk_document(text: str, max_words: int = 40, overlap: int = 10) -> list[dict[str, object]]:

- Validate inputs: raise ValueError if max_words <= 0, overlap < 0, or overlap >= max_words.
- Split text on whitespace with text.split(); if empty, return [].
- Walk with step = max_words - overlap, emitting {"chunk_index": idx, "text": " ".join(slice_words), "word_count": len(slice_words)}, breaking once start + max_words >= len(words).

Hint 1: Put if max_words <= 0 or overlap < 0 or overlap >= max_words: raise ValueError("invalid chunk params") at the top of the function, and check if not words: return [] immediately after splitting.
Hint 2: Keep start = 0 and idx = 0. Slice window = words[start : start + max_words], append the dict, check if start + max_words >= len(words): break, then increment start += step and idx += 1.
Final Answer & Rationale: 
def chunk_document(
    text: str,
    max_words: int = 40,
    overlap: int = 10,
) -> list[dict[str, object]]:
    if max_words <= 0 or overlap < 0 or overlap >= max_words:
        raise ValueError("max_words must be > 0 and 0 <= overlap < max_words")

    words = text.split()
    if not words:
        return []

    step = max_words - overlap
    chunks: list[dict[str, object]] = []
    start = 0
    idx = 0
    while start < len(words):
        window = words[start : start + max_words]
        chunks.append({
            "chunk_index": idx,
            "text": " ".join(window),
            "word_count": len(window),
        })
        if start + max_words >= len(words):
            break
        start += step
        idx += 1
    return chunks

3. Build Core Engine Module 2: Hybrid Keyword + Vector RRF Ranker

Pure semantic vector search often misses exact matches like ERR_504_UPSTREAM or invoice numbers. Pure keyword search misses paraphrased questions. Production AI backends run both in parallel and fuse their top results using Reciprocal Rank Fusion (RRF):

rrf_score(doc_id) = sum(1.0 / (k + rank))   # rank starts at 1 in each list, typical k = 60

[PRACTICE P2] Implement docupulse.domain.fusion.rrf_fuse
Solved ✓

Implement rrf_fuse(keyword_ids: list[str], vector_ids: list[str], k: int = 60, top_n: int = 5) -> list[tuple[str, float]]:

- Raise ValueError if k <= 0 or top_n < 0.
- For each ranked list (keyword_ids, then vector_ids), add 1.0 / (k + rank) using enumerate(..., start=1) into a scores dict.
- Sort descending by score, then ascending by doc_id for deterministic ties: key=lambda item: (-item[1], item[0]), and return [:top_n].

Hint 1: Loop with for ranked_list in (keyword_ids, vector_ids): and inside it run for rank, doc_id in enumerate(ranked_list, start=1): scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank).
Hint 2: Sort scores.items() via sorted(scores.items(), key=lambda item: (-item[1], item[0]))[:top_n].
Final Answer & Rationale: 
def rrf_fuse(
    keyword_ids: list[str],
    vector_ids: list[str],
    k: int = 60,
    top_n: int = 5,
) -> list[tuple[str, float]]:
    if k <= 0 or top_n < 0:
        raise ValueError("k must be > 0 and top_n >= 0")

    scores: dict[str, float] = {}
    for ranked_list in (keyword_ids, vector_ids):
        for rank, doc_id in enumerate(ranked_list, start=1):
            scores[doc_id] = scores.get(doc_id, 0.0) + (1.0 / (k + rank))

    ordered = sorted(scores.items(), key=lambda item: (-item[1], item[0]))
    return ordered[:top_n]

4. Build Core Engine Module 3: Idempotent Ingestion & Token Budgeter

Webhook deliveries and queue workers retry on timeouts. Without content-hash idempotency scoped by tenant_id and a hard token quota guard, one flaky upstream webhook can embed the same 200-page PDF fifty times and blow through your monthly AI budget.

[PRACTICE P3] Implement IngestionCoordinator
Solved ✓

Complete IngestionCoordinator.ingest(tenant_id, text, estimated_tokens) returning a dict:

- Normalize whitespace via normalized = " ".join(text.split()) and hash with hashlib.sha256(normalized.encode("utf-8")).hexdigest().
- Dedup key is (tenant_id, content_hash). If already seen in self.seen, return {"status": "duplicate", "content_hash": content_hash, "tokens_used": self.used.get(tenant_id, 0)}.
- Otherwise if current_used + estimated_tokens > self.max_tokens_per_tenant, return {"status": "budget_exceeded", ...} without charging tokens or marking seen.
- Otherwise record key, increment self.used[tenant_id], and return {"status": "accepted", ...}.

Hint 1: Check (tenant_id, content_hash) in self.seen before checking the token budget so retries still report "duplicate" even if the tenant later hit quota.
Hint 2: Read current = self.used.get(tenant_id, 0). If current + estimated_tokens > self.max_tokens_per_tenant, return early. Otherwise update self.seen.add(key) and self.used[tenant_id] = current + estimated_tokens.
Final Answer & Rationale: 
import hashlib

class IngestionCoordinator:
    def __init__(self, max_tokens_per_tenant: int) -> None:
        if max_tokens_per_tenant <= 0:
            raise ValueError("max_tokens_per_tenant must be > 0")
        self.max_tokens_per_tenant = max_tokens_per_tenant
        self.seen: set[tuple[str, str]] = set()
        self.used: dict[str, int] = {}

    def ingest(self, tenant_id: str, text: str, estimated_tokens: int) -> dict[str, object]:
        if estimated_tokens < 0:
            raise ValueError("estimated_tokens must be >= 0")

        normalized = " ".join(text.split())
        content_hash = hashlib.sha256(normalized.encode("utf-8")).hexdigest()
        key = (tenant_id, content_hash)
        current = self.used.get(tenant_id, 0)

        if key in self.seen:
            return {"status": "duplicate", "content_hash": content_hash, "tokens_used": current}

        if current + estimated_tokens > self.max_tokens_per_tenant:
            return {"status": "budget_exceeded", "content_hash": content_hash, "tokens_used": current}

        self.seen.add(key)
        self.used[tenant_id] = current + estimated_tokens
        return {
            "status": "accepted",
            "content_hash": content_hash,
            "tokens_used": self.used[tenant_id],
        }

5. Build Core Engine Module 4: Automated Golden-Dataset RAG Eval Gate

How do you prove to an interviewer that your RAG system actually works instead of just "looking good on two prompts"? You run an automated evaluation suite in CI across a labeled golden dataset tracking three signals:

  • Recall@K: Did retrieval find at least one expected_doc_id inside retrieved_ids[:k]?
  • Schema Pass Rate: Did the response include a non-empty string answer and a list of non-empty string citations?
  • Grounded Rate: Were citations non-empty and 100% present in retrieved_ids[:k] (catching fabricated doc IDs)?
[PRACTICE P4] Implement docupulse.evals.run.evaluate_rag_run
Solved ✓

Given cases: list[dict[str, object]] (each with "expected_doc_ids", "retrieved_ids", "response") and k: int = 3, return {"total": int, "recall_at_k": float, "schema_pass_rate": float, "grounded_rate": float} rounded to 4 decimals (return 0.0 for all three rates if cases is empty).

Hint 1: Use isinstance(resp, dict), isinstance(resp.get("answer"), str) and bool(resp["answer"].strip()), and isinstance(resp.get("citations"), list) and all(isinstance(c, str) and bool(c.strip()) for c in resp["citations"]) so malformed outputs never crash.
Hint 2: Convert top_k_set = set(top_k). Increment recall_hits if any(doc_id in top_k_set for doc_id in expected), and increment grounded_hits if schema passed, citations is non-empty, and set(citations).issubset(top_k_set).
Final Answer & Rationale: 
def evaluate_rag_run(cases: list[dict[str, object]], k: int = 3) -> dict[str, object]:
    if k <= 0:
        raise ValueError("k must be > 0")
    total = len(cases)
    if total == 0:
        return {"total": 0, "recall_at_k": 0.0, "schema_pass_rate": 0.0, "grounded_rate": 0.0}

    recall_hits = 0
    schema_hits = 0
    grounded_hits = 0

    for case in cases:
        expected = case.get("expected_doc_ids", [])
        top_k = list(case.get("retrieved_ids", []))[:k]
        top_k_set = set(top_k)

        if any(doc_id in top_k_set for doc_id in expected):
            recall_hits += 1

        resp = case.get("response")
        valid_schema = (
            isinstance(resp, dict)
            and isinstance(resp.get("answer"), str)
            and bool(resp["answer"].strip())
            and isinstance(resp.get("citations"), list)
            and all(isinstance(c, str) and bool(c.strip()) for c in resp["citations"])
        )
        if valid_schema:
            schema_hits += 1
            citations = resp["citations"]
            if citations and set(citations).issubset(top_k_set):
                grounded_hits += 1

    return {
        "total": total,
        "recall_at_k": round(recall_hits / total, 4),
        "schema_pass_rate": round(schema_hits / total, 4),
        "grounded_rate": round(grounded_hits / total, 4),
    }
