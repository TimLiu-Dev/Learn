# Mission: Python & AI Backend Engineer (2027)

## Why
Transition from a basic junior Android level into a job-ready Python / AI Application & Backend Engineer by 2027—building true code-writing fluency from scratch and shipping an end-to-end production AI backend project strong enough for a resume and technical interviews.

## Success looks like
- Write clean Python functions, data structures, classes, and async workflows independently from a blank editor without freezing.
- Master core Python internals, typing (`mypy`/`pyright`, `Pydantic v2`), `uv`, `ruff`, `pytest`, and `asyncio`.
- Build production AI-ready backend services using FastAPI, streaming SSE, PostgreSQL (`SQLAlchemy 2.0` + `pgvector`), Redis, structured LLM/agent orchestration, and automated evaluation suites.
- Ship a resume-grade end-to-end Capstone Project with Docker, CI/CD, observability, and strong test coverage.

## Constraints
- Current baseline: junior Android developer, basic reading ability, finds writing code from scratch difficult — lessons must build writing confidence with scaffolded steps and tight feedback loops.
- Self-paced interactive HTML curriculum running real Python in-browser (Pyodide) plus local terminal/Docker work in production phases.
- Must maintain 100% alignment with [roadmap.sh/python](https://roadmap.sh/python).

## Out of scope
- PhD-level ML research, custom CUDA kernels, or training foundation models from scratch (PyTorch research math). Focus is Python software engineering + production AI systems.
