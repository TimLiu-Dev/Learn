Functions, Closures, Scope & Functional Tools Cheat Sheet

Fast reference for parameter separators (/ and *), mutable default sentinels, LEGB scope, closures, and recursion.

1. Parameter APIs & Defaults

  • def fn(pos_only, /, normal, *args, kw_only=1, **kwargs):
  • Never use mutable defaults (items=[], cfg={})—they evaluate once at def time!
  • Use items=None and initialize inside: items = [] if items is None else list(items).

2. LEGB Scope & nonlocal

  • Lookup order: Local → Enclosing → Global → Built-in.
  • Assigning to a name inside a function makes it local; reading before assigning raises UnboundLocalError.
  • Use nonlocal count to rebind an enclosing function variable inside a closure.

3. Late-Binding Closures

  • Trap: [lambda x: x + i for i in range(3)] binds i lazily—all functions use the final i=2.
  • Fix 1: Capture value at definition time: [lambda x, i=i: x + i for i in range(3)].
  • Fix 2: Use functools.partial or a helper factory function.

4. Lambdas, partial & Recursion

  • lambda is for short single-expression callbacks (e.g. sorted(items, key=lambda x: x["score"])).
  • functools.partial(fn, fixed_arg) pre-binds arguments cleanly without wrapper boilerplate.
  • No tail-call optimization in CPython; sys.getrecursionlimit() defaults to 1000. Use explicit stacks for deep graphs.
