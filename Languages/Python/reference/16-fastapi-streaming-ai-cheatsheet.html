Web APIs, FastAPI, SSE & AI Backends Cheat Sheet

Production patterns for ASGI concurrency, FastAPI contracts, cursor pagination, and real-time LLM token streaming.

1. WSGI vs. ASGI & Framework Fit

  • WSGI: app(environ, start_response) — sync thread-per-request (Flask, classic Django).
  • ASGI: async def app(scope, receive, send) — event-loop concurrency (FastAPI, Starlette).
  • Event loop rule: Never call blocking I/O (requests, time.sleep) inside async def; use httpx.AsyncClient or plain def.
  • Pick FastAPI for AI APIs/SSE/OpenAPI · Django for ORM+Admin monoliths · Flask for tiny sync services.

2. FastAPI Production Patterns

  • Split endpoints with APIRouter(prefix="/v1/...", tags=[...]).
  • Inject auth, DB sessions, and limiters via Annotated[T, Depends(...)] for easy test overrides.
  • Always set response_model=... so internal fields (secrets, hashes) are stripped before serialization.
  • Use cursor pagination (where id > cursor limit N+1) instead of OFFSET to prevent drift and O(N) scans.

3. Server-Sent Events (SSE) Wire Format

  • Headers: Content-Type: text/event-stream, Cache-Control: no-cache, X-Accel-Buffering: no.
  • Frame format: optional id: 1 + event: token + data: {"delta":"hi"} + blank line \n\n.
  • Serialize payloads as single-line JSON so newlines inside LLM text never split an SSE frame prematurely.

4. Structured LLM & Tool Contracts

  • Generate JSON Schemas from Pydantic v2 models for reliable structured extraction.
  • Treat tool calls as untrusted input: validate envelope types, enforce an explicit tool allowlist, and return structured 4xx error payloads so agents can self-correct.
