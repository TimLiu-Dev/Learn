Control Flow, Pattern Matching & Exceptions Cheat Sheet

Fast reference for guard clauses, Python 3.10+ match/case, Pythonic loops, and production exception handling.

1. Guard Clauses & Ternary

  • Validate failure cases at the top and return / raise early to avoid nested pyramids.
  • Ternary expression: label = "high" if score >= 80 else "low".
  • Remember Lesson 01: for None defaults when 0 is valid, use x if x is not None else default.

2. Structural Pattern Matching (match/case)

  • Dict patterns match keys as a subset (extra keys are ignored unless captured with **rest).
  • Type + value capture: case {"tool": str(name), "limit": int(n)} if n > 0:
  • OR pattern: case 401 | 403: · Wildcard fallback: case _:
  • Trap: bare name case status: captures anything! Use dotted names like Status.OK for constants.

3. Pythonic Loops

  • Index + item: for idx, item in enumerate(items, start=0):
  • Parallel lists: for a, b in zip(xs, ys, strict=True): (raises ValueError on length mismatch).
  • for ... else: the else block runs only if the loop finished without hitting break.
  • Never mutate a list while iterating over it—iterate over a copy or build a new list.

4. Exception Engineering

  • try: risky operation only · except Err as e: handle specific error.
  • else: runs only when try succeeded (keeps catch scope narrow).
  • finally: always runs (cleanup), even on return/exception.
  • Never write bare except: (catches KeyboardInterrupt / SystemExit); catch Exception at boundaries.
  • Chain errors cleanly: raise DomainError("bad payload") from exc.
