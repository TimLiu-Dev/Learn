Python Foundations, Bindings & Primitives Cheat Sheet

Keep this open for fast review of Python's execution pipeline, object identity, precision rules, truthiness, and f-string formatting.

1. Execution & Type System

  • Pipeline: Source → AST → Bytecode (.pyc) → CPython Stack VM.
  • Inspect bytecode: import dis; dis.dis(fn).
  • Typing: Dynamic (names have no fixed type) + Strong (no implicit "5" + 3).
  • SyntaxError fails at compile time; TypeError fails at runtime when reached.

2. Names, Identity & Equality

  • Variables are name bindings to heap PyObjects, not memory boxes.
  • a == b checks value equality (__eq__).
  • a is b checks memory identity (id(a) == id(b)).
  • Use is None / is not None; never use is for numbers or strings.
  • a += [3] mutates lists in place; a = a + [3] rebinds a to a new list.

3. Numbers & Operator Traps

  • int: arbitrary precision. bool is a subclass of int (check bool before int).
  • float: IEEE-754 binary (0.1 + 0.2 != 0.3); compare via math.isclose().
  • Money: Use Decimal("0.10") from strings, never Decimal(0.1).
  • Floor div: // rounds toward −∞ (-7 // 2 == -4, -7 % 2 == 1).
  • Precedence: ** binds tighter than unary - (-3 ** 2 == -9).

4. Truthiness & Short-Circuiting

  • Falsy: False, None, 0, 0.0, "", [], (), {}, set(), range(0).
  • Trap: bool("false") is True! Non-empty strings are always truthy.
  • a or b returns the deciding operand, not necessarily a bool.
  • When 0 or "" is valid, write default if val is None else val (not val or default).
