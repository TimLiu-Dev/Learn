OOP, Protocols, Enums & Data Containers Cheat Sheet

Fast reference for dunder methods, @dataclass, StrEnum, C3 MRO, Protocol vs. ABC, and container selection.

1. Data Model & @dataclass

  • Custom __eq__ sets __hash__ = None unless you define __hash__ too (invariant: a == b ⇒ hash(a) == hash(b)).
  • @dataclass(frozen=True, slots=True): auto __init__, __repr__, __eq__, __hash__, immutability, and no __dict__!
  • Use field(default_factory=list) for mutable defaults and __post_init__ for validation.
  • StrEnum (3.11+): members equal raw strings and serialize cleanly to JSON.

2. C3 MRO & Composition

  • Inspect resolution order with ClassName.__mro__.
  • super() calls the next class in type(self).__mro__, enabling cooperative mixins.
  • Prefer composition (RagService(retriever=...)) over deep inheritance trees for easy testing and swapping.

3. typing.Protocol vs. abc.ABC

  • Protocol (structural): any class with matching methods satisfies the contract without inheriting. Add @runtime_checkable for isinstance().
  • abc.ABC (nominal): subclasses must inherit explicitly and implement every @abstractmethod.

4. Container Decision Guide

  • NamedTuple: tiny immutable unpackable rows (tuple subclass).
  • @dataclass(slots=True): internal domain objects & hashable keys.
  • TypedDict: static typing over existing plain dict JSON objects.
  • Pydantic BaseModel: runtime validation & coercion at untrusted API / LLM boundaries.
