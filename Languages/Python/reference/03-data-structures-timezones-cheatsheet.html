Data Structures, Hash Internals & Timezones Cheat Sheet

Fast reference for Big-O container tradeoffs, hashability rules, deep copying, collections, and UTC-first datetime.

1. Sequences & Big-O Complexity

  • list: dynamic pointer array. items[i] & .append() are O(1); insert(0, x), pop(0), and x in items are O(n).
  • tuple: fixed-size immutable sequence; hashable if all nested elements are hashable.
  • Use collections.deque when you need O(1) pops from both ends (queues/sliding windows).

2. Compact dict & set Hash Tables

  • Lookup & membership (k in d, x in s) are O(1) average.
  • Python 3.7+ dict preserves insertion order.
  • Hashable keys: str, int, tuple of hashables, frozenset. Mutable list/dict/set raise TypeError.
  • Safe read: cfg.get("model", "default") avoids KeyError.

3. Copying & collections

  • b = a is an alias · a.copy() / a[:] is a shallow copy (nested mutables stay shared!).
  • Use copy.deepcopy(a) before mutating nested dicts/lists.
  • Avoid [[0] * 3] * 3; use [[0] * 3 for _ in range(3)].
  • defaultdict(list) groups cleanly; Counter(seq).most_common(k) counts frequencies.

4. UTC-First datetime & zoneinfo

  • Current UTC: datetime.now(timezone.utc) (never deprecated utcnow()).
  • Parse ISO-8601 (including "Z"): datetime.fromisoformat(s).
  • Label naive clock: dt.replace(tzinfo=timezone.utc) · Convert aware instant: dt.astimezone(ZoneInfo("America/New_York")).
  • In minimal Docker/WASM containers, add tzdata for IANA zone keys.
