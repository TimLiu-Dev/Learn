Observability, Security, Docker & CI/CD Cheat Sheet

Production checklist for structured logs, OpenTelemetry traces, HMAC/SSRF security, multi-stage uv Docker builds, and CI gates.

1. Structured Logging & Traces

  • Emit single-line JSON logs (structlog), never messy print() strings.
  • Store request_id / tenant_id in contextvars.ContextVar so async tasks keep trace correlation.
  • Always scrub secrets (authorization, api_key, password) before logging.

2. AppSec Non-Negotiables

  • Compare HMAC signatures and API tokens with hmac.compare_digest() (constant time).
  • Store API keys/passwords hashed (Argon2 / SHA-256 with high-entropy prefix for lookup), never plaintext.
  • Block SSRF: allow only https/http and reject loopback, private, link-local (169.254.169.254), and reserved IPs.

3. Multi-Stage uv Dockerfiles

  • Install dependencies with uv sync --frozen --no-dev so builds match uv.lock byte-for-byte.
  • Copy only the .venv + src/ into a slim runtime image, and run as a non-root user.

4. Automated CI Quality Gates

  • 1. uv run ruff check . & uv run ruff format --check .
  • 2. uv run pyright (strict type check)
  • 3. uv run pytest --cov=src
