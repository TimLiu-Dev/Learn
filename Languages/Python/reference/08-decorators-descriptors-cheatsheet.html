Decorators, Descriptors & Class Hooks Cheat Sheet

Fast reference for function/class decorators, @functools.wraps, the Descriptor Protocol, @property internals, and __init_subclass__.

1. Function Decorators

  • @dec above def f(): means f = dec(f).
  • Always place @functools.wraps(func) on wrapper to keep __name__, __doc__, and signatures.
  • Forward arguments generally with def wrapper(*args, **kwargs):.

2. Parameterized & Class Decorators

  • 3-layer pattern: factory(cfg) → decorator(func) → wrapper(*args, **kwargs).
  • Class decorator: receives cls, attaches metadata or registers cls, and returns cls.
  • Re-raise original traceback cleanly with bare raise inside except.

3. Descriptor Protocol & @property

  • __set_name__(self, owner, name) captures the attribute name automatically.
  • __get__(self, instance, owner): return self when instance is None.
  • __set__(self, instance, value): validate & store in instance.__dict__[self.name] (never on self!).
  • Built-in @property is a standard C data descriptor implementing __get__/__set__.

4. __init_subclass__ vs. Metaclasses

  • Use __init_subclass__(cls, **kwargs) for plugin registries & subclass validation at definition time.
  • Always call super().__init_subclass__(**kwargs) inside __init_subclass__.
  • Avoid custom metaclasses (class Meta(type)) unless you need __prepare__ or framework-level type.__new__.
