File I/O, Bytes, Context Managers & Regex Cheat Sheet

Fast reference for pathlib.Path, streaming JSON/CSV/tomllib, UTF-8 bytes, @contextmanager, and safe re.

1. pathlib.Path & Streaming Formats

  • Join paths: p = Path("/tmp") / "logs" / "app.jsonl"; create dirs: p.parent.mkdir(parents=True, exist_ok=True).
  • Always pass encoding="utf-8" for text files; stream line-by-line (for line in f:) instead of .read().
  • tomllib.load(f) requires binary mode "rb"; io.StringIO streams in-memory text in tests.

2. bytes, bytearray & memoryview

  • text.encode("utf-8") → bytes · raw.decode("utf-8") → str.
  • Multi-byte chars: len("🚀".encode("utf-8")) == 4. Safe byte truncate: raw[:n].decode("utf-8", errors="ignore").
  • bytearray is mutable; memoryview(buf)[a:b] slices buffers with zero copy.

3. Custom Context Managers

  • Class style: implement __enter__ and __exit__(self, exc_type, exc_val, exc_tb); return False to propagate errors.
  • Decorator style: @contextmanager + try: yield resource + finally: cleanup().
  • Never omit try/finally in @contextmanager—exceptions throw into yield!

4. Regex (re) & ReDoS Safety

  • Always use raw strings (r"..."), pre-compile with re.compile, and use named groups (?P<name>...).
  • re.fullmatch matches the whole string; re.match only anchors the start!
  • ReDoS prevention: avoid nested quantifiers like (a+)+; use disjoint character classes.
