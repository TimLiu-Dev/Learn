DocuPulse AI — Production RAG Backend Cheat Sheet

Senior 2027 reference covering service boundaries, overlapping chunking, hybrid Reciprocal Rank Fusion (RRF), idempotent ingestion, RAG evals, and resume defense points.

1. Clean Package Layout (src/docupulse/)

  • api/: FastAPI routers, dependency injection (Depends), SSE streaming, auth & rate limits.
  • domain/: Pure Python chunking, RRF fusion, prompt assembly, token budgets (0 DB/HTTP imports).
  • infra/: SQLAlchemy 2.0 Async + pgvector, Redis idempotency cache, OpenAI/Anthropic async SDK wrappers.
  • evals/: Golden-dataset runner computing Recall@K, grounded citation check, and Pydantic schema pass rate.

2. Hybrid Retrieval & RRF Formula

  • Why hybrid? Dense vectors catch synonyms; lexical keyword search catches exact error codes, SKUs, and IDs.
  • Reciprocal Rank Fusion merges ranked lists without calibrating raw cosine vs BM25 scores:
  • score(d) = sum(1 / (k + rank_i(d))) (standard constant k = 60, 1-based rank).
  • Always filter by tenant_id in SQL before ranking/merging to prevent cross-tenant leaks.

3. Idempotency & Cost Controls

  • Compute sha256 of normalized document bytes + tenant_id so webhook retries never pay twice for embeddings.
  • Wrap external LLM/embedding calls in an asyncio.Semaphore(N) + exponential backoff with jitter + hard timeout.
  • Enforce per-tenant daily token budgets atomically in Redis (INCRBY / Lua check) before calling paid models.

4. Eval & CI Release Gates

  • 1. uv run ruff check . && uv run ruff format --check .
  • 2. uv run pyright (strict typing across domain + schemas)
  • 3. uv run pytest -q (unit tests for pure domain + TestClient API contract tests)
  • 4. uv run python -m docupulse.evals.run (block prompt/chunker changes if Recall@K drops).
