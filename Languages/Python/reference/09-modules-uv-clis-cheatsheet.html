Modules, Packages, uv & CLIs Cheat Sheet

Fast reference for src/ layout, import resolution, circular import fixes, pyproject.toml, uv, and CLIs.

1. Import Resolution & src/ Layout

  • Order: sys.modules cache → sys.path (script dir / CWD → site-packages).
  • src/my_pkg/__init__.py prevents pytest from accidentally importing un-installed local dirs.
  • Prefer explicit absolute imports (from my_pkg.core import x) across subpackages.

2. Fixing Circular Imports

  • Extract shared types into a lower-layer models.py (keep dependency graph a DAG).
  • Type-only imports: wrap inside if TYPE_CHECKING: + string/postponed annotations.
  • Lazy import: move the import inside the function that uses it.

3. uv & PEP 621 pyproject.toml

  • uv init, uv add pkg, uv add --dev pytest, uv run cmd.
  • CI/Docker: uv sync --frozen installs exact locked versions from uv.lock.
  • Monorepos: [tool.uv.workspace] with members = ["packages/*", "apps/*"].
  • Parse TOML cleanly with stdlib tomllib.loads(...) (Python 3.11+).

4. Shippable CLIs

  • Expose CLI via [project.scripts]: ragctl = "rag_app.cli:main".
  • Stdlib argparse: add_subparsers(dest="command", required=True) + type=int.
  • Pass argv=None into main(argv=None) so tests call parse_args([...]) directly.
  • Production upgrade: Typer (type-hint CLIs) + Rich (tables, progress, color).
