Asyncio, Structured Concurrency & Backpressure

Essential patterns for high-concurrency LLM/API backends using event loops, TaskGroup, semaphores, and bounded queues.

1. Event Loop Golden Rule

  • All coroutines run on one thread cooperatively, yielding only at await.
  • Never block the loop: No time.sleep(), no requests.get(), no heavy CPU loops inside async def.
  • Use httpx.AsyncClient / aiohttp, or offload sync code via await asyncio.to_thread(fn).

2. Structured Concurrency (TaskGroup)

  • async with asyncio.TaskGroup() as tg: awaits all spawned tasks before exiting.
  • If one task raises, sibling tasks are automatically cancelled and errors surface as an ExceptionGroup.
  • Safer than bare asyncio.create_task() (which can leak orphan background tasks silently).

3. Timeouts & Cancellation

  • Use async with asyncio.timeout(5.0): (Python 3.11+) or await asyncio.wait_for(coro, 5.0).
  • Never swallow asyncio.CancelledError! If you catch it for cleanup, always re-raise it.

4. Backpressure Primitives

  • sem = asyncio.Semaphore(10) caps simultaneous in-flight LLM/DB calls.
  • q = asyncio.Queue(maxsize=100) slows fast producers when workers fall behind, preventing OOM crashes.
