# Teaching Notes & User Preferences

- **Learner Baseline (ZPD):** Junior Android developer at a basic level; can barely read Kotlin and finds writing code from scratch hard. Never assume prior OOP/Kotlin/Java fluency. Emphasize small, scaffolded coding wins, clear starter stubs, and building **writing fluency** step by step before heavy abstractions.
- **Target 2027 Role Focus:** AI Application / AI Backend Engineer (Python + FastAPI + Pydantic v2 + Async + Postgres/pgvector + Redis + LLM/Agent Orchestration + Evals + Observability/Docker/CI).
- **Required Lesson Format (every lesson):**
  - Clear mental-model explanations + primary-source citations.
  - Live runnable code examples inside the HTML (Pyodide).
  - Auto-graded coding practice inside the HTML with progressive hints AND final answer + explanation.
  - Multiple-choice quizzes with balanced option lengths and full explanations for BOTH why the right answer is correct and why every wrong option is wrong.
- **Benchmarking:** Lesson 01 (`lessons/lesson-01-python-foundations.html`) is the structural benchmark; future lessons (02+) should open with a **Spaced Review** warm-up and keep practice difficulty smoothly ramped for someone building writing fluency.
