# Junior Android Baseline & 2027 AI Role Interest

Status: active

The learner is a junior Android developer at a basic level who can barely read Kotlin and finds writing code from scratch very hard. They want to aim toward an AI-focused Python role for 2027.

## Evidence
- User stated directly: "i am a junior android developer who barely reads kotlin but unabel to write kotlin or very hard and is as a basic level, what is a role focus for 2027? i think AI"

## Implications
- **Zone of Proximal Development:** Start from basic first principles for code *writing* — provide clear function skeletons, small single-concept steps, and frequent automated feedback so writing fluency builds steadily without cognitive overload.
- **No Assumed OOP/JVM Fluency:** Do not lean on Kotlin/Java analogies as shortcuts; teach Python's object model and syntax cleanly on its own terms.
- **Curriculum Alignment:** Core Python (Phases 1–4) remains identical and mandatory; Phase 5 and the Capstone should emphasize **AI Application / AI Backend Engineering** (FastAPI, Pydantic structured outputs, async LLM/tool-calling orchestration, `pgvector`/RAG, and automated evals) rather than generic CRUD or PhD-level model training.
