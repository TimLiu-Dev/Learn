Dynamic Programming Mastery: 1D/2D States, Knapsack, LIS & Space Rolling

Master 1D/2D dynamic programming, space-rolling optimizations, and O(N log N) patience sorting.

1. The Dynamic Programming Paradigm: Overlapping Subproblems

Dynamic Programming solves optimization problems by breaking them down into simpler subproblems. While naive recursion results in exponential O(2^N) time due to repeated computation, DP memoizes or tabulates states to achieve polynomial runtime: 

// ANTI-PATTERN: Exponential naive recursion without memoization
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2); // O(2^N) CPU disaster! 2^50 operations!
}

2. Under the Hood: Space Rolling (1D and 2D Compression)

When evaluating transition dp[i] = f(dp[i-1], dp[i-2]), storing the full array is wasteful. Compressing state to 2 rolling variables reduces memory from O(N) to O(1). In 0/1 Knapsack, iterating capacity backwards allows compressing a 2D table into a single 1D array: 

// UNDER THE HOOD: 0/1 Knapsack 1D Reverse Iterate
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    // REVERSE LOOP prevents using the same item multiple times in the same pass!
    for (int w = W; w >= weights[i]; w--) {
        dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
    }
}

3. Longest Increasing Subsequence: O(N log N) Patience Sorting

While classic DP for LIS takes O(N^2), senior systems use Patience Sorting with Binary Search to find LIS length in O(N log N): 

// IDIOMATIC JAVA 21: O(N log N) LIS via binary search
int[] tails = new int[nums.length];
int len = 0;
for (int x : nums) {
    int i = Arrays.binarySearch(tails, 0, len, x);
    if (i < 0) i = -(i + 1);
    tails[i] = x;
    if (i == len) len++;
}
return len;
