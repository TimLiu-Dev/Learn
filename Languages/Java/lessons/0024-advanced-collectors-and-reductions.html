Advanced Collectors, Downstream Grouping, teeing() & Reductions

Master the Collector interface, multi-level groupingBy, Collectors.toMap merge rules, and Java 12+ Collectors.teeing().

1. The Collector<T, A, R> Architecture

Under the hood, a stream reduction into a mutable container is defined by the Collector interface with five components:

  • Supplier<A>: Allocates the mutable result container (e.g., ArrayList::new).
  • BiConsumer<A, T>: Accumulates an input element into the container (e.g., List::add).
  • BinaryOperator<A>: Combines two partial containers during parallel evaluation.
  • Function<A, R>: Performs final transformation from accumulator to result (e.g., unmodifiable wrapper).
  • Characteristics: Flags like IDENTITY_FINISH, CONCURRENT, UNORDERED.
// ANTI-PATTERN: Collecting to map without duplicate key resolution
Map<String, User> map = users.stream()
    .collect(Collectors.toMap(User::email, u -> u)); // CRASH on duplicate email!
    // Throws: IllegalStateException: Duplicate key user@domain.com!

2. Multi-Level Grouping & Downstream Collectors

Collectors.groupingBy supports hierarchical categorization by combining classification functions with downstream collectors: 

// IDIOMATIC JAVA 21: Multi-level grouping with downstream mapping and counting
Map<Department, Map<Role, Long>> staffCount = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::department,
        Collectors.groupingBy(Employee::role, Collectors.counting())
    ));

3. Java 12+ Single-Pass Dual Reductions with Collectors.teeing()

Historically, computing average without storing all items required running two passes over data. Collectors.teeing() splits a single stream into two downstream collectors and merges results: 

// IDIOMATIC JAVA 21: Single-pass average calculation via teeing()
public record Stats(long sum, long count) {
    public double average() { return count == 0 ? 0.0 : (double) sum / count; }
}

Stats stats = orders.stream()
    .collect(Collectors.teeing(
        Collectors.summingLong(Order::amountCents),
        Collectors.counting(),
        Stats::new // Merges sum and count in a single pass!
    ));
