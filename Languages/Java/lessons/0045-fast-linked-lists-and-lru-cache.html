Fast/Slow Linked List Manipulation & Custom O(1) LRU Cache

Master Fast & Slow pointers, in-place linked list reversal, and custom O(1) LRU Cache architecture.

1. Fast & Slow Pointers (Floyd's Cycle Detection)

The Tortoise and Hare algorithm detects cycles in linked lists without auxiliary memory. A slow pointer advances 1 step while a fast pointer advances 2 steps. If a cycle exists, they must meet: 

// ANTI-PATTERN: Using a HashSet to detect cycles (O(N) memory overhead)
Set<ListNode> visited = new HashSet<>();
while (head != null) {
    if (!visited.add(head)) return true; // O(N) memory waste!
    head = head.next;
}

// IDIOMATIC JAVA 21: Floyd's Tortoise and Hare (O(1) memory)
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) return true; // Cycle detected in O(1) space!
}

2. Under the Hood: In-Place Singly Linked List Reversal

Reversing a linked list in-place requires three pointers (prev, curr, next) to rewire pointers without allocating new nodes: 

// UNDER THE HOOD: 3-pointer in-place reversal
ListNode prev = null, curr = head;
while (curr != null) {
    ListNode next = curr.next; // 1. Save forward pointer
    curr.next = prev;          // 2. Reverse link
    prev = curr;               // 3. Step prev forward
    curr = next;               // 4. Step curr forward
}
return prev; // New head of reversed list!

3. Enterprise Architecture: Custom O(1) LRU Cache

Building a production Least Recently Used (LRU) Cache combines a HashMap<K, Node> for O(1) key lookup with a Doubly Linked List with sentinel head and tail dummy nodes for O(1) node splicing: 

// IDIOMATIC JAVA 21: Doubly Linked List Sentinel Splicing
class Node { int key, val; Node prev, next; }
// Sentinel dummy nodes eliminate null-check edge cases!
head.next = tail;
tail.prev = head;

void removeNode(Node n) {
    n.prev.next = n.next;
    n.next.prev = n.prev;
}
void addToHead(Node n) {
    n.next = head.next;
    n.prev = head;
    head.next.prev = n;
    head.next = n;
}
