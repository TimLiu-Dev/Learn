Phase 1 • Documentation & Logging • Lesson 0080

Markdown Javadoc (JEP 467) & Production Logging (SLF4J, Logback, System.Logger)

Document public APIs cleanly with Java 25 Markdown /// Javadoc comments, separate logging facades from backends, and prevent hot-path string allocation and CRLF log injection.

1. Classic Javadoc (/** */) vs. Java 25 Markdown Javadoc (///, JEP 467)

Writing HTML tags (<p>, <ul>, {@code ...}) inside traditional /** ... */ Javadoc breaks readability in editors. Starting cleanly in JDK 23 and Java 25 LTS (**JEP 467**), triple-slash **///** doc comments parse standard CommonMark Markdown natively in javadoc: 

/// Calculates an invoice subtotal with explicit rounding precision.
///
/// - Rejects negative amounts early via [IllegalArgumentException]
/// - Preserves audit trail fields without floating-point drift
///
/// @param unitCents item price in minor currency units (`>= 0`)
/// @return formatted receipt summary
/// @throws IllegalArgumentException if `unitCents` is negative
public static String summarize(long unitCents) { ... }

Notice how inline backticks (unitCents), bullet lists (-), and bracket cross-references ([IllegalArgumentException], [java.math.BigDecimal#setScale]) replace verbose {@link ...} and <li> noise completely while still supporting @param, @return, and @throws block tags.

2. Logging Facade Architecture (SLF4J & System.Logger) vs. Production Traps

Production libraries never hardcode System.out.println(...) (unbuffered global lock contention, zero log levels, unroutable) and never bind directly to a concrete log writer (Logback or Log4j2). Instead:

Facade (Library API)Minimal interface compiled against your code; decouples log call sitesSLF4J 2.x (Spring default), JDK System.Logger (java.lang)
Implementation (Backend)Formats JSON/pattern lines, rolls files, filters async appendersLogback (Spring Boot default), Log4j2 (LMAX Disruptor async)
 
// ANTI-PATTERN: Uncontrolled concatenation, debug waste & CRLF log injection!
log.debug("Payload dump: " + serializeHugeOrderJson(order)); // Serializes JSON EVEN WHEN DEBUG IS OFF!
log.info("Login failed for user=" + rawUsername);          // Unsanitized \n injects fake log lines!

// IDIOMATIC SLF4J 2.x (Spring Boot): Parameterized + Fluent Key-Value / Supplier
log.debug("Order processed id={} items={}", orderId, itemCount);
log.atDebug()
   .addKeyValue("orderId", orderId)
   .setMessage("Deep payload trace")
   .addArgument(() -> sanitize(rawInput)) // Deferred Supplier only evaluated if DEBUG active!
   .log();

// IDIOMATIC JDK BUILT-IN (zero external JARs!): System.Logger
private static final System.Logger LOG = System.getLogger(OrderService.class.getName());
LOG.log(System.Logger.Level.DEBUG, () -> "Lazy trace order=" + orderId);
