Apache Kafka Internals: KRaft, ISR/acks=all, Idempotent Producers & Cooperative Rebalancing

Master Apache Kafka KRaft architecture, zero-copy I/O, idempotent producers, and cooperative rebalancing.

1. Apache Kafka Architecture: KRaft, Log Segments & Zero-Copy

Modern Kafka operates with KRaft (Kafka Raft Metadata mode), eliminating ZooKeeper dependencies. Data is written to immutable, append-only log segments on disk. Broker reads bypass JVM user-space memory entirely using the Linux sendfile system call (Zero-Copy), streaming OS page cache pages directly to network sockets: 

// UNDER THE HOOD: Zero-Copy sendfile data transfer
// Disk File -> OS Page Cache -> (Bypasses JVM Heap!) -> Network Socket Buffer -> NIC

2. Production Producer Durability: acks=all & Idempotence

Guaranteeing zero data loss under broker failure requires setting acks=all (acks=-1) in combination with broker-side min.insync.replicas=2. Modern producers enable enable.idempotence=true by default, attaching a Producer ID (PID) and monotonically increasing sequence number to prevent duplicate records during network retries: 

// IDIOMATIC JAVA 21: High-durability idempotent producer settings
Properties props = new Properties();
props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "kafka:9092");
props.put(ProducerConfig.ACKS_CONFIG, "all"); // Waits for all ISR replicas
props.put(ProducerConfig.ENABLE_IDEMPOTENCE_CONFIG, "true"); // De-duplicates retries
props.put(ProducerConfig.RETRIES_CONFIG, Integer.MAX_VALUE);

3. Cooperative Sticky Rebalancing

Historically, when a consumer joined or left a group, the Eager Rebalance protocol revoked all partitions from all consumers, freezing message consumption across the entire group. Cooperative Sticky Rebalancing revokes only the specific partitions being migrated, allowing uninterrupted consumption on all unaffected partitions: 

// IDIOMATIC JAVA 21: Non-stop consumer rebalancing
props.put(
    ConsumerConfig.PARTITION_ASSIGNMENT_STRATEGY_CONFIG,
    "org.apache.kafka.clients.consumer.CooperativeStickyAssignor"
);
