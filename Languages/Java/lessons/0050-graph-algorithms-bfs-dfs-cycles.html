Graph Algorithms: Multi-Source BFS, DFS & 3-Color Cycle Detection

Master Graph BFS, Multi-Source BFS, and 3-color DFS cycle detection in directed graphs.

1. Graph Representations: Adjacency List vs Matrix

Real-world graphs are typically sparse (E << V^2). An Adjacency Matrix consumes O(V^2) memory and requires O(V) to inspect neighbors. An Adjacency List (List<List<Integer>> or int[][]) consumes O(V + E) memory and inspects neighbors in O(degree): 

// ANTI-PATTERN: Adjacency Matrix on 100,000 sparse nodes
int[][] matrix = new int[100_000][100_000]; // CRASH: Demands 40GB of heap memory!

// IDIOMATIC JAVA 21: Adjacency List
List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < n; i++) adj.add(new ArrayList<>());

2. Under the Hood: Multi-Source BFS (Rotten Oranges / 01 Matrix)

In multi-source problems, expanding from each source individually takes O(K * V). By pushing all initial sources into the queue simultaneously at time t=0, standard BFS guarantees the shortest traversal distance in a single O(V + E) pass: 

// UNDER THE HOOD: Multi-Source BFS initialization
Deque<int[]> queue = new ArrayDeque<>();
for (int r = 0; r < rows; r++) {
    for (int c = 0; c < cols; c++) {
        if (grid[r][c] == 2) queue.offer(new int[]{r, c}); // Seed all sources at time 0!
    }
}

3. 3-Color DFS Cycle Detection in Directed Graphs

In directed graphs, detecting cycles requires distinguishing between back-edges (ancestors in current call stack) and cross-edges (nodes already visited in completed branches). A 3-color state array resolves this:

  • 0 (WHITE): Unvisited.
  • 1 (GRAY): Currently in recursion stack (active ancestor). Visiting a Gray node indicates a Cycle!
  • 2 (BLACK): Fully explored with all descendants verified acyclic.
// IDIOMATIC JAVA 21: 3-Color Cycle Detection
boolean hasCycle(int u, List<List<Integer>> adj, int[] color) {
    color[u] = 1; // Mark GRAY (in stack)
    for (int v : adj.get(u)) {
        if (color[v] == 1) return true; // BACK-EDGE: Cycle found!
        if (color[v] == 0 && hasCycle(v, adj, color)) return true;
    }
    color[u] = 2; // Mark BLACK (completed)
    return false;
}
