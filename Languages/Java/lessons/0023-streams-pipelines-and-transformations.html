Stream Pipelines, Lazy Spliterators & Parallel Stream Hazards

Master Stream lazy pipelines, short-circuiting, stateful operations on infinite streams, and primitive unboxed streams.

1. The Stream Mental Model: Lazy Pipelines & Short-Circuiting

Unlike collections (which store data in memory), a Stream is a view of computation. Intermediate operations (filter, map, flatMap) do not execute when called; they are fused together into a single-pass processing pipeline that evaluates lazily only when a terminal operation (collect, findFirst, sum) is invoked: 

// ANTI-PATTERN: Believing intermediate operations execute immediately
Stream<String> stream = names.stream()
    .filter(name -> {
        System.out.println("Filtering: " + name); // NEVER PRINTS! No terminal operation attached!
        return name.startsWith("A");
    });

2. Stateful vs Stateless Operations & The Infinite Stream Trap

Intermediate operations fall into two fundamental categories:

  • Stateless: Process each element independently in O(1) space (filter, map, flatMap).
  • Stateful: Require buffering previous or all elements in memory (sorted, distinct).
// PRODUCTION TRAP: Calling stateful operations on infinite streams
Stream.iterate(0, i -> i + 1)
    .sorted() // CRASH: OutOfMemoryError / CPU Hang! sorted() tries to buffer infinite elements!
    .limit(10);

// IDIOMATIC JAVA 25: Truncate BEFORE stateful operations
Stream.iterate(0, i -> i + 1)
    .limit(10) // Finite stream of 10 items
    .sorted(); // Safe to sort!
⚡ Primitive Streams Avoid Boxing Garbage
Using stream.map(Item::getPrice).reduce(0, Integer::sum) allocates boxed Integer objects on every step. Use mapToInt(Item::getPrice).sum() to execute purely on primitive CPU registers.

3. Under the Hood: flatMap for One-to-Many Transformations

flatMap flattens nested streams (such as orders containing order items) into a unified continuous stream: 

// IDIOMATIC JAVA 25: One-to-many flattening with flatMap
List<String> allSkus = orders.stream()
    .flatMap(order -> order.items().stream()) // Flattens Stream<List<Item>> to Stream<Item>
    .map(Item::sku)
    .distinct()
    .toList(); // Java 16+ toList() produces an unmodifiable List!
