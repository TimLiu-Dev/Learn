Binary Search Boundaries & Monotonic Answer-Space Optimization

Master binary search templates, overflow avoidance, boundary finding, and monotonic answer-space optimization.

1. The Integer Overflow Bug & Standard Binary Search Template

The canonical binary search expression mid = (low + high) / 2 contains a classic 32-bit integer overflow bug when low + high > Integer.MAX_VALUE. Senior implementations always compute mid = low + (high - low) / 2: 

// ANTI-PATTERN: Integer overflow on large arrays
int mid = (low + high) / 2; // OVERFLOWS to negative integer when low + high > 2^31 - 1!

// IDIOMATIC JAVA 25: Overflow-safe midpoint
int mid = low + (high - low) / 2; // Mathematically equivalent, 100% overflow safe!

2. Under the Hood: Left Boundary vs Right Boundary Templates

When search targets contain duplicates, binary search can find the first occurrence (left boundary / lower_bound) or last occurrence (right boundary / upper_bound): 

// UNDER THE HOOD: Left Boundary (first index where nums[mid] >= target)
int low = 0, high = nums.length - 1, ans = -1;
while (low <= high) {
    int mid = low + (high - low) / 2;
    if (nums[mid] >= target) {
        ans = mid;       // Candidate found; keep searching left for earlier match!
        high = mid - 1;
    } else {
        low = mid + 1;
    }
}

3. Binary Search on Answer Space (Monotonic Predicates)

When an optimization problem asks for the minimum or maximum value satisfying a constraint, and the feasibility function canDeliver(capacity) is monotonic (e.g. [F, F, F, T, T, T]), binary search finds the optimal threshold in O(log(Range) * N): 

// IDIOMATIC JAVA 25: Binary search on answer space (Ship Within Days)
int low = maxWeight, high = sumWeight, optimalCapacity = high;
while (low <= high) {
    int midCapacity = low + (high - low) / 2;
    if (canShipWithinDays(weights, midCapacity, days)) {
        optimalCapacity = midCapacity; // Valid capacity; try smaller!
        high = midCapacity - 1;
    } else {
        low = midCapacity + 1;         // Too small; must increase capacity!
    }
}
