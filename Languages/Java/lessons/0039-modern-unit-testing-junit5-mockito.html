Modern Unit Testing: JUnit 5, Parameterized Tests, AssertJ & Mockito

Master JUnit 5 parameterized tests, AssertJ fluent assertions, and Mockito side-effect verification.

1. The Modern Java 25 Testing Stack

Senior enterprise Java relies on JUnit 5 (Jupiter) for test lifecycle and parameterized execution, AssertJ for fluent, readable assertions, and Mockito for isolating external I/O boundaries: 

// ANTI-PATTERN: Over-mocking domain models and immutable records
User mockUser = Mockito.mock(User.class); // MOCKING RECORD: Anti-pattern!
Mockito.when(mockUser.name()).thenReturn("Alice"); // Brittle, slow, unnecessary mock!

// IDIOMATIC JAVA 25: Instantiate real records directly
User realUser = new User("USR-1", "Alice", 100L); // Pure, instant, refactoring-safe!

2. Under the Hood: Parameterized Testing with CsvSource

Instead of writing multiple repetitive test methods, @ParameterizedTest with @CsvSource evaluates edge cases cleanly: 

// UNDER THE HOOD: Data-driven parameterized testing
@ParameterizedTest(name = "Order {0} cents with code {1} yields discount {2} cents")
@CsvSource({
    "10000, SUMMER10, 1000",
    "20000, VIP20,    4000",
    "5000,  INVALID,     0"
})
void testDiscountCalculation(long amount, String promo, long expectedDiscount) {
    long discount = DiscountEngine.calculate(amount, promo);
    assertThat(discount).isEqualTo(expectedDiscount);
}

3. AssertJ Fluent Assertions & Mockito Side-Effect Verification

AssertJ's fluent API provides rich diagnostic messages on assertion failures. Mockito is reserved for verifying side-effects on external dependencies (such as sending emails or publishing events), while integration suites add REST Assured (or Spring Framework 7's RestTestClient in Lesson 0081) for declarative HTTP JSON contract verification: 

// IDIOMATIC JAVA 25: Fluent assertions and interaction verification
assertThat(order.items())
    .hasSize(2)
    .extracting(Item::sku)
    .containsExactly("SKU-A", "SKU-B");

verify(eventPublisher, times(1)).publish(any(OrderCreatedEvent.class));
