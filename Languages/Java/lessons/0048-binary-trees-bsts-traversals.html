Binary Trees, BST Bounds Validation, Iterative Traversals & LCA

Master BST range bounds validation, iterative traversals with ArrayDeque, and LCA algorithms.

1. The BST Subtree Validation Trap

A Binary Search Tree requires that all nodes in the left subtree are strictly less than the root, and all nodes in the right subtree are strictly greater. A common junior mistake is checking only immediate children: 

// ANTI-PATTERN: Checking only immediate children
boolean isValid(Node root) {
    if (root == null) return true;
    if (root.left != null && root.left.val >= root.val) return false;
    if (root.right != null && root.right.val <= root.val) return false;
    return isValid(root.left) && isValid(root.right); // Fails for [10, 5, 15, null, null, 6, 20]! 6 < 10 in right subtree!
}

2. Under the Hood: Range Invariant Propagation

The correct validation propagates dynamic bounds (minVal, maxVal) downwards through the recursive call stack: 

// UNDER THE HOOD: Validating BST with propagated bounds
boolean isValidBST(Node root, Long min, Long max) {
    if (root == null) return true;
    if (root.val <= min || root.val >= max) return false;
    // Left subtree must be < root.val; Right subtree must be > root.val
    return isValidBST(root.left, min, (long) root.val)
        && isValidBST(root.right, (long) root.val, max);
}

3. Lowest Common Ancestor (LCA) in BST vs Binary Tree

In a BST, LCA can be determined in O(H) time without recursion simply by comparing values against p and q: 

// IDIOMATIC JAVA 25: Iterative O(H) BST LCA without stack recursion
public Node lowestCommonAncestor(Node root, Node p, Node q) {
    Node curr = root;
    while (curr != null) {
        if (p.val < curr.val && q.val < curr.val) curr = curr.left;
        else if (p.val > curr.val && q.val > curr.val) curr = curr.right;
        else return curr; // Split point is the LCA!
    }
    return null;
}
