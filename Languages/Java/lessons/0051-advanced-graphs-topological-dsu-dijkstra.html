Advanced Graphs: Kahn's Topological Sort, Union-Find (DSU) & Dijkstra

Master Kahn's topological sort, DSU with path compression, and Dijkstra shortest path invariants.

1. Kahn's Algorithm: Topological Sort & Cycle Detection

Kahn's Algorithm performs topological sorting on Directed Acyclic Graphs (DAGs) using an in-degree array and a FIFO queue:

  • Compute in-degrees for all vertices. Enqueue all nodes with inDegree == 0.
  • Dequeue node u, append to order, and decrement in-degree for all neighbors v.
  • If neighbor in-degree reaches 0, enqueue it.
  • Cycle Check: If the processed count is less than V, the graph contains a directed cycle!
// UNDER THE HOOD: Kahn's Algorithm loop
while (!queue.isEmpty()) {
    int u = queue.poll();
    order[idx++] = u;
    for (int v : adj.get(u)) {
        if (--inDegree[v] == 0) queue.offer(v);
    }
}
if (idx < V) throw new IllegalArgumentException("Graph contains a cycle!");

2. Disjoint Set Union (DSU / Union-Find) with Path Compression

DSU manages dynamic connectivity across disjoint sets. Combining Path Compression (flattening tree pointers directly to the root during find) with Union by Rank reduces operations to near-constant O(alpha(N)) amortized time: 

// IDIOMATIC JAVA 21: High-performance DSU
class DSU {
    int[] parent, rank;
    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path compression!
    }
    boolean union(int i, int j) {
        int rootI = find(i), rootJ = find(j);
        if (rootI == rootJ) return false; // Already connected!
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
        else if (rank[rootI] > rank[rootJ]) parent[rootJ] = rootI;
        else { parent[rootJ] = rootI; rank[rootI]++; }
        return true;
    }
}

3. Dijkstra's Shortest Path & The Non-Negative Weight Invariant

Dijkstra's algorithm finds single-source shortest paths in weighted graphs using a Min-Heap (PriorityQueue). Dijkstra strictly requires non-negative edge weights; negative edges violate the greedy relaxation invariant: 

// UNDER THE HOOD: Dijkstra Min-Heap relaxation
PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1])); // [node, dist]
pq.offer(new int[]{source, 0});
while (!pq.isEmpty()) {
    int[] curr = pq.poll();
    int u = curr[0], d = curr[1];
    if (d > dist[u]) continue; // Stale heap entry; skip!
    for (Edge e : adj.get(u)) {
        if (dist[u] + e.weight < dist[e.to]) {
            dist[e.to] = dist[u] + e.weight;
            pq.offer(new int[]{e.to, dist[e.to]});
        }
    }
}
