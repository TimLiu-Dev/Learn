API Security (OWASP Top 10, BOLA/IDOR, CORS), ABAC/ReBAC, HTTP Caching (ETag) & Lifecycle

Close the biggest real-world API gaps on roadmap.sh/api-design: fix Spring Security CORS preflight traps, stop OWASP API1 BOLA/IDOR and SSRF, move beyond coarse RBAC to ABAC/ReBAC, and ship HTTP ETag caching + RFC 8594 Sunset deprecation headers.

1. Spring Security 7 CORS Trap & OWASP API Security Top 10 (BOLA, Mass Assignment, SSRF)

Configuring @CrossOrigin or WebMvcConfigurer.addCorsMappings alone fails in production: Spring Security's filter chain executes before Spring MVC, rejecting browser OPTIONS preflight requests with 401 Unauthorized or stripping CORS headers on error responses! Always wire a CorsConfigurationSource directly into http.cors(...): 

// IDIOMATIC SPRING SECURITY 7: Explicit CORS Filter + Never Wildcard "*" with Credentials
@Bean
public SecurityFilterChain apiSecurity(HttpSecurity http) throws Exception {
    return http
        .cors(Customizer.withDefaults()) // Runs CorsFilter BEFORE authentication filters!
        .csrf(csrf -> csrf.disable())
        .authorizeHttpRequests(auth -> auth.anyRequest().authenticated())
        .oauth2ResourceServer(oauth2 -> oauth2.jwt(Customizer.withDefaults()))
        .build();
}

@Bean
public CorsConfigurationSource corsConfigurationSource() {
    CorsConfiguration cfg = new CorsConfiguration();
    cfg.setAllowedOrigins(List.of("https://app.acme.io")); // NEVER "*" when allowCredentials=true!
    cfg.setAllowedMethods(List.of("GET", "POST", "PUT", "PATCH", "DELETE"));
    cfg.setAllowedHeaders(List.of("Authorization", "Content-Type", "Idempotency-Key"));
    cfg.setAllowCredentials(true);
    var source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/api/**", cfg);
    return source;
}

Even with valid JWT authentication, the #1 vulnerability on the OWASP API Security Top 10 is API1: Broken Object Level Authorization (BOLA / IDOR)—checking that a caller is logged in, without verifying that the caller owns the requested orderId or tenantId: 

// ANTI-PATTERN (OWASP API1 BOLA): Authenticated user swaps /orders/101 -> /orders/102!
@GetMapping("/orders/{orderId}")
public OrderDto getOrderBad(@PathVariable UUID orderId) {
    return orderRepo.findById(orderId).map(OrderDto::from).orElseThrow(); // No tenant/owner check!
}

// IDIOMATIC DEFENSE: Scope EVERY query by JWT tenant/subject claim + reject Mass Assignment via DTOs
@GetMapping("/orders/{orderId}")
public OrderDto getOrderSafe(@PathVariable UUID orderId, @AuthenticationPrincipal Jwt jwt) {
    String tenantId = jwt.getClaimAsString("tenant_id");
    return orderRepo.findByIdAndTenantId(orderId, tenantId)
        .map(OrderDto::from) // Never bind @RequestBody directly onto @Entity (OWASP API3)!
        .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND));
}

2. Authorization Models (RBAC vs. ABAC vs. ReBAC), HTTP Caching & API Lifecycle

Roles (ROLE_USER, ROLE_ADMIN) quickly hit a wall when permissions depend on resource attributes or organizational hierarchies:

AuthZ ModelHow Decisions WorkWhen to Use in Spring Boot 4
RBACStatic roles (hasRole('ADMIN'))Coarse internal admin vs. standard user endpoints.
ABACAttributes on user, resource, environment (e.g., tenantId, region == 'EU', amount < 1000)Multi-tenant SaaS rules via custom AuthorizationManager / OPA.
ReBACGraph relationships (user:alice → editor → folder:9)Google-Docs-style sharing via Zanzibar / OpenFGA / SpiceDB.

For read scalability and clean API governance, combine HTTP Conditional Caching (ETag + If-None-Match → 304 Not Modified) with RFC 8594 Lifecycle Headers (Deprecation and Sunset) and explicit Content Negotiation (produces = {MediaType.APPLICATION_JSON_VALUE, MediaType.APPLICATION_PROBLEM_JSON_VALUE}): 

// IDIOMATIC SPRING MVC: Conditional ETag (304 Not Modified) + RFC 8594 Sunset Header
@GetMapping(path = "/catalog/{id}", produces = MediaType.APPLICATION_JSON_VALUE)
public ResponseEntity<CatalogItemDto> getCatalogItem(@PathVariable String id, WebRequest request) {
    CatalogItem item = catalogService.findById(id);
    String eTag = "\"" + item.version() + "\"";
    if (request.checkNotModified(eTag)) {
        return null; // Spring automatically returns 304 Not Modified with zero JSON body!
    }
    return ResponseEntity.ok()
        .cacheControl(CacheControl.maxAge(Duration.ofSeconds(60)).cachePublic())
        .eTag(eTag)
        .header("Deprecation", "true")
        .header("Sunset", "Wed, 01 Jul 2027 00:00:00 GMT")
        .body(CatalogItemDto.from(item));
}
