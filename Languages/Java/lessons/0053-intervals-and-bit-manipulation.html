Sweep-Line Intervals, Greedy Scheduling & Bitwise / Bitmask DP

Master sweep-line interval algorithms, greedy interval scheduling, and bitwise manipulation tricks.

1. Sweep-Line: Meeting Rooms II

The Sweep-Line technique processes events on a 1D timeline. In Meeting Rooms II, instead of checking pairwise overlaps, we decompose each interval [start, end] into two events: (start, +1) and (end, -1). Sorting all events on time yields the maximum concurrent meetings in a single pass: 

// UNDER THE HOOD: Sweep-line timeline event simulation
int[] starts = Arrays.stream(intervals).mapToInt(i -> i[0]).sorted().toArray();
int[] ends = Arrays.stream(intervals).mapToInt(i -> i[1]).sorted().toArray();

int rooms = 0, endIdx = 0;
for (int i = 0; i < starts.length; i++) {
    if (starts[i] < ends[endIdx]) rooms++; // Meeting started before prior ended: allocate room!
    else endIdx++;                        // Reused existing room
}

2. Interval Merging & Greedy Activity Selection

Merging intervals requires sorting by start time, extending the current end boundary whenever intervals overlap: 

// IDIOMATIC JAVA 25: Clean interval merging
Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
List<int[]> merged = new ArrayList<>();
for (int[] curr : intervals) {
    if (merged.isEmpty() || merged.getLast()[1] < curr[0]) {
        merged.add(curr); // Disjoint: append new interval
    } else {
        merged.getLast()[1] = Math.max(merged.getLast()[1], curr[1]); // Overlap: extend end!
    }
}

3. Senior Bitwise Manipulation Tricks

Bit manipulation executes directly on hardware CPU registers in a single cycle:

  • x & (x - 1): Clears the lowest set bit (Brian Kernighan's bit-counting algorithm).
  • x & (-x): Isolates the lowest set bit (Binary Indexed Tree / Fenwick Tree).
  • (1 << k): Bitmask flag for the k-th element in subset enumeration.
// UNDER THE HOOD: Counting set bits in O(k) steps
int count = 0;
while (x != 0) {
    x &= (x - 1); // Clears rightmost '1' bit
    count++;
}
