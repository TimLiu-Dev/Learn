Java Cryptography (JCA), AES-GCM, Password Hashing & Java 25 KDF API (JEP 510)

Master CSPRNGs (SecureRandom), constant-time digest verification, authenticated AES-GCM encryption, key derivation with Java 25 javax.crypto.KDF, and slow password hashing.

1. Core Java Cryptography Architecture (JCA) Rules

  • Randomness: Never use java.util.Random or Math.random() for tokens, salts, or IVs (predictable linear congruential seed). Always allocate SecureRandom (new SecureRandom()).
  • Constant-Time Tag Verification: Never compare HMAC/digest bytes with Arrays.equals(a, b) (short-circuits on byte index mismatch, leaking secret prefix bytes via timing). Always call MessageDigest.isEqual(a, b).
  • Symmetric Encryption: Never use AES/ECB/PKCS5Padding (deterministic block patterns leak plaintext structure) or unauthenticated CBC. Always use AEAD **AES/GCM/NoPadding** with a fresh 12-byte (96-bit) random IV per message + optional Associated Authenticated Data (cipher.updateAAD(aad)).
  • Password Storage: Never store raw SHA-256(password). Use memory-hard KDFs (Argon2id or BCrypt in Spring Security, or JDK PBKDF2WithHmacSHA256 with high work factor + 16-byte random salt).

2. Production Trap vs. Java 25 KDF API (JEP 510) & AES-GCM

// ANTI-PATTERN: Broken AES/ECB + timing-unsafe Arrays.equals + weak Random IV
Cipher bad = Cipher.getInstance("AES/ECB/PKCS5Padding"); // NO IV, deterministic blocks!
boolean ok = Arrays.equals(computedMac, expectedMac);    // Timing side-channel leak!

In Java 25 (JEP 510), javax.crypto.KDF provides a clean standard API for extracting and expanding high-entropy cryptographic keys via **HKDF-SHA256** without hand-rolling HMAC loops: 

// IDIOMATIC JAVA 25: JEP 510 HKDF key derivation + AES-256-GCM AEAD encryption
import javax.crypto.Cipher;
import javax.crypto.KDF;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.HKDFParameterSpec;
import java.nio.charset.StandardCharsets;
import java.security.SecureRandom;

public final class AeadVault {
    private static final SecureRandom RNG = new SecureRandom();

    public static SecretKey deriveAesKey(byte[] masterSecret, byte[] salt, String context) throws Exception {
        KDF hkdf = KDF.getInstance("HKDF-SHA256");
        var spec = HKDFParameterSpec.ofExtract()
                .addIKM(masterSecret)
                .addSalt(salt)
                .thenExpand(context.getBytes(StandardCharsets.UTF_8), 32); // 256-bit AES key
        return hkdf.deriveKey("AES", spec);
    }

    public static byte[] encryptGcm(SecretKey key, byte[] plaintext, byte[] iv) throws Exception {
        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));
        return cipher.doFinal(plaintext);
    }
}
