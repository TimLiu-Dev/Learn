Java NIO.2, ByteBuffers, Channels & Atomic File Operations

Master Java NIO.2 Path, Files, ByteBuffers, Channel operations, and crash-resilient atomic file writes.

1. The Path and Files Architecture in NIO.2

Modern Java file I/O operates on java.nio.file.Path and static helper methods in java.nio.file.Files. The legacy java.io.File class fails to throw descriptive exceptions, lacks symlink support, and does not support atomic operations. 

// ANTI-PATTERN: Leaking operating system file descriptors via unclosed Files.lines()
Stream<String> lines = Files.lines(Path.of("/var/log/audit.log"));
long count = lines.filter(s -> s.contains("ERROR")).count();
// BUG: Files.lines() opens an unmanaged FileInputStream; failing to close the stream leaves fd open!

2. Under the Hood: Channels, ByteBuffers & Direct Memory

For high-performance I/O, FileChannel communicates with operating system page caches using ByteBuffer. Buffers manage state via three core pointers: position (current cursor), limit (usable boundary), and capacity (total memory allocated): 

// UNDER THE HOOD: ByteBuffer write-to-read transition
ByteBuffer buffer = ByteBuffer.allocate(1024);
buffer.put("PAYLOAD".getBytes(StandardCharsets.UTF_8)); // pos=7, limit=1024
buffer.flip(); // Prepares for channel read/drain: limit=7, pos=0!
channel.write(buffer);

3. Atomic File Writes: Preventing Incomplete Crash Corruption

Writing directly to a production configuration file risks leaving a corrupted, zero-byte file if the process crashes midway. The senior pattern writes to a sibling temporary file and performs an atomic rename: 

// IDIOMATIC JAVA 21: Crash-resilient atomic file write
Path target = Path.of("/etc/service/config.json");
Path temp = Files.createTempFile(target.getParent(), "cfg-", ".tmp");
Files.writeString(temp, "{ \"active\": true }", StandardCharsets.UTF_8);
// Atomic filesystem inode swap prevents partial reads
Files.move(temp, target, StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING);
