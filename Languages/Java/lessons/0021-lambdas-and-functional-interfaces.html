Lambdas, invokedynamic, Variable Capture & Functional Interfaces

Master invokedynamic LambdaMetafactory mechanics, variable capture, and core functional interfaces.

1. The LambdaMetafactory vs Anonymous Classes

In Java 7 and earlier, functional callbacks required anonymous inner classes, which forced javac to emit a distinct Class$1.class file for every single callback and allocated an object instance on the heap upon each invocation.

Since Java 8, lambdas use the invokedynamic bytecode instruction targeting LambdaMetafactory. The JVM spins up a lightweight class at runtime and caches singleton instances for stateless lambdas, eliminating allocation overhead: 

// ANTI-PATTERN: Heavy anonymous class allocation in hot loops
Runnable r1 = new Runnable() {
    @Override public void run() { doWork(); } // Emits $1.class, allocates heap object every loop!
};

// IDIOMATIC JAVA 25: Zero-allocation stateless lambda via LambdaMetafactory
Runnable r2 = () -> doWork(); // Single cached singleton instance reused across invocations!

2. Variable Capture & Effective Finality

Lambdas can capture local variables from their enclosing lexical scope, but only if the variables are effectively final (assigned exactly once): 

// PRODUCTION TRAP: Mutating captured variable inside lambda
int counter = 0;
// Runnable r = () -> counter++; // COMPILATION ERROR: local variables must be effectively final!

// Under the hood: When a lambda captures a variable, it stores a copy of that primitive/reference
// in a hidden synthetic field. Allowing mutation would create thread-safety race conditions!
⚡ Primitive Specializations Prevent Boxing
Using Predicate<Integer> incurs boxing overhead on every call (allocating Integer objects). Use primitive specializations: IntPredicate, LongPredicate, DoubleSupplier to operate directly on CPU primitive registers.

3. The Core Functional Interfaces

Standard Java 25 functional contracts in java.util.function: 

// 1. Predicate<T>:    T -> boolean (filter, validate)
// 2. Function<T, R>:  T -> R       (map, transform)
// 3. Consumer<T>:     T -> void    (side-effects, logging)
// 4. Supplier<T>:     () -> T      (lazy generation, factory)
Predicate<String> isNonEmpty = s -> !s.isBlank();
Function<String, Integer> parse = Integer::parseInt;
Consumer<String> printer = System.out::println;
Supplier<Instant> clock = Instant::now;
