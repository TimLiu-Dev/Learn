Monotonic Stacks, Queues & ArrayDeque Sliding Window Maximum

Master Monotonic Stacks, Monotonic Queues, and ArrayDeque sliding window maximum amortized O(N) proofs.

1. The Monotonic Stack Invariant: Next Greater Element

A Monotonic Stack preserves elements in strictly increasing or decreasing order. Whenever an incoming element violates the monotonicity condition, elements are popped from the stack until the invariant is restored. This resolves the Next Greater Element problem in O(N) time: 

// ANTI-PATTERN: Nested O(N^2) scan for Next Greater Element
int[] res = new int[n];
for (int i = 0; i < n; i++) {
    res[i] = -1;
    for (int j = i + 1; j < n; j++) {
        if (nums[j] > nums[i]) { res[i] = nums[j]; break; } // O(N^2) time!
    }
}

2. Under the Hood: Monotonic Deque for Sliding Window Maximum

In LeetCode 239 (Sliding Window Maximum), maintaining a window maximum in O(1) per step requires a Monotonic Decreasing Deque storing array indices:

  • Evict out-of-window: If deque.peekFirst() <= i - k, remove from head.
  • Evict smaller elements: While !deque.isEmpty() && nums[deque.peekLast()] < nums[i], pop from tail.
  • Current Maximum: The maximum for the current window is always at nums[deque.peekFirst()].
// UNDER THE HOOD: Sliding Window Maximum step
Deque<Integer> deque = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    // 1. Remove expired indices outside [i - k + 1, i]
    if (!deque.isEmpty() && deque.peekFirst() <= i - k) deque.pollFirst();
    // 2. Maintain decreasing order: drop smaller elements
    while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) deque.pollLast();
    deque.offerLast(i);
    // 3. Record window max
    if (i >= k - 1) result[i - k + 1] = nums[deque.peekFirst()];
}

3. ArrayDeque vs LinkedList: The CPU Cache Locality Truth

Always use java.util.ArrayDeque rather than java.util.LinkedList for stacks and queues. ArrayDeque uses a contiguous circular array with zero node allocation and superior CPU cache prefetching: 

// IDIOMATIC JAVA 21: ArrayDeque allocation efficiency
// LinkedList allocates a 24-byte Node object for EVERY element (pointer chasing, cache misses).
// ArrayDeque uses a primitive Object[] array; ~3-5x faster under high throughput!
Deque<Integer> stack = new ArrayDeque<>(); // Preferred senior implementation
