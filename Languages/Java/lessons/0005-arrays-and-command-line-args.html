Arrays, Contiguous Memory & java.util.Arrays

Master Java heap arrays, array covariance traps, System.arraycopy intrinsics, and binary search insertion points.

1. Arrays on the Heap: The Memory Layout Trap

In Java, arrays are true heap objects. Even primitive arrays (like int[]) are allocated on the heap with a standard 16-byte object header (12 bytes under Compressed OOPs with 4-byte array length field): 

// ANTI-PATTERN: Believing array assignment creates a copy
int[] original = { 1, 2, 3 };
int[] duplicate = original; // COPIES REFERENCE ONLY!
duplicate[0] = 99;
// original[0] is now 99! Both pointers share the identical heap memory buffer!

To create true independent copies, use Arrays.copyOf() or System.arraycopy() (which maps to an intrinsic native hardware memmove): 

// IDIOMATIC JAVA 25: High-performance native memory copy
int[] trueCopy = Arrays.copyOf(original, original.length);
// Under the hood: System.arraycopy(original, 0, trueCopy, 0, original.length);

2. Array Covariance & ArrayStoreException

Java arrays are covariant (i.e., if Sub extends Super, then Sub[] is a subtype of Super[]). While this was introduced early in Java 1.0 to support polymorphic sorting before Generics existed, it introduces a notorious runtime failure mode: 

// PRODUCTION TRAP: Array covariance runtime crash
String[] strings = new String[5];
Object[] objects = strings; // Legal compilation because of array covariance!

objects[0] = Integer.valueOf(42); // CRASH! Throws ArrayStoreException at runtime!
⚠ ArrayStoreException at Runtime
Because array components store runtime type information in their heap header, every reference write to an array performs an internal type check. Prefer generic collections (List<String>) in business code, which enforce invariant type safety at compile time.

3. Modern Arrays Utilities: Binary Search & Multi-Dimensional Clones

Arrays.binarySearch() executes in O(log N) time, but requires the array to be sorted first. If the key is not present, it returns (-(insertion point) - 1): 

// IDIOMATIC JAVA 25: Binary search with insertion point recovery
int[] nums = { 10, 20, 30, 40 };
int idx = Arrays.binarySearch(nums, 25);
// idx is -3. Insertion point is (-idx - 1) = 2.
