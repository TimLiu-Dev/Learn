Master every flagship upgrade introduced by Spring Boot 4.0 & Spring Framework 7.0 (Nov 2025), and know when lightweight alternatives like Quarkus or Javalin fit best.

2. Production Examples: Jackson 3, JSpecify, Native Versioning & Ecosystem Frameworks

// BOOT 4 / FRAMEWORK 7 CONTROLLER & RESILIENCE EXAMPLE
package com.acme.orders;

import org.jspecify.annotations.NullMarked;
import org.jspecify.annotations.Nullable;
import org.springframework.resilience.annotation.Retryable;
import org.springframework.web.bind.annotation.*;
import tools.jackson.databind.json.JsonMapper;

@NullMarked // JSpecify: all parameters/returns in class are non-null unless @Nullable!
@RestController
@RequestMapping("/api/orders")
public class OrderV2Controller {
    private final JsonMapper jsonMapper; // Jackson 3 immutable thread-safe mapper

    public OrderV2Controller(JsonMapper jsonMapper) {
        this.jsonMapper = jsonMapper;
    }

    @GetMapping(path = "/{id}", version = "2.0") // Native Framework 7 API versioning
    @Retryable(includes = TransientBackendException.class, maxRetries = 3, delay = 200)
    public OrderDto fetchOrder(@PathVariable String id, @Nullable @RequestParam String cursor) {
        return new OrderDto(id, cursor);
    }
}
⚡ Choosing Among JVM Web Frameworks (Spring Boot 4 vs. Quarkus vs. Javalin)
  • Spring Boot 4.0: Default enterprise standard—deepest ecosystem, Virtual Threads (spring.threads.virtual.enabled=true), AOT repositories, Jackson 3, OpenTelemetry starter.
  • Quarkus: Container-first Kubernetes stack moving classpath scanning & DI wiring cleanly into build time for tiny RSS memory and sub-second GraalVM / JVM startup.
  • Javalin: Ultra-minimal programmatic web layer directly over embedded Jetty (app.get("/health", ctx -> ctx.result("ok")))—zero classpath scanning or DI annotations for tiny tools/proxies.
