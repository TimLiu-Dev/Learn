# Mission: Master Modern Java 25 LTS & Spring Boot 4.0 for 2027 Backend Engineering

## Why
Transition from reading beginner Kotlin on Android to writing, debugging, and architecting production backend systems in Java 25 LTS and Spring Boot 4.0. Master the modern JVM language, standard libraries, concurrency primitives, and enterprise Spring mechanics needed to thrive as a Java backend engineer in 2027, with optional interview DSA and distributed streaming tracks.

## Success looks like
- Bridge Android/Kotlin mental models (`val`, `data class`, `when`, nullability, coroutines) cleanly into idiomatic Java 25 (`final`, `record`, exhaustive `switch`, `Optional`/JSpecify, Virtual Threads, `StructuredTaskScope`).
- Write clean core Java from scratch across OOP, packages/`package-private`, JEP 511/512/513/485, Collections, Streams, Regex, I/O & Sockets, Cryptography (AES-GCM & JEP 510 KDF), JUnit 5/AssertJ/Mockito, and SLF4J/Javadoc.
- Understand deep runtime mechanics behind frameworks: JDK/CGLIB proxies, JDBC/HikariCP pools, JPA entity lifecycles, ACID isolation & Flyway, plus JVM memory, Generational ZGC, JIT, and JFR profiling.
- Build and test resilient microservices with Spring Boot 4.0, Spring Framework 7.0 (`@Retryable`, native API versioning, `RestTestClient`), Jackson 3 (`tools.jackson`), JSpecify null safety, Spring Security 7 OAuth2/JWT, and Apache Kafka + Transactional Outbox.
- Optionally master LeetCode DSA patterns (`[Optional Track A]`) and Apache Spark/Flink streaming (`[Optional Track B]`) once Core Java and Spring Boot 4 are solid.

## Constraints
- Starting baseline: Junior Android developer who can read some Kotlin syntax, with minimal prior Java coding practice.
- Local toolchain verified: OpenJDK `25.0.4.1` LTS (`--release 25`), Gradle `9.7.1`, IntelliJ IDEA, Docker.
- Every coding lesson stays short and focused with runnable Java workbenches, progressive hints, balanced 4-option retrieval quizzes, and a paired cheat sheet.

## Out of scope
- Android UI / Jetpack Compose / APK lifecycle development.
- Legacy Java EE / XML Spring configs / obsolete Java 8 patterns replaced by Java 25 LTS & Spring Boot 4.0.
