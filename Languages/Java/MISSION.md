# Mission: Master Java for Spring Boot, DSA Coding Interviews & Big Data Systems

## Why
Transition from basic code reading to writing, designing, and debugging production-grade Java systems. Build the foundational fluency required to solve technical algorithmic interview challenges (LeetCode), architect robust enterprise backends with Spring Boot 3, and engineer high-throughput distributed event streaming systems (Kafka, Spark, Flink).

## Success looks like
- Confidently implement core data structures and solve technical interview problems (LeetCode Medium/Hard) with optimal time and space complexity in idiomatic Java.
- Design, build, test, and containerize modern RESTful enterprise microservices using Spring Boot 3, Spring Data JPA, and Java 21 LTS features (records, virtual threads).
- Understand the deep Java mechanics behind frameworks: dynamic proxies, AOP, reflection, generics type tokens, JDBC/HikariCP, and JPA entity lifecycle.
- Architect and write Java producers and consumers for Apache Kafka with schema registry, transactional semantics, and event-driven pipelines.
- Understand distributed data processing and stateful stream processing fundamentals with Apache Spark and Apache Flink.

## Constraints
- Starting baseline: Early stage — can read basic Kotlin syntax, but needs deliberate practice writing code from scratch.
- Tooling: IntelliJ IDEA + OpenJDK 21 LTS + Docker for containerized infrastructure.
- Every lesson must be interactive with hands-on practice drills, automated feedback, and retention checks.

## Out of scope
- Android mobile application development.
- Legacy Java EE / XML-heavy configuration patterns.
