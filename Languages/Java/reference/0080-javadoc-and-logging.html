Canonical Production Snippet: JEP 467 & Safe Structured Logging

/// Summarizes payment batch using Markdown Javadoc (JEP 467).
/// - Validates non-empty payload
/// - Bridges cleanly through [org.slf4j.Logger] or [System.Logger]
/// @param id batch identifier
/// @return sanitized log tag
String formatTag(String id) {
    // Strip CR/LF before logging untrusted user strings!
    String clean = id.replace("\r", "_").replace("\n", "_");
    log.atDebug().addArgument(() -> expensiveJson()).setMessage("detail={}").log();
    return clean;
}

Senior Production Pitfalls Checklist

  • Eager Argument Evaluation Trap: Writing log.debug("body={}", toJson(req)) still executes toJson(req) even when DEBUG is disabled; pass a lazy Supplier.
  • CRLF Log Injection: Never log raw user-controlled strings in text appenders without stripping \r and \n or using structured JSON encoding.
  • Library Logging Lock-In: Libraries must depend only on a facade (slf4j-api or System.Logger), never forcing a concrete backend (logback-classic) onto consumers.
