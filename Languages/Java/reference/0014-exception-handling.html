Robust Exception Handling, Suppressed Exceptions & AutoCloseable — Quick Reference

Robust Exception Handling & Suppression Reference.

Robust Exception Handling Reference

Hierarchy Level Checked / Unchecked Catch Policy
java.lang.Error Unchecked DO NOT CATCH. Indicates fatal JVM corruption (OOM, StackOverflow).
java.lang.Exception Checked Recoverable external conditions (I/O, network). Catch or declare.
RuntimeException Unchecked Programming bugs or domain errors. Handle via centralized ControllerAdvice.

Canonical Production Snippet: Exception Chaining & AutoCloseable

public void transferPayload(Path src, Path dest) {
    try (InputStream in = Files.newInputStream(src);
         OutputStream out = Files.newOutputStream(dest)) {
        in.transferTo(out);
    } catch (IOException e) {
        throw new StorageOperationException("Failed transferring " + src, e); // Chain cause!
    }
}

Senior Production Pitfalls Checklist

  • Never Swallow Root Cause: Always supply the caught exception as the cause parameter when rethrowing custom domain exceptions.
  • Preserve Thread Interruption: If you catch InterruptedException, restore the status with Thread.currentThread().interrupt().
  • Inspect Suppressed Exceptions: In try-with-resources, read ex.getSuppressed() to log secondary resource closure failures.
