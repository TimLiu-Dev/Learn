Canonical Production Snippet: Robust Comparator Chaining

Comparator<Employee> hierarchy = Comparator
    .comparing(Employee::department)
    .thenComparingInt(Employee::salary)
    .thenComparing(Employee::hireDate, Comparator.nullsLast(Comparator.naturalOrder()))
    .reversed(); // Reverses entire combined ordering

Senior Production Pitfalls Checklist

  • Never Subtract in Comparators: Always use Integer.compare(a, b) or Comparator.comparingInt() to prevent subtraction overflow.
  • Handle Null Fields in Sorting: Wrap nested field comparators in Comparator.nullsFirst() or Comparator.nullsLast().
  • O(1) Reversed Views: Mutating a seq.reversed() view mutates the underlying original collection.
