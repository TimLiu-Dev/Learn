Dynamic Programming Mastery: 1D/2D States, Knapsack, LIS & Space Rolling — Quick Reference

Dynamic Programming Reference.

Dynamic Programming Reference

Pattern State Transition & Space Optimization Senior Production Note
1D Rolling State (House Robber) curr = max(p1, p2 + val); p2 = p1; p1 = curr; Reduces memory from O(N) to O(1) space using 2 registers.
0/1 Knapsack (1D Reverse) for (int w = W; w >= wt; w--) Backwards loop prevents reusing item; compresses 2D to 1D table.
Unbounded Knapsack (Coin Change) for (int w = wt; w <= W; w++) Forwards loop permits unlimited item reuse.
LIS Patience Sorting Binary search on tails[] array Achieves O(N log N) vs naive O(N^2) DP.

Canonical Production Snippet: 1D Knapsack Template

public int knapsack(int W, int[] wt, int[] val) {
    int[] dp = new int[W + 1];
    for (int i = 0; i < wt.length; i++) {
        for (int w = W; w >= wt[i]; w--) { // Reverse order for 0/1!
            dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
        }
    }
    return dp[W];
}

Senior Production Pitfalls Checklist

  • Recursion Depth Limits: Never use top-down recursion when N > 10,000; convert to bottom-up tabulation to avoid StackOverflowError.
  • 0/1 vs Unbounded Loop Direction: 0/1 Knapsack iterates capacity backwards; Unbounded Knapsack (Coin Change) iterates forwards.
  • Integer Overflow in Min-Cost DP: When initializing DP arrays for minimization (e.g. Arrays.fill(dp, Integer.MAX_VALUE)), beware that dp[w - c] + 1 will overflow to negative! Use Integer.MAX_VALUE / 2 or guard against infinity.
