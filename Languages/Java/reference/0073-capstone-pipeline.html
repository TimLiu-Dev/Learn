Pipeline Layer Core Technology Senior Production Guarantees
API Ingress Gateway Spring Boot 3 + Redis Idempotency Key validation via Redis SETNX; deduplicates client retries.
Atomic Persistence PostgreSQL + Outbox Table Single ACID transaction commits business entity and event payload together.
Message Backbone Apache Kafka (KRaft) acks=all, min.insync.replicas=2, idempotent producer.

Canonical Production Snippet: End-to-End Capstone Verification

// 1. Ingress validates Idempotency Key in Redis
boolean acquired = redisTemplate.opsForValue().setIfAbsent("idemp:" + key, "LOCKED", Duration.ofMinutes(10));
if (!acquired) return cachedResponse;

// 2. Commit to Outbox inside PostgreSQL transaction
outboxRepository.save(new OutboxRecord("payments.incoming", key, payload));

// 3. Kafka Producer publishes with durability
kafkaTemplate.send(new ProducerRecord<>("payments.incoming", key, payload));

Senior Production Pitfalls Checklist

  • Dual-Write Failure: Never publish to Kafka and save to DB in separate non-transactional calls; always use the Outbox pattern.
  • Missing Kafka acks=all: With default settings, broker failover can lose acknowledged records; enforce acks=all and min.insync.replicas=2.
  • Loss of Distributed Context: Always inject the W3C traceparent header into Kafka record headers so OpenTelemetry traces do not break across asynchronous queues.
