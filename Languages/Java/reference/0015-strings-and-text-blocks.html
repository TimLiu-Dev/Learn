Strings & Text Blocks Reference

Feature Introduced In Optimization Mechanism
Compact Strings Java 9 Stores byte[] + coder (LATIN1 = 1 byte/char; UTF16 = 2 bytes/char).
Indify Concatenation Java 9 invokedynamic to StringConcatFactory (exact-sized single buffer).
Text Blocks Java 15 Triple quotes """; automatic indentation stripping & clean formatting.

Canonical Production Snippet: Text Block SQL Query

public String buildSearchQuery(String status) {
    return """
        SELECT u.id, u.email, o.total_cents
        FROM users u
        JOIN orders o ON u.id = o.user_id
        WHERE u.status = '%s'
        ORDER BY o.created_at DESC;
        """.formatted(status).strip();
}

Senior Production Pitfalls Checklist

  • Avoid new String("..."): Always use string literals or factory methods; explicit constructor bypasses the pool and wastes heap memory.
  • Preserve Trailing Spaces in Text Blocks: Use \s when trailing whitespace is semantically significant.
  • Size StringBuilder in Loops: When building large strings inside loops, always supply an estimated initial capacity.
