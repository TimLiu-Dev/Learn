Binary Trees, BST Bounds Validation, Iterative Traversals & LCA — Quick Reference

Binary Trees & BST Reference.

Binary Trees & BST Reference

Pattern / Problem Time / Space Complexity Senior Implementation Invariant
Validate BST O(N) / O(H) stack Must propagate (min, max) range bounds downwards to all descendants.
LCA in BST O(H) / O(1) space Split point: move left if both < root, right if both > root, else return root.
LCA in Binary Tree O(N) / O(H) stack Post-order traversal: if both left & right return non-null, root is LCA.
Iterative Traversals O(N) / O(H) heap Use ArrayDeque stack to prevent StackOverflowError on skewed trees.

Canonical Production Snippet: Iterative Pre-Order Traversal

public List<Integer> preorderTraversal(Node root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    Deque<Node> stack = new ArrayDeque<>();
    stack.push(root);

    while (!stack.isEmpty()) {
        Node curr = stack.pop();
        result.add(curr.val);
        if (curr.right != null) stack.push(curr.right); // Push right first so left pops first
        if (curr.left != null) stack.push(curr.left);
    }
    return result;
}

Senior Production Pitfalls Checklist

  • Integer Boundary Overflow: In BST validation, initialize bounds with Long.MIN_VALUE and Long.MAX_VALUE so nodes containing Integer.MIN_VALUE are handled correctly.
  • Skewed Tree StackOverflow: Deeply unbalanced trees cause recursion to crash the JVM thread stack; use explicit ArrayDeque for production safety.
  • Null Check in LCA: Always guard p == null || q == null at method entry.
