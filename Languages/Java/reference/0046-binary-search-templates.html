Binary Search Boundaries & Monotonic Answer-Space Optimization — Quick Reference

Binary Search Templates & Answer Space Reference.

Binary Search Templates & Answer Space Reference

Template / Pattern Loop Condition & Update Senior Production Usage Note
Exact Target Search while (low <= high) Always use mid = low + (high - low) / 2 to prevent 32-bit overflow.
Left Boundary (First Occurrence) Match: ans = mid; high = mid - 1; Narrows leftward upon finding matches to locate first occurrence.
Right Boundary (Last Occurrence) Match: ans = mid; low = mid + 1; Narrows rightward upon finding matches to locate last occurrence.
Binary Search on Answer Space Search in [minPossible, maxPossible] Requires monotonic predicate canDeliver(x): O(log(range) * N).

Canonical Production Snippet: Monotonic Answer Space Template

public int optimizeMetric(int[] data, int constraint) {
    int low = getMinimumPossibleAnswer(data);
    int high = getMaximumPossibleAnswer(data);
    int optimal = high;

    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (isFeasible(data, mid, constraint)) {
            optimal = mid;      // Feasible; search for more optimal in left half
            high = mid - 1;
        } else {
            low = mid + 1;      // Infeasible; increase target metric
        }
    }
    return optimal;
}

Senior Production Pitfalls Checklist

  • Midpoint Overflow: Never write (low + high) / 2; always use low + (high - low) / 2 or (low + high) >>> 1.
  • Predicate Monotonicity: Verify that the feasibility function does not oscillate (e.g. true, false, true); binary search strictly requires monotonic partition.
  • Infinite Loop in While: If updating low = mid instead of low = mid + 1, mid calculation must round up: low + (high - low + 1) / 2 to prevent 2-element infinite loops.
