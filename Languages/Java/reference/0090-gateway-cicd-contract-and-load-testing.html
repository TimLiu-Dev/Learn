Nginx/Spring Cloud Gateway forwarding, 12-Factor config, GitHub Actions, Pact/OpenAPI diff, and k6 budgets.

1. Delivery & Edge Verification Matrix

Canonical Production Snippet: Trusted Forward Headers + Actuator Shutdown

server:
  shutdown: graceful
  forward-headers-strategy: framework
  tomcat:
    remoteip:
      internal-proxies: 10\.\d{1,3}\.\d{1,3}\.\d{1,3}
spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s

Senior Production Pitfalls Checklist

  • Never Trust Public X-Forwarded-For Headers: Spoofed headers defeat IP rate limits and audit logs unless restricted to internal proxy CIDRs.
  • Never Measure Only Average Latency in Load Tests: Always assert p(95) / p(99) latency and HikariCP acquisition wait under 2x peak load.
  • Never Remove Response Fields or Add Required Request Fields Without Versioning: Enforce OpenAPI/Pact contract compatibility gates in CI.
