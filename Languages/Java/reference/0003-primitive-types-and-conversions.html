Primitive Types, Conversions & Safe Arithmetic Reference

Quick-lookup table of bit widths, widening/precision loss paths, and JDK 25 overflow-safe APIs.

1. Primitive Layout & Widening Precision Matrix

Type Bytes (Array) Min / Max Constants Implicit Widening Targets Precision Hazard on Widening?
byte 1 B -128 .. 127 short, int, long, float, double None (exact)
short 2 B -32,768 .. 32,767 int, long, float, double None (exact; cannot widen implicitly to char)
char 2 B '\u0000' .. '\uffff' int, long, float, double None (zero-extended unsigned 16-bit)
int 4 B Integer.MIN_VALUE .. MAX_VALUE long, float, double Loses precision → float above 224 (16,777,216)! Exact → double.
long 8 B Long.MIN_VALUE .. MAX_VALUE float, double Loses precision → float AND double above 253!
float 4 B 24-bit mantissa (~7 dec digits) double Exact binary value preserved (base-10 fractions remain approximate)
double 8 B 53-bit mantissa (~15–17 dec digits) None (widest primitive) NaN != NaN; -0.0 == +0.0 is true (use Double.compare)

2. Canonical Safe Numeric Idioms (Java 25)

import java.math.BigDecimal;

public final class NumericPatterns {
    // 1. Checked arithmetic (throws ArithmeticException on wrap-around; C2 CPU-flag intrinsic)
    public static long checkedLineItemCents(long qty, long unitPriceCents) {
        return Math.multiplyExact(qty, unitPriceCents);
    }

    // 2. Checked long -> int narrowing (rejects silent truncation > 2.14B)
    public static int checkedArraySize(long count) {
        return Math.toIntExact(count);
    }

    // 3. Overflow-proof midpoint for binary search / divide-and-conquer
    public static int midpoint(int lo, int hi) {
        return (lo + hi) >>> 1; // Safe for all non-negative lo, hi
    }

    // 4. Euclidean modulo for hash bucketing (safe for Integer.MIN_VALUE)
    public static int shard(Object key, int shardCount) {
        return Math.floorMod(key.hashCode(), shardCount);
    }

    // 5.Unsigned operations on 32-bit/64-bit primitives (network protocols, CRC, byte parsing)
    public static int unsignedByteToInt(byte b) {
        return Byte.toUnsignedInt(b); // Equivalent to b & 0xFF (avoids sign extension!)
    }

    // 6. Total ordering comparison for primitives (never subtract in comparators!)
    public static int compareDoubles(double a, double b) {
        return Double.compare(a, b); // Correctly orders -0.0 < +0.0 and NaN consistently
    }
}

3. Senior Production Pitfalls Checklist

  • Anchor 64-bit expressions on the FIRST operand: Write long ns = seconds * 1_000_000_000L;—without the trailing L, int * int overflows before assignment.
  • Never negate or call Math.abs on arbitrary hashes: Math.abs(Integer.MIN_VALUE) returns negative -2147483648; use Math.floorMod(h, n) or (h & 0x7fffffff) % n.
  • Sign extension when reading raw network bytes: byte b = (byte) 0xFF; int x = b; yields -1, not 255! Always mask with Byte.toUnsignedInt(b) (`b & 0xFF`).
  • Never represent currency in float or double: Use long minor units (cents/micros) for low-latency ledgers or BigDecimal initialized from String/valueOf for arbitrary scale.
  • Compound assignments hide narrowing casts: short s = 30_000; s += 10_000; compiles without warning and silently wraps into a negative number.
