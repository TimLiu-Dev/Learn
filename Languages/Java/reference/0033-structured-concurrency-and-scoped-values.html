Structured Concurrency (StructuredTaskScope) & ScopedValue vs ThreadLocal — Quick Reference

StructuredTaskScope and ScopedValue Reference.

Structured Concurrency & Scoped Values Reference

Construct Cancellation / Lifecycle Semantics Primary Production Use Case
StructuredTaskScope.open() (JDK 25 JEP 505) Cancels remaining subtasks if any fails; join() throws Fan-out aggregations (e.g. User Profile + Orders + Payment). (JDK 21 preview used ShutdownOnFailure)
Joiner.anySuccessfulResultOrThrow() Cancels siblings when FIRST subtask succeeds; join() returns T Redundant quoting, querying replicated mirrors, fastest-wins searches. (JDK 21 preview used ShutdownOnSuccess)
ScopedValue<T> (Final in JDK 25 JEP 506) Immutable, lexically bounded to execution block Request trace IDs, tenant context, security credentials in Virtual Threads.
ThreadLocal<T> (Legacy) Mutable, unbounded lifetime, requires explicit remove() Legacy frameworks (avoid in modern millions-of-virtual-threads systems).

Canonical Production Snippet: Structured Task Aggregation (JDK 25 --enable-preview)

public InvoiceSummary buildInvoice(long orderId) throws Exception {
    try (var scope = StructuredTaskScope.open()) {
        Subtask<OrderDetails> orderSub = scope.fork(() -> orderService.get(orderId));
        Subtask<TaxDetails> taxSub = scope.fork(() -> taxService.calculate(orderId));

        scope.join(); // Awaits completion; throws FailedException and cancels siblings on failure

        return new InvoiceSummary(orderSub.get(), taxSub.get());
    }
}

Senior Production Pitfalls Checklist

  • Always Call scope.join() Before Subtask.get(): Calling join() awaits subtasks and surfaces failures (note: JDK 21–24 previews required scope.throwIfFailed(), whereas JDK 25 JEP 505 throws directly from join()).
  • Unbounded ThreadLocal in Virtual Threads: ThreadLocal adds map overhead to every single virtual thread; use ScopedValue to avoid heap bloat.
  • Ensure Try-With-Resources: Always manage StructuredTaskScope inside try-with-resources to guarantee thread termination and socket cleanup on exit.
