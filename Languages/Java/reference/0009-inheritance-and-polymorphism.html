Inheritance & Polymorphic Dispatch Reference.

Inheritance & Polymorphic Dispatch Reference

Dispatch State Distinct Receiver Classes HotSpot C2 Optimization
Monomorphic Exactly 1 class Direct method inlining behind speculative class-check guard.
Bimorphic Exactly 2 classes Bimorphic inline cache (if-else direct inlining).
Megamorphic 3 or more classes Indirect vtable / itable stub lookup (cannot inline).

Canonical Production Snippet: Composition Forwarding Wrapper

public class ForwardingSet<E> implements Set<E> {
    private final Set<E> delegate;

    public ForwardingSet(Set<E> delegate) {
        this.delegate = Objects.requireNonNull(delegate);
    }

    @Override public boolean add(E e) { return delegate.add(e); }
    @Override public boolean addAll(Collection<? extends E> c) { return delegate.addAll(c); }
    // All other Set methods delegate cleanly without inheritance fragility...
}

Senior Production Pitfalls Checklist

  • Fragile Base Class Trap: Overriding parent methods that internally call other overridden methods leads to double-counting or infinite recursion.
  • Overriding Invariants: Never narrow visibility (e.g. public to protected) or add broader checked exceptions in subclasses.
  • Avoid Megamorphism in Hot Loops: Passing many implementations of an interface through a tight loop forces megamorphic vtable dispatch, preventing C2 inlining.
