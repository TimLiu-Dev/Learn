Classes, Heap Allocation & Object Lifecycle — Quick Reference

Object Lifecycle & Header Layout Reference.

Object Lifecycle & Memory Layout Reference

Component Size (Compressed OOPs) Contents / Purpose
Mark Word 8 bytes Identity hash, GC age (4 bits: max 15), lock bits, bias flags.
Klass Word 4 bytes Reference pointer to Metaspace class metadata.
Array Length 4 bytes (arrays only) Tracks number of elements in array buffer.
Padding 0–7 bytes Aligns total object size to 8-byte boundaries.

Canonical Production Snippet: Record Compact Constructor

public record Money(BigDecimal amount, Currency currency) {
    public Money {
        Objects.requireNonNull(amount, "amount required");
        Objects.requireNonNull(currency, "currency required");
        amount = amount.setScale(2, RoundingMode.HALF_EVEN);
    }
}

Senior Production Pitfalls Checklist

  • Overridable Constructor Invocations: Never call overridable methods inside constructors; child fields will still be null when executed.
  • Boxed Integer Overhead: Integer occupies 16 bytes vs 4 bytes for primitive int. Storing millions in collections multiplies memory 4x.
  • Max Tenuring Age: The Mark Word allocates only 4 bits for age; -XX:MaxTenuringThreshold can never exceed 15.
