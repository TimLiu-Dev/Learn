Java 25 Compact Sources, Module Imports & Stream Gatherers

Quick syntax reference for JEP 512 compact files, JEP 511 module imports, and JEP 485 built-in Gatherers.

Built-in java.util.stream.Gatherers

MethodBehaviorTypical Use Case
Gatherers.windowFixed(n)Non-overlapping batches of size ≤ nBulk DB saves (saveAll per 500 items)
Gatherers.windowSliding(n)Overlapping windows of size nMoving averages, anomaly detection
Gatherers.scan(init, biFn)Emits every running prefix resultRunning account balances / cumulative totals
Gatherers.fold(init, biFn)Collapses upstream lazily into 1 itemMid-pipeline reduction before further mapping
Gatherers.mapConcurrent(max, fn)Concurrent Virtual-Thread mapping up to maxBounded parallel HTTP enrichment inside Streams
 
// JEP 512 + JEP 485 quick CLI script
void main() {
    var windows = Stream.of(1, 2, 3, 4).gather(Gatherers.windowSliding(2)).toList();
    IO.println(windows); // [[1, 2], [2, 3], [3, 4]]
}
