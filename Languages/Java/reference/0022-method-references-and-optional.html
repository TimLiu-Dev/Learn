Method References & Optional Reference.

Method References & Optional Reference

Method Reference Kind Syntax Equivalent Lambda
Static Integer::parseInt s -> Integer.parseInt(s)
Bound Instance instance::method args -> instance.method(args)
Unbound Instance String::trim s -> s.trim() (first argument is target receiver)
Constructor ArrayList::new () -> new ArrayList<>()

Canonical Production Snippet: Safe Optional Chaining

public String resolveUserCountry(User user) {
    return Optional.ofNullable(user)
        .flatMap(User::getAddress)
        .map(Address::getCountryCode)
        .filter(Predicate.not(String::isBlank))
        .orElseGet(() -> fetchDefaultCountryFromService()); // Lazy fallback!
}

Senior Production Pitfalls Checklist

  • Never orElse(callHeavyMethod()): Always use orElseGet(() -> callHeavyMethod()) to avoid eager evaluation overhead.
  • Never Store Optional in Fields: Optional is not Serializable and wastes 16 bytes of heap header per field.
  • Avoid Optional.get(): Use orElseThrow(() -> new DomainException()) or ifPresent().
