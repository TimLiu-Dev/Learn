Arrays, Contiguous Memory & java.util.Arrays — Quick Reference

Arrays & Native Memory Copy Reference.

Arrays & Utilities Reference

Operation API Call Complexity & Mechanism
High-Speed Copy System.arraycopy(...) O(N) intrinsic hardware memmove.
Defensive Clone Arrays.copyOf(arr, len) Allocates new heap buffer and copies elements.
Dual-Pivot Quicksort Arrays.sort(arr) O(N log N) Dual-Pivot Quicksort (primitives) / Timsort (objects).
Binary Search Arrays.binarySearch(arr, k) O(log N); returns (-(ins) - 1) if absent.

Canonical Production Snippet: Safe Array Duplication

public int[] sanitizeAndSort(int[] input) {
    if (input == null) return new int[0];
    int[] safe = Arrays.copyOf(input, input.length);
    Arrays.sort(safe);
    return safe;
}

Senior Production Pitfalls Checklist

  • Array Covariance Dangers: Never pass Sub[] as Super[] if elements might be written, preventing runtime ArrayStoreException.
  • Binary Search Prerequisite: Calling Arrays.binarySearch() on an unsorted array returns undefined and misleading index positions.
  • Multi-Dimensional Shallow Clone: matrix.clone() or Arrays.copyOf(matrix, len) only copies row pointers! Nested column arrays remain shared.
