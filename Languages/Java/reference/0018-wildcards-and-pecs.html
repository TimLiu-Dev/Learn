Generic Wildcards, Variance & The PECS Principle — Quick Reference

Generic Wildcards & PECS Reference.

Generic Wildcards & PECS Reference

Wildcard Form Variance Allowed Operations
List<? extends T> (PECS Producer) Covariant READ-ONLY: T val = list.get(i). Cannot add()!
List<? super T> (PECS Consumer) Contravariant WRITE-ONLY: list.add(val). Reads return Object.
List<?> (Unbounded) Bivariant Can only read Object; can only write null.

Canonical Production Snippet: PECS Copy Method

public static <T> void transfer(List<? extends T> source, List<? super T> destination) {
    for (T item : source) {
        destination.add(item); // Clean, type-safe transfer
    }
}

Senior Production Pitfalls Checklist

  • Never Use Wildcards in Return Types: Returning List<? extends T> forces callers to deal with wildcards; return exact types like List<T>.
  • Cannot Add to ? extends T: You cannot insert elements into an upper-bounded wildcard collection; use ? super T.
  • Invariance: Remember List<String> does not inherit from List<Object>.
