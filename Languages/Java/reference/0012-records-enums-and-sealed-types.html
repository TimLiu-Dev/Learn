Modern Algebraic Types: Records, Enums & Sealed Classes — Quick Reference

Records, Enums & Sealed Classes Reference.

Records, Enums & Sealed Classes Reference

Modern Type Inheritance Constraints Primary Production Use Case
record Implicitly final; extends java.lang.Record Immutable DTOs, API payloads, value objects, map keys.
enum Cannot extend classes; extends java.lang.Enum State machines, fixed strategies, type-safe singletons.
sealed Subclasses MUST be final, sealed, or non-sealed Algebraic Data Types (ADTs), domain command/event hierarchies.

Canonical Production Snippet: Sealed Hierarchy with Records

public sealed interface UserEvent permits UserRegistered, UserEmailChanged, UserDeactivated {}

public record UserRegistered(UUID id, String email, Instant timestamp) implements UserEvent {}
public record UserEmailChanged(UUID id, String newEmail) implements UserEvent {}
public record UserDeactivated(UUID id, String reason) implements UserEvent {}

Senior Production Pitfalls Checklist

  • Subclass Modifiers: Forgetting to mark a permitted subclass as final, sealed, or non-sealed causes an immediate compilation failure.
  • Records Are Shallowly Immutable: If a record holds a reference to a mutable List or Date, external code can still mutate the list contents. Use unmodifiable collections.
  • Enum Instance State: Keep enum instances stateless or immutable; mutable fields in enums create multi-threaded concurrency bugs.
