Functional Interfaces & Lambdas Reference.

Lambdas & Functional Interfaces Reference

Interface Signature Primitive Specializations
Predicate<T> T -> boolean IntPredicate, LongPredicate, DoublePredicate
Function<T, R> T -> R ToIntFunction, ToLongFunction, LongFunction
Consumer<T> T -> void IntConsumer, LongConsumer, DoubleConsumer
Supplier<T> () -> T IntSupplier, LongSupplier, BooleanSupplier

Canonical Production Snippet: Non-Capturing Lambda Re-use

// Static method reference acts as zero-allocation stateless singleton:
List<String> clean = rawStrings.stream()
    .filter(Predicate.not(String::isBlank))
    .map(String::strip)
    .toList();

Senior Production Pitfalls Checklist

  • Avoid Boxed Functional Interfaces: In high-throughput numerical loops, replace Predicate<Integer> with IntPredicate to avoid boxing allocations.
  • Capturing Lambdas Create Garbage: Lambdas that reference outer variables allocate an instance on the heap each time; extract into static method references when possible.
  • Effective Finality: You cannot mutate an outer local variable from inside a lambda; use an AtomicInteger or return a transformed value.
