ThreadPoolExecutor, Queues & Sizing Quick Reference

Fast lookup matrix for factory hazards, queue memory layouts, saturation policies, and pool-sizing equations.

1. Executors Factories vs. Explicit ThreadPoolExecutor

Executor Construction Core / Max Threads Backing Queue Failure Mode Under Load
newFixedThreadPool(n) n / n LinkedBlockingQueue(Integer.MAX_VALUE) Heap OOM: Queue grows without bound when downstream slows.
newSingleThreadExecutor() 1 / 1 LinkedBlockingQueue(Integer.MAX_VALUE) Heap OOM: Unbounded FIFO queue behind single worker.
newCachedThreadPool() 0 / Integer.MAX_VALUE SynchronousQueue (0 capacity) Native OOM / CPU Thrash: Spawns thousands of ~1 MB OS threads.
newScheduledThreadPool(n) n / Integer.MAX_VALUE DelayedWorkQueue (unbounded heap) Heap OOM if millions of far-future timers are registered unchecked.
Explicit ThreadPoolExecutor Explicit core / max ArrayBlockingQueue(bounded) Predictable: Bounded RAM + deterministic backpressure/load-shedding.

2. Blocking Queue & Sizing Matrix

Dimension Recommendation Key Invariant / Formula
Dispatch Order Core → Queue → Max → Reject Burst threads (> corePoolSize) ONLY spawn after workQueue.offer() returns false!
Queue Choice ArrayBlockingQueue(cap) Pre-allocated Object[] ring buffer; zero per-task Node GC allocation churn.
CPU-Bound Sizing N_cpu (or N_cpu + 1) Runtime.getRuntime().availableProcessors(); extra threads degrade L1/L2 cache locality.
Blocking I/O Sizing N_cpu * U * (1 + W / C) Cap strictly below downstream DB pool / rate limits; prefer Virtual Threads + Semaphore in JDK 21.

3. Canonical Production Template (Java 21 LTS)

ThreadFactory factory = Thread.ofPlatform()
        .name("svc-worker-", 0)
        .uncaughtExceptionHandler((t, e) -> log.error("Uncaught in {}", t.getName(), e))
        .factory();

ThreadPoolExecutor pool = new ThreadPoolExecutor(
        cores,
        cores * 2,
        60L, TimeUnit.SECONDS,
        new ArrayBlockingQueue<>(512),
        factory,
        new ThreadPoolExecutor.AbortPolicy()
);

// Graceful two-phase shutdown hook:
pool.shutdown();
try {
    if (!pool.awaitTermination(10, TimeUnit.SECONDS)) {
        pool.shutdownNow();
    }
} catch (InterruptedException e) {
    pool.shutdownNow();
    Thread.currentThread().interrupt();
}

4. Senior Production Pitfalls Checklist

  • Never pair CallerRunsPolicy with Netty/NIO event loops: Overflow tasks run synchronously on the caller event-loop thread, freezing all multiplexed non-blocking connections.
  • Never pair DiscardPolicy / DiscardOldestPolicy with submit() + untimed Future.get(): Silently dropping an uncancelled FutureTask parks the waiting caller forever—always pass timeouts to future.get(t, unit).
  • Watch container CPU quotas: Verify -XX:+UseContainerSupport (enabled by default) so availableProcessors() reflects Kubernetes pod CPU limits rather than the 64-core bare-metal host.
  • Core threads never time out by default: Idle threads at or below corePoolSize stay alive indefinitely unless pool.allowCoreThreadTimeOut(true) is explicitly enabled.
