Reference Cheat Sheet • 0075

Packages, Nested Classes & JEP 513 Flexible Constructors

Quick lookup for Java visibility scopes, initialization order, inner-class memory safety, and Java 25 constructor prologues.

1. Initialization Sequence & Visibility Rules

  1. Class load (once): Superclass static initializers → Subclass static initializers (in textual declaration order).
  2. Per instantiation: Superclass instance fields/blocks → Superclass constructor body.
  3. Java 25 Prologue (JEP 513): Parameter checks & own field writes before super(...); instance methods/reads of this only after super(...).

2. Production Snippets

import module java.base; // JEP 511: imports all packages exported by java.base

public class SecurePort extends BasePort {
    public SecurePort(int port) {
        if (port < 1024 || port > 65535) {
            throw new IllegalArgumentException("Bad port: " + port);
        }
        super(port); // JEP 513 prologue validation before super()
    }

    // Always prefer 'static' nested classes unless outer instance access is required
    public static final class ConfigSnapshot {
        private final int port;
        public ConfigSnapshot(int port) { this.port = port; }
    }
}
