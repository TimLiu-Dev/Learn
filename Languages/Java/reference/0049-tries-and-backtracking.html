Prefix Tries & Pruned Backtracking Reference.

Prefix Tries & Pruned Backtracking Reference

Component / Technique Performance Characteristic Senior Production Usage Note
Array-Backed Trie (Node[26]) O(L) search; zero boxing Preferred for lowercase alphabets; 5x faster than HashMap.
Trie-Guided Pruning Collapses 4^L search space Traverse grid and Trie together; abort branch if child == null.
In-Place Masking (#) O(1) space; zero GC churn Mutate board[r][c] = '#' and restore during backtracking.

Canonical Production Snippet: In-Place Trie Backtracking

public void dfs(char[][] board, int r, int c, TrieNode node, List<String> res) {
    char ch = board[r][c];
    if (ch == '#' || node.children[ch - 'a'] == null) return;

    TrieNode next = node.children[ch - 'a'];
    if (next.word != null) {
        res.add(next.word);
        next.word = null; // De-duplicate found words!
    }

    board[r][c] = '#'; // Mark visited in-place
    int[] d = {-1, 0, 1, 0, -1};
    for (int i = 0; i < 4; i++) {
        int nr = r + d[i], nc = c + d[i + 1];
        if (nr >= 0 && nr < board.length && nc >= 0 && nc < board[0].length) {
            dfs(board, nr, nc, next, res);
        }
    }
    board[r][c] = ch; // Restore board in-place
}

Senior Production Pitfalls Checklist

  • Duplicate Matching Words: In Word Search II, clear node.word = null after adding to result to prevent duplicate entries from alternative paths.
  • Character Bounds: Always verify characters are within 'a'..'z' before calculating c - 'a'.
  • Trie Leaf Unlinking: For optimal pruning, decrement child word counts and unlink leaf nodes once all descendant words are discovered.
