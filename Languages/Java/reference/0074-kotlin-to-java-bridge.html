Kotlin-to-Java 25 Translation Reference

Quick-lookup guide comparing Kotlin idioms against Java 25 syntax, nullability contracts, visibility defaults, and runtime traps.

1. Core Grammar & Runtime Equivalence (Kotlin → Java 25)

Feature Kotlin Java 25 LTS
Variable declaration val x: Int = 5 / var y = 10 final int x = 5; / int y = 10; (or local final var x = 5;)
Function / Method fun calc(a: Int): String public static String calc(int a) (return type on left, void for Unit)
Object creation Order("ORD-1", 500) new Order("ORD-1", 500) (explicit new keyword)
Length / Size trio arr.size / s.length / list.size arr.length (field) • s.length() (method) • list.size() (method)
Value carrier data class User(val id: Long) public record User(long id) {} (accessor is user.id() with ())
Structural equality a == b (calls equals) Objects.equals(a, b) (Java == compares heap addresses!)
Inline conditional / Elvis if (c) a else b / x ?: "NONE" c ? a : b / x != null ? x : "NONE" (ternary ? :)
Default visibility public package-private (must write public explicitly)
Nested class default Static (non-capturing) Non-static inner (captures outer this$0 unless marked static class!)
Null safety Compiler-enforced ? types JSpecify @NullMarked / @Nullable & Optional<T> returns
Collections listOf vs mutableListOf List.of (strictly immutable, rejects null) vs new ArrayList<>()

2. Idiomatic Translation Pattern

import java.util.List;
import java.util.Objects;
import java.util.Optional;

public final class BillingBridge {
    public record Invoice(String id, long cents) {
        public Invoice {
            if (id == null || id.isBlank() || cents < 0) {
                throw new IllegalArgumentException("Bad invoice");
            }
        }
    }

    public static String band(long cents) {
        return cents >= 10_000 ? "ENTERPRISE" : (cents > 0 ? "STANDARD" : "ZERO");
    }

    public static String safeTrim(String input) {
        return input == null ? "" : input.trim();
    }
}

3. Senior Production Pitfalls Checklist

  • Never compare Strings or boxed numbers with ==: In Java, == checks pointer identity on objects. Always use Objects.equals(a, b) or a.equals(b).
  • Remember .length vs. .length() vs. .size(): Arrays use the field arr.length; String uses str.length(); Collections (List, Set, Map) use col.size() and do not support [] indexing (use list.get(i) / map.get(k)).
  • Mark nested classes static by default: Omitting static on a nested class in Java creates an inner class holding a hidden this$0 reference to the outer object (like leaking an Android Activity).
  • Do not mutate List.of(...) or pass null into it: List.of and Map.of throw NullPointerException on null elements and UnsupportedOperationException on writes.
