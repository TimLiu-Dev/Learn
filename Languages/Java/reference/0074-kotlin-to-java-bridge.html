Kotlin-to-Java 25 Translation Reference

Quick-lookup guide comparing Kotlin idioms against Java 25 syntax, nullability contracts, visibility defaults, and runtime traps.

1. Core Syntax & Runtime Equivalence

Feature Kotlin Java 25 LTS
Value carrier data class User(val id: Long) public record User(long id) {}
Structural equality a == b Objects.equals(a, b)
Default visibility public package-private (must write public)
Nested class default Static (non-capturing) Non-static inner (captures outer this!)
Null safety Compiler-enforced ? types JSpecify @Nullable / Optional<T>
Collections listOf vs mutableListOf List.of (strictly immutable) vs new ArrayList<>()

2. Idiomatic Translation Pattern

import java.util.List;
import java.util.Objects;
import java.util.Optional;

public final class BillingBridge {
    public record Invoice(String id, long cents) {
        public Invoice {
            if (id == null || id.isBlank() || cents < 0) {
                throw new IllegalArgumentException("Bad invoice");
            }
        }
    }

    public static String band(long cents) {
        return cents >= 10_000 ? "ENTERPRISE" : (cents > 0 ? "STANDARD" : "ZERO");
    }

    public static String safeTrim(String input) {
        return Optional.ofNullable(input).map(String::trim).orElse("");
    }
}
