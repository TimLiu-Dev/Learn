Canonical Production Snippet: Java 25 HKDF (JEP 510) + AES-256-GCM

public static byte[] deriveAndEncrypt(byte[] ikm, byte[] salt, byte[] iv12, byte[] plain) throws Exception {
    KDF hkdf = KDF.getInstance("HKDF-SHA256");
    SecretKey aesKey = hkdf.deriveKey("AES",
        HKDFParameterSpec.ofExtract().addIKM(ikm).addSalt(salt)
            .thenExpand("vault-v1".getBytes(StandardCharsets.UTF_8), 32));
    Cipher gcm = Cipher.getInstance("AES/GCM/NoPadding");
    gcm.init(Cipher.ENCRYPT_MODE, aesKey, new GCMParameterSpec(128, iv12));
    return gcm.doFinal(plain);
}

Senior Production Pitfalls Checklist

  • Never Reuse an AES-GCM IV: Encrypting two messages with the same key and 12-byte IV leaks both the XOR of plaintexts and the GCM authentication key.
  • Constant-Time MAC Comparison: Always use MessageDigest.isEqual(a, b) rather than Arrays.equals(a, b) when verifying webhook HMACs or signatures.
  • Password Storage: Never use fast digests (SHA-256) for user passwords; use memory-hard Argon2idPasswordEncoder or BCryptPasswordEncoder.
