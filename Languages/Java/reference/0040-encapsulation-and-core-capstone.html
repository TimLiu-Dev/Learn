Canonical Production Snippet: Striped Concurrent Cache

public class ShardedCache<K, V> {
    private static final int STRIPES = 32;
    private final ReentrantLock[] locks = new ReentrantLock[STRIPES];
    private final Map<K, V> store = new HashMap<>();

    public ShardedCache() {
        for (int i = 0; i < STRIPES; i++) locks[i] = new ReentrantLock();
    }

    public void put(K key, V val) {
        int idx = (key.hashCode() & 0x7FFFFFFF) % STRIPES;
        locks[idx].lock();
        try {
            store.put(key, val);
        } finally {
            locks[idx].unlock();
        }
    }
}

Senior Production Pitfalls Checklist

  • Negative Modulo Trap: In Java, -1 % 16 == -1. Always mask with 0x7FFFFFFF or use Math.floorMod.
  • Stripe Sizing: Sizing stripes as powers of two (16, 32, 64) allows fast bitwise masking: hash & (STRIPES - 1).
  • Avoid Deep Reflection: Do not rely on `--add-opens` flags in Docker containers; design for clean public object accessors.
