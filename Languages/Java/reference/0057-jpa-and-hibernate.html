JPA & Hibernate Lifecycle, Fetch & Equality Reference

Entity state transitions, JPA fetch defaults, ActionQueue ordering, and proxy-safe natural key templates.

1. Entity Lifecycle States & Persistence Context Behavior

State How Entered In 1st-Level Cache? Dirty Checked at Flush?
Transient new Entity() No No
Managed em.persist(e), em.find(...), JPQL result, return value of em.merge(d) Yes (EntityKey identity map + Object[] loadedState snapshot) Yes (unless @Transactional(readOnly = true))
Detached Transaction closes, em.detach(e), em.clear() No (uninitialized proxies throw LazyInitializationException) No
Removed em.remove(managedEntity) Marked deleted Queued for EntityDeleteAction

2. JPA Association Fetch Defaults & Primary Key Generators

Annotation / Feature JPA Spec Default Senior Production Rule
@ManyToOne / @OneToOne FetchType.EAGER (Danger!) Always override to fetch = FetchType.LAZY to avoid cascading N+1 queries.
@OneToMany / @ManyToMany FetchType.LAZY Keep LAZY; hydrate selectively via query-specific LEFT JOIN FETCH, @EntityGraph, or @BatchSize(size = 50).
GenerationType.IDENTITY DB auto-increment Disables Hibernate JDBC insert batching! Prefer GenerationType.SEQUENCE (allocationSize = 50) or UUIDv7.
Hibernate ActionQueue Order INSERT → UPDATE → DELETE Call em.flush() after em.remove(old) before inserting a replacement row with the same unique key.

3. Canonical Proxy-Safe Entity & Two-Step Collection Pagination

@Entity
@Table(name = "ledger_items")
public class LedgerItem {
    @Id
    @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "ledger_seq")
    @SequenceGenerator(name = "ledger_seq", sequenceName = "ledger_id_seq", allocationSize = 50)
    private Long id;

    @NaturalId
    @Column(nullable = false, updatable = false, unique = true)
    private UUID businessKey = UUID.randomUUID();

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "account_id", nullable = false)
    private Account account;

    protected LedgerItem() {}

    public UUID getBusinessKey() { return businessKey; }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || Hibernate.getClass(this) != Hibernate.getClass(o)) return false;
        LedgerItem other = (LedgerItem) o;
        return Objects.equals(businessKey, other.getBusinessKey());
    }

    @Override
    public int hashCode() {
        return Objects.hashCode(businessKey);
    }
}

4. Senior Production Pitfalls Checklist

  • Never put Lombok @Data or @EqualsAndHashCode on JPA @Entity classes: Hashing a mutable @GeneratedValue ID corrupts HashSet buckets after flush, and generated toString() triggers lazy associations.
  • Never combine JOIN FETCH on a collection with Pageable: Watch logs for HHH90003004 (or set spring.jpa.properties.hibernate.query.fail_on_pagination_over_collection_fetch=true so CI fails immediately instead of OOMing in prod!).
  • Use getters inside equals(): Accessing other.field directly on an uninitialized Hibernate ByteBuddy proxy reads null instead of initializing the target entity.
  • Bound Persistence Context growth in batch jobs: Call em.flush(); em.clear(); every 500 entities so 1st-level cache snapshots do not exhaust heap or cause O(N2) dirty-check scans.
