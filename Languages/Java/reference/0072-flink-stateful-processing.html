Apache Flink Stateful Streaming: Watermarks, KeyedProcessFunction, ValueState & RocksDB Checkpoints — Quick Reference

Apache Flink Stateful Processing Reference.

Apache Flink Stateful Processing Reference

Concept / API Mechanism Senior Production Note
Watermarks Event-time completeness markers Handles out-of-order records; triggers window evaluation.
KeyedProcessFunction Stateful processing + Timer service Low-level building block for complex fraud and session patterns.
Checkpoint Barriers Asynchronous Chandy-Lamport snapshotting Provides Exactly-Once recovery without stopping the world.
RocksDB State Backend Out-of-core local disk state Scales to multi-terabyte state without Java heap GC pressure.

Canonical Production Snippet: RocksDB Checkpointed Pipeline

StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
env.enableCheckpointing(10000, CheckpointingMode.EXACTLY_ONCE);
env.setStateBackend(new EmbeddedRocksDBStateBackend(true));
env.getCheckpointConfig().setCheckpointStorage("s3://flink-checkpoints/prod/");

Senior Production Pitfalls Checklist

  • State TTL Configuration: Always configure StateTtlConfig on keyed state; unbounded state accumulation without TTL causes disk and memory leaks.
  • Event Time Lateness: Configure allowedLateness() and side outputs for records arriving after the watermark has passed.
  • Checkpoint Alignment: Monitor checkpoint alignment duration; high backpressure delays barrier arrival and increases checkpoint lag.
