Collections Internals: HashMap Treeification, Load Factor & ArrayDeque — Quick Reference

Collections Framework Core Reference.

Collections Framework Core Reference

Collection Backing Structure Get(i) / Add / Remove Complexity
ArrayList Contiguous Object[] O(1) get; amortized O(1) add; O(N) remove.
ArrayDeque Circular Object[] ring buffer Amortized O(1) head/tail push, pop, and peek.
LinkedList Doubly-linked heap nodes O(N) get; O(1) add at ends; heavy cache misses.

Canonical Production Snippet: Safe Single-Pass Filter

public void purgeExpiredSessions(List<UserSession> sessions) {
    // Single-pass O(N) in-place array shift without modCount iterator crash:
    sessions.removeIf(UserSession::isExpired);
}

Senior Production Pitfalls Checklist

  • Prefer ArrayDeque over Stack: Legacy java.util.Stack extends Vector, synchronizing every method and incurring lock penalties.
  • Never Remove During Foreach: Always use removeIf() or explicit iterator.remove().
  • Null Hostility of List.of: List.of() throws NullPointerException if null is passed; use standard ArrayList if nulls are required.
