Canonical Production Snippet: GraphQL @BatchMapping Bulk Resolver

@Controller
public class OrderGraphController {
    @BatchMapping(typeName = "Order", field = "customer")
    public Map<OrderDto, CustomerDto> customer(List<OrderDto> orders) {
        Set<String> ids = orders.stream().map(OrderDto::customerId).collect(Collectors.toSet());
        Map<String, CustomerDto> byId = customerClient.fetchByIds(ids); // 1 bulk query!
        return orders.stream().collect(Collectors.toMap(o -> o, o -> byId.get(o.customerId())));
    }
}

Senior Production Pitfalls Checklist

  • Never Reuse Protobuf Tag Numbers: Mark removed .proto fields with reserved 2; reserved "old_field"; so binary wire compatibility is never broken.
  • Always Set gRPC Deadlines (withDeadlineAfter): gRPC calls have no default timeout; always attach a per-call deadline on client stubs.
  • Enforce GraphQL Max Query Depth & Complexity: Public GraphQL endpoints must configure MaxQueryDepthInstrumentation and MaxQueryComplexityInstrumentation to block recursive DoS queries.
