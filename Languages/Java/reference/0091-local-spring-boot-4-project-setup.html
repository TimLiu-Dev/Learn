Local Spring Boot 4.0 Project, Profiles & JdbcClient — Quick Reference

Companion guide for projects/springboot4-order-service/.

Spring Boot 4.0 Modular Starters & Persistence Choice

Starter / Component Role in Spring Boot 4.0 When to Reach For It
spring-boot-starter-webmvc Servlet 6.1 MVC + Tomcat + Jackson 3 Synchronous REST APIs running on Java 25 Virtual Threads.
spring-boot-starter-jdbc (JdbcClient) Fluent named-parameter SQL mapped to records SQL-first microservices wanting explicit queries, PostgreSQL RETURNING, and zero ORM overhead.
spring-boot-starter-data-jpa Hibernate 7 / JPA 3.2 + Spring Data repositories Rich aggregate graphs needing optimistic locking, projections, or entity state tracking.
spring-boot-docker-compose (developmentOnly) Auto-starts compose.yaml & binds DataSource Zero-config local dev Postgres/Redis/Kafka; excluded automatically from bootJar.

Canonical Production Snippet: Fluent JdbcClient + Profile Guard

@Repository
public class LedgerEntryRepository {
    private final JdbcClient jdbc;
    public LedgerEntryRepository(JdbcClient jdbc) { this.jdbc = jdbc; }

    public record LedgerRow(long id, String accountId, long deltaCents) {}

    @Transactional(readOnly = true)
    public List<LedgerRow> findRecent(String accountId, int limit) {
        return jdbc.sql("""
                SELECT id, account_id, delta_cents
                FROM ledger_entries
                WHERE account_id = :accountId
                ORDER BY id DESC LIMIT :limit
                """)
                .param("accountId", accountId)
                .param("limit", limit)
                .query(LedgerRow.class)
                .list();
    }
}

Senior Production Pitfalls Checklist

  • Enable Resilient Methods Explicitly: Add @EnableResilientMethods on your @SpringBootApplication or @Configuration class before using Framework 7 @Retryable or @ConcurrencyLimit.
  • Never Commit Plaintext Secrets: Use ${DB_PASSWORD} without a production fallback so missing secrets fail fast at boot time; keep local defaults inside application-local.yml or compose.yaml.
  • Gate Sandbox Seeders with @Profile("local"): Any CommandLineRunner inserting sample data must declare @Profile("local") so it can never fire in staging or production.
