Graph Algorithms: Multi-Source BFS, DFS & 3-Color Cycle Detection — Quick Reference

Graph Algorithms Reference.

Graph Algorithms Reference

Algorithm Data Structure Time / Space & Invariants
Multi-Source BFS ArrayDeque O(V + E). Seed all sources at time 0. Shortest path in unweighted graphs.
3-Color DFS Cycle Detection int[] color (0=White, 1=Gray, 2=Black) O(V + E). Back-edge to Gray node indicates directed cycle.
Connected Components BFS / DFS / DSU Partition graph into disjoint subgraphs in O(V + E).

Canonical Production Snippet: 3-Color Cycle Detector

public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
    for (int[] p : prerequisites) adj.get(p[1]).add(p[0]);

    int[] color = new int[numCourses]; // 0=White, 1=Gray, 2=Black
    for (int i = 0; i < numCourses; i++) {
        if (color[i] == 0 && hasCycle(i, adj, color)) return false;
    }
    return true;
}

Senior Production Pitfalls Checklist

  • Matrix Memory Blowup: Never allocate an int[V][V] matrix when V > 5,000; always use an adjacency list.
  • Cross-Edge False Positives: In directed graphs, never use a simple boolean visited array for cycle detection; only back-edges to Gray nodes represent cycles.
  • Level Snapshotting: In BFS level traversals, always capture int size = queue.size() before the inner loop to prevent processing next-level nodes prematurely.
