Canonical Production Snippet: Tenant-Scoped Lookup + ETag 304

@GetMapping("/orders/{orderId}")
public ResponseEntity<OrderDto> getOrder(@PathVariable UUID orderId,
                                         @AuthenticationPrincipal Jwt jwt,
                                         WebRequest request) {
    Order order = orderRepo.findByIdAndTenantId(orderId, jwt.getClaimAsString("tenant_id"))
        .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND));
    String eTag = "\"" + order.getVersion() + "\"";
    if (request.checkNotModified(eTag)) return null;
    return ResponseEntity.ok().eTag(eTag).body(OrderDto.from(order));
}

Senior Production Pitfalls Checklist

  • Never Bind JPA @Entity Directly to @RequestBody: Prevent Mass Assignment (OWASP API3) using immutable Java record DTOs.
  • Never Assume JWT Authentication Means Authorization: Always enforce object-level ownership (BOLA) or ABAC/ReBAC policy checks.
  • Always Set Vary: Accept, Authorization on Cached Content-Negotiated Responses: Prevents shared caches from serving one tenant's or format's payload to another.
