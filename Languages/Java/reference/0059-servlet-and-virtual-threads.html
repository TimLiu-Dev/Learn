Servlet Containers & Virtual Threads Reference

Component / Setting Architecture Role Senior Production Usage Note
DispatcherServlet Front Controller Coordinates HandlerMapping, HandlerAdapter, and Interceptors.
OncePerRequestFilter Guaranteed single execution Prevents duplicate filter execution across async and forward dispatches.
spring.threads.virtual.enabled Tomcat Virtual Threads One virtual thread per request; replaces 200 platform thread pool.

Canonical Production Snippet: Enabling Virtual Threads (application.properties)

# Enable Java 25 Virtual Threads for Tomcat & async tasks
spring.threads.virtual.enabled=true
server.tomcat.threads.max=0 # Virtual threads create on demand; no pooling!

Senior Production Pitfalls Checklist

  • Carrier Pinning & Native I/O: Avoid long JNI native calls inside request threads, and use ReentrantLock if targeting JDK 21–23 around blocking I/O (note: JDK 24/25 JEP 491 unpinned synchronized).
  • ThreadLocal Memory Leaks: Large objects stored in ThreadLocal will bloat memory when 50,000 concurrent virtual threads are active. Use ScopedValue.
  • Filter Ordering: Use @Order(Ordered.HIGHEST_PRECEDENCE) or FilterRegistrationBean to ensure security and correlation filters execute first.
