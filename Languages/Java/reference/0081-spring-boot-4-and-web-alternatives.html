Spring Boot 4.0 / Framework 7.0 Upgrade & Ecosystem Card

Quick delta reference for Jackson 3, JSpecify, Native API Versioning, core @Retryable, RestTestClient, Quarkus & Javalin.

AreaBoot 4.0 / Framework 7.0 Pattern
Jackson 3import tools.jackson.databind.json.JsonMapper; + JsonMapperBuilderCustomizer
Null Safetyimport org.jspecify.annotations.{NullMarked, Nullable};
API Versioning@GetMapping(path = "/{id}", version = "2.0") + spring.mvc.apiversion.*

Canonical Production Snippet: Boot 4 JSpecify + Jackson 3 + Native Versioning

@NullMarked
@RestController
@RequestMapping("/api/orders")
public class OrderV2Controller {
    private final JsonMapper jsonMapper;

    public OrderV2Controller(JsonMapper jsonMapper) {
        this.jsonMapper = jsonMapper;
    }

    @GetMapping(path = "/{id}", version = "2.0")
    @Retryable(includes = TransientException.class, maxRetries = 3, delay = 200)
    public OrderDto getOrder(@PathVariable String id, @Nullable @RequestParam String expand) {
        return new OrderDto(id, expand);
    }
}

Senior Production Pitfalls Checklist

  • Jackson 2 vs Jackson 3 Package Split: Core and databind classes moved to tools.jackson.* (JsonMapper), while annotations remain in com.fasterxml.jackson.annotation.*.
  • Removed @MockBean: Spring Boot 4 removes @MockBean / @SpyBean completely; use Spring Framework's standard @MockitoBean / @MockitoSpyBean.
  • Core @Retryable vs Resilience4j: Use Spring Framework 7's built-in @Retryable / @ConcurrencyLimit for lightweight retries/bulkheads, and add Resilience4j when stateful sliding-window Circuit Breakers are required.
