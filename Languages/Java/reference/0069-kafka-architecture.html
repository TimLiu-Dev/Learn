Apache Kafka Internals: KRaft, ISR/acks=all, Idempotent Producers & Cooperative Rebalancing — Quick Reference

Apache Kafka Architecture Reference.

Apache Kafka Architecture Reference

Configuration Key Recommended Setting Senior Production Guarantees
acks all (-1) Waits for all In-Sync Replicas; zero message loss on leader crash.
min.insync.replicas 2 (on broker/topic) Rejects writes if fewer than 2 ISR nodes are online.
enable.idempotence true Eliminates duplicate messages across network retries via PID + sequence.
partition.assignment.strategy CooperativeStickyAssignor Incremental rebalancing; eliminates stop-the-world consumer pauses.

Canonical Production Snippet: Idempotent Producer Properties

Properties props = new Properties();
props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "kafka-broker-1:9092,kafka-broker-2:9092");
props.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, StringSerializer.class.getName());
props.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, StringSerializer.class.getName());
props.put(ProducerConfig.ACKS_CONFIG, "all");
props.put(ProducerConfig.ENABLE_IDEMPOTENCE_CONFIG, "true");
props.put(ProducerConfig.MAX_IN_FLIGHT_REQUESTS_PER_CONNECTION, 5); // Safe with idempotence!

Senior Production Pitfalls Checklist

  • Acks=1 False Durability: With default acks=1, if the leader crashes after sending ACK before replication, the message is permanently lost. Always use acks=all.
  • min.insync.replicas=1 Hazard: If min.insync.replicas is 1, acks=all degenerates to acks=1 if replicas fall out of sync. Always set it to 2 on replication-factor 3 topics.
  • Zero-Copy sendfile: Keep TLS offloading at the network perimeter (or use kernel TLS) when maximum zero-copy throughput is required.
