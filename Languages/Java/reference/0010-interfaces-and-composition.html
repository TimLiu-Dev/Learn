Interfaces, Default Methods & Composition over Inheritance — Quick Reference

Interfaces & Composition Reference.

Interfaces & Composition Reference

Interface Method Type Introduced In Visibility & Invocation Rule
Abstract Method Java 1.0 Implicitly public abstract; must be implemented.
Default Method Java 8 Implicitly public; provides backward-compatible fallback.
Static Method Java 8 Called ONLY via InterfaceName.method(); not inherited.
Private Method Java 9 Encapsulated internal helper for default methods.

Canonical Production Snippet: Disambiguating Diamond Conflicts

public class CompositeService implements PaymentGateway, FraudDetector {
    @Override
    public boolean verifyTransaction(Transaction tx) {
        // Disambiguate conflicting default methods explicitly:
        return PaymentGateway.super.verifyTransaction(tx) 
            && FraudDetector.super.verifyTransaction(tx);
    }
}

Senior Production Pitfalls Checklist

  • Class Wins Rule: A concrete method from a superclass always overrides an interface default method with the same signature.
  • Static Method Non-Inheritance: You cannot call an interface static method through an implementing class or instance reference.
  • Avoid Over-Populating Default Methods: Default methods should provide convenience defaults, not heavy stateful enterprise business logic.
