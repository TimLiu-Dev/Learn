Inversion of Control (IoC), Bean Scopes & BeanPostProcessor Internals — Quick Reference

Spring IoC & Bean Lifecycle Reference.

Spring IoC & Bean Lifecycle Reference

Lifecycle Stage Interface / Mechanism Senior Production Usage Note
Metadata Processing BeanFactoryPostProcessor Resolves ${...} property placeholders; runs before beans exist.
Bean Instantiation Constructor Injection Always use final fields and constructor injection; eliminate @Autowired on fields.
Pre-Initialization BPP.postProcessBeforeInitialization Processes @PostConstruct callbacks.
Post-Initialization BPP.postProcessAfterInitialization Wraps beans in AOP proxies (@Transactional, @Async).

Canonical Production Snippet: Prototype Resolution via ObjectProvider

@Service
public class OrderProcessor {
    private final ObjectProvider<PaymentTransaction> txProvider;

    public OrderProcessor(ObjectProvider<PaymentTransaction> txProvider) {
        this.txProvider = txProvider;
    }

    public void process(Order order) {
        PaymentTransaction tx = txProvider.getObject(); // Fresh prototype instance every call!
        tx.execute(order);
    }
}

Senior Production Pitfalls Checklist

  • Field Injection: Never use @Autowired private MyService svc;; it hides dependencies and breaks unit testing without Spring.
  • Prototype in Singleton: Never inject a prototype directly as a constructor argument to a singleton; use ObjectProvider<T>.
  • @PostConstruct Limitations: Never initiate asynchronous background threads or invoke proxy-dependent methods in @PostConstruct; proxies are not yet attached!
