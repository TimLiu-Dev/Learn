Advanced Graphs: Kahn's Topological Sort, Union-Find (DSU) & Dijkstra — Quick Reference

Advanced Graphs Reference.

Advanced Graphs (Topo Sort, DSU, Dijkstra) Reference

Algorithm Data Structure Time / Space & Key Guarantees
Kahn's Topological Sort int[] inDegree + ArrayDeque O(V + E). Produces linear ordering of DAG. Detects cycles if count < V.
Disjoint Set Union (DSU) parent[] + rank[] arrays O(alpha(N)) amortized. Path compression + Union by rank.
Dijkstra's Algorithm PriorityQueue<int[]> O(E log V). Single-source shortest path. Requires non-negative weights!

Canonical Production Snippet: Dijkstra with Stale Entry Guard

public int[] dijkstra(int n, List<List<int[]>> adj, int src) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
    pq.offer(new int[]{src, 0});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int u = curr[0], d = curr[1];
        if (d > dist[u]) continue; // CRITICAL: Skip stale heap entries!

        for (int[] edge : adj.get(u)) {
            int v = edge[0], weight = edge[1];
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}

Senior Production Pitfalls Checklist

  • Dijkstra Stale Entries: Always guard if (d > dist[u]) continue;. Without this guard, Dijkstra degrades to exponential runtime on dense graphs due to duplicate heap entries.
  • Negative Edge Weights: Never use Dijkstra if negative edge weights exist; use Bellman-Ford or SPFA instead.
  • DSU Path Compression: Always assign parent[i] = find(parent[i]); omitting the assignment breaks path compression and causes DSU to degrade to O(N) per operation.
