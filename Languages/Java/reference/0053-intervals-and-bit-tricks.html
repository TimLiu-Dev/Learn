Sweep-Line & Bit Manipulation Reference

Technique / Expression Operation Senior Production Usage Note
Sweep-Line (Meeting Rooms) Decompose intervals into (t, +1) and (t, -1) Sort: process end events before start events at identical times.
Interval Merging Sort by start; extend max(end) Linear scan O(N) after initial O(N log N) sort.
x & (x - 1) Clears lowest set 1-bit Kernighan's bit count; power of two test: (x > 0) && (x & (x - 1)) == 0.
x & (-x) Isolates lowest set 1-bit Used in Binary Indexed Trees (Fenwick Trees).

Canonical Production Snippet: Power-of-Two Check

public static boolean isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}

Senior Production Pitfalls Checklist

  • Negative Numbers in Bitwise Shift: Always use unsigned right shift (>>>) instead of signed right shift (>>) when handling raw bitmasks.
  • Simultaneous Intervals: Clarify whether [1, 2] and [2, 3] are considered overlapping; in some business rules boundary equality is an overlap, in others it is not.
  • Operator Precedence: In Java, bitwise operators (&, |, ^) have lower precedence than comparison operators (==, !=). Always write (n & 1) == 0 with parentheses!
