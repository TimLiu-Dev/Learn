Canonical Production Snippet: Sliding Window Maximum Template

public int[] maxSlidingWindow(int[] nums, int k) {
    int[] ans = new int[nums.length - k + 1];
    Deque<Integer> q = new ArrayDeque<>(); // stores indices

    for (int i = 0; i < nums.length; i++) {
        if (!q.isEmpty() && q.peekFirst() <= i - k) q.pollFirst();
        while (!q.isEmpty() && nums[q.peekLast()] <= nums[i]) q.pollLast();
        q.offerLast(i);
        if (i >= k - 1) ans[i - k + 1] = nums[q.peekFirst()];
    }
    return ans;
}

Senior Production Pitfalls Checklist

  • ArrayDeque over LinkedList: Never use new LinkedList<>() for stacks or queues; ArrayDeque is 3x faster and avoids 24-byte per-node GC garbage.
  • Store Indices in Deques: Always store indices in sliding window deques so you can check expiration (idx <= i - k).
  • ArrayDeque Rejects Nulls: ArrayDeque throws NullPointerException on push(null) or offer(null).
