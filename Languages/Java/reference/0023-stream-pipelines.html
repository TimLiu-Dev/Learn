Streams Pipelines & Transformations Reference.

Streams Pipelines & Operations Reference

Operation Category Memory & Execution Characteristics
filter, map Stateless Intermediate O(1) memory; processes items lazily one-by-one.
sorted, distinct Stateful Intermediate O(N) memory; must buffer all items before emitting.
limit, takeWhile Short-Circuiting Intermediate Truncates infinite streams to finite bounds.
findFirst, anyMatch Short-Circuiting Terminal Terminates traversal immediately upon first match.

Canonical Production Snippet: Unboxed Aggregate Pipeline

long totalRevenue = transactions.stream()
    .filter(t -> t.status() == Status.COMPLETED)
    .mapToLong(Transaction::amountCents) // Unboxed LongStream
    .sum();                              // Single-pass primitive accumulation

Senior Production Pitfalls Checklist

  • Infinite Stream Freeze: Never call sorted() or distinct() on an infinite stream without first applying limit().
  • Streams Cannot Be Reused: Once a terminal operation is called on a stream, it is consumed; invoking another operation throws IllegalStateException.
  • Use Primitive Streams: Avoid boxing overhead in arithmetic calculations; prefer mapToInt, mapToLong.
