Canonical Production Snippet: Fully Encapsulated Class

public final class UserSession {
    private final String userId;
    private final List<String> roles;

    public UserSession(String userId, List<String> roles) {
        this.userId = Objects.requireNonNull(userId);
        this.roles = List.copyOf(roles); // Truly immutable defensive copy
    }

    public List<String> getRoles() {
        return this.roles; // Safe to return; cannot be modified externally
    }
}

Senior Production Pitfalls Checklist

  • Unmodifiable View vs Immutable Copy: Never rely on Collections.unmodifiableList if the caller still holds a pointer to the original collection. Use List.copyOf.
  • Array Leakage: Arrays are always mutable in Java. Always return array.clone() in accessors.
  • Mutable Date/Time: Avoid legacy java.util.Date; use immutable java.time.Instant.
