Spring Boot 3 Auto-Configuration (@Conditional) & Record Properties — Quick Reference

Auto-Configuration & Properties Reference.

Auto-Configuration & Properties Reference

Annotation / File Target Scope Senior Production Usage Note
AutoConfiguration.imports META-INF/spring/ Spring Boot 3 replacement for legacy spring.factories.
@ConfigurationProperties Java 16+ Records Always use records with @Validated for immutable configuration.
@ConditionalOnMissingBean @Bean methods Mandatory on auto-configuration defaults to enable clean user overrides.

Canonical Production Snippet: Validated Record Configuration

@Validated
@ConfigurationProperties(prefix = "app.resilience")
public record ResilienceConfig(
    @Positive int maxAttempts,
    @NotNull Duration backoffDuration
) {}

Senior Production Pitfalls Checklist

  • Mutable Properties: Avoid declaring @ConfigurationProperties on POJOs with setters; use records to enforce immutability.
  • Missing Imports Registration: In custom starter libraries, forgetting to list auto-configurations in AutoConfiguration.imports causes beans to fail to load.
  • Ordering Auto-Configurations: Use @AutoConfiguration(after = DataSourceAutoConfiguration.class) to enforce dependency ordering between auto-configurations.
