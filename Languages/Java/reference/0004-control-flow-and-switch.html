Control Flow & Modern Switch Expressions — Quick Reference

Control Flow & Modern Switch Reference.

Control Flow & Switch Reference

Feature Legacy Switch Statement Modern Switch Expression (Java 25)
Syntax case 200: ... break; case 200 -> ...;
Fall-Through Yes (bug-prone if break omitted) No fall-through with arrow syntax
Returns Value? No (statement only) Yes (can assign or return directly)
Multi-statement Return N/A yield value; inside block

Canonical Production Snippet: Modern Switch Expression

public String formatHttpResult(int status) {
    return switch (status) {
        case 200, 201 -> "SUCCESS";
        case 400, 404 -> "CLIENT_ERROR";
        case 500 -> {
            logAlert("Server degraded");
            yield "SERVER_ERROR";
        }
        default -> "UNKNOWN";
    };
}

Senior Production Pitfalls Checklist

  • Avoid Mixing Arrow and Colon Syntax: Javac strictly forbids mixing -> and : labels within the same switch block.
  • Exhaustiveness Requirement: Switch expressions must be exhaustive; always supply a default arm unless switching over an enum or sealed hierarchy.
  • Use Labeled Break for Matrix Loops: Standard break only exits the innermost loop; use labeled breaks to avoid boolean flag bloat.
