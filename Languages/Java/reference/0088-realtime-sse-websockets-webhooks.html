Senior Production Pitfalls Checklist

  • Never Verify HMAC on Re-Serialized JSON: Always read the raw HTTP payload bytes before Jackson parses them.
  • Always Evict Dead SseEmitters: Register onCompletion, onTimeout, and onError callbacks plus per-send IOException removal.
  • Skip SOAP & Full HATEOAS for Greenfield 2027 APIs: Only implement SOAP for legacy integrations; prefer OpenAPI 3.1, gRPC, or GraphQL.
