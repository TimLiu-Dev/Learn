Java 21 Virtual Threads Quick Reference

Property Platform Thread Virtual Thread (Java 21 LTS)
Memory Overhead ~1 MB OS stack ~1 KB in Java heap (grows dynamically)
Creation / Task Model Expensive; requires pooling (FixedThreadPool) Near-zero cost; create per task (never pool!)
Blocking I/O Behavior Blocks OS kernel thread completely Yields continuation; unmounts from carrier thread
Carrier Pinning Trigger N/A (already an OS thread) synchronized blocks and JNI native code

Canonical Production Snippet: Structured Task Execution

public void handleIncomingRequests(List<Request> requests) {
    try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
        for (var req : requests) {
            executor.submit(() -> processRequest(req));
        }
    } // Implicit join and await completion of all virtual threads
}

Senior Production Pitfalls Checklist

  • Never Pool Virtual Threads: Avoid Executors.newFixedThreadPool(N, Thread.ofVirtual().factory()); pooling defeats their design.
  • Eliminate Carrier Pinning: Replace synchronized with ReentrantLock in code paths that perform network or file I/O.
  • ThreadLocals Memory Bloat: Virtual threads can number in the millions; storing large objects in ThreadLocal can cause severe memory bloat. Prefer ScopedValue (Lesson 0033).
