Modern HTTP Client (java.net.http), HTTP/2 & Timeouts — Quick Reference

Modern HTTP Client Reference.

Modern HTTP Client Reference

Component Recommended Configuration Production Purpose
HttpClient Singleton shared instance Shares TCP connection pools, SSL context, and worker threads.
connectTimeout Duration.ofSeconds(3-5) Fails fast when remote network or DNS is unreachable.
request.timeout Duration.ofSeconds(10-30) Prevents hung requests when remote server processes too slowly.
BodyHandlers.ofFile Streaming to disk Safely handles large file downloads without heap memory explosion.

Canonical Production Snippet: Non-Blocking Asynchronous Client

public class GatewayService {
    private static final HttpClient CLIENT = HttpClient.newBuilder()
        .connectTimeout(Duration.ofSeconds(5))
        .version(HttpClient.Version.HTTP_2)
        .build();

    public CompletableFuture<String> fetchPayload(URI uri) {
        HttpRequest request = HttpRequest.newBuilder(uri)
            .timeout(Duration.ofSeconds(10))
            .GET()
            .build();
        return CLIENT.sendAsync(request, HttpResponse.BodyHandlers.ofString())
            .thenApply(HttpResponse::body);
    }
}

Senior Production Pitfalls Checklist

  • Never Instantiate Per-Request: HttpClient is thread-safe and stateful; instantiate once and reuse across the entire application lifecycle.
  • Always Specify Request Timeouts: By default, an HttpRequest has no timeout and can hang indefinitely if the server freezes.
  • Avoid ofString() for Unknown Payloads: Use BodyHandlers.ofInputStream() or BodyHandlers.ofFile() when payload size exceeds a few megabytes.
