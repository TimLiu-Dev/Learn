Prefix Sums & String Hashing Reference

Pattern Preprocessing Query / Update Time
1D Prefix Sums O(N) O(1) Range Sum: P[R+1] - P[L]
2D Prefix Sums O(R * C) O(1) Region Sum via Inclusion-Exclusion
Difference Array O(N) O(1) Range Update: +V at L, -V at R+1

Canonical Production Snippet: 2D Prefix Sum Inclusion-Exclusion

public long querySubgrid(long[][] p, int r1, int c1, int r2, int c2) {
    return p[r2 + 1][c2 + 1] - p[r1][c2 + 1] - p[r2 + 1][c1] + p[r1][c1];
}

Senior Production Pitfalls Checklist

  • Negative Modulo in Java: Always write ((val % MOD + MOD) % MOD) to avoid negative hash values.
  • 1-Indexed Prefix Array: Size your prefix array N + 1 with P[0] = 0 to eliminate edge cases when querying ranges starting at index 0.
  • Long Overflow: Accumulate sums in long[] arrays even when input values are int, avoiding 32-bit integer overflow.
