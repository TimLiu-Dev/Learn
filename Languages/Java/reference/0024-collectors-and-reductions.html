Advanced Collectors, Downstream Grouping, teeing() & Reductions — Quick Reference

Advanced Collectors & Reductions Reference.

Advanced Collectors Reference

Collector Output Type Production Usage
groupingBy(classifier, downstream) Map<K, D> Categorizing items by key with downstream aggregations.
partitioningBy(predicate, downstream) Map<Boolean, D> Binary partitioning into true and false groups.
teeing(c1, c2, merger) Merged R Single-pass dual reductions (sum + count, min + max).
toMap(key, val, mergeRule) Map<K, V> Safe index building with collision resolution.

Canonical Production Snippet: Collectors.teeing() Single-Pass Average

public double calculateAverageSalary(List<Employee> staff) {
    return staff.stream().collect(Collectors.teeing(
        Collectors.summingDouble(Employee::salary),
        Collectors.counting(),
        (sum, count) -> count == 0 ? 0.0 : sum / count
    ));
}

Senior Production Pitfalls Checklist

  • Duplicate Key in toMap: Always supply a merge function (oldVal, newVal) -> oldVal to prevent IllegalStateException on key collisions.
  • Avoid Multiple Passes: Never run stream.count() followed by stream.sum(); use Collectors.teeing() for single-pass dual metrics.
  • Use unmodifiable collections: Use Collectors.toUnmodifiableList() or Stream.toList() to enforce immutability.
