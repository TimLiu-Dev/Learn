Apache Spark Architecture Reference

Component / Feature Core Function Senior Performance Note
Catalyst Optimizer Logical & physical plan optimization Predicate pushdown + column pruning; minimizes scanned bytes.
Project Tungsten Off-heap memory + whole-stage codegen Zero GC pauses; compact binary encoding eliminates object header bloat.

Broadcast Hash Join functions.broadcast(smallTable) Copies table <10MB to all nodes; completely eliminates network shuffle!

Canonical Production Snippet: Broadcast Join

Dataset<Row> joined = orders
    .join(functions.broadcast(currencyRates), "currency_code")
    .filter(functions.col("amount").gt(100));

Senior Production Pitfalls Checklist

  • Shuffle Partitions Tuning: Default spark.sql.shuffle.partitions is 200; on small datasets this creates 200 tiny files, on large datasets it causes executor OOM. Tune based on data volume.
  • Broadcast Table Size Limits: Never broadcast tables larger than available executor memory (e.g. >100MB); doing so triggers Driver and Executor OutOfMemoryError.
  • Avoid Collect on Large Datasets: Never call df.collect() on millions of rows; it pulls all distributed data into the single JVM driver node heap, crashing the driver.
