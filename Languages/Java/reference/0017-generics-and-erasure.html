Generics & Type Erasure Reference.

Generics & Type Erasure Reference

Source Code Generic Bytecode After Erasure Compiler Action
<T> (Unbounded) Object Inserts explicit checkcast bytecodes at call sites.
<T extends Number> Number Replaces T with first upper bound Number.
Generic Overrides Synthetic Bridge Method Generates method(Object) that casts and calls method(T).

Canonical Production Snippet: Type Token Array Instantiation

public class GenericRepository<T> {
    private final Class<T> type;

    public GenericRepository(Class<T> type) {
        this.type = Objects.requireNonNull(type);
    }

    @SuppressWarnings("unchecked")
    public T[] createArray(int size) {
        // Safe runtime array creation using explicit Class type token:
        return (T[]) java.lang.reflect.Array.newInstance(type, size);
    }
}

Senior Production Pitfalls Checklist

  • Cannot Check Generic Types: instanceof List<String> does not compile; test instanceof List<?> instead.
  • Heap Pollution with Varargs: Always mark safe generic varargs methods with @SafeVarargs and make them final or static.
  • Arrays and Generics Do Not Mix: Avoid List<T>[] arrays; prefer collections of collections: List<List<T>>.
