Production Observability: Micrometer, OpenTelemetry Tracing, MDC Logging & Graceful Shutdown — Quick Reference

OpenTelemetry Tracing, MDC & Kubernetes Probes Reference.

Observability & Actuator Reference

Component Standard / Protocol Primary Role
OpenTelemetry Tracing W3C traceparent End-to-end request correlation across distributed microservices.
SLF4J MDC Mapped Diagnostic Context Injects traceId, userId, and tenantId into structured JSON logs.
Liveness Probe /actuator/health/liveness Indicates whether JVM process is deadlocked (triggers container restart).
Readiness Probe /actuator/health/readiness Indicates whether pod can accept traffic (removes from load balancer on failure).

Canonical Production Snippet: Custom Readiness Probe

// Boot 4: import org.springframework.boot.health.contributor.{Health, HealthIndicator};
@Component
public class DatabaseReadinessCheck implements HealthIndicator {
    private final DataSource dataSource;

    public DatabaseReadinessCheck(DataSource dataSource) {
        this.dataSource = dataSource;
    }

    @Override
    public Health health() {
        try (Connection conn = dataSource.getConnection()) {
            if (conn.isValid(1)) {
                return Health.up().withDetail("database", "ONLINE").build();
            }
        } catch (Exception ex) {
            return Health.down(ex).withDetail("database", "OFFLINE").build();
        }
        return Health.down().build();
    }
}

Senior Production Pitfalls Checklist

  • Never Check External DBs in Liveness Probes: If the database has a transient outage, all pods fail liveness simultaneously, causing a cascading restart loop that destroys the cluster. Put external checks in Readiness!
  • Propagate MDC Across Virtual Threads: Wrap executor tasks or use Micrometer Context Propagation to ensure traceId values are not dropped when threads switch.
  • W3C Traceparent Header Parsing: Adhere to the 4-part 00-{traceId}-{spanId}-{flags} standard when validating upstream headers.
