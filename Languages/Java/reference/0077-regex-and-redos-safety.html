Java Regular Expressions (Pattern/Matcher) & ReDoS Defense

Quick-lookup guide for Matcher.find() vs matches(), named capturing groups, quantifier modes, and ReDoS prevention.

Method / ConstructMeaningKey Rule
static final PatternCompiled regex machineImmutable & thread-safe; never call String.matches in hot paths.
matcher.matches()Full-string matchImplicit ^...$ boundaries across whole input.
matcher.find()Substring searchAdvances match cursor forward per match (results() streams them).
a++ / (?>a+)Possessive / atomic quantifierPrevents backtracking into matched characters — eliminates ReDoS!
(?<name>...)Named groupExtract clearly via matchResult.group("name").
