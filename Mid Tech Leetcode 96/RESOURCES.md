# Universal Mid-Tech LeetCode 126 Resources

## Knowledge

- [Introduction to Algorithms (CLRS, 4th Edition) — Cormen, Leiserson, Rivest, Stein](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/)
  Canonical reference for asymptotic analysis, hash collision resolution, dynamic programming formulations, Union-Find (`O(α(N))`), and graph proofs. Use for: mathematical rigor on `O(N)` vs `O(1)` amortized bounds, loop invariants, and formal algorithm design.
- [Algorithms, 4th Edition — Robert Sedgewick & Kevin Wayne](https://algs4.cs.princeton.edu/home/)
  Visual, implementation-driven reference on priority queues, binary search trees, tries, topological sort, and shortest-path graphs. Use for: mental models of binary heaps, `TreeMap` range queries, and BFS/DFS/Dijkstra invariants.
- [Kotlin Standard Library Documentation: Collections Overview](https://kotlinlang.org/docs/collections-overview.html)
  Official reference on Kotlin collection hierarchies (`List`, `MutableList`, `Set`, `Map`, `ArrayDeque`), inline higher-order functions, and primitive arrays (`IntArray` vs `Array<Int>`). Use for: writing zero-overhead, idiomatic Kotlin in technical screens and pair programming.
- [Java SE Platform API Specification: java.util Collections](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/package-summary.html)
  Official Oracle reference for `HashMap`, `HashSet`, `ArrayDeque`, `PriorityQueue`, and `TreeMap`. Use for: bucket treeification (`O(log N)` worst-case bucket lookup), comparator contracts, and primitive boxing caveats.
- [Python 3 Standard Library: Built-in Types, collections & heapq](https://docs.python.org/3/library/stdtypes.html)
  Official Python documentation for `dict`, `set`, `collections.deque`, `bisect`, and `heapq`. Use for: amortized `O(1)` dictionary lookups, `O(1)` `popleft()` queue mechanics, and tuple comparator idioms.
- [CodeSignal Industry Coding Assessment (ICA) & GCA Prep Overview](https://codesignal.com/learn/)
  Overview of timed assessment structures including 4-question GCA (`Q1` warmup, `Q2` array/string, `Q3` matrix/simulation, `Q4` hash/prefix/greedy) and 90-minute 4-Stage Progressive OOP ICAs (`CRUD -> Filter/Sort -> TTL/Quotas -> Rollback/Snapshots`).
- [NeetCode 150 & Practice Roadmap](https://neetcode.io/practice)
  Curated algorithmic problem sets organized by data-structure dependency graph. Use for: external judge cross-checking and company-tagged practice sets.

  High-signal community sharing recent 2026–2027 interview loop debriefs across Fintech, Retail, Mobility, and SaaS companies (Capital One, Stripe, Target, Walmart, Uber, Airbnb, Atlassian, Intuit). Use for: spotting current CodeSignal ICA themes and Karat screen formats.
- [Team Blind (LeetCode & Tech Careers)](https://www.teamblind.com/channels/leetcode)
  Verified engineering forum. Use for: Mid-Level (`SDE II / L4`) vs Senior (`L5`) rubric calibration and company-specific interview stage breakdowns.
- [r/cscareerquestions (Reddit)](https://www.reddit.com/r/cscareerquestions/)
  Broad software engineering career community. Use for: mock interview partner matching and offer/leveling context.
