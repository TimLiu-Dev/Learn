# Universal Mid-Tech LeetCode 96 Resources

## Knowledge

- [Introduction to Algorithms (CLRS) — Cormen, Leiserson, Rivest, Stein](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/)
  Canonical reference for asymptotic analysis, hash collision resolution, dynamic programming formulations, and graph proofs. Use for: mathematical rigor on $O(N)$ vs $O(1)$ amortized bounds, Master Theorem, and formal algorithm design.
- [Algorithms, 4th Edition — Robert Sedgewick & Kevin Wayne](https://algs4.cs.princeton.edu/home/)
  Highly visual, implementation-driven reference on data structures, priority queues, binary search trees, and graphs. Use for: mental models of tree rotations, priority queue binary heaps, and graph search invariants.
- [Kotlin Standard Library Documentation: Collections Overview](https://kotlinlang.org/docs/collections-overview.html)
  Official reference on Kotlin collection hierarchies (`List`, `MutableList`, `Set`, `Map`), inline higher-order functions, and primitive arrays (`IntArray` vs `Array<Int>`). Use for: writing zero-overhead, idiomatic Kotlin in technical phone screens and pair programming.
- [Java SE Platform API Specification: java.util Collections](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/package-summary.html)
  Official Oracle reference for `HashMap`, `HashSet`, `ArrayDeque`, `PriorityQueue`, and `TreeMap`. Use for: internal bucket treeification mechanics ($O(\log N)$ on collision), initial capacity sizing, and boxing/unboxing performance caveats.
- [Python 3 Standard Library: Data Model & Built-in Types](https://docs.python.org/3/library/stdtypes.html)
  Official Python documentation for dictionaries, sets, `collections.deque`, and `heapq`. Use for: amortized $O(1)$ dictionary operations, $O(1)$ deque double-ended pop mechanics, and pythonic interview idioms.
- [NeetCode 150 & Grind 75 Curated Sets](https://neetcode.io/)
  Curated algorithmic interview patterns categorized by data structure and difficulty. Use for: cross-checking frequency distributions, sister problems, and pattern clustering.

## Wisdom (Communities)

- [r/leetcode (Reddit)](https://www.reddit.com/r/leetcode/)
  High-signal community sharing real-world interview loop debriefs, question patterns, and technical screen formats across mid-tech companies. Use for: discovering recent question trends and interview variations.
- [LeetCode Discuss (Interview Questions & Experiences)](https://leetcode.com/discuss/interview-question)
  Direct candidate reports tagging specific mid-tech companies (Target, Capital One, Walmart, Stripe, Uber, Salesforce). Use for: verbatim interview prompts, exact follow-up questions asked by interviewers, and technical/OOP splits.
- [Team Blind (LeetCode & Tech Careers)](https://www.teamblind.com/channels/leetcode)
  Anonymous verified tech worker forum. Use for: company hiring bar calibrations, level-specific expectations (Mid vs Senior), and realistic loop format insights.
- [r/cscareerquestions (Reddit)](https://www.reddit.com/r/cscareerquestions/)
  Broad engineering career community. Use for: prep timelines, mock interview practice partners, and offer evaluation.
