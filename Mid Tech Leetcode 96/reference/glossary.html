1. Core Complexity & Runtime Mechanics

Amortized O(1) Time

Constant average cost per operation over a sequence of operations, even though occasional hash-table or dynamic-array resizing costs O(N).

Guardrail: Never call standard HashMap lookup "guaranteed worst-case O(1)".

Auxiliary Space

Extra memory allocated temporarily by an algorithm beyond the input itself (excluding required output storage unless specified).

Guardrail: Distinguish auxiliary workspace from output list size in Karat Q&A.

Boxing & Unboxing (JVM)

Wrapping a primitive int / Kotlin Int inside a heap-allocated Integer object (~16–24 bytes) inside generic collections like HashSet<Int>.

See: #217, #242 (IntArray(26)).

Canonical Signature (Equivalence Key)

A deterministic representation (sorted chars "aet" or delimited 26-count key "#1#0#0...") shared by every member of an equivalence class.

Guardrail: Always delimit multi-digit counts (#49, #271).

Early Exit (Short-Circuit)

Returning as soon as a decisive witness is found (e.g., first duplicate or first overlap) instead of processing all remaining elements.

See: #217, #252.

Hash Collision

Two distinct keys mapping to the same bucket index, resolved via bucket chaining/treeification plus .equals() key comparison.

Guardrail: Equal hash codes never guarantee equal keys.

In-Place & Input Mutation

Transforming data directly inside the caller's structure using O(1) extra memory (e.g., sorting in place or masking visited grid cells).

Guardrail: Always ask the interviewer if mutating input is acceptable (#48, #79).

Loop Invariant

A condition guaranteed true before and after every loop iteration that proves correctness when the loop terminates.

Tip: Naming your invariant is the fastest way to fix off-by-one bugs.

2. Algorithmic Pattern & Data-Structure Invariants

Sliding Window Invariant

Maintaining a valid contiguous [left..right] range by advancing right greedily and advancing left monotonically on constraint violation.

See: #3, #424, #76.

Prefix Sum + HashMap / Binary Search

Precomputing cumulative sums so range sums take O(1) (#560 with negatives) or weighted interval sampling takes O(log N) (#528).

Guardrail: Sliding Window fails when negative numbers break monotonicity.

Sub-Box Coordinate Indexing

Mapping cell (r, c) on a 9 × 9 board to its 3 × 3 box index 0..8 via (r / 3) * 3 + (c / 3) in O(1).

See: #36 Valid Sudoku (classic GCA Q3 pattern).

Monotonic Stack / Deque

Evicting elements that violate strict monotonicity before pushing, resolving Next Greater/Smaller or sliding window extrema in amortized O(N).

See: #739, #239.

Dummy Sentinel & Floyd's Fast/Slow

Using a placeholder ListNode(0) to eliminate head special cases, and 1x/2x pointers to detect cycles or split lists at the midpoint.

See: #19, #2, #143.

Lower-Bound & Binary Search on Answer

Halving either a sorted index range or a monotonic feasibility range [minAns..maxAns] via mid = left + (right - left) / 2.

See: #34, #875.

Comparator Inversion in Size-K Heaps

In a size-K Min-Heap that evicts the worst item first, tie-breakers must place the worse tie-breaker (e.g., lexicographically larger word) at the root so it is polled first.

See: #703, #692.

Same-Depth Sibling Deduplication

Sorting candidates and skipping i > start && nums[i] == nums[i - 1] so equal values aren't branched twice at the same tree depth while still allowing child reuse at i == start.

See: #40 Combination Sum II, #15 3Sum.

Union-Find (Disjoint Set Union)

Merging undirected components or entity equivalence classes in O(α(N)) amortized time via path compression + union by rank/size.

See: #684, #721 Accounts Merge.

Kahn's Topological BFS & Dijkstra

Kahn's peels indegree == 0 DAG nodes (#207, #210); Dijkstra pops min cumulative cost on non-negative weighted edges (#743).

Guardrail: Mark unweighted BFS visited on enqueue (#1091), not dequeue.

0/1 vs. Unbounded Knapsack & Dual-Extremum DP

Iterate 1D capacity backward for single-use 0/1 (#416), forward for unlimited reuse (#322), and track (curMax, curMin) when negatives flip sign (#152).

Trie (Prefix Tree)

Multi-way character or path tree resolving prefix lookups in O(L) independent of dictionary count N.

See: #208, #211, #588.

3. 2027 Multi-Tier OOP & CodeSignal 4-Stage ICA Mechanics

Half-Open Deterministic TTL [ts, ts + ttl)

A record written at integer timestamp with duration ttl is live while now < timestamp + ttl and expired at now >= timestamp + ttl.

See: #0067 KV Store ICA. Never call System.currentTimeMillis() in ICA tests.

Before-Image Delta Undo Stack

Recording only the first pre-transaction Entry? per mutated key in the top UndoMap for O(1) begin and O(T) rollback; nested commit merges via putIfAbsent.

See: #0067 KV Store ICA.

Swap-with-Last O(1) Deletion

Deleting index idx from an ArrayList in O(1) by copying list.last() into list[idx], updating indexMap[lastVal] = idx, and popping the tail.

See: #380 Insert Delete GetRandom O(1).

Quota Eviction & Scoped Entity Snapshots

Evicting a user's largest files (tie-breaking lexicographically) when capacity shrinks, and snapshotting per-user path -> size maps while respecting global path collisions on restore.

See: #0126 Cloud Storage 4-Stage ICA.
