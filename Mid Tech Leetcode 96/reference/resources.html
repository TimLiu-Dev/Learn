4-Stage Progressive OOP Systems

Capital One, Stripe, Coinbase, Robinhood, Dropbox, and DoorDash rely heavily on 90-minute 4-Level Progressive ICAs where each stage unlocks only after all tests on the current stage pass.

  • Rule 1: Wrap state in a record class (Entry / FileMeta) in Level 1 so Level 3 TTL/quotas need zero schema rewrite.
  • Rule 2: Use deterministic integer timestamps (now < ts + ttl), never wall-clock threads.
  • Rule 3: Budget 12m / 18m / 28m / 32m across Levels 1–4.
