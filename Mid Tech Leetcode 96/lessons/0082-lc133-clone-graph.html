LeetCode #133: Clone Graph

Official LC #133

Official Problem Statement

Given a reference of a node in a connected undirected graph.

Return a deep copy (clone) of the graph.

Each node in the graph contains a value (int) and a list (List[Node]) of its neighbors.

class Node {
    public int val;
    public List<Node> neighbors;
}

Test case format: For simplicity, each node's value is the same as the node's index (1-indexed). For example, the first node with val == 1, the second node with val == 2, and so on. The graph is represented in the test case using an adjacency list.

Example 1: adjList = [[2,4],[1,3],[2,4],[1,3]] → Output: [[2,4],[1,3],[2,4],[1,3]] Explanation: There are 4 nodes in the graph. 1st node (val = 1)'s neighbors are 2nd node (val = 2) and 4th node (val = 4). 2nd node (val = 2)'s neighbors are 1st node (val = 1) and 3rd node (val = 3). 3rd node (val = 3)'s neighbors are 2nd node (val = 2) and 4th node (val = 4). 4th node (val = 4)'s neighbors are 1st node (val = 1) and 3rd node (val = 3).

Example 2: adjList = [[]] → Output: [[]] Explanation: Note that the input contains one empty list. The graph consists of only one node with val = 1 and it does not have any neighbors.

Example 3: adjList = [] → Output: [] Explanation: This an empty graph, it does not have any nodes.

Plain-English Translation & Core Nuance

A deep copy means every node and neighbor list must be brand-new memory objects, with the exact same values and connectivity as the original graph. Because graphs have cycles, navigating without tracking visited nodes causes infinite recursion. We maintain a hash map `cloned = HashMap()` mapping original nodes to their cloned copies. For any node, if it's already in the map, return the existing copy. Otherwise, create `Node(node.val)`, store it in the map, and recursively clone each neighbor, adding each clone to `copy.neighbors`.

Official Constraints:
  • The number of nodes in the graph is in the range [0, 100].
  • 1 <= Node.val <= 100
  • Node.val is unique for each node.
  • There are no repeated edges and no self-loops in the graph.
  • The Graph is connected and all nodes can be visited starting from the given node.

The Mental Model & "Explain Like I'm 12"

💡 The Identity Registry & 3D Printer

Imagine a network of friends holding hands in circles. To clone this network, you walk up to person 1. If you haven't 3D-printed a twin for them yet, you print `Twin(1)` and write their name in your registry: `Original 1 -> Twin 1`. Then you look at person 1's friends. For each friend, you consult the registry: if their twin already exists, you simply have `Twin(1)` hold hands with that existing twin. If not, you print that friend's twin and recurse. Because of the registry, you never print the same person twice and never get stuck in an endless loop.

The Mental "A-Ha!" Switch:

Put the cloned node into the map BEFORE recursing on its neighbors! If you wait until after recursing, a cycle will try to clone the original node again, causing a stack overflow.

Pattern Trigger:

Deep copy of cyclic data structure / graph → Hash Map (`original -> clone`) combined with DFS or BFS.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(V + E) Time, O(V) Space

DFS/BFS with HashMap. Since every node and edge must be duplicated, O(V + E) is both theoretically and practically optimal.

Wasted Work: Re-instantiating nodes or getting stuck in infinite loops if a visited set/map is omitted.
The Optimal Breakthrough O(V + E) Time, O(V) Space

HashMap + DFS recursion or BFS queue. Traverses every vertex once and every edge twice (undirected).

Core Invariant: Every unique node `u` in the original graph corresponds to exactly one node `cloned[u]` in the cloned graph, created before its outgoing edges are explored.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
DFS with Map (Pre-order) O(V + E) O(V) Cleanest code; recursion stack depth bounded by V.
BFS with Map + Queue O(V + E) O(V) Iterative; avoids call stack overhead for very deep graphs.

Production Implementations

From Naive to Optimal & Runnable Practice Arena

Strict ordering: Kotlin (Default) → Python → Java across all approaches.

DFS with Cloned Node Hash Map

Depth-first traversal with a hash map `cloned = HashMap()`. Instantiate and store each node before exploring its neighbors to avoid cycle recursion.

Time: O(V + E) Time Space: O(V) Space 
class Solution {
    private val cloned = HashMap<Node, Node>()

    fun cloneGraph(node: Node?): Node? {
        if (node == null) return null
        // If already cloned, return existing copy (breaks cycles)
        if (cloned.containsKey(node)) return cloned[node]

        // Create copy and record immediately before recursing on neighbors
        val copy = Node(node.`val`)
        cloned[node] = copy

        for (neighbor in node.neighbors) {
            neighbor?.let {
                copy.neighbors.add(cloneGraph(it))
            }
        }
        return copy
    }
}

class Solution:
    def cloneGraph(self, node: 'Optional[Node]') -> 'Optional[Node]':
        if not node:
            return None
        
        cloned = {}
        
        def dfs(curr: 'Node') -> 'Node':
            if curr in cloned:
                return cloned[curr]
            
            copy = Node(curr.val)
            cloned[curr] = copy
            
            for neighbor in curr.neighbors:
                copy.neighbors.append(dfs(neighbor))
            return copy

class Solution {
    private final Map<Node, Node> cloned = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (cloned.containsKey(node)) return cloned.get(node);

        Node copy = new Node(node.val);
        cloned.put(node, copy);

        for (Node neighbor : node.neighbors) {
            copy.neighbors.add(cloneGraph(neighbor));
        }
        return copy;
    }
}

"Crucially, we must store the new cloned node in the map *before* we iterate through its neighbors. If node A has neighbor B, and B has neighbor A, when B looks up A, A is already in the map, returning immediately and terminating the cycle."
