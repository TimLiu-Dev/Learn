LeetCode #853: Car Fleet

Official LC #853

Official Problem Statement

There are n cars at given miles away from the starting mile 0, traveling to reach the mile target.

You are given two integer arrays position and speed, both of length n, where position[i] is the starting mile of the ith car and speed[i] is the speed of the ith car in miles per hour.

A car cannot pass another car ahead of it. It can only catch up to the car ahead at the same speed. A car fleet is some non-empty set of cars driving at the same position and same speed. Note that a single car is also considered a car fleet.

If a car catches up to a car fleet right at the destination point, it will still be considered as part of the car fleet.

Return the number of car fleets that will arrive at the destination.

Example 1: target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3] → Output: 3 Explanation: - The cars starting at 10 (speed 2) and 8 (speed 4) become a fleet, meeting each other at 12. The fleet forms at target. - The car starting at 0 (speed 1) does not catch up to any other car, so it is a fleet by itself. - The cars starting at 5 (speed 1) and 3 (speed 3) become a fleet, meeting each other at 6. The fleet moves at speed 1 until it reaches target. Total fleets = 3.

Example 2: target = 10, position = [3], speed = [3] → Output: 1

Example 3: target = 100, position = [0,2,4], speed = [4,2,1] → Output: 1

Plain-English Translation & Core Nuance

Calculate each car's remaining arrival time: `time = (target - position) / speed`. Sort the cars in descending order of starting position (closest to target first). Iterate from closest to farthest: if a car behind arrives earlier or at the same time as the fleet in front (`time <= leaderTime`), it gets stuck behind it and merges into that fleet. If it takes strictly longer (`time > leaderTime`), it cannot catch up and becomes the leader of a new fleet.

Official Constraints:
  • n == position.length == speed.length
  • 1 <= n <= 10^5
  • 0 <= position[i] < target
  • All the values of position are unique.
  • 0 < speed[i] <= 10^6

The Mental Model & "Explain Like I'm 12"

💡 The Narrow One-Lane Mountain Highway

Imagine a single-lane mountain highway with no passing allowed. The car closest to the summit reaches it at some time T. Any car behind it that could drive faster will simply get stuck behind this car, slowed down to its pace, arriving at that exact same time T. Only a car that is so slow that its arrival time is strictly greater than T will form a new, separate traffic jam behind it.

The Mental "A-Ha!" Switch:

Cars cannot pass. Therefore, sorting by position descending allows us to resolve fates from front to back. A car behind merges if its arrival time <= the fleet ahead. Maintaining a monotonic decreasing stack (or a simple running max time) yields the fleet count directly.

Pattern Trigger:

Objects moving at different speeds along a line without overtaking → Sort by position descending + Monotonic arrival time comparison.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(T * N) Time, O(N) Space

Discrete time step simulation: advance all cars by their speeds every tick, checking for collisions and grouping fleets.

Wasted Work: Simulating millions of continuous time increments; floating point collision precision errors.
The Optimal Breakthrough O(N log N) Time, O(N) Space

Sort cars by position descending. Single linear pass comparing arrival times to the current fleet leader's arrival time.

Core Invariant: A car at position `p2 < p1` merges into the fleet at `p1` if and only if `(target - p2) / v2 <= (target - p1) / v1`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Discrete Time Simulation O(Time * N) O(N) Severely times out; prone to floating point errors.
2. Monotonic Stack O(N log N) O(N) Pushes arrival times; pops if time <= top.
★ 3. Sort + Running Max Scalar O(N log N) O(N) Optimal; compares arrival time to maxTime without extra stack pushes.

Approach 1: Monotonic Decreasing Stack

Sort cars by position descending. Compute arrival times and push to stack. If new time <= top of stack, it merges so pop new time. Stack size at end is fleet count.

Time: O(N log N) Time Space: O(N) Space 
import java.util.ArrayDeque

class Solution {
    fun carFleet(target: Int, position: IntArray, speed: IntArray): Int {
        val n = position.size
        val cars = Array(n) { i -> Pair(position[i], speed[i]) }
        cars.sortByDescending { it.first }

        val stack = ArrayDeque<Double>()
        for (car in cars) {
            val time = (target - car.first).toDouble() / car.second
            if (stack.isEmpty() || time > stack.peek()) {
                stack.push(time)
            }
        }
        return stack.size
    }
}

import java.util.Arrays;
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int carFleet(int target, int[] position, int[] speed) {
        int n = position.length;
        double[][] cars = new double[n][2];
        for (int i = 0; i < n; i++) {
            cars[i][0] = position[i];
            cars[i][1] = speed[i];
        }

        Arrays.sort(cars, (a, b) -> Double.compare(b[0], a[0]));

        Deque<Double> stack = new ArrayDeque<>();
        for (double[] car : cars) {
            double time = (target - car[0]) / car[1];
            if (stack.isEmpty() || time > stack.peek()) {
                stack.push(time);
            }
        }
        return stack.size();
    }
}

★ Approach 2: Sort + Running Max Arrival Time (Production Optimal)

Eliminates the stack! A simple scalar `maxTime` tracks the arrival time of the current fleet leader ahead. If a car's time > maxTime, increment fleet count and update maxTime.

Time: O(N log N) Time Space: O(N) Space 
class Solution {
    fun carFleet(target: Int, position: IntArray, speed: IntArray): Int {
        val n = position.size
        val cars = Array(n) { i -> Pair(position[i], speed[i]) }
        cars.sortByDescending { it.first }

        var fleets = 0
        var maxTime = 0.0

        for (car in cars) {
            val time = (target - car.first).toDouble() / car.second
            if (time > maxTime) {
                fleets++
                maxTime = time
            }
        }
        return fleets
    }
}

import java.util.Arrays;

class Solution {
    public int carFleet(int target, int[] position, int[] speed) {
        int n = position.length;
        int[][] cars = new int[n][2];
        for (int i = 0; i < n; i++) {
            cars[i][0] = position[i];
            cars[i][1] = speed[i];
        }

        Arrays.sort(cars, (a, b) -> Integer.compare(b[0], a[0]));

        int fleets = 0;
        double maxTime = 0.0;

        for (int[] car : cars) {
            double time = (double)(target - car[0]) / car[1];
            if (time > maxTime) {
                fleets++;
                maxTime = time;
            }
        }
        return fleets;
    }
}
