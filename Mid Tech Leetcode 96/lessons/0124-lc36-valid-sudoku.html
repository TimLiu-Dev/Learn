Problem #36: Valid Sudoku

External Judge ↗

Official Problem Statement

Determine if a 9 x 9 Sudoku board is valid. Only the filled cells need to be validated according to the following rules:
1. Each row must contain the digits 1-9 without repetition.
2. Each column must contain the digits 1-9 without repetition.
3. Each of the nine 3 x 3 sub-boxes of the grid must contain the digits 1-9 without repetition.

Note: Empty cells are '.'. A partially filled Sudoku board can be valid without necessarily being solvable!

Example 1: Standard partial 9x9 board with unique digits in every row, col, and 3x3 box → Output: true

Example 2: Top-left cell changed from '5' to '8', colliding with '8' in row 0 / box 0 → Output: false

Plain-English Translation & Core Nuance

Do NOT run a backtracking Sudoku solver! Simply scan all 81 cells once, skip '.', map (r, c) to its 3 x 3 box index box = (r / 3) * 3 + (c / 3), and verify digit d hasn't already appeared in rows[r], cols[c], or boxes[box].

Official Constraints:
  • board.length == 9, board[i].length == 9
  • board[i][j] is a digit '1'-'9' or '.'.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Board of all '.' empty cells -> Every cell is skipped, returns true.
Best-Case Early Exit
Duplicate digit in row 0 (e.g., two '8's) -> Detected immediately in the first few cells, returns false.
Worst-Case Full Scan
All 81 cells checked once -> Fixed 81 iterations using three 9-int bitmask arrays.

Section 01 • Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 Three Simultaneous Attendance Sheets + The (r/3)*3 + (c/3) Coordinate Formula

Every filled cell (r, c) belongs to three clubs at once: Row r, Column c, and one of the nine 3 x 3 neighborhoods. Dividing r / 3 gives the macro-row 0..2 and c / 3 gives the macro-col 0..2; flattening a 3 x 3 macro-grid into 0..8 uses standard 2D-to-1D row-major math macroRow * 3 + macroCol = (r / 3) * 3 + (c / 3)! Even better: each attendance sheet only tracks digits 0..8, which fits in a single 9-bit integer bitmask (1 shl d)!

The Mental "A-Ha!" Switch:

boxIdx = (r / 3) * 3 + (c / 3) + three 9-element integer bitmasks (rows[9], cols[9], boxes[9]) validates the entire board in 1 pass and 108 bytes!

Section 02 • Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap 3 Separate Passes + String Allocation

Write 3 separate nested loop blocks (one for rows, one for cols, one for 4-nested 3x3 boxes) or build string keys per cell.

Wasted Work: Four-deep nested box loops are bug-prone under GCA time pressure, and string concatenation allocates up to 243 strings.
The Optimal Breakthrough O(1) Fixed 81-Cell Pass (O(N²) for N×N), O(1) Space

One r in 0..8, c in 0..8 loop checking bit bit = 1 shl (ch - '1') against rows[r], cols[c], and boxes[(r / 3) * 3 + (c / 3)].

Core Invariant: Bit d of rows[r], cols[c], and boxes[b] is 1 iff digit (d + 1) has already been seen in that row, column, or 3x3 box.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
3 Separate Loops (Rows, Cols, Boxes) 3 × 81 ops O(1) Verbose 4-loop sub-box indexing invites off-by-one bugs.
Single Pass + Boolean[9][9] Tables 81 ops 243 bools Super readable alternative in interviews.
Optimal: Single Pass + 9-Int Bitmasks 81 ops 27 ints ★ Zero object allocation, instant bitwise OR/AND check.

From Naive to Optimal & Runnable Practice Arena

Single Pass with 2D Boolean Tables

Tracks rows[9][9], cols[9][9], and boxes[9][9] boolean flags in one 81-cell pass.

Time: O(1) (81 cells) Space: O(1) (243 bools) 
class Solution {
    fun isValidSudoku(board: Array<CharArray>): Boolean {
        val rows = Array(9) { BooleanArray(9) }
        val cols = Array(9) { BooleanArray(9) }
        val boxes = Array(9) { BooleanArray(9) }
        for (r in 0 until 9) {
            for (c in 0 until 9) {
                val ch = board[r][c]
                if (ch == '.') continue
                val d = ch - '1'
                val b = (r / 3) * 3 + (c / 3)
                if (rows[r][d] || cols[c][d] || boxes[b][d]) return false
                rows[r][d] = true
                cols[c][d] = true
                boxes[b][d] = true
            }
        }
        return true
    }
}

Optimal: Single Pass with 9-Int Bitmasks

Compresses each row, column, and 3x3 sub-box into a 9-bit integer mask for zero-allocation bitwise validation.

Time: O(1) (81 cells) Space: O(1) (27 ints) 
class Solution {
    fun isValidSudoku(board: Array<CharArray>): Boolean {
        val rows = IntArray(9)
        val cols = IntArray(9)
        val boxes = IntArray(9)
        for (r in 0 until 9) {
            for (c in 0 until 9) {
                val ch = board[r][c]
                if (ch == '.') continue
                val bit = 1 shl (ch - '1')
                val b = (r / 3) * 3 + (c / 3)
                if ((rows[r] and bit) != 0 || (cols[c] and bit) != 0 || (boxes[b] and bit) != 0) {
                    return false
                }
                rows[r] = rows[r] or bit
                cols[c] = cols[c] or bit
                boxes[b] = boxes[b] or bit
            }
        }
        return true
    }
}

        Section 06 • Live Interview Execution Transcript
        
Live Interview Spoken Script & Mid-Level (L4) Follow-Ups

        
4-phase spoken communication script for Karat, pair-programming screens, and onsite loops.

      


      

        

          Phase 1: Clarifying Constraints
          
First, an important scope check: we are ONLY validating that currently filled digits '1'..'9' don't repeat in any row, column, or 3 x 3 sub-box—we do NOT need to check whether the board is solvable!

        

        

          Phase 2: Space-Time Trade-Off Pitch
          
Writing three separate multi-loop passes is verbose and error-prone. Instead, one 9 x 9 scan maps any cell (r, c) to its 3 x 3 box 0..8 via (r / 3) * 3 + (c / 3) and uses three 9-int bitmasks (rows, cols, boxes).

        

        

          Phase 3: Clean Implementation Narration
          
For each non-dot cell, bit = 1 shl (ch - '1'); if (rows[r] and bit) != 0 or cols or boxes has that bit set, return false; otherwise OR bit into all three masks.

        

        

          Phase 4: Boundary Dry-Run Verification
          
Checking (2, 2): r/3 = 0, c/3 = 0 -> box = 0 (same box as (0, 0)!). Checking (4, 7): r/3 = 1, c/3 = 2 -> box = 1*3 + 2 = 5.

        

      


      

        ⚡ Mid-Level (L4) Production & Requirement-Pivot Follow-Up:
        
If generalized to an N x N Sudoku (N = K², e.g., 64 x 64 where N > 32 exceeds 32-bit Int bitmasks), replace IntArray(N) with Array(N) { BooleanArray(N) } or BitSet(N) and compute box = (r / K) * K + (c / K) in O(N²) time.
