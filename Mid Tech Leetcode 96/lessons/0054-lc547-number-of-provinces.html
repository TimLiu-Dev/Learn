LeetCode #547: Number of Provinces

Official LC #547

Official Problem Statement

There are n cities. Some of them are connected, while some are not. If city a is connected directly with city b, and city b is connected directly with city c, then city a is connected indirectly with city c.

A province is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an n x n matrix isConnected where isConnected[i][j] = 1 if the ith city and the jth city are directly connected, and isConnected[i][j] = 0 otherwise.

Return the total number of provinces.

Example 1: isConnected = [[1,1,0],[1,1,0],[0,0,1]] → Output: 2

Example 2: isConnected = [[1,0,0],[0,1,0],[0,0,1]] → Output: 3

Plain-English Translation & Core Nuance

Count the number of connected components in an undirected graph given as an adjacency matrix. Loop through all cities `0` to `n - 1`. If city `i` has not been visited, increment province count and launch a DFS/BFS to visit every city reachable from `i`.

Official Constraints:
  • 1 <= n <= 200
  • n == isConnected.length
  • n == isConnected[i].length
  • isConnected[i][j] is 1 or 0.
  • isConnected[i][i] == 1
  • isConnected[i][j] == isConnected[j][i]

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single city [[1]] → Returns 1 province.
Best-Case Early Exit
All cities connected isConnected[i][j] == 1 → Sunk in 1 DFS call, returns 1.
Worst-Case Full Scan
Identity matrix (all 0s off-diagonal) → Every city isolated, returns N provinces.

The Mental Model & "Explain Like I'm 12"

💡 Social Network Friendship Circles

Think of N students in a school. If Alice is friends with Bob, and Bob is friends with Charlie, they all belong to the same social circle (province). To count the distinct friendship circles, you pick an uncounted student, invite everyone in their entire friend network into the gymnasium, and count them as Circle #1. You then find the next student who hasn't been called yet and repeat. The number of groups called is the number of provinces.

The Mental "A-Ha!" Switch:

This is identical to 'Number of Islands', but instead of a 4-directional grid, the graph is represented by an N \times N adjacency matrix! Each DFS visits city `u` by looping `for (v in 0 until n)` and recursing if `isConnected[u][v] == 1` and `!visited[v]`.

Pattern Trigger:

Connected components in undirected graph, adjacency matrix clusters → DFS with boolean visited array or Disjoint Set Union (Union-Find).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2 * alpha(N)) Time, O(N) Space

Initialize Disjoint Set Union with N sets. Loop through all pairs `(i, j)` where `i < j`: if `isConnected[i][j] == 1`, union them and decrement count.

Wasted Work: Union-Find structure overhead when a simple DFS visits each vertex and edge in O(N^2) time.
The Optimal Breakthrough O(N^2) Time, O(N) Auxiliary Space

DFS with boolean `visited` array. Scans each row of the adjacency matrix once.

Core Invariant: After completing DFS for city `i`, every city in `i`'s connected component has `visited[c] == true`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Disjoint Set Union (Union-Find) O(N^2 * alpha(N)) O(N) Excellent for dynamic graphs where edges arrive over time.
2. Queue BFS with Visited Array O(N^2) O(N) Iterative FIFO exploration of components.
★ 3. Recursive DFS with Boolean Array O(N^2) O(N) Call Stack Standard optimal algorithm. Cleanest in interviews.

Disjoint Set Union (Union-Find)

Initialize DSU with N components. Loop over all pairs (i, j): if isConnected[i][j] == 1, union them.

Time: O(N^2 * alpha(N)) Space: O(N) 
class Solution {
    fun findCircleNum(isConnected: Array<IntArray>): Int {
        val n = isConnected.size
        val parent = IntArray(n) { it }
        var provinces = n

        fun find(i: Int): Int {
            var root = i
            while (root != parent[root]) root = parent[root]
            var curr = i
            while (curr != root) {
                val nxt = parent[curr]
                parent[curr] = root
                curr = nxt
            }
            return root
        }

        fun union(i: Int, j: Int) {
            val r1 = find(i)
            val r2 = find(j)
            if (r1 != r2) {
                parent[r1] = r2
                provinces--
            }
        }

        for (i in 0 until n) {
            for (j in i + 1 until n) {
                if (isConnected[i][j] == 1) {
                    union(i, j)
                }
            }
        }

        return provinces
    }
}

Union-Find with path compression. Decrements component counter on each successful union.

class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        parent = list(range(n))
        provinces = n

        def find(i):
            if parent[i] == i: return i
            parent[i] = find(parent[i])
            return parent[i]

        def union(i, j):
            nonlocal provinces
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
                provinces -= 1

        for i in range(n):
            for j in range(i + 1, n):
                if isConnected[i][j] == 1:
                    union(i, j)

        return provinces

class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        int[] parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        int provinces = n;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) {
                    int r1 = find(parent, i);
                    int r2 = find(parent, j);
                    if (r1 != r2) {
                        parent[r1] = r2;
                        provinces--;
                    }
                }
            }
        }

        return provinces;
    }

    private int find(int[] parent, int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent, parent[i]);
    }
}

Breadth-First Search (Queue BFS)

Iterate cities 0..N-1. For each unvisited city, increment count and run Queue BFS to mark all connected cities.

Time: O(N^2) Space: O(N) 
class Solution {
    fun findCircleNum(isConnected: Array<IntArray>): Int {
        val n = isConnected.size
        val visited = BooleanArray(n)
        var provinces = 0
        val queue = ArrayDeque<Int>()

        for (i in 0 until n) {
            if (!visited[i]) {
                provinces++
                queue.add(i)
                visited[i] = true

                while (queue.isNotEmpty()) {
                    val u = queue.removeFirst()
                    for (v in 0 until n) {
                        if (isConnected[u][v] == 1 && !visited[v]) {
                            visited[v] = true
                            queue.add(v)
                        }
                    }
                }
            }
        }
        return provinces
    }
}

class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int provinces = 0;
        Queue<Integer> queue = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                queue.offer(i);
                visited[i] = true;
                while (!queue.isEmpty()) {
                    int u = queue.poll();
                    for (int v = 0; v < n; v++) {
                        if (isConnected[u][v] == 1 && !visited[v]) {
                            visited[v] = true;
                            queue.offer(v);
                        }
                    }
                }
            }
        }
        return provinces;
    }
}

Recursive Depth-First Search (Optimal Primary)

Loop over cities 0..N-1. If unvisited, increment province count and launch recursive DFS to visit component.

Time: O(N^2) Space: O(N) Call Stack 
class Solution {
    /**
     * Optimal: Recursive DFS Connected Components
     * Time: O(N^2) - Traverses N x N adjacency matrix
     * Space: O(N) - Visited boolean array and recursion stack
     */
    fun findCircleNum(isConnected: Array<IntArray>): Int {
        val n = isConnected.size
        val visited = BooleanArray(n)
        var provinces = 0

        fun dfs(u: Int) {
            visited[u] = true
            for (v in 0 until n) {
                if (isConnected[u][v] == 1 && !visited[v]) {
                    dfs(v)
                }
            }
        }

        for (i in 0 until n) {
            if (!visited[i]) {
                provinces++
                dfs(i)
            }
        }

        return provinces
    }
}

class Solution {
    /**
     * Optimal: Recursive DFS Connected Components
     * Time: O(N^2) - Iterates over N x N matrix
     * Space: O(N) - Recursion stack bounded by N
     */
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int provinces = 0;

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                provinces++;
                dfs(i, isConnected, visited);
            }
        }

        return provinces;
    }

    private void dfs(int u, int[][] isConnected, boolean[] visited) {
        visited[u] = true;
        for (int v = 0; v < isConnected.length; v++) {
            if (isConnected[u][v] == 1 && !visited[v]) {
                dfs(v, isConnected, visited);
            }
        }
    }
}
