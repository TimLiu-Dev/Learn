LeetCode #15: 3Sum

Official LC #15

Official Problem Statement

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.

Example 1: nums = [-1,0,1,2,-1,-4] → Output: [[-1,-1,2],[-1,0,1]] Explanation: nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0. nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0. nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0. The distinct triplets are [-1,0,1] and [-1,-1,2].

Example 2: nums = [0,1,1] → Output: [] Explanation: The only possible triplet does not sum up to 0.

Example 3: nums = [0,0,0] → Output: [[0,0,0]] Explanation: The only possible triplet sums up to 0.

Plain-English Translation & Core Nuance

Sort the array first. Fix each element nums[i] with an outer loop, then use inward Two Pointers (left = i + 1, right = n - 1) to find pairs that sum to -nums[i]. To prevent duplicate triplets in the output, advance past identical adjacent numbers at both the outer loop and inner pointer levels.

Official Constraints:
  • 3 <= nums.length <= 3000
  • -10^5 <= nums[i] <= 10^5

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Exactly 3 elements nums = [0, 0, 0] → Returns `[[0, 0, 0]]`.
Best-Case Early Exit
All positive or first element > 0 after sort nums = [1, 2, 3] → Returns `[]` immediately since sum can never be 0.
Worst-Case Full Scan
Many duplicates nums = [-2, 0, 0, 2, 2] → Skipped correctly without allocating duplicates.

Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 Anchor One Weight, Balance the Other Two

Imagine balancing a 3-pan scale to 0. First, sort all weights in a line. Choose one weight `nums[i]` as your anchor. Now you need two remaining weights to balance `-nums[i]`. Place one pointer at the lightest available weight (`left`) and one at the heaviest (`right`). If the sum is too light, step `left` inward to heavier weights. If too heavy, step `right` inward to lighter weights. Skip identical duplicate weights along the way.

The Mental "A-Ha!" Switch:

Sorting the array upfront costs O(N log N), which is completely dominated by the O(N^2) two-pointer search. In exchange, sorting makes duplicate skipping trivial and enables directional O(N) two-pointer convergence.

Pattern Trigger:

Find distinct combinations of 3 elements summing to target → Sort + Outer Anchor Loop + Inward Two Pointers.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^3) Time, O(N) Space

Three nested loops trying all triplets (i, j, k), sorting each triplet and inserting into a set to eliminate duplicates.

Wasted Work: Testing cubic combinations and heavy hashing overhead to deduplicate triplets (N=3000 \rightarrow 2.7 \times 10^{10} ops).
The Optimal Breakthrough O(N^2) Time, O(1) or O(log N) Space

Sort in O(N log N). Outer loop runs N times; inner two pointers scan in O(N). Duplicate skipping handles uniqueness in-place.

Core Invariant: For a fixed sorted anchor `nums[i]`, `nums[left] + nums[right] == -nums[i]`. `left < right` always holds, and duplicates are skipped before next search.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute Force (3 Nested Loops) O(N^3) O(N) Severe TLE on N = 3,000.
2. Hash Set Two-Sum Inner Loop O(N^2) O(N) Requires hash set of lists to prevent duplicate triplets.
★ 3. Sort + Two Pointers O(N^2) O(1) to O(log N) Gold standard; zero auxiliary memory beyond sorting.

Approach 1: Cubic Triple Loops + HashSet (O(N^3))

Loop over all triplets (i, j, k). For each matching triplet, sort it and insert into a HashSet to filter duplicate combinations.

Time: O(N^3) Time Space: O(N) Space 
class Solution {
    fun threeSum(nums: IntArray): List<List<Int>> {
        val n = nums.size
        val set = mutableSetOf<List<Int>>()
        for (i in 0 until n) {
            for (j in i + 1 until n) {
                for (k in j + 1 until n) {
                    if (nums[i] + nums[j] + nums[k] == 0) {
                        val triplet = listOf(nums[i], nums[j], nums[k]).sorted()
                        set.add(triplet)
                    }
                }
            }
        }
        return set.toList()
    }
}

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        int n = nums.length;
        Set<List<Integer>> set = new HashSet<>();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    if (nums[i] + nums[j] + nums[k] == 0) {

                        set.add(trip);
                    }
                }
            }
        }

    }
}

Approach 2: Hash Map Complement Lookup (O(N^2) Time, O(N) Space)

Sort the array. For each anchor i, run a Two-Sum HashMap search on the remaining subarray, keeping track of seen values in a set to avoid duplicates.

Time: O(N^2) Time Space: O(N) Space 
class Solution {
    fun threeSum(nums: IntArray): List<List<Int>> {
        nums.sort()
        val res = mutableListOf<List<Int>>()
        for (i in nums.indices) {
            if (i > 0 && nums[i] == nums[i - 1]) continue
            val seen = mutableSetOf<Int>()
            var j = i + 1
            while (j < nums.size) {
                val complement = -nums[i] - nums[j]
                if (seen.contains(complement)) {
                    res.add(listOf(nums[i], complement, nums[j]))
                    while (j + 1 < nums.size && nums[j] == nums[j + 1]) j++
                }
                seen.add(nums[j])
                j++
            }
        }
        return res
    }
}

★ Approach 3: Sort + Inward Two Pointers (Production Optimal)

Sort once. Anchor nums[i], then converge left and right pointers. Skip duplicate anchors and duplicate inner values in-place.

Time: O(N^2) Time Space: O(1) Auxiliary Space 
class Solution {
    fun threeSum(nums: IntArray): List<List<Int>> {
        nums.sort()
        val res = mutableListOf<List<Int>>()
        val n = nums.size

        for (i in 0 until n - 2) {
            // Early exit: if the smallest remaining number is > 0, sum can never be 0
            if (nums[i] > 0) break

            // Skip duplicate anchors
            if (i > 0 && nums[i] == nums[i - 1]) continue

            var l = i + 1
            var r = n - 1

            while (l < r) {
                val sum = nums[i] + nums[l] + nums[r]
                when {
                    sum == 0 -> {
                        res.add(listOf(nums[i], nums[l], nums[r]))
                        // Skip duplicates for left and right
                        while (l < r && nums[l] == nums[l + 1]) l++
                        while (l < r && nums[r] == nums[r - 1]) r--
                        l++
                        r--
                    }
                    sum < 0 -> l++
                    else -> r--
                }
            }
        }
        return res
    }
}

    def threeSum(self, nums: list[int]) -> list[list[int]]:

        n = len(nums)

            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s == 0:
                    res.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l + 1]:
                        l += 1
                    while l < r and nums[r] == nums[r - 1]:
                        r -= 1
                    l += 1
                    r -= 1
                elif s < 0:
                    l += 1
                else:
                    r -= 1

        return res

import java.util.*;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int l = i + 1, r = n - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum == 0) {
                    res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++;
                    while (l < r && nums[r] == nums[r - 1]) r--;
                    l++;
                    r--;
                } else if (sum < 0) {
                    l++;
                } else {
                    r--;
                }
            }
        }
        return res;
    }
}
