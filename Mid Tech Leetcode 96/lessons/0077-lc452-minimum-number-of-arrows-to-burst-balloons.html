LeetCode #452: Minimum Number of Arrows to Burst Balloons

Official LC #452

Official Problem Statement

There are some spherical balloons taped onto a flat wall that represents the XY-plane. The balloons are represented as a 2D integer array points where points[i] = [x_start, x_end] denotes a balloon whose horizontal diameter stretches between x_start and x_end.

An arrow can be shot up exactly vertically (in the positive Y-direction) from different points along the X-axis. A balloon with x_start and x_end is burst by an arrow shot at x if x_start <= x <= x_end. There is no limit to the number of arrows that can be shot. A single arrow can burst multiple balloons as long as its shot coordinate overlaps each balloon.

Given the array points, return the minimum number of arrows that must be shot to burst all balloons.

Example 1: points = [[10,16],[2,8],[1,6],[7,12]] → Output: 2 Explanation: The balloons can be burst by 2 arrows: - Shoot an arrow at x = 6, bursting the balloons [2,8] and [1,6]. - Shoot an arrow at x = 11, bursting the balloons [10,16] and [7,12].

Example 2: points = [[1,2],[3,4],[5,6],[7,8]] → Output: 4 Explanation: One arrow needs to be shot for each balloon for a total of 4 arrows.

Example 3: points = [[1,2],[2,3],[3,4],[4,5]] → Output: 2 Explanation: The balloons can be burst by 2 arrows: - Shoot an arrow at x = 2, bursting the balloons [1,2] and [2,3]. - Shoot an arrow at x = 4, bursting the balloons [3,4] and [4,5].

Plain-English Translation & Core Nuance

Each arrow shot at coordinate x bursts all balloons covering x. To burst the maximum number of overlapping balloons with each arrow, sort balloons by their end coordinate `x_end` ascending. Shoot the first arrow at the end of the first balloon (`arrowPos = points[0][1]`). For every subsequent balloon, if its start is <= `arrowPos`, it is already pierced by the same arrow! Only when a balloon starts strictly after `arrowPos` (`x_start > arrowPos`) do we need a new arrow, which we shoot at that balloon's end coordinate.

Official Constraints:
  • 1 <= points.length <= 10^5
  • points[i].length == 2
  • -2^31 <= x_start < x_end <= 2^31 - 1

★ Approach: Greedy Sort by End Coordinate (Production Optimal)

Sort balloons by end coordinate ascending. Shoot first arrow at points[0][1]. For each subsequent balloon, if its start > arrowPos, shoot a new arrow at its end coordinate.

Time: O(N log N) Time Space: O(1) Auxiliary Space 
class Solution {
    fun findMinArrowShots(points: Array<IntArray>): Int {
        if (points.isEmpty()) return 0

        // Use compareTo to avoid integer subtraction overflow with large negative numbers
        points.sortWith { a, b -> a[1].compareTo(b[1]) }

        var arrows = 1
        var arrowPos = points[0][1]

        for (i in 1 until points.size) {
            if (points[i][0] > arrowPos) {
                arrows++
                arrowPos = points[i][1]
            }
        }
        return arrows
    }
}

class Solution:
    def findMinArrowShots(self, points: list[list[int]]) -> int:
        if not points:
            return 0

        points.sort(key=lambda x: x[1])

        arrows = 1
        arrow_pos = points[0][1]

        for i in range(1, len(points)):
            if points[i][0] > arrow_pos:
                arrows += 1
                arrow_pos = points[i][1]

        return arrows

import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        if (points == null || points.length == 0) return 0;

        // Use Integer.compare to prevent integer overflow with Integer.MIN_VALUE
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

        int arrows = 1;
        int arrowPos = points[0][1];

        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > arrowPos) {
                arrows++;
                arrowPos = points[i][1];
            }
        }
        return arrows;
    }
}
