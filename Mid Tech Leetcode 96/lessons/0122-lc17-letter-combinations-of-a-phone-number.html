Problem #17: Letter Combinations of a Phone Number

External Judge ↗

Official Problem Statement

Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent. Return the answer in any order.

Keypad mapping: 2:abc, 3:def, 4:ghi, 5:jkl, 6:mno, 7:pqrs, 8:tuv, 9:wxyz.

Example 1: digits = "23" → Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]

Example 2: digits = "" → Output: []

Example 3: digits = "2" → Output: ["a","b","c"]

Plain-English Translation & Core Nuance

First guard digits.isEmpty() -> emptyList() (NOT [""]!). Then at position idx from 0 to digits.length - 1, branch across the 3 or 4 letters mapped to digits[idx], append to a single mutable StringBuilder / buffer, recurse, and pop.

Official Constraints:
  • 0 <= digits.length <= 4
  • digits[i] is a digit in the range ['2', '9'].

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
digits = "" -> Must return [] (empty list), NOT [""] (list containing one empty string)!
Best-Case Early Exit
digits = "2" -> Depth 1 yields ["a", "b", "c"].
Worst-Case Full Scan
digits = "7979" (all 4-letter keys pqrs/wxyz) -> 4^4 = 256 combinations, each length 4.

Section 01 • Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 Combination Lock Wheels Spinning in Sequence

Think of a luggage lock where Wheel 0 has letters ['a','b','c'] (for digit '2') and Wheel 1 has ['d','e','f'] (for digit '3'). Instead of subset include/exclude choices, every wheel MUST pick exactly one letter before advancing to idx + 1. Using one shared CharArray(digits.length) overwritten at buf[idx] = ch avoids string concatenation garbage AND doesn't even need an explicit delete step!

The Mental "A-Ha!" Switch:

Guard if (digits.isEmpty()) return emptyList() first! Then overwrite buf[idx] = ch at each depth idx for zero-garbage O(N · 4^N) generation.

Section 02 • Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N · 4^N) with Intermediate String Garbage

Repeatedly build new immutable strings (prefix + ch) or allocate full intermediate lists at every digit level.

Wasted Work: Immutable prefix + ch allocates a fresh String at every internal tree node instead of only at the 4^N leaves.
The Optimal Breakthrough O(N · 4^N) Time, O(N) Auxiliary Stack/Buffer Space

Pre-allocate one fixed CharArray(digits.length) (or StringBuilder), write buf[idx] = ch, recurse dfs(idx + 1), and materialize String(buf) only at idx == digits.length.

Core Invariant: At recursion depth idx, buf[0..idx-1] holds the chosen prefix for digits[0..idx-1].
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Iterative BFS Queue Expansion O(N · 4^N) O(4^N) queue Clean iterative alternative; holds partial strings in queue.
Optimal: Fixed-Buffer DFS Backtracking O(N · 4^N) O(N) auxiliary ★ Allocates strings ONLY at leaf combinations.

2. Step-by-Step Non-Code Algorithm Walkthrough
1. Boundary Guards & Container Setup

Check degenerate inputs upfront (digits = "" -> Must return [] (empty list), NOT [""] (list containing one empty string)!) and initialize only the auxiliary state needed to avoid Immutable prefix + ch allocates a fresh String at every internal tree node instead of only at the 4^N leaves..

2. Core Traversal & Decision Rule

Pre-allocate one fixed CharArray(digits.length) (or StringBuilder), write buf[idx] = ch, recurse dfs(idx + 1), and materialize String(buf) only at idx == digits.length. Instead of re-scanning prior elements, each step makes a local O(1) or O(log N) transition.

3. Invariant Preservation Across Steps

Guard if (digits.isEmpty()) return emptyList() first! Then overwrite buf[idx] = ch at each depth idx for zero-garbage O(N · 4^N) generation. After every update, the core invariant holds: At recursion depth idx, buf[0..idx-1] holds the chosen prefix for digits[0..idx-1].

4. Early Exit & Final Return

Short-circuit immediately when decisive conditions trigger (digits = "2" -> Depth 1 yields ["a", "b", "c"].); otherwise complete traversal and return the final state. Because buf[idx] is overwritten by the next loop iteration at the same depth, fixed-size CharArray needs no explicit pop!

From Naive to Optimal & Runnable Practice Arena

Iterative Queue / Cartesian Expansion

Expands partial prefixes level-by-level for each digit.

Time: O(N · 4^N) Space: O(4^N) 
class Solution {
    fun letterCombinations(digits: String): List<String> {
        if (digits.isEmpty()) return emptyList()
        val pad = arrayOf("", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz")
        var cur = listOf("")
        for (i in 0 until digits.length) {
            val letters = pad[digits[i] - '0']
            val next = mutableListOf<String>()
            for (prefix in cur) {
                for (j in 0 until letters.length) {
                    next.add(prefix + letters[j])
                }
            }
            cur = next
        }
        return cur
    }
}

Optimal: Mutable Buffer DFS Backtracking

Uses O(N) auxiliary stack + StringBuilder/list buffer and materializes strings only at depth N.

Time: O(N · 4^N) Space: O(N) aux 
class Solution {
    fun letterCombinations(digits: String): List<String> {
        if (digits.isEmpty()) return emptyList()
        val pad = arrayOf("", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz")
        val res = mutableListOf<String>()
        val sb = StringBuilder()

        fun dfs(idx: Int) {
            if (idx == digits.length) {
                res.add(sb.toString())
                return
            }
            val letters = pad[digits[idx] - '0']
            for (i in 0 until letters.length) {
                sb.append(letters[i])
                dfs(idx + 1)
                sb.deleteCharAt(sb.length - 1)
            }
        }

        dfs(0)
        return res
    }
}

import java.util.*;

class Solution {
    private static final String[] PAD = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

    public List<String> letterCombinations(String digits) {
        List<String> res = new ArrayList<>();
        if (digits.isEmpty()) return res;
        dfs(0, digits, new StringBuilder(), res);
        return res;
    }

    private void dfs(int idx, String digits, StringBuilder sb, List<String> res) {
        if (idx == digits.length()) {
            res.add(sb.toString());
            return;
        }
        String letters = PAD[digits.charAt(idx) - '0'];
        for (int i = 0; i < letters.length(); i++) {
            sb.append(letters.charAt(i));
            dfs(idx + 1, digits, sb, res);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
