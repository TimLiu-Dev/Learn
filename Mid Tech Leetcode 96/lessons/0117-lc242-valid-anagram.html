Problem #242: Valid Anagram

External Judge ↗

Official Problem Statement

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

An anagram is a word or phrase formed by rearranging the letters of a different word or phrase, using all the original letters exactly once.

Example 1: s = "anagram", t = "nagaram" → Output: true

Example 2: s = "rat", t = "car" → Output: false

Example 3: s = "ab", t = "a" → Output: false

Plain-English Translation & Core Nuance

Check whether two strings contain the exact same multiset of characters—meaning identical lengths and identical counts for every letter from 'a' to 'z'.

Official Constraints:
  • 1 <= s.length, t.length <= 5 * 10^4
  • s and t consist of lowercase English letters.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
s = "a", t = "a" -> Same length 1, bucket[0] increments then decrements back to 0 -> true.
Best-Case Early Exit
s = "abc", t = "ab" -> Unequal lengths (3 != 2) short-circuits in O(1) before touching any array.
Worst-Case Full Scan
s.length = t.length = 50,000 -> Single pass updates IntArray(26), followed by 26-slot zero check.

Section 01 • Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 The 26-Slot Scrabble Tile Ledger

Imagine a wooden tray with 26 labeled compartments from 'a' to 'z'. As you read string s, every letter drops +1 marble into its compartment; at the exact same index in string t, its letter removes -1 marble. If s and t are true anagrams, every single deposit is canceled out by an equal withdrawal, leaving all 26 compartments at 0.

The Mental "A-Ha!" Switch:

Guard s.length != t.length upfront, then use a fixed 26-integer array (+1 for s[i], -1 for t[i]) for zero-boxing O(N) time and O(1) auxiliary space.

Pattern Trigger:

Comparing character frequencies across lowercase ASCII strings or building canonical keys for anagram grouping.

Section 02 • Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N log N) Time, O(N) Space

Convert both strings to character arrays, sort both alphabetically, and compare the sorted arrays.

Wasted Work: Comparison sorting spends O(N log N) work ordering characters when only total per-letter counts matter, and allocates two O(N) char copies.
The Optimal Breakthrough O(N) Time, O(1) Space

Reject mismatched lengths immediately, then increment counts[s[i] - 'a'] and decrement counts[t[i] - 'a'] inside one primitive IntArray(26).

Core Invariant: After scanning prefix 0..i, counts[c] equals freq_s(c, 0..i) - freq_t(c, 0..i) for all c in 'a'..'z'.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: Sort Both Char Arrays O(N log N) O(N) Allocates two char arrays; slower for 50K strings.
Better: Generic HashMap<Char, Int> O(N) O(U) Required for full Unicode follow-up, but boxes chars on JVM.
Optimal: Fixed 26-Int Bucket Counter O(N) O(1) (26 ints) ★ Cache-resident 104-byte array; zero heap boxing.

Section 05 • Production Implementations

From Naive to Optimal & Runnable Practice Arena

Strict ordering: Kotlin (Default) → Python → Java across all approaches.

Sorting Both Strings

Sort both character arrays and check equality in O(N log N) time.

Time: O(N log N) Space: O(N) 
class Solution {
    fun isAnagram(s: String, t: String): Boolean {
        if (s.length != t.length) return false
        val a = s.toCharArray()
        val b = t.toCharArray()
        a.sort()
        b.sort()
        return a.contentEquals(b)
    }
}
Kotlin Runtime & Memory Nuance:

In Sorting Both Strings, Kotlin uses unboxed JVM primitive arrays (IntArray / BooleanArray) to eliminate object header overhead.

import java.util.Arrays;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        char[] a = s.toCharArray();
        char[] b = t.toCharArray();
        Arrays.sort(a);
        Arrays.sort(b);
        return Arrays.equals(a, b);
    }
}

In Sorting Both Strings, Java operates on unboxed primitive Java arrays to avoid Integer autoboxing GC pressure.

Optimal: Fixed 26-Slot Net Frequency Array

Single-pass +1/-1 counting inside a fixed 26-int array with O(1) space.

Time: O(N) Space: O(1) 
class Solution {
    fun isAnagram(s: String, t: String): Boolean {
        if (s.length != t.length) return false
        val counts = IntArray(26)
        for (i in 0 until s.length) {
            counts[s[i] - 'a']++
            counts[t[i] - 'a']--
        }
        for (c in counts) {
            if (c != 0) return false
        }
        return true
    }
}

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        counts = [0] * 26
        for i in range(len(s)):
            counts[ord(s[i]) - 97] += 1
            counts[ord(t[i]) - 97] -= 1
        for c in counts:
            if c != 0:
                return False
        return True

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] counts = new int[26];
        for (int i = 0; i < s.length(); i++) {
            counts[s.charAt(i) - 'a']++;
            counts[t.charAt(i) - 'a']--;
        }
        for (int c : counts) {
            if (c != 0) return false;
        }
        return true;
    }
}
