LeetCode 104: Maximum Depth of Binary Tree

Official LC #104

Official Problem Statement

Given the root of a binary tree, return its maximum depth.

A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

Example 1: root = [3,9,20,null,null,15,7] → Output: 3

Example 2: root = [1,null,2] → Output: 2

Plain-English Translation & Core Nuance

Find the tallest vertical chain of parent-to-child links from the root down to the deepest leaf node. Count every node on this path, including the root.

🌲 The Universal Tree Recurrence: The depth of any node is:
depth(root) = 1 + max(depth(root.left), depth(root.right))
Base case: If root == null, depth is 0.
Input Constraints

Node count: [0, 10,000]

-100 ≤ Node.val ≤ 100

O(N) linear time is optimal; each node is visited once.

Empty & Single Node

root = null → 0

root = [1] → 1

Base case returns 0 for null root; single node returns 1 + max(0,0) = 1.

Degenerate Skewed Chain

[1, 2, null, 3, null, 4]

Output: 4

Height equals N; depth correctly accumulates without stack underflow.

Strategic Contrast

Naive Trap vs. Optimal Breakthrough

❌

The Naive Trap: Global Mutable Counter & Leaked State

Beginners often declare a global class variable var depth = 0, incrementing it on pre-order traversal without decrementing upon returning, polluting calculations across independent subtrees.

• Leaked mutable state: Fails on concurrent threads and multiple calls

• Complex backtracking: Prone to off-by-one errors

✅

The Breakthrough: Pure Functional Post-Order Recurrence

Treat each subtree as an independent pure function. No global mutable state. Base case returns 0. The return value bubbles up: 1 + max(left, right).

• Time Complexity: O(N) single linear traversal

• Space Complexity: O(H) call stack height (O(log N) average, O(N) worst)

• Thread-Safe & Pure: No side effects, 1-line expression body in Kotlin.

Approach Time Space Thread-Safe? Tradeoff Summary
1. Global Mutable Counter DFS O(N) O(H) No Prone to state pollution bugs; fails in concurrent multi-threaded execution.
2. BFS Level-Order (Queue) O(N) O(W) Yes Iterative, increments counter once per level. Great for preventing deep stack overflows.
3. Post-Order DFS (Optimal) O(N) O(H) Yes Standard production gold standard. Concise, elegant, mathematically pure.

Solution Evolution

From Level-by-Level BFS to Post-Order DFS

Approach 1: BFS Level-Order (Queue)

Traverses the tree level-by-level using a FIFO Queue. For each level, determine levelSize = queue.size(), pop all nodes belonging to that level, enqueue their children, and increment depth by 1.

Time: O(N) Space: O(W) (Queue holds maximum tree width) 
class Solution {
    fun maxDepth(root: TreeNode?): Int {
        if (root == null) return 0
        val queue = java.util.ArrayDeque<TreeNode>()
        queue.offer(root)
        var depth = 0
        
        while (queue.isNotEmpty()) {
            val size = queue.size
            for (i in 0 until size) {
                val curr = queue.poll()
                if (curr.left != null) queue.offer(curr.left)
                if (curr.right != null) queue.offer(curr.right)
            }
            depth++
        }
        return depth
    }
}
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        queue = collections.deque([root])
        depth = 0
        while queue:
            for _ in range(len(queue)):
                curr = queue.popleft()
                if curr.left: queue.append(curr.left)
                if curr.right: queue.append(curr.right)
            depth += 1
        return depth
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 0;
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode curr = queue.poll();
                if (curr.left != null) queue.offer(curr.left);
                if (curr.right != null) queue.offer(curr.right);
            }
            depth++;
        }
        return depth;
    }
}

Approach 2: Iterative DFS (Stack of Node-Depth Pairs)

Uses an explicit stack storing pairs of (TreeNode, currentDepth). Tracks running maxDepth = max(maxDepth, currentDepth).

Time: O(N) Space: O(H) Stack 
class Solution {
    fun maxDepth(root: TreeNode?): Int {
        if (root == null) return 0
        val stack = java.util.ArrayDeque<Pair<TreeNode, Int>>()
        stack.push(root to 1)
        var maxDepth = 0
        
        while (stack.isNotEmpty()) {
            val (curr, currentDepth) = stack.pop()
            maxDepth = maxOf(maxDepth, currentDepth)
            if (curr.left != null) stack.push(curr.left to currentDepth + 1)
            if (curr.right != null) stack.push(curr.right to currentDepth + 1)
        }
        return maxDepth
    }
}
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        stack = [(root, 1)]
        max_depth = 0
        while stack:
            curr, depth = stack.pop()
            max_depth = max(max_depth, depth)
            if curr.left: stack.append((curr.left, depth + 1))
            if curr.right: stack.append((curr.right, depth + 1))
        return max_depth
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Deque<TreeNode> nodeStack = new ArrayDeque<>();
        Deque<Integer> depthStack = new ArrayDeque<>();
        nodeStack.push(root);
        depthStack.push(1);
        int maxDepth = 0;
        
        while (!nodeStack.isEmpty()) {
            TreeNode curr = nodeStack.pop();
            int depth = depthStack.pop();
            maxDepth = Math.max(maxDepth, depth);
            if (curr.left != null) { nodeStack.push(curr.left); depthStack.push(depth + 1); }
            if (curr.right != null) { nodeStack.push(curr.right); depthStack.push(depth + 1); }
        }
        return maxDepth;
    }
}

Approach 3: Post-Order Recursive DFS (Production Optimal)

INTERVIEW DEFAULT

The canonical implementation. Computes left and right subtree depths bottom-up, returning 1 + maxOf(leftDepth, rightDepth). Clean 1-line expression body in Kotlin.

Time: O(N) Space: O(H) 
class Solution {
    fun maxDepth(root: TreeNode?): Int {
        if (root == null) return 0
        return 1 + maxOf(maxDepth(root.left), maxDepth(root.right))
    }
}
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}

          Senior Scalability & System Follow-Ups
        

        

          

            1. Tree Rebalancing (AVL & Red-Black Trees):
            

              In self-balancing binary search trees (Java `TreeMap`, C++ `std::map`), storing subtree heights at each node allows detecting balance factor imbalances ($|h_L - h_R| > 1) in \mathcal{O}(1)$ time to trigger tree rotations.
            

          

          

            2. Distributed File System Directory Depth Limits:
            

              In distributed filesystems (HDFS, Ceph), excessively deep nested directory paths degrade namespace inode lookup performance. Filesystem metadata daemons run periodic bottom-up depth audits to enforce directory hierarchy depth limits.
