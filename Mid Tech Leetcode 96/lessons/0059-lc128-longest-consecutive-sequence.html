LeetCode #128: Longest Consecutive Sequence

Official LC #128

Official Problem Statement

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence.

You must write an algorithm that runs in O(n) time.

Example 1: nums = [100,4,200,1,3,2] → Output: 4 Explanation: The longest consecutive elements sequence is [1, 2, 3, 4]. Therefore its length is 4.

Example 2: nums = [0,3,7,2,5,8,4,6,0,1] → Output: 9 Explanation: The sequence is [0, 1, 2, 3, 4, 5, 6, 7, 8]. Length is 9.

Plain-English Translation & Core Nuance

Insert all numbers into a HashSet for O(1) membership lookup. A number is the beginning of a consecutive streak if and only if `num - 1` is NOT present in the set. For every streak leader, count forward `num + 1, num + 2, ...` to determine streak length. Because each element is visited at most twice, total runtime is strictly O(N).

Official Constraints:
  • 0 <= nums.length <= 10^5
  • -10^9 <= nums[i] <= 10^9

The Mental Model & "Explain Like I'm 12"

💡 Finding the Head of the Conga Line

Imagine a crowded party with people wearing numbers. If you want to find the longest chain of consecutive numbers, don't start counting from someone if their predecessor is already standing behind them. Only start counting if you are looking at the head of a line (`num - 1` does not exist). From that head, march forward counting consecutive people until the chain breaks.

The Mental "A-Ha!" Switch:

Checking `num - 1 not in set` filters out 90%+ of numbers from initiating a count. Each number is visited once during set insertion and at most once while expanding a sequence. This guarantees O(N) linear time despite the nested while loop.

Pattern Trigger:

Unsorted array, find longest consecutive sequence in O(N) time → HashSet with sequence-start filtering (`!set.contains(n - 1)`).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N log N) Time, O(1) or O(N) Space

Sort the array and scan linearly, incrementing a streak counter whenever nums[i] == nums[i-1] + 1.

Wasted Work: Sorting takes O(N log N) which violates the strict O(N) requirement in the problem description.
The Optimal Breakthrough O(N) Time, O(N) Auxiliary Space

HashSet lookup: populate set in O(N). Check streak start in O(1). Each streak member visited exactly once.

Core Invariant: A sequence expansion only starts at `num` if `!numSet.contains(num - 1)`. Total while-loop iterations across all numbers sum to at most N.

1. Brute Force Search O(N^3) O(1) For each element, sequentially search array for n+1, n+2.
2. Sorting Baseline O(N log N) O(1) to O(N) Sorts array; violates the explicit O(N) requirement.
★ 3. HashSet Sequence-Start Scan O(N) O(N) Optimal linear time amortized; avoids sorting.

Approach 1: Brute Force Search (O(N^3))

For every number n, sequentially search the array to see if n+1 exists. If so, search for n+2, and so forth.

Time: O(N^3) Time Space: O(1) Space 
class Solution {
    fun longestConsecutive(nums: IntArray): Int {
        var maxLen = 0
        for (num in nums) {
            var curr = num
            var count = 1
            while (nums.contains(curr + 1)) {
                curr++
                count++
            }
            maxLen = maxOf(maxLen, count)
        }
        return maxLen
    }
}

class Solution {
    public int longestConsecutive(int[] nums) {
        int maxLen = 0;
        for (int num : nums) {
            int curr = num;
            int count = 1;
            while (contains(nums, curr + 1)) {
                curr++;
                count++;
            }
            maxLen = Math.max(maxLen, count);
        }
        return maxLen;
    }
    private boolean contains(int[] nums, int target) {
        for (int n : nums) if (n == target) return true;
        return false;
    }
}

Approach 2: Sorting Baseline (O(N log N))

Sort the array in-place. Traverse linearly, skipping duplicate adjacent elements and incrementing the count when nums[i] == nums[i-1] + 1.

Time: O(N log N) Time Space: O(1) Space 
class Solution {
    fun longestConsecutive(nums: IntArray): Int {
        if (nums.isEmpty()) return 0
        nums.sort()
        var maxLen = 1
        var currLen = 1

        for (i in 1 until nums.size) {
            if (nums[i] == nums[i - 1]) continue
            if (nums[i] == nums[i - 1] + 1) {
                currLen++
                maxLen = maxOf(maxLen, currLen)
            } else {
                currLen = 1
            }
        }
        return maxLen
    }
}

★ Approach 3: HashSet Sequence Head Expansion (Production Optimal)

Convert array to a HashSet. For every element, check if num - 1 is present. If not, expand sequence forward. Each number is touched at most twice.

Time: O(N) Time Space: O(N) Space 
class Solution {
    fun longestConsecutive(nums: IntArray): Int {
        val numSet = nums.toHashSet()
        var maxLen = 0

        for (num in numSet) {
            // Only initiate a streak if num is the start of a sequence
            if (!numSet.contains(num - 1)) {
                var currentNum = num
                var currentStreak = 1

                while (numSet.contains(currentNum + 1)) {
                    currentNum++
                    currentStreak++
                }

                maxLen = maxOf(maxLen, currentStreak)
            }
        }
        return maxLen
    }
}

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> numSet = new HashSet<>();
        for (int num : nums) {
            numSet.add(num);
        }

        int maxLen = 0;
        for (int num : numSet) {
            // Check if num is the start of a sequence
            if (!numSet.contains(num - 1)) {
                int currentNum = num;
                int currentStreak = 1;

                while (numSet.contains(currentNum + 1)) {
                    currentNum++;
                    currentStreak++;
                }

                maxLen = Math.max(maxLen, currentStreak);
            }
        }
        return maxLen;
    }
}
