LeetCode #435: Non-overlapping Intervals

Official LC #435

Official Problem Statement

Given an array of intervals intervals where intervals[i] = [start_i, end_i], return the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.

Note: Intervals that touch at a point like [1, 2] and [2, 3] are non-overlapping.

Example 1: intervals = [[1,2],[2,3],[3,4],[1,3]] → Output: 1 Explanation: [1,3] can be removed and the rest of the intervals are non-overlapping.

Example 2: intervals = [[1,2],[1,2],[1,2]] → Output: 2 Explanation: You need to remove two [1,2] to make the rest of the intervals non-overlapping.

Example 3: intervals = [[1,2],[2,3]] → Output: 0 Explanation: You don't need to remove any of the intervals since they're already non-overlapping.

Plain-English Translation & Core Nuance

Minimizing the number of intervals to remove is equivalent to maximizing the number of compatible non-overlapping intervals you keep! The classic greedy strategy (Interval Scheduling) is to sort intervals by their END time ascending. Always keep the interval that finishes earliest, because it leaves the maximum possible remaining time for subsequent intervals. If the next interval starts before the last kept interval ends, an overlap occurs and it must be removed.

Official Constraints:
  • 1 <= intervals.length <= 10^5
  • intervals[i].length == 2
  • -5 * 10^4 <= start_i < end_i <= 5 * 10^4

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(2^N) Time, O(N) Space

Brute-force recursion trying all subsets of intervals and checking which valid subset has the maximum size.

Wasted Work: Exploring exponential subsets when the greedy choice property guarantees optimal substructure.
The Optimal Breakthrough O(N log N) Time, O(1) Space

Sort intervals by end coordinate in O(N log N). Single linear pass counting removals.

Core Invariant: At each step, `lastEnd` is the minimum possible finishing time of all valid subsets of compatible intervals chosen so far.

Production Implementations

From Naive to Optimal & Runnable Practice Arena

Strict ordering: Kotlin (Default) → Python → Java across all approaches.

★ Approach: Greedy Sort by End Time (Production Optimal)

Sort intervals ascending by end coordinate. Iterate linearly: if interval starts >= lastEnd, advance lastEnd. Otherwise, increment removal counter.

Time: O(N log N) Time Space: O(1) Auxiliary Space 
class Solution {
    fun eraseOverlapIntervals(intervals: Array<IntArray>): Int {
        if (intervals.isEmpty()) return 0
        intervals.sortBy { it[1] } // Sort by end time ascending

        var removals = 0
        var lastEnd = intervals[0][1]

        for (i in 1 until intervals.size) {
            if (intervals[i][0] >= lastEnd) {
                lastEnd = intervals[i][1] // No overlap, keep this interval
            } else {
                removals++ // Overlap detected, remove this interval
            }
        }
        return removals
    }
}

        if not intervals:
            return 0

        # Sort by end time ascending
        intervals.sort(key=lambda x: x[1])

        removals = 0
        last_end = intervals[0][1]

        for i in range(1, len(intervals)):
            if intervals[i][0] >= last_end:
                last_end = intervals[i][1]
            else:
                removals += 1

        return removals

import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        if (intervals.length == 0) return 0;

        // Sort by end time ascending
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));

        int removals = 0;
        int lastEnd = intervals[0][1];

        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] >= lastEnd) {
                lastEnd = intervals[i][1];
            } else {
                removals++;
            }
        }
        return removals;
    }
}
