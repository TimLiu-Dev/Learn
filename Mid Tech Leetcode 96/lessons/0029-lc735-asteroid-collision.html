LeetCode #735: Asteroid Collision

Official LC #735

Official Problem Statement

We are given an array asteroids of integers representing asteroids in a row.

For each asteroid, the absolute value represents its size, and the sign represents its direction (positive meaning right, negative meaning left). Each asteroid moves at the same speed.

Find out the state of the asteroids after all collisions. If two asteroids meet, the smaller one will explode. If both are the same size, both will explode. Two asteroids moving in the same direction will never meet.

Example 1: asteroids = [5,10,-5] → Output: [5,10] (10 and -5 collide resulting in 10; 5 and 10 never collide)

Example 2: asteroids = [8,-8] → Output: [] (Both explode)

Example 3: asteroids = [10,2,-5] → Output: [10] (2 and -5 collide -> -5; 10 and -5 collide -> 10)

Plain-English Translation & Core Nuance

Simulate moving asteroids. A collision only happens when a right-moving asteroid (positive) is followed by a left-moving asteroid (negative). Use a stack to hold surviving asteroids. When a negative asteroid arrives, compare it against positive asteroids on top of the stack: smaller explodes, equal both explode, larger destroys the stack top and keeps colliding.

Official Constraints:
  • 2 <= asteroids.length <= 10^4
  • -1000 <= asteroids[i] <= 1000
  • asteroids[i] != 0

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
[8, -8] → Equal size opposite direction → Both explode → [].
Best-Case Early Exit
All same sign [1, 2, 3] or moving apart [-5, 5] → Zero collisions.
Worst-Case Full Scan
Large negative asteroid [1, 2, 3, -10] → Negative asteroid destroys all previous stack elements.

The Mental Model & "Explain Like I'm 12"

💡 The Sumo Wrestling Tunnel

Imagine sumo wrestlers entering a narrow 1-lane tunnel. Wrestlers moving East (+) wait in line. When a Westbound (-) wrestler enters, they clash with the last Eastbound wrestler who entered (the top of the stack). The heavier wrestler wins and stays; equal weights eliminate each other. The Westbound wrestler continues fighting preceding Eastbound wrestlers until stopped, eliminated, or clearing the tunnel.

The Mental "A-Ha!" Switch:

Collisions ONLY happen if `top > 0` and `incoming < 0`. If `top < 0` and `incoming > 0`, they are moving AWAY from each other and will never meet! Stack perfectly models this sequential LIFO clash.

Pattern Trigger:

Whenever sequential entities collide, cancel, or eliminate based on direction or matching pairs → Stack.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N) Space

Repeatedly scan the array for adjacent collision pairs (+, -), splice them out, and restart scanning from the beginning.

Wasted Work: Re-scanning the entire prefix of the array after every single collision.
The Optimal Breakthrough O(N) Time, O(N) Space

Process each asteroid once using a stack. Each asteroid is pushed at most once and popped at most once.

Core Invariant: The stack contains only asteroids that can never collide with each other.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Repeated Array Rescan O(N^2) O(N) Splices array elements repeatedly.
★ 2. Monotonic Collision Stack O(N) O(N) Each asteroid enters/exits stack once.

Standard Stack Simulation

Use Stack/ArrayDeque to resolve collisions sequentially.

Time: O(N) Space: O(N) 
class Solution {
    fun asteroidCollision(asteroids: IntArray): IntArray {
        val stack = ArrayDeque<Int>()
        for (ast in asteroids) {
            var alive = true
            while (alive && ast < 0 && stack.isNotEmpty() && stack.last() > 0) {
                val top = stack.last()
                if (top < -ast) {
                    stack.removeLast()
                } else if (top == -ast) {
                    stack.removeLast()
                    alive = false
                } else {
                    alive = false
                }
            }
            if (alive) {
                stack.addLast(ast)
            }
        }
        return stack.toIntArray()
    }
}

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (int ast : asteroids) {
            boolean alive = true;
            while (alive && ast < 0 && !stack.isEmpty() && stack.peek() > 0) {
                if (stack.peek() < -ast) {
                    stack.pop();
                } else if (stack.peek() == -ast) {
                    stack.pop();
                    alive = false;
                } else {
                    alive = false;
                }
            }
            if (alive) {
                stack.push(ast);
            }
        }
        int[] result = new int[stack.size()];
        for (int i = result.length - 1; i >= 0; i--) {
            result[i] = stack.pop();
        }
        return result;
    }
}
Java Runtime & Memory Nuance:

Since ArrayDeque pop() pops from the front, reversing into `result[i]` correctly maintains chronological order.

Better: Two-Pointer In-Place Array Stack

Use the input array itself as the stack storage via top pointer.

Time: O(N) Space: O(1) Auxiliary Space 
class Solution {
    fun asteroidCollision(asteroids: IntArray): IntArray {
        var top = -1
        for (ast in asteroids) {
            var alive = true
            while (alive && ast < 0 && top >= 0 && asteroids[top] > 0) {
                if (asteroids[top] < -ast) {
                    top--
                } else if (asteroids[top] == -ast) {
                    top--
                    alive = false
                } else {
                    alive = false
                }
            }
            if (alive) {
                asteroids[++top] = ast
            }
        }
        return asteroids.copyOfRange(0, top + 1)
    }
}

Optimal: Clean Production ArrayDeque

Production gold standard with robust readability and defensive edge checks.

Time: O(N) Space: O(N) 
class Solution {
    /**
     * Optimal: Monotonic Collision Stack
     * Time: O(N) - Each asteroid is pushed and popped at most once
     * Space: O(N) - Survivor storage
     */
    fun asteroidCollision(asteroids: IntArray): IntArray {
        val stack = ArrayDeque<Int>()

        for (ast in asteroids) {
            var destroyed = false
            while (stack.isNotEmpty() && stack.last() > 0 && ast < 0) {
                val top = stack.last()
                val diff = top + ast // ast is negative, so diff compares magnitudes
                when {
                    diff < 0 -> stack.removeLast() // top destroyed, incoming keeps going
                    diff == 0 -> { stack.removeLast(); destroyed = true; break } // both destroyed
                    else -> { destroyed = true; break } // incoming destroyed
                }
            }
            if (!destroyed) {
                stack.addLast(ast)
            }
        }

        return stack.toIntArray()
    }
}
Kotlin Runtime & Memory Nuance:

Using `when` with `diff = top + ast` is idiomatic Kotlin: if `diff < 0`, incoming magnitude is larger; if `diff == 0`, equal.

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    /**
     * Optimal: Collision Stack with Magnitude Delta
     * Time: O(N) - Linear pass
     * Space: O(N) - Survivor storage
     */
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();

        for (int ast : asteroids) {
            boolean exploded = false;
            while (!stack.isEmpty() && stack.peekLast() > 0 && ast < 0) {
                int diff = stack.peekLast() + ast;
                if (diff < 0) {
                    stack.pollLast(); // top destroyed
                } else if (diff == 0) {
                    stack.pollLast(); // both destroyed
                    exploded = true;
                    break;
                } else {
                    exploded = true; // incoming destroyed
                    break;
                }
            }
            if (!exploded) {
                stack.addLast(ast);
            }
        }

        int[] result = new int[stack.size()];
        int idx = 0;
        for (int val : stack) {
            result[idx++] = val;
        }
        return result;
    }
}
Java Runtime & Memory Nuance:

Iterating directly through ArrayDeque with `for (int val : stack)` preserves first-to-last insertion order.
