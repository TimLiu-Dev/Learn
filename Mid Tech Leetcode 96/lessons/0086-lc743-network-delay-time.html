LeetCode #743: Network Delay Time

Official LC #743

Official Problem Statement

You are given a network of n nodes, labeled from 1 to n. You are also given times, a list of travel times as directed edges times[i] = (ui, vi, wi), where ui is the source node, vi is the target node, and wi is the time it takes for a signal to travel from source to target.

We will send a signal from a given node k. Return the minimum time it takes for all the n nodes to receive the signal. If it is impossible for all the n nodes to receive the signal, return -1.

Example 1: times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2 → Output: 2 Explanation: The signal is sent from node 2. At time 1, nodes 1 and 3 receive the signal. At time 2, node 4 receives the signal. All nodes have received the signal, so the answer is 2.

Example 2: times = [[1,2,1]], n = 2, k = 1 → Output: 1

Example 3: times = [[1,2,1]], n = 2, k = 2 → Output: -1 Explanation: Node 1 cannot be reached from node 2.

Plain-English Translation & Core Nuance

A signal radiates outward from node `k`. Because travel times `w` are non-negative, the earliest time node `v` receives the signal is the shortest path distance from `k` to `v`. The time for ALL reachable nodes to receive the signal is the maximum of these shortest paths: `max(dist[1..n])`. If any node remains unreachable (`dist[i] == ∞`), return -1. Since all edge weights are non-negative, this is a textbook Dijkstra's Single-Source Shortest Path algorithm using a Min-Heap (PriorityQueue).

Official Constraints:
  • 1 <= k <= n <= 100
  • 1 <= times.length <= 6000
  • times[i].length == 3
  • 1 <= ui, vi <= n
  • ui != vi
  • 0 <= wi <= 100
  • All the pairs (ui, vi) are unique. (i.e., no multiple edges.)

The Mental Model & "Explain Like I'm 12"

💡 Ripples in a Pond

Drop a pebble at node `k`. A circular wave ripples outward in water. Nodes closer in distance are touched by the wave front first. A priority queue tracks the expanding perimeter of the wavefront, always expanding the node that is touched soonest in chronological time. Once the wave has touched every island, the timestamp of the last island touched is your answer.

The Mental "A-Ha!" Switch:

The problem asks for the minimum time for *all* nodes to receive the signal. That equals the *maximum* shortest path distance among all nodes from `k`! If any shortest path is \infty, it's unreachable.

Pattern Trigger:

Shortest path with non-negative edge weights from a single source → Dijkstra's Algorithm with Min-Heap `(dist, node)`.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(V * E) Time, O(V) Space

Bellman-Ford algorithm relaxing all edges V - 1 times.

Wasted Work: Repeatedly scanning every edge regardless of whether its source distance has stabilized.
The Optimal Breakthrough O(E log V) Time, O(V + E) Space

Dijkstra's Algorithm using a binary Min-Heap priority queue.

Core Invariant: When a node `u` is extracted from the min-heap, its recorded distance `dist[u]` is strictly optimal and will never be improved.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Bellman-Ford O(V * E) O(V) General for negative weights, but slower when weights are non-negative.
★ Dijkstra (Min-Heap) O(E log V) O(V + E) Greedy wavefront expansion; visits nodes in monotonically increasing distance.

Dijkstra's Algorithm with Min-Heap

Adjacency list with Min-Heap priority queue holding pairs `(dist, node)`. Relax edges when `dist[u] + w < dist[v]`. The network delay is `max(dist[1..n])` or `-1` if any node is unreachable.

Time: O(E log V) Time Space: O(V + E) Space 
import java.util.PriorityQueue

class Solution {
    fun networkDelayTime(times: Array<IntArray>, n: Int, k: Int): Int {
        val adj = Array(n + 1) { mutableListOf<Pair<Int, Int>>() }
        for (edge in times) {
            val u = edge[0]
            val v = edge[1]
            val w = edge[2]
            adj[u].add(Pair(v, w))
        }

        val dist = IntArray(n + 1) { Int.MAX_VALUE }
        dist[k] = 0

        // Min-Heap ordered by travel time from source
        val pq = PriorityQueue<Pair<Int, Int>>(compareBy { it.first })
        pq.add(Pair(0, k)) // (current_dist, node)

        while (pq.isNotEmpty()) {
            val (d, u) = pq.poll()

            // Skip outdated pairs in heap
            if (d > dist[u]) continue

            for ((v, weight) in adj[u]) {
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight
                    pq.add(Pair(dist[v], v))
                }
            }
        }

        var maxTime = 0
        for (i in 1..n) {
            if (dist[i] == Int.MAX_VALUE) return -1
            maxTime = maxOf(maxTime, dist[i])
        }
        return maxTime
    }
}

import heapq

class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        adj = [[] for _ in range(n + 1)]
        for u, v, w in times:
            adj[u].append((v, w))
            
        dist = [float('inf')] * (n + 1)
        dist[k] = 0
        
        # Priority queue stores (time, node)
        pq = [(0, k)]
        
        while pq:
            d, u = heapq.heappop(pq)
            
            if d > dist[u]:
                continue
                
            for v, weight in adj[u]:
                if dist[u] + weight < dist[v]:
                    dist[v] = dist[u] + weight
                    heapq.heappush(pq, (dist[v], v))
                    
        max_time = max(dist[1:])
        return max_time if max_time != float('inf') else -1

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<List<int[]>> adj = new ArrayList<>();
        for (int i = 0; i <= n; i++) adj.add(new ArrayList<>());
        for (int[] edge : times) {
            adj.get(edge[0]).add(new int[]{edge[1], edge[2]});
        }

        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;

        // Min-heap ordered by distance
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        pq.offer(new int[]{0, k});

        while (!pq.isEmpty()) {
            int[] curr = pq.poll();
            int d = curr[0];
            int u = curr[1];

            if (d > dist[u]) continue;

            for (int[] edge : adj.get(u)) {
                int v = edge[0];
                int weight = edge[1];
                if (dist[u] + weight < dist[v]) {
                    dist[v] = dist[u] + weight;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }

        int maxTime = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == Integer.MAX_VALUE) return -1;
            maxTime = Math.max(maxTime, dist[i]);
        }
        return maxTime;
    }
}
