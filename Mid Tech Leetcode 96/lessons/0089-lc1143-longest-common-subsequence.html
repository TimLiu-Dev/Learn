LeetCode #1143: Longest Common Subsequence

Official LC #1143

Official Problem Statement

Given two strings text1 and text2, return the length of their longest common subsequence. If there is no common subsequence, return 0.

A subsequence of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.

  • For example, "ace" is a subsequence of "abcde".

A common subsequence of two strings is a subsequence that is common to both strings.

Example 1: text1 = "abcde", text2 = "ace" → Output: 3 Explanation: The longest common subsequence is "ace" and its length is 3.

Example 2: text1 = "abc", text2 = "abc" → Output: 3 Explanation: The longest common subsequence is "abc" and its length is 3.

Example 3: text1 = "abc", text2 = "def" → Output: 0 Explanation: There is no such common subsequence, so the result is 0.

Plain-English Translation & Core Nuance

We want to find the length of the longest subsequence shared between two strings `text1` (length M) and `text2` (length N). We build a 2D table `dp` of size `(M + 1) x (N + 1)`, where `dp[i][j]` is the LCS of prefixes `text1[0 until i]` and `text2[0 until j]`. The base cases are `dp[0][j] = 0` and `dp[i][0] = 0`. For each cell `(i, j)`: if characters match (`text1[i - 1] == text2[j - 1]`), we extend the diagonal result: `dp[i][j] = dp[i - 1][j - 1] + 1`. If they don't match, we take the best choice of skipping one character: `dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])`. Space can be optimized to O(\min(M, N)) using two rolling 1D rows.

Official Constraints:
  • 1 <= text1.length, text2.length <= 1000
  • text1 and text2 consist of only lowercase English characters.

💡 The DNA Alignment Grid

Imagine comparing two strands of DNA written along the top and left of a grid. Whenever two matching nucleotides line up at coordinate `(i, j)`, you get a bonus point and step diagonally down-right (`dp[i-1][j-1] + 1`). When they don't match, you can either delete a nucleotide from strand 1 (taking the value from above) or strand 2 (taking the value from the left), whichever achieved a higher score so far.

The Mental "A-Ha!" Switch:

When `text1[i-1] == text2[j-1]`, it is mathematically proven that matching them greedily is never worse than skipping one. Hence `1 + dp[i-1][j-1]` is strictly optimal for matching characters.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(2^(M+N)) Time, O(M+N) Space

Recursive branching: if matching, advance both; if differing, branch into two recursive calls (advance i OR advance j).

Wasted Work: Re-evaluating identical prefix coordinate pairs `(i, j)` exponentially many times.
The Optimal Breakthrough O(M * N) Time, O(min(M, N)) Space

2D DP with two 1D rolling arrays `prev` and `curr`.

Core Invariant: `dp[i][j]` is the exact length of the longest common subsequence between `text1[0 until i]` and `text2[0 until j]`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Recursion without Memoization O(2^(M+N)) O(M+N) Exponential branching.
2D DP Grid O(M * N) O(M * N) Full table allows backtracking to reconstruct the actual string.
★ 1D Rolling Row DP O(M * N) O(min(M, N)) Memory optimized; only requires two rows (previous & current).

Space-Optimized 1D Rolling Row DP

Because `dp[i][j]` only references the current row and previous row, maintain two 1D rows `prev` and `curr`. Swap rows after each character of `text1`.

Time: O(M * N) Time Space: O(min(M 
class Solution {
    fun longestCommonSubsequence(text1: String, text2: String): Int {
        // Ensure text2 is the shorter string to minimize space
        var s1 = text1
        var s2 = text2
        if (s1.length < s2.length) {
            val tmp = s1; s1 = s2; s2 = tmp
        }

        val m = s1.length
        val n = s2.length
        var prev = IntArray(n + 1)
        var curr = IntArray(n + 1)

        for (i in 1..m) {
            for (j in 1..n) {
                if (s1[i - 1] == s2[j - 1]) {
                    curr[j] = prev[j - 1] + 1
                } else {
                    curr[j] = maxOf(prev[j], curr[j - 1])
                }
            }
            // Swap rows
            val temp = prev
            prev = curr
            curr = temp
        }

        return prev[n]
    }
}

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        if (text1.length() < text2.length()) {
            String temp = text1;
            text1 = text2;
            text2 = temp;
        }

        int m = text1.length();
        int n = text2.length();
        int[] prev = new int[n + 1];
        int[] curr = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    curr[j] = prev[j - 1] + 1;
                } else {
                    curr[j] = Math.max(prev[j], curr[j - 1]);
                }
            }
            int[] temp = prev;
            prev = curr;
            curr = temp;
        }

        return prev[n];
    }
}

Full `(M + 1) x (N + 1)` matrix. Straightforward implementation; facilitates backtracking from `dp[M][N]` to reconstruct the actual common subsequence characters.

class Solution2D {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}

          Phase 1: Clarifying Questions & Edge Cases
          
"First, let's establish the problem requirements: given two strings `text1` and `text2`, we need to find the length of the longest subsequence present in both. Subsequences maintain order but do not need to be contiguous."

        

        

          Phase 2: Space-Time Strategy Pitch
          
"A naive recursion would branch on each character pair: if they match, advance both; if they differ, branch into skipping a char in text1 or text2. This yields O(2^{M+N}) worst-case time."

        

        

          Phase 3: Live Coding Narrative
          
"We can formulate this as a 2D dynamic program: `dp[i][j]` is the LCS of `text1[0..i-1]` and `text2[0..j-1]`. If `text1[i-1] == text2[j-1]`, we extend the diagonal: `1 + dp[i-1][j-1]`. Otherwise, we take `max(dp[i-1][j], dp[i][j-1])`."

        

        

          Phase 4: Cold Edge-Case Verification
          
"Notice each row only depends on the row directly above it. By assigning the shorter string to the columns and keeping just two rolling 1D arrays (`prev` and `curr`), we reduce the auxiliary space from O(M \times N) down to $O(\min(M, N))$."
