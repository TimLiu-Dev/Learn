Problem #210: Course Schedule II

View on NeetCode ↗

Official Problem Statement

There are a total of numCourses courses you have to take, labeled from 0 to numCourses - 1. You are given an array prerequisites where prerequisites[i] = [ai, bi] indicates that you must take course bi first if you want to take course ai.

Return the ordering of courses you should take to finish all courses. If there are many valid answers, return any of them. If it is impossible to finish all courses, return an empty array.

Example 1: numCourses = 2, prerequisites = [[1,0]] → Output: [0,1] Explanation: There are a total of 2 courses to take. To take course 1 you should have finished course 0. So the correct course order is [0,1].

Example 2: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]] → Output: [0,2,1,3] Explanation: There are a total of 4 courses to take. To take course 3 you should have finished both courses 1 and 2. Both courses 1 and 2 should be taken after you finished course 0. So one correct course order is [0,1,2,3]. Another correct ordering is [0,2,1,3].

Example 3: numCourses = 1, prerequisites = [] → Output: [0]

Plain-English Translation & Core Nuance

This is the direct continuation of Course Schedule (LC 207). Instead of returning a boolean, we must return the actual valid topological order array. We allocate an integer array order of size numCourses. Whenever a node with in-degree 0 is dequeued in Kahn's algorithm, we write it into order[index++]. When the queue empties: if index == numCourses, return order; if index < numCourses (a cycle existed), return intArrayOf() (empty array).

Official Constraints:
  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= numCourses * (numCourses - 1)
  • prerequisites[i].length == 2
  • 0 <= ai, bi < numCourses
  • ai != bi
  • All the pairs [ai, bi] are distinct.

Kahn's Topological Sort with Output Array

Pre-allocate an integer array of size numCourses. Append each popped zero-in-degree vertex. If idx == numCourses, return order; else return empty array.

Time: O(V + E) Time Space: O(V + E) Space 
class Solution {
    fun findOrder(numCourses: Int, prerequisites: Array<IntArray>): IntArray {
        val inDegree = IntArray(numCourses)
        val adj = Array(numCourses) { mutableListOf<Int>() }

        for (edge in prerequisites) {
            val course = edge[0]
            val pre = edge[1]
            adj[pre].add(course)
            inDegree[course]++
        }

        val queue = ArrayDeque<Int>()
        for (i in 0 until numCourses) {
            if (inDegree[i] == 0) {
                queue.add(i)
            }
        }

        val order = IntArray(numCourses)
        var idx = 0

        while (queue.isNotEmpty()) {
            val curr = queue.removeFirst()
            order[idx++] = curr

            for (neighbor in adj[curr]) {
                inDegree[neighbor]--
                if (inDegree[neighbor] == 0) {
                    queue.add(neighbor)
                }
            }
        }

        return if (idx == numCourses) order else IntArray(0)
    }
}
Kotlin Runtime & Memory Nuance:

In Kahn's Topological Sort with Output Array, Kotlin uses unboxed JVM primitive arrays (IntArray / BooleanArray) to eliminate object header overhead and keep traversal L1-cache friendly; and uses ArrayDeque as a zero-lock circular buffer for O(1) head/tail operations instead of synchronized java.util.Stack or pointer-heavy LinkedList.

from collections import deque

class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        in_degree = [0] * numCourses
        adj = [[] for _ in range(numCourses)]
        
        for course, pre in prerequisites:
            adj[pre].append(course)
            in_degree[course] += 1
            
        queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
        order = []
        
        while queue:
            curr = queue.popleft()
            order.append(curr)
            
            for neighbor in adj[curr]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
                    
        return order if len(order) == numCourses else []
Python Runtime & Memory Nuance:

In Kahn's Topological Sort with Output Array, Python uses collections.deque for true O(1) popleft() / append(), avoiding the O(N) memory shift penalty of list.pop(0); and iterates with lazy C-iterators (range / enumerate) to avoid allocating intermediate index lists.

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        int[] inDegree = new int[numCourses];
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        for (int[] p : prerequisites) {
            int course = p[0];
            int pre = p[1];
            adj.get(pre).add(course);
            inDegree[course]++;
        }

        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        int[] order = new int[numCourses];
        int idx = 0;

        while (!queue.isEmpty()) {
            int curr = queue.poll();
            order[idx++] = curr;

            for (int neighbor : adj.get(curr)) {
                if (--inDegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        return idx == numCourses ? order : new int[0];
    }
}
Java Runtime & Memory Nuance:

In Kahn's Topological Sort with Output Array, Java uses resizable circular array ArrayDeque, which outperforms LinkedList by eliminating per-node 24-byte heap allocations; and operates directly on primitive Java arrays (int[] / char[]) to prevent autoboxing GC pressure.
