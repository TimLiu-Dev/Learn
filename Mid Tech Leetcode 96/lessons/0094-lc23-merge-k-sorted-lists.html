LeetCode #23: Merge k Sorted Lists

Official LC #23

Official Problem Statement

You are given an array of k linked-lists lists, each linked-list is sorted in ascending order.

Merge all the linked-lists into one sorted linked-list and return it.

Example 1: lists = [[1,4,5],[1,3,4],[2,6]] → Output: [1,1,2,3,4,4,5,6] Explanation: The linked-lists are: [ 1->4->5, 1->3->4, 2->6 ] merging them into one sorted list: 1->1->2->3->4->4->5->6

Example 2: lists = [] → Output: []

Example 3: lists = [[]] → Output: []

Plain-English Translation & Core Nuance

We have `k` sorted linked lists and want to merge them into a single sorted list. There are two primary optimal strategies: (1) Min-Heap: We maintain a PriorityQueue of size at most `k` holding the current head node of each non-empty list. We repeatedly poll the smallest node, attach it to our merged result, and if that node has a `next`, offer `node.next` into the heap. Total time: O(N log k), space: O(k). (2) Divide and Conquer: Pairwise merge lists 2-by-2 in rounds (e.g. 0 with 1, 2 with 3) like Merge Sort. After log2(k) rounds, one combined list remains. Total time: O(N log k), space: O(1) auxiliary space.

Official Constraints:
  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • lists[i] is sorted in ascending order.
  • The sum of lists[i].length will not exceed 10^4.

Imagine k parallel lanes of traffic merging into a single highway lane. In each lane, cars are already sorted from smallest to largest license plate number. Rather than comparing all k cars across every lane on every move, a single traffic director watches only the very front car of each lane using a mini leaderboard (the Min-Heap). Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N * K) Time, O(1) Space

Repeatedly merge lists one by one: merge list 0 with list 1, then the result with list 2, then list 3, etc.

Wasted Work: Re-traversing already merged elements K times, leading to quadratic time on the number of lists.
The Optimal Breakthrough O(N log K) Time, O(K) Space

Min-Heap priority queue holding at most K active node heads.

Core Invariant: The priority queue always holds the active candidate head of every non-exhausted linked list, guaranteeing `pq.peek()` is the global minimum.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Sequential 1-by-1 Merge O(N * K) O(1) N = 10,000, K = 1,000 → 10^7 operations (too slow).
★ 2. Min-Heap PriorityQueue O(N log K) O(K) Optimal runtime; heap size strictly bounded by K.
★ 3. Divide & Conquer Pairwise O(N log K) O(1) In-place pointer rewiring; zero heap memory overhead.

Min-Heap PriorityQueue

PriorityQueue holding at most K list heads. Poll smallest node, wire into merged list, and offer its next pointer into the queue.

Time: O(N log K) Time Space: O(K) Space 
import java.util.PriorityQueue

class Solution {
    fun mergeKLists(lists: Array<ListNode?>): ListNode? {
        if (lists.isEmpty()) return null

        val pq = PriorityQueue<ListNode>(compareBy { it.`val` })
        for (head in lists) {
            if (head != null) {
                pq.add(head)
            }
        }

        val dummy = ListNode(0)
        var tail = dummy

        while (pq.isNotEmpty()) {
            val minNode = pq.poll()
            tail.next = minNode
            tail = tail.next!!

            if (minNode.next != null) {
                pq.add(minNode.next)
            }
        }

        return dummy.next
    }
}

import heapq

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        # Store (val, unique_id, node) to break ties without comparing ListNode objects
        pq = []
        for i, head in enumerate(lists):
            if head:
                heapq.heappush(pq, (head.val, i, head))
                
        dummy = ListNode(0)
        tail = dummy
        count = len(lists)
        
        while pq:
            val, _, min_node = heapq.heappop(pq)
            tail.next = min_node
            tail = tail.next
            
            if min_node.next:
                heapq.heappush(pq, (min_node.next.val, count, min_node.next))
                count += 1
                
        return dummy.next

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;

        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> Integer.compare(a.val, b.val));
        for (ListNode head : lists) {
            if (head != null) {
                pq.offer(head);
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;

        while (!pq.isEmpty()) {
            ListNode minNode = pq.poll();
            tail.next = minNode;
            tail = tail.next;

            if (minNode.next != null) {
                pq.offer(minNode.next);
            }
        }

        return dummy.next;
    }
}

Divide and Conquer Pairwise Merging

Merge pairs of lists iteratively in rounds (0 with 1, 2 with 3, etc.). In each round, the number of lists is halved, terminating after log2(K) rounds with zero extra memory.

Time: O(N log K) Time Space: O(1) Auxiliary Space 
class SolutionDivideConquer {
    fun mergeKLists(lists: Array<ListNode?>): ListNode? {
        if (lists.isEmpty()) return null
        var interval = 1
        val k = lists.size

        while (interval < k) {
            for (i in 0 until k - interval step interval * 2) {
                lists[i] = mergeTwo(lists[i], lists[i + interval])
            }
            interval *= 2
        }

        return lists[0]
    }

    private fun mergeTwo(l1: ListNode?, l2: ListNode?): ListNode? {
        val dummy = ListNode(0)
        var tail = dummy
        var p1 = l1
        var p2 = l2

        while (p1 != null && p2 != null) {
            if (p1.`val` <= p2.`val`) {
                tail.next = p1
                p1 = p1.next
            } else {
                tail.next = p2
                p2 = p2.next
            }
            tail = tail.next!!
        }

        tail.next = p1 ?: p2
        return dummy.next
    }
}

class SolutionDivideConquer:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        if not lists:
            return None
        interval = 1
        k = len(lists)
        
        while interval < k:
            for i in range(0, k - interval, interval * 2):
                lists[i] = self.merge_two(lists[i], lists[i + interval])
            interval *= 2
            
        return lists[0]
        
    def merge_two(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0)
        tail = dummy
        while l1 and l2:
            if l1.val <= l2.val:
                tail.next = l1
                l1 = l1.next
            else:
                tail.next = l2
                l2 = l2.next
            tail = tail.next
        tail.next = l1 or l2
        return dummy.next

class SolutionDivideConquer {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) return null;
        int interval = 1;
        int k = lists.length;

        while (interval < k) {
            for (int i = 0; i < k - interval; i += interval * 2) {
                lists[i] = mergeTwo(lists[i], lists[i + interval]);
            }
            interval *= 2;
        }

        return lists[0];
    }

    private ListNode mergeTwo(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                tail.next = l1;
                l1 = l1.next;
            } else {
                tail.next = l2;
                l2 = l2.next;
            }
            tail = tail.next;
        }
        tail.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
