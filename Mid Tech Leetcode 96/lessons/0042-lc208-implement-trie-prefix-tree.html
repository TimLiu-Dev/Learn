LeetCode #208: Implement Trie (Prefix Tree)

Official LC #208

Official Problem Statement

A trie (pronounced as "try") or prefix tree is a tree data structure used to efficiently store and retrieve keys in a dataset of strings. There are various applications of this data structure, such as autocomplete and spellchecker.

Implement the Trie class:

  • Trie() Initializes the trie object.
  • void insert(String word) Inserts the string word into the trie.
  • boolean search(String word) Returns true if the string word is in the trie (i.e., was inserted before), and false otherwise.
  • boolean startsWith(String prefix) Returns true if there is a previously inserted string word that has the prefix prefix, and false otherwise.

Example 1: ["Trie", "insert", "search", "search", "startsWith", "insert", "search"] [[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]] → Output: [null, null, true, false, true, null, true]

Plain-English Translation & Core Nuance

A tree where each node has up to 26 children ('a' through 'z') and a boolean `isEnd` flag. To insert, walk characters, creating nodes as needed, marking the terminal node `isEnd = true`. For search, ensure path exists and `isEnd == true`. For startsWith, ensure path exists regardless of `isEnd`.

Official Constraints:
  • 1 <= word.length, prefix.length <= 2000
  • word and prefix consist only of lowercase English letters.
  • At most 3 * 10^4 calls in total will be made to insert, search, and startsWith.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single character word insert('a') → Creates root child at index 0, marks `isEnd = true`.
Best-Case Early Exit
Search prefix that equals full word → Both `search` and `startsWith` return true.
Worst-Case Full Scan
Querying word that fails at first character → Immediately returns false in O(1).

💡 Airport Luggage Routing Hub

Think of an automated airport conveyor system. Bags are routed conveyor by conveyor based on the code letters 'A-P-P-L-E'. Conveyor A branches to P, then P, then L, then E. At room E, a green stamp 'FINAL DESTINATION' is marked. If a baggage handler asks: 'Are there any bags routed through A-P-P?' (startsWith), we answer YES because room P exists. If they ask: 'Is A-P-P a final flight?' (search), we check if room P has the green stamp.

The Mental "A-Ha!" Switch:

`search` and `startsWith` share identical node-walking logic! Extracting a private helper `findPrefixNode(str)` unifies both operations: `startsWith` returns `node != null`, while `search` returns `node != null && node.isEnd`.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap Search: O(L), Prefix: O(W * L) Time

Store words in a HashSet. Exact search is O(L), but `startsWith(prefix)` requires scanning all W words in the dictionary.

Wasted Work: Re-scanning every word in the dictionary for prefix queries.
The Optimal Breakthrough O(L) Time per Op, O(Total Chars * 26) Space

26-Way Array TrieNode. Insert, search, and startsWith all execute in strict O(L) time proportional to query length L, completely independent of total words W.

Core Invariant: Every path from the root node represents a unique prefix formed by the concatenated edge characters.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. HashSet + Linear Prefix Scan Search: O(L), Prefix: O(W * L) O(W * L) Prefix search degrades with large dictionaries.
2. HashMap-Based TrieNode Insert/Search/Prefix: O(L) O(Total Chars) Memory adaptive for Unicode charsets.
★ 3. 26-Way Array TrieNode Insert/Search/Prefix: O(L) O(Total Chars * 26) Optimal cache locality and zero hash collisions.

HashSet + Linear Prefix Scan (Naive)

Store words in a HashSet. Search checks set membership in O(L). startsWith scans all words in O(W * L).

Time: Search: O(L), Prefix: O(W * L) Space: O(W * L) 
class Trie() {
    private val words = HashSet<String>()

    fun insert(word: String) {
        words.add(word)
    }

    fun search(word: String): Boolean {
        return words.contains(word)
    }

    fun startsWith(prefix: String): Boolean {
        return words.any { it.startsWith(prefix) }
    }
}

HashMap-Based Dynamic TrieNode

Use a HashMap for child links. Saves memory when the character set is large or sparse (e.g. Unicode).

Time: O(L) per operation Space: O(Total Chars) 
class Trie() {
    private class TrieNode {
        val children = HashMap<Char, TrieNode>()
        var isEnd = false
    }

    private val root = TrieNode()

    fun insert(word: String) {
        var curr = root
        for (ch in word) {
            curr = curr.children.computeIfAbsent(ch) { TrieNode() }
        }
        curr.isEnd = true
    }

    fun search(word: String): Boolean {
        var curr = root
        for (ch in word) {
            curr = curr.children[ch] ?: return false
        }
        return curr.isEnd
    }

    fun startsWith(prefix: String): Boolean {
        var curr = root
        for (ch in prefix) {
            curr = curr.children[ch] ?: return false
        }
        return true
    }
}

class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word: str) -> None:
        curr = self.root
        for ch in word:
            curr = curr.setdefault(ch, {})

        curr = self.root
        for ch in word:
            if ch not in curr: return False
            curr = curr[ch]
        return '#' in curr

    def startsWith(self, prefix: str) -> bool:
        curr = self.root
        for ch in prefix:
            if ch not in curr: return False
            curr = curr[ch]
        return True

class Trie {
    private static class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        boolean isEnd = false;
    }

    private final TrieNode root = new TrieNode();

    public void insert(String word) {
        TrieNode curr = root;
        for (char ch : word.toCharArray()) {
            curr = curr.children.computeIfAbsent(ch, k -> new TrieNode());
        }
        curr.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode curr = root;
        for (char ch : word.toCharArray()) {
            curr = curr.children.get(ch);
            if (curr == null) return false;
        }
        return curr.isEnd;
    }

    public boolean startsWith(String prefix) {
        TrieNode curr = root;
        for (char ch : prefix.toCharArray()) {
            curr = curr.children.get(ch);
            if (curr == null) return false;
        }
        return true;
    }
}

26-Way Array TrieNode (Optimal Primary)

Array of size 26 per node (`TrieNode[26]`). Zero hashing overhead and maximum memory locality.

Time: O(L) per operation Space: O(Total Chars * 26) 
class Trie() {
    /**
     * Optimal: 26-Way Fixed Array Trie
     * Time: O(L) - Operations proportional to query length L
     * Space: O(N * 26) - Fixed alphabet storage
     */
    private class TrieNode {
        val children = arrayOfNulls<TrieNode>(26)
        var isEnd = false
    }

    private val root = TrieNode()

    fun insert(word: String) {
        var curr = root
        for (ch in word) {
            val idx = ch - 'a'
            if (curr.children[idx] == null) {
                curr.children[idx] = TrieNode()
            }
            curr = curr.children[idx]!!
        }
        curr.isEnd = true
    }

    fun search(word: String): Boolean {
        val node = findPrefixNode(word)
        return node != null && node.isEnd
    }

    fun startsWith(prefix: String): Boolean {
        return findPrefixNode(prefix) != null
    }

    private fun findPrefixNode(str: String): TrieNode? {
        var curr = root
        for (ch in str) {
            val idx = ch - 'a'
            curr = curr.children[idx] ?: return null
        }
        return curr
    }
}

class TrieNode:
    def __init__(self):

class Trie:
    # Optimal: 26-Way Array Trie
    # Time: O(L) per operation
    # Space: O(Total Chars * 26)
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for ch in word:
            idx = ord(ch) - ord('a')
            if not curr.children[idx]:
                curr.children[idx] = TrieNode()
            curr = curr.children[idx]
        curr.is_end = True

    def search(self, word: str) -> bool:
        node = self._find_node(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._find_node(prefix) is not None

    def _find_node(self, prefix: str) -> Optional[TrieNode]:
        curr = self.root
        for ch in prefix:
            idx = ord(ch) - ord('a')
            if not curr.children[idx]:
                return None
            curr = curr.children[idx]
        return curr
Python Runtime & Memory Nuance:

Index mapping `ord(ch) - ord('a')` delivers instant O(1) branch indexing.

class Trie {
    /**
     * Optimal: 26-Way Array TrieNode
     * Time: O(L) per operation
     * Space: O(Total Chars * 26)
     */
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isEnd = false;
    }

    private final TrieNode root;

    public Trie() {
        this.root = new TrieNode();
    }

    public void insert(String word) {
        TrieNode curr = root;
        for (int i = 0; i < word.length(); i++) {
            int idx = word.charAt(i) - 'a';
            if (curr.children[idx] == null) {
                curr.children[idx] = new TrieNode();
            }
            curr = curr.children[idx];
        }
        curr.isEnd = true;
    }

    public boolean search(String word) {
        TrieNode node = findNode(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return findNode(prefix) != null;
    }

    private TrieNode findNode(String prefix) {
        TrieNode curr = root;
        for (int i = 0; i < prefix.length(); i++) {
            int idx = prefix.charAt(i) - 'a';
            if (curr.children[idx] == null) return null;
            curr = curr.children[idx];
        }
        return curr;
    }
}
