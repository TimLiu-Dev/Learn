Problem #380: Insert Delete GetRandom O(1)

View on NeetCode ↗

Official Problem Statement

Implement the RandomizedSet class:

  • RandomizedSet() Initializes the RandomizedSet object.
  • bool insert(int val) Inserts an item val into the set if not present. Returns true if the item was not present, false otherwise.
  • bool remove(int val) Removes an item val from the set if present. Returns true if the item was present, false otherwise.
  • int getRandom() Returns a random element from the current set of elements (it's guaranteed that at least one element exists when this method is called). Each element must have the same probability of being returned.

You must implement the functions of the class such that each function works in average O(1) time complexity.

Example 1: ["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"] [[], [1], [2], [2], [], [1], [2], []] → Output: [null, true, false, true, 2, true, false, 2] Explanation: RandomizedSet randomizedSet = new RandomizedSet(); randomizedSet.insert(1); // Inserts 1 to the set. Returns true as 1 was inserted successfully. randomizedSet.remove(2); // Returns false as 2 does not exist in the set. randomizedSet.insert(2); // Inserts 2 to the set, returns true. Set now contains [1,2]. randomizedSet.getRandom(); // getRandom() should return either 1 or 2 randomly. randomizedSet.remove(1); // Removes 1 from the set, returns true. Set now contains [2]. randomizedSet.insert(2); // 2 was already in the set, so return false. randomizedSet.getRandom(); // Since 2 is the only number in the set, getRandom() will always return 2.

Plain-English Translation & Core Nuance

A HashMap provides O(1) insert and delete, but cannot pick an element uniformly at random in O(1) time. An ArrayList allows O(1) random index sampling, but deletion from an arbitrary index takes O(N) due to array shifting. To get O(1) across all three operations, we combine an ArrayList with a HashMap<Value, Index>. For deletion, we swap the target element with the last element in the list, update the map, and pop the last element in O(1) time without shifting.

Official Constraints:
  • -2^31 <= val <= 2^31 - 1
  • At most 2 * 10^5 calls will be made to insert, remove, and getRandom.
  • There will be at least one element in the data structure when getRandom is called.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case

Best-Case Early Exit
Remove element already at the end → No swap needed; simple O(1) pop.
Worst-Case Full Scan
Duplicate insert insert(1) -> insert(1) → Second call returns false immediately in O(1).

The Mental Model & "Explain Like I'm 12"

💡 The Swapping Parking Lot

Imagine a parking lot with numbered parking stalls (an array) and a guard booth ledger listing where each license plate is parked (a HashMap). If car #3 wants to leave, you don't shift all cars from stall #4 to #100 forward! Instead, you take the car in the very last stall, drive it into stall #3, update the guard's ledger, and close the last stall. Now stall #3 is occupied, the last stall is free, and nobody else had to move.

The Mental "A-Ha!" Switch:

Array deletion is only O(N) because shifting elements preserves order. But a Set has NO concept of order! Swapping the element to delete with the tail element turns an O(N) shift into an O(1) pop.

Pattern Trigger:

Insert, Delete, and GetRandom all in O(1) average time → ArrayList + HashMap with Swap-With-Last deletion.

★ Production Optimal: ArrayList + HashMap with Swap-With-Last Removal

ArrayList stores values for uniform random indexing; HashMap maps each value to its index in the list. On deletion, overwrite target with tail element and pop the tail.

Time: Insert: O(1) Space: Delete: O(1) 
import kotlin.random.Random

class RandomizedSet() {
    private val list = ArrayList<Int>()
    private val map = HashMap<Int, Int>() // val -> index in list

    fun insert(`val`: Int): Boolean {
        if (map.containsKey(`val`)) return false
        map[`val`] = list.size
        list.add(`val`)
        return true
    }

    fun remove(`val`: Int): Boolean {
        val idx = map[`val`] ?: return false
        val lastIdx = list.size - 1
        val lastVal = list[lastIdx]

        // Swap target with last element
        list[idx] = lastVal
        map[lastVal] = idx

        // Pop last element
        list.removeAt(lastIdx)
        map.remove(`val`)
        return true
    }

    fun getRandom(): Int {
        val randIdx = Random.nextInt(list.size)
        return list[randIdx]
    }
}
Kotlin Runtime & Memory Nuance:

In ★ Production Optimal: ArrayList + HashMap with Swap-With-Last Removal, Kotlin leverages HashMap for amortized O(1) key lookup while avoiding repeated key hashing via getOrPut / getOrDefault; and uses a nested local function or helper method to share outer scope cleanly without passing redundant state parameters.

import random

class RandomizedSet:
    def __init__(self):
        self.list = []
        self.map = {}  # val -> index in list

    def insert(self, val: int) -> bool:
        if val in self.map:
            return False
        self.map[val] = len(self.list)
        self.list.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.map:
            return False
        idx = self.map[val]
        last_val = self.list[-1]

        # Swap target with last element
        self.list[idx] = last_val
        self.map[last_val] = idx

        # Pop last element
        self.list.pop()
        del self.map[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.list)

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Random;

class RandomizedSet {
    private final List<Integer> list;
    private final Map<Integer, Integer> map;
    private final Random rand;

    public RandomizedSet() {
        list = new ArrayList<>();
        map = new HashMap<>();
        rand = new Random();
    }

    public boolean insert(int val) {
        if (map.containsKey(val)) return false;
        map.put(val, list.size());
        list.add(val);
        return true;
    }

    public boolean remove(int val) {
        Integer idx = map.get(val);
        if (idx == null) return false;

        int lastIdx = list.size() - 1;
        int lastVal = list.get(lastIdx);

        // Swap with last element
        list.set(idx, lastVal);
        map.put(lastVal, idx);

        // Pop tail
        list.remove(lastIdx);
        map.remove(val);
        return true;
    }

    public int getRandom() {
        return list.get(rand.nextInt(list.size()));
    }
}
