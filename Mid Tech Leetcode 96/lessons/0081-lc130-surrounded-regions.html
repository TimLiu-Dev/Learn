LeetCode #130: Surrounded Regions

Official LC #130

Official Problem Statement

Given an m x n matrix board containing 'X' and 'O', capture all regions that are 4-directionally surrounded by 'X'.

A region is captured by flipping all 'O's into 'X's in that surrounded region.

Example 1: board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]] → Output: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]] Explanation: Notice that an 'O' should not be flipped if: - It is on the border, or - It is adjacent to an 'O' that should not be flipped. The bottom 'O' is on the border, so it is not flipped. All other 'O's are surrounded and flipped to 'X'.

Example 2: board = [["X"]] → Output: [["X"]]

Plain-English Translation & Core Nuance

Any 'O' region that touches the border of the board CANNOT be captured. Therefore, any 'O' connected to a border 'O' must be saved! We run DFS/BFS starting ONLY from border 'O' cells, temporarily renaming them to a safe marker 'T' (for Temporary/Safe). Once all border-connected 'O's are safely marked as 'T', we sweep the board: any remaining 'O' is truly surrounded, so we flip it to 'X'. Finally, we restore all 'T's back to 'O'.

Official Constraints:
  • m == board.length
  • n == board[i].length
  • 1 <= m, n <= 200
  • board[i][j] is 'X' or 'O'.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single cell board [['O']] → It touches the border, so it remains 'O'.
Best-Case Early Exit
All 'X's [['X', 'X'], ['X', 'X']] → No 'O's exist; board unchanged.
Worst-Case Full Scan
Snake-like 'O' channel winding from border to center → All connected cells correctly marked as 'T' and preserved.

💡 The Medieval Castle Moat Escape Tunnel

Imagine soldiers trapped inside a castle grid. Any soldier ('O') who has an open tunnel connecting them to the outside border escapes freely. You start at all outside castle gates (borders): if there is an escape tunnel ('O'), you follow it inward and give every connected soldier a permanent green evacuation badge ('T'). Once all escape tunnels are surveyed, any soldier still wearing an unbadged 'O' was completely cut off and surrounded—they are captured ('X'). Finally, all badged soldiers take off their temporary badges and return to 'O'.

The Mental "A-Ha!" Switch:

It is much easier to find what CANNOT be captured than what CAN be captured. Any 'O' connected to the border survives; everything else is captured.

Pattern Trigger:

Capture surrounded interior regions in a 2D grid → Border-seeded DFS marking safe cells with a temporary sentinel 'T'.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O((M * N)^2) Time, O(M * N) Space

From every interior 'O', run a traversal to check if it can reach the border. If false, flip all cells in that component.

Wasted Work: Re-traversing overlapping components from multiple starting points.
The Optimal Breakthrough O(M * N) Time, O(M * N) Space

Seed DFS only from the perimeter border 'O's. Flip surviving 'O's to 'T', then one final sweep flips 'O' -> 'X' and 'T' -> 'O'.

Core Invariant: After phase 1, all 'O's remaining on the board are strictly surrounded by 'X's and have zero connectivity to any border.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Component Flood Check O((M * N)^2) O(M * N) Tests every interior component independently.
★ 2. Border-Seeded Safe Marking O(M * N) O(M * N) In-place modifications; exactly two matrix passes.

★ Approach: Border-Seeded Safe-Marking (Production Optimal)

Seed DFS from perimeter border 'O's, temporarily renaming connected cells to 'T'. Then scan all cells: flip remaining 'O' to 'X' (captured), and 'T' back to 'O' (rescued).

Time: O(M * N) Time Space: O(M * N) Space 
class Solution {
    fun solve(board: Array<CharArray>) {
        if (board.isEmpty() || board[0].isEmpty()) return
        val m = board.size
        val n = board[0].size

        fun dfs(r: Int, c: Int) {
            if (r !in 0 until m || c !in 0 until n || board[r][c] != 'O') return
            board[r][c] = 'T' // Mark as temporary safe
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)
        }

        // Step 1: Flood fill from borders
        for (r in 0 until m) {
            if (board[r][0] == 'O') dfs(r, 0)
            if (board[r][n - 1] == 'O') dfs(r, n - 1)
        }
        for (c in 0 until n) {
            if (board[0][c] == 'O') dfs(0, c)
            if (board[m - 1][c] == 'O') dfs(m - 1, c)
        }

        // Step 2: Final sweep
        for (r in 0 until m) {
            for (c in 0 until n) {
                if (board[r][c] == 'O') {
                    board[r][c] = 'X' // Captured!
                } else if (board[r][c] == 'T') {
                    board[r][c] = 'O' // Restored safe
                }
            }
        }
    }
}

class Solution {
    public void solve(char[][] board) {
        if (board == null || board.length == 0 || board[0].length == 0) return;
        int m = board.length;
        int n = board[0].length;

        // Step 1: Run DFS from all border 'O's
        for (int r = 0; r < m; r++) {
            if (board[r][0] == 'O') dfs(r, 0, board);
            if (board[r][n - 1] == 'O') dfs(r, n - 1, board);
        }
        for (int c = 0; c < n; c++) {
            if (board[0][c] == 'O') dfs(0, c, board);
            if (board[m - 1][c] == 'O') dfs(m - 1, c, board);
        }

        // Step 2: Flip 'O' -> 'X' and 'T' -> 'O'
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (board[r][c] == 'O') {
                    board[r][c] = 'X';
                } else if (board[r][c] == 'T') {
                    board[r][c] = 'O';
                }
            }
        }
    }

    private void dfs(int r, int c, char[][] board) {
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length || board[r][c] != 'O') return;
        board[r][c] = 'T';
        dfs(r + 1, c, board);
        dfs(r - 1, c, board);
        dfs(r, c + 1, board);
        dfs(r, c - 1, board);
    }
}

          Phase 2: Space-Time Strategy Pitch
          
""Instead of checking every interior 'O' to see if it can reach the boundary, we flip the logic: any 'O' that can reach the boundary is SAFE from capture. We only seed DFS from border cells (row 0, row m-1, col 0, col n-1) that contain 'O'. During DFS, we mark all connected 'O' cells with a temporary marker 'T'. Once all border-connected components are safely marked as 'T', we perform a single linear sweep over the entire board: any cell still labeled 'O' was cut off from the border, so we flip it to 'X'. Any cell labeled 'T' was border-connected, so we restore it to 'O'. This takes O(M*N) time and requires zero extra auxiliary heap allocation.""

        

        

          Phase 3: Live Coding Narrative
          
""Let me write the code. `dfs(r, c)`: boundary checks, if `board[r][c] != 'O'` return. Set `board[r][c] = 'T'`, then recurse on 4 neighbors. Loop over columns: call `dfs(0, c)` and `dfs(m-1, c)`. Loop over rows: call `dfs(r, 0)` and `dfs(r, n-1)`. In the final nested loops: if cell is 'O', set to 'X'; if 'T', set to 'O'.""

        

        

          Phase 4: Cold Edge-Case Verification
          
""Tracing with Example 1: bottom border cell at (3, 1) has 'O'. DFS runs from (3, 1), marks it 'T'. Its neighbors are 'X', so DFS stops. Interior cells (1, 1), (1, 2), (2, 2) remain 'O'. In the final sweep, (1, 1), (1, 2), (2, 2) become 'X'. Cell (3, 1) is restored from 'T' back to 'O'. Clean, in-place, and runs in optimal O(M*N) time.""
