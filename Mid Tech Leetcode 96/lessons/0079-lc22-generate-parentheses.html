LeetCode #22: Generate Parentheses

Official LC #22

Official Problem Statement

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

Example 1: n = 3 → Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2: n = 1 → Output: ["()"]

Plain-English Translation & Core Nuance

A sequence of n pairs of parentheses is well-formed if and only if: 1) It has exactly n '(' and n ')' characters; and 2) At any prefix, the number of closing brackets ')' never exceeds the number of opening brackets '('. We use constrained backtracking tracking `openCount` and `closeCount`. We can append '(' whenever `openCount < n`. We can append ')' whenever `closeCount < openCount`. When length reaches 2n, we record the valid string.

Official Constraints:
  • 1 <= n <= 8

The Mental Model & "Explain Like I'm 12"

💡 The Bank Deposit / Withdrawal Balance

Think of '(' as depositing a dollar and ')' as withdrawing a dollar. You are allowed to make at most n deposits and n withdrawals. The only rule is: your account balance can NEVER go negative! You can make another deposit whenever you haven't reached your n deposit limit (`open < n`). You can only make a withdrawal if you currently have money in the bank (`close < open`). When all n deposits and n withdrawals are complete, your balance is exactly $0.

The Mental "A-Ha!" Switch:

Never generate invalid strings! Instead of generating all 2^(2n) strings and validating them with a stack, our two simple numeric guards (`open < n` and `close < open`) prune all invalid paths at birth, generating ONLY 100% valid well-formed strings.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(2^(2N) * N) Time, O(N) Space

Generate all 2^(2N) combinations of '(' and ')' characters using brute-force recursion, then validate each with a stack.

Wasted Work: Generating vast numbers of invalid combinations (e.g. ")))((") only to reject them at the end.
The Optimal Breakthrough O(4^N / sqrt(N)) Time, O(N) Space

Constrained backtracking. Every branch explored leads to a strictly valid well-formed string (Catalan number C_n).

Core Invariant: At every step in the path, `0 <= closeCount <= openCount <= n`. No invalid prefix is ever constructed.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Generate All & Validate O(2^(2N) * N) O(N) Tests 2^{16} = 65,536 combinations for n=8.
★ 2. Constrained Backtracking O(C_n * N) O(N) Generates exactly 1,430 valid strings for n=8; zero waste.

★ Approach: Constrained Backtracking (Production Optimal)

Branch only on valid moves: add '(' if open < n; add ')' if close < open. Generates exactly the n-th Catalan number of strings with zero invalid dead ends.

Time: O(4^N / sqrt(N)) Time Space: O(N) Auxiliary Space 
class Solution {
    fun generateParenthesis(n: Int): List<String> {
        val result = mutableListOf<String>()
        val sb = StringBuilder()

        fun backtrack(open: Int, close: Int) {
            if (sb.length == 2 * n) {
                result.add(sb.toString())
                return
            }

            if (open < n) {
                sb.append('(')
                backtrack(open + 1, close)
                sb.deleteCharAt(sb.lastIndex) // Backtrack
            }

            if (close < open) {
                sb.append(')')
                backtrack(open, close + 1)
                sb.deleteCharAt(sb.lastIndex) // Backtrack
            }
        }

        backtrack(0, 0)
        return result
    }
}

class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        result = []
        path = []

        def backtrack(open_count: int, close_count: int):
            if len(path) == 2 * n:
                result.append("".join(path))
                return

            if open_count < n:
                path.append('(')
                backtrack(open_count + 1, close_count)
                path.pop()

            if close_count < open_count:
                path.append(')')
                backtrack(open_count, close_count + 1)
                path.pop()

        backtrack(0, 0)
        return result

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(0, 0, new StringBuilder(), n, result);
        return result;
    }

    private void backtrack(int open, int close, StringBuilder sb, int n, List<String> result) {
        if (sb.length() == 2 * n) {
            result.add(sb.toString());
            return;
        }

        if (open < n) {
            sb.append('(');
            backtrack(open + 1, close, sb, n, result);
            sb.deleteCharAt(sb.length() - 1);
        }

        if (close < open) {
            sb.append(')');
            backtrack(open, close + 1, sb, n, result);
            sb.deleteCharAt(sb.length() - 1);
        }
    }
}
