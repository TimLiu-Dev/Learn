Problem Statement & Boundary Checks

LeetCode #20 ↗

Verbatim Problem Statement

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.
  3. Every close bracket has a corresponding open bracket of the same type.

Plain-English Translation

Brackets must match from the inside out, like nesting Russian dolls. The most recently opened bracket must be the very first one closed. If you encounter a closing bracket with no open partner, or it closes the wrong type, or unclosed open brackets remain at the end, the string is invalid.

Example 1 (Sequential)
Input: s = "()[]{}"
Output: true

Each pair opens and immediately closes with its matching partner.

Example 2 (Nested)
Input: s = "([])"
Output: true

Inner [] closes first, then outer () closes.

Example 3 (Interleaved / Mismatch)
Input: s = "([)]"
Output: false

) attempts to close [ before [ was closed.

Constraints

  • 1 ≤ s.length ≤ 104
  • s consists only of '()[]{}'

3 Canonical Boundary Check Shapes

1. Odd Length: "()(" → Any odd length string can never be valid; exit in O(1) via s.length % 2 != 0.
2. Closing First (Underflow): ")(" → Stack is empty when ')' arrives; must not throw exception, return false.
3. Unclosed Residue: "(()" → String finishes but stack still contains '('. Check stack.isEmpty().

The Mental Model & "Explain Like I'm 12"

Why a spring-loaded tube perfectly mirrors nested bracket closures.

The Cafeteria Plate Dispenser

Picture a cafeteria plate dispenser: a vertical cylinder with a spring at the bottom. You can only drop a plate on top, and you can only grab the top plate off.

The Senior Secret Trick: When you see an open bracket like '(', don't push '('. Instead, push its expected closing partner ')' onto the plate dispenser!

  • See '(' → push ')'
  • See '{' → push '}'
  • See '[' → push ']'

Now, whenever a closing bracket arrives, you only need to do one trivial check:

if (stack.isEmpty() || stack.pop() != currentChar) return false

No hash maps, no switch statements, no reverse lookups. The stack tells you exactly which character must be seen next!

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

Why string replacement loops are a disaster in interviews.

The Naive Trap: String Replace Loop O(N²) String Copies

Continuously deleting adjacent pairs: 

var str = s
while (str.contains("()") || str.contains("[]") || str.contains("{}")) {
    str = str.replace("()", "").replace("[]", "").replace("{}", "")
}
return str.isEmpty()
  • Catastrophic Heap Allocations: For $N = 10,000$, deeply nested parentheses like "((((...))))" take N / 2 iterations. Each iteration creates 3 full copies of the remaining string.
  • Quadratic Overhead: O(N^2) execution causes extreme GC pressure and severe lag.
Interview Verdict: Major red flag in technical screen
Optimal Breakthrough: Partner-Pushing Stack O(N) Time • O(N) Space

Push expected closing characters; assert top equality upon closure: 

if (s.length % 2 != 0) return false
val stack = ArrayDeque<Char>()
for (c in s) {
    when (c) {
        '(' -> stack.addLast(')')
        '{' -> stack.addLast('}')
        '[' -> stack.addLast(']')
        else -> if (stack.isEmpty() || stack.removeLast() != c) return false
    }
}
return stack.isEmpty()
  • Strictly Linear: Each character is pushed at most once and popped at most once. Exactly O(N) operations.
  • Zero Lookup Overhead: No HashMap search. Direct character comparison on pop.
Interview Verdict: Standard senior implementation

From Brute Force to Optimal & Interactive Sandbox

Evolution from quadratic string replacement to partner-pushing LIFO stack.

Approach 1: Continuous String Replacement (O(N²))

Continuously search for adjacent matching pairs "()", "[]", "{}" and remove them until no more pairs can be eliminated. Extremely slow due to quadratic string copying. 

class Solution {
    fun isValid(s: String): Boolean {
        var str = s
        while (str.contains("()") || str.contains("[]") || str.contains("{}")) {
            str = str.replace("()", "")
                     .replace("[]", "")
                     .replace("{}", "")
        }
        return str.isEmpty()
    }
}
class Solution:
    def isValid(self, s: str) -> bool:
        while '()' in s or '[]' in s or '{}' in s:
            s = s.replace('()', '').replace('[]', '').replace('{}', '')
        return len(s) == 0
class Solution {
    public boolean isValid(String s) {
        String str = s;
        while (str.contains("()") || str.contains("[]") || str.contains("{}")) {
            str = str.replace("()", "").replace("[]", "").replace("{}", "");
        }
        return str.isEmpty();
    }
}
Approach 2: Standard Stack with Lookup Map (O(N) Time, O(N) Space)

Push opening brackets to a stack. When a closing bracket arrives, look up its matching opening bracket in a dictionary/map and check against the popped top element. 

class Solution {
    fun isValid(s: String): Boolean {
        val map = mapOf(')' to '(', '}' to '{', ']' to '[')
        val stack = ArrayDeque<Char>()

        for (c in s) {
            if (map.containsKey(c)) {
                if (stack.isEmpty() || stack.removeLast() != map[c]) {
                    return false
                }
            } else {
                stack.addLast(c)
            }
        }
        return stack.isEmpty()
    }
}
class Solution:
    def isValid(self, s: str) -> bool:
        bracket_map = {')': '(', '}': '{', ']': '['}
        stack = []

        for char in s:
            if char in bracket_map:
                top_element = stack.pop() if stack else '#'
                if bracket_map[char] != top_element:
                    return False
            else:
                stack.append(char)
        return not stack
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        Map<Character, Character> map = Map.of(')', '(', '}', '{', ']', '[');
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (map.containsKey(c)) {
                if (stack.isEmpty() || stack.pollLast() != map.get(c)) {
                    return false;
                }
            } else {
                stack.addLast(c);
            }
        }
        return stack.isEmpty();
    }
}
Approach 3: Partner-Pushing LIFO Stack (O(N) Time, O(N) Space)

Push expected closing partners directly. Enables simple single-token comparison on closing events without any hash table allocations. 

class Solution {
    fun isValid(s: String): Boolean {
        // 1. Parity Check: Odd length strings cannot be partitioned into valid pairs
        if (s.length % 2 != 0) return false

        // 2. ArrayDeque is significantly faster than legacy java.util.Stack
        val stack = ArrayDeque<Char>()

        for (c in s) {
            when (c) {
                '(' -> stack.addLast(')')
                '{' -> stack.addLast('}')
                '[' -> stack.addLast(']')
                else -> {
                    // If stack is empty or top doesn't match current closing bracket
                    if (stack.isEmpty() || stack.removeLast() != c) {
                        return false
                    }
                }
            }
        }

        // 3. Valid only if all opened brackets were successfully popped
        return stack.isEmpty()
    }
}
class Solution:
    def isValid(self, s: str) -> bool:
        if len(s) % 2 != 0:
            return False

        stack = []
        partner = {'(': ')', '{': '}', '[': ']'}

        for c in s:
            if c in partner:
                stack.append(partner[c])
            elif not stack or stack.pop() != c:
                return False

        return not stack
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isValid(String s) {
        if (s.length() % 2 != 0) return false;

        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(') stack.addLast(')');
            else if (c == '{') stack.addLast('}');
            else if (c == '[') stack.addLast(']');
            else if (stack.isEmpty() || stack.pollLast() != c) {
                return false;
            }
        }

        return stack.isEmpty();
    }
}
★ Senior Engineering Guardrails

1. Why avoid java.util.Stack: Java's legacy Stack class extends Vector, meaning every method (push, pop) is synchronized! This introduces unnecessary mutex synchronization locks on every iteration. Always use ArrayDeque.

2. Micro-optimization with primitive array: In extreme latency-critical applications, avoid boxed object allocations (Character) completely by allocating a primitive char[s.length()] array and managing a top pointer index head = 0!
