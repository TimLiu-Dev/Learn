LeetCode #424: Longest Repeating Character Replacement

Official LC #424

Official Problem Statement

You are given a string s and an integer k. You can choose any character of the string and change it to any other uppercase English character. You can perform this operation at most k times.

Return the length of the longest substring containing the same letter you can get after performing the above operations.

Example 1: s = "ABAB", k = 2 → Output: 4 Explanation: Replace the two 'A's with 'B's or vice versa.

Example 2: s = "AABABBA", k = 1 → Output: 4 Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA". The substring "BBBB" has the longest repeating letters, which is 4.

Plain-English Translation & Core Nuance

Maintain a dynamic sliding window [left..right]. In any window, the number of characters that must be replaced to make the whole window uniform is `windowLength - maxFreqChar`. If this count exceeds k, the window is invalid, so we increment left. Otherwise, we expand right. The maximum valid window size seen is our answer.

Official Constraints:
  • 1 <= s.length <= 10^5
  • s consists of only uppercase English letters.
  • 0 <= k <= s.length

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
k >= string length s = "ABC", k = 5 → Returns 3 (entire string can be replaced).
Best-Case Early Exit
All identical letters s = "AAAA", k = 0 → Returns 4 without any replacements.
Worst-Case Full Scan
k = 0 with alternating letters s = "ABABA", k = 0 → Returns 1.

The Mental Model & "Explain Like I'm 12"

💡 The Dominant Color Banner

Imagine stretching a rectangular frame over a banner of colored flags. Inside the frame, you find the most frequent flag color (`maxCount`). Every other flag in the frame must be repainted using your limited supply of paint cans (`k`). If the number of other flags `(windowSize - maxCount)` exceeds your paint cans `k`, the frame is too wide. Shift the left edge of the frame to the right.

The Mental "A-Ha!" Switch:

You do not need to decrease `maxCount` when shrinking the window! A window can only beat our current global maximum if it achieves a strictly higher `maxCount`. Stale `maxCount` values cannot produce false positives because window validity is bounded by `right - left + 1`.

Pattern Trigger:

Maximize substring length with at most k character replacements → Sliding window with frequency map and `windowSize - maxCount <= k` invariant.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(26 * N^2) Time, O(1) Space

Check all O(N^2) substrings. For each substring, count frequencies of 26 uppercase letters, find max frequency, and check if length - max <= k.

Wasted Work: Re-scanning substrings from scratch repeatedly instead of sliding existing frequency counts.
The Optimal Breakthrough O(N) Time, O(1) Auxiliary Space

Two-pointer sliding window with a 26-element integer frequency array. Both pointers advance monotonically from 0 to N.

Core Invariant: At any instant, `(right - left + 1) - maxCount <= k` guarantees the window can be turned into identical characters within k edits.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute Force Substrings O(26 * N^2) O(1) Times out on N = 10^5 (2.6 \times 10^{11} ops).
2. Sliding Window with Recalculation O(26 * N) O(1) Scans 26 alphabet buckets on every window contraction.
★ 3. Monotonic Expanding Sliding Window O(N) O(1) Optimal linear execution; maxCount never decremented.

Approach 1: Brute Force All Substrings (O(26 * N^2))

Generate all pairs (i, j). In each substring, count character occurrences across 26 uppercase letters and test if length - maxCount <= k.

Time: O(26 * N^2) Time Space: O(1) Space 
class Solution {
    fun characterReplacement(s: String, k: Int): Int {
        var maxLen = 0
        val n = s.length
        for (i in 0 until n) {
            val count = IntArray(26)
            var maxFreq = 0
            for (j in i until n) {
                count[s[j] - 'A']++
                maxFreq = maxOf(maxFreq, count[s[j] - 'A'])
                val len = j - i + 1
                if (len - maxFreq <= k) {
                    maxLen = maxOf(maxLen, len)
                }
            }
        }
        return maxLen
    }
}

Approach 2: Sliding Window with Rescan (O(26 * N))

Two-pointer sliding window. When window becomes invalid, scan the 26-element array to recompute maxCount precisely before advancing left.

Time: O(26 * N) Time Space: O(1) Space 
class Solution {
    fun characterReplacement(s: String, k: Int): Int {
        val count = IntArray(26)
        var l = 0
        var maxLen = 0

        for (r in s.indices) {
            count[s[r] - 'A']++
            var maxCount = 0
            for (c in count) maxCount = maxOf(maxCount, c)

            while ((r - l + 1) - maxCount > k) {
                count[s[l] - 'A']--
                l++
                maxCount = 0
                for (c in count) maxCount = maxOf(maxCount, c)
            }
            maxLen = maxOf(maxLen, r - l + 1)
        }
        return maxLen
    }
}

★ Approach 3: Monotonic Expanding Window (Production Optimal)

Never decrement maxCount when shrinking! A smaller maxCount cannot increase the maximum valid window size seen so far.

Time: O(N) Time Space: O(1) Auxiliary Space 
class Solution {
    fun characterReplacement(s: String, k: Int): Int {
        val count = IntArray(26)
        var l = 0
        var maxCount = 0
        var maxLen = 0

        for (r in s.indices) {
            val idx = s[r] - 'A'
            count[idx]++
            maxCount = maxOf(maxCount, count[idx])

            // If invalid, shift left pointer by 1
            if ((r - l + 1) - maxCount > k) {
                count[s[l] - 'A']--
                l++
            }

            maxLen = maxOf(maxLen, r - l + 1)
        }
        return maxLen
    }
}

          Phase 1: Clarifying Questions & Edge Cases
          
""First, let me confirm the constraints: s consists of uppercase English letters A through Z. k is between 0 and s.length. The return value is the maximum length of a substring with all identical characters after at most k replacements.""

        

        

          Phase 2: Space-Time Strategy Pitch
          
""We can solve this in linear time using a sliding window. In any window [left..right], the length is (right - left + 1). The most frequent character occurs `maxCount` times. That means we need to replace `(right - left + 1) - maxCount` characters to make the entire window uniform. If this needed replacements exceeds k, the window is invalid and we shift left forward. Crucially, we do NOT need to decrement maxCount when left shifts forward, because our answer can only improve if we discover a new window with a higher maxCount. This gives strict O(N) runtime.""

        

        

          Phase 3: Live Coding Narrative
          
""Let me write the code. I allocate an integer array of size 26 for character frequencies. Initialize `l = 0`, `maxCount = 0`, and `maxLen = 0`. Iterate `r` from 0 to s.length - 1: update frequency, update `maxCount = max(maxCount, count[idx])`. If `(r - l + 1) - maxCount > k`, decrement `count[s[l] - 'A']` and increment `l`. Then update `maxLen = max(maxLen, r - l + 1)`. Return `maxLen`.""

        

        

          Phase 4: Cold Edge-Case Verification
          
""Tracing with `"AABABBA"` and `k=1`. At r=0..3 ('AABA'), maxCount=3, windowSize=4, needed=1 <= 1, maxLen=4. At r=4 ('B'), needed becomes 2 > 1, so l increments to 1. The window size never drops below our previous best. The final maxLen is 4. For edge case k=0, only identical contiguous characters qualify. Everything is verified.""
