LeetCode #53: Maximum Subarray

Official LC #53

Official Problem Statement

Given an integer array nums, find the subarray with the largest sum, and return its sum.

A subarray is a contiguous non-empty sequence of elements within an array.

Example 1: nums = [-2,1,-3,4,-1,2,1,-5,4] → Output: 6

Example 2: nums = [1] → Output: 1

Example 3: nums = [5,4,-1,7,8] → Output: 23

Plain-English Translation & Core Nuance

Find a contiguous slice of numbers whose sum is as large as possible. If extending the current running sum makes it drop below zero, that accumulated sum is a liability to any future subarray, so we drop it and restart our running sum at 0.

Official Constraints:
  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single element array: max sum is that element itself, even if negative.
Best-Case Early Exit
All positive numbers: max sum is the sum of the entire array.
Worst-Case Full Scan
All negative numbers (e.g. [-5, -2, -8]): max sum is the least negative single element (-2).

The Mental Model & "Explain Like I'm 12"

💡 The Debt Reset Button

Imagine running a daily profit-and-loss business. As long as your accumulated net worth is positive, any future profitable day adds to your total wealth. But if your accumulated debt drops below zero, walking away with bankruptcy and restarting fresh tomorrow is better than carrying that negative balance into the future.

The Mental "A-Ha!" Switch:

Kadane's Choice: At each element x, currSum = max(x, currSum + x). If currSum dips negative, reset it to x!

Pattern Trigger:

Contiguous subarray optimization with positive and negative numbers.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(1) Space

Compute the sum of every possible pair of start and end indices (i, j) with two nested loops.

Wasted Work: Re-calculates contiguous slice sums from scratch instead of carrying over the optimal prefix sum.
The Optimal Breakthrough O(N) Time, O(1) Space

Single pass Kadane's algorithm. Maintain current running sum and global maximum. If current running sum is negative, reset to current element.

Core Invariant: currMax stores the maximum contiguous sum ending strictly at index i.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: Nested Loops O(N^2) O(1) Quadratic brute force. TLE for N = 100,000.
Divide and Conquer O(N log N) O(log N) Split array in half; merge cross sums. Educational but non-optimal.
Kadane's Algorithm (DP / Greedy) O(N) O(1) ★ Production standard. Single pass, cache friendly.

Approach 1: Quadratic Prefix Sums

Check every contiguous subarray sum using nested loops.

Time: O(N^2) Space: O(1) 
class Solution {
    fun maxSubArray(nums: IntArray): Int {
        var maxSum = Int.MIN_VALUE
        for (i in nums.indices) {
            var sum = 0
            for (j in i until nums.size) {
                sum += nums[j]
                maxSum = maxOf(maxSum, sum)
            }
        }
        return maxSum
    }
}

        for (int i = 0; i < nums.length; i++) {
            int sum = 0;

}

Approach 2: Kadane's Algorithm

Single pass greedy/dynamic programming running sum tracking.

Time: O(N) Space: O(1) 
class Solution {
    fun maxSubArray(nums: IntArray): Int {
        var currSum = nums[0]
        var maxSum = nums[0]
        for (i in 1 until nums.size) {
            currSum = maxOf(nums[i], currSum + nums[i])
            maxSum = maxOf(maxSum, currSum)
        }
        return maxSum
    }
}
Kotlin Runtime & Memory Nuance:

Zero extra allocations. Handles all negative numbers seamlessly.

class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        curr_sum = nums[0]
        max_sum = nums[0]
        for x in nums[1:]:
            curr_sum = max(x, curr_sum + x)
            max_sum = max(max_sum, curr_sum)
        return max_sum

class Solution {
