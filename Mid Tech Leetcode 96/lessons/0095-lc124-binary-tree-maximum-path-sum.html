LeetCode #124: Binary Tree Maximum Path Sum

Official LC #124

Official Problem Statement

A path in a binary tree is a sequence of nodes where each pair of adjacent nodes in the sequence has an edge connecting them. A node can only appear in the sequence at most once. Note that the path does not need to pass through the root.

The path sum of a path is the sum of the node's values in the path.

Given the root of a binary tree, return the maximum path sum of any non-empty path.

Example 1: root = [1,2,3] → Output: 6 Explanation: The optimal path is 2 -> 1 -> 3 with a path sum of 2 + 1 + 3 = 6.

Example 2: root = [-10,9,20,null,null,15,7] → Output: 42 Explanation: The optimal path is 15 -> 20 -> 7 with a path sum of 15 + 20 + 7 = 42.

Plain-English Translation & Core Nuance

A path in a binary tree can start and end at any node, traveling upward through ancestors and downward into other branches. At each node, the path can either 'arch' through this node (combining left branch + node + right branch), or continue upward to the node's parent (node + max(left, right)). Crucially, any child branch that yields a negative sum should be clamped to 0 (`max(0, gain)`), meaning we simply choose NOT to extend our path down that branch. We run a post-order DFS: for each node, compute `leftGain = max(0, dfs(left))` and `rightGain = max(0, dfs(right))`. The maximum arched path through this node is `node.val + leftGain + rightGain`, which updates our global maximum. We then return `node.val + max(leftGain, rightGain)` to the parent caller.

Official Constraints:
  • The number of nodes in the tree is in the range [1, 3 * 10^4].
  • -1000 <= Node.val <= 1000

The Mental Model & "Explain Like I'm 12"

💡 The Mountain Bridge and Ridgeline

Imagine standing on a mountain peak (`node.val`). You look down your left ridge (`leftGain`) and your right ridge (`rightGain`). If a ridge leads into a toxic swamp (negative sum), you close that trail (`max(0, gain)`). You can build an arching scenic bridge across your peak connecting the left ridge and right ridge (`node.val + leftGain + rightGain`), which might be the most scenic view in the entire mountain range (updating global max). However, if your parent mountain higher up wants you to connect to them, you can only offer them ONE ridge (the best one: `node.val + max(leftGain, rightGain)`), because a continuous trail cannot split into two directions at once.

The Mental "A-Ha!" Switch:

A path can only arch (use both left and right children) at ONE apex node! For that apex's parent, it can only extend along a single branch. Clamping negative child gains to 0 cleanly handles negative node values.

Pattern Trigger:

Maximum path sum in binary tree (any start/end, non-empty) → Post-order DFS returning single-branch gain while updating global arched max.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(H) Space

For every node in the tree, run a separate DFS down its left and right subtrees to calculate max linear paths.

Wasted Work: Re-traversing subtrees multiple times from different ancestor frames instead of bottom-up post-order aggregation.
The Optimal Breakthrough O(N) Time, O(H) Space

Single-pass post-order DFS (bottom-up). Each node is visited once.

Core Invariant: The recursive function `dfs(node)` returns the strictly maximum non-negative contribution this node can provide to a path extending to its parent.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Top-Down DFS per Node O(N^2) O(H) Calculates subtree depths repeatedly; quadratic on skewed trees.
★ Post-Order Single Pass DFS O(N) O(H) Optimal; visits each node once in bottom-up post-order.

Post-Order Bottom-Up DFS

Bottom-up recursive DFS. At each node, clamp negative child contributions to 0, update global max with `node.val + leftGain + rightGain`, and return `node.val + max(leftGain, rightGain)` to parent.

Time: O(N) Time Space: O(H) Space 
class Solution {
    private var maxSum = Int.MIN_VALUE

    fun maxPathSum(root: TreeNode?): Int {
        maxSum = Int.MIN_VALUE
        maxGain(root)
        return maxSum
    }

    private fun maxGain(node: TreeNode?): Int {
        if (node == null) return 0

        // Clamping to 0: ignore subtrees with negative net contribution
        val leftGain = maxOf(0, maxGain(node.left))
        val rightGain = maxOf(0, maxGain(node.right))

        // Price of the new path where `node` acts as apex
        val currentPath = node.`val` + leftGain + rightGain
        maxSum = maxOf(maxSum, currentPath)

        // For parent recursion: can only extend along ONE child branch
        return node.`val` + maxOf(leftGain, rightGain)
    }
}

class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        max_sum = float('-inf')
        
        def max_gain(node: Optional[TreeNode]) -> int:
            nonlocal max_sum
            if not node:
                return 0
                
            # Clamp negative branches to 0
            left_gain = max(0, max_gain(node.left))
            right_gain = max(0, max_gain(node.right))
            
            # Check path arching at this node
            current_path = node.val + left_gain + right_gain
            max_sum = max(max_sum, current_path)
            
            # Return single-branch extension to parent
            return node.val + max(left_gain, right_gain)
            
        max_gain(root)
        return max_sum

class Solution {
    private int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        maxSum = Integer.MIN_VALUE;
        maxGain(root);
        return maxSum;
    }

    private int maxGain(TreeNode node) {
        if (node == null) return 0;

        // Clamp negative paths to 0
        int leftGain = Math.max(0, maxGain(node.left));
        int rightGain = Math.max(0, maxGain(node.right));

        // Evaluate arched path through node
        int currentPath = node.val + leftGain + rightGain;
        maxSum = Math.max(maxSum, currentPath);

        // Return best single branch to parent
        return node.val + Math.max(leftGain, rightGain);
    }
}
