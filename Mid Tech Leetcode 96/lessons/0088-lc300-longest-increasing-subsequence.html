LeetCode #300: Longest Increasing Subsequence

Official LC #300

Official Problem Statement

Given an integer array nums, return the length of the longest strictly increasing subsequence.

Example 1: nums = [10,9,2,5,3,7,101,18] → Output: 4 Explanation: The longest increasing subsequence is [2,3,7,101], therefore the length is 4.

Example 2: nums = [0,1,0,3,2,3] → Output: 4

Example 3: nums = [7,7,7,7,7,7,7] → Output: 1

Plain-English Translation & Core Nuance

A subsequence is derived by deleting zero or more elements without changing the order of remaining elements. We want the maximum length of a strictly increasing subsequence. There are two standard approaches: (1) O(N^2) Dynamic Programming: `dp[i]` is the length of the longest increasing subsequence ending at index `i`. For each `i`, we check all `j < i` and if `nums[j] < nums[i]`, `dp[i] = max(dp[i], dp[j] + 1)`. (2) O(N log N) Patience Sorting: We maintain an array `tails` where `tails[k]` stores the smallest ending tail of all valid increasing subsequences of length `k + 1`. For each number `x`, we use binary search to find the first tail >= `x`. If `x` is larger than all tails, we append it; otherwise we replace that tail with `x`. The length of `tails` at the end is the optimal LIS length.

Official Constraints:
  • 1 <= nums.length <= 2500
  • -10^4 <= nums[i] <= 10^4

The Mental Model & "Explain Like I'm 12"

💡 Patience Card Game Solitaire

Think of the card game Patience. When dealt cards one by one: you can place a card on top of the leftmost pile whose top card is >= current card. If no such pile exists (the card is strictly larger than all pile tops), you start a BRAND-NEW pile to the right. Because pile top cards are always in sorted order from left to right, finding which pile to place a card onto takes just O(\log N) binary search! At the end, the total number of piles created equals the length of the Longest Increasing Subsequence.

The Mental "A-Ha!" Switch:

Replacing a pile top with a smaller number doesn't change the number of piles, but it 'greedily' opens up more opportunities for subsequent smaller numbers to extend the sequence!

Pattern Trigger:

Longest increasing / non-decreasing subsequence → Patience Sorting with Binary Search (O(N \log N)).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N) Space

Standard 1D DP nested loops: for each i, scan all j < i to find max dp[j].

Wasted Work: Linearly re-scanning all previous elements instead of maintaining a sorted monotonic tails array.
The Optimal Breakthrough O(N log N) Time, O(N) Space

Patience Sorting binary search on `tails` array.

Core Invariant: Array `tails` is always strictly sorted in ascending order; `tails[k]` stores the minimum possible last element of an increasing subsequence of length `k + 1`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Classical 1D DP O(N^2) O(N) Intuitive; easy to reconstruct actual sequence; too slow for N > 10,000.
★ 2. Patience Sorting + Binary Search O(N log N) O(N) Optimal; uses binary search (bisect_left) on tails array.

Patience Sorting with Binary Search

Maintain `tails` array where `tails[k]` is the smallest ending value among all increasing subsequences of length `k + 1`. Binary search for insertion point of each number.

Time: O(N log N) Time Space: O(N) Space 
class Solution {
    fun lengthOfLIS(nums: IntArray): Int {
        val tails = IntArray(nums.size)
        var size = 0

        for (x in nums) {
            var l = 0
            var r = size
            while (l < r) {
                val mid = (l + r) ushr 1
                if (tails[mid] < x) {
                    l = mid + 1
                } else {
                    r = mid
                }
            }
            tails[l] = x
            if (l == size) size++
        }

        return size
    }
}

import bisect

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []
        for x in nums:
            # Find the leftmost index where tails[idx] >= x
            idx = bisect.bisect_left(tails, x)
            if idx == len(tails):
                tails.append(x)
            else:
                tails[idx] = x
        return len(tails)

class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int x : nums) {
            int l = 0, r = size;
            while (l < r) {
                int mid = (l + r) >>> 1;
                if (tails[mid] < x) {
                    l = mid + 1;
                } else {
                    r = mid;
                }
            }
            tails[l] = x;
            if (l == size) size++;
        }

        return size;
    }
}

Classical 1D Dynamic Programming

Let `dp[i]` be the length of LIS ending at index `i`. For each `i`, scan all `j < i` and update `dp[i] = max(dp[i], dp[j] + 1)` when `nums[j] < nums[i]`.

Time: O(N^2) Time Space: O(N) Space 
class SolutionDP {
    fun lengthOfLIS(nums: IntArray): Int {
        if (nums.isEmpty()) return 0
        val dp = IntArray(nums.size) { 1 }
        var maxLen = 1

        for (i in 1 until nums.size) {
            for (j in 0 until i) {
                if (nums[j] < nums[i]) {
                    dp[i] = maxOf(dp[i], dp[j] + 1)
                }
            }
            maxLen = maxOf(maxLen, dp[i])
        }

        return maxLen
    }
}

class SolutionDP:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
        dp = [1] * len(nums)
        for i in range(1, len(nums)):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)

class SolutionDP {
    public int lengthOfLIS(int[] nums) {
        if (nums.length == 0) return 0;
        int[] dp = new int[nums.length];
        Arrays.fill(dp, 1);
        int maxLen = 1;

        for (int i = 1; i < nums.length; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }

        return maxLen;
    }
}
