LeetCode #359: Logger Rate Limiter

Official LC #359

Official Problem Statement

Design a logger system that receives a stream of messages along with their timestamps. Each unique message should only be printed at most once every 10 seconds (i.e. a message printed at timestamp t will prevent other identical messages from being printed until timestamp t + 10).

All timestamps are in seconds granularity and arrive in non-decreasing chronological order.

Implement the Logger class:
• Logger() Initializes the logger object.
• bool shouldPrintMessage(int timestamp, string message) Returns true if the message should be printed in the given timestamp, otherwise returns false.

Example 1: ['Logger', 'shouldPrintMessage', 'shouldPrintMessage', 'shouldPrintMessage', 'shouldPrintMessage', 'shouldPrintMessage', 'shouldPrintMessage']\n[[], [1, 'foo'], [2, 'bar'], [3, 'foo'], [8, 'bar'], [10, 'foo'], [11, 'foo']] → Output: [null, true, true, false, false, false, true]

Plain-English Translation & Core Nuance

You need to prevent duplicate log messages within a 10-second rolling window. When a message arrives at time t, check if it was printed recently. If it was printed at t_prev and t - t_prev < 10, reject it. Otherwise, print it and update its last-printed timestamp to t.

Official Constraints:
  • 0 <= timestamp <= 10^9
  • Every timestamp is in non-decreasing order
  • 1 <= message.length <= 30
  • At most 10^4 calls will be made to shouldPrintMessage

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N) Time per call, O(N) Space

Store all incoming (timestamp, message) pairs in an append-only list and linearly scan backward on every call to verify the 10-second rule.

Wasted Work: Scanning past history costs O(N) comparisons per message, causing quadratic O(N^2) total execution for N incoming events.
The Optimal Breakthrough O(1) Time per call, O(U) Space (U = unique messages)

Keep a HashMap mapping message -> last_printed_timestamp. For each call, lookup in O(1) time. If absent or time diff >= 10, record new timestamp and return true.

Core Invariant: Map lookups and writes are expected O(1) amortized under standard universal hashing.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: Full History Scan O(N) O(N) Linear scan on every call; unscalable.
Optimal: HashMap Next-Allowed Timestamp O(1) O(U) ★ Production interview standard. Instant check and update.
Senior: Sliding Queue + Set O(1) amortized O(10s window) Evicts expired entries to bound memory leaks.

From Naive to Optimal & Runnable Practice Arena

Approach 1: HashMap Last Printed Timestamp

Store message to timestamp. Expected O(1) check and update.

Time: O(1) per call Space: O(U) unique messages 
class Logger() {
    private val lastPrinted = HashMap<String, Int>()

    fun shouldPrintMessage(timestamp: Int, message: String): Boolean {
        val last = lastPrinted[message]
        if (last == null || timestamp - last >= 10) {
            lastPrinted[message] = timestamp
            return true
        }
        return false
    }
}
Kotlin Runtime & Memory Nuance:

Standard HashMap with nullable lookup. Thread-safe wrapper can use ConcurrentHashMap.

class Logger:
    def __init__(self):
        self.last_printed = {}

    def shouldPrintMessage(self, timestamp: int, message: str) -> bool:
        if message not in self.last_printed or timestamp - self.last_printed[message] >= 10:
            self.last_printed[message] = timestamp
            return True
        return False
Python Runtime & Memory Nuance:

Python dict provides average O(1) lookup.

import java.util.HashMap;
import java.util.Map;

class Logger {
    private final Map<String, Integer> lastPrinted;

    public Logger() {
        this.lastPrinted = new HashMap<>();
    }

    public boolean shouldPrintMessage(int timestamp, String message) {
        Integer last = lastPrinted.get(message);
        if (last == null || timestamp - last >= 10) {
            lastPrinted.put(message, timestamp);
            return true;
        }
        return false;
    }
}

HashMap with autoboxed Integer.
