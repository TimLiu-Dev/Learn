Problem #62: Unique Paths

View on NeetCode ↗

Official Problem Statement

There is a robot on an m x n grid. The robot is initially located at the top-left corner (i.e., grid[0][0]). The robot tries to move to the bottom-right corner (i.e., grid[m - 1][n - 1]). The robot can only move either down or right at any point in time.

Given the two integers m and n, return the number of possible unique paths that the robot can take to reach the bottom-right corner.

The test cases are generated so that the answer will be less than or equal to 2 * 109.

Example 1: m = 3, n = 7 → Output: 28

Example 2: m = 3, n = 2 → Output: 3 Explanation: From the top-left corner, there are a total of 3 ways to reach the bottom-right corner: 1. Right -> Down -> Down 2. Down -> Down -> Right 3. Down -> Right -> Down

Plain-English Translation & Core Nuance

The robot can only reach cell (r, c) from the cell above (r - 1, c) or the cell to the left (r, c - 1). Therefore, paths(r, c) = paths(r - 1, c) + paths(r, c - 1). By using a rolling 1D row array of size N initialized to 1s, each cell updates with row[c] += row[c - 1], solving the problem in O(M*N) time and O(N) space.

Official Constraints:
  • 1 <= m, n <= 100

The Mental Model & "Explain Like I'm 12"

💡 Pascal's Triangle in a Manhattan Grid

Think of walking along street intersections in Manhattan. To reach the intersection of 5th Ave and 3rd St, you can only arrive from 5th Ave & 2nd St (from the West) or 4th Ave & 3rd St (from the North). The total routes to any corner is the sum of routes from those two feeding intersections. This is Pascal's Triangle tilted onto a grid.

The Mental "A-Ha!" Switch:

Notice that to compute a new row, we only need the value above it (row[c]) and the value to the left of it in the current row (row[c-1]). The update row[c] = row[c] + row[c-1] can be done in place inside a single 1D array of size N!

Pattern Trigger:

Paths on 2D grid moving only Down and Right → Grid DP: dp[r][c] = dp[r-1][c] + dp[r][c-1] or 1D rolling array.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(2^(M + N)) Time, O(M + N) Space

Brute-force recursion branching right or down at every cell.

Wasted Work: Re-exploring overlapping coordinate paths exponentially.
The Optimal Breakthrough O(M * N) Time, O(N) Space

1D Rolling Row DP. Updates row[c] += row[c-1] across M rows in O(N) space.

Core Invariant: Before processing column c in row r, row[c] holds the path count from (r-1, c) and row[c-1] holds the count from (r, c-1).

1. Brute-Force Recursion O(2^(M + N)) O(M + N) Exponential branching without memoization.
2. Full 2D DP Table O(M * N) O(M * N) Allocates full M x N table.

2. Core Traversal & Decision Rule

3. Invariant Maintenance & State Transition

I implement uniquePaths: allocate dp = IntArray(n) { 1 }. Loop r from 1 to m-1, and inner loop c from 1 to n-1, executing dp[c] += dp[c - 1]. Finally return dp[n - 1]. 4. Termination & Output Guarantee

Check for early-exit conditions (Single row m = 1, n = 5 or single column m = 5, n = 1 → Strictly 1 path.). Once traversal completes, return the accumulated result. Total unique paths = 6. Rolling 1D array collapses grid rows perfectly.

Full 2D DP Table (Standard)

Allocate an M x N table. Initialize first row and column with 1. Fill table using dp[r][c] = dp[r-1][c] + dp[r][c-1].

Time: O(M * N) Space: O(M * N) 
class Solution {
    fun uniquePaths(m: Int, n: Int): Int {
        val dp = Array(m) { IntArray(n) }
        for (r in 0 until m) dp[r][0] = 1
        for (c in 0 until n) dp[0][c] = 1

        for (r in 1 until m) {
            for (c in 1 until n) {
                dp[r][c] = dp[r - 1][c] + dp[r][c - 1]
            }
        }

        return dp[m - 1][n - 1]
    }
}

class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int r = 0; r < m; r++) dp[r][0] = 1;
        for (int c = 0; c < n; c++) dp[0][c] = 1;

        for (int r = 1; r < m; r++) {
            for (int c = 1; c < n; c++) {
                dp[r][c] = dp[r - 1][c] + dp[r][c - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
}

Combinatorics Formula (Math)

The robot must take (m - 1) down moves and (n - 1) right moves. Total unique paths is C(m+n-2, m-1).

Time: O(min(M, N)) Space: O(1) 
class Solution {
    fun uniquePaths(m: Int, n: Int): Int {
        val totalMoves = m + n - 2
        val k = minOf(m - 1, n - 1)
        var result: Long = 1

        for (i in 1..k) {
            result = result * (totalMoves - k + i) / i
        }

        return result.toInt()
    }
}
Kotlin Runtime & Memory Nuance:

Computes combination nCr in O(min(m, n)) time. Must use Long to prevent intermediate overflow.

Python 3.8+ math.comb computes exact combinations in O(min(M, N)).

class Solution {
    public int uniquePaths(int m, int n) {
        int total = m + n - 2;
        int k = Math.min(m - 1, n - 1);
        long result = 1;

        for (int i = 1; i <= k; i++) {
            result = result * (total - k + i) / i;
        }

        return (int) result;
    }
}
Java Runtime & Memory Nuance:

Fastest mathematical formulation. Requires careful ordering to avoid integer truncation.

1D Rolling Row Array (Optimal Primary)

Maintain a single 1D array of size n initialized to 1. In place update dp[c] += dp[c-1] for each row.

Time: O(M * N) Space: O(N) Auxiliary Space 
class Solution {
    /**
     * Optimal: 1D Rolling Row Dynamic Programming
     * Time: O(M * N) - Every grid cell processed once
     * Space: O(N) - Single 1D array of size N
     */
    fun uniquePaths(m: Int, n: Int): Int {
        val dp = IntArray(n) { 1 }

        for (r in 1 until m) {
            for (c in 1 until n) {
                dp[c] += dp[c - 1]
            }
        }

        return dp[n - 1]
    }
}
Kotlin Runtime & Memory Nuance:

Extremely clean state compression. Space reduced from O(M*N) to O(N).

class Solution {
    /**
     * Optimal: 1D Rolling Row DP
     * Time: O(M * N) - Computes all cells
     * Space: O(N) - 1D array bounded by column count
     */
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);

        for (int r = 1; r < m; r++) {
            for (int c = 1; c < n; c++) {
                dp[c] += dp[c - 1];
            }
        }

        return dp[n - 1];
    }
}
