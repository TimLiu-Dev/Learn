LeetCode #994: Rotting Oranges

Official LC #994

Official Problem Statement

You are given an m x n grid where each cell can have one of three values:

  • 0 representing an empty cell,
  • 1 representing a fresh orange, or
  • 2 representing a rotten orange.

Every minute, any fresh orange that is 4-directionally adjacent to a rotten orange becomes rotten.

Return the minimum number of minutes that must elapse until no cell has a fresh orange. If this is impossible, return -1.

Example 1: grid = [[2,1,1],[1,1,0],[0,1,1]] → Output: 4

Example 2: grid = [[2,1,1],[0,1,1],[1,0,1]] → Output: -1 Explanation: The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.

Example 3: grid = [[0,2]] → Output: 0 Explanation: Since there are already no fresh oranges at minute 0, the answer is just 0.

Plain-English Translation & Core Nuance

All rotten oranges spread rot simultaneously minute by minute. This is a multi-source Breadth-First Search (BFS). Initialize a queue with all starting rotten oranges and count all fresh oranges. Each minute, snapshot the queue size, pop all current rotten oranges, turn their 4-way adjacent fresh neighbors to rotten (2), push them to the queue, and decrement `freshCount`. If `freshCount == 0`, return minutes elapsed; otherwise return -1.

Official Constraints:
  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 10
  • grid[i][j] is 0, 1, or 2.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
No fresh oranges at all freshCount == 0 → Immediately returns 0 minutes.
Best-Case Early Exit
All oranges already rotten → Returns 0.

The Mental Model & "Explain Like I'm 12"

💡 Multi-Source Forest Fire Wavefront

Imagine a forest where lightning strikes multiple trees simultaneously at minute 0 (multi-source rotten oranges). Every minute, the fire spreads simultaneously from all active fire fronts to adjacent unburnt trees (`1 → 2`). The fire burns in concentric expanding rings. Once all fire fronts burn out, if any unburnt tree remains standing, the fire failed to reach it (-1). Otherwise, the time of the last wave is the total duration.

The Mental "A-Ha!" Switch:

DFS CANNOT solve this because different rotten sources spread simultaneously! BFS naturally computes the shortest time for contamination because a queue processes time steps in strict chronological waves.

Pattern Trigger:

Simultaneous multi-source spreading, minimum time to infect/reach all nodes in grid → Multi-Source Queue BFS with `size` snapshot.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O((M * N)^2) Time, O(M * N) Space

Simulation: at each minute, scan the whole grid to find all 2s, create a new grid copying rots, and repeat until no changes occur.

Wasted Work: Re-scanning every cell in the matrix on every single minute.
The Optimal Breakthrough O(M * N) Time, O(M * N) Space

Multi-Source BFS. Every cell is enqueued at most once. Time is strictly linear with respect to grid cells.

Core Invariant: At minute t, the queue contains exclusively the oranges that turned rotten exactly at minute t.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Full-Grid Minute Simulation O((M * N)^2) O(M * N) Scans entire matrix every minute; quadratic time.
2. Multi-Source BFS with Time Matrix O(M * N) O(M * N) Allocates separate `time[M][N]` array.
★ 3. Multi-Source BFS + Fresh Counter O(M * N) O(M * N) In-place grid rot mutation with instant `fresh == 0` check.

Minute-by-Minute Grid Simulation (Naive)

At each minute, iterate over the whole grid to find 2s, create a grid copy, and infect neighbors. Repeat until no new rots.

Time: O((M * N)^2) Space: O(M * N) 
class Solution {
    fun orangesRotting(grid: Array<IntArray>): Int {
        val m = grid.size
        val n = grid[0].size
        var minutes = 0
        while (true) {
            val toRot = mutableListOf<Pair<Int, Int>>()
            for (r in 0 until m) {
                for (c in 0 until n) {
                    if (grid[r][c] == 2) {
                        for (d in arrayOf(intArrayOf(0,1), intArrayOf(1,0), intArrayOf(0,-1), intArrayOf(-1,0))) {
                            val nr = r + d[0]; val nc = c + d[1]
                            if (nr in 0 until m && nc in 0 until n && grid[nr][nc] == 1) {
                                toRot.add(Pair(nr, nc))
                            }
                        }
                    }
                }
            }
            if (toRot.isEmpty()) break
            for (p in toRot) grid[p.first][p.second] = 2
            minutes++
        }
        for (r in 0 until m) for (c in 0 until n) if (grid[r][c] == 1) return -1
        return minutes
    }
}

Multi-Source BFS with Separate Time Matrix

Maintain a `dist[M][N]` array initialized to infinity. Multi-source BFS relaxes distance.

Time: O(M * N) Space: O(M * N) 
class Solution {
    fun orangesRotting(grid: Array<IntArray>): Int {
        val m = grid.size
        val n = grid[0].size
        val dist = Array(m) { IntArray(n) { -1 } }
        val queue = ArrayDeque<IntArray>()
        for (r in 0 until m) for (c in 0 until n) {
            if (grid[r][c] == 2) {
                dist[r][c] = 0
                queue.add(intArrayOf(r, c))
            }
        }
        val dirs = arrayOf(intArrayOf(0,1), intArrayOf(1,0), intArrayOf(0,-1), intArrayOf(-1,0))
        var maxTime = 0
        while (queue.isNotEmpty()) {
            val (r, c) = queue.removeFirst()
            for (d in dirs) {
                val nr = r + d[0]; val nc = c + d[1]
                if (nr in 0 until m && nc in 0 until n && grid[nr][nc] == 1 && dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[r][c] + 1
                    maxTime = maxOf(maxTime, dist[nr][nc])
                    queue.add(intArrayOf(nr, nc))
                }
            }
        }
        for (r in 0 until m) for (c in 0 until n) {
            if (grid[r][c] == 1 && dist[r][c] == -1) return -1
        }
        return maxTime
    }
}

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, -1);
        Queue<int[]> queue = new ArrayDeque<>();

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 2) {
                    dist[r][c] = 0;
                    queue.offer(new int[]{r, c});
                }
            }
        }

        int maxTime = 0;
        int[][] dirs = {{0,1}, {1,0}, {0,-1}, {-1,0}};

        while (!queue.isEmpty()) {
            int[] curr = queue.poll();
            int r = curr[0], c = curr[1];
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1 && dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[r][c] + 1;
                    maxTime = Math.max(maxTime, dist[nr][nc]);
                    queue.offer(new int[]{nr, nc});
                }
            }
        }

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1 && dist[r][c] == -1) return -1;
            }
        }
        return maxTime;
    }
}

Multi-Source BFS + Fresh Counter (Optimal Primary)

Initialize queue with all 2s and tally fresh oranges count. Snapshot queue.size per minute. Mutate 1 -> 2.

Time: O(M * N) Space: O(M * N) 
class Solution {
    /**
     * Optimal: Multi-Source Queue BFS with Fresh Orange Counter
     * Time: O(M * N) - Every cell is processed at most once
     * Space: O(M * N) - Queue size bounded by grid dimensions
     */
    fun orangesRotting(grid: Array<IntArray>): Int {
        val m = grid.size
        val n = grid[0].size
        val queue = ArrayDeque<IntArray>()
        var freshCount = 0

        // 1. Collect all initial rotten oranges and count fresh oranges
        for (r in 0 until m) {
            for (c in 0 until n) {
                if (grid[r][c] == 2) {
                    queue.add(intArrayOf(r, c))
                } else if (grid[r][c] == 1) {
                    freshCount++
                }
            }
        }

        // If no fresh oranges exist initially, 0 minutes needed
        if (freshCount == 0) return 0

        var minutes = 0
        val dirs = arrayOf(intArrayOf(0, 1), intArrayOf(1, 0), intArrayOf(0, -1), intArrayOf(-1, 0))

        // 2. Multi-source BFS spreading in concentric waves
        while (queue.isNotEmpty() && freshCount > 0) {
            val levelSize = queue.size
            minutes++

            for (i in 0 until levelSize) {
                val (r, c) = queue.removeFirst()
                for (d in dirs) {
                    val nr = r + d[0]
                    val nc = c + d[1]

                    if (nr in 0 until m && nc in 0 until n && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2 // Mark rotten immediately
                        freshCount--
                        queue.add(intArrayOf(nr, nc))
                    }
                }
            }
        }

        return if (freshCount == 0) minutes else -1
    }
}
Kotlin Runtime & Memory Nuance:

`freshCount` avoids post-scan loops. `freshCount > 0` condition prevents phantom minute increments.

class Solution:
    # Optimal: Multi-Source Queue BFS
    # Time: O(M * N) - Single pass
    # Space: O(M * N)
    def orangesRotting(self, grid: List[List[int]]) -> int:

        queue = collections.deque()
        fresh = 0

        # Step 1: Initialize multi-source queue and count fresh

            for c in range(n):
                if grid[r][c] == 2:
                    queue.append((r, c))
                elif grid[r][c] == 1:
                    fresh += 1

            return 0

                for dr, dc in dirs:

                        grid[nr][nc] = 2
                        fresh -= 1
                        queue.append((nr, nc))

        return minutes if fresh == 0 else -1

class Solution {
    /**
     * Optimal: Multi-Source Queue BFS with Fresh Orange Counter
     * Time: O(M * N) - Linear graph traversal
     * Space: O(M * N) - Queue allocation
     */
    public int orangesRotting(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        Queue<int[]> queue = new ArrayDeque<>();
        int fresh = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 2) {
                    queue.offer(new int[]{r, c});
                } else if (grid[r][c] == 1) {
                    fresh++;
                }
            }
        }

        if (fresh == 0) return 0;

        int minutes = 0;
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

        while (!queue.isEmpty() && fresh > 0) {
            int levelSize = queue.size();
            minutes++;

            for (int i = 0; i < levelSize; i++) {
                int[] curr = queue.poll();
                for (int[] d : dirs) {
                    int nr = curr[0] + d[0];
                    int nc = curr[1] + d[1];

                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2; // Infect immediately
                        fresh--;
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }

        return (fresh == 0) ? minutes : -1;
    }
}
