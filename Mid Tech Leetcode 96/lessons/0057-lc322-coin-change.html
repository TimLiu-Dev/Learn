LeetCode #322: Coin Change

Official LC #322

Official Problem Statement

You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1.

You may assume that you have an infinite number of each kind of coin.

Example 1: coins = [1,2,5], amount = 11 → Output: 3 Explanation: 11 = 5 + 5 + 1

Example 2: coins = [2], amount = 3 → Output: -1

Example 3: coins = [1], amount = 0 → Output: 0

Plain-English Translation & Core Nuance

Find the minimum number of coins to make `amount`. Maintain a 1D DP array of size `amount + 1` initialized to an impossible sentinel `amount + 1` (with `dp[0] = 0`). For each sub-amount `a` from 1 to `amount`, try every coin: `if (a >= coin) dp[a] = min(dp[a], dp[a - coin] + 1)`. If `dp[amount] > amount`, return -1; else return `dp[amount]`.

Official Constraints:
  • 1 <= coins.length <= 12
  • 1 <= coins[i] <= 2^31 - 1
  • 0 <= amount <= 10^4

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
amount = 0 → 0 coins needed; returns 0.
Best-Case Early Exit
Single coin equals amount (e.g. coin 5 for amount 5) → Returns 1.
Worst-Case Full Scan
Impossible amount (e.g. coins = [2], amount = 3) → `dp[amount]` stays sentinel `amount + 1`; returns -1.

The Mental Model & "Explain Like I'm 12"

💡 Shortest Path in an Amount Stepping-Stone Graph

Imagine stepping stones across a river labeled 0 to `amount`. Stone 0 is your starting shore. Each coin denomination is a fixed jumping distance. A coin of 5 lets you leap 5 stones forward in 1 step. You want to reach stone `amount` in the minimum number of leaps. At stone `a`, you look back at all stepping stones you could have jumped from (`a - coin`): your minimum leap count is 1 plus the best leap count among those landing pads.

The Mental "A-Ha!" Switch:

Greedy (always picking the largest coin) FAILS! For coins = [1, 3, 4] and amount = 6: greedy picks 4 + 1 + 1 (3 coins), whereas the optimal DP finds 3 + 3 (2 coins). Dynamic programming guarantees the global minimum.

Pattern Trigger:

Fewest items to make exact target, infinite supply, greedy fails → Unbounded Knapsack / 1D Bottom-Up Dynamic Programming.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(C^A) Time, O(A) Space

Brute-force recursion: at each step, try subtracting every coin. Branch factor C raised to depth A.

Wasted Work: Exponentially recalculating identical sub-amounts millions of times.
The Optimal Breakthrough O(amount * C) Time, O(amount) Space

Bottom-up 1D DP array of size `amount + 1`. Each sub-amount is computed once in O(C) operations.

Core Invariant: For every `a <= amount`, `dp[a]` stores the globally optimal minimum coin count to produce exact amount `a`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute-Force Recursion O(C^A) O(A) Exponential tree; time limit exceeded.
2. Queue BFS on Amount Graph O(amount * C) O(amount) Level-by-level BFS finds shortest path in unweighted DAG.
★ 3. Bottom-Up 1D DP Array O(amount * C) O(amount) Standard optimal algorithm. Cleanest cache performance.

Top-Down Recursion with Memoization

Recursively compute `coinChange(amount)` trying all coins, memoizing answers in a map or array.

Time: O(amount * C) Space: O(amount) 
class Solution {
    fun coinChange(coins: IntArray, amount: Int): Int {
        val memo = IntArray(amount + 1) { -2 }
        return dfs(amount, coins, memo)
    }

    private fun dfs(amt: Int, coins: IntArray, memo: IntArray): Int {
        if (amt == 0) return 0
        if (amt < 0) return -1
        if (memo[amt] != -2) return memo[amt]

        var minCoins = Int.MAX_VALUE
        for (c in coins) {
            val res = dfs(amt - c, coins, memo)
            if (res >= 0 && res < minCoins) {
                minCoins = res + 1
            }
        }

        memo[amt] = if (minCoins == Int.MAX_VALUE) -1 else minCoins
        return memo[amt]
    }
}

Breadth-First Search (Shortest Path in DAG)

Model amounts as graph nodes. Multi-level queue BFS finds the shortest path from `amount` down to `0`.

Time: O(amount * C) Space: O(amount) 
class Solution {
    fun coinChange(coins: IntArray, amount: Int): Int {
        if (amount == 0) return 0
        val queue = ArrayDeque<Int>()
        val visited = BooleanArray(amount + 1)
        queue.add(amount)
        visited[amount] = true
        var steps = 0

        while (queue.isNotEmpty()) {
            steps++
            val size = queue.size
            for (i in 0 until size) {
                val curr = queue.removeFirst()
                for (c in coins) {
                    val next = curr - c
                    if (next == 0) return steps
                    if (next > 0 && !visited[next]) {
                        visited[next] = true
                        queue.add(next)
                    }
                }
            }
        }
        return -1
    }
}

Queue BFS shortest path. First path to reach 0 is guaranteed to be minimal.

class Solution {
    public int coinChange(int[] coins, int amount) {
        if (amount == 0) return 0;
        Queue<Integer> queue = new ArrayDeque<>();
        boolean[] visited = new boolean[amount + 1];
        queue.offer(amount);
        visited[amount] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int curr = queue.poll();
                for (int c : coins) {
                    int next = curr - c;
                    if (next == 0) return steps;
                    if (next > 0 && !visited[next]) {
                        visited[next] = true;
                        queue.offer(next);
                    }
                }
            }
        }
        return -1;
    }
}

Bottom-Up 1D DP Array (Optimal Primary)

Initialize DP array of size amount + 1 with amount + 1. Set dp[0] = 0. Iterate sub-amounts and coins.

Time: O(amount * C) Space: O(amount) 
class Solution {
    /**
     * Optimal: Bottom-Up 1D Array Dynamic Programming
     * Time: O(amount * |coins|) - Inner loop processes each coin per sub-amount
     * Space: O(amount) - Primitive integer array of size amount + 1
     */
    fun coinChange(coins: IntArray, amount: Int): Int {
        val sentinel = amount + 1
        val dp = IntArray(amount + 1) { sentinel }
        dp[0] = 0

        for (a in 1..amount) {
            for (coin in coins) {
                if (a >= coin) {
                    dp[a] = minOf(dp[a], dp[a - coin] + 1)
                }
            }
        }

        return if (dp[amount] > amount) -1 else dp[amount]
    }
}
Kotlin Runtime & Memory Nuance:

Using `amount + 1` as sentinel avoids integer overflow bugs when adding `+ 1`.

class Solution {
    /**
     * Optimal: Bottom-Up 1D DP Array
     * Time: O(amount * |coins|)
     * Space: O(amount)
     */
    public int coinChange(int[] coins, int amount) {
        int sentinel = amount + 1;
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, sentinel);
        dp[0] = 0;

        for (int a = 1; a <= amount; a++) {
            for (int coin : coins) {
                if (a >= coin) {
                    dp[a] = Math.min(dp[a], dp[a - coin] + 1);
                }
            }
        }

        return (dp[amount] > amount) ? -1 : dp[amount];
    }
}
