LeetCode #5: Longest Palindromic Substring

Official LC #5

Official Problem Statement

Given a string s, return the longest palindromic substring in s.

A substring is a contiguous sequence of characters within a string.

Example 1: s = 'babad' → Output: 'bab' (or 'aba')

Example 2: s = 'cbbd' → Output: 'bb'

Plain-English Translation & Core Nuance

Find the longest sequence of characters within a string that reads the same forwards and backwards. Instead of testing all O(N^2) substrings by reversing them in O(N^3), notice that every palindrome expands outwards from a center. There are only 2N - 1 possible centers (odd-length single letters and even-length gaps between letters). Expanding outwards from each center takes O(N^2) total time and O(1) space.

Official Constraints:
  • 1 <= s.length <= 1000
  • s consist of only digits and English letters

Canonical Input Shapes (Mental Boundary Checks)

Best-Case Early Exit
Two identical characters 'aa': returns 'aa'.

String of all identical characters (e.g. 1000 'a's): every expansion goes to boundaries.

The Mental Model & "Explain Like I'm 12"

💡 The Ripples in a Pond (Expanding from Centers)

Imagine throwing a stone into a still pond: ripples expand outward symmetrically from the impact point. A palindrome works identically: it has an epicenter (either a single character like 'r-a-c-e-c-a-r' or a mirrored pair like 'n-o-o-n') and expands symmetrically to the left and right as long as both characters match.

The Mental "A-Ha!" Switch:

Expand Around Center: There are only 2N - 1 centers! Expand odd centers (i, i) and even centers (i, i+1). Zero DP table allocation, strictly O(1) space!

Pattern Trigger:

Longest contiguous palindromic sequence in a string.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^3) Time, O(1) Space

Check every possible substring (i, j) and verify if it is a palindrome by reading it backwards.

Wasted Work: Examines O(N^2) substrings and spends O(N) checking each, re-verifying identical inner palindromes repeatedly.
The Optimal Breakthrough O(N^2) Time, O(1) Space

Expand around 2N - 1 centers. For each center, expand pointers left and right while s[left] == s[right]. Track the maximum start index and length.

Core Invariant: A palindrome of length L can only exist if its inner core of length L - 2 is also a palindrome.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive Substring Verification O(N^3) O(1) Cubic time; completely unscalable.
2D Dynamic Programming Table O(N^2) O(N^2) dp[i][j] table; quadratic heap memory is wasteful.
Expand Around Center O(N^2) O(1) ★ Production standard. Cache friendly, zero heap allocations.

Approach 1: Expand Around Center

Check 2N - 1 centers expanding outwards symmetrically.

Time: O(N^2) Space: O(1) memory 
class Solution {
    fun longestPalindrome(s: String): String {
        if (s.length <= 1) return s
        var start = 0
        var maxLen = 0

        fun expand(l: Int, r: Int) {
            var left = l
            var right = r
            while (left >= 0 && right < s.length && s[left] == s[right]) {
                left--
                right++
            }
            val len = right - left - 1
            if (len > maxLen) {
                maxLen = len
                start = left + 1
            }
        }

        for (i in s.indices) {
            expand(i, i)     // Odd length
            expand(i, i + 1) // Even length
        }

        return s.substring(start, start + maxLen)
    }
}
Kotlin Runtime & Memory Nuance:

Zero memory allocation. Pure index pointers with single substring slice at end.

class Solution:
    def longestPalindrome(self, s: str) -> str:
        if len(s) <= 1:
            return s

        start = 0
        max_len = 0

        def expand(left: int, right: int):
            nonlocal start, max_len
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            length = right - left - 1
            if length > max_len:
                max_len = length
                start = left + 1

        for i in range(len(s)):
            expand(i, i)       # Odd length
            expand(i, i + 1)   # Even length

        return s[start:start + max_len]

class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() <= 1) return s;

        int start = 0, maxLen = 0;

        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);     // Odd length
            int len2 = expand(s, i, i + 1); // Even length
            int len = Math.max(len1, len2);

            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }

        return s.substring(start, start + maxLen);
    }

    private int expand(String s, int left, int right) {
        while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
Java Runtime & Memory Nuance:

String.charAt avoids creating intermediate strings.
