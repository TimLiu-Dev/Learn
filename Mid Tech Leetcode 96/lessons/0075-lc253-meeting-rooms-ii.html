Problem #253: Meeting Rooms II

View on NeetCode ↗

Official Problem Statement

Given an array of meeting time intervals intervals where intervals[i] = [start_i, end_i], return the minimum number of conference rooms required.

Example 1: intervals = [[0,30],[5,10],[15,20]] → Output: 2 Explanation: Room 1: [0,30] Room 2: [5,10], [15,20]

Example 2: intervals = [[7,10],[2,4]] → Output: 1

Plain-English Translation & Core Nuance

Sort all meetings by their start time. Maintain a Min-Heap of meeting end times representing the rooms currently in use. For each meeting, check the earliest ending room (`heap.peek()`). If the new meeting starts after or at the moment that meeting ends (`start >= heap.peek()`), that room is now free, so we reuse it by popping the old end time. Then we push the new meeting's end time. The maximum size of the heap (or the final heap size) is the minimum conference rooms required.

Official Constraints:
  • 1 <= intervals.length <= 10^4
  • 0 <= start_i < end_i <= 10^6

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single meeting intervals = [[1, 5]] → Returns 1.
Best-Case Early Exit
All meetings strictly disjoint [[1, 2], [3, 4], [5, 6]] → Reuses same room; returns 1.
Worst-Case Full Scan
All meetings completely overlapping [[1, 10], [2, 10], [3, 10]] → Requires N rooms.

The Mental Model & "Explain Like I'm 12"

💡 The Airport Gate Assignment Desk

Imagine assigning airport gates to incoming flights. You sort all flights by their arrival time. You keep a scoreboard of the departure times for all occupied gates. When a new flight lands, you look at the earliest departing plane on your scoreboard. If that plane has already left, you clear that gate and assign the incoming flight to it. If not, all gates are occupied, so airport operations must open a brand new gate.

The Mental "A-Ha!" Switch:

We only need to track the EARLIEST finishing meeting room! If the meeting that finishes earliest isn't free yet, NO room is free, forcing us to allocate a new room. A Min-Heap gives instant O(1) access to the earliest finishing room.

Pattern Trigger:

Count maximum concurrent overlapping intervals / minimum resources required → Sort by start time + Min-Heap of end times (or Chronological Two-Pointer Event Scan).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N) Space

For each meeting, compare with all other meetings to count how many overlap with its start time.

Wasted Work: Re-scanning every interval pair pairwise (10^8 checks for N=10,000).
The Optimal Breakthrough O(N log N) Time, O(N) Space

Sort intervals in O(N log N). Each meeting pushed and popped from Min-Heap at most once in O(log N).

Core Invariant: At any instant after processing a meeting, `minHeap.size()` equals the exact number of conference rooms currently active.

Approach 1: Two Pointers / Chronological Sweep-Line

Extract all start times and end times into separate arrays. Sort both. Use two pointers to track active meetings without a heap.

Time: O(N log N) Time Space: O(N) Space 
class Solution {
    fun minMeetingRooms(intervals: Array<IntArray>): Int {
        val n = intervals.size
        val starts = IntArray(n) { intervals[it][0] }.sorted()
        val ends = IntArray(n) { intervals[it][1] }.sorted()

        var rooms = 0
        var endPtr = 0

        for (i in 0 until n) {
            if (starts[i] < ends[endPtr]) {
                rooms++ // Need a new room
            } else {
                endPtr++ // Room freed up, reuse it
            }
        }
        return rooms
    }
}

import java.util.Arrays;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        int n = intervals.length;
        int[] starts = new int[n];
        int[] ends = new int[n];

        for (int i = 0; i < n; i++) {
            starts[i] = intervals[i][0];
            ends[i] = intervals[i][1];
        }

        Arrays.sort(starts);
        Arrays.sort(ends);

        int rooms = 0;
        int endPtr = 0;

        for (int i = 0; i < n; i++) {
            if (starts[i] < ends[endPtr]) {
                rooms++;
            } else {
                endPtr++;
            }
        }
        return rooms;
    }
}

★ Approach 2: Sort + Min-Heap of End Times (Production Optimal)

Sort meetings by start time. Maintain a PriorityQueue of active room end times. If meeting starts >= heap.peek(), poll old end time. Offer new end time.

Time: O(N log N) Time Space: O(N) Space 
import java.util.PriorityQueue

class Solution {
    fun minMeetingRooms(intervals: Array<IntArray>): Int {
        if (intervals.isEmpty()) return 0
        intervals.sortBy { it[0] }

        val minHeap = PriorityQueue<Int>() // stores room end times

        for (m in intervals) {
            if (minHeap.isNotEmpty() && m[0] >= minHeap.peek()) {
                minHeap.poll() // reuse room
            }
            minHeap.offer(m[1])
        }
        return minHeap.size
    }
}
Kotlin Runtime & Memory Nuance:

In ★ Approach 2: Sort + Min-Heap of End Times (Production Optimal), Kotlin uses unboxed JVM primitive arrays (IntArray / BooleanArray) to eliminate object header overhead and keep traversal L1-cache friendly; and maintains heap invariant in O(log K) per operation via java.util.PriorityQueue.

import heapq

class Solution:
    def minMeetingRooms(self, intervals: list[list[int]]) -> int:
        if not intervals:
            return 0

        intervals.sort(key=lambda x: x[0])
        min_heap = []  # stores end times

        for start, end in intervals:
            if min_heap and start >= min_heap[0]:
                heapq.heappop(min_heap)
            heapq.heappush(min_heap, end)

        return len(min_heap)

In ★ Approach 2: Sort + Min-Heap of End Times (Production Optimal), Python uses C-backed heapq binary heap operations on flat lists for low-overhead O(log N) priority updates.

import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        if (intervals == null || intervals.length == 0) return 0;

        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        PriorityQueue<Integer> minHeap = new PriorityQueue<>();

        for (int[] m : intervals) {
            if (!minHeap.isEmpty() && m[0] >= minHeap.peek()) {
                minHeap.poll(); // reuse room
            }
            minHeap.offer(m[1]);
        }
        return minHeap.size();
    }
}

""To find the minimum number of rooms, we must find the maximum number of concurrent overlapping meetings. We first sort the meetings by start time so we process them in chronological order.
