LeetCode #560: Subarray Sum Equals K

Official LC #560

Official Problem Statement

Given an array of integers nums and an integer k, return the total number of subarrays whose sum equals to k.

A subarray is a contiguous non-empty sequence of elements within an array.

Example 1: nums = [1,1,1], k = 2 → Output: 2

Example 2: nums = [1,2,3], k = 3 → Output: 2

Plain-English Translation & Core Nuance

Maintain a running prefix sum and a frequency map storing how many times each prefix sum has occurred. At any index, the sum of a subarray between some earlier index j and current index i is `currSum - prefixSum[j]`. If `currSum - prefixSum[j] == k`, then `prefixSum[j] == currSum - k`. We add `map.getOrDefault(currSum - k, 0)` to our answer on every step in O(1) time.

Official Constraints:
  • 1 <= nums.length <= 2 * 10^4
  • -1000 <= nums[i] <= 1000
  • -10^7 <= k <= 10^7

The Mental Model & "Explain Like I'm 12"

💡 The Elevation Difference Altimeter

Imagine hiking along a mountain trail with an altimeter. You want to know how many trail sections had an elevation gain of exactly k meters. You log every elevation you have ever crossed into a notebook. At your current altitude `currSum`, you look back in your notebook: have you ever stood at altitude `currSum - k`? Every time you did, the hike from that point to where you are now gained exactly k meters.

The Mental "A-Ha!" Switch:

Sliding window FAILS when numbers can be negative (because shrinking the window does not monotonically decrease the sum). Prefix Sum + HashMap is the only O(N) strategy that handles negative and zero values unconditionally.

Pattern Trigger:

Contiguous subarray sum equals target with negative numbers allowed → Running Prefix Sum with HashMap count lookup.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(1) Space

Test all O(N^2) subarrays with nested loops: outer loop fixes start i, inner loop sums from i to j.

Wasted Work: Recomputing sum combinations independently instead of looking up mathematical complements in O(1).
The Optimal Breakthrough O(N) Time, O(N) Auxiliary Space

Single linear pass. Keep running sum and store frequencies of past prefix sums in a HashMap.

Core Invariant: At index i, `count` increases by `prefixCounts[currSum - k]`, representing the exact number of contiguous subarrays ending at i that sum to k.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute Force (All Subarrays) O(N^3) O(1) Computes sum from scratch for each subarray.
2. Running Sum Inner Loop O(N^2) O(1) Times out on N = 20,000 (4 \times 10^8 ops).
★ 3. Prefix Sum + Frequency HashMap O(N) O(N) Single linear pass; immune to negative numbers.

Approach 1: Nested Loops Running Sum (O(N^2))

For each start index i, run inner loop j from i to n-1 accumulating sum. Increment count whenever sum == k.

Time: O(N^2) Time Space: O(1) Space 
class Solution {
    fun subarraySum(nums: IntArray, k: Int): Int {
        var count = 0
        val n = nums.size
        for (i in 0 until n) {
            var sum = 0
            for (j in i until n) {
                sum += nums[j]
                if (sum == k) count++
            }
        }
        return count
    }
}

Approach 2: Full Prefix Array + Nested Search (O(N^2) Time, O(N) Space)

Precompute prefix sum array where prefix[i] = sum(nums[0..i-1]). Check all pairs (i, j) where prefix[j] - prefix[i] == k.

Time: O(N^2) Time Space: O(N) Space 
class Solution {
    fun subarraySum(nums: IntArray, k: Int): Int {
        val n = nums.size
        val prefix = IntArray(n + 1)
        for (i in 0 until n) {
            prefix[i + 1] = prefix[i] + nums[i]
        }
        var count = 0
        for (i in 0 until n) {
            for (j in i + 1..n) {
                if (prefix[j] - prefix[i] == k) count++
            }
        }
        return count
    }
}

★ Approach 3: Prefix Sum + Frequency HashMap (Production Optimal)

Keep running prefix sum. Query map for currSum - k occurrences in O(1) time. Increment current sum frequency in map.

Time: O(N) Time Space: O(N) Space 
class Solution {
    fun subarraySum(nums: IntArray, k: Int): Int {
        val map = HashMap<Int, Int>()
        map[0] = 1 // Base case: prefix sum of 0 has occurred once
        var currSum = 0
        var count = 0

        for (num in nums) {
            currSum += num
            count += map.getOrDefault(currSum - k, 0)
            map[currSum] = map.getOrDefault(currSum, 0) + 1
        }
        return count
    }
}

from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        prefix_counts = defaultdict(int)
        prefix_counts[0] = 1  # Base case
        curr_sum = 0
        count = 0

        for num in nums:
            curr_sum += num
            count += prefix_counts[curr_sum - k]
            prefix_counts[curr_sum] += 1

        return count

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1); // Base case: prefix sum of 0 occurred once
        int currSum = 0;
        int count = 0;

        for (int num : nums) {
            currSum += num;
            count += map.getOrDefault(currSum - k, 0);
            map.put(currSum, map.getOrDefault(currSum, 0) + 1);
        }
        return count;
    }
}

          Phase 2: Space-Time Strategy Pitch
          
""The optimal approach uses a Prefix Sum combined with a Hash Map. For any contiguous subarray from index j to index i, the sum is `prefixSum[i] - prefixSum[j-1]`. If this sum equals k, then `prefixSum[j-1] = prefixSum[i] - k`. As we traverse the array, we maintain a running sum `currSum` and ask the map: how many times have we seen a prefix sum equal to `currSum - k`? We add that count to our total, and then record `currSum` into the map. We initialize `map[0] = 1` to handle the case where a prefix from the very start of the array equals k directly.""
