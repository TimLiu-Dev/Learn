LeetCode #347: Top K Frequent Elements

Official LC #347

Official Problem Statement

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.

Example 1: nums = [1,1,1,2,2,3], k = 2 → Output: [1,2]

Example 2: nums = [1], k = 1 → Output: [1]

Plain-English Translation & Core Nuance

Count occurrences of each number in a hash map. Then use Bucket Sort where the array index directly represents frequency (0 to N). Traverse the buckets backward from highest frequency N down to 1, collecting numbers until k elements are gathered in strictly linear O(N) time.

Official Constraints:
  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4
  • k is in the range [1, the number of unique elements in the array].
  • It is guaranteed that the answer is unique.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
nums = [1], k = 1 → Single element returns [1] directly.
Best-Case Early Exit
k == unique elements count → Returns all unique elements.
Worst-Case Full Scan
All elements have frequency 1 (e.g. `[1,2,3,4], k=2`) → Problem guarantees answer is unique.

The Mental Model & "Explain Like I'm 12"

💡 Pigeonhole Ballot Counting Shelves

Suppose you have N ballots. You count the votes for each candidate. You set up N + 1 pigeonhole shelves numbered 0 to N, representing the number of votes received. A candidate with 3 votes goes onto Shelf #3; a candidate with 10 votes goes onto Shelf #10. To find the top K candidates, you simply walk from Shelf #N down to Shelf #0, collecting candidates until you have K winners. No sorting required!

The Mental "A-Ha!" Switch:

An element's frequency can NEVER exceed N (the array length). Because the frequency range is bounded between 0 and N, Bucket Sort solves Top K in strict O(N) linear time without any heap or comparison sorting!

Pattern Trigger:

Top K frequent / count-based rankings with bounded frequencies → Bucket Sort (index = frequency) or Min-Heap of size K.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(U log U) Time, O(U) Space

Build frequency map of unique elements U, convert to list of pairs, and sort by frequency descending.

Wasted Work: Sorting all U unique elements when we only need the top k.
The Optimal Breakthrough O(N) Time, O(N) Space

Bucket Sort: create array of lists of size N + 1 where `buckets[freq]` contains numbers with that count. Traverse backward from N to 0.

Core Invariant: Bucket index `f` strictly represents the exact count of occurrences in the input array.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Frequency Map + Full Sort O(U log U) O(U) Sorts all unique keys; U up to N.
2. Frequency Map + Min-Heap of Size K O(N log K) O(N + K) Standard heap approach; ideal for streaming data.
★ 3. Frequency Map + Bucket Sort O(N) O(N) Strict linear O(N) time using bounded count pigeonholes.

Frequency Map + Full Sort (Naive)

Count frequencies in a Map, convert to a list of entries, and sort descending by value.

Time: O(U log U) Space: O(U) 
class Solution {
    fun topKFrequent(nums: IntArray, k: Int): IntArray {
        val countMap = HashMap<Int, Int>()
        for (num in nums) countMap[num] = countMap.getOrDefault(num, 0) + 1

        return countMap.entries
            .sortedByDescending { it.value }
            .take(k)
            .map { it.key }
            .toIntArray()
    }
}

Idiomatic Kotlin collections sort. Sorts all U unique keys.

Sorts all keys. Runs in O(U log U) time.

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> countMap = new HashMap<>();
        for (int num : nums) countMap.put(num, countMap.getOrDefault(num, 0) + 1);

        List<Integer> keys = new ArrayList<>(countMap.keySet());
        keys.sort((a, b) -> countMap.get(b).compareTo(countMap.get(a)));

        int[] result = new int[k];
        for (int i = 0; i < k; i++) result[i] = keys.get(i);
        return result;
    }
}

O(U log U) comparison sort on all distinct elements.

Frequency Map + Min-Heap of Size K (Streaming)

Maintain a Min-Heap of size k comparing map frequencies. Eject lowest frequency when heap size > k.

Time: O(N log K) Space: O(N + K) 
class Solution {
    fun topKFrequent(nums: IntArray, k: Int): IntArray {
        val countMap = HashMap<Int, Int>()
        for (num in nums) countMap[num] = countMap.getOrDefault(num, 0) + 1

        val minHeap = java.util.PriorityQueue<Int> { a, b ->
            countMap[a]!!.compareTo(countMap[b]!!)
        }

        for (num in countMap.keys) {
            minHeap.offer(num)
            if (minHeap.size > k) minHeap.poll()
        }

        val result = IntArray(k)
        for (i in 0 until k) result[i] = minHeap.poll()
        return result
    }
}
Kotlin Runtime & Memory Nuance:

Standard heap approach. Excellent for streaming data feeds.

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_map = collections.Counter(nums)
        min_heap = []
        
        for num, freq in count_map.items():
            heapq.heappush(min_heap, (freq, num))
            if len(min_heap) > k:
                heapq.heappop(min_heap)
                
        return [num for (freq, num) in min_heap]

Bounded heap size k ensures memory is kept low.

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> countMap = new HashMap<>();
        for (int num : nums) countMap.put(num, countMap.getOrDefault(num, 0) + 1);

        PriorityQueue<Integer> minHeap = new PriorityQueue<>(
            Comparator.comparingInt(countMap::get)
        );

        for (int num : countMap.keySet()) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = minHeap.poll();
        }
        return result;
    }
}

Frequency Map + Bucket Sort (Optimal Primary)

Tally frequencies in a HashMap, place numbers into an array of buckets where index = frequency, scan downward.

Time: O(N) Space: O(N) 
class Solution {
    /**
     * Optimal: Bucket Sort by Frequency
     * Time: O(N) - Strictly linear time bypassing comparison sorting
     * Space: O(N) - Bounded array of size N + 1
     */
    fun topKFrequent(nums: IntArray, k: Int): IntArray {
        val countMap = HashMap<Int, Int>()
        for (num in nums) {
            countMap[num] = countMap.getOrDefault(num, 0) + 1
        }

        // Buckets where index represents frequency (0 to nums.size)
        val buckets = Array(nums.size + 1) { mutableListOf<Int>() }
        for ((num, count) in countMap) {
            buckets[count].add(num)
        }

        val result = IntArray(k)
        var idx = 0
        for (freq in buckets.indices.reversed()) {
            for (num in buckets[freq]) {
                result[idx++] = num
                if (idx == k) return result
            }
        }
        return result
    }
}
Kotlin Runtime & Memory Nuance:

Bypasses comparison sort entirely. Guarantees linear O(N) performance on all inputs.

class Solution:
    # Optimal: Bucket Sort by Frequency
    # Time: O(N) - Linear time
    # Space: O(N)
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_map = collections.Counter(nums)
        n = len(nums)
        buckets = [[] for _ in range(n + 1)]
        
        for num, count in count_map.items():
            buckets[count].append(num)
            
        result = []
        for freq in range(n, 0, -1):
            for num in buckets[freq]:
                result.append(num)
                if len(result) == k:
                    return result
                    
        return result

class Solution {
    /**
     * Optimal: Bucket Sort by Frequency
     * Time: O(N) - Linear execution
     * Space: O(N) - Array of frequency buckets
     */
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> countMap = new HashMap<>();
        for (int num : nums) {
            countMap.put(num, countMap.getOrDefault(num, 0) + 1);
        }

        List<Integer>[] buckets = new List[nums.length + 1];
        for (int i = 0; i <= nums.length; i++) {
            buckets[i] = new ArrayList<>();
        }

        for (Map.Entry<Integer, Integer> entry : countMap.entrySet()) {
            int num = entry.getKey();
            int count = entry.getValue();
            buckets[count].add(num);
        }

        int[] result = new int[k];
        int idx = 0;
        for (int freq = nums.length; freq >= 0 && idx < k; freq--) {
            for (int num : buckets[freq]) {
                result[idx++] = num;
                if (idx == k) return result;
            }
        }
        return result;
    }
}
Java Runtime & Memory Nuance:

Unchecked generic array cast is safe here because array elements are strictly `List`.
