Problem #684: Redundant Connection

View on NeetCode ↗

Official Problem Statement

In this problem, a tree is an undirected graph that is connected and has no cycles.

You are given a graph that started as a tree with n nodes labeled from 1 to n, with one additional edge added. The added edge has two different vertices chosen from 1 to n, and was not an edge that already existed. The graph is represented as an array edges of length n where edges[i] = [ui, vi] indicates that there is an edge between nodes ui and vi in the graph.

Return an edge that can be removed so that the resulting graph is a tree of n nodes. If there are multiple answers, return the answer that occurs last in the input.

Example 1: edges = [[1,2],[1,3],[2,3]] → Output: [2,3]

Example 2: edges = [[1,2],[2,3],[3,4],[1,4],[1,5]] → Output: [1,4]

Plain-English Translation & Core Nuance

A tree with n vertices has exactly n - 1 edges and no cycles. We are given n edges, meaning exactly ONE extra edge was added that creates a cycle. We process edges in their given order using a Disjoint Set Union (DSU / Union-Find) structure. For each edge [u, v], we find the representative roots of u and v. If find(u) == find(v), nodes u and v are already connected through another path—so adding this edge closes a cycle! Since we iterate in order and want the last edge that creates a cycle, this exact edge is our answer.

Official Constraints:
  • n == edges.length
  • 3 <= n <= 1000
  • edges[i].length == 2
  • 1 <= ui < vi <= edges.length
  • ui != vi
  • There are no repeated edges.
  • The given graph is connected.

Disjoint Set Union (DSU with Path Compression)

Maintain a parent array of size N + 1. For each edge [u, v], find their root representatives. If find(u) == find(v), this edge forms a cycle and is the redundant connection. Otherwise union them.

Time: O(N * α(N)) Time Space: O(N) Space 
class Solution {
    fun findRedundantConnection(edges: Array<IntArray>): IntArray {
        val parent = IntArray(edges.size + 1) { it }

        fun find(i: Int): Int {
            if (parent[i] != i) {
                parent[i] = find(parent[i]) // Path compression
            }
            return parent[i]
        }

        fun union(i: Int, j: Int): Boolean {
            val rootI = find(i)
            val rootJ = find(j)
            if (rootI == rootJ) return false // Already in same component -> cycle!
            parent[rootI] = rootJ
            return true
        }

        for (edge in edges) {
            if (!union(edge[0], edge[1])) {
                return edge
            }
        }
        return IntArray(0)
    }
}
Kotlin Runtime & Memory Nuance:

In Disjoint Set Union (DSU with Path Compression), Kotlin uses unboxed JVM primitive arrays (IntArray / BooleanArray) to eliminate object header overhead and keep traversal L1-cache friendly; and uses a nested local function or helper method to share outer scope cleanly without passing redundant state parameters.

class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        parent = list(range(len(edges) + 1))
        
        def find(i: int) -> int:
            if parent[i] != i:
                parent[i] = find(parent[i]) # Path compression
            return parent[i]
        
        def union(i: int, j: int) -> bool:
            root_i = find(i)
            root_j = find(j)
            if root_i == root_j:
                return False
            parent[root_i] = root_j
            return True
            
        for u, v in edges:
            if not union(u, v):
                return [u, v]
                
        return []

In Disjoint Set Union (DSU with Path Compression), Python iterates with lazy C-iterators (range / enumerate) to avoid allocating intermediate index lists.

class Solution {
    public int[] findRedundantConnection(int[][] edges) {
        int[] parent = new int[edges.length + 1];
        for (int i = 0; i <= edges.length; i++) parent[i] = i;

        for (int[] edge : edges) {
            int rootU = find(parent, edge[0]);
            int rootV = find(parent, edge[1]);

            if (rootU == rootV) {
                return edge; // Cycle detected
            }
            parent[rootU] = rootV;
        }
        return new int[0];
    }

    private int find(int[] parent, int i) {
        if (parent[i] != i) {
            parent[i] = find(parent, parent[i]); // Path compression
        }
        return parent[i];
    }
}
