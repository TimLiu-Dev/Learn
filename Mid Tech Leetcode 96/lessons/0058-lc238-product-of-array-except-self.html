LeetCode #238: Product of Array Except Self

Official LC #238

Official Problem Statement

Given an integer array nums, return an array answer such that answer[i] is equal to the product of all the elements of nums except nums[i].

The product of any prefix or suffix of nums is guaranteed to fit in a 32-bit integer.

You must write an algorithm that runs in O(n) time and without using the division operation.

Example 1: nums = [1,2,3,4] → Output: [24,12,8,6]

Example 2: nums = [-1,1,0,-3,3] → Output: [0,0,9,0,0]

Plain-English Translation & Core Nuance

For every position i, the result is the product of everything strictly to its left multiplied by the product of everything strictly to its right. We compute prefix products directly into the output array in pass 1, then sweep backwards maintaining a running suffix product in pass 2, achieving O(N) time with O(1) extra space.

Official Constraints:
  • 2 <= nums.length <= 10^5
  • -30 <= nums[i] <= 30
  • The product of any prefix or suffix of nums is guaranteed to fit in a 32-bit integer.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Two elements nums = [3, 4] → Returns `[4, 3]` immediately.
Best-Case Early Exit
Single zero nums = [-1, 1, 0, -3, 3] → Only index of 0 gets non-zero product; all others become 0.
Worst-Case Full Scan
Multiple zeros nums = [0, 4, 0] → Every element evaluates to 0.

The Mental Model & "Explain Like I'm 12"

💡 The Two-Sided Grandstand View

Imagine standing in a stadium row. You want to know the combined weight of everyone except yourself. You ask the person to your left for the product of everyone from the left edge up to them, and the person to your right for the product from the right edge up to them. You multiply those two numbers together. By sweeping left-to-right first and right-to-left second, everyone gets their answer without any division.

The Mental "A-Ha!" Switch:

Any element `nums[i]` splits the array into two disjoint halves: prefix `nums[0..i-1]` and suffix `nums[i+1..n-1]`. Instead of allocating two O(N) arrays for prefix and suffix, we store prefix products directly into the return array `res`, and fold the suffix product into `res[i]` on-the-fly using a single scalar variable `postfix`.

Pattern Trigger:

Calculate total aggregate excluding current index without division → Prefix product sweep followed by running suffix accumulator.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(1) Space

Nested loops: for each index i, iterate through all other indices j != i and multiply nums[j].

Wasted Work: Re-multiplying overlapping chains of numbers over and over (O(N^2) scalar multiplications).
The Optimal Breakthrough O(N) Time, O(1) Auxiliary Space

Two linear passes: Left-to-right pass writes prefix products into output array; right-to-left pass accumulates running suffix scalar into output.

Core Invariant: After prefix pass, `res[i] = prod(nums[0..i-1])`. During suffix pass at index i, `res[i] = res[i] * postfix`, where `postfix = prod(nums[i+1..n-1])`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute Force (Nested Loops) O(N^2) O(1) Times out on N = 10^5 (10^{10} ops).
2. Prefix & Suffix Arrays O(N) O(N) Allocates two auxiliary arrays (2N integers).
★ 3. In-Place Output Accumulator O(N) O(1) Auxiliary Optimal cache locality; output array does not count as extra space per problem spec.

Approach 1: Brute Force (O(N^2))

Iterate through every index i, and for every i, run an inner loop over all j != i multiplying nums[j].

Time: O(N^2) Time Space: O(1) Space 
class Solution {
    fun productExceptSelf(nums: IntArray): IntArray {
        val n = nums.size
        val res = IntArray(n)
        for (i in 0 until n) {
            var prod = 1
            for (j in 0 until n) {
                if (i != j) {
                    prod *= nums[j]
                }
            }
            res[i] = prod
        }
        return res
    }
}

Approach 2: Separate Prefix & Suffix Arrays (O(N) Space)

Allocate prefix[N] and suffix[N] arrays. Precompute all prefix and suffix products in linear time, then set res[i] = prefix[i-1] * suffix[i+1].

Time: O(N) Time Space: O(N) Space 
class Solution {
    fun productExceptSelf(nums: IntArray): IntArray {
        val n = nums.size
        val prefix = IntArray(n)
        val suffix = IntArray(n)
        val res = IntArray(n)

        prefix[0] = nums[0]
        for (i in 1 until n) {
            prefix[i] = prefix[i - 1] * nums[i]
        }

        suffix[n - 1] = nums[n - 1]
        for (i in n - 2 downTo 0) {
            suffix[i] = suffix[i + 1] * nums[i]
        }

        for (i in 0 until n) {
            val left = if (i > 0) prefix[i - 1] else 1
            val right = if (i < n - 1) suffix[i + 1] else 1
            res[i] = left * right
        }
        return res
    }
}

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] prefix = new int[n];
        int[] suffix = new int[n];
        int[] res = new int[n];

        prefix[0] = nums[0];
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i];
        }

        suffix[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i];
        }

        for (int i = 0; i < n; i++) {
            int left = (i > 0) ? prefix[i - 1] : 1;
            int right = (i < n - 1) ? suffix[i + 1] : 1;
            res[i] = left * right;
        }
        return res;
    }
}

★ Approach 3: Two-Pass Output Array Accumulation (Production Optimal)

Store prefix products directly in res. Sweep backwards folding in a rolling suffix product scalar. Achieves strict O(1) auxiliary space.

Time: O(N) Time Space: O(1) Auxiliary Space 
class Solution {
    fun productExceptSelf(nums: IntArray): IntArray {
        val n = nums.size
        val res = IntArray(n) { 1 }

        // Pass 1: Build prefix products directly into res
        var prefix = 1
        for (i in 0 until n) {
            res[i] = prefix
            prefix *= nums[i]
        }

        // Pass 2: Multiply by running suffix product backwards
        var postfix = 1
        for (i in n - 1 downTo 0) {
            res[i] *= postfix
            postfix *= nums[i]
        }

        return res
    }
}

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];

        // Pass 1: Prefix accumulation
        int prefix = 1;
        for (int i = 0; i < n; i++) {
            res[i] = prefix;
            prefix *= nums[i];
        }

        // Pass 2: Suffix accumulation
        int postfix = 1;
        for (int i = n - 1; i >= 0; i--) {
            res[i] *= postfix;
            postfix *= nums[i];
        }

        return res;
    }
}
