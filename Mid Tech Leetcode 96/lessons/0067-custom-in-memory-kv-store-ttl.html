Official LC #Custom

Official Problem Statement

Design a production-grade, in-memory Key-Value store with Time-to-Live (TTL) expiration, prefix search, and multi-tier transaction rollback capabilities.

Implement the InMemoryKVStore class supporting:

  • set(key: String, value: String): Stores key-value pair indefinitely.
  • setWithTTL(key: String, value: String, ttlMs: Long): Stores key-value with TTL expiration in milliseconds from current clock time.
  • get(key: String): String?: Returns value if present and not expired; returns null otherwise.
  • delete(key: String): Boolean: Removes key, returns true if key was present.
  • scan(prefix: String): List>: Returns all non-expired key-value pairs whose keys start with prefix in lexicographical order.
  • beginTransaction(): Starts a nested transaction block.
  • commit(): Boolean: Commits current transaction changes permanently. Returns false if no transaction active.
  • rollback(): Boolean: Reverts all mutations made within the current transaction block. Returns false if no transaction active.

Example 1 (TTL Expiration): setWithTTL("user:1", "Alice", 1000) get("user:1") -> "Alice" (Wait 1500ms) get("user:1") -> null → Output: "Alice", then null

Example 2 (Transactions & Rollback): set("balance", "100") beginTransaction() set("balance", "200") get("balance") -> "200" rollback() get("balance") -> "100" → Output: "200", then "100" after rollback

Plain-English Translation & Core Nuance

We implement a Redis-style in-memory KV engine across 4 enterprise tiers: 1) Core CRUD with ConcurrentHashMap and an Entry wrapper storing expiration timestamps; 2) Passive expiration on `get()` and active sweep; 3) Prefix search using a concurrent TreeMap or Trie; 4) Nested transactions using a stack of delta undo-logs (recording the previous value before each write so rollback restores exact prior state).

Official Constraints:
  • Keys and values are non-empty strings up to 1024 characters.
  • TTL values are positive integers up to 10^9 ms.
  • Transactions can be nested up to 50 levels deep.
  • Operations must be thread-safe for high concurrency.

The Mental Model & "Explain Like I'm 12"

💡 The Restaurant Kitchen Order Ticket Stack

Think of an in-memory KV store as an executive kitchen pantry. Each shelf has labeled boxes with freshness expiration tags. When you pull an ingredient, you check the tag—if expired, you throw it away (passive TTL). When a chef says 'Let's try a special dish' (begin transaction), you place an overlay sheet of tracing paper on the clipboard. Every modification is jotted down with the original state. If the chef cancels (rollback), you tear off the overlay sheet. If approved (commit), you ink the changes down permanently.

The Mental "A-Ha!" Switch:

Transaction rollback does NOT require copying the entire database! By maintaining an 'Undo Log' (delta map of original states before each modification), a rollback simply replays the undo log in reverse order in O(T) time where T is the number of writes in that transaction.

Pattern Trigger:

Build in-memory storage engine with TTL, prefix scan, and rollback → ConcurrentHashMap + Expiry Metadata + Undo-Log Stack.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(Database Size) Space per Transaction

Deep clone the entire database HashMap on every `beginTransaction()`.

Wasted Work: Cloning millions of keys on every transaction level; massive memory spikes and latency freezes.
The Optimal Breakthrough O(Mutations) Space per Transaction, O(1) CRUD

Delta logging: each transaction maintains an UndoMap. On rollback, apply only the captured deltas.

Core Invariant: An active transaction's undo log stores the state of key `k` as it existed before the transaction's first mutation to `k`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Full Database Snapshots Begin: O(N), Rollback: O(1) O(D * N) Catastrophic memory overhead on large databases.
2. Global Mutex Lock O(1) CRUD O(1) Bottlenecks multi-threaded reader throughput.
★ 3. ConcurrentMap + Delta Undo Stacks Begin: O(1), CRUD: O(1), Rollback: O(T) O(T) Auxiliary Enterprise standard; minimal memory footprint.

★ Full Production Implementation: In-Memory KV Store with TTL & Transactions

Multi-tier design: ConcurrentHashMap for core storage, ConcurrentSkipListMap for prefix scans, passive & active TTL expiration, and a stack of delta maps for O(T) transaction rollback.

Time: CRUD: O(1) Space: Scan: O(K + log N) 
import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.ConcurrentSkipListMap
import java.util.ArrayDeque

class InMemoryKVStore {
    private data class ValueEntry(val value: String, val expiresAt: Long = Long.MAX_VALUE) {
        fun isExpired(now: Long = System.currentTimeMillis()) = now >= expiresAt
    }

    // Core data structures
    private val store = ConcurrentHashMap<String, ValueEntry>()
    private val sortedIndex = ConcurrentSkipListMap<String, String>()
    private val txStack = ArrayDeque<MutableMap<String, ValueEntry?>>()

    @Synchronized
    fun set(key: String, value: String) {
        setWithTTL(key, value, Long.MAX_VALUE)
    }

    @Synchronized
    fun setWithTTL(key: String, value: String, ttlMs: Long) {
        val expiresAt = if (ttlMs == Long.MAX_VALUE) Long.MAX_VALUE else System.currentTimeMillis() + ttlMs
        recordUndo(key)
        store[key] = ValueEntry(value, expiresAt)
        sortedIndex[key] = value
    }

    fun get(key: String): String? {
        val entry = store[key] ?: return null
        if (entry.isExpired()) {
            delete(key) // Passive eviction
            return null
        }
        return entry.value
    }

    @Synchronized
    fun delete(key: String): Boolean {
        if (!store.containsKey(key)) return false
        recordUndo(key)
        store.remove(key)
        sortedIndex.remove(key)
        return true
    }

    fun scan(prefix: String): List<Pair<String, String>> {
        val result = mutableListOf<Pair<String, String>>()
        val subMap = sortedIndex.tailMap(prefix)
        for ((k, v) in subMap) {
            if (!k.startsWith(prefix)) break
            if (get(k) != null) { // Validates TTL on the fly
                result.add(Pair(k, v))
            }
        }
        return result
    }

    @Synchronized
    fun beginTransaction() {
        txStack.push(mutableMapOf())
    }

    @Synchronized
    fun commit(): Boolean {
        if (txStack.isEmpty()) return false
        val committedDeltas = txStack.pop()
        // If nested, merge into parent transaction
        if (txStack.isNotEmpty()) {
            val parent = txStack.peek()
            committedDeltas.forEach { (k, old) ->
                parent.putIfAbsent(k, old)
            }
        }
        return true
    }

    @Synchronized
    fun rollback(): Boolean {
        if (txStack.isEmpty()) return false
        val deltas = txStack.pop()
        deltas.forEach { (k, originalEntry) ->
            if (originalEntry == null) {
                store.remove(k)
                sortedIndex.remove(k)
            } else {
                store[k] = originalEntry
                sortedIndex[k] = originalEntry.value
            }
        }
        return true
    }

    private fun recordUndo(key: String) {
        if (txStack.isNotEmpty()) {
            val currentTx = txStack.peek()
            if (!currentTx.containsKey(key)) {
                currentTx[key] = store[key]
            }
        }
    }
}

import time
from collections import deque

class ValueEntry:
    def __init__(self, value: str, expires_at: float = float('inf')):
        self.value = value
        self.expires_at = expires_at

    def is_expired(self) -> bool:
        return time.time() >= self.expires_at

class InMemoryKVStore:
    def __init__(self):
        self.store = {}
        self.tx_stack = deque()

    def set(self, key: str, value: str) -> None:
        self.set_with_ttl(key, value, float('inf'))

    def set_with_ttl(self, key: str, value: str, ttl_ms: float) -> None:
        expires_at = float('inf') if ttl_ms == float('inf') else time.time() + (ttl_ms / 1000.0)
        self._record_undo(key)
        self.store[key] = ValueEntry(value, expires_at)

    def get(self, key: str) -> str | None:
        if key not in self.store:
            return None
        entry = self.store[key]
        if entry.is_expired():
            self.delete(key)
            return None
        return entry.value

    def delete(self, key: str) -> bool:
        if key not in self.store:
            return False
        self._record_undo(key)
        del self.store[key]
        return True

    def scan(self, prefix: str) -> list[tuple[str, str]]:
        res = []
        for k in sorted(self.store.keys()):
            if k.startswith(prefix):
                val = self.get(k)
                if val is not None:
                    res.append((k, val))
        return res

    def begin_transaction(self) -> None:
        self.tx_stack.append({})

    def commit(self) -> bool:
        if not self.tx_stack:
            return False
        deltas = self.tx_stack.pop()
        if self.tx_stack:
            parent = self.tx_stack[-1]
            for k, old in deltas.items():
                if k not in parent:
                    parent[k] = old
        return True

    def rollback(self) -> bool:
        if not self.tx_stack:
            return False
        deltas = self.tx_stack.pop()
        for k, old_entry in deltas.items():
            if old_entry is None:
                self.store.pop(k, None)
            else:
                self.store[k] = old_entry
        return True

    def _record_undo(self, key: str) -> None:
        if self.tx_stack:
            current_tx = self.tx_stack[-1]
            if key not in current_tx:
                current_tx[key] = self.store.get(key)

import java.util.*;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentSkipListMap;

public class InMemoryKVStore {
    private static class ValueEntry {
        final String value;
        final long expiresAt;

        ValueEntry(String value, long expiresAt) {
            this.value = value;
            this.expiresAt = expiresAt;
        }

        boolean isExpired() {
            return System.currentTimeMillis() >= expiresAt;
        }
    }

    private final Map<String, ValueEntry> store = new ConcurrentHashMap<>();
    private final ConcurrentSkipListMap<String, String> sortedIndex = new ConcurrentSkipListMap<>();
    private final Deque<Map<String, ValueEntry>> txStack = new ArrayDeque<>();

    public synchronized void set(String key, String value) {
        setWithTTL(key, value, Long.MAX_VALUE);
    }

    public synchronized void setWithTTL(String key, String value, long ttlMs) {
        long expiresAt = (ttlMs == Long.MAX_VALUE) ? Long.MAX_VALUE : System.currentTimeMillis() + ttlMs;
        recordUndo(key);
        store.put(key, new ValueEntry(value, expiresAt));
        sortedIndex.put(key, value);
    }

    public String get(String key) {
        ValueEntry entry = store.get(key);
        if (entry == null) return null;
        if (entry.isExpired()) {
            delete(key);
            return null;
        }
        return entry.value;
    }

    public synchronized boolean delete(String key) {
        if (!store.containsKey(key)) return false;
        recordUndo(key);
        store.remove(key);
        sortedIndex.remove(key);
        return true;
    }

    public List<Map.Entry<String, String>> scan(String prefix) {
        List<Map.Entry<String, String>> list = new ArrayList<>();
        NavigableMap<String, String> subMap = sortedIndex.tailMap(prefix, true);
        for (Map.Entry<String, String> e : subMap.entrySet()) {
            if (!e.getKey().startsWith(prefix)) break;
            if (get(e.getKey()) != null) {
                list.add(e);
            }
        }
        return list;
    }

    public synchronized void beginTransaction() {
        txStack.push(new HashMap<>());
    }

    public synchronized boolean commit() {
        if (txStack.isEmpty()) return false;
        Map<String, ValueEntry> committed = txStack.pop();
        if (!txStack.isEmpty()) {
            Map<String, ValueEntry> parent = txStack.peek();
            for (Map.Entry<String, ValueEntry> e : committed.entrySet()) {
                parent.putIfAbsent(e.getKey(), e.getValue());
            }
        }
        return true;
    }

    public synchronized boolean rollback() {
        if (txStack.isEmpty()) return false;
        Map<String, ValueEntry> deltas = txStack.pop();
        for (Map.Entry<String, ValueEntry> e : deltas.entrySet()) {
            if (e.getValue() == null) {
                store.remove(e.getKey());
                sortedIndex.remove(e.getKey());
            } else {
                store.put(e.getKey(), e.getValue());
                sortedIndex.put(e.getKey(), e.getValue().value);
            }
        }
        return true;
    }

    private void recordUndo(String key) {
        if (!txStack.isEmpty()) {
            Map<String, ValueEntry> currentTx = txStack.peek();
            if (!currentTx.containsKey(key)) {
                currentTx.put(key, store.get(key));
            }
        }
    }
}

          Phase 2: Space-Time Strategy Pitch
          
""For storage, I use a `ConcurrentHashMap` for O(1) key-value lookups paired with a `ConcurrentSkipListMap` to maintain lexicographical order for `scan(prefix)`. To handle TTL, each entry wraps its value with an `expiresAt` epoch millisecond timestamp. On `get()`, we perform passive expiration—if `now >= expiresAt`, delete the key and return null. For transactions, rather than taking a full snapshot of the database (which is memory-prohibitive), we maintain a stack of delta undo-logs. When `beginTransaction()` is called, we push a new empty undo-map. On any write, if the key hasn't been recorded in the current transaction, we save its prior state. On `rollback()`, we simply replay the undo log in reverse order, restoring original values and removing newly added keys in O(T) time where T is mutations made.""

        

        

          Phase 3: Live Coding Narrative
          
""Let me write the code. I define `ValueEntry(value, expiresAt)`. The `store` map holds entries. `txStack` is a `Deque>`. In `recordUndo(key)`, if `txStack` is non-empty and the current map doesn't have `key`, put `(key, store.get(key))`. In `rollback()`, pop the top map, iterate through entries: if value was null, remove key; otherwise put it back. `commit()` simply pops the top undo map, merging into the parent transaction if nested.""

        

        

          Phase 4: Cold Edge-Case Verification
          
""Testing with the rollback flow: `set("a", "1")`. Call `beginTransaction()`. Call `set("a", "2")` → undo log captures `a: "1"`. Call `set("b", "3")` → undo log captures `b: null`. Querying inside the transaction gives `a="2", b="3"`. Call `rollback()`: key 'a' is restored to "1", key 'b' is deleted. Querying outside gives `a="1", b=null`. Tested TTL expiration: after expiration, `get()` returns null. Concurrency is guaranteed by synchronized mutation blocks and concurrent maps.""
