Problem #ICA: In-Memory Key-Value Store with TTL (4-Stage ICA)

External Judge ↗

Official Problem Statement

Design a deterministic 4-Stage CodeSignal ICA In-Memory Key-Value Store supporting CRUD, lexicographical prefix scans, deterministic integer-timestamp TTL expiration, and nested transaction rollbacks.

Implement InMemoryKVStore across 4 progressive levels:
• Level 1 (Core CRUD): set(key, value), get(key) (returns value or null), delete(key) (returns true if live key existed).
• Level 2 (Sorted Prefix Scan): scan(prefix) returns all live entries starting with prefix sorted lexicographically by key as "key(value)" strings.
• Level 3 (Deterministic TTL): setAtWithTtl(key, value, timestamp, ttl) stores a value live on [timestamp, timestamp + ttl) (expired when now >= timestamp + ttl); plus getAt(key, timestamp), deleteAt(key, timestamp), and scanAt(prefix, timestamp).
• Level 4 (Nested Transactions): beginTransaction(), commit(), and rollback() (restores exact pre-transaction values and TTLs in O(T) delta time; returns false if no transaction is active).

Stage 1–2 (CRUD & Scan): set("u:2","Bob"); set("u:1","Ada"); scan("u:") → Output: ["u:1(Ada)", "u:2(Bob)"]

Stage 3 (Deterministic TTL): setAtWithTtl("tok","xyz", 10, 5); getAt("tok", 14); getAt("tok", 15) → Output: "xyz", then null (expired at t=15)

Stage 4 (Nested Rollback): set("bal","100"); beginTransaction(); set("bal","200"); rollback(); get("bal") → Output: "100"

Plain-English Translation & Core Nuance

Model each stored record as an immutable Entry(value, expiresAt) so Level 1 timeless writes simply use expiresAt = INF. Instead of cloning the whole database on beginTransaction(), push an empty UndoMap onto a stack and record the prior Entry only on the FIRST mutation to each key inside that transaction.

Official Constraints:
  • 1 <= operations <= 10^4 across all 4 progressive ICA stages.
  • Timestamps and TTLs are positive integers in [1, 10^9]; key is live strictly while timestamp < expiresAt.
  • Transactions can nest arbitrarily deep; commit() merges undo deltas into parent transaction if nested.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
commit() or rollback() with empty transaction stack -> cleanly returns false without mutating store.
Best-Case Early Exit
Exact boundary timestamp == start + ttl -> key is already expired (half-open interval [start, start + ttl)), returns null.
Worst-Case Full Scan
Nested transactions: begin -> write k=v2 -> begin -> write k=v3 -> commit -> rollback -> restores k back to original v1!

Section 01 • Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 Tracing-Paper Undo Overlays & Stamped Freshness Tickets

Picture a ledger book where every row holds a value plus an integer expiration tick (or Infinity). In CodeSignal ICA assessments, how you design Level 1 decides whether Level 3 and Level 4 break your code: wrapping values in Entry(value, expiresAt) from the start makes Level 3 TTL a 2-line helper! For Level 4 transactions, place a sheet of tracing paper (an empty UndoMap) on top of the stack. The first time you touch key K on that sheet, jot down K's previous Entry. Rollback tears off the top sheet and restores those jotted entries in O(T) time; nested commit merges the top sheet's earliest before-images down into the parent sheet via putIfAbsent.

The Mental "A-Ha!" Switch:

Store Entry(value, expiresAt) from Level 1 so timeless CRUD is just expiresAt = Long.MAX_VALUE, and use a stack of before-image UndoMaps (recording only the FIRST touch per key per transaction) for O(T) rollback.

Section 02 • Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N) Space & Time per beginTransaction()

Store raw strings in Level 1 (forcing a total rewrite at Level 3) and deep-clone the entire HashMap on every beginTransaction().

Wasted Work: Deep-cloning N keys across D nested transactions allocates O(D * N) memory and times out on Level 4 hidden suites.
The Optimal Breakthrough O(1) CRUD/Begin, O(N log N) or O(log N + K) Scan, O(T) Rollback

Unified Entry(value, expiresAt) map + helper isLive(entry, ts) + Deque of UndoMaps capturing first-write before-images.

Core Invariant: Each transaction frame maps every mutated key k to the exact Entry (or null) that existed immediately before that transaction began.

Naive: Full Map Clone per Txn Begin: O(N), CRUD: O(1) O(D · N) TLE/MLE when 10^4 keys meet nested transactions.

Naive: Full HashMap Snapshot per Transaction

Clones the entire store HashMap on every beginTransaction(). Simple but O(N) time & space per transaction.

Time: O(N) begin / O(1) rollback Space: O(D · N) 
import java.util.ArrayDeque

class InMemoryKVStore {
    private data class Entry(val value: String, val expiresAt: Long)
    private var store = HashMap<String, Entry>()
    private val snapshots = ArrayDeque<HashMap<String, Entry>>()
    private val INF = Long.MAX_VALUE

    fun set(key: String, value: String) = setAtWithTtl(key, value, 0L, INF)
    fun get(key: String): String? = getAt(key, 0L)
    fun delete(key: String): Boolean = deleteAt(key, 0L)
    fun scan(prefix: String): List<String> = scanAt(prefix, 0L)

    fun setAtWithTtl(key: String, value: String, timestamp: Long, ttl: Long) {
        val exp = if (ttl == INF) INF else timestamp + ttl
        store[key] = Entry(value, exp)
    }

    fun getAt(key: String, timestamp: Long): String? {
        val e = store[key] ?: return null
        return if (timestamp < e.expiresAt) e.value else null
    }

    fun deleteAt(key: String, timestamp: Long): Boolean {
        val e = store[key] ?: return false
        store.remove(key)
        return timestamp < e.expiresAt
    }

    fun scanAt(prefix: String, timestamp: Long): List<String> {
        val res = mutableListOf<String>()
        for (k in store.keys.toList().sorted()) {
            val e = store[k]
            if (k.startsWith(prefix) && e != null && timestamp < e.expiresAt) {
                res.add("$k(${e.value})")
            }
        }
        return res
    }

    fun beginTransaction() { snapshots.addLast(HashMap(store)) }
    fun commit(): Boolean {
        if (snapshots.isEmpty()) return false
        snapshots.removeLast()
        return true
    }
    fun rollback(): Boolean {
        if (snapshots.isEmpty()) return false
        store = snapshots.removeLast()
        return true
    }
}

    def __init__(self):
        self.store = {}
        self.snapshots = []

    def set(self, key: str, value: str) -> None:
        self.setAtWithTtl(key, value, 0, float('inf'))

    def get(self, key: str):
        return self.getAt(key, 0)

    def delete(self, key: str) -> bool:
        return self.deleteAt(key, 0)

    def scan(self, prefix: str) -> list[str]:
        return self.scanAt(prefix, 0)

    def setAtWithTtl(self, key: str, value: str, timestamp: int, ttl: float) -> None:
        exp = float('inf') if ttl == float('inf') else timestamp + ttl
        self.store[key] = [value, exp]

    def getAt(self, key: str, timestamp: int):
        entry = self.store.get(key)
        if entry is None or timestamp >= entry[1]:
            return None
        return entry[0]

    def deleteAt(self, key: str, timestamp: int) -> bool:
        entry = self.store.pop(key, None)
        return entry is not None and timestamp < entry[1]

    def scanAt(self, prefix: str, timestamp: int) -> list[str]:
        out = []
        for k in sorted(self.store.keys()):
            entry = self.store[k]
            if k.startswith(prefix) and timestamp < entry[1]:
                out.append(f"{k}({entry[0]})")
        return out

    def beginTransaction(self) -> None:
        self.snapshots.append(dict(self.store))

    def commit(self) -> bool:
        if not self.snapshots:
            return False
        self.snapshots.pop()
        return True

    def rollback(self) -> bool:
        if not self.snapshots:
            return False
        self.store = self.snapshots.pop()
        return True

        final long expiresAt;

    }

    private final Deque<Map<String, Entry>> snapshots = new ArrayDeque<>();

    public void set(String key, String value) { setAtWithTtl(key, value, 0L, Long.MAX_VALUE); }
    public String get(String key) { return getAt(key, 0L); }
    public boolean delete(String key) { return deleteAt(key, 0L); }
    public List<String> scan(String prefix) { return scanAt(prefix, 0L); }

    public void setAtWithTtl(String key, String value, long timestamp, long ttl) {
        long exp = (ttl == Long.MAX_VALUE) ? Long.MAX_VALUE : timestamp + ttl;
        store.put(key, new Entry(value, exp));
    }

    public String getAt(String key, long timestamp) {
        Entry e = store.get(key);
        return (e != null && timestamp < e.expiresAt) ? e.value : null;
    }

    public boolean deleteAt(String key, long timestamp) {
        Entry e = store.remove(key);
        return e != null && timestamp < e.expiresAt;
    }

        Collections.sort(keys);
        List<String> res = new ArrayList<>();
        for (String k : keys) {
            Entry e = store.get(k);
            if (k.startsWith(prefix) && e != null && timestamp < e.expiresAt) {
                res.add(k + "(" + e.value + ")");
            }

        return res;
    }

        snapshots.removeLast();
        return true;

import java.util.ArrayDeque

class InMemoryKVStore {
    private data class Entry(val value: String, val expiresAt: Long)

    private val store = HashMap<String, Entry>()
    private val txStack = ArrayDeque<HashMap<String, Entry?>>()
    private val INF = Long.MAX_VALUE

    fun set(key: String, value: String) {
        setAtWithTtl(key, value, 0L, INF)
    }

    fun get(key: String): String? {
        return getAt(key, 0L)
    }

    fun delete(key: String): Boolean {
        return deleteAt(key, 0L)
    }

    fun scan(prefix: String): List<String> {
        return scanAt(prefix, 0L)
    }

    fun setAtWithTtl(key: String, value: String, timestamp: Long, ttl: Long) {
        recordUndo(key)
        val exp = if (ttl == INF) INF else timestamp + ttl
        store[key] = Entry(value, exp)
    }

    fun getAt(key: String, timestamp: Long): String? {
        val e = store[key] ?: return null
        if (timestamp >= e.expiresAt) return null
        return e.value
    }

    fun deleteAt(key: String, timestamp: Long): Boolean {
        val e = store[key] ?: return false
        val wasLive = timestamp < e.expiresAt
        recordUndo(key)
        store.remove(key)
        return wasLive
    }

    fun scanAt(prefix: String, timestamp: Long): List<String> {
        val keys = store.keys.toList().sorted()
        val out = mutableListOf<String>()
        for (k in keys) {
            val e = store[k]
            if (k.startsWith(prefix) && e != null && timestamp < e.expiresAt) {
                out.add("$k(${e.value})")
            }
        }
        return out
    }

    fun beginTransaction() {
        txStack.addLast(HashMap())
    }

    fun commit(): Boolean {
        if (txStack.isEmpty()) return false
        val top = txStack.removeLast()
        if (txStack.isNotEmpty()) {
            val parent = txStack.last()
            for ((k, oldEntry) in top) {
                if (!parent.containsKey(k)) {
                    parent[k] = oldEntry
                }
            }
        }
        return true
    }

    fun rollback(): Boolean {
        if (txStack.isEmpty()) return false
        val deltas = txStack.removeLast()
        for ((k, oldEntry) in deltas) {
            if (oldEntry == null) {
                store.remove(k)
            } else {
                store[k] = oldEntry
            }
        }
        return true
    }

    private fun recordUndo(key: String) {
        if (txStack.isNotEmpty()) {
            val top = txStack.last()
            if (!top.containsKey(key)) {
                top[key] = store[key]
            }
        }
    }
}

from collections import deque

class InMemoryKVStore:
    def __init__(self):
        self.store = {}
        self.tx_stack = deque()

    def _record_undo(self, key: str) -> None:
        if self.tx_stack:
            top = self.tx_stack[-1]
            if key not in top:
                top[key] = self.store.get(key)

    def set(self, key: str, value: str) -> None:
        self.setAtWithTtl(key, value, 0, float('inf'))

    def get(self, key: str):
        return self.getAt(key, 0)

    def delete(self, key: str) -> bool:
        return self.deleteAt(key, 0)

    def scan(self, prefix: str) -> list[str]:
        return self.scanAt(prefix, 0)

    def setAtWithTtl(self, key: str, value: str, timestamp: int, ttl: float) -> None:
        self._record_undo(key)
        exp = float('inf') if ttl == float('inf') else timestamp + ttl
        self.store[key] = [value, exp]

    def getAt(self, key: str, timestamp: int):
        entry = self.store.get(key)
        if entry is None or timestamp >= entry[1]:
            return None
        return entry[0]

    def deleteAt(self, key: str, timestamp: int) -> bool:
        entry = self.store.get(key)
        if entry is None:
            return False
        was_live = timestamp < entry[1]
        self._record_undo(key)
        del self.store[key]
        return was_live

    def scanAt(self, prefix: str, timestamp: int) -> list[str]:
        res = []
        for k in sorted(self.store.keys()):
            entry = self.store[k]
            if k.startswith(prefix) and timestamp < entry[1]:
                res.append(f"{k}({entry[0]})")
        return res

    def beginTransaction(self) -> None:
        self.tx_stack.append({})

    def commit(self) -> bool:
        if not self.tx_stack:
            return False
        top = self.tx_stack.pop()
        if self.tx_stack:
            parent = self.tx_stack[-1]
            for k, old_entry in top.items():
                if k not in parent:
                    parent[k] = old_entry
        return True

    def rollback(self) -> bool:
        if not self.tx_stack:
            return False
        deltas = self.tx_stack.pop()
        for k, old_entry in deltas.items():
            if old_entry is None:
                self.store.pop(k, None)
            else:
                self.store[k] = old_entry
        return True

import java.util.*;

class InMemoryKVStore {
    private static class Entry {
        final String value;
        final long expiresAt;
        Entry(String value, long expiresAt) {
            this.value = value;
            this.expiresAt = expiresAt;
        }
    }

    private final Map<String, Entry> store = new HashMap<>();
    private final Deque<Map<String, Entry>> txStack = new ArrayDeque<>();

    public void set(String key, String value) {
        setAtWithTtl(key, value, 0L, Long.MAX_VALUE);
    }

    public String get(String key) {
        return getAt(key, 0L);
    }

    public boolean delete(String key) {
        return deleteAt(key, 0L);
    }

    public List<String> scan(String prefix) {
        return scanAt(prefix, 0L);
    }

    public void setAtWithTtl(String key, String value, long timestamp, long ttl) {
        recordUndo(key);
        long exp = (ttl == Long.MAX_VALUE) ? Long.MAX_VALUE : timestamp + ttl;
        store.put(key, new Entry(value, exp));
    }

    public String getAt(String key, long timestamp) {
        Entry e = store.get(key);
        if (e == null || timestamp >= e.expiresAt) return null;
        return e.value;
    }

    public boolean deleteAt(String key, long timestamp) {
        Entry e = store.get(key);
        if (e == null) return false;
        boolean wasLive = timestamp < e.expiresAt;
        recordUndo(key);
        store.remove(key);
        return wasLive;
    }

    public List<String> scanAt(String prefix, long timestamp) {
        List<String> keys = new ArrayList<>(store.keySet());
        Collections.sort(keys);
        List<String> out = new ArrayList<>();
        for (String k : keys) {
            Entry e = store.get(k);
            if (k.startsWith(prefix) && e != null && timestamp < e.expiresAt) {
                out.add(k + "(" + e.value + ")");
            }
        }
        return out;
    }

    public void beginTransaction() {
        txStack.addLast(new HashMap<>());
    }

    public boolean commit() {
        if (txStack.isEmpty()) return false;
        Map<String, Entry> top = txStack.removeLast();
        if (!txStack.isEmpty()) {
            Map<String, Entry> parent = txStack.peekLast();
            for (Map.Entry<String, Entry> e : top.entrySet()) {
                parent.putIfAbsent(e.getKey(), e.getValue());
            }
        }
        return true;
    }

    public boolean rollback() {
        if (txStack.isEmpty()) return false;
        Map<String, Entry> deltas = txStack.removeLast();
        for (Map.Entry<String, Entry> e : deltas.entrySet()) {
            if (e.getValue() == null) {
                store.remove(e.getKey());
            } else {
                store.put(e.getKey(), e.getValue());
            }
        }
        return true;
    }

    private void recordUndo(String key) {
        if (!txStack.isEmpty()) {
            Map<String, Entry> top = txStack.peekLast();
            if (!top.containsKey(key)) {
                top.put(key, store.get(key));
            }
        }
    }
}

4-phase spoken communication script for Karat, pair-programming screens, and onsite loops.

      


      

        

          Phase 1: Clarifying Constraints
          
In a 4-stage ICA, I first align on data invariants: TTL intervals are half-open [timestamp, timestamp + ttl), scan outputs lexicographically sorted 'key(value)' strings, and commit/rollback return false when no transaction is active.

        

        

          Phase 2: Space-Time Trade-Off Pitch
          
Even in Stage 1, I wrap values in Entry(value, expiresAt = Long.MAX_VALUE) rather than raw strings so Stage 3 TTL requires zero refactoring. For Stage 4 transactions, full snapshots cost O(N) per begin; a stack of UndoMaps recording only the first mutation per key takes O(1) per write and O(T) on rollback.

        

        

          Phase 3: Clean Implementation Narration
          
Every mutating method calls recordUndo(key) before touching store: if txStack is non-empty and top doesn't contain key yet, store top[key] = store[key]. On rollback(), pop top and restore old Entry or remove if null. On nested commit(), merge top into parent via putIfAbsent so parent still remembers the pre-parent state!

        

        

          Phase 4: Boundary Dry-Run Verification
          
Tracing nested commit + outer rollback: bal='100' -> begin(#1) -> set('200') records #1[bal='100'] -> begin(#2) -> set('300') records #2[bal='200'] -> commit(#2) uses putIfAbsent so #1 keeps bal='100' -> rollback(#1) restores bal='100'!

        

      


      

        ⚡ Mid-Level (L4) Production & Requirement-Pivot Follow-Up:
        
If Stage 2 scan(prefix) becomes read-heavy over 10^5 keys, replace the HashMap key sort with a TreeMap<String, Entry> and iterate store.tailMap(prefix) stopping on the first key that no longer startsWith(prefix), achieving O(log N + K) prefix scans.
