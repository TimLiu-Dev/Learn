LeetCode #146: LRU Cache

Official LC #146

Official Problem Statement

Design a data structure that follows the constraints of a Least Recently Used (LRU) cache.

Implement the LRUCache class:

  • LRUCache(int capacity) Initialize the LRU cache with positive size capacity.
  • int get(int key) Return the value of the key if the key exists, otherwise return -1.
  • void put(int key, int value) Update the value of the key if the key exists. Otherwise, add the key-value pair to the cache. If the number of keys exceeds the capacity from this operation, evict the least recently used key.

The functions get and put must each run in O(1) average time complexity.

Example 1: ["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"] [[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]] → Output: [null, null, null, 1, null, -1, null, -1, 3, 4] Explanation: LRUCache lRUCache = new LRUCache(2); lRUCache.put(1, 1); // cache is {1=1} lRUCache.put(2, 2); // cache is {1=1, 2=2} lRUCache.get(1); // return 1 lRUCache.put(3, 3); // LRU key was 2, evicts key 2, cache is {1=1, 3=3} lRUCache.get(2); // returns -1 (not found) lRUCache.put(4, 4); // LRU key was 1, evicts key 1, cache is {4=4, 3=3} lRUCache.get(1); // return -1 (not found) lRUCache.get(3); // return 3 lRUCache.get(4); // return 4

Plain-English Translation & Core Nuance

A Least Recently Used (LRU) cache must support O(1) lookup and O(1) eviction of the oldest item. We combine a HashMap for instant O(1) node lookup with a Doubly Linked List with dummy head (Most Recently Used) and dummy tail (Least Recently Used) sentinels. When an item is accessed (get or put), we splice it out of its current position and insert it right behind head. When capacity is exceeded, we evict the node right in front of tail.

Official Constraints:
  • 1 <= capacity <= 3000
  • 0 <= key <= 10^4
  • 0 <= value <= 10^5
  • At most 2 * 10^5 calls will be made to get and put.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Capacity = 1 cap = 1 → Every new key immediately evicts previous key.
Best-Case Early Exit
Overwrite existing key put(1, 10) -> put(1, 20) → Updates value and moves to MRU without increasing cache size.
Worst-Case Full Scan
Continuous gets on non-existent keys → Returns -1 immediately in O(1).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(1) Get, O(N) Put / Evict

Store timestamps in a HashMap. On eviction, scan all N keys to find the minimum timestamp.

Wasted Work: Scanning all entries linearly to find the oldest timestamp (O(N) per write on N=3000).
The Optimal Breakthrough O(1) Get, O(1) Put

Doubly Linked List node pointers (`prev` and `next`) provide instant O(1) detachment and re-attachment. HashMap maps key to Node pointer.

Core Invariant: `head.next` always points to the Most Recently Used node; `tail.prev` always points to the Least Recently Used node. `map.size <= capacity` at all times.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Timestamp Map Linear Scan Get: O(1), Put: O(N) O(C) Scanning timestamps times out on large caches.
2. Java LinkedHashMap Get: O(1), Put: O(1) O(C) Uses built-in access-order; forbidden in pure interviews.
★ 3. Custom Doubly Linked List + HashMap Get: O(1), Put: O(1) O(C) Production standard; zero framework dependency.

★ Production Optimal: Custom Doubly Linked List + HashMap

Doubly Linked List with dummy head and tail sentinels for O(1) splicing. HashMap maps key directly to Node reference for instant O(1) lookup.

Time: Get: O(1) Space: Put: O(1) 
class LRUCache(private val capacity: Int) {
    private class Node(var key: Int = 0, var value: Int = 0) {
        var prev: Node? = null
        var next: Node? = null
    }

    private val map = HashMap<Int, Node>()
    private val head = Node()
    private val tail = Node()

    init {
        head.next = tail
        tail.prev = head
    }

    fun get(key: Int): Int {
        val node = map[key] ?: return -1
        moveToHead(node)
        return node.value
    }

    fun put(key: Int, value: Int) {
        val node = map[key]
        if (node != null) {
            node.value = value
            moveToHead(node)
        } else {
            val newNode = Node(key, value)
            map[key] = newNode
            addToHead(newNode)
            if (map.size > capacity) {
                val lru = removeTail()
                map.remove(lru.key)
            }
        }
    }

    private fun addToHead(node: Node) {
        node.prev = head
        node.next = head.next
        head.next?.prev = node
        head.next = node
    }

    private fun removeNode(node: Node) {
        node.prev?.next = node.next
        node.next?.prev = node.prev
    }

    private fun moveToHead(node: Node) {
        removeNode(node)
        addToHead(node)
    }

    private fun removeTail(): Node {
        val lru = tail.prev!!
        removeNode(lru)
        return lru
    }
}

class Node:
    def __init__(self, key: int = 0, value: int = 0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.map = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def get(self, key: int) -> int:
        if key not in self.map:
            return -1
        node = self.map[key]
        self._move_to_head(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.map:
            node = self.map[key]
            node.value = value
            self._move_to_head(node)
        else:
            new_node = Node(key, value)
            self.map[key] = new_node
            self._add_to_head(new_node)
            if len(self.map) > self.capacity:
                lru = self._remove_tail()
                del self.map[lru.key]

    def _add_to_head(self, node: Node) -> None:
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node: Node) -> None:
        node.prev.next = node.next
        node.next.prev = node.prev

    def _move_to_head(self, node: Node) -> None:
        self._remove_node(node)
        self._add_to_head(node)

    def _remove_tail(self) -> Node:
        lru = self.tail.prev
        self._remove_node(lru)
        return lru

import java.util.HashMap;
import java.util.Map;

class LRUCache {
    private static class Node {
        int key;
        int value;
        Node prev;
        Node next;
        Node() {}
        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> map;
    private final Node head;
    private final Node tail;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.map = new HashMap<>();
        this.head = new Node();
        this.tail = new Node();
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
        } else {
            Node newNode = new Node(key, value);
            map.put(key, newNode);
            addToHead(newNode);
            if (map.size() > capacity) {
                Node lru = removeTail();
                map.remove(lru.key);
            }
        }
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private Node removeTail() {
        Node lru = tail.prev;
        removeNode(lru);
        return lru;
    }
}

          Phase 1: Clarifying Questions & Edge Cases
          
""First, let me clarify the constraints: `capacity` is positive, up to 3000. `get` and `put` must both execute in average O(1) time complexity. When capacity is exceeded during a `put`, we must evict the least recently used key. A `get` or an update `put` both count as using the key.""

        

        

          Phase 2: Space-Time Strategy Pitch
          
""To achieve O(1) for both operations, we need two components: a HashMap to locate keys in O(1) time, and a Doubly Linked List to maintain the recency ordering of keys. Singly linked list won't work because removing an arbitrary node requires O(1) access to its `prev` pointer. To prevent edge cases when inserting or removing from the ends, I will use dummy sentinel nodes: `head` (pointing to Most Recently Used) and `tail` (pointing to Least Recently Used). When an item is read or written, we remove it from its current position and prepend it directly behind `head`. If size exceeds capacity, `tail.prev` gives the LRU node, which we splice out and delete from the map in O(1).""

        

        

          Phase 3: Live Coding Narrative
          
""Let me write the code. I define `class Node(key, value, prev, next)`. In `LRUCache(capacity)`, initialize `head` and `tail`, link `head.next = tail` and `tail.prev = head`. Helper `addHead(node)` links `node` between `head` and `head.next`. Helper `remove(node)` links `node.prev.next = node.next` and `node.next.prev = node.prev`. In `get(key)`: if not in map, return -1. Otherwise, call `remove(node)` and `addHead(node)`, return `node.value`. In `put(key, value)`: if key exists, update value, move to head. If new, create node, add to map, add to head; if `map.size > capacity`, remove `tail.prev` and delete from map.""

        

        

          Phase 4: Cold Edge-Case Verification
          
""Tracing with `cap = 2`: `put(1, 1)`, `put(2, 2)`. List is `head <-> [2:2] <-> [1:1] <-> tail`. Call `get(1)`: node 1 moves to head, list becomes `head <-> [1:1] <-> [2:2] <-> tail`. Returns 1. Now `put(3, 3)`: adds 3 to head. Size is 3 > 2. Evicts `tail.prev`, which is key 2! Map removes 2. Calling `get(2)` returns -1. Calling `get(1)` returns 1. Everything is O(1) and verified.""

        

      


      

        ⚡ Senior Architectural & Scalability Follow-Up:
        
"In high-concurrency production systems (like Guava Cache or Caffeine), a single global lock around LRU links causes thread contention. Modern caches use striped ring buffers or ConcurrentLinkedQueue with read-write batching, or the W-TinyLFU eviction algorithm to achieve millions of ops/sec across concurrent cores."
