LeetCode #841: Keys and Rooms

Official LC #841

Official Problem Statement

There are n rooms labeled from 0 to n - 1 and all the rooms are locked, except for room 0. Your goal is to visit all the rooms. However, you cannot enter a locked room without having its key.

When you visit a room, you may find a set of distinct keys in it. Each key has a number on it, denoting which room it unlocks, and you can take all of them with you to unlock other rooms.

Given an array rooms where rooms[i] is the set of keys that you can obtain if you visited room i, return true if you can visit all the rooms, or false otherwise.

Example 1: rooms = [[1],[2],[3],[]] → Output: true Explanation: We visit room 0 and pick up key 1. We then visit room 1 and pick up key 2. We then visit room 2 and pick up key 3. We then visit room 3. Since we were able to visit every room, we return true.

Example 2: rooms = [[1,3],[3,0,1],[2],[0]] → Output: false Explanation: We can not enter room number 2 since the only key that unlocks it is in that room.

Plain-English Translation & Core Nuance

Check if all nodes in a directed graph are reachable starting from node 0. Traverse the graph with DFS or BFS, keeping track of visited rooms in a boolean array or set. At the end, return `true` if `visitedCount == rooms.length`, else `false`.

Official Constraints:
  • n == rooms.length
  • 2 <= n <= 1000
  • 0 <= rooms[i].length <= 1000
  • 1 <= sum(rooms[i].length) <= 3000
  • 0 <= rooms[i][j] < n
  • All the values of rooms[i] are unique.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(V + E) Time, O(V) Space

Iterative Queue BFS collecting keys and tracking visited in a HashSet.

Wasted Work: HashSet hashing overhead when room numbers are compact integers `0..N-1`.
The Optimal Breakthrough O(V + E) Time, O(V) Space

DFS with primitive `boolean[n]` array and running count. Direct array indexing with zero hash overhead.

Core Invariant: Every room entered is marked `visited[room] = true` exactly once, preventing infinite cycles.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Queue BFS with HashSet O(V + E) O(V) Uses HashSet for visited; object boxing overhead.
2. BitSet Reachability O(V + E) O(V / 64) Uses bitwise flags; optimal memory footprint.
★ 3. Recursive DFS with Boolean Array O(V + E) O(V) Call Stack Fastest execution speed; standard interview solution.

Iterative Queue BFS

Use a Queue to hold available keys. Dequeue keys and visit rooms, enqueuing new keys.

Time: O(V + E) Space: O(V) 
class Solution {
    fun canVisitAllRooms(rooms: List<List<Int>>): Boolean {
        val visited = BooleanArray(rooms.size)
        val queue = ArrayDeque<Int>()
        queue.add(0)
        visited[0] = true
        var count = 1

        while (queue.isNotEmpty()) {
            val curr = queue.removeFirst()
            for (key in rooms[curr]) {
                if (!visited[key]) {
                    visited[key] = true
                    count++
                    queue.add(key)
                }
            }
        }

        return count == rooms.size
    }
}
Kotlin Runtime & Memory Nuance:

Standard iterative BFS using `ArrayDeque`. Immune to stack overflow.

class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        visited[0] = true;
        int count = 1;

        while (!queue.isEmpty()) {
            int curr = queue.poll();
            for (int key : rooms.get(curr)) {
                if (!visited[key]) {
                    visited[key] = true;
                    count++;
                    queue.offer(key);
                }
            }
        }

        return count == n;
    }
}

Iterative BFS. Safe against recursion stack limits.

BitSet Reachability

Use a Java BitSet or Python integer bitmask to track visited rooms.

Time: O(V + E) Space: O(V / 64) 
class Solution {
    fun canVisitAllRooms(rooms: List<List<Int>>): Boolean {
        val n = rooms.size
        val visited = java.util.BitSet(n)
        val stack = ArrayDeque<Int>()
        stack.add(0)
        visited.set(0)

        while (stack.isNotEmpty()) {
            val u = stack.removeLast()
            for (v in rooms[u]) {
                if (!visited.get(v)) {
                    visited.set(v)
                    stack.add(v)
                }
            }
        }
        return visited.cardinality() == n
    }
}

Compact BitSet representation. Excellent memory efficiency.

class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        BitSet visited = new BitSet(n);
        visited.set(0);
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);

        while (!stack.isEmpty()) {
            int u = stack.pop();
            for (int key : rooms.get(u)) {
                if (!visited.get(key)) {
                    visited.set(key);
                    stack.push(key);
                }
            }
        }

        return visited.cardinality() == n;
    }
}

Recursive DFS with Boolean Array (Optimal Primary)

Explore reachable rooms recursively. Mark visited in boolean array and increment counter.

Time: O(V + E) Space: O(V) Call Stack 
class Solution {
    /**
     * Optimal: Recursive DFS Reachability
     * Time: O(V + E) - Visits each room and key edge exactly once
     * Space: O(V) - Recursion stack and boolean array of size V
     */
    fun canVisitAllRooms(rooms: List<List<Int>>): Boolean {
        val visited = BooleanArray(rooms.size)
        var count = 0

        fun dfs(room: Int) {
            visited[room] = true
            count++

            for (key in rooms[room]) {
                if (!visited[key]) {
                    dfs(key)
                }
            }
        }

        dfs(0)
        return count == rooms.size
    }
}
Kotlin Runtime & Memory Nuance:

Optimal and concise. Visiting each vertex and edge once in O(V + E) time.

Textbook optimal graph DFS.

class Solution {
    private int count = 0;

    /**
     * Optimal: Recursive DFS Reachability
     * Time: O(V + E)
     * Space: O(V)
     */
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] visited = new boolean[n];
        dfs(0, rooms, visited);
        return count == n;
    }

    private void dfs(int room, List<List<Integer>> rooms, boolean[] visited) {
        visited[room] = true;
        count++;

        for (int key : rooms.get(room)) {
            if (!visited[key]) {
                dfs(key, rooms, visited);
            }
        }
    }
}
Java Runtime & Memory Nuance:

Production standard. Fastest cache performance with direct boolean array lookups.
