LeetCode #48: Rotate Image

Official LC #48

Official Problem Statement

You are given an n x n 2D matrix representing an image, rotate the image by 90 degrees (clockwise).

You have to rotate the image in-place, which means you have to modify the input 2D matrix directly. DO NOT allocate another 2D matrix and do the rotation.

Example 1: matrix = [[1,2,3],[4,5,6],[7,8,9]] → Output: [[7,4,1],[8,5,2],[9,6,3]]

Example 2: matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]] → Output: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

Plain-English Translation & Core Nuance

Rotate an N x N square grid 90 degrees clockwise without creating a second grid. Mathematically, rotating 90 degrees clockwise is identical to: 1. Transposing the matrix (swapping matrix[i][j] with matrix[j][i]), then 2. Reversing each row horizontally.

Official Constraints:
  • n == matrix.length == matrix[i].length
  • 1 <= n <= 20
  • -1000 <= matrix[i][j] <= 1000

The Mental Model & "Explain Like I'm 12"

💡 The Fold and Flip (Origami Geometry)

If you draw a picture on square tracing paper and want to rotate it 90 degrees clockwise, you can achieve the exact same transformation in two simple physical folds: first, fold the paper diagonally from top-left to bottom-right (transposing rows into columns), then flip the paper horizontally like a page in a book (reversing each row).

The Mental "A-Ha!" Switch:

Rotate 90° Clockwise = Transpose across main diagonal + Reverse each row horizontally!

Pattern Trigger:

In-place 90 degree matrix rotation without allocating a new 2D grid.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N^2) Space

Allocate a new N x N result matrix and assign res[j][n - 1 - i] = matrix[i][j]. Violates the in-place constraint.

Wasted Work: Allocates an entirely redundant 2D matrix on the heap, violating strict in-place interview requirements.
The Optimal Breakthrough O(N^2) Time, O(1) Space

Two-phase in-place transformation: 1. Transpose the matrix across main diagonal (i < j: swap matrix[i][j] and matrix[j][i]). 2. Reverse each row.

Core Invariant: Every element is swapped in-place using O(1) temporary variables without auxiliary arrays.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: New 2D Buffer O(N^2) O(N^2) Forbidden by problem statement; fails in-place constraint.
Four-Way Cycle Rotation O(N^2) O(1) Rotates 4 corners in concentric rings; mathematically equivalent but error-prone indexing.
Transpose + Horizontal Reverse O(N^2) O(1) ★ Production standard. Clean, bug-free, and easy to explain in live interviews.

Approach 1: Transpose and Reverse Rows

In-place linear algebra transformation: transpose diagonally, then reverse horizontally.

Time: O(N^2) Space: O(1) memory 
class Solution {
    fun rotate(matrix: Array<IntArray>): Unit {
        val n = matrix.size
        // Phase 1: Transpose
        for (i in 0 until n) {
            for (j in i + 1 until n) {
                val temp = matrix[i][j]
                matrix[i][j] = matrix[j][i]
                matrix[j][i] = temp
            }
        }
        // Phase 2: Reverse each row
        for (i in 0 until n) {
            matrix[i].reverse()
        }
    }
}

class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        // Phase 1: Transpose
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }
        // Phase 2: Reverse each row
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }
}
Java Runtime & Memory Nuance:

Explicit two-pointer reversal for each row avoids allocations.
