LeetCode #76: Minimum Window Substring

Official LC #76

Official Problem Statement

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

The testcases will be generated such that the answer is unique.

Example 1: s = "ADOBECODEBANC", t = "ABC" → Output: "BANC" Explanation: The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.

Example 2: s = "a", t = "a" → Output: "a"

Example 3: s = "a", t = "aa" → Output: "" Explanation: Both 'a's from t must be included in the window. Since the largest window of s only has one 'a', return empty string.

Plain-English Translation & Core Nuance

We want to find the shortest contiguous slice of `s` that contains all characters of `t` with at least their required frequencies. We count the target character requirements into a frequency map `needMap` and track how many unique required characters have their quota met (`have == need`). We expand `r` to include characters into `windowMap`. When a character's count in `windowMap` matches its requirement in `needMap`, we increment `have`. Once `have == need`, the window is valid: we record the substring if it's the shortest seen so far, and greedily shrink `l` until the window is no longer valid. Then we continue expanding `r`.

Official Constraints:
  • m == s.length
  • n == t.length
  • 1 <= m, n <= 10^5
  • s and t consist of uppercase and lowercase English letters.

💡 The Grocery Shopping Cart

Think of string `t` as a shopping grocery list: 2 apples, 1 banana, 1 milk (`need = 3 unique items`). You walk down the supermarket aisle `s` pushing your cart. As you walk forward (expanding `r`), you toss items into your cart. The moment your cart has at least 2 apples, 1 banana, and 1 milk (`have == need`), your list is satisfied! Now you stop and look at your rear cart wheel (shrinking `l`): if the first item you picked up was a useless box of cereal or an extra apple you didn't need, you drop it back on the shelf to make your trip as short as possible.

The Mental "A-Ha!" Switch:

Comparing two frequency maps on every character addition would cost O(128) per step. By maintaining a single integer `have` that only increments when `windowMap[c] == needMap[c]`, validation checks become strictly O(1)!

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(M^2 * |Σ|) Time, O(|Σ|) Space

Generate all O(M^2) substrings of s and check if each contains all characters of t.

Wasted Work: Re-evaluating overlapping substrings from scratch rather than sliding window boundaries.
The Optimal Breakthrough O(M + N) Time, O(|Σ|) Space

Two-pointer sliding window where each pointer advances at most M times, with O(1) condition checks via `have` counter.

Core Invariant: Whenever `have == need`, the current window `s[l..r]` is guaranteed to contain every required character from `t` with sufficient multiplicity.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
All Substrings Generation O(M^2 * |Σ|) O(|Σ|) Vastly too slow for M = 100,000 (10^10 operations).
★ Two-Pointer Sliding Window O(M + N) O(|Σ|) Single pass; each character processed at most twice (entered & exited).

Sliding Window with IntArray Frequency Vector

Two pointers `l` and `r` with fixed size 128 integer array. Increment `have` when `window[c] == need[c]`. Once `have == required`, record minimum length and greedily shrink `l`.

Time: O(M + N) Time Space: O(1) Space 
class Solution {
    fun minWindow(s: String, t: String): String {
        if (s.length < t.length) return ""

        val need = IntArray(128)
        var required = 0
        for (c in t) {
            if (need[c.code] == 0) required++
            need[c.code]++
        }

        val window = IntArray(128)
        var have = 0
        var l = 0
        var minLen = Int.MAX_VALUE
        var startIdx = 0

        for (r in s.indices) {
            val c = s[r]
            window[c.code]++

            if (need[c.code] > 0 && window[c.code] == need[c.code]) {
                have++
            }

            while (have == required) {
                val currentLen = r - l + 1
                if (currentLen < minLen) {
                    minLen = currentLen
                    startIdx = l
                }

                val leftChar = s[l]
                window[leftChar.code]--
                if (need[leftChar.code] > 0 && window[leftChar.code] < need[leftChar.code]) {
                    have--
                }
                l++
            }
        }

        return if (minLen == Int.MAX_VALUE) "" else s.substring(startIdx, startIdx + minLen)
    }
}

from collections import Counter

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if len(s) < len(t):
            return ""
            
        need = Counter(t)
        required = len(need)
        window = {}
        have = 0
        
        min_len = float('inf')
        best_range = (0, 0)
        l = 0
        
        for r, c in enumerate(s):
            window[c] = window.get(c, 0) + 1
            if c in need and window[c] == need[c]:
                have += 1
                
            while have == required:
                if (r - l + 1) < min_len:
                    min_len = r - l + 1
                    best_range = (l, r)
                    
                left_c = s[l]
                window[left_c] -= 1
                if left_c in need and window[left_c] < need[left_c]:
                    have -= 1
                l += 1
                
        return "" if min_len == float('inf') else s[best_range[0]:best_range[1] + 1]

class Solution {
    public String minWindow(String s, String t) {
        if (s.length() < t.length()) return "";

        int[] need = new int[128];
        int required = 0;
        for (char c : t.toCharArray()) {
            if (need[c] == 0) required++;
            need[c]++;
        }

        int[] window = new int[128];
        int have = 0;
        int l = 0;
        int minLen = Integer.MAX_VALUE;
        int startIdx = 0;

        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            window[c]++;

            if (need[c] > 0 && window[c] == need[c]) {
                have++;
            }

            while (have == required) {
                int len = r - l + 1;
                if (len < minLen) {
                    minLen = len;
                    startIdx = l;
                }

                char leftChar = s.charAt(l);
                window[leftChar]--;
                if (need[leftChar] > 0 && window[leftChar] < need[leftChar]) {
                    have--;
                }
                l++;
            }
        }

        return minLen == Integer.MAX_VALUE ? "" : s.substring(startIdx, startIdx + minLen);
    }
}
