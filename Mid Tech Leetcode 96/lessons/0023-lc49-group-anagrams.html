Group Anagrams

View on LeetCode ↗

Problem Description

Given an array of strings strs, group the anagrams together. You can return the answer in any order.

An anagram is a word or phrase formed by rearranging the letters of a different word or phrase, typically using all the original letters exactly once.

🗣️
Plain-English Translation:

"Take a list of words, cluster every word that contains the exact same character frequencies into the same bucket, and return all buckets. Two words belong in the same group if and only if their sorted canonical form (or 26-element character frequency tuple) is identical."

Official Examples

Example 1:
Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
Three distinct anagram families formed.
Example 2:
Input: strs = [""]
Output: [[""]]
Empty string inside single bucket.
Example 3:
Input: strs = ["a"]
Output: [["a"]]
Single character singleton bucket.
Official Constraints:
  • 1 ≤ strs.length ≤ 10⁴ (N is up to 10,000 strings → pairwise O(N²) comparison will TLE)
  • 0 ≤ strs[i].length ≤ 100 (K is small ≤ 100 characters per string)
  • strs[i] consists of lowercase English letters only. (Fixed alphabet of 26 characters allows integer array tallying)
The 3 Canonical Input Shapes (Mental Boundary Checks):
1. Minimum Base Case
strs = [""]
Length = 0 string. Single empty bucket [[""]]. Must not crash on empty character arrays.
2. Completely Disjoint
strs = ["rat", "car", "pig"]
Zero anagram pairs exist. Map creates N individual singleton buckets.
3. Massive Single Bucket
10,000 permutations of "abc"
All words funnel into a single bucket of 10,000 strings under key "abc".

🏰 The Real-World Analogy

The Mailroom Sorting Cubbies

Imagine a mailroom clerk receiving thousands of envelopes. Instead of picking up an envelope and comparing it against every other envelope in the building (quadratic O(N²)), the clerk computes a canonical fingerprint key for each envelope: alphabetizing the letters ("eat" → "aet", "tea" → "aet").

Words sharing the exact same fingerprint drop into the same labeled wall cubby (HashMap<Key, List<String>>) in O(1) time. When all envelopes are processed, the clerk simply collects the contents of each cubby.

The Mental "A-Ha!" Switch:

Anagram equivalence is an equivalence relation. Map every string to a canonical equivalence key: either sorted string ("aet") or a 26-integer count tuple ("#1#0#0...#1").

Pattern Trigger:

Whenever asked to 'group', 'cluster', or 'partition' items by character composition → reach for a HashMap of buckets with a canonical signature key.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N² × K log K)

The Pairwise Comparison Scan

Compare every pair of strings (i, j) by sorting both words and checking equality. If equal, merge them into the same group using a boolean visited table. Across 10,000 strings, this forces ~50,000,000 pairwise string comparisons!

Wasted CPU Cycles: Repeatedly re-verifying characters against multiple candidate words instead of indexing directly into a hash bucket.
The Optimal Breakthrough O(N × K) or O(N × K log K)

The Single-Pass HashMap Bucketing

Iterate through the array once. For each string of length K, compute its canonical signature. Insert into HashMap<Signature, List<String>>. Return map.values() as a nested list in one clean sweep.

Core Invariant: Two words are anagrams if and only if their 26-character frequency signature is identical.
Asymptotic Trade-off Matrix Target Bound: O(N × K) Time
Approach Time Complexity Space Complexity Practical Bottleneck Interview Verdict
1. Naive Pairwise Scan O(N² × K log K) O(N × K) Nested comparisons across 10,000 strings → TLE. ❌ Rejected
2. Sorting as HashMap Key O(N × K log K) O(N × K) Sort each string as key. Fast, readable, industry standard. ✅ Accepted Standard
★ 3. 26-Count Frequency Key O(N × K) O(N × K) Fixed 26-int tally eliminates string sorting overhead. ★ Optimal Gold Standard

class Solution {
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
        val result = mutableListOf<MutableList<String>>()
        val visited = BooleanArray(strs.size)
        
        for (i in strs.indices) {
            if (visited[i]) continue
            val group = mutableListOf(strs[i])
            visited[i] = true
            val sortedI = strs[i].toCharArray().sorted().joinToString("")
            
            for (j in i + 1 until strs.size) {
                if (!visited[j]) {
                    val sortedJ = strs[j].toCharArray().sorted().joinToString("")
                    if (sortedI == sortedJ) {
                        group.add(strs[j])
                        visited[j] = true
                    }
                }
            }
            result.add(group)
        }
        return result
    }
}

                if not visited[j] and sorted_i == sorted(strs[j]):
                    group.append(strs[j])
                    visited[j] = True
            result.append(group)
        return result

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> result = new ArrayList<>();
        boolean[] visited = new boolean[strs.length];
        for (int i = 0; i < strs.length; i++) {
            if (visited[i]) continue;
            List<String> group = new ArrayList<>();
            group.add(strs[i]);
            visited[i] = true;
            char[] arrI = strs[i].toCharArray();
            Arrays.sort(arrI);
            String sortedI = new String(arrI);
            for (int j = i + 1; j < strs.length; j++) {
                if (!visited[j]) {
                    char[] arrJ = strs[j].toCharArray();
                    Arrays.sort(arrJ);
                    if (sortedI.equals(new String(arrJ))) {
                        group.add(strs[j]);
                        visited[j] = true;
                    }
                }
            }
            result.add(group);
        }
        return result;
    }
}
class Solution {
    /**
     * Approach 2: Better (Sorting as HashMap Key)
     * Time: O(N * K log K) - Sort each string of length K.
     * Space: O(N * K) - Stored strings in hash map buckets.
     */
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
        val map = HashMap<String, MutableList<String>>()
        for (s in strs) {
            val key = String(s.toCharArray().apply { sort() })
            map.getOrPut(key) { ArrayList() }.add(s)
        }
        return ArrayList(map.values)
    }
}

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
class Solution {
    /**
     * Approach 3: Optimal (26-Character Frequency Counting Key)
     * Time: O(N * K) - Linear in total input characters; zero sort overhead.
     * Space: O(N * K) - Total strings preserved in map.
     */
    fun groupAnagrams(strs: Array<String>): List<List<String>> {
        val map = HashMap<String, MutableList<String>>()
        
        for (s in strs) {
            val count = IntArray(26)
            for (ch in s) {
                count[ch - 'a']++
            }
            // Build delimiter-separated canonical signature
            val key = buildString {
                for (c in count) {
                    append('#')
                    append(c)
                }
            }
            map.getOrPut(key) { ArrayList() }.add(s)
        }
        return ArrayList(map.values)
    }
}
Kotlin Senior Engineering Breakdown:
  • buildString { ... }: Pre-allocates a local StringBuilder efficiently with zero syntax boilerplate.
  • IntArray(26): Stays unboxed on the thread stack without wrapping 26 Integer instances.
  • Delimiter Requirement: Prepended '#' ensures counts like [1, 10] and [11, 0] do not collide into ambiguous string "110".
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        from collections import defaultdict
        groups = defaultdict(list)
        for s in strs:
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1
            # Tuples are immutable & hashable in Python
            groups[tuple(count)].append(s)
        return list(groups.values())

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] count = new int[26];
            for (int i = 0; i < s.length(); i++) {
                count[s.charAt(i) - 'a']++;
            }
            StringBuilder sb = new StringBuilder();
            for (int c : count) {
                sb.append('#').append(c);
            }
            String key = sb.toString();
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
