Problem #236: Lowest Common Ancestor of a Binary Tree

View on NeetCode ↗

Official Problem Statement

Given a binary tree, find the lowest common ancestor (LCA) of two given nodes, p and q.

According to the definition of LCA on Wikipedia: “The lowest common ancestor is defined between two nodes p and q as the lowest node in T that has both p and q as descendants (where we allow a node to be a descendant of itself).”

Example 1: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1 → Output: 3 Explanation: The LCA of nodes 5 and 1 is 3.

Example 2: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4 → Output: 5 Explanation: The LCA of nodes 5 and 4 is 5, since a node can be a descendant of itself according to the LCA definition.

Plain-English Translation & Core Nuance

Perform a bottom-up post-order DFS. If the current node is null, or matches p or q, return the current node immediately. Recurse down left and right subtrees. If both the left and right recursive calls return non-null references, it means p and q are in separate subtrees, so the current node is their Lowest Common Ancestor! If only one side returns non-null, bubble up that non-null node.

Official Constraints:
  • The number of nodes in the tree is in the range [2, 10^5].
  • -10^9 <= Node.val <= 10^9
  • All Node.val are unique.
  • p != q
  • p and q will exist in the tree.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
p is direct parent of q p=5, q=4 → Returns 5 as soon as node 5 is reached.
Best-Case Early Exit
Root is p or q → Returns root immediately without scanning subtrees.
Worst-Case Full Scan
p and q at deepest leaf nodes in opposite subtrees → Full post-order DFS visits all N nodes.

The Mental Model & "Explain Like I'm 12"

💡 The River Confluence Search

Imagine two lost hikers p and q in a river delta system. Search boats travel up every tributary. When a boat finds p, it signals upstream 'Found p'. When a boat finds q, it signals 'Found q'. The first river fork where signals arrive simultaneously from two different tributaries is the confluence point—the Lowest Common Ancestor.

The Mental "A-Ha!" Switch:

A node is the LCA if and only if: 1) One target is in its left subtree and the other is in its right subtree; OR 2) The node itself is p (or q) and the other target is in one of its subtrees. Both cases are unified into a single 4-line recursive post-order check.

Pattern Trigger:

Find lowest common ancestor in a general binary tree (without BST ordering) → Bottom-up Post-Order DFS returning matched target nodes.

★ Approach: Bottom-Up Post-Order DFS (Production Optimal)

Bottom-up recursion. If root matches p or q, bubble up root. If both left and right branches return non-null, root is LCA. Otherwise propagate whichever branch returned non-null.

Time: O(N) Time Space: O(Height) Auxiliary Space 
class TreeNode(var `val`: Int) {
    var left: TreeNode? = null
    var right: TreeNode? = null
}

class Solution {
    fun lowestCommonAncestor(root: TreeNode?, p: TreeNode?, q: TreeNode?): TreeNode? {
        if (root == null || root == p || root == q) return root

        val left = lowestCommonAncestor(root.left, p, q)
        val right = lowestCommonAncestor(root.right, p, q)

        return when {
            left != null && right != null -> root // Split point: this is the LCA
            left != null -> left                  // Both targets on left side
            else -> right                         // Both targets on right side
        }
    }
}

class TreeNode:
    def __init__(self, x):

        self.left = None
        self.right = None

class Solution:
    def lowestCommonAncestor(self, root: TreeNode | None, p: TreeNode, q: TreeNode) -> TreeNode | None:
        if not root or root == p or root == q:
            return root

        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left and right:
            return root
        return left if left else right

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int x) { val = x; }

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) return root;
        return (left != null) ? left : right;
    }
}
