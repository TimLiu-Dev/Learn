LeetCode #417: Pacific Atlantic Water Flow

Official LC #417

Official Problem Statement

There is an m x n rectangular island that borders both the Pacific Ocean and Atlantic Ocean. The Pacific Ocean touches the island's left and top edges, and the Atlantic Ocean touches the island's right and bottom edges.

The island is partitioned into a grid of square cells. You are given an m x n integer matrix heights where heights[r][c] represents the height above sea level of the cell at coordinate (r, c).

The island receives a lot of rain, and the rain water can flow to neighboring cells directly north, south, east, and west if the neighboring cell's height is less than or equal to the current cell's height. Water can flow from any cell adjacent to an ocean into the ocean.

Return a 2D list of grid coordinates result where result[i] = [r_i, c_i] denotes that rain water can flow from cell (r_i, c_i) to both the Pacific and Atlantic oceans.

Example 1: heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]] → Output: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]] Explanation: The water from these cells can flow to both Pacific and Atlantic oceans.

Example 2: heights = [[1]] → Output: [[0,0]] Explanation: The single cell touches both oceans.

Plain-English Translation & Core Nuance

Instead of simulating water flowing downward from every single cell to the oceans (which takes O((M*N)^2) time), we reverse the flow! We start water at the ocean coastlines and flow UPWARD into cells with equal or greater height (`neighborHeight >= currHeight`). We run one DFS/BFS seeded from Pacific borders (top row and left column) and another DFS/BFS seeded from Atlantic borders (bottom row and right column). The intersection of cells reachable by both traversals is our answer.

Official Constraints:
  • m == heights.length
  • n == heights[r].length
  • 1 <= m, n <= 200
  • 0 <= heights[r][c] <= 10^5

Canonical Input Shapes (Mental Boundary Checks)

The Mental Model & "Explain Like I'm 12"

💡 Rising Sea Tides from Opposite Shores

Imagine two tidal waves rising: a blue tide from the Pacific (north and west edges) and an orange tide from the Atlantic (south and east edges). Water can only flood uphill or across flat ground (`neighbor >= curr`). Let the blue tide flood inward as far as it can reach. Let the orange tide flood inward as far as it can reach. Any peak or plateau that gets soaked in BOTH blue and orange water can drain to both oceans.

The Mental "A-Ha!" Switch:

Reversing the flow from the ocean borders inward transforms an intractable O((M*N)^2) search into two simple O(M*N) linear flood fills. An intersection check on two boolean 2D matrices yields the answer in O(1) per cell.

Pattern Trigger:

Find cells that can reach both opposite boundaries in a 2D height grid → Reverse Inward Multi-source DFS/BFS from both borders.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O((M * N)^2) Time, O(M * N) Space

From every individual cell (r, c), run a fresh DFS to see if it can reach a Pacific cell AND an Atlantic cell.

Wasted Work: Re-traversing identical downhill paths thousands of times (40,000 \times 40,000 = 1.6 \times 10^9 ops for 200x200 grid).
The Optimal Breakthrough O(M * N) Time, O(M * N) Auxiliary Space

Two reverse DFS traversals: Pacific border flood fill + Atlantic border flood fill. Find intersection.

Core Invariant: `pacific[r][c] == true` if and only if cell (r, c) can flow water to Pacific. `atlantic[r][c] == true` if and only if it can reach Atlantic.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Per-Cell Downhill Search O((M * N)^2) O(M * N) Severe timeout on 200x200 matrix.
★ 2. Reverse Coastline Inward Fill O(M * N) O(M * N) Optimal linear grid scan; each cell visited at most twice.

★ Approach: Multi-Source Reverse Coastline DFS (Production Optimal)

Flood fill uphill (`heights[nr][nc] >= heights[r][c]`) starting from the Pacific coastline into `pacific[][]`, and from the Atlantic coastline into `atlantic[][]`. Cells where both booleans are true form the answer.

Time: O(M * N) Time Space: O(M * N) Space 
class Solution {
    fun pacificAtlantic(heights: Array<IntArray>): List<List<Int>> {
        val m = heights.size
        val n = heights[0].size
        val pacific = Array(m) { BooleanArray(n) }
        val atlantic = Array(m) { BooleanArray(n) }

        val dirs = arrayOf(intArrayOf(1, 0), intArrayOf(-1, 0), intArrayOf(0, 1), intArrayOf(0, -1))

        fun dfs(r: Int, c: Int, visited: Array<BooleanArray>) {
            visited[r][c] = true
            for (d in dirs) {
                val nr = r + d[0]
                val nc = c + d[1]
                if (nr in 0 until m && nc in 0 until n && !visited[nr][nc] && heights[nr][nc] >= heights[r][c]) {
                    dfs(nr, nc, visited)
                }
            }
        }

        // Top and bottom borders
        for (c in 0 until n) {
            dfs(0, c, pacific)
            dfs(m - 1, c, atlantic)
        }
        // Left and right borders
        for (r in 0 until m) {
            dfs(r, 0, pacific)
            dfs(r, n - 1, atlantic)
        }

        val result = mutableListOf<List<Int>>()
        for (r in 0 until m) {
            for (c in 0 until n) {
                if (pacific[r][c] && atlantic[r][c]) {
                    result.add(listOf(r, c))
                }
            }
        }
        return result
    }
}

class Solution:
    def pacificAtlantic(self, heights: list[list[int]]) -> list[list[int]]:
        m, n = len(heights), len(heights[0])
        pacific = set()
        atlantic = set()

        def dfs(r: int, c: int, visited: set):
            visited.add((r, c))
            for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and (nr, nc) not in visited:
                    if heights[nr][nc] >= heights[r][c]:
                        dfs(nr, nc, visited)

        for c in range(n):
            dfs(0, c, pacific)
            dfs(m - 1, c, atlantic)

        for r in range(m):
            dfs(r, 0, pacific)
            dfs(r, n - 1, atlantic)

        return [[r, c] for r, c in pacific & atlantic]

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length;
        int n = heights[0].length;
        boolean[][] pacific = new boolean[m][n];
        boolean[][] atlantic = new boolean[m][n];

        for (int c = 0; c < n; c++) {
            dfs(0, c, pacific, heights);
            dfs(m - 1, c, atlantic, heights);
        }
        for (int r = 0; r < m; r++) {
            dfs(r, 0, pacific, heights);
            dfs(r, n - 1, atlantic, heights);
        }

        List<List<Integer>> result = new ArrayList<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (pacific[r][c] && atlantic[r][c]) {
                    result.add(Arrays.asList(r, c));
                }
            }
        }
        return result;
    }

    private void dfs(int r, int c, boolean[][] visited, int[][] heights) {
        visited[r][c] = true;
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int[] d : dirs) {
            int nr = r + d[0];
            int nc = c + d[1];
            if (nr >= 0 && nr < heights.length && nc >= 0 && nc < heights[0].length 
                && !visited[nr][nc] && heights[nr][nc] >= heights[r][c]) {
                dfs(nr, nc, visited, heights);
            }
        }
    }
}
