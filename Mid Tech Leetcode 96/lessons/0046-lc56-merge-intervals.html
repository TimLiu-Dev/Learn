LeetCode #56: Merge Intervals

Official LC #56

Official Problem Statement

Given an array of intervals where intervals[i] = [starti, endi], merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

Example 1: intervals = [[1,3],[2,6],[8,10],[15,18]] → Output: [[1,6],[8,10],[15,18]] Explanation: Since intervals [1,3] and [2,6] overlap, merge them into [1,6].

Example 2: intervals = [[1,4],[4,5]] → Output: [[1,5]] Explanation: Intervals [1,4] and [4,5] are considered overlapping.

Plain-English Translation & Core Nuance

Sort intervals by their starting times. Maintain a list of merged intervals. For each interval, if it starts before or when the previous interval ends (`curr.start <= last.end`), merge them by extending `last.end = max(last.end, curr.end)`. Otherwise, append the interval as a new disjoint block.

Official Constraints:
  • 1 <= intervals.length <= 10^4
  • intervals[i].length == 2
  • 0 <= start_i <= end_i <= 10^4

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single interval [[1, 5]] → Returns [[1, 5]] directly.
Best-Case Early Exit
Adjacent touching boundary [[1,4],[4,5]] → Overlaps at point 4, merges to [[1,5]].
Worst-Case Full Scan
Enclosing interval [[1,10],[2,3],[4,5],[6,7]] → All engulfed into [[1,10]].

Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 Calendar Meeting Compactor

Imagine scheduling meetings on a calendar. First, sort all meeting slips by their start time on your desk. Take the earliest meeting slip. Pick up the next slip: does it begin before your current meeting ends? If yes, you simply slide your departure time out to whichever meeting ends later (`max(end1, end2)`). If the next meeting starts after a break, you lock in the current block and start a fresh meeting block.

The Mental "A-Ha!" Switch:

Sorting by start time guarantees that once an interval starts AFTER the current merged interval ends (`curr[0] > last[1]`), NO SUBSEQUENT interval can ever overlap with `last`! This reduces a quadratic pairwise comparison problem to a single linear sweep.

Pattern Trigger:

Overlapping ranges, calendar booking, scheduling conflicts, range consolidation → Sort by start time + Greedy merge loop.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N) Space

Model intervals as graph nodes where an edge exists if two intervals overlap. Find connected components and compute their bounding hulls.

Wasted Work: Comparing every pair of intervals when a single sort establishes total ordering.
The Optimal Breakthrough O(N log N) Time, O(N) Space

Sort by start time in O(N log N). Single pass merge in O(N) time with constant space per step.

Core Invariant: All intervals prior to the current index in `result` are strictly disjoint, sorted, and immutable.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Connected Components Graph O(N^2) O(N^2) Builds overlap graph; extremely slow on large N.
2. Sweep-Line Event Points O(N log N) O(N) Splits into +1/-1 start/end points; complex edge cases on touching endpoints.
★ 3. Sort by Start Time + Greedy Sweep O(N log N) O(N) Standard optimal algorithm. Cleanest in interviews.

Connected Components Overlap Graph (Naive)

Construct an adjacency graph where an edge connects two overlapping intervals. Find components with BFS/DFS.

Time: O(N^2) Space: O(N^2) 
class Solution {
    fun merge(intervals: Array<IntArray>): Array<IntArray> {
        val n = intervals.size
        val adj = Array(n) { mutableListOf<Int>() }
        for (i in 0 until n) {
            for (j in i + 1 until n) {
                if (maxOf(intervals[i][0], intervals[j][0]) <= minOf(intervals[i][1], intervals[j][1])) {
                    adj[i].add(j)
                    adj[j].add(i)
                }
            }
        }
        val visited = BooleanArray(n)
        val result = mutableListOf<IntArray>()
        for (i in 0 until n) {
            if (!visited[i]) {
                var start = intervals[i][0]
                var end = intervals[i][1]
                val q = ArrayDeque<Int>().apply { add(i) }
                visited[i] = true
                while (q.isNotEmpty()) {
                    val curr = q.removeFirst()
                    start = minOf(start, intervals[curr][0])
                    end = maxOf(end, intervals[curr][1])
                    for (neighbor in adj[curr]) {
                        if (!visited[neighbor]) {
                            visited[neighbor] = true
                            q.add(neighbor)
                        }
                    }
                }
                result.add(intArrayOf(start, end))
            }
        }
        return result.toTypedArray()
    }
}

class Solution {
    public int[][] merge(int[][] intervals) {
        int n = intervals.length;
        List<Integer>[] adj = new List[n];
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (Math.max(intervals[i][0], intervals[j][0]) <= Math.min(intervals[i][1], intervals[j][1])) {
                    adj[i].add(j);
                    adj[j].add(i);
                }
            }
        }
        boolean[] visited = new boolean[n];
        List<int[]> result = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                int start = intervals[i][0], end = intervals[i][1];
                Queue<Integer> q = new ArrayDeque<>();
                q.offer(i);
                visited[i] = true;
                while (!q.isEmpty()) {
                    int cur = q.poll();
                    start = Math.min(start, intervals[cur][0]);
                    end = Math.max(end, intervals[cur][1]);
                    for (int nbr : adj[cur]) {
                        if (!visited[nbr]) {
                            visited[nbr] = true;
                            q.offer(nbr);
                        }
                    }
                }
                result.add(new int[]{start, end});
            }
        }
        return result.toArray(new int[result.size()][]);
    }
}

Sweep Line / Endpoint Events

Decompose intervals into start (+1) and end (-1) point events. Track active interval count.

Time: O(N log N) Space: O(N) 
class Solution {
    fun merge(intervals: Array<IntArray>): Array<IntArray> {
        val starts = IntArray(intervals.size) { intervals[it][0] }.sortedArray()
        val ends = IntArray(intervals.size) { intervals[it][1] }.sortedArray()
        val result = mutableListOf<IntArray>()
        var startIdx = 0
        for (endIdx in ends.indices) {
            if (endIdx == ends.size - 1 || starts[endIdx + 1] > ends[endIdx]) {
                result.add(intArrayOf(starts[startIdx], ends[endIdx]))
                startIdx = endIdx + 1
            }
        }
        return result.toTypedArray()
    }
}

class Solution {
    public int[][] merge(int[][] intervals) {
        int n = intervals.length;
        int[] starts = new int[n];
        int[] ends = new int[n];
        for (int i = 0; i < n; i++) {

Sort by Start Time + Greedy Merge (Optimal Primary)

Sort intervals by start time. Maintain merged list, extending last interval's end on overlap.

Time: O(N log N) Space: O(N) 
class Solution {
    /**
     * Optimal: Sort by Start Time + Single Linear Merge Pass
     * Time: O(N log N) - Dominated by sorting
     * Space: O(N) - Storage for merged result array
     */
    fun merge(intervals: Array<IntArray>): Array<IntArray> {
        if (intervals.size <= 1) return intervals

        // Sort ascending by start time
        intervals.sortBy { it[0] }

        val result = mutableListOf<IntArray>()

        for (interval in intervals) {
            // If result is empty or current does not overlap with previous
            if (result.isEmpty() || interval[0] > result.last()[1]) {
                result.add(interval)
            } else {
                // Overlap exists: extend previous interval's end time
                result.last()[1] = maxOf(result.last()[1], interval[1])
            }
        }

        return result.toTypedArray()
    }
}
Kotlin Runtime & Memory Nuance:

Canonical interview solution. Sorting by `it[0]` establishes deterministic linear order.

class Solution:
    # Optimal: Sort by Start Time + Greedy Merge
    # Time: O(N log N) - Sorting dominates
    # Space: O(N) - Output list
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        merged = []

        for interval in intervals:
            if not merged or interval[0] > merged[-1][1]:
                merged.append(interval)
            else:
                merged[-1][1] = max(merged[-1][1], interval[1])

        return merged
Python Runtime & Memory Nuance:

Concise, idiomatic Python. Modifies `merged[-1][1]` in place.

class Solution {
    /**
     * Optimal: Sort by Start Time + Greedy Merge
     * Time: O(N log N) - Array sorting
     * Space: O(N) - Output array
     */
    public int[][] merge(int[][] intervals) {
        if (intervals.length <= 1) return intervals;

        // Sort by start time ascending
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> result = new ArrayList<>();

        for (int[] interval : intervals) {
            if (result.isEmpty() || interval[0] > result.get(result.size() - 1)[1]) {
                result.add(interval);
            } else {
                int[] last = result.get(result.size() - 1);
                last[1] = Math.max(last[1], interval[1]);
            }
        }

        return result.toArray(new int[result.size()][]);
    }
}
Java Runtime & Memory Nuance:

Standard industry template. Integer.compare prevents subtraction underflow.
