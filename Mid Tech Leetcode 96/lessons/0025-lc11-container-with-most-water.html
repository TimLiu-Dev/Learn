LeetCode #11: Container With Most Water

Official LC #11

Official Problem Statement

You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

Example 1: height = [1,8,6,2,5,4,8,3,7] → Output: 49 (between index 1 and 8: min(8, 7) * (8 - 1) = 7 * 7 = 49)

Example 2: height = [1,1] → Output: 1 (min(1, 1) * (1 - 0) = 1)

Plain-English Translation & Core Nuance

Pick two vertical walls such that the area of water trapped between them (width * minimum height of the two walls) is maximized. Start with the widest possible container at both ends, and greedily move the pointer pointing to the shorter wall inward.

Official Constraints:
  • n == height.length
  • 2 <= n <= 10^5
  • 0 <= height[i] <= 10^4

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
height = [1, 1] → Only two walls, area = min(1, 1) * 1 = 1.
Best-Case Early Exit
Two huge walls at the ends [1000, 1, 1, 1000] → Maximum width and height immediately evaluated.
Worst-Case Full Scan
100,000 ascending walls → Single linear converging scan in O(N) time.

Cognitive Anchor

The Mental Model & "Explain Like I'm 12"

💡 The Two Telescoping Dam Walls

Think of a valley between two movable dam gates. The water level is limited strictly by the shorter gate (water spills over anything higher). As the gates move closer together, width strictly decreases. The only possible way to compensate for lost width is to find a significantly taller wall. Moving the taller gate inward can NEVER increase water volume (height is still bottlenecked by the short gate, while width shrank). Therefore, you must discard the shorter gate and search inward.

The Mental "A-Ha!" Switch:

Area = (right - left) * min(h[left], h[right]). If you keep the shorter wall and move the taller one inward, width decreases and height cannot increase. Thus, moving the taller wall is mathematically guaranteed to be inferior. You must advance the shorter wall.

Pattern Trigger:

Whenever maximizing an area bounded by two array indices → Inward-Converging Two Pointers.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(1) Space

Compute area for every pair (i, j) with nested loops. For N = 100,000, this requires 5 billion iterations, triggering Time Limit Exceeded.

Wasted Work: Testing pairs with smaller widths and identical or smaller heights that cannot possibly beat the current maximum.
The Optimal Breakthrough O(N) Time, O(1) Space

Start left=0, right=n-1. Compute area. Advance the pointer with the smaller height. Converges in N steps.

Core Invariant: At each step, the discarded wall can never form a larger container with any remaining unexamined line.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Brute Force Nested Loops O(N^2) O(1) Tests all N*(N-1)/2 pairs. TLE on N=10^5.
★ 2. Converging Two Pointers O(N) O(1) Single pass. Optimal and production standard.

Brute Force All Pairs

Check area for every pair (i, j) with nested loops.

Time: O(N^2) Space: O(1) 
class Solution {
    fun maxArea(height: IntArray): Int {
        var maxArea = 0
        for (i in 0 until height.size) {
            for (j in i + 1 until height.size) {
                val area = minOf(height[i], height[j]) * (j - i)
                maxArea = maxOf(maxArea, area)
            }
        }
        return maxArea
    }
}
Kotlin Runtime & Memory Nuance:

Quadratic O(N^2) time complexity. For 100,000 lines, 10^10 operations trigger Time Limit Exceeded.

class Solution:

        for i in range(n):
            for j in range(i + 1, n):
                area = min(height[i], height[j]) * (j - i)
                if area > max_area:

        return max_area

class Solution {
    public int maxArea(int[] height) {
        int maxArea = 0;
        for (int i = 0; i < height.length; i++) {
            for (int j = i + 1; j < height.length; j++) {
                int area = Math.min(height[i], height[j]) * (j - i);
                maxArea = Math.max(maxArea, area);
            }
        }
        return maxArea;
    }
}
Java Runtime & Memory Nuance:

Simple to write in 30 seconds as the naive baseline, but fails on large datasets.

Better: Two Pointers with Fast Skipping

Two pointers skipping inward while height is smaller than current bottleneck.

Time: O(N) Space: O(1) 
class Solution {
    fun maxArea(height: IntArray): Int {
        var l = 0
        var r = height.size - 1
        var maxArea = 0
        
        while (l < r) {
            val minH = minOf(height[l], height[r])
            maxArea = maxOf(maxArea, minH * (r - l))
            // Fast skip walls that are shorter than current bottleneck
            while (l < r && height[l] <= minH) l++
            while (l < r && height[r] <= minH) r--
        }
        return maxArea
    }
}
Kotlin Runtime & Memory Nuance:

Inner while-loops skip walls that cannot beat `minH`, saving loop iterations on plateau-heavy datasets.

class Solution:
    def maxArea(self, height: list[int]) -> int:

                l += 1
            while l < r and height[r] <= min_h:

Skips flat/redundant walls quickly, yielding lower runtime percentiles in competitive scoring.

Optimal: Classic Converging Two Pointers

Clean canonical interview solution with single branch pointer advancement.

Time: O(N) Space: O(1) 
class Solution {
    /**
     * Optimal: Inward-Converging Two Pointers
     * Time: O(N) - Single pass with pointers meeting in the middle
     * Space: O(1) - Constant auxiliary memory
     */
    fun maxArea(height: IntArray): Int {
        var left = 0
        var right = height.size - 1
        var maxWater = 0

        while (left < right) {
            val width = right - left
            val hL = height[left]
            val hR = height[right]

            if (hL < hR) {
                val area = hL * width
                if (area > maxWater) maxWater = area
                left++
            } else {
                val area = hR * width
                if (area > maxWater) maxWater = area
                right--
            }
        }

        return maxWater
    }
}
Kotlin Runtime & Memory Nuance:

Direct indexing on primitive `IntArray` avoids all boxing overhead. Extremely clean and fast.

class Solution {
    /**
     * Optimal: Inward-Converging Two Pointers
     * Time: O(N) - Exactly N - 1 iterations
     * Space: O(1) - Primitive integers only
     */
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxWater = 0;

        while (left < right) {
            int width = right - left;
            int hL = height[left];
            int hR = height[right];

            if (hL < hR) {
                int area = hL * width;
                if (area > maxWater) maxWater = area;
                left++;
            } else {
                int area = hR * width;
                if (area > maxWater) maxWater = area;
                right--;
            }
        }

        return maxWater;
    }
}
Java Runtime & Memory Nuance:

The production gold standard. No Math.min or Math.max overhead; uses direct branch comparison.
