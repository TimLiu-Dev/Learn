Problem #91: Decode Ways

View on NeetCode ↗

Official Problem Statement

A message containing letters from A-Z can be encoded into numbers using the following mapping:
'A' -> "1", 'B' -> "2", ..., 'Z' -> "26".

To decode an encoded message, all the digits must be grouped then mapped back into letters using the reverse of the mapping above (there may be multiple ways). For example, "11106" can be mapped into:
• "AAJF" with the grouping (1 1 10 6)
• "KJF" with the grouping (11 10 6)
Note that the grouping (1 11 06) is invalid because "06" cannot be mapped into 'F' since "6" is different from "06".

Given a string s containing only digits, return the number of ways to decode it.

Example 1: s = "12" → Output: 2

Example 2: s = "226" → Output: 3

Example 3: s = "06" → Output: 0

Plain-English Translation & Core Nuance

Count how many valid ways a string of digits can be sliced into 1-digit ('1'..'9') and 2-digit ('10'..'26') letter codes. Watch out for '0': '0' can NEVER stand alone, and can only survive as the second digit of '10' or '20'.

Official Constraints:
  • 1 <= s.length <= 100
  • s contains only digits and may contain leading zero(s).

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
s starts with '0' (e.g. "0" or "06") -> 0 valid ways! Immediately return 0.
Best-Case Early Exit
s = "10" -> Only 1 way ('J'), because '0' cannot be decoded alone.
Worst-Case Full Scan
s = "111111..." -> Fibonacci growth where every step branches into both 1-digit and 2-digit decodings.

The Mental Model & "Explain Like I'm 12"

💡 Climbing Stairs with Locked '0' Steps

Decode Ways is identical to Climbing Stairs (where you can take a 1-digit step or a 2-digit step), EXCEPT some steps are booby-trapped! A 1-digit step from index i is only legal if s[i] != '0' (since '1'..'9' are valid). A 2-digit step from index i-1 to i+1 is only legal if the two digits form a number between 10 and 26 (i.e., s[i-1] is '1', or s[i-1] is '2' and s[i] <= '6').

The Mental "A-Ha!" Switch:

At each position i, ways[i] = (ways[i-1] if s[i] != '0' else 0) + (ways[i-2] if s[i-1..i] in 10..26 else 0). And since we only look back 2 steps, we only need two integer variables!

Pattern Trigger:

Counting valid ways to partition a string into 1-char or 2-char tokens under validity rules.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(2^N) Time, O(N) Space

Recursively branch at index i into decode(i + 1) and decode(i + 2) without memoization.

Wasted Work: On a string of 100 '1's, the recursion tree branches like Fibonacci F(100) ~ 3.5 x 10^20 calls.
The Optimal Breakthrough O(N) Time, O(1) Space

Track prev2 = 1 (empty prefix) and prev1 = 1 (after verifying s[0] != '0'). For i from 1 to n - 1, compute curr by adding prev1 (if s[i] != '0') and prev2 (if twoDigit in 10..26), then shift prev2 = prev1, prev1 = curr.

Core Invariant: At the end of iteration i, prev1 holds the exact number of valid decodings for prefix s[0..i].
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: Unmemoized Recursive Branching O(2^N) O(N) Exponential Fibonacci branching; TLE on length 45+.
Better: 1D DP Array (IntArray(N + 1)) O(N) O(N) Linear time, allocates O(N) array.
Optimal: Two-Variable Rolling DP O(N) O(1) ★ Constant space using only prev2 and prev1 registers.

Variables and containers maintained during execution:

  • prev2 (i-2) Tracks prev2 (i-2) across iterations (initial state: 1).
  • prev1 (i-1) Tracks prev1 (i-1) across iterations (initial state: 1).
  • curr Ways Tracks curr ways across iterations (initial state: 1).
2. Step-by-Step Non-Code Algorithm Walkthrough
1. Guard Clauses & State Initialization

Before entering the main loop, verify base boundaries (s starts with '0' (e.g. "0" or "06") -> 0 valid ways! Immediately return 0.) and allocate the primary state containers required for Decode Ways so that subsequent lookups or pointer updates run in O(1) time.

2. Core Traversal & Decision Rule

Track prev2 = 1 (empty prefix) and prev1 = 1 (after verifying s[0] != '0'). For i from 1 to n - 1, compute curr by adding prev1 (if s[i] != '0') and prev2 (if twoDigit in 10..26), then shift prev2 = prev1, prev1 = curr. At each step, instead of re-scanning elements we already visited, we use our maintained state to make an immediate local decision.

3. Invariant Maintenance & State Transition

First, if s[0] == '0' we return 0 immediately. Otherwise we set prev2 = 1 and prev1 = 1. Looping i from 1 to s.lastIndex, curr starts at prev1 if s[i] != '0' else 0. Then we compute twoDigits = (s[i-1] - '0') * 10 + (s[i] - '0'); if twoDigits is in 10..26, we add prev2 to curr. Finally we shift prev2 = prev1 and prev1 = curr. Throughout every transition, we preserve the core invariant: At the end of iteration i, prev1 holds the exact number of valid decodings for prefix s[0..i].

4. Termination & Output Guarantee

Check for early-exit conditions (s = "10" -> Only 1 way ('J'), because '0' cannot be decoded alone.). Once traversal completes, return the accumulated result. If s = "206", at i=1 ('0') the 1-digit check is 0 and the 2-digit check ("20") adds prev2 (1) -> curr = 1. Then at i=2 ('6'), 1-digit adds 1 and 2-digit ("06") adds 0 -> total 1!

Approach 1: 1D DP Array (Bottom-Up Prefix Table)

Maintain dp[i] = number of ways to decode prefix of length i, checking 1-digit and 2-digit transitions.

Time: O(N) Space: O(N) 
class Solution {
    fun numDecodings(s: String): Int {
        if (s.isEmpty() || s[0] == '0') return 0
        val n = s.length
        val dp = IntArray(n + 1)
        dp[0] = 1
        dp[1] = 1

        for (i in 2..n) {
            val oneDigit = s[i - 1] - '0'
            val twoDigits = (s[i - 2] - '0') * 10 + oneDigit
            if (oneDigit in 1..9) {
                dp[i] += dp[i - 1]
            }
            if (twoDigits in 10..26) {
                dp[i] += dp[i - 2]
            }
        }
        return dp[n]
    }
}
Kotlin Runtime & Memory Nuance:

Clear 1-indexed prefix state where dp[0] = 1 represents the empty prefix base case.

class Solution:
    def numDecodings(self, s: str) -> int:
        if not s or s[0] == '0':
            return 0
        n = len(s)
        dp = [0] * (n + 1)
        dp[0] = 1
        dp[1] = 1

        for i in range(2, n + 1):
            if s[i - 1] != '0':
                dp[i] += dp[i - 1]
            two_digit = int(s[i - 2 : i])
            if 10 <= two_digit <= 26:
                dp[i] += dp[i - 2]
        return dp[n]
Python Runtime & Memory Nuance:

Allocates an O(N) list when only the last 2 states are ever read.

class Solution {
    public int numDecodings(String s) {
        if (s == null || s.isEmpty() || s.charAt(0) == '0') return 0;
        int n = s.length();
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {
            int oneDigit = s.charAt(i - 1) - '0';
            int twoDigits = (s.charAt(i - 2) - '0') * 10 + oneDigit;
            if (oneDigit >= 1) dp[i] += dp[i - 1];
            if (twoDigits >= 10 && twoDigits <= 26) dp[i] += dp[i - 2];
        }
        return dp[n];
    }
}
Java Runtime & Memory Nuance:

Char arithmetic (s.charAt(i) - '0') avoids Integer.parseInt substring allocations.

Approach 2: Two-Variable Rolling DP (O(1) Space)

Compress dp[i-2] and dp[i-1] into two scalar integers prev2 and prev1.

Time: O(N) Space: O(1) 
class Solution {
    fun numDecodings(s: String): Int {
        if (s.isEmpty() || s[0] == '0') return 0
        var prev2 = 1
        var prev1 = 1

        for (i in 1 until s.length) {
            var curr = if (s[i] != '0') prev1 else 0
            val twoDigits = (s[i - 1] - '0') * 10 + (s[i] - '0')
            if (twoDigits in 10..26) {
                curr += prev2
            }
            prev2 = prev1
            prev1 = curr
        }
        return prev1
    }
}
Kotlin Runtime & Memory Nuance:

If an un-decodable '00' or '30' occurs, curr becomes 0 and naturally propagates 0 to the end.

class Solution:
    def numDecodings(self, s: str) -> int:

Tuple swap prev2, prev1 = prev1, curr updates state in O(1) registers.

class Solution {
    public int numDecodings(String s) {
        if (s == null || s.isEmpty() || s.charAt(0) == '0') return 0;
        int prev2 = 1;
        int prev1 = 1;

        for (int i = 1; i < s.length(); i++) {
            int curr = (s.charAt(i) != '0') ? prev1 : 0;
            int twoDigits = (s.charAt(i - 1) - '0') * 10 + (s.charAt(i) - '0');
            if (twoDigits >= 10 && twoDigits <= 26) {
                curr += prev2;
            }
            prev2 = prev1;
            prev1 = curr;
        }
        return prev1;
    }
}
Java Runtime & Memory Nuance:

Zero heap allocations; runs in O(N) time and O(1) auxiliary memory.
