LeetCode #207: Course Schedule

Official LC #207

Official Problem Statement

There are a total of numCourses courses you have to take, labeled from 0 to numCourses - 1. You are given an array prerequisites where prerequisites[i] = [ai, bi] indicates that you must take course bi first if you want to take course ai.

For example, the pair [0, 1], indicates that to take course 0 you have to first take course 1.

Return true if you can finish all courses. Otherwise, return false.

Example 1: numCourses = 2, prerequisites = [[1,0]] → Output: true Explanation: There are a total of 2 courses to take. To take course 1 you should have finished course 0. So it is possible.

Example 2: numCourses = 2, prerequisites = [[1,0],[0,1]] → Output: false Explanation: There are a total of 2 courses to take. To take course 1 you should have finished course 0, and to take course 0 you should also have finished course 1. So it is impossible.

Plain-English Translation & Core Nuance

This is cycle detection in a directed graph. Courses are vertices, and each prerequisite `[a, b]` is a directed edge `b -> a` (course `b` must precede course `a`). You can finish all courses if and only if there are no directed cycles (the graph is a Directed Acyclic Graph, or DAG). We can solve this with Kahn's Algorithm (BFS topological sort): count the in-degree (number of prerequisites) for every course. Add courses with in-degree 0 to a queue. Dequeue each course, increment our completed count, and decrement the in-degree of its outgoing neighbors. Any neighbor whose in-degree drops to 0 is enqueued. If completed courses equals `numCourses`, return true; otherwise a cycle blocked progress, return false.

Official Constraints:
  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= 5000
  • prerequisites[i].length == 2
  • 0 <= ai, bi < numCourses
  • All the pairs prerequisites[i] are unique.

💡 College Degree Prerequisite Tree

Think of your university syllabus. Freshman year, you can only enroll in courses that have ZERO prerequisites (in-degree 0), like Math 101 and CS 101. Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(V * (V + E)) Time, O(V) Space

Run DFS from every single vertex independently to search for a back-edge to an ancestor.

Wasted Work: Re-traversing overlapping directed paths multiple times without memoizing completed components.
The Optimal Breakthrough O(V + E) Time, O(V + E) Space

Kahn's Algorithm (BFS) or 3-color DFS. Processes every vertex and edge exactly once.

Core Invariant: Only courses whose prerequisites have all been completely resolved (in-degree == 0) enter the queue.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
DFS with 3 States (White/Gray/Black) O(V + E) O(V + E) Recursion detects back-edges (Gray → Gray).

Kahn's Algorithm (BFS with In-Degree)

Count prerequisite in-degrees. Seed queue with in-degree 0 courses. Pop and decrement neighbor in-degrees, pushing to queue when 0. If processed count equals `numCourses`, no cycles exist.

Time: O(V + E) Time Space: O(V + E) Space 
class Solution {
    fun canFinish(numCourses: Int, prerequisites: Array<IntArray>): Boolean {
        val inDegree = IntArray(numCourses)
        val adj = Array(numCourses) { mutableListOf<Int>() }

        // prereq: [course, prereq] -> edge: prereq -> course
        for (edge in prerequisites) {
            val course = edge[0]
            val pre = edge[1]
            adj[pre].add(course)
            inDegree[course]++
        }

        val queue = ArrayDeque<Int>()
        for (i in 0 until numCourses) {
            if (inDegree[i] == 0) {
                queue.add(i)
            }
        }

        var completed = 0
        while (queue.isNotEmpty()) {
            val curr = queue.removeFirst()
            completed++

            for (neighbor in adj[curr]) {
                inDegree[neighbor]--
                if (inDegree[neighbor] == 0) {
                    queue.add(neighbor)
                }
            }
        }

        return completed == numCourses
    }
}

from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        in_degree = [0] * numCourses
        adj = [[] for _ in range(numCourses)]
        
        for course, pre in prerequisites:
            adj[pre].append(course)
            in_degree[course] += 1
            
        queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
        completed = 0
        
        while queue:
            curr = queue.popleft()
            completed += 1
            
            for neighbor in adj[curr]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
                    
        return completed == numCourses

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        int[] inDegree = new int[numCourses];
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        for (int[] p : prerequisites) {
            int course = p[0];
            int pre = p[1];
            adj.get(pre).add(course);
            inDegree[course]++;
        }

        Queue<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }

        int completed = 0;
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            completed++;

            for (int neighbor : adj.get(curr)) {
                if (--inDegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        return completed == numCourses;
    }
}
