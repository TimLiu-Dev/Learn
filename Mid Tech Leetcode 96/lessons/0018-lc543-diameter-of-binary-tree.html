LeetCode 543: Diameter of Binary Tree

Official LC #543

Official Problem Statement

Given the root of a binary tree, return the length of the diameter of the tree.

The diameter of a binary tree is the length of the longest path between any two nodes in a tree. This path may or may not pass through the root.

The length of a path between two nodes is represented by the number of edges between them.

Example 1: root = [1,2,3,4,5] → Output: 3 (Path [4,2,1,3] or [5,2,1,3] has 3 edges)

Example 2: root = [1,2] → Output: 1

Plain-English Translation & Core Nuance

Find the maximum distance (counted in edges) between any two nodes in the tree. The longest path does not necessarily pass through the tree root!

⚠️ Root Assumption Trap: If a tree has a massive left subtree with two deep branches, the longest path lives entirely inside the left subtree! At every node, the longest path arching through that node is:
diameterThroughNode = leftHeight + rightHeight.
Input Constraints

Node count: [1, 10,000]

-100 ≤ Node.val ≤ 100

Single pass O(N) runtime expected by senior interviewers.

Single Node (Zero Edges)

root = [1] → Output: 0

0 edges between a node and itself.

Leaves have leftHeight=0 and rightHeight=0, diameter = 0.

Path Bypassing Root

Deep left subtree with 2 long branches

Root only has 1 shallow right node.

Global max variable catches diameter inside subtrees.

Conceptual Architecture

Physical Mental Model: The Mountain Ridge Pass

⛰️

Apex Mountain Summit and Valley Trails

Every node in a binary tree is a candidate mountain pass (apex):

  • Hiker climbs up from the deepest valley on the left (leftHeight steps).
  • Hiker reaches the summit node (apex).
  • Hiker descends into the deepest valley on the right (rightHeight steps).
  • Total trail length through this summit is leftHeight + rightHeight edges!
  • When reporting to parent mountain, the summit can only offer one single ridge: $1 + \max(leftHeight, rightHeight)$!
⚡

Pattern Trigger Signals & Sister Problems

Signal 1: "Longest path between any two nodes in tree." → Post-Order DFS with Global Max (leftHeight + rightHeight).
Signal 2: LeetCode 124 (Binary Tree Maximum Path Sum) → Directly extends this kernel by summing node values instead of counting edges, ignoring negative branches.
Signal 3: LeetCode 687 (Longest Univalue Path) → Adds univalue matching filter to left and right arms.
Strategic Contrast

Naive Trap vs. Optimal Breakthrough

❌

The Naive Trap: Redundant O(N^2) Height Recomputations

Calling a separate maxDepth() subroutine for every node in the tree. Because calculating height takes O(N) and is repeated for all N nodes, total runtime balloons to \mathcal{O}(N^2).

• Time Complexity: O(N^2) on skewed trees

• Massive redundant recalculations on descendant nodes

✅

The Breakthrough: Single-Pass Post-Order DFS

Combine depth calculation and diameter tracking in one single traversal! As bottom-up heights return, update maxDiameter = max(maxDiameter, leftH + rightH) and return 1 + max(leftH, rightH).

• Time Complexity: O(N) — Each node visited once

• Space Complexity: O(H) on call stack

• Dual duty: Returns branch height upward while recording curve diameter globally.

Approach Time Space Visits per Node Tradeoff Summary
1. Recompute Height at Each Node O(N^2) O(H) O(N) Repeatedly recurses over subtrees, timing out on 10,000 nodes.
2. Iterative Post-Order + Height Map O(N) O(N) 1 Iterative, but requires a HashMap storing heights for every TreeNode.
3. Single-Pass Post-Order DFS (Optimal) O(N) O(H) 1 Senior standard. Updates global max diameter while bubbling up branch depth.

From Quadratic Depth Recomputations to Single-Pass Post-Order DFS

Approach 1: Naive Height Recalculation O(N^2)

For each node, calls a separate height() function on left and right children, then recursively tests left and right subtrees. Extremely slow on degenerate trees.

Time: O(N^2) Space: O(H) 
class Solution {
    fun diameterOfBinaryTree(root: TreeNode?): Int {
        if (root == null) return 0
        val current = height(root.left) + height(root.right)
        val leftDiameter = diameterOfBinaryTree(root.left)
        val rightDiameter = diameterOfBinaryTree(root.right)
        return maxOf(current, maxOf(leftDiameter, rightDiameter))
    }
    
    private fun height(node: TreeNode?): Int {
        if (node == null) return 0
        return 1 + maxOf(height(node.left), height(node.right))
    }
}
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        def height(node):
            if not node: return 0
            return 1 + max(height(node.left), height(node.right))
            
        current = height(root.left) + height(root.right)
        return max(current, self.diameterOfBinaryTree(root.left), self.diameterOfBinaryTree(root.right))
class Solution {
    public int diameterOfBinaryTree(TreeNode root) {
        if (root == null) return 0;
        int current = height(root.left) + height(root.right);
        int leftD = diameterOfBinaryTree(root.left);
        int rightD = diameterOfBinaryTree(root.right);
        return Math.max(current, Math.max(leftD, rightD));
    }
    
    private int height(TreeNode node) {
        if (node == null) return 0;
        return 1 + Math.max(height(node.left), height(node.right));
    }
}

Approach 2: Iterative Post-Order with Node-Height Map

Performs an iterative post-order traversal using a Stack. Stores computed heights in a HashMap<TreeNode, Int>, updating global max diameter as nodes are popped.

Time: O(N) Space: O(N) Map + Stack 
class Solution {
    fun diameterOfBinaryTree(root: TreeNode?): Int {
        if (root == null) return 0
        val heightMap = HashMap<TreeNode, Int>()
        val stack = java.util.ArrayDeque<TreeNode>()
        var curr = root
        var lastVisited: TreeNode? = null
        var maxDiameter = 0
        
        while (curr != null || stack.isNotEmpty()) {
            while (curr != null) { stack.push(curr); curr = curr.left }
            val peek = stack.peek()
            if (peek.right != null && lastVisited != peek.right) {
                curr = peek.right
            } else {
                stack.pop()
                val leftH = heightMap[peek.left] ?: 0
                val rightH = heightMap[peek.right] ?: 0
                maxDiameter = maxOf(maxDiameter, leftH + rightH)
                heightMap[peek] = 1 + maxOf(leftH, rightH)
                lastVisited = peek
            }
        }
        return maxDiameter
    }
}
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        if not root: return 0
        height_map = {}
        stack = []
        curr = root
        last = None
        max_d = 0
        while curr or stack:
            while curr:
                stack.append(curr)
                curr = curr.left
            peek = stack[-1]
            if peek.right and last != peek.right:
                curr = peek.right
            else:
                stack.pop()
                left_h = height_map.get(peek.left, 0)
                right_h = height_map.get(peek.right, 0)
                max_d = max(max_d, left_h + right_h)
                height_map[peek] = 1 + max(left_h, right_h)
                last = peek
        return max_d
class Solution {
    public int diameterOfBinaryTree(TreeNode root) {
        if (root == null) return 0;
        Map<TreeNode, Integer> heightMap = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode curr = root, last = null;
        int maxD = 0;
        
        while (curr != null || !stack.isEmpty()) {
            while (curr != null) { stack.push(curr); curr = curr.left; }
            TreeNode peek = stack.peek();
            if (peek.right != null && last != peek.right) {
                curr = peek.right;
            } else {
                stack.pop();
                int leftH = heightMap.getOrDefault(peek.left, 0);
                int rightH = heightMap.getOrDefault(peek.right, 0);
                maxD = Math.max(maxD, leftH + rightH);
                heightMap.put(peek, 1 + Math.max(leftH, rightH));
                last = peek;
            }
        }
        return maxD;
    }
}

Approach 3: Single-Pass Post-Order DFS (Production Optimal)

INTERVIEW DEFAULT

The canonical senior solution. Simultaneously computes height and records the maximum diameter in a single post-order pass.

Time: O(N) Space: O(H) 
class Solution {
    private var maxDiameter = 0
    
    fun diameterOfBinaryTree(root: TreeNode?): Int {
        maxDiameter = 0
        dfsHeight(root)
        return maxDiameter
    }
    
    private fun dfsHeight(node: TreeNode?): Int {
        if (node == null) return 0
        
        val leftH = dfsHeight(node.left)
        val rightH = dfsHeight(node.right)
        
        // Longest path passing through this node as apex
        maxDiameter = maxOf(maxDiameter, leftH + rightH)
        
        // Return height to parent (only one branch can be chosen)
        return 1 + maxOf(leftH, rightH)
    }
}
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        max_diameter = 0
        
        def dfs(node: Optional[TreeNode]) -> int:
            nonlocal max_diameter
            if not node:
                return 0
            left_h = dfs(node.left)
            right_h = dfs(node.right)
            
            max_diameter = max(max_diameter, left_h + right_h)
            return 1 + max(left_h, right_h)
            
        dfs(root)
        return max_diameter
class Solution {
    private int maxDiameter = 0;
    
    public int diameterOfBinaryTree(TreeNode root) {
        maxDiameter = 0;
        dfsHeight(root);
        return maxDiameter;
    }
    
    private int dfsHeight(TreeNode node) {
        if (node == null) return 0;
        
        int leftH = dfsHeight(node.left);
        int rightH = dfsHeight(node.right);
        
        maxDiameter = Math.max(maxDiameter, leftH + rightH);
        
        return 1 + Math.max(leftH, rightH);
    }
}

            1. Generalized Tree Diameter (N-ary Trees & Network Routing):
            

              In computer network topology graphs (Spanning Trees in OSPF / BGP), the diameter represents the worst-case packet propagation latency across the network. For N-ary trees, maintain the top-2 largest branch depths at each node: diameter = max_1 + max_2.
            

          

          

            2. Maximum Path Sum (LeetCode #124 Hard):
            

              This exact algorithm forms the architectural foundation for LeetCode 124. Instead of adding 1 for edge count, add `node.val` and truncate negative branches with `max(0, dfs(child))`.
