LeetCode #1396: Design Underground System

Official LC #1396

Official Problem Statement

An underground railway system is keeping track of customer travel times between different stations. They are using this data to calculate the average time it takes to travel from one station to another.

Implement the UndergroundSystem class:

  • void checkIn(int id, string stationName, int t)
    • A customer with a card ID equal to id, checks in at the station stationName at time t.
    • A customer can only be checked into one place at a time.
  • void checkOut(int id, string stationName, int t)
    • A customer with a card ID equal to id, checks out from the station stationName at time t.
  • double getAverageTime(string startStation, string endStation)
    • Returns the average time it takes to travel from startStation to endStation.
    • The average time is computed from all the previous traveling times between startStation and endStation that have happened directly, meaning a check in at startStation followed by a check out from endStation.

Example 1: checkIn(45,"Leyton",3), checkIn(32,"Paradise",8), checkIn(27,"Leyton",10), checkOut(45,"Waterloo",15), checkOut(27,"Waterloo",20), checkOut(32,"Cambridge",22), getAverageTime("Paradise","Cambridge") → Output: 14.0 (22 - 8 = 14)

Plain-English Translation & Core Nuance

Track transit travel durations between stations. When a passenger checks in, store their active trip (startStation, startTime). When they check out, retrieve and remove their check-in, compute the trip duration, and update the aggregate stats (totalDuration, totalTrips) for that route (startStation -> endStation). getAverageTime returns totalDuration / totalTrips in O(1) time.

Official Constraints:
  • 1 <= id, t <= 10^6
  • 1 <= stationName.length, startStation.length, endStation.length <= 10
  • All strings consist of uppercase and lowercase English letters and digits.
  • There will be at most 2 * 10^4 calls in total to checkIn, checkOut, and getAverageTime.
  • Answers within 10^-5 of the actual value will be accepted.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case

Best-Case Early Exit

The Mental Model & "Explain Like I'm 12"

💡 The Metro Turnstile Ledger

Think of a subway station turnstile. When you tap in, the system writes a temporary post-it note: [Card 45: Station 'Leyton' at 3:00 PM]. When you tap out at 'Waterloo' at 3:15 PM, the exit turnstile takes down your post-it, calculates 15 minutes, throws away the post-it, and updates a permanent tally board labeled 'Leyton → Waterloo': +15 minutes, +1 trip. To find the average time, the station manager just divides the board's total minutes by the trip count.

The Mental "A-Ha!" Switch:

Two distinct HashMaps: 1) `checkInMap` tracking in-flight passenger trips; 2) `routeStatsMap` tracking running totals. When checkOut occurs, delete from checkInMap to prevent memory leaks.

Pattern Trigger:

Whenever computing real-time aggregations (averages, counts) between start and end events → Active-Event Map + Aggregate-Stats Map.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap checkIn: O(1), checkOut: O(1), getAverageTime: O(TotalTrips)

Store every completed trip in a massive list. In getAverageTime, linearly iterate through all historical trips filtering by startStation and endStation.

Wasted Work: Re-calculating the sum and count of matching trips on every query instead of maintaining pre-aggregated running stats.
The Optimal Breakthrough All operations strictly O(1) Time, O(P + R) Space

checkOut updates running sum and count on the route. getAverageTime divides sum / count in O(1) time.

Core Invariant: checkInMap holds strictly in-flight journeys; routeStatsMap holds precomputed (sum, count) for each route.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Historical Trips List getAverageTime: O(N) O(N) Scans all completed trips on every query.
★ 2. Two HashMaps (Pre-Aggregated) All O(1) O(P + R) O(1) lookups; memory evicted on checkout.

Two HashMaps with Composite String Key

checkInMap for passenger state, routeMap with 'startStation->endStation' key.

Time: All operations O(1) Space: O(P + R) where P is active passengers, R is routes 
class UndergroundSystem() {
    private data class CheckIn(val station: String, val time: Int)
    private data class RouteStats(var totalTime: Long, var count: Int)

    private val checkIns = HashMap<Int, CheckIn>()
    private val routes = HashMap<String, RouteStats>()

    fun checkIn(id: Int, stationName: String, t: Int) {
        checkIns[id] = CheckIn(stationName, t)
    }

    fun checkOut(id: Int, stationName: String, t: Int) {
        val start = checkIns.remove(id) ?: return
        val routeKey = "${start.station}->$stationName"
        val stats = routes.getOrPut(routeKey) { RouteStats(0L, 0) }
        stats.totalTime += (t - start.time)
        stats.count++
    }

    fun getAverageTime(startStation: String, endStation: String): Double {
        val stats = routes["startStation->endStation"] ?: return 0.0
        return stats.totalTime.toDouble() / stats.count
    }
}

class UndergroundSystem:
    def __init__(self):
        self.check_ins = {}  # id -> (station, time)
        self.routes = {}     # (start, end) -> [total_time, count]

    def checkIn(self, id: int, stationName: str, t: int) -> None:
        self.check_ins[id] = (stationName, t)

    def checkOut(self, id: int, stationName: str, t: int) -> None:
        start_station, start_time = self.check_ins.pop(id)
        route_key = (start_station, stationName)
        duration = t - start_time
        
        if route_key not in self.routes:
            self.routes[route_key] = [0, 0]
        self.routes[route_key][0] += duration
        self.routes[route_key][1] += 1

    def getAverageTime(self, startStation: str, endStation: str) -> float:
        total_time, count = self.routes[(startStation, endStation)]
        return total_time / count

import java.util.HashMap;
import java.util.Map;

class UndergroundSystem {
    private static class CheckIn {
        final String station;
        final int time;
        CheckIn(String station, int time) {
            this.station = station;
            this.time = time;
        }
    }

    private static class RouteStats {
        long totalTime = 0;
        int count = 0;
    }

    private final Map<Integer, CheckIn> checkIns = new HashMap<>();
    private final Map<String, RouteStats> routes = new HashMap<>();

    public UndergroundSystem() {}

    public void checkIn(int id, String stationName, int t) {
        checkIns.put(id, new CheckIn(stationName, t));
    }

    public void checkOut(int id, String stationName, int t) {
        CheckIn start = checkIns.remove(id);
        if (start == null) return;
        String routeKey = start.station + "->" + stationName;
        RouteStats stats = routes.computeIfAbsent(routeKey, k -> new RouteStats());
        stats.totalTime += (t - start.time);
        stats.count++;
    }

    public double getAverageTime(String startStation, String endStation) {
        RouteStats stats = routes.get(startStation + "->" + endStation);
        if (stats == null || stats.count == 0) return 0.0;
        return (double) stats.totalTime / stats.count;
    }
}

import java.util.HashMap;
import java.util.Map;

class UndergroundSystem {
    private final Map<Integer, Object[]> checkIns = new HashMap<>();
    private final Map<String, double[]> routes = new HashMap<>();

    public void checkIn(int id, String stationName, int t) {
        checkIns.put(id, new Object[]{stationName, t});
    }

    public void checkOut(int id, String stationName, int t) {
        Object[] start = checkIns.remove(id);
        String key = (String) start[0] + "->" + stationName;
        double duration = t - (int) start[1];
        double[] stats = routes.computeIfAbsent(key, k -> new double[2]);
        stats[0] += duration;
        stats[1] += 1.0;
    }

    public double getAverageTime(String startStation, String endStation) {
        double[] stats = routes.get(startStation + "->" + endStation);
        return stats[0] / stats[1];
    }
}

Optimal: Domain-Driven Object Entities with Immutability

Production gold standard with strict domain models (PassengerTrip & RouteAggregator).

Time: All operations O(1) Space: O(P + R) 
class UndergroundSystem() {
    /**
     * Optimal: Domain-Driven Two-Map Architecture
     * Time: All operations O(1)
     * Space: O(Passengers + Routes)
     */
    private class ActiveTrip(val origin: String, val departureTime: Int)

    private class RouteMetric {
        var cumulativeTime: Long = 0L
        var tripCount: Int = 0

        fun record(duration: Int) {
            cumulativeTime += duration
            tripCount++
        }

        fun average(): Double = cumulativeTime.toDouble() / tripCount
    }

    private val inFlightTrips = HashMap<Int, ActiveTrip>()
    private val routeMetrics = HashMap<String, RouteMetric>()

    fun checkIn(id: Int, stationName: String, t: Int) {
        inFlightTrips[id] = ActiveTrip(stationName, t)
    }

    fun checkOut(id: Int, stationName: String, t: Int) {
        val trip = inFlightTrips.remove(id) ?: return
        val key = trip.origin + "->" + stationName
        routeMetrics.getOrPut(key) { RouteMetric() }.record(t - trip.departureTime)
    }

    fun getAverageTime(startStation: String, endStation: String): Double {
        return routeMetrics[startStation + "->" + endStation]?.average() ?: 0.0
    }
}

            self.total = 0
            self.count = 0

            self.total += duration
            self.count += 1
        def average(self) -> float:
            return self.total / self.count

        self.active_trips = {}
        self.metrics = {}

import java.util.HashMap;
import java.util.Map;

class UndergroundSystem {
    /**
     * Optimal: Domain Entity Encapsulation
     * Time: All operations O(1)
     * Space: O(P + R)
     */
    private static class ActiveTrip {
        final String station;
        final int time;
        ActiveTrip(String station, int time) {
            this.station = station;
            this.time = time;
        }
    }

    private static class RouteMetric {
        long totalDuration = 0L;
        int tripCount = 0;

        void record(int duration) {
            totalDuration += duration;
            tripCount++;
        }

        double getAverage() {
            return (double) totalDuration / tripCount;
        }
    }

    private final Map<Integer, ActiveTrip> activeTrips = new HashMap<>();
    private final Map<String, RouteMetric> routeMetrics = new HashMap<>();

    public void checkIn(int id, String stationName, int t) {
        activeTrips.put(id, new ActiveTrip(stationName, t));
    }

    public void checkOut(int id, String stationName, int t) {
        ActiveTrip trip = activeTrips.remove(id);
        if (trip == null) return;
        String key = trip.station + "->" + stationName;
        routeMetrics.computeIfAbsent(key, k -> new RouteMetric()).record(t - trip.time);
    }

    public double getAverageTime(String startStation, String endStation) {
        RouteMetric metric = routeMetrics.get(startStation + "->" + endStation);
        return (metric != null) ? metric.getAverage() : 0.0;
    }
}

"For strategy: saving all completed trips to a list would require O(N) linear filtering for every getAverageTime call.           Phase 3: Live Coding Narrative
          
"In checkIn, I put (station, time) in checkInMap. In checkOut, I remove the entry by id to avoid memory leaks, calculate duration = t - checkIn.time, and update totalTime += duration and count++ in routeStatsMap. In getAverageTime, I read the route object in O(1) time and return totalTime / count."

"Dry running edge cases: a passenger checking out must remove their ID from checkInMap so if they travel again tomorrow with the same card ID, old state won't interfere.
