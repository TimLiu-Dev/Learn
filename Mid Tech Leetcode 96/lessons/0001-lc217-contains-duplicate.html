Contains Duplicate

View on LeetCode ↗

Problem Description

Given an integer array nums, return true if any value appears at least twice in the array, and return false if every element is distinct.

🗣️
Plain-English Translation:

"Are there any duplicate twins in this list? If even a single number appears twice, immediately return true. If every number is 100% unique, return false."

Official Examples

Example 1:
Input: nums = [1,2,3,1]
Output: true
Element 1 occurs at index 0 and 3.
Example 2:
Input: nums = [1,2,3,4]
Output: false
All elements are distinct.
Example 3:
Input: nums = [1,1,1,3,3,4,3,2,4,2]
Output: true
Multiple duplicate clusters exist.
Official Constraints:
  • 1 ≤ nums.length ≤ 10⁵ (N is up to 100,000 → O(N²) quadratic loops will TLE)
  • -10⁹ ≤ nums[i] ≤ 10⁹ (Values span negative and positive 32-bit signed range)
The 3 Canonical Input Shapes (Mental Boundary Checks):
1. Minimum Base Case
nums = [42]
Length = 1. A single element can never contain duplicates. Guaranteed false in O(1).
2. Best-Case Early Exit
nums = [7, 7, 1, 2, 3]
Duplicate appears at index 1. Algorithm halts on 2nd step, avoiding scanning the remaining elements.
3. Worst-Case Full Scan
nums = [1, 2, 3, ... 10⁵]
All elements distinct. Forces full linear traversal and hash set reaches max O(N) capacity.

The Mental Model & "Explain Like I'm 12"

🏰 The Real-World Analogy

The VIP Nightclub Bouncer & The Stamp Checklist

Imagine you are a bouncer guarding the front door of a crowded VIP party. Guests arrive one by one, each wearing a numbered sports jersey. Your job is simple: sound the alarm the moment anyone tries to enter who has already entered before.

The naive bouncer lets a guest in, but for every new arrival, walks into the dark, crowded dance floor and compares the newcomer against every single person dancing inside. If there are 1,000 guests, that bouncer makes hundreds of thousands of exhausting comparisons.

The master bouncer keeps a digital tablet with a checklist (HashSet) right at the door. When guest #17 walks up:

  1. Look at the tablet: is #17 checked?
  2. If YES: Stop them immediately! Duplicate detected (return true).
  3. If NO: Check off #17 in O(1) time, let them in, and look at the next person.
💡 The "A-Ha!" Switch

Stop Searching Forward; Store What You've Seen

Beginners mentally search forward into the future array ("Does any later element match this one?"). The algorithmic breakthrough is to look backward at a persistent memory record. As you step through each element, the only question you ask is: "Did I already record this in my seen set?"

02
Algorithmic Contrast

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Brute Force Trap O(N²) Time • O(1) Space

The Nested Loop Pair-Scanner

The candidate nests two loops, checking every pair (i, j): 

for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        // ❌ CPU CYCLES WASTED HERE:
        // Comparing nums[i] with elements already 
        // proven unique against earlier entries!
        if (nums[i] == nums[j]) return true;
    }
}
return false;
Why it fails in mid-tech interviews:

For N = 100,000, N(N - 1) / 2 ≈ 5 × 10⁹ operations. At standard CPU throughput (10⁸ ops/sec), this takes 50 seconds. The platform terminates with Time Limit Exceeded (TLE).

The Optimal Breakthrough O(N) Time • O(N) Space

The One-Pass HashSet Memory Trade

We purchase O(N) auxiliary memory to reduce the lookup time of previously seen items from O(N) to O(1): 

val seen = hashSetOf<Int>()
for (num in nums) {
    // ✅ O(1) Hash Bucket Lookup:
    if (!seen.add(num)) {
        return true // Duplicate found immediately!
    }
}
return false
The Space-Time Bargain:

For N = 100,000, storing 100,000 integers consumes only ~4MB of RAM. In exchange, the execution finishes in 15 milliseconds. A 3,000x speedup!

Asymptotic Trade-off Matrix Target Bound: O(N) Time
Approach Best Time Average Time Worst Time Space Complexity Interview Verdict
1. Brute Force (Nested Loops) O(1) O(N²) O(N²) O(1) ❌ Rejected (TLE on large inputs)
2. Sorting + Adjacent Scan O(N log N) O(N log N) O(N log N) O(1) or O(N)* ⚠️ Suboptimal (Mutates array, slower)
3. Optimal: One-Pass HashSet O(1) O(N) O(N) O(N) ✅ Optimal Production Standard
*Note: In-place sort mutates the input array, violating API immutability contracts in production environments.

Solution Evolution & Production Code

From Brute Force to Optimal & Runnable Practice Arena

Approach:
Time: O(N) | Space: O(N) • ★ Production Standard 
class Solution {
    /**
     * Approach 1: Brute Force (Nested Loops)
     * Time: O(N²) - Compares all N*(N-1)/2 pairs.
     * Space: O(1) - Zero memory allocation.
     * LeetCode Status: Time Limit Exceeded on N = 100,000.
     */
    fun containsDuplicate(nums: IntArray): Boolean {
        val n = nums.size
        for (i in 0 until n) {
            for (j in i + 1 until n) {
                if (nums[i] == nums[j]) {
                    return true
                }
            }
        }
        return false
    }
}
Brute Force Engineering Tradeoff:
  • Why it exists: Requires zero heap allocation. Useful in tiny memory budgets (N < 50).
  • The Failure Point: Performs N(N - 1) / 2 comparisons (~5 × 10⁹ ops for N = 100,000), guaranteeing Time Limit Exceeded (TLE).
class Solution:
    """
    Approach 1: Brute Force (Nested Loops)
    Time: O(N²) - Quadratic pair comparisons.
    Space: O(1) - In-place index traversal.
    """
    def containsDuplicate(self, nums: list[int]) -> bool:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] == nums[j]:
                    return True
        return False
class Solution {
    /**
     * Approach 1: Brute Force (Nested Loops)
     * Time: O(N²) - Quadratic comparisons.
     * Space: O(1) - Primitive array traversal.
     */
    public boolean containsDuplicate(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] == nums[j]) {
                    return true;
                }
            }
        }
        return false;
    }
}
class Solution {
    /**
     * Approach 2: Better (In-Place Sorting & Adjacent Scan)
     * Time: O(N log N) - Dual-Pivot Quicksort + O(N) adjacent scan.
     * Space: O(1) - In-place primitive sort (or O(log N) recursion stack).
     */
    fun containsDuplicate(nums: IntArray): Boolean {
        nums.sort() // In-place Dual-Pivot Quicksort
        for (i in 1 until nums.size) {
            if (nums[i] == nums[i - 1]) {
                return true
            }
        }
        return false
    }
}
Sorting Tradeoff Analysis:
  • Memory Advantage: Avoids allocating an O(N) hash table. Crucial when heap allocation is strictly forbidden.
  • Production Caveat: Mutates the input array nums, which breaks caller immutability expectations.
class Solution:
    """
    Approach 2: Better (In-Place Sorting & Adjacent Scan)
    Time: O(N log N) - Built-in Timsort algorithm.
    Space: O(1) - In-place list sort.
    """
    def containsDuplicate(self, nums: list[int]) -> bool:
        nums.sort()
        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                return True
        return False
import java.util.Arrays;

class Solution {
    /**
     * Approach 2: Better (In-Place Sorting & Adjacent Scan)
     * Time: O(N log N) - Arrays.sort on primitives uses Dual-Pivot Quicksort.
     * Space: O(1) - In-place recursion call stack.
     */
    public boolean containsDuplicate(int[] nums) {
        Arrays.sort(nums);
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] == nums[i - 1]) {
                return true;
            }
        }
        return false;
    }
}
class Solution {
    /**
     * Approach 3: Optimal (One-Pass HashSet) - Production Gold Standard
     * Time: O(N) - Single linear pass with O(1) average lookup/insert.
     * Space: O(N) - Stores at most N distinct integers in HashSet.
     */
    fun containsDuplicate(nums: IntArray): Boolean {
        val seen = hashSetOf<Int>()

        for (num in nums) {
            // Set.add() returns false if element was ALREADY present
            if (!seen.add(num)) {
                return true
            }
        }

        return false
    }
}
Kotlin Mid-Level Engineering Breakdown:
  • nums: IntArray: Directly maps to Java unboxed primitive int[], avoiding object wrapping overhead during indexing.
  • !seen.add(num): Highly idiomatic in Kotlin. Atomically checks membership and inserts; returns false if already present without double lookup.
  • One-liner caution: nums.size != nums.distinct().count() is readable but always processes the entire array without early exit capability, wasting CPU cycles on early duplicates like [1, 1, ...].
class Solution:
    """
    Approach 3: Optimal (One-Pass HashSet) - Production Gold Standard
    Time: O(N) - Linear pass with O(1) amortized hash lookups.
    Space: O(N) - Stores up to N integers in Python set.
    """
    def containsDuplicate(self, nums: list[int]) -> bool:
        seen = set()
        for num in nums:
            if num in seen:
                return True
            seen.add(num)
        return False
import java.util.HashSet;
import java.util.Set;

class Solution {
    /**
     * Approach 3: Optimal (One-Pass HashSet) - Production Gold Standard
     * Time: O(N) - Single pass with O(1) amortized operations.
     * Space: O(N) - At most N entries in HashSet.
     */
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            if (!seen.add(num)) {
                return true;
            }
        }
        return false;
    }
}
