LeetCode #399: Evaluate Division

Official LC #399

Official Problem Statement

You are given an array of variable pairs equations and an array of real numbers values, where equations[i] = [Ai, Bi] and values[i] represent the equation Ai / Bi = values[i]. Each Ai or Bi is a string representing a single variable.

You are also given some queries, where queries[j] = [Cj, Dj] represents the j-th query where you must find the answer for Cj / Dj = ?.

Return the answers to all queries. If a single answer cannot be determined, return -1.0.

Example 1: equations = [['a','b'],['b','c']], values = [2.0,3.0], queries = [['a','c'],['b','a'],['a','e'],['a','a'],['x','x']] → Output: [6.0,0.5,-1.0,1.0,-1.0]

Plain-English Translation & Core Nuance

Given ratios between variables like a/b = 2 and b/c = 3, calculate queries like a/c. Think of this as a currency exchange graph: moving from 'a' to 'b' multiplies by 2, and moving from 'b' to 'a' multiplies by 1/2. To find a/c, find a path from a to c and multiply the edge weights along the path.

Official Constraints:
  • 1 <= equations.length <= 20
  • values.length == equations.length
  • 0.0 < values[i] <= 20.0
  • 1 <= queries.length <= 20
  • Ai, Bi, Cj, Dj consist of lowercase English letters and have length between 1 and 5

The Mental Model & "Explain Like I'm 12"

💡 The Foreign Currency Exchange Ledger

Suppose you know 1 USD = 0.9 EUR, and 1 EUR = 160 JPY. If someone asks for USD / JPY, you follow the exchange chain: USD -> EUR -> JPY, multiplying 0.9 * 160 = 144. If you want JPY / USD, you follow the reverse edges with reciprocal weights (1 / 144). If someone asks about Bitcoin and you have no exchange rate, the answer is undefined (-1.0).

The Mental "A-Ha!" Switch:

Model equations as a directed, weighted graph! For a/b = v, create edge a -> b with weight v, and reverse edge b -> a with weight 1/v. Querying c/d is just path search (DFS/BFS) multiplying weights!

Pattern Trigger:

Transitive ratio calculations or multi-step currency conversion rates.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(Q * (V + E)) Time, O(V + E) Space

Run DFS or BFS from start to end for each query independently.

Wasted Work: Re-explores the same graph paths for identical or redundant queries.
The Optimal Breakthrough O(Q * α(V) + (V + E)) with Union-Find or O(Q * (V + E)) with clean Graph DFS

Construct adjacency list with weights. For each query, run DFS tracking cumulative product with a visited set. For small constraints (E, Q <= 20), Graph DFS is standard and easiest to write cleanly in an interview.

Core Invariant: Path product from source to target represents the exact ratio source / target.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Graph DFS / BFS O(Q * (V + E)) O(V + E) ★ FinTech interview standard. Clean, highly readable, and handles reciprocals naturally.
Disjoint Set with Weights (Union-Find) O((E + Q) * α(V)) O(V) Optimal for millions of online queries; requires complex parent-weight tracking.

Approach 1: Graph Construction & Multiplicative DFS

Adjacency list graph with forward and reciprocal edges, evaluated via DFS.

Time: O(Q * (V + E)) Space: O(V + E) 
class Solution {
    fun calcEquation(
        equations: List<List<String>>,
        values: DoubleArray,
        queries: List<List<String>>
    ): DoubleArray {
        val graph = HashMap<String, MutableMap<String, Double>>()

        for (i in equations.indices) {
            val u = equations[i][0]
            val v = equations[i][1]
            val w = values[i]
            graph.getOrPut(u) { HashMap() }[v] = w
            graph.getOrPut(v) { HashMap() }[u] = 1.0 / w
        }

        fun dfs(curr: String, target: String, visited: HashSet<String>, acc: Double): Double {
            if (curr == target) return acc
            visited.add(curr)

            val neighbors = graph[curr] ?: return -1.0
            for ((next, weight) in neighbors) {
                if (next !in visited) {
                    val res = dfs(next, target, visited, acc * weight)
                    if (res != -1.0) return res
                }
            }
            return -1.0
        }

        val result = DoubleArray(queries.size)
        for (i in queries.indices) {
            val u = queries[i][0]
            val v = queries[i][1]
            if (u !in graph || v !in graph) {
                result[i] = -1.0
            } else if (u == v) {
                result[i] = 1.0
            } else {
                result[i] = dfs(u, v, HashSet(), 1.0)
            }
        }
        return result
    }
}

class Solution:
    def calcEquation(
        self,
        equations: list[list[str]],
        values: list[float],
        queries: list[list[str]]
    ) -> list[float]:
        from collections import defaultdict
        graph = defaultdict(dict)

        for (u, v), val in zip(equations, values):
            graph[u][v] = val
            graph[v][u] = 1.0 / val

        def dfs(curr: str, target: str, visited: set, acc: float) -> float:
            if curr == target:
                return acc
            visited.add(curr)
            for nxt, weight in graph[curr].items():
                if nxt not in visited:
                    res = dfs(nxt, target, visited, acc * weight)
                    if res != -1.0:
                        return res
            return -1.0

        ans = []
        for u, v in queries:
            if u not in graph or v not in graph:
                ans.append(-1.0)
            elif u == v:
                ans.append(1.0)
            else:
                ans.append(dfs(u, v, set(), 1.0))
        return ans

import java.util.*;

class Solution {
    public double[] calcEquation(
        List<List<String>> equations,
        double[] values,
        List<List<String>> queries
    ) {
        Map<String, Map<String, Double>> graph = new HashMap<>();

        for (int i = 0; i < equations.size(); i++) {
            String u = equations.get(i).get(0);
            String v = equations.get(i).get(1);
            double w = values[i];
            graph.computeIfAbsent(u, k -> new HashMap<>()).put(v, w);
            graph.computeIfAbsent(v, k -> new HashMap<>()).put(u, 1.0 / w);
        }

        double[] ans = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            String u = queries.get(i).get(0);
            String v = queries.get(i).get(1);
            if (!graph.containsKey(u) || !graph.containsKey(v)) {
                ans[i] = -1.0;
            } else if (u.equals(v)) {
                ans[i] = 1.0;
            } else {
                ans[i] = dfs(graph, u, v, new HashSet<>(), 1.0);
            }
        }
        return ans;
    }

    private double dfs(
        Map<String, Map<String, Double>> graph,
        String curr,
        String target,
        Set<String> visited,
        double acc
    ) {
        if (curr.equals(target)) return acc;
        visited.add(curr);

        Map<String, Double> neighbors = graph.get(curr);
        if (neighbors != null) {
            for (Map.Entry<String, Double> entry : neighbors.entrySet()) {
                String next = entry.getKey();
                if (!visited.contains(next)) {
                    double res = dfs(graph, next, target, visited, acc * entry.getValue());
                    if (res != -1.0) return res;
                }
            }
        }
        return -1.0;
    }
}
