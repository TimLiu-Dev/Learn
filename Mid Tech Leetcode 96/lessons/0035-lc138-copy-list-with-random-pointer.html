LeetCode #138: Copy List with Random Pointer

Official LC #138

Official Problem Statement

A linked list of length n is given such that each node contains an additional random pointer, which could point to any node in the list, or null.

Construct a deep copy of the list. The deep copy should consist of exactly n brand new nodes, where each new node has its value set to the value of its corresponding original node. Both the next and random pointer of the new nodes should point to new nodes in the copied list such that the pointers in the original list and copied list represent the same list state. None of the pointers in the new list should point to nodes in the original list.

Return the head of the copied linked list.

Example 1: head = [[7,null],[13,0],[11,4],[10,2],[1,0]] → Output: [[7,null],[13,0],[11,4],[10,2],[1,0]]

Example 2: head = [[1,1],[2,1]] → Output: [[1,1],[2,1]]

Plain-English Translation & Core Nuance

Deep clone a linked list where nodes have both next and random pointers. Maintain a 1-to-1 mapping between original nodes and copied nodes so random pointers can be wired to newly cloned nodes rather than old ones. Can be done with a HashMap in O(N) space or in-place interweaving in O(1) auxiliary space.

Official Constraints:
  • 0 <= n <= 1000
  • -10^4 <= Node.val <= 10^4
  • Node.random is null or is pointing to some node in the linked list.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
head = null → Empty list → returns null.
Best-Case Early Exit
All random pointers null → Standard linked list deep copy.
Worst-Case Full Scan
Random pointers pointing to themselves or earlier nodes → Hash table or interweaving prevents cycles.

The Mental Model & "Explain Like I'm 12"

💡 The Shadow Clone Weaver

Imagine each person in a line clones themselves and places their clone directly behind them in line: A -> A' -> B -> B' -> C -> C'. Now, if original A has a laser pointer aimed at C, clone A' simply looks at original A's target (C) and aims its own laser at C's clone (C.next = C'). Once all clones have mirrored their lasers, we untangle the alternating line into two clean, independent lines.

The Mental "A-Ha!" Switch:

Interweaving clones directly after each original node (`curr.next = clone; clone.next = nextNode`) encodes the 1-to-1 mapping into the pointer structure itself, achieving O(1) auxiliary space without a hash table!

Pattern Trigger:

Whenever deep cloning a graph or linked structure with arbitrary cross-references → HashMap or In-Place Interweaving.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(1) Space

Copy the list linearly, then for each node's random pointer, scan from the head to find the matching node index.

Wasted Work: Linear search to locate target nodes for random pointers.
The Optimal Breakthrough O(N) Time, O(1) Auxiliary Space (Interweaving)

3 passes: 1) Create interweaved clones; 2) Assign clone.random = orig.random.next; 3) Separate lists.

Core Invariant: During step 2, for every original node, its clone is at `curr.next`, and its random clone is at `curr.random.next`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. HashMap Two-Pass O(N) O(N) Intuitive, clean, standard interview solution.
★ 2. In-Place Interweaving O(N) O(1) aux Zero hash table overhead; production standard.

From Naive to Optimal & Runnable Practice Arena

HashMap Two-Pass (Most Common)

Pass 1 creates new nodes in HashMap; Pass 2 wires next and random pointers.

Time: O(N) Space: O(N) 
class Solution {
    fun copyRandomList(node: Node?): Node? {
        if (node == null) return null
        val map = HashMap<Node, Node>()

        var curr = node
        while (curr != null) {
            map[curr] = Node(curr.`val`)
            curr = curr.next
        }

        curr = node
        while (curr != null) {
            map[curr]?.next = map[curr.next]
            map[curr]?.random = map[curr.random]
            curr = curr.next
        }

        return map[node]
    }
}
Kotlin Runtime & Memory Nuance:

Two-pass hash map is intuitive and completely avoids touching input node pointers.

import java.util.HashMap;
import java.util.Map;

class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;
        Map<Node, Node> map = new HashMap<>();

        Node curr = head;
        while (curr != null) {
            map.put(curr, new Node(curr.val));
            curr = curr.next;
        }

        curr = head;
        while (curr != null) {
            map.get(curr).next = map.get(curr.next);
            map.get(curr).random = map.get(curr.random);
            curr = curr.next;
        }

        return map.get(head);
    }
}

The standard interview solution. Clear, reliable, and easily executed in 5 minutes.

Optimal: In-Place Interweaving (Zero Extra Space)

Interweave clone nodes in-place, copy random pointers, then decouple lists.

Time: O(N) Space: O(1) Auxiliary Space 
class Solution {
    /**
     * Optimal: In-Place Interweaving with O(1) Auxiliary Space
     * Time: O(N) - Three linear passes
     * Space: O(1) - No hash table allocation
     */
    fun copyRandomList(node: Node?): Node? {
        if (node == null) return null

        // 1. Interweave: A -> A' -> B -> B'
        var curr = node
        while (curr != null) {
            val clone = Node(curr.`val`)
            clone.next = curr.next
            curr.next = clone
            curr = clone.next
        }

        // 2. Wire random pointers: clone.random = orig.random.next
        curr = node
        while (curr != null) {
            curr.next?.random = curr.random?.next
            curr = curr.next?.next
        }

        // 3. Decouple lists
        curr = node
        val newHead = node.next
        while (curr != null) {
            val clone = curr.next
            curr.next = clone?.next
            clone?.next = clone?.next?.next
            curr = curr.next
        }

        return newHead
    }
}
Kotlin Runtime & Memory Nuance:

Demonstrates masterclass pointer manipulation. Decouples both original and copy in linear time without extra memory.

class Solution:
    # Optimal: In-Place Interweaving
    # Time: O(N) - 3 passes
    # Space: O(1) auxiliary
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':
        if not head:
            return None
            
        # 1. Create interwoven clone nodes
        curr = head
        while curr:
            clone = Node(curr.val, curr.next)
            curr.next = clone
            curr = clone.next

        curr = head

            curr = curr.next.next

        curr = head
        new_head = head.next
        while curr:
            clone = curr.next
            curr.next = clone.next
            if clone.next:
                clone.next = clone.next.next
            curr = curr.next
            
        return new_head

High-signal staff engineer solution. Restores original list pointers while generating a brand new list.

class Solution {
    /**
     * Optimal: In-Place Interweaving
     * Time: O(N)
     * Space: O(1) auxiliary
     */
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        // Step 1: Interweave
        Node curr = head;
        while (curr != null) {
            Node clone = new Node(curr.val);
            clone.next = curr.next;
            curr.next = clone;
            curr = clone.next;
        }

        // Step 2: Copy random pointers
        curr = head;
        while (curr != null) {
            if (curr.random != null) {
                curr.next.random = curr.random.next;
            }
            curr = curr.next.next;
        }

        // Step 3: Decouple lists
        curr = head;
        Node newHead = head.next;
        while (curr != null) {
            Node clone = curr.next;
            curr.next = clone.next;
            if (clone.next != null) {
                clone.next = clone.next.next;
            }
            curr = curr.next;
        }

        return newHead;
    }
}
Java Runtime & Memory Nuance:

The production gold standard. Avoids thousands of Map.Entry heap allocations.

Recursive Graph DFS with Memoization

Treat list as directed graph with next and random edges, cloning via DFS.

Time: O(N) Space: O(N) Call Stack + Map 
class Solution {
    private val visited = HashMap<Node, Node>()

    fun copyRandomList(node: Node?): Node? {
        if (node == null) return null
        if (visited.containsKey(node)) return visited[node]

        val clone = Node(node.`val`)
        visited[node] = clone

        clone.next = copyRandomList(node.next)
        clone.random = copyRandomList(node.random)

        return clone
    }
}

import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<Node, Node> visited = new HashMap<>();

    public Node copyRandomList(Node head) {
        if (head == null) return null;
        if (visited.containsKey(head)) return visited.get(head);

        Node clone = new Node(head.val);
        visited.put(head, clone);

        clone.next = copyRandomList(head.next);
        clone.random = copyRandomList(head.random);

        return clone;
    }
}
