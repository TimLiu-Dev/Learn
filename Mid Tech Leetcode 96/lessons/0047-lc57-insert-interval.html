LeetCode #57: Insert Interval

Official LC #57

Official Problem Statement

You are given an array of non-overlapping intervals intervals where intervals[i] = [starti, endi] represent the start and the end of the ith interval and intervals is sorted in ascending order by starti. You are also given an interval newInterval = [start, end] that represents the start and end of another interval.

Insert newInterval into intervals such that intervals is still sorted in ascending order by starti and intervals still does not have any overlapping intervals (merge overlapping intervals if necessary).

Return intervals after the insertion.

Note that you don't need to modify intervals in-place. You can make a new array and return it.

Example 1: intervals = [[1,3],[6,9]], newInterval = [2,5] → Output: [[1,5],[6,9]]

Example 2: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8] → Output: [[1,2],[3,10],[12,16]] Explanation: Because the new interval [4,8] overlaps with [3,5],[6,7],[8,10].

Plain-English Translation & Core Nuance

The original intervals are already sorted and disjoint. Solve in 3 sequential phases: 1) add all intervals that end before `newInterval` starts (`interval[1] < newInterval[0]`); 2) merge all intervals that overlap with `newInterval` by updating `newInterval = [min(start), max(end)]`; 3) add all remaining intervals that start after `newInterval` ends.

Official Constraints:
  • 0 <= intervals.length <= 10^4
  • intervals[i].length == 2
  • 0 <= start_i <= end_i <= 10^5
  • intervals is sorted by start_i in ascending order.
  • newInterval.length == 2
  • 0 <= start <= end <= 10^5

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
intervals = [], newInterval = [5, 7] → Empty list returns [[5, 7]].
Best-Case Early Exit
Inserted before first interval or after last interval → Inserted cleanly with zero merges.
Worst-Case Full Scan
Inserted interval engulfs all existing intervals newInterval = [0, 100] → All merged into a single block.

The Mental Model & "Explain Like I'm 12"

💡 The 3-Act Highway Construction Zone

Think of a highway with established paving zones already sorted from West to East. A new construction crew arrives with zone `newInterval`. Act 1: All paving zones completely West of the new zone are untouched and immediately approved. Act 2: Any paving zones that touch or overlap the new crew are merged together into one continuous mega-zone (`min(starts), max(ends)`). Act 3: All paving zones strictly East of the new zone are appended without alteration.

The Mental "A-Ha!" Switch:

Because `intervals` is ALREADY sorted and non-overlapping, we do NOT need to sort! A 3-phase linear scan solves insertion and merging in strict O(N) time and O(N) space.

Pattern Trigger:

Inserting into pre-sorted disjoint intervals → 3-phase linear scan: Left Disjoint → Overlapping Merge → Right Disjoint.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N log N) Time, O(N) Space

Append `newInterval` to `intervals`, sort the entire array by start time, and run LC 56 Merge Intervals.

Wasted Work: Re-sorting an array that was already 99% sorted.
The Optimal Breakthrough O(N) Time, O(N) Space

3-phase single pass: add strictly earlier intervals, merge overlapping intervals with `newInterval`, add strictly later intervals.

Core Invariant: An interval overlaps with `newInterval` if and only if `interval[0] <= newInterval[1]` and `interval[1] >= newInterval[0]`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Append + Full Re-Sort O(N log N) O(N) Disregards existing sorted property.
2. Binary Search Insertion Point O(log N + N) O(N) Finds position in O(log N), but merging still requires O(N) shifts.
★ 3. Three-Phase Linear Sweep O(N) O(N) Strict single-pass linear time; zero re-sorting.

From Naive to Optimal & Runnable Practice Arena

Append & Full Re-Sort (Naive)

Append newInterval to intervals, sort the entire list by start time, and run standard merge intervals.

Time: O(N log N) Space: O(N) 
class Solution {
    fun insert(intervals: Array<IntArray>, newInterval: IntArray): Array<IntArray> {
        val list = intervals.toMutableList().apply { add(newInterval) }
        list.sortBy { it[0] }
        val result = mutableListOf<IntArray>()
        for (iv in list) {
            if (result.isEmpty() || iv[0] > result.last()[1]) {
                result.add(iv)
            } else {
                result.last()[1] = maxOf(result.last()[1], iv[1])
            }
        }
        return result.toTypedArray()
    }
}

Appends and re-sorts. Discards the valuable pre-sorted property of the input.

Binary Search Insert Position + Merge

Use binary search to locate the insertion index of newInterval in O(log N), then merge overlapping neighbors.

Time: O(log N + N) = O(N) Space: O(N) 
class Solution {
    fun insert(intervals: Array<IntArray>, newInterval: IntArray): Array<IntArray> {
        val n = intervals.size
        var left = 0
        var right = n - 1
        var insertIdx = n
        while (left <= right) {
            val mid = (left + right) / 2
            if (intervals[mid][0] >= newInterval[0]) {
                insertIdx = mid
                right = mid - 1
            } else {
                left = mid + 1
            }
        }
        val list = ArrayList<IntArray>(n + 1)
        for (i in 0 until insertIdx) list.add(intervals[i])
        list.add(newInterval)
        for (i in insertIdx until n) list.add(intervals[i])

        val result = mutableListOf<IntArray>()
        for (iv in list) {
            if (result.isEmpty() || iv[0] > result.last()[1]) {
                result.add(iv)
            } else {
                result.last()[1] = maxOf(result.last()[1], iv[1])
            }
        }
        return result.toTypedArray()
    }
}

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {

        int low = 0, high = n - 1, idx = n;

Three-Phase Linear Scan (Optimal Primary)

Add all intervals ending before newInterval starts. Merge overlapping intervals. Add remaining intervals.

Time: O(N) Space: O(N) 
class Solution {
    /**
     * Optimal: Three-Phase Linear Scan
     * Time: O(N) - Strictly single pass through intervals
     * Space: O(N) - Space for result list
     */
    fun insert(intervals: Array<IntArray>, newInterval: IntArray): Array<IntArray> {
        val result = mutableListOf<IntArray>()
        var i = 0
        val n = intervals.size
        var start = newInterval[0]
        var end = newInterval[1]

        // Phase 1: Add all intervals ending strictly before newInterval starts
        while (i < n && intervals[i][1] < start) {
            result.add(intervals[i])
            i++
        }

        // Phase 2: Merge all overlapping intervals
        while (i < n && intervals[i][0] <= end) {
            start = minOf(start, intervals[i][0])
            end = maxOf(end, intervals[i][1])
            i++
        }
        result.add(intArrayOf(start, end))

        // Phase 3: Add all remaining intervals starting after newInterval ends
        while (i < n) {
            result.add(intervals[i])
            i++
        }

        return result.toTypedArray()
    }
}
Kotlin Runtime & Memory Nuance:

Zero sorting. Direct single pass through the pre-sorted input array.

            i += 1

Masterclass interview solution. Clean division of 3 sequential while-loops.

class Solution {
    /**
     * Optimal: Three-Phase Linear Scan
     * Time: O(N) - Single pass
     * Space: O(N) - Output array
     */
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> result = new ArrayList<>();
        int i = 0;
        int n = intervals.length;
        int start = newInterval[0];
        int end = newInterval[1];

        // Phase 1: Non-overlapping before
        while (i < n && intervals[i][1] < start) {
            result.add(intervals[i]);
            i++;
        }

        // Phase 2: Overlapping intervals merged
        while (i < n && intervals[i][0] <= end) {
            start = Math.min(start, intervals[i][0]);
            end = Math.max(end, intervals[i][1]);
            i++;
        }
        result.add(new int[]{start, end});

        // Phase 3: Non-overlapping after
        while (i < n) {
            result.add(intervals[i]);
            i++;
        }

        return result.toArray(new int[result.size()][]);
    }
}

Optimal O(N) time with no sorting. Guarantees non-overlapping sorted output.
