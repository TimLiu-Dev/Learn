LeetCode #102: Binary Tree Level Order Traversal

Official LC #102

Official Problem Statement

Given the root of a binary tree, return the level order traversal of its nodes' values. (i.e., from left to right, level by level).

Example 1: root = [3,9,20,null,null,15,7] → Output: [[3],[9,20],[15,7]]

Example 2: root = [1] → Output: [[1]]

Example 3: root = [] → Output: []

Plain-English Translation & Core Nuance

Traverse the tree layer by layer from top to bottom and left to right. Maintain a queue. For each level, snapshot the current queue size, pop that exact number of nodes, append their values to the level list, and push their children into the queue for the next level.

Official Constraints:
  • The number of nodes in the tree is in the range [0, 2000].
  • -1000 <= Node.val <= 1000

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
root == null → Empty tree returns empty list [].
Best-Case Early Exit
Single node tree root = [1] → Immediately returns [[1]].
Worst-Case Full Scan
Completely unbalanced (skewed) tree of depth N → N tiers with 1 node per tier; queue size stays 1.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N^2) Time, O(N) Space

Compute height H, then for each d from 1 to H run a separate DFS printing nodes at depth d from scratch.

Wasted Work: Re-traversing ancestor nodes up to N times.
The Optimal Breakthrough O(N) Time, O(W) <= O(N) Space

Queue BFS snapshot loop. Every node is enqueued and dequeued exactly once.

Core Invariant: At the start of the outer while-loop, the queue contains exclusively the nodes belonging to level d.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Repeated Depth-Scoped DFS O(N^2) O(N) Scans depth d repeatedly from root.
2. Recursive Pre-order DFS with Depth Index O(N) O(H) Passes depth index; appends to result[depth].
★ 3. Queue BFS with Snapshot Size O(N) O(W) <= O(N) Textbook BFS pattern; optimal row-by-row streaming.

Repeated Depth-Scoped DFS (Naive)

Calculate maximum depth, then run a separate recursive traversal for depth 0 to maxDepth.

Time: O(N^2) Space: O(N) 
class Solution {
    fun levelOrder(root: TreeNode?): List<List<Int>> {
        val result = mutableListOf<List<Int>>()
        val height = getHeight(root)
        for (d in 0 until height) {
            val level = mutableListOf<Int>()
            collectLevel(root, d, level)
            result.add(level)
        }
        return result
    }

    private fun getHeight(node: TreeNode?): Int {
        if (node == null) return 0
        return 1 + maxOf(getHeight(node.left), getHeight(node.right))
    }

    private fun collectLevel(node: TreeNode?, depthRemaining: Int, level: MutableList<Int>) {
        if (node == null) return
        if (depthRemaining == 0) {
            level.add(node.`val`)
            return
        }
        collectLevel(node.left, depthRemaining - 1, level)
        collectLevel(node.right, depthRemaining - 1, level)
    }
}
Kotlin Runtime & Memory Nuance:

Naive multi-pass. Scans ancestor nodes repeatedly for each depth level.

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        int h = getHeight(root);
        for (int d = 0; d < h; d++) {
            List<Integer> row = new ArrayList<>();
            collect(root, d, row);
            result.add(row);
        }
        return result;
    }

    private int getHeight(TreeNode node) {
        if (node == null) return 0;
        return 1 + Math.max(getHeight(node.left), getHeight(node.right));
    }

    private void collect(TreeNode node, int d, List<Integer> row) {
        if (node == null) return;
        if (d == 0) {
            row.add(node.val);
            return;
        }
        collect(node.left, d - 1, row);
        collect(node.right, d - 1, row);
    }
}

Recursive Pre-order DFS with Depth Index

Traverse tree recursively, passing current depth. Append each node to result[depth].

Time: O(N) Space: O(H) Call Stack 
class Solution {
    fun levelOrder(root: TreeNode?): List<List<Int>> {
        val result = mutableListOf<MutableList<Int>>()
        dfs(root, 0, result)
        return result
    }

    private fun dfs(node: TreeNode?, depth: Int, result: MutableList<MutableList<Int>>) {
        if (node == null) return
        if (depth == result.size) {
            result.add(mutableListOf())
        }
        result[depth].add(node.`val`)
        dfs(node.left, depth + 1, result)
        dfs(node.right, depth + 1, result)
    }
}
Kotlin Runtime & Memory Nuance:

Visits left child before right child, preserving left-to-right order at each depth level.

class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        res = []
        def dfs(node, depth):
            if not node: return
            if depth == len(res):
                res.append([])
            res[depth].append(node.val)
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        dfs(root, 0)
        return res

Compact DFS alternative. Stack space is O(H), saving memory on wide trees.

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int depth, List<List<Integer>> result) {
        if (node == null) return;
        if (depth == result.size()) {
            result.add(new ArrayList<>());
        }
        result.get(depth).add(node.val);
        dfs(node.left, depth + 1, result);
        dfs(node.right, depth + 1, result);
    }
}
Java Runtime & Memory Nuance:

Clean recursive formulation that automatically groups tiers by depth.

Queue BFS with Snapshot Size (Optimal Primary)

Standard Breadth-First Search using a Queue. Snapshot size at the beginning of each level.

Time: O(N) Space: O(W) <= O(N) 
class Solution {
    /**
     * Optimal: Queue BFS with Snapshot Level Size
     * Time: O(N) - Every node is queued and dequeued once
     * Space: O(W) - Max width of tree in queue (up to N/2)
     */
    fun levelOrder(root: TreeNode?): List<List<Int>> {
        if (root == null) return emptyList()
        val result = mutableListOf<List<Int>>()
        val queue = ArrayDeque<TreeNode>()
        queue.add(root)

        while (queue.isNotEmpty()) {
            val levelSize = queue.size
            val currentLevel = ArrayList<Int>(levelSize)

            for (i in 0 until levelSize) {
                val node = queue.removeFirst()
                currentLevel.add(node.`val`)
                node.left?.let { queue.add(it) }
                node.right?.let { queue.add(it) }
            }

            result.add(currentLevel)
        }

        return result
    }
}
Kotlin Runtime & Memory Nuance:

`ArrayDeque` provides zero-allocation FIFO operations in Kotlin/Java. `levelSize` isolates the layer.

class Solution:
    # Optimal: Queue BFS with Snapshot Level Size
    # Time: O(N) - Visits each node once
    # Space: O(W) - Max tree width in deque
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []
        result = []
        queue = collections.deque([root])

        while queue:
            level_size = len(queue)
            current_level = []
            for _ in range(level_size):
                node = queue.popleft()
                current_level.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            result.append(current_level)
            
        return result
Python Runtime & Memory Nuance:

Using `collections.deque` ensures O(1) `popleft()`. Avoid list `pop(0)` which is O(N).

class Solution {
    /**
     * Optimal: Queue BFS with Snapshot Level Size
     * Time: O(N) - Linear scan
     * Space: O(W) - Maximum width of binary tree
     */
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> currentLevel = new ArrayList<>(levelSize);

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                currentLevel.add(node.val);
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            result.add(currentLevel);
        }

        return result;
    }
}
Java Runtime & Memory Nuance:

`ArrayDeque` is significantly faster than `LinkedList` as a queue in Java due to cache locality.
