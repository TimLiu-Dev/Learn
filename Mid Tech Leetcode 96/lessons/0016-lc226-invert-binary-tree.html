LeetCode 226: Invert Binary Tree

Official LC #226

Official Problem Statement

Given the root of a binary tree, invert the tree, and return its root.

Example 1: root = [4,2,7,1,3,6,9] → Output: [4,7,2,9,6,3,1]

Example 2: root = [2,1,3] → Output: [2,3,1]

Example 3: root = [] → Output: []

Plain-English Translation & Core Nuance

Create the vertical mirror reflection of the tree: at every node in the tree, swap its left child with its right child, and recursively repeat for all descendants.

🪞 The Mirror Invariant: Inverting a binary tree does NOT mean reversing values in an array. It means swapping the physical left and right pointer references of every node. Swapping can be executed pre-order (before recursing) or post-order (after recursing).
Input Constraints

Node count: [0, 100]

-100 ≤ Node.val ≤ 100

Tree can be completely empty, skewed, or balanced.

Null & Single Node

root = null → null

root = [1] → [1]

Base case: if (root == null) return null;

Asymmetric Skewed Chain

[1, null, 2, null, 3]

Output: [1, 2, null, 3, null]

Right-leaning spine mirrors completely into a left-leaning spine.

Strategic Contrast

Naive Trap vs. Optimal Breakthrough

❌

The Naive Trap: Uncached Overwrite & Tree Cloning

Beginners often write: root.left = invertTree(root.right); root.right = invertTree(root.left);. Because root.left was just overwritten with the inverted right tree, the second line inverts the right tree AGAIN and overwrites `root.right`!

• Overwrite bug: Destroys original left subtree permanently

• Cloning Trap: Allocating brand-new TreeNode instances wastes heap memory

✅

The Breakthrough: Temporary Swap Reference

Save a temporary handle before mutating: val temp = root.left; root.left = invertTree(root.right); root.right = invertTree(temp);. Reuses existing nodes in-place.

• Time Complexity: O(N) visits every node exactly once

• Space Complexity: O(H) call stack height (O(log N) balanced, O(N) worst)

• Zero node allocations: in-place pointer swapping.

Approach Time Space Node Allocations Tradeoff Summary
1. BFS Level-Order (Queue) O(N) O(W) = O(N/2) 0 Avoids recursion call stack depth, but consumes memory proportional to tree width.
2. Iterative DFS (Explicit Stack) O(N) O(H) Stack 0 Good for preventing OS stack overflow on extremely deep trees (H > 10,000).
3. Recursive DFS (Optimal) O(N) O(H) Call Stack 0 Standard idiomatic solution. 4 lines of clean, expressive code.

Solution Evolution

From Level-Order BFS to Recursive Pointer Swap

Approach 1: Iterative BFS Level-Order (Queue)

Pushes root onto a Queue. While the queue is not empty, pop a node, swap its left and right pointers, and enqueue any non-null children.

Time: O(N) Space: O(W) (Queue holds maximum level width) 
class Solution {
    fun invertTree(root: TreeNode?): TreeNode? {
        if (root == null) return null
        
        val queue = java.util.ArrayDeque<TreeNode>()
        queue.offer(root)
        
        while (queue.isNotEmpty()) {
            val curr = queue.poll()
            // Swap left and right
            val temp = curr.left
            curr.left = curr.right
            curr.right = temp
            
            if (curr.left != null) queue.offer(curr.left)
            if (curr.right != null) queue.offer(curr.right)
        }
        return root
    }
}
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        
        queue = collections.deque([root])
        while queue:
            curr = queue.popleft()
            curr.left, curr.right = curr.right, curr.left
            if curr.left: queue.append(curr.left)
            if curr.right: queue.append(curr.right)
        return root
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        
        while (!queue.isEmpty()) {
            TreeNode curr = queue.poll();
            TreeNode temp = curr.left;
            curr.left = curr.right;
            curr.right = temp;
            
            if (curr.left != null) queue.offer(curr.left);
            if (curr.right != null) queue.offer(curr.right);
        }
        return root;
    }
}

Approach 2: Iterative DFS (Explicit Stack)

Replaces the implicit recursion call stack with an explicit Stack<TreeNode> to avoid JVM/OS StackOverflowError on deep trees.

Time: O(N) Space: O(H) Stack 
class Solution {
    fun invertTree(root: TreeNode?): TreeNode? {
        if (root == null) return null
        
        val stack = java.util.ArrayDeque<TreeNode>()
        stack.push(root)
        
        while (stack.isNotEmpty()) {
            val curr = stack.pop()
            val temp = curr.left
            curr.left = curr.right
            curr.right = temp
            
            if (curr.left != null) stack.push(curr.left)
            if (curr.right != null) stack.push(curr.right)
        }
        return root
    }
}
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        stack = [root]
        while stack:
            curr = stack.pop()
            curr.left, curr.right = curr.right, curr.left
            if curr.left: stack.append(curr.left)
            if curr.right: stack.append(curr.right)
        return root
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode curr = stack.pop();
            TreeNode temp = curr.left;
            curr.left = curr.right;
            curr.right = temp;
            
            if (curr.left != null) stack.push(curr.left);
            if (curr.right != null) stack.push(curr.right);
        }
        return root;
    }
}

Approach 3: Recursive DFS Pointer Swapping (Production Optimal)

INTERVIEW DEFAULT

The canonical implementation. Base case returns null. Inverts right subtree and assigns to left; inverts cached left subtree and assigns to right. Zero node allocations.

Time: O(N) Space: O(H) (H = tree height) 
class Solution {
    fun invertTree(root: TreeNode?): TreeNode? {
        if (root == null) return null
        
        // Cache left child before overwriting
        val tempLeft = root.left
        root.left = invertTree(root.right)
        root.right = invertTree(tempLeft)
        
        return root
    }
}
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
            
        # Tuple unpacking simultaneously swaps without temporary variable
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        
        TreeNode tempLeft = root.left;
        root.left = invertTree(root.right);
        root.right = invertTree(tempLeft);
        
        return root;
    }
}

          Senior Scalability & System Follow-Ups
        

        

          

            1. Massive Deep Tree (StackOverflow Prevention):
            

              If the tree has 100,000 skewed nodes, recursion causes a JVM `StackOverflowError`. In production engines (e.g. AST transformers in compilers like Babel/Kotlin), iterative BFS using a heap-allocated Queue or Morris traversal is preferred to guarantee O(1) recursion depth.
            

          

          

            2. UI Layout Mirroring (RTL Localization):
            

              In mobile layout rendering (Android View hierarchy or Flutter Widget trees), localizing an app from Left-to-Right (LTR) to Right-to-Left (RTL, e.g. Arabic/Hebrew) conceptually inverts the horizontal layout tree, mirroring layout gravity and margins.
