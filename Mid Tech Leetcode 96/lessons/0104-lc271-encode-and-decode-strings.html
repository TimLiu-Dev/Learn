Problem #271: Encode and Decode Strings

View on NeetCode ↗

Official Problem Statement

Design an algorithm to encode a list of strings to a single string. The encoded string is then sent over the network and is decoded back to the original list of strings.

Implement encode and decode methods.

You are not allowed to solve the problem using any serialize methods (such as eval or JSON.stringify). The input strings may contain any possible characters out of 256 valid ASCII characters.

Example 1: strs = ["neet","code","love","you"] → Output: ["neet","code","love","you"]

Example 2: strs = ["we","say",":","yes"] → Output: ["we","say",":","yes"]

Example 3: strs = ["","a#b",""] → Output: ["","a#b",""]

Plain-English Translation & Core Nuance

Pack a list of arbitrary strings into one flat string so that you can unpack it back into the exact original list—even if the strings themselves contain colons, hashes, numbers, or empty strings.

Official Constraints:
  • 1 <= strs.length <= 200
  • 0 <= strs[i].length <= 200
  • strs[i] contains any possible characters out of 256 valid ASCII characters.

The Mental Model & "Explain Like I'm 12"

💡 HTTP Content-Length Packet Framing

When a web server sends raw bytes over TCP, it cannot rely on a special 'end-of-message' character because the payload itself (like an image or text) might contain that exact byte! Instead, HTTP headers declare 'Content-Length: 4\r\n' followed by raw payload bytes. Once the reader sees the header delimiter '#', it stops looking for delimiters altogether and blindly reads the exact number of characters announced by the length.

The Mental "A-Ha!" Switch:

Prefix every string with its character count and a single delimiter '#' (e.g., '4#neet4#code'). During decoding, only scan for '#' to parse the length integer L, then jump exactly L characters forward!

Pattern Trigger:

Serializing variable-length strings or binary payloads that may contain any delimiter character.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N) Time, Fragile / Incorrect on Collisions

Joining strings with a single delimiter like ',' or '#' (e.g., strs.joinToString("#")) and calling split("#").

Wasted Work: Breaks immediately when an input string naturally contains '#' or when empty strings collide with delimiter boundaries.
The Optimal Breakthrough O(C) Time, O(1) Aux Space (where C = total characters)

Write '#' for each item. Decode with a pointer i: find the next '#' from i, parse the integer length in s[i..hashIdx-1], slice s[hashIdx+1 .. hashIdx+1+len], and advance i directly to the end of the slice.

Core Invariant: Pointer i always lands on the first digit of the next chunk's length header—never inside a string payload.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
Naive: Simple Delimiter Split O(C) O(C) Fails when payload contains delimiter characters.
Better: Character Escaping (\\#) O(C) O(C) Correct, but requires char-by-char state machine scanning and doubles escape characters.
Optimal: Length-Prefix Framing (#) O(C) O(1) aux ★ Production protocol standard (HTTP/gRPC/Redis RESP). Zero escaping needed.

  • Delimiter (#) Tracks delimiter (#) across iterations (initial state: -).
  • Payload Length Tracks payload length across iterations (initial state: -).
  • Decoded Count Tracks decoded count across iterations (initial state: 0).
2. Step-by-Step Non-Code Algorithm Walkthrough
1. Guard Clauses & State Initialization

Before entering the main loop, verify base boundaries (strs = [""] (Single empty string) -> Encodes to "0#", decodes back to [""].) and allocate the primary state containers required for Encode and Decode Strings so that subsequent lookups or pointer updates run in O(1) time.

2. Core Traversal & Decision Rule

Write '#' for each item. Decode with a pointer i: find the next '#' from i, parse the integer length in s[i..hashIdx-1], slice s[hashIdx+1 .. hashIdx+1+len], and advance i directly to the end of the slice. At each step, instead of re-scanning elements we already visited, we use our maintained state to make an immediate local decision.

3. Invariant Maintenance & State Transition

In encode, we iterate over strs and append str.length, '#', and str into a StringBuilder. In decode, we maintain index i = 0. While i < s.length, we locate the next '#' starting from i, parse the integer length in s[i..hashIdx], extract the substring of that exact length starting at hashIdx + 1, and jump i to hashIdx + 1 + length. Throughout every transition, we preserve the core invariant: Pointer i always lands on the first digit of the next chunk's length header—never inside a string payload.

4. Termination & Output Guarantee

Check for early-exit conditions (strs = ["a", "b"] -> Simple length-prefixed framing "1#a1#b".). Once traversal completes, return the accumulated result. Even if a string contained '99#tricky', jumping by len skips right over the internal '#' without ever misinterpreting it as a header!

3. Clean Whiteboard Pseudocode (Syntax-Free) Direct blueprint for Trace Table & Code 
01FUNCTION encode(input):
02    SET i = 0; SET res = mutableListOf<String>()
03    WHILE i < s.length DO
04    SET hashIdx = s.indexOf('#', i)
05    SET len = s.substring(i, hashIdx).toInt()
06    res.add(s.substring(hashIdx + 1, hashIdx + 1 + len))
07    i = hashIdx + 1 + len

Approach 1: Non-ASCII Delimiter Split

Join strings using a rare non-ASCII delimiter (e.g., Char(257)) and split. Fails if full Unicode is permitted or if empty list is ambiguous.

Time: O(C) Space: O(C) 
class Solution {
    fun encode(strs: List<String>): String {
        if (strs.isEmpty()) return ""
        return strs.joinToString(separator = "\u0100")
    }

    fun decode(s: String): List<String> {
        if (s.isEmpty()) return emptyList()
        return s.split("\u0100")
    }
}
Kotlin Runtime & Memory Nuance:

Distinguishing [] vs [""] is broken when encoding to an empty string without framing.

Relies on out-of-band character assumption, which interviewers immediately challenge in follow-ups.

Approach 2: Character Escaping State Machine

Double every '/' as '//' and terminate each string with '/:'. Requires scanning every character during both encode and decode.

Time: O(C) Space: O(C) 
class Solution {
    fun encode(strs: List<String>): String = buildString {
        for (str in strs) {
            for (ch in str) {
                if (ch == '/') append("//") else append(ch)
            }
            append("/:")
        }
    }

    fun decode(s: String): List<String> {
        val res = mutableListOf<String>()
        val sb = StringBuilder()
        var i = 0
        while (i < s.length) {
            if (s[i] == '/') {
                if (s[i + 1] == '/') {
                    sb.append('/')
                } else if (s[i + 1] == ':') {
                    res.add(sb.toString())
                    sb.setLength(0)
                }
                i += 2
            } else {
                sb.append(s[i++])
            }
        }
        return res
    }
}
Kotlin Runtime & Memory Nuance:

Works for any character set, but forces char-by-char inspection instead of fast block memory copies.

class Solution:
    def encode(self, strs: list[str]) -> str:
        return "".join(s.replace("/", "//") + "/:" for s in strs)

    def decode(self, s: str) -> list[str]:
        res, cur, i = [], [], 0
        while i < len(s):
            if s[i:i+2] == "//":
                cur.append("/")
                i += 2
            elif s[i:i+2] == "/:":
                res.append("".join(cur))
                cur = []
                i += 2
            else:
                cur.append(s[i])
                i += 1
        return res
Python Runtime & Memory Nuance:

String replacement allocates intermediate copies per string.

import java.util.*;

class Solution {
    public String encode(List<String> strs) {
        StringBuilder sb = new StringBuilder();
        for (String str : strs) {
            sb.append(str.replace("/", "//")).append("/:");
        }
        return sb.toString();
    }

    public List<String> decode(String s) {
        List<String> res = new ArrayList<>();
        StringBuilder cur = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            if (s.charAt(i) == '/') {
                if (s.charAt(i + 1) == '/') cur.append('/');
                else { res.add(cur.toString()); cur.setLength(0); }
                i += 2;
            } else {
                cur.append(s.charAt(i++));
            }
        }
        return res;
    }
}
Java Runtime & Memory Nuance:

StringBuilder.setLength(0) reuses the internal char[] buffer across words.

Approach 3: Length-Prefix Framing (#)

Prefix each string with its character length followed by '#'. Decode by parsing the length header and slicing the exact byte range in O(1) jumps.

Time: O(C) Space: O(1) auxiliary 
class Solution {
    fun encode(strs: List<String>): String = buildString {
        for (str in strs) {
            append(str.length).append('#').append(str)
        }
    }

    fun decode(s: String): List<String> {
        val result = ArrayList<String>()
        var i = 0
        while (i < s.length) {
            val hashIdx = s.indexOf('#', startIndex = i)
            val length = s.substring(i, hashIdx).toInt()
            val start = hashIdx + 1
            result.add(s.substring(start, start + length))
            i = start + length
        }
        return result
    }
}
Kotlin Runtime & Memory Nuance:

buildString allocates a single StringBuilder. s.indexOf('#', startIndex = i) scans only the tiny digit prefix (1-3 chars).

class Solution:
    def encode(self, strs: list[str]) -> str:
        return "".join(f"{len(s)}#{s}" for s in strs)

    def decode(self, s: str) -> list[str]:
        res = []
        i = 0
        while i < len(s):
            j = s.find("#", i)
            length = int(s[i:j])
            start = j + 1
            res.append(s[start : start + length])
            i = start + length
        return res
Python Runtime & Memory Nuance:

s.find('#', i) avoids slicing the remaining string, keeping decoding strictly linear O(C).

import java.util.*;

class Solution {
    public String encode(List<String> strs) {
        StringBuilder sb = new StringBuilder();
        for (String str : strs) {
            sb.append(str.length()).append('#').append(str);
        }
        return sb.toString();
    }

    public List<String> decode(String s) {
        List<String> res = new ArrayList<>();
        int i = 0;
        while (i < s.length()) {
            int hashIdx = s.indexOf('#', i);
            int len = Integer.parseInt(s.substring(i, hashIdx));
            int start = hashIdx + 1;
            res.add(s.substring(start, start + len));
            i = start + len;
        }
        return res;
    }
}
Java Runtime & Memory Nuance:

s.substring(start, start + len) copies the exact payload range in one native System.arraycopy call.
