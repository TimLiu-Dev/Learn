LeetCode #199: Binary Tree Right Side View

Official LC #199

Official Problem Statement

Given the root of a binary tree, imagine yourself standing on the right side of it, return the values of the nodes you can see ordered from top to bottom.

Example 1: root = [1,2,3,null,5,null,4] → Output: [1,3,4]

Example 2: root = [1,null,3] → Output: [1,3]

Example 3: root = [] → Output: []

Plain-English Translation & Core Nuance

Return the rightmost node at every vertical depth level. In BFS, record the last element popped in each level snapshot. In DFS, visit right children before left children: the very first node visited at each depth level is the visible rightmost node.

Official Constraints:
  • The number of nodes in the tree is in the range [0, 100].
  • -100 <= Node.val <= 100

The Mental Model & "Explain Like I'm 12"

💡 Horizons from an Observation Deck

You are standing on a viewing platform looking across a forest canopy from the right side. At each horizontal altitude (depth), you can only see the outermost tree branch protruding toward the right. If the right wing terminates early, deeper left branches underneath are exposed to the horizon.

The Mental "A-Ha!" Switch:

A node in the left subtree CAN be visible from the right if no node exists at that same depth in the right subtree! You cannot merely traverse `curr = curr.right`.

Pattern Trigger:

View from an angle (Right view, Left view, Top view) → BFS taking terminal row element OR Reverse DFS (Right before Left) with depth check `depth == result.size`.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N) Time, O(N) Space

Run full Level-Order BFS, construct entire sublists for every level, then extract `sublist.last()` for each level.

Wasted Work: Allocating full row arrays for all N nodes when we only ever preserve one element per level.
The Optimal Breakthrough O(N) Time, O(H) Space

Reverse Pre-order DFS (visit Root, Right, Left). When `depth == result.size`, append the node value immediately. Uses minimal O(H) recursion stack.

Core Invariant: Because right subtrees are fully traversed before left subtrees, the first node reached at depth d is strictly the rightmost node at that level.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Full BFS Sublist Collection O(N) O(N) Allocates lists for all tree nodes across all tiers.
2. BFS Queue Snapshot (Last Element) O(N) O(W) Captures `if (i == size - 1)` without extra row allocations.
★ 3. Reverse DFS (Root -> Right -> Left) O(N) O(H) Appends directly on `depth == result.size`; optimal call stack.

Level-by-Level BFS Queue Snapshot

Perform level-order traversal with a FIFO queue. Record the last element in each level snapshot.

Time: O(N) Space: O(W) <= O(N) 
class Solution {
    fun rightSideView(root: TreeNode?): List<Int> {
        if (root == null) return emptyList()
        val result = mutableListOf<Int>()
        val queue = ArrayDeque<TreeNode>()
        queue.add(root)

        while (queue.isNotEmpty()) {
            val levelSize = queue.size
            for (i in 0 until levelSize) {
                val node = queue.removeFirst()
                if (i == levelSize - 1) {
                    result.add(node.`val`)
                }
                node.left?.let { queue.add(it) }
                node.right?.let { queue.add(it) }
            }
        }
        return result
    }
}
Kotlin Runtime & Memory Nuance:

Standard queue BFS. Capturing `i == levelSize - 1` takes the rightmost node of each tier.

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (i == levelSize - 1) {
                    result.add(node.val);
                }
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return result;
    }
}
Java Runtime & Memory Nuance:

Iterative and robust against recursion depth stack overflow exceptions.

Reverse BFS (Right to Left Enqueue)

Enqueue right children before left children in BFS; the first element popped per level is the rightmost.

Time: O(N) Space: O(W) <= O(N) 
class Solution {
    fun rightSideView(root: TreeNode?): List<Int> {
        if (root == null) return emptyList()
        val result = mutableListOf<Int>()
        val queue = ArrayDeque<TreeNode>()
        queue.add(root)

        while (queue.isNotEmpty()) {
            val levelSize = queue.size
            for (i in 0 until levelSize) {
                val node = queue.removeFirst()
                if (i == 0) {
                    result.add(node.`val`)
                }
                node.right?.let { queue.add(it) }
                node.left?.let { queue.add(it) }
            }
        }
        return result
    }
}

Enqueueing `node.right` first allows taking `i == 0` immediately as the visible node.

Reverse Pre-order DFS (Optimal Primary)

Traverse recursively visiting right child before left. When depth == result.size, record node.

Time: O(N) Space: O(H) Call Stack 
class Solution {
    /**
     * Optimal: Reverse Pre-Order DFS (Root -> Right -> Left)
     * Time: O(N) - Visits each node once
     * Space: O(H) - Recursion stack bounded by tree height (log N balanced)
     */
    fun rightSideView(root: TreeNode?): List<Int> {
        val result = mutableListOf<Int>()
        dfs(root, 0, result)
        return result
    }

    private fun dfs(node: TreeNode?, depth: Int, result: MutableList<Int>) {
        if (node == null) return

        // First node reached at this depth is guaranteed to be the rightmost
        if (depth == result.size) {
            result.add(node.`val`)
        }

        dfs(node.right, depth + 1)
        dfs(node.left, depth + 1)
    }
}
Kotlin Runtime & Memory Nuance:

Minimal O(H) memory. Bypasses queue heap allocation entirely.

class Solution:
    # Optimal: Reverse Pre-Order DFS
    # Time: O(N) - Single pass
    # Space: O(H) - Recursion stack
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        
        def dfs(node: Optional[TreeNode], depth: int):
            if not node:
                return
            if depth == len(result):
                result.append(node.val)
            dfs(node.right, depth + 1)
            dfs(node.left, depth + 1)
            
        dfs(root, 0)
        return result

class Solution {
    /**
     * Optimal: Reverse Pre-Order DFS
     * Time: O(N) - Visits all nodes
     * Space: O(H) - Call stack proportional to tree height
     */
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int depth, List<Integer> result) {
        if (node == null) return;

        if (depth == result.size()) {
            result.add(node.val);
        }

        dfs(node.right, depth + 1);
        dfs(node.left, depth + 1);
    }
}

"For strategy: In BFS, we can collect the last node of each level snapshot in O(N) time and O(W) space. But an even cleaner approach is reverse pre-order DFS (visiting root, then right child, then left child). By visiting right first, the first node reached at depth d is strictly the rightmost node at that level. We add it whenever `depth == result.size`. Time is O(N) and space is O(H)."

        

        

          Phase 3: Live Coding Narrative
          
"I implement reverse DFS. In the helper function `dfs(node, depth)`: base check returns if node is null. If `depth == result.size`, append `node.val`. Then call `dfs(node.right, depth + 1)`, followed by `dfs(node.left, depth + 1)`. Finally return the result list."
