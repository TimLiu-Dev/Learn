LeetCode #1448: Count Good Nodes in Binary Tree

Official LC #1448

Official Problem Statement

Given a binary tree root, a node X in the tree is named good if in the path from the root to X there are no nodes with a value greater than X.

Return the number of good nodes in the binary tree.

Example 1: root = [3,1,4,3,null,1,5] → Output: 4 (Nodes: 3, 4, 5, 3)

Example 2: root = [3,3,null,4,2] → Output: 3 (Nodes: 3, 3, 4)

Example 3: root = [1] → Output: 1

Plain-English Translation & Core Nuance

A node is 'good' if its value is greater than or equal to the maximum value seen so far on the path from the root. Traverse top-down with DFS, passing `maxSoFar`. If `node.val >= maxSoFar`, increment good count and propagate `max(maxSoFar, node.val)` downward.

Official Constraints:
  • The number of nodes in the binary tree is in the range [1, 10^5].
  • Each node's value is between [-10^4, 10^4].

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
Single node tree [1] → Root has no ancestors, so it is always good (returns 1).
Best-Case Early Exit
All strictly increasing path (e.g. 1 → 2 → 3) → Every node is good (returns N).
Worst-Case Full Scan
All strictly decreasing path (e.g. 5 → 4 → 3 → 1) → Only root is good (returns 1).

The Mental Model & "Explain Like I'm 12"

💡 Mountain Ridge Line-of-Sight

Imagine descending down a mountain ridge. You only have a clear line of sight back up to the base camp if no higher peak blocks your view. As you hike down, you maintain a record of the highest summit traversed so far (`maxSoFar`). If your current spot is at least as high as `maxSoFar`, you plant a flag (Good Node!).

The Mental "A-Ha!" Switch:

You do NOT need to store or search the entire ancestor path! Storing just a single scalar `maxSoFar` passed down the call stack compresses path validation from O(H) to O(1) per node.

Pattern Trigger:

Condition depends on all ancestors on the path from root → Top-down DFS passing running aggregate (max, min, bitmask, sum).

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N * H) Time, O(H) Space

Collect ancestor values in a list during DFS. At each node, iterate through all ancestors in the list to check if any is greater than node.val.

Wasted Work: Re-scanning the entire ancestor array of length H at every single node.
The Optimal Breakthrough O(N) Time, O(H) Space

Pass a single integer `maxSoFar` down the recursive call stack. Update with `max(maxSoFar, node.val)` in O(1) per step.

Core Invariant: `maxSoFar` always represents the maximum node value strictly on the simple path from root to the current node.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Full Ancestor Array Check O(N * H) O(H) Scans ancestor list of size up to H at each node.
2. Iterative BFS with (Node, MaxSoFar) Pairs O(N) O(W) Queue of pairs; safe against call-stack overflow.
★ 3. Recursive Top-Down DFS with Scalar Max O(N) O(H) O(1) work per node by passing running max scalar.

Full Ancestor List Passing (Naive)

Pass a list of all ancestor values down the tree. Check every ancestor for values > node.val.

Time: O(N * H) Space: O(H) 
class Solution {
    fun goodNodes(root: TreeNode?): Int {
        if (root == null) return 0
        return dfs(root, mutableListOf())
    }

    private fun dfs(node: TreeNode?, ancestors: MutableList<Int>): Int {
        if (node == null) return 0
        val isGood = if (ancestors.all { it <= node.`val` }) 1 else 0
        ancestors.add(node.`val`)
        val left = dfs(node.left, ancestors)
        val right = dfs(node.right, ancestors)
        ancestors.removeAt(ancestors.size - 1)
        return isGood + left + right
    }
}
Kotlin Runtime & Memory Nuance:

Stores all ancestors on path. Validating all ancestors incurs redundant O(H) overhead per node.

class Solution:
    def goodNodes(self, root: TreeNode) -> int:
        def dfs(node, ancestors):

            is_good = 1 if all(a <= node.val for a in ancestors) else 0
            ancestors.append(node.val)
            cnt = is_good + dfs(node.left, ancestors) + dfs(node.right, ancestors)
            ancestors.pop()
            return cnt
        return dfs(root, [])
Python Runtime & Memory Nuance:

Passing path lists leads to quadratic behavior on skewed trees.

class Solution {
    public int goodNodes(TreeNode root) {
        if (root == null) return 0;
        return dfs(root, new ArrayList<>());
    }

    private int dfs(TreeNode node, List<Integer> ancestors) {
        if (node == null) return 0;
        boolean good = true;
        for (int a : ancestors) {
            if (a > node.val) { good = false; break; }
        }
        int count = good ? 1 : 0;
        ancestors.add(node.val);
        count += dfs(node.left, ancestors);
        count += dfs(node.right, ancestors);
        ancestors.remove(ancestors.size() - 1);
        return count;
    }
}
Java Runtime & Memory Nuance:

Wasteful list allocations and linear lookups at each step.

Iterative BFS with (Node, MaxSoFar) Pairs

Queue BFS storing pairs of (node, maxSoFar). Safe against stack overflow on skewed trees.

Time: O(N) Space: O(W) <= O(N) 
class Solution {
    fun goodNodes(root: TreeNode?): Int {
        if (root == null) return 0
        var count = 0
        val queue = ArrayDeque<Pair<TreeNode, Int>>()
        queue.add(Pair(root, root.`val`))

        while (queue.isNotEmpty()) {
            val (node, maxSoFar) = queue.removeFirst()
            if (node.`val` >= maxSoFar) count++
            val newMax = maxOf(maxSoFar, node.`val`)
            node.left?.let { queue.add(Pair(it, newMax)) }
            node.right?.let { queue.add(Pair(it, newMax)) }
        }
        return count
    }
}
Kotlin Runtime & Memory Nuance:

Iterative approach storing state in the heap queue. Immune to call stack recursion limits.

class Solution:
    def goodNodes(self, root: TreeNode) -> int:
        if not root:
            return 0
        count = 0
        queue = collections.deque([(root, root.val)])

        while queue:

            if node.left:

            if node.right:

Python Runtime & Memory Nuance:

Uses `collections.deque` with lightweight 2-tuples.

class Solution {
    record Pair(TreeNode node, int maxSoFar) {}

    public int goodNodes(TreeNode root) {
        if (root == null) return 0;
        int count = 0;
        Queue<Pair> queue = new ArrayDeque<>();
        queue.offer(new Pair(root, root.val));

        while (!queue.isEmpty()) {
            Pair curr = queue.poll();
            TreeNode node = curr.node;
            int maxSoFar = curr.maxSoFar;
            if (node.val >= maxSoFar) count++;
            int newMax = Math.max(maxSoFar, node.val);
            if (node.left != null) queue.offer(new Pair(node.left, newMax));
            if (node.right != null) queue.offer(new Pair(node.right, newMax));
        }
        return count;
    }
}
Java Runtime & Memory Nuance:

Java 17+ record `Pair` provides compact tuple encapsulation.

Recursive Top-Down DFS with Scalar Max (Optimal Primary)

Pass running maximum value down recursive call stack. Compute result bottom-up.

Time: O(N) Space: O(H) Call Stack 
class Solution {
    /**
     * Optimal: Top-Down DFS Passing Running Maximum
     * Time: O(N) - Every node visited once
     * Space: O(H) - Recursion stack bounded by tree height
     */
    fun goodNodes(root: TreeNode?): Int {
        if (root == null) return 0
        return dfs(root, root.`val`)
    }

    private fun dfs(node: TreeNode?, maxSoFar: Int): Int {
        if (node == null) return 0

        val isGood = if (node.`val` >= maxSoFar) 1 else 0
        val newMax = maxOf(maxSoFar, node.`val`)

        return isGood + dfs(node.left, newMax) + dfs(node.right, newMax)
    }
}
Kotlin Runtime & Memory Nuance:

Passing primitive `maxSoFar` by value means sibling calls do not pollute each other's state.

class Solution:
    # Optimal: Top-Down DFS Passing Running Maximum
    # Time: O(N) - Visits each node once
    # Space: O(H) - Call stack proportional to tree height
    def goodNodes(self, root: TreeNode) -> int:
        def dfs(node: TreeNode, max_so_far: int) -> int:
            if not node:
                return 0
            is_good = 1 if node.val >= max_so_far else 0
            new_max = max(max_so_far, node.val)
            return is_good + dfs(node.left, new_max) + dfs(node.right, new_max)
            
        return dfs(root, root.val)
Python Runtime & Memory Nuance:

Textbook optimal solution. Extremely clean recursion with zero mutable global variables.

class Solution {
    /**
     * Optimal: Top-Down DFS with Scalar Max
     * Time: O(N) - Linear single-pass traversal
     * Space: O(H) - Recursion stack
     */
    public int goodNodes(TreeNode root) {
        if (root == null) return 0;
        return dfs(root, root.val);
    }

    private int dfs(TreeNode node, int maxSoFar) {
        if (node == null) return 0;

        int isGood = (node.val >= maxSoFar) ? 1 : 0;
        int newMax = Math.max(maxSoFar, node.val);

        return isGood + dfs(node.left, newMax) + dfs(node.right, newMax);
    }
}
Java Runtime & Memory Nuance:

Stack frames automatically backtrack `maxSoFar` upon returning from subtrees.
