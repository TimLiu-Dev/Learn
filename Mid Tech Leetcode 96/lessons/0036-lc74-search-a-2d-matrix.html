LeetCode #74: Search a 2D Matrix

Official LC #74

Official Problem Statement

You are given an m x n integer matrix matrix with the following two properties:

  • Each row is sorted in non-decreasing order.
  • The first integer of each row is greater than the last integer of the previous row.

Given an integer target, return true if target is in matrix or false otherwise.

You must write a solution in O(log(m * n)) time complexity.

Example 1: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3 → Output: true

Example 2: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13 → Output: false

Plain-English Translation & Core Nuance

Search for a target value in a 2D grid where every row is sorted and each row strictly follows the previous one. Because the entire grid is in sorted order from top-left to bottom-right, treat it as a flattened 1D array of length m * n and perform a single binary search. Convert 1D index mid to 2D coordinates: row = mid / n, col = mid % n.

Official Constraints:
  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 100
  • -10^4 <= matrix[i][j], target <= 10^4

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
1x1 matrix [[5]], target = 5 → single check, returns true.
Best-Case Early Exit
Target at middle index matrix[m/2][n/2] == target → exits on step 1.
Worst-Case Full Scan
Target not in matrix → standard O(log(m*n)) search interval exhaustion.

The Mental Model & "Explain Like I'm 12"

💡 The Unfolded Calendar Ribbon

Think of a wall calendar with rows (weeks) and columns (days). Because day 8 starts right after day 7, the calendar is just a single long ribbon of numbers folded into rows of width 7. To find any day index `i` on the calendar, week is `i / 7` and day of week is `i % 7`. You can binary search the entire year in one smooth sequence without checking row by row.

The Mental "A-Ha!" Switch:

A 2D matrix with these properties is mathematically identical to a 1D sorted array of length `m * n`. Virtual mapping: index `mid` → `matrix[mid / cols][mid % cols]` in O(1) time.

Pattern Trigger:

Whenever searching a sorted 2D matrix where row starts > previous row ends → Flattened 1D Binary Search.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(m * n) Time, O(1) Space

Nested loop scanning all elements row by row. Completely ignores sorted properties.

Wasted Work: Checking every cell instead of eliminating half the search space at each step.
The Optimal Breakthrough O(log(m * n)) Time, O(1) Space

Standard binary search over range `[0..m*n - 1]`. Halves search space on every iteration.

Core Invariant: If target exists in the matrix, it must lie within the flattened 1D interval `[left..right]`.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Linear Scan O(m * n) O(1) Scans every cell; fails logarithmic requirement.
2. Double Binary Search O(log m + log n) O(1) Search row first, then search column.
★ 3. Virtual 1D Binary Search O(log(m * n)) O(1) Single binary search via coordinate math. Optimal.

From Naive to Optimal & Runnable Practice Arena

Two Binary Searches (Row then Col)

Binary search first column to find row, then binary search within that row.

Time: O(log m + log n) = O(log(m * n)) Space: O(1) 
class Solution {
    fun searchMatrix(matrix: Array<IntArray>, target: Int): Boolean {
        val m = matrix.size
        val n = matrix[0].size

        // 1. Binary search target row
        var top = 0
        var bot = m - 1
        var targetRow = -1

        while (top <= bot) {
            val mid = top + (bot - top) / 2
            if (target >= matrix[mid][0] && target <= matrix[mid][n - 1]) {
                targetRow = mid
                break
            } else if (target < matrix[mid][0]) {
                bot = mid - 1
            } else {
                top = mid + 1
            }
        }

        if (targetRow == -1) return false

        // 2. Binary search within targetRow
        var l = 0
        var r = n - 1
        while (l <= r) {
            val mid = l + (r - l) / 2
            if (matrix[targetRow][mid] == target) return true
            else if (matrix[targetRow][mid] < target) l = mid + 1
            else r = mid - 1
        }
        return false
    }
}

Optimal: Virtual 1D Flattened Binary Search (Production Standard)

Single binary search treating m x n matrix as 1D array via mid / n and mid % n.

Time: O(log(m * n)) Space: O(1) 
class Solution {
    /**
     * Optimal: Virtual 1D Binary Search
     * Time: O(log(m * n)) - Single binary search loop
     * Space: O(1) - Constant auxiliary memory
     */
    fun searchMatrix(matrix: Array<IntArray>, target: Int): Boolean {
        val m = matrix.size
        val n = matrix[0].size
        var left = 0
        var right = m * n - 1

        while (left <= right) {
            val mid = left + (right - left) / 2
            val midVal = matrix[mid / n][mid % n]

            when {
                midVal == target -> return true
                midVal < target -> left = mid + 1
                else -> right = mid - 1
            }
        }

        return false
    }
}
Kotlin Runtime & Memory Nuance:

Cleanest possible code. `mid / n` gives row index, `mid % n` gives column index.

Top-Right Corner Elimination (Search 2D Matrix II Style)

Start at top-right corner; step left if value > target, step down if value < target.

Time: O(m + n) Space: O(1) 
class Solution {
    fun searchMatrix(matrix: Array<IntArray>, target: Int): Boolean {
        var r = 0
        var c = matrix[0].size - 1

        while (r < matrix.size && c >= 0) {
            val curr = matrix[r][c]
            if (curr == target) return true
            else if (curr > target) c--
            else r++
        }
        return false
    }
}

Runs in O(m + n) time. Slower than O(log(m*n)) for this problem, but universal for LC 240.
