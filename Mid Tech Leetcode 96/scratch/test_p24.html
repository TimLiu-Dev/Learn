LeetCode #443: String Compression

Official LC #443

Official Problem Statement

Given an array of characters chars, compress it using the following algorithm:

Begin with an empty string s. For each group of consecutive repeating characters in chars:

  • If the group's length is 1, append the character to s.
  • Otherwise, append the character followed by the group's length.

The compressed string s should not be returned separately, but instead, be stored in the input character array chars. Note that group lengths that are 10 or longer will be split into multiple characters in chars.

After you are done modifying the input array, return the new length of the array.

You must write an algorithm that uses only constant extra space.

Example 1: chars = ["a","a","b","b","c","c","c"] → Output: 6, chars = ["a","2","b","2","c","3"]

Example 2: chars = ["a"] → Output: 1, chars = ["a"]

Example 3: chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"] → Output: 4, chars = ["a","b","1","2"]

Plain-English Translation & Core Nuance

Perform in-place run-length encoding directly inside the given char array. Count consecutive repeating characters. Write the character, and if count > 1, write each digit of the count into the array. Return the new length, using strictly O(1) auxiliary space.

Official Constraints:
  • 1 <= chars.length <= 2000
  • chars[i] is a lowercase English letter, uppercase English letter, digit, or symbol.

Canonical Input Shapes (Mental Boundary Checks)

Minimum Base Case
chars = ["a"] → Single character, count 1 → return 1.
Best-Case Early Exit
All distinct chars ["a","b","c"] → No compression needed, return N.
Worst-Case Full Scan
12 consecutive 'b's → 'b','1','2' (length 3, multi-digit count split).

The Mental Model & "Explain Like I'm 12"

💡 The Tape Recorder Overwriter

Imagine a cassette tape where a scanner head (read pointer) moves forward listening to repeated musical tones. A recording head (write pointer) follows behind on the same tape, overwriting old data with a compressed summary: the tone symbol followed by its repeat count. Because a compressed group (char + digits) is always less than or equal to the uncompressed group length, the write head never overtakes the read head.

The Mental "A-Ha!" Switch:

Two pointers (read & write) operating on the same array. Since 1 char takes 1 cell, 2 chars take 2 cells ('a2'), and 10 chars take 3 cells ('a10'), the write pointer is strictly <= read pointer at all times.

Pattern Trigger:

Whenever asked for in-place array modification with run-length or grouping → Fast/Slow Read-Write Two Pointers.

Algorithmic Trade-off Analysis

The Naive Trap (Red) vs. Optimal Breakthrough (Green)

The Naive Trap O(N) Time, O(N) Auxiliary Space

Build a StringBuilder or list containing compressed tokens, then copy characters back to chars. Fails the strict O(1) space interview constraint.

Wasted Work: Allocating heap memory for a temporary buffer when the input array has sufficient capacity.
The Optimal Breakthrough O(N) Time, O(1) Auxiliary Space

Linear scan with `read` finding group boundaries, and `write` updating characters and count digits in-place.

Core Invariant: write <= read at all iterations; no unread character is ever prematurely overwritten.
Approach Time Complexity Space Complexity Practical Trade-off / Bottleneck
1. Auxiliary Buffer O(N) O(N) Allocates StringBuilder; violates O(1) space constraint.
★ 2. In-Place Read/Write O(N) O(1) Modifies chars array directly. Constant memory.

Naive: Auxiliary Buffer

Construct compressed string in StringBuilder, then copy back to array.

Time: O(N) Space: O(N) 
class Solution {
    fun compress(chars: CharArray): Int {
        val sb = StringBuilder()
        var i = 0
        while (i < chars.size) {
            val char = chars[i]
            var count = 0
            while (i < chars.size && chars[i] == char) {
                count++
                i++
            }
            sb.append(char)
            if (count > 1) sb.append(count)
        }
        for (j in 0 until sb.length) {
            chars[j] = sb[j]
        }
        return sb.length
    }
}

Better: Two Pointers with String Split

Two pointers using standard string formatting for digits.

Time: O(N) Space: O(1) 
class Solution {
    fun compress(chars: CharArray): Int {
        var write = 0
        var read = 0
        while (read < chars.size) {
            val start = read
            val ch = chars[start]
            while (read < chars.size && chars[read] == ch) {
                read++
            }
            chars[write++] = ch
            val count = read - start
            if (count > 1) {
                for (digit in count.toString()) {
                    chars[write++] = digit
                }
            }
        }
        return write
    }
}

Optimal: Pure In-Place Mathematical Digit Extraction

Pure O(1) auxiliary space without even temporary string allocation for count digits.

Time: O(N) Space: O(1) Absolute Zero Heap Allocation 
class Solution {
    /**
     * Optimal: In-Place Two Pointers with Arithmetic Digit Extraction
     * Time: O(N) - Linear single pass over characters
     * Space: O(1) - Zero heap allocations; absolute constant memory
     */
    fun compress(chars: CharArray): Int {
        var write = 0
        var read = 0
        
        while (read < chars.size) {
            val start = read
            val ch = chars[start]
            while (read < chars.size && chars[read] == ch) {
                read++
            }
            
            chars[write++] = ch
            val count = read - start
            
            if (count > 1) {
                // Invert digits arithmetically or write via digit scan
                val digitStart = write
                var temp = count
                while (temp > 0) {
                    chars[write++] = '0' + (temp % 10)
                    temp /= 10
                }
                // Reverse written digits into correct significant order
                var l = digitStart
                var r = write - 1
                while (l < r) {
                    val swap = chars[l]
                    chars[l] = chars[r]
                    chars[r] = swap
                    l++; r--
                }
            }
        }
        return write
    }
}
Kotlin Runtime & Memory Nuance:

Demonstrates staff-level systems awareness: extracts digits via modulo/division and reverses in-place, eliminating temporary String objects.

class Solution {
    /**
     * Optimal: In-Place Two Pointers with Arithmetic Digit Extraction
     * Time: O(N) - Linear scan
     * Space: O(1) - Pure zero-allocation
     */
    public int compress(char[] chars) {
        int write = 0;
        int read = 0;

        while (read < chars.length) {
            int start = read;
            char ch = chars[start];
            while (read < chars.length && chars[read] == ch) {
                read++;
            }

            chars[write++] = ch;
            int count = read - start;

            if (count > 1) {
                int digitStart = write;
                int temp = count;
                while (temp > 0) {
                    chars[write++] = (char) ('0' + (temp % 10));
                    temp /= 10;
                }
                // Reverse digits in-place
                int l = digitStart;
                int r = write - 1;
                while (l < r) {
                    char swap = chars[l];
                    chars[l] = chars[r];
                    chars[r] = swap;
                    l++; r--;
                }
            }
        }
        return write;
    }
}
Java Runtime & Memory Nuance:

Avoids String/Integer wrappers entirely. Critical for real-time low-latency systems (e.g. streaming telemetry).
