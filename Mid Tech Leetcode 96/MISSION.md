# Mission: Mid-Tech LeetCode 103 — 2027 Mid-Level (Pre-Senior) Masterclass

## Why
Pass 2027 **Mid-Level Software Engineer (SDE II / L4, pre-Senior)** technical interviews across the full Mid-Tech ecosystem (Fintech, Retail/E-Commerce, Consumer Apps, Mobility/Hospitality, and Enterprise SaaS — spanning CodeSignal GCA, CodeSignal 4-Stage Progressive ICA, Karat live screens, and human pair-programming loops). Build durable storage strength across the 96 foundational problems plus 7 essential 2027 Mid-Level additions (`#0097`–`#0103`) to pitch space-time trade-offs clearly and write clean, bug-free production code from scratch.

## Curriculum Scope (103 Problems)
1. **Pass 1 — Foundation Easy (`#0001`–`#0022`, plus `#0097` LC #88 Merge Sorted Array & `#0098` LC #359 Logger Rate Limiter)**: Core instincts for phone screens and OA warm-ups.
2. **Pass 2A — Core Medium Templates (`#0023`–`#0057`, plus `#0099` LC #53 Maximum Subarray & `#0100` LC #48 Rotate Image)**: Canonical interview workhorses unlocking 85%+ of Mid-Tech loops.
3. **Pass 2B — Stretch Medium Variations (`#0058`–`#0089`, plus `#0101` LC #79 Word Search, `#0102` LC #399 Evaluate Division & `#0103` LC #5 Longest Palindromic Substring)**: Multi-pattern synthesis, Karat grid backtracking, weighted ratio graphs, and progressive in-memory OOP systems.
4. **Pass 3 — High-ROI Upper-Bar Hards (`#0090`–`#0096`)**: The 7 highest-frequency stretch Hards used as bar-raisers in upper Mid-Tech (`#42`, `#76`, `#239`, `#23`, `#124`, `#295`, `#588`).

## Success looks like
- Solving any Pass 1–2B problem cold from an empty method stub within 15–25 minutes without revealing hints.
- Executing the 4-phase live interview script aloud: clarifying constraints, pitching brute-to-optimal trade-offs, writing idiomatic code, and dry-running boundary cases.
- Writing idiomatic **Kotlin (primary)**, **Python**, and **Java** while explaining collection and memory trade-offs accurately.
- Passing all in-browser runnable test suites, 4-question diagnostic code quizzes, and 48-hour spaced cold recall checks.

## Constraints
- 100% standalone, offline-friendly HTML lessons (`https://cdn.tailwindcss.com` + shared `./assets/` CSS/JS, zero local server required).
- Strict language ordering everywhere: **Kotlin (Default) → Python → Java**.
- Effortful retrieval over passive reading: practice editors open with empty method stubs, gated progressive Hints (`1–3`), and gated Final Answer reveal.

## Out of scope
- Senior/Staff (`L5+`) distributed systems design, multi-threaded lock-striping/concurrency primitives, and consensus protocols.
- Low-ROI competitive programming structures (Fenwick Trees, Lazy Segment Trees, Treaps, Aho-Corasick, Heavy-Light Decomposition).
