# Mission: Design Patterns for 2027 Senior Android & Spring Boot Engineers

## Why
Transition from a junior developer (starting with zero design-pattern knowledge) to a 2027 Senior Engineer capable of architecting both the **Android client** (Part 1: Kotlin, Compose, KMP, Offline-First) and the **Java + Spring Boot backend** (Part 2: Java 21–25, Virtual Threads, Hexagonal, Double-Entry Ledger, Sagas, Resilience4j) powering the end-to-end **PayVault** Fintech Wallet & Payment Engine—strong enough for a senior resume and system-design interviews.

## Success looks like
- **Part 1 (Android Senior Track — L0001–L0023):** Architect decoupled, offline-first Kotlin/Compose apps with pure-JVM testable domains, MVI state machines, Transactional Outbox, and Circuit Breakers.
- **Part 2 (Java Spring Boot Senior Track — L0024–L0033):** Build high-integrity Spring Boot backends using modern Java (Records, Sealed types, Virtual Threads), Spring AOP/Proxy mastery, Hexagonal/Spring Modulith boundaries, Optimistic Locking + Double-Entry Ledgers, Server Idempotency + Outbox-to-Kafka, Distributed Sagas, and Resilience4j.
- **Part 3 (Polyglot Spring Boot Java + Kotlin Side-by-Side & 23/23 GoF — L0034–L0039):** Complete all 23/23 GoF patterns (adding Flyweight, Interpreter, Null Object) and master Spring Boot in Java and Kotlin side-by-side (`allopen`, Coroutines vs. Virtual Threads, `coRouter`, Specification, MockK/Mockito, Testcontainers).

## Constraints
- Self-paced interactive HTML lessons (`master-plan.html` legend + `./lessons/0001..0033.html`) with runnable auto-graded labs, 3 progressive hints, final answers, and balanced code quizzes explaining both right and wrong answers.
- `file://` compatible offline-first interactive experience (Offline JS Sandbox + Kotlin Playground / Java 21+ Reference).

## Out of scope
- Non-JVM language ecosystems (Go/Rust/Python backends) and Kubernetes YAML/Terraform ops deep dives beyond service resilience boundaries.
