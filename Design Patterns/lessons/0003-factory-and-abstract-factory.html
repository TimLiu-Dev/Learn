Factory Method & Abstract Factory: Centralizing Creation

Knowing what interface to call isn't enough if every screen still has a 40-line when (region) constructing concrete classes. Factories encapsulate which concrete object (or coherent family of objects) gets created so callers stay clean and Open/Closed.

Creational Regional Rails (US/EU/BR) KMP / DI

The Junior → Senior Shift: Regional Payment Rails in PayVault

PayVault launches in 3 regions: US (ACH + USD Tax Formatter + SSN KYC), EU (SEPA + EUR Formatter + IBAN KYC), and BR (Pix + BRL Formatter + CPF KYC). If a ViewModel constructs SepaRail() in one file and UsdFormatter() in another, you risk fatal mismatches like pairing a Pix rail with a US SSN validator!

Per Refactoring.Guru, Factory Method abstracts creating one product, while Abstract Factory produces an entire compatible family of related objects.

1. Factory Method & Registry Factory

Kotlin — Registry-Based Rail Factory (Zero ViewModel Coupling)
interface PaymentRail { fun submit(cents: Long): String }

class PaymentRailFactory(
    private val creators: Map<String, () -> PaymentRail>
) {
    fun create(railCode: String): PaymentRail =
        creators[railCode]?.invoke()
            ?: throw IllegalArgumentException("Unknown rail: $railCode")
}

2. Abstract Factory: Enforcing Coherent Regional Families

Kotlin — Regional Fintech Suite Factory
interface RegionalPayFactory {
    fun createRail(): PaymentRail
    fun createIdValidator(): (String) -> Boolean
}

class BrazilPayFactory : RegionalPayFactory {
    override fun createRail() = PixRail()
    override fun createIdValidator() = { cpf: String -> cpf.length == 11 }
}

5. 2027 Senior Android Interview Corner

Q1: "When do we use a Factory if we already have Hilt / Dependency Injection?"
Senior Answer: Hilt injects static compile-time dependency graphs. When the concrete implementation depends on runtime user input (e.g., chosen currency, region, or dynamic feature flag) or you need fresh instances per call (`@AssistedFactory`), you inject a Factory!
