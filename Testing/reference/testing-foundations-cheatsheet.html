AAA Structure

  • Arrange: Build fresh inputs, fixed clocks, and test doubles inside the test.
  • Act: Invoke the single behavior under test.
  • Assert: Compare against an independent concrete Test Oracle (or assertThrows).

F.I.R.S.T. Checklist

  • Fast: Milliseconds on JVM (src/test) wherever Android UI isn't needed.
  • Isolated: Zero shared mutable globals or execution-order dependencies.
  • Repeatable: Inject Clock, random seeds, and dispatchers; zero real network.
  • Self-Validating: Explicit pass/fail assertions, never println() inspection.
  • Timely: Written alongside or before production code (Shift-Left).
