Senior Backend Developer Testing Cheat Sheet (Spring Boot)

Modern Spring Boot 3.4+/4.x testing architecture for Java 21+ and Kotlin: Slices, Context Caching, Testcontainers @ServiceConnection, Security, Awaitility, Kafka, and Transactions.

LayerAnnotation / ToolJava / Kotlin Rule

JPA + SQL + Redis + Flyway@DataJpaTest + @AutoConfigureTestDatabase(NONE) + @ServiceConnectionReal Postgres + Redis containers + Flyway; clear L1 cache (em.flush(); em.clear()) and assert N+1 SQL counts.
