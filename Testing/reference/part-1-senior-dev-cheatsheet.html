Senior Android Developer Quality Cheat Sheet

Everything a Senior Android Developer puts into daily PRs: test design, DI for testability, JUnit 5, MockK/Fakes, Coroutines + Turbine, Room, MockWebServer, Compose UI, and Roborazzi.

Black-Box & White-Box Quick Rules

  • EP + BVA: Pick 1 valid/invalid representative per partition + exact boundaries (min-1, min, max, max+1).
  • Decision Tables: Cover every rule column when 3+ boolean conditions interact.
  • Coverage vs Mutation: Branch coverage beats line coverage; Mutation Score proves assertions fail when code breaks.
  • DI for Testability: Never call Instant.now(), UUID.randomUUID(), or Dispatchers.IO directly inside business logic; inject providers.

Test Doubles & Coroutines

  • Fake > Mock for stateful repositories/DAOs; use MockK (coEvery/verify) selectively at external boundaries.
  • runTest + StandardTestDispatcher: Explicit advanceUntilIdle() or advanceTimeBy() catches loading/debounce states cleanly.
  • Turbine (flow.test { ... }): Assert ordered awaitItem() emissions and cancelAndIgnoreRemainingEvents().
  • Property Testing: Test invariants (round-trip, monotonicity, idempotency) across 1,000 generated inputs.
