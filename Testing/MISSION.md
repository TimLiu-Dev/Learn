# Mission: Multi-Track Mastery — Senior Android Dev &amp; Senior Backend Dev (Spring Boot) &rarr; Senior Testing Engineer (2027)

## Why
Level up from a Junior Android Developer across three concrete, resume-backed milestones:
1. **Part 1 (Senior Android Developer Track):** Master unit, async, integration, Compose UI, and Roborazzi visual testing in Kotlin.
2. **Part 1A (Senior Backend Developer Track — Spring Boot Java &amp; Kotlin):** Master Spring Boot test slices (`@WebMvcTest`, `@DataJpaTest`), `@MockitoBean`/`@MockkBean`, `@ServiceConnection` Testcontainers + Flyway, Spring Security JWT/RBAC, Awaitility/Kafka, transactions &amp; optimistic locking concurrency.
3. **Part 2 (Senior Testing Engineer / SDET Track):** Expand across Pact contracts, Appium/Maestro, Playwright Web/API E2E, Macrobenchmark/k6, OWASP MASVS, AI evals, and sharded CI/CD to qualify for Senior Testing Engineer (SDET) roles in 2027.

## Success looks like
- **Part 1 Milestone (`0013`):** Ship **Project 1 ("PulseCart Android")** — Senior Android Developer test suite.
- **Part 1A Milestone (`0031`):** Ship **Project 1A ("PulseOrder Spring Boot")** — Senior Backend Developer (Java &amp; Kotlin) test suite.
- **Part 2 Capstone (`0026`):** Ship **Project 2 ("ShopPulse E2E")** — Full-stack Senior SDET portfolio across Android, Spring Boot API, Web Admin, and CI/CD.

## Constraints
- Starting baseline: Junior Android Developer (Kotlin, Gradle, Compose, ViewModels).
- Learning format: Interactive HTML lessons in `./lessons/` with runnable browser labs (checks, mutation verification, progressive hints, final answers), matched-word-count MCQs explaining right and wrong options, and printable `./reference/` sheets.
- Target era: 2026/2027 industry relevance (Spring Boot 3.4+/4.x, Java 21+, Kotlin).

## Out of scope
- Manual click-testing workflows without automation/engineering rigor.
- Legacy deprecated Spring annotations (`@MockBean`, JUnit 4 `@RunWith(SpringRunner.class)`) except for migration awareness.
