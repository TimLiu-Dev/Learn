Lesson 10: API & Network Testing (OkHttp MockWebServer)

Mocking a Retrofit interface with MockK never exercises your Moshi/Kotlinx.serialization annotations, OkHttp auth interceptors, HTTP status mapping, or request headers. MockWebServer spins up a real local HTTP server on localhost in milliseconds.

00 Why Mocking Retrofit Interfaces Leaves Huge Blind Spots

Bug ClassMockK on ApiServiceMockWebServer (Real HTTP Loopback)
Wrong @SerialName("user_id")Missed completely (returns Kotlin DTO directly).Caught immediately when real JSON fails to parse!
Missing Authorization: Bearer headerMissed (interceptor never runs).Caught via server.takeRequest().getHeader("Authorization").

01 Enqueue Responses, Dispatchers & Token Refresh Authenticators

Always shut down MockWebServer in @AfterEach (or JUnit extension) so sockets never leak across tests. For multi-step flows (like 401 → /refresh → retry original request), use a Dispatcher or sequential enqueue() responses and assert server.requestCount to ensure an infinite 401 retry loop is impossible! 

@Test
fun `getOrders sends Bearer token and parses snake_case JSON`() = runTest {
  val server = MockWebServer()
  server.enqueue(MockResponse().setResponseCode(200).setBody("""{"order_id":"ord-9","total_cents":1999}"""))

  val api = buildRetrofit(server.url("/")).create(OrdersApi::class.java)
  val order = api.getOrder("ord-9")
  val recorded = server.takeRequest()

  assertThat(recorded.path).isEqualTo("/orders/ord-9")
  assertThat(recorded.getHeader("Authorization")).isEqualTo("Bearer tok-123")
  assertThat(order.totalCents).isEqualTo(1999)
  server.shutdown()
}
@Test
fun `401 refreshes token once and stops if refreshed token still fails`() = runTest {
  server.enqueue(MockResponse().setResponseCode(401)) // Initial call fails
  server.enqueue(MockResponse().setResponseCode(200).setBody("""{"accessToken":"new-tok"}""")) // /refresh
  server.enqueue(MockResponse().setResponseCode(200).setBody("""{"order_id":"ord-9","total_cents":1999}""")) // Retry

  val order = api.getOrder("ord-9")

  assertThat(order.id).isEqualTo("ord-9")
  assertThat(server.requestCount).isEqualTo(3)
  assertThat(server.takeRequest().path).isEqualTo("/orders/ord-9")
  assertThat(server.takeRequest().path).isEqualTo("/auth/refresh")
  assertThat(server.takeRequest().getHeader("Authorization")).isEqualTo("Bearer new-tok")
}
val mockEngine = MockEngine { request ->
  when (request.url.encodedPath) {
    "/health" -> respond("""{"status":"ok"}""", HttpStatusCode.OK, headersOf(HttpHeaders.ContentType, "application/json"))
    else -> respond("Not found", HttpStatusCode.NotFound)
  }
}

02 The Network Edge-Case Matrix Every Senior Checks

Always verify: (1) outgoing URL, query params, and Auth headers; (2) 200 empty arrays & null optional fields; (3) 401 refresh vs 403 forbidden (403 must NOT trigger refresh!); (4) 429 rate-limit + Retry-After; (5) 502 HTML gateway page (non-JSON body!) & SocketPolicy.NO_RESPONSE timeouts.
