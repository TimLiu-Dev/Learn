Lesson 11: Jetpack Compose UI Testing

Jetpack Compose has no XML R.id.btn_submit views. Instead, it exposes a Semantics Tree (Compose Testing Docs) shared directly with TalkBack accessibility! Testing via semantics verifies both UI behavior and accessibility at once.

01 Finder → Action → Assertion, Navigation & Semantics

Note: Compose UI Test has no built-in onNodeWithRole() helper—use onNode(hasRole(Role.Button) and hasText("Pay Now")) with a 2-line SemanticsMatcher.expectValue(SemanticsProperties.Role, role) helper, or query directly by text/contentDescription. For multi-screen flows, pass a TestNavHostController so you can assert the exact destination route after a click. 

@get:Rule val composeRule = createComposeRule()

fun hasRole(role: Role) = SemanticsMatcher.expectValue(SemanticsProperties.Role, role)

@Test
fun `checkout button enables only after terms checkbox is checked`() {
  composeRule.setContent {
    CheckoutButtonBar(onSubmit = submittedSpy)
  }

  composeRule.onNode(hasRole(Role.Button) and hasText("Pay Now")).assertIsNotEnabled()
  composeRule.onNodeWithText("I agree to terms").performClick()
  composeRule.onNode(hasRole(Role.Button) and hasText("Pay Now")).assertIsEnabled().performClick()

  assertThat(submittedSpy.wasCalled).isTrue()
}
@Test
fun `tapping item navigates to order detail route with orderId`() {
  lateinit var navController: TestNavHostController
  composeRule.setContent {
    navController = TestNavHostController(LocalContext.current).apply {
      navigatorProvider.addNavigator(ComposeNavigator())
    }
    ShopPulseNavGraph(navController = navController)
  }

  composeRule.onNodeWithText("Order #ord-9").performClick()
  assertThat(navController.currentBackStackEntry?.destination?.route).isEqualTo("orders/{orderId}")
  assertThat(navController.currentBackStackEntry?.arguments?.getString("orderId")).isEqualTo("ord-9")
}
// 1. Scroll off-screen LazyColumn items by semantics key/tag:
composeRule.onNodeWithTag("orders_list").performScrollToNode(hasText("Order #42"))

// 2. Inspect unmerged child semantics inside a clickable Row:
composeRule.onNodeWithTag("item_row", useUnmergedTree = true).assertIsDisplayed()

// 3. Freeze animation clock to assert mid-transition state deterministically:
composeRule.mainClock.autoAdvance = false
composeRule.onNodeWithText("Expand").performClick()
composeRule.mainClock.advanceTimeBy(150)
composeRule.waitUntil(timeoutMillis = 3_000) {
  composeRule.onAllNodesWithText("Order Confirmed").fetchSemanticsNodes().isNotEmpty()
}

02 Why State Hoisting Unlocks Fast Compose Tests

When a Composable takes (uiState: CartUiState, onRemove: (String) -> Unit) instead of a live ViewModel, you can render Loading, Empty, Error, and Populated states directly with createComposeRule() without mocking networks or databases.
