Lesson 18: Modern Web & Full-Stack E2E with Playwright

Senior SDETs don't stop at Android — real products include Web Admin dashboards, checkout portals, and REST APIs. Playwright sets the 2027 standard with multi-browser isolation (BrowserContexts), auto-waiting user-facing locators, network route interception, and time-travel Trace Viewer.

01 User-Facing Locators, Fixtures, storageState & Visual Snapshots

Log in once inside a Playwright setup project and save cookies/localStorage to playwright/.auth/admin.json (storageState) so 100 test files skip repeating UI login! Combine getByRole locators, custom test.extend fixtures, page.route() fault mocking, and toHaveScreenshot() visual checks in one TypeScript runner. 

test("admin refunds order and handles 500 error banner", async ({ page }) => {
  await page.route("**/api/orders/ord-9/refund", (route) =>
    route.fulfill({ status: 500, json: { error: "Gateway down" } })
  );

  await page.goto("/admin/orders/ord-9");
  await page.getByRole("button", { name: "Issue Refund" }).click();

  await expect(page.getByRole("alert")).toContainText("Gateway down");
});
test("API + UI hybrid: seed order via API then verify in browser", async ({ request, page }) => {
  const created = await request.post("/api/orders", { data: { sku: "SKU-1", qty: 1 } });
  expect(created.ok()).toBeTruthy();
  await page.goto("/admin/orders");
  await expect(page.getByText("SKU-1")).toBeVisible();
});
// playwright.config.ts: use: { storageState: "playwright/.auth/admin.json", trace: "on-first-retry" }
// Custom Page Object fixture:
export const test = base.extend<{ ordersPage: OrdersAdminPage }>({
  ordersPage: async ({ page }, use) => {
    const pom = new OrdersAdminPage(page);
    await pom.goto();
    await use(pom);
  }
});

test("orders summary matches visual baseline", async ({ ordersPage, page }) => {
  await expect(ordersPage.summaryCard).toHaveScreenshot("orders-summary.png", { maxDiffPixelRatio: 0.01 });
});

02 Why Web-First Assertions Prevent Flakes

Never write expect(await locator.isVisible()).toBe(true) — that evaluates once instantly with zero retry! Always use await expect(locator).toBeVisible() so Playwright auto-retries until timeout without blocking.
