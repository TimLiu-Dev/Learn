Lesson 12: Visual & Screenshot Regression Testing

A Compose semantics test says assertIsDisplayed() — even when white text renders on a white dark-mode background, or a button clips off-screen at 200% font scale! Paparazzi and Roborazzi catch pixel regressions in seconds right on the JVM.

00 What Functional UI Tests Cannot See

Semantics tests check existence and state; Screenshot tests check pixels and layout geometry: truncated German strings, broken RTL mirroring, missing dark-mode tokens, overlapping badges, and clipped CTAs under large system fonts.

Eliminate Cross-OS Font Flakes & Dynamic Data Noise
macOS and Linux CI render sub-pixel fonts slightly differently! Always record and verify goldens in the same OS environment (e.g., Linux Docker container in CI), inject fixed clocks/static images (Coil fake engine), and disable blinking cursors/indeterminate progress spinners before capturing.
