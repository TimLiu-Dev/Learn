01 Equivalence Partitioning (EP) & Boundary Value Analysis (BVA)

Equivalence Partitioning (EP)

Group inputs that should behave identically into partitions. Testing 25 and 26 for an 18..65 rule wastes effort — pick 1 valid (30) and both invalid sides (10, 80).

  • Valid Partition: 18..65 → pick 30
  • Invalid Low: < 18 → pick 10 (plus -1 for negative/type guard)
  • Invalid High: > 65 → pick 80

Boundary Value Analysis (BVA)

Bugs cluster at edges (< vs <=, off-by-one indexing). For valid range [18, 65], test exact edges and immediate neighbors: 17, 18 and 65, 66 (2-value BVA).

  • 2-Value BVA: {17, 18, 65, 66} (minimum to catch > vs >=)
  • 3-Value BVA (High-Risk): {17, 18, 19, 64, 65, 66} (catches exact equality mistakes too)
Senior Trap: Never Combine Invalid Inputs in One Test!
If a promo check rejects both expired = true AND subtotal = -50, passing both in one call only tests whichever if runs first — masking bugs in the second check! Isolate each invalid partition into its own test case.

02 Decision Tables & State Transition Testing

When multiple conditions interact (e.g., VIP status + order total + coupon validity), a Decision Table guarantees no combination slips through. When behavior depends on history (e.g., Android checkout cart, media player, or subscription lifecycle), draw a State Transition Table and verify both valid transitions and forbidden transitions.

03 Pairwise Testing & JUnit 5 @ParameterizedTest

If an Android app has 4 toggles/configs (OS API × Theme × Network × Locale = 3 × 2 × 3 × 4 = 72 combinations), Pairwise (All-Pairs) testing covers every pair of parameter values in ~12 tests, catching ~90%+ of multi-factor config bugs (JUnit 5 User Guide). 

@ParameterizedTest(name = "age={0} -> valid={1}")
@CsvSource(
  "17, false", // Below lower boundary
  "18, true",  // Lower boundary
  "65, true",  // Upper boundary
  "66, false"  // Above upper boundary
)
fun `validateDriverAge checks inclusive 18 to 65 boundaries`(age: Int, expected: Boolean) {
  assertThat(validator.isEligible(age)).isEqualTo(expected)
}
companion object {
  @JvmStatic
  fun shippingRules() = listOf(
    Arguments.of(true,  1_000, null,       0),   // R1: Prime always free
    Arguments.of(false, 5_000, null,       0),   // R2: Non-Prime >= $50 boundary
    Arguments.of(false, 4_999, "FREESHIP", 0),   // R3: Coupon waives fee below $50
    Arguments.of(false, 4_999, null,       799)  // R4: Base fee applies at $49.99
  )
}

@ParameterizedTest(name = "prime={0}, total={1}, coupon={2} -> fee={3}")
@MethodSource("shippingRules")
fun `shipping calculator satisfies every decision rule`(
  isPrime: Boolean, totalCents: Int, coupon: String?, expectedFee: Int
) {
  assertThat(calculator.feeCents(isPrime, totalCents, coupon)).isEqualTo(expectedFee)
}
@Test
fun `cancelled order cannot transition to shipped`() {
  val order = Order(state = OrderState.DRAFT)
  order.submit()
  order.cancel()

  assertThrows<IllegalStateException> { order.ship() }
  assertThat(order.state).isEqualTo(OrderState.CANCELLED)
}
