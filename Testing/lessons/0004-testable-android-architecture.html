Lesson 04: Designing Testable Android Architecture

Hard-to-test code is almost always tightly coupled code. Before touching MockK or Robolectric, learn how Senior Android Developers structure dependencies so 80% of logic runs on the plain JVM with zero Android Context.

01 The 5 Testability Killers on Android

Avoid Directly Inside Domain/ViewModel
  • object Singleton with mutable fields
  • System.currentTimeMillis() / Instant.now()
  • UUID.randomUUID() / Random.nextInt()
  • Hardcoded Dispatchers.IO / Dispatchers.Main
  • android.content.Context / SharedPreferences in UseCases
Senior Constructor-Injected Equivalents
  • Interface + Hilt @Singleton binding
  • Injected Clock (Clock.fixed() in tests)
  • Injected IdGenerator (() -> "id-1" in tests)
  • Injected DispatcherProvider (StandardTestDispatcher)
  • Repository/Storage interface + In-Memory Fake in src/test

02 Clean DI, Hilt @TestInstallIn & Characterization Tests

Constructor injection keeps pure Kotlin UseCases and ViewModels testable on the local JVM in ~5ms. For Hilt integration tests, swap production bindings cleanly with @TestInstallIn instead of brittle reflection hacks. When refactoring untested legacy code, write Characterization Tests first to lock down existing behavior before breaking dependencies apart. 

class RecordDailyStreakUseCase(
  private val storage: StreakStorage,
  private val clock: Clock,
  private val dispatchers: DispatcherProvider
) {
  suspend fun recordVisit(): Int = withContext(dispatchers.io) {
    val today = LocalDate.now(clock)
    val last = storage.lastVisitDate()
    val nextCount = when {
      last == today -> storage.currentStreak() // Same-day idempotent
      last == today.minusDays(1) -> storage.currentStreak() + 1
      else -> 1
    }
    storage.save(today, nextCount)
    nextCount
  }
}
// ANTI-PATTERN: Impossible to run reliably in src/test!
object LegacyStreakHelper {
  fun recordVisit(context: Context): Int {
    val prefs = context.getSharedPreferences("app", Context.MODE_PRIVATE) // Android dependency!
    val today = LocalDate.now() // Hidden real system clock -> flaky at midnight!
    // ... mutates global prefs directly
    return 1
  }
}
@Module @InstallIn(SingletonComponent::class)
object TimeModule {
  @Provides fun provideClock(): Clock = Clock.systemUTC()
}

// In src/androidTest or Robolectric Hilt test:
@Module @TestInstallIn(components = [SingletonComponent::class], replaces = [TimeModule::class])
object FakeTimeModule {
  @Provides fun provideClock(): Clock = Clock.fixed(Instant.parse("2027-01-15T12:00:00Z"), ZoneOffset.UTC)
}
