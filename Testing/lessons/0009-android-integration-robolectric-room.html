Lesson 09: Android Component Integration

Mocking a Room DAO hides SQL syntax bugs, broken foreign keys, and destructive schema migrations. Learn how Senior Android Developers test real Room queries, database migrations, WorkManager constraints, and Hilt bindings cleanly.

00 Never Mock Your Own SQL Queries

Why Mocking CartDao Misses Real Production Crashes
If you write coEvery { cartDao.activeItems() } returns listOf(...), you never test whether your SQL WHERE deleted_at IS NULL ORDER BY updated_at DESC actually works—or whether upgrading DB v1 → v2 crashes returning users with IllegalStateException: Migration didn't properly handle....

01 Robolectric (JVM Android Sandbox) vs Instrumented Runner

Robolectric simulates Android framework APIs (Context, SQLite, Uri, SharedPreferences, Compose) directly inside src/test on the JVM—minutes faster than booting an emulator. Use instrumented src/androidTest when you need real GPU rendering, OS permissions, or hardware/Play Services fidelity.

02 Room Migrations, DataStore, Paging 3 & WorkManager

@RunWith(AndroidJUnit4::class)
class AppDatabaseMigrationTest {
  @get:Rule
  val helper = MigrationTestHelper(
    InstrumentationRegistry.getInstrumentation(),
    AppDatabase::class.java
  )

  @Test
  fun migrate1To2_preservesExistingCartRowsAndSetsDefaultNote() {
    helper.createDatabase("test-db", 1).apply {
      execSQL("INSERT INTO cart_items (id, sku, qty) VALUES (1, 'SKU-A', 2)")
      close()
    }
    val db = helper.runMigrationsAndValidate("test-db", 2, true, MIGRATION_1_2)
    val cursor = db.query("SELECT sku, qty, gift_note FROM cart_items WHERE id = 1")
    assertThat(cursor.moveToFirst()).isTrue()
    assertThat(cursor.getString(2)).isEqualTo("")
  }
}
@Test
fun `preferences DataStore persists theme across reads`(@TempDir tempDir: Path) = runTest {
  val dataStore = PreferenceDataStoreFactory.create(
    scope = backgroundScope,
    produceFile = { tempDir.resolve("settings.preferences_pb").toFile() }
  )
  val repo = SettingsRepository(dataStore)
  repo.setDarkMode(true)
  assertThat(repo.isDarkMode.first()).isTrue()
}

@Test
fun `paging source loads page 1 and page 2 sequentially`() = runTest {
  val items = pagerFlow.asSnapshot { scrollTo(index = 25) }
  assertThat(items).hasSize(30)
}
@HiltAndroidTest
@UninstallModules(NetworkModule::class)
class SyncOrdersWorkerTest {
  @get:Rule val hiltRule = HiltAndroidRule(this)
  @BindValue val fakeApi: OrdersApi = FakeOrdersApi(shouldFail = true)

  @Test
  fun syncWorker_retriesWhenNetworkThrowsIOException() = runTest {
    val worker = TestListenableWorkerBuilder<SyncOrdersWorker>(context)
      .setWorkerFactory(FakeSyncWorkerFactory(fakeApi))
      .build()

    val result = worker.doWork()
    assertThat(result).isEqualTo(ListenableWorker.Result.retry())
  }
}
