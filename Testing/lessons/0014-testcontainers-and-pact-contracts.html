Lesson 14: Testcontainers & Pact Contract Testing

Welcome to Part 2 (Senior Testing Engineer)! A Junior tester relies on a fragile shared staging environment that breaks whenever any team deploys. A Senior SDET uses Testcontainers for real ephemeral dependencies and Pact contracts so Android and backend never drift silently.

01 Testcontainers: Real Postgres, Redis & WireMock in CI

Testcontainers manages Docker container lifecycles cleanly inside JUnit 5 or Jest/Playwright tests: ephemeral ports, automatic Ryuk cleanup after JVM exit, and zero shared-database pollution across developers.

02 How Consumer-Driven Contract Testing Works

@Pact(consumer = "PulseCartAndroid")
fun createOrderPact(builder: PactDslWithProvider): V4Pact =
  builder.uponReceiving("GET order ord-9")
    .path("/orders/ord-9").method("GET")
    .willRespondWith().status(200)
    .body(newJsonBody { o ->
      o.stringType("order_id", "ord-9")
      o.integerType("total_cents", 1999)
    }.build())
    .toPact(V4Pact::class.java)
@Testcontainers
class OrdersRepoIntegrationTest {
  companion object {
    @Container
    val postgres = PostgreSQLContainer("postgres:16-alpine")
  }

  @Test
  fun `inserts and queries real Postgres JSONB order metadata`() {
    DriverManager.getConnection(postgres.jdbcUrl, postgres.username, postgres.password).use { conn ->
      conn.createStatement().execute("CREATE TABLE orders(id TEXT PRIMARY KEY, meta JSONB NOT NULL)")
      conn.createStatement().execute("INSERT INTO orders VALUES ('ord-1', '{\"tier\":\"vip\"}')")
      val rs = conn.createStatement().executeQuery("SELECT id FROM orders WHERE meta->>'tier' = 'vip'")
      assertThat(rs.next()).isTrue()
      assertThat(rs.getString(1)).isEqualTo("ord-1")
    }
  }
}
Pact vs OpenAPI Schema Validation (Know Both!)
OpenAPI / Schemathesis validates that a server matches its own published spec; Consumer-Driven Pact proves every field/type actually parsed by Android or Web consumers is preserved by the provider (verified via pact-broker can-i-deploy before prod release).
