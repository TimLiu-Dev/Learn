Module 1A.4: Spring Transactions, Concurrency Races & Contracts

Two classic Spring Boot bugs escape junior test suites straight to production: (1) putting @Transactional on a @SpringBootTest (hiding LazyInitializationException and un-committed async/REST writes), and (2) inventory overselling when 2 threads buy the last item simultaneously!

00 The Infamous @Transactional on @SpringBootTest Trap

Why Seniors Avoid @Transactional on Full REST / Multi-Threaded Tests
When a test method is @Transactional:
1. Your test holds an open DB transaction across the entire test, keeping Hibernate sessions alive — hiding LazyInitializationException that WILL crash your controller serialization in prod!
2. Background @Async / Kafka threads or TestRestTemplate HTTP threads run in separate DB connections and cannot see uncommitted rows!

01 Testing Multi-Threaded Inventory Races (@Version) & ArchUnit

@Test // NOTE: NO @Transactional on this test! Clean tables in @BeforeEach instead.
void twoConcurrentBuyers_onlyOneCanClaimLastItemInStock() throws Exception {
  stockRepo.save(new Stock("SKU-1", 1)); // quantity = 1, @Version = 0
  var startGate = new CountDownLatch(1);
  var pool = Executors.newFixedThreadPool(2);

  Future<Boolean> t1 = pool.submit(() -> { startGate.await(); return tryReserve("SKU-1"); });
  Future<Boolean> t2 = pool.submit(() -> { startGate.await(); return tryReserve("SKU-1"); });
  startGate.countDown(); // Both threads race simultaneously!

  int successes = (t1.get() ? 1 : 0) + (t2.get() ? 1 : 0);
  assertThat(successes).isEqualTo(1);
  assertThat(stockRepo.findBySku("SKU-1").getQuantity()).isZero();
  pool.shutdown();
}
@Test
fun `optimistic locking rejects stale version update and prevents negative inventory`() {
  stockRepo.saveAndFlush(Stock(sku = "SKU-1", quantity = 1))
  val ready = CountDownLatch(2)
  val start = CountDownLatch(1)
  val pool = Executors.newFixedThreadPool(2)

  val futures = (1..2).map {
    pool.submit<Boolean> {
      ready.countDown(); start.await()
      runCatching { inventoryService.claimLastUnit("SKU-1") }.isSuccess
    }
  }
  ready.await(); start.countDown()

  assertThat(futures.count { it.get() }).isEqualTo(1)
  assertThat(stockRepo.findBySku("SKU-1").quantity).isEqualTo(0)
  pool.shutdown()
}
