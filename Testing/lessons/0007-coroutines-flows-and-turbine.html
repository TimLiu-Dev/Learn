Lesson 07: Testing Kotlin Coroutines, Dispatchers & Turbine

Async race conditions are the #1 source of flaky Android ViewModel tests. Learn how runTest, StandardTestDispatcher virtual time (kotlinx-coroutines-test), and Cash App Turbine make async streams 100% deterministic.

01 StandardTestDispatcher, Unconfined & SharingStarted.WhileSubscribed

StandardTestDispatcher queues launched coroutines until you explicitly advance virtual time (runCurrent() / advanceUntilIdle()), letting you inspect intermediate Loading states! UnconfinedTestDispatcher executes eagerly until the first suspension point — convenient for simple state collection, dangerous when testing intermediate states or debounces.

Senior ViewModel Gotcha: stateIn(WhileSubscribed(5_000)) & backgroundScope
When a ViewModel exposes flow.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), Initial), upstream collection only activates while a subscriber exists (and runTest hangs if an infinite Flow lives on testScope directly!). Collect inside Turbine's flow.test { ... } or launch a collector on backgroundScope, and pass navigation args via SavedStateHandle(mapOf("orderId" to "ord-9")).

02 ViewModel + StateFlow + Turbine in Kotlin

@Test
fun `loadOrders emits Loading then Success`() = runTest {
  val vm = OrdersViewModel(FakeOrdersRepo())

  vm.uiState.test {
    assertThat(awaitItem()).isEqualTo(OrdersUiState.Idle)
    vm.loadOrders()
    assertThat(awaitItem()).isEqualTo(OrdersUiState.Loading)
    assertThat(awaitItem()).isInstanceOf(OrdersUiState.Success::class.java)
    cancelAndIgnoreRemainingEvents()
  }
}
@Test
fun `search query debounces 300ms using virtual clock`() = runTest {
  val api = FakeSearchApi()
  val vm = SearchViewModel(api, dispatcher = StandardTestDispatcher(testScheduler))

  vm.onQueryChanged("ko")
  vm.onQueryChanged("kotl")
  advanceTimeBy(299)
  runCurrent()
  assertThat(api.queries).isEmpty()

  advanceTimeBy(1)
  runCurrent()
  assertThat(api.queries).containsExactly("kotl")
}
@Test
fun `SavedStateHandle orderId drives WhileSubscribed StateFlow without leaking`() = runTest {
  val savedState = SavedStateHandle(mapOf("orderId" to "ord-42"))
  val vm = OrderDetailViewModel(savedState, FakeOrdersRepo())

  // backgroundScope cancels automatically when runTest finishes (prevents UncompletedCoroutinesError!)
  backgroundScope.launch(UnconfinedTestDispatcher(testScheduler)) { vm.uiState.collect {} }

  advanceUntilIdle()
  assertThat(vm.uiState.value).isEqualTo(OrderDetailUiState.Loaded("ord-42"))
}
