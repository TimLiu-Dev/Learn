Lesson 17: Cross-Platform Mobile E2E (Appium 2/3 vs Maestro)

Is Appium still used in 2027? Yes — especially across enterprise Android+iOS teams, React Native/Flutter, and BrowserStack/Sauce Labs device farms. Meanwhile, Maestro has captured huge adoption for fast declarative smoke flows. Senior SDETs master both and choose objectively.

01 Why Appium Flakes (and How Senior SDETs Fix It)

Appium talks over out-of-process HTTP JSON requests, so developers who add browser.pause(5000) or brittle XPath like //android.widget.LinearLayout[3]/android.widget.TextView[2] suffer terrible flakiness. Senior SDETs enforce accessibility IDs (~checkout_btn), explicit WebDriver waits, and clean Page Objects.

02 Appium 2 WebdriverIO POM vs Maestro YAML

// Cross-platform Page Object using accessibilityId (~) instead of brittle XPath
class CartPage {
  get checkoutBtn() { return $("~checkout_button"); }
  get orderBanner() { return $("~order_confirmed_banner"); }

  async completeCheckout() {
    await this.checkoutBtn.waitForDisplayed({ timeout: 5000 });
    await this.checkoutBtn.click();
    await this.orderBanner.waitForDisplayed({ timeout: 8000 });
  }
}
appId: com.shoppulse.android
---
- launchApp:
    clearState: true
- tapOn:
    id: "checkout_button"
- assertVisible: "Order Confirmed"
