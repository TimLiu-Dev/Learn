01 Portfolio Monorepo Structure, Starter Scaffold & CI Workflow

Use the real starter monorepo scaffold in projects/shoppulse-e2e/ (with Playwright config, Maestro YAML flow, k6 script, and 3-tier GitHub Actions workflow) to build your portfolio repository. 

shoppulse-quality-platform/
  android-app/                  # Kotlin + Compose + Hilt + Room + Roborazzi + Macrobenchmark
  backend-api/                  # Spring Boot + Testcontainers + Pact Provider + BOLA AuthZ
  e2e-mobile/
    maestro/                    # Declarative YAML PR smoke flows
    appium/                     # Appium 2 + WebdriverIO TypeScript Page Objects (Android & iOS)
  e2e-web-api/                  # Playwright TypeScript + storageState + axe-core + HAR/Trace
  perf-k6/                      # Grafana k6 load scripts + P95 & error-rate thresholds
  ai-evals/                     # Golden dataset + schema/grounding/PII eval harness
  .github/workflows/ci.yml      # 3-tier sharded pipeline + Allure / HTML report artifacts
name: ShopPulse Quality Gate
on: [pull_request, push, schedule]
jobs:
  tier1-pr:
    runs-on: ubuntu-latest
    steps:
      - run: ./gradlew testDebugUnitTest verifyRoborazziDebug pitest
      - run: npx playwright test --grep @smoke --shard=1/2
  tier3-nightly:
    if: github.event_name == 'schedule'
    runs-on: ubuntu-latest
    steps:
      - run: k6 run perf-k6/checkout-load.js
      - run: npx playwright test && node ai-evals/run-evals.js
