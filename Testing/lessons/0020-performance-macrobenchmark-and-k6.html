Lesson 20: Performance, Jank & Load Testing

An app that takes 4 seconds to cold-start or drops 20% of scroll frames gets uninstalled; an API that collapses at 500 concurrent Flash-Sale users loses revenue. Master Jetpack Macrobenchmark, Baseline Profiles, LeakCanary, and Grafana k6 thresholds.

00 Why Averages Lie (P50 vs P95 / P99)

If 90 requests take 20ms and 10 requests take 3,000ms, the mean average looks okay (~318ms) — yet 1 in 10 users waits 3 seconds! Senior SDETs gate CI builds on P95 / P99 percentiles, error rate (<1%), and frame duration budgets (≤16.6ms for 60Hz / 8.3ms for 120Hz).

01 Jetpack Macrobenchmark, Baseline Profiles & Grafana k6

@Test
fun coldStartupAndScrollJank() = benchmarkRule.measureRepeated(
  packageName = "com.shoppulse.android",
  metrics = listOf(StartupTimingMetric(), FrameTimingMetric()),
  iterations = 5,
  startupMode = StartupMode.COLD,
  compilationMode = CompilationMode.Partial()
) {
  pressHome()
  startActivityAndWait()
  device.findObject(By.res("catalog_list")).scroll(Direction.DOWN, 1.0f)
}
import http from "k6/http";
import { check } from "k6";
export const options = {
  stages: [
    { duration: "30s", target: 50 },  // Ramp-up
    { duration: "1m",  target: 50 },  // Sustained load
    { duration: "15s", target: 0 }    // Ramp-down
  ],
  thresholds: { http_req_failed: ["rate<0.01"], http_req_duration: ["p(95)<300", "p(99)<600"] }
};
export default function () {
  const res = http.get("https://api.shoppulse.dev/catalog");
  check(res, { "status 200": (r) => r.status === 200 });
}
// In debug/QA UI tests, fail CI if LeakCanary detects retained Activities/Fragments:
@get:Rule val leakRule = DetectLeaksAfterTestSuccess()

02 Memory Leaks & Non-Debuggable Release Builds

Never benchmark a debug Android build! Debuggable APKs disable ART optimizations and add runtime overhead, giving bogus timings. Always benchmark non-debuggable benchmark/release variants on real physical devices (never slow software emulators).
