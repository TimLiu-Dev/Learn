Lesson 08: TDD, BDD & Property-Based Testing

Example-based tests check cases you thought of. TDD guarantees every requirement starts with a failing test, BDD aligns engineers & product via Given-When-Then behavior, and Property-Based Testing (Kotest Property) generates hundreds of randomized edge cases automatically.

00 Beyond Example-Only Testing

ApproachCore QuestionBest Fit
TDD (Red → Green → Refactor)"Did I see this test fail before writing code?"Complex domain rules, bug-fix regressions, API design.
BDD (Given-When-Then)"Do Product, QA, and Devs agree on behavior?"Business specs, feature acceptance criteria (without Gherkin bloat when unnecessary).
Property-Based"Does this invariant hold for all inputs?"Parsers/serializers (round-trip), sorting, pricing bounds, pagination merge.

01 The TDD Loop, Pragmatic BDD & 5 Property Invariants

In TDD, never skip Red: watching a test fail proves your test harness actually runs and fails for the right reason. Once Green with minimal code, Refactor safely under the green umbrella. For BDD, keep Given-When-Then clarity directly inside Kotlin @Nested / method names unless non-engineers truly author Gherkin feature files.

Property PatternInvariant FormulaReal Example
Round-Tripdecode(encode(x)) == xJSON DTO serialization, Deep-link URI builder/parser.
Idempotencyf(f(x)) == f(x)Normalize/trim slug, apply same idempotent payment key twice.
Monotonicitya ≤ b ⇒ f(a) ≤ f(b)Higher cart subtotal never produces lower loyalty points.
Bounds / Conservation0 ≤ discount(x) ≤ xPromo discounts never create negative totals; split bills sum to total.

02 Property-Based Testing with Kotest (Shrinking & Deterministic Seeds)

@Test
fun `discount price is always between 0 and original subtotal`() = runTest {
  checkAll(Arb.int(0..1_000_000), Arb.int(0..100)) { subtotal, percent ->
    val discounted = applyPercentDiscount(subtotal, percent)
    discounted shouldBeInRange 0..subtotal
  }
}

@Test
fun `json encode-decode round-trip preserves CartItem`() = runTest {
  checkAll(Arb.string(1..20), Arb.int(1..99)) { sku, qty ->
    decodeCartItem(encodeCartItem(CartItem(sku, qty))) shouldBe CartItem(sku, qty)
  }
}
@Nested
inner class `Given an expired refresh token` {
  @Test
  fun `when refreshing session, then emits SignedOut and clears local cache`() = runTest {
    val auth = FakeAuthApi(refreshFailsWith = HttpStatus.UNAUTHORIZED)
    val repo = SessionRepository(auth, FakeTokenStore(token = "expired"))

    val state = repo.refreshSession()

    assertThat(state).isEqualTo(SessionState.SignedOut)
    assertThat(repo.cachedToken()).isNull()
  }
}
// When Kotest finds a failing input, it shrinks (e.g. "x#9!k" -> "!") and prints the seed:
@Test
fun `reproduces shrinking failure deterministically in CI`() = runTest {
  checkAll(PropTestConfig(seed = 84729103L, iterations = 1_000), Arb.string()) { input ->
    sanitizeQuery(input).length shouldBeLessThanOrEqual 128
  }
}
