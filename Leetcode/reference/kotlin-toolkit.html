Null safety, in one breath

var node: ListNode? = ListNode(1)
node?.next                       // null-safe access
val v = node?.`val` ?: -1        // Elvis: default when null
while (node != null) { node = node.next }  // smart cast inside the loop

LeetCode's node classes

class ListNode(var `val`: Int) { var next: ListNode? = null }
class TreeNode(var `val`: Int) { var left: TreeNode? = null; var right: TreeNode? = null }

Gotchas

  • == compares contents (like equals) and === compares identity. Arrays are the exception: IntArray == IntArray compares identity. Use contentEquals, and never use an array as a map key. Use a String or List instead.
  • 0..n includes n, while 0 until n stops before it. Off-by-one bugs often hide in the range.
  • Int overflows silently. Sums of many values, products, and midpoints are the usual culprits.
  • listOf and mapOf are read-only. Use mutableListOf, HashMap(), or ArrayDeque() when you need to modify them.
  • Avoid !!. If you're sure a value isn't null, a smart cast or ?: usually reads better and fails more clearly.
