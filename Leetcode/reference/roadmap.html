39 structured sessions (Sessions 0–38) from core foundations to range query trees, in-memory & concurrent system design, progressive multi-stage specs, AI bug-hunt rounds, and full 45-minute mock rehearsals. Aligned with roadmap.sh/leetcode and 2027 Big Tech hiring bars (Google, Meta, Apple, Amazon, Stripe, Anthropic).

Kotlin-First + /teach Workflow. Prototype rapidly in each lesson's live in-browser Python 3.12 (Pyodide) sandbox, unlock progressive hints only when stuck, and write your final interview-grade solution in Kotlin (with Python and Java side-by-side). Run /teach in the terminal at any session for Socratic coaching, code review, and timed mocks.

2027 ROI Study Order (Core Track vs. Track B): Complete the Core Track first — Phases 0–4 (skipping Track B modules on your first pass), Phase 6 (Sessions 28–30: Caches, Rate Limiters, Concurrency), Core Phase 7 (Sessions 31–33 & 35), and Phase 8 (Sessions 36–38: Checkpoints A–D, 2027 Progressive Specs & Bug Hunting, and Mock Rehearsals). Tackle Track B · L5+ / Specialized modules (Sessions 15, 20, 25, 26, 34) afterward or for Staff/Google/Quant loops.

How every session runs

  1. Two-part spaced warm-up (10 min). Re-solve one problem from the previous session (1-back) and one earlier pattern (3- or 7-back) from memory before reading new material.
  2. The idea & trilingual templates. Core invariant first, paired with side-by-side Kotlin · Python · Java templates and interactive step-by-step trace visualizers on pointer/DP/graph mechanics.
  3. Walkthrough with 6-step script. Solve the canonical archetype out loud: Clarify → Examples → Approach → Code → Test → Complexity.
  4. In-browser Pyodide sandbox & tests. Run real Python 3.12 unit tests directly in the browser, use progressive hints if needed, and translate to clean Kotlin.
  5. Multiple-choice retrieval check. Three rapid invariant and complexity questions explaining why every distractor fails.
  6. Your turn (Core vs. Stretch). Solve 2–3 Core problems in session (self-contained specs included for any Premium problem) and save Stretch variants for spaced review.

Frequency & Priority Tiers

Frequency weights combine 2026–2027 interview tracking across Blind 75, NeetCode 150, and L4–L6 Big Tech loop debriefs:

  • High: Appears in >75% of loops (Arrays/Hashing, Two Pointers, Sliding Window, Prefix Sums, Stacks, Binary Search, Linked Lists, Trees, Grid/Graph Traversal, LRU Cache, Progressive Multi-Stage Rounds).
  • Medium: Appears in 40–70% of loops; essential for L4/L5+ rounds (Heaps, Intervals, Backtracking, 0-1 & Bidirectional BFS, Topo Sort, Union-Find, Greedy, 1-D/2-D DP, Rate Limiters, Concurrency, Matrix/Strings/Quickselect).
  • Lower / Specialized Track B: Tested in specialized algorithmic rounds at Google, Uber, Databricks, or Quant firms (Tries/XOR Trie, Dijkstra/Bellman-Ford, Bitmask DP, Segment/Fenwick Trees, MST/Eulerian Paths).
