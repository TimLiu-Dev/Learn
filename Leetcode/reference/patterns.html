Arrays & Hashing High

Lesson: Session 1

Signals

  • Find a pair or complement: target - current
  • Detect duplicates or check if element occurred previously
  • Anagram detection or frequency distribution counting
  • Grouping elements sharing an invariant signature (e.g. sorted characters)

Template (Kotlin)

// 1. Seen-before: single-pass complement lookup
val seen = HashMap<Int, Int>() // val -> index
for (i in nums.indices) {
    val complement = target - nums[i]
    if (complement in seen) return intArrayOf(seen[complement]!!, i)
    seen[nums[i]] = i
}

// 2. Frequency counting: primitive IntArray(26) for ASCII
val count = IntArray(26)
for (c in s) count[c - 'a']++

Complexity

Time O(n): single linear pass with O(1) hash map operations. Space O(n): stores up to n key-value entries in hash map.

Canonical ProblemsTwo Sum · Valid Anagram · Group Anagrams · Top K Frequent Elements

Two Pointers High

Lesson: Session 2

Signals

  • Sorted array asking for pair sum or condition
  • Palindrome verification or symmetric string comparison
  • In-place partitioning or removing elements without extra memory (O(1) space)

Template (Kotlin)

// 1. Converging opposite ends (Sorted array)
var l = 0; var r = nums.size - 1
while (l < r) {
    val sum = nums[l] + nums[r]
    when {
        sum == target -> return intArrayOf(l + 1, r + 1)
        sum < target -> l++   // sum too small: advance left
        else -> r--           // sum too big: advance right
    }
}

// 2. Fast / slow pointer (In-place array write)
var slow = 0
for (fast in nums.indices) {
    if (nums[fast] != 0) nums[slow++] = nums[fast]
}

Complexity

Time O(n): each pointer moves inwards at most n times total. Space O(1): two integer index variables.

Canonical ProblemsValid Palindrome · Two Sum II – Input Array Is Sorted · 3Sum · Container With Most Water

Sliding Window High

Lesson: Session 3

Signals

  • Contiguous subarray or substring problem
  • Longest / shortest substring satisfying a frequency condition
  • Fixed window of length k (e.g. maximum average subarray)
  • Maximum sum or product of contiguous elements

Template (Kotlin)

// Dynamic window: expand r, shrink l while invalid
var l = 0; var best = 0
val window = HashMap<Char, Int>()
for (r in s.indices) {
    window[s[r]] = window.getOrDefault(s[r], 0) + 1
    while (!isValid(window)) {
        window[s[l]] = window[s[l]]!! - 1
        l++
    }
    best = maxOf(best, r - l + 1)
}

Complexity

Time O(n): each character is added and removed from seen at most once. Space O(min(m, n)): size of charset in hash set.

Canonical ProblemsLongest Substring Without Repeating Characters · Best Time to Buy and Sell Stock · Longest Repeating Character Replacement · Minimum Window Substring

Prefix Sums High

Lesson: Session 4

Signals

  • Frequent range sum queries: sum(i, j)
  • Subarrays summing to target k (especially with negative numbers)
  • Continuous subarrays where sliding window fails because sum is non-monotonic
  • Difference arrays for batch range updates

Template (Kotlin)

// Prefix sum lookup: prefix[j+1] - prefix[i]
val prefix = IntArray(nums.size + 1)
for (i in nums.indices) prefix[i + 1] = prefix[i] + nums[i]

// Subarray Sum Equals K: prefix + hash map
val counts = HashMap<Int, Int>()
counts[0] = 1
var curr = 0; var ans = 0
for (x in nums) {
    curr += x
    ans += counts.getOrDefault(curr - k, 0)
    counts[curr] = counts.getOrDefault(curr, 0) + 1
}

Complexity

Time O(n): single linear pass with O(1) hash map operations. Space O(n): stores up to n distinct prefix sums in map.

Canonical ProblemsSubarray Sum Equals K · Range Sum Query - Immutable · Contiguous Array · Subarray Sums Divisible by K

Monotonic Stack High

Lesson: Session 6

Signals

  • Find next greater element or next smaller element
  • Previous greater element or span problems (Stock Spanner)
  • Largest rectangle in a histogram or trapping rain water
  • Removing digits to create smallest/largest number

Template (Kotlin)

// Monotonic decreasing stack (stores indices)
val stack = ArrayDeque<Int>()
val result = IntArray(nums.size)
for (i in nums.indices) {
    while (stack.isNotEmpty() && nums[i] > nums[stack.last()]) {
        val prevIdx = stack.removeLast()
        result[prevIdx] = i - prevIdx // resolved by index i!
    }
    stack.addLast(i)
}

Complexity

Time O(n): each index is pushed and popped at most once. Space O(n): stack holds at most n indices in worst case.

Canonical ProblemsDaily Temperatures · Next Greater Element I · Online Stock Span · Largest Rectangle in Histogram

Binary Search High

Lesson: Session 7

Signals

  • Sorted array or sorted matrix
  • Searching for minimum or maximum value satisfying a condition (search on answer)
  • Problem statement specifies O(log n) time requirement
  • Rotated sorted array or mountain array peak finding

Template (Kotlin)

// 1. Classic exact match binary search
var l = 0; var r = nums.size - 1
while (l <= r) {
    val mid = l + (r - l) / 2
    when {
        nums[mid] == target -> return mid
        nums[mid] < target -> l = mid + 1
        else -> r = mid - 1
    }
}
return -1

// 2. Binary search on answer (lower bound)
var l = minPossible; var r = maxPossible
while (l < r) {
    val mid = l + (r - l) / 2
    if (isValid(mid)) r = mid // try smaller
    else l = mid + 1          // must be larger
}
return l

Complexity

Time O(log n): search space halved each step. Space O(1): three pointer variables.

Canonical ProblemsBinary Search · Search in Rotated Sorted Array · Find Minimum in Rotated Sorted Array · Koko Eating Bananas

Linked Lists High

Lesson: Session 8

Signals

  • Reverse a linked list (or reverse subsegments k at a time)
  • Detect cycle or find cycle start node in O(1) memory
  • Find the middle node of a list in a single pass
  • Merge two or more sorted linked lists

Template (Kotlin)

// 1. In-place reversal: 3-pointer pattern
var prev: ListNode? = null
var curr = head
while (curr != null) {
    val nextTemp = curr.next
    curr.next = prev
    prev = curr
    curr = nextTemp
}
return prev // new head

// 2. Dummy node for clean list construction
val dummy = ListNode(0)
var tail = dummy
// attach nodes: tail.next = node; tail = tail.next
return dummy.next

Complexity

Time O(n): single linear pass through all n nodes. Space O(1): pointers only, no heap allocations.

Canonical ProblemsReverse Linked List · Merge Two Sorted Lists · Linked List Cycle · Reorder List

Trees DFS High

Lesson: Session 9

Signals

  • Binary tree maximum / minimum depth
  • Tree symmetry, invert binary tree, or identical trees
  • Subtree sum, diameter of binary tree, or path sum
  • Lowest Common Ancestor in a general binary tree

Template (Kotlin)

// Post-order DFS: bottom-up aggregation
fun maxDepth(root: TreeNode?): Int {
    if (root == null) return 0
    val left = maxDepth(root.left)
    val right = maxDepth(root.right)
    return 1 + maxOf(left, right)
}

Complexity

Time O(n): visits each node exactly once. Space O(h): call stack depth proportional to tree height (O(log n) balanced, O(n) worst-case skewed).

Canonical ProblemsMaximum Depth of Binary Tree · Invert Binary Tree · Diameter of Binary Tree · Lowest Common Ancestor of a Binary Tree

Trees BFS High

Lesson: Session 10

Signals

  • Level-order traversal: return values grouped level by level
  • Binary tree right side view or left side view
  • Minimum depth of binary tree (earliest leaf found is guaranteed shortest)
  • Zigzag level order traversal or level averages

Template (Kotlin)

// Level-order BFS with size snapshot
val result = mutableListOf<List<Int>>()
if (root == null) return result
val queue = ArrayDeque<TreeNode>()
queue.addLast(root)

while (queue.isNotEmpty()) {
    val levelSize = queue.size
    val currentLevel = mutableListOf<Int>()
    for (i in 0 until levelSize) {
        val node = queue.removeFirst()
        currentLevel.add(node.`val`)
        node.left?.let { queue.addLast(it) }
        node.right?.let { queue.addLast(it) }
    }
    result.add(currentLevel)
}

Complexity

Time O(n): each node enqueued and dequeued once. Space O(w): queue size proportional to maximum tree width (up to n/2 in a balanced binary tree, so O(n)).

Canonical ProblemsBinary Tree Level Order Traversal · Binary Tree Right Side View · Binary Tree Zigzag Level Order Traversal · Minimum Depth of Binary Tree

Binary Search Trees High

Lesson: Session 11

Signals

  • Validate whether a binary tree satisfies the BST invariant
  • Lowest Common Ancestor (LCA) in a BST
  • Kth smallest or kth largest element in a BST
  • Insert, delete, or search for a key in O(h) time

Template (Kotlin)

// BST Search: prune half the tree at each step
fun searchBST(root: TreeNode?, target: Int): TreeNode? {
    var curr = root
    while (curr != null) {
        if (curr.`val` == target) return curr
        curr = if (target < curr.`val`) curr.left else curr.right
    }
    return null
}

Complexity

Time O(h): visits at most one node per level. O(log n) for balanced BST, O(n) worst-case. Space O(1): iterative traversal uses no extra stack.

Canonical ProblemsLowest Common Ancestor of a BST · Validate Binary Search Tree · Kth Smallest Element in a BST · Insert into a Binary Search Tree

Backtracking & Pruning Medium

Lesson: Session 14

Signals

  • 'Find all combinations', 'subsets', 'permutations'
  • 'Word search on a grid', 'N-Queens', 'Sudoku solver'
  • Input size is very small: n <= 15 to 20 (suggesting O(2^n) or O(n!))

Template (Kotlin)

fun backtrack(start: Int, path: MutableList<Int>, result: MutableList<List<Int>>) {
    result.add(path.toList()) // COPY current state
    for (i in start until nums.size) {
        path.add(nums[i])     // 1. Choose
        backtrack(i + 1, path, result) // 2. Explore
        path.removeLast()     // 3. Unchoose
    }
}

Complexity

Time O(n × 2ⁿ): 2ⁿ total subsets, each taking O(n) to copy. Space O(n): maximum recursion stack depth.

Canonical ProblemsSubsets · Permutations · Combination Sum · Word Search

Tries & Bitwise Trie Lower / Specialized

Lesson: Session 15

Signals

  • 'Autocomplete', 'prefix search', 'startsWith'
  • Word search on a grid with a dictionary of words (Word Search II)
  • 'Find two numbers with maximum XOR' (Bitwise Trie)

Template (Kotlin)

class TrieNode {
    val children = arrayOfNulls<TrieNode>(26)
    var isWord = false
}
class Trie {
    val root = TrieNode()
    fun insert(word: String) {
        var curr = root
        for (c in word) {
            val i = c - 'a'
            if (curr.children[i] == null) curr.children[i] = TrieNode()
            curr = curr.children[i]!!
        }
        curr.isWord = true
    }
}

Complexity

Time: O(L) for insert, search, and startsWith where L is string length. Space O(N × L × 26): worst-case memory for storing distinct characters.

Graph Traversal: Grid & Adjacency High

Lesson: Session 16

Signals

  • 'Number of islands', 'connected components', 'flood fill'
  • 'Rotting oranges', 'walls and gates', 'shortest path in matrix'
  • Adjacency lists / clone graph

Template (Kotlin)

val dirs = arrayOf(intArrayOf(1, 0), intArrayOf(-1, 0), intArrayOf(0, 1), intArrayOf(0, -1))
fun dfs(r: Int, c: Int, grid: Array<CharArray>) {
    if (r !in grid.indices || c !in grid[0].indices || grid[r][c] != '1') return
    grid[r][c] = '0' // mark visited
    for (d in dirs) dfs(r + d[0], c + d[1], grid)
}

Complexity

Time O(M × N): each cell is visited at most once. Space O(M × N): recursion stack for a completely filled island.

Canonical ProblemsNumber of Islands · Clone Graph · Rotting Oranges · Pacific Atlantic Water Flow

Topological Sort (Kahn's vs DFS) Medium

Lesson: Session 18

Signals

  • 'Course schedule', 'build order', 'task dependencies'
  • 'Alien dictionary' (derive alphabet order from sorted word list)
  • Detect cycle in a directed graph

Template (Kotlin)

val inDegree = IntArray(numCourses)

// populate inDegree and graph...
val q = ArrayDeque<Int>()
for (i in 0 until numCourses) if (inDegree[i] == 0) q.addLast(i)

Disjoint Set Union (DSU / Union-Find) Medium

Lesson: Session 19

Signals

  • 'Dynamic connectivity', 'number of connected components'
  • 'Redundant connection', cycle detection in undirected graphs
  • Kruskal's Minimum Spanning Tree algorithm

Template (Kotlin)

class DSU(n: Int) {
    val parent = IntArray(n) { it }
    val rank = IntArray(n) { 1 }

    fun find(i: Int): Int {
        if (parent[i] != i) parent[i] = find(parent[i]) // path compression
        return parent[i]
    }

    fun union(i: Int, j: Int): Boolean {
        val rootI = find(i); val rootJ = find(j)
        if (rootI == rootJ) return false // cycle / already connected
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ
        else {
            parent[rootJ] = rootI
            if (rank[rootI] == rank[rootJ]) rank[rootI]++
        }
        return true
    }
}

Complexity

Time O(n × α(n)) ≈ O(n): each find/union is nearly O(1). Space O(n): parent array.

Canonical ProblemsRedundant Connection · Number of Connected Components in an Undirected Graph · Graph Valid Tree · Accounts Merge

Shortest Paths: Dijkstra & Bellman-Ford Lower / Specialized

Lesson: Session 20

Signals

  • 'Network delay time', 'cheapest flight', 'minimum cost path'
  • Weighted directed/undirected graph with positive edge weights
  • Grid where moving between cells has variable costs

Template (Kotlin)

val dist = IntArray(n + 1) { Int.MAX_VALUE }
dist[src] = 0
val pq = java.util.PriorityQueue<IntArray>(compareBy { it[1] }) // [node, cost]
pq.offer(intArrayOf(src, 0))
while (pq.isNotEmpty()) {
    val (u, d) = pq.poll()
    if (d > dist[u]) continue // stale entry pruning
    for ((v, weight) in graph[u]) {
        if (d + weight < dist[v]) {
            dist[v] = d + weight
            pq.offer(intArrayOf(v, dist[v]))
        }
    }
}

Complexity

Time O((V + E) log V): each edge relaxed once with heap push. Space O(V + E): graph and priority queue.

Canonical ProblemsNetwork Delay Time · Cheapest Flights Within K Stops · Path with Minimum Effort · Swim in Rising Water

State Machine & Bitmask DP Lower / Specialized

Lesson: Session 25

Signals

  • 'Stock trading with cooldown / transaction fee'
  • 'Divide array into k equal subsets' (N <= 16)
  • 'Shortest path visiting all nodes / Traveling Salesman'
  • Constraint: N <= 16 with decision tree

Template (Kotlin)

// State Machine DP: Stock with Cooldown
var held = -prices[0]
var sold = 0
var rest = 0
for (i in 1 until prices.size) {
    val prevSold = sold
    sold = held + prices[i]
    held = maxOf(held, rest - prices[i])
    rest = maxOf(rest, prevSold)
}
val maxProfit = maxOf(sold, rest)

Complexity

Time O(n): single linear pass through prices. Space O(1): three state variables.

Segment Trees & Fenwick Trees Lower / Specialized

Lesson: Session 26

Signals

  • 'Range sum query with mutable / update operations'
  • 'Count of smaller numbers after self' (inversion counting)
  • Dynamic range minimum/maximum with updates

Template (Kotlin)

class FenwickTree(val n: Int) {
    val tree = IntArray(n + 1)
    fun update(index: Int, delta: Int) {
        var i = index + 1
        while (i <= n) { tree[i] += delta; i += i and -i }
    }
    fun query(index: Int): Int {
        var sum = 0; var i = index + 1
        while (i > 0) { sum += tree[i]; i -= i and -i }
        return sum
    }
}

Complexity

Time: O(n log n) construction, O(log n) update, O(log n) sumRange. Space O(n): tree array of size n + 1.

Canonical ProblemsRange Sum Query - Mutable · Count of Smaller Numbers After Self · Queue Reconstruction by Height · Range Sum Query 2D - Mutable

Bit Manipulation & Math Tricks Lower / Specialized

Lesson: Session 27

Signals

  • 'Single Number' (all numbers appear twice except one)
  • 'Number of 1 Bits / Hamming Weight'
  • 'Counting bits', 'Reverse bits'
  • 'Pow(x, n)' in O(log n)

Template (Kotlin)

// Brian Kernighan: count 1-bits
var count = 0; var num = n
while (num != 0) { num = num and (num - 1); count++ }

// Fast exponentiation O(log n)
fun myPow(x: Double, n: Long): Double {
    var res = 1.0; var base = x; var exp = if (n < 0) -n else n
    while (exp > 0) {
        if (exp % 2L == 1L) res *= base
        base *= base
        exp /= 2L
    }
    return if (n < 0) 1.0 / res else res
}

Complexity

Time O(n): single pass. Space O(1): one accumulator variable.

Canonical ProblemsSingle Number · Number of 1 Bits · Counting Bits · Pow(x, n)
