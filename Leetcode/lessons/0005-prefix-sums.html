Prefix Sums

Convert range sum queries into O(1) subtractions: sum(i..j) = prefix[j+1] - prefix[i].

Your winAnswer range sum queries in O(1) and count subarray sum targets with hash maps in O(n) time.

The idea

Computing subarray sums repeatedly in O(n) per query is too slow. A prefix sum array stores cumulative sums, turning any range sum into a single subtraction in O(1). When combined with a hash map of prefix sum frequencies, you can find subarrays summing to k in O(n) time even with negative numbers.

Reach for it when you see…

  • Frequent range sum queries: sum(i, j)
  • Subarrays summing to target k (especially with negative numbers)
  • Continuous subarrays where sliding window fails because sum is non-monotonic
  • Difference arrays for batch range updates

Walkthrough: Subarray Sum Equals K

Given an array of integers nums and an integer k, return the total number of continuous subarrays whose sum equals to k.

1 · Clarify

Can nums contain negative numbers? Can k be zero or negative? Yes! Negative numbers mean prefix sums are non-monotonic, so sliding window will not work.

2 · Examples

nums = [1, 1, 1], k = 2 -> 2. nums = [1, 2, 3], k = 3 -> 2. nums = [1, -1, 0], k = 0 -> 3.

3 · Approach

We want sum(nums[i..j]) == k. In terms of prefix sums: prefix[j] - prefix[i-1] == k, which rearranges to prefix[i-1] == prefix[j] - k. As we accumulate running sum curr, we check how many times curr - k has occurred so far, adding that count to our answer. Initialize map with {0: 1} to account for subarrays starting at index 0.

4 · Code 
class Solution {
    fun subarraySum(nums: IntArray, k: Int): Int {
        val countMap = HashMap<Int, Int>()
        countMap[0] = 1
        var curr = 0
        var total = 0
        for (x in nums) {
            curr += x
            total += countMap.getOrDefault(curr - k, 0)
            countMap[curr] = countMap.getOrDefault(curr, 0) + 1
        }
        return total
    }
}

Quick check

Why can sliding window NOT be used on Subarray Sum Equals K when the array contains negative numbers?

  1. Sliding window algorithms crash with division by zero on negative values
  2. Negative numbers break the monotonic property: expanding window does not guarantee sum increases
  3. Hash maps cannot store negative keys in Java or Python
  4. Pointers cannot move from left to right over negative integers

Sliding window depends on monotonic expansion/shrinkage. If negative numbers exist, expanding r can decrease the sum and advancing l can increase it, breaking greedy shrinkage.

Why is the hash map initialized with {0: 1} in the prefix sum subarray algorithm?

  1. Because all arrays must have at least one 0 element at the start
  2. To prevent NullPointerException when hashing index 0
  3. To account for subarrays whose sum equals k starting directly at index 0
  4. To satisfy the 1-based indexing constraint of Kotlin collections

If a prefix sum curr itself equals k, we need curr - k = 0 to match an existing count of 1, correctly representing the subarray from index 0 to current index.

Given a 1D prefix sum array prefix of length n+1 where prefix[i] = sum(nums[0..i-1]), what is the formula for sum(nums[left..right])?

  1. prefix[right] - prefix[left - 1]
  2. prefix[right + 1] + prefix[left]
  3. prefix[right] * prefix[left]
  4. prefix[right + 1] - prefix[left]

prefix[right + 1] includes sum up to index right, and subtracting prefix[left] removes elements before index left in O(1) time.

Range Sum Query - Immutable Easy

  1. Precompute prefix array in O(n) during initialization.
  2. Answer each sumRange(left, right) in O(1) with prefix[right+1] - prefix[left].
  3. 1-indexed prefix array avoids boundary check for left == 0.

Contiguous Array Medium

  1. Treat 0 as -1 and 1 as +1.
  2. Equal 0s and 1s means finding the longest subarray summing to 0.
  3. Store prefix_sum -> earliest_index in a hash map.

Subarray Sums Divisible by K Medium

  1. Two prefix sums with the same remainder modulo k have a difference divisible by k.
  2. Normalize negative remainders: (curr % k + k) % k.
  3. Count remainder frequencies with an IntArray(k).
