Topological Sort (Kahn's vs DFS)

Order nodes in a Directed Acyclic Graph (DAG) by dependency constraints.

Your winOrder tasks with dependencies, detect deadlocks/cycles, and implement Kahn's BFS algorithm in O(V + E) time across Kotlin, Python, and Java.

Warm-up from memory

Close this page and recall: what does it mean if a directed graph contains a cycle when attempting topological sort?

The idea

In a DAG, a topological order ensures that for every directed edge u → v, node u comes before v. Kahn's Algorithm (BFS) counts in-degrees: 1. Push nodes with in-degree 0 (no prerequisites) into a queue. 2. Pop u, append to order, decrement in-degree of its neighbors. 3. If a neighbor reaches in-degree 0, enqueue it. If output count < V, a cycle exists!

Walkthrough: Course Schedule

There are total numCourses courses to take. Given prerequisites pairs [a, b] indicating you must take b before a, return if you can finish all courses.

1 · Clarify

Can prerequisites contain duplicate pairs? Can a course depend on itself? Yes, duplicates possible. If a depends on a, a cycle exists (return false).

2 · Examples

numCourses = 2, prerequisites = [[1, 0]] → true (take 0, then 1). prerequisites = [[1, 0], [0, 1]] → false (cycle).

3 · Approach

1. Model courses as directed graph: edge b → a means b must be taken before a. Track inDegree[a]++.

2. Push all courses with inDegree == 0 into a queue.

3. Process queue: increment completed counter, decrement neighbors' in-degrees. Enqueue neighbors that reach 0.

4. Return completed == numCourses.

4 · Code 
class Solution {
    fun canFinish(numCourses: Int, prerequisites: Array<IntArray>): Boolean {
        val inDegree = IntArray(numCourses)
        val adj = Array(numCourses) { mutableListOf<Int>() }

        for (p in prerequisites) {
            val course = p[0]; val prereq = p[1]
            adj[prereq].add(course)
            inDegree[course]++
        }

        val queue = ArrayDeque<Int>()
        for (i in 0 until numCourses) {
            if (inDegree[i] == 0) queue.addLast(i)
        }

        var completed = 0
        while (queue.isNotEmpty()) {
            val curr = queue.removeFirst()
            completed++
            for (next in adj[curr]) {
                if (--inDegree[next] == 0) queue.addLast(next)
            }
        }
        return completed == numCourses
    }
}

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        int[] inDegree = new int[numCourses];
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());

        for (int[] p : prerequisites) {
            adj.get(p[1]).add(p[0]);
            inDegree[p[0]]++;
        }

        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) queue.offer(i);
        }

        int completed = 0;
        while (!queue.isEmpty()) {
            int curr = queue.poll();
            completed++;
            for (int next : adj.get(curr)) {
                if (--inDegree[next] == 0) queue.offer(next);
            }
        }
        return completed == numCourses;
    }
}

Cycle test: [[1, 0], [0, 1]]: inDegree[0]=1, inDegree[1]=1. Neither enters queue. completed = 0 != 2 → returns false. ✓ Normal DAG: [[1, 0]]: queue starts with 0, decrements 1, completed = 2 → returns true. ✓

6 · Complexity

Time O(V + E): each vertex enqueued once, each edge traversed once. Space O(V + E): adjacency list and in-degree array.

Quick check

If Kahn's algorithm terminates and the number of processed nodes is less than V, what does that prove?

  1. Graph is disconnected tree
  2. Graph has multiple sources
  3. In-degree array had overflows
  4. Graph contains directed cycle

Nodes participating in a cycle never reach in-degree 0, so they are never enqueued, leaving processed count < V.

In Kahn's topological sort, which nodes are added to the queue initially?

  1. Nodes having in-degree of 0
  2. Nodes having out-degree of 0
  3. Leaf nodes in undirected tree
  4. Root node of highest index

Nodes with in-degree 0 have no prerequisite dependencies and are immediately ready to execute.

Can an undirected graph have a valid topological ordering?

  1. Yes if graph has no loops
  2. No undirected graphs cannot
  3. Yes if vertices are sorted
  4. Only if weights are uniform

Topological order is only defined for Directed Acyclic Graphs (DAGs); an undirected edge is a 2-node cycle.
