Warm-up from memory

The idea

A 2D matrix is simply an implicit graph where each cell (r, c) connects to its 4 cardinal neighbors. To explore components or flood-fill, use DFS (recursive or stack) or BFS (queue). Always mark cells visited immediately upon discovery to prevent infinite loops.

Walkthrough: Number of Islands

Given an m x n 2D binary grid which represents a map of '1's (land) and '0's (water), return the number of islands.

1 · Clarify

Can grid be empty? Are diagonals connected? Grid has m, n >= 1. Diagonals are NOT connected (4 directions only).

2 · Examples

Grid with 3 disconnected clusters of '1's → returns 3.

3 · Approach

Scan every cell (r, c). When we find '1':

  1. Increment island counter.
  2. Launch DFS/BFS to sink the entire island by flipping all connected '1's to '0'.
  3. Continue scanning. Water and already-sunken islands are ignored.
4 · Code 
class Solution {
    fun numIslands(grid: Array<CharArray>): Int {
        var count = 0
        for (r in grid.indices) {
            for (c in grid[0].indices) {
                if (grid[r][c] == '1') {
                    count++
                    sink(grid, r, c)
                }
            }
        }
        return count
    }

    private fun sink(grid: Array<CharArray>, r: Int, c: Int) {
        if (r !in grid.indices || c !in grid[0].indices || grid[r][c] != '1') return
        grid[r][c] = '0'
        sink(grid, r + 1, c)
        sink(grid, r - 1, c)
        sink(grid, r, c + 1)
        sink(grid, r, c - 1)
    }
}
class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        count = 0
        rows, cols = len(grid), len(grid[0])

        def sink(r: int, c: int):
            if not (0 <= r < rows and 0 <= c < cols) or grid[r][c] != '1':
                return
            grid[r][c] = '0'
            sink(r + 1, c)
            sink(r - 1, c)
            sink(r, c + 1)
            sink(r, c - 1)

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == '1':
                    count += 1
                    sink(r, c)
        return count
class Solution {
    public int numIslands(char[][] grid) {
        int count = 0;
        for (int r = 0; r < grid.length; r++) {
            for (int c = 0; c < grid[0].length; c++) {
                if (grid[r][c] == '1') {
                    count++;
                    sink(grid, r, c);
                }
            }
        }
        return count;
    }

    private void sink(char[][] grid, int r, int c) {
        if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] != '1') return;
        grid[r][c] = '0';
        sink(grid, r + 1, c);
        sink(grid, r - 1, c);
        sink(grid, r, c + 1);
        sink(grid, r, c - 1);
    }
}
5 · Test

Grid of 1x1 ['1']: count becomes 1, sink flips to '0'. Loop finishes, returns 1. ✓ Grid of all '0's: sink never called, returns 0. ✓

6 · Complexity

Time O(M × N): each cell is visited at most once. Space O(M × N): recursion stack for a completely filled island.

            }
        }
        return count
    }

Quick check

When modifying grid cells in place during DFS traversal, what does flipping '1' to '0' achieve?

  1. Deletes array pointers in memory
  2. Marks cell visited without memory
  3. Shortens total loop count by 2
  4. Inverts coordinate math indices

Overwriting visited land '1' with water '0' acts as an in-place visited set, requiring O(1) extra space.

In an unweighted grid with multiple starting points (multi-source BFS), how are starts initialized?

  1. Run DFS separately on each node
  2. Sort grid cells by distance val
  3. Push all starting cells to queue
  4. Use a priority queue for starts

Pushing all starting nodes (e.g. all rotten oranges) into the queue at t=0 expands frontiers simultaneously.

What is the time complexity of BFS on an adjacency list graph with V vertices and E edges?

  1. O(V * E) quadratic bound
  2. O(V log E) heap operations
  3. O(E^2) edge comparisons
  4. O(V + E) linear traversal

Every vertex is enqueued once O(V) and every edge is examined once O(E), giving O(V + E).

Clone Graph Medium

  1. Use a hash map mapping original node → cloned copy.
  2. If node is already in map, return the cloned copy to avoid infinite cycle recursion.
  3. DFS on neighbors: clone.neighbors.add(dfs(neighbor)).

Rotting Oranges Medium

  1. This is multi-source BFS.
  2. Count fresh oranges and push all rotten oranges into the queue at minute 0.
  3. Each level increments minute. If fresh oranges remain at end, return -1.

Pacific Atlantic Water Flow Medium

  1. Instead of flowing water down from every cell, flow water UP from the oceans.
  2. Run BFS/DFS from Pacific borders and Atlantic borders.
  3. Cells reachable from both oceans form the intersection answer.
