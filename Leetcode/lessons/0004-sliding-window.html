Sliding Window

Maintain a contiguous subarray range [l, r] as r expands and l shrinks.

Your winSolve subarray and substring optimization problems in O(n) time by maintaining window invariants.

Warm-up from memory

The idea

When examining contiguous subarrays or substrings, brute-force checks O(n²) ranges. But as the right boundary advances, most elements from the previous window remain. By adding nums[r] to the window state and shrinking nums[l] when invalid, each index enters and leaves the window at most once, achieving O(n) total time.

Reach for it when you see…

  • Contiguous subarray or substring problem
  • Longest / shortest substring satisfying a frequency condition
  • Fixed window of length k (e.g. maximum average subarray)
  • Maximum sum or product of contiguous elements

        l++

Walkthrough: Longest Substring Without Repeating Characters

Given a string s, find the length of the longest substring without repeating characters.

1 · Clarify

Can s be empty? What character set does s contain (English letters, symbols, spaces)? s can contain English letters, digits, symbols, and spaces. Length up to 5 * 10^4.

2 · Examples

s = 'abcabcbb' -> 3 ('abc'). s = 'bbbbb' -> 1 ('b'). s = 'pwwkew' -> 3 ('wke').

3 · Approach

Maintain a set of characters currently in window [l, r]. As r advances, if s[r] is already in the set, shrink from the left by removing s[l] and incrementing l until s[r] is no longer duplicated. Add s[r] and update maxLen = max(maxLen, r - l + 1).

4 · Code 
class Solution {
    fun lengthOfLongestSubstring(s: String): Int {
        val seen = HashSet<Char>()
        var l = 0
        var maxLen = 0
        for (r in s.indices) {
            while (s[r] in seen) {
                seen.remove(s[l])
                l++
            }
            seen.add(s[r])
            maxLen = maxOf(maxLen, r - l + 1)
        }
        return maxLen
    }
}

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> seen = new HashSet<>();
        int l = 0, maxLen = 0;
        for (int r = 0; r < s.length(); r++) {
            while (seen.contains(s.charAt(r))) {
                seen.remove(s.charAt(l));
                l++;
            }
            seen.add(s.charAt(r));
            maxLen = Math.max(maxLen, r - l + 1);
        }
        return maxLen;
    }
}

Quick check

Why is the sliding window approach O(n) time even though there is a while loop nested inside the for loop?

  1. The inner while loop only executes on prime-indexed loop iterations
  2. Because strings have a constant length in modern compilers
  3. Both l and r move strictly forward, so each element enters and leaves window at most once
  4. The inner loop breaks immediately on every single iteration

This is amortized analysis: r advances n times, and l advances at most n times across the entire algorithm lifetime. Total operations = 2n = O(n).

What key distinction separates Sliding Window from generic Two Pointers?

  1. Sliding Window requires input arrays to be sorted in strictly ascending order
  2. Two Pointers cannot be used on strings, only integer arrays
  3. Sliding Window only works when the window size is fixed and constant
  4. Sliding Window maintains and optimizes state over a contiguous subarray range [l, r]

Sliding window specifically tracks aggregate state (sum, counts, distinct elements) across contiguous spans [l, r], whereas two pointers can jump or converge arbitrarily.

In Best Time to Buy and Sell Stock (LeetCode 121), what single invariant do you track as you iterate?

  1. The minimum price seen so far to compute potential profit at current price
  2. The cumulative prefix sum of stock prices
  3. The median price across all past trading days
  4. The count of days where stock price strictly dropped

For each day, the optimal transaction selling on that day is price[i] - minPriceSoFar. Tracking minPrice yields a clean O(n) one-pass solution with O(1) space.
