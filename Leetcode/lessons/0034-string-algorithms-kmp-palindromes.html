Warm-up from memory

Close this page and recall: how many potential palindrome centers exist in a string of length n (counting both odd-length and even-length palindromes)?

The idea

String interviews combine three classic mechanics: (1) Expand Around Center for palindromes in O(n²) time and O(1) space (beating 2D DP's O(n²) memory); (2) KMP (Knuth-Morris-Pratt), which builds a Longest Prefix Suffix (lps) failure table in O(m) so text matching never backtracks in O(n + m); and (3) One-Pass Expression Parsing using running num, last_num, and op (handling *// precedence without a full token stack).

Reach for it when you see…

  • 'Longest palindromic substring' or 'count palindromic substrings'
  • 'Find first occurrence of needle in haystack' in O(n + m) worst-case (KMP / Rabin-Karp)
  • 'Basic Calculator' / evaluate arithmetic expression with operator precedence

fun expand(s: String, left: Int, right: Int): IntRange {
    var l = left; var r = right
    while (l >= 0 && r < s.length && s[l] == s[r]) { l--; r++ }
    return (l + 1) until r
}

// 2. KMP Longest Prefix Suffix (LPS) table
fun buildLps(p: String): IntArray {
    val lps = IntArray(p.length)
    var len = 0; var i = 1
    while (i < p.length) {
        when {
            p[i] == p[len] -> lps[i++] = ++len
            len > 0 -> len = lps[len - 1]
            else -> lps[i++] = 0
        }
    }
    return lps
}

Rabin-Karp (Polynomial Rolling Hash) Alternative: Instead of building KMP's lps table, slide a hash over window size m using h = (h * base + char) % mod (subtracting char_out * base^(m-1) cleanly via modular arithmetic). Expected matching is O(n + m) (verify exact characters on hash match to guard collisions). Rolling hash also pairs with Binary Search to solve harder follow-ups like Longest Duplicate Substring.

Walkthrough: Longest Palindromic Substring

Given a string s, return the longest palindromic substring in s.

1 · Clarify

Can s be empty? What if multiple palindromes share the max length? Length is 1 <= s.length <= 1000, alphanumeric characters, return any longest palindrome.

2 · Examples

s = "babad" → "bab" (or "aba"). s = "cbbd" → "bb".

3 · Approach

Brute force: check all O(n²) substrings in O(n) each → O(n³).

Expand Around Center: Every palindrome mirrors around either a single character center (i, i) (odd length) or a pair gap (i, i + 1) (even length). Expanding outward while s[l] == s[r] takes O(n) per center across 2n - 1 centers: O(n²) time and O(1) space (avoiding O(n²) DP table memory).

4 · Code 
class Solution {
    fun longestPalindrome(s: String): String {
        var bestStart = 0; var bestLen = 0
        fun expand(left: Int, right: Int) {
            var l = left; var r = right
            while (l >= 0 && r < s.length && s[l] == s[r]) { l--; r++ }
            val len = r - l - 1
            if (len > bestLen) { bestLen = len; bestStart = l + 1 }
        }
        for (i in s.indices) {
            expand(i, i)
            expand(i, i + 1)
        }
        return s.substring(bestStart, bestStart + bestLen)
    }
}
class Solution:
    def longestPalindrome(self, s: str) -> str:
        best_start, best_len = 0, 0
        def expand(l: int, r: int):
            nonlocal best_start, best_len
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            if r - l - 1 > best_len:
                best_len = r - l - 1
                best_start = l + 1
        for i in range(len(s)):
            expand(i, i)
            expand(i, i + 1)
        return s[best_start:best_start + best_len]
class Solution {
    private int bestStart = 0, bestLen = 0;
    private void expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
        int len = r - l - 1;
        if (len > bestLen) { bestLen = len; bestStart = l + 1; }
    }
    public String longestPalindrome(String s) {
        bestStart = 0; bestLen = 0;
        for (int i = 0; i < s.length(); i++) {
            expand(s, i, i);
            expand(s, i, i + 1);
        }
        return s.substring(bestStart, bestStart + bestLen);
    }
}

6 · Complexity

    private int expand(String s, int l, int r) {
        int cnt = 0;

        return cnt;

Quick check

Why does KMP achieve O(n + m) worst-case string matching where naive matching degrades to O(n * m)?

  1. Uses rolling polynomial hash
  2. Never backtracks haystack ptr
  3. Sorts pattern chars first
  4. Caches full n^2 table

Because the haystack pointer `i` never decreases and `j` drops via `lps[j-1]` at most as many times as it incremented, total work is strictly O(n + m).

In Basic Calculator II (with +, -, *, / and no parentheses), how do you handle * and / precedence in O(1) extra space?

  1. Sort numbers by operator
  2. Evaluate strictly left to right
  3. Defer add via lastTerm
  4. Scan string right to left

Tracking `lastTerm` lets you add `+` / `-` lazily while immediately multiplying or dividing `lastTerm` on `*` and `/` in O(n) time and O(1) space.

Why is Expand Around Center often preferred over 2D DP for Longest Palindromic Substring in interviews?

  1. Reduces space to O(1)
  2. Improves time to O(n)
  3. Handles even length strings
  4. Avoids checking char equality

2D DP allocates an n x n table (O(n²) space), whereas expanding from 2n - 1 centers achieves the same O(n²) time in O(1) space.
