Backtracking & Pruning

Choose, explore, and unchoose to generate combinations, subsets, and permutations.

Warm-up from memory

Close this page and recall: when appending a candidate path to your result list in backtracking, why must you make a copy (e.g. ArrayList(path) or path[:])?

The idea

Backtracking is exhaustive depth-first search on a decision tree. At each step: 1. Choose an option, 2. Recurse, 3. Unchoose (backtrack) to restore state. When results require subsets or combinations, sort first to prune duplicates easily.

Reach for it when you see…

  • 'Find all combinations', 'subsets', 'permutations'
  • 'Word search on a grid', 'N-Queens', 'Sudoku solver'
  • Input size is very small: n <= 15 to 20 (suggesting O(2^n) or O(n!))

Pattern templates

fun backtrack(start: Int, path: MutableList<Int>, result: MutableList<List<Int>>) {
    result.add(path.toList()) // COPY current state
    for (i in start until nums.size) {
        path.add(nums[i])     // 1. Choose
        backtrack(i + 1, path, result) // 2. Explore
        path.removeLast()     // 3. Unchoose
    }
}
def backtrack(start: int, path: list[int]):
    result.append(path[:])    # COPY current state
    for i in range(start, len(nums)):
        path.append(nums[i])  # 1. Choose
        backtrack(i + 1, path)# 2. Explore
        path.pop()            # 3. Unchoose
void backtrack(int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path)); // COPY current state
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);             // 1. Choose
        backtrack(i + 1, path, result);// 2. Explore
        path.remove(path.size() - 1);  // 3. Unchoose
    }
}

Walkthrough: Subsets

Given an integer array nums of unique elements, return all possible subsets (the power set).

1 · Clarify

Can nums have duplicates? What order should the subsets be returned? Elements are unique. Subsets can be in any order. Empty set is included.

2 · Examples

[1, 2, 3] → [[], [1], [2], [3], [1, 2], [1, 3], [2, 3], [1, 2, 3]]. Total subsets = 2^3 = 8.

3 · Approach

At each index i, we have two decisions: include nums[i] or don't include it. Alternatively, loop from start to nums.size: record current path, pick nums[i], recurse on i + 1, and backtrack.

4 · Code 
class Solution {
    fun subsets(nums: IntArray): List<List<Int>> {
        val result = mutableListOf<List<Int>>()
        val path = mutableListOf<Int>()

        fun dfs(start: Int) {
            result.add(ArrayList(path))
            for (i in start until nums.size) {
                path.add(nums[i])
                dfs(i + 1)
                path.removeAt(path.size - 1)
            }
        }

        dfs(0)
        return result
    }
}

    def subsets(self, nums: list[int]) -> list[list[int]]:
        result = []
        path = []

        def dfs(start: int):

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(0, nums, new ArrayList<>(), result);
        return result;
    }

    private void dfs(int start, int[] nums, List<Integer> path, List<List<Integer>> result) {
        result.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            dfs(i + 1, nums, path, result);
            path.remove(path.size() - 1);
        }
    }
}
5 · Test

Trace [1, 2]: dfs(0) adds [] → picks 1, dfs(1) adds [1] → picks 2, dfs(2) adds [1, 2] → unpicks 2, unpicks 1 → picks 2, dfs(2) adds [2] → unpicks 2. Returns [[], [1], [1, 2], [2]]. ✓

6 · Complexity

Time O(n × 2ⁿ): 2ⁿ total subsets, each taking O(n) to copy. Space O(n): maximum recursion stack depth.

Quick check

What happens if you do result.add(path) without copying path in a backtracking algorithm?

  1. The code throws OutOfMemoryError
  2. Recursion stack loops infinitely
  3. Only the initial path is created
  4. Every result entry ends up empty

Because path is modified in-place and emptied by backtracking, all stored references point to the same empty list.

How do you prevent duplicate subsets when the input array nums contains duplicate values?

  1. Sort array and skip duplicates
  2. Use a linked hash set queue
  3. Reverse the array after sorting
  4. Recurse only on even indices

Sorting groups duplicates together; skip with if (i > start && nums[i] == nums[i - 1]) continue.

What is the typical input size constraint that strongly hints at a backtracking approach?

  1. n <= 100,000 array elements
  2. n <= 20 elements input size
  3. n >= 1,000,000 stream data
  4. n <= 5,000 array elements

Because backtracking runs in exponential time (O(2^n) or O(n!)), problems constrain n <= 15-20.

Permutations Medium

  1. Unlike combinations, order matters. Start the loop from 0, not start.
  2. Keep a boolean visited[] array or check if nums[i] in path.
  3. Base case: path.size == nums.size.

Combination Sum Medium

  1. The same element can be chosen unlimited times. Recurse with dfs(i, remain - nums[i]).
  2. Base case: remain == 0 → add to result. remain < 0 → prune branch.
  3. Sort candidates first to break early when nums[i] > remain.

Word Search Medium

  1. Start DFS from every cell matching word[0].
  2. Temporarily mark visited cell with '#' to avoid allocating a separate boolean matrix.
  3. Restore cell character when backtracking.
