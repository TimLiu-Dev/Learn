Walkthrough: Diagnostic Exercise: Continuous Subarray Sum

Given an integer array nums and an integer k, return true if nums has a good subarray of length at least 2 whose sum is a multiple of k.

1 · Clarify

Can k be negative? Can nums contain 0? Length must be >= 2. Elements are non-negative. k >= 1.

2 · Examples

nums = [23, 2, 4, 6, 7], k = 6 → true ([2, 4] sums to 6).

3 · Approach

Pattern Diagnosis:

  • Can we use Sliding Window? No, because values can be arbitrary and adding elements doesn't monotonically grow mod k remainders.
  • Can we use Prefix Sums? Yes! (prefix[r] - prefix[l]) % k == 0 means prefix[r] % k == prefix[l] % k.
  • Pattern: Prefix Sum modulo arithmetic with seen-before HashMap storing remainder → earliest_index!
4 · Code 
class Solution {
    fun checkSubarraySum(nums: IntArray, k: Int): Boolean {
        val map = HashMap<Int, Int>() // remainder -> earliest index
        map[0] = -1
        var runningSum = 0

        for ((i, x) in nums.withIndex()) {
            runningSum += x
            val rem = runningSum % k
            if (rem in map) {
                if (i - map[rem]!! >= 2) return true
            } else {
                map[rem] = i // only store earliest to maximize length
            }
        }
        return false
    }
}
class Solution:
    def checkSubarraySum(self, nums: list[int], k: int) -> bool:
        rem_map = {0: -1}
        running_sum = 0

        for i, x in enumerate(nums):
            running_sum += x
            rem = running_sum % k
            if rem in rem_map:
                if i - rem_map[rem] >= 2:
                    return True
            else:
                rem_map[rem] = i
        return False
class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, -1);
        int runningSum = 0;

        for (int i = 0; i < nums.length; i++) {
            runningSum += nums[i];
            int rem = runningSum % k;
            if (map.containsKey(rem)) {
                if (i - map.get(rem) >= 2) return true;
            } else {
                map.put(rem, i);
            }
        }
        return false;
    }
}
5 · Test

[23, 2, 4, 6, 7], k = 6: i=0: 23%6=5 → map[5]=0. i=1: 25%6=1 → map[1]=1. i=2: 29%6=5 → 5 in map at index 0. Gap = 2 - 0 = 2 >= 2 → returns true. ✓

6 · Complexity

Time O(n): single pass. Space O(min(n, k)): hash map holds at most k distinct remainders.

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence in O(n) time.

Verified Trilingual Solutions & Complexity

Time O(n): each number visited at most twice. Space O(n): hash set.

class Solution {
    fun longestConsecutive(nums: IntArray): Int {
        val numSet = nums.toHashSet()
        var best = 0
        for (x in numSet) {
            if (x - 1 !in numSet) {
                var y = x + 1
                while (y in numSet) y++
                best = maxOf(best, y - x)
            }
        }
        return best
    }
}

    def longestConsecutive(self, nums: list[int]) -> int:

        best = 0
        for x in num_set:

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);
        int best = 0;
        for (int x : set) {
            if (!set.contains(x - 1)) {
                int y = x + 1;
                while (set.contains(y)) y++;
                best = Math.max(best, y - x);
            }
        }
        return best;
    }
}

Quick check

You are asked to find the 'next warmer temperature' for every day in an array. Which pattern is this?

  1. Binary search on answers space
  2. Sliding window variable sized
  3. Monotonic stack for next greater
  4. Two pointers moving from ends

Next greater/warmer element is the signature pattern of a Monotonic Decreasing Stack.

A problem asks to find the shortest transformation sequence between two words. Which pattern fits?

  1. Depth-first search path traversal
  2. Disjoint set union tree checks
  3. Dynamic programming 1D states
  4. Breadth-first search shortest path

Shortest path in unweighted graphs or word mutations is uniquely solved by BFS (or Bidirectional BFS).

If a problem asks for 'minimum coins to make amount', why is greedy (picking largest coin) insufficient?

  1. Large coins can block exact sums
  2. Greedy takes O(n!) factorial time
  3. Coins must be negative integers
  4. Greedy cannot run on array sets

With arbitrary coin systems (e.g. coins [1, 3, 4] for amount 6), greedy picks 4 + 1 + 1 (3 coins) while DP finds 3 + 3 (2 coins).

Subarray Product Less Than K Medium

  1. Can you use Prefix Sums? No, products grow too fast and overflow.
  2. Because all numbers are positive, expanding the window strictly increases the product.
  3. Use Sliding Window: count += right - left + 1.

Target Sum Medium

  1. Looks like backtracking, but with n = 20, 2^20 is 10^6.
  2. Math transformation: P - N = target, P + N = sum → 2P = target + sum.
  3. Reduces to 0/1 Knapsack: count subsets that sum to P!

Car Pooling Medium

  1. Can be viewed as intervals, sweep-line, or difference array.
  2. trips[i] = [numPassengers, from, to].
  3. Difference array on 1,000 stops: diff[from] += passengers, diff[to] -= passengers.
