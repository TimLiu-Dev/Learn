The idea

A greedy algorithm builds up a solution piece by piece, always choosing the next piece that offers the most immediate benefit (greedy choice property) and never reconsidering past choices. The challenge in technical interviews is proving to yourself and the interviewer that local optimal choices lead to global optimum (exchange argument).

Walkthrough: Maximum Subarray

Given an integer array nums, find the subarray with the largest sum, and return its sum.

1 · Clarify

Can nums contain negative numbers? Must the subarray contain at least 1 element? Yes: negative numbers allowed, subarray must be non-empty.

2 · Examples

nums = [-2,1,-3,4,-1,2,1,-5,4] → 6 ([4,-1,2,1]). nums = [-1] → -1.

3 · Approach

Kadane's Insight: As we iterate through the array, if the running sum becomes negative, adding it to any future element will only decrease that element's sum. So whenever currSum < 0, reset currSum = 0!

4 · Code 
class Solution {
    fun maxSubArray(nums: IntArray): Int {
        var maxSoFar = nums[0]
        var currSum = 0
        for (x in nums) {
            currSum += x
            maxSoFar = maxOf(maxSoFar, currSum)
            if (currSum < 0) currSum = 0
        }
        return maxSoFar
    }
}
class Solution:

class Solution {
    public int maxSubArray(int[] nums) {
        int maxSoFar = nums[0];
        int currSum = 0;
        for (int x : nums) {
            currSum += x;
            maxSoFar = Math.max(maxSoFar, currSum);
            if (currSum < 0) currSum = 0;
        }
        return maxSoFar;
    }
}

class Solution {
    fun canJump(nums: IntArray): Boolean {
        var farthest = 0
        for (i in nums.indices) {
            if (i > farthest) return false
            farthest = maxOf(farthest, i + nums[i])
            if (farthest >= nums.size - 1) return true
        }
        return true
    }
}
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        farthest = 0
        for i, x in enumerate(nums):
            if i > farthest:
                return False
            farthest = max(farthest, i + x)
            if farthest >= len(nums) - 1:
                return True
        return True
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }
}

Quick check

In Kadane's algorithm, under what condition do we discard the accumulated prefix sum?

  1. When accumulated sum drops < 0
  2. When next array element is zero
  3. When current index exceeds n / 2
  4. When array elements are all even

A negative running sum will only detract from any future subarray sum, so resetting to 0 is always optimal.

What differentiates Greedy from Dynamic Programming in algorithmic problem-solving?

  1. DP does not use cache memoization
  2. Greedy never reconsiders choices
  3. Greedy always explores all paths
  4. DP works only on sorted arrays

Greedy makes a locally optimal choice immediately and commits to it; DP considers and compares multiple subproblem solutions.

Gas Station Medium

  1. If sum(gas) < sum(cost), it's impossible → return -1.
  2. If you run out of gas starting at A and failing at B, no station between A and B can reach B either!
  3. Restart search at B + 1 with tank = 0.

Partition Labels Medium

  1. Precompute the last occurrence index of each character in a map or int[26].
  2. Maintain the boundary end = max(end, last[c]).
  3. When current index i == end, a partition boundary is reached! Record length and reset start.
