The idea

Trees are recursively defined hierarchical structures without cycles. Depth-First Search (DFS) explores as deep as possible along each branch before backtracking. Pre-order processes root before children; in-order visits left, root, right (sorted order for BSTs); post-order collects results from both children before computing the parent's answer.

Reach for it when you see…

  • Binary tree maximum / minimum depth
  • Tree symmetry, invert binary tree, or identical trees
  • Subtree sum, diameter of binary tree, or path sum
  • Lowest Common Ancestor in a general binary tree

Pattern templates

// Post-order DFS: bottom-up aggregation
fun maxDepth(root: TreeNode?): Int {
    if (root == null) return 0
    val left = maxDepth(root.left)
    val right = maxDepth(root.right)
    return 1 + maxOf(left, right)
}
# Post-order DFS
def maxDepth(root: Optional[TreeNode]) -> int:
    if not root:
        return 0
    left = maxDepth(root.left)
    right = maxDepth(root.right)
    return 1 + max(left, right)
// Post-order DFS
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int left = maxDepth(root.left);
    int right = maxDepth(root.right);
    return 1 + Math.max(left, right);
}

Walkthrough: Maximum Depth of Binary Tree

Given the root of a binary tree, return its maximum depth. A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

1 · Clarify

Can root be null? What is the depth of a single-node tree? Null tree has depth 0. Single root node has depth 1.

2 · Examples

root = [3,9,20,null,null,15,7] -> 3. root = [1,null,2] -> 2.

3 · Approach

Base case: if root == null, depth is 0. Recursively compute depth of left subtree and right subtree. The depth at current node is 1 + max(leftDepth, rightDepth). This is post-order DFS (bottom-up aggregation).

4 · Code 
class Solution {
    fun maxDepth(root: TreeNode?): Int {
        if (root == null) return 0
        val left = maxDepth(root.left)
        val right = maxDepth(root.right)
        return 1 + maxOf(left, right)
    }
}
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        int left = maxDepth(root.left);
        int right = maxDepth(root.right);
        return 1 + Math.max(left, right);
    }
}
5 · Test

Trace [3, 9, 20, null, null, 15, 7]: maxDepth(9)=1. maxDepth(15)=1, maxDepth(7)=1 -> maxDepth(20)=1+max(1,1)=2. maxDepth(3)=1+max(1,2)=3. Returns 3. Correct! ✓

6 · Complexity

Time O(n): visits each node exactly once. Space O(h): call stack depth proportional to tree height (O(log n) balanced, O(n) worst-case skewed).

Quick check

What is the worst-case space complexity of recursive DFS on a binary tree with n nodes?

  1. O(n) auxiliary call stack space when the tree degenerates into a single linked list
  2. O(1) space because recursive frames allocate no heap memory
  3. O(n²) stack memory due to function pointer cloning
  4. Strictly O(log n) regardless of tree shape

If each node has only one child (a completely skewed tree), the recursion depth reaches n, requiring O(n) active call stack frames.

When calculating the Diameter of a Binary Tree (longest path between any two nodes), why is post-order DFS required?

  1. Pre-order traversal is unable to visit leaf nodes in binary trees
  2. The diameter passing through root requires knowing the maximum depths of both left and right subtrees first
  3. Because post-order traversal reverses the order of node values in-place
  4. Diameter algorithms cannot accept negative node values

At each node, the longest path using that node as highest ancestor is leftDepth + rightDepth. You must compute child depths before resolving parent diameter.

In Invert Binary Tree (LeetCode 226), what is the core operation at each visited node?

  1. Negate the integer value stored inside node.val
  2. Rotate the tree 90 degrees clockwise using AVL pivot rotations
  3. Swap node.left and node.right pointers, then recursively invert both subtrees
  4. Delete all right child nodes and append them to the left child

Inverting a tree is mirroring: swapping left and right child pointers at every node creates the exact mirror image.

  1. If root is null or root == p or root == q, return root.
  2. Recurse left and right.
  3. If both left and right return non-null, root is LCA! If only one is non-null, return that one.
