The idea

In 2D Dynamic Programming, the subproblem state depends on two coordinates: (row, col) in a matrix, or (index_i, index_j) representing prefixes of two strings. Because computing the current row only requires the previous row, 2D tables can almost always be compressed to 1D arrays of size O(min(M, N)).

Walkthrough: Unique Paths

A robot is located at the top-left corner of an m x n grid. The robot can only move either down or right at any point in time. How many possible unique paths are there to the bottom-right corner?

1 · Clarify

Can m or n be 1? Are there obstacles? m, n between 1 and 100. No obstacles in this basic version. Output fits in 32-bit integer.

2 · Examples

m = 3, n = 7 → 28. m = 3, n = 2 → 3.

3 · Approach

1. State: dp[r][c] = number of unique paths to cell (r, c).

2. Recurrence: Robot can only arrive from top (r-1, c) or left (r, c-1): dp[r][c] = dp[r-1][c] + dp[r][c-1].

3. Base cases: dp[0][c] = 1 and dp[r][0] = 1 (only one straight path).

4. Space: Notice that computing row r only needs row r-1. A single 1D array of size n is sufficient: dp[c] = dp[c] (from above) + dp[c-1] (from left).

4 · Code 
class Solution {
    fun uniquePaths(m: Int, n: Int): Int {

        for (r in 1 until m) {
            for (c in 1 until n) {

            }
        }
        return dp[n - 1]
    }
}

Quick check

In Longest Common Subsequence, if text1[i] == text2[j], how is dp[i][j] calculated?

  1. max(dp[i-1][j], dp[i][j-1])
  2. 1 + dp[i - 1][j - 1]
  3. dp[i - 1][j] + dp[i][j - 1]
  4. 1 + max(dp[i][j-1], dp[i-1][j])

Matching characters contribute 1 to the match, reducing the subproblem to the diagonal earlier state dp[i-1][j-1].

In Edit Distance (Levenshtein), what three operations correspond to the three adjacent transitions?

  1. Swap, Copy, and Translate
  2. Push, Pop, and Peek entries
  3. Insert, Delete, and Replace
  4. Split, Join, and Filter chars

dp[i-1][j] corresponds to deletion, dp[i][j-1] to insertion, and dp[i-1][j-1] to replacement.

How can the space complexity of an M x N 2D dynamic programming grid be reduced?

  1. Transpose the input matrix first
  2. Run DFS with iterative stack
  3. Sort the array before processing
  4. Maintain only current and prev row

Because cell (r, c) only reads from row r and row r-1, keeping 1 or 2 rows reduces space from O(M*N) to O(min(M, N)).

Longest Common Subsequence Medium

  1. dp[i][j] = LCS length of text1[0..i] and text2[0..j].
  2. If text1[i-1] == text2[j-1]: dp[i][j] = 1 + dp[i-1][j-1].
  3. Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).

Edit Distance Medium

  1. Base cases: dp[i][0] = i (deleting all), dp[0][j] = j (inserting all).
  2. If chars match: dp[i][j] = dp[i-1][j-1].
  3. If mismatch: dp[i][j] = 1 + min(dp[i-1][j] (del), dp[i][j-1] (ins), dp[i-1][j-1] (replace)).

Coin Change II Medium

  1. Count combinations (order does not matter).
  2. Outer loop over coins, inner loop over amounts 1..amount.
  3. dp[i] += dp[i - coin].
