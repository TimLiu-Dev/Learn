Two Pointers

Two indices, one pass. Every step prunes a row of invalid choices.

Your winReplace nested loops with two converging or fast/slow pointers, achieving O(1) auxiliary space.

The idea

When an array is sorted or symmetric, checking all pairs (i, j) in O(n²) tests combinations that cannot possibly work. By starting pointers at opposite ends (or fast/slow) and comparing against a target, every comparison prunes an entire row or column of pairs in O(1).

Reach for it when you see…

  • Sorted array asking for pair sum or condition
  • Palindrome verification or symmetric string comparison
  • In-place partitioning or removing elements without extra memory (O(1) space)

Walkthrough: Valid Palindrome

A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward.

1 · Clarify

Are empty strings considered palindromes? Should we treat alphanumeric characters case-insensitively? Yes, empty strings are valid palindromes, and comparison is case-insensitive.

2 · Examples

s = 'A man, a plan, a canal: Panama' -> True. s = 'race a car' -> False. s = ' ' -> True.

3 · Approach

Brute force: Filter the string into a new cleaned string, reverse it, and compare. Takes O(n) time and O(n) extra memory.

Two pointers: Place l = 0 and r = len(s) - 1. Skip non-alphanumeric characters with l++ and r--. Compare lowercase characters. If they mismatch, return false immediately. If pointers cross, return true. Takes O(n) time and O(1) space.

4 · Code 
class Solution {
    fun isPalindrome(s: String): Boolean {
        var l = 0
        var r = s.length - 1
        while (l < r) {
            while (l < r && !s[l].isLetterOrDigit()) l++
            while (l < r && !s[r].isLetterOrDigit()) r--
            if (s[l].lowercaseChar() != s[r].lowercaseChar()) return false
            l++
            r--
        }
        return true
    }
}
class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1

                return False
            l += 1
            r -= 1
        return True
class Solution {
    public boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
            while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
            if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) {
                return false;
            }
            l++;
            r--;
        }
        return true;
    }
}

6 · Complexity

Quick check

When running two pointers on a sorted array, why does nums[l] + nums[r] < target mean you MUST increment l rather than decrement r?

  1. Incrementing l guarantees the algorithm finishes in exactly n/2 steps
  2. Decreasing r would cause array index underflow below 0
  3. Because sorted arrays cannot contain negative numbers
  4. r is already paired with the smallest available value, so only increasing l can raise sum

Since the array is sorted, pairing nums[r] with any value to the left of l would produce an even smaller sum. Thus nums[l] cannot be part of any valid pair with the remaining elements.

What does in-place two-pointer palindrome check save compared to building a filtered reversed string?

  1. Saves O(n) auxiliary heap memory allocations
  2. Reduces time complexity from O(n²) to O(n)
  3. Eliminates character comparison operations completely
  4. Enables concurrent parallel processing across threads

Both approaches take O(n) time, but two pointers operates directly on the original string, dropping auxiliary memory from O(n) to O(1).

In the 3Sum problem (a + b + c = 0), what preprocessing step enables the two-pointer approach?

  1. Hashing all elements into a bitset array
  2. Sorting the array in O(n log n) time
  3. Reversing the array in O(n) time
  4. Partitioning the array by even and odd integers

Sorting in O(n log n) allows you to fix the first element nums[i] and run two pointers (l and r) on the remaining suffix, while skipping duplicate values easily.

Two Sum II – Input Array Is Sorted Medium

  1. Since the array is sorted, start pointers at 0 and len - 1.
  2. If sum < target, l++. If sum > target, r--.
  3. Problem uses 1-based indexing for return values.

3Sum Medium

  1. Sort array first in O(n log n).
  2. Loop i from 0 to n-3. Skip duplicates if nums[i] == nums[i-1].
  3. Run two pointers on (i+1, n-1) looking for target -nums[i]. Skip duplicates when advancing l and r.

Container With Most Water Medium

  1. Area is (r - l) * min(h[l], h[r]).
  2. Which pointer should you move? Moving the taller line cannot increase area because width shrinks and bottleneck remains min height.
  3. Always move the shorter line inward.
