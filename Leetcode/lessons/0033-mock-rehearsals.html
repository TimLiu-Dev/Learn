Walkthrough: Cap-Stone Problem: Trapping Rain Water

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

1 · Clarify

Can heights be negative? Can array be empty? Heights are non-negative. Array size up to 2 * 10^4. Elevation at ends cannot trap water.

2 · Examples

height = [0,1,0,2,1,0,1,3,2,1,2,1] → 6. height = [4,2,0,3,2,5] → 9.

3 · Approach

Candidate Narration:

For any bar at index i, the water it traps is max(0, min(maxLeft, maxRight) - height[i]).

We can precompute maxLeft and maxRight in O(n) space using prefix arrays. But can we optimize space to O(1)?

Two-Pointer Space Optimization: Keep pointers l = 0 and r = n - 1. Whichever side has the smaller max boundary determines water trapped on that side, because the other side is guaranteed to be taller! Move the smaller boundary inward.

4 · Code 
class Solution {
    fun trap(height: IntArray): Int {
        if (height.isEmpty()) return 0
        var l = 0; var r = height.size - 1
        var leftMax = height[l]; var rightMax = height[r]
        var water = 0

        while (l < r) {
            if (leftMax < rightMax) {
                l++
                leftMax = maxOf(leftMax, height[l])
                water += leftMax - height[l]
            } else {
                r--
                rightMax = maxOf(rightMax, height[r])
                water += rightMax - height[r]
            }
        }
        return water
    }
}

class Solution {
    public int trap(int[] height) {
        if (height == null || height.length == 0) return 0;
        int l = 0, r = height.length - 1;
        int leftMax = height[l], rightMax = height[r];
        int water = 0;

        while (l < r) {
            if (leftMax < rightMax) {
                l++;
                leftMax = Math.max(leftMax, height[l]);
                water += leftMax - height[l];
            } else {
                r--;
                rightMax = Math.max(rightMax, height[r]);
                water += rightMax - height[r];
            }
        }
        return water;
    }
}
5 · Test

Trace [4, 2, 0, 3, 2, 5]: l=0 (4), r=5 (5). leftMax=4 < rightMax=5 → l advances: l=1 (2), water += 4 - 2 = 2. l=2 (0), water += 4 - 0 = 4. l=3 (3), water += 4 - 3 = 1. l=4 (2), water += 4 - 2 = 2. l meets r → total water = 9. ✓

6 · Complexity

Time O(n): single two-pointer pass. Space O(1): optimal constant memory.

Given a string s and a dictionary of strings wordDict, return true if s can be segmented into a space-separated sequence of one or more dictionary words.

Time O(n² * k): n is string length, k is max word length. Space O(n + W): DP array and word set.

class Solution {
    fun wordBreak(s: String, wordDict: List<String>): Boolean {
        val words = wordDict.toHashSet()
        val dp = BooleanArray(s.length + 1)
        dp[0] = true
        for (i in 1..s.length) {
            for (j in 0 until i) {
                if (dp[j] && s.substring(j, i) in words) {
                    dp[i] = true
                    break
                }
            }
        }
        return dp[s.length]
    }
}

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 1; i <= s.length(); i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && words.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}

Quick check

What is the single biggest red flag in communication during a Big Tech coding interview?

  1. Asking clarifying question on inputs
  2. Going silent for 10 minutes coding
  3. Proposing a brute-force approach
  4. Tracing through normal test cases

Silence leaves the interviewer with no visibility into your thought process. Always narrate your reasoning out loud.

In the Big Tech grading rubric, what is expected during the Verification step after coding?

  1. Immediately announce that you are done
  2. Ask the interviewer if it is correct
  3. Dry-run an example manually line by line
  4. Click submit to let tests find bugs

Top candidates proactively trace their code line-by-line with an example, catching edge cases before the interviewer says a word.

What does BTTC stand for in interview problem analysis?

  1. Binary Tree Traversal Calculation math
  2. Branch Target Translation Cache memory
  3. Base Type Transition Comparator method
  4. Best Theoretical Time Complexity bound

Best Theoretical Time Complexity is the lower bound you can deduce from reading inputs (e.g. must visit N items &rarr; Omega(N)).

Median of Two Sorted Arrays Hard Google / Meta benchmark

  1. Target is O(log(min(m, n))) time.
  2. Binary search on the partition point of the smaller array.
  3. Ensure left_half_max <= right_half_min across both arrays.

Serialize and Deserialize Binary Tree Hard

  1. Use Pre-order DFS with delimiter ',' and sentinel 'null'.
  2. Deserialize: split by comma into a queue, reconstruct recursively: poll node, recurse left, recurse right.

Merge k Sorted Lists Hard

  1. Approach 1: Min-Heap of size k storing list heads in O(N log k).
  2. Approach 2: Divide and conquer merge pairs in O(N log k) and O(1) space.
