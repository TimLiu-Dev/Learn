Walkthrough: Insert Delete GetRandom O(1)

Implement the RandomizedSet class: insert(val), remove(val), and getRandom() each in average O(1) time.

1 · Clarify

Are elements unique? What if val is not present during remove? Elements are unique. If val not present, remove returns false. getRandom must return each element with equal probability.

2 · Examples

insert(1) → true. remove(2) → false. insert(2) → true. getRandom() → 1 or 2 equally. remove(1) → true. getRandom() → 2.

3 · Approach

1. A Hash Map alone gives O(1) insert/remove, but cannot pick a random element in O(1) (keys cannot be indexed directly).

2. An Array gives O(1) getRandom by index, but removing an arbitrary element takes O(n) to shift elements.

3. Composite Solution: Maintain an ArrayList of values, and a HashMap of value → index_in_list.

4. To remove val in O(1): swap it with the last element in the list, update the swapped element's index in the map, and pop the last element!

4 · Code 
class RandomizedSet() {
    private val list = mutableListOf<Int>()
    private val map = HashMap<Int, Int>() // val -> index in list
    private val random = java.util.Random()

    fun insert(`val`: Int): Boolean {
        if (`val` in map) return false
        map[`val`] = list.size
        list.add(`val`)
        return true
    }

    fun remove(`val`: Int): Boolean {
        val idx = map[`val`] ?: return false
        val lastVal = list.last()
        list[idx] = lastVal
        map[lastVal] = idx
        list.removeAt(list.size - 1)
        map.remove(`val`)
        return true
    }

    fun getRandom(): Int = list[random.nextInt(list.size)]
}

class RandomizedSet:
    def __init__(self):
        self.list = []
        self.map = {} # val -> index

    def insert(self, val: int) -> bool:
        if val in self.map: return False
        self.map[val] = len(self.list)
        self.list.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.map: return False
        idx = self.map[val]
        last_val = self.list[-1]
        self.list[idx] = last_val
        self.map[last_val] = idx
        self.list.pop()
        del self.map[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.list)
class RandomizedSet {
    private final List<Integer> list = new ArrayList<>();
    private final Map<Integer, Integer> map = new HashMap<>();
    private final Random random = new Random();

    public boolean insert(int val) {
        if (map.containsKey(val)) return false;
        map.put(val, list.size());
        list.add(val);
        return true;
    }

    public boolean remove(int val) {
        if (!map.containsKey(val)) return false;
        int idx = map.get(val);
        int lastVal = list.get(list.size() - 1);
        list.set(idx, lastVal);
        map.put(lastVal, idx);
        list.remove(list.size() - 1);
        map.remove(val);
        return true;
    }

    public int getRandom() {
        return list.get(random.nextInt(list.size()));
    }
}

class TokenBucket(val capacity: Double, val refillRate: Double) {
    private var tokens = capacity
    private var lastTimestamp = 0.0
    fun allowRequest(currentTimestamp: Double, tokensNeeded: Double = 1.0): Boolean {
        val elapsed = currentTimestamp - lastTimestamp
        tokens = minOf(capacity, tokens + elapsed * refillRate)
        lastTimestamp = currentTimestamp
        if (tokens >= tokensNeeded) {
            tokens -= tokensNeeded
            return true
        }
        return false
    }
}
class TokenBucket:
    def __init__(self, capacity: float, refill_rate: float):
        self.capacity = capacity
        self.refill_rate = refill_rate
        self.tokens = capacity
        self.last_ts = 0.0
    def allow_request(self, current_ts: float, needed: float = 1.0) -> bool:
        elapsed = current_ts - self.last_ts
        self.tokens = min(self.capacity, self.tokens + elapsed * self.refill_rate)
        self.last_ts = current_ts
        if self.tokens >= needed:
            self.tokens -= needed
            return True
        return False
class TokenBucket {
    private final double capacity, refillRate;
    private double tokens, lastTimestamp;
    public TokenBucket(double capacity, double refillRate) {
        this.capacity = capacity;
        this.refillRate = refillRate;
        this.tokens = capacity;
        this.lastTimestamp = 0.0;
    }
    public synchronized boolean allowRequest(double currentTimestamp, double needed) {
        double elapsed = currentTimestamp - lastTimestamp;
        tokens = Math.min(capacity, tokens + elapsed * refillRate);
        lastTimestamp = currentTimestamp;
        if (tokens >= needed) {
            tokens -= needed;
            return true;
        }
        return false;
    }
}

Quick check

Why does removing an element by swapping with the last element achieve O(1) time complexity?

  1. Avoids shifting subsequent array items
  2. Bypasses JVM garbage collection runs
  3. Compresses underlying memory headers
  4. Re-indexes hash keys instantaneously

Standard array removal shifts all remaining elements left in O(n); swapping with the tail allows O(1) pop from the end.

In a Sliding Window Log Rate Limiter, how are expired request timestamps removed from a queue?

  1. Evict from rear of double queue
  2. Evict from front while t < now - win
  3. Clear entire queue at start of sec
  4. Run binary search on timestamps

Because timestamps are monotonically increasing, expired entries sit at the front of the queue and are polled in O(1).

What advantage does a Token Bucket algorithm have over a Fixed Window Counter rate limiter?

  1. Requires zero integer memory bytes
  2. Runs strictly in logarithmic bound
  3. Handles traffic bursts without reset
  4. Eliminates need for system clock calls

Token Bucket smooths traffic and permits configured bursts up to bucket capacity while replenishing continuously.

Design Hit Counter Medium

  1. Calls arrive in chronological order (timestamps are non-decreasing).
  2. Keep a queue of timestamps: hit(timestamp) appends timestamp.
  3. getHits(timestamp): pop timestamps <= timestamp - 300, then return queue.size.

Logger Rate Limiter Easy

  1. Maintain a map of message → next_allowed_timestamp.
  2. If timestamp >= map[msg], update map[msg] = timestamp + 10 and return true.
  3. Else return false.
