The idea

2D matrix interview problems rarely test exotic algorithms—they test index discipline under pressure. Instead of writing fragile four-way layer swaps, decompose rotations into two simple passes (transpose + horizontal reverse for 90° clockwise), shrink four boundaries (top, bottom, left, right) for spiral scans, and reuse row 0 / col 0 as O(1) marker flags.

Reach for it when you see…

  • 'Rotate matrix by 90 degrees in-place' (transpose + reverse rows)
  • 'Spiral order traversal' or 'generate spiral matrix'
  • 'Set entire row and column to zero in O(1) extra space'
  • Grid simulation ('Valid Sudoku', 'Game of Life' bit-packing)

Walkthrough: Rotate Image

You are given an n x n 2D matrix representing an image. Rotate the image by 90 degrees clockwise in-place without allocating another 2D matrix.

1 · Clarify

Is the matrix always square (n x n)? What are the dimensions? Yes, n x n with 1 <= n <= 20, integer values can be negative, and mutation must be in-place (O(1) extra space).

2 · Examples

[[1,2,3],[4,5,6],[7,8,9]] → transpose → [[1,4,7],[2,5,8],[3,6,9]] → reverse each row → [[7,4,1],[8,5,2],[9,6,3]].

3 · Approach

A 90° clockwise rotation maps (r, c) → (c, n - 1 - r). Notice that this composition equals two simpler operations:

  • Transpose across the main diagonal: (r, c) → (c, r), looping only over the upper triangle c > r so elements aren't swapped twice.
  • Reflect horizontally (reverse each row): (c, r) → (c, n - 1 - r).

Why prefer this over 4-way ring swaps? Fewer index mistakes under interview pressure and identical O(n²) time, O(1) space.

    }
}

class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        for (int r = 0; r < n; r++) {
            for (int c = r + 1; c < n; c++) {
                int tmp = matrix[r][c];
                matrix[r][c] = matrix[c][r];
                matrix[c][r] = tmp;
            }
        }
        for (int r = 0; r < n; r++) {
            int l = 0, h = n - 1;
            while (l < h) {
                int tmp = matrix[r][l];
                matrix[r][l++] = matrix[r][h];
                matrix[r][h--] = tmp;
            }
        }
    }
}

6 · Complexity

Time O(n²): touches each of the n² cells twice. Space O(1): strictly in-place swaps.

Quick check

How do you rotate an N x N matrix 90 degrees counter-clockwise using two simple in-place passes?

  1. Transpose then reverse every row
  2. Reverse rows then transpose grid
  3. Reverse rows and reverse columns
  4. Sort rows then swap diagonals

Reversing each row maps (r, c) to (r, n-1-c), and transposing then maps it to (n-1-c, r), which is 90° counter-clockwise.

In Spiral Matrix on a rectangular M x N grid, why must the bottom and left loops re-check boundaries?

  1. Prevent signed integer overflows
  2. Reduce space usage to O(1)
  3. Avoid re-scanning the final strip
  4. Speed up runtime from O(N^2)

In a 1xN or Mx1 leftover strip, top++ or right-- crosses the opposite bound mid-iteration, so without if top <= bottom and if left <= right you visit cells twice.

In Set Matrix Zeroes, how do you mark zeroed rows and columns without allocating O(M + N) arrays?

  1. Reuse first row and column
  2. Store zero indices in HashSet
  3. Zero neighbors during first pass
  4. Sort matrix rows by zero count

Reusing row 0 and column 0 as flag arrays (with one extra boolean to separate matrix[0][0]'s row vs column role) achieves strict O(1) extra space.

Spiral Matrix Medium High frequency

  1. Maintain four shrinking boundaries: top = 0, bottom = R - 1, left = 0, right = C - 1.
  2. Traverse top row, right column, bottom row (if top <= bottom), left column (if left <= right).
  3. Tighten each boundary immediately after scanning it.

Set Matrix Zeroes Medium

  1. O(M + N) space uses two boolean arrays: zeroRow[M] and zeroCol[N].
  2. To get O(1) space, store those flags in matrix[r][0] and matrix[0][c] — plus a boolean firstColZero so matrix[0][0] isn't overloaded.
  3. Fill interior cells (1..M-1, 1..N-1) first, then zero row 0 and col 0 last.

Valid Sudoku Medium

  1. You need 3 constraint checks per filled digit: row r, col c, and 3x3 sub-box.
  2. Sub-box index from (r, c) is (r / 3) * 3 + (c / 3) (or integer pair (r // 3, c // 3)).
  3. Use three bitmasks (int[9]) or hash sets for O(1) space/time validation.
