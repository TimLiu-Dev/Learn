Disjoint Set Union (DSU / Union-Find)

Track connected components and detect cycles in undirected graphs in near O(1) time.

The idea

Disjoint Set Union (DSU) partitions n elements into disjoint sets. With two optimizations — Path Compression (flattening trees during find) and Union by Rank/Size (attaching smaller tree under larger tree) — both find and union run in O(alpha(n)) amortized time, which is effectively <= 4 for all practical universe sizes.

Pattern templates

class DSU(n: Int) {
    val parent = IntArray(n) { it }
    val rank = IntArray(n) { 1 }

    fun find(i: Int): Int {
        if (parent[i] != i) parent[i] = find(parent[i]) // path compression
        return parent[i]
    }

    fun union(i: Int, j: Int): Boolean {
        val rootI = find(i); val rootJ = find(j)
        if (rootI == rootJ) return false // cycle / already connected
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ
        else {
            parent[rootJ] = rootI
            if (rank[rootI] == rank[rootJ]) rank[rootI]++
        }
        return true
    }
}
class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [1] * n

    def find(self, i: int) -> int:
        if self.parent[i] != i:
            self.parent[i] = self.find(self.parent[i]) # path compression
        return self.parent[i]

    def union(self, i: int, j: int) -> bool:
        root_i, root_j = self.find(i), self.find(j)
        if root_i == root_j:
            return False # already connected
        if self.rank[root_i] < self.rank[root_j]:
            self.parent[root_i] = root_j
        else:
            self.parent[root_j] = root_i
            if self.rank[root_i] == self.rank[root_j]:
                self.rank[root_i] += 1
        return True
class DSU {
    int[] parent, rank;
    public DSU(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; rank[i] = 1; }
    }
    public int find(int i) {
        if (parent[i] != i) parent[i] = find(parent[i]); // path compression
        return parent[i];
    }
    public boolean union(int i, int j) {
        int rootI = find(i), rootJ = find(j);
        if (rootI == rootJ) return false;
        if (rank[rootI] < rank[rootJ]) parent[rootI] = rootJ;
        else {
            parent[rootJ] = rootI;
            if (rank[rootI] == rank[rootJ]) rank[rootI]++;
        }
        return true;
    }
}

Walkthrough: Redundant Connection

Given an undirected graph that started as a tree with n nodes and had one extra edge added, return an edge that can be removed so the graph is a tree.

1 · Clarify

Are nodes 1-indexed? If multiple answers, which do we return? Nodes are 1-indexed (1 to n). Return the edge that occurs last in the input.

2 · Examples

edges = [[1,2],[1,3],[2,3]] → [2,3] (forms cycle with 1-2 and 1-3).

3 · Approach

A tree with n nodes has n - 1 edges and no cycles. Adding 1 edge creates exactly 1 cycle.

Iterate through edges: call union(u, v). If u and v already have the same root (i.e. union returns false), this edge forms the cycle! Return it.

4 · Code 
class Solution {
    fun findRedundantConnection(edges: Array<IntArray>): IntArray {
        val n = edges.size
        val parent = IntArray(n + 1) { it }

        fun find(i: Int): Int {
            if (parent[i] != i) parent[i] = find(parent[i])
            return parent[i]
        }

        for (edge in edges) {
            val u = edge[0]; val v = edge[1]
            val rootU = find(u); val rootV = find(v)
            if (rootU == rootV) return edge
            parent[rootU] = rootV
        }
        return intArrayOf()
    }
}
class Solution:
    def findRedundantConnection(self, edges: list[list[int]]) -> list[int]:
        n = len(edges)
        parent = list(range(n + 1))

        def find(i: int) -> int:
            if parent[i] != i:
                parent[i] = find(parent[i])
            return parent[i]

        for u, v in edges:
            root_u, root_v = find(u), find(v)
            if root_u == root_v:
                return [u, v]
            parent[root_u] = root_v

        return []
class Solution {
    public int[] findRedundantConnection(int[][] edges) {
        int n = edges.length;
        int[] parent = new int[n + 1];
        for (int i = 0; i <= n; i++) parent[i] = i;

        for (int[] edge : edges) {
            int rootU = find(parent, edge[0]);
            int rootV = find(parent, edge[1]);
            if (rootU == rootV) return edge;
            parent[rootU] = rootV;
        }
        return new int[0];
    }

    private int find(int[] parent, int i) {
        if (parent[i] != i) parent[i] = find(parent, parent[i]);
        return parent[i];
    }
}

class Solution {
    fun countComponents(n: Int, edges: Array<IntArray>): Int {
        val parent = IntArray(n) { it }
        fun find(i: Int): Int {
            var root = i
            while (root != parent[root]) root = parent[root]
            var curr = i
            while (curr != root) {
                val nxt = parent[curr]
                parent[curr] = root
                curr = nxt
            }
            return root
        }
        var count = n
        for (e in edges) {
            val r1 = find(e[0]); val r2 = find(e[1])
            if (r1 != r2) {
                parent[r1] = r2
                count--
            }
        }
        return count
    }
}

Quick check

What is the amortized time complexity of DSU operations with path compression and union by rank?

  1. O(log n) tree depth lookup
  2. O(1) strict constant bound
  3. O(alpha(n)) inverse Ackermann
  4. O(n) linear tree traversal

Both optimizations together bound operation cost to alpha(n), which is <= 4 for all practical values of n.

How does path compression optimize future find() operations in a disjoint set?

  1. Sorts nodes in parent array
  2. Deletes empty component sets
  3. Balances binary search trees
  4. Points visited nodes to root

During find(x), path compression updates parent[x] = root, flattening the tree so future lookups are O(1).

When union(u, v) is called on an edge and find(u) == find(v), what is revealed about the graph?

  1. A cycle is created by edge
  2. Graph has split components
  3. The edge weight is negative
  4. Node u must be an ancestor

If u and v already belong to the same connected component, connecting them directly closes a cycle.
