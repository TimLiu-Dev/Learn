The idea

Interviewers evaluate your thought process, constraint verification, and communication just as much as final syntax. In 2027 interviews, Big Tech rubric specifically grades whether you explain space overhead (heap allocations vs stack frames vs unboxed primitives) and whether you clarify bounds before writing a line of code.

Reach for it when you see…

  • Any coding interview prompt: execute Clarify -> Examples -> Approach -> Code -> Test -> Complexity

  • Memory model questions: boxed objects vs unboxed primitive arrays (IntArray vs Array, int[] vs Integer[])

Walkthrough: Running Sum of 1d Array

Given an array nums, define a running sum of an array as runningSum[i] = sum(nums[0]…nums[i]). Return the running sum.

1 · Clarify

Can nums be empty? What are the value ranges? Can we modify the input array in-place or should we allocate fresh memory? Problem statement guarantees nums.length >= 1, elements fit in standard 32-bit integer. Always ask whether mutating the input array is acceptable to the interviewer.

2 · Examples

Input: nums = [1,2,3,4]. Output: [1,3,6,10]. Edge case: [1] -> [1].

3 · Approach

Approach 1 (Clean Functional / Out-of-place): Allocate an output array of length n. Initialize res[0] = nums[0], then for each i from 1 to n-1, res[i] = res[i-1] + nums[i]. This takes O(n) time and O(n) extra space.

Approach 2 (In-place): If mutation is permitted, iterate from index 1 to n-1 updating nums[i] += nums[i-1]. This takes O(n) time and O(1) auxiliary space.

4 · Code 
class Solution {
    fun runningSum(nums: IntArray): IntArray {
        val result = IntArray(nums.size)
        result[0] = nums[0]
        for (i in 1 until nums.size) {
            result[i] = result[i - 1] + nums[i]
        }
        return result
    }
}
class Solution:
    def runningSum(self, nums: list[int]) -> list[int]:
        result = [0] * len(nums)
        result[0] = nums[0]
        for i in range(1, len(nums)):
            result[i] = result[i - 1] + nums[i]
        return result
class Solution {
    public int[] runningSum(int[] nums) {
        int[] result = new int[nums.length];
        result[0] = nums[0];
        for (int i = 1; i < nums.length; i++) {
            result[i] = result[i - 1] + nums[i];
        }
        return result;
    }
}
5 · Test

Trace [1, 2, 3, 4]: result[0]=1. i=1: result[1]=1+2=3. i=2: result[2]=3+3=6. i=3: result[3]=6+4=10. Return [1,3,6,10]. Matches expected exactly. ✓

6 · Complexity

Time O(n): single linear pass doing O(1) arithmetic per element. Space O(n) for the allocated return array (or O(1) auxiliary space if output array does not count toward space complexity).

  1. LinkedList<T>()
  2. Array<T>()
  3. ArrayDeque<T>()
  4. IntArray(n)

ArrayDeque provides O(1) amortized addLast, removeLast, and removeFirst with high memory cache locality.

A recursive function calls itself once per level, descending n levels deep, with no other heap allocations. What is its auxiliary space complexity?

  1. O(1) space bound
  2. O(log n) tree depth
  3. O(n²) stack frames
  4. O(n) call stack space

Every active recursive call preserves a stack frame in memory. A recursion chain of depth n consumes O(n) call stack space.
