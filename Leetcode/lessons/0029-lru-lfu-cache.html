Warm-up from memory

Close this page and recall: why is a Doubly Linked List required for LRU cache instead of a singly linked list?

The idea

An LRU (Least Recently Used) cache requires O(1) key lookup and O(1) node repositioning. A Hash Map gives O(1) lookup, while a Doubly Linked List gives O(1) node deletion and insertion (provided we have direct node pointers and sentinel dummy head/tail nodes). LFU (Least Frequently Used) organizes nodes into frequency buckets.

Walkthrough: LRU Cache

Design a data structure that follows the constraints of a Least Recently Used (LRU) cache with get(key) and put(key, value) in O(1) time complexity.

1 · Clarify

Can values be negative? What happens on existing key update? Capacity >= 1. Existing key update refreshes its recency and updates value.

2 · Examples

LRUCache(2): put(1, 1), put(2, 2), get(1) → 1, put(3, 3) → evicts 2 (LRU), get(2) → -1.

3 · Approach

1. map: key → Node for O(1) lookups.

2. Doubly linked list with dummy head and tail. Most recently used nodes are near head; least recently used nodes sit at tail.prev.

3. get(key): find in map, move node to head, return val.

4. put(key, val): if exists, update val and move to head. If full, evict tail.prev and remove from map. Insert new node at head.

4 · Code 
class LRUCache(private val capacity: Int) {
    private class Node(var key: Int = 0, var value: Int = 0) {
        var prev: Node? = null; var next: Node? = null
    }

    private val map = HashMap<Int, Node>()
    private val head = Node(); private val tail = Node()

    init { head.next = tail; tail.prev = head }

    fun get(key: Int): Int {
        val node = map[key] ?: return -1
        moveToHead(node)
        return node.value
    }

    fun put(key: Int, value: Int) {
        val existing = map[key]
        if (existing != null) {
            existing.value = value
            moveToHead(existing)
            return
        }
        if (map.size == capacity) {
            val lru = tail.prev!!
            removeNode(lru)
            map.remove(lru.key)
        }
        val newNode = Node(key, value)
        map[key] = newNode
        addToHead(newNode)
    }

    private fun removeNode(node: Node) {
        node.prev?.next = node.next
        node.next?.prev = node.prev
    }

    private fun addToHead(node: Node) {
        node.next = head.next
        node.prev = head
        head.next?.prev = node
        head.next = node
    }

    private fun moveToHead(node: Node) {
        removeNode(node); addToHead(node)
    }
}

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}
        self.head, self.tail = Node(), Node()
        self.head.next, self.tail.prev = self.tail, self.head

    def get(self, key: int) -> int:
        if key not in self.cache: return -1
        node = self.cache[key]
        self._move_to_head(node)
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self._move_to_head(node)
            return
        if len(self.cache) == self.cap:
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]
        new_node = Node(key, value)
        self.cache[key] = new_node
        self._add_to_head(new_node)

    def _remove(self, node: Node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_head(self, node: Node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _move_to_head(self, node: Node):
        self._remove(node); self._add_to_head(node)
class LRUCache {
    private static class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
        Node() {}
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(), tail = new Node();

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail; tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }
        if (map.size() == capacity) {
            Node lru = tail.prev;
            removeNode(lru);
            map.remove(lru.key);
        }
        Node newNode = new Node(key, value);
        map.put(key, newNode);
        addToHead(newNode);
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addToHead(Node node) {
        node.next = head.next; node.prev = head;
        head.next.prev = node; head.next = node;
    }

    private void moveToHead(Node node) {
        removeNode(node); addToHead(node);
    }
}

class LRUCache(private val capacity: Int) {
    class Node(var key: Int = 0, var value: Int = 0) {
        var prev: Node? = null
        var next: Node? = null
    }
    private val map = HashMap<Int, Node>()
    private val head = Node()
    private val tail = Node()
    init {
        head.next = tail
        tail.prev = head
    }
    private fun remove(node: Node) {
        node.prev?.next = node.next
        node.next?.prev = node.prev
    }
    private fun add(node: Node) {
        node.next = head.next
        node.prev = head
        head.next?.prev = node
        head.next = node
    }
    fun get(key: Int): Int {
        val node = map[key] ?: return -1
        remove(node); add(node)
        return node.value
    }
    fun put(key: Int, value: Int) {
        map[key]?.let { remove(it) }
        val node = Node(key, value)
        map[key] = node
        add(node)
        if (map.size > capacity) {
            val lru = tail.prev!!
            remove(lru)
            map.remove(lru.key)
        }
    }
}

class LRUCache {
    static class Node {
        int key, val;
        Node prev, next;
        Node() {}
        Node(int k, int v) { key = k; val = v; }
    }
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(), tail = new Node();
    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }
    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    private void add(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }
    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        remove(node); add(node);
        return node.val;
    }
    public void put(int key, int value) {
        if (map.containsKey(key)) remove(map.get(key));
        Node node = new Node(key, value);
        map.put(key, node);
        add(node);
        if (map.size() > capacity) {
            Node lru = tail.prev;
            remove(lru);
            map.remove(lru.key);
        }
    }
}

Quick check

Why are sentinel dummy head and tail nodes used in the LRU doubly linked list?

  1. Doubles pointer traversal speed
  2. Eliminates null edge-case checks
  3. Encrypts stored memory pointers
  4. Prevents memory garbage pauses

Dummy sentinels ensure head.next and tail.prev always exist, eliminating null-pointer edge cases during insertion and deletion.

Why can a singly linked list NOT achieve O(1) node deletion in LRU cache?

  1. Singly linked lists lack headers
  2. Singly linked lists cannot store
  3. Cannot access prev node in O(1)
  4. Tail deletion causes stack faults

Deleting a node requires rewiring prev.next = next. Without a prev pointer, finding the predecessor requires an O(n) scan.

In an LFU (Least Frequently Used) cache, what tie-breaking eviction policy is applied?

  1. Evict highest numerical key node
  2. Evict random node from min list
  3. Evict newest inserted node item
  4. Evict least recently used among min

When multiple keys share the minimum frequency, the least recently used key among them is evicted.

LFU Cache Hard High frequency

  1. Maintain two maps: key → Node, and freq → DoublyLinkedList.
  2. Track minFreq = 1.
  3. When node is accessed, move from freq list to freq + 1 list. If old list is empty and was minFreq, minFreq++.

All O(1) Data Structure Hard

  1. Maintain a doubly linked list of frequency buckets, where each bucket holds a HashSet of keys.
  2. inc(key): move key from current bucket to freq + 1 bucket.
  3. getMaxKey() returns any key in tail.prev; getMinKey() returns any key in head.next.

Design Circular Deque Medium

  1. Use a fixed-size array with front and rear pointers and capacity + 1.
  2. front = (front - 1 + cap) % cap; rear = (rear + 1) % cap.
  3. Check isEmpty (front == rear) and isFull ((rear + 1) % cap == front).
