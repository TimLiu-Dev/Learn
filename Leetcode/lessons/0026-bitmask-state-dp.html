The idea

In State Machine DP, transitions occur between distinct finite states (e.g. Held, Sold, Cooldown). In Bitmask DP, an integer bitmask represents a subset of items (the i-th bit is 1 if item i is selected). This allows DP over combinations and permutations when N is small (N <= 16, where 2^16 = 65,536).

Walkthrough: Best Time to Buy and Sell Stock with Cooldown

You are given an array prices. You may complete as many transactions as you like with one restriction: after you sell your stock, you cannot buy stock on the next day (cooldown 1 day). Return the maximum profit.

1 · Clarify

Can you buy on the same day you sell? No. Can you hold multiple stocks? No, at most 1 stock held at any time. Prices array length between 1 and 5,000.

2 · Examples

prices = [1,2,3,0,2] → 3 ([buy, sell, cooldown, buy, sell]). prices = [1] → 0.

3 · Approach

Model as 3 states on each day i:

  • held: currently holding a stock. Stay in held, or buy from rest: held = max(held, rest - price).
  • sold: just sold stock today. Must come from held: sold = held + price.
  • rest: in cooldown or doing nothing. Come from rest or yesterday's sold: rest = max(rest, prevSold).

class Solution {
    public boolean canPartition(int[] nums) {
        int total = 0;
        for (int x : nums) total += x;
        if (total % 2 != 0) return false;
        int target = total / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int x : nums) {
            for (int s = target; s >= x; s--) {
                if (dp[s - x]) dp[s] = true;
            }
        }
        return dp[target];
    }
}

Quick check

How many total states exist for an integer bitmask representing subsets of N items?

  1. 2^N total binary bitmask states
  2. N! permutation bitmask states
  3. N^2 quadratic table entries
  4. 2 * N linear state numbers

Each of the N items can either be included (1) or excluded (0), yielding exactly 2^N states.

In bit manipulation, how do you add item i to an existing bitmask mask?

  1. mask = mask & (1 << i)
  2. mask = mask | (1 << i)
  3. mask = mask ^ (1 << i)
  4. mask = mask + (1 >> i)

Bitwise OR with (1 << i) sets the i-th bit to 1 without altering any other bits.

Why can Stock with Cooldown be solved in O(1) space?

  1. Prices can be sorted in place
  2. Binary search prunes the days
  3. Day i states only need day i-1
  4. The graph has no cyclic edges

State transitions (held, sold, rest) depend solely on the immediate previous day's states.
