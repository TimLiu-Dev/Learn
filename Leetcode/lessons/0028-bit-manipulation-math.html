Warm-up from memory

Close this page and recall: what does the XOR identity x ^ x and x ^ 0 evaluate to?

The idea

Bitwise operations run directly on CPU registers in 1 clock cycle. Key identities: 1. XOR cancellation: x ^ x = 0, x ^ 0 = x. 2. Brian Kernighan's trick: x & (x - 1) removes the lowest set bit. 3. Fast Power (Binary Exponentiation): compute x^n in O(log n) by squaring base when n is even.

Reach for it when you see…

  • 'Single Number' (all numbers appear twice except one)
  • 'Number of 1 Bits / Hamming Weight'
  • 'Counting bits', 'Reverse bits'
  • 'Pow(x, n)' in O(log n)

Pattern templates

// Brian Kernighan: count 1-bits
var count = 0; var num = n
while (num != 0) { num = num and (num - 1); count++ }

// Fast exponentiation O(log n)
fun myPow(x: Double, n: Long): Double {
    var res = 1.0; var base = x; var exp = if (n < 0) -n else n
    while (exp > 0) {
        if (exp % 2L == 1L) res *= base
        base *= base
        exp /= 2L
    }
    return if (n < 0) 1.0 / res else res
}

# Fast exponentiation O(log n)
def my_pow(x: float, n: int) -> float:
    exp = abs(n)
    res = 1.0
    while exp > 0:
        if exp % 2 == 1:
            res *= x
        x *= x
        exp //= 2
    return 1.0 / res if n < 0 else res
// Brian Kernighan: count 1-bits
int count = 0;
while (n != 0) { n &= (n - 1); count++; }

// Fast exponentiation O(log n)
public double myPow(double x, int n) {
    long exp = n;
    if (exp < 0) { x = 1 / x; exp = -exp; }
    double res = 1.0;
    while (exp > 0) {
        if ((exp & 1) == 1) res *= x;
        x *= x;
        exp >>= 1;
    }
    return res;
}

Walkthrough: Single Number

Given a non-empty array of integers nums, every element appears twice except for one. Find that single one in O(n) time and O(1) space.

1 · Clarify

Can nums contain negative numbers? Can the array have no single element? Array is guaranteed to have exactly one element appearing once. Negatives allowed.

2 · Examples

nums = [2, 2, 1] → 1. nums = [4, 1, 2, 1, 2] → 4.

3 · Approach

XOR property: A ^ A = 0, and A ^ 0 = A. XOR is commutative and associative.

XOR all elements together: all pairs cancel each other out to 0 (e.g. 2 ^ 2 = 0, 1 ^ 1 = 0), leaving only the single unique number.

4 · Code 
class Solution {
    fun singleNumber(nums: IntArray): Int {
        var res = 0
        for (x in nums) res = res xor x
        return res
    }
}
class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        res = 0
        for x in nums:
            res ^= x
        return res
class Solution {
    public int singleNumber(int[] nums) {
        int res = 0;
        for (int x : nums) res ^= x;
        return res;
    }
}
5 · Test

[4, 1, 2, 1, 2]: 4 ^ (1 ^ 1) ^ (2 ^ 2) = 4 ^ 0 ^ 0 = 4. Returns 4. ✓

6 · Complexity

Time O(n): single pass. Space O(1): one accumulator variable.

Quick check

What does x & (x - 1) do to the binary representation of integer x?

  1. Doubles integer x value
  2. Inverts all bits of num
  3. Clears lowest set one bit
  4. Checks if x is an odd num

Subtracting 1 flips the lowest set bit and all trailing zeros; bitwise AND with original x clears that bit.

How does fast binary exponentiation compute x^n in O(log n) time?

  1. Multiplies x n times linear
  2. Approximates using log table
  3. Divides base by factor of 2
  4. Squares base and halves exp

When exponent is even, x^n = (x^2)^(n/2), halving the number of multiplications at each step.

In Kotlin, how are bitwise XOR and AND operators written?

  1. Infix words: xor and and
  2. Symbols: ^ and & exactly
  3. Functions: bitXor(a, b)
  4. Methods: a.bitwiseXor(b)

Kotlin uses readable infix function words: a xor b, a and b, a or b, a shl 1, a ushr 1.

Number of 1 Bits Easy

  1. Use Brian Kernighan's trick: while n != 0: n &= (n - 1); count++.
  2. Runs in O(k) where k is number of 1-bits, rather than checking all 32 bits.

Counting Bits Easy

  1. Count set bits for all numbers from 0 to n in O(n) total time (DP + Bits).
  2. dp[i] = dp[i >> 1] + (i & 1).
  3. Or dp[i] = dp[i & (i - 1)] + 1.

Pow(x, n) Medium

  1. Watch out for n = -2147483648: negating in 32-bit overflows Integer.MIN_VALUE! Convert n to Long first.
  2. Binary exponentiation loop: square base, halve exponent.
