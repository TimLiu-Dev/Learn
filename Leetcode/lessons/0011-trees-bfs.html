The idea

Breadth-First Search (BFS) explores tree nodes level by level, from top to bottom, left to right. By capturing `levelSize = queue.size` before processing each level, you create an explicit boundary: exactly `levelSize` nodes are popped and processed, while their children are enqueued for the next level.

Reach for it when you see…

  • Level-order traversal: return values grouped level by level
  • Binary tree right side view or left side view
  • Minimum depth of binary tree (earliest leaf found is guaranteed shortest)
  • Zigzag level order traversal or level averages

Pattern templates

// Level-order BFS with size snapshot
val result = mutableListOf<List<Int>>()
if (root == null) return result
val queue = ArrayDeque<TreeNode>()
queue.addLast(root)

while (queue.isNotEmpty()) {
    val levelSize = queue.size
    val currentLevel = mutableListOf<Int>()
    for (i in 0 until levelSize) {
        val node = queue.removeFirst()
        currentLevel.add(node.`val`)
        node.left?.let { queue.addLast(it) }
        node.right?.let { queue.addLast(it) }
    }
    result.add(currentLevel)
}

while queue:
    level_size = len(queue)
    current_level = []

        if node.left:

Walkthrough: Binary Tree Level Order Traversal

Given the root of a binary tree, return the level order traversal of its nodes' values (i.e., from left to right, level by level).

1 · Clarify

Can root be null? Should output be a list of lists? Yes, null returns empty list. Output is List> where each sublist corresponds to one depth layer.

2 · Examples

root = [3,9,20,null,null,15,7] -> [[3],[9,20],[15,7]]. root = [1] -> [[1]]. root = [] -> [].

3 · Approach

If root == null, return empty list. Initialize queue with root. In a while loop, record levelSize = queue.size. Loop levelSize times: pop the front node, add its value to currentLevel, and enqueue any non-null children. Append currentLevel to result. Repeat until queue is empty.

6 · Complexity

Time O(n): each node enqueued and dequeued once. Space O(w): queue size proportional to maximum tree width (up to n/2 in a balanced binary tree, so O(n)).

Quick check

Why is capturing levelSize = queue.size BEFORE the inner loop crucial in level-order BFS?

  1. It resets the queue pointer to index 0 in memory
  2. It calculates tree depth in O(1) time without visiting children
  3. Queue methods throw ConcurrentModificationException without capturing size
  4. It freezes the count of nodes on the current level, preventing newly enqueued children from being processed early

As you pop nodes on level L, you enqueue their children on level L+1. Capturing levelSize ensures the inner loop processes strictly the nodes from level L.

In Binary Tree Right Side View (LeetCode 199), which node on each level is included in the answer?

  1. The last element processed in the current level's inner loop (index levelSize - 1)
  2. Only nodes that have node.left == null
  3. The node whose value is the maximum integer on that level
  4. All leaf nodes at the maximum depth of the tree

Looking at a tree from the right side reveals the rightmost node of each level, which corresponds exactly to the last element in level-order traversal for that level.

Why is BFS preferred over DFS for finding the Minimum Depth of a Binary Tree?

  1. DFS requires O(n²) space whereas BFS requires strictly O(1) space
  2. BFS explores shortest paths first, allowing immediate early termination upon encountering the first leaf node
  3. DFS cannot handle binary trees with odd node counts
  4. BFS executes directly on GPU cores without stack memory

BFS processes nodes in order of increasing depth. The very first leaf encountered is guaranteed to be at minimum depth, allowing immediate return without exploring remaining branches.

Binary Tree Right Side View Medium

  1. Run level-order BFS.
  2. For each level, when i == levelSize - 1, append node.val to result.
  3. Alternatively, do DFS visiting right child before left child, adding first node seen at each depth.

Binary Tree Zigzag Level Order Traversal Medium

  1. Maintain a boolean flag leftToRight = true.
  2. Reverse currentLevel if leftToRight is false, or append using a deque.
  3. Toggle leftToRight = !leftToRight after each level.

Minimum Depth of Binary Tree Easy

  1. Queue stores pairs of (node, depth).
  2. When node.left == null && node.right == null, return depth immediately!
  3. This early termination is why BFS beats DFS here.
