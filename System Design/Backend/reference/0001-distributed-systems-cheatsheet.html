3. Core Distributed Formulas

Little's Law (Concurrency & Throughput)

L = λ × W

Where L = average number of concurrent requests in system, λ = throughput (arrivals/sec), W = average request latency (seconds).
Example: If system handles 10,000 QPS with 200ms (0.2s) latency, concurrent in-flight requests = 10,000 × 0.2 = 2,000 connections.

Quorum Consensus Formula

W + R > N and W > N / 2

Where N = total replica count, W = write quorum, R = read quorum. Guarantees that at least one replica in any read set has the latest acknowledged write.
