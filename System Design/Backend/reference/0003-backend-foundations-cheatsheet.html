5. Auth, Docker & real-time delivery (0023, 0024, 0025)

AreaRule to remember
PasswordsHash with Argon2id or bcrypt (cost ≥ 10), never encrypt or use plain SHA-256 (OWASP).
Tokens & OAuthShort-lived JWT access token (5–15 min; verify alg, signature, exp, aud) + rotating refresh token (RFC 9700). Native apps use Authorization Code + PKCE (RFC 8252).
12-Factor configSecrets in env vars; Spring relaxed binding maps spring.datasource.url → SPRING_DATASOURCE_URL (. → _, strip -, uppercase).
Health probes/actuator/health/liveness failing → restart container; /actuator/health/readiness failing → drain traffic without restarting.
Real-time to mobileSSE (text/event-stream + Last-Event-ID) for one-way live updates while foregrounded; WebSockets for two-way high-rate; FCM when backgrounded; Redis Pub/Sub to fan out across app instances.

6. Interview math & SRE formulas (0026, 0027)

Seconds/day         = 86,400  (~10^5 for quick mental math)
Write QPS           = ceil(DAU * writes_per_user_per_day / 86,400)
Read QPS            = Write QPS * read_write_ratio
Storage (N years)   = writes_per_day * 365 * N * bytes_per_record
Base62 capacity     = 62^7 ≈ 3.52 * 10^12 (3.52 trillion unique 7-char codes)

SLI (availability)  = (total_requests - failed_requests) / total_requests
Error Budget        = 1 - SLO_target                      (e.g. 99.9% SLO -> 0.1% = 0.001 budget)
Burn Rate           = observed_error_rate / (1 - SLO_target)   (1.0 = exact 30d pace; 14.4 = exhausted in 50h)
