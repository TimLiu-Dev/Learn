Backend System Design 2027: From Android Dev to Senior

Two goals in order. Part 1: pass junior-to-mid (L3/L4) backend system design interviews. Part 2: pass senior ones. You start by building a real Kotlin + Spring Boot service, because you can't design systems you've never run.

Curriculum Progress 19 of 27 modules live (70%)

How this plan relates to roadmap.sh

The roadmap.sh System Design roadmap (132 topics) is used as a coverage checklist, not a learning order. About 45% of it comes from the System Design Primer and about 40% from Azure cloud patterns. This plan adds what it's missing: hands-on building, transactions, estimation, consistent hashing, real-time delivery, server-side auth, and worked case studies. It also merges or skips niche Azure patterns.

Existing lessons were written at senior depth

On your first pass through a Part 1 lesson, aim for the core idea and the sandbox. Skip the deep asides and come back to them in Part 2. Ask your teacher which sections to skip.
