Backend System Design 2027: From Android Dev to Senior

Two sequential goals, each anchored by its own portfolio capstone. Part 1: pass junior-to-mid (L3/L4) backend system design interviews and ship Project PulseOrder. Part 2: pass senior (L5+) rounds and upgrade PulseOrder into Project NexusPulse.

Curriculum Progress (All 27 Interactive Modules + 2 Capstones Live) 27 of 27 modules live (100%)

How this plan relates to roadmap.sh

The roadmap.sh System Design roadmap (132 topics) is used as a coverage checklist, not a learning order. About 45% of it comes from the System Design Primer and about 40% from Azure cloud patterns. This plan adds what it's missing: hands-on building in Kotlin + Spring Boot (0019–0024), transactions & isolation (0022), server-side auth (0023), real-time delivery + FCM (0025), worked L3/L4 case studies (0026), and SLO/observability basics (0027).

Two-pass strategy for Part 1 vs Part 2

Start with Phase 0 (0019–0024) while building PulseOrder M1–M4. When you move into Phase 1 and Phase 2, focus on the core mechanism and sandbox first (and finish PulseOrder M5–M8). Save Part 2's storage-engine, consensus, Spanner, and CRDT internals — and the NexusPulse upgrade — for after Part 1 is solid.
