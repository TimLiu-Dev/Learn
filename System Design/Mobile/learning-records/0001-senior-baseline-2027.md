# Senior Android 2027 Mobile System Design Baseline

The learner is targeting Senior/Staff Android roles in 2027 across both Mid-Tech and Big-Tech standards. The curriculum must explicitly split expectations between Mid-Tech (robust pragmatic offline-first, clean MVI, standard caching, WorkManager) and Big-Tech (extreme distributed scale, CRDTs, binary protocols, cellular radio states, edge SLM/AI inference, sub-millisecond telemetry), while establishing an iOS parallel architectural vocabulary to handle multi-stack panels.
