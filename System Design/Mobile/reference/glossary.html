Architectural Glossary (2027 Standards)

The authoritative definitions, acronyms, and terminology expected in Senior and Staff Mobile System Design interviews.

UDF (Unidirectional Data Flow) / MVI UI Architecture

An architectural pattern where state flows downward strictly in one direction (Repository → ViewModel → UI), and user events flow upward as immutable Intents/Actions. Prevents multiple sources of truth and UI desynchronization bugs.

CRDT (Conflict-Free Replicated Data Type) Distributed Edge Data

A data structure that can be replicated across multiple client devices and merged concurrently without requiring a centralized consensus coordinator or locking mechanism. Essential for real-time collaborative applications (e.g. Google Docs, Figma mobile).

RRC (Radio Resource Control) State Machine Hardware & Battery

The telecommunications protocol operating on mobile baseband chips that manages cellular modem power states (IDLE, FACH, DCH). Active data transmissions transition the radio to high power (DCH) which lingers in a "tail state" consuming power even after transfer finishes unless batched efficiently.

WAL (Write-Ahead Logging) Persistence & Storage

A SQLite journaling mode where changes are appended to a separate -wal file before being written to the database file. Allows concurrent reads without blocking writes, significantly accelerating Room DB throughput under high write contention.

HTTP/3 & QUIC Networking & Protocols

The transport protocol built over UDP replacing TCP. Features 0-RTT connection resumption, native encryption via TLS 1.3, and independent multiplexed streams that completely eliminate Head-of-Line (HoL) blocking on unstable mobile networks.

Edge AI / LiteRT On-Device Machine Learning

Google's 2027 runtime evolution of TensorFlow Lite for on-device inference. Enables running quantized 4-bit Small Language Models (such as Gemini Nano) directly on the device NPU (Neural Processing Unit) without cloud latency or user privacy leaks.

Keyset Pagination Data Transport

A pagination strategy relying on an indexed sequential key (or cursor, e.g. created_at < timestamp) rather than OFFSET. Guarantees $O(1)$ query lookups and immune to duplicate or skipped items caused by concurrent inserts at the top of the feed.

Process Death & State Restoration OS Lifecycle

The event where the Android or iOS operating system terminates an app process in the background to reclaim RAM for foreground tasks. Senior mobile designs must distinguish between in-memory cache recreation and persistent ID restoration using SavedStateHandle.

Sync-on-Tickle (Push-to-Sync) Real-Time Messaging

An architectural pattern where push notifications (FCM/APNs) carry only a lightweight sequence token (<100 bytes) rather than message content. The client then pulls ordered, authenticated deltas over a trusted socket or REST API, avoiding 4KB payload caps and out-of-order delivery bugs.

Player Instance Pooling (Media3) Media & Video Systems

Reusing 2–3 pre-allocated player instances across a scrolling feed rather than instantiating a player per list item. Prevents exhausting mobile silicon hardware decoders (limited to 4–8 instances system-wide) and eliminates MediaCodec out-of-resource crashes.

401 Refresh Mutex Queue Security & Auth

A synchronization pattern in OkHttp/Ktor where multiple concurrent requests encountering HTTP 401 Unauthorized are suspended behind a coroutine Mutex. Exactly one refresh request executes, and all queued callers replay with the new bearer token, preventing race conditions under Refresh Token Rotation.

Dead Reckoning & Kalman Filtering Sensors & Navigation

Techniques to overcome GPS signal failure: Kalman filters smooth urban canyon multipath satellite jitter, while dead reckoning fuses on-device accelerometer, gyroscope, and vehicle speed at 60 FPS to estimate position changes during tunnel blackouts.

Sticky Bucketing & Local Evaluation A/B Testing & Config

Feature flagging where compiled rule manifests are downloaded to disk and evaluated locally in microseconds. Consistent hashing on Hash(userId + salt) % 100 guarantees deterministic test variant assignment across app restarts without server round-trips.

Typeahead Debounce & flatMapLatest Search Architecture

An operator combination in Kotlin Coroutines Flow where rapid keystrokes are debounced by 300ms, and flatMapLatest cancels the preceding in-flight search network call when a new character arrives, permanently eliminating out-of-order search result overwrites.

S3 Multipart / TUS Chunked Upload Media Transport

A protocol strategy where large binary files (>50MB) are divided into uniform 5MB slices. Each slice is uploaded with an MD5 checksum and recorded in local SQLite database; network drops or process death resume strictly from the first un-uploaded chunk without restarting from 0%.

MediaSessionService & Audio Ducking Media & Audio Systems

AndroidX Media3 architecture enabling background audio streaming under FOREGROUND_SERVICE_MEDIA_PLAYBACK with lock-screen controls. The audio focus state machine smoothly lowers music volume to 20% (ducking) during voice navigation prompts and restores volume on gain.
