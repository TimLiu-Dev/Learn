Lesson 0009: Binary Protocols, gRPC over HTTP/3 (QUIC) & Bidirectional Multiplexing

Transition from REST/JSON to high-scale binary streaming. Dissect Protocol Buffers varint encoding, eliminate Head-of-Line (HoL) blocking with HTTP/3 over QUIC, and leverage 0-RTT handshakes and connection migration.

1. Why FAANG Abandons REST/JSON at Mobile Scale

At 500 million daily active users, JSON payloads introduce two major bottlenecks:

1. Verbose Text Overhead

In JSON, keys like "author_avatar_url" repeat for every list item, wasting 40-70% of network packets on field names. String-to-object parsing consumes significant CPU and battery cycles.

2. TCP Head-of-Line (HoL) Blocking

In HTTP/2 over TCP, if a single packet drops on a flaky 4G/5G connection, the entire TCP buffer freezes until the missing packet is retransmitted—stalling all other concurrent streams!

2. The HTTP/3 QUIC Revolution in 2027

HTTP/3 replaces TCP with QUIC over UDP. It solves the core mobile network challenges:

  • Independent Streams: Packet loss in Stream A (e.g. image download) does not stall Stream B (e.g. real-time chat messages).
  • 0-RTT Connection Resumption: After initial handshake, subsequent connections resume in 0 round-trips, eliminating TLS handshake latency on app re-open.
  • Connection Migration: A QUIC connection is identified by a 64-bit Connection ID, not IP/Port. When a user walks out of their house and transitions from Wi-Fi to 5G, the active gRPC streaming call continues without disconnection or re-handshake.

3. Interactive Practice: Implement a Protobuf Varint Decoder

Task: In Protocol Buffers, integers are encoded as Varints (Variable-length quantities) using 7 bits per byte, where the Most Significant Bit (MSB, 0x80) indicates if more bytes follow. Implement decodeVarint(bytes). Parse the byte array and return the decoded integer.

Protobuf Varint Decoder Sandbox
Hint 1: Mask out the continuation bit with byte & 0x7F and shift by shift bits.
Hint 2: When (byte & 0x80) === 0, the current byte is the final byte of the integer.
Canonical Solution: 
function decodeVarint(bytes) {
  let result = 0;
  let shift = 0;
  for (let i = 0; i < bytes.length; i++) {
    const byte = bytes[i];
    result |= (byte & 0x7F) << shift;
    if ((byte & 0x80) === 0) break;
    shift += 7;
  }
  return result;
}
