Lesson 0012: On-Device Edge AI & SLM Architecture: Gemini Nano, MediaPipe & NPU Offload

Integrate Local Small Language Models (SLMs) in 2027 Android apps. Master LiteRT runtimes, INT4 quantization, memory-mapped weights (mmap), and hybrid client-cloud intelligent routing.

1. The Edge AI Paradigm: Zero Latency & Privacy

In 2027, top mobile systems no longer send every AI prompt across cellular networks to cloud GPUs. On-Device SLMs (Gemini Nano via Google AI Edge) execute directly on the smartphone's Neural Processing Unit (NPU):

1. Zero Egress & Cost

Processing smart replies, text summarization, and local embeddings on-device eliminates cloud GPU serving bills and API token costs entirely.

2. Instant 0ms Network Latency

Inference starts within 15ms directly on device NPU cores, completely immune to subway tunnels, airplane mode, or dropped cell signals.

2. INT4 Quantization & Memory Mapping (mmap)

Full 16-bit floating point models require gigabytes of RAM. Mobile architectures rely on INT4 Quantization:

Weight Virtual Memory Mapping (mmap)

Model weights must never be loaded into the Java/Kotlin runtime heap as byte arrays (this would trigger an immediate Out-Of-Memory crash). Instead, LiteRT memory-maps (mmap) the model file directly into virtual address space. The Linux OS kernel pages weights into physical RAM on-demand and can discard clean pages under memory pressure without swapping.

3. Interactive Practice: Implement a Hybrid AI Prompt Router

Task: Implement routePrompt(prompt, deviceContext). deviceContext: { isOnline, batteryPct, isThermalThrottling, hasNpu }.
Routing Rules:
1. If prompt.isPrivate is true: MUST return 'LOCAL_NPU' (or throw error if offline & no NPU).
2. If !deviceContext.hasNpu or deviceContext.isThermalThrottling: route to 'CLOUD_API' (if online).
3. If prompt.tokenCount > 500: route to 'CLOUD_API' (complex reasoning).
4. Otherwise: route to 'LOCAL_NPU'.

Hybrid AI Prompt Router Sandbox
Hint 1: Always prioritize privacy constraints first before evaluating hardware throttles.
Hint 2: Large prompts (>500 tokens) route to 'CLOUD_API' when online.
Canonical Solution: 
function routePrompt(prompt, deviceContext) {
  if (prompt.isPrivate) {
    if (!deviceContext.hasNpu) throw new Error('Private prompt requires on-device NPU');
    return 'LOCAL_NPU';
  }
  if (deviceContext.isThermalThrottling || !deviceContext.hasNpu) {
    if (deviceContext.isOnline) return 'CLOUD_API';
    throw new Error('Device throttled and offline');
  }
  if (prompt.tokenCount > 500) {
    return deviceContext.isOnline ? 'CLOUD_API' : 'LOCAL_NPU';
  }
  return 'LOCAL_NPU';
}
