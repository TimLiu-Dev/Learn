Lesson 0008: Mid-Tech System Design Mock: Design an Offline-First Instagram Feed

Put all Part 1 skills into action in a simulated 45-minute Mid-Tech Senior Android System Design interview. Step through all 5 stages from initial requirements to complete Room schemas, optimistic like queues, and failure recovery.

Stage 1: Requirements & Sizing (00:00 – 05:00)

Functional & Non-Functional Agreement

  • Core User Flows: Infinite scrolling feed with media, instant optimistic like toggle, offline viewing of previously loaded feed, background upload of queued likes on reconnect.
  • Performance Constraints: Cold startup to cached feed render < 250ms; smooth 120 FPS scrolling; client RAM footprint strictly < 100MB heap.
  • Network Constraints: Unpredictable latency (subway tunnel mode); automatic retry with full jitter backoff.

Stage 4 & 5: Failure Modes & Scaling Wrap-Up (30:00 – 45:00)

  • Process Death: Save last viewed item ID and cursor to SavedStateHandle. Rehydrate immediately from Room SQLite WAL without hitting network.
  • Network Backoff: When server returns HTTP 429 or connection fails, LikeWorker applies exponential backoff with full jitter up to 10 minutes.
  • Image Memory: Coil configured with inBitmap pooling and downsampling to exact viewport width ($1080\text{px}$), capping L1 memory cache to 25% of app heap.

Interactive Practice: Implement the Feed Repository Core

Task: Implement toggleLikeOptimistic(localPosts, pendingQueue, postId). It inverts isLiked and increments/decrements likeCount in localPosts, and records/updates the pending mutation in pendingQueue. Return the updated post.

Feed Repository Optimistic Sandbox
Hint 1: Update isLiked = !isLiked, and adjust likeCount accordingly.
Hint 2: Check if pendingQueue already contains an entry for postId before pushing.
Canonical Solution: 
function toggleLikeOptimistic(localPosts, pendingQueue, postId) {
  const post = localPosts.find(p => p.id === postId);
  if (!post) return null;

  post.isLiked = !post.isLiked;
  post.likeCount += post.isLiked ? 1 : -1;

  const existingIdx = pendingQueue.findIndex(q => q.postId === postId);
  if (existingIdx !== -1) {
    pendingQueue[existingIdx].targetState = post.isLiked;
  } else {
    pendingQueue.push({ postId, targetState: post.isLiked });
  }

  return post;
}
