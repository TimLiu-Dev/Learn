Lesson 0007: Media & Image Loading Pipelines: Memory Pools, Downsampling & Disk Caching

Prevent Out-Of-Memory (OOM) crashes and scrolling stutter. Master Bitmap memory sizing equations, inSampleSize downsampling, inBitmap pooling, and multi-tier L1/L2/L3 cache architectures.

1. The Math of Bitmap Memory & OOMs

Images are compressed on disk (JPEG/WebP are often only ~500 KB). However, when decoded into memory for rendering, they expand into uncompressed raw pixel arrays:

Bitmap RAM Sizing Equation (ARGB_8888)

Memory (Bytes) = Width × Height × 4 bytes

A standard 12MP phone camera photo ($4000 \times 3000$) requires $4000 \times 3000 \times 4 = 48,000,000\text{ bytes} \approx \mathbf{48\text{ MB}}$ of heap RAM! Decoding just 4 full photos into memory will immediately crash an app on devices with 192MB heap limits.

2. inSampleSize Downsampling & inBitmap Pooling

Image pipelines like Coil, Fresco, and Glide prevent OOMs using two core Android API primitives:

1. inJustDecodeBounds

Reads image dimensions from headers without allocating pixel bytes in memory. Calculates the exact power-of-two inSampleSize needed to match the view's pixel size before decoding.

2. inBitmap (Bitmap Pool)

Instead of garbage-collecting old bitmaps and allocating new heap memory during scrolling, inBitmap reuses an existing allocated memory block, eliminating GC pauses (jank).

3. Interactive Practice: Calculate inSampleSize & Byte Size

Task: Implement calculateDownsample(rawW, rawH, reqW, reqH). It must calculate the greatest power of 2 inSampleSize where both downsampled dimensions remain $\ge$ the required dimensions. Return { inSampleSize, downsampledBytes } (assuming ARGB_8888 = 4 bytes per pixel).

Bitmap Downsampler Sandbox
Hint 1: Start with inSampleSize = 1 and double it (* 2) as long as halving both dimensions still satisfies >= reqW and >= reqH.
Hint 2: downsampledBytes equals Math.floor(rawW / inSampleSize) * Math.floor(rawH / inSampleSize) * 4.
Canonical Solution: 
function calculateDownsample(rawW, rawH, reqW, reqH) {
  let inSampleSize = 1;
  while ((rawW / (inSampleSize * 2)) >= reqW && (rawH / (inSampleSize * 2)) >= reqH) {
    inSampleSize *= 2;
  }
  const finalW = Math.floor(rawW / inSampleSize);
  const finalH = Math.floor(rawH / inSampleSize);
  const downsampledBytes = finalW * finalH * 4;
  return { inSampleSize, downsampledBytes };
}
