Stage 3: Subsystem Deep Dives (20:00 – 40:00)

Fractional Indexing CRDT (Logoot/Lseq)

Traditional integer indexes (e.g. insertAt(5, 'c')) break when two users type concurrently. Fractional indexing gives every character a dense decimal position between 0 and 1. Inserting between 0.1 and 0.2 assigns position 0.15, allowing infinite insertions without re-indexing existing characters!

Dead Reckoning GPS Smoothing

When a driver enters a highway tunnel and GPS satellite signals drop to zero, the mobile client fuses device accelerometer, gyroscope, and last known vehicle velocity to estimate position changes at 60 FPS, eliminating navigation freezes on the map.

Stage 4 & 5: Failure Modes, Hardware Radio & Edge AI (40:00 – 60:00)

  • Process Death: The document buffer is backed by a native memory-mapped file (mmap) with periodic SQLite snapshot checkpoints. If the OS terminates the app due to RAM starvation, zero un-synced characters are lost.
  • Cellular Radio Power Optimization: Driver location points are coalesced with document edits. The radio stays in IDLE for 4 seconds, wakes up to DCH for a 500ms burst transmission, reducing battery consumption by 62%.
  • On-Device Edge AI: Gemini Nano is loaded via LiteRT to perform local grammar corrections and smart syntax completion on-device with sub-25ms latency.

Interactive Practice: Implement Fractional Indexing Text Buffer

Task: Implement FractionalDocBuffer.
• insertBetween(leftPos, rightPos, char, authorId): Computes the midpoint (leftPos + rightPos) / 2, stores the character, and maintains ascending sorted order by position.
• getText(): Returns the full string constructed from the sorted characters.

Fractional Indexing CRDT Sandbox
Hint 1: Calculate position as (leftPos + rightPos) / 2.
Hint 2: Sort by a.pos - b.pos to maintain deterministic text order.
Canonical Solution: 
class FractionalDocBuffer {
  constructor() {
    this.nodes = [];
  }

  insertBetween(leftPos, rightPos, char, authorId) {
    const pos = (leftPos + rightPos) / 2;
    this.nodes.push({ pos, char, authorId });
    this.nodes.sort((a, b) => a.pos - b.pos);
    return pos;
  }

  getText() {
    return this.nodes.map(n => n.char).join('');
  }
}
