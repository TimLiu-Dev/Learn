Lesson 0005: High-Performance List Pagination: Keyset vs Offset & Prefetch Heuristics

Architect infinite scrolling feeds without jank or duplicate items. Compare keyset/cursor pagination against offset pagination, configure Android Paging 3 RemoteMediator, and tune prefetch distance algorithms.

1. The Duplicate Item Bug in Offset Pagination

In interview discussions, candidates frequently propose ?page=2&limit=20 (Offset pagination). At scale, this introduces two fatal flaws:

Offset Pagination (`OFFSET 20`)

If new posts are published while the user views Page 1, all existing posts shift down by one index. When the client fetches Page 2 with OFFSET 20, the last post from Page 1 now occupies index 20, causing the user to see duplicate posts on their feed.

Keyset Pagination (`cursor_id`)

The client requests ?after_cursor=post_999&limit=20. The server executes WHERE created_at < :cursor_timestamp ORDER BY created_at DESC LIMIT 20. This is $O(1)$ via database index, completely immune to newly created items at the top!

2. Paging 3 RemoteMediator & Prefetch Distances

In Android Jetpack Paging 3, RemoteMediator coordinates between local SQLite (Room) and the remote API: 

val pager = Pager(
    config = PagingConfig(
        pageSize = 20,
        prefetchDistance = 5, // Triggers next fetch 5 items before end of list
        enablePlaceholders = false,
        initialLoadSize = 40
    ),
    remoteMediator = FeedRemoteMediator(database, networkApi),
    pagingSourceFactory = { database.feedDao().pagingSource() }
)

A prefetchDistance of 5 ensures that on 120Hz displays, background network fetching begins before the user hits the bottom loading indicator, delivering a seamless infinite scroll experience.

3. Interactive Practice: Implement Keyset Pagination

Task: Implement paginate(dataset, cursorId, limit). Given an array of sorted items [{ id: 10, ... }, { id: 9, ... }, { id: 8, ... }], find the index of cursorId and return the next slice of up to limit items. If cursorId is null, start from index 0.

Keyset Pagination Sandbox
Hint 1: Find the cursor index using dataset.findIndex(item => item.id === cursorId). Next page begins at idx + 1.
Hint 2: nextCursor should be the ID of the last item in the returned slice, or null if slice is empty.
Canonical Solution: 
function paginate(dataset, cursorId, limit) {
  let startIndex = 0;
  if (cursorId !== null) {
    const idx = dataset.findIndex(item => item.id === cursorId);
    startIndex = idx !== -1 ? idx + 1 : 0;
  }
  const slice = dataset.slice(startIndex, startIndex + limit);
  const nextCursor = slice.length > 0 ? slice[slice.length - 1].id : null;
  return { items: slice, nextCursor };
}
