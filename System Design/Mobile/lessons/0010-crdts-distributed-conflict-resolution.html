Lesson 0010: Distributed Conflict Resolution on Mobile: CRDTs & Lamport Timestamps

Build peer-to-peer and multi-device collaborative systems that never lose edits. Dissect Conflict-Free Replicated Data Types (CRDTs), solve mobile wall-clock skew with Lamport Logical Clocks, and build an LWW-Element-Set merge engine.

1. Why System.currentTimeMillis() Fails at Scale

In multi-device systems (e.g. Google Keep, Notion, or Figma mobile), two users can edit the same document while offline on airplanes.

The Wall-Clock Skew Trap

Device A's hardware clock might be 4 minutes slow; Device B's clock might be 2 minutes fast, or manually manipulated by the user in system settings. If you use physical timestamps (System.currentTimeMillis()) for Last-Write-Wins, Device B's edits will silently overwrite Device A's edits into eternity!

Staff Solution: Use Lamport Timestamps or Hybrid Logical Clocks (HLC), where clocks increment causally: clock = max(local_clock, remote_clock) + 1.

2. LWW-Element-Set (Last-Write-Wins CRDT)

A State-based CRDT guarantees Strong Eventual Consistency (SEC): regardless of the order or route updates travel, any two replicas that have received the same set of updates will deterministically arrive at the identical state without locking.

An LWW-Element-Set consists of two growing internal sets:

  • Add-Set ($A$): Tuples of (element, timestamp) added to the collection.
  • Remove-Set ($R$): Tuples of (element, timestamp) removed from the collection.
  • Lookup Rule: An element is present in the set if and only if it exists in $A$ with a timestamp strictly greater than its latest entry in $R$.

3. Interactive Practice: Implement an LWW-Element-Set CRDT

Task: Implement the LWWSet class with add(val, ts), remove(val, ts), has(val), and merge(otherSet).

LWW-Element-Set CRDT Sandbox
Hint 1: In has(val), the value is active if addTs > (removeTs || 0).
Hint 2: In merge(), iterate through both other.addSet and other.removeSet, recording maximum timestamps.
Canonical Solution: 
class LWWSet {
  constructor() {
    this.addSet = new Map();
    this.removeSet = new Map();
  }

  add(val, ts) {
    const cur = this.addSet.get(val) || 0;
    if (ts > cur) this.addSet.set(val, ts);
  }

  remove(val, ts) {
    const cur = this.removeSet.get(val) || 0;
    if (ts > cur) this.removeSet.set(val, ts);
  }

  has(val) {
    const addTs = this.addSet.get(val);
    if (addTs === undefined) return false;
    const removeTs = this.removeSet.get(val) || 0;
    return addTs > removeTs;
  }

  merge(other) {
    for (const [val, ts] of other.addSet.entries()) this.add(val, ts);
    for (const [val, ts] of other.removeSet.entries()) this.remove(val, ts);
  }
}
