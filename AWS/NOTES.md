# Teaching & Workspace Notes

## Learner Profile & Preferences
- **Current Role**: Junior Android Developer (bridges best from mobile/client concepts: OkHttp/Retrofit, Coroutines, Room/SQLite, Gradle, REST/JSON).
- **Target Role**: Senior AWS Engineer in 2027 (must feel genuinely senior, job-ready, and defensible in interviews).
- **Curriculum Structure**:
  1. `master-plan.html` acts as the Master Legend across the entire curriculum, audited against `roadmap.sh/aws` (showing what is kept, added, and removed/deprioritized).
  2. **Part 1**: What makes a strong Senior Software Engineer (backend, networking, databases, async/distributed systems, containers/observability) + **Part 1 Capstone Project**.
  3. **Part 2**: What is required to become a Senior AWS Engineer (IAM/Orgs, VPC/PrivateLink, Compute, Storage/CDN/DNS, Databases, Serverless/Events, IaC CDK+Terraform, Security/Observability/FinOps/DR) + **Part 2 Ending Resume-Grade Capstone Project**.
- **Lesson Design Requirements (Benchmark = Lesson 0001)**:
  - Self-contained HTML linking shared `./assets/styles.css` and `./assets/lesson-widgets.js`.
  - Clean, Tufte-inspired editorial design (high readability, margin notes, print-friendly).
  - Concise conceptual teaching grounded in primary sources + bridged from Android dev intuition.
  - Runnable code examples and interactive code practice **directly inside the HTML** with real automated test checks, progressive hints, reset, and final answer reveal.
  - Multiple-choice quizzes with **balanced option lengths** (per `SKILL.md` rule: no formatting clues!) and detailed explanations for **why the right answer is right AND why every wrong option is wrong**.
  - Links to `master-plan.html`, `reference/glossary.html`, previous/next lessons, primary source reading, and reminder to ask follow-up questions.
