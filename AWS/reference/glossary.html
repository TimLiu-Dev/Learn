Part 1: Senior SWE Foundations (Modules 1.1–1.5)

Networking, Protocols & Linux Foundations (Module 1.1)

Lessons 0001–0003
Term Canonical Definition Android / AWS Anchor
DNS Resolution Translates a human-readable domain name (e.g., api.example.com) into one or more IP addresses via recursive resolvers and TTL-cached records. Android Dns.SYSTEM → AWS Route 53
TCP 3-Way Handshake SYN → SYN-ACK → ACK negotiation establishing a reliable byte stream before application data flows. Costs 1 full Round-Trip Time (RTT). OkHttp socket open → ALB / NLB frontend socket
TLS 1.3 Handshake Cryptographic negotiation authenticating the server certificate and deriving session keys. Typically adds 1 RTT (0-RTT on session resumption). Android SSLSocketFactory → ACM + ALB TLS termination
HTTP Keep-Alive / Connection Pooling Reusing an already-established TCP + TLS socket across multiple sequential HTTP requests, avoiding repeated handshake RTTs. OkHttp ConnectionPool → ALB target & client keep-alive
Connection Idle Timeout Maximum duration a pooled connection may sit without sending or receiving bytes before the load balancer or server closes it. AWS ALB default is 60s; backend idle timeout must exceed ALB's.
Keep-Alive Close Race (HTTP 502) Failure occurring when an upstream server closes an idle TCP socket at the exact millisecond the load balancer sends a new request down that socket. Solved by setting backend keepAliveTimeout > ALB idle_timeout.
Application Load Balancer (ALB) Layer 7 (HTTP/HTTPS) AWS load balancer that terminates client TLS, inspects headers/paths, and forwards requests over pooled connections to backend targets. Entry point for containerized ECS/EKS & EC2 HTTP services.
CIDR (Classless Inter-Domain Routing) Notation ip/prefix (e.g., 10.0.0.0/16) specifying how many leading bits identify the network versus host addresses (2^(32 - prefix) IPs). Local Docker bridges → AWS VPC & Subnet address blocks (RFC 1918)
Subnetting & Reserved IPs Partitioning a parent CIDR block into smaller non-overlapping networks; in AWS VPCs, the first 4 IPs and the last IP (5 total) of every subnet are reserved. /24 = 256 total → 251 usable IPs in an AWS VPC subnet
NAT & Ephemeral Ports Network Address Translation rewrites private source IP:port tuples to a public IP and ephemeral port (e.g., 1024–65535) for outbound traffic while tracking return flows. Home Wi-Fi router → AWS NAT Gateway (65,535 max ports/dest)
Route Table & Longest-Prefix Match Ordered rules mapping destination CIDRs to a next hop (local, IGW, NAT, TGW); routers always select the most specific matching prefix (highest /N). ip route → VPC Subnet Route Tables
SIGTERM & Graceful Shutdown Catchable OS termination signal (15) giving a process a grace window to fail readiness checks, drain in-flight requests, and close DB pools before forced SIGKILL (9). Android onCleared() → ECS / Kubernetes stop timeout
File Descriptors & epoll Per-process integer handles representing open files, pipes, and network sockets; bounded by ulimit -n and multiplexed efficiently by the Linux kernel via epoll. Android OkHttp threads/sockets → Node/Go/Netty event loops on EC2/Fargate

Backend APIs, Concurrency, Auth & Caching (Module 1.2)

Lessons 0004–0006
Term Canonical Definition Android / AWS Anchor
Cursor (Keyset) Pagination Paging via an opaque token encoding the last seen sort key (WHERE (ts, id) < (:ts, :id)), avoiding duplicate/skipped rows and O(N) OFFSET scans. Jetpack Paging 3 RemoteMediator → DynamoDB ExclusiveStartKey / SQL keyset
Rate Limiting (Token Bucket) Shaping request bursts with a refilling token bucket or sliding window and returning HTTP 429 Too Many Requests with a Retry-After header when exhausted. OkHttp backoff on 429 → API Gateway / AWS WAF / Redis rate limits
OAuth 2.0 (Auth Code + PKCE) Delegated authorization protocol issuing short-lived access tokens; public mobile clients must use Proof Key for Code Exchange (PKCE) instead of a static client secret. Android AppAuth / Custom Tabs → Amazon Cognito / OAuth IdP
OpenID Connect (OIDC) Identity layer on top of OAuth 2.0 providing a signed id_token (JWT) and /.well-known/openid-configuration discovery for authentication and federation. User sign-in claims → AWS STS AssumeRoleWithWebIdentity
JWT & JWKS Verification Stateless signed token (header.payload.signature) validated locally by checking signature against cached JWKS public keys, plus iss, aud, exp, and pinning alg. Android bearer header → API Gateway JWT Authorizer / ALB
RBAC vs ABAC Role-Based Access Control grants permissions to static roles (admin); Attribute-Based Access Control evaluates dynamic tags/claims (tenant_id == resource.owner). App feature gates → AWS IAM Condition Keys (aws:PrincipalTag)
Cache-Aside vs Write-Through Cache-aside reads cache first and populates on miss (resilient to cache failure); write-through updates cache synchronously on every write at higher write latency. Room + Retrofit repository → ElastiCache (Redis/Valkey) + RDS
TTL Jitter Adding bounded randomness to cache expiration times (e.g., 300s + rand(0, 60s)) so keys warmed together do not expire simultaneously and spike database load. Stale-while-revalidate caches → ElastiCache / CloudFront expiry smoothing
Cache Stampede & Singleflight Thundering-herd DB overload when many concurrent requests miss the same hot expired key; prevented via request coalescing (singleflight) or probabilistic early refresh. Concurrent coroutine deduplication → ElastiCache lock / singleflight

Data Modeling, Transactions & Storage Internals (Module 1.3)

Lessons 0007–0009
Term Canonical Definition Android / AWS Anchor
B-Tree Index Balanced multi-way search tree stored in fixed 8 KB pages mapping sorted key values to heap tuple pointers (CTIDs), enabling O(log N) equality and range lookups. SQLite Room @Index → RDS / Aurora PostgreSQL indexes
Leftmost Prefix Rule A composite index on (a, b, c) can accelerate filters on (a), (a, b), or (a, b, c), but generally cannot seek efficiently on (b) or (c) alone. Multi-column Room DAO queries → PostgreSQL composite index design
MVCC (Multi-Version Concurrency Control) Concurrency model keeping multiple row versions (tuple xmin/xmax) so readers never block writers and writers never block readers, at the cost of dead-tuple bloat cleaned by VACUUM. Snapshot reads without read locks → PostgreSQL transaction visibility
Visibility Map & Index Only Scan Per-page bitmap tracking whether all tuples in a heap page are visible to all transactions; allows covering indexes (INCLUDE) to skip heap fetches when VACUUM keeps pages marked all-visible. Watch Heap Fetches: 0 in EXPLAIN (ANALYZE, BUFFERS)
Connection Pooler (Transaction Mode) Middle-tier proxy multiplexing thousands of short-lived or idle application TCP sockets onto a small fixed pool of backend PostgreSQL worker processes (one backend server connection per transaction). Serverless/container fleets → PgBouncer / Amazon RDS Proxy
ACID & Isolation Levels Atomicity, Consistency, Isolation, Durability guarantees; PostgreSQL defaults to Read Committed, while Repeatable Read / Serializable prevent non-repeatable reads and write skew. Room @Transaction → RDS PostgreSQL vs DynamoDB TransactWriteItems
Optimistic vs Pessimistic Locking Optimistic locking checks a version/timestamp in WHERE version = :expected without holding locks; pessimistic locking acquires row locks (SELECT ... FOR UPDATE) across the transaction. Concurrent inventory/wallet updates → SQL version or DynamoDB ConditionExpression
Expand-and-Contract Migrations Zero-downtime schema evolution: (1) add nullable column/new structure, (2) dual-write & backfill, (3) switch reads, (4) drop legacy column once old app versions drain. Android Room schema migration → Blue/Green ECS + RDS zero-downtime deploys
Access-Pattern-First Modeling Designing schemas around known query paths, cardinality, and latency SLAs: relational normalization for ad-hoc joins vs denormalized item collections for predictable single-digit-ms NoSQL reads. Normalized Room tables → RDS PostgreSQL vs Amazon DynamoDB

Distributed Reliability & Async Architecture (Module 1.4)

Lessons 0010–0011
Term Canonical Definition Android / AWS Anchor
Bounded Timeouts & Deadline Propagation Setting explicit connect, read, and total request timeouts, and forwarding remaining caller budget downstream so slow dependencies fail fast instead of exhausting thread/connection pools. OkHttp callTimeout → ALB / API Gateway (29s max) & Lambda deadlines
Exponential Backoff with Full Jitter Delaying retries via random(0, min(cap, base * 2^attempt)) to desynchronize failing clients instead of hammering a recovering downstream service in lockstep. WorkManager BackoffPolicy.EXPONENTIAL → AWS SDK standard retryer
Circuit Breaker State machine (Closed → Open → Half-Open) that short-circuits calls to an unhealthy dependency after error thresholds trip, allowing recovery without waiting on timeouts. Fast-fail fallback UI → Microservice resilience / App Mesh / Envoy
Retry Storm (Amplification) Cascading outage caused when every tier in a call graph retries (e.g., 3x × 3x × 3x = 27x load) against an already-saturated service; mitigated by retry budgets and retrying only at the edge. Client + Gateway + Worker retries → Use Circuit Breakers & retry budgets
At-Least-Once Delivery Messaging guarantee ensuring every message is delivered at least once, meaning consumers must handle duplicates cleanly; true end-to-end "exactly-once" requires idempotent consumers. WorkManager re-execution → SQS Standard / SNS / EventBridge
Idempotency Key Client-generated unique token (e.g., UUIDv4 per checkout attempt) stored server-side with the request hash and outcome so safe retries return the original result without repeating side effects. Android double-tap / tunnel drop → Idempotency table in Postgres or DynamoDB
Transactional Outbox Pattern Writing domain state and an outbox event row in the same local ACID transaction, then relaying outbox rows asynchronously to a broker—eliminating dual-write inconsistency. Local DB + sync worker → RDS Outbox / DynamoDB Streams → SQS/EventBridge
Dead-Letter Queue (DLQ) Quarantine queue receiving messages that exceed maxReceiveCount (poison pills or downstream bugs) so they stop blocking healthy queue throughput and can be inspected and redriven. Failed background job sink → Amazon SQS DLQ + CloudWatch Alarm + Redrive

Containers, Observability, CI/CD & System Design (Module 1.5)

Lessons 0012–0015
Term Canonical Definition Android / AWS Anchor
Docker Multi-Stage Build & Non-Root Compiling artifacts in a builder stage and copying only runtime binaries into a minimal non-root final image (e.g., distroless/alpine) to shrink image size and CVE attack surface. Gradle build vs APK → Amazon ECR container images for ECS/EKS
Liveness vs Readiness Health Checks Readiness signals whether an instance can accept load-balanced traffic (e.g., DB reachable, not draining); liveness detects deadlocked processes that must be restarted. ALB TargetGroup health check vs ECS/K8s container probe
Structured Logging & Correlation IDs Emitting single-line JSON logs with consistent fields (timestamp, level, request_id, trace_id, tenant_id) so log queries filter accurately across distributed nodes. Timber structured tags → CloudWatch Logs Insights JSON parsing
RED & USE Metrics Request-scoped RED (Rate, Errors, Duration percentiles like p95/p99) for services/APIs, paired with resource-scoped USE (Utilization, Saturation, Errors) for CPUs, pools, and queues. App performance vitals → CloudWatch Metrics / Prometheus dashboards
OpenTelemetry (OTel) Vendor-neutral standard for propagating W3C traceparent headers and exporting correlated traces, spans, metrics, and logs across services without lock-in. OkHttp interceptor headers → ADOT (AWS Distro for OTel) → X-Ray
SLI, SLO & Error Budget SLI is the measured indicator (e.g., good requests / valid requests); SLO is the target (e.g., 99.9% over 30d); Error Budget (0.1%) governs release velocity vs reliability work. Crash-free users target → Multi-window burn-rate alerts in CloudWatch
Testcontainers & Testing Pyramid Running ephemeral real dependencies (PostgreSQL, Redis, LocalStack) in Docker during CI integration tests rather than mocking SQL/cache semantics. Android Espresso/Robolectric → Real-engine CI tests in GitHub Actions
Architecture Decision Record (ADR) Short immutable Markdown document capturing a significant technical choice: Context, Decision, Considered Alternatives, and Consequences/Tradeoffs. Engineering RFC → Repo docs/adr/ justifying RDS vs DynamoDB or ECS vs EKS

Part 2: Senior AWS Engineer Mastery (Modules 2.1–2.8)

AWS Foundations, Well-Architected & IAM/Governance (Module 2.1)

Lessons 0016–0019
Term Canonical Definition Android / AWS Anchor
AWS Region & Availability Zone (AZ) A Region is a geographic cluster of 3+ isolated Availability Zones; each AZ has independent power, cooling, and physical networking connected by low-latency (<2 ms) fiber. Multi-AZ protects against datacenter loss; Multi-Region handles regional DR.
Shared Responsibility Model AWS secures of the cloud (physical hardware, hypervisor, managed service control planes); you secure in the cloud (IAM policies, VPC rules, encryption config, app code). Google Play OS sandbox vs app code → AWS IAM, KMS, SGs & patching
AWS Well-Architected (6 Pillars) Architectural review framework across Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, and Sustainability. Production readiness checklist → AWS Well-Architected Tool
IAM Policy Evaluation Engine Request evaluation within an account: an Explicit Deny in any applicable policy (SCP, RCP, Boundary, Identity, Resource, Session) always wins; otherwise an Explicit Allow is required (default Implicit Deny). Android runtime permissions → Least-privilege IAM JSON policies & Condition keys
IAM Permissions Boundary Managed policy attached to an IAM role/user that sets the maximum permissions it can ever receive (intersection of Identity Policy ∩ Boundary), preventing privilege escalation. Safe self-service role creation in CI/CD & developer sandboxes
AWS STS & AssumeRole Security Token Service issues short-lived credentials (AccessKey, SecretKey, SessionToken); cross-account third parties use sts:ExternalId to prevent confused-deputy attacks. Short-lived session tokens → Zero long-lived IAM user keys
OIDC Workload Federation Exchanging a signed external OIDC JWT (e.g., from GitHub Actions or Cognito) directly for temporary STS credentials via AssumeRoleWithWebIdentity with strict sub conditions. Passwordless CI/CD → GitHub Actions → AWS IAM Role
AWS Organizations & SCPs Multi-account governance hierarchy (Management Account → OUs → Member Accounts) using Service Control Policies (SCPs) as account-wide guardrails that cap maximum possible permissions. Isolating dev, staging, prod, and security accounts
IAM Identity Center (AWS SSO) Centralized workforce SSO connecting corporate IdPs (Okta, Google, Entra) to Permission Sets across all AWS Organizations accounts using short-lived CLI/console sessions. Replaces legacy IAM users with static passwords/keys for human engineers

VPC Networking, Private Connectivity & Edge Security (Module 2.2)

Lessons 0020–0023
Term Canonical Definition Android / AWS Anchor
Public, Private & Isolated Subnets Public subnets route 0.0.0.0/0 to an IGW; Private subnets route outbound via a NAT Gateway; Isolated subnets have only a local VPC route with zero internet egress. ALB in Public → ECS/Lambda in Private → RDS / ElastiCache in Isolated
IGW vs NAT Gateway An Internet Gateway (IGW) provides free, horizontally scaled 1:1 public/private NAT for public IPs; a NAT Gateway enables private subnets to initiate outbound internet calls (~$32/mo/AZ + $0.045/GB). Put one NAT Gateway per AZ for HA; avoid routing S3/ECR traffic through NAT!
Security Group (SG) Stateful virtual firewall at the ENI level supporting Allow rules only; return traffic is automatically allowed, and rules can reference another Security Group ID instead of brittle IPs. sg-alb → sg-app:8080 → sg-rds:5432
Network ACL (NACL) Stateless subnet-level firewall evaluated by numbered rules (lowest first) with explicit Allow and Deny; requires explicit outbound rules for ephemeral return ports (1024–65535). Subnet quarantine / CIDR blocklists; remember stateless return traffic!
VPC Flow Logs Metadata capture of IP traffic accepted or rejected at ENIs/Subnets/VPCs (source, dest, ports, protocol, ACCEPT/REJECT), essential for diagnosing SG/NACL drops without packet payloads. Like Wireshark metadata → Queryable via CloudWatch Logs Insights or Athena
AWS PrivateLink & Interface Endpoints Private ENI inside your VPC backed by Private DNS exposing AWS services (ECR, Secrets Manager, STS, SQS) or partner services over the AWS backbone without traversing the public internet or NAT. Eliminates NAT Gateway data charges for high-volume AWS API calls
Gateway VPC Endpoint (S3 / DynamoDB) Free route-table target that directs S3 and DynamoDB traffic privately inside the AWS network, bypassing NAT Gateways entirely with zero hourly or per-GB endpoint fees. Always deploy S3 & DynamoDB Gateway Endpoints in every private route table
VPC Peering vs Transit Gateway VPC Peering is a non-transitive 1:1 link between two non-overlapping VPCs; Transit Gateway (TGW) is a regional Layer 3 hub-and-spoke router connecting dozens of VPCs, VPNs, and Direct Connect. 2–3 VPCs → Peering; Multi-account enterprise / hybrid → Transit Gateway
Route 53 Resolver (Hybrid DNS) VPC DNS at VPC_CIDR + 2 plus Inbound/Outbound Resolver Endpoints allowing on-premises networks and hub-and-spoke VPCs to resolve Route 53 Private Hosted Zones bidirectionally. Bridges corporate DNS with private AWS service discovery

AWS Compute Spectrum: EC2, ALB, ECS, EKS & Lambda (Module 2.3)

Lessons 0024–0028
Term Canonical Definition Android / AWS Anchor
Graviton (ARM64) & IMDSv2 Graviton processors deliver ~20–40% better price-performance using ARM64; IMDSv2 hardens EC2 instance metadata (169.254.169.254) against SSRF by requiring a PUT session token. Android arm64-v8a builds → Graviton EC2 / Fargate / Lambda
SSM Session Manager IAM-authenticated, CloudTrail-audited shell/port-forwarding tunnel to EC2 instances via the SSM Agent, eliminating open inbound port 22, SSH keys, and bastion hosts. ADB over Wi-Fi debugging → Bastionless private EC2 operations
NLB & Deregistration Delay Network Load Balancer (Layer 4 TCP/UDP/TLS) preserving client source IPs at ultra-low latency; Target Group deregistration delay (default 300s, often tuned to 15–30s) drains in-flight connections on scale-in. ALB for HTTP routing; NLB for static IPs, gRPC passthrough, or PrivateLink
Auto Scaling Group (ASG) Manages EC2 capacity across AZs using Launch Templates, health check replacement, and Target Tracking scaling policies (e.g., maintain 60% CPU or 1,000 ALB requests/target). Warm pools & predictive scaling smooth traffic spikes
Amazon ECR & ECS on Fargate Serverless container compute running Docker images from ECR without managing EC2 nodes; distinguishes the Execution Role (agent pulling image/secrets) from the Task Role (app AWS SDK calls). Default senior choice for containerized AWS APIs without K8s operational overhead
Amazon EKS & IRSA / Pod Identity Managed Kubernetes control plane on AWS; IRSA (OIDC) and EKS Pod Identity map Kubernetes ServiceAccounts to scoped IAM Roles so pods never share node-level permissions. Use EKS for K8s ecosystem/multi-cloud needs; prefer ECS Fargate when simpler
AWS Lambda & Firecracker Event-driven FaaS running each execution environment inside a lightweight Firecracker microVM; billed per ms × configured memory (which also scales vCPU allocation linearly). 1,769 MB ≈ 1 full vCPU; tune memory via AWS Lambda Power Tuning
Cold Starts & Lambda SnapStart Latency penalty when Lambda provisions a new Firecracker sandbox and runs runtime/framework init; mitigated with slim dependencies, Provisioned Concurrency, or SnapStart (JVM/Python/.NET snapshots). Avoid VPC NAT dependency unless needed; modern VPC ENIs (Hyperplane) add minimal init time

Storage, Content Delivery & DNS (Module 2.4)

Lessons 0029–0031
Term Canonical Definition Android / AWS Anchor
S3 Strong Consistency & Lifecycle Amazon S3 provides strong read-after-write consistency for all PUTs, overwrites, DELETEs, and LISTs; Lifecycle policies transition objects to Intelligent-Tiering/Glacier and abort stale multipart uploads. 11 nines (99.999999999%) durability across 3+ AZs; always enable Block Public Access
S3 Pre-Signed URL Time-limited, SigV4-signed URL generated by the backend allowing a mobile client to upload or download a specific S3 object directly without proxying bytes through your API servers. Android OkHttp PUT directly to S3 → Zero API server bandwidth bottleneck
CloudFront Origin Access Control (OAC) Modern IAM SigV4 mechanism allowing CloudFront edge distributions to read from a completely private S3 bucket (with Block Public Access ON), replacing legacy OAI and supporting SSE-KMS. Users hit CloudFront CDN; direct S3 URLs return 403 AccessDenied
CloudFront Cache Policies & Edge Compute Cache Keys define what varies a cached object (path, selected headers/query params/cookies); CloudFront Functions handle sub-ms header/URL rewrites at edge POPs while Lambda@Edge runs heavier Node/Python logic at Regional Edge Caches. Minimize Cache Key entropy (never forward Authorization unless needed) for high hit ratios
Route 53 Alias vs CNAME Route 53 Alias records map domain names (including the zone apex example.com) directly to AWS targets (ALB, CloudFront, S3) with free Alias queries, whereas standard CNAMEs cannot sit at the root apex. Always prefer Alias over CNAME for AWS resources
Route 53 Routing Policies Traffic steering modes: Failover (active-passive health-checked switch), Latency (lowest-RTT AWS Region), and Weighted (canary split across stacks), backed by global edge Health Checks. DNS TTL caching on Android/ISPs limits instant cutover; combine with CloudFront/Global Accelerator

Managed Databases & Caching on AWS (Module 2.5)

Lessons 0032–0035
Term Canonical Definition Android / AWS Anchor
RDS Multi-AZ vs Read Replicas Multi-AZ provides high availability via synchronous replication to a standby in another AZ with automatic DNS failover; Read Replicas scale read throughput asynchronously (and can be cross-region). Multi-AZ = HA (not read scaling); Read Replicas = read scaling & DR promotion
Amazon Aurora Cloud-native MySQL/PostgreSQL engine separating compute from a shared distributed storage volume replicated 6 ways across 3 AZs, supporting sub-30s failover and up to 15 low-lag read replicas. Aurora Serverless v2 scales ACUs granularly for spiky workloads
Amazon RDS Proxy Fully managed connection pooler sitting in front of RDS/Aurora that multiplexes thousands of Lambda/container connections, enforces IAM DB authentication, and reduces failover disruption by up to 66%. Essential when AWS Lambda connects to PostgreSQL/MySQL
DynamoDB PK/SK & Hot Partitions Items are hashed by Partition Key (PK) onto storage partitions (max 1,000 WCU / 3,000 RCU per partition) and sorted within a partition by Sort Key (SK); skewed PKs create hot-partition throttling. High-cardinality PKs (e.g., USER#123, write sharding) prevent ProvisionedThroughputExceededException
DynamoDB GSI, LSI & Capacity Modes Global Secondary Indexes (GSIs) add alternate PK/SK lookups asynchronously with separate throughput; Local Secondary Indexes (LSIs) share the base PK (10 GB item-collection cap); choose On-Demand for spiky/unknown traffic vs Provisioned + Auto Scaling for steady load. Never use Scan in hot API paths; design Query access patterns upfront
DynamoDB Single-Table Design Storing heterogeneous entity types (e.g., User, Order, OrderItem) in one DynamoDB table with generic keys (PK, SK, GSI1PK) so related entities return in a single Query round trip. Pre-joined item collections → Eliminates N+1 queries at single-digit-ms latency
DynamoDB Streams Ordered, 24-hour Change Data Capture (CDC) log of item-level inserts, updates, and deletes triggering AWS Lambda or EventBridge Pipes for async projections, analytics, or outbox dispatch. Replaces dual-writes for search indexing, audit logs, and event publishing
Amazon ElastiCache (Redis / Valkey) Managed sub-millisecond in-memory data store supporting cluster-mode sharding, Multi-AZ replication, sorted sets for leaderboards/rate-limiters, and Serverless scaling. Use Valkey/Redis for shared rate limits, sessions & hot reads; not as durable system of record

Serverless APIs & Event-Driven Integration (Module 2.6)

Lessons 0036–0039
Term Canonical Definition Android / AWS Anchor
API Gateway (HTTP API vs REST API) HTTP APIs offer lower latency and ~70% lower cost for JWT + Lambda/ALB proxies; REST APIs add API keys, Usage Plans, request validation, caching, and WAF integration. High-RPS container APIs → ALB; per-tenant SaaS throttling/serverless → API Gateway
Amazon SQS (Standard vs FIFO) Managed pull queue: Standard offers near-unlimited throughput with at-least-once/best-effort ordering; FIFO guarantees strict per-MessageGroupId ordering and 5-minute deduplication; Visibility Timeout hides in-flight messages during processing. Long polling (WaitTimeSeconds=20) cuts empty polls & cost; always attach a DLQ
Amazon SNS Fan-Out & Filtering Managed pub/sub topic broadcasting one event simultaneously to multiple independent SQS queues, Lambda functions, or push targets, with JSON filter policies to avoid waking unneeded consumers. OrderPlaced → SNS → separate Billing, Inventory & Email SQS queues
Amazon EventBridge (Buses, Pipes & Scheduler) Serverless event router matching JSON payloads via content-based Rules across AWS/SaaS/custom buses; Pipes connect point-to-point sources (SQS/DDB Streams) to targets with filtering/enrichment, and Scheduler replaces cron Lambdas. Decoupled cross-domain events + transactional email dispatch via SES
AWS Step Functions (Standard vs Express) Managed workflow state machine with retries, branching, parallel states, and human/async callback tokens; Standard runs up to 1 year with exactly-once step history, while Express handles high-rate (<5 min) workflows. Visual, auditable orchestration replacing fragile cron + state tables
Saga Pattern (Orchestration & Compensations) Managing multi-service distributed transactions without 2PC locks by pairing each forward step (e.g., Reserve Inventory, Charge Card) with an idempotent compensating action (Release Inventory, Refund) on failure. Implemented via Step Functions (orchestration) or EventBridge/SQS (choreography)

Infrastructure as Code (IaC) & Platform CI/CD (Module 2.7)

Lessons 0040–0043
Term Canonical Definition Android / AWS Anchor
AWS CloudFormation (Change Sets & Drift) AWS-native declarative JSON/YAML IaC engine tracking stack resources, previewing destructive replacements via Change Sets, detecting manual console edits (Drift), and deploying multi-account StackSets. Set DeletionPolicy: Retain on stateful RDS/S3/KMS resources!
AWS CDK (Constructs, Aspects & cdk-nag) Imperative-code-to-CloudFormation framework in TypeScript/Python/etc. using L1 (raw CFN), L2 (curated defaults + grant*() helpers), and L3 (opinionated patterns), checked at synth time by Aspects and cdk-nag. Unit-testable AWS infrastructure using assertions.Template
Terraform Remote State & Modules Cloud-agnostic HCL IaC tool comparing desired config against a shared remote state file in encrypted S3 with state locking (use_lockfile / DynamoDB) to prevent concurrent apply corruption. terraform plan in PRs; reusable versioned modules for VPC/IAM/EKS
Canary Deployments & Auto-Rollback Shifting a small fraction of live traffic (e.g., CodeDeploy Canary10Percent5Minutes) to a new task set or Lambda alias while CloudWatch 5xx/latency alarms trigger automatic rollback in seconds. Google Play staged rollouts → CodeDeploy Blue/Green behind ALB or API GW

Security, Observability, FinOps & Disaster Recovery (Module 2.8)

Lessons 0044–0050
Term Canonical Definition Android / AWS Anchor
AWS KMS & Envelope Encryption Key Management Service storing Customer Managed Keys (CMKs) in HSMs; Envelope Encryption generates a plaintext Data Encryption Key (DEK) to encrypt large payloads locally and stores the KMS-encrypted DEK alongside the ciphertext. Android Keystore → KMS GenerateDataKey + S3/RDS/EBS encryption
Secrets Manager vs Parameter Store Secrets Manager natively rotates RDS/API credentials via Lambda (~$0.40/secret/mo); SSM Parameter Store offers free Standard configuration parameters and KMS-encrypted SecureString values without built-in rotation. Zero secrets in Git or task-def plain env vars; inject via ARN at runtime
AWS WAF & AWS Shield WAF inspects Layer 7 HTTP traffic on CloudFront/ALB/API GW for SQLi, XSS, bot control, and IP rate limits; Shield Standard (free) / Advanced mitigates Layer 3/4 DDoS floods. Attach WAF at CloudFront edge to block abusive traffic before compute scales
CloudTrail, GuardDuty & Security Hub CloudTrail logs every AWS API call (who did what, when, from where); GuardDuty analyzes CloudTrail, VPC Flow Logs, and DNS logs with ML threat detection; Security Hub aggregates findings across accounts. Essential forensic audit trail + automated anomaly alerting
CloudWatch Insights, Synthetics & X-Ray Logs Insights queries structured JSON logs at scale; Synthetics runs headless canary probes from outside the VPC; X-Ray/ADOT visualizes end-to-end distributed latency and fault bottlenecks. Pair alarms with concise Operational Runbooks (triage steps & rollback commands)
AWS FinOps & Cost Traps Cloud financial discipline using cost-allocation tags, AWS Budgets anomaly alerts, Savings Plans/Graviton rightsizing, and eliminating hidden traps like NAT Gateway GB charges, cross-AZ data transfer, and unbounded CloudWatch log retention. Measure unit cost (cost per 1M requests or active tenant), not just total bill
RPO, RTO & Disaster Recovery Tiers RPO (Recovery Point Objective) is maximum tolerable data loss in time; RTO (Recovery Time Objective) is maximum tolerable downtime; implemented via Backup & Restore, Pilot Light, Warm Standby, or Multi-Site Active/Active. Match tier to SLA & budget—Active/Active costs 2x+ and adds replication complexity
AWS Fault Injection Service (FIS) Controlled chaos engineering service that injects real faults (AZ isolation, EC2/ECS termination, RDS failover, network latency, DynamoDB throttling) gated by CloudWatch stop-condition alarms. Proves failover, alarms, and runbooks actually work before a real outage
