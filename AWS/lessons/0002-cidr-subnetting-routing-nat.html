IPv4/CIDR Subnetting, Routing Tables, NAT & Ports

Every packet leaving your Android device carries a source IP, destination IP, and port pair—and crosses at least two NAT boundaries before reaching a private EC2 or ECS container. Mastering 32-bit CIDR masks, AWS's 5-IP subnet reservation, longest-prefix routing, and NAT port limits prevents silent IP exhaustion and asymmetric outage traps.

Your Android Bridge

On Android Wi-Fi or 5G, your phone's local interface holds an RFC 1918 private address like 192.168.1.42 and opens an ephemeral source port (for example, 51432) to call api.myapp.com:443. Your home router or mobile carrier performs Source NAT (SNAT) so packets can return across the public internet. Inside AWS, an Amazon VPC works identically in reverse: your backend tasks live on private IPs inside a 10.0.0.0/16 CIDR block, route via longest-prefix rules, and rely on a NAT Gateway for outbound calls.

1. IPv4 as a 32-Bit Integer & AWS CIDR Subnet Math

An IPv4 address such as 10.0.1.42 is human shorthand for a single unsigned 32-bit integer: four 8-bit octets packed left-to-right (0x0A00012A = 167,772,458). A CIDR block (defined in RFC 4632) pairs an IP prefix with a bitmask length /n from 0 to 32:

  • Network bits (n): The top n bits are fixed and identify the network or subnet.
  • Host bits (32 - n): The remaining bits identify hosts within that subnet, giving 2^(32 - n) total addresses.
  • Subnet membership test: An IP belongs to a CIDR block if and only if (ipInt & maskInt) === networkInt using unsigned 32-bit bitwise arithmetic.

In standard textbook networking, a subnet loses 2 addresses (network ID and broadcast). In AWS VPCs, however, the AWS VPC Subnet Sizing specification reserves 5 IP addresses in every subnet—which cannot be assigned to EC2 instances, ALBs, or ECS tasks:

  1. +0 (e.g., 10.0.1.0): Network address.
  2. +1 (e.g., 10.0.1.1): Reserved by AWS for the VPC router.
  3. +2 (e.g., 10.0.1.2): Reserved by AWS for Amazon-provided DNS.
  4. +3 (e.g., 10.0.1.3): Reserved by AWS for future use.
  5. last (e.g., 10.0.1.255): Network broadcast address (AWS VPC does not support broadcast, but still reserves it).

Consequently, a /24 subnet provides 256 - 5 = 251 usable IPs, whereas the smallest allowed AWS VPC subnet, a /28, provides 16 - 5 = 11 usable IPs. Oversizing or undersizing subnets early is expensive because an existing subnet's CIDR block cannot be resized in place.

2. Longest-Prefix Match Routing & Asymmetric Failure Modes

Unlike firewall ACL rules or if/else lists that execute top-to-bottom, IP routers and AWS VPC Route Tables evaluate every entry and pick the longest-prefix match (LPM)—the matching route with the largest /n prefix length.

  • A /32 host route (10.0.2.45/32) overrides a /24 subnet route, which overrides a /16 VPC local route, which overrides the 0.0.0.0/0 default route.
  • AWS local route protection: Every VPC route table automatically includes a local route for the VPC CIDR (e.g., 10.0.0.0/16 → local) that cannot be deleted, though more specific routes (/24 or /32) can redirect subsets of traffic to a firewall appliance or peering link.
Production Trap: Asymmetric Routing & Overlapping CIDRs

If Subnet A routes traffic to Subnet B through a stateful inspection firewall (or NAT Gateway), but Subnet B's route table uses local directly back to Subnet A, return packets bypass the firewall. Because stateful firewalls and NAT gateways only forward packets belonging to known connection-tracking (conntrack) flows, return traffic is silently dropped—causing mysterious 100% TCP timeouts despite healthy security groups. Similarly, overlapping VPC CIDRs (two VPCs both using 10.0.0.0/16) cannot be directly peered without ambiguous routing.

3. TCP/UDP Ports, Ephemeral Ranges & NAT Traversal

IP addresses locate a host; 16-bit ports (0–65,535) locate a specific socket process on that host. Every TCP connection is uniquely identified by its 5-tuple: 

(protocol, srcIP, srcPort, dstIP, dstPort)
// Example: (TCP, 10.0.2.45, 51432, 93.184.216.34, 443)

When a private subnet backend (with no public IP) calls an external API like Stripe or Firebase:

  1. The backend OS picks an ephemeral port (Linux default net.ipv4.ip_local_port_range is 32768–60999 = 28,232 ports; IANA recommends 49152–65535).
  2. The private subnet's 0.0.0.0/0 route sends the packet to an AWS NAT Gateway in a public subnet.
  3. The NAT Gateway performs SNAT, rewriting srcIP:srcPort (10.0.2.45:51432) to its own Elastic IP and an allocated NAT source port (54.12.34.56:38104), recording the translation in its stateful NAT table.
  4. Return packets to 54.12.34.56:38104 match that table entry, undergo Destination NAT (DNAT) back to 10.0.2.45:51432, and reach the backend container. Unsolicited inbound packets from the internet have no table entry and are dropped.

Real scale limit: Per the AWS NAT Gateway specification, a single NAT Gateway supports up to 55,000 simultaneous connections to any single unique destination (dstIP, dstPort) pair. Opening 60,000 parallel connections to the same external endpoint triggers ErrorPortAllocation failures even when CPU and bandwidth look idle.

4. Production Example: VPC Subnets, Route Tables & CLI Verification

Below is a realistic Terraform topology pairing a /16 VPC with /24 public/private subnets, plus the Linux diagnostics used on an EC2 host to verify routes and socket tuples: 

# Terraform: Public vs. Private Subnet Routing with NAT Gateway
resource "aws_vpc" "app" {
  cidr_block = "10.0.0.0/16" # 65,536 IPs; non-overlapping with peered VPCs
}

resource "aws_subnet" "public_a" {
  vpc_id     = aws_vpc.app.id
  cidr_block = "10.0.1.0/24" # 251 AWS-usable IPs (.0-.3 and .255 reserved)
}

resource "aws_subnet" "private_a" {
  vpc_id     = aws_vpc.app.id
  cidr_block = "10.0.2.0/24" # 251 AWS-usable IPs for ECS/RDS workloads
}

resource "aws_route_table" "private_a" {
  vpc_id = aws_vpc.app.id
  # Implicit "10.0.0.0/16 -> local" exists automatically
  route {
    cidr_block     = "0.0.0.0/0"
    nat_gateway_id = aws_nat_gateway.az_a.id # Outbound SNAT only
  }
}
# Linux shell: inspect kernel route selection and live TCP 5-tuples

Why AWS Reserves 5 IPs Classic RFC 950 subnets reserve 2 IPs (network + broadcast). AWS adds 3 more at +1 (VPC router), +2 (VPC DNS), and +3 (future use), shrinking a /28 from 14 to 11 usable hosts.
JavaScript's >>> 0 Trap In JS, bitwise operators coerce numbers to signed 32-bit integers, and x << 32 wraps to x << 0! Always guard prefix === 0 explicitly and append >>> 0 so masks stay unsigned.
IGW vs. NAT Gateway An Internet Gateway performs stateless 1:1 public-to-private IP mapping for instances that already have a public IP. A NAT Gateway is stateful and lets many private-only hosts share one public Elastic IP outbound.
