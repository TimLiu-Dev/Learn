Production AI on AWS: Amazon Bedrock, PrivateLink, Guardrails & Token Throttling

In 2027, Senior AWS Engineers are expected to ship GenAI features with the exact same security, network isolation, and FinOps rigor as payment APIs—keeping customer prompts off the public internet via PrivateLink, blocking PII leaks with Bedrock Guardrails, and protecting token quotas.

Your Android Bridge

Never ship an AI API key inside an Android APK—anyone can extract strings from an APK in 30 seconds. Your Android app authenticates to your backend using a Cognito OIDC JWT, and your ECS/Lambda AI Gateway assumes an IAM Task Role to call Amazon Bedrock privately inside your VPC with per-tenant rate limits and content guardrails.

1. Zero-Trust AI Architecture: PrivateLink, IAM & Guardrails

Calling an external SaaS LLM over a NAT Gateway sends sensitive customer data across public internet hops and racks up $0.045/GB NAT charges. On AWS, Amazon Bedrock PrivateLink places a com.amazonaws.<region>.bedrock-runtime Interface Endpoint inside your private subnets so inference traffic never leaves the AWS backbone and AWS never trains base models on your prompts.

  • Least-Privilege IAM: Scope bedrock:InvokeModel and bedrock:InvokeModelWithResponseStream strictly to approved model ARNs (or cross-region inference profile ARNs) plus bedrock:ApplyGuardrail.
  • Bedrock Guardrails: Enforce PII redaction (SSN, credit cards, email/phone), denied topics, and prompt-attack / jailbreak filters uniformly across models before tokens hit your database or Android UI.

2. Token Throttling, Cross-Region Profiles & Cost Guardrails

Unlike classic REST APIs where 1 request = 1 unit of work, LLM workloads fail via Tokens Per Minute (TPM) exhaustion and runaway output token bills. Senior gateways enforce:

  • Hard maxTokens Caps: Never let untrusted clients choose unbounded output lengths (output tokens typically cost 3–5× more than input tokens).
  • Cross-Region Inference Profiles: Prefixing model IDs (e.g., us.anthropic.claude-...) lets Bedrock automatically route inference across multiple US regions during regional capacity spikes, drastically reducing ThrottlingException rates.
  • Token-Bucket Per-Tenant Quotas + Full Jitter Retries: Meter actual input + output tokens returned in the Bedrock usage metadata.
// AWS CDK v2: PrivateLink Endpoint + Least-Privilege Bedrock IAM Policy
const bedrockEndpoint = vpc.addInterfaceEndpoint("BedrockRuntimeEndpoint", {
  service: ec2.InterfaceVpcEndpointAwsService.BEDROCK_RUNTIME,
  subnets: { subnetType: ec2.SubnetType.PRIVATE_WITH_EGRESS },
  privateDnsEnabled: true,
});

ecsTaskRole.addToPolicy(new iam.PolicyStatement({
  actions: ["bedrock:InvokeModel", "bedrock:InvokeModelWithResponseStream"],
  resources: [
    "arn:aws:bedrock:us-east-1:123456789012:inference-profile/us.anthropic.*",
  ],
  conditions: {
    StringEquals: { "bedrock:GuardrailIdentifier": guardrail.attrGuardrailId },
  },
}));
