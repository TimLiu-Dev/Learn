1. Curriculum Audit Against roadmap.sh/aws

roadmap.sh/aws is a solid service checklist, but a checklist alone does not turn a junior mobile developer into a senior cloud engineer. Senior engineers are hired for systems judgment, failure-mode reasoning, Infrastructure as Code, security boundaries, and cost tradeoffs—not console memorization. Below is the exact audit of what we keep, add, and remove.

Decision Topics Why This Choice Makes You Stronger for 2027
Verified & Kept Cloud Basics, IAM, VPC, EC2/ASG, S3, Route 53, CloudWatch, CloudFront, RDS, DynamoDB, ElastiCache, ECR/ECS/EKS, Lambda, EventBridge, API Gateway, SQS/SNS, CloudFormation/CDK/Terraform, KMS. Every core roadmap.sh/aws node is preserved, sequenced by dependency order, and taught via code/IaC rather than manual console clicking.
Added (Critical) Part 1 Senior SWE Bridge (Lessons 0001–0015): HTTP/TCP/TLS, connection pooling, REST/Auth (OIDC/JWT), SQL transactions & indexing, idempotency, retries/jitter, containers, OpenTelemetry, Capstone 1. roadmap.sh/aws assumes you already understand backend systems. Skipping this leaves a junior Android dev memorizing AWS knobs without knowing why databases lock, sockets drop 502s, or retries cause outages.
Added (Critical) Multi-Account & Zero-Trust Ops: AWS Organizations, Control Tower, SCPs, IAM Identity Center, STS, GitHub Actions OIDC, PrivateLink/VPC Endpoints, Secrets Manager. Real senior roles run multi-account landing zones (dev/stage/prod) with zero static credentials—never a single root-ish account with IAM user access keys.
Added (Critical) FinOps, Resilience & DR: NAT Gateway cost traps, S3/DynamoDB/RDS pricing models, Well-Architected Reviews, RPO/RTO DR tiers, Step Functions, CloudTrail auditing, ADRs. Senior interview loops always test cost awareness ("why did our AWS bill jump $4k?") and recovery design ("what happens if us-east-1 loses an AZ or region?").
Removed / Scoped Manual EC2 "ClickOps" pets, Classic Load Balancer (CLB), static IAM access keys in apps, raw self-managed K8s control planes, Memcached tuning, standalone SES mail-ops. Removed legacy patterns that signal junior habits in interviews. SES is kept strictly as a brief transactional-email integration pattern inside serverless workflows.
