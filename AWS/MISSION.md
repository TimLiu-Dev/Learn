# Mission: Junior Android Developer to Senior AWS Engineer (2027)

## Why
Transition from a junior Android developer to a hireable Senior AWS Engineer in 2027. Rather than memorizing AWS console trivia, build true end-to-end systems mastery in two progressive stages: first becoming a strong Senior Software Engineer in backend/distributed systems (Part 1), then mastering production AWS architecture, Infrastructure as Code, security, and operations (Part 2)—backed by resume-grade capstone projects.

## Success looks like
- Design, build, and deploy an end-to-end backend system (Part 1 Capstone) with solid networking, relational/cache data modeling, async workers, observability, and automated tests.
- Design, provision via IaC (CDK/Terraform), and operate a multi-AZ, event-driven, zero-trust AWS production platform (Part 2 Capstone) strong enough to showcase on a resume and defend in senior system design interviews.
- Pass every lesson's runnable coding exercises and diagnostic quizzes by reasoning from first principles, not guesswork.

## Constraints
- Starting baseline: Junior Android developer (familiar with mobile app architecture, REST APIs, and basic Kotlin/Java; new to backend distributed systems and production AWS).
- Target timeline: Job-ready in 2027.
- Teaching format: Self-contained interactive HTML lessons with runnable code examples, automated practice checks with progressive hints and final answer reveal, and multi-choice quizzes explaining why every option is right or wrong.
- Curriculum benchmarked and audited against [roadmap.sh/aws](https://roadmap.sh/aws).

## Out of scope
- Legacy ClickOps-only workflows (manual EC2 pet servers, Classic Load Balancers, static long-lived IAM user keys in app code).
- Deep ML/AI model training infrastructure or specialized telecom/IoT AWS services unrelated to senior cloud/backend engineering roles.
