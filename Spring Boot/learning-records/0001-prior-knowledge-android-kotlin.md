# Prior Knowledge: Junior Android Kotlin Developer Transitioning to Backend

The learner is currently a junior Android developer proficient in Kotlin, with foundational familiarity in Gradle, client-side HTTP (Retrofit/OkHttp), and client dependency injection (Hilt/Koin), but with zero prior backend experience. Future sessions must bridge client-side mental models to server-side realities (stateless concurrent request handling, raw SQL before ORM abstractions, and thread models) while using their existing Kotlin fluency to accelerate Java 21 comprehension.
