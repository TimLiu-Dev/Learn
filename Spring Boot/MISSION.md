# Mission: Senior Spring Boot Backend Developer (2027)

## Why
Transition from a junior Android Kotlin developer with zero backend experience into a senior-caliber, autonomous backend software engineer for 2027, capable of designing, architecting, securing, testing, and operating resilient high-scale distributed systems with **Spring Boot 4.2, Spring Framework 7.1, Spring Security 7, Java 25 LTS, and Kotlin 2.2+**.

## Success looks like
- **Stage 1 (Mid-Level Core — 27 Lessons, `0001`–`0027` → Project 1):** Master HTTP/Jackson 3 (`JsonMapper`), modern Java 25 for Kotlin developers (Records, Sealed Switches, JSpecify `@NullMarked`), Gradle/Maven BOMs, `spring-boot-docker-compose` local workflow & Virtual Thread debugging, Spring Core & Advanced DI (`@Qualifier`, Strategy Maps, Scopes, `BeanPostProcessor`), Profiles/AOP, REST/Validation/ProblemDetail/API Versioning (`version = "1.0+"`), Money (`BigDecimal`)/UTC (`Instant`)/PII masking, PostgreSQL 17/HikariCP, Production SQL (CTEs, Window Functions, `UPSERT`, `JdbcClient`), Indexes (`EXPLAIN ANALYZE`), Flyway, Composite Keyset Pagination, Hibernate 7 JPA/Projections/Specifications/Auditing/Transactions, and `@WebMvcTest` (`RestTestClient`, `@MockitoBean`) + `@DataJpaTest` + Testcontainers (`@ServiceConnection`), shipping **Project 1 (Core Order & Catalog API)**.
- **Stage 2 (Senior Backend Core — 30 Lessons, `0028`–`0057` → Project 2):** Master edge reverse proxies/CORS/`ETag`, SSE/WebSockets + Redis fan-out, Read-Replica Routing (`AbstractRoutingDataSource`) + Partitioning/Sharding + CAP/PACELC, Redis caching/locks/fencing tokens/idempotency/multi-tier L1+L2/Bucket4j rate limiting + Redis Internals (eviction, JSON, Lua, Streams), Spring 7 `@Retryable`/`@ConcurrencyLimit` & Resilience4j `@CircuitBreaker`, Kafka + Transactional Outbox + Schema Registry/EOS + Kafka Production Ops (manual acks, `CooperativeStickyAssignor`, lag & compaction), Spring Security 7 (JWT RTR, RBAC, OAuth2 PKCE, WebAuthn Passkeys, mTLS, Argon2id & OWASP API Top 10), Java 25 Virtual Threads (JEP 491)/Locking/ShedLock/JFR, DDD & Spring Modulith 2/Sagas/HMAC Webhooks & WireMock/System Design capacity math, Enterprise Migration Playbook (Boot 3 → 4.2 & `ScopedValue`), and Kotlin 2.2+ Coroutines + `MockK`, shipping **Project 2 (NexusCommerce Distributed Engine)**.
- **Stage 3 ("Just-Enough" Production Engineering — 18 Lessons, `0058`–`0075` → Milestone 3):** Master PostgreSQL 17 MVCC/`AUTOVACUUM`/`lock_timeout`/deadlock triage, Linux & container diagnostics (`SIGTERM` 143 vs 137, `ulimit -n`, `ss`, `jq`), backend networking (DNS TTL, TCP Keep-Alive, timeouts, TLS 1.3 & SSL Bundles), Actuator probes, W3C `traceparent` + MDC, ECS structured JSON logging & cardinality guards, PromQL RED dashboards & SLO burn-rate alerts, Boot 4 native OpenTelemetry (`spring-boot-starter-opentelemetry`) + Grafana LGTM, `k6` load testing & `StreamingResponseBody`, bounded `@Async` pools & `TaskDecorator`, GitHub Actions CI, multi-stage Distroless & Paketo CDS/Leyden AOT containers (`-XX:MaxRAMPercentage=75.0 -XX:+UseZGC`), Kubernetes Pods/Deployments/Services/Probes/Graceful Shutdown, Expand-and-Contract zero-downtime migrations, and AWS S3 Presigned URLs + RDS Proxy/Secrets Manager/LocalStack, completing **Milestone 3 (Productionizing NexusCommerce)**.
- **Stage 4 (Optional Deep-Dive Shelf — 16 Lessons, `0076`–`0091` → Optional Capstone):** K8s CFS CPU throttling/HPA/PDB, Helm/Kustomize/Cosign/SBOM, AWS VPC/EKS Pod Identity, SQS/SNS vs Kafka, Terraform IaC, gRPC/GraphQL `@BatchMapping`, Postgres FTS/`pgvector`/Elasticsearch/CQRS, Multi-Tenancy (`@TenantId` & Postgres RLS) + OpenFeature, Spring Data MongoDB & DynamoDB, Debezium WAL CDC & Event Sourcing, GraalVM Native vs AppCDS/Leyden AOT, Spring AI 2.x (`ChatClient`, `pgvector` RAG, `@Tool`, Streamable-HTTP `@McpTool`), Spring Data JDBC/jOOQ, Spring Cloud Gateway Server WebMvc (`TokenRelay`), Spring Batch 6, and Spring Cloud Contract + ArchUnit Guardrails.

## Constraints
- Learner is a junior Android developer fluent in Kotlin; bridge client-side mental models (Retrofit, Room, Hilt, Coroutines, DataStore, Emulator) to accelerate server-side mastery.
- Every lesson (`0001`–`0091`) follows strict sequential numbering matching study order and includes multi-section conceptual prose, dual Java 25 LTS & Kotlin 2.2+ code examples, 3 balanced active-recall quizzes, and an automated multi-assertion in-browser coding lab.

## Out of scope
- Legacy reactive WebFlux/Reactor stacks — superseded for standard microservices in 2027 by Java 25 Virtual Threads (Project Loom + JEP 491) and Kotlin Coroutines.
- Bare-metal Linux kernel sysadmin or low-level Kubernetes CNI setup — focus strictly on developer-facing production ownership ("You Build It, You Run It").
- Legacy Spring XML configuration or pre-Boot 3 / pre-Java 21 patterns (covered only as migration sources in Lesson `0056`).
