Project 1: Core Order & Catalog REST Service (Mid-Level Benchmark)

Do not wait until Lesson 50+ to write real backend code! Right after finishing Stage 1 (Lessons 0001–0073 + 0038–0039), solidify everything you learned by building a clean, single-service Spring Boot REST API backed by real PostgreSQL—without Kafka, Redis, or Kubernetes yet.

1. Clean Single-Service Architecture

[ Android / Postman / OpenAPI Swagger UI ] │ (HTTP / JSON + Validation) ▼ [ Spring Boot REST API (Java 21/25 or Kotlin 2.x) ] ├─ Type-safe @ConfigurationProperties + @Profile("dev" / "!prod") ├─ @RestController + Jakarta @Valid DTOs + RFC 9457 ProblemDetail ├─ Dynamic Search: JpaSpecificationExecutor (status, minPrice, cursor) ├─ Performance: Keyset Cursor Pagination + JOIN FETCH + Record Projections └─ ACID Boundaries: @Transactional + @EnableJpaAuditing + @SoftDelete │ ▼ (HikariCP Pool + Flyway Migrations) [ PostgreSQL 16 (Docker Compose locally / Testcontainers in JUnit) ]

2. Mid-Level Verification Checklist

✓
1. Zero-Magic Boot & Build Hygiene: Bootstrapped with Maven BOM or Gradle Kotlin DSL, constructor injection only (zero @Autowired field injection), and immutable Java Records / Kotlin data classes for all DTOs and @ConfigurationProperties.
✓
2. Flyway + PostgreSQL Query Discipline: All tables and composite indexes created via versioned Flyway SQL scripts (ddl-auto: validate). Verified zero N+1 queries via Hibernate SQL logs and EXPLAIN ANALYZE on your filtered search endpoint.
✓
3. Composable Filtering, Auditing & RFC 9457 Errors: GET /api/v1/orders supports optional filters via Specification<T> and keyset pagination; invalid payloads or missing IDs return structured RFC 9457 ProblemDetail JSON instead of raw 500 stack traces.
✓
4. Automated Slice & Testcontainers Suite: Fast @WebMvcTest controller contract tests + real PostgreSQL integration tests using @ServiceConnection (zero H2 in-memory database mocks!).

3. Upgrade Path into Stage 2 (Project 2)

Once Project 1 compiles, passes all Testcontainers tests, and runs via docker compose up, move straight into Stage 2 (Senior Spring Boot)! You will upgrade this exact architecture into the NexusCommerce Distributed Engine (Project 2) by adding Redis idempotency & multi-tier caching, @Version optimistic locking, Virtual Threads, JWT/RBAC, Kafka Transactional Outbox + Kotlin Coroutine workers, and WireMock contract tests.
