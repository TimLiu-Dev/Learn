Project 1: Core Order & Catalog REST Service (Mid-Level Benchmark)

Do not wait until Lesson 50+ to write real backend code! Right after finishing Stage 1 (Lessons 0001–0027), solidify everything you learned by building a clean, single-service Spring Boot 4.2 REST API in Java 25 LTS or Kotlin 2.2+ backed by real PostgreSQL 17—without Kafka, Redis, or Kubernetes yet.

1. Clean Single-Service Architecture

[ Android / IntelliJ .http Client / OpenAPI 3.1 Swagger UI ] │ (HTTP / Jackson 3 JSON + API Version 1.0) ▼ [ Spring Boot 4.2 REST API (Java 25 LTS or Kotlin 2.2+) ] ├─ JSpecify @NullMarked + @ConfigurationProperties + @Profile("!prod") ├─ @RestController + Jakarta @Valid DTOs + RFC 9457 ProblemDetail ├─ Exact Money (BigDecimal HALF_EVEN), UTC Instant & PII Masking ├─ Dynamic Search: JpaSpecificationExecutor + JdbcClient Reporting ├─ Performance: Composite Keyset Cursor Pagination + JOIN FETCH + Projections └─ ACID Boundaries: @Transactional + @EnableJpaAuditing + @SoftDelete │ ▼ (HikariCP Pool + Flyway Migrations) [ PostgreSQL 17 (spring-boot-docker-compose locally / Testcontainers in JUnit) ]

2. Mid-Level Verification Checklist

✓
1. Zero-Magic Boot 4.2 & Local Docker Inner Loop (Lessons 0001–0010): Bootstrapped on start.spring.io (Spring Boot 4.2, Java 25 / Kotlin 2.2+), auto-wired locally via spring-boot-docker-compose (postgres:17-alpine), constructor injection only, and custom @Around timing/audit aspect.
✓
2. Financial/Temporal Safety & Contract Hygiene (Lessons 0011–0016): All monetary amounts stored as NUMERIC(19, 4) / BigDecimal (zero double!), timestamps stored as TIMESTAMPTZ / UTC Instant, PII masked in logs, native Spring 7 API versioning (version = "1.0+"), and RFC 9457 ProblemDetail error responses.
✓
3. Flyway, Production SQL & Zero-N+1 Persistence (Lessons 0017–0025): All tables and composite B-Tree indexes created via versioned Flyway migrations (ddl-auto: validate). Includes composite (created_at, id) keyset cursor pagination, a JdbcClient analytical summary endpoint, and verified zero N+1 queries via EXPLAIN (ANALYZE, BUFFERS).
✓
4. Automated Slice & Testcontainers Suite (Lessons 0026–0027): Fast @WebMvcTest controller contract tests using RestTestClient / MockMvcTester and @MockitoBean, plus real PostgreSQL 17 repository/service integration tests via @DataJpaTest and @ServiceConnection (zero H2 mocks!).

3. Upgrade Path into Stage 2 (Project 2)

Once Project 1 compiles, passes all Testcontainers checks, and runs via a single IDE click with compose.yaml, advance straight into Stage 2 (Lessons 0028–0057)! You will evolve this exact codebase into the NexusCommerce Distributed Engine (Project 2) by adding Read-Replica routing, Redis idempotency & multi-tier caching, Bucket4j rate limiting, Spring Security 7 JWT/Passkeys/RBAC, Java 25 Virtual Threads & @Version locking, Kafka Transactional Outbox + Kotlin Coroutine consumers, and WireMock webhook verification.
