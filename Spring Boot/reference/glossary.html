📖 Engineering Glossary

The canonical technical vocabulary for this workspace. Every lesson and architectural explanation strictly adheres to these definitions.

Core Framework Architecture

IoC (Inversion of Control)
An architectural pattern where control over object instantiation, configuration, and lifecycle is inverted from the application program to an external container or framework.
Avoid calling: Just "magic", framework takeover, background runner.
Dependency Injection (DI)
A specific subtype of IoC wherein an object's collaborators (dependencies) are supplied to it at runtime by the container, preferentially via constructor arguments.
Avoid calling: Wiring (informal), `@Autowired` on private fields (deprecated anti-pattern).
ApplicationContext
The central interface representing the Spring IoC container, responsible for instantiating, configuring, and assembling beans, as well as providing internationalization, event propagation, and environment abstraction.
Avoid calling: Bean map, global singleton holder.
Spring Bean
An object that is instantiated, assembled, and managed by the Spring IoC container. By default, beans are singletons per ApplicationContext.
Avoid calling: Java bean (which is just a POJO with getters/setters).
Spring Dynamic Proxy (CGLIB / JDK)
An interceptor wrapper created around a bean at runtime that enables cross-cutting concerns (such as @Transactional, @Async, and security checks) without modifying the target class bytecode.
Avoid calling: Direct method interceptor, wrapper class.

Modern Concurrency & Runtimes

Virtual Thread (Project Loom)
A lightweight thread managed entirely by the Java Virtual Machine runtime rather than the operating system kernel, enabling millions of concurrent I/O-bound tasks with minimal memory footprint.
Avoid calling: Kotlin coroutine (coroutines are userland cooperative state machines, virtual threads are preemptive JVM threads).

Data Persistence & JPA

N+1 Query Problem
A critical persistence performance defect where loading 1 parent entity results in N additional separate database queries to fetch child associations, exponentially degrading database latency.
Avoid calling: Slow query, lazy loading bug.
@Transactional Boundary
An annotation marking a method to execute inside an atomic, consistent, isolated, and durable database transaction managed by Spring's PlatformTransactionManager via AOP proxying.
Avoid calling: Database lock, auto-commit wrapper.

Testing & Cloud Native

Testcontainers
An open-source Java library that spins up throwaway, real Docker containers (e.g. true PostgreSQL, Kafka, Redis) during automated test execution to guarantee fidelity with production environments.
Avoid calling: Mock database, in-memory simulator.
Problem Details (RFC 9457 / RFC 7807)
An IETF standard format for HTTP API error responses defining consistent fields (type, title, status, detail, instance) supported natively in Spring 6.
Avoid calling: Custom error JSON, generic error map.
