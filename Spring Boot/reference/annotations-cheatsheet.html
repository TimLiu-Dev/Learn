🏷️ Spring Boot Annotation Cheat Sheet

Modern Spring Boot 3.x+ / Java 21 production annotations categorized by architectural layer. Keep this page bookmarked for reference.

1. Spring Core & IoC Container

Annotation Target / Scope Production Purpose & Best Practice
@Component Class Generic stereotype for any Spring-managed component. Base annotation for `@Service`, `@Repository`, and `@Controller`.
@Service Class Specialization of `@Component` indicating business logic layer. Preferred for transaction boundary placement.
@Configuration Class Indicates a source of bean definitions via `@Bean` methods. Enhanced by CGLIB proxies by default (`proxyBeanMethods=true`).
@Bean Method Explicitly registers a third-party or custom object instance into the ApplicationContext. Use when you cannot annotate the class directly.
@ConfigurationProperties Class / Record Binds external configuration from application.yml into strongly-typed Java records or classes.

2. RESTful Web Layer (Spring MVC)

Annotation Target / Scope Production Purpose & Best Practice
@RestController Class Convenience annotation combining `@Controller` and `@ResponseBody`. Serializes return values directly to JSON.
@GetMapping, @PostMapping... Method Shorthand HTTP method routing. Prefer explicit method annotations over generic `@RequestMapping(method = ...)`.
@PathVariable Method Parameter Extracts values from the URI path template (e.g. /api/orders/{id}).
@RequestBody Method Parameter Deserializes inbound HTTP JSON request body into a Java Record or DTO class via Jackson.
@RestControllerAdvice Class Centralized global exception handling. Intercepts exceptions thrown by any `@RestController` and formats Problem Details (RFC 9457).

3. Persistence Layer (Spring Data JPA / Hibernate)

Annotation Target / Scope Production Purpose & Best Practice
@Entity Class Specifies that the class is a JPA persistent domain entity mapped to a relational database table.
@ManyToOne(fetch = LAZY) Field Defines a single-valued association to another entity. Always specify fetch = FetchType.LAZY to avoid immediate N+1 joins.
@Transactional Method / Class Demarcates transaction boundaries. Use @Transactional(readOnly = true) on read queries for performance optimization.
@Query Method Declares explicit JPQL or native SQL queries on Spring Data Repository interfaces.

4. Testing & Verification

Annotation Target / Scope Production Purpose & Best Practice
@SpringBootTest Test Class Loads the complete ApplicationContext for end-to-end integration tests.
@WebMvcTest Test Class Slice test: loads only the web layer (controllers, filters) while mocking service dependencies. Fast execution.
@ServiceConnection Boot 3.1+ Field / Container Automatically configures database, Kafka, or Redis connection properties directly from a Testcontainers container without manual `@DynamicPropertySource`.
