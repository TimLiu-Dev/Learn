Redis Internals: Eviction Policies, JSON Serialization, Atomic Lua Scripts & Redis Streams

Target: Knowing @Cacheable and Redisson isn't enough when Redis hits production scale. Senior engineers prevent four subtle Redis outages: LRU eviction wiping out distributed locks and idempotency keys, Spring's default JdkSerializationRedisSerializer crashing deployments, non-atomic multi-key read-then-write races (solved with DefaultRedisScript Lua scripts), and choosing Redis Streams (XADD/XREADGROUP) over lossy Pub/Sub when durable consumer groups are needed without Kafka overhead.

📖 Primary Source Recommendation

Study the official authorities: Redis Official Docs: Key Eviction Policies and Spring Data Redis Reference: Atomic Lua Scripting & Streams.

💡 Android Mental Model Bridge

Think of Redis's single-threaded command loop like a super-fast serialized actor: a Lua script executes from start to finish atomically with zero interleaving from other pods—like running a single atomic SQL transaction directly inside Redis RAM!

1. Four Senior Redis Rules for Spring Boot Backends

  • Isolate Cache vs. Lock/Idempotency Redis Policies (maxmemory-policy): A cache cluster uses allkeys-lru (evicts least-recently-used keys when RAM is full). If you store distributed locks, rate-limit buckets, or Idempotency-Key records on that same instance, Redis will silently evict active locks under memory pressure! Put state/lock keys on a dedicated noeviction Redis instance (or use volatile-lru where only cache keys have TTL—though separate instances are safest).
  • Ban Default Java Serialization (JdkSerializationRedisSerializer): Spring Data Redis defaults to Java binary serialization, which writes unreadable blobs, breaks cross-language consumers, and throws InvalidClassException whenever you add a field to a DTO! Always configure StringRedisSerializer keys + GenericJackson2JsonRedisSerializer values.
  • Atomic Lua Scripts (DefaultRedisScript) & Pipelining: Calling redis.opsForValue().get() followed by decrement() in Java has a race window between pods. Executing a 5-line Lua script runs atomically on the Redis server in one roundtrip! For bulk reads/writes, use executePipelined(...) to avoid 500 sequential TCP roundtrips.
  • Redis Pub/Sub vs. Redis Streams: Pub/Sub is fire-and-forget (offline pods permanently miss events). Redis Streams (XADD + XREADGROUP + XACK) persist messages in an append-only log with consumer groups—a lightweight alternative when you don't run Apache Kafka.

Atomic Lua Stock-Decrement Script & JSON RedisTemplate Configuration 
package com.nexus.redis;

import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class AtomicInventoryCache {
    private static final DefaultRedisScript<Long> DECREMENT_IF_ENOUGH = new DefaultRedisScript<>("""
        local current = tonumber(redis.call('GET', KEYS[1]) or '0')
        local req = tonumber(ARGV[1])
        if current < req then return -1 end
        return redis.call('DECRBY', KEYS[1], req)
        """, Long.class);

    private final StringRedisTemplate redis;

    public AtomicInventoryCache(StringRedisTemplate redis) { this.redis = redis; }

    public boolean tryReserve(String skuKey, int quantity) {
        Long remaining = redis.execute(DECREMENT_IF_ENOUGH, List.of(skuKey), String.valueOf(quantity));
        return remaining != null && remaining >= 0;
    }
}
package com.nexus.redis

import org.springframework.data.redis.core.StringRedisTemplate
import org.springframework.data.redis.core.script.DefaultRedisScript
import org.springframework.stereotype.Service

@Service
class AtomicInventoryCache(private val redis: StringRedisTemplate) {
    companion object {
        private val DECREMENT_IF_ENOUGH = DefaultRedisScript(
            """
            local current = tonumber(redis.call('GET', KEYS[1]) or '0')
            local req = tonumber(ARGV[1])
            if current < req then return -1 end
            return redis.call('DECRBY', KEYS[1], req)
            """.trimIndent(),
            Long::class.java
        )
    }

    fun tryReserve(skuKey: String, quantity: Int): Boolean {
        val remaining = redis.execute(DECREMENT_IF_ENOUGH, listOf(skuKey), quantity.toString())
        return remaining != null && remaining >= 0
    }
}

💡 Complete Production Reference Solution
Java 21/25 Implementation:
package com.nexus.redis;

import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;
import java.util.List;

public class SafeRedisConfig {
    public static RedisTemplate<String, Object> jsonTemplate(RedisConnectionFactory factory) {
        var template = new RedisTemplate<String, Object>();
        template.setConnectionFactory(factory);
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
        return template;
    }

    public static Long runAtomicScript(RedisTemplate<String, Object> template, DefaultRedisScript<Long> script, String key) {
        return template.execute(script, List.of(key));
    }
}
Kotlin 2.x Implementation:
package com.nexus.redis

import org.springframework.data.redis.connection.RedisConnectionFactory
import org.springframework.data.redis.core.RedisTemplate
import org.springframework.data.redis.core.script.DefaultRedisScript
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer
import org.springframework.data.redis.serializer.StringRedisSerializer

object SafeRedisConfig {
    fun jsonTemplate(factory: RedisConnectionFactory): RedisTemplate<String, Any> =
        RedisTemplate<String, Any>().apply {
            connectionFactory = factory
            keySerializer = StringRedisSerializer()
            valueSerializer = GenericJackson2JsonRedisSerializer()
        }

    fun runAtomicScript(template: RedisTemplate<String, Any>, script: DefaultRedisScript<Long>, key: String): Long? =
        template.execute(script, listOf(key))
}
Architectural Breakdown:

Human-readable JSON/String serialization eliminates rolling-deploy binary breakages, while atomic Lua scripts execute check-and-mutate logic on Redis without multi-pod race conditions.
