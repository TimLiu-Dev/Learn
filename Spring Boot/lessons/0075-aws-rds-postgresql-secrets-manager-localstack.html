Lesson 0075 • Stage 3 • Phase 17

AWS RDS PostgreSQL, RDS Proxy, Secrets Manager & LocalStack

Target: In AWS production, relational workloads run on Amazon RDS PostgreSQL 17 Multi-AZ behind RDS Proxy (connection multiplexing + sub-5-second failover recovery), with rotating credentials pulled dynamically from AWS Secrets Manager—and verified deterministically in CI via LocalStack Testcontainers.

📖 Primary Source Recommendation

Study the official authorities: Spring Cloud AWS Reference: Secrets Manager and Amazon RDS Proxy Architecture Guide.

1. The AWS RDS High-Availability Topology

[ Spring Boot Pods (EKS / ECS Fargate) ]
         │  (HikariCP max-lifetime: 15m-30m)
         ▼
[ AWS RDS Proxy ]  (Multiplexes warm connections & masks DNS failover stalls)
         │
         ├──► [ Primary DB (AZ-1) ] ──(Sync Replication)──► [ Standby DB (AZ-2) ]
         └──► [ Read Replica (AZ-3) ] (Async Replication for @Transactional(readOnly=true))

Why Tune HikariCP max-lifetime with Secrets Rotation & RDS Proxy? Always set spring.datasource.hikari.max-lifetime (e.g., 900000–1800000 ms = 15–30 minutes) shorter than firewall/proxy idle limits so stale sockets cycle gracefully and pick up rotated credentials cleanly.

2. Zero-Hardcoded-Passwords via Spring Cloud AWS Secrets Manager

With io.awspring.cloud:spring-cloud-aws-starter-secrets-manager, importing spring.config.import: "aws-secretsmanager:production/billing/rds" fetches JSON secret keys at startup via your pod's IAM Role (zero static AWS keys!) and binds ${db_username} / ${db_password} straight into your DataSource.

3. Production Implementation & LocalStack Integration Test

Production RDS Proxy + Secrets Manager Config & LocalStack Test 
# application-prod.yml
spring:
  config:
    import: "aws-secretsmanager:production/order-service/rds"
  datasource:
    url: jdbc:postgresql://order-proxy.proxy-abc123.us-east-1.rds.amazonaws.com:5432/orders_db
    username: ${db_username}
    password: ${db_password}
    hikari:
      maximum-pool-size: 20
      max-lifetime: 1800000

// LocalStack Testcontainers Verification (Zero Live AWS Account Needed!)
@SpringBootTest
@Testcontainers
class AwsSecretsIntegrationTest {

    @Container
    static LocalStackContainer localstack =
        new LocalStackContainer(DockerImageName.parse("localstack/localstack:3.8"))
            .withServices(LocalStackContainer.Service.SECRETSMANAGER);

    @Test
    void verifySecretRetrievalFromLocalStack() {
        SecretsManagerClient client = SecretsManagerClient.builder()
            .endpointOverride(localstack.getEndpointOverride(LocalStackContainer.Service.SECRETSMANAGER))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(localstack.getAccessKey(), localstack.getSecretKey())))
            .region(Region.of(localstack.getRegion()))
            .build();

        client.createSecret(CreateSecretRequest.builder()
            .name("production/order-service/rds")
            .secretString("{\"db_username\":\"postgres\",\"db_password\":\"vault_pass_99\"}")
            .build());

        String secretValue = client.getSecretValue(r -> r.secretId("production/order-service/rds")).secretString();
        assertThat(secretValue).contains("vault_pass_99");
    }
}

@SpringBootTest
@Testcontainers
class AwsSecretsIntegrationTest {
    companion object {
        @Container
        val localstack = LocalStackContainer(DockerImageName.parse("localstack/localstack:3.8"))
            .withServices(LocalStackContainer.Service.SECRETSMANAGER)
    }

    @Test
    fun verifySecretRetrievalFromLocalStack() {
        val client = SecretsManagerClient.builder()
            .endpointOverride(localstack.getEndpointOverride(LocalStackContainer.Service.SECRETSMANAGER))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(localstack.accessKey, localstack.secretKey)))
            .region(Region.of(localstack.region))
            .build()

        client.createSecret(CreateSecretRequest.builder()
            .name("production/order-service/rds")
            .secretString("""{"db_username":"postgres","db_password":"vault_pass_99"}""")
            .build())

        val value = client.getSecretValue { it.secretId("production/order-service/rds") }.secretString()
        assertThat(value).contains("vault_pass_99")
    }
}
