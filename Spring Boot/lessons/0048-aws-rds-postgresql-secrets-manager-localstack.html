AWS RDS PostgreSQL, Secrets Manager & LocalStack Testing

Target: Running relational databases in cloud production requires far more than spinning up a simple single-node container. In Amazon Web Services (AWS), production workloads rely on AWS RDS PostgreSQL with Multi-AZ automated failover, read replicas for query offloading, and AWS RDS Proxy to manage connection pooling during serverless spikes. Furthermore, hardcoded passwords in configuration files are strictly forbidden by enterprise compliance frameworks (SOC2, PCI-DSS): database credentials must be rotated dynamically via AWS Secrets Manager. In this lesson, we configure Spring Boot for AWS RDS, integrate AWS Secrets Manager, and test cloud services locally using LocalStack.

📖 Primary Source Recommendation

Study the official authority: AWS RDS Documentation: Using Amazon RDS Proxy & Spring Cloud AWS Reference Documentation (Secrets Manager).. Ground your learning in primary architecture rather than secondary summaries.

💡 Why This Matters in Production

A database password rotation in production shouldn't require restarting application pods or causing downtime. By integrating Spring Cloud AWS with AWS Secrets Manager, Spring Boot automatically reloads rotated database credentials without interrupting serving traffic.

Key Architectural Takeaways

  • AWS RDS Multi-AZ synchronously replicates data to a standby instance in a different Availability Zone (AZ) for automated failover with zero data loss.
  • RDS Proxy sits between Spring Boot and RDS to pool connections and reduce failover recovery time from minutes to under 5 seconds.
  • Spring Cloud AWS Secrets Manager integration loads secrets transparently into the Spring Environment using 'spring.config.import=aws-secretsmanager:/path/to/secret'.
  • Automatic Credential Rotation: AWS Secrets Manager uses Lambda functions to rotate passwords every 30 days without manual operator intervention.
  • LocalStack provides a fully functional local AWS cloud stack (S3, Secrets Manager, SQS, KMS) running in Docker for deterministic integration testing.
  • IAM Database Authentication: Allows Spring Boot to connect to RDS using short-lived IAM authentication tokens instead of static passwords.

1. The AWS RDS High-Availability Architecture

         │                                                      (Auto-failover target)

2. Spring Cloud AWS Secrets Manager

Add the dependency io.awspring.cloud:spring-cloud-aws-starter-secrets-manager. In application.yml: 

spring:
  config:
    import: "aws-secretsmanager:production/order-service/database"

Spring Cloud AWS queries AWS Secrets Manager during bootstrap, decodes the JSON payload, and injects username and password directly into Spring's property environment.

3. Local Testing with LocalStack

Never test AWS integrations against live cloud resources in developer environments—it costs money and causes race conditions. Run LocalStack in Testcontainers: 

LocalStackContainer localstack = 
    new LocalStackContainer(DockerImageName.parse("localstack/localstack:3.0"))
        .withServices(LocalStackContainer.Service.SECRETSMANAGER, LocalStackContainer.Service.S3);

// Java Testcontainers integration with LocalStack
package com.example.aws;

import org.junit.jupiter.api.BeforeAll;
import org.junit.jupiter.api.Test;
import org.springframework.boot.test.context.SpringBootTest;
import org.testcontainers.containers.localstack.LocalStackContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;
import org.testcontainers.utility.DockerImageName;
import software.amazon.awssdk.auth.credentials.AwsBasicCredentials;
import software.amazon.awssdk.auth.credentials.StaticCredentialsProvider;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.services.secretsmanager.SecretsManagerClient;
import software.amazon.awssdk.services.secretsmanager.model.CreateSecretRequest;

import static org.assertj.core.api.Assertions.assertThat;

@SpringBootTest
@Testcontainers
class AwsSecretsIntegrationTest {

    @Container
    static LocalStackContainer localstack = 
        new LocalStackContainer(DockerImageName.parse("localstack/localstack:3.0"))
            .withServices(LocalStackContainer.Service.SECRETSMANAGER);

    @Test
    void verifySecretRetrievalFromLocalStack() {
        SecretsManagerClient client = SecretsManagerClient.builder()
            .endpointOverride(localstack.getEndpointOverride(LocalStackContainer.Service.SECRETSMANAGER))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(localstack.getAccessKey(), localstack.getSecretKey())))
            .region(Region.of(localstack.getRegion()))
            .build();

        client.createSecret(CreateSecretRequest.builder()
            .name("production/order-service/rds")
            .secretString("{"db_username":"postgres","db_password":"vault_pass_99"}")
            .build());

        String secretValue = client.getSecretValue(r -> r.secretId("production/order-service/rds")).secretString();
        assertThat(secretValue).contains("vault_pass_99");
    }
}

package com.example.aws

import org.assertj.core.api.Assertions.assertThat
import org.junit.jupiter.api.Test
import org.springframework.boot.test.context.SpringBootTest
import org.testcontainers.containers.localstack.LocalStackContainer
import org.testcontainers.junit.jupiter.Container
import org.testcontainers.junit.jupiter.Testcontainers
import org.testcontainers.utility.DockerImageName
import software.amazon.awssdk.auth.credentials.AwsBasicCredentials
import software.amazon.awssdk.auth.credentials.StaticCredentialsProvider
import software.amazon.awssdk.regions.Region
import software.amazon.awssdk.services.secretsmanager.SecretsManagerClient
import software.amazon.awssdk.services.secretsmanager.model.CreateSecretRequest

@SpringBootTest
@Testcontainers
class AwsSecretsIntegrationTest {

    companion object {
        @Container
        val localstack: LocalStackContainer = 
            LocalStackContainer(DockerImageName.parse("localstack/localstack:3.0"))
                .withServices(LocalStackContainer.Service.SECRETSMANAGER)
    }

    @Test
    fun verifySecretRetrievalFromLocalStack() {
        val client = SecretsManagerClient.builder()
            .endpointOverride(localstack.getEndpointOverride(LocalStackContainer.Service.SECRETSMANAGER))
            .credentialsProvider(StaticCredentialsProvider.create(
                AwsBasicCredentials.create(localstack.accessKey, localstack.secretKey)))
            .region(Region.of(localstack.region))
            .build()

        client.createSecret(CreateSecretRequest.builder()
            .name("production/order-service/rds")
            .secretString("{"db_username":"postgres","db_password":"vault_pass_99"}")
            .build())

        val value = client.getSecretValue { it.secretId("production/order-service/rds") }.secretString()
        assertThat(value).contains("vault_pass_99")
    }
}
