AWS S3 Presigned URLs: The Scalable Mobile Upload Pattern

Target: A classic architectural anti-pattern in cloud backends is streaming large file uploads (user avatars, PDF invoices, high-resolution videos) directly through Spring Boot application servers. When 1,000 mobile clients upload 50MB video files through your REST API, your Tomcat threads remain pinned for minutes during slow cellular uploads, consuming gigabytes of heap memory and suffocating backend databases. The cloud-native architectural pattern delegates the heavy upload directly to Amazon S3 using Presigned URLs: Spring Boot verifies permissions and generates a signed URL in 5ms, and the client streams bytes directly into S3.

Study the official authority: AWS SDK for Java 2.x Documentation: Working with Amazon S3 Presigned URLs & S3 Security Best Practices.. Ground your learning in primary architecture rather than secondary summaries.

💡 Why This Matters in Production

Routing multi-megabyte binary payloads through your compute layer wastes expensive bandwidth and saturates CPU/heap memory. Generating cryptographic Presigned URLs decouples file streaming from your compute cluster, allowing your backend to handle millions of uploads with minimal CPU and memory footprints.

Key Architectural Takeaways

  • Anti-Pattern: Streaming large file payloads through Spring Boot Tomcat threads exhausts server threads, memory buffers, and bandwidth.
  • Presigned URLs: Spring Boot uses the AWS SDK v2 ('S3Presigner') to generate a cryptographically signed URL valid for a short window (e.g. 10 minutes).
  • The client uploads the file directly to Amazon S3 via HTTP PUT: zero bytes pass through the Spring Boot application cluster.
  • Security: The presigned URL restricts the upload to a specific S3 bucket key, HTTP method (PUT), and maximum content length.
  • Event-Driven Processing: Once S3 receives the complete file, it emits an S3 ObjectCreated event notification to Amazon SQS or Kafka to trigger asynchronous virus scanning and thumbnail generation.
  • Use S3 Server-Side Encryption (SSE-S3 or SSE-KMS) and enforce CORS configuration on the bucket.

2. Cryptographic Security with AWS SDK v2

The S3Presigner uses AWS Signature Version 4 (SigV4) to sign the bucket, object key, HTTP verb, and expiration timestamp using the backend's IAM credentials. The client never receives AWS secret access keys—only a temporary single-use signature.

AWS S3 Presigned URLs: The Scalable Mobile Upload Pattern 
package com.example.aws;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.bind.annotation.*;
import software.amazon.awssdk.auth.credentials.DefaultCredentialsProvider;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.services.s3.model.PutObjectRequest;
import software.amazon.awssdk.services.s3.presigner.S3Presigner;
import software.amazon.awssdk.services.s3.presigner.model.PresignedPutObjectRequest;
import software.amazon.awssdk.services.s3.presigner.model.PutObjectPresignRequest;

import java.time.Duration;
import java.util.Map;
import java.util.UUID;

record UploadRequest(String originalFilename, String contentType, long fileSize) {}
record PresignedUrlResponse(UUID fileId, String uploadUrl, long expiresInMinutes) {}

@Service
class S3PresignedUploadService {
    private final S3Presigner s3Presigner;
    private final String bucketName;

    public S3PresignedUploadService(@Value("${aws.s3.bucket-name:my-app-uploads}") String bucketName) {
        this.bucketName = bucketName;
        // Uses IAM Instance Profile or AWS environment credentials automatically
        this.s3Presigner = S3Presigner.builder()
            .region(Region.US_EAST_1)
            .credentialsProvider(DefaultCredentialsProvider.create())
            .build();
    }

    public PresignedUrlResponse generateUploadUrl(UploadRequest request) {
        UUID fileId = UUID.randomUUID();
        String s3Key = "uploads/" + fileId + "-" + sanitize(request.originalFilename());

        PutObjectRequest objectRequest = PutObjectRequest.builder()
            .bucket(bucketName)
            .key(s3Key)
            .contentType(request.contentType())
            .build();

        PutObjectPresignRequest presignRequest = PutObjectPresignRequest.builder()
            .signatureDuration(Duration.ofMinutes(15)) // URL expires in 15 minutes
            .putObjectRequest(objectRequest)
            .build();

        PresignedPutObjectRequest presigned = s3Presigner.presignPutObject(presignRequest);

        return new PresignedUrlResponse(fileId, presigned.url().toString(), 15);
    }

    private String sanitize(String input) {
        return input.replaceAll("[^a-zA-Z0-9.-]", "_");
    }
}

@RestController
@RequestMapping("/api/uploads")
class UploadController {
    private final S3PresignedUploadService uploadService;

    public UploadController(S3PresignedUploadService uploadService) {
        this.uploadService = uploadService;
    }

    @PostMapping("/presigned-url")
    public PresignedUrlResponse getPresignedUrl(@RequestBody UploadRequest request) {
        return uploadService.generateUploadUrl(request);
    }
}

data class PresignedUrlResponse(val fileId: UUID, val uploadUrl: String, val expiresInMinutes: Long)

@Service
class S3PresignedUploadService(
    @Value("\${aws.s3.bucket-name:my-app-uploads}") private val bucketName: String
) {
    private val s3Presigner: S3Presigner = S3Presigner.builder()
        .region(Region.US_EAST_1)
        .credentialsProvider(DefaultCredentialsProvider.create())
        .build()

    fun generateUploadUrl(request: UploadRequest): PresignedUrlResponse {
        val fileId = UUID.randomUUID()
        val s3Key = "uploads/$fileId-\${request.originalFilename.replace(Regex("[^a-zA-Z0-9.-]"), "_")}"

        val objectRequest = PutObjectRequest.builder()
            .bucket(bucketName)
            .key(s3Key)
            .contentType(request.contentType)
            .build()

        val presignRequest = PutObjectPresignRequest.builder()
            .signatureDuration(Duration.ofMinutes(15))
            .putObjectRequest(objectRequest)
            .build()

        val presigned = s3Presigner.presignPutObject(presignRequest)
        return PresignedUrlResponse(fileId, presigned.url().toString(), 15)
    }
}

package com.example.aws;

import software.amazon.awssdk.services.s3.model.PutObjectRequest;
import software.amazon.awssdk.services.s3.presigner.model.PutObjectPresignRequest;
import java.time.Duration;

public class S3PresignHelper {
    public static PutObjectPresignRequest create10MinPresignRequest(PutObjectRequest putObjectRequest) {
        return PutObjectPresignRequest.builder()
            .signatureDuration(Duration.ofMinutes(10))
            .putObjectRequest(putObjectRequest)
            .build();
    }
}

package com.example.aws
