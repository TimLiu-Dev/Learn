1. Securing Inbound Webhooks: Raw Bytes, HMAC-SHA256 & Constant-Time Comparison

When a user completes a mobile Apple Pay or Google Pay checkout, Stripe or Adyen notifies your backend asynchronously via an HTTP POST /webhooks/payments request. Since this endpoint is reachable on the public internet without a user's JWT, attackers will try to POST fake "payment_intent.succeeded" JSON payloads! Senior engineers enforce four strict defenses:

  • Bind the Raw byte[] or String Payload: Never bind the webhook request directly to a Java Record/DTO before verifying the signature—Jackson re-serializing an object alters whitespace and key ordering, invalidating the cryptographic hash!
  • Replay Window Enforcement: Verify the signed timestamp header (e.g., t=1732150000) is within 5 minutes (300 seconds) of Instant.now(), then compute HMAC-SHA256(secret, timestamp + "." + rawPayload).
  • Constant-Time Comparison (MessageDigest.isEqual): Never compare signatures with String.equals(), which short-circuits on the first mismatched byte and leaks signature bytes via nanosecond timing side-channels! Always use MessageDigest.isEqual(expectedBytes, providedBytes).
  • Event Idempotency + Fast 200 OK: Deduplicate the provider's event_id in Redis/PostgreSQL because webhook providers retry on network timeouts.

2. Testing Outbound RestClient with WireMock

Unit-mocking a Java interface with Mockito completely skips HTTP serialization, header propagation, status-code error handlers, and timeout configuration. With @EnableWireMock (from wiremock-spring-boot), WireMock spins up a real local HTTP server on a dynamic port and injects ${wiremock.server.baseUrl} into your Spring properties so you can verify exact wire-level JSON, retry backoff, and 503 Service Unavailable circuit-breaker fallbacks.

Constant-Time HMAC-SHA256 Webhook Verifier & WireMock Integration Test 
package com.nexus.webhooks;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.time.Instant;
import java.util.HexFormat;

public class WebhookSignatureVerifier {
    private static final long MAX_AGE_SECONDS = 300L;

    public static boolean verifyHmac(String secret, String rawBody, long timestampEpochSec, String headerHexSig) {
        long age = Math.abs(Instant.now().getEpochSecond() - timestampEpochSec);
        if (age > MAX_AGE_SECONDS) {
            return false; // Reject replay attack outside 5-minute window
        }
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(secret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            String signedPayload = timestampEpochSec + "." + rawBody;
            byte[] computedHex = HexFormat.of().formatHex(
                mac.doFinal(signedPayload.getBytes(StandardCharsets.UTF_8))
            ).getBytes(StandardCharsets.UTF_8);
            byte[] providedHex = headerHexSig.getBytes(StandardCharsets.UTF_8);

            // Constant-time comparison prevents timing side-channel attacks!
            return MessageDigest.isEqual(computedHex, providedHex);
        } catch (Exception e) {
            return false;
        }
    }
}
package com.nexus.webhooks

import java.nio.charset.StandardCharsets
import java.security.MessageDigest
import java.time.Instant
import java.util.HexFormat
import javax.crypto.Mac
import javax.crypto.spec.SecretKeySpec
import kotlin.math.abs

object WebhookSignatureVerifier {
    private const val MAX_AGE_SECONDS = 300L

    fun verifyHmac(secret: String, rawBody: String, timestampEpochSec: Long, headerHexSig: String): Boolean {
        val age = abs(Instant.now().epochSecond - timestampEpochSec)
        if (age > MAX_AGE_SECONDS) return false

        return runCatching {
            val mac = Mac.getInstance("HmacSHA256").apply {
                init(SecretKeySpec(secret.toByteArray(StandardCharsets.UTF_8), "HmacSHA256"))
            }
            val signedPayload = "$timestampEpochSec.$rawBody"
            val computedHex = HexFormat.of().formatHex(
                mac.doFinal(signedPayload.toByteArray(StandardCharsets.UTF_8))
            ).toByteArray(StandardCharsets.UTF_8)
            val providedHex = headerHexSig.toByteArray(StandardCharsets.UTF_8)

            MessageDigest.isEqual(computedHex, providedHex)
        }.getOrDefault(false)
    }
}

💡 Complete Production Reference Solution
Java 21/25 Implementation:
package com.nexus.webhooks;

import java.security.MessageDigest;

public class WebhookGuard {
    public static boolean isValid(long ageSeconds, byte[] expectedSig, byte[] providedSig) {
        if (ageSeconds < 0 || ageSeconds > 300) {
            return false;
        }
        return MessageDigest.isEqual(expectedSig, providedSig);
    }
}
Kotlin 2.x Implementation:
package com.nexus.webhooks

import java.security.MessageDigest

object WebhookGuard {
    fun isValid(ageSeconds: Long, expectedSig: ByteArray, providedSig: ByteArray): Boolean {
        if (ageSeconds < 0 || ageSeconds > 300) {
            return false
        }
        return MessageDigest.isEqual(expectedSig, providedSig)
    }
}
Architectural Breakdown:

Combining a strict 300-second timestamp window with constant-time MessageDigest.isEqual blocks both captured replay requests and timing side-channel signature forgery.
