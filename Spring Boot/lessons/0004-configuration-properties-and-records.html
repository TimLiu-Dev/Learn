Lesson 0004 • Phase 1

Type-Safe Configuration Properties, Java Records & Validation

Target: Replace brittle @Value annotations with immutable, strongly typed Java 21 Records and Kotlin data classes bound to application.yml, validated at startup with Jakarta Validation.

📖 Primary Source Recommendation

Study the official authority: Spring Boot Reference: Type-safe Configuration Properties. Ground your learning in primary architecture rather than secondary summaries.

1. Why Mid-Level Engineers Avoid `@Value`

Junior developers sprinkle @Value("${aws.s3.bucket}") private String bucket; across services. This causes severe defects:

  • Typos like "${aws.s3.buckett}" are not caught until runtime when the bean initializes.
  • It scatters configuration keys across dozens of files instead of centralizing them.
  • No validation: if an engineer provides an invalid port -1 or blank URL, the app starts and fails later in production.

2. Modern Standard: Java 21 Records & `@ConfigurationProperties`

Spring Boot 3 natively binds configuration properties into immutable Java Records and Kotlin data classes:

Validated Configuration Properties Record 
package com.example.ecommerce.config;

import jakarta.validation.constraints.*;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.validation.annotation.Validated;
import java.time.Duration;

@Validated
@ConfigurationProperties(prefix = "storage.s3")
public record S3Properties(
    @NotBlank String bucket,
    @NotBlank String region,
    @NotNull Duration uploadTimeout,
    @Min(1) @Max(100) int maxConcurrentUploads
) {}
package com.example.ecommerce.config

import jakarta.validation.constraints.*
import org.springframework.boot.context.properties.ConfigurationProperties
import org.springframework.validation.annotation.Validated
import java.time.Duration

@Validated
@ConfigurationProperties(prefix = "storage.s3")
data class S3Properties(
    @field:NotBlank val bucket: String,
    @field:NotBlank val region: String,
    @field:NotNull val uploadTimeout: Duration,
    @field:Min(1) @field:Max(100) val maxConcurrentUploads: Int
)

3. Matching `application.yml`

storage: s3: bucket: "nexus-production-media" region: "us-east-1" upload-timeout: 30s # Automatically parsed into java.time.Duration! max-concurrent-uploads: 25

💡 Complete Production Reference Solution
Java 21 Implementation:

import jakarta.validation.constraints.*;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.validation.annotation.Validated;

@Validated
@ConfigurationProperties(prefix = "storage.s3")

    @NotBlank String bucket,
    @Min(1) int maxConnections
) {}
Kotlin 2.x Implementation:
package com.example.config

import jakarta.validation.constraints.*
import org.springframework.boot.context.properties.ConfigurationProperties
import org.springframework.validation.annotation.Validated

@Validated
@ConfigurationProperties(prefix = "storage.s3")
data class S3StorageProperties(
    @field:NotBlank val bucket: String,
    @field:Min(1) val maxConnections: Int
)
Architectural Breakdown:

By binding properties into a validated Java 21 Record, the entire configuration is immutable and guaranteed non-null, preventing runtime NullPointerExceptions in your services.
