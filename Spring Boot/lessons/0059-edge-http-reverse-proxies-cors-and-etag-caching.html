Edge HTTP: Reverse Proxies (X-Forwarded-*), CORS & ETag Caching

Target: In production, mobile and web clients rarely connect straight to Tomcat on port 8080—requests pass through a Reverse Proxy / Load Balancer (Nginx, Cloudflare, AWS ALB) that terminates TLS. Without explicit proxy header handling, Spring Boot thinks every user has the load balancer's private IP (breaking Redis rate limiters!) and generates broken http:// redirect links. Meanwhile, Android's OkHttp caches responses automatically if your backend emits proper Cache-Control and ETag headers—cutting bandwidth and DB load dramatically.

📖 Primary Source Recommendation

Study the official authorities: Spring Boot Reference: Running Behind a Front-End Proxy Server and Spring MVC HTTP Caching (ETag & Cache-Control).

💡 Android Mental Model Bridge

On Android, OkHttp's Cache automatically sends If-None-Match: "abc123" when a cached response expires and skips parsing JSON if the server returns 304 Not Modified. On the backend, returning ResponseEntity.ok().cacheControl(...).eTag(version).body(dto) unlocks that exact mobile optimization with two lines of code.

Key Architectural Takeaways

  • Reverse Proxy Forwarding (server.forward-headers-strategy=framework): Tells Spring Boot to trust Forwarded / X-Forwarded-For / X-Forwarded-Proto headers from your edge load balancer (Nginx/ALB) so request.getRemoteAddr() and OAuth2 redirect URIs resolve accurately.
  • Conditional HTTP Caching (ETag + 304 Not Modified): Include CacheControl.maxAge(60, TimeUnit.SECONDS).cachePublic() and .eTag(String.valueOf(product.version())); Spring automatically checks If-None-Match and returns an empty 304 body on cache hits.
  • Explicit Spring Security CORS: Configure a strict CorsConfigurationSource bean with explicit origin allow-lists (never wildcard * paired with allowCredentials(true), which browsers reject!).

Proxy Headers, ETag Controller & Strict CORS Bean 
# application.yml — Essential behind Nginx / AWS ALB / Cloudflare
server:
  forward-headers-strategy: framework   # Or 'native' for Tomcat RemoteIpValve

---
@RestController
@RequestMapping("/api/v1/products")
public class ProductCatalogController {

    @GetMapping("/{id}")
    public ResponseEntity<ProductDto> getProduct(@PathVariable UUID id, WebRequest request) {
        ProductDto product = catalogService.findById(id);
        String eTag = "\"" + product.version() + "\"";

        if (request.checkNotModified(eTag)) {
            return null; // Spring automatically emits 304 Not Modified with empty body!
        }

        return ResponseEntity.ok()
            .cacheControl(CacheControl.maxAge(60, TimeUnit.SECONDS).cachePublic())
            .eTag(eTag)
            .body(product);
    }
}

@Bean
CorsConfigurationSource corsConfigurationSource() {
    CorsConfiguration cfg = new CorsConfiguration();
    cfg.setAllowedOrigins(List.of("https://app.nexuscommerce.com"));
    cfg.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE"));
    cfg.setAllowedHeaders(List.of("Authorization", "Content-Type", "Idempotency-Key"));
    cfg.setAllowCredentials(true);
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/api/**", cfg);
    return source;
}

@RestController
@RequestMapping("/api/v1/products")
class ProductCatalogController(private val catalogService: CatalogService) {

    @GetMapping("/{id}")
    fun getProduct(@PathVariable id: UUID, request: WebRequest): ResponseEntity<ProductDto>? {
        val product = catalogService.findById(id)
        val eTag = "\"${product.version}\""

        if (request.checkNotModified(eTag)) {
            return null // Emits HTTP 304 Not Modified cleanly
        }

        return ResponseEntity.ok()
            .cacheControl(CacheControl.maxAge(60, TimeUnit.SECONDS).cachePublic())
            .eTag(eTag)
            .body(product)
    }
}

@Bean
fun corsConfigurationSource(): CorsConfigurationSource {
    val cfg = CorsConfiguration().apply {
        allowedOrigins = listOf("https://app.nexuscommerce.com")
        allowedMethods = listOf("GET", "POST", "PUT", "DELETE")
        allowedHeaders = listOf("Authorization", "Content-Type", "Idempotency-Key")
        allowCredentials = true
    }
    return UrlBasedCorsConfigurationSource().apply {
        registerCorsConfiguration("/api/**", cfg)
    }
}

// server.forward-headers-strategy=framework
public ResponseEntity<String> getCatalogItem(String version, WebRequest request) {
