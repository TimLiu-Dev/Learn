Distributed Tracing with Micrometer & OpenTelemetry (W3C traceparent)

Target: When a customer checkout request traverses an API Gateway, an Order Service, a Payment Gateway, a Kafka topic, and an Inventory Worker, identifying why a request took 4.2 seconds is impossible using isolated logs. Distributed Tracing assigns a globally unique Trace ID to the initial HTTP request and propagates it across every network hop, REST call, and Kafka message header. In modern Spring Boot 3, Micrometer Tracing with OpenTelemetry (OTel) is the industry standard for W3C Trace Context propagation, automatic Slf4j MDC log injection, and span visualization in Grafana Tempo, Jaeger, and Datadog.

📖 Primary Source Recommendation

Study the official authority: W3C Recommendation: Trace Context (W3C Recommendation 23 November 2021) & Micrometer Tracing Official Documentation.. Ground your learning in primary architecture rather than secondary summaries.

💡 Why This Matters in Production

Without distributed tracing, diagnosing multi-service latency bottlenecks requires correlating timestamps across desynchronized servers. With W3C 'traceparent' headers, you can click on an error log in Kibana, copy the 'traceId', and open a complete flame graph visualizing every database query and downstream network hop down to the exact millisecond.

Key Architectural Takeaways

  • W3C Trace Context standardizes the 'traceparent' HTTP header: '00-{trace_id}-{parent_id}-{trace_flags}' (e.g. '00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01').
  • A Trace represents the entire end-to-end journey of a request; a Span represents a single unit of contiguous work (e.g. an HTTP handler execution or SQL query).
  • Micrometer Tracing automatically injects '[traceId, spanId]' into Slf4j's Mapped Diagnostic Context (MDC), ensuring every log line includes the trace context.
  • Kafka message propagation: Micrometer injects the W3C traceparent directly into Kafka record headers, maintaining end-to-end trace correlation through asynchronous brokers.
  • Configure sampling rates ('management.tracing.sampling.probability=0.1') in high-throughput environments to prevent trace storage exhaustion.
  • Use '@NewSpan' and '@SpanTag' to create custom business spans around critical code blocks.

1. The W3C Traceparent Header Format

The W3C Trace Context specification defines the standard header: 

traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
              │  └──────────────┬───────────────┘ └──────┬───────┘ └─┬─┘
              │                 │                        │           └── Flags (01 = sampled)
              │                 │                        └── Parent Span ID (16 hex chars)
              │                 └── Trace ID (32 hex characters)
              └── Version (00)

When the Order Service invokes the Payment Service via RestClient, Spring's Micrometer bridge automatically serializes the active Span ID into this header.

2. MDC Log Correlation

Micrometer Tracing integrates with Slf4j MDC out of the box. By configuring your Logback pattern: 

logging.pattern.level=%5p [${spring.application.name:},%X{traceId:-},%X{spanId:-}]

Every log line automatically outputs: 

INFO [order-service,4bf92f3577b34da6a3ce929d0e0e4736,00f067aa0ba902b7] Placing order for user 102

Distributed Tracing with Micrometer & OpenTelemetry (W3C traceparent) 
package com.example.tracing;

import io.micrometer.tracing.Span;
import io.micrometer.tracing.Tracer;
import io.micrometer.tracing.annotation.NewSpan;
import io.micrometer.tracing.annotation.SpanTag;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.client.RestClient;

@Service
class FraudInspectionService {
    private static final Logger log = LoggerFactory.getLogger(FraudInspectionService.class);
    private final Tracer tracer;

    public FraudInspectionService(Tracer tracer) {
        this.tracer = tracer;
    }

    // Creates a new child span in the trace tree
    @NewSpan("fraud-risk-score-calculation")
    public double calculateRiskScore(@SpanTag("customer.id") String customerId) {
        log.info("Calculating fraud score for customer: {}", customerId);
        // Slf4j MDC automatically includes traceId and spanId!
        
        // Manual Span creation for fine-grained sub-operations:
        Span manualSpan = tracer.nextSpan().name("external-ml-model-inference").start();
        try (Tracer.SpanInScope ws = tracer.withSpan(manualSpan)) {
            simulateMlInference();
            manualSpan.tag("model.version", "v2.4");
            return 0.12; // Low risk
        } finally {
            manualSpan.end(); // Span duration recorded
        }
    }

    private void simulateMlInference() {
        try {
            Thread.sleep(50);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

@RestController
class CheckoutController {
    private final FraudInspectionService fraudService;
    private final RestClient restClient;

    public CheckoutController(FraudInspectionService fraudService, RestClient.Builder builder) {
        this.fraudService = fraudService;
        // RestClient configured with Micrometer Tracing auto-propagates W3C headers!
        this.restClient = builder.baseUrl("https://payment.internal.net").build();
    }

    @GetMapping("/api/checkout")
    public String checkout(@RequestParam String customerId) {
        double risk = fraudService.calculateRiskScore(customerId);
        return "Checkout processed with risk score: " + risk;
    }
}
package com.example.tracing

import io.micrometer.tracing.Tracer
import io.micrometer.tracing.annotation.NewSpan
import io.micrometer.tracing.annotation.SpanTag
import org.slf4j.LoggerFactory
import org.springframework.stereotype.Service
import org.springframework.web.bind.annotation.GetMapping
import org.springframework.web.bind.annotation.RequestParam
import org.springframework.web.bind.annotation.RestController

@Service
class FraudInspectionService(private val tracer: Tracer) {
    private val log = LoggerFactory.getLogger(FraudInspectionService::class.java)

    @NewSpan("fraud-risk-score-calculation")
    fun calculateRiskScore(@SpanTag("customer.id") customerId: String): Double {
        log.info("Calculating fraud score for customer: $customerId")

        val childSpan = tracer.nextSpan().name("external-ml-model-inference").start()
        try {
            tracer.withSpan(childSpan).use {
                Thread.sleep(50)
                childSpan.tag("model.version", "v2.4")
                return 0.12
            }
        } finally {
            childSpan.end()
        }
    }
}

@RestController
class CheckoutController(private val fraudService: FraudInspectionService) {
    @GetMapping("/api/checkout")
    fun checkout(@RequestParam customerId: String): String {
        val score = fraudService.calculateRiskScore(customerId)
        return "Checkout processed with risk score: $score"
    }
}

Java 21 Implementation:
package com.example.tracing;

import io.micrometer.tracing.Span;
import io.micrometer.tracing.Tracer;

public class CryptoHasher {
    private final Tracer tracer;

    public CryptoHasher(Tracer tracer) {
        this.tracer = tracer;
    }

    public String hashData(String input) {
        Span span = tracer.nextSpan().name("crypto-hash").start();
        try {
            span.tag("algorithm", "SHA-256");
            return "hashed-" + input;
        } finally {
            span.end();
        }
    }
}
