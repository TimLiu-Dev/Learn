Outbound HTTP Clients: RestClient & Declarative HTTP Interfaces

Target: Learn how Spring Boot calls external third-party APIs (Stripe, Twilio, microservices). Master Spring Boot 3.2+ RestClient, declarative @HttpExchange interfaces (the backend twin of Retrofit!), and timeout resilience.

📖 Primary Source Recommendation

Study the official authority: Spring Framework Reference: REST Clients & HTTP Interfaces. Ground your learning in primary architecture rather than secondary summaries.

1. The Evolution of Calling External APIs in Spring

Over the years, Spring provided several HTTP client tools:

  • RestTemplate: The legacy synchronous client (created in 2009). Functional, but verbose and lacks modern fluent API design.
  • WebClient: Introduced in Spring 5 for reactive programming. Required bringing in the heavy spring-boot-starter-webflux dependency.
  • RestClient (Spring Boot 3.2+): The modern, fluent synchronous HTTP client that combines the simplicity of RestTemplate with the fluent API of WebClient and pairs with Java 21 Virtual Threads!
🤖 Android Mental Model: Retrofit on the Backend

In Spring 6+, you can write Declarative HTTP Interfaces using @HttpExchange. You write an interface with annotations, and Spring dynamically generates the HTTP client implementation at startup! This is literally Retrofit for the backend!

2. Declarative HTTP Interfaces (`@HttpExchange`)

Declarative HTTP Interface (Retrofit Twin) 
package com.example.ecommerce.payment;

import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.service.annotation.*;

@HttpExchange("/v1/payments")
public interface PaymentGatewayClient {

    @PostExchange
    PaymentResponse chargeCreditCard(@RequestBody PaymentRequest request);

    @GetExchange("/{transactionId}")
    PaymentStatus getTransactionStatus(@PathVariable String transactionId);
}

3. Registering the Client Bean with Timeouts

Crucial Senior Rule: Never make external HTTP calls without strict connect & read timeouts!

Configuring RestClient Adapter with Timeouts 
package com.example.ecommerce.payment;

import org.springframework.context.annotation.*;
import org.springframework.http.client.SimpleClientHttpRequestFactory;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.support.RestClientAdapter;
import org.springframework.web.service.invoker.HttpServiceProxyFactory;
import java.time.Duration;

@Configuration
public class PaymentClientConfig {

    @Bean
    public PaymentGatewayClient paymentGatewayClient() {
        var requestFactory = new SimpleClientHttpRequestFactory();
        requestFactory.setConnectTimeout(Duration.ofSeconds(3));
        requestFactory.setReadTimeout(Duration.ofSeconds(5));

        RestClient restClient = RestClient.builder()
            .baseUrl("https://api.stripe.example.com")
            .requestFactory(requestFactory)
            .defaultHeader("Authorization", "Bearer sk_test_secret_key")
            .build();

        var adapter = RestClientAdapter.create(restClient);
        var factory = HttpServiceProxyFactory.builderFor(adapter).build();
        return factory.createClient(PaymentGatewayClient.class);
    }
}

💡 Complete Production Reference Solution
Java 21 Implementation:
package com.example.client;

import org.springframework.http.client.SimpleClientHttpRequestFactory;
import org.springframework.web.client.RestClient;
import java.time.Duration;

public class RestClientFactory {
    public static RestClient createClient(String baseUrl, int timeoutSeconds) {
        var factory = new SimpleClientHttpRequestFactory();
        factory.setConnectTimeout(Duration.ofSeconds(timeoutSeconds));
        factory.setReadTimeout(Duration.ofSeconds(timeoutSeconds));

        return RestClient.builder()
            .baseUrl(baseUrl)
            .requestFactory(factory)
            .build();
    }
}
Kotlin 2.x Implementation:
package com.example.client

import org.springframework.http.client.SimpleClientHttpRequestFactory
import org.springframework.web.client.RestClient
import java.time.Duration

object RestClientFactory {
    fun createClient(baseUrl: String, timeoutSeconds: Int): RestClient {
        val factory = SimpleClientHttpRequestFactory().apply {
            setConnectTimeout(Duration.ofSeconds(timeoutSeconds.toLong()))
            setReadTimeout(Duration.ofSeconds(timeoutSeconds.toLong()))
        }

        return RestClient.builder()
            .baseUrl(baseUrl)
            .requestFactory(factory)
            .build()
    }
}
Architectural Breakdown:

Every production outbound client MUST configure connect and read timeouts. RestClient allows passing a configured ClientHttpRequestFactory cleanly.
