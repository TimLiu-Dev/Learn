Application Security Hardening: Argon2/BCrypt & OWASP API Top 10

Target: Phase 8 gave you JWTs, OAuth2, RBAC, and mTLS. Yet two classic application-level flaws still cause most real-world breaches: storing passwords or API keys with fast hashes (MD5/SHA-256 instead of slow, memory-hard Argon2id / BCrypt), and falling into OWASP API Top 10 traps—especially BOLA/IDOR (Broken Object Level Authorization), Mass Assignment (binding JPA entities directly in controllers), and SSRF (Server-Side Request Forgery).

📖 Primary Source Recommendation

Study the official authorities: OWASP API Security Top 10 and Spring Security Reference: Password Storage (Argon2 & DelegatingPasswordEncoder).

💡 Why This Matters in Production

Modern GPUs crack unsalted or fast SHA-256 hashes at tens of billions of guesses per second. Using Spring Security's PasswordEncoderFactories.createDelegatingPasswordEncoder() (backed by Argon2id or BCrypt) enforces per-user salts, high work factors, and zero-downtime future algorithm upgrades via {argon2} / {bcrypt} prefixes.

Key Architectural Takeaways

  • Slow, Memory-Hard Password Hashing: Never use MD5, SHA-1, or plain SHA-256 for passwords. Prefer Argon2id (Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8()) or BCrypt wrapped inside DelegatingPasswordEncoder.
  • BOLA / IDOR Defense (OWASP API1): Never trust client-supplied userId or orderId alone—scope queries to the authenticated principal (WHERE id = :orderId AND user_id = :authUserId) or enforce @PreAuthorize ownership checks.
  • Ban Mass Assignment (OWASP API3): Never use a @Entity class as a @RequestBody parameter—an attacker sending {"role": "ADMIN", "balance": 999999} overwrites sensitive fields! Always bind strictly to immutable Java record / Kotlin data class DTOs.
  • SSRF Defense (OWASP API7): When fetching user-supplied webhook or avatar URLs via RestClient, restrict schemes to https, validate hostnames against an allow-list or reject private/link-local IPs (169.254.169.254 cloud metadata endpoint!).

Production Implementation (Java 21/25 vs Kotlin 2.x)

Argon2id DelegatingPasswordEncoder + SSRF URL Guard + Safe DTO Binding 
@Configuration
public class SecurityHardeningConfig {

    @Bean
    PasswordEncoder passwordEncoder() {
        // Argon2id is memory-hard (defeats GPU/ASIC cracking) and version-prefixed ({argon2})
        return Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8();
    }
}

// SSRF Guard before calling external webhook URLs
public URI validateSafeExternalUrl(String rawUrl) {
    URI uri = URI.create(rawUrl);
    if (!"https".equalsIgnoreCase(uri.getScheme())) {
        throw new IllegalArgumentException("Only HTTPS outbound URLs allowed");
    }
    InetAddress addr = InetAddress.getByName(uri.getHost());
    if (addr.isSiteLocalAddress() || addr.isLoopbackAddress() || addr.isLinkLocalAddress()) {
        throw new SecurityException("Blocked SSRF attempt to internal/metadata IP: " + addr);
    }
    return uri;
}
@Configuration
class SecurityHardeningConfig {

    @Bean
    fun passwordEncoder(): PasswordEncoder =
        Argon2PasswordEncoder.defaultsForSpringSecurity_v5_8()
}

fun validateSafeExternalUrl(rawUrl: String): URI {
    val uri = URI.create(rawUrl)
    require("https".equals(uri.scheme, ignoreCase = true)) {
        "Only HTTPS outbound URLs allowed"
    }

        throw SecurityException("Blocked SSRF attempt to internal/metadata IP: $addr")
    }

}
