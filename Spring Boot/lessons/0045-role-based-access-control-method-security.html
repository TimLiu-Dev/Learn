Role-Based Access Control (RBAC), @EnableMethodSecurity & BOLA Defense

Target: Enforce defense-in-depth inside your domain layer with Spring Security 7. Enable @EnableMethodSecurity, guard admin actions with @PreAuthorize, and block OWASP API #1 Broken Object Level Authorization (BOLA / IDOR) vulnerabilities using SpEL ownership expressions.

📖 Primary Source Recommendation

Study the official authority: Spring Security 7 Reference: Method Security & AuthorizationManager.

1. Why URL Security Alone Leaves Gaps

Configuring URL patterns inside SecurityFilterChain (e.g., .requestMatchers("/api/v1/admin/**")) only guards the outer HTTP servlet edge. If a GraphQL resolver, secondary REST controller, or gRPC endpoint calls your UserManagementService directly, URL matchers never run! Method Security (@EnableMethodSecurity + @PreAuthorize) wraps the service bean itself in an AOP authorization proxy.

2. Preventing BOLA / IDOR with SpEL Ownership Checks

⚠️ OWASP API #1: Broken Object Level Authorization (BOLA / IDOR)

User u-500 logs in with a valid JWT and calls GET /api/v1/users/u-999/orders. If the backend only checks authenticated() without verifying that the caller actually owns u-999, User u-500 can read every customer's orders!

With SpEL inside @PreAuthorize, Spring Security verifies ownership before your method body even starts:

@PreAuthorize("hasRole('ADMIN') or #userId == authentication.name") public List<OrderDto> getOrdersForUser(String userId) { ... }

3. Production Dual Method Security Configuration (Spring Security 7)

@EnableMethodSecurity + Admin RBAC & BOLA Ownership Guards 
package com.example.ecommerce.user;

import org.springframework.context.annotation.Configuration;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.stereotype.Service;

@Configuration
@EnableMethodSecurity // Enables @PreAuthorize, @PostAuthorize, @AuthorizeReturnObject
class MethodSecurityConfig {}

@Service
public class UserManagementService {

    @PreAuthorize("hasRole('ADMIN')")
    public void deleteUser(String userId) {
        // Only callers with GrantedAuthority("ROLE_ADMIN") reach this line
    }

    @PreAuthorize("hasRole('ADMIN') or #userId == authentication.name")
    public UserProfile getProfile(String userId) {
        // Callers can only fetch their OWN profile unless they hold ROLE_ADMIN
        return new UserProfile(userId);
    }
}

package com.example.admin

import org.springframework.context.annotation.Configuration

import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity
import org.springframework.stereotype.Service

@Configuration
@EnableMethodSecurity
class MethodSecConfig

@Service
class OrderAccessService {

    @PreAuthorize("hasRole('ADMIN')")
