2. Model Security Hygiene: Always .safetensors, Never .ckpt!

Security Rule: Standard Python pickle files (.ckpt, .pt, .bin) can execute arbitrary malicious code on your Mac/Z13 the moment you load them! When downloading community checkpoints or LoRAs from Civitai or Hugging Face, check file extensions strictly:

Safety Check · ComfyUI Model Directory Hygiene

# DANGEROUS FROM UNKNOWN AUTHORS (Python pickle can run arbitrary code on load!):
# untrusted_model.ckpt / untrusted_lora.pt

3. Multi-LoRA Stacking & Pony CLIP Skip Pattern

In ComfyUI, chain multiple LoraLoader nodes in series while keeping combined weights balanced (e.g., Identity LoRA 0.75 + Realism LoRA 0.55) so features blend cleanly without burning contrast. For Pony/Illustrious models, insert a CLIPSetLastLayer node (stop_at_clip_layer = -2) between the checkpoint CLIP output and CLIPTextEncode so penultimate tag semantics aren't clipped away.
