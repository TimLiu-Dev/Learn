Batch Automation, WebSocket API, Upscaling & Quality Evals

Separating hobbyists from senior engineers: driving ComfyUI deterministically over WebSockets, avoiding brittle hardcoded node IDs, tiled 4K upscaling, and scoring likeness automatically with InsightFace ArcFace.

1. Headless ComfyUI WebSocket Client (Complete Runnable Pattern)

ComfyUI is an HTTP + WebSocket server. Export any workflow via Save (API Format) to get workflow_api.json. Instead of fire-and-forget POSTs or fragile hardcoded node IDs like graph["3"], locate nodes by _meta.title or class_type, listen on /ws until execution completes, and fetch outputs via /history + /view:

Python · Full WebSocket Seed Sweep + Image Retrieval
import json, uuid, urllib.request, urllib.parse, websocket  # pip install websocket-client

SERVER = "127.0.0.1:8188"
CLIENT_ID = str(uuid.uuid4())

def find_node(graph, title=None, class_type=None):
    for node_id, node in graph.items():
        if title and node.get("_meta", {}).get("title") == title:
            return node
        if class_type and node.get("class_type") == class_type:
            return node
    raise KeyError(f"Node not found: title={title}, class_type={class_type}")

with open("workflow_api.json") as f:
    base_graph = json.load(f)

ws = websocket.WebSocket()
ws.connect(f"ws://{SERVER}/ws?clientId={CLIENT_ID}")

for seed in [101, 202, 303, 404]:
    for strength in [0.75, 0.85]:
        graph = json.loads(json.dumps(base_graph))
        find_node(graph, class_type="KSampler")["inputs"]["seed"] = seed
        find_node(graph, class_type="LoraLoader")["inputs"]["strength_model"] = strength

        req = urllib.request.Request(
            f"http://{SERVER}/prompt",
            data=json.dumps({"prompt": graph, "client_id": CLIENT_ID}).encode(),
            headers={"Content-Type": "application/json"},
        )
        prompt_id = json.loads(urllib.request.urlopen(req).read())["prompt_id"]

        while True:
            msg = json.loads(ws.recv())
            if msg.get("type") == "executing" and msg["data"]["node"] is None and msg["data"]["prompt_id"] == prompt_id:
                break  # DAG finished!

        history = json.loads(urllib.request.urlopen(f"http://{SERVER}/history/{prompt_id}").read())[prompt_id]
        for node_out in history["outputs"].values():
            for img in node_out.get("images", []):
                params = urllib.parse.urlencode({"filename": img["filename"], "subfolder": img["subfolder"], "type": img["type"]})
                data = urllib.request.urlopen(f"http://{SERVER}/view?{params}").read()
                with open(f"sweep_s{seed}_w{strength}.png", "wb") as out:
                    out.write(data)
ws.close()

2. Tiled 4K Upscaling & FaceDetailer Polish

  • Why Tiled? Sampling directly at 4096 × 4096 explodes attention memory and introduces duplicated heads/limbs. Generate at ~1024 × 1024 first, then run Ultimate SD Upscale + 4x-UltraSharp at low tiled denoise (0.20–0.30).
  • Video Upscaling: Run frame-consistent upscalers (SeedVR2 / Real-ESRGAN per frame) only on your top selected clips.

3. Quantitative Quality Evals (ArcFace Cosine Similarity)

Instead of eyeballing 40 candidates manually, extract 512-D facial identity embeddings with InsightFace (buffalo_l) and rank generated portraits objectively against your reference selfie:

Python · Rank Sweep Candidates by ArcFace Cosine Similarity
import cv2, glob, numpy as np
from insightface.app import FaceAnalysis  # pip install insightface onnxruntime

app = FaceAnalysis(name="buffalo_l", providers=["CPUExecutionProvider"])
app.prepare(ctx_id=0, det_size=(640, 640))

def face_vec(path):
    faces = app.get(cv2.imread(path))
    if not faces:
        return None
    v = faces[0].normed_embedding
    return v

ref = face_vec("datasets/me_raw/me_01.png")
scores = []
for p in glob.glob("sweep_*.png"):
    vec = face_vec(p)
    if vec is not None:
        scores.append((float(np.dot(ref, vec)), p))

for sim, path in sorted(scores, reverse=True)[:5]:
    print(f"{sim:.4f}  {path}")  # > 0.55–0.70+ indicates strong identity lock
