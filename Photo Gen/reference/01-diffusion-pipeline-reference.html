The Diffusion Pipeline Cheat Sheet

Compressed anatomy, tensor math, and parameter defaults shared by SDXL, FLUX.2, Wan 2.2, and managed media APIs.

1. The Four-Stage Pipeline

Stage Component Input → Output Android Mental Model
1. Encode Text Text Encoder (CLIP / T5 / VLM) Prompt string → token embeddings [B, Seq, Dim] Parsing user intent into a typed search vector
2. Init Noise PRNG + seed Integer seed → latent noise z_T Deterministic Random(seed) grid initializer
3. Denoise Loop Denoiser (UNet / DiT) + Scheduler Noisy latent + embeddings → clean latent z_0 Iterative Coroutines refinement loop over N steps
4. Decode Pixels VAE Decoder Compressed latent z_0 → RGB image [B, 3, H, W] Decompressing a compact asset into a display Bitmap

2. Latent Compression Rule (8× Spatial Factor)

Standard 2D image VAEs compress height and width by a factor of 8: 

# Given target pixel dimensions H, W (must be divisible by 8, ideally 16 or 64):
latent_h = H // 8
latent_w = W // 8

# Example: 1024 x 1024 portrait
# SDXL (4 latent channels):  [1, 4,  128, 128]
# FLUX (16 latent channels): [1, 16, 128, 128]
# Decoded RGB Bitmap tensor: [1, 3, 1024, 1024]

Video VAEs (e.g., Wan 2.2 / HunyuanVideo) also compress the time axis (typically 4× or 8× temporal compression), turning T video frames into 1 + (T - 1) // 4 latent frames.

3. Core Inference Knobs

Parameter What It Controls Typical Sweet Spot Failure Mode If Misconfigured
seed Initial Gaussian noise tensor z_T Fixed integer for A/B tests; random for exploration Changing seed alters composition—never test prompts with drifting seeds.
num_inference_steps Number of solver iterations from T to 0 20–30 (SDXL/FLUX.2 dev); 4–8 (distilled Schnell/Klein) Too low = blurry/incomplete; too high = wasted GPU cost with flat returns.
guidance_scale (CFG) How strongly conditional prediction beats unconditional prediction 5.0–7.5 (SDXL); 1.0–4.0 (FLUX guidance-distilled) Too low = ignores prompt; too high = burned contrast, plastic skin, color clipping.

4. Minimal Diffusers Inspection Pattern

import torch
from diffusers import DiffusionPipeline

device = "mps" if torch.backends.mps.is_available() else "cuda"
dtype = torch.bfloat16 if device == "mps" else torch.float16

pipe = DiffusionPipeline.from_pretrained(
    "stabilityai/stable-diffusion-xl-base-1.0",
    torch_dtype=dtype,
).to(device)

generator = torch.Generator(device=device).manual_seed(42)
image = pipe(
    prompt="studio LinkedIn headshot, natural softbox lighting, 85mm lens",
    negative_prompt="plastic skin, oversaturated, blurry",
    width=1024,
    height=1024,
    num_inference_steps=28,
    guidance_scale=6.5,
    generator=generator,
).images[0]
