Domain Android / Legacy Reference 2027 Senior iOS Standard Architectural & Runtime Rule
Obj-C Interop JNI / Legacy Java Interop Bridging Header + @objc + Unmanaged Use Swift 6 wrappers over Obj-C SDKs; never leak Unmanaged retains; avoid @objc dynamic unless KVO/swizzling requires it.
Swift 6.2/6.3 Concurrency Dispatcher-bound suspend nonisolated(nonsending) + @concurrent + Mutex Nonisolated async functions stay on caller's executor by default (SE-0461); opt into background hopping with @concurrent; use Mutex for short synchronous critical sections.
Zero-Copy & Ownership Direct ByteBuffer / JNI pinning ~Copyable + InlineArray + Span<T> Use ~Copyable for unique file/socket handles with deterministic deinit; InlineArray & Span eliminate heap allocations in hot paths.
State Architecture MVI / Orbit / Circuit @Observable UDF or TCA (@Reducer) Use @Observable UDF for low-ceremony modularity, or TCA when exhaustive TestStore effect/state verification justifies macro boilerplate.
Files & SQLite Scoped Storage + Room / SQLDelight Sandbox + FileProtectionType + SQLite/GRDB Mark caches isExcludedFromBackup; use .completeUnlessOpen for encrypted files; prefer SQLite/GRDB over SwiftData for heavy concurrent sync.
Binary SDKs AAR / Maven Publishing XCFramework + Mergeable Libraries Enable BUILD_LIBRARY_FOR_DISTRIBUTION=YES for ABI/module stability (.swiftinterface) across Swift versions.
Quality & Test Matrices ktlint / Detekt + Gradle Test Suites swift-format + SwiftLint + .xctestplan Enforce formatting via toolchain swift-format; run parallel, randomized, TSan & RTL localization passes via .xctestplan.
UI & Localization Material 3 Expressive + strings.xml Liquid Glass + Animators + .xcstrings Apply .glassEffect() on floating controls (not scrolling lists); drive multi-step motion with PhaseAnimator; manage plurals in .xcstrings.
On-Device AI Gemini Nano / AICore + LiteRT FoundationModels + Core ML Use @Generable for type-safe guided generation on-device; profile Core ML models against the Neural Engine (ANE).
System Intelligence App Actions / Shortcuts AppIntents + AppEntity Expose core domain actions & RelevantEntities so Siri, Spotlight, Widgets, and Control Center can invoke them out-of-process.
IAP & Auth Play Billing + Credential Manager StoreKit 2 (JWS) + Passkeys Verify transactions locally via VerificationResult JWS signatures; prefer FIDO2 Passkeys over password + SMS OTP.
Apple CI/CD GitHub Actions + Play Console Xcode Cloud + GitHub Actions + Fastlane Use Xcode Cloud for zero-maintenance Apple signing/TestFlight; pair with GitHub Actions + xcodebuild for custom SPM monorepo pipelines.
