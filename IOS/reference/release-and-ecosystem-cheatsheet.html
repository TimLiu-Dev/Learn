Domain Android Platform Apple Platform Senior Release Engineering Rule
Privacy Manifest Google Play Data Safety Form PrivacyInfo.xcprivacy file Mandatory in all App Store submissions. Declares Required Reason APIs (UserDefaults, disk space, file timestamps) and tracking domains.
Push Notifications Firebase Cloud Messaging (FCM) Apple Push Notification service (APNs) Direct HTTP/2 connection to APNs gateways using `.p8` token authentication; handles background wakeups via `content-available: 1`.
Signing & Profiles Keystore (`.jks` / `.keystore`) Certificates + Provisioning Profiles Cryptographic binding of Bundle ID, developer certificate, device UDIDs (for Ad-Hoc), and entitlements (Push, Keychain Access Groups).
Automated Deploy Fastlane `supply` to Play Console Fastlane `match` + `gym` + `pilot` `match` manages code signing certificates via an encrypted git repo; `pilot` distributes builds automatically to TestFlight beta testers.
