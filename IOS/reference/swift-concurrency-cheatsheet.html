Concept Kotlin (Android) Swift 6 (iOS) Senior Systems Distinction
Async Execution suspend fun async throws -> T Swift cooperative thread pool limits threads to the number of CPU cores. Blocking a thread starves the entire system.
Parent-Child Scope coroutineScope { } withTaskGroup(of:) { } Child tasks in Swift automatically inherit priority, task-locals, and cancellation state from parent.
Thread Isolation Mutex / AtomicReference actor Actors run mailbox queues. Synchronization is compiler-enforced; external synchronous state access is forbidden.
Main Thread Dispatchers.Main @MainActor Global actor pinned directly to the application's main run loop for UI safety.
Thread Boundary Transfer Any JVM object (Race hazard!) Sendable protocol Swift 6 enforces that values passed across concurrency boundaries are thread-safe (immutable value types or actors).
Cancellation isActive / ensureActive() Task.checkCancellation() Cooperative. Canceling a task sets a flag; work continues unless the task cooperatively checks and throws CancellationError.
⚠️ The Actor Reentrancy Hazard: Unlike a traditional mutex or synchronized lock, when an actor calls an await function, it yields its thread to other callers! State modified across an await boundary can change out from underneath the actor. Always validate state assumptions immediately before and after any await.
