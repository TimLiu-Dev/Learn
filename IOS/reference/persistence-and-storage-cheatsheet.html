iOS Persistence & Storage Architecture Cheatsheet

Comparing Android Room/DataStore with iOS SwiftData, Core Data, and Keychain Services.

← Master Plan • Lesson 4.1

Tier Android (Kotlin) iOS (Swift) Senior Engineering Purpose
Lightweight Prefs Jetpack DataStore / SharedPreferences UserDefaults / @AppStorage Unencrypted plist file. For UI flags, theme settings, and last opened tabs. Never store sensitive tokens.
Secure Credentials EncryptedSharedPreferences / KeyStore Apple Keychain Services Hardware-encrypted enclave storage with biometric (Face ID / Touch ID) access controls for auth tokens.
Modern Graph ORM Room ORM (SQLite) SwiftData (@Model, @Query) Pure Swift macro-driven object graph persistence natively integrated into SwiftUI render loops.
Enterprise Database Room / SQLDelight Core Data Foundational Apple persistence framework. Essential for brownfield enterprise apps and complex multi-context workloads.
Schema Migrations Room Migration classes VersionedSchema & SchemaMigrationPlan Deterministic, staged schema evolution preventing corrupt SQLite tables and app crash loops upon user updates.
