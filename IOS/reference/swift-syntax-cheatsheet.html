Swift Syntax: Mutability & Optionals

High-density reference for Swift types, declaration rules, and unwrapping patterns. Cross-referenced for Android/Kotlin engineers.

← Master Plan & Dashboard • Lesson 1.1

1. Mutability: let vs. var

// Immutable constant (Kotlin: val)
let maxRetries = 3

// Mutable variable (Kotlin: var)
var currentCount = 0
currentCount += 1

// CRITICAL DIFFERENCE on Structs:
struct Coordinate { var x: Double; var y: Double }
let origin = Coordinate(x: 0, y: 0)
// ERROR: origin.x = 5.0 
// 'let' makes the ENTIRE struct immutable!

2. Type Inference & Literals

let count = 42             // Int (64-bit on iOS)
let price = 19.99          // Double (default)
let floatVal: Float = 3.14 // Explicit Float
let isActive = true        // Bool
let title = "PulseFlow"    // String

// String Interpolation (Kotlin: "$title")
let msg = "App: \(title), count: \(count)"

3. Optionals: Under The Hood

// Syntactic sugar:
var avatarURL: String? = nil

// Exact compiler representation:
enum Optional<Wrapped> {
    case none
    case some(Wrapped)
}

// Optionals are actual enum states!

4. Unwrapping Techniques

// 1. guard let (Early exit, retains scope)
guard let url = avatarURL else {
    return // or throw error
}
print(url) // 'url' is String in outer scope!

// 2. if let (Scoped unwrap)
if let url = avatarURL {
    print(url)
}

// 3. Nil-Coalescing (Kotlin Elvis ?:)
let display = avatarURL ?? "default.png"
💡 The Golden Rule for Android Migrators: In Kotlin, val list = mutableListOf(1, 2) allows mutating contents because val only prevents reassigning the reference. In Swift, let list = [1, 2] is an immutable value type—you cannot append to it, period.
