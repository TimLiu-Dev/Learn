Concept Android (Gradle) iOS (Swift Package Manager) Senior Architectural Rule
Module Definition Gradle subproject (:feature:profile) SPM Package target in Package.swift Local SPM packages compile in parallel, enforcing strict boundary encapsulation without circular dependencies.
Linkage Strategy AAR / APK packaging Static Library (.static) vs Dynamic (.dynamic) Prefer static libraries in SPM: dynamic frameworks add dylib binding overhead to pre-main dyld launch time.
Configuration Matrix Build variants & productFlavors Xcode Configurations + .xcconfig files Store API endpoints, bundle identifiers, and compiler flags in plain-text git-tracked `.xcconfig` files; inject secrets via CI environment variables.
Data Flow MVI (Model-View-Intent) Unidirectional Data Flow (State $\rightarrow$ Action $\rightarrow$ Reducer) All state mutations happen in a single deterministic reducer; views only emit actions and render immutable state snapshots.
