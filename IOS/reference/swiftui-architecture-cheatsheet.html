Concept Jetpack Compose SwiftUI Senior Architectural Distinction
Component @Composable fun MyView() struct MyView: View { var body: some View } SwiftUI views are lightweight immutable structs. Generating view bodies is virtually free; rendering is managed by the AttributeGraph.
Local State remember { mutableStateOf() } @State private var count = 0 @State allocates heap storage managed by SwiftUI, surviving view re-evaluations tied to view identity.
Two-Way Binding Value + Callback (value, onValueChange) @Binding var text: String ($text) First-class reference to a source of truth without passing separate state and lambda handlers.
Observable ViewModel class VM: ViewModel() { val state: StateFlow } @Observable class VM iOS 17+ Observation tracks dependencies at the property read level. Views only re-evaluate if accessed properties change.
Environment Injection CompositionLocalProvider @Environment(\.keyPath) Scoped dependency injection down the view hierarchy without manual prop-drilling.
View Identity Compiler keys / position Structural (type tree) vs Explicit (.id(...)) Senior engineers avoid resetting view state accidentally by controlling explicit vs structural identity.
