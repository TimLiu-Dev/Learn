App Security: CryptoKit & SSL Certificate Pinning

Apple CryptoKit (AES-GCM, SHA-256), Secure Enclave, URLSessionDelegate TLS pinning, and App Attest defenses.

← Master Curriculum & Systems Legend • 📖 Persistence Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android, certificate pinning is configured via NetworkSecurityConfig.xml or OkHttp CertificatePinner.

In iOS, Apple CryptoKit provides modern, hardware-accelerated cryptographic primitives (AES-GCM, Curve25519, SHA-256). Certificate and public key pinning is implemented via URLSessionDelegate (didReceive challenge:), inspecting the server's X.509 certificate trust chain to prevent Man-in-the-Middle (MITM) attacks.

⚡ Low-Level Core: How Swift Works Under the Hood

1. Modern Encryption with CryptoKit (AES-GCM)

import CryptoKit

func encryptPayload(plainData: Data, symmetricKey: SymmetricKey) throws -> Data {
    let sealedBox = try AES.GCM.seal(plainData, using: symmetricKey)
    return sealedBox.combined ?? Data()
}

func decryptPayload(combinedData: Data, symmetricKey: SymmetricKey) throws -> Data {
    let sealedBox = try AES.GCM.SealedBox(combined: combinedData)
    return try AES.GCM.open(sealedBox, using: symmetricKey)
}

2. TLS Public Key Pinning (URLSessionDelegate)

In urlSession(_:didReceive:completionHandler:), validate the server's public key hash against your pinned SPKI (Subject Public Key Info) SHA-256 hash. If they do not match, abort connection with .cancelAuthenticationChallenge.

⚠️ Senior Failure Mode & Anti-Pattern:

Pinning Expiring Root Certificates without Backup Keys: If your server certificates rotate and you pinned a leaf certificate with no backup pin, the app will fail all network requests until an emergency App Store update is approved. Always pin the intermediate CA or include backup public key pins.

🔑 Reveal Final Reference Solution & Architecture Walkthrough 
import Foundation
import CryptoKit

func verifyPayloadHash(data: Data, expectedHexHash: String) -> Bool {
    let digest = SHA256.hash(data: data)
    let hex = digest.map { String(format: "%02x", $0) }.joined()
    return hex == expectedHexHash.lowercased()
}

    print("🧪 Running Lesson 4.2 Verification Tests...")

    assert(isValid == true)
