⚡ Low-Level Core: How Swift Works Under the Hood

1. The Core Data Concurrency Rule (Senior Interview Classic)

An NSManagedObjectContext (and any NSManagedObject fetched from it) is strictly bound to the queue/thread where it was created. Accessing a managed object on the wrong thread corrupts memory and causes instant crashes!

// Safe background processing:
persistentContainer.performBackgroundTask { context in
    // context runs on a private background queue:
    let request: NSFetchRequest<ItemEntity> = ItemEntity.fetchRequest()
    let items = try? context.fetch(request)
    // Perform mutations...
    try? context.save()
}

2. Faulting & Memory Optimization

Core Data does not load entire tables into memory. Fetched objects are initially lightweight faults (hollow shells containing only the object ID). When a property is read, Core Data 'fires the fault', fetching values from disk on-demand.

⚠️ Senior Failure Mode & Anti-Pattern:

Passing NSManagedObjects Across Threads: Passing a managed object reference from a background context to the main thread causes silent data races and crashes. Pass only the thread-safe NSManagedObjectID and re-fetch the object in the destination context via context.object(with: objectID).

import Foundation

struct ManagedObjectID: Hashable {
    let uri: String
}

final class MockContextCoordinator {
    private var database: [ManagedObjectID: String] = [:]

    func seed(id: ManagedObjectID, title: String) {
        database[id] = title
    }

    func resolveObject(with id: ManagedObjectID) -> String? {
        database[id]
    }
}

func runTests() {
    print("🧪 Running Lesson 4.5 Verification Tests...")
    let coordinator = MockContextCoordinator()
    let id1 = ManagedObjectID(uri: "coredata://User/101")
    coordinator.seed(id: id1, title: "Lead Architect")

    let title = coordinator.resolveObject(with: id1)
    assert(title == "Lead Architect")

    let missing = coordinator.resolveObject(with: ManagedObjectID(uri: "coredata://User/999"))
    assert(missing == nil)
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

In Core Data, NSManagedObjectID is the universal thread-safe token. Passing the ID across threads and re-fetching in the destination context eliminates concurrency data races.
