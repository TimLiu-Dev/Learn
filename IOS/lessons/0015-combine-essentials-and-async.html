Combine Essentials & Bridging to Swift Concurrency

Publishers, AnyCancellable, sink retain cycle traps, and bridging Combine streams into async/await via .values.

🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), reactive event streams use Flow or RxJava. Subscriptions are retained via CompositeDisposable or Coroutine jobs.

In iOS, Apple introduced Combine in iOS 13 (analogous to Kotlin Flow). In production enterprise iOS codebases, millions of lines of Combine still exist. Senior engineers must master Combine operators, avoid retain cycles with AnyCancellable, and bridge Combine publishers into modern Swift Concurrency using publisher.values.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The Combine Subscription Lifecycle

import Combine

final class SearchService {
    @Published var searchQuery: String = ""
    private var cancellables = Set<AnyCancellable>()

    func setupDebounce() {
        $searchQuery
            .debounce(for: .milliseconds(300), scheduler: RunLoop.main)
            .removeDuplicates()
            .sink { [weak self] query in
                self?.performSearch(query: query)
            }
            .store(in: &cancellables) // Retains subscription
    }
    func performSearch(query: String) {}
}

2. Bridging Combine to AsyncSequence (.values)

Instead of registering .sink closures, modern Swift Concurrency lets you iterate over any Combine Publisher using for await value in publisher.values:

func observeQueryStream(service: SearchService) async {
    for await query in service.$searchQuery.values {
        print("Received async query: \(query)")
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Omitting [weak self] in Combine .sink: The .sink closure retains self if called directly. Storing the returned AnyCancellable in self.cancellables creates an immediate retain cycle (self -> cancellables -> subscription -> sink -> self). Always use [weak self] in sink closures.

import Foundation
import Combine

func consumeThreeValues(subject: CurrentValueSubject) async -> [Int] {
    var output: [Int] = []
    for await val in subject.values {
        output.append(val)
        if output.count == 3 {
            break
        }
    }
    return output
}

func runTests() async {
    print("🧪 Running Lesson 2.7 Verification Tests...")
    let subject = CurrentValueSubject(10)
    Task {
        try? await Task.sleep(nanoseconds: 5_000_000)
        subject.send(20)
        try? await Task.sleep(nanoseconds: 5_000_000)
        subject.send(30)
    }
    let results = await consumeThreeValues(subject: subject)
    assert(results == [10, 20, 30])
    print("  ✅ All tests passed!")
}
