File System Sandboxing, Data Protection & Direct SQLite / GRDB

Documents vs Application Support vs Caches, iCloud backup exclusion, NSFileProtectionCompleteUnlessOpen, and SQLite/GRDB vs SwiftData.

🧠 The Senior Android Anchor: Systems Comparison

In Android, you distinguish filesDir from cacheDir and choose between Room ORM and SQLDelight for SQL control.

In iOS, misplacing downloaded media inside Documents/ triggers App Store rejection for bloating iCloud backups! Senior iOS engineers master sandbox directory rules, hardware-backed FileProtectionType classes, and know when to step below SwiftData into direct SQLite / GRDB (or Point-Free's SQLiteData) for high-throughput background writes.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The iOS Sandbox Directory Contract

  • Documents/: User-created files only (visible in Files app if enabled). Backed up to iCloud automatically.
  • Library/Application Support/: App-managed databases & state. Backed up to iCloud (set isExcludedFromBackup = true for re-downloadable assets!).
  • Library/Caches/: Ephemeral cache; iOS purges it under storage pressure (never backed up).
  • tmp/: Scratch files; purged on termination/reboot.

2. Hardware File Protection & SQLite WAL Mode

var resourceValues = URLResourceValues()
resourceValues.isExcludedFromBackup = true
try cacheURL.setResourceValues(resourceValues)

try data.write(to: secureURL, options: [.atomic, .completeFileProtectionUnlessOpen])

Use .completeFileProtectionUnlessOpen for background sync SQLite/GRDB databases: files already open stay readable during background wakeups while locked, whereas new opens require device unlock.

⚠️ Senior Failure Mode & Anti-Pattern:

Writing Databases to Documents/ or Using .completeFileProtection for Background Sync: Putting 500MB of synced cache in Documents fails App Store review. Worse, encrypting a background-synced SQLite file with .complete causes SQLITE_CANTOPEN errors whenever BGAppRefreshTask wakes the app while the user's iPhone is locked in their pocket.

import Foundation

enum StorageKind {
    case userDocument
    case database
    case ephemeralCache
}

enum SandboxRouter {
    static func destinationURL(base: URL, kind: StorageKind, filename: String) -> URL {
        let folder: String
        switch kind {
        case .userDocument: folder = "Documents"
        case .database: folder = "ApplicationSupport"
        case .ephemeralCache: folder = "Caches"
        }
        return base.appendingPathComponent(folder).appendingPathComponent(filename)
    }

    static func writeProtected(_ data: Data, to url: URL) throws {
        try FileManager.default.createDirectory(
            at: url.deletingLastPathComponent(),
            withIntermediateDirectories: true
        )
        try data.write(to: url, options: [.atomic, .completeFileProtectionUnlessOpen])
    }
}

func runTests() throws {
    print("🧪 Running Lesson 8.5 Verification Tests...")
    let tempBase = FileManager.default.temporaryDirectory.appendingPathComponent("pulse_sandbox_\(UUID().uuidString)")
    defer { try? FileManager.default.removeItem(at: tempBase) }

    let dbURL = SandboxRouter.destinationURL(base: tempBase, kind: .database, filename: "sync.sqlite")
    assert(dbURL.path.contains("ApplicationSupport/sync.sqlite"))

    let docURL = SandboxRouter.destinationURL(base: tempBase, kind: .userDocument, filename: "export.pdf")
    assert(docURL.path.contains("Documents/export.pdf"))

    let payload = Data("WAL_HEADER_V1".utf8)
    try SandboxRouter.writeProtected(payload, to: dbURL)
    let readBack = try Data(contentsOf: dbURL)
    assert(readBack == payload)
    print("  ✅ All tests passed!")
}
