Global Actors, @MainActor & Custom Executors

Thread hopping, ensuring UI mutations on the main runloop, and custom serial actor executors.

← Master Curriculum & Systems Legend • 📖 Swift Concurrency Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), switching to the UI thread requires withContext(Dispatchers.Main) { ... }. Calling UI mutations from worker threads causes runtime exceptions.

In Swift, the main thread is encapsulated as a global actor: @MainActor. Tagging a class, function, or property with @MainActor instructs the Swift compiler to guarantee execution on the main runloop at compile time. Swift 6 eliminates manual DispatchQueue.main.async calls.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The @MainActor Isolation Domain

@MainActor
final class ProfileViewModel: ObservableObject {
    @Published var userName: String = ""

    func updateName(to newName: String) {
        // Guaranteed to run on main thread:
        self.userName = newName
    }
}

2. Safe Thread Hopping with MainActor.run

When executing inside a background worker actor or nonisolated utility function, use await MainActor.run { ... } to hop over to the main thread:

func processBackgroundPayload() async {
    let result = parseBigData()
    // Thread hop to main actor:
    await MainActor.run {
        updateUI(result)
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Over-decorating Services with @MainActor: Tagging network clients, parsers, or database repositories with @MainActor forces background work onto the main thread, introducing UI hitches (frame drops). Keep background services on default actors or detached tasks.

import Foundation

@MainActor
final class UIStateHolder {
    var text: String = "empty"
    var isMainThread: Bool = false

    func apply(value: String) {
        self.text = value
        self.isMainThread = Thread.isMainThread
    }
}

func deliverUpdate(to holder: UIStateHolder, rawValue: String) async {
    let formatted = "formatted_\(rawValue.uppercased())"
    await MainActor.run {
        holder.apply(value: formatted)
    }
}

func runTests() async {
    print("🧪 Running Lesson 2.5 Verification Tests...")
    let holder = await UIStateHolder()
    await Task.detached {
        await deliverUpdate(to: holder, rawValue: "senior")
    }.value

    let finalText = await holder.text
    let wasOnMain = await holder.isMainThread
    assert(finalText == "formatted_SENIOR")
    assert(wasOnMain == true)
    print("  ✅ All tests passed!")
}

await runTests()
Senior Engineering Walkthrough:

MainActor.run coordinates with the Darwin main runloop, hopping execution from the background cooperative thread to the main thread safely. This ensures UI mutations are 100% thread-safe under Swift 6 data-race immunity.
