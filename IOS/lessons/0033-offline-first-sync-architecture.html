Offline-First Sync Architecture: Optimistic UI & Conflict Resolution

Local persistence as single source of truth, optimistic UI state updates, Vector Clocks / Last-Write-Wins (LWW), and sync queues.

← Master Curriculum & Systems Legend • 📖 Persistence Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android, offline-first architectures use Room as the single source of truth: network requests write directly to Room, and the UI observes Room Flow streams.

In iOS, Offline-First Architecture follows the same principle: SwiftUI views observe the local store (@Query or SwiftData). When the user performs an action (e.g. liking a post or sending a message), the app commits an optimistic update to the local SQLite database immediately. A background sync queue uploads changes to the server, resolving conflicts via Vector Clocks or Last-Write-Wins (LWW).

⚡ Low-Level Core: How Swift Works Under the Hood

1. The Offline-First Flow

  1. User action: User creates or mutates a record.
  2. Local commit: App writes mutation to local database with status .pendingSync. UI updates instantly (0ms latency!).
  3. Background sync: When network is available, SyncWorker uploads pending mutations.
  4. Server ack: Server confirms; local status updates to .synced. If server rejects, app rolls back or prompts user.

2. Last-Write-Wins (LWW) Conflict Resolution

struct SyncRecord {
    let id: String
    var content: String
    var timestampEpoch: Int64

    func resolveConflict(with serverRecord: SyncRecord) -> SyncRecord {
        // Last-Write-Wins: newer timestamp wins
        if self.timestampEpoch >= serverRecord.timestampEpoch {
            return self
        } else {
            return serverRecord
        }
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Waiting for Network Before Updating Local UI: Forcing a spinning indicator for 2 seconds while waiting for network responses ruins the app experience on poor connections. Always mutate local storage optimistically and sync in the background.

import Foundation

struct NoteRecord: Equatable {
    let id: String
    let text: String
    let updatedAt: Int64
}

func resolveLWW(local: NoteRecord, server: NoteRecord) -> NoteRecord {
    if local.updatedAt > server.updatedAt {
        return local
    } else {
        return server
    }
}

func runTests() {
    print("🧪 Running Lesson 4.6 Verification Tests...")
    let localNewer = NoteRecord(id: "n1", text: "Local edit", updatedAt: 200)
    let serverOlder = NoteRecord(id: "n1", text: "Server edit", updatedAt: 100)
    let r1 = resolveLWW(local: localNewer, server: serverOlder)
    assert(r1 == localNewer)

    let localOlder = NoteRecord(id: "n2", text: "Local old", updatedAt: 100)
    let serverNewer = NoteRecord(id: "n2", text: "Server new", updatedAt: 300)
    let r2 = resolveLWW(local: localOlder, server: serverNewer)
    assert(r2 == serverNewer)
    print("  ✅ All tests passed!")
}
