🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), coroutines run inside a CoroutineScope with explicit Dispatchers. Dispatchers are backed by unbounded or flexible thread pools.

In Swift, concurrency is built on a cooperative thread pool bounded strictly to CPU core count. There is no thread explosion. When a function hits await, it yields the physical thread, and Darwin schedules other tasks. Tasks carry priority and cooperative cancellation tokens.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The Cooperative Thread Pool & Suspension Points

In Grand Central Dispatch (GCD), dispatching 1,000 blocks spawned 1,000 threads, blowing through kernel memory. Swift Concurrency solves this: exactly 1 thread per CPU core. A thread suspension point (await) yields the thread to other work.

2. Cooperative Cancellation (Task.isCancelled & Task.checkCancellation)

func computeMetrics(batches: [DataBatch]) async throws -> [Result] {
    var results: [Result] = []
    for batch in batches {
        try Task.checkCancellation() // Throws CancellationError immediately if cancelled
        results.append(batch.process())
    }
    return results
}
⚠️ Senior Failure Mode & Anti-Pattern:

Blocking the Cooperative Thread Pool with Synchronous Locks: Calling synchronous blocking APIs (Thread.sleep, DispatchSemaphore.wait) inside an async context starves the cooperative pool. If all core threads block, the entire app freezes. Always use Task.sleep.

import Foundation

struct WorkItem: Equatable {
    let id: Int
    let value: String
}

func processWorkItems(_ items: [WorkItem]) async throws -> [String] {
    var processed: [String] = []
    for item in items {
        try Task.checkCancellation()
        try await Task.sleep(nanoseconds: 1_000_000)
        processed.append("processed_\(item.id)")
    }
    return processed
}

func runTests() async {
    print("🧪 Running Lesson 2.1 Verification Tests...")
    let items = (1...5).map { WorkItem(id: $0, value: "val") }
    do {
        let results = try await processWorkItems(items)
        assert(results.count == 5)
        assert(results[0] == "processed_1")
    } catch { fatalError() }

    let task = Task {
        try await processWorkItems((1...100).map { WorkItem(id: $0, value: "val") })
    }
    task.cancel()
    do {
        _ = try await task.value
        fatalError()
    } catch is CancellationError {
        print("  ✅ All tests passed!")
    } catch { fatalError() }
}

await runTests()
Senior Engineering Walkthrough:

Task.checkCancellation() checks the Task's cancellation flag cooperatively and throws CancellationError to unwind stack safely without data corruption.
