🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), JSON parsing typically uses Moshi or kotlinx.serialization. Unknown keys or malformed items in an array often throw parsing exceptions unless custom adapters are registered.

In Swift, Codable (Encodable & Decodable) is synthesized by the compiler. Senior iOS engineers build lossy decoders: if one item out of 100 in an array is malformed, standard Codable throws and discards all 100 items! Lossy decoders isolate malformed items, keeping the 99 valid elements.

2. The Lossy Array Pattern (Senior Must-Have)

A single invalid object should never crash the entire list:

struct LossyArray<T: Decodable>: Decodable {
    let elements: [T]

    init(from decoder: Decoder) throws {
        var container = try decoder.unkeyedContainer()
        var elements: [T] = []
        while !container.isAtEnd {
            if let element = try? container.decode(T.self) {
                elements.append(element)
            } else {
                _ = try? container.decode(EmptyDecodable.self) // Skip bad item!
            }
        }
        self.elements = elements
    }
}
private struct EmptyDecodable: Decodable {}
⚠️ Senior Failure Mode & Anti-Pattern:

Strict Decoding on Volatile Backends: When backends deploy breaking changes (new null values or changed type formats), rigid Codable models cause the entire app screen to fail to load. Use lossy decoding and optional fallbacks for non-critical fields.

import Foundation

struct User: Codable, Equatable {
    let id: Int
    let name: String
}

func decodeLossyList(jsonData: Data) -> [User] {
    struct LossyElement: Decodable {
        let value: T?
        init(from decoder: Decoder) throws {
            let container = try decoder.singleValueContainer()
            self.value = try? container.decode(T.self)
        }
    }

    let decoder = JSONDecoder()
    guard let elements = try? decoder.decode([LossyElement].self, from: jsonData) else {
        return []
    }
    return elements.compactMap { $0.value }
}

func runTests() {
    print("🧪 Running Lesson 2.9 Verification Tests...")
    let rawJSON = """
    [
        {"id": 1, "name": "Alice"},
        {"id": "invalid_id", "name": "Bob"},
        {"id": 3, "name": "Charlie"},
        {"broken_json": true}
    ]
    """.data(using: .utf8)!

    let validUsers = decodeLossyList(jsonData: rawJSON)
    assert(validUsers.count == 2)
    assert(validUsers[0] == User(id: 1, name: "Alice"))
    assert(validUsers[1] == User(id: 3, name: "Charlie"))
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

Wrapping array elements in LossyElement catches per-item decoding failures via try?. Invalid objects decode as LossyElement(value: nil). compactMap strips out the nil values, preserving all valid elements without dropping the entire payload.
