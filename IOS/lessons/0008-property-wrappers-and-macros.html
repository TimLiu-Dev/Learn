Metaprogramming: Property Wrappers, KeyPaths & Swift Macros

@propertyWrapper mechanics, projected values ($), KeyPaths, and compile-time Swift Macros vs Kotlin KSP.

← Master Curriculum & Systems Legend • 📖 Swift Syntax Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), compile-time metaprogramming relies on Kotlin Symbol Processing (KSP) or annotation processors (kapt) which generate separate source files during Gradle build. Kotlin also has property delegation (by lazy, by Delegates.observable).

In Swift, property delegation is achieved via @propertyWrapper (backing @State and @Binding). Furthermore, Swift 5.9+ introduced Swift Macros (e.g. @Observable, @Model): they operate directly on the Abstract Syntax Tree (AST) at compile time without reflection!

⚡ Low-Level Core: How Swift Works Under the Hood

1. Property Wrapper Anatomy

@propertyWrapper
struct Clamped<T: Comparable> {
    private var value: T
    let range: ClosedRange<T>

    init(wrappedValue: T, _ range: ClosedRange<T>) {
        self.range = range
        self.value = min(max(wrappedValue, range.lowerBound), range.upperBound)
    }

    var wrappedValue: T {
        get { value }
        set { value = min(max(newValue, range.lowerBound), range.upperBound) }
    }

    // Projected value exposed via '$' prefix operator
    var projectedValue: Bool {
        value == range.lowerBound || value == range.upperBound
    }
}

struct AudioSettings {
    @Clamped(0...100) var volume: Int = 50
}
var audio = AudioSettings()
audio.volume = 150 // Clamped to 100!
print(audio.$volume) // true (projectedValue indicates clamped at boundary)

2. Type-Safe KeyPaths

KeyPaths (\User.email) are strongly typed property references. Senior engineers use them for sorting, filtering, and functional transforms without closure overhead:

extension Sequence {
    func sorted<T: Comparable>(by keyPath: KeyPath<Element, T>) -> [Element] {
        sorted { $0[keyPath: keyPath] < $1[keyPath: keyPath] }
    }
}

3. Swift Macros (Compile-Time AST Manipulation)

Unlike runtime reflection or source generation, Swift Macros expand directly into the compiler AST during compilation. They are sandboxed, deterministic, and inspectable in Xcode.

⚠️ Senior Failure Mode & Anti-Pattern:

Overusing Property Wrappers for Heavy Business Logic: Property wrappers execute on property get/set. Putting blocking I/O, network requests, or database transactions inside a property wrapper creates silent performance stalls during simple property assignments.

import Foundation

@propertyWrapper
struct Trimmed {
    private var text: String
    private(set) var wasTrimmed: Bool = false

    init(wrappedValue: String) {
        let cleaned = wrappedValue.trimmingCharacters(in: .whitespacesAndNewlines)
        self.text = cleaned
        self.wasTrimmed = (cleaned != wrappedValue)
    }

    var wrappedValue: String {
        get { text }
        set {
            let cleaned = newValue.trimmingCharacters(in: .whitespacesAndNewlines)
            self.text = cleaned
            self.wasTrimmed = (cleaned != newValue)
        }
    }

    var projectedValue: Bool {
        wasTrimmed
    }
}

struct UserInput {
    @Trimmed var username: String
}

func runTests() {
    print("🧪 Running Lesson 1.8 Verification Tests...")
    var input = UserInput(username: "  AlexiOS  ")
    assert(input.username == "AlexiOS")
    assert(input.$username == true)
    input.username = "CleanName"
    assert(input.username == "CleanName")
    assert(input.$username == false)
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

Property wrappers encapsulate property read/write transformations. By providing projectedValue, consumers can query auxiliary state using the dollar-sign prefix ($input.username) cleanly.
