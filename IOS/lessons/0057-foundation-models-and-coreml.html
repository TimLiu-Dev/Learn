🧠 The Senior Android Anchor: Systems Comparison

In Android, on-device GenAI uses Gemini Nano via ML Kit / AICore and LiteRT for custom TFLite models.

In 2027 iOS, Apple gives native apps zero-cost, offline-capable access to Apple Intelligence via the FoundationModels framework—featuring compile-time typed structured output (@Generable) and Tool calling—alongside Core ML for custom vision/audio models running on the Apple Neural Engine (ANE).

⚡ Low-Level Core: How Swift Works Under the Hood

1. Guided Generation with @Generable & LanguageModelSession

import FoundationModels

@Generable
struct IncidentTriage {
    @Guide(description: "Severity from 1 (low) to 5 (critical)", .range(1...5))
    var severity: Int
    var summary: String
}

let session = LanguageModelSession(instructions: "Triage mobile telemetry logs concisely.")
let response = try await session.respond(to: crashLog, generating: IncidentTriage.self)
// response.content is a strongly-typed IncidentTriage—never brittle regex JSON parsing!

2. Core ML & Availability Guardrails

  • Check Device Availability First: Always inspect SystemLanguageModel.default.availability and gracefully degrade to deterministic heuristics or cloud endpoints on unsupported hardware.
  • Core ML Compute Units: Profile MLComputeUnits.all in Xcode Instruments (Core ML template) to confirm operators execute on the Neural Engine rather than falling back to CPU.
⚠️ Senior Failure Mode & Anti-Pattern:

Prompting Unconstrained Text and Parsing JSON Manually: Asking an on-device 3B model for raw JSON frequently yields markdown fences or malformed braces. Always use @Generable constrained decoding, and never assume Apple Intelligence is available without checking device eligibility and user opt-in status.

🔑 Reveal Final Reference Solution & Architecture Walkthrough 
import Foundation

enum ModelAvailability {
    case available
    case unavailable(reason: String)
}

enum TriageBackend: Equatable {
    case onDeviceFoundationModel
    case cloudFallback
    case deterministicRuleEngine
}

enum AITriageRouter {
    static func selectBackend(availability: ModelAvailability, isOffline: Bool) -> TriageBackend {
        switch availability {
        case .available:
            return .onDeviceFoundationModel
        case .unavailable:
            return isOffline ? .deterministicRuleEngine : .cloudFallback
        }
    }

    static func validateTriage(severity: Int, summary: String) -> (Int, String)? {
        let trimmed = summary.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { return nil }
        let clamped = min(max(severity, 1), 5)
        return (clamped, trimmed)
    }
}

func runTests() {
    print("🧪 Running Lesson 8.9 Verification Tests...")
    assert(AITriageRouter.selectBackend(availability: .available, isOffline: true) == .onDeviceFoundationModel)
    assert(AITriageRouter.selectBackend(availability: .unavailable(reason: "Older chip"), isOffline: false) == .cloudFallback)
    assert(AITriageRouter.selectBackend(availability: .unavailable(reason: "Disabled"), isOffline: true) == .deterministicRuleEngine)
    assert(AITriageRouter.validateTriage(severity: 9, summary: "Memory spike")?.0 == 5)
    assert(AITriageRouter.validateTriage(severity: 3, summary: "   ") == nil)
    print("  ✅ All tests passed!")
}
runTests()
