Production Networking with URLSession & HTTP Security

Async URLSession.shared.data(for:), status code validation, custom HTTP headers, timeout policies, and HTTP/3 support.

← Master Curriculum & Systems Legend • 📖 Swift Concurrency Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android, developers almost universally import third-party libraries (OkHttp + Retrofit) to execute network calls.

In iOS, URLSession is Apple's first-party, high-performance HTTP client. It supports HTTP/2, HTTP/3 (QUIC), connection pooling, background downloads, and async/await natively. Third-party networking libraries (like Alamofire) are rarely needed in modern Swift.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The Modern URLSession async Pipeline

enum HTTPError: Error, Equatable {
    case invalidResponse
    case statusCode(Int)
}

func executeRequest(url: URL) async throws -> Data {
    var request = URLRequest(url: url)
    request.httpMethod = "GET"
    request.setValue("application/json", forHTTPHeaderField: "Accept")
    request.timeoutInterval = 15.0

    let (data, response) = try await URLSession.shared.data(for: request)

    guard let httpResponse = response as? HTTPURLResponse else {
        throw HTTPError.invalidResponse
    }

    guard (200...299).contains(httpResponse.statusCode) else {
        throw HTTPError.statusCode(httpResponse.statusCode)
    }

    return data
}

2. URLSessionConfiguration Profiles

  • .default: Standard disk-persisted caching and credentials.
  • .ephemeral: In-memory only (private browsing / zero cache written to disk).
  • .background(withIdentifier:): Transfers continue even if the app is suspended or terminated by Darwin Jetsam!
⚠️ Senior Failure Mode & Anti-Pattern:

Ignoring HTTP Status Codes on Successful data(for:): A 404 Not Found or 500 Internal Server Error does NOT throw an error from URLSession.data(for:). It returns valid HTML/JSON error payloads. You must always inspect (response as? HTTPURLResponse)?.statusCode.

🔑 Reveal Final Reference Solution & Architecture Walkthrough 
import Foundation

enum NetworkError: Error, Equatable {
    case invalidResponse
    case httpStatus(Int)
}

func validateHTTPResponse(data: Data, response: URLResponse) throws -> Data {
    guard let http = response as? HTTPURLResponse else {
        throw NetworkError.invalidResponse
    }
    guard (200...299).contains(http.statusCode) else {
        throw NetworkError.httpStatus(http.statusCode)
    }
    return data
}

func runTests() {
    print("🧪 Running Lesson 2.8 Verification Tests...")
    let dummyURL = URL(string: "https://api.example.com/data")!
    let sampleData = "{\"status\":\"ok\"}".data(using: .utf8)!

    let resp200 = HTTPURLResponse(url: dummyURL, statusCode: 200, httpVersion: nil, headerFields: nil)!
    let valid = try! validateHTTPResponse(data: sampleData, response: resp200)
    assert(valid == sampleData)

    let resp404 = HTTPURLResponse(url: dummyURL, statusCode: 404, httpVersion: nil, headerFields: nil)!
    do {
        _ = try validateHTTPResponse(data: sampleData, response: resp404)
        fatalError()
    } catch NetworkError.httpStatus(let code) {
        assert(code == 404)
        print("  ✅ All tests passed!")
    } catch { fatalError() }
}
runTests()
Senior Engineering Walkthrough:

URLSession returns URLResponse as an abstract base type. Inspecting status code requires downcasting to HTTPURLResponse. Bounding status codes between 200 and 299 ensures client errors (4xx) and server errors (5xx) are categorized cleanly.
