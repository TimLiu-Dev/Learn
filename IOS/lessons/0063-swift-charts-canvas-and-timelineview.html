🧠 The Senior Android Anchor: Systems Comparison

In Android Compose, custom 60/120fps charts and particle drawings drop down to Compose Canvas(modifier) (DrawScope) so you don't allocate thousands of composable layout nodes.

In iOS, Apple provides Swift Charts for accessible, VoiceOver-ready declarative charts (with vectorized LinePlot for 10,000+ telemetry points) and Canvas + TimelineView for immediate-mode CoreGraphics rendering without polluting SwiftUI's AttributeGraph.

2. Immediate-Mode Canvas + TimelineView

⚠️ Senior Failure Mode & Anti-Pattern:

Rendering 5,000 Scatter Points as Individual Circle() Views Inside a ZStack: Creating thousands of SwiftUI View nodes exhausts CPU/memory inside AttributeGraph diffing and causes severe frame hitches. Use Canvas for custom high-density drawing or vectorized LinePlot/PointPlot in Swift Charts.

import Foundation

enum ChartMath {
    static func mapToCanvasY(value: Double, minValue: Double, maxValue: Double, height: Double) -> Double {
        guard maxValue > minValue else { return height / 2.0 }
        let normalized = (value - minValue) / (maxValue - minValue)
        return height * (1.0 - normalized)
    }
