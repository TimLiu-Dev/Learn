Thread Safety with Actors & The Reentrancy Hazard

Actor isolation boundaries, nonisolated declarations, and preventing silent state corruption across await suspension points.

← Master Curriculum & Systems Legend • 📖 Swift Concurrency Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android (Kotlin), thread safety relies on explicit locks (ReentrantLock, synchronized, Mutex.withLock { ... }) or atomic primitives. Traditional locks block the thread, risking deadlocks and priority inversions.

In Swift, thread safety is achieved natively via actor. An actor is a reference type that serializes access to its internal mutable state automatically. However, actors are reentrant: when an actor method reaches an await, it yields its thread to other callers!

⚡ Low-Level Core: How Swift Works Under the Hood

1. Actor Isolation & nonisolated Declarations

actor UserStore {
    var profile: Profile // Isolated state
    let storeId: String  // Immutable constant

    init(storeId: String, profile: Profile) {
        self.storeId = storeId
        self.profile = profile
    }

    // Can be accessed synchronously without 'await':
    nonisolated var id: String { storeId }
}

2. The Senior Reentrancy Hazard

Unlike mutex locks, actors do not freeze when suspended. Other tasks can execute methods on the same actor during an await:

actor AccountManager {
    var balance: Double = 100.0

    // ❌ REENTRANCY BUG:
    func withdraw(amount: Double) async throws {
        guard balance >= amount else { throw Error.insufficientFunds }
        // Suspension point: Thread yields! Another caller can withdraw!
        try await NetworkGateway.charge()
        balance -= amount // 💥 CORRUPTION: balance may now be negative!
    }

    // ✅ DEFENSIVE SENIOR PATTERN:
    func withdrawSafely(amount: Double) async throws {
        guard balance >= amount else { throw Error.insufficientFunds }
        try await NetworkGateway.charge()
        // Re-check invariants immediately after resumption:
        guard balance >= amount else { throw Error.insufficientFunds }
        balance -= amount
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Assuming Actor Invariants Across await: Any state checked before an await must be re-verified after the await resumes, because other callers may have mutated the actor during the suspension interval.

import Foundation

actor ImagePipelineCache {
    private var cachedImages: [URL: String] = [:]
    private var inFlightTasks: [URL: Task] = [:]

    func fetchImage(from url: URL) async throws -> String {
        if let existing = cachedImages[url] { return existing }
        if let runningTask = inFlightTasks[url] { return try await runningTask.value }

        let downloadTask = Task {
            try await Task.sleep(nanoseconds: 10_000_000)
            return "image_\(url.lastPathComponent)"
        }
        inFlightTasks[url] = downloadTask
        defer {
            inFlightTasks.removeValue(forKey: url)
        }

        let downloaded = try await downloadTask.value
        cachedImages[url] = downloaded
        return downloaded
    }

    var cacheCount: Int { cachedImages.count }
}

func runTests() async {
    print("🧪 Running Lesson 2.4 Verification Tests...")
    let cache = ImagePipelineCache()
    let url = URL(string: "https://cdn.example.com/avatars/user.png")!

    let results = await withTaskGroup(of: String?.self) { group in
        for _ in 0..<5 {
            group.addTask { try? await cache.fetchImage(from: url) }
        }
        var list: [String] = []
        for await res in group { if let res { list.append(res) } }
        return list
    }

    assert(results.count == 5)
    assert(results.allSatisfy { $0 == "image_user.png" })
    let count = await cache.cacheCount
    assert(count == 1)
    print("  ✅ All tests passed!")
}

await runTests()
Senior Engineering Walkthrough:

In an actor, checking and storing the running Task in inFlightTasks happens synchronously before the await suspension point. Subsequent concurrent callers find the existing Task and await its result, deduplicating duplicate network requests.
