🧠 The Senior Android Anchor: Systems Comparison

In Android, monetization uses Google Play Billing Library (BillingClient) and passwordless sign-in uses Jetpack Credential Manager (GetCredentialRequest).

In iOS, StoreKit 2 replaces legacy delegate-based receipts with async/await APIs and built-in JWS cryptographic verification (VerificationResult<Transaction>). For auth, Passkeys (ASAuthorizationPlatformPublicKeyCredentialProvider) bind WebAuthn credentials directly to Face ID and iCloud Keychain.

⚠️ Senior Failure Mode & Anti-Pattern:

Forgetting Transaction.updates or Granting Unverified Purchases: Only handling product.purchase() misses Family Sharing grants, Ask-to-Buy approvals, and subscription renewals that arrive later. Worse, unlocking pro features on .unverified transactions exposes your app to trivial jailbreak/proxy spoofing.

import Foundation

struct StoreTransaction {
    let id: UInt64
    let productID: String
    let revocationDate: Date?
}

enum VerificationOutcome {
    case verified(StoreTransaction)
    case unverified(StoreTransaction)
}

final class EntitlementEngine {
    private(set) var activeProducts: Set = []
    private(set) var finishedIDs: [UInt64] = []

    func process(_ outcome: VerificationOutcome) {
        switch outcome {
        case .unverified:
            return
        case .verified(let tx):
            if tx.revocationDate != nil {
                activeProducts.remove(tx.productID)
            } else {
                activeProducts.insert(tx.productID)
            }
            finishedIDs.append(tx.id)
        }
    }
}

func runTests() {
    print("🧪 Running Lesson 8.11 Verification Tests...")
    let engine = EntitlementEngine()
    engine.process(.unverified(StoreTransaction(id: 1, productID: "pro.yearly", revocationDate: nil)))
    assert(engine.activeProducts.isEmpty && engine.finishedIDs.isEmpty)

    engine.process(.verified(StoreTransaction(id: 2, productID: "pro.yearly", revocationDate: nil)))
    assert(engine.activeProducts == ["pro.yearly"] && engine.finishedIDs == [2])

    engine.process(.verified(StoreTransaction(id: 3, productID: "pro.yearly", revocationDate: Date())))
    assert(engine.activeProducts.isEmpty && engine.finishedIDs == [2, 3])
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

Filtering out .unverified payloads and honoring revocationDate for refunds protects revenue without server-side receipt polling, while calling finish() after entitlement update prevents duplicate processing.
