Structured Concurrency: async let & TaskGroup Hierarchies

Bounded child tasks, dynamic concurrency trees with withTaskGroup, and automatic cancellation propagation.

← Master Curriculum & Systems Legend • 📖 Swift Concurrency Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Kotlin Coroutines, structured concurrency is managed via coroutineScope { async { ... } } where child coroutines inherit the parent Job.

In Swift, structured concurrency is guaranteed via async let (fixed number of child tasks) and withTaskGroup / withThrowingTaskGroup (dynamic parallel tasks). When the parent scope exits or throws, all child tasks are cancelled automatically!

⚡ Low-Level Core: How Swift Works Under the Hood

1. Fixed Parallelism with async let

func loadDashboard() async throws -> Dashboard {
    async let profile = fetchProfile()
    async let notifications = fetchNotifications()
    async let settings = fetchSettings()
    return try await Dashboard(profile: profile, notifications: notifications, settings: settings)
}

2. Dynamic Parallelism with withTaskGroup

func fetchAllAvatars(ids: [String]) async throws -> [String: Data] {
    try await withThrowingTaskGroup(of: (String, Data).self) { group in
        for id in ids {
            group.addTask { (id, try await downloadImage(id: id)) }
        }
        var results: [String: Data] = [:]
        for try await (id, data) in group { results[id] = data }
        return results
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Unstructured Concurrency Leaks via Task { ... }: Unparented tasks created with Task { ... } do not cancel when screens dismiss, creating background memory and network leaks.

import Foundation

func fetchPrice(symbol: String) async -> (String, Double) {
    try? await Task.sleep(nanoseconds: 5_000_000)
    let mockPrices: [String: Double] = ["AAPL": 220.5, "GOOG": 175.0, "NVDA": 125.0]
    return (symbol, mockPrices[symbol] ?? 100.0)
}

func fetchBatchPrices(symbols: [String]) async -> [String: Double] {
    await withTaskGroup(of: (String, Double).self) { group in
        for symbol in symbols {
            group.addTask {
                await fetchPrice(symbol: symbol)
            }
        }
        var results: [String: Double] = [:]
        for await (sym, price) in group {
            results[sym] = price
        }
        return results
    }
}

func runTests() async {
    print("🧪 Running Lesson 2.2 Verification Tests...")
    let symbols = ["AAPL", "GOOG", "NVDA"]
    let prices = await fetchBatchPrices(symbols: symbols)
    assert(prices.count == 3)
    assert(prices["AAPL"] == 220.5)
    print("  ✅ All tests passed!")
}

await runTests()

withTaskGroup creates a structured concurrency scope where child tasks run in parallel on the cooperative thread pool. The parent task awaits results asynchronously using for await, maintaining complete lifetime bounding.
