Result Builders (@resultBuilder) & @ViewBuilder Mechanics

How buildBlock, buildOptional, buildEither, and buildArray desugar SwiftUI DSLs—and how to author custom type-safe builders.

← Master Curriculum & Systems Legend • 📖 SwiftUI Architecture Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Jetpack Compose, @Composable functions emit UI nodes imperatively into a Slot Table during execution, powered by a Kotlin compiler plugin.

In SwiftUI, there is no compiler plugin—instead, @ViewBuilder is a pure Swift @resultBuilder! At compile time, Swift rewrites multi-statement view closures into nested generic value types (TupleView and _ConditionalContent). Understanding this desugaring explains both SwiftUI structural identity and slow compiler type-check errors.

⚡ Low-Level Core: How Swift Works Under the Hood

1. How @ViewBuilder Desugars Your Code

// What you write:
@ViewBuilder
func statusBanner(isOnline: Bool) -> some View {
    Text("PulseFlow")
    if isOnline {
        Label("Connected", systemImage: "checkmark.circle")
    } else {
        Label("Offline", systemImage: "wifi.slash")
    }
}

// What the Swift compiler actually generates:
// TupleView<(Text, _ConditionalContent<Label, Label>)>
  • buildBlock: Combines sibling statements into a single tuple/composite value (in SwiftUI, variadic parameter packs remove the old 10-view limit!).
  • buildOptional / buildEither(first:second:): Translates if and if/else or switch branches into distinct static wrapper types, preserving compile-time type safety.
  • buildArray / buildLimitedAvailability: Handles loops (in custom builders) and if #available(...) checks.

2. Authoring Custom @resultBuilder DSLs

Senior engineers build custom @resultBuilder types for declarative validation pipelines, routing tables, or design-system form sections:

@resultBuilder
struct SectionBuilder<Item> {
    static func buildBlock(_ components: [Item]...) -> [Item] { components.flatMap { $0 } }
    static func buildExpression(_ item: Item) -> [Item] { [item] }
    static func buildOptional(_ component: [Item]?) -> [Item] { component ?? [] }
    static func buildEither(first: [Item]) -> [Item] { first }
    static func buildEither(second: [Item]) -> [Item] { second }
    static func buildArray(_ components: [[Item]]) -> [Item] { components.flatMap { $0 } }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Monolithic 200-Line body Closures & AnyView Type Erasure: Deeply nested @ViewBuilder expressions create massive generic type trees that cause "The compiler is unable to type-check this expression in reasonable time". Extract small subviews (using some View or @ViewBuilder helper properties)—never reach for AnyView, which destroys structural identity and disables AttributeGraph diffing.

import Foundation

struct MenuItem: Equatable {
    let title: String
}

@resultBuilder
struct MenuDSLBuilder {
    static func buildExpression(_ item: MenuItem) -> [MenuItem] {
        [item]
    }

    static func buildBlock(_ components: [MenuItem]...) -> [MenuItem] {
        components.flatMap { $0 }
    }

    static func buildOptional(_ component: [MenuItem]?) -> [MenuItem] {
        component ?? []
    }

    static func buildEither(first component: [MenuItem]) -> [MenuItem] {
        component
    }

    static func buildEither(second component: [MenuItem]) -> [MenuItem] {
        component
    }

    static func buildArray(_ components: [[MenuItem]]) -> [MenuItem] {
        components.flatMap { $0 }
    }
}

func buildMenu(@MenuDSLBuilder _ content: () -> [MenuItem]) -> [MenuItem] {
    content()
}

func runTests() {
    print("🧪 Running Lesson 9.1 Verification Tests...")
    let isAdmin = true
    let showBeta = false
    let dynamicTags = ["Logs", "Traces"]

    let items = buildMenu {
        MenuItem(title: "Home")
        if showBeta {
            MenuItem(title: "Beta")
        }
        if isAdmin {
            MenuItem(title: "Admin")
        } else {
            MenuItem(title: "User")
        }
        for tag in dynamicTags {
            MenuItem(title: tag)
        }
    }
    assert(items.map(\.title) == ["Home", "Admin", "Logs", "Traces"])
    print("  ✅ All tests passed!")
}
runTests()
