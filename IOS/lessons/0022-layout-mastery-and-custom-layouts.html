Layout Mastery & The Custom Layout Protocol

The 3-step layout negotiation algorithm, avoiding GeometryReader performance traps, and building custom Layout containers.

← Master Curriculum & Systems Legend • 📖 SwiftUI Architecture Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Jetpack Compose, custom layouts are built by implementing the Layout(content) { measurables, constraints -> ... } measuring and placing pass.

In SwiftUI (iOS 16+), the Layout protocol gives Senior engineers direct control over child sizing and placement via sizeThatFits and placeSubviews. This completely eliminates heavy, layout-thrashing GeometryReader wrappers.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The 3-Step Layout Negotiation Algorithm

  1. Parent proposes size: The parent container proposes a size (e.g. 300x100) to the child.
  2. Child chooses its size: The child determines its own actual dimensions based on its content (e.g. Text chooses 240x40).
  3. Parent places the child: The parent positions the child within its coordinate space (defaulting to center alignment).

2. Implementing the Custom Layout Protocol

struct FlowLayout: Layout {
    func sizeThatFits(proposal: ProposedViewSize, subviews: Subviews, cache: inout ()) -> CGSize {
        // Calculate container bounds
        return CGSize(width: proposal.width ?? 300, height: 200)
    }

    func placeSubviews(in bounds: CGRect, proposal: ProposedViewSize, subviews: Subviews, cache: inout ()) {
        var origin = bounds.origin
        for subview in subviews {
            subview.place(at: origin, proposal: .unspecified)
            origin.x += subview.sizeThatFits(.unspecified).width + 8
        }
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Overusing GeometryReader for Simple Sizing: GeometryReader eagerly expands to fill all available parent space, breaking layout flow and forcing extra passes. Avoid it whenever the Layout protocol or .frame(maxWidth: .infinity) suffices.

import Foundation

func calculateFlowWidths(itemWidths: [Double], spacing: Double) -> Double {
    guard !itemWidths.isEmpty else { return 0.0 }
    let itemsSum = itemWidths.reduce(0, +)
    let totalSpacing = Double(itemWidths.count - 1) * spacing
    return itemsSum + totalSpacing
}

func runTests() {
    print("🧪 Running Lesson 3.4 Verification Tests...")
    let widths = [50.0, 75.0, 100.0]
    let total = calculateFlowWidths(itemWidths: widths, spacing: 10.0)
    assert(total == 245.0)
    let emptyTotal = calculateFlowWidths(itemWidths: [], spacing: 10.0)
    assert(emptyTotal == 0.0)
    print("  ✅ All tests passed!")
}

Senior Engineering Walkthrough:

Custom Layout implementations in SwiftUI calculate layout dimensions during sizeThatFits. Summing child sizes with inter-element spacing enables flexible wrapping and flow containers with zero GeometryReader overhead.
