Production Observability: MetricKit & Apple Unified Logging

Apple Unified Logging (os.Logger), structured subsystems, privacy redaction (), and on-device MetricKit telemetry.

← Master Curriculum & Systems Legend • 📖 Testing & Profiling Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android, production logging uses Timber or Logcat, and telemetry relies on Firebase Crashlytics or Play Console Android Vitals.

In iOS, production logging uses Apple Unified Logging (os.Logger). It is kernel-buffered, zero-allocation, and automatically redacts Personally Identifiable Information (PII) to <private> in production console logs. Production telemetry is delivered directly on-device via MetricKit (MXMetricManager), reporting daily battery drain, hang rates, and dirty memory limits.

⚡ Low-Level Core: How Swift Works Under the Hood

1. Apple Unified Logging (os.Logger)

import OSLog

extension Logger {
    private static let subsystem = Bundle.main.bundleIdentifier ?? "com.pulseflow.app"
    static let auth = Logger(subsystem: subsystem, category: "authentication")
    static let network = Logger(subsystem: subsystem, category: "networking")
}

// Logging with privacy protection:
let userEmail = "dev@example.com"
Logger.auth.info("User signed in: \(userEmail, privacy: .private)")
// In production Console.app, prints: "User signed in: "!

2. MetricKit Daily Telemetry Payloads

Register an MXMetricManagerSubscriber. Once every 24 hours, Darwin delivers an MXMetricPayload containing:

  • Hang Rate: Seconds per hour the main thread was unresponsive.
  • Dirty Memory: Peak physical RAM consumed before Jetsam limits.
  • Thermal State: Device thermal throttling telemetry.
⚠️ Senior Failure Mode & Anti-Pattern:

Using print() in Production Code: print() formats strings synchronously, writes unencrypted plain text to system logs, leaks PII, and degrades main-thread performance. Always use os.Logger.

import Foundation

enum PrivacyLevel {
    case `public`
    case `private`
}

func logMessage(category: String, message: String, secret: String, privacy: PrivacyLevel) -> String {
    let formattedSecret = (privacy == .private) ? "" : secret
    return "[\(category.uppercased())] \(message) [\(formattedSecret)]"
}

func runTests() {
    print("🧪 Running Lesson 6.6 Verification Tests...")
    let priv = logMessage(category: "auth", message: "Login attempt", secret: "user_email@test.com", privacy: .private)
    assert(priv == "[AUTH] Login attempt []")

    let pub = logMessage(category: "net", message: "GET /status", secret: "200 OK", privacy: .public)
    assert(pub == "[NET] GET /status [200 OK]")
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

Apple Unified Logging censors interpolated values marked with privacy: .private in production release logs, preventing sensitive user credentials and tokens from leaking into system bug reports.
