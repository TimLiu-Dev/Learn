Enterprise Design Systems & Custom ViewModifiers

Design tokens, custom ViewModifier pipelines, ButtonStyles, typography scales, and dynamic dark mode palettes.

🧠 The Senior Android Anchor: Systems Comparison

In Jetpack Compose, design systems are built around MaterialTheme (Typography, ColorScheme, Shapes) and custom composable modifiers (Modifier.then(...)).

In SwiftUI, design systems are built using ViewModifier, custom ButtonStyle, and extension methods. Reusable modifiers encapsulate styling, border radius, shadows, and accessible contrast into declarative tokens.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The ViewModifier Anatomy

struct CardStyleModifier: ViewModifier {
    let cornerRadius: CGFloat
    let borderColor: Color

    func body(content: Content) -> some View {
        content
            .padding(16)
            .background(Color(.secondarySystemBackground))
            .cornerRadius(cornerRadius)
            .overlay(
                RoundedRectangle(cornerRadius: cornerRadius)
                    .stroke(borderColor, lineWidth: 1)
            )
    }
}

extension View {
    func cardStyle(radius: CGFloat = 12, border: Color = .gray.opacity(0.3)) -> some View {
        modifier(CardStyleModifier(cornerRadius: radius, borderColor: border))
    }
}

2. Custom ButtonStyles

A custom ButtonStyle controls pressed states, scale effects, and haptic feedback uniformly across the entire application.

⚠️ Senior Failure Mode & Anti-Pattern:

Hardcoding Colors and Spacing: Scattering raw hex colors (Color(hex: 0x0284C7)) and magic padding numbers across views makes dark mode and branding redesigns painful. Always route styles through semantic design tokens.

🔑 Reveal Final Reference Solution & Architecture Walkthrough 
import Foundation

struct DesignTokens {
    static func formatBadge(text: String, category: String) -> String {
        return "[\(category.uppercased())] \(text.uppercased())"
    }
}

func runTests() {
    print("🧪 Running Lesson 3.6 Verification Tests...")
    let badge = DesignTokens.formatBadge(text: "verified account", category: "security")
    assert(badge == "[SECURITY] VERIFIED ACCOUNT")
    print("  ✅ All tests passed!")
}
runTests()
