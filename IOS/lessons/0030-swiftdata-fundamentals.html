🧠 The Senior Android Anchor: Systems Comparison

In Android, local SQLite persistence is managed via Room ORM (@Entity, @Dao, @Database).

In iOS, SwiftData (iOS 17+) is Apple's modern, macro-powered persistence framework replacing legacy Core Data. Models are declared with @Model on standard Swift classes. CRUD operations execute via ModelContext, and SwiftUI views query data reactively using @Query.

⚡ Low-Level Core: How Swift Works Under the Hood

1. The SwiftData Architecture

  • @Model: Macro that transforms a Swift class into a managed persistence schema.
  • ModelContainer: Manages the schema and physical SQLite database storage.
  • ModelContext: Scratchpad tracking inserts, updates, and deletes before committing to disk.
  • @Query: SwiftUI property wrapper that automatically fetches and animates records.

2. Basic Model Definition

import SwiftData

@Model
final class DeviceReading {
    var id: String
    var timestamp: Date
    var metricValue: Double

    init(id: String, timestamp: Date = .now, metricValue: Double) {
        self.id = id
        self.timestamp = timestamp
        self.metricValue = metricValue
    }
}
⚠️ Senior Failure Mode & Anti-Pattern:

Accessing ModelContext Across Concurrency Domains: ModelContext is NOT thread-safe. A ModelContext created on the main thread must only be touched on the main thread. Background insertions require ModelActor or a dedicated background context.

import Foundation

struct ManagedItem: Equatable {
    let id: String
    var title: String
}

final class MockModelContext {
    private var storage: [String: ManagedItem] = [:]

    func insert(_ item: ManagedItem) {
        storage[item.id] = item
    }

    func fetchAll() -> [ManagedItem] {
        Array(storage.values)
    }
}

func runTests() {
    print("🧪 Running Lesson 4.3 Verification Tests...")
    let context = MockModelContext()
    context.insert(ManagedItem(id: "item_1", title: "Metrics"))
    context.insert(ManagedItem(id: "item_2", title: "Logs"))

    let items = context.fetchAll()
    assert(items.count == 2)
    assert(items.contains(ManagedItem(id: "item_1", title: "Metrics")))
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

ModelContext tracks object mutations in memory before flushing transactions to SQLite. Using persistent identifiers ensures relationships and object graphs remain deterministic across saves.
