Background Processing & Apple Push Notifications (APNs)

BGTaskScheduler (App Refresh & Processing), silent push notifications (content-available: 1), and device token registration.

← Master Curriculum & Systems Legend • 📖 Release & Ecosystem Cheatsheet • 📚 Systems Glossary

🧠 The Senior Android Anchor: Systems Comparison

In Android, background work uses WorkManager (OneTimeWorkRequest, PeriodicWorkRequest) and Firebase Cloud Messaging (FCM).

In iOS, background execution is strictly sandboxed and managed by Darwin's BGTaskScheduler (BGAppRefreshTask for quick data refreshes, BGProcessingTask for heavy maintenance while charging). Remote triggers rely on Apple Push Notification service (APNs) with silent notifications (content-available: 1) to wake the app for background data sync.

⚡ Low-Level Core: How Swift Works Under the Hood

1. BGTaskScheduler Architecture

import BackgroundTasks

func registerBackgroundTasks() {
    BGTaskScheduler.shared.register(
        forTaskWithIdentifier: "com.pulseflow.app.refresh",
        using: nil
    ) { task in
        handleAppRefresh(task: task as! BGAppRefreshTask)
    }
}

func scheduleNextRefresh() {
    let request = BGAppRefreshTaskRequest(identifier: "com.pulseflow.app.refresh")
    request.earliestBeginDate = Date(timeIntervalSinceNow: 15 * 60) // 15 mins
    try? BGTaskScheduler.shared.submit(request)
}

2. Handling Expiration in Background Tasks

Darwin grants a maximum of ~30 seconds for app refresh tasks. You must register an expirationHandler to cancel in-flight work and call setTaskCompleted(success: false) gracefully before the OS terminates your app.

⚠️ Senior Failure Mode & Anti-Pattern:

Forgetting to call setTaskCompleted(): Failing to call task.setTaskCompleted(success: true/false) causes Darwin to penalize your app's background budget. Subsequent scheduled background requests will be deferred or withheld by the system.

import Foundation

final class SimulatedBackgroundTask {
    private(set) var wasCancelled: Bool = false
    var shouldCancelEarly: Bool = false

    func executeWork() -> Bool {
        if shouldCancelEarly {
            wasCancelled = true
            return false
        }
        return true
    }
}

func runTests() {
    print("🧪 Running Lesson 7.2 Verification Tests...")
    let successTask = SimulatedBackgroundTask()
    assert(successTask.executeWork() == true)
    assert(successTask.wasCancelled == false)

    let cancelledTask = SimulatedBackgroundTask()
    cancelledTask.shouldCancelEarly = true
    assert(cancelledTask.executeWork() == false)
    assert(cancelledTask.wasCancelled == true)
    print("  ✅ All tests passed!")
}
runTests()
Senior Engineering Walkthrough:

BGTaskScheduler requires registering an expirationHandler. When Darwin signals expiration, cancelling cooperative tasks and marking completion ensures the app preserves its system background execution budget.
