# iOS Development Resources

## Knowledge

- [Apple Developer Documentation & Swift Documentation](https://developer.apple.com/documentation/swift)
  Official language reference, standard library documentation, and API guides. Use for: standard API contracts, foundation types, and framework updates.
- [The Swift Programming Language Book (Swift.org)](https://docs.swift.org/swift-book/)
  Authoritative, canonical guide to Swift syntax, memory management, concurrency, and semantics. Use for: deep dives into language features, ARC, and type system rules.
- [Apple Human Interface Guidelines (HIG)](https://developer.apple.com/design/human-interface-guidelines/)
  The design and user experience foundation for all Apple platforms. Use for: navigation models, typography, accessibility, and platform conventions.
- [Point-Free (Brandon Williams & Stephen Celis)](https://www.pointfree.co)
  Advanced functional programming, modular architecture, and modern Swift concurrency. Use for: deep structural insights, composition, and state modeling.
- [Donny Wals — Practical Swift Concurrency & Combine](https://www.donnywals.com)
  High-signal books and articles on modern async/await, actors, and reactive programming in Swift. Use for: concurrency patterns and async migrations.
- [WWDC Sessions (Apple)](https://developer.apple.com/videos/)
  Direct guidance from Apple engineers on new APIs, Instruments profiling, and Swift evolution. Use for: architectural best practices and debugging techniques.
- [Swift Evolution Proposals (apple/swift-evolution)](https://github.com/apple/swift-evolution)
  Detailed rationale behind Swift language design choices. Use for: understanding why Swift behaves the way it does compared to Kotlin.
- [Apple Developer: Foundation Models & App Intents](https://developer.apple.com/documentation/foundationmodels)
  Official Apple documentation for on-device guided generation (`@Generable`), tool calling, and system intelligence (`AppIntents`). Use for: integrating Apple Intelligence and Siri/Spotlight actions.
- [Apple Developer: StoreKit 2 & AuthenticationServices](https://developer.apple.com/documentation/storekit)
  Modern async JWS-verified in-app purchases and FIDO2 Passkeys authentication. Use for: subscription entitlements and passwordless sign-in.
- [GRDB.swift (Gwendal Roué)](https://github.com/groue/GRDB.swift)
  Production-grade Swift SQLite toolkit for concurrent database access, migrations, and observation. Use for: high-throughput offline-first persistence beyond SwiftData's limits.
- [swift-format (apple/swift-format)](https://github.com/swiftlang/swift-format)
  Official Swift toolchain formatter and linter. Use for: automated CI style gates and Xcode Build Tool Plugins.

## Wisdom (Communities)

- [r/iOSProgramming](https://reddit.com/r/iOSProgramming)
  Primary Reddit hub for iOS engineering discussion, portfolio critique, and job market insights. Use for: industry trends, resume reviews, and common interview questions.
- [iOS Dev Weekly (Dave Verwer)](https://iosdevweekly.com)
  Longest-running curated newsletter covering essential articles, tools, and releases. Use for: keeping pulse on community shifts and library updates.
- [Swift Forums (forums.swift.org)](https://forums.swift.org)
  Official forums where language designers and open source contributors discuss upcoming features and edge cases. Use for: bleeding-edge Swift language behavior.
- [Swift Discord (discord.gg/swiftlang)](https://discord.gg/swiftlang)
  Active community of iOS developers answering real-time questions. Use for: peer feedback and quick debugging sanity checks.
