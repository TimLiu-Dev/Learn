# Notes & Learner Profile

## Learner Background
- Current role: Junior Android Developer.
- Familiar technologies: Kotlin, Android SDK, Jetpack Compose, Coroutines, Flow, MVVM, Room, Retrofit, Gradle, Hilt/Koin.
- Target role: **Senior iOS Developer / Technical Lead Candidate**.
- Learning goal: Complete, rigorous end-to-end mastery of iOS platform engineering—from Swift compiler and memory runtime internals to advanced Swift 6 concurrency, performance optimization (Instruments, MetricKit, dyld launch time), resilient enterprise architectures, and flagship portfolio capstone.

## Teaching Preferences & Pedagogical Style
- **Senior-Level Bar**: Target the senior/staff technical interview bar. Focus not just on "how to write it," but on compiler mechanics, runtime trade-offs, dispatch costs (static vs witness table vs vtable vs message send), memory overhead (existential containers vs generics), and thread safety under high contention.
- **Bilingual Mental Model (Rosetta Stone)**: Bridge new Swift/iOS concepts to familiar Kotlin/Android concepts when introducing them, but immediately dive deeper into system-level differences (e.g., Darwin Jetsam memory eviction vs Android LMK, dyld dynamic linking vs Android DEX bytecode verification, ARC retain counts vs JVM generational garbage collection).
- **Code & Practice First**: Every lesson features production-standard code snippets, explicit failure modes/anti-patterns, and hands-on exercises with automated verification suites.
- **Desirable Difficulty & Retention**: Build durable storage strength via retrieval practice, deliberate edge-case debugging, and architectural trade-off evaluations.
