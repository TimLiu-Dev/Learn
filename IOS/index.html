🧭 The Rosetta Stone: Android/Kotlin ⇄ iOS/Swift

Use this interactive legend to translate Android and Kotlin instincts directly into idiomatic Swift. Filter by keyword to quickly cross-reference concepts.

Dimension Android / Kotlin Android iOS / Swift iOS Key Conceptual Shift & Trap to Avoid
Paradigm OOP + Functional (JVM classes, interfaces) Protocol-Oriented + Value Semantics Default to struct (value type). Memory is copied on write; stack-allocated by default.
Method Dispatch vtable dispatch for all open methods Static, Witness Table (PWT), Vtable & objc_msgSend Senior engineers optimize dispatch: static inline dispatch for structs, PWT for protocols, and dynamic dispatch when required.
Polymorphism Overhead Boxed interface references on JVM heap Generics (some P) vs Existentials (any P) some generates monomorphic specialized code; any allocates a 5-word existential container with heap boxing if > 3 words.
Memory Model JVM Tracing Garbage Collector Automatic Reference Counting (ARC) No GC pauses, but retain cycles cause silent, permanent memory leaks. Use [weak self] in escaping closures.
OS Memory Pressure Low Memory Killer (LMK) via oom_adj Darwin Kernel Jetsam iOS terminates background apps exceeding dirty memory limits without page swapping. Must monitor dirty memory vs clean memory.
Mutability val vs var let vs var let on a Swift value type enforces deep immutability on all stored properties, unlike JVM references.
Nullability Nullable types (String?), Elvis ?: Optionals (Optional<T>), ?? Swift Optionals are actual enums (.some(T), .none). Unwrap cleanly with guard let or if let.
Data Objects data class User(val id: String) struct User: Identifiable, Codable Swift structs synthesize initializers and conform to compiler-driven protocols without extra boilerplate.
Declarative UI Jetpack Compose (@Composable) SwiftUI (View protocol + body) Both rebuild views reactively, but SwiftUI relies on state property wrappers (@State, @Binding, @Observable).
State Streams StateFlow, SharedFlow @Observable (Observation macro), Combine iOS 17+ uses the @Observable macro. Views automatically register dependencies at property read time.
Async / Concurrency Coroutines, Dispatchers, Job Swift Concurrency (async/await, Task, Actor) Swift 6 enforces compile-time data race safety. Actors provide thread-isolated state; UI code requires @MainActor.
Networking Retrofit + OkHttp + Moshi URLSession + Codable No third-party networking library needed; first-party URLSession with async/await is industry standard.
Persistence Room ORM (SQLite) SwiftData / Core Data SwiftData uses Swift macros (@Model) to persist graphs directly with SwiftUI lifecycle integration.
Dependency Injection Hilt, Dagger 2, Koin @Environment, Protocol Factory DI Clean constructor injection with Swift protocols and SwiftUI Environment injection replace heavy annotation processors.
Build & Packages Gradle (build.gradle.kts) Swift Package Manager (SPM) Declarative, standardized package manifests (Package.swift) integrated directly into Xcode.
Unit Testing JUnit 5, Mockk, Turbine Swift Testing (@Test, #expect), XCTest The new Swift Testing framework replaces verbose XCTest boilerplate with macro-driven assertions and parameterized tests.
Diagnostics & Logging Timber, Logcat Apple Unified Logging (os.Logger, OSLog) Production iOS replaces print() with structured subsystem/category logging for privacy, performance, and Console.app filtering.
Privacy & Compliance Manifest permissions Privacy Manifest (PrivacyInfo.xcprivacy) Apple-mandated privacy declarations for required reason APIs and third-party SDK signature verification.
Profiling Android Studio Profiler, LeakCanary Xcode Instruments (Leaks, Time Profiler) Instruments profiles directly against Darwin kernel metrics, identifying exact allocation stacks and retain cycles.
